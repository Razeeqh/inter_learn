# PATTERN 1 — Position and electronic configuration

### Q1
The general electronic configuration of the d block elements is

(a) ns1-2 &nbsp; (b) (n-1)d1-10 ns1-2 &nbsp; (c) (n-2)f1-14 ns2 &nbsp; (d) ns2 np1-6

**ANSWER: (b)** — the last electron enters the (n-1)d orbital.

---

### Q2
The correct electronic configuration of chromium (Z = 24) is

(a) [Ar] 3d4 4s2 &nbsp; (b) [Ar] 3d5 4s1 &nbsp; (c) [Ar] 3d6 &nbsp; (d) [Ar] 4s2 4p4

**ANSWER: (b)**
```
  A HALF-FILLED 3d5 subshell is extra stable (greater symmetry and
  greater exchange energy), so one 4s electron shifts into 3d.
```

---

### Q3
The electronic configuration of Cu2+ is

(a) 3d9 &nbsp; (b) 3d10 &nbsp; (c) 3d8 4s1 &nbsp; (d) 3d9 4s2

**ANSWER: (a)**
```
  Cu = [Ar] 3d10 4s1.  Remove the 4s electron FIRST, then one 3d.
  Cu2+ = 3d9
```

> **SHORTCUT:** For ANY transition metal ion, take the group-position electron
> count and just subtract the charge from the d count after emptying the s
> shell. In one line: **"ns out first, always."**

---

### Q4
Which of the following is NOT a transition element?

(a) Sc &nbsp; (b) Cu &nbsp; (c) Zn &nbsp; (d) Fe

**ANSWER: (c)**
```
  Zn = [Ar]3d10 4s2 and Zn2+ = 3d10. The d subshell is COMPLETELY
  FILLED in both the atom and the ion, so there is no partly filled
  d subshell.  Cu counts because Cu2+ is 3d9 (partly filled).
```

---

### Q5
The number of elements in each complete transition series is

(a) 8 &nbsp; (b) 10 &nbsp; (c) 14 &nbsp; (d) 18

**ANSWER: (b)** — a d subshell holds 10 electrons.

---

### Q6
The 3d transition series begins with

(a) Ca &nbsp; (b) Sc &nbsp; (c) Ti &nbsp; (d) K

**ANSWER: (b)** — Sc (Z = 21), configuration [Ar] 3d1 4s2.

# PATTERN 2 — Physical properties and trends

### Q7
The element with the highest melting point in the 3d series is

(a) Sc &nbsp; (b) Cr &nbsp; (c) Fe &nbsp; (d) Zn

**ANSWER: (b)**
```
  Cr has the maximum number of unpaired d electrons available for
  metallic bonding, so it has the strongest metallic bond.
  Zn is the LOWEST (d10 full, no d participation).
```

> **SHORTCUT:** Melting point across a series is a **hill** — low at the ends,
> peak in the middle. Mn is a small dip in the hill (stable 3d5 4s2).

---

### Q8
Which pair of elements has almost the same atomic radius?

(a) Ti and Zr &nbsp; (b) Zr and Hf &nbsp; (c) Sc and Y &nbsp; (d) V and Cr

**ANSWER: (b)**
```
  Zr = 160 pm , Hf = 159 pm.
  The 14 lanthanoids lie between them, and the LANTHANOID CONTRACTION
  cancels the size increase expected from the extra shell.
```

> **SHORTCUT:** The three "twin pairs" to remember: **Zr/Hf, Nb/Ta, Mo/W.**

---

### Q9
Atomic radii of the 3d elements remain almost constant from Cr to Ni because

(a) nuclear charge does not change
(b) increasing nuclear charge is balanced by increasing d-d repulsion and screening
(c) the elements are all in the same group
(d) they all have the same number of electrons

**ANSWER: (b)**

---

### Q10
The first ionisation enthalpy is highest for which 3d element?

(a) Sc &nbsp; (b) Mn &nbsp; (c) Cu &nbsp; (d) Zn

**ANSWER: (d)** — Zn (906 kJ/mol), because of its stable, fully filled
3d10 4s2 configuration.

---

### Q11
Mercury is a liquid at room temperature because

(a) it has a very high atomic mass
(b) its 5d10 shell is full so only the 6s electrons take part in metallic bonding
(c) it has unpaired d electrons
(d) it is radioactive

**ANSWER: (b)** — weak metallic bonding, so a very low melting point.

# PATTERN 3 — Oxidation states

### Q12
The element showing the maximum number of oxidation states in the 3d series is

(a) Cr &nbsp; (b) Mn &nbsp; (c) Fe &nbsp; (d) Cu

**ANSWER: (b)**
```
  Mn = [Ar]3d5 4s2 has 5 + 2 = 7 available electrons, giving the
  oxidation states +2, +3, +4, +5, +6 and +7.
```

---

### Q13
Transition elements show variable oxidation states because

(a) their d orbitals are empty
(b) (n-1)d and ns orbitals have nearly the same energy
(c) they are all radioactive
(d) they have large atomic size

**ANSWER: (b)**

---

### Q14
The oxidation state of Mn in KMnO4 is

(a) +2 &nbsp; (b) +4 &nbsp; (c) +6 &nbsp; (d) +7

**ANSWER: (d)**
```
  K = +1 , 4 O = -8  ->  Mn = +7
```

---

### Q15
The oxidation state of Cr in K2Cr2O7 is

(a) +3 &nbsp; (b) +5 &nbsp; (c) +6 &nbsp; (d) +7

**ANSWER: (c)**
```
  2 K = +2 , 7 O = -14  ->  2 Cr = +12  ->  each Cr = +6
```

---

### Q16
The oxidation state of nickel in Ni(CO)4 is

(a) 0 &nbsp; (b) +2 &nbsp; (c) +4 &nbsp; (d) -2

**ANSWER: (a)** — CO is a neutral ligand, so nickel is in the ZERO
oxidation state. Low oxidation states occur with pi-acceptor ligands like CO.

---

### Q17
Which of these is more stable and why?

(a) Fe2+ because it is 3d6 &nbsp; (b) Fe3+ because it is 3d5
(c) Fe2+ because it has fewer charges &nbsp; (d) both are equally stable

**ANSWER: (b)** — Fe3+ is 3d5, a HALF-FILLED and extra stable configuration.
That is why Fe2+ solutions slowly oxidise to Fe3+ in air.

---

### Q18
The highest oxidation states of transition metals are found in their

(a) hydrides &nbsp; (b) chlorides &nbsp; (c) oxides and fluorides &nbsp; (d) sulphides

**ANSWER: (c)** — O and F are the most electronegative and can stabilise a
very high positive charge. Examples: MnO4- (+7), CrO4 2- (+6), OsF6 (+6).

# PATTERN 4 — Magnetic moment (the calculation questions)

### Q19
The spin-only magnetic moment of Mn2+ is

(a) 1.73 BM &nbsp; (b) 3.87 BM &nbsp; (c) 4.90 BM &nbsp; (d) 5.92 BM

**ANSWER: (d)**
```
  Mn = [Ar]3d5 4s2  ->  Mn2+ = 3d5  ->  n = 5
  mu = sqrt(5 x 7) = sqrt 35 = 5.92 BM
```

> **SHORTCUT — MEMORISE THE LIST, NEVER CALCULATE:**
> ```
>    n  =  0     1      2      3      4      5
>    mu =  0.00  1.73   2.83   3.87   4.90   5.92
> ```
> If your answer is not one of those six numbers, it is wrong.

---

### Q20
An ion has a magnetic moment of 3.87 BM. The number of unpaired electrons is

(a) 1 &nbsp; (b) 2 &nbsp; (c) 3 &nbsp; (d) 4

**ANSWER: (c)** — 3.87 corresponds to n = 3 (for example Cr3+ or V2+ or Co2+).

---

### Q21
Which of the following ions is diamagnetic?

(a) Fe2+ &nbsp; (b) Cu2+ &nbsp; (c) Zn2+ &nbsp; (d) Ni2+

**ANSWER: (c)** — Zn2+ is 3d10, all electrons paired, n = 0, mu = 0.

---

### Q22
The magnetic moment of Cr3+ is

(a) 1.73 BM &nbsp; (b) 2.83 BM &nbsp; (c) 3.87 BM &nbsp; (d) 5.92 BM

**ANSWER: (c)**
```
  Cr = [Ar]3d5 4s1 -> Cr3+ = 3d3  ->  n = 3  ->  mu = sqrt 15 = 3.87 BM
```

---

### Q23
Which of the following has the highest number of unpaired electrons?

(a) Fe2+ &nbsp; (b) Fe3+ &nbsp; (c) Co2+ &nbsp; (d) Ni2+

**ANSWER: (b)** — Fe3+ is 3d5 with 5 unpaired; Fe2+ (3d6) has 4,
Co2+ (3d7) has 3, Ni2+ (3d8) has 2.

# PATTERN 5 — Colour of the ions

### Q24
Which of the following aqueous ions is COLOURLESS?

(a) Cu2+ &nbsp; (b) Ni2+ &nbsp; (c) Sc3+ &nbsp; (d) Co2+

**ANSWER: (c)** — Sc3+ is 3d0. With no d electron there can be no d-d
transition, so it is colourless.

> **SHORTCUT:** Only two configurations are colourless — **d0 and d10.**
> Scan the options, work out the d count, and pick the one that hits 0 or 10.
> Common colourless ions: **Sc3+, Ti4+, Cu+, Zn2+, Cd2+, Hg2+, Ag+.**

---

### Q25
The colour of transition metal ions is due to

(a) charge transfer &nbsp; (b) d-d transition
(c) nuclear transition &nbsp; (d) s-p transition

**ANSWER: (b)** — for ions with a partly filled d subshell.

---

### Q26
KMnO4 is intensely purple even though Mn is in the +7 state (3d0). The colour
is due to

(a) d-d transition &nbsp; (b) charge transfer &nbsp; (c) paramagnetism &nbsp; (d) hydration

**ANSWER: (b)**
```
  Mn7+ is 3d0, so there is NO d electron to make a d-d jump.
  An electron momentarily transfers from an oxygen to the manganese
  - a CHARGE TRANSFER transition.
  The same is true of the orange colour of K2Cr2O7 (Cr6+ = 3d0).
```

---

### Q27
The blue colour of an aqueous CuSO4 solution is due to the ion

(a) Cu+ (3d10) &nbsp; (b) Cu2+ (3d9) &nbsp; (c) SO4 2- &nbsp; (d) Cu metal

**ANSWER: (b)**

# PATTERN 6 — Electrode potentials

### Q28
Which of the following has a POSITIVE standard electrode potential E°(M2+/M)?

(a) Zn &nbsp; (b) Fe &nbsp; (c) Cu &nbsp; (d) Mn

**ANSWER: (c)** — E°(Cu2+/Cu) = +0.34 V. It is the only positive value in

E°(Mn2+/Mn) is unusually negative (-1.18 V) because

### Q30
Which metal does NOT liberate hydrogen from dilute HCl?

(a) Zn &nbsp; (b) Fe &nbsp; (c) Mg &nbsp; (d) Cu

**ANSWER: (d)** — copper's E° is positive, so it lies below hydrogen in the
activity series.

# PATTERN 7 — Potassium dichromate

### Q31
The ore used for the manufacture of potassium dichromate is

(a) pyrolusite &nbsp; (b) chromite &nbsp; (c) haematite &nbsp; (d) bauxite

**ANSWER: (b)** — chromite, FeCr2O4 (also written FeO.Cr2O3).

> **SHORTCUT:** **CHROM**ite gives **CHROM**ate. **PYRO**lusite gives
> per**MANGAN**ate. The ore name always contains a clue to the product.

---

### Q32
On adding alkali to an orange solution of K2Cr2O7, the colour changes to

(a) green &nbsp; (b) yellow &nbsp; (c) blue &nbsp; (d) colourless

**ANSWER: (b)**
```
  Cr2O7 2- + 2 OH-  ->  2 CrO4 2- + H2O
   ORANGE                 YELLOW
  Acid reverses it back to orange. Cr stays +6 - not a redox change.
```

---

### Q33
In the dichromate ion Cr2O7 2-, the Cr - O - Cr bond angle is about

(a) 90 degrees &nbsp; (b) 109.5 degrees &nbsp; (c) 126 degrees &nbsp; (d) 180 degrees

**ANSWER: (c)** — two tetrahedra joined through one bridging oxygen at
about 126 degrees.

---

### Q34
One mole of acidified K2Cr2O7 oxidises how many moles of Fe2+?

(a) 2 &nbsp; (b) 3 &nbsp; (c) 5 &nbsp; (d) 6

**ANSWER: (d)**
```
  Cr2O7 2- + 14 H+ + 6 e- -> 2 Cr3+ + 7 H2O    (gains 6 electrons)
  Each Fe2+ gives 1 electron, so 6 moles of Fe2+ are oxidised.
```

> **SHORTCUT — the two "n-factor" numbers that solve almost every
> equivalent-weight question:**
> ```
>    K2Cr2O7 in acid  ->  n = 6  ->  eq. wt = 294 / 6 = 49
>    KMnO4   in acid  ->  n = 5  ->  eq. wt = 158 / 5 = 31.6
>    KMnO4   neutral  ->  n = 3  ->  eq. wt = 158 / 3 = 52.7
>    KMnO4   alkaline ->  n = 1  ->  eq. wt = 158
> ```

---

### Q35
Acidified K2Cr2O7 solution turns from orange to which colour on reduction?

(a) yellow &nbsp; (b) green &nbsp; (c) purple &nbsp; (d) brown

**ANSWER: (b)** — the green Cr3+ ion is formed.

# PATTERN 8 — Potassium permanganate

### Q36
When MnO2 is fused with KOH in the presence of air, the product is

(a) KMnO4 &nbsp; (b) K2MnO4 &nbsp; (c) Mn2O3 &nbsp; (d) MnSO4

**ANSWER: (b)**
```
  2 MnO2 + 4 KOH + O2 --(fused)--> 2 K2MnO4 + 2 H2O
  K2MnO4 is DARK GREEN, and Mn is in the +6 state.
```

---

### Q37
In acidic medium, KMnO4 is reduced to

(a) MnO2 &nbsp; (b) MnO4 2- &nbsp; (c) Mn2+ &nbsp; (d) Mn metal

**ANSWER: (c)**
```
  MnO4- + 8 H+ + 5 e-  ->  Mn2+ + 4 H2O
  purple                  colourless      (5 electrons)
```

---

### Q38
In neutral or faintly alkaline medium, KMnO4 is reduced to

(a) Mn2+ &nbsp; (b) MnO2 &nbsp; (c) MnO4 2- &nbsp; (d) MnO

**ANSWER: (b)**
```
  MnO4- + 2 H2O + 3 e-  ->  MnO2 + 4 OH-      (brown solid, 3 electrons)
```

> **SHORTCUT — the "5, 3, 1" rule for KMnO4:**
> ```
>    ACID     -> Mn2+     -> 5 electrons -> colourless
>    NEUTRAL  -> MnO2     -> 3 electrons -> brown
>    ALKALINE -> MnO4 2-  -> 1 electron  -> green
> ```

---

### Q39
The shape of the permanganate ion MnO4- is

(a) square planar &nbsp; (b) tetrahedral &nbsp; (c) octahedral &nbsp; (d) linear

**ANSWER: (b)** — tetrahedral, all four Mn-O bonds identical, diamagnetic.

---

### Q40
Baeyer's reagent, used to test for unsaturation, is

(a) acidified KMnO4 &nbsp; (b) cold dilute alkaline KMnO4
(c) acidified K2Cr2O7 &nbsp; (d) bromine water

**ANSWER: (b)** — the purple colour is discharged by an alkene.

---

### Q41
In neutral medium, KMnO4 oxidises iodide ion to

(a) I2 &nbsp; (b) IO3- &nbsp; (c) IO4- &nbsp; (d) HI

**ANSWER: (b)**
```
  2 MnO4- + H2O + I-  ->  2 MnO2 + 2 OH- + IO3-
  In ACIDIC medium, however, I- is oxidised only to I2.
```

# PATTERN 9 — Catalysis, complexes, interstitial compounds, alloys

### Q42
The catalyst used in the Contact process is

(a) Fe &nbsp; (b) V2O5 &nbsp; (c) Ni &nbsp; (d) MnO2

**ANSWER: (b)** — V2O5 for 2 SO2 + O2 -> 2 SO3. (Fe is the Haber process,
Ni is hydrogenation of oils.)

---

### Q43
Which of the following is an interstitial compound?

(a) NaCl &nbsp; (b) TiC &nbsp; (c) CuSO4 &nbsp; (d) K2Cr2O7

**ANSWER: (b)** — a small carbon atom sits in a hole in the titanium
lattice. Interstitial compounds are hard, high melting, non-stoichiometric
and chemically inert.

---

### Q44
Transition metals form alloys readily because

(a) they are radioactive &nbsp; (b) their atomic radii are very similar
(c) they have full d orbitals &nbsp; (d) they are non-metals

**ANSWER: (b)** — one metal atom can substitute for another in the lattice
without disturbing the structure.

---

### Q45
Transition elements form complexes because of

(a) small size, high charge and vacant d orbitals
(b) large size and low charge
(c) radioactivity
(d) completely filled d orbitals

**ANSWER: (a)**

---

### Q46
German silver is an alloy of

(a) Ag + Cu &nbsp; (b) Cu + Zn + Ni &nbsp; (c) Cu + Sn &nbsp; (d) Fe + Cr + Ni

**ANSWER: (b)** — it contains NO silver at all. (Brass = Cu + Zn,
bronze = Cu + Sn, stainless steel = Fe + Cr + Ni.)

# PATTERN 10 — The f block

### Q47
The number of lanthanoid elements is

(a) 10 &nbsp; (b) 14 &nbsp; (c) 15 &nbsp; (d) 18

**ANSWER: (b)** — Ce (58) to Lu (71), because the 4f subshell holds
14 electrons.

---

### Q48
Lanthanoid contraction is caused by

(a) good shielding by 4f electrons &nbsp; (b) poor shielding by 4f electrons
(c) decreasing nuclear charge &nbsp; (d) increasing number of shells

**ANSWER: (b)** — 4f orbitals have a diffuse charge cloud and shield the
outer electrons poorly, so the effective nuclear charge keeps rising.

---

### Q49
The most common oxidation state of the lanthanoids is

(a) +2 &nbsp; (b) +3 &nbsp; (c) +4 &nbsp; (d) +6

**ANSWER: (b)**

---

### Q50
Ce4+ acts as a good oxidising agent because

(a) it has a 4f0 configuration and readily returns to the stable Ce3+
(b) it is radioactive
(c) it is a large ion
(d) it has 14 f electrons

**ANSWER: (a)**

> **SHORTCUT:** Any unusual lanthanoid oxidation state exists because the ion
> lands on **4f0, 4f7 or 4f14**.
> ```
>    Ce4+ = 4f0    Eu2+ = 4f7    Tb4+ = 4f7    Yb2+ = 4f14
> ```

---

### Q51
Misch metal consists of

(a) 95% lanthanoid + 5% Fe &nbsp; (b) 95% Fe + 5% lanthanoid
(c) pure cerium &nbsp; (d) Cu + Zn

**ANSWER: (a)** — used in lighter flints, bullets and shells.

---

### Q52
Which statement about the actinoids is correct?

(a) none of them is radioactive &nbsp; (b) all of them are radioactive
(c) only uranium is radioactive &nbsp; (d) they show only the +3 state

**ANSWER: (b)** — all actinoids are radioactive, and elements beyond
uranium (transuranic) are man-made.

---

### Q53
Actinoid contraction is greater than lanthanoid contraction because

(a) 5f electrons shield even more poorly than 4f electrons
(b) actinoids are lighter
(c) actinoids have fewer electrons
(d) 5f orbitals are closer to the nucleus

**ANSWER: (a)**

---

### Q54
The general electronic configuration of the actinoids is

(a) [Xe] 4f1-14 5d0-1 6s2 &nbsp; (b) [Rn] 5f1-14 6d0-1 7s2
(c) [Kr] 4d1-10 5s1-2 &nbsp; (d) [Ar] 3d1-10 4s1-2

**ANSWER: (b)**

---

### Q55
Which of the following is NOT a consequence of lanthanoid contraction?

(a) Zr and Hf have almost the same size
(b) separation of lanthanoids is difficult
(c) basicity of hydroxides decreases from La(OH)3 to Lu(OH)3
(d) all lanthanoids become radioactive

**ANSWER: (d)** — radioactivity has nothing to do with size. Only
promethium among the lanthanoids is radioactive.
