# The d and f Block Elements — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The element in the question changes every year.
The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — DEFINE A TRANSITION ELEMENT / WHY THE NAME             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are transition elements?" / "Why are they called
            transition elements?"
  METHOD    1. Definition: an element whose ATOM has a partly filled
               d subshell, OR which gives rise to CATIONS with a partly
               filled d subshell.
            2. Name: they lie BETWEEN the metallic s block and the
               non-metallic p block, and their properties change
               gradually from one to the other.
            3. General configuration:  (n-1) d 1-10   n s 1-2
  TRAP      Do NOT drop the "or its cations" half of the definition.
            Without it you cannot justify copper (Cu is 3d10, but
            Cu2+ is 3d9).
```

```
  PATTERN 2 — WHY Zn, Cd, Hg ARE NOT TYPICAL                         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is zinc not regarded as a transition element?" /
            "Which of Sc, Cu, Zn is not a transition element?"
  METHOD    1. Write the configurations:
                 Zn = [Ar]3d10 4s2 , Cd = [Kr]4d10 5s2 ,
                 Hg = [Xe]4f14 5d10 6s2
            2. Write the ion: M2+ = d10 in every case.
            3. Conclude: the d subshell is COMPLETELY FILLED in the
               atom AND in the ion, so there is NO partly filled d
               subshell. They fail the definition.
            4. Bonus mark: therefore no colour, no paramagnetism, no
               variable oxidation state, low melting point.
  TRAP      Copper IS a transition element even though Cu is 3d10,
            because Cu2+ is 3d9. Do not group Cu with Zn.
```

```
  PATTERN 3 — WRITE THE ELECTRONIC CONFIGURATION OF AN ELEMENT       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the electronic configuration of Cr / Cu / Fe ..."
  METHOD    1. Use [Ar] for the first series, [Kr] for the second,
               [Xe] for the third.
            2. Fill 4s before 3d (Aufbau).
            3. Apply the TWO EXCEPTIONS:
                 Cr = [Ar] 3d5  4s1
                 Cu = [Ar] 3d10 4s1
  TRAP      Writing Cr as 3d4 4s2. The examiner is specifically
            looking for 3d5 4s1.
```

```
  PATTERN 4 — WHY ARE Cr AND Cu EXCEPTIONAL                          2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain why Cr is 3d5 4s1" / "Account for the anomalous
            configuration of copper."
  METHOD    1. Write the expected and the actual configuration side
               by side.
            2. Give the reason in TWO parts:
                 - exactly half-filled (d5) and completely filled (d10)
                   subshells are SYMMETRICAL, hence lower in energy;
                 - they give the MAXIMUM EXCHANGE ENERGY, because more
                   parallel-spin electrons means more possible swaps,
                   and every swap releases energy.
            3. Draw the orbital boxes if space allows.
  TRAP      "It is more stable" alone is not an answer. You must say
            SYMMETRY and EXCHANGE ENERGY.
```

```
  PATTERN 5 — CONFIGURATION OF AN ION (M2+ or M3+)                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the configuration of Fe2+ / Fe3+ / Cu2+ / Mn2+."
  METHOD    1. Write the ATOM's configuration first.
            2. Remove the ns electrons FIRST, then (n-1)d electrons.
            3. Quote the special stability if it applies:
                 Fe3+ = 3d5 (half-filled) -> more stable than Fe2+
  TRAP      *** THE NUMBER ONE MISTAKE IN THE WHOLE CHAPTER ***
            Fe2+ is 3d6, NOT 3d4 4s2. ns electrons ALWAYS leave first.
```

```
  PATTERN 6 — SPIN-ONLY MAGNETIC MOMENT CALCULATION              2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the magnetic moment of ..." / "Bohr Magneton" /
            "How many unpaired electrons ...".
  METHOD    1. Configuration of the ATOM.
            2. Remove ns electrons first -> configuration of the ION.
            3. Fill the five d boxes SINGLY first (Hund's rule),
               then pair.
            4. Count n = unpaired electrons.
            5.        mu = sqrt( n ( n + 2 ) )   BM
            6. Check against the list:
                 0 , 1.73 , 2.83 , 3.87 , 4.90 , 5.92
  TRAP      Never count 4s electrons for an ion - they are gone.
            Always write the unit BM.
```

```
  PATTERN 7 — GO BACKWARDS FROM mu TO n                              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "An ion has a magnetic moment of 3.87 BM. Find the number
            of unpaired electrons / identify the ion."
  METHOD    1. Square the value:   3.87^2 = 15  (approximately)
            2. Solve n(n+2) = 15  ->  n = 3
            3. Name a matching ion: Cr3+ (3d3), V2+ (3d3), Co2+ (3d7).
  SHORTCUT  Just read the memorised list backwards. Do not do algebra.
```

```
  PATTERN 8 — PARAMAGNETIC OR DIAMAGNETIC?                          objective
  ------------------------------------------------------------------------
  TRIGGER   "Which of the following is diamagnetic?"
  METHOD    ONE LINE ANSWERS ALL OF THEM:

                 d0 or d10   ->  DIAMAGNETIC  (mu = 0)
                 d1 to d9    ->  PARAMAGNETIC

            Common diamagnetic ions: Sc3+, Ti4+, Cu+, Zn2+, Cd2+, Hg2+.
```

```
  PATTERN 9 — WHY ARE TRANSITION IONS COLOURED?                      4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the colour of transition metal ions" / "Why is
            CuSO4 blue but ZnSO4 colourless?"
  METHOD    1. State the condition: a PARTLY FILLED d subshell.
            2. Ligands SPLIT the five d orbitals into two sets with a
               small energy gap - draw the two-level diagram.
            3. An electron absorbs visible light and jumps up:
               a d-d TRANSITION.
            4. The COMPLEMENTARY colour of the absorbed light is seen.
            5. Give examples AND the colourless exceptions:
               Sc3+ (d0) and Zn2+ (d10) are colourless.
  TRAP      KMnO4 and K2Cr2O7 are d0 and are still deeply coloured.
            Their colour is CHARGE TRANSFER, not a d-d transition.
            If the question names KMnO4, "d-d transition" is WRONG.
```

```
  PATTERN 10 — VARIABLE OXIDATION STATES                         2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why do transition elements show variable oxidation
            states?" / "Which shows the maximum number?"
  METHOD    1. REASON: (n-1)d and ns orbitals have almost the SAME
               energy, so both s electrons and a variable number of
               d electrons can be lost.
            2. Hence the states differ by ONE unit (contrast: p block
               differs by two).
            3. Mn shows the MAXIMUM (+2 to +7) because it has 5 d + 2 s
               = 7 available electrons.
            4. The number rises to Mn then falls, because after Mn the
               d electrons start PAIRING and are held more tightly.
            5. Highest states occur only in OXIDES and FLUORIDES.
  TRAP      Do not say "because they have d orbitals". Say the d and s
            ENERGIES ARE CLOSE.
```

```
  PATTERN 11 — STABILITY OF A PARTICULAR OXIDATION STATE            objective
  ------------------------------------------------------------------------
  TRIGGER   "Which is more stable, Fe2+ or Fe3+?" / "Why is Mn2+ so
            stable?"
  METHOD    Work out the d configuration of the ION and look for
                 d5  (half-filled)   or   d10 (fully filled)
            Fe3+ = 3d5 -> more stable than Fe2+ (3d6)
            Mn2+ = 3d5 -> very stable
            Zn2+ = 3d10 -> very stable
  TRAP      Higher charge does NOT automatically mean less stable.
            The d count decides it.
```

```
  PATTERN 12 — ATOMIC / IONIC RADII TREND                            4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the variation of atomic radii across the 3d
            series" / "Why is the size almost constant in the middle?"
  METHOD    1. Quote the numbers: 164, 147, 135, 129, 137, 126, 125,
               125, 128, 137 pm.
            2. START falls sharply - nuclear charge rises, electron
               enters the SAME inner d shell.
            3. MIDDLE almost constant - increasing nuclear charge
               (pulls in) is cancelled by increasing d-d repulsion
               and screening (pushes out).
            4. END rises slightly - repulsion in the nearly full d
               shell wins.
  TRAP      The word "cancel" or "balance" must appear for part 3.
            "Because of the lanthanoid contraction" is WRONG here -
            that applies going DOWN a group, not across a series.
```

```
  PATTERN 13 — LANTHANOID CONTRACTION                            2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is lanthanoid contraction?" / "Give its causes and
            consequences." / "Why do Zr and Hf have the same size?"
  METHOD    1. DEFINITION: the steady decrease in atomic and ionic
               radii from La (57) to Lu (71).
               (La3+ = 103 pm down to Lu3+ = 86 pm)
            2. CAUSE: the added electron enters the inner 4f subshell,
               and 4f electrons SHIELD very POORLY, so the effective
               nuclear charge on the outer electrons keeps increasing.
            3. FOUR CONSEQUENCES:
                 (i)   4d and 5d elements have nearly the same size -
                       Zr/Hf, Nb/Ta, Mo/W behave as twin pairs;
                 (ii)  the lanthanoids are very hard to separate;
                 (iii) basicity falls: La(OH)3 most basic ->
                       Lu(OH)3 least basic;
                 (iv)  complex-forming ability increases La3+ -> Lu3+.
  TRAP      The magic phrase is "POOR SHIELDING BY 4f ELECTRONS".
            Without it you lose the reason mark.
```

```
  PATTERN 14 — STANDARD ELECTRODE POTENTIAL ANOMALIES                4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the anomalous E° values of Mn, Ni and Zn" /
            "Why is E°(Cu2+/Cu) positive?"
  METHOD    1. Quote the values row.
            2. State the general trend: less negative going right.
            3. Give each reason:
                 Mn (-1.18)  Mn2+ is 3d5 half-filled and stable
                 Zn (-0.76)  Zn2+ is 3d10 fully filled and stable
                 Ni (-0.25)  very high (negative) hydration enthalpy
                 Cu (+0.34)  high sublimation + ionisation enthalpy,
                             NOT compensated by hydration enthalpy
            4. Consequence for Cu: it does NOT liberate H2 from
               dilute acids.
  TRAP      Remember E° depends on THREE terms (sublimation,
            ionisation, hydration), not just one.
```

```
  PATTERN 15 — WHY ARE THEY GOOD CATALYSTS?                          4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the catalytic properties of transition metals" /
            "Name the catalyst in the Haber / Contact process."
  METHOD    THREE REASONS, then examples:
            1. VARIABLE OXIDATION STATES - the metal lends and takes
               back electrons, giving a path of lower activation
               energy. Show the Fe3+/Fe2+ cycle with I- and S2O8 2-.
            2. LARGE SURFACE AREA with FREE VALENCIES - reactants are
               ADSORBED, which concentrates them and weakens their
               bonds.
            3. FORMATION OF UNSTABLE INTERMEDIATE COMPOUNDS.
            EXAMPLES: Fe (Haber), V2O5 (Contact), Ni (hydrogenation),
                      Pt/Rh (catalytic converter), MnO2 (KClO3).
  TRAP      Two reasons only gets partial marks. Write all three.
```

```
  PATTERN 16 — COMPLEX FORMATION                                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why do transition metals form complexes?" / "Give
            examples of complexes."
  METHOD    THREE REASONS:
              1. small size of the metal ion
              2. high ionic charge (so high charge density)
              3. VACANT d ORBITALS of suitable energy that ACCEPT
                 lone pairs from the ligands
            EXAMPLES: [Fe(CN)6]4- , [Fe(CN)6]3- , [Cu(NH3)4]2+ ,
                      [Ni(CN)4]2- , [Co(NH3)6]3+
  TRAP      Say VACANT d orbitals. "d orbitals" alone is not enough -
            they must be EMPTY to accept a lone pair.
```

```
  PATTERN 17 — INTERSTITIAL COMPOUNDS                            2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are interstitial compounds?" / "Give their
            characteristic properties."
  METHOD    1. Definition: small atoms (H, C, N, B) occupy the empty
               spaces (interstices) in the metal lattice.
            2. Examples: TiC, Mn4N, Fe3H, VH0.56, TiH1.7, steel.
            3. FIVE properties:
                 non-stoichiometric ; very hard ; very high melting
                 point ; retain metallic conductivity ; chemically inert
            4. Reason for the hardness: the trapped atoms stop the
               metal layers from sliding.
  TRAP      "Non-stoichiometric" is the word that earns the mark.
            Notice the formulas VH0.56 and TiH1.7 are not whole numbers.
```

```
  PATTERN 18 — ALLOYS                                                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are alloys?" / "Why do transition metals form
            alloys easily?"
  METHOD    1. Definition: a homogeneous solid solution of two or more
               metals.
            2. Reason: transition metals have very SIMILAR ATOMIC
               RADII, so one atom can substitute for another in the
               lattice.
            3. Examples: brass (Cu+Zn), bronze (Cu+Sn), stainless
               steel (Fe+Cr+Ni), German silver (Cu+Zn+Ni, no silver).
  TRAP      Do not confuse an ALLOY (substitutional, similar sizes)
            with an INTERSTITIAL compound (small atoms in holes).
```

```
  PATTERN 19 — PREPARATION OF K2Cr2O7                          *** 8 marks ***
  ------------------------------------------------------------------------
  TRIGGER   "How is potassium dichromate prepared from chromite ore?"
  METHOD    1. Name the ore: CHROMITE  FeCr2O4 ( = FeO.Cr2O3 ).
            2. Draw the FLOW CHART:
                 FeCr2O4 -> Na2CrO4 -> Na2Cr2O7 -> K2Cr2O7
            3. Write all THREE equations:
                 4 FeCr2O4 + 8 Na2CO3 + 7 O2 -->
                                 8 Na2CrO4 + 2 Fe2O3 + 8 CO2
                 2 Na2CrO4 + H2SO4 -> Na2Cr2O7 + Na2SO4 + H2O
                 Na2Cr2O7 + 2 KCl  -> K2Cr2O7 + 2 NaCl
            4. Say WHY KCl is used: K2Cr2O7 is much less soluble than
               Na2Cr2O7, so it crystallises out cleanly.
  NOTE      *** ONE OF THE TWO MOST FREQUENT 8-MARK QUESTIONS ***
  TRAP      Equation 1 must be BALANCED - the coefficients 4, 8, 7,
            8, 2, 8 are what the examiner counts.
```

```
  PATTERN 20 — STRUCTURE OF CHROMATE AND DICHROMATE                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Draw the structure of the dichromate ion."
  METHOD    CrO4 2-  : TETRAHEDRAL, four EQUAL Cr-O bonds (161 pm),
                       Cr is +6, YELLOW.
            Cr2O7 2- : TWO tetrahedra sharing ONE bridging oxygen,
                       Cr - O - Cr angle about 126 degrees,
                       terminal Cr-O = 163 pm, bridging = 179 pm,
                       Cr is +6, ORANGE.
  TRAP      The bridging oxygen must be shown. A drawing of two
            separate tetrahedra earns nothing.
```

```
  PATTERN 21 — CHROMATE / DICHROMATE EQUILIBRIUM AND pH          2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the effect of pH on a dichromate solution?" /
            "What happens when alkali is added to K2Cr2O7?"
  METHOD    1. Write both equilibria:
                 2 CrO4 2- + 2 H+  <-> Cr2O7 2- + H2O
                 Cr2O7 2-  + 2 OH- <-> 2 CrO4 2- + H2O
            2. State the colours: chromate YELLOW, dichromate ORANGE.
            3. ACID lowers the pH -> orange dichromate predominates.
               ALKALI raises the pH -> yellow chromate predominates.
            4. Add the key sentence: chromium stays +6 throughout,
               so this is NOT a redox reaction.
  TRAP      Chromate is YELLOW, not orange. Memory: "Acid -> orange".
```

```
  PATTERN 22 — OXIDISING ACTION OF K2Cr2O7                       4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the oxidising reactions of acidified K2Cr2O7."
  METHOD    1. Write the MASTER half equation first:
                 Cr2O7 2- + 14 H+ + 6 e- -> 2 Cr3+ + 7 H2O
                 (orange -> green , E° = +1.33 V)
            2. Then list the reactions, each balanced for 6 electrons:
                 I- -> I2 , Fe2+ -> Fe3+ , H2S -> S ,
                 SO3 2- -> SO4 2- , Sn2+ -> Sn4+
  SHORTCUT  n-factor = 6 , so equivalent weight = 294 / 6 = 49.
  TRAP      Balance the CHARGE as well as the atoms. Count both sides.
```

```
  PATTERN 23 — PREPARATION OF KMnO4                            *** 8 marks ***
  ------------------------------------------------------------------------
  TRIGGER   "How is potassium permanganate prepared from pyrolusite?"
  METHOD    1. Name the ore: PYROLUSITE  MnO2.
            2. Draw the FLOW CHART:
                 MnO2 -> K2MnO4 (green, +6) -> KMnO4 (purple, +7)
            3. Equations:
                 2 MnO2 + 4 KOH + O2 --(fused)--> 2 K2MnO4 + 2 H2O
                 (or MnO2 + 2KOH + KNO3 --> K2MnO4 + KNO2 + H2O)
               then EITHER
                 anode:  MnO4 2- -> MnO4- + e-   (electrolytic)
                 cathode: H2O + e- -> OH- + (1/2) H2
               OR
                 3 MnO4 2- + 4 H+ -> 2 MnO4- + MnO2 + 2 H2O
                 (disproportionation)
            4. State the colours and the oxidation states at each step.
  NOTE      *** THE OTHER MOST FREQUENT 8-MARK QUESTION ***
  TRAP      Manganate K2MnO4 is GREEN and Mn is +6.
            Permanganate KMnO4 is PURPLE and Mn is +7. Do not swap them.
```

```
  PATTERN 24 — OXIDISING ACTION OF KMnO4 IN THE THREE MEDIA      4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Describe the oxidising action of KMnO4 in acidic,
            alkaline and neutral media."
  METHOD    Write all THREE half equations with the colour change:

              ACIDIC     MnO4- + 8H+ + 5e-  -> Mn2+ + 4H2O
                         purple -> colourless   , +7 to +2 , 5 e-
              NEUTRAL /  MnO4- + 2H2O + 3e-  -> MnO2 + 4OH-
              FAINTLY    purple -> brown solid  , +7 to +4 , 3 e-
              ALKALINE
              STRONGLY   MnO4- + e-          -> MnO4 2-
              ALKALINE   purple -> dark green   , +7 to +6 , 1 e-

            Then give one example reaction from each medium.
  SHORTCUT  "5 , 3 , 1"  -  acid, neutral, alkali. Count down in odds.
  TRAP      In ACID, iodide goes to I2. In NEUTRAL it goes all the way
            to IODATE IO3-. Students mix these two up constantly.
```

```
  PATTERN 25 — STRUCTURE OF THE PERMANGANATE ION                     2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Give the structure of MnO4-."
  METHOD    TETRAHEDRAL, bond angles 109.5 degrees, Mn is +7 (3d0),
            all four Mn-O bonds identical, pi bonding from oxygen p
            orbitals into the empty d orbitals of Mn, DIAMAGNETIC,
            purple colour from CHARGE TRANSFER (not d-d).
  TRAP      If asked why it is purple, do NOT say d-d transition.
            Mn7+ has no d electrons.
```

```
  PATTERN 26 — USES / PRIMARY STANDARD COMPARISON                2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Give the uses of K2Cr2O7 / KMnO4" / "Why is K2Cr2O7 a
            primary standard but KMnO4 is not?"
  METHOD    USES of K2Cr2O7: primary standard, leather tanning,
            dyeing, chromyl chloride test.
            USES of KMnO4: volumetric analysis, disinfectant (Condy's
            fluid), bleaching, benzoic acid from toluene, Baeyer's
            reagent for unsaturation.
            PRIMARY STANDARD: K2Cr2O7 can be obtained pure, is not
            hygroscopic, and its solution is stable. KMnO4 cannot be
            obtained pure (contains MnO2) and its solution decomposes
            slowly, so it must be standardised before use.
```

```
  PATTERN 27 — f BLOCK CONFIGURATION AND OXIDATION STATES        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the general configuration of the lanthanoids" /
            "Why is +3 the common oxidation state?"
  METHOD    1. LANTHANOIDS  [Xe] 4f 1-14  5d 0-1  6s 2
               ACTINOIDS    [Rn] 5f 1-14  6d 0-1  7s 2
               GENERAL      (n-2)f 1-14 (n-1)d 0-1  ns 2
            2. +3 is common because the two 6s and one 4f/5d electron
               are lost easily; a fourth needs far too much energy.
            3. Unusual states occur only when the ion lands on
               4f0 , 4f7 or 4f14 :
                 Ce4+ = 4f0 (oxidiser) , Eu2+ = 4f7 (reducer) ,
                 Tb4+ = 4f7 , Yb2+ = 4f14
  TRAP      Lanthanum La (57) itself has NO 4f electron: [Xe]5d1 6s2.
```

```
  PATTERN 28 — LANTHANOIDS vs ACTINOIDS COMPARISON                   4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Compare the lanthanoids and the actinoids" / "Give any
            four differences."
  METHOD    Answer as a TWO-COLUMN TABLE. Give at least six rows:
              4f vs 5f  |  Pm only vs ALL radioactive  |
              mainly +3 vs +3 to +7  |  no oxo-cations vs UO2 2+ |
              weaker vs stronger complex formation |
              lanthanoid vs GREATER actinoid contraction |
              all natural vs transuranic elements are man-made
  TRAP      The single most important row is RADIOACTIVITY -
            ALL actinoids are radioactive. Never leave it out.
```

```
  PATTERN 29 — MISCH METAL AND USES OF LANTHANOIDS                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is misch metal?" / "Give the uses of lanthanoids."
  METHOD    MISCH METAL = about 95 % lanthanoid metal + about 5 % iron
            + traces of S, C, Ca, Al.
            USES: with magnesium in bullets, shells and LIGHTER FLINTS
            (it is pyrophoric); mixed oxides as cracking catalysts;
            in TV screens, glass and ceramics; added to steel to
            improve strength.
  TRAP      95 % lanthanoid and 5 % iron, not the other way round.
```

```
  PATTERN 30 — GENERAL PROPERTIES ESSAY                        *** 8 marks ***
  ------------------------------------------------------------------------
  TRIGGER   "Explain the general characteristics / properties of the
            transition elements."
  METHOD    Write EIGHT headed paragraphs, each with a REASON:
              1. metallic character (unpaired d electrons bond)
              2. atomic radii (fall, flat, slight rise)
              3. ionisation enthalpy (screening cancels nuclear charge)
              4. variable oxidation states (d and s energies close)
              5. magnetic properties (unpaired electrons, mu formula)
              6. colour (d-d transition, complementary colour)
              7. catalysis (variable states + adsorption)
              8. complex formation (small size, high charge, vacant d)
            Add interstitial compounds and alloys if time allows.
  TRAP      Marks are awarded for the REASON, not the property.
            Every paragraph must contain the word "because".
```

      0 / 1.73 / 2.83 / 3.87 / 4.90 / 5.92             (PATTERNS 6-8)
