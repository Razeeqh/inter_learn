# TOPIC 1 — WHY NITROGEN BEHAVES THE WAY IT DOES

Everything in this chapter comes from one fact about the nitrogen atom.

```
   Nitrogen has 5 electrons in its outer shell.

        N  :  2s2 2p3     ->    5 outer electrons

   It uses 3 of them to make 3 bonds.
   The other 2 sit together as a pair that is NOT bonded to anything.

                         ..
                         N          <--- these two dots are the LONE PAIR
                       / | \
                      H  H  H

   That is ammonia, NH3.
```

Now replace the hydrogens of ammonia with carbon chains and you get **amines**:

```
        ..                ..                 ..                  ..
        N                 N                  N                   N
      / | \             / | \              / | \               / | \
     H  H  H           R  H  H            R  R  H             R  R  R

     AMMONIA        PRIMARY (1deg)     SECONDARY (2deg)    TERTIARY (3deg)
       NH3             R-NH2               R2-NH               R3-N
```

**The lone pair is the hero of this chapter.** Ask one question about every
compound you meet:

```
   +--------------------------------------------------------------+
   |                                                              |
   |   IS THE LONE PAIR FREE, OR IS IT BUSY?                      |
   |                                                              |
   |   FREE  ->  the compound is a good BASE and a good           |
   |             NUCLEOPHILE, and if it is on a ring it           |
   |             ACTIVATES that ring                              |
   |                                                              |
   |   BUSY  ->  (delocalised into a ring, or into a C=O, or      |
   |             pulled away by an electron-withdrawing group)    |
   |             the compound is a WEAK base                      |
   |                                                              |
   +--------------------------------------------------------------+
```

Examples you will meet later, so that the idea sticks now:

| Compound | Where is the lone pair? | Base strength |
|---|---|---|
| CH3-NH2 (methylamine) | free on N | strong (for an amine) |
| NH3 (ammonia) | free on N | reference |
| C6H5-NH2 (aniline) | delocalised into the ring | very weak |
| CH3-CO-NH2 (acetamide) | delocalised into the C=O | almost neutral |
| C6H5-NO2 (nitrobenzene) | N already positive | not a base at all |

## 1.1 The five nitrogen groups in this chapter

Learn to WRITE these before you learn anything else.

```
   +----------------+------------------+----------------------------+
   |  GROUP         |  WRITTEN AS      |  FAMILY NAME               |
   +----------------+------------------+----------------------------+
   |  -NO2          |  CH3-NO2         |  nitro compound            |
   |  -NH2          |  CH3-NH2         |  primary amine             |
   |  -NH-          |  CH3-NH-CH3      |  secondary amine           |
   |  -N<           |  (CH3)3N         |  tertiary amine            |
   |  -C(triple)N   |  CH3-CN          |  cyanide / nitrile         |
   |  -N(triple)C   |  CH3-NC          |  isocyanide / carbylamine  |
   |  -N2+ X-       |  C6H5-N2+ Cl-    |  diazonium salt            |
   +----------------+------------------+----------------------------+
```

> **TRAP:** `-NO2` (nitro) and `-O-N=O` (nitrite) both contain N and two O,
> but they are completely different compounds. In a **nitro** compound the
> **NITROGEN** is joined to carbon. In a **nitrite** the **OXYGEN** is joined
> to carbon. Examiners love this.
>
> ```
>    CH3-NO2      nitromethane     C joined to N     b.p. 374 K
>    CH3-O-N=O    methyl nitrite   C joined to O     b.p. 285 K
> ```

# TOPIC 2 — NITRO COMPOUNDS: NAMING AND STRUCTURE

## 2.1 Naming

A nitro compound is just a parent chain with `-NO2` stuck on it. You name it
by putting the word **nitro** in front, with a number if you need one.

| Formula | Name |
|---|---|
| CH3-NO2 | nitromethane |
| CH3-CH2-NO2 | nitroethane |
| CH3-CH2-CH2-NO2 | 1-nitropropane |
| CH3-CH(NO2)-CH3 | 2-nitropropane |
| C6H5-NO2 | nitrobenzene |
| 1,3-(NO2)2C6H4 | 1,3-dinitrobenzene (m-dinitrobenzene) |

Nitroalkanes are also classified as **primary, secondary and tertiary**, based
on the carbon carrying the -NO2 group:

```
   CH3-CH2-NO2          1deg      the C with NO2 carries 2 H
   (CH3)2CH-NO2         2deg      the C with NO2 carries 1 H
   (CH3)3C-NO2          3deg      the C with NO2 carries 0 H
```

## 2.2 Structure — why both N-O bonds are the same length

You would expect one **double** bond (short) and one **single** bond (long).
Experiment says both are **the same length**. The reason is **resonance**.

```
              O                          O -
             //                         /
     R -- N          <-------->   R -- N +
             \                         \\
              O -                       O

     The real molecule is the AVERAGE of these two.
     So both N-O bonds are IDENTICAL, halfway between single and double.

     The nitrogen is sp2 hybridised.
     The nitrogen carries a FORMAL POSITIVE charge.
     The group as a whole is strongly ELECTRON-WITHDRAWING
     (both by -I effect and by -R / resonance effect).
```

**Why this matters later:** because -NO2 pulls electrons hard,

- nitrobenzene is **deactivated** and **meta-directing**,
- p-nitroaniline is a much **weaker base** than aniline,
- nitrophenols are **stronger acids** than phenol.

> **TRAP:** do not draw the nitro group as `R-N(=O)=O` with five bonds to
> nitrogen. Nitrogen can never have five bonds — it has only four orbitals.
> Draw it with the `+` on N and the `-` on one O.

```

# TOPIC 3 — HOW TO MAKE NITRO COMPOUNDS

Four methods. Two for the aliphatic ones, one for the aromatic one.

## 3.1 Direct nitration of an alkane (vapour phase)

```
   CH4  +  HNO3   --673-723 K, vapour phase-->   CH3-NO2  +  H2O

   Needs very high temperature. Gives a MIXTURE of all possible
   nitroalkanes plus products from chain breaking, so it is an
   industrial method, not a laboratory one.
```

## 3.2 From an alkyl halide + silver nitrite

```
   CH3-CH2-Br  +  AgNO2   -->   CH3-CH2-NO2  +  AgBr
                                nitroethane (MAJOR)
```

## 3.3 From an alkyl halide + potassium nitrite — the ambident nucleophile trap

```
   CH3-CH2-Br  +  KNO2    -->   CH3-CH2-O-N=O  +  KBr
                                ethyl nitrite (MAJOR)

   SAME halide. DIFFERENT product. Why?

   The nitrite ion  NO2-  has TWO places that can attack.
   A nucleophile with two attacking atoms is called AMBIDENT.

        KNO2  is IONIC        ->  free NO2- ion, the more
                                  electronegative OXYGEN attacks
                                  ->  R-O-N=O   (nitrite)

        AgNO2 is COVALENT     ->  the O is tied up with silver,
                                  so NITROGEN attacks
                                  ->  R-NO2     (nitro compound)

   MEMORY HOOK:   "Ag gives N,  K gives O"
                  (Ag and N are both in the metal-ish/silver mirror
                   world of nitro compounds)
```

## 3.4 Nitration of benzene (this is the one that matters)

```
                       conc. HNO3  +  conc. H2SO4
   C6H6      ---------------------------------------->   C6H5-NO2  +  H2O
                          330 K  (about 60 C)              nitrobenzene

   The attacking species (the electrophile) is the NITRONIUM ION, NO2+ ,
   made like this:

        HNO3  +  2 H2SO4   -->   NO2+  +  H3O+  +  2 HSO4-

   Keep the temperature near 330 K. Above about 373 K you get
   m-dinitrobenzene as well.
```

# TOPIC 4 — REDUCTION OF NITROBENZENE IN DIFFERENT MEDIA

This is a **guaranteed 4-mark question**. It is pure memory. There is no
thinking involved, so there is no excuse for losing the marks.

The idea: nitrobenzene can be reduced a little, or a lot, and the **medium**
(acidic / neutral / alkaline) decides where it stops.

```
   THE REDUCTION LADDER OF NITROBENZENE

   C6H5-NO2                     nitrobenzene
      |
      |  (add 2 H, remove 1 O)
      v
   C6H5-N=O                     nitrosobenzene       [not usually isolated]
      |
      |  (add 2 H)
      v
   C6H5-NH-OH                   N-phenylhydroxylamine
      |
      |  (add 2 H, remove H2O)
      v
   C6H5-NH2                     ANILINE

   AND, in ALKALINE medium, two molecules join up sideways instead:

   C6H5-N=N-C6H5                azobenzene
        |
        O                        (azoxybenzene = the same with an O on one N)


   C6H5-NH-NH-C6H5              hydrazobenzene
```

## The table you must memorise

| MEDIUM | REAGENT | PRODUCT |
|---|---|---|
| ACIDIC | Sn + conc. HCl, then NaOH | **aniline** C6H5-NH2 |
| ACIDIC | Fe + HCl (steam) | **aniline** (industrial method) |
| CATALYTIC | H2 / Pd or Pt or Ni | **aniline** |
| NEUTRAL | Zn dust + NH4Cl (aqueous) | **N-phenylhydroxylamine** C6H5-NH-OH |
| MILD ALKALINE | Na3AsO3 or As2O3 / NaOH | **azoxybenzene** C6H5-N(O)=N-C6H5 |
| ALKALINE | LiAlH4, or Zn dust + NaOH (limited) | **azobenzene** C6H5-N=N-C6H5 |
| STRONG ALKALINE | Zn dust + NaOH (excess) | **hydrazobenzene** C6H5-NH-NH-C6H5 |
| ELECTROLYTIC | cathode, conc. H2SO4 | **p-aminophenol** |

```
   MEMORY SENTENCE (say it out loud):

     "ACID gives the AMINE.
      NEUTRAL stops at the hydroxylAMINE.
      ALKALI joins TWO rings together: AZOXY, AZO, HYDRAZO
      (in that order as you make it more strongly reducing).
      ELECTRICITY in strong acid rearranges it to p-AMINOPHENOL."
```

The main equation, written out fully:

```
   C6H5-NO2  +  6 [H]   --Sn / conc. HCl-->   C6H5-NH2  +  2 H2O

   In practice the aniline comes out as its salt, so you add NaOH at the end:

   C6H5-NH3+ Cl-  +  NaOH   -->   C6H5-NH2  +  NaCl  +  H2O
```

> **TRAP:** Why is **Fe/HCl preferred in industry** over Sn/HCl?
> Because FeCl2 formed is hydrolysed by water and **regenerates the HCl**,
> so only a small amount of HCl is needed. Iron is also far cheaper than tin.
> That exact sentence is a 2-mark answer.

## WORKED EXAMPLE 2

**Q. Nitrobenzene is treated separately with (a) Sn/HCl (b) Zn dust and NH4Cl
solution (c) Zn dust and excess NaOH. Name the product in each case.**

```
  (a)  Sn / HCl              =  ACIDIC medium
       ->  C6H5-NH2          =  ANILINE

  (b)  Zn dust + NH4Cl(aq)   =  NEUTRAL medium
       ->  C6H5-NH-OH        =  N-PHENYLHYDROXYLAMINE

  (c)  Zn dust + excess NaOH =  STRONGLY ALKALINE medium
       ->  C6H5-NH-NH-C6H5   =  HYDRAZOBENZENE

  Notice that in (c) TWO rings are joined. In alkaline medium the
  intermediates condense with each other instead of being reduced
  all the way down.
```

# TOPIC 5 — AMINES: CLASSIFICATION

An amine is **ammonia with its hydrogens swapped for carbon groups**.

```
   HOW TO CLASSIFY:  count how many CARBON groups are joined to the NITROGEN.

        1 carbon on N   ->   PRIMARY    (1deg)     R-NH2
        2 carbons on N  ->   SECONDARY  (2deg)     R2-NH
        3 carbons on N  ->   TERTIARY   (3deg)     R3-N
        4 carbons on N  ->   QUATERNARY ammonium salt  R4-N+ X-
```

```
   +-----------------------+---------+--------------------------------+
   |  COMPOUND             |  CLASS  |  WHY                           |
   +-----------------------+---------+--------------------------------+
   |  CH3-NH2              |  1deg   |  one C on N                    |
   |  CH3-CH2-NH2          |  1deg   |  one C on N                    |
   |  (CH3)3C-NH2          |  1deg   |  STILL one C on N !            |
   |  CH3-NH-CH3           |  2deg   |  two C on N                    |
   |  CH3-NH-C2H5          |  2deg   |  two C on N                    |
   |  (CH3)3N              |  3deg   |  three C on N                  |
   |  C6H5-NH2             |  1deg   |  one C (the ring) on N         |
   |  C6H5-NH-CH3          |  2deg   |  two C on N                    |
   |  C6H5-N(CH3)2         |  3deg   |  three C on N                  |
   |  (CH3)4N+ I-          |  quat.  |  four C on N, so N is + ve     |
   +-----------------------+---------+--------------------------------+
```

> **TRAP — the biggest one in the chapter.**
> `(CH3)3C-NH2` (tert-butylamine) is a **PRIMARY amine**, not a tertiary one.
> You classify an **amine** by counting carbons on the **NITROGEN**.
> You classify an **alcohol** by counting carbons on the **CARBON** bearing -OH.
> Different rules for different families. Students lose 2 marks here every year.
>
> ```
>       (CH3)3C-OH    ->  TERTIARY alcohol   (3 C on the C holding OH)
>       (CH3)3C-NH2   ->  PRIMARY amine      (1 C on the N)
> ```

## 5.1 Aliphatic versus aromatic

```
   ALIPHATIC AMINE   the nitrogen is joined to a CHAIN carbon
                     CH3-NH2  ,  C2H5-NH2  ,  C6H5-CH2-NH2 (benzylamine!)

   AROMATIC AMINE    the nitrogen is joined DIRECTLY to a BENZENE RING
                     C6H5-NH2 (aniline)  ,  C6H5-NH-CH3
```

> **TRAP:** **benzylamine** `C6H5-CH2-NH2` has a benzene ring in it, but the
> nitrogen is joined to a **CH2**, not to the ring. So it is an **ALIPHATIC**
> amine and it is a **strong** base (pKb about 4.7), almost as strong as
> ethylamine. Do not lump it with aniline.

# TOPIC 6 — THE STRUCTURE OF THE AMINO GROUP

```
   The nitrogen in an amine is  sp3  hybridised.
   Four sp3 orbitals point to the four corners of a tetrahedron.
   THREE of them make bonds. The FOURTH holds the LONE PAIR.

   Since one corner has no atom in it, the SHAPE we can see is a
   PYRAMID with the nitrogen at the top:

                    ..                     <- lone pair, in an sp3 orbital
                    N
                  / | \
                 /  |  \
                C   C   C                  <- the three groups, forming
                                              a triangular base

              PYRAMIDAL   (trigonal pyramidal)


   BOND ANGLE:  in trimethylamine the C-N-C angle is about 108 degrees.

   Why is it LESS than the perfect tetrahedral 109.5 degrees?
   Because a LONE PAIR takes up more room than a bond pair, so it
   squeezes the three bonds slightly closer together.
```

```
   COMPARE WITH AMMONIA:

        NH3            H-N-H angle  =  107 degrees
        (CH3)3N        C-N-C angle  =  108 degrees

   Both pyramidal. Both sp3. Both have one lone pair.
   An amine is genuinely just "ammonia wearing carbon coats".
```

# TOPIC 7 — NOMENCLATURE OF AMINES

Two systems. The examiner may ask for either, so learn both.

```
   COMMON NAME    :  name the alkyl group(s), then add the word "amine"
                     all as ONE word.
                        CH3-NH2      ->  methylamine
                        (CH3)2NH     ->  dimethylamine

   IUPAC NAME     :  name the alkane, drop the final "e", add "amine".
                        CH3-NH2      ->  methanamine
                        CH3CH2-NH2   ->  ethanamine

   For 2deg and 3deg amines the SMALLER groups become prefixes with
   the letter N in front, showing they are on the NITROGEN.
                        CH3-NH-C2H5  ->  N-methylethanamine
```

| CH3-NH2 | methylamine | methanamine |
| CH3-CH2-NH2 | ethylamine | ethanamine |
| CH3-CH2-CH2-NH2 | n-propylamine | propan-1-amine |
| (CH3)2CH-NH2 | isopropylamine | propan-2-amine |
| (CH3)3C-NH2 | tert-butylamine | 2-methylpropan-2-amine |
| CH3-NH-CH3 | dimethylamine | N-methylmethanamine |
| CH3-NH-C2H5 | ethylmethylamine | N-methylethanamine |
| (CH3)3N | trimethylamine | N,N-dimethylmethanamine |
| (C2H5)3N | triethylamine | N,N-diethylethanamine |
| H2N-CH2-CH2-NH2 | ethylenediamine | ethane-1,2-diamine |
| H2N-(CH2)3-NH2 | trimethylenediamine | propane-1,3-diamine |
| C6H5-NH2 | aniline | aniline (retained) / benzenamine |

```
   THE RULES FOR PICKING THE PARENT, in order:

   1.  Choose the LONGEST carbon chain that carries the -NH2.
   2.  Number it so the -NH2 gets the LOWEST number.

   4.  If there are two -NH2 groups keep the final "e" of the alkane:
          ethane + diamine  ->  ethane-1,2-diamine  (NOT ethandiamine)
   5.  "Aniline" is kept by IUPAC, so use it. It is not a mistake.
```

## WORKED EXAMPLE 3

**Q. Give the IUPAC name of `CH3-CH2-CH(NH2)-CH3` and of
`C6H5-N(CH3)-C2H5`.**

```
  (a)   CH3-CH2-CH(NH2)-CH3

        Longest chain containing the -NH2  =  4 carbons  =  butane

        Number from the end that gives -NH2 the smaller number:

             CH3 - CH2 - CH - CH3
              4     3    2    1
                         |
                        NH2

        The -NH2 is on carbon 2.

        IUPAC NAME  =  butan-2-amine
        Class       =  PRIMARY amine (only 1 C on N)


  (b)   C6H5-N(CH3)-C2H5

        The nitrogen carries: a phenyl ring, a methyl, an ethyl.
        Three carbon groups  ->  TERTIARY amine.

        Parent  =  aniline (because N is joined straight to the ring)
        On the N there is a methyl and an ethyl.

        IUPAC NAME  =  N-ethyl-N-methylaniline
        (alphabetical order: ethyl before methyl)
```

> **TRAP:** for two -NH2 groups you keep the "e": **ethane-1,2-diamine**.
> For one -NH2 you drop it: **ethanamine**. One letter, half a mark.

# TOPIC 8 — HOW TO MAKE AMINES (SIX METHODS)

This is a Section C question on its own. Learn all six, with equations.

```
   THE SIX ROUTES AT A GLANCE

   +---+---------------------------+----------------+------------------+
   | # | METHOD                    | GIVES          | CARBON COUNT     |
   +---+---------------------------+----------------+------------------+
   | 1 | reduce a NITRO compound   | 1deg only      | SAME             |
   | 2 | AMMONOLYSIS of R-X        | 1,2,3deg + quat| SAME             |
   |   |                           | (a MIXTURE)    |                  |
   | 3 | reduce a NITRILE R-CN     | 1deg only      | ONE MORE carbon  |
   | 4 | reduce an AMIDE R-CONH2   | 1deg only      | SAME             |
   | 5 | GABRIEL phthalimide       | 1deg only,PURE | SAME             |
   | 6 | HOFMANN bromamide         | 1deg only,PURE | ONE LESS carbon  |
   +---+---------------------------+----------------+------------------+

   Notice: FIVE of the six give ONLY primary amines.
   Only AMMONOLYSIS gives 2deg and 3deg amines, and it gives a mess.
```

## 8.1 Reduction of nitro compounds

```
   R-NO2  +  6 [H]   -->   R-NH2  +  2 H2O

   THREE ways to supply the [H]:

   (a) CATALYTIC       C6H5-NO2  +  3 H2  --Ni or Pd or Pt-->  C6H5-NH2 + 2H2O
   (b) Sn / conc. HCl  C6H5-NO2  --Sn/HCl, then NaOH-->  C6H5-NH2
   (c) Fe / HCl        C6H5-NO2  --Fe/HCl, steam-->  C6H5-NH2
```

| Method | Advantage | Disadvantage |
|---|---|---|
| H2 / Ni, Pd, Pt | clean, no salts to remove | will also reduce C=C, C(triple)C, -CHO if present |
| Sn / conc. HCl | works on everything, gentle on other groups | tin is expensive; lots of acid needed |
| Fe / HCl | cheapest; FeCl2 is hydrolysed so **HCl is regenerated** — only a small amount needed | slower; iron sludge |

> **TRAP:** if the molecule also contains a C=C double bond, **catalytic
> hydrogenation will reduce that too**. So to reduce ONLY the -NO2 you must
> use Sn/HCl or Fe/HCl. This is a favourite "give a reason" question.

## 8.2 Ammonolysis of alkyl halides — and why it gives a mixture

Ammonia has a lone pair, so it is a **nucleophile**. It attacks the carbon of
an alkyl halide and kicks out the halide. That is an SN2 reaction.

```
   STEP 1:   CH3-Br  +  NH3      -->   CH3-NH3+ Br-   --NaOH-->  CH3-NH2
                                                                 1deg

   BUT CH3-NH2 also has a lone pair. It is in fact a BETTER nucleophile
   than ammonia (the methyl group pushes electrons onto N). So it attacks
   the next CH3-Br that comes along:

   STEP 2:   CH3-NH2  +  CH3-Br  -->   (CH3)2NH2+ Br-  --NaOH--> (CH3)2NH
                                                                 2deg

   STEP 3:   (CH3)2NH +  CH3-Br  -->   (CH3)3NH+ Br-   --NaOH--> (CH3)3N
                                                                 3deg

   STEP 4:   (CH3)3N  +  CH3-Br  -->   (CH3)4N+ Br-
                                       QUATERNARY ammonium salt
                                       (this one cannot go further and
                                        cannot be freed by NaOH)
```

```
   +--------------------------------------------------------------+
   |  WHY A MIXTURE?                                              |
   |                                                              |
   |  Because the amine PRODUCT is itself a nucleophile, and it   |
   |  is a BETTER nucleophile than the ammonia you started with.  |
   |  So it competes for the alkyl halide and the reaction does   |
   |  not stop at the first stage.                                |
   |                                                              |
   |  HOW TO GET MAINLY THE PRIMARY AMINE:                        |
   |     use a LARGE EXCESS OF AMMONIA.                           |
   |     Then a halide molecule is far more likely to bump into   |
   |     an NH3 than into an amine.                               |
   |                                                              |
   |  HOW TO GET MAINLY THE QUATERNARY SALT:                      |
   |     use a large excess of the ALKYL HALIDE.                  |
   +--------------------------------------------------------------+

   Order of reactivity of the halide:   R-I  >  R-Br  >  R-Cl
   (weakest C-X bond breaks most easily)
```

> **TRAP:** ammonolysis **does not work on aryl halides**. Chlorobenzene will
> not react with ammonia under normal conditions, because the C-Cl bond has
> partial double-bond character from resonance with the ring, so it is short,
> strong and very hard to break. You cannot make aniline this way.

## 8.3 Reduction of nitriles (cyanides) — THE STEP-UP METHOD

```
   R-C(triple)N  +  4 [H]   -->   R-CH2-NH2

   Reagents:  H2 / Ni      or   LiAlH4     or   Na + C2H5OH
                                                (this last one is called
                                                 MENDIUS reduction)

   EXAMPLE:
   CH3-C(triple)N   --H2/Ni-->   CH3-CH2-NH2
   1 carbon in CH3                2 carbons
   + 1 in CN = 2 C                ethanamine


   WHY IT IS USEFUL — the two-step CHAIN LENGTHENING:

        R-X   --KCN(alcoholic)-->   R-CN   --H2/Ni-->   R-CH2-NH2
        n carbons                   n+1 C               n+1 carbons

        CH3-Br  --KCN-->  CH3-CN  --H2/Ni-->  CH3-CH2-NH2
        1 C                2 C                 2 C

   You have turned a 1-carbon compound into a 2-carbon amine.
   This is the ONLY method here that ADDS a carbon.
```

## 8.4 Reduction of amides

```
   R-CO-NH2   --(i) LiAlH4  (ii) H2O-->   R-CH2-NH2

   EXAMPLE:
   CH3-CO-NH2  --LiAlH4-->  CH3-CH2-NH2
   acetamide, 2 C            ethanamine, 2 C          SAME carbon count

   Here LiAlH4 turns the  C=O  into  CH2  and leaves the N in place.
```

```
   ONE AMIDE, TWO DIFFERENT ANSWERS — this is the classic trick question:

        CH3-CO-NH2   --LiAlH4-->          CH3-CH2-NH2     (2 carbons)
        CH3-CO-NH2   --Br2 + 4NaOH-->     CH3-NH2         (1 carbon)
                        (HOFMANN)

   SAME starting material. Different reagent. Different carbon count.
   Read the reagent before you answer.
```

## 8.5 GABRIEL PHTHALIMIDE SYNTHESIS

The point of this method: it gives a **pure primary amine with no mixture at
all**. The phthalimide acts as a "protected ammonia" that can only be used once.

```
   STEP 1   Phthalimide is acidic (the N-H sits between two C=O groups),
            so KOH removes that H:

                O                             O
                ||                            ||
            /---C\                        /---C\
    ring   |      N-H   + KOH   ---->    |      N- K+   +  H2O
            \---C/                        \---C/
                ||                            ||
                O                             O
              phthalimide            potassium phthalimide

   STEP 2   The nitrogen anion attacks the alkyl halide (SN2):

            potassium phthalimide  +  R-X   -->   N-alkylphthalimide + KX

            Now the nitrogen has NO hydrogen left and is locked between
            two C=O groups. It CANNOT attack a second R-X.
            ***That is why there is no mixture.***

   STEP 3   Break it open with alkali (or with hydrazine):

            N-alkylphthalimide  --(i) aq. NaOH, boil  (ii) H3O+-->
                                R-NH2  +  phthalic acid

   OVERALL:      R-X   ---->   R-NH2   (PRIMARY, PURE, no 2deg or 3deg)
```

```
   +--------------------------------------------------------------+
   |  WHY GABRIEL FAILS FOR AROMATIC PRIMARY AMINES               |
   |                                                              |
   |  Step 2 needs the phthalimide anion to do a NUCLEOPHILIC     |
   |  SUBSTITUTION on the halide.                                 |
   |                                                              |
   |  ARYL HALIDES (like C6H5-Cl) do NOT undergo nucleophilic     |
   |  substitution easily, because the C-Cl bond has partial      |
   |  DOUBLE BOND CHARACTER from resonance with the ring.         |
   |  It is short and strong and will not break.                  |
   |                                                              |
   |  So step 2 simply does not happen, and ANILINE CANNOT BE     |
   |  MADE by the Gabriel synthesis.                              |
   |                                                              |
   |  (Make aniline by reducing nitrobenzene instead.)            |
   +--------------------------------------------------------------+
```

## 8.6 HOFMANN BROMAMIDE DEGRADATION

```
   R-CO-NH2  +  Br2  +  4 NaOH   -->   R-NH2 + Na2CO3 + 2 NaBr + 2 H2O

   THE WORD "DEGRADATION" IS THE HINT:
   the molecule gets SMALLER. The product amine has ONE CARBON LESS
   than the amide you started with.

   EXAMPLE:
        CH3-CO-NH2  + Br2 + 4NaOH  -->  CH3-NH2 + Na2CO3 + 2NaBr + 2H2O
        acetamide (2 C)                 methanamine (1 C)

        C6H5-CO-NH2 + Br2 + 4NaOH  -->  C6H5-NH2 + Na2CO3 + 2NaBr + 2H2O
        benzamide (7 C)                 ANILINE (6 C)

   Where did the missing carbon go?  Into the Na2CO3.
```

```
   WHAT HAPPENS INSIDE (you may be asked for the intermediate):

        R-CO-NH2   --Br2/NaOH-->  R-CO-NH-Br      (N-bromoamide)
                   --NaOH-->      R-CO-N- Br      (anion)
                   -Br- leaves,   R-N=C=O         (ISOCYANATE  <-- name this)
                    R migrates
                    from C to N
                   --H2O/NaOH-->  R-NH2  +  CO3 2-

   The key step is the MIGRATION of the alkyl (or aryl) group from the
   carbonyl carbon to the nitrogen. That is what loses the carbon.
```

> **TRAP:** the Hofmann reaction works on **amides**, and gives an amine with
> one carbon **less**. LiAlH4 works on the same amides and gives an amine with
> the **same** number of carbons. If you get these two mixed up you will get
> the whole conversion question wrong.

## WORKED EXAMPLE 4

**Q. How will you convert CH3-CH2-Br into (a) CH3-CH2-CH2-NH2 and
(b) CH3-CH2-NH2, using different routes?**

```
  (a)  We need THREE carbons but we only have TWO.  ->  STEP UP  ->  use CN.

       CH3-CH2-Br  --KCN (alcoholic)-->  CH3-CH2-CN  --H2/Ni-->
                                                   CH3-CH2-CH2-NH2

       Check the carbons:   2  ->  3  ->  3.  Correct.


  (b)  We need TWO carbons and we have TWO.  ->  SAME COUNT  ->  use NH3
       (excess) or Gabriel.

       ROUTE 1 (ammonolysis):
       CH3-CH2-Br  +  NH3 (excess, alcoholic)  -->  CH3-CH2-NH2 + HBr

       ROUTE 2 (Gabriel, purer):
       CH3-CH2-Br + potassium phthalimide -->  N-ethylphthalimide
                     --(i) NaOH (ii) H3O+-->  CH3-CH2-NH2 + phthalic acid

       Route 2 is better because it gives NO secondary or tertiary amine.
```

## 9.1 The look and the smell

```
   Lower aliphatic amines  (up to about 3 carbons)   ->  GASES,
                                                         fishy ammonia smell
   Middle ones                                       ->  liquids
   Higher ones                                       ->  solids, odourless
   ANILINE                                           ->  colourless oily
                                                         liquid, turns
                                                         BROWN in air
                                                         (it is oxidised)
```

## 9.2 Boiling points — the comparison you will be asked

Amines can hydrogen bond, because N-H is a polar bond and N has a lone pair.

```
   HYDROGEN BONDING IN AMINES

        R              R              R
        |              |              |
    H-- N ---- H ----- N ---- H ----- N --H
        |              |              |
        H              H              H

   The dotted link  ---- is the hydrogen bond.
   It costs extra energy to break, so the boiling point goes UP.
```

**Comparison 1 — amines of the same molar mass (1deg vs 2deg vs 3deg):**

```
   How many N-H bonds does each have?

        1deg  R-NH2      TWO   N-H   ->  most hydrogen bonding
        2deg  R2-NH      ONE   N-H   ->  some
        3deg  R3-N       ZERO  N-H   ->  NONE AT ALL

   BOILING POINT ORDER:       1deg  >  2deg  >  3deg

   Actual numbers (all C4H11N, molar mass 73):
        n-butylamine    CH3(CH2)3NH2      351 K     1deg
        diethylamine    (C2H5)2NH         329 K     2deg
        trimethylamine ... (compare (C2H5)3N, 3deg)  lowest

   A tertiary amine has NO hydrogen on nitrogen, so it cannot
   hydrogen bond WITH ITSELF at all. Lowest boiling point.
```

**Comparison 2 — amine vs alcohol vs alkane of similar mass:**

```
   +----------------------+--------+------------------------------+
   |  COMPOUND            | b.p./K |  WHY                         |
   +----------------------+--------+------------------------------+
   |  C2H5-OH  ethanol    |  351   |  strong H-bonds (O is very   |
   |                      |        |  electronegative)            |
   |  C2H5-NH2 ethylamine |  290   |  weaker H-bonds (N is less   |
   |                      |        |  electronegative than O)     |
   |  CH3-O-CH3           |  248   |  no N-H or O-H, only dipole  |
   |  C3H8  propane       |  231   |  no polarity at all          |
   +----------------------+--------+------------------------------+

   ORDER:    ALCOHOL   >   AMINE   >   ETHER   >   ALKANE

   ONE-LINE REASON:
   "Nitrogen is less electronegative than oxygen, so the N---H---N
    hydrogen bond is weaker than the O---H---O hydrogen bond.
    Hence amines boil lower than alcohols of similar molar mass,
    but higher than alkanes, which have no hydrogen bonding at all."
```

## 9.3 Solubility

```
   Lower amines DISSOLVE in water, because they form hydrogen bonds
   WITH WATER:

             R                       H
             |                       |
        H -- N ---- H ---- O         (amine N accepts an H from water)
             |              |
             H              H

   Note that even a TERTIARY amine dissolves reasonably well, because
   although it has no N-H of its own, its LONE PAIR can still accept a
   hydrogen bond from water.

   SOLUBILITY FALLS as the carbon chain gets LONGER, because the
   greasy hydrocarbon part gets bigger and pushes the water away.

        CH3-NH2       very soluble
        C2H5-NH2      very soluble
        C6H13-NH2     slightly soluble
        C6H5-NH2      almost INSOLUBLE in water (big ring, weak H bonding)
                      but DISSOLVES IN dil. HCl, because it forms the
                      salt C6H5-NH3+ Cl-  which is ionic.
```

> **TRAP:** "Aniline is insoluble in water but dissolves in dilute HCl. Why?"
> Answer: it reacts with the acid to form **anilinium chloride**, an **ionic
> salt**, and ionic salts dissolve in water. This is how you separate an
> amine from a neutral organic compound in the laboratory.

# TOPIC 10 — BASIC STRENGTH OF AMINES (the theory question)

## 10.1 What "basic" means here

```
   A base is something that DONATES ITS LONE PAIR to a proton.

        R-NH2  +  H2O   <-->   R-NH3+  +  OH-

                          [R-NH3+][OH-]
        Kb    =         ----------------
                            [R-NH2]

        pKb   =   - log Kb

   +---------------------------------------------------------+
   |  BIG Kb  =  SMALL pKb  =  STRONGER BASE                 |
   |                                                         |
   |  So when you compare pKb values, the SMALLEST number     |
   |  is the STRONGEST base. Do not get this backwards.       |
   +---------------------------------------------------------+
```

The pKb values you should know:

| Compound | pKb | Comment |
|---|---|---|
| (C2H5)2NH | 3.00 | strongest of the common ones |
| (C2H5)3N | 3.25 | |
| (CH3)2NH | 3.27 | |
| C2H5NH2 | 3.29 | |
| CH3NH2 | 3.38 | |
| (CH3)3N | 4.22 | |
| NH3 | 4.75 | the reference point |
| C6H5-CH2-NH2 (benzylamine) | 4.70 | aliphatic, so still strong |
| C6H5-NH2 (aniline) | 9.38 | about a MILLION times weaker |
| C6H5-NH-CH3 | 9.30 | slightly stronger than aniline |
| (C6H5)2NH | 13.2 | two rings pull the lone pair, almost neutral |

## 10.2 The three effects that fight each other

```
   EFFECT 1 — INDUCTIVE (+I) EFFECT
   --------------------------------
   Alkyl groups PUSH electrons towards the nitrogen.
   More electron density on N  ->  lone pair more available  ->  more basic.

        R3N  >  R2NH  >  RNH2  >  NH3            (by +I alone)
        3 pushers  2   1     0

   EFFECT 2 — SOLVATION (hydrogen bonding of the CATION)
   -----------------------------------------------------
   After the amine grabs the proton you get the ammonium ion.
   Water stabilises that ion by hydrogen bonding to its N-H bonds.
   MORE N-H bonds  ->  BETTER stabilised  ->  the base looks STRONGER.

        R-NH3+     has 3 N-H   ->  best solvated
        R2-NH2+    has 2 N-H
        R3-NH+     has 1 N-H   ->  worst solvated

        1deg  >  2deg  >  3deg                  (by solvation alone)

   EFFECT 3 — STERIC HINDRANCE
   ---------------------------
   Three bulky alkyl groups crowd around the nitrogen and physically
   BLOCK the proton from reaching the lone pair.

        3deg is the most crowded  ->  hardest to protonate.

        1deg  >  2deg  >  3deg                  (by sterics alone)
```

```
   +--------------------------------------------------------------+
   |  EFFECT 1 says   3deg > 2deg > 1deg                          |
   |  EFFECTS 2 and 3 say   1deg > 2deg > 3deg                    |
   |                                                              |
   |  They pull in OPPOSITE directions.                           |
   |  The SECONDARY amine sits in the middle and wins both ways,  |
   |  so it usually comes out on TOP.                             |
   +--------------------------------------------------------------+
```

## 10.3 The gas phase versus aqueous solution

```
   IN THE GAS PHASE there is NO WATER, so there is NO SOLVATION.
   Only the inductive effect is left. So:

        (CH3)3N  >  (CH3)2NH  >  CH3NH2  >  NH3
        3deg     >  2deg      >  1deg    >  ammonia

        "In the gas phase, basic strength increases steadily
         with the number of alkyl groups."


   IN AQUEOUS SOLUTION all three effects operate together, and the
   order becomes IRREGULAR:

        METHYL amines:   (CH3)2NH  >  CH3NH2  >  (CH3)3N  >  NH3
                          2deg     >   1deg   >   3deg    >  NH3
                          3.27        3.38       4.22       4.75  (pKb)

        ETHYL amines:    (C2H5)2NH >  (C2H5)3N >  C2H5NH2  >  NH3
                          2deg     >   3deg    >   1deg    >  NH3
                          3.00        3.25       3.29       4.75  (pKb)
```

> **TRAP:** these two orders are **different**, and the examiner picks whichever
> one you have not learnt. Memorise both lines exactly:
>
> ```
>   METHYL:   2 , 1 , 3 , NH3
>   ETHYL:    2 , 3 , 1 , NH3
> ```
>
> The ethyl group has a bigger +I push than methyl, which lifts the tertiary
> ethylamine above the primary one.

## 10.4 Why aromatic amines are much weaker bases

This is the single most asked "explain why" question in the chapter.

```
   IN ANILINE, THE LONE PAIR IS NOT SITTING STILL.
   It is DELOCALISED into the benzene ring through resonance.

    +NH2          +NH2                 +NH2
     ||            ||                   ||
     |   <-->      |     <-->           |     <-->  (and the plain
    ( )-          (  )                 ( )            structure)
     -             |                    |
                   -                    -
      (the negative charge appears at the ortho and para
       positions; the nitrogen becomes positive)

   In simple words:
      the two electrons of the lone pair are SHARED WITH THE RING.
      They are no longer fully available to be handed to a proton.
      A base that cannot hand over its lone pair is a WEAK base.
```

```
   THE SECOND WAY TO SAY IT (the stability argument — write this one,
   it scores higher):

        ANILINE          has 5 resonance structures   -> well stabilised
        ANILINIUM ION    has only 2 (the ring Kekule  -> poorly stabilised
        C6H5-NH3+        structures); the nitrogen
                         lone pair is now used up on
                         the proton, so NO delocalisation
                         into the ring is possible

        The REACTANT (aniline) is stabilised MORE than the PRODUCT
        (anilinium ion). So the reaction of aniline with H+ is
        less favourable.  Hence aniline is a WEAK base.

        pKb aniline = 9.38   versus   pKb methylamine = 3.38
        That is a difference of 6 units  =  10^6  =  a MILLION times weaker.
```

```
   THE ORDER YOU MUST BE ABLE TO WRITE:

     CH3-NH2  >  NH3  >  C6H5-CH2-NH2  ~  ...  >  C6H5-NH2  >
                                                  (C6H5)2NH  >  (C6H5)3N

     more rings on the nitrogen  =  more places for the lone pair to
     run away to  =  weaker base.
     Triphenylamine is essentially NOT basic at all.
```

## 10.5 Effect of substituents on the basicity of aniline

```
   THE RULE, IN ONE LINE:

     ELECTRON-RELEASING groups (-CH3, -OCH3, -NH2, -OH)
          push electrons TOWARDS the nitrogen
          ->  lone pair MORE available  ->  MORE basic than aniline

     ELECTRON-WITHDRAWING groups (-NO2, -CN, -CHO, -COOH, -X)
          pull electrons AWAY from the nitrogen
          ->  lone pair LESS available  ->  LESS basic than aniline
```

| Compound | pKb | Compared with aniline (9.38) |
|---|---|---|
| p-toluidine (p-CH3) | 8.92 | MORE basic (-CH3 releases) |
| p-anisidine (p-OCH3) | 8.66 | MORE basic |
| aniline | 9.38 | reference |
| p-chloroaniline | 9.85 | less basic (-Cl withdraws) |
| m-nitroaniline | 11.5 | much less basic |
| p-nitroaniline | 13.0 | far less basic |
| o-nitroaniline | 14.3 | least basic of all |

```
   THE NITROANILINE ORDER (asked often):

        ANILINE  >  m-nitroaniline  >  p-nitroaniline  >  o-nitroaniline

   Why is META less bad than PARA?
        From the meta position the -NO2 can only pull by the INDUCTIVE
        effect (through the bonds).
        From the ORTHO and PARA positions it can pull by BOTH the
        inductive effect AND RESONANCE (it can put a + charge right
        next to the nitrogen). So o- and p- are hit harder.

   Why is ORTHO always the worst, whatever the group?
        Because a group sitting right next to the -NH2 also gets in the
        way physically and twists the -NH2 out of the plane.
        This is called the ORTHO EFFECT: whatever the substituent is,
        an ortho substituent always LOWERS the basicity.
```

## WORKED EXAMPLE 5

**Q. Arrange in increasing order of basic strength in aqueous solution:
`C6H5-NH2`, `NH3`, `(C2H5)2NH`, `C2H5-NH2`, `p-NO2-C6H4-NH2`.**

```
  STEP 1  Split into aromatic and aliphatic.
          AROMATIC (weak):  C6H5-NH2 , p-NO2-C6H4-NH2
          AMMONIA:          NH3
          ALIPHATIC (strong): C2H5-NH2 , (C2H5)2NH

  STEP 2  Within the aromatics: -NO2 is electron withdrawing, so
          p-nitroaniline is WEAKER than aniline.
             p-NO2-C6H4-NH2  <  C6H5-NH2

  STEP 3  All aliphatic amines beat ammonia (alkyl +I effect).
          Within the ethyl series: 2deg beats 1deg.
             NH3  <  C2H5-NH2  <  (C2H5)2NH

  STEP 4  Aromatic amines are weaker than ammonia.

  ANSWER (increasing basic strength):

     p-NO2-C6H4-NH2  <  C6H5-NH2  <  NH3  <  C2H5-NH2  <  (C2H5)2NH

  In pKb terms:   13.0  >  9.38  >  4.75  >  3.29  >  3.00
  (remember pKb runs the OTHER way)
```

## 11.1 As a base — salt formation

```

   That is why alkylation is a poor preparative method.

## 11.3 Acylation — putting a C=O onto the nitrogen

```
   The N-H of a 1deg or 2deg amine is replaced by an ACYL group (R-CO-).
   The product is an AMIDE.

   ACETYLATION  (with acetyl chloride or acetic anhydride):

   C6H5-NH2  +  CH3-CO-Cl   --pyridine-->   C6H5-NH-CO-CH3  +  HCl

                acetic anhydride  acetanilide

   C6H5-NH2  +  C6H5-CO-Cl   --aqueous NaOH-->  C6H5-NH-CO-C6H5  +  HCl
   aniline      benzoyl chloride                BENZANILIDE
                                                (N-phenylbenzamide)
                                                a white solid

   For a primary aliphatic amine:
   CH3-NH2 + C6H5-CO-Cl --NaOH-->  C6H5-CO-NH-CH3  (N-methylbenzamide)

```
   WHY IS A BASE (pyridine or NaOH) ADDED?
        The reaction makes HCl. That HCl would grab the amine and turn it
        into its unreactive salt, stopping the reaction.
        The added base MOPS UP the HCl and drives the reaction forward.

   WHICH AMINES REACT?
        1deg  ->  YES (it has 2 N-H)
        2deg  ->  YES (it has 1 N-H)
        3deg  ->  NO. There is no hydrogen on nitrogen to replace.
```

> and the fact that acetylation is the **protecting step** you need before
> brominating or nitrating aniline (Topic 15).

# TOPIC 13 — THE HINSBERG TEST (DISTINGUISHES ALL THREE)

The reagent is **benzenesulphonyl chloride**, `C6H5-SO2-Cl`, also called
**Hinsberg's reagent**.

## 13.1 What happens with each class

```
   PRIMARY AMINE
   -------------
   C6H5-SO2-Cl  +  H2N-R    -->   C6H5-SO2-NH-R   +   HCl
                                  N-alkylbenzene-
                                  sulphonamide

   The nitrogen still carries ONE hydrogen.
   That hydrogen is ACIDIC, because the SO2 group is strongly electron
   withdrawing and pulls the electrons away from the N-H bond.
   So an alkali can take it off:

   C6H5-SO2-NH-R  +  KOH   -->   C6H5-SO2-N-(K+)-R   +  H2O
                                 a POTASSIUM SALT = SOLUBLE

   OBSERVATION:  a precipitate forms, and it DISSOLVES in excess KOH/NaOH.


   SECONDARY AMINE
   ---------------
   C6H5-SO2-Cl  +  HN-R2    -->   C6H5-SO2-N-R2   +   HCl
                                  N,N-dialkylbenzene-
                                  sulphonamide

   The nitrogen now has NO hydrogen left.
   There is nothing for the alkali to remove, so no salt can form.

   OBSERVATION:  a precipitate forms, and it does NOT dissolve in alkali.


   TERTIARY AMINE
   --------------
   C6H5-SO2-Cl  +  R3N    -->   NO REACTION

   The tertiary amine has no hydrogen on nitrogen at all, so there is
   nothing to substitute.

   OBSERVATION:  nothing happens; the amine stays as an insoluble
                 liquid layer. Add dilute HCl and it dissolves
                 (because it forms R3NH+ Cl-), which confirms it.
```

```

```
   THE ONE-LINE SUMMARY TO WRITE IN THE EXAM:

     1deg  ->  ppt SOLUBLE in alkali
     2deg  ->  ppt INSOLUBLE in alkali
     3deg  ->  NO REACTION

   Say it as:   "soluble, insoluble, no reaction."
```

> **TRAP:** the Hinsberg test also **separates** a mixture of the three amines,
> not just identifies them. Filter off the insoluble 2deg sulphonamide, extract
> the 3deg amine into acid, and get the 1deg back by acidifying the alkaline
> solution. If a question says "how will you SEPARATE a mixture of 1deg, 2deg
> and 3deg amines", Hinsberg is the answer.

## 13.3 Hofmann's method (the other separation method)

```
   Reagent:  diethyl oxalate,  (COOC2H5)2

     1deg amine  ->  a SOLID  N,N'-dialkyloxamide
     2deg amine  ->  a LIQUID N,N-dialkyloxamic ester
     3deg amine  ->  NO REACTION

   Solid, liquid, nothing -> so they can be separated by filtration
   and distillation.
```

# TOPIC 14 — REACTION WITH NITROUS ACID (HNO2)

Nitrous acid is unstable, so it is always made **fresh, in the flask**, from
sodium nitrite and a mineral acid, in ice:

```
   NaNO2  +  HCl   -->   HNO2  +  NaCl          at 273 - 278 K (0 - 5 C)
```

## 14.1 What each amine does

```
   1deg ALIPHATIC AMINE
   --------------------
   R-NH2  --NaNO2/HCl, 273-278 K-->  [R-N2+ Cl-]  -->  R-OH  +  N2 (gas)
                                     unstable! falls
                                     apart at once

   Example:  C2H5-NH2 + HNO2  -->  C2H5-OH + N2 + H2O

   OBSERVATION:  BRISK EFFERVESCENCE of a colourless, odourless gas (N2).
   THE TEST:     "brisk effervescence of nitrogen" = primary ALIPHATIC amine.
   WHY IT IS USEFUL: this reaction is quantitative, so the N2 collected
                     can be measured to estimate the amine.


   1deg AROMATIC AMINE
   -------------------
   C6H5-NH2  --NaNO2/HCl, 273-278 K-->  C6H5-N2+ Cl-   +  NaCl  +  2 H2O
                                        BENZENEDIAZONIUM CHLORIDE
                                        which is STABLE at this temperature

   OBSERVATION:  no gas at 273-278 K; a clear solution you use straight away.
   This is called DIAZOTISATION and it opens the whole of Topic 16.


   2deg AMINE (aliphatic OR aromatic)
   ----------------------------------
   R2-NH  +  HNO2   -->   R2-N-N=O   +   H2O
                          N-NITROSOAMINE

   Example: (CH3)2NH + HNO2 --> (CH3)2N-N=O  (N-nitrosodimethylamine)
            C6H5-NH-CH3 + HNO2 --> C6H5-N(CH3)-N=O

   OBSERVATION:  a YELLOW OILY LIQUID separates out.
   (Warm it with phenol and conc. H2SO4, then add NaOH: a deep blue or
    green colour appears. That is LIEBERMANN'S NITROSO TEST.)


   3deg AMINE
   ----------
   ALIPHATIC:   R3N  +  HNO2   -->   R3NH+ NO2-
                                     a soluble trialkylammonium nitrite
                                     (just an acid-base salt; nothing more)

   AROMATIC:    C6H5-N(CH3)2  +  HNO2  -->  p-nitroso-N,N-dimethylaniline
                                            a GREEN solid
                (the ring is so activated that the weak NO+ electrophile
                 can attack the para position)
```

# TOPIC 15 — ELECTROPHILIC SUBSTITUTION IN ANILINE

## 15.1 Why the -NH2 group is so powerful

```
   The nitrogen lone pair flows INTO the ring. That dumps extra electron
   density on the ORTHO and PARA carbons:

               NH2                     +NH2                    +NH2
                |                       ||                      ||
               ( )         <-->        (  )-        <-->       ( )
                                         ^                      |
                                      ORTHO gets                |
                                      the charge                v
                                                             PARA gets
                                                             the charge

   Electrophiles attack where the electrons are.
   So  -NH2  is a STRONGLY ACTIVATING,  ORTHO / PARA DIRECTING group.

   In fact it is TOO strong: aniline reacts so eagerly that you get
   substitution at ALL THREE activated positions at once.
```

## 15.2 Bromination

```
   WITHOUT PROTECTION (in water, at room temperature):

   C6H5-NH2  +  3 Br2 (aqueous)  -->  2,4,6-tribromoaniline  +  3 HBr
                                      a WHITE PRECIPITATE

                     NH2
                      |
              Br --- ( ) --- Br
                      |
                      Br

   Instant, no catalyst needed. The white ppt is itself a TEST for aniline.
   But if you actually wanted only ONE bromine, you have failed.
```

```
   WITH PROTECTION (the three-step route to p-bromoaniline):

   STEP 1  PROTECT   C6H5-NH2 + (CH3CO)2O  -->  C6H5-NH-CO-CH3
                                                ACETANILIDE

   STEP 2  BROMINATE C6H5-NH-CO-CH3 + Br2 --CH3COOH-->
                                          p-bromoacetanilide  (+ some ortho)

   STEP 3  DEPROTECT p-Br-C6H4-NH-CO-CH3 --H3O+ (or NaOH), hydrolysis-->
                                          p-BROMOANILINE + CH3COOH


   WHY DOES ACETYLATION HELP?
        In acetanilide the nitrogen lone pair is pulled towards the
        C=O of the acetyl group instead of into the ring:

                O                     O -
                ||                    |
        Ar-N -- C - CH3   <-->  Ar-N = C - CH3
           |                       |
           H                       H  (+)

        So LESS electron density reaches the ring.
        The ring is still activated, but only MODERATELY.
        Result: only ONE substitution takes place.

        The bulky -NH-CO-CH3 group also BLOCKS the ortho positions,
        so the PARA product is the main one.
```

## 15.3 Nitration

```
   DIRECT NITRATION IS A DISASTER:

   C6H5-NH2 --conc. HNO3 + conc. H2SO4-->
                    ortho about 2 % , META about 47 % , para about 51 %

   WHY SO MUCH META, when -NH2 is supposed to be ortho/para directing?

        Because the mixture is STRONGLY ACIDIC.
        In strong acid the aniline is PROTONATED:

             C6H5-NH2  +  H+   -->   C6H5-NH3+   (anilinium ion)

        The anilinium ion has NO lone pair left on nitrogen, and it
        carries a POSITIVE charge. A positive group is
        DEACTIVATING and META-DIRECTING.

        So you are really nitrating TWO different species at once:
        some free aniline (giving o- and p-) and a lot of anilinium
        ion (giving m-). Hence the ugly mixture.


   THE PROPER ROUTE TO p-NITROANILINE:

   STEP 1  C6H5-NH2  + (CH3CO)2O   -->  acetanilide
   STEP 2  acetanilide + conc.HNO3 / conc.H2SO4, 288 K
                                   -->  p-nitroacetanilide (major)
   STEP 3  p-nitroacetanilide  --H3O+ , hydrolysis-->  p-NITROANILINE
```

## 15.4 Sulphonation — and the zwitterion

```
   C6H5-NH2  +  conc. H2SO4   -->   C6H5-NH3+ HSO4-
                                    anilinium hydrogensulphate
                                          |
                                    heat, 453 - 473 K
                                          v
                                    SULPHANILIC ACID
                                    (p-aminobenzenesulphonic acid)

   SULPHANILIC ACID EXISTS AS A ZWITTERION (a dipolar ion / inner salt):

                 NH3+                       the -NH2 is basic
                  |                         the -SO3H is acidic
                 ( )                        so the acid gives its
                  |                         proton to the amine
                 SO3-                       INSIDE THE SAME MOLECULE

   Because it is really an ionic salt, sulphanilic acid has a very high
   melting point and is insoluble in organic solvents.
   Its amide, SULPHANILAMIDE, is the parent of the SULPHA DRUGS.
```

## 15.5 Why aniline gives NO Friedel-Crafts reaction

```
   +--------------------------------------------------------------+
   |  Friedel-Crafts needs the Lewis acid ANHYDROUS AlCl3.         |
   |                                                              |
   |  AlCl3 is an electron PAIR ACCEPTOR (a Lewis acid).           |
   |  Aniline has a lone pair, so it is an electron PAIR DONOR     |
   |  (a Lewis base).                                             |
   |                                                              |
   |  They react with each other FIRST:                            |
   |                                                              |
   |      C6H5-NH2   +   AlCl3    -->   C6H5-NH2+ - AlCl3-        |
   |                                    (an acid-base complex)     |
   |                                                              |
   |  Now the nitrogen carries a POSITIVE charge. A positively     |
   |  charged group is strongly DEACTIVATING - it sucks electrons  |
   |  out of the ring instead of feeding them in.                  |
   |                                                              |
   |  The deactivated ring will not react with the weak            |
   |  electrophile, so NO alkylation or acylation occurs.          |
   +--------------------------------------------------------------+

   Write it as one sentence:
   "Aniline is a Lewis base and reacts with the Lewis acid AlCl3 to form
    a salt in which nitrogen bears a positive charge; this strongly
    deactivates the ring, so aniline does not undergo Friedel-Crafts
    reaction."
```

> **TRAP:** the same logic explains why aniline is **not nitrated cleanly**
> and why aniline **does not react in strongly acidic media**: once the
> nitrogen is positive, the ring is dead. One idea, three marks.

# TOPIC 16 — DIAZONIUM SALTS: PREPARATION AND STABILITY

## 16.1 What they are

```
   General formula:      Ar - N2+  X-          (X- = Cl-, HSO4-, BF4- ...)

   Benzenediazonium chloride:      C6H5 - N(triple)N+  Cl-

   The two nitrogens are joined by a triple bond and the whole
   -N2+ group carries a positive charge, balanced by the anion.
```

## 16.2 Preparation — DIAZOTISATION

```
   C6H5-NH2 + NaNO2 + 2 HCl  --273-278 K-->  C6H5-N2+ Cl- + NaCl + 2 H2O

   In two steps as it really happens:

        NaNO2  +  HCl        -->  HNO2  +  NaCl         (nitrous acid, fresh)
        C6H5-NH2  +  HNO2  +  HCl  -->  C6H5-N2+Cl-  +  2 H2O
```

```
   THE CONDITIONS - all four are worth marks:

   1.  TEMPERATURE  273 - 278 K  (0 - 5 C), in an ICE BATH.
       Above 278 K the salt decomposes:
            C6H5-N2+Cl-  +  H2O   -->   C6H5-OH  +  N2  +  HCl
       and you get phenol instead of what you wanted.

   2.  EXCESS MINERAL ACID (HCl or H2SO4). It makes the HNO2 and keeps
       the medium acidic.

   3.  NaNO2 IS ADDED SLOWLY, with stirring.

   4.  USE THE SOLUTION IMMEDIATELY. Do not try to isolate the solid.
       Dry solid diazonium chlorides are UNSTABLE and EXPLOSIVE.
       (The fluoroborate C6H5-N2+ BF4- is the exception - it is stable
        enough to be isolated as a dry solid.)
```

## 16.3 Why the ARENEdiazonium ion is stable but the alkyl one is not

```
   In C6H5-N2+ the positive charge is NOT stuck on the nitrogen.
   It is spread out over the whole ring by RESONANCE:

        C6H5-N(triple)N+     <-->     +(ring) = N = N     <-->  ...

        The positive charge visits the ortho and para carbons of the
        ring as well as the nitrogen.

   SPREADING A CHARGE OUT ALWAYS LOWERS THE ENERGY.
   Lower energy  =  more stable.
   That is why an ARENEdiazonium salt survives at 273-278 K.


   In an ALKYL diazonium salt  R-N2+  there is NO ring to spread the
   charge into. The charge stays on one atom, the ion is high in energy,
   and it falls apart the instant it is formed:

        R-N2+   -->   R+  +  N2 (gas)   -->   R-OH

   THAT is why a primary ALIPHATIC amine + HNO2 gives an alcohol and
   nitrogen gas, while a primary AROMATIC amine + HNO2 gives a salt
   you can keep in the beaker.
```

# TOPIC 17 — REACTIONS OF DIAZONIUM SALTS

Split them into two families and you will never confuse them.

```
   FAMILY A   the N2 LEAVES as a gas, and something takes its place.
              (these are SUBSTITUTIONS. You end up with C6H5-Z.)

   FAMILY B   the N2 STAYS in the product.
              (these are the COUPLING reactions, giving AZO DYES.)
```

## 17.1 The fan diagram — FAMILY A

```
                             Cu2Cl2 / HCl
                       +-------------------->  C6H5-Cl   + N2   SANDMEYER
                       |
                       |     Cu2Br2 / HBr
                       +-------------------->  C6H5-Br   + N2   SANDMEYER
                       |
                       |     CuCN / KCN
                       +-------------------->  C6H5-CN   + N2   SANDMEYER
                       |
                       |     Cu powder / HCl
                       +-------------------->  C6H5-Cl   + N2   GATTERMANN
                       |
                       |     Cu powder / HBr
   C6H5-N2+ Cl-  ------+-------------------->  C6H5-Br   + N2   GATTERMANN
                       |
                       |     KI , warm
                       +-------------------->  C6H5-I    + N2
                       |                       (no catalyst needed!)
                       |
                       |     (i) HBF4  (ii) heat the dry salt
                       +-------------------->  C6H5-F + BF3 + N2
                       |                       BALZ-SCHIEMANN
                       |
                       |     H2O , warm 283 K
                       +-------------------->  C6H5-OH + N2 + HCl
                       |
                       |     H3PO2 + H2O   (hypophosphorous acid)
                       +-------------------->  C6H6 + N2 + H3PO3
                       |                       (also works with C2H5OH)
                       |
                       |     NaNO2 / Cu
                       +-------------------->  C6H5-NO2 + N2
```

## 17.2 Sandmeyer versus Gattermann — know the difference

| | SANDMEYER | GATTERMANN |
|---|---|---|
| Reagent | **Cu2X2** (cuprous halide) + HX | **Cu powder** + HX |
| Products possible | -Cl, -Br and **-CN** | -Cl and -Br only |
| Yield | higher | lower |
| Convenience | needs the cuprous salt prepared | simpler, just copper dust |

```
   Cu2Cl2 = cuprous chloride = CuCl. Both ways of writing it are accepted.

   MEMORY HOOK:  "SANDmeyer uses a SALT (Cu2X2).
                  GATTERmann uses the metal (Cu)."
```

## 17.3 The equations, written out

```
   C6H5-N2+Cl-   --Cu2Cl2 / HCl-->    C6H5-Cl   +  N2
   C6H5-N2+Cl-   --Cu2Br2 / HBr-->    C6H5-Br   +  N2
   C6H5-N2+Cl-   --CuCN / KCN-->      C6H5-CN   +  N2
   C6H5-N2+Cl-   --Cu / HCl-->        C6H5-Cl   +  N2
   C6H5-N2+Cl-   --KI , warm-->       C6H5-I    +  N2  +  KCl
   C6H5-N2+Cl-   --HBF4-->            C6H5-N2+BF4-  --heat-->
                                      C6H5-F  +  BF3  +  N2
   C6H5-N2+Cl-   --H2O , 283 K-->     C6H5-OH   +  N2  +  HCl
   C6H5-N2+Cl-   --H3PO2 + H2O-->     C6H6  +  N2  +  H3PO3  +  HCl
   C6H5-N2+Cl-   --NaNO2 / Cu-->      C6H5-NO2  +  N2  +  NaCl
```

> **TRAP:** iodination needs **no copper catalyst at all** — just warm with
> KI. Fluorination needs the **fluoroborate to be isolated and heated dry**.
> Examiners ask exactly these two exceptions.

## 17.4 The reaction with H3PO2 — why it matters

```
   C6H5-N2+ Cl-  +  H3PO2  +  H2O   -->   C6H6  +  N2  +  H3PO3  +  HCl

   This REMOVES the nitrogen and puts back a plain hydrogen.
   Why would you ever want to do that?

   BECAUSE THE -NH2 GROUP CAN BE USED AS A TEMPORARY SIGNPOST.
   You put -NH2 on the ring, let it DIRECT other groups to the ortho
   and para positions, and then you REMOVE it with diazotisation +
   H3PO2 as if it had never been there.

   That trick is how you make compounds you could never make directly.
   See the worked example in Topic 19.
```

# TOPIC 18 — COUPLING REACTIONS AND AZO DYES

Here the nitrogen **stays**. The diazonium ion acts as a (weak) electrophile
and attacks another aromatic ring.

```
   GENERAL SHAPE:

        Ar-N2+   +   H-Ar'    -->    Ar - N = N - Ar'   +   H+
                                     an AZO COMPOUND
                                     (the -N=N- is the AZO group)
```

## 18.1 Coupling with phenol

```
   C6H5-N2+Cl-   +   C6H5-OH   --NaOH, pH 9-10, 273-278 K-->

                  C6H5 - N = N - C6H4 - OH   (para)
                  p-hydroxyazobenzene
                  an ORANGE DYE

   CONDITION:  MILDLY ALKALINE (pH about 9 - 10).
   WHY?        NaOH converts phenol into the PHENOXIDE ion C6H5-O- ,
               which is even MORE activated than phenol itself, so the
               weak diazonium electrophile can attack it.
               (Strongly alkaline is bad: it destroys the diazonium ion.)
```

## 18.2 Coupling with aniline

```
   C6H5-N2+Cl-   +   C6H5-NH2   --pH 4-5, 273-278 K-->

                  C6H5 - N = N - C6H4 - NH2  (para)
                  p-aminoazobenzene
                  a YELLOW DYE

   CONDITION:  MILDLY ACIDIC (pH about 4 - 5).
   WHY?        Strongly acidic would protonate the aniline to the
               anilinium ion C6H5-NH3+ , which is DEACTIVATED and would
               not couple at all. So keep the acid weak.
```

```
   THE TABLE TO MEMORISE

   +---------------+-------------------+----------------------+--------+
   |  COUPLES WITH |  CONDITION        |  PRODUCT             | COLOUR |
   +---------------+-------------------+----------------------+--------+
   |  PHENOL       |  mildly ALKALINE  |  p-hydroxyazobenzene | ORANGE |
   |               |  NaOH, pH 9-10    |                      |        |
   |  ANILINE      |  mildly ACIDIC    |  p-aminoazobenzene   | YELLOW |
   |               |  pH 4-5           |                      |        |
   +---------------+-------------------+----------------------+--------+

   MEMORY HOOK:  "PHENOL likes the BASE (both start with a soft sound),
                  ANILINE (a base itself) needs a little ACID."
```

## 18.3 The rules of coupling

```
   1.  Coupling ALWAYS happens at the PARA position of the other ring.
       If para is blocked, it goes ORTHO.

   2.  The other ring MUST be STRONGLY ACTIVATED (-OH, -NH2, -NR2).
       Benzene, toluene, nitrobenzene etc. do NOT couple.
       REASON: the diazonium ion is only a WEAK electrophile.

   3.  Temperature stays at 273-278 K throughout.

   4.  The product is COLOURED because the -N=N- bridge joins the two
       rings into one long conjugated system of alternating single and
       double bonds. Long conjugation absorbs visible light.
       That is why azo compounds are used as DYES and as INDICATORS
       (methyl orange is an azo dye).
```

# TOPIC 19 — WHY DIAZONIUM SALTS MATTER IN SYNTHESIS

```
   +---------------------------------------------------------------+
   |  GROUPS YOU CANNOT PUT ON A BENZENE RING DIRECTLY,            |
   |  BUT CAN PUT ON THROUGH A DIAZONIUM SALT:                      |
   |                                                               |
   |       -F      -I      -CN      -OH      -H (removal)          |
   |                                                               |
   |  You also get -Cl and -Br in positions that direct            |
   |  substitution differently from the way they would if you       |
   |  halogenated the ring directly.                                |
   +---------------------------------------------------------------+
```

## WORKED EXAMPLE 7 — the classic synthesis question

**Q. How would you prepare 1,3,5-tribromobenzene from benzene?**

```
  WHY YOU CANNOT DO IT DIRECTLY:
     -Br is an ORTHO/PARA director. Brominating benzene three times
     would give you 1,2,4-tribromobenzene, never 1,3,5-.
     You need the three Br atoms all META to each other, and no
     ortho/para director can arrange that.

  THE TRICK: use -NH2 as a temporary signpost, then delete it.

  STEP 1   NITRATE benzene
           C6H6  --conc.HNO3 + conc.H2SO4, 330 K-->  C6H5-NO2

  STEP 2   REDUCE to aniline
           C6H5-NO2  --Sn / HCl , then NaOH-->  C6H5-NH2

  STEP 3   BROMINATE. The -NH2 is so activating that all three
           ortho/para positions react at once - exactly what we want.
           C6H5-NH2  +  3 Br2 (aq)  -->  2,4,6-tribromoaniline + 3 HBr

  STEP 4   DIAZOTISE
           2,4,6-tribromoaniline  --NaNO2 / HCl , 273-278 K-->
                                  2,4,6-tribromobenzenediazonium chloride

  STEP 5   REMOVE the nitrogen with hypophosphorous acid
           --H3PO2 + H2O-->   1,3,5-TRIBROMOBENZENE  +  N2  +  H3PO3

  Look at what happened: the three Br atoms were placed by the -NH2
  group, and then the -NH2 was thrown away, leaving them in a pattern
  that direct bromination could never produce.
```

## WORKED EXAMPLE 8

**Q. Convert aniline into (a) phenol (b) iodobenzene (c) benzonitrile
(d) fluorobenzene.**

```
  ALL FOUR START THE SAME WAY:

     C6H5-NH2  --NaNO2 + HCl , 273-278 K-->  C6H5-N2+ Cl-

  Then:

  (a) PHENOL          C6H5-N2+Cl- --H2O , warm 283 K-->  C6H5-OH + N2 + HCl

  (b) IODOBENZENE     C6H5-N2+Cl- --KI , warm-->  C6H5-I + N2 + KCl
                      (no copper catalyst needed)

  (c) BENZONITRILE    C6H5-N2+Cl- --CuCN / KCN-->  C6H5-CN + N2
                      (SANDMEYER)

  (d) FLUOROBENZENE   C6H5-N2+Cl- --HBF4-->  C6H5-N2+ BF4-
                      --heat the dry salt-->  C6H5-F + BF3 + N2
                      (BALZ-SCHIEMANN)

  MARK-SCORING TIP: always write the diazotisation step with its
  TEMPERATURE. Half the marks in these questions are for "273-278 K".
```

# TOPIC 20 — CYANIDES AND ISOCYANIDES

Two compounds with the **same formula** but a different atom doing the joining.
They are **isomers** (this kind is called *functional isomerism*).

```
   CYANIDE  (nitrile)              ISOCYANIDE (carbylamine)
   ------------------              ------------------------
        R - C (triple) N                R - N (triple) C

   CARBON joins the R group        NITROGEN joins the R group

   Example, both C2H3N:
        CH3-CN   methyl cyanide         CH3-NC   methyl isocyanide
                 (ethanenitrile)                 (methyl carbylamine)
```

## 20.1 Structure

```
   CYANIDE:      R - C (triple) N  :
                 carbon is sp hybridised, the molecule is LINEAR,
                 a lone pair sits on the nitrogen.

   ISOCYANIDE:   two resonance structures:

                 R - N (triple) C -            R - N = C :
                     (+)      (-)

                 The main contributor is the charged one.
                 The terminal CARBON has a lone pair and is
                 formally DIVALENT - which is why isocyanides are
                 so reactive and so smelly.
```

## 20.2 Preparation

```
   CYANIDES
        R-X  +  KCN (alcoholic)   -->   R-CN  +  KX      (major product)
        R-CO-NH2  --P2O5 , heat-->      R-CN  +  H2O     (dehydration
                                                          of an amide)

   ISOCYANIDES
        R-X  +  AgCN             -->    R-NC  +  AgX     (major product)
        R-NH2 + CHCl3 + 3KOH --heat-->  R-NC + 3KCl + 3H2O
                                        (the CARBYLAMINE reaction)
```

```
   WHY DOES KCN GIVE THE CYANIDE BUT AgCN GIVE THE ISOCYANIDE?

        CN-  is an AMBIDENT nucleophile: it can attack through C or N.

        KCN  is IONIC.  The free CN- ion attacks through CARBON,
                        because the C-C bond formed is stronger
                        than a C-N bond.       ->  R-CN

        AgCN is COVALENT. The carbon is tied up with silver, so only
                        the NITROGEN lone pair is free to attack.
                                                 ->  R-NC

   Compare this with the nitrite case in Topic 3.3 - it is exactly the
   same idea. Learn them as a pair:

        KCN  -> cyanide          AgCN  -> isocyanide
        KNO2 -> nitrite          AgNO2 -> nitro compound
```

## 20.3 The differences table (a ready-made 4-mark answer)

| PROPERTY | CYANIDE R-CN | ISOCYANIDE R-NC |
|---|---|---|
| Joining atom | carbon | nitrogen |
| Smell | pleasant, almond-like | extremely offensive |
| Polarity / dipole | higher | lower |
| Boiling point | higher | lower |
| **Acid hydrolysis** | **R-COOH + NH3** | **R-NH2 + HCOOH** |
| Alkaline hydrolysis | R-COONa + NH3 | does **not** happen (only acids hydrolyse isocyanides) |
| **Reduction** | **R-CH2-NH2** (1deg amine) | **R-NH-CH3** (2deg amine) |
| Made from | R-X + KCN | R-X + AgCN, or RNH2 + CHCl3 + KOH |
| Carbon count of product | acid has the SAME carbons as the nitrile | amine has ONE LESS than the isocyanide |

```
   THE TWO HYDROLYSES, WRITTEN OUT — learn these two lines:

     CH3-CN  +  2 H2O   --H+-->   CH3-COOH   +   NH3
     (2 C)                        acetic acid (2 C)

     CH3-NC  +  2 H2O   --H+-->   CH3-NH2    +   HCOOH
     (2 C)                        methylamine (1 C) + formic acid (1 C)

   MEMORY HOOK:
     "cyaNide gives an aCid.  isocyaNide gives an amiNe (and formic acid)."
```

```
   THE TWO REDUCTIONS:

     CH3-CN  +  4[H]  --Na/C2H5OH-->  CH3-CH2-NH2      PRIMARY amine
     CH3-NC  +  4[H]  --Na/C2H5OH-->  CH3-NH-CH3       SECONDARY amine

   Why? Because in the isocyanide the R group is already on the nitrogen,
   so when the added hydrogens build a CH3 on the other side you end up
   with TWO carbon groups on one nitrogen.
```

```
   USES OF AMINES AND THEIR RELATIVES

     Aniline           ->  dyes, drugs, rubber chemicals
     Azo compounds     ->  DYES and INDICATORS (methyl orange)
     Sulphanilamide    ->  the first SULPHA DRUG (antibacterial)
     Quaternary        ->  detergents, fabric softeners,
     ammonium salts        phase-transfer catalysts
     Diazonium salts   ->  the gateway to -F, -I, -CN, -OH, -H on a ring
     Nitro compounds   ->  explosives (TNT), solvents
```

```
   THREE SMALL FACTS THAT TURN UP AS 2-MARKERS

   1.  Aniline turns BROWN on standing in air.
       It is slowly OXIDISED by oxygen. Store it in a dark bottle.

   2.  Aniline reacts with CHCl3 + KOH to give a foul smell
       (carbylamine) - so a foul smell is a positive test for
       a primary amine, aromatic or aliphatic.

   3.  Amines are BASIC, so they turn red litmus BLUE, unlike almost
       all the other organic compounds you have studied.
       Alcohols, aldehydes and ketones are neutral; acids and phenols
       are acidic; AMINES ARE THE ONLY BASIC FAMILY in the syllabus.
```
