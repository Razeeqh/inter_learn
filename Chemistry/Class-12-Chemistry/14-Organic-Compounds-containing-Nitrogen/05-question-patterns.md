# Organic Compounds containing Nitrogen — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The compounds change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — CLASSIFY THE AMINE (1deg / 2deg / 3deg)             2 marks
  ------------------------------------------------------------------------
  TRIGGER   A structure is given and you are asked whether it is primary,
            secondary or tertiary.
  METHOD    Look at the NITROGEN atom.
            Count how many CARBON GROUPS are attached to it.
               1 carbon  ->  PRIMARY
               2 carbons ->  SECONDARY
               3 carbons ->  TERTIARY
               4 carbons ->  QUATERNARY ammonium salt (N is + charged)
  EXAMPLE   (CH3)3C-NH2  ->  one C on N  ->  PRIMARY
            C6H5-NH-CH3  ->  two C on N  ->  SECONDARY
  TRAP      You count carbons on the NITROGEN for an amine, but on the
            CARBON for an alcohol. So (CH3)3C-OH is a TERTIARY alcohol
            while (CH3)3C-NH2 is a PRIMARY amine. This single confusion
            costs more marks than anything else in the chapter.
```

```
  PATTERN 2 — ALIPHATIC OR AROMATIC?                              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Is this an aromatic amine?" or a basicity comparison that
            includes a compound with a benzene ring in it.
  METHOD    Ask ONE question: is the NITROGEN joined DIRECTLY to the RING?
               YES ->  AROMATIC amine (weak base, lone pair delocalised)
               NO  ->  ALIPHATIC amine (strong base)
  EXAMPLE   C6H5-NH2       N on the ring       AROMATIC, pKb 9.38
            C6H5-CH2-NH2   N on a CH2          ALIPHATIC, pKb 4.7
  TRAP      Benzylamine C6H5-CH2-NH2 looks aromatic and is not. It is a
            STRONG base. Examiners put it in basicity lists on purpose.
```

```
  PATTERN 3 — NAME THE AMINE (IUPAC and common)                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the IUPAC name of ..." or "Write the structure of ..."
  METHOD    1. Find the LONGEST chain carrying the -NH2. Name the alkane.
            2. Drop the final "e", add "amine". (ethane -> ethanamine)
            3. Number so the -NH2 gets the LOWEST locant.
            4. Groups on the NITROGEN get the prefix  N-  .
            5. If the N is joined straight to a ring, the parent is ANILINE.
            6. For TWO amino groups, KEEP the "e": ethane-1,2-diamine.
  EXAMPLE   CH3-CH2-CH(NH2)-CH3   ->  butan-2-amine
            C6H5-N(CH3)-C2H5      ->  N-ethyl-N-methylaniline
  TRAP      Forgetting the "N-" prefix, or dropping the "e" in a diamine.
            Half a mark each, and they add up.
```

```
  PATTERN 4 — STRUCTURE AND SHAPE OF THE AMINO GROUP              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the shape of the amino group?" / "hybridisation" /
            "bond angle in trimethylamine".
  METHOD    Write these four facts:
               1. nitrogen is sp3 hybridised
               2. three orbitals hold bonds, the fourth holds the LONE PAIR
               3. shape is PYRAMIDAL (trigonal pyramidal)
               4. C-N-C angle about 108 deg, LESS than 109.5 deg because
                  lone pair - bond pair repulsion is stronger than
                  bond pair - bond pair repulsion
  TRAP      Saying "tetrahedral". The ARRANGEMENT of orbitals is
            tetrahedral, but the SHAPE (which counts only atoms) is
            PYRAMIDAL. Write pyramidal.
```

```
  PATTERN 5 — CARBON COUNTING IN A CONVERSION                4 marks often
  ------------------------------------------------------------------------
  TRIGGER   "Convert A into B" where A and B have different chain lengths.
  METHOD    Count the carbons in A and in B FIRST, before writing anything.
               B has ONE MORE  ->  go through a NITRILE (R-X + KCN, then
                                   reduce)
               B has ONE LESS  ->  HOFMANN bromamide on the amide
               SAME            ->  ammonolysis, Gabriel, nitro reduction,
                                   or LiAlH4 on the amide
  EXAMPLE   CH3-Br (1C) -> CH3-CH2-NH2 (2C):
               CH3-Br --KCN--> CH3-CN --H2/Ni--> CH3-CH2-NH2
            CH3-CONH2 (2C) -> CH3-NH2 (1C):
               CH3-CONH2 + Br2 + 4NaOH -> CH3-NH2 + Na2CO3 + 2NaBr + 2H2O
  TRAP      Using LiAlH4 when the question needs Hofmann, or the reverse.
            Same amide, opposite carbon count.
```

```
  PATTERN 6 — "WHY DOES AMMONOLYSIS GIVE A MIXTURE?"              2 marks
  ------------------------------------------------------------------------
  TRIGGER   R-X + NH3 in the question, or the word "mixture".
  METHOD    Three sentences:
               1. The amine formed is ITSELF a nucleophile.
               2. It is a BETTER nucleophile than ammonia, because the
                  alkyl group pushes electrons onto nitrogen (+I effect).
               3. So it attacks more R-X, giving 2deg, 3deg and finally
                  the quaternary ammonium salt.
            Then the cure: use a LARGE EXCESS OF AMMONIA.
  TRAP      Forgetting to mention the QUATERNARY salt as the final stage,
            and forgetting that ammonolysis does NOT work on aryl halides.
```

```
  PATTERN 7 — GABRIEL PHTHALIMIDE SYNTHESIS                  2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   The word "phthalimide", or "how do you get a PURE primary
            amine", or "why does this method fail for aniline".
  METHOD    Three steps, always in this order:
               1. phthalimide + KOH -> potassium phthalimide
               2. + R-X -> N-alkylphthalimide  (SN2)
               3. + aq. NaOH, boil, then H3O+ -> R-NH2 + phthalic acid
            Why no mixture: after step 2 the nitrogen has NO hydrogen and
            is locked between two C=O groups, so it cannot react again.
  TRAP      The "why it fails for aromatic amines" part is worth half the
            marks: aryl halides do NOT undergo nucleophilic substitution,
            because the C-X bond has partial double-bond character from
            resonance with the ring.
```

```
  PATTERN 8 — HOFMANN BROMAMIDE DEGRADATION                  2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   An AMIDE plus Br2 plus NaOH, or the word "degradation", or
            a product with one carbon fewer.
  METHOD    1. Write the BALANCED equation:
                  R-CO-NH2 + Br2 + 4NaOH ->
                            R-NH2 + Na2CO3 + 2NaBr + 2H2O
            2. State that the product has ONE CARBON LESS.
            3. If asked for the mechanism, give the four steps:
                  N-bromoamide -> its anion -> ISOCYANATE R-N=C=O
                  -> hydrolysis to R-NH2
            4. Name the intermediate: ISOCYANATE.
  TRAP      (i) Not balancing it. The 4 NaOH and the Na2CO3 carry marks.
            (ii) Writing "isocyanide" instead of "isocyanate".
                 ISOCYANATE = R-N=C=O (Hofmann intermediate)
                 ISOCYANIDE = R-NC   (carbylamine product)
```

```
  PATTERN 9 — REDUCTION OF NITROBENZENE IN DIFFERENT MEDIA        4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Reduction of nitrobenzene in acidic / neutral / alkaline
            medium", or a reagent like "Zn dust + NH4Cl".
  METHOD    Read the MEDIUM, not the metal.
               ACID (Sn/HCl, Fe/HCl, H2/Ni)  ->  ANILINE
               NEUTRAL (Zn + NH4Cl aq)       ->  N-PHENYLHYDROXYLAMINE
               mild alkali (Na3AsO3)         ->  AZOXYBENZENE
               alkali (LiAlH4)               ->  AZOBENZENE
               strong alkali (Zn + excess NaOH) -> HYDRAZOBENZENE
               ELECTROLYTIC (conc. H2SO4)    ->  p-AMINOPHENOL
  MEMORY    "Acid gives the amine. Neutral stops at the hydroxylamine.
             Alkali joins two rings: azoxy, azo, hydrazo.
             Electricity gives p-aminophenol."
  TRAP      Zn appears in both the NEUTRAL and the ALKALINE answer. The
            metal does not decide the product - the OTHER reagent does.
            Zn + NH4Cl is neutral; Zn + NaOH is alkaline.
```

```
  PATTERN 10 — BOILING POINT OR SOLUBILITY COMPARISON             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange in increasing order of boiling point" with amines,
            or a comparison with an alcohol or an alkane.
  METHOD    WITHIN the amines: count the N-H bonds.
                  1deg (2 N-H) > 2deg (1 N-H) > 3deg (0 N-H)
            ACROSS families of similar mass:
                  ALCOHOL > AMINE > ETHER > ALKANE
            Reason in one line: nitrogen is LESS electronegative than
            oxygen, so N---H---N hydrogen bonds are WEAKER than
            O---H---O hydrogen bonds.
  TRAP      Forgetting that a TERTIARY amine cannot hydrogen bond with
            ITSELF at all (no N-H), even though it still DISSOLVES in
            water, because its lone pair can accept a hydrogen bond
            FROM water.
```

```
  PATTERN 11 — BASICITY ORDER OF ALIPHATIC AMINES            2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange in order of basic strength" with 1deg, 2deg, 3deg
            amines, or the words "gas phase" / "aqueous solution".
  METHOD    First ask: GAS PHASE or WATER?
               GAS PHASE  -> only the +I effect
                             3deg > 2deg > 1deg > NH3
               WATER      -> three effects fight:
                             (i)  +I effect        favours 3deg
                             (ii) SOLVATION        favours 1deg
                             (iii) STERIC HINDRANCE favours 1deg
                             so 2deg usually wins.
               METHYL series:  2 > 1 > 3 > NH3
               ETHYL series:   2 > 3 > 1 > NH3
  TRAP      (i) Giving the GAS PHASE order when the question says aqueous.
            (ii) Using the methyl order for ethyl amines. They are
                 DIFFERENT. "Methyl = two one three. Ethyl = two three one."
            (iii) Reading pKb backwards. SMALL pKb = STRONG base.
```

```
  PATTERN 12 — WHY IS ANILINE A WEAK BASE?                   2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Any comparison of an aromatic amine with an aliphatic amine
            or with ammonia.
  METHOD    Write BOTH arguments:
            1. DELOCALISATION: the lone pair on nitrogen is delocalised
               into the benzene ring by resonance, so it is not available
               for donation to a proton. Draw two resonance structures.
            2. STABILITY: aniline has 5 resonance structures and is well
               stabilised; the anilinium ion C6H5-NH3+ has none involving
               nitrogen, because the lone pair is used up on the proton.
               The reactant is stabilised more than the product, so
               protonation is unfavourable.
            Quote the numbers: pKb aniline 9.38 vs methylamine 3.38,
            a difference of 6 units = 10^6 times weaker.
  TRAP      Only writing "resonance" as a single word. You must say WHAT
            is delocalised (the lone pair) and WHERE it goes (into the
            ring) and WHY that matters (not available to a proton).
```

```
  PATTERN 13 — SUBSTITUENT EFFECT ON ANILINE BASICITY             4 marks
  ------------------------------------------------------------------------
  TRIGGER   Substituted anilines in a basicity list: toluidine,
            nitroaniline, chloroaniline, anisidine.
  METHOD    1. Classify each substituent:
                  RELEASING (-CH3, -OCH3, -NH2, -OH) -> MORE basic
                  WITHDRAWING (-NO2, -CN, -CHO, -X)  -> LESS basic
            2. Among isomers of the same substituent:
                  meta is the LEAST affected (inductive only)
                  para is more affected (inductive AND resonance)
                  ORTHO is ALWAYS the weakest (the ORTHO EFFECT -
                  steric twisting of the -NH2 out of plane)
            3. Final order for nitroanilines:
                  aniline > meta > para > ortho
  TRAP      Assuming ortho and para behave the same. Ortho is always
            worst, whatever the group, because of the steric ortho effect.
```

```
  PATTERN 14 — THE CARBYLAMINE TEST                               2 marks
  ------------------------------------------------------------------------
  TRIGGER   "CHCl3 + KOH", "foul smell", "test for primary amine",
            "isocyanide".
  METHOD    1. Balanced equation:
                  R-NH2 + CHCl3 + 3KOH --heat--> R-NC + 3KCl + 3H2O
            2. Observation: an extremely offensive, penetrating smell.
            3. Scope: ONLY PRIMARY amines, aliphatic AND aromatic.
               2deg and 3deg give no reaction.
  TRAP      (i) Not balancing (3 KOH, 3 KCl, 3 H2O).
            (ii) Claiming it distinguishes all three classes. It does not.
                 It only proves the amine is PRIMARY. For all three, use
                 Hinsberg.
```

```
  PATTERN 15 — THE HINSBERG TEST                                  4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between primary, secondary and tertiary amines",
            or the reagent C6H5-SO2-Cl.
  METHOD    1. Name the reagent: BENZENESULPHONYL CHLORIDE.
            2. Write the three equations.
            3. Give the three OBSERVATIONS with NaOH:
                  1deg -> ppt SOLUBLE in alkali
                  2deg -> ppt INSOLUBLE in alkali
                  3deg -> NO REACTION
            4. Give the REASON for 1deg: the leftover N-H is acidic
               because -SO2- withdraws electrons, so it forms a soluble
               salt with alkali.
            5. Draw the decision tree.
  TRAP      Writing the products but not the OBSERVATIONS. The examiner
            marks the words "soluble" and "insoluble", not the formulae.
```

```
  PATTERN 16 — REACTION WITH NITROUS ACID                         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "NaNO2 + HCl at 273-278 K", "HNO2", "nitrous acid".
  METHOD    Split into FOUR cases, never three:
               1deg ALIPHATIC -> R-OH + N2, BRISK EFFERVESCENCE
               1deg AROMATIC  -> a STABLE DIAZONIUM SALT, no gas
               2deg (either)  -> R2N-N=O, a YELLOW OILY LIQUID
               3deg aliphatic -> a soluble nitrite salt R3NH+NO2-
               3deg aromatic  -> a GREEN p-nitroso solid
  TRAP      Lumping the two primary amines together. They give completely
            different answers, and that is exactly what is being tested.
            Also: always write the temperature 273-278 K.
```

```
  PATTERN 17 — ACYLATION AND THE SCHOTTEN-BAUMANN REACTION   2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Acetyl chloride, acetic anhydride or benzoyl chloride plus
            an amine; the word "acetanilide" or "benzanilide".
  METHOD    1. Write the equation:
                  C6H5-NH2 + CH3COCl --pyridine--> C6H5-NH-COCH3 + HCl
                  C6H5-NH2 + C6H5COCl --aq.NaOH--> C6H5-NH-CO-C6H5 + HCl
            2. Name the products: ACETANILIDE and BENZANILIDE.
            3. Say WHY the base is added: to neutralise the HCl, which
               would otherwise convert the amine to its unreactive salt.
            4. Note that TERTIARY amines do NOT acylate (no N-H).
  TRAP      Forgetting that "Schotten-Baumann" specifically means
            BENZOYLATION with aqueous NaOH, not acetylation.
```

```
  PATTERN 18 — BROMINATION OR NITRATION OF ANILINE                4 marks
  ------------------------------------------------------------------------
  TRIGGER   Aniline plus Br2 or plus HNO3; "why is the -NH2 protected".
  METHOD    1. Say what happens WITHOUT protection:
                  Br2/water -> 2,4,6-tribromoaniline, WHITE ppt
                  HNO3/H2SO4 -> a mess, about 47 % META
            2. Explain the meta product: in acid, aniline becomes the
               ANILINIUM ION, which is deactivating and meta-directing.
            3. Give the three-step protected route:
                  acetylate -> substitute -> hydrolyse
            4. Explain WHY acetylation helps: the lone pair is pulled
               towards the C=O of the acetyl group, so the ring is only
               MODERATELY activated and only one substitution occurs;
               the bulky group also blocks ortho, giving the PARA product.
  TRAP      Only writing the three steps without the REASON. The reason
            is half the marks.
```

```
  PATTERN 19 — "WHY NO FRIEDEL-CRAFTS WITH ANILINE?"              2 marks
  ------------------------------------------------------------------------
  TRIGGER   Aniline + AlCl3, or "Friedel-Crafts".
  METHOD    Four short sentences:
               1. AlCl3 is a Lewis acid; aniline is a Lewis base.
               2. They combine: C6H5-NH2 + AlCl3 -> the complex
                  C6H5-NH2(+)---AlCl3(-)
               3. The nitrogen now carries a POSITIVE charge.
               4. A positive group strongly DEACTIVATES the ring, so no
                  substitution occurs.
  TRAP      Saying "aniline is too reactive". It is the opposite - once
            AlCl3 binds, the ring becomes DEACTIVATED.
```

```
  PATTERN 20 — DIAZOTISATION: EQUATION AND CONDITIONS        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Aniline + NaNO2 + HCl; the word "diazonium" or "diazotisation".
  METHOD    1. Balanced equation:
                  C6H5-NH2 + NaNO2 + 2HCl --273-278 K-->
                                    C6H5-N2+Cl- + NaCl + 2H2O
            2. All FOUR conditions:
                  - 273 to 278 K in an ice bath
                  - excess mineral acid
                  - NaNO2 added slowly with stirring
                  - use at once; the dry solid is EXPLOSIVE
            3. Why the low temperature: above 278 K it hydrolyses to
               PHENOL with loss of N2.
  TRAP      Omitting the temperature. It is the single most marked detail
            in the whole chapter.
```

```
  PATTERN 21 — WHY IS THE ARENEDIAZONIUM ION STABLE?              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is benzenediazonium chloride more stable than
            ethanediazonium chloride?"
  METHOD    1. In C6H5-N2+ the positive charge is DELOCALISED over the
               benzene ring by resonance.
            2. Spreading a charge over many atoms LOWERS the energy, so
               the ion is stabilised.
            3. An ALKYL diazonium ion has no ring to delocalise into, so
               the charge stays on one atom and the ion decomposes at
               once to R+ and N2.
            4. That is why a primary ALIPHATIC amine + HNO2 gives an
               alcohol and nitrogen gas.
  TRAP      Just saying "it is aromatic". You must say the CHARGE is
            delocalised, not the electrons of the ring.
```

```
  PATTERN 22 — SANDMEYER OR GATTERMANN?                           2 marks
  ------------------------------------------------------------------------
  TRIGGER   A diazonium salt plus a copper reagent.
  METHOD    Read the copper reagent:
               Cu2Cl2 / Cu2Br2 / CuCN  ->  SANDMEYER
               Cu POWDER + HX          ->  GATTERMANN
            Products are the same halide; only the name and yield differ.
            Sandmeyer can also give -CN; Gattermann cannot.
  MEMORY    "SANDmeyer uses a SALT. GATTERmann uses the metal."
  TRAP      Writing "Gattermann-Koch". That is a DIFFERENT reaction, from
            Chapter 13, that makes benzaldehyde from benzene with CO+HCl.
```

```
  PATTERN 23 — THE DIAZONIUM FAN: PREDICT THE PRODUCT             2 marks
  ------------------------------------------------------------------------
  TRIGGER   C6H5-N2+Cl- plus any reagent.
  METHOD    Look up the reagent in this list and write the product:
               Cu2Cl2/HCl   -> C6H5-Cl        Cu/HCl     -> C6H5-Cl
               Cu2Br2/HBr   -> C6H5-Br        Cu/HBr     -> C6H5-Br
               CuCN/KCN     -> C6H5-CN        KI, warm   -> C6H5-I
               HBF4 + heat  -> C6H5-F         H2O, 283 K -> C6H5-OH
               H3PO2        -> C6H6           NaNO2/Cu   -> C6H5-NO2
            Always add "+ N2" to the product side.
  TRAP      Forgetting the N2. It is part of the equation and carries
            marks. Also, KI needs NO copper - do not add one.
```

```
  PATTERN 24 — COUPLING REACTIONS AND AZO DYES               2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Diazonium salt plus phenol or aniline; the words "azo dye",
            "coupling", or a colour in the question.
  METHOD    1. Write the equation with the PARA product.
            2. State the pH:
                  PHENOL  -> mildly ALKALINE, pH 9-10 -> ORANGE
                  ANILINE -> mildly ACIDIC, pH 4-5   -> YELLOW
            3. Give the reason for the pH in each case:
                  alkali makes the more reactive PHENOXIDE ion;
                  strong acid would deactivate aniline as the
                  ANILINIUM ion.
            4. Add: the diazonium ion is a WEAK electrophile, so the
               other ring must be strongly ACTIVATED.
  TRAP      Swapping the two conditions or the two colours. Learn the pair
            as one block: "phenol - alkaline - orange; aniline - acidic -
            yellow."
```

```
  PATTERN 25 — THE SYNTHESIS ROUTE PROBLEM                   4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "How would you prepare X from benzene / from aniline?"
  METHOD    Work BACKWARDS from the target.
               1. Does the target have -F, -I, -CN, -OH or a plain H
                  where a group used to be?  ->  a DIAZONIUM SALT is
                  involved. Work back to aniline.
               2. Are the groups arranged META but all ortho/para
                  directors? -> -NH2 was used as a TEMPORARY director
                  and removed with H3PO2.
               3. Do you need a MONO-substituted aniline? -> acetylate,
                  substitute, hydrolyse.
               4. Then write forward, with every reagent and temperature.
  EXAMPLE   1,3,5-tribromobenzene from benzene:
               C6H6 --HNO3/H2SO4, 330 K--> C6H5-NO2
                    --Sn/HCl--> C6H5-NH2
                    --3 Br2 (aq)--> 2,4,6-tribromoaniline
                    --NaNO2/HCl, 273-278 K--> the diazonium salt
                    --H3PO2 + H2O--> 1,3,5-TRIBROMOBENZENE
  TRAP      Trying to brominate benzene three times directly. -Br is an
            ortho/para director and can never give the 1,3,5 pattern.
```

```
  PATTERN 26 — CYANIDE versus ISOCYANIDE                     2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   R-CN and R-NC in the same question, or KCN versus AgCN.
  METHOD    1. Structure: R-C(triple)N versus R-N(triple)C.
            2. Preparation: KCN (ionic) -> cyanide; AgCN (covalent) ->
               isocyanide, because in AgCN only the nitrogen lone pair
               is free.
            3. Acid hydrolysis:
                  R-CN + 2H2O -> R-COOH + NH3
                  R-NC + 2H2O -> R-NH2 + HCOOH
            4. Reduction:
                  R-CN -> R-CH2-NH2  (PRIMARY amine)
                  R-NC -> R-NH-CH3   (SECONDARY amine)
            5. Isocyanides are hydrolysed only by ACIDS, not by alkalis.
  MEMORY    "cyaNide gives an aCid; isocyaNide gives an amiNe."
  TRAP      Swapping the two hydrolysis products. Also remember that
            R-X + AgNO2 / KNO2 follows exactly the same logic, so learn
            the four lines together.
```

```
  PATTERN 27 — DISTINGUISH THE GIVEN PAIR                         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How will you distinguish between A and B?"
  METHOD    Pick a test where ONE reacts and the OTHER does not, and
            state the OBSERVATION, not just the product.
               1deg vs 2deg vs 3deg amine  ->  HINSBERG
               1deg amine vs anything else ->  CARBYLAMINE (foul smell)
               1deg aliphatic vs 1deg aromatic amine -> HNO2:
                     gas evolved vs stable diazonium salt
               2deg amine vs 3deg amine    ->  HNO2: yellow oil vs nothing
               aniline vs phenol           ->  aniline dissolves in
                     dil. HCl; phenol gives a VIOLET colour with FeCl3
               amine vs alcohol            ->  amine turns red litmus BLUE
               cyanide vs isocyanide       ->  smell, or hydrolysis
                     products (acid vs amine)
  TRAP      Giving a test that BOTH compounds answer. Always check the
            negative case as well as the positive one.
```

```
  PATTERN 28 — COMPLETE THE REACTION / IDENTIFY A, B, C           4 marks
  ------------------------------------------------------------------------
  TRIGGER   A chain of arrows with letters over them.
  METHOD    1. Work through ONE arrow at a time. Do not skip ahead.
            2. At each arrow write the reagent's meaning from the
               reaction sheet.
            3. Track the CARBON COUNT at every step.
            4. Track whether nitrogen is being ADDED, KEPT or LOST.
  EXAMPLE   C6H5-NO2 --Sn/HCl--> A --NaNO2/HCl, 273 K--> B --CuCN--> C
                                                             --H3O+--> D
               A = aniline          B = benzenediazonium chloride
               C = benzonitrile     D = benzoic acid
  TRAP      Writing the free amine when the reaction actually gives the
            salt, or forgetting the hydrolysis step at the end.
```

```
  PATTERN 29 — NITRO COMPOUND NOMENCLATURE AND STRUCTURE          2 marks
  ------------------------------------------------------------------------
  TRIGGER   CH3-NO2 versus CH3-O-N=O; "why are both N-O bonds equal".
  METHOD    1. NITRO: the CARBON is joined to NITROGEN, C-NO2.
               NITRITE: the CARBON is joined to OXYGEN, C-O-N=O.
               They are FUNCTIONAL ISOMERS.
            2. Both N-O bonds are equal because of RESONANCE; draw the
               two structures with + on N and - on one O.
            3. Nitrogen is sp2 hybridised and carries a formal + charge.
            4. -NO2 is strongly electron withdrawing, so it deactivates
               a ring and directs META.
  TRAP      Drawing nitrogen with FIVE bonds. Nitrogen has only four
            orbitals and can never form five bonds. Use the + and - charges.
```

```
  PATTERN 30 — THE "GIVE REASONS" ONE-LINER                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Give reasons:" followed by a statement.
  METHOD    Answer in ONE clean sentence that names the EFFECT.
            The stock answers:
               aniline is a weak base       -> lone pair delocalised into
                                               the ring
               aniline dissolves in HCl     -> forms the ionic salt
                                               anilinium chloride
               3deg amines do not acylate   -> no hydrogen on nitrogen
               amines boil below alcohols   -> N is less electronegative
                                               than O, weaker H bonds
               diazotisation needs 273-278 K-> above 278 K it hydrolyses
                                               to phenol
               Gabriel fails for aniline    -> aryl halides do not undergo
                                               nucleophilic substitution
               Fe/HCl is preferred          -> FeCl2 hydrolyses and
                                               regenerates HCl; iron is
                                               cheap
               aniline turns brown in air   -> it is slowly oxidised
  TRAP      Writing three vague sentences instead of one precise one. The
            examiner is looking for a NAMED effect: resonance, inductive
            effect, solvation, steric hindrance, hydrogen bonding.
```

# SELF-TEST — can you name the pattern in 5 seconds?

Cover the right-hand column. Read the stem. Say the pattern number out loud.

| QUESTION STEM | PATTERN |
