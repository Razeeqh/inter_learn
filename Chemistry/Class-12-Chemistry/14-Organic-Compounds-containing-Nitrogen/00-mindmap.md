## THE 60-SECOND VERSION

Nitrogen has **five outer electrons**. Three of them make bonds. The other two
sit together as a **LONE PAIR**. That lone pair explains the entire chapter.

```
   THE LONE PAIR CAN DO THREE THINGS:

   1.  Grab a proton          ->  the amine is a BASE
   2.  Attack a carbon        ->  the amine is a NUCLEOPHILE
                                  (alkylation, acylation)
   3.  Get delocalised        ->  the amine becomes a WEAK base
       into a ring or into        (aniline, amides, nitro group)
       a C=O group

   EVERY comparison question in this chapter is really asking:
        "IS THE LONE PAIR FREE, OR IS IT BUSY?"

        FREE lone pair   ->  strong base, activating group
        BUSY lone pair   ->  weak base, deactivated
```

**The one line that runs through the whole chapter:**

```
   BASIC STRENGTH:

     (C2H5)2NH  >  (C2H5)3N  >  C2H5NH2  >  NH3  >  C6H5NH2  >  (C6H5)2NH

     aliphatic amines            ammonia      aromatic amines
     (lone pair free)            (reference)  (lone pair in the ring)


   NITROGEN OXIDATION LADDER (going left = adding hydrogen):

     R-NO2   -->   R-NH-OH   -->   R-NH2
     nitro         hydroxylamine   amine

     R-CN    -->   R-CH2-NH2       (adds a carbon to the chain)
     R-CONH2 -->   R-CH2-NH2       (same carbons)
     R-CONH2 -->   R-NH2           (Hofmann: LOSES a carbon)
```

Learn the carbon bookkeeping in that last box. Three questions a year come
from "does the product have more, fewer or the same number of carbons?"

## THE CARBON-COUNTING RULE (this one idea decides 3 questions)

```
   When you convert one compound into an amine, does the carbon
   chain get LONGER, SHORTER, or stay the SAME?

   +--------------------------------+----------------+---------------+
   |  METHOD                        |  CARBON COUNT  |  EXAMPLE      |
   +--------------------------------+----------------+---------------+
   |  R-NO2  --Sn/HCl-->  R-NH2     |  SAME          | C2H5NO2 (2C)  |
   |                                |                | -> C2H5NH2(2C)|
   |  R-X + NH3 -> R-NH2            |  SAME          | 2C -> 2C      |
   |  R-CONH2 --LiAlH4--> R-CH2NH2  |  SAME          | CH3CONH2 (2C) |
   |                                |                | -> C2H5NH2(2C)|
   |  R-X + KCN -> R-CN --[H]-->    |  ONE MORE      | CH3Br (1C)    |
   |     R-CH2-NH2                  |  (STEP UP)     | -> C2H5NH2(2C)|
   |  R-CONH2 + Br2 + 4NaOH         |  ONE LESS      | CH3CONH2 (2C) |
   |     -> R-NH2  (HOFMANN)        |  (STEP DOWN)   | -> CH3NH2 (1C)|
   +--------------------------------+----------------+---------------+

   MEMORY HOOK:
        HOFMANN  ->  "H for  HALVED / one carbon gone"
        NITRILE  ->  "N for  NEW carbon added"
```
