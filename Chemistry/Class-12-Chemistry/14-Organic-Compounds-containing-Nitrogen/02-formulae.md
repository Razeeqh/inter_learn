# Organic Compounds containing Nitrogen — Reactions and Name-Reactions Sheet

In physics and physical chemistry you learn formulae.
In organic chemistry you learn **REACTIONS**. This is that sheet.

Copy it by hand into a notebook. Writing it once beats reading it ten times.

---

# 0. HOW TO READ THIS SHEET

```
   Every reaction is written in the same shape:

        STARTING COMPOUND   --REAGENT , CONDITION-->   PRODUCT

   The examiner gives you TWO of the three and asks for the third.
   So you must be able to read the line in ALL THREE directions:

        given compound + reagent   ->  what is the product?
        given compound + product   ->  what is the reagent?
        given reagent + product    ->  what did we start from?

   AND FOR THIS CHAPTER, one extra question every single time:

        DID THE CARBON COUNT CHANGE?
             one MORE  ->  you went through a nitrile (R-CN)
             one LESS  ->  you went through HOFMANN bromamide
             the SAME  ->  everything else
```

# 3. THE SIX ROUTES

| # | STARTING MATERIAL | REAGENT / CONDITION | PRODUCT | CARBONS |
|---|---|---|---|---|
| 1 | R-NO2 | Sn/HCl, Fe/HCl, or H2/Ni | R-NH2 (1deg only) | SAME |
| 2 | R-X | NH3 (large excess), heat | R-NH2 + R2NH + R3N + R4N+X- | SAME |
| 3 | R-CN | H2/Ni, LiAlH4, or Na/C2H5OH | R-CH2-NH2 (1deg) | **ONE MORE** |
| 4 | R-CO-NH2 | LiAlH4, then H2O | R-CH2-NH2 (1deg) | SAME |
| 5 | R-X | potassium phthalimide, then NaOH/H3O+ | R-NH2 (1deg, PURE) | SAME |
| 6 | R-CO-NH2 | Br2 + 4 NaOH | R-NH2 (1deg, PURE) | **ONE LESS** |

## 3.1 The equations, written out

```
   1.  REDUCTION OF NITRO COMPOUND
       C6H5-NO2  +  6[H]   --Sn / conc. HCl-->   C6H5-NH2  +  2 H2O
       CH3-NO2   +  6[H]   --H2 / Ni-->         CH3-NH2   +  2 H2O

   2.  AMMONOLYSIS OF ALKYL HALIDE
       CH3-Br + NH3      ->  CH3-NH3+Br-   --NaOH-->  CH3-NH2      1deg
       CH3-NH2 + CH3-Br  ->  (CH3)2NH2+Br- --NaOH-->  (CH3)2NH     2deg
       (CH3)2NH + CH3-Br ->  (CH3)3NH+Br-  --NaOH-->  (CH3)3N      3deg
       (CH3)3N + CH3-Br  ->  (CH3)4N+ Br-                     quaternary

       Excess NH3      ->  mainly the PRIMARY amine
       Excess R-X      ->  mainly the QUATERNARY salt
       Halide order    ->  R-I > R-Br > R-Cl
       DOES NOT WORK on aryl halides (C-Cl too strong).

   3.  REDUCTION OF A NITRILE  (chain gets LONGER)
       CH3-CN  +  4[H]  --H2/Ni or LiAlH4 or Na/C2H5OH-->  CH3-CH2-NH2
       (Na + alcohol is the MENDIUS reduction.)

       Two-step chain lengthening:
       R-X  --KCN(alc.)-->  R-CN  --H2/Ni-->  R-CH2-NH2

   4.  REDUCTION OF AN AMIDE  (chain UNCHANGED)
       CH3-CO-NH2  --(i) LiAlH4  (ii) H2O-->  CH3-CH2-NH2

   5.  GABRIEL PHTHALIMIDE SYNTHESIS  (PURE 1deg, chain UNCHANGED)
       phthalimide  --KOH-->  potassium phthalimide
       potassium phthalimide + R-X  -->  N-alkylphthalimide + KX
       N-alkylphthalimide --(i) aq. NaOH boil (ii) H3O+-->
                                        R-NH2 + phthalic acid
       *** FAILS for AROMATIC primary amines, because aryl halides do
           not undergo nucleophilic substitution. ***

   6.  HOFMANN BROMAMIDE DEGRADATION  (PURE 1deg, chain ONE SHORTER)
       R-CO-NH2 + Br2 + 4 NaOH  ->  R-NH2 + Na2CO3 + 2 NaBr + 2 H2O

       CH3-CO-NH2 + Br2 + 4NaOH  ->  CH3-NH2 + Na2CO3 + 2NaBr + 2H2O
       C6H5-CO-NH2 + Br2 + 4NaOH ->  C6H5-NH2 + Na2CO3 + 2NaBr + 2H2O

       Intermediate to name if asked:  R-N=C=O  (an ISOCYANATE)
```

# 5. ACYLATION — the equations

```
   ACETYLATION with acetyl chloride:
   C6H5-NH2  +  CH3-CO-Cl   --pyridine-->   C6H5-NH-CO-CH3  +  HCl
                                            ACETANILIDE

   ACETYLATION with acetic anhydride:
   C6H5-NH2  +  (CH3CO)2O   -->   C6H5-NH-CO-CH3  +  CH3-COOH

   BENZOYLATION (SCHOTTEN-BAUMANN):
   C6H5-NH2  +  C6H5-CO-Cl  --aq. NaOH-->  C6H5-NH-CO-C6H5  +  HCl
                                           BENZANILIDE (white solid)

   CH3-NH2  +  C6H5-CO-Cl   --aq. NaOH-->  C6H5-CO-NH-CH3  +  HCl
                                           N-methylbenzamide

   WHY ADD PYRIDINE / NaOH ?
        to neutralise the HCl produced, which would otherwise convert
        the amine into its unreactive salt and stop the reaction.

   3deg AMINES DO NOT ACYLATE. There is no H on nitrogen to replace.
```

## 6.1 The equations for the tests

```
   CARBYLAMINE (isocyanide) TEST — primary amines only
   R-NH2  +  CHCl3  +  3 KOH  --heat-->  R-NC  +  3 KCl  +  3 H2O
   C6H5-NH2 + CHCl3 + 3 KOH   --heat-->  C6H5-NC + 3 KCl + 3 H2O


   HINSBERG TEST
   1deg:  C6H5-SO2-Cl + H2N-R   ->  C6H5-SO2-NH-R + HCl
          C6H5-SO2-NH-R + KOH   ->  C6H5-SO2-N(K)-R + H2O   SOLUBLE
   2deg:  C6H5-SO2-Cl + HN-R2   ->  C6H5-SO2-NR2 + HCl      INSOLUBLE
   3deg:  C6H5-SO2-Cl + R3N     ->  NO REACTION


   WITH NITROUS ACID  (NaNO2 + HCl, 273-278 K)
   1deg aliphatic: C2H5-NH2 + HNO2 -> C2H5-OH + N2(gas) + H2O
   1deg aromatic : C6H5-NH2 + NaNO2 + 2HCl -> C6H5-N2+Cl- + NaCl + 2H2O
   2deg          : (CH3)2NH + HNO2 -> (CH3)2N-N=O + H2O   yellow oil
   3deg aliphatic: (CH3)3N + HNO2  -> (CH3)3NH+ NO2-      soluble salt
   3deg aromatic : C6H5N(CH3)2 + HNO2 -> p-nitroso-N,N-dimethylaniline
                                          (GREEN solid)
```

# 7. ELECTROPHILIC SUBSTITUTION IN ANILINE

| REACTION | REAGENT / CONDITION | PRODUCT |
|---|---|---|
| Bromination (uncontrolled) | Br2 in **water**, room temp | **2,4,6-tribromoaniline**, WHITE ppt |
| Bromination (controlled) | (i) (CH3CO)2O (ii) Br2/CH3COOH (iii) hydrolysis | **p-bromoaniline** |
| Nitration (direct) | conc. HNO3 + conc. H2SO4 | mixture: o 2 %, **m 47 %**, p 51 % |
| Nitration (controlled) | (i) (CH3CO)2O (ii) HNO3/H2SO4, 288 K (iii) hydrolysis | **p-nitroaniline** |
| Sulphonation | conc. H2SO4, then 453-473 K | **sulphanilic acid** (a ZWITTERION) |
| Friedel-Crafts | CH3Cl / anhyd. AlCl3 | **NO REACTION** |
| Oxidation (air) | O2, standing | turns brown |
| With bleaching powder / K2Cr2O7 | oxidation | black dye (aniline black) |

```
   THE PROTECTION SEQUENCE — write it as three arrows:

   C6H5-NH2  --(CH3CO)2O-->  C6H5-NH-CO-CH3  --Br2 / CH3COOH-->
                             ACETANILIDE
             p-Br-C6H4-NH-CO-CH3  --H3O+ , hydrolysis-->  p-Br-C6H4-NH2

   WHY:  the acetyl group pulls the nitrogen lone pair towards its own
         C=O, so LESS electron density reaches the ring. The ring is
         only MODERATELY activated, so only ONE substitution happens.
         The bulky group also blocks the ortho positions -> PARA major.

   WHY NO FRIEDEL-CRAFTS:
         aniline (Lewis base) + AlCl3 (Lewis acid) -> salt in which
         N is POSITIVE -> ring strongly DEACTIVATED -> no reaction.

   WHY SO MUCH META ON DIRECT NITRATION:
         in the strongly acidic medium aniline is protonated to the
         ANILINIUM ION C6H5-NH3+ , which is deactivating and
         META-DIRECTING.
```

# 8. PREPARATION

```
   C6H5-NH2 + NaNO2 + 2 HCl  --273-278 K-->  C6H5-N2+Cl- + NaCl + 2 H2O

   CONDITIONS  (all four are marks):
     1.  273 - 278 K  (ice bath). Above this it hydrolyses to phenol.
     2.  Excess mineral acid (HCl or H2SO4).
     3.  NaNO2 added slowly with stirring.
     4.  Use the solution AT ONCE. Dry solid salts are EXPLOSIVE.

   STABILITY:  the positive charge is delocalised over the benzene ring
               by resonance, so the ARENEdiazonium ion survives at 0-5 C.
               An ALKYL diazonium ion has no ring to spread the charge
               into, so it decomposes instantly to R+ + N2.
```

# 10. COUPLING REACTIONS (nitrogen STAYS)

| COUPLES WITH | CONDITION | PRODUCT | COLOUR |
|---|---|---|---|
| **phenol** C6H5-OH | mildly **ALKALINE**, NaOH, pH 9-10, 273-278 K | p-hydroxyazobenzene | **ORANGE** |
| **aniline** C6H5-NH2 | mildly **ACIDIC**, pH 4-5, 273-278 K | p-aminoazobenzene | **YELLOW** |

```
   C6H5-N2+Cl-  +  C6H5-OH   --NaOH, pH 9-10-->
                             C6H5-N=N-C6H4-OH  (para)  ORANGE dye

   C6H5-N2+Cl-  +  C6H5-NH2  --pH 4-5-->
                             C6H5-N=N-C6H4-NH2 (para)  YELLOW dye

   RULES OF COUPLING:
     1.  Always at the PARA position (ORTHO if para is blocked).
     2.  The other ring must be STRONGLY ACTIVATED (-OH, -NH2, -NR2).
         Benzene and nitrobenzene do NOT couple - the diazonium ion is
         only a WEAK electrophile.
     3.  -N=N- is the AZO group. The long conjugation makes the
         product COLOURED, which is why these are DYES.
```

# 13. THE ORDERS AND COMPARISONS
# ===============================================================

