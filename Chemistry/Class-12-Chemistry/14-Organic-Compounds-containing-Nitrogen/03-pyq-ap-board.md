## Topic: Nitro compounds

### Q A1
Write the structures of nitromethane and methyl nitrite. How do they differ?

**ANSWER:**
```
  NITROMETHANE        CH3-NO2         the CARBON is joined to NITROGEN

                          O
                         //
                CH3 -- N (+)
                         \
                          O (-)

  METHYL NITRITE      CH3-O-N=O       the CARBON is joined to OXYGEN

  They have the SAME molecular formula CH3NO2 but different linkage,
  so they are FUNCTIONAL ISOMERS. Nitromethane boils at 374 K and
  methyl nitrite at 285 K.
```

---

### Q A2
Why are both the N-O bonds in a nitro group of equal length?

**ANSWER:**
```
  Because of RESONANCE.

            O                        O (-)
           //                       /
    R -- N (+)     <-------->  R -- N (+)
           \                        \\
            O (-)                    O

  The real molecule is a resonance hybrid of these two structures,
  so each N-O bond is identical - halfway between a single and a
  double bond. The nitrogen is sp2 hybridised.
```

### Q A3
What product is formed when nitrobenzene is reduced in a **neutral** medium?
Give the reagent.

**ANSWER:**
```
  REAGENT:   Zn dust  +  NH4Cl solution  (neutral medium)

  C6H5-NO2  --Zn dust / NH4Cl (aq)-->  C6H5-NH-OH

  PRODUCT:   N-PHENYLHYDROXYLAMINE

  (In ACIDIC medium, Sn/HCl, you would get ANILINE instead.)
```

### Q A4
Why is Fe/HCl preferred to Sn/HCl for the industrial reduction of nitrobenzene?

**ANSWER:**
```
  1.  The FeCl2 formed is hydrolysed by water and REGENERATES the HCl,
      so only a small amount of HCl is needed.

  2.  Iron is much cheaper than tin.

  Hence the process is far more economical on a large scale.
```

## Topic: Classification and nomenclature of amines

### Q A5
Classify the following as primary, secondary or tertiary amines:
`(CH3)3C-NH2` , `(CH3)3N` , `C6H5-NH-CH3` , `C6H5-CH2-NH2`.

**ANSWER:**
```
  RULE: count how many CARBON groups are attached to the NITROGEN.

  (CH3)3C-NH2     1 carbon on N   ->  PRIMARY
                  (the "tert" refers to the carbon, NOT the nitrogen)
  (CH3)3N         3 carbons on N  ->  TERTIARY
  C6H5-NH-CH3     2 carbons on N  ->  SECONDARY
  C6H5-CH2-NH2    1 carbon on N   ->  PRIMARY (and it is ALIPHATIC,
                                      because N is joined to CH2,
                                      not to the ring)
```

### Q A7
What is the shape of the amino group in an amine? Give the bond angle in
trimethylamine and explain it.

**ANSWER:**
```
  The nitrogen is sp3 hybridised with FOUR sp3 orbitals.
  Three hold bonds; the fourth holds the LONE PAIR.
  Since one corner has no atom in it, the shape is PYRAMIDAL
  (trigonal pyramidal).

  C-N-C bond angle in (CH3)3N  =  about 108 degrees.

  It is LESS than the ideal tetrahedral 109.5 degrees because the
  LONE PAIR repels the bond pairs more strongly than a bond pair does,
  squeezing the three bonds slightly closer together.
```

## Topic: Preparation of amines

### Q A8
What is the Gabriel phthalimide synthesis? Why does it fail for aromatic
primary amines?

**ANSWER:**
```
  phthalimide --KOH--> potassium phthalimide
  potassium phthalimide + R-X  -->  N-alkylphthalimide + KX
  N-alkylphthalimide --(i) aq. NaOH, boil (ii) H3O+-->
                                   R-NH2  +  phthalic acid

  It gives a PURE PRIMARY amine, with no secondary or tertiary amine
  mixed in.

  IT FAILS FOR AROMATIC AMINES because the second step needs a
  NUCLEOPHILIC SUBSTITUTION on the halide. Aryl halides such as
  C6H5-Cl do not undergo nucleophilic substitution easily: the C-Cl
  bond has partial double-bond character due to resonance with the
  ring, so it is short, strong and will not break.
```

### Q A9
Write the equation for the Hofmann bromamide degradation of acetamide.
What is special about the product?

**ANSWER:**
```
  CH3-CO-NH2  +  Br2  +  4 NaOH  -->
                       CH3-NH2  +  Na2CO3  +  2 NaBr  +  2 H2O
  acetamide (2 C)      methanamine (1 C)

  SPECIAL POINT: the amine formed has ONE CARBON LESS than the amide.
  The lost carbon leaves as the carbonate.
  The reaction gives a PURE PRIMARY amine.
```

### Q A10
Why does ammonolysis of an alkyl halide give a mixture of products?
How can the primary amine be made the main product?

**ANSWER:**
```
  CH3-Br + NH3 -> CH3-NH2 -> (CH3)2NH -> (CH3)3N -> (CH3)4N+Br-

  The amine formed in the first step is ITSELF a nucleophile, and in
  fact a BETTER nucleophile than ammonia because the alkyl group pushes
  electrons onto nitrogen. So it attacks more alkyl halide and the
  reaction runs on to the 2deg, 3deg and quaternary stages.

  TO GET MAINLY THE PRIMARY AMINE: use a LARGE EXCESS OF AMMONIA,
  so a halide molecule is far more likely to meet an NH3 than an amine.
```

### Q A11
How is ethanamine prepared from methyl bromide? Name the type of reaction.

**ANSWER:**
```
  We need to go from ONE carbon to TWO carbons, so we must ADD a carbon.
  The nitrile route does that.

  CH3-Br  --KCN (alcoholic)-->  CH3-CN  --H2 / Ni-->  CH3-CH2-NH2
  (1 C)                         (2 C)                 (2 C)

  STEP 1 is a nucleophilic substitution.
  STEP 2 is a REDUCTION of a nitrile (Na/C2H5OH would also work -
  that version is called the MENDIUS reduction).
```

## Topic: Properties and basicity

### Q A12
Why are amines less soluble in water than alcohols of comparable molar mass?

**ANSWER:**
```
  Both form hydrogen bonds with water, but nitrogen is LESS
  ELECTRONEGATIVE than oxygen. So the N---H---O hydrogen bond formed by
  an amine is WEAKER than the O---H---O hydrogen bond formed by an
  alcohol.

  Weaker hydrogen bonding with water  ->  lower solubility.
  (The same reason makes amines boil lower than alcohols.)
```

---

### Q A13
Arrange in increasing order of boiling point: `(C2H5)3N`, `C2H5-NH2`,
`(C2H5)2NH`. Give the reason.

**ANSWER:**
```
  Count the N-H bonds available for hydrogen bonding:

     C2H5-NH2      2 N-H   ->  most hydrogen bonding
     (C2H5)2NH     1 N-H   ->  some
     (C2H5)3N      0 N-H   ->  NONE

  INCREASING boiling point:

     (C2H5)3N   <   (C2H5)2NH   <   C2H5-NH2
     3deg           2deg            1deg

  A tertiary amine has no hydrogen on nitrogen, so it cannot hydrogen
  bond with itself at all, and boils lowest.
```

### Q A14
Why is aniline insoluble in water but soluble in dilute HCl?

**ANSWER:**
```
  Aniline has a large hydrophobic benzene ring, and its hydrogen
  bonding with water is weak, so it is almost insoluble in water.

  With dilute HCl it reacts as a BASE:

     C6H5-NH2  +  HCl   -->   C6H5-NH3+ Cl-
                              anilinium chloride

  The product is an IONIC SALT, and ionic salts dissolve readily
  in water. Hence aniline dissolves in dilute HCl.
```

### Q A15
Why is aniline a weaker base than methylamine?

**ANSWER:**
```
  In ANILINE the lone pair on nitrogen is DELOCALISED into the benzene
  ring by resonance, so it is not fully available for donation to a
  proton.

  Also, aniline itself has FIVE resonance structures and is well
  stabilised, whereas the anilinium ion C6H5-NH3+ has no such
  delocalisation (the lone pair is used up on the proton). The
  reactant is stabilised more than the product, so protonation is
  unfavourable.

  In METHYLAMINE the -CH3 group PUSHES electrons (+I effect) onto the
  nitrogen, making the lone pair even more available.

     pKb  aniline = 9.38 ,  methylamine = 3.38
     -> aniline is about a MILLION times weaker.
```

### Q A16
Give the order of basic strength of methylamines in the **gas phase** and
explain in one line why it differs from the order in water.

**ANSWER:**
```
  GAS PHASE:   (CH3)3N  >  (CH3)2NH  >  CH3NH2  >  NH3
               3deg     >  2deg      >  1deg    >  ammonia

  In the gas phase there is NO SOLVENT, so only the INDUCTIVE (+I)
  effect operates, and basicity rises steadily with the number of
  alkyl groups.

  IN WATER two more effects appear - SOLVATION of the ammonium ion
  (which favours 1deg) and STERIC HINDRANCE (which harms 3deg) -
  so the order becomes irregular:
       (CH3)2NH > CH3NH2 > (CH3)3N > NH3
```

## Topic: Reactions and tests

### Q A17
What is the carbylamine reaction? Write the equation and state its use.

**ANSWER:**
```
  R-NH2  +  CHCl3  +  3 KOH   --heat-->   R-NC  +  3 KCl  +  3 H2O

  With aniline:
  C6H5-NH2 + CHCl3 + 3KOH --heat--> C6H5-NC + 3KCl + 3H2O

  The alkyl (or aryl) ISOCYANIDE formed has an extremely offensive,
  penetrating smell.

  USE: it is a TEST FOR PRIMARY AMINES. Secondary and tertiary amines
  give no reaction, so the foul smell proves the amine is primary.
```

### Q A18
What is the Hinsberg reagent? What does a primary amine give with it?

**ANSWER:**
```
  HINSBERG REAGENT  =  BENZENESULPHONYL CHLORIDE  C6H5-SO2-Cl

  With a PRIMARY amine:

     C6H5-SO2-Cl  +  H2N-R   -->   C6H5-SO2-NH-R  +  HCl
                                   N-alkylbenzenesulphonamide

  The remaining N-H is acidic (the SO2 group withdraws electrons
  strongly), so the product DISSOLVES in NaOH or KOH by forming a
  soluble salt.

  OBSERVATION: a precipitate that DISSOLVES in alkali.
```

### Q A19
What happens when ethylamine is treated with nitrous acid?

**ANSWER:**
```
  C2H5-NH2  +  HNO2   -->   C2H5-OH  +  N2 (gas)  +  H2O
                            ethanol

  (HNO2 is made in the flask from NaNO2 + dil. HCl at 273-278 K.)

  The intermediate ethanediazonium ion is unstable and breaks up at
  once, so you see BRISK EFFERVESCENCE of nitrogen gas.
  This is the test for a PRIMARY ALIPHATIC amine.
```

### Q A20
What happens when a secondary amine reacts with nitrous acid? Name the test.

**ANSWER:**
```
  (CH3)2NH  +  HNO2   -->   (CH3)2N-N=O  +  H2O
                            N-nitrosodimethylamine

  OBSERVATION: a YELLOW OILY LIQUID separates out.

  If this oil is warmed with phenol and conc. H2SO4 and then made

  That is LIEBERMANN'S NITROSO TEST, the test for a SECONDARY amine.
```

### Q A21
What is the Schotten-Baumann reaction? Give the equation with aniline.

**ANSWER:**
```
  It is the BENZOYLATION of an amine (or a phenol) using benzoyl
  chloride in the presence of aqueous NaOH.

  C6H5-NH2  +  C6H5-CO-Cl   --aq. NaOH-->   C6H5-NH-CO-C6H5  +  HCl
  aniline      benzoyl chloride             BENZANILIDE (white solid)

  The NaOH is there to neutralise the HCl formed, which would
  otherwise convert the amine into its unreactive salt.
```

### Q A22
Why does aniline not undergo the Friedel-Crafts reaction?

**ANSWER:**
```
  Friedel-Crafts needs the Lewis acid anhydrous AlCl3.
  Aniline has a lone pair on nitrogen, so it is a LEWIS BASE.

     C6H5-NH2  +  AlCl3   -->   C6H5-NH2(+)---AlCl3(-)
                                an acid-base complex

  The nitrogen now carries a POSITIVE charge. A positively charged
  group strongly DEACTIVATES the ring by pulling electrons out of it,
  so the ring will not react with the weak electrophile.

  Hence no alkylation or acylation of the ring takes place.
```

### Q A23
Why is aniline acetylated before nitration?

**ANSWER:**
```
  Direct nitration is done in a strongly acidic mixture, in which
  aniline is protonated to the ANILINIUM ION C6H5-NH3+ . That ion is
  DEACTIVATING and META-DIRECTING, so you get a bad mixture
  (about 47 % meta).

  Acetylation converts aniline to ACETANILIDE C6H5-NH-CO-CH3.
  The nitrogen lone pair is now pulled towards the C=O of the acetyl
  group, so the ring is only MODERATELY activated and the bulky group
  blocks the ortho positions.

  Result: nitration gives mainly p-nitroacetanilide, which is
  hydrolysed back to p-NITROANILINE.
```

### Q A24
What happens when aniline is treated with bromine water?

**ANSWER:**
```
  C6H5-NH2  +  3 Br2 (aqueous)  -->  2,4,6-tribromoaniline  +  3 HBr

                    NH2
                     |
            Br --- ( ( ) ) --- Br
                     |
                     Br

  The -NH2 group is so strongly activating and o/p directing that all
  three available positions are substituted at once. This white
  precipitate is used as a TEST for aniline.
```

## Topic: Diazonium salts

### Q A25
What is diazotisation? Write the equation and the conditions.

**ANSWER:**
```
  Diazotisation is the conversion of a primary AROMATIC amine into a
  diazonium salt using nitrous acid at low temperature.

  C6H5-NH2 + NaNO2 + 2 HCl  --273-278 K-->  C6H5-N2+Cl- + NaCl + 2 H2O
                                            benzenediazonium chloride

  CONDITIONS:
    - temperature 273 - 278 K (0 - 5 C), an ice bath
    - excess mineral acid (HCl)
    - NaNO2 added slowly with stirring
    - the solution is used IMMEDIATELY; the dry solid is explosive
```

---

### Q A26
Why must diazotisation be carried out at 273-278 K?

**ANSWER:**
```
  Above about 278 K the diazonium salt is hydrolysed:

     C6H5-N2+Cl-  +  H2O   -->   C6H5-OH  +  N2  +  HCl

  You would get PHENOL instead of the diazonium salt, and the nitrogen
  would be lost as gas.

  Also, HNO2 itself is unstable and decomposes if it is not kept cold.
```

---

### Q A27
Why is benzenediazonium chloride more stable than ethanediazonium chloride?

**ANSWER:**
```
  In C6H5-N2+ the POSITIVE CHARGE IS DELOCALISED over the benzene ring
  by resonance - it is shared between the nitrogen and the ortho and
  para carbons. Spreading the charge out lowers the energy, so the ion
  is stable at 273-278 K.

  In C2H5-N2+ there is no ring to delocalise into. The charge stays on
  one atom, the ion is high in energy and it decomposes instantly:

     C2H5-N2+  ->  C2H5+ + N2  ->  C2H5-OH

  That is why a primary ALIPHATIC amine gives an alcohol and nitrogen
  gas, while a primary AROMATIC amine gives an isolable salt.
```

### Q A28
What is the Sandmeyer reaction? Write any two equations.

**ANSWER:**
```
  Replacement of the diazonium group by a halogen or by -CN using a
  CUPROUS SALT (Cu2X2) in the corresponding halogen acid.

     C6H5-N2+Cl-   --Cu2Cl2 / HCl-->   C6H5-Cl   +   N2
     C6H5-N2+Cl-   --Cu2Br2 / HBr-->   C6H5-Br   +   N2
     C6H5-N2+Cl-   --CuCN / KCN-->     C6H5-CN   +   N2

  (Any two of the three earn the marks.)
```

### Q A29
How does the Gattermann reaction differ from the Sandmeyer reaction?

**ANSWER:**
```
  +---------------+-----------------------+---------------------------+
  |               |  SANDMEYER            |  GATTERMANN               |
  +---------------+-----------------------+---------------------------+
  |  Reagent      |  Cu2X2 (cuprous salt) |  Cu POWDER + HX           |
  |               |  + HX                 |                           |
  |  Groups given |  -Cl, -Br AND -CN     |  -Cl and -Br only         |

     C6H5-N2+Cl- --Cu / HCl-->   C6H5-Cl + N2     GATTERMANN

### Q A31
How is benzene obtained from benzenediazonium chloride? Why is this
reaction useful?

**ANSWER:**
```
  C6H5-N2+Cl-  +  H3PO2  +  H2O   -->   C6H6  +  N2  +  H3PO3  +  HCl

Write the equation for the coupling of benzenediazonium chloride with

**ANSWER:**
```

With aniline, under what condition does benzenediazonium chloride couple,

## Topic: Cyanides and isocyanides

### Q A34
Why does R-X give a cyanide with KCN but an isocyanide with AgCN?

**ANSWER:**
```
  CN- is an AMBIDENT nucleophile - it can attack through carbon or
  through nitrogen.

  KCN is IONIC. The free CN- ion attacks through CARBON, because the
  C-C bond formed is stronger than a C-N bond.
        R-X + KCN  ->  R-CN     (alkyl cyanide)

  AgCN is COVALENT. The carbon is tied up with the silver, so only the
  NITROGEN lone pair is free to attack.
        R-X + AgCN ->  R-NC     (alkyl isocyanide)
```

### Q A35
Give the acid hydrolysis products of methyl cyanide and of methyl isocyanide.

**ANSWER:**
```
  CH3-C(triple)N  +  2 H2O   --H+-->   CH3-COOH   +   NH3
  methyl cyanide                       acetic acid   ammonia

  CH3-N(triple)C  +  2 H2O   --H+-->   CH3-NH2    +   HCOOH
  methyl isocyanide                    methylamine   formic acid

  MEMORY: "cyaNide gives an aCid; isocyaNide gives an amiNe."
  Note also that isocyanides are hydrolysed only by ACIDS, not alkalis.
```

### Q A36
What amines are obtained on reducing CH3-CN and CH3-NC?

**ANSWER:**
```

  CH3-NC  +  4[H]   --Na / C2H5OH-->   CH3-NH-CH3

  after reduction the nitrogen ends up carrying TWO carbon groups.
```

### Q B1
**Describe the Hinsberg test. How does it distinguish primary, secondary and
tertiary amines? Give the observations.**

**ANSWER:**
```
  REAGENT: benzenesulphonyl chloride, C6H5-SO2-Cl (Hinsberg's reagent),
           followed by aqueous NaOH or KOH.

  1. PRIMARY AMINE
     C6H5-SO2-Cl  +  H2N-R   ->   C6H5-SO2-NH-R  +  HCl
                                  N-alkylbenzenesulphonamide

     The N-H left over is ACIDIC, because the -SO2- group withdraws
     electrons strongly. So alkali removes it:

     C6H5-SO2-NH-R  +  KOH   ->   C6H5-SO2-N(K)-R  +  H2O   SOLUBLE

     OBSERVATION: a precipitate which DISSOLVES in excess alkali.

  2. SECONDARY AMINE
     C6H5-SO2-Cl  +  HN-R2   ->   C6H5-SO2-N-R2  +  HCl
                                  N,N-dialkylbenzenesulphonamide

     There is NO hydrogen left on the nitrogen, so no salt can form.

     OBSERVATION: a precipitate which does NOT dissolve in alkali.

  3. TERTIARY AMINE
     C6H5-SO2-Cl  +  R3N   ->   NO REACTION
     (no hydrogen on nitrogen to be replaced)

     OBSERVATION: no reaction; the amine remains as an insoluble layer.
     It dissolves on adding dilute HCl, forming R3NH+ Cl-.
```

### Q B2
**How does nitrous acid react with primary, secondary and tertiary amines?
Give equations and observations.**

**ANSWER:**
```
  Nitrous acid is generated in the flask:
       NaNO2  +  HCl   ->   HNO2  +  NaCl      at 273 - 278 K

  1. PRIMARY ALIPHATIC AMINE
     C2H5-NH2  +  HNO2  ->  C2H5-OH  +  N2 (gas)  +  H2O
     The diazonium ion formed is unstable and breaks up at once.
     OBSERVATION: BRISK EFFERVESCENCE of nitrogen. An alcohol is left.

  2. PRIMARY AROMATIC AMINE
     C6H5-NH2 + NaNO2 + 2HCl --273-278 K--> C6H5-N2+Cl- + NaCl + 2H2O
     The arenediazonium salt is STABLE at this temperature because the
     positive charge is delocalised into the ring.
     OBSERVATION: a clear solution, NO gas. (Confirm it by coupling
     with phenol to give an orange dye.)

  3. SECONDARY AMINE (aliphatic or aromatic)
     (CH3)2NH  +  HNO2   ->   (CH3)2N-N=O  +  H2O
                              N-nitrosodimethylamine
     OBSERVATION: a YELLOW OILY LIQUID separates.
     (Liebermann's test then gives a blue/green colour.)

### Q B3
**Explain the order of basic strength of primary, secondary and tertiary
amines in the gas phase and in aqueous solution.**

**ANSWER:**
```
  A. IN THE GAS PHASE
     There is no solvent, so only the INDUCTIVE (+I) EFFECT operates.
     Each alkyl group pushes electron density onto the nitrogen and
     makes the lone pair more available.

         (CH3)3N  >  (CH3)2NH  >  CH3NH2  >  NH3
         3deg     >  2deg      >  1deg    >  ammonia

  B. IN AQUEOUS SOLUTION
     THREE effects now operate together and they FIGHT each other:

     (i)   INDUCTIVE (+I) EFFECT       favours   3deg > 2deg > 1deg
           more alkyl groups push more electrons onto N.

     (ii)  SOLVATION OF THE CATION     favours   1deg > 2deg > 3deg
           after protonation, water hydrogen-bonds to the N-H bonds
           of the ammonium ion and stabilises it.
              R-NH3+   3 N-H  -> best stabilised
              R2-NH2+  2 N-H
              R3-NH+   1 N-H  -> worst stabilised

     (iii) STERIC HINDRANCE            favours   1deg > 2deg > 3deg
           three bulky groups physically block the proton from
           reaching the lone pair.

     Because (i) pulls one way and (ii)+(iii) pull the other way, the
     SECONDARY amine, which sits in the middle, usually comes out on top.

         METHYL series:  (CH3)2NH > CH3NH2 > (CH3)3N > NH3
                          3.27      3.38     4.22      4.75   (pKb)

         ETHYL series:  (C2H5)2NH > (C2H5)3N > C2H5NH2 > NH3
                         3.00        3.25       3.29      4.75 (pKb)

     (Remember: SMALLER pKb = STRONGER base.)
```

### Q B4
**Why are aromatic amines much weaker bases than aliphatic amines?
Explain with structures.**

**ANSWER:**
```
  REASON 1 - THE LONE PAIR IS DELOCALISED

  In aniline the nitrogen lone pair is not held on the nitrogen. It
  flows into the benzene ring:

       NH2            +NH2            +NH2            +NH2
        |              ||              ||              ||
       ( )    <-->    (  )-   <-->    ( )     <-->    ( )
                                       |               |
                                       -               -
                     (charge appears at ortho and para positions)

  A lone pair that is shared with the ring is not free to be given to
  a proton. Hence aniline is a WEAK base.

  REASON 2 - THE STABILITY ARGUMENT (write this one for full marks)

     ANILINE           5 resonance structures  ->  well stabilised
     ANILINIUM ION     only the 2 Kekule ring structures, because the
     C6H5-NH3+         lone pair has been used up on the proton, so
                       there is NO delocalisation onto nitrogen

     The REACTANT is stabilised MORE than the PRODUCT, so protonation
     is energetically unfavourable and the equilibrium lies to the left.

  IN AN ALIPHATIC AMINE there is no ring. The alkyl group pushes
  electrons TOWARDS the nitrogen (+I effect), so the lone pair is even
  more available than in ammonia.

     pKb :  CH3NH2 = 3.38     NH3 = 4.75     C6H5NH2 = 9.38

  The difference of 6 pKb units means aniline is 10^6 = a MILLION times
  weaker a base than methylamine.

  ORDER:  CH3NH2 > NH3 > C6H5NH2 > (C6H5)2NH > (C6H5)3N
  (each extra ring gives the lone pair another place to run away to)
```

### Q B5
**Explain the effect of substituents on the basic strength of aniline,
with the nitroaniline order.**

**ANSWER:**
```
  THE RULE

    ELECTRON-RELEASING groups (-CH3, -OCH3, -NH2, -OH)
        push electrons towards nitrogen
        -> lone pair more available -> MORE basic than aniline

    ELECTRON-WITHDRAWING groups (-NO2, -CN, -CHO, -COOH, -X)
        pull electrons away from nitrogen
        -> lone pair less available -> LESS basic than aniline

  EXAMPLES (pKb; smaller = stronger base)

     p-anisidine  (p-OCH3)   8.66   stronger than aniline
     p-toluidine  (p-CH3)    8.92   stronger than aniline
     ANILINE                 9.38   reference
     p-chloroaniline         9.85   weaker
     m-nitroaniline         11.50   much weaker
     p-nitroaniline         13.00   far weaker
     o-nitroaniline         14.30   weakest

  THE NITROANILINE ORDER

     ANILINE > m-nitroaniline > p-nitroaniline > o-nitroaniline

  WHY META IS LESS AFFECTED THAN PARA
     From the meta position -NO2 can only withdraw by the INDUCTIVE
     effect. From the ortho and para positions it withdraws by BOTH
     the inductive effect AND RESONANCE, placing a positive charge
     right next to the nitrogen. So o- and p- are hit much harder.

  WHY ORTHO IS ALWAYS THE WEAKEST - THE ORTHO EFFECT
     A group sitting next to the -NH2 also interferes STERICALLY and
     twists the -NH2 out of the plane of the ring. Whatever the
     substituent is, an ortho substituent always lowers basicity.
```

**Explain the Hofmann bromamide degradation with the mechanism, and state

**What are diazonium salts? How are they prepared? Explain their stability.**

```

                       benzenediazonium chloride

     the charge sits on one atom, the ion is unstable and it decomposes

### Q B12
**What are coupling reactions? Give two examples with conditions and colours.
Why do these reactions need an activated ring?**

**ANSWER:**
```

  and the diazonium ion attacks another aromatic ring as an
  electrophile, giving an AZO compound Ar-N=N-Ar'.

     nitrobenzene do NOT couple.

     The -N=N- bridge joins the two rings into one long conjugated
     system, which absorbs visible light. That is why azo compounds
     are used as DYES and as INDICATORS (methyl orange is an azo dye).

  6. HOFMANN BROMAMIDE DEGRADATION  (PURE 1deg, chain SHORTENED)
     R-CO-NH2 + Br2 + 4NaOH -> R-NH2 + Na2CO3 + 2NaBr + 2H2O
     Intermediate: the isocyanate R-N=C=O.


  PART B - CHEMICAL PROPERTIES                            [4 marks]

  1. BASIC CHARACTER (salt formation)
     R-NH2 + HCl -> R-NH3+Cl-
     Amines turn red litmus blue - the only basic organic family in
     the syllabus.

  2. ALKYLATION
     R-NH2 --R'X--> R-NH-R' --R'X--> R-NR'2 --R'X--> R-NR'3+ X-

  3. ACYLATION
     C6H5-NH2 + CH3COCl --pyridine--> C6H5-NH-CO-CH3 (acetanilide) + HCl
     C6H5-NH2 + C6H5COCl --aq.NaOH--> C6H5-NH-CO-C6H5 (benzanilide)
                                       SCHOTTEN-BAUMANN reaction
     A base is added to remove the HCl. 3deg amines do not acylate.

  4. CARBYLAMINE REACTION (test for 1deg amines)
     R-NH2 + CHCl3 + 3KOH --heat--> R-NC + 3KCl + 3H2O
     Foul-smelling isocyanide. 2deg and 3deg amines give no reaction.

  5. REACTION WITH NITROUS ACID
     1deg aliphatic: R-NH2 + HNO2 -> R-OH + N2 (brisk effervescence)
     1deg aromatic : C6H5-NH2 + NaNO2/HCl, 273-278 K -> C6H5-N2+Cl-

  6. HINSBERG REACTION
     R-NH2 + C6H5SO2Cl -> C6H5SO2-NH-R, which DISSOLVES in NaOH
     (the N-H is acidic because -SO2- withdraws electrons).

  7. ELECTROPHILIC SUBSTITUTION (aromatic amines)
     C6H5-NH2 + 3Br2(aq) -> 2,4,6-tribromoaniline (white ppt) + 3HBr
     For mono-substitution the -NH2 must first be protected by
     acetylation and then regenerated by hydrolysis.
     Aniline gives NO Friedel-Crafts reaction because it forms a salt
     with AlCl3 in which nitrogen is positive and the ring is
     deactivated.
```

### Q C2
**Describe the preparation of benzenediazonium chloride and explain its
reactions, including its importance in synthesis.**

**MODEL ANSWER:**

```
  PART A - PREPARATION (DIAZOTISATION)                    [2 marks]

     C6H5-NH2 + NaNO2 + 2HCl --273-278 K--> C6H5-N2+Cl- + NaCl + 2H2O

     In two stages:
        NaNO2 + HCl -> HNO2 + NaCl
        C6H5-NH2 + HNO2 + HCl -> C6H5-N2+Cl- + 2H2O

     CONDITIONS
       - 273 to 278 K (ice bath); above 278 K it hydrolyses to phenol
       - excess mineral acid
       - NaNO2 added slowly with stirring
       - use immediately; the dry solid is EXPLOSIVE

     STABILITY: the positive charge is delocalised over the benzene
     ring by resonance, which is why the ARENEdiazonium ion survives.
     An alkyl diazonium ion has no ring and decomposes at once.


  PART B - REACTIONS IN WHICH NITROGEN IS LOST            [4 marks]

     SANDMEYER (cuprous salt):
        C6H5-N2+Cl- --Cu2Cl2/HCl--> C6H5-Cl + N2
        C6H5-N2+Cl- --Cu2Br2/HBr--> C6H5-Br + N2
        C6H5-N2+Cl- --CuCN/KCN-->   C6H5-CN + N2

     GATTERMANN (copper powder):
        C6H5-N2+Cl- --Cu/HCl--> C6H5-Cl + N2
        C6H5-N2+Cl- --Cu/HBr--> C6H5-Br + N2

     IODINE (no catalyst):
        C6H5-N2+Cl- + KI --warm--> C6H5-I + N2 + KCl

     FLUORINE (BALZ-SCHIEMANN):
        C6H5-N2+Cl- + HBF4 -> C6H5-N2+BF4- --heat--> C6H5-F + BF3 + N2

     HYDROXYL:
        C6H5-N2+Cl- + H2O --283 K--> C6H5-OH + N2 + HCl

     HYDROGEN:
        C6H5-N2+Cl- + H3PO2 + H2O -> C6H6 + N2 + H3PO3 + HCl

     NITRO:
        C6H5-N2+Cl- --NaNO2 / Cu--> C6H5-NO2 + N2


  PART C - REACTIONS IN WHICH NITROGEN IS RETAINED        [1 mark]

     COUPLING WITH PHENOL (mildly alkaline, pH 9-10, 273-278 K):
        C6H5-N2+Cl- + C6H5-OH -> p-hydroxyazobenzene, ORANGE dye

     COUPLING WITH ANILINE (mildly acidic, pH 4-5, 273-278 K):
        C6H5-N2+Cl- + C6H5-NH2 -> p-aminoazobenzene, YELLOW dye

     Coupling occurs at the PARA position and needs a strongly
     activated ring, because the diazonium ion is a weak electrophile.


  PART D - IMPORTANCE IN SYNTHESIS                        [1 mark]

     They introduce -F, -I, -CN, -OH and -H, none of which can be put
     on a benzene ring directly. They also allow -NH2 to be used as a
     temporary directing group and then removed with H3PO2.

     EXAMPLE: benzene -> nitrobenzene -> aniline -> 2,4,6-tribromo-
     aniline -> diazonium salt -> 1,3,5-TRIBROMOBENZENE, a compound
     that direct bromination can never give.
```

### Q C3
**Explain the basic strength of amines. Discuss the effect of the inductive
effect, solvation and steric hindrance, and explain why aromatic amines are
weaker bases. Include the effect of substituents on aniline.**

**MODEL ANSWER:**

```
  PART A - WHAT MAKES AN AMINE BASIC                      [1 mark]

     R-NH2 + H2O <--> R-NH3+ + OH-        Kb = [RNH3+][OH-] / [RNH2]
     pKb = -log Kb.   SMALL pKb = STRONG base.

     The base strength depends on HOW AVAILABLE the nitrogen lone pair
     is, and on HOW STABLE the resulting ammonium ion is.


  PART B - THE THREE COMPETING EFFECTS                    [3 marks]

  (i) INDUCTIVE (+I) EFFECT
      Alkyl groups push electron density onto nitrogen, making the
      lone pair more available.
      By this effect alone:  3deg > 2deg > 1deg > NH3

  (ii) SOLVATION OF THE CATION
      Water hydrogen-bonds to the N-H bonds of the ammonium ion and
      stabilises it. More N-H bonds means better stabilisation.
           R-NH3+ (3 N-H) > R2NH2+ (2 N-H) > R3NH+ (1 N-H)
      By this effect alone:  1deg > 2deg > 3deg

  (iii) STERIC HINDRANCE
      Bulky alkyl groups crowd the nitrogen and block the approach of
      the proton. The tertiary amine is the most crowded.
      By this effect alone:  1deg > 2deg > 3deg

  THE RESULT
      (i) pulls one way, (ii) and (iii) pull the other. The SECONDARY
      amine sits in the middle and usually wins.

      GAS PHASE (no solvent, no solvation):
         (CH3)3N > (CH3)2NH > CH3NH2 > NH3

      AQUEOUS, METHYL series:
         (CH3)2NH > CH3NH2 > (CH3)3N > NH3
          3.27      3.38     4.22      4.75    (pKb)

      AQUEOUS, ETHYL series:
         (C2H5)2NH > (C2H5)3N > C2H5NH2 > NH3
          3.00       3.25       3.29      4.75 (pKb)


  PART C - WHY AROMATIC AMINES ARE WEAK                   [2 marks]

      In aniline the nitrogen lone pair is DELOCALISED into the ring:

         NH2          +NH2            +NH2
          |            ||              ||
         ( )   <-->   (  )-   <-->    ( )
                                       |
                                       -

      A shared lone pair is not free to be donated to a proton.

      STABILITY ARGUMENT: aniline has 5 resonance structures and is
      well stabilised; the anilinium ion C6H5-NH3+ has no
      delocalisation onto nitrogen at all. The reactant is stabilised
      more than the product, so protonation is unfavourable.

         pKb  CH3NH2 = 3.38   NH3 = 4.75   C6H5NH2 = 9.38
         Aniline is about a MILLION times weaker than methylamine.

      ORDER: CH3NH2 > NH3 > C6H5NH2 > (C6H5)2NH > (C6H5)3N
      Each extra ring gives the lone pair another escape route.


  PART D - SUBSTITUENT EFFECT ON ANILINE                  [2 marks]

      ELECTRON-RELEASING groups (-CH3, -OCH3) INCREASE basicity.
      ELECTRON-WITHDRAWING groups (-NO2, -CN, -X) DECREASE it.

         p-anisidine 8.66 > p-toluidine 8.92 > ANILINE 9.38 >
         p-chloroaniline 9.85 > m-nitroaniline 11.5 >
         p-nitroaniline 13.0 > o-nitroaniline 14.3

      NITROANILINE ORDER:
         aniline > m-nitroaniline > p-nitroaniline > o-nitroaniline

      From the META position -NO2 withdraws only by the INDUCTIVE
      effect; from ORTHO and PARA it withdraws by RESONANCE as well,
      so those isomers are far weaker.

      THE ORTHO EFFECT: any group in the ortho position also hinders
      the -NH2 sterically and twists it out of plane, so ortho isomers
      are always the weakest bases, whatever the group.
```

### Q C4
**How would you distinguish between primary, secondary and tertiary amines?
Describe all the methods with observations.**

  METHOD 1 - HINSBERG TEST (the complete one)             [3 marks]

### Q C5
**Write an account of aniline: its preparation, physical properties and
chemical reactions.**

**MODEL ANSWER:**

```
  PART A - PREPARATION                                    [2 marks]

     1.  FROM NITROBENZENE (the standard route)
         C6H6 --conc.HNO3 + conc.H2SO4, 330 K--> C6H5-NO2
         C6H5-NO2 + 6[H] --Sn/conc.HCl, then NaOH--> C6H5-NH2
         Industrially, Fe/HCl is used because the HCl is regenerated.

     2.  FROM BENZAMIDE (Hofmann bromamide)
         C6H5-CO-NH2 + Br2 + 4NaOH -> C6H5-NH2 + Na2CO3 + 2NaBr + 2H2O

     NOTE: aniline CANNOT be made by ammonolysis of chlorobenzene or
     by the Gabriel synthesis, because aryl halides do not undergo
     nucleophilic substitution.


  PART B - PHYSICAL PROPERTIES                            [1 mark]

     - Colourless oily liquid; turns BROWN on standing because it is
       slowly oxidised by air.
     - Almost insoluble in water (large hydrophobic ring), but
       DISSOLVES IN DILUTE HCl by forming the ionic salt
       C6H5-NH3+ Cl-.
     - Boiling point 457 K - higher than an alkane of similar mass
       because of N-H hydrogen bonding, but lower than the
       corresponding alcohol because N is less electronegative than O.
     - A very WEAK base, pKb 9.38, because the lone pair is
       delocalised into the ring.


  PART C - CHEMICAL REACTIONS                             [5 marks]

     1.  AS A BASE
         C6H5-NH2 + HCl -> C6H5-NH3+ Cl-   (anilinium chloride)

     2.  ACYLATION
         C6H5-NH2 + CH3COCl --pyridine--> C6H5-NH-CO-CH3 + HCl
                                          ACETANILIDE
         C6H5-NH2 + C6H5COCl --aq.NaOH--> C6H5-NH-CO-C6H5
                                          BENZANILIDE
                                          (SCHOTTEN-BAUMANN)

     3.  CARBYLAMINE REACTION (test for a primary amine)
         C6H5-NH2 + CHCl3 + 3KOH --heat--> C6H5-NC + 3KCl + 3H2O
         foul-smelling phenyl isocyanide

     4.  WITH NITROUS ACID - DIAZOTISATION
         C6H5-NH2 + NaNO2 + 2HCl --273-278 K--> C6H5-N2+Cl- + 2H2O

     5.  BROMINATION
         C6H5-NH2 + 3Br2(aq) -> 2,4,6-tribromoaniline (WHITE ppt) + 3HBr
         For the mono product, protect first:
         aniline --(CH3CO)2O--> acetanilide --Br2/CH3COOH-->
         p-bromoacetanilide --hydrolysis--> p-bromoaniline

     6.  NITRATION
         Direct: o 2 %, m 47 %, p 51 % - because in the acidic medium
         aniline becomes the anilinium ion, which is meta-directing.
         Proper route: acetylate, nitrate at 288 K, hydrolyse ->
         p-NITROANILINE.

     7.  SULPHONATION
         C6H5-NH2 + conc.H2SO4 -> C6H5-NH3+HSO4-
                                --453-473 K--> SULPHANILIC ACID,
         which exists as a ZWITTERION (NH3+ and SO3- in one molecule).

     8.  NO FRIEDEL-CRAFTS REACTION
         Aniline is a Lewis base and forms a complex with AlCl3 in
         which nitrogen bears a positive charge; the ring is then
         strongly deactivated.

     9.  USES
         Dyes, drugs, rubber chemicals; sulphanilamide from
         sulphanilic acid is the parent of the SULPHA DRUGS.
```

### Q C6
**Explain nitro compounds: their nomenclature, structure, preparation and
the reduction of nitrobenzene under different conditions.**

**MODEL ANSWER:**

```
  PART A - NOMENCLATURE                                   [1 mark]

     CH3-NO2            nitromethane
     CH3-CH2-NO2        nitroethane
     CH3-CH2-CH2-NO2    1-nitropropane      (primary)
     (CH3)2CH-NO2       2-nitropropane      (secondary)
     C6H5-NO2           nitrobenzene

     Classified as 1deg, 2deg, 3deg by the carbon carrying the -NO2.

     DO NOT CONFUSE with the isomeric NITRITES:
        CH3-NO2 nitromethane (C-N bond) versus
        CH3-O-N=O methyl nitrite (C-O bond).


  PART B - STRUCTURE                                      [2 marks]

              O                          O -
             //                         /
     R -- N (+)      <-------->  R -- N (+)
             \                         \\
              O -                       O

     The molecule is a RESONANCE HYBRID, so BOTH N-O BONDS ARE
     IDENTICAL in length - halfway between single and double.
     The nitrogen is sp2 hybridised and carries a formal + charge.
     The group is strongly ELECTRON-WITHDRAWING (-I and -R), so it
     deactivates a benzene ring and directs META.


  PART C - PREPARATION                                    [2 marks]

     1.  CH4 + HNO3 --673-723 K, vapour phase--> CH3-NO2 + H2O
         (industrial; gives a mixture)

     2.  R-X + AgNO2 -> R-NO2 + AgX          (nitro compound)
         R-X + KNO2  -> R-O-N=O + KX         (nitrite - the trap!)

         The nitrite ion is AMBIDENT. Covalent AgNO2 lets the NITROGEN
         attack; ionic KNO2 lets the OXYGEN attack.

     3.  C6H6 --conc.HNO3 + conc.H2SO4, 330 K--> C6H5-NO2 + H2O
         The electrophile is the NITRONIUM ION NO2+:
            HNO3 + 2H2SO4 -> NO2+ + H3O+ + 2HSO4-

     4.  C6H5-N2+Cl- --NaNO2 / Cu--> C6H5-NO2 + N2


  PART D - REDUCTION OF NITROBENZENE                      [3 marks]

  +-----------------+-------------------------+---------------------+
  |  MEDIUM         |  REAGENT                |  PRODUCT            |
  +-----------------+-------------------------+---------------------+
  |  ACIDIC         |  Sn/HCl or Fe/HCl       |  ANILINE            |
  |  CATALYTIC      |  H2 / Ni, Pd, Pt        |  ANILINE            |
  |  NEUTRAL        |  Zn dust + NH4Cl(aq)    |  N-phenylhydroxyl-  |
  |                 |                         |  amine C6H5-NH-OH   |
  |  MILD ALKALINE  |  Na3AsO3 / As2O3        |  azoxybenzene       |
  |  ALKALINE       |  LiAlH4                 |  azobenzene         |
  |  STRONG ALKALI  |  Zn dust + excess NaOH  |  hydrazobenzene     |
  |  ELECTROLYTIC   |  cathode, conc. H2SO4   |  p-aminophenol      |
  +-----------------+-------------------------+---------------------+

     MAIN EQUATION
        C6H5-NO2 + 6[H] --Sn/HCl--> C6H5-NH2 + 2H2O
        C6H5-NH3+Cl- + NaOH -> C6H5-NH2 + NaCl + H2O

     WHY Fe/HCl IS USED INDUSTRIALLY
        FeCl2 is hydrolysed by water and REGENERATES the HCl, so only
        a small amount of acid is needed, and iron is cheap.

     ONE-LINE MEMORY
        ACID -> amine.  NEUTRAL -> hydroxylamine.
        ALKALI -> azoxy, azo, hydrazo (two rings joined).
        ELECTRICITY in strong acid -> p-aminophenol.
