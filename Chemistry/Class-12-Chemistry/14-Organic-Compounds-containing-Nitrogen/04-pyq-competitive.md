# ===============================================================
# PATTERN 1 — "WHICH REAGENT GIVES WHICH PRODUCT"
# ===============================================================

### Q1
`C6H5-N2+Cl-` on treatment with `Cu2Cl2 / HCl` gives:

(a) phenol  (b) chlorobenzene  (c) benzene  (d) aniline

**ANSWER: (b) chlorobenzene**
```
  C6H5-N2+Cl-  --Cu2Cl2 / HCl-->  C6H5-Cl  +  N2
  This is the SANDMEYER reaction.
```

---

### Q2
Benzenediazonium chloride warmed with water at 283 K gives:

(a) benzene  (b) chlorobenzene  (c) phenol  (d) nitrobenzene

**ANSWER: (c) phenol**
```
  C6H5-N2+Cl-  +  H2O  --283 K-->  C6H5-OH  +  N2  +  HCl

  This is exactly why diazotisation must be done at 273-278 K:
  warm the solution and you lose your diazonium salt to phenol.
```

---

### Q3
The reagent used to convert benzenediazonium chloride into benzene is:

(a) Cu2Cl2/HCl  (b) H3PO2  (c) KI  (d) HBF4

**ANSWER: (b) H3PO2 (hypophosphorous acid)**
```
  C6H5-N2+Cl- + H3PO2 + H2O  ->  C6H6 + N2 + H3PO3 + HCl

  Ethanol also works, giving acetaldehyde as the by-product.
```

> **SHORTCUT:** the question "how do you REMOVE a group from a benzene ring"
> has exactly one answer in the whole syllabus: **diazotise, then H3PO2**.

---

### Q4
Fluorobenzene is best prepared from benzenediazonium chloride using:

(a) NaF  (b) CuF2  (c) HBF4 then heat  (d) F2/AlCl3

**ANSWER: (c) HBF4 then heat**
```
  C6H5-N2+Cl- + HBF4 -> C6H5-N2+BF4- --heat--> C6H5-F + BF3 + N2

  This is the BALZ-SCHIEMANN reaction, the only practical route to
  an aryl fluoride.
```

---

### Q5
Iodobenzene is prepared from benzenediazonium chloride by:

(a) Cu2I2/HI  (b) simply warming with KI  (c) Cu/HI  (d) I2/AlCl3

**ANSWER: (b) simply warming with KI**
```
  C6H5-N2+Cl- + KI --warm--> C6H5-I + N2 + KCl

  Iodide is the ODD ONE OUT: it needs NO copper catalyst.
```

> **SHORTCUT:** remember the two exceptions in the diazonium fan —
> **iodine needs no catalyst, fluorine needs HBF4 and dry heat**.
> Every other halide needs copper in some form.

---

### Q6
`CH3-CH2-Br` reacts with `AgNO2` to give mainly:

(a) ethyl nitrite  (b) nitroethane  (c) ethanol  (d) ethylamine

**ANSWER: (b) nitroethane, CH3-CH2-NO2**
```
  AgNO2 is COVALENT, so only the NITROGEN lone pair is free to attack.
  The product is the NITRO compound.

  With KNO2 (ionic) you would get ethyl NITRITE CH3CH2-O-N=O instead.
```

---

### Q7
`R-X` with `AgCN` gives mainly:

(a) R-CN  (b) R-NC  (c) R-OH  (d) R-NH2

**ANSWER: (b) R-NC, an isocyanide**
```
  AgCN covalent -> nitrogen attacks -> ISOcyanide.
  KCN ionic     -> carbon attacks   -> cyanide.
```

> **SHORTCUT:** one rule covers Q6 and Q7.
> **SILVER salt -> the NITROGEN attacks.** Ag and N go together.

---

### Q8
Acetamide `CH3-CONH2` treated with `Br2` and `NaOH` gives:

(a) ethanamine  (b) methanamine  (c) acetic acid  (d) acetonitrile

**ANSWER: (b) methanamine, CH3-NH2**
```
  CH3-CO-NH2 + Br2 + 4NaOH -> CH3-NH2 + Na2CO3 + 2NaBr + 2H2O

  HOFMANN BROMAMIDE: the product has ONE CARBON LESS.
  2 carbons in, 1 carbon out.
```

---

### Q9
Acetamide treated with `LiAlH4` gives:

(a) methanamine  (b) ethanamine  (c) ethanol  (d) acetaldehyde

**ANSWER: (b) ethanamine, CH3-CH2-NH2**
```
  CH3-CO-NH2 --LiAlH4--> CH3-CH2-NH2

  LiAlH4 turns the C=O into CH2. SAME number of carbons.

  Compare with Q8: same amide, different reagent, different carbon count.
  This exact pair is the most common trap in the chapter.
```

---

### Q10
`CH3-CN` on reduction with `Na / C2H5OH` gives:

(a) CH3-NH2  (b) CH3-CH2-NH2  (c) CH3-NH-CH3  (d) CH3-COOH

**ANSWER: (b) CH3-CH2-NH2**
```
  CH3-CN + 4[H] --Na/C2H5OH--> CH3-CH2-NH2   (MENDIUS reduction)

  A nitrile gives a PRIMARY amine with ONE MORE carbon in the chain.
```

---

### Q11
`CH3-NC` on reduction gives:

(a) CH3-CH2-NH2  (b) CH3-NH-CH3  (c) CH3-NH2  (d) (CH3)3N

**ANSWER: (b) CH3-NH-CH3, a SECONDARY amine**
```
  In the isocyanide the alkyl group is already on the NITROGEN.
  Adding hydrogens builds a second carbon group on the same nitrogen,
  so you end up with a SECONDARY amine.

     R-CN  -> 1deg amine
     R-NC  -> 2deg amine
```

---

### Q12
Nitrobenzene reduced with **Zn dust and NH4Cl solution** gives:

(a) aniline  (b) azobenzene  (c) N-phenylhydroxylamine  (d) hydrazobenzene

**ANSWER: (c) N-phenylhydroxylamine, C6H5-NH-OH**
```
  Zn + NH4Cl = NEUTRAL medium, so the reduction stops halfway.

  ACID -> aniline.  NEUTRAL -> hydroxylamine.  ALKALI -> two rings joined.
```

---

### Q13
Nitrobenzene reduced with **Zn dust and excess NaOH** gives:

(a) aniline  (b) hydrazobenzene  (c) p-aminophenol  (d) nitrosobenzene

**ANSWER: (b) hydrazobenzene, C6H5-NH-NH-C6H5**
```
  Strongly ALKALINE medium -> two rings condense together.
  The alkaline sequence as reduction gets stronger:
      azoxybenzene -> azobenzene -> hydrazobenzene
```

> **SHORTCUT:** before you look at the options, count the carbons in the

### Q14
Which reagent converts `CH3-CH2-CO-NH2` into `CH3-CH2-NH2`?

(a) LiAlH4  (b) Br2/NaOH  (c) H2/Ni  (d) NaBH4

**ANSWER: (b) Br2/NaOH**
```
  Starting amide has 3 carbons; the product amine has 2.
  Carbon count went DOWN by one  ->  HOFMANN BROMAMIDE  ->  Br2 + NaOH.

  LiAlH4 would have given CH3-CH2-CH2-NH2 (3 carbons).
```

---

### Q15
`CH3-Br` is to be converted into `CH3-CH2-NH2`. The correct sequence is:

(a) NH3 then heat
(b) KCN then H2/Ni
(c) AgCN then H2/Ni
(d) KOH then NH3

**ANSWER: (b) KCN then H2/Ni**
```
  1 carbon in, 2 carbons out. We need to ADD a carbon -> nitrile route.

     CH3-Br --KCN(alc.)--> CH3-CN --H2/Ni--> CH3-CH2-NH2

  Option (c) with AgCN would give CH3-NC, which on reduction gives
  CH3-NH-CH3, a SECONDARY amine. Wrong product.
```

---

### Q16
Which of these gives an amine with the SAME number of carbon atoms as the
starting material?

(a) Hofmann bromamide on an amide
(b) reduction of a nitrile
(c) Gabriel phthalimide synthesis on R-X
(d) none of these

**ANSWER: (c) Gabriel phthalimide synthesis**
```
  R-X  ->  R-NH2.  The R group is carried through unchanged.

  (a) loses one carbon.   (b) gains one carbon.
```

---

### Q17
The number of carbon atoms in the amine obtained when benzamide
`C6H5-CO-NH2` undergoes Hofmann degradation is:

(a) 7  (b) 6  (c) 5  (d) 8

**ANSWER: (b) 6**
```
  C6H5-CO-NH2 (7 carbons) + Br2 + 4NaOH -> C6H5-NH2 (6 carbons) = ANILINE
  One carbon leaves as Na2CO3.
```

# PATTERN 3 — "WHICH ONE GIVES A POSITIVE TEST"
# ===============================================================

### Q18
Which of the following gives the carbylamine test?

(a) (CH3)2NH  (b) (CH3)3N  (c) CH3-NH2  (d) CH3-CO-NH2

**ANSWER: (c) CH3-NH2**
```
  The carbylamine test works ONLY for PRIMARY AMINES,
  aliphatic and aromatic alike.

     R-NH2 + CHCl3 + 3KOH --heat--> R-NC (foul smell) + 3KCl + 3H2O

  An amide is not an amine, so (d) is out.
```

---

### Q19
An amine reacts with benzenesulphonyl chloride to give a product that is
INSOLUBLE in NaOH. The amine is:

(a) primary  (b) secondary  (c) tertiary  (d) quaternary

**ANSWER: (b) secondary**
```
  1deg -> ppt SOLUBLE in NaOH (the leftover N-H is acidic)
  2deg -> ppt INSOLUBLE in NaOH (no N-H left)
  3deg -> NO REACTION at all

  "Soluble, insoluble, no reaction."
```

---

### Q20
An organic compound gives brisk effervescence of a colourless gas with
NaNO2/HCl at 273 K and leaves an alcohol. The compound is:

(a) aniline  (b) ethylamine  (c) diethylamine  (d) triethylamine

**ANSWER: (b) ethylamine**
```
  C2H5-NH2 + HNO2 -> C2H5-OH + N2 (gas) + H2O

  Only a PRIMARY ALIPHATIC amine does this: its diazonium ion is
  unstable and falls apart at once.
  Aniline would give a stable diazonium salt with no gas.
```

---

### Q21
A yellow oily liquid is obtained when an amine is treated with nitrous acid.
The amine is:

(a) primary aliphatic  (b) primary aromatic  (c) secondary  (d) tertiary

**ANSWER: (c) secondary**
```
  R2NH + HNO2 -> R2N-N=O    an N-nitrosoamine, a YELLOW OILY LIQUID.
  Confirm with LIEBERMANN'S test (blue/green colour).
```

---

### Q22
Aniline reacts with bromine water to give:

(a) o-bromoaniline  (b) p-bromoaniline
(c) 2,4,6-tribromoaniline  (d) m-bromoaniline

**ANSWER: (c) 2,4,6-tribromoaniline, a WHITE precipitate**
```
  C6H5-NH2 + 3Br2(aq) -> 2,4,6-tribromoaniline + 3HBr

  -NH2 is so strongly activating that all three o/p positions react
  at once. To get the mono product you must acetylate first.
```

> **SHORTCUT:** if the question says **"bromine WATER"** and the compound is
> aniline or phenol, the answer is always the **2,4,6-TRI substituted white
> precipitate**. If it says **Br2 in CS2 / CH3COOH**, it is the mono product.

### Q23
Which reagent distinguishes primary, secondary AND tertiary amines in a
single test?

(a) CHCl3 + KOH  (b) C6H5-SO2-Cl  (c) Br2 water  (d) FeCl3

**ANSWER: (b) benzenesulphonyl chloride (Hinsberg reagent)**
```
  The carbylamine test (a) identifies only the primary amine; it cannot
  separate secondary from tertiary because both give nothing.
```

---

### Q24
Which of the following does NOT react with acetyl chloride?

(a) CH3-NH2  (b) (CH3)2NH  (c) (CH3)3N  (d) C6H5-NH2

**ANSWER: (c) (CH3)3N**
```
  Acylation replaces a hydrogen ON THE NITROGEN.
  A tertiary amine has no such hydrogen, so it does not acylate.
```

# PATTERN 4 — BASICITY AND REACTIVITY ORDER
# ===============================================================

### Q25
The correct order of basic strength in AQUEOUS solution is:

(a) (CH3)3N > (CH3)2NH > CH3NH2 > NH3
(b) (CH3)2NH > CH3NH2 > (CH3)3N > NH3
(c) CH3NH2 > (CH3)2NH > (CH3)3N > NH3
(d) NH3 > CH3NH2 > (CH3)2NH > (CH3)3N

**ANSWER: (b) (CH3)2NH > CH3NH2 > (CH3)3N > NH3**
```
  The METHYL order is  "2 , 1 , 3 , NH3".
  pKb:  3.27  <  3.38  <  4.22  <  4.75    (smaller pKb = stronger base)

  Option (a) is the GAS PHASE order - a very common trap.
```

---

### Q26
The correct order of basic strength of ethylamines in water is:

(a) (C2H5)2NH > (C2H5)3N > C2H5NH2 > NH3
(b) (C2H5)3N > (C2H5)2NH > C2H5NH2 > NH3
(c) C2H5NH2 > (C2H5)2NH > (C2H5)3N > NH3
(d) (C2H5)2NH > C2H5NH2 > (C2H5)3N > NH3

**ANSWER: (a) (C2H5)2NH > (C2H5)3N > C2H5NH2 > NH3**
```
  The ETHYL order is  "2 , 3 , 1 , NH3".
  pKb:  3.00  <  3.25  <  3.29  <  4.75

  It is NOT the same as the methyl order. The bigger +I push of the
  ethyl group lifts the tertiary amine above the primary one.
```

> **SHORTCUT:** memorise the two lines as sounds.
> **METHYL = "two one three".  ETHYL = "two three one".**
> Both start with 2. Both end with NH3.

---

### Q27
In the GAS PHASE, the order of basic strength of methylamines is:

(a) 1deg > 2deg > 3deg  (b) 3deg > 2deg > 1deg
(c) 2deg > 1deg > 3deg  (d) all equal

**ANSWER: (b) 3deg > 2deg > 1deg**
```
  No solvent means NO SOLVATION, so only the +I effect operates and
  basicity rises steadily with the number of alkyl groups.
```

---

### Q28
Which is the strongest base?

(a) aniline  (b) p-nitroaniline  (c) p-toluidine  (d) diphenylamine

**ANSWER: (c) p-toluidine**
```
  -CH3 is electron RELEASING -> makes the lone pair more available
  -> MORE basic than aniline.
  -NO2 is electron withdrawing -> far LESS basic.
  Two rings (diphenylamine) -> weakest of all.

  pKb:  p-toluidine 8.92 < aniline 9.38 < p-nitroaniline 13.0
        < diphenylamine 13.2
```

---

### Q29
The correct order of basic strength is:

(a) o-nitroaniline > m-nitroaniline > p-nitroaniline
(b) m-nitroaniline > p-nitroaniline > o-nitroaniline
(c) p-nitroaniline > m-nitroaniline > o-nitroaniline
(d) all are equal

**ANSWER: (b) m > p > o**
```
  From META, -NO2 withdraws only by the INDUCTIVE effect.
  From ORTHO and PARA it withdraws by RESONANCE as well.
  ORTHO is worst of all because of the extra steric ORTHO EFFECT.

  Full order:  aniline > m- > p- > o-nitroaniline
```

> **SHORTCUT:** for ANY substituted aniline question, the **ortho isomer is
> the weakest base**, whatever the substituent. That single fact eliminates
> options fast.

---

### Q30
Which of the following is the weakest base?

(a) NH3  (b) CH3NH2  (c) C6H5NH2  (d) C6H5CH2NH2

**ANSWER: (c) C6H5NH2 (aniline)**
```
  The lone pair is delocalised into the ring.

  BEWARE (d): benzylamine C6H5-CH2-NH2 has the nitrogen on a CH2,
  not on the ring, so the lone pair is NOT delocalised. It is a
  STRONG base, pKb about 4.7 - stronger than ammonia.
```

### Q31
The order of boiling points of the isomeric amines C4H11N is:

(a) 3deg > 2deg > 1deg  (b) 1deg > 2deg > 3deg
(c) 2deg > 1deg > 3deg  (d) all equal

**ANSWER: (b) 1deg > 2deg > 3deg**
```
  Count the N-H bonds available for hydrogen bonding:
     1deg has 2 ,  2deg has 1 ,  3deg has 0.

  A tertiary amine cannot hydrogen bond with itself at all.
```

---

### Q32
Which has the highest boiling point?

(a) CH3-CH2-OH  (b) CH3-CH2-NH2  (c) CH3-O-CH3  (d) CH3-CH2-CH3

**ANSWER: (a) CH3-CH2-OH**
```
  ALCOHOL > AMINE > ETHER > ALKANE

  Oxygen is more electronegative than nitrogen, so the O---H---O
  hydrogen bond is stronger than the N---H---N one.
  (351 K , 290 K , 248 K , 231 K)
```

---

### Q33
The order of reactivity of alkyl halides in ammonolysis is:

(a) R-Cl > R-Br > R-I  (b) R-I > R-Br > R-Cl
(c) R-F > R-Cl > R-Br  (d) all equal

**ANSWER: (b) R-I > R-Br > R-Cl**
```
  The weakest C-X bond breaks most easily, and C-I is the weakest.
```

### Q34
`R-CO-NH2 + Br2 + 4NaOH -> R-NH2 + Na2CO3 + 2NaBr + 2H2O` is called:

(a) Gabriel synthesis  (b) Hofmann bromamide degradation
(c) Sandmeyer reaction  (d) Mendius reduction

**ANSWER: (b) Hofmann bromamide degradation**
```
  The word DEGRADATION is the clue: the molecule gets SMALLER.
  Intermediate: the isocyanate R-N=C=O.
```

### Q35
The intermediate formed in the Hofmann bromamide reaction is:

(a) an isocyanide  (b) an isocyanate  (c) a nitrile  (d) an amide

**ANSWER: (b) an isocyanate, R-N=C=O**
```
  R-CO-NH-Br --NaOH--> R-CO-N(-)-Br --> R-N=C=O --H2O/OH---> R-NH2

  Do not confuse ISOCYANATE R-N=C=O (Hofmann) with
  ISOCYANIDE R-NC (carbylamine).
```

### Q36
The reaction of an amine with benzoyl chloride in aqueous NaOH is called:

(a) Hinsberg reaction  (b) Schotten-Baumann reaction
(c) Gabriel synthesis  (d) Gattermann reaction

**ANSWER: (b) Schotten-Baumann reaction**
```
  C6H5-NH2 + C6H5-CO-Cl --aq. NaOH--> C6H5-NH-CO-C6H5 + HCl
                                       benzanilide
```

---

### Q37
`C6H5-N2+Cl- --Cu powder / HCl--> C6H5-Cl + N2` is called:

(a) Sandmeyer reaction  (b) Gattermann reaction
(c) Balz-Schiemann reaction  (d) Rosenmund reduction

**ANSWER: (b) Gattermann reaction**
```
  SANDmeyer uses a SALT, Cu2X2.
  GATTERmann uses the METAL, copper powder.
```

---

### Q38
Which reaction CANNOT be used to prepare aniline?

(a) reduction of nitrobenzene with Sn/HCl
(b) Hofmann degradation of benzamide
(c) Gabriel phthalimide synthesis on chlorobenzene
(d) catalytic hydrogenation of nitrobenzene

**ANSWER: (c) Gabriel phthalimide synthesis**
```
  Gabriel needs a nucleophilic substitution on the halide.
  ARYL halides do not undergo nucleophilic substitution, because the
  C-Cl bond has partial double-bond character from resonance with
  the ring. So aromatic primary amines cannot be made this way.
```

The Mendius reduction refers to:

(c) R-COCl + H2/Pd-BaSO4 -> R-CHO
(d) R-CONH2 + LiAlH4 -> R-CH2-NH2

### Q40
Diazotisation of aniline is carried out at:

(a) 273-278 K  (b) 298 K  (c) 330 K  (d) 373 K

**ANSWER: (a) 273-278 K**
```
  Above 278 K the diazonium salt hydrolyses to phenol and loses N2.
```

> **SHORTCUT:** learn the four temperatures of this chapter and you will
> pick up a free mark almost every year:
> ```
>    273 - 278 K   diazotisation
>    283 K         hydrolysis of the diazonium salt to phenol
>    330 K         nitration of benzene
>    453 - 473 K   sulphonation of aniline to sulphanilic acid
>    673 - 723 K   vapour-phase nitration of an alkane
> ```

### Q41
Coupling of benzenediazonium chloride with phenol is carried out in:

(a) strongly acidic medium  (b) mildly acidic medium
(c) mildly alkaline medium  (d) strongly alkaline medium

**ANSWER: (c) mildly alkaline medium (pH 9-10)**
```
  NaOH converts phenol into the PHENOXIDE ion, which is even more
  strongly activated, so the weak diazonium electrophile can attack.
  STRONG alkali is bad - it destroys the diazonium salt.
```

---

### Q42
The colour of p-hydroxyazobenzene, obtained by coupling a diazonium salt
with phenol, is:

(a) yellow  (b) orange  (c) green  (d) blue

**ANSWER: (b) orange**
```
  PHENOL  + alkaline  ->  p-hydroxyazobenzene  ->  ORANGE
  ANILINE + acidic    ->  p-aminoazobenzene    ->  YELLOW
```

---

### Q43
Coupling of a diazonium salt with aniline requires:

(a) pH 4-5  (b) pH 9-10  (c) pH 1  (d) pH 14

**ANSWER: (a) pH 4-5 (mildly acidic)**
```
  In strong acid the aniline would be protonated to the anilinium ion,
  which is deactivated and will not couple.
```

---

### Q44
Which compound will NOT couple with benzenediazonium chloride?

(a) phenol  (b) aniline  (c) nitrobenzene  (d) N,N-dimethylaniline

**ANSWER: (c) nitrobenzene**
```
  A diazonium ion is only a WEAK electrophile, so it needs a
  STRONGLY ACTIVATED ring (-OH, -NH2, -NR2).
  Nitrobenzene is DEACTIVATED, so it cannot couple.
```

---

### Q45
Sulphanilic acid exists as:

(a) a normal molecule  (b) a zwitterion
(c) a free radical  (d) a carbanion

**ANSWER: (b) a zwitterion (an internal salt)**
```
              NH3+
               |
              ( )        the basic -NH2 takes the proton from
               |         the acidic -SO3H inside the same molecule
              SO3-

  Because it is really ionic, it has a very high melting point and
  is insoluble in organic solvents.
```

# PATTERN 7 — "WHY" AND ASSERTION-STYLE
# ===============================================================

### Q46
Aniline does not undergo Friedel-Crafts reaction because:

(a) aniline is unstable
(b) aniline forms a salt with AlCl3 in which nitrogen is positive,
    deactivating the ring
(c) the -NH2 group is meta directing
(d) AlCl3 reacts with the benzene ring

**ANSWER: (b)**
```
  Aniline is a Lewis BASE; AlCl3 is a Lewis ACID. They combine first.
  The nitrogen then carries a POSITIVE charge, which strongly
  DEACTIVATES the ring.
```

---

### Q47
Nitration of aniline gives a large amount of the META product because:

(a) -NH2 is meta directing
(b) aniline is protonated to the anilinium ion in the acidic medium
(c) the reaction is done at high temperature
(d) nitric acid is a weak acid

**ANSWER: (b)**
```
  C6H5-NH2 + H+ -> C6H5-NH3+
  The anilinium ion is positively charged, so it is DEACTIVATING and
  META-DIRECTING. About 47 % meta product results.
```

### Q48
Benzenediazonium chloride is more stable than ethanediazonium chloride
because:

(a) it is a solid
(b) the positive charge is delocalised over the benzene ring
(c) nitrogen is more electronegative in it
(d) it is prepared at low temperature

**ANSWER: (b)**
```
  Delocalising a charge over many atoms lowers the energy.
  An alkyl diazonium ion has no ring to delocalise into, so it
  decomposes instantly to R+ and N2.
```

### Q53
Benzene -> X -> Y -> chlorobenzene. If step 1 is nitration and step 2 is
Sn/HCl reduction, then Y and the last reagent are:

(a) aniline, Cu2Cl2/HCl after diazotisation
(b) phenol, HCl
(c) nitrobenzene, Cl2
(d) benzoic acid, SOCl2

**ANSWER: (a) aniline; diazotise, then Cu2Cl2/HCl (Sandmeyer)**
```
  C6H6 --HNO3/H2SO4--> C6H5-NO2 --Sn/HCl--> C6H5-NH2
       --NaNO2/HCl, 273-278 K--> C6H5-N2+Cl- --Cu2Cl2/HCl--> C6H5-Cl
```

### Q54
1,3,5-tribromobenzene is prepared from aniline by:

(a) direct bromination with Br2/Fe
(b) Br2 water, then diazotisation, then H3PO2
(c) Br2 water, then NaOH
(d) diazotisation, then Br2

**ANSWER: (b)**
```
  aniline --Br2(aq)--> 2,4,6-tribromoaniline
          --NaNO2/HCl, 273-278 K--> the diazonium salt
          --H3PO2 + H2O--> 1,3,5-TRIBROMOBENZENE

  Direct bromination of benzene could never give the 1,3,5 pattern,
  because -Br is an ortho/para director. The -NH2 group places the
  bromines and is then deleted.
```

> **SHORTCUT:** if a question asks for a **meta-arrangement of ortho/para
> directing groups**, the answer always involves **-NH2 as a temporary
> director, removed with H3PO2**.

### Q55
The correct sequence to convert aniline into p-nitroaniline is:

(a) direct nitration with HNO3/H2SO4
(b) acetylation, nitration, hydrolysis
(c) nitration, acetylation, hydrolysis
(d) diazotisation, then NaNO2/Cu

**ANSWER: (b) acetylation, nitration, hydrolysis**

  p-nitroacetanilide --H3O+ hydrolysis--> p-NITROANILINE

  Direct nitration would give about 47 % meta, because aniline is
  protonated to the meta-directing anilinium ion.

### Q57
`CH3-CH2-CN` is hydrolysed with dilute acid. The product is:

(a) CH3-CH2-COOH  (b) CH3-COOH  (c) CH3-CH2-NH2  (d) CH3-CH2-CH2-NH2
