# Chemistry in Everyday Life — Concepts From Zero

Read this with a pen. Every time you meet a drug name, **write it down once**
next to what it does. This chapter is a naming chapter, not a thinking chapter.

There is no formula here. There is no numerical here. There is nothing to
derive. There is only a list to learn — and that is exactly why a weak student
should love this chapter.

# ===============================================================
# TOPIC 1 — WHAT IS A DRUG?
# ===============================================================

## 1.1 The everyday picture

You have a headache. You swallow a tablet. Twenty minutes later the headache
is gone.

What actually happened? A small chemical molecule travelled in your blood,
found one particular big molecule in your body, stuck to it, and stopped it
doing its job. That is all a drug ever does.

```
   +--------+        travels        +---------------+       +-----------+
   |  DRUG  |  ------------------>  |   TARGET      | ----> | RESPONSE  |
   | (small |     in the blood      | (a big        |       | (headache |
   | molecule)                      |  biomolecule) |       |  stops)   |
   +--------+                       +---------------+       +-----------+

   Molecular mass of a drug is usually 100 - 500 u.
   That is TINY compared with the target, which may be tens of
   thousands of u.
```

Think of it like a **key and a lock**. The target is the lock. The natural
chemical of your body is the correct key. A drug is either a **duplicate key**
(it opens the lock and gives the same effect) or a **broken key jammed in the
lock** (nothing can open it any more). Almost every drug is one of these two.

## 1.2 The exam definitions — learn these word for word

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |  DRUG                                                             |
  |  Drugs are chemicals of LOW molecular mass (about 100 - 500 u)    |
  |  which interact with macromolecular targets in the body and       |
  |  produce a biological response.                                   |
  |                                                                   |
  |  MEDICINE                                                         |
  |  When the biological response of a drug is THERAPEUTIC (useful)   |
  |  and NON-TOXIC, the drug is called a medicine and is used in the  |
  |  diagnosis, prevention and treatment of disease.                  |
  |                                                                   |
  |  CHEMOTHERAPY                                                     |
  |  The use of CHEMICALS for the treatment of disease is called      |
  |  chemotherapy.                                                    |
  |                                                                   |
  |  THERAPEUTIC EFFECT                                               |
  |  The useful, disease-curing effect produced by a drug.            |
  |                                                                   |
  |  THERAPEUTIC INDEX                                                |
  |  The ratio of the TOXIC dose of a drug to its THERAPEUTIC         |
  |  (effective) dose. It measures how SAFE the drug is.              |
  |                                                                   |
  |                              toxic dose                           |
  |       therapeutic index  =  ---------------                       |
  |                            therapeutic dose                       |
  |                                                                   |
  |       HIGH value -> large safety margin -> SAFE drug              |
  |       LOW  value -> small safety margin -> DANGEROUS drug         |
  |                                                                   |
  +-------------------------------------------------------------------+
```

## 1.3 Why "drug" is not the same as "medicine"

```
   ALL medicines are drugs.
   NOT all drugs are medicines.

   A drug taken in a HIGHER dose than recommended is a POISON.
   The same chemical can heal or kill. Only the DOSE decides.

        small dose  ->  medicine
        large dose  ->  poison

   This is exactly what the THERAPEUTIC INDEX measures.
```

### WORKED EXAMPLE 1.1

A doctor has two drugs, both of which cure the same fever.

```
  DRUG P :  effective dose = 10 mg  ,  toxic dose = 1000 mg
  DRUG Q :  effective dose = 10 mg  ,  toxic dose =   20 mg

  STEP 1   Therapeutic index of P  =  1000 / 10  =  100
  STEP 2   Therapeutic index of Q  =    20 / 10  =    2

  ANSWER:  Drug P is far safer. With P you would have to swallow 100
           times the correct dose before you were poisoned. With Q,
           just twice the dose is dangerous.

  So a HIGH therapeutic index means a SAFE drug.
```

> **TRAP:** Students write "therapeutic index means how well the drug works."
> Wrong. It measures **SAFETY**, not strength — it is a ratio of toxic dose to
> effective dose.

# ===============================================================
# TOPIC 2 — CLASSIFICATION OF DRUGS (FOUR BASES)
# ===============================================================

This is a **standing 4-mark question**. There are four bases. You must be able
to name all four and give one example for each.

## 2.1 The four bases

```
  +--------------------------+---------------------------------------------+
  |  BASIS                   |  GROUPED ACCORDING TO ...                   |
  +--------------------------+---------------------------------------------+
  |  1. PHARMACOLOGICAL      |  the EFFECT the drug has on the body        |
  |     EFFECT               |                                             |
  |  2. DRUG ACTION          |  the BIOCHEMICAL PROCESS the drug acts on   |
  |  3. CHEMICAL STRUCTURE   |  a COMMON STRUCTURAL FEATURE in the         |
  |                          |  molecules                                  |
  |  4. MOLECULAR TARGETS    |  the BIOMOLECULE the drug attacks           |
  +--------------------------+---------------------------------------------+

  MEMORY HOOK:   "P A S T"
       P - Pharmacological effect
       A - Action
       S - Structure
       T - Targets
```

## 2.2 Each one explained

### (a) On the basis of PHARMACOLOGICAL EFFECT

```
  All drugs that produce the SAME KIND OF EFFECT are put in one group,
  no matter what they are made of.

  EXAMPLE:  ANALGESICS  -  every drug that relieves pain
            ANTISEPTICS -  every drug that kills or stops microorganisms

  WHO USES IT:  a DOCTOR. He wants to treat a symptom, so he wants the
                whole shelf of pain killers in one place.
```

### (b) On the basis of DRUG ACTION

```
  All drugs that act on the SAME BIOCHEMICAL PROCESS are put in one
  group.

  EXAMPLE:  ANTIHISTAMINES  -  every drug that inhibits the action of
                               the compound HISTAMINE

  So the grouping is by the PROCESS being blocked, not by the symptom.
```

### (c) On the basis of CHEMICAL STRUCTURE

```
  All drugs with the SAME STRUCTURAL FEATURE are put in one group.
  They often (but not always) share the same pharmacological activity.

  EXAMPLE:  SULPHONAMIDES  (the "sulpha drugs")
            All of them contain the group

                  -SO2 - NH -

            sulphapyridine, sulphadiazine, sulphanilamide,
            prontosil ...
```

### (d) On the basis of MOLECULAR TARGETS

```
  Drugs are grouped by WHICH BIOMOLECULE they interact with -
  proteins, enzymes, receptors, carbohydrates, lipids, nucleic acids.

  EXAMPLE:  all drugs that act on ENZYMES form one group;
            all drugs that act on RECEPTORS form another.

  WHO USES IT:  a MEDICINAL CHEMIST. This is the MOST USEFUL
                classification for designing a new drug.
```

### WORKED EXAMPLE 2.1

Classify the following statements under the correct basis of classification.

```
  (i)   "Aspirin and paracetamol are both analgesics."
  (ii)  "Sulphadiazine and sulphapyridine both contain -SO2NH-."
  (iii) "Cimetidine acts on the histamine H2 receptor."
  (iv)  "Terfenadine blocks the action of histamine."

  STEP 1  (i) groups by the EFFECT (both relieve pain)
              ->  PHARMACOLOGICAL EFFECT

  STEP 2  (ii) groups by a shared structural fragment
              ->  CHEMICAL STRUCTURE

  STEP 3  (iii) names the biomolecule attacked (a receptor)
              ->  MOLECULAR TARGET

  STEP 4  (iv) names the biochemical process blocked
              ->  DRUG ACTION
```

> **TRAP:** (iii) and (iv) look almost the same. The difference:
> **"which molecule?" = molecular target. "which process?" = drug action.**

# ===============================================================
# TOPIC 3 — DRUG-TARGET INTERACTION
# ===============================================================

Proteins do many jobs in the body. Two of those jobs matter here:

```
   PROTEIN AS AN ENZYME      ->  it CATALYSES a reaction
   PROTEIN AS A RECEPTOR     ->  it CATCHES A MESSAGE and passes it in

   A drug either JAMS the enzyme, or COPIES/BLOCKS the message
   at the receptor. That is the entire topic.
```

## 3.1 ENZYMES AS DRUG TARGETS

### How an enzyme does its job (two things it must do)

```
  1. HOLD THE SUBSTRATE IN PLACE.
     The enzyme has a pocket on its surface called the ACTIVE SITE.
     The substrate fits into it like a hand into a glove.
     It is held there by weak forces:
         - ionic bonding
         - hydrogen bonding
         - dipole-dipole interaction
         - van der Waals forces

  2. PROVIDE THE FUNCTIONAL GROUPS that attack the substrate and
     break/form the bond, and provide the right environment
     (acidic / basic groups) for the reaction.
```

```
         SUBSTRATE
            ___
           /   \
          |  S  |
           \___/
             |    fits into
             v
    +---------------------+
    |      ___            |
    |     /   \           |      <-- ACTIVE SITE, the pocket
    |     \___/           |
    |                     |
    |      E N Z Y M E    |
    +---------------------+

    Result: the reaction happens MUCH faster than it otherwise would.
```

### How a drug STOPS an enzyme — ENZYME INHIBITORS

```
  A drug that blocks the action of an enzyme is called an
  ENZYME INHIBITOR.

  It can do this in TWO ways.
```

**WAY 1 — COMPETITIVE INHIBITOR (the drug sits in the active site)**

```
  The drug is built to LOOK LIKE the substrate. It slides into the
  active site and sits there. The real substrate now has nowhere to go.

     NORMAL                      WITH A COMPETITIVE INHIBITOR

     Substrate S enters          Drug D enters instead
     +----------------+          +----------------+
     |     ( S )      |          |     [ D ]      |   <- drug occupies
     |   active site  |          |   active site  |      the active site
     +----------------+          +----------------+
       reaction happens            NO reaction; S is locked out

  Because the drug and the substrate COMPETE for the same site, the
  drug is called a COMPETITIVE INHIBITOR.
```

**WAY 2 — ALLOSTERIC / NON-COMPETITIVE INHIBITOR (the drug sits somewhere
else and spoils the shape)**

```
  Some drugs bind to a DIFFERENT site on the enzyme, called the
  ALLOSTERIC SITE. Binding there CHANGES THE SHAPE of the active site,
  so the substrate can no longer recognise it.

     +-------------------------+
     |     ___                 |
     |    /   \  active site   |          normal shape - S fits
     |    \___/                |
     |                  ( )    |  <- empty allosteric site
     +-------------------------+

     +-------------------------+
     |     _/\_                |
     |    /    \ active site   |          DISTORTED shape - S no longer fits
     |    \_/\_/  is now the   |
     |            WRONG SHAPE  |
     |                  (D)    |  <- drug bound in the allosteric site
     +-------------------------+

  This is a NON-COMPETITIVE (allosteric) inhibitor, because it is
  NOT competing with the substrate for the same place.
```

### Reversible or irreversible?

```
  If the drug is attached by WEAK BONDS (hydrogen bonding, ionic,
  van der Waals)      ->  the effect can be REVERSED by removing the
                          drug; the enzyme recovers.

  If the drug is attached by a STRONG COVALENT BOND
                      ->  the effect is IRREVERSIBLE; the enzyme is
                          permanently dead.
```

### WORKED EXAMPLE 3.1

Explain, in four points, how a competitive inhibitor differs from an allosteric
inhibitor. (This is a very common 4-mark answer.)

```
  +---------------------------+---------------------------------+
  | COMPETITIVE INHIBITOR     | ALLOSTERIC (NON-COMPETITIVE)    |
  +---------------------------+---------------------------------+
  | 1. Binds at the ACTIVE    | 1. Binds at a DIFFERENT site,   |
  |    SITE itself            |    the ALLOSTERIC SITE          |
  | 2. Structurally SIMILAR   | 2. Need NOT resemble the        |
  |    to the substrate       |    substrate                    |
  | 3. Physically BLOCKS the  | 3. CHANGES THE SHAPE of the     |
  |    substrate from         |    active site so the substrate |
  |    entering               |    can no longer bind           |
  | 4. Competes with the      | 4. Does not compete; substrate  |
  |    substrate; excess      |    concentration does not       |
  |    substrate can overcome |    reverse it                   |
  |    it                     |                                 |
  +---------------------------+---------------------------------+
```

## 3.2 RECEPTORS AS DRUG TARGETS

### What a receptor is

```
  RECEPTORS are PROTEINS that are EMBEDDED IN THE CELL MEMBRANE.
  Most of the receptor lies inside the membrane; the part that
  RECEIVES THE MESSAGE sticks OUT of the cell into the fluid outside.

           OUTSIDE THE CELL
                 |
            ~~~~~|~~~~~   <- the binding site sticks out here
     ===========[ R ]===========   <- cell membrane
                 |
            INSIDE THE CELL
```

### How the body sends messages

```
  Nerve cells do NOT touch each other. There is a gap between them.
  To pass a message across the gap, the body releases a chemical
  called a CHEMICAL MESSENGER (a neurotransmitter, e.g. histamine,
  noradrenaline, serotonin).

     nerve cell A                        nerve cell B
     ------------\   messenger   /---------------------
                  \    o  o  o  /
                   \  o      o /
                    \_________/  --> messenger binds to a RECEPTOR on
                       the gap       cell B and the message is passed on

  When the messenger binds, the SHAPE of the receptor changes, and this
  change carries the message INTO the cell.
```

### The two kinds of drug that act on receptors

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  AGONIST                                                           |
  |  A drug that MIMICS the natural chemical messenger. It binds to    |
  |  the receptor and PRODUCES THE SAME RESPONSE as the messenger.     |
  |  Used when the body's own messenger is MISSING or too little.      |
  |                                                                    |
  |  ANTAGONIST                                                        |
  |  A drug that binds to the receptor site and BLOCKS it, so the      |
  |  natural messenger cannot bind. It STOPS the message.              |
  |  Used when the body's message is TOO STRONG and must be stopped.   |
  |                                                                    |
  +--------------------------------------------------------------------+

     AGONIST                          ANTAGONIST
     "a fake key that works"          "a broken key that jams the lock"

     drug binds -> message SENT       drug binds -> message BLOCKED
```

### The real examples you must quote

```
  ANTAGONIST examples:
     cimetidine and ranitidine  - block the HISTAMINE H2 RECEPTOR
                                  in the stomach, so acid is not released
     terfenadine, brompheniramine - block the HISTAMINE H1 RECEPTOR,
                                  so allergy symptoms stop

  AGONIST example:
     a drug given when the natural messenger is deficient - it takes
     the messenger's place and produces the same effect.
```

### WHY DRUGS ARE SELECTIVE — the key idea for a 4-mark answer

```
  The body has MANY different receptors. Each one has a slightly
  DIFFERENT SHAPE at its binding site.

  A drug is designed to fit only ONE of those shapes.

  That is why cimetidine blocks the H2 receptor in the STOMACH but
  does NOT touch the H1 receptor that controls allergy,
  and why terfenadine blocks H1 (stops the allergy) but does NOT stop
  acid production in the stomach.

  SAME messenger (histamine). DIFFERENT receptors. DIFFERENT drugs.
```

> **TRAP:** The single most-asked tricky question in this chapter is
> *"Why do antihistamines like brompheniramine not affect the release of acid
> in the stomach?"* The answer is exactly the box above: **histamine acts
> through DIFFERENT receptors (H1 for allergy, H2 for acid). Antihistamine
> drugs are designed to fit only the H1 receptor, so they cannot bind to the
> H2 receptor and therefore cannot stop acid release.**

# ===============================================================
# TOPIC 4 — ANTACIDS
# ===============================================================

## 4.1 The everyday picture

Your stomach makes hydrochloric acid to digest food. Sometimes it makes too
much. The excess acid burns the stomach lining and you get "acidity",
heartburn, and in bad cases an **ulcer**.

**An ANTACID is a chemical that removes the excess acid and raises the pH of
the stomach to a safe level.**

## 4.2 The three generations of treatment — tell the story in this order

```
  GENERATION 1  (the old way)
  ---------------------------
  SODIUM HYDROGENCARBONATE  (NaHCO3, "baking soda") - it neutralises acid.

     NaHCO3  +  HCl  ---->  NaCl  +  H2O  +  CO2

  DRAWBACK (very commonly asked):
     If you take too much, the stomach becomes ALKALINE. The stomach
     answers by producing EVEN MORE ACID than before.
     So the problem comes back worse.

  A mixture of ALUMINIUM HYDROXIDE and MAGNESIUM HYDROXIDE was used
  instead, because metal hydroxides are BETTER: they are only weakly
  basic, so they do NOT make the stomach alkaline and do not trigger
  extra acid.

  BUT: all of these only NEUTRALISE the acid that is already there.
       They do not stop the stomach MAKING acid. So they give only
       temporary relief.
```

```
  GENERATION 2  (the breakthrough - a receptor blocker)
  -----------------------------------------------------
  Scientists found that HISTAMINE stimulates the stomach to secrete
  acid. So instead of mopping up the acid, why not stop it being made?

  A drug was needed that would BLOCK the HISTAMINE H2 RECEPTOR in the
  stomach wall - an ANTAGONIST.

     CIMETIDINE  (trade name Tagamet)   - the first one
     RANITIDINE  (trade name Zantac)    - the improved one

  These were a REVOLUTION in the treatment of acidity and ulcers,
  and for a time ranitidine was the largest selling drug in the world.
```

```
  GENERATION 3  (proton pump inhibitors)
  ---------------------------------------
  OMEPRAZOLE and LANSOPRAZOLE.
  These do not block a receptor - they PREVENT THE FORMATION OF ACID
  itself, by shutting down the "proton pump" that pushes H+ into
  the stomach.
```

## 4.3 The bacteria twist — Helicobacter pylori

```
  Excessive acid is not always the whole story.

  A BACTERIUM called HELICOBACTER PYLORI lives in the stomach and is
  responsible for hyperacidity and ULCERS in many patients.

  Treatment: ANTIBIOTICS are given (usually together with an antacid)
  to KILL the bacteria. Without killing the bacteria, the ulcer keeps
  coming back.
```

### WORKED EXAMPLE 4.1

Why is the use of sodium hydrogencarbonate as an antacid not recommended,
whereas magnesium hydroxide is?

```
  STEP 1   NaHCO3 is a fairly strong base. If an excess is taken, it
           does not just neutralise the acid - it makes the stomach
           ALKALINE.

  STEP 2   An alkaline stomach triggers the stomach to secrete MORE
           acid to correct itself. The acidity therefore returns and
           is worse than before.

  STEP 3   Mg(OH)2 (and Al(OH)3) are only WEAKLY basic and are
           sparingly soluble. They neutralise the excess acid but
           CANNOT raise the pH above neutral.

  ANSWER:  Metal hydroxides are preferred because they cannot make the
           stomach alkaline and therefore do not cause rebound
           over-production of acid.
```

> **TRAP:** Do not write that antacids "kill the acid". They **neutralise**
> it (generations 1) or **prevent its release** (generations 2 and 3). The
> examiner is checking that you know the difference between neutralising acid
> and preventing acid.

# ===============================================================
# TOPIC 5 — ANTIHISTAMINES (ANTIALLERGIC DRUGS)
# ===============================================================

## 5.1 What histamine does

```
  HISTAMINE is a natural chemical messenger in the body. It is
  released when the body meets something it is allergic to
  (pollen, dust, certain foods).

  Histamine causes:
     - contraction of the smooth muscles of the bronchi and gut
     - the nasal congestion, running nose and watery eyes of hay fever
     - skin rashes and swelling
     - relaxation of the muscles of the blood vessels (a drop in BP)
     - and, through a DIFFERENT receptor, the release of stomach acid
```

## 5.2 The definition and the examples

```
  +-------------------------------------------------------------------+
  |  ANTIHISTAMINES (antiallergic drugs) are drugs which INTERFERE    |
  |  WITH THE NATURAL ACTION OF HISTAMINE by competing with histamine |
  |  for the binding sites of the H1 RECEPTOR.                        |
  |                                                                   |
  |  EXAMPLES:   BROMPHENIRAMINE  (Dimetapp)                          |
  |              TERFENADINE      (Seldane)                           |
  |                                                                   |
  |  They are ANTAGONISTS at the H1 receptor.                         |
  +-------------------------------------------------------------------+
```

## 5.3 The question that is asked every single year

**"Why do antihistamines like brompheniramine and terfenadine not affect the
release of acid in the stomach?"**

```
  ANSWER, in three steps:

  STEP 1   Histamine works through MORE THAN ONE kind of receptor.
              H1 RECEPTOR  -> allergy symptoms
              H2 RECEPTOR  -> secretion of stomach acid

  STEP 2   The two receptors have DIFFERENT SHAPES at their binding
           sites.

  STEP 3   Brompheniramine and terfenadine are designed to fit only the
           H1 receptor. They CANNOT bind to the H2 receptor.

  CONCLUSION: they stop the allergy but leave the acid secretion
              untouched.

  And the mirror image of this answer:
  Cimetidine and ranitidine fit only the H2 receptor, so they stop
  the acid but do NOT cure an allergy.
```

# ===============================================================
# TOPIC 6 — NEUROLOGICALLY ACTIVE DRUGS: TRANQUILISERS
# ===============================================================

## 6.1 Definition

```
  +-------------------------------------------------------------------+
  |  TRANQUILISERS are chemical compounds used for the treatment of    |
  |  STRESS, and mild or severe MENTAL DISEASES. They act on the       |
  |  higher centres of the CENTRAL NERVOUS SYSTEM.                     |
  |                                                                   |
  |  They are an essential component of SLEEPING PILLS.                |
  +-------------------------------------------------------------------+
```

## 6.2 The different kinds — and this is exactly what the examiner wants

```
  (a) THE ANTIDEPRESSANTS THAT PROTECT NORADRENALINE
  ---------------------------------------------------
  NORADRENALINE is one of the chemical messengers involved in mood.
  If its level is LOW, the person feels depressed and low-spirited.

  In this case ANTIDEPRESSANT DRUGS are used. They INHIBIT THE ENZYMES
  which catalyse the degradation of noradrenaline. If the enzyme is
  blocked, noradrenaline is not destroyed, its level rises, and the
  mood improves.

     Examples:   IPRONIAZID  ,  PHENELZINE

  (b) THE MILD TRANQUILISERS
  ---------------------------
     CHLORDIAZEPOXIDE  and  MEPROBAMATE
        - relatively mild tranquilisers, suitable for relieving tension

     EQUANIL
        - used to control depression and HYPERTENSION (high blood
          pressure)

  (c) THE BENZODIAZEPINES
  ------------------------
     VALIUM (diazepam)  and  SEROTONIN
        - used to relieve anxiety and as tranquilisers

  (d) THE BARBITURATES   *** hypnotics = sleep producing agents ***
  ----------------------
     Derivatives of BARBITURIC ACID. They are HYPNOTIC drugs, that is,
     they PRODUCE SLEEP.

     Examples:   VERONAL  ,  LUMINAL  ,  SECONAL
                 (also amytal, nembutal, and the general name
                  "barbiturates")
```

## 6.3 A one-look summary table

```
  +-------------------+----------------------------------------------+
  |  DRUG             |  WHAT IT IS USED FOR                         |
  +-------------------+----------------------------------------------+
  |  Noradrenaline    |  a NEUROTRANSMITTER (not a drug) - low level  |
  |                   |  causes depression                           |
  |  Iproniazid       |  ANTIDEPRESSANT - inhibits the enzyme that    |
  |  Phenelzine       |  degrades noradrenaline                      |
  |  Chlordiazepoxide |  MILD tranquiliser, relieves tension          |
  |  Meprobamate      |  MILD tranquiliser, relieves tension          |
  |  Equanil          |  depression and HYPERTENSION                  |
  |  Valium (diazepam)|  tranquiliser, relieves anxiety               |
  |  Serotonin        |  neurotransmitter / tranquiliser              |
  |  Veronal          |  BARBITURATE - hypnotic (sleep producing)     |
  |  Luminal          |  BARBITURATE - hypnotic                       |
  |  Seconal          |  BARBITURATE - hypnotic                       |
  +-------------------+----------------------------------------------+
```

> **TRAP:** Barbiturates are **hypnotics (sleep producing)** — do not call
> them analgesics. And remember the three names **VERONAL, LUMINAL, SECONAL**
> as a set. They rhyme, which makes them easy to remember together.

# ===============================================================
# TOPIC 7 — NEUROLOGICALLY ACTIVE DRUGS: ANALGESICS
# ===============================================================

## 7.1 Definition

```
  +-------------------------------------------------------------------+
  |  ANALGESICS are drugs which REDUCE OR ABOLISH PAIN WITHOUT        |
  |  causing impairment of consciousness, mental confusion,           |
  |  incoordination or paralysis, or some other disturbance of the    |
  |  nervous system.                                                  |
  +-------------------------------------------------------------------+

  They are of TWO types:

              ANALGESICS
                  |
        +---------+---------+
        |                   |
   NON-NARCOTIC        NARCOTIC
   (non-addictive)     (addictive - opioids)
        |                   |
   aspirin             morphine
   paracetamol         codeine
   (analgin,           heroin
    ibuprofen)         (all obtained from the opium poppy)
```

## 7.2 NON-NARCOTIC (non-addictive) analgesics

```
  EXAMPLES:  ASPIRIN , PARACETAMOL

  ASPIRIN is the most familiar drug in the world. Its extra uses are
  a favourite exam question:

  ASPIRIN:
     1. ANALGESIC     - relieves pain (headache, toothache, joint pain)
     2. ANTIPYRETIC   - brings down fever
     3. ANTI-INFLAMMATORY - reduces swelling, used in arthritis
     4. *** ANTIBLOOD-CLOTTING (antiplatelet) agent ***
           Because it prevents the blood from clotting, aspirin is
           given in LOW DOSES to patients to PREVENT HEART ATTACKS.

  Chemically aspirin is ACETYLSALICYLIC ACID.

  These drugs are EFFECTIVE in relieving skeletal pain such as that
  due to ARTHRITIS. They are NON-ADDICTIVE.
```

## 7.3 NARCOTIC (addictive) analgesics

```
  EXAMPLES:  MORPHINE , CODEINE , HEROIN
             (all narcotics obtained from OPIUM POPPY, and their
              synthetic modifications)

  These are called OPIATES.

  USES (when given in MEDICINAL DOSES):
     - relieve pain and produce sleep
     - used mainly for the relief of POST-OPERATIVE PAIN
     - CARDIAC PAIN
     - PAINS OF TERMINAL CANCER
     - CHILD BIRTH

  DANGER (when the dose is higher than medicinal):
     - stupor, coma, convulsions
     - in high enough dose, DEATH
     - and they are HABIT FORMING - they cause ADDICTION.

  HEROIN is the diacetyl derivative of morphine and is the most
  addictive of the three.
  CODEINE has a much lower analgesic power and is used in cough syrups.
```

### WORKED EXAMPLE 7.1

A patient has severe pain after a major surgery. Another has a mild headache.
Which class of analgesic is given to each and why?

```
  STEP 1   Severe post-operative pain  ->  NARCOTIC analgesic
           (e.g. morphine). Non-narcotics are not strong enough for
           this level of pain.

  STEP 2   Mild headache  ->  NON-NARCOTIC analgesic
           (e.g. aspirin or paracetamol).

  STEP 3   Why not give morphine for a headache?
           Because narcotics are HABIT FORMING and cause ADDICTION,
           and in higher doses produce stupor, coma and convulsions.
           They are reserved for pain that nothing else can control.
```

> **TRAP:** Do not confuse **ANALGESIC** (kills pain), **ANTIPYRETIC** (kills
> fever) and **ANTISEPTIC** (kills germs). Aspirin happens to be the first
> two, but they are different words with different meanings.

# ===============================================================
# TOPIC 8 — ANTIMICROBIALS
# ===============================================================

This is the biggest topic in the chapter and the one asked most often.

## 8.1 The words

```
  A MICROBE is a microorganism - bacteria, virus, fungi, or other
  parasites.

  DISEASES caused by microbes are called INFECTIOUS DISEASES.

  An ANTIMICROBIAL is any drug that tends to DESTROY or PREVENT THE
  DEVELOPMENT or INHIBIT THE PATHOGENIC ACTION of microbes.

  Antimicrobials come in THREE kinds:
         ANTIBIOTICS  ,  ANTISEPTICS  ,  DISINFECTANTS
```

## 8.2 ANTIBIOTICS

```
  +-------------------------------------------------------------------+
  |  ANTIBIOTICS are substances PRODUCED WHOLLY OR PARTLY BY CHEMICAL |
  |  SYNTHESIS, which in LOW CONCENTRATIONS inhibit the growth of, or |
  |  destroy, microorganisms by intervening in their metabolic        |
  |  processes.                                                       |
  |                                                                   |
  |  Originally, an antibiotic was a substance produced by ONE         |
  |  microorganism that selectively inhibits the growth of ANOTHER.    |
  +-------------------------------------------------------------------+
```

### Bactericidal versus bacteriostatic — a guaranteed 2-mark question

```
  +-----------------------+-----------------------------------------+
  |  BACTERICIDAL         |  KILLS the bacteria outright            |
  |                       |  Examples: PENICILLIN, AMINOGLYCOSIDES, |
  |                       |            OFLOXACIN                    |
  +-----------------------+-----------------------------------------+
  |  BACTERIOSTATIC       |  Only STOPS THE GROWTH (inhibits        |
  |                       |  multiplication); it does not kill      |
  |                       |  Examples: ERYTHROMYCIN, TETRACYCLINE,  |
  |                       |            CHLORAMPHENICOL              |
  +-----------------------+-----------------------------------------+

  MEMORY HOOK:
      "-CIDAL" comes from the Latin for KILL (like sui-CIDE, pesti-CIDE)
      "-STATIC" comes from STATIONARY - it just stands still
```

### Spectrum of an antibiotic — the second guaranteed question

```
  +-------------------+------------------------------------------------+
  |  BROAD SPECTRUM   |  Effective against SEVERAL DIFFERENT TYPES of  |
  |                   |  harmful bacteria (both Gram positive AND      |
  |                   |  Gram negative).                              |
  |                   |  Examples: CHLORAMPHENICOL, AMPICILLIN,        |
  |                   |            AMOXICILLIN, TETRACYCLINE,          |
  |                   |            OFLOXACIN, VANCOMYCIN               |
  +-------------------+------------------------------------------------+
  |  NARROW SPECTRUM  |  Effective mainly against GRAM POSITIVE OR     |
  |                   |  GRAM NEGATIVE bacteria - one group only.     |
  |                   |  Examples: PENICILLIN G, STREPTOMYCIN          |
  +-------------------+------------------------------------------------+
  |  LIMITED SPECTRUM |  Effective against a SINGLE ORGANISM or a      |
  |                   |  single disease.                              |
  |                   |  Example: DYSIDAZIRINE                         |
  +-------------------+------------------------------------------------+

  Picture it as a torch beam:

      BROAD SPECTRUM      \   |   /      lights up the whole room
                           \  |  /
                            \ | /
                             \|/
                              *

      NARROW SPECTRUM         ||          lights up one corner
                              ||
                              **

      LIMITED SPECTRUM        |           lights up one object
                              *
```

### The story of penicillin — worth knowing for a 4-mark answer

```
  1929  ALEXANDER FLEMING noticed that a mould (Penicillium notatum)
        growing accidentally on his culture plate had killed the
        bacteria around it. He named the active substance PENICILLIN.

  Later CHAIN and FLOREY isolated and purified it, and it came into
  clinical use during the SECOND WORLD WAR, where it saved enormous
  numbers of lives from infected wounds.

  Fleming, Chain and Florey shared the NOBEL PRIZE for it.

  PENICILLIN today:
     - It is NARROW SPECTRUM (penicillin G).
     - It is BACTERICIDAL.
     - It is highly EFFECTIVE against Gram positive bacteria.
     - Some patients are ALLERGIC to it, so it must be given carefully.
     - It can be made SEMI-SYNTHETIC by changing the side chain:
          AMPICILLIN and AMOXICILLIN are semi-synthetic modifications
          of penicillin, and both are BROAD SPECTRUM.
```

### The individual antibiotics you must know

```
  +------------------+-----------------------------------------------+
  |  ANTIBIOTIC      |  THE FACT THE EXAMINER WANTS                  |
  +------------------+-----------------------------------------------+

  |  STREPTOMYCIN    |  NARROW spectrum; used for TUBERCULOSIS (TB)  |
  |  TETRACYCLINE    |  BROAD spectrum; BACTERIOSTATIC               |

  |  DYSIDAZIRINE    |  LIMITED spectrum                             |
  +------------------+-----------------------------------------------+
```

### Sulpha drugs

```
  SULPHA DRUGS (SULPHONAMIDES) are antibacterial drugs which contain
  the group   -SO2 - NH -   . They were the first effective

  Examples:  SULPHANILAMIDE , SULPHAPYRIDINE , SULPHADIAZINE ,
```

## 8.3 ANTISEPTICS AND DISINFECTANTS

```
  +-------------------------------------------------------------------+
  |  ANTISEPTICS are chemicals which either KILL or PREVENT THE       |
  |  GROWTH of microorganisms and are APPLIED TO LIVING TISSUES -     |
  |  wounds, cuts, ulcers and diseased skin surfaces.                 |
  |                                                                   |
  |  DISINFECTANTS are chemicals which kill microorganisms but are    |
  |  APPLIED TO INANIMATE (non-living) OBJECTS - floors, drainage     |
  |  systems, instruments. They are not safe for living tissue.       |
  +-------------------------------------------------------------------+
```

### The examples

```
  ANTISEPTICS
     DETTOL          - a mixture of CHLOROXYLENOL and TERPINEOL
     BITHIONOL       - added to soaps to give them ANTISEPTIC properties
     TINCTURE OF IODINE - 2-3 % solution of iodine in
                          alcohol-water; a powerful antiseptic
     IODOFORM        - used as an antiseptic for wounds
     BORIC ACID      - dilute aqueous solution, weak antiseptic for eyes
     FURACIN, SOFRAMYCIN - antibiotics also used as antiseptic creams
     HYDROGEN PEROXIDE, dilute - antiseptic

  DISINFECTANTS
     1 % PHENOL solution
     CHLORINE, 0.2 to 0.4 ppm in water - used to sterilise drinking water
     SULPHUR DIOXIDE in very low concentrations
```

### *** THE PHENOL POINT *** — asked over and over

```
  +------------------------------------------------------------------+
  |                                                                  |
  |   0.2 %  solution of phenol   ->   ANTISEPTIC                    |
  |   1.0 %  solution of phenol   ->   DISINFECTANT                  |
  |                                                                  |
  |   THE SAME SUBSTANCE. Only the CONCENTRATION changes the name.    |
  |                                                                  |
  +------------------------------------------------------------------+

  Same idea for CHLORINE and for SULPHUR DIOXIDE:
     in LOW concentration they are antiseptic / harmless,
     in HIGH concentration they are disinfectant / toxic.
```

### WORKED EXAMPLE 8.1

Give one point of difference between an antiseptic and a disinfectant, and give
one substance that is both.

```
  STEP 1   Difference:
              ANTISEPTIC   - applied to LIVING tissue (wounds, skin)
              DISINFECTANT - applied to NON-LIVING objects
                             (floors, instruments)

  STEP 2   Both:
              PHENOL. 0.2 % phenol is an antiseptic;
                      1 % phenol is a disinfectant.

  ANSWER:  Phenol acts as an antiseptic in dilute (0.2 %) solution and
           as a disinfectant in concentrated (1 %) solution.
```

```
  +-------------------------------------------------------------------+

  |  They are the chemicals of BIRTH CONTROL PILLS.                   |
  |                                                                   |
  |  They are essentially mixtures of SYNTHETIC ESTROGEN and          |
```

# TOPIC 9 — CHEMICALS IN FOOD: ARTIFICIAL SWEETENING AGENTS
# ===============================================================

## 9.1 Why we need them

```
  Ordinary sugar (SUCROSE, cane sugar) gives energy - which means
  CALORIES. Two groups of people cannot afford those calories:

       DIABETIC patients  (sugar raises blood glucose)
       People who need to control their WEIGHT

  ARTIFICIAL SWEETENERS are chemicals that TASTE SWEET but are
  NOT metabolised in the body, so they give NO calories.
```

## 9.2 The four you must know — with numbers

```
  +----------------+------------+---------------------------------------+
  |  SWEETENER     | SWEETNESS  |  THE FACTS TO QUOTE                   |
  |                | vs CANE    |                                       |
  |                | SUGAR      |                                       |
  +----------------+------------+---------------------------------------+
  |  SACCHARIN     |  550 x     |  The FIRST artificial sweetener.      |
  |                |            |  Marketed as its SOLUBLE SODIUM SALT. |
  |                |            |  Completely INERT and HARMLESS - it   |
  |                |            |  is excreted from the body unchanged. |
  |                |            |  Of great value to DIABETIC patients  |
  |                |            |  and those who need to control        |
  |                |            |  calorie intake.                      |
  +----------------+------------+---------------------------------------+
  |  ASPARTAME     |  100 x     |  The MOST SUCCESSFUL and widely used. |
  |                |            |  It is the METHYL ESTER OF A DIPEPTIDE|
  |                |            |  (aspartic acid + phenylalanine).     |
  |                |            |  *** LIMITATION: it is UNSTABLE AT    |
  |                |            |  COOKING TEMPERATURE - it decomposes. |
  |                |            |  So its use is LIMITED TO COLD FOODS  |
  |                |            |  AND SOFT DRINKS ONLY.                |
  +----------------+------------+---------------------------------------+
  |  ALITAME       |  2000 x    |  A HIGH POTENCY sweetener, more stable |
  |                |            |  than aspartame.                      |
  |                |            |  *** LIMITATION: it is DIFFICULT TO   |
  |                |            |  CONTROL THE SWEETNESS of the food    |
  |                |            |  while using it, because it is so     |
  |                |            |  powerful.                            |
  +----------------+------------+---------------------------------------+
  |  SUCRALOSE     |  600 x     |  A TRICHLORO DERIVATIVE OF SUCROSE.   |
  |                |            |  Its APPEARANCE AND TASTE ARE LIKE    |
  |                |            |  SUGAR.                               |
  |                |            |  It is STABLE AT COOKING TEMPERATURE. |
  |                |            |  It does NOT provide calories.        |
  +----------------+------------+---------------------------------------+

  ORDER OF SWEETNESS (smallest to largest) - learn this order:

       ASPARTAME (100)  <  SACCHARIN (550)  <  SUCRALOSE (600)
                                            <  ALITAME (2000)

  MEMORY SENTENCE:  "A Sweet Sugar Alternative"
                     A(100) S(550) S(600) A(2000)
```

### WORKED EXAMPLE 9.1

A company wants a sweetener for a **baked cake** and another for a **cold soft
drink**. Which would you choose and why?

```
  STEP 1   Baked cake means HIGH TEMPERATURE.
           Aspartame decomposes at cooking temperature, so it is OUT.

  STEP 2   Sucralose is STABLE at cooking temperature and tastes like
           sugar.
           ANSWER for the cake:  SUCRALOSE.

  STEP 3   A soft drink is cold and is not heated.
           ANSWER for the drink:  ASPARTAME (the most widely used
           sweetener in soft drinks worldwide).
```

> **TRAP:** The most common mistake is writing that aspartame is "unstable"
> without saying **at cooking temperature**, and forgetting to add **so it is
> used only in cold foods and soft drinks**. That second half is the mark.

# TOPIC 10 — CHEMICALS IN FOOD: PRESERVATIVES AND ANTIOXIDANTS
# ===============================================================

## 10.1 Food preservatives

```
  +-------------------------------------------------------------------+
  |  FOOD PRESERVATIVES are chemicals which PREVENT THE SPOILAGE OF   |
  |  FOOD due to MICROBIAL GROWTH.                                    |
  +-------------------------------------------------------------------+

  THE TRADITIONAL ONES (used for hundreds of years)
       TABLE SALT   - pickles, meat, fish
       SUGAR        - jams, jellies, squashes
       VEGETABLE OILS - pickles

  THE MODERN CHEMICAL ONES
       SODIUM BENZOATE     C6H5COONa
            - the MOST COMMON one
            - it is used in SMALL CONCENTRATIONS
            - it is METABOLISED IN THE BODY, so it is safe

       SALTS OF SORBIC ACID
       SALTS OF PROPANOIC ACID
            - both are also used as food preservatives
```

```
  HOW THEY WORK, in one line:
       Salt and sugar draw water OUT of microbial cells by osmosis,
       so the microbes cannot grow.
       Sodium benzoate and the other salts are directly toxic to
       microorganisms in the acidic conditions of food.
```

## 10.2 Antioxidants

```
  +-------------------------------------------------------------------+
  |  ANTIOXIDANTS are compounds which RETARD THE OXIDATION of food.   |
  |  They are MORE REACTIVE TOWARDS OXYGEN than the food is, so they  |
  |  react with the oxygen first and protect the food.                |
  |                                                                   |
  |  EXAMPLES:                                                        |
  |     BHA   -  butylated hydroxyanisole                             |
  |     BHT   -  butylated hydroxytoluene                             |
  |     Sulphur dioxide and sulphite salts                            |
  |     Vitamin E (a natural antioxidant)                             |
  +-------------------------------------------------------------------+

  WHY THEY MATTER:  fats and oils in food react with oxygen in air and
  turn RANCID (bad smell, bad taste). BHA and BHT added to butter
  increase its storage life from months to YEARS.

  BHA + BHT together are MORE EFFECTIVE than either one alone.
```

## 10.3 Edible colours and flavours (know them briefly)

```
  EDIBLE COLOURS
      Added to make food look attractive.
      They are ESTERS-based or approved synthetic dyes, and must be
      permitted food-grade colours only. Non-permitted dyes are
      harmful. Natural examples: turmeric (yellow), saffron, caramel.

  FLAVOURS (FLAVOURING AGENTS)
      Added to give or improve the taste and smell of food.
      Many are ESTERS - the same esters that give fruits their smell.
      Examples: vanilla essence, esters of low molecular mass,
      and natural extracts.

  Both are used in SMALL, LEGALLY PERMITTED quantities only.
```

# TOPIC 11 — CLEANSING AGENTS: SOAPS
# ===============================================================

## 11.1 What a soap is

```
  +-------------------------------------------------------------------+
  |  SOAPS are the SODIUM or POTASSIUM SALTS OF LONG CHAIN FATTY      |
  |  ACIDS such as stearic acid, oleic acid and palmitic acid.        |
  |                                                                   |
  |  Example:  SODIUM STEARATE     C17H35COO- Na+                     |
  |            SODIUM PALMITATE    C15H31COO- Na+                     |
  |            SODIUM OLEATE       C17H33COO- Na+                     |
  +-------------------------------------------------------------------+

  Only SODIUM and POTASSIUM soaps are soluble in water and can be used
  for cleaning.
```

## 11.2 SAPONIFICATION — how soap is made

```
  Soap is made by HEATING A FAT OR OIL (a glyceryl ester of a long
  chain fatty acid) WITH AQUEOUS SODIUM HYDROXIDE.

  This reaction is called SAPONIFICATION.

  THE EQUATION - learn to write it:

      CH2 - OOC - R                            CH2 - OH
       |                                        |
      CH  - OOC - R   +  3 NaOH  ----------->  CH  - OH   +  3 RCOONa
       |                                        |
      CH2 - OOC - R                            CH2 - OH

       fat or oil        sodium hydroxide      GLYCEROL      SOAP
      (glyceryl ester)                                     (sodium salt
                                                            of fatty acid)

  In words:
      FAT / OIL  +  NaOH  --(heat)-->  SOAP  +  GLYCEROL

  The soap is then precipitated out as a solid by adding SODIUM
  CHLORIDE to the mixture. This is called SALTING OUT.
  The glycerol is recovered separately and used elsewhere.
```

> **TRAP:** Saponification produces **glycerol as a by-product** — that word
> earns a mark and students always leave it out. Also do not forget the
> **3 NaOH**, because a fat has three ester links.

## 11.4 *** THE CLEANSING ACTION OF SOAP *** — the micelle

This is the most-drawn diagram in the chapter. Learn to draw it.

### Step 1 — a soap molecule has two different ends

```
      SODIUM STEARATE     CH3-(CH2)16 - COO-  Na+
                          <-------------->  <------->
                            the LONG TAIL   the HEAD

  +--------------------------------------------------------------+
  |                                                              |
  |  THE TAIL   :  a long HYDROCARBON chain                      |
  |                NON-POLAR ,  WATER-HATING (HYDROPHOBIC) ,     |
  |                but OIL-LOVING (LIPOPHILIC)                   |
  |                                                              |
  |  THE HEAD   :  the -COO- Na+ group                           |
  |                POLAR / IONIC ,  WATER-LOVING (HYDROPHILIC)   |
  |                                                              |
  +--------------------------------------------------------------+

  Drawn as a tadpole:

              ~~~~~~~~~~~~~~~~~(O)
              <-- tail -->    head

              hates water     loves water
              loves grease
```

### Step 2 — the soap surrounds the grease and forms a MICELLE

```
  Dirt on cloth is usually held there by OIL or GREASE.
  Water alone cannot remove it, because oil and water do not mix.

  When soap is added:

     - the TAILS bury themselves in the drop of oil (they love oil)
     - the HEADS stick outwards into the water (they love water)

  The result is a ball called a MICELLE.


                          O   O   O
                       O  |   |   |  O
                     O  \ |   |   | /  O
                        \ \   |   / /
                   O ----\ \  |  / /---- O
                          \ \ | / /
                    O -----\\\|///----- O
                       ,----[ O I L ]----,        <-- the greasy dirt
                    O -----///|\\\----- O             trapped inside
                          / / | \ \
                   O ----/ /  |  \ \---- O
                        / /   |   \ \
                     O  / |   |   | \  O
                       O  |   |   |  O
                          O   O   O

              O = the WATER-LOVING (hydrophilic) HEAD, outside
              |  = the OIL-LOVING (hydrophobic) TAIL, pointing inwards
```

### Step 3 — the dirt is washed away

```
  1. Soap dissolves in water and the molecules arrange themselves
     with their tails towards any oil or grease.

  2. The tails bore into the oily dirt; the heads stay in the water.

  3. The dirt is completely enclosed in a MICELLE - a ball with an
     oily centre and an IONIC OUTER SURFACE.

  4. Because the outside of the micelle is negatively charged,
     micelles REPEL ONE ANOTHER and cannot join up again.
     They stay dispersed as an EMULSION in the water.

  5. Agitation (rubbing, or the washing machine) lifts the micelle off
     the cloth, and RINSING WITH WATER carries the whole micelle away.

  The cloth is now clean.
```

### WORKED EXAMPLE 11.1

Why can water alone not remove greasy dirt, but soapy water can?

```
  STEP 1   Grease is NON-POLAR. Water is POLAR. "Like dissolves like",
           so water cannot wet or dissolve grease at all.

  STEP 2   A soap molecule has BOTH kinds of end - a non-polar
           hydrocarbon tail and a polar ionic head.

  STEP 3   The tail dissolves in the grease while the head stays in
           the water. The soap therefore acts as a BRIDGE between the
           two liquids that would otherwise never mix.

  STEP 4   The grease is packed inside a MICELLE whose outside is
           ionic, so the whole ball is now water-soluble and washes
           away.

  ANSWER:  Soap works because one molecule can hold on to grease at one
           end and to water at the other end.
```

## 11.5 THE DISADVANTAGE OF SOAP — hard water

```
  HARD WATER contains dissolved CALCIUM and MAGNESIUM salts.

  When soap is used in hard water, the sodium of the soap is exchanged
  for calcium or magnesium, and the products are INSOLUBLE.

  THE EQUATIONS - write at least one of them:

     2 C17H35COO- Na+  +  Ca2+   ---->  (C17H35COO)2 Ca  +  2 Na+
        (soap, soluble)                  (calcium stearate,
                                          INSOLUBLE - a white curdy
                                          precipitate = SCUM)

     2 C17H35COO- Na+  +  Mg2+   ---->  (C17H35COO)2 Mg  +  2 Na+
                                         (magnesium stearate,
                                          INSOLUBLE)

  THE CONSEQUENCES (all three are marks):
     1. The soap is WASTED - it is used up forming scum instead of
        cleaning.
     2. NO LATHER forms until all the Ca2+ and Mg2+ has been removed.
     3. The insoluble SCUM STICKS TO THE CLOTH and spoils it.

  ALSO: soap cannot be used in ACIDIC water, because the acid converts
  the soap back into the free fatty acid, which is insoluble and useless
  as a cleanser:
        C17H35COO- Na+  +  H+  ---->  C17H35COOH  +  Na+
```

# ===============================================================
# TOPIC 12 — SYNTHETIC DETERGENTS
# ===============================================================

## 12.1 Why they were invented

```
  Synthetic detergents were made to do everything soap does, but
  WITHOUT the hard-water problem.

  +-------------------------------------------------------------------+
  |  SYNTHETIC DETERGENTS are cleansing agents which have ALL THE     |
  |  PROPERTIES OF SOAPS, but which ACTUALLY CONTAIN NO SOAP.         |
  |                                                                   |
  |  They can be used BOTH IN SOFT AND IN HARD WATER, because their   |
  |  calcium and magnesium salts are SOLUBLE, so they still LATHER.   |
  +-------------------------------------------------------------------+
```

## 12.2 THE THREE TYPES

### TYPE 1 — ANIONIC DETERGENTS

```
  Called ANIONIC because the ANION (the negative part) of the molecule
  is the part that does the cleaning.

  MADE FROM:
     (a) SODIUM SALTS OF SULPHONATED LONG CHAIN ALCOHOLS
     (b) SODIUM SALTS OF SULPHONATED LONG CHAIN HYDROCARBONS
         (alkyl benzene sulphonates)

  EXAMPLE 1 - SODIUM LAURYL SULPHATE

     Step 1: a long chain alcohol is treated with conc. H2SO4
     Step 2: the resulting alkyl hydrogensulphate is neutralised
             with NaOH

        CH3-(CH2)10-CH2-OH   --(conc. H2SO4)-->
                                     CH3-(CH2)10-CH2-O-SO3H
        lauryl alcohol                lauryl hydrogensulphate

        CH3-(CH2)10-CH2-O-SO3H  +  NaOH  ---->
                        CH3-(CH2)10-CH2-O-SO3- Na+  +  H2O
                        SODIUM LAURYL SULPHATE
                        (an anionic detergent)

  EXAMPLE 2 - SODIUM DODECYLBENZENE SULPHONATE (an ABS)

        CH3-(CH2)11 - C6H4 - SO3- Na+

  USES OF ANIONIC DETERGENTS:
     - in HOUSEHOLD WORK (washing clothes and dishes)
     - *** in TOOTHPASTE ***  (sodium lauryl sulphate is the foaming
       agent in almost every toothpaste)
```

### TYPE 2 — CATIONIC DETERGENTS

```
  Called CATIONIC because the CATION (the positive part) does the
  cleaning.

  THEY ARE:  QUATERNARY AMMONIUM SALTS of amines with acetates,
             chlorides or bromides as the anion.
             The cation carries a LONG HYDROCARBON CHAIN and a
             POSITIVE CHARGE ON THE NITROGEN ATOM.

  EXAMPLE - CETYLTRIMETHYLAMMONIUM BROMIDE

                          CH3
                           |
        CH3-(CH2)15 - N+ - CH3      Br-
                           |
                          CH3

  PROPERTIES AND USES:
     - they have GERMICIDAL PROPERTIES
     - used in HAIR CONDITIONERS
     - *** they are EXPENSIVE, so their use is LIMITED ***
```

### TYPE 3 — NON-IONIC DETERGENTS

```
  These contain NO IONS AT ALL.

  HOW MADE: by the reaction of a LONG CHAIN ALCOHOL with
            POLYETHYLENEGLYCOL - the product is an ETHER, not a salt.

        CH3(CH2)16CH2-O-(CH2CH2O)n-CH2CH2OH

  ANOTHER EXAMPLE:  a monoester of a polyhydric alcohol such as
                    GLYCEROL with a fatty acid - e.g. GLYCERYL
                    STEARATE, used in LIQUID DISHWASHING DETERGENTS.

  USES:
     - LIQUID DISHWASHING DETERGENTS
     - they clean by the same emulsifying action as soap
```

## 12.4 WHY DETERGENTS WORK IN HARD WATER

```
  SOAP        +  Ca2+ / Mg2+   ->  INSOLUBLE calcium / magnesium
                                    stearate  =  SCUM  =  no lather

  DETERGENT   +  Ca2+ / Mg2+   ->  the calcium and magnesium salts of
                                    the sulphonic acid are STILL
                                    SOLUBLE  =  lather is still formed

  ONE LINE ANSWER:
      Detergents lather in hard water because their calcium and
      magnesium salts are SOLUBLE in water, unlike those of soap.
```

## 12.5 *** THE PROBLEM OF BIODEGRADABILITY ***

```
  Detergents solved the hard-water problem but created a new one:
  POLLUTION.

  +-------------------------------------------------------------------+
  |                                                                   |
  |  A detergent with a STRAIGHT hydrocarbon chain                    |
  |        ->  bacteria can degrade it easily                         |
  |        ->  it is BIODEGRADABLE                                    |
  |        ->  no pollution                                           |
  |                                                                   |
  |  A detergent with a HIGHLY BRANCHED hydrocarbon chain             |
  |        ->  bacteria CANNOT degrade it easily                      |
  |        ->  it is NON-BIODEGRADABLE                                |
  |        ->  it accumulates and causes POLLUTION                    |
  |                                                                   |
  +-------------------------------------------------------------------+

  A picture of the two:

    BIODEGRADABLE (straight chain)
        CH3-CH2-CH2-CH2-CH2-CH2-CH2-CH2-CH2-CH2-CH2-CH2-C6H4-SO3Na
        sodium 4-(1-dodecyl)benzenesulphonate

    NON-BIODEGRADABLE (branched chain)
                CH3   CH3   CH3   CH3   CH3
                 |     |     |     |     |
        CH3 - C - CH2- C - CH2- C - CH2- C - C6H4 - SO3Na
                 |     |     |     |
                CH3   CH3    H     H
        sodium 4-(1,3,5,7-tetramethyloctyl)benzenesulphonate

  WHAT GOES WRONG:
     Non-biodegradable detergents are not broken down in sewage
     treatment plants. They flow into rivers and lakes, where they
     FOAM and pollute the water.

  THE REMEDY:
     Manufacture detergents with STRAIGHT, UNBRANCHED chains, which
     bacteria can break down.
```

### WORKED EXAMPLE 12.1

Which of these two detergents would you expect to be biodegradable, and why?

```
  (A)  CH3-(CH2)11-C6H4-SO3Na
  (B)  a molecule with five methyl branches on the chain

  STEP 1   Look only at the SHAPE of the hydrocarbon chain.

  STEP 2   (A) has an unbranched, straight chain of 12 carbons.
               Bacteria attack the chain end and work along it, so a
               straight chain is broken down easily.

  STEP 3   (B) is highly branched. The branches physically get in the
               way of the bacterial enzymes, so degradation is slow or
               impossible.

  ANSWER:  (A) is BIODEGRADABLE. (B) is NON-BIODEGRADABLE and causes
           water pollution.
```

> **TRAP:** Students write "detergent is bad for the environment." Not enough.
> You must say **branched chain = non-biodegradable = pollution**, and
> **straight chain = biodegradable = safe**. The word *branched* is the mark.
