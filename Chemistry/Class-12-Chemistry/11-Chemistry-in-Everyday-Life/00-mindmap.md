**Almost every year: 1-2 very short answers (2M) + very often 1 short answer (4M)**

This is a **PURE MEMORY chapter**. There is not a single formula, not a single
numerical, not a single derivation in the whole chapter. Every question is
**direct recall** — "what is an antacid", "give an example of an antiseptic",
"name two artificial sweeteners".

**Be blunt with yourself: this is one of the CHEAPEST sources of marks in the
entire Chemistry paper for a weak student.** You do not need to be clever. You
need to sit down for two evenings with one big table of drug names and learn it.
Anyone who can memorise a cricket team can score full marks here.

## THE 60-SECOND VERSION

```
  This chapter answers three questions about ordinary life:

  1.  WHAT IS IN A MEDICINE, AND HOW DOES IT WORK?
         A DRUG is a low molecular mass chemical that interacts with a
         big biological molecule (a TARGET) and produces a response.
         Targets are of two kinds:
              ENZYMES     -> drugs INHIBIT them
              RECEPTORS   -> drugs act as AGONISTS or ANTAGONISTS
         Then a list of classes: antacids, antihistamines, tranquilisers,
         analgesics, antimicrobials, antifertility drugs.

  2.  WHAT IS ADDED TO OUR FOOD?
         Artificial sweeteners (sugar without calories)
         Preservatives (stop microbes)
         Antioxidants (stop oxidation / rancidity)
         Colours and flavours.

  3.  HOW DOES SOAP CLEAN?
         Soap = sodium/potassium salt of a long chain fatty acid.
         One end LOVES water, the other end LOVES grease.
         It surrounds the dirt in a ball called a MICELLE and lifts it off.
         Soap FAILS in hard water; synthetic DETERGENTS do not.
```

**Almost every question in this chapter is "define X and give two examples."**
So learn every definition together with two examples. The example carries
half the mark, every single time.

## THE ONE BOX THAT UNLOCKS THE WHOLE CHAPTER

There is no formula in this chapter, so instead here is the single frame that
every "how does it work" question fits into:

```
  +---------------------------------------------------------------+
  |                                                               |
  |   A DRUG WORKS BY BINDING TO A BIOLOGICAL TARGET               |
  |                                                               |
  |        DRUG   +   TARGET   ---->   RESPONSE                   |
  |     (small)      (macro-                                      |
  |                  molecule)                                    |
  |                                                               |
  |   THE TARGET IS ONE OF TWO THINGS:                            |
  |                                                               |
  |   1. AN ENZYME  (a catalyst)                                  |
  |         drug BLOCKS it  ->  called an INHIBITOR               |
  |            - COMPETITIVE      : sits in the ACTIVE SITE       |
  |            - NON-COMPETITIVE  : sits in the ALLOSTERIC SITE   |
  |              (allosteric)       and changes the shape of      |
  |                                 the active site               |
  |                                                               |
  |   2. A RECEPTOR (a message-catcher in the cell membrane)      |
  |         drug MIMICS the natural messenger  ->  AGONIST        |
  |         drug BLOCKS the natural messenger  ->  ANTAGONIST     |
  |                                                               |
  +---------------------------------------------------------------+

  THERAPEUTIC INDEX = a measure of the safety margin of a drug

        the ratio of the dose that is TOXIC
        to the dose that is THERAPEUTIC (effective)

        HIGH therapeutic index  ->  SAFE drug (big gap)
        LOW  therapeutic index  ->  DANGEROUS drug (small gap)
```

## THE FOUR CLASSIFICATIONS OF DRUGS ON ONE CARD

```
  +--------------------------+---------------------------------------------+
  |  1. ON PHARMACOLOGICAL   |  Grouped by the EFFECT on the body.         |
  |     EFFECT               |  Most useful to a DOCTOR.                   |
  |                          |  e.g. ANALGESICS - all pain killers         |
  |                          |       ANTISEPTICS - all kill microorganisms |
  +--------------------------+---------------------------------------------+
  |  2. ON DRUG ACTION       |  Grouped by the BIOCHEMICAL PROCESS they    |
  |                          |  act on.                                    |
  |                          |  e.g. ANTIHISTAMINES - all inhibit the      |
  |                          |       action of the compound histamine      |
  +--------------------------+---------------------------------------------+
  |  3. ON CHEMICAL          |  Grouped by a COMMON STRUCTURAL FEATURE.    |
  |     STRUCTURE            |  Often similar pharmacological activity.    |
  |                          |  e.g. SULPHONAMIDES (sulpha drugs) - all    |
  |                          |       carry the -SO2NH- group               |
  +--------------------------+---------------------------------------------+
  |  4. ON MOLECULAR         |  Grouped by the biomolecule they attack.    |
  |     TARGETS              |  Most useful to a MEDICINAL CHEMIST.        |
  |                          |  e.g. drugs acting on ENZYMES, drugs        |
  |                          |       acting on RECEPTORS, on nucleic acids |
  +--------------------------+---------------------------------------------+

  MEMORY HOOK for the four bases:   "P A S T"
        P - Pharmacological effect
        A - Action (drug action)
        S - Structure (chemical structure)
        T - Targets (molecular targets)
```

## THE THREE "ANTI-MICROBE" WORDS THAT GET CONFUSED EVERY YEAR

```
  +---------------+------------------------+--------------------------------+
  |  WORD         |  APPLIED TO            |  EXAMPLES                      |
  +---------------+------------------------+--------------------------------+
  |  ANTIBIOTIC   |  Taken INTO the body   |  penicillin, chloramphenicol,  |
  |               |  (swallowed/injected). |  streptomycin, tetracycline,   |
  |               |  Produced by micro-    |  ofloxacin                     |
  |               |  organisms, kills or   |                                |
  |               |  stops other microbes. |                                |
  +---------------+------------------------+--------------------------------+
  |  ANTISEPTIC   |  Applied to LIVING     |  dettol (chloroxylenol +       |
  |               |  tissue - wounds,      |  terpineol), bithionol in      |
  |               |  cuts, skin, ulcers.   |  soaps, tincture of iodine,    |
  |               |  Does NOT harm you.    |  iodoform, boric acid (dilute),|
  |               |                        |  0.2% phenol                   |
  +---------------+------------------------+--------------------------------+
  |  DISINFECTANT |  Applied to NON-LIVING |  1% phenol, chlorine (0.2 to   |
  |               |  objects - floors,     |  0.4 ppm in water), SO2 in     |
  |               |  drains, instruments.  |  very low concentration        |
  |               |  TOO HARSH for skin.   |                                |
  +---------------+------------------------+--------------------------------+

  *** THE PHENOL POINT — asked again and again ***

        0.2 % solution of phenol  ->  ANTISEPTIC
        1.0 % solution of phenol  ->  DISINFECTANT

  SAME CHEMICAL. Only the CONCENTRATION decides which name it gets.
  If a question mentions phenol and concentration, this is the answer.
```
