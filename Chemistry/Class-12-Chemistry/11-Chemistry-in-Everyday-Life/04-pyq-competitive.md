# =====================================================
# PATTERN 1 — NAME THE CLASS OF A GIVEN DRUG
# =====================================================

The single most common question shape from this chapter.

### Q1. Ranitidine is a
(a) analgesic (b) antacid (c) antiseptic (d) tranquiliser

**ANSWER: (b)**
```
  Ranitidine (Zantac) is a HISTAMINE H2 RECEPTOR BLOCKER.
  It stops the stomach releasing acid, so it is an ANTACID.
  Cimetidine (Tagamet) is the other one.
```

---

### Q2. Terfenadine is used as
(a) an antibiotic (b) an antifertility drug (c) an antihistamine (d) an antacid

**ANSWER: (c)**
```
  Terfenadine (Seldane) and brompheniramine (Dimetapp) are
  ANTIHISTAMINES - H1 receptor antagonists.
```

---

### Q3. Equanil is
(a) an analgesic (b) a tranquiliser (c) an antiseptic (d) a sweetener

**ANSWER: (b)**
```
  Equanil is a TRANQUILISER used to control DEPRESSION and
  HYPERTENSION.
```

---

### Q4. Which of the following is a narcotic analgesic?
(a) aspirin (b) paracetamol (c) morphine (d) ibuprofen

**ANSWER: (c)**
```
  NARCOTIC (addictive)   : morphine, codeine, heroin - from opium poppy
  NON-NARCOTIC           : aspirin, paracetamol, ibuprofen, analgin
```

> **SHORTCUT:** If the name comes from the **opium poppy** family
> (morphine, codeine, heroin), it is **narcotic and addictive**.
> Everything else in the syllabus is non-narcotic.

---

### Q5. Norethindrone is
(a) an antibiotic (b) an antiseptic (c) an antifertility drug (d) an antioxidant

**ANSWER: (c)**
```
  NORethindrone   -> a synthetic PROgesterone derivative
  ethynylESTRADIOL -> a synthetic ESTRogen derivative
  Both are ANTIFERTILITY drugs (birth control pills).
```

---

### Q6. Bithionol is added to soap to give it
(a) transparency (b) antiseptic properties (c) a good lather (d) hardness

**ANSWER: (b)**
```
  BITHIONOL is an ANTISEPTIC added to soaps -> MEDICATED SOAP.
  Do not confuse with:
     ROSIN    -> added to shaving soap so it lathers well
     GLYCEROL -> added to shaving soap to prevent rapid drying
     ETHANOL  -> used to make transparent soap
```

---

### Q7. Chloroxylenol and terpineol are the constituents of
(a) dettol (b) tincture of iodine (c) iodoform (d) aspirin

**ANSWER: (a)**
```
  DETTOL = CHLOROXYLENOL + TERPINEOL. It is an ANTISEPTIC.
```

---

### Q8. Veronal and luminal belong to which class?
(a) antibiotics (b) barbiturates (c) sulpha drugs (d) analgesics

**ANSWER: (b)**
```
  VERONAL, LUMINAL and SECONAL are BARBITURATES - derivatives of
  barbituric acid - and are HYPNOTIC (sleep producing) tranquilisers.
```

> **SHORTCUT:** the "-al" ending trio **veron-AL, lumin-AL, secon-AL**
> always means barbiturate.

---

### Q9. Iproniazid and phenelzine are used as
(a) antidepressants (b) antibiotics (c) antihistamines (d) preservatives

**ANSWER: (a)**
```
  They are ANTIDEPRESSANTS. They INHIBIT THE ENZYMES that degrade
  NORADRENALINE, so its level rises and the mood improves.
```

---

### Q10. Sodium benzoate is used as
(a) an antioxidant (b) a food preservative (c) a sweetener (d) a detergent

**ANSWER: (b)**
```
  Sodium benzoate C6H5COONa is the MOST COMMON FOOD PRESERVATIVE.
  Antioxidants are BHA and BHT - do not swap them.
```

# PATTERN 2 — ANTISEPTIC vs DISINFECTANT
# =====================================================

### Q11. A substance applied to living tissue to kill microorganisms is called
(a) a disinfectant (b) an antiseptic (c) an antibiotic (d) an antacid

**ANSWER: (b)**
```
  ANTISEPTIC    -> LIVING tissue
  DISINFECTANT  -> NON-LIVING objects
```

---

### Q12. Phenol acts as a disinfectant at a concentration of
(a) 0.2 % (b) 0.02 % (c) 1 % (d) 10 %

**ANSWER: (c)**
```
  0.2 %  phenol  ->  ANTISEPTIC
  1.0 %  phenol  ->  DISINFECTANT

  Same chemical, different concentration.
```

> **SHORTCUT:** Whenever phenol appears with a percentage, the answer is
> one of these two numbers. **Small number = safe = antiseptic.**

---

### Q13. Chlorine is used to disinfect drinking water at a concentration of
(a) 0.2 to 0.4 ppm (b) 2 to 4 ppm (c) 0.2 % (d) 1 %

**ANSWER: (a)**
```
  0.2 - 0.4 PPM chlorine sterilises drinking water.
  Note the unit: PPM, not per cent.
```

---

### Q14. Tincture of iodine is
(a) 2-3 % iodine in alcohol-water (b) 2-3 % iodine in water
(c) 10 % iodine in alcohol (d) iodine in glycerol

**ANSWER: (a)**
```
  TINCTURE OF IODINE = 2-3 % solution of iodine in ALCOHOL-WATER.
  A powerful ANTISEPTIC.
```

---

### Q15. Which of the following is NOT an antiseptic?
(a) dettol (b) iodoform (c) 1 % phenol (d) bithionol

**ANSWER: (c)**
```
  1 % phenol is a DISINFECTANT. At 0.2 % it would be an antiseptic.
  Dettol, iodoform and bithionol are all antiseptics.
```

# PATTERN 3 — BACTERICIDAL vs BACTERIOSTATIC
# =====================================================

### Q16. Which of the following is bactericidal?
(a) tetracycline (b) chloramphenicol (c) penicillin (d) erythromycin

**ANSWER: (c)**
```
  BACTERICIDAL (kills)      : penicillin, ofloxacin, aminoglycosides
  BACTERIOSTATIC (stops growth): tetracycline, chloramphenicol,
                                 erythromycin
```

> **SHORTCUT:** "-CIDAL" contains the idea of **killing** (pesti-cide).
> "-STATIC" means it just **stands still**. Learn the two example lists
> as blocks of three — that answers every question of this type.

**ANSWER: (b)**

```
  (a) tetracycline is BACTERIOSTATIC
  (b) penicillin is BACTERICIDAL
  (d) chloramphenicol is BACTERIOSTATIC
  (c) ofloxacin is BACTERICIDAL - correct
```

**ANSWER: (c)**
```
  BROAD   : chloramphenicol, ampicillin, amoxicillin, tetracycline,

  NARROW  : penicillin G, streptomycin
  LIMITED : dysidazirine
```

---

### Q20. A limited spectrum antibiotic is
(a) ampicillin (b) dysidazirine (c) tetracycline (d) amoxicillin

**ANSWER: (b)**
```
  LIMITED SPECTRUM = effective against a SINGLE organism or disease.
  Dysidazirine is the only example in the syllabus, so if you see the
  word "limited", the answer is dysidazirine.
```

### Q21. Which antibiotic is used in the treatment of typhoid?
(a) streptomycin (b) penicillin (c) chloramphenicol (d) ofloxacin

**ANSWER: (c)**
```
  CHLORAMPHENICOL - broad spectrum, orally effective, used for
  TYPHOID, DYSENTERY, acute fever, urinary infections, meningitis and
  pneumonia.
```

---

### Q22. Streptomycin is used against
(a) malaria (b) tuberculosis (c) typhoid (d) diabetes

**ANSWER: (b)**
```
  STREPTOMYCIN - narrow spectrum - TUBERCULOSIS (TB).

  Remember the pairing:  TB -> STREPTOMYCIN
                         TYPHOID -> CHLORAMPHENICOL
```

---

### Q23. Ampicillin and amoxicillin are
(a) natural penicillins (b) semi-synthetic penicillins
(c) sulpha drugs (d) antiseptics

  Both are SEMI-SYNTHETIC modifications of penicillin made by changing
  the side chain, and both are BROAD SPECTRUM.
```

### Q24. Penicillin was discovered by
(a) Louis Pasteur (b) Alexander Fleming (c) Robert Koch (d) Paul Ehrlich

  ALEXANDER FLEMING, 1929, from the mould Penicillium notatum.

**ANSWER: (b)**

  BHA = butylated hydroxyanisole

**ANSWER: (d)**
```
  BHT is an ANTIOXIDANT, not a preservative.
  A preservative stops MICROBIAL growth; an antioxidant stops
  OXIDATION.
```

### Q33. Table salt and sugar preserve food because they

(c) are antioxidants (d) change the colour of the food

**ANSWER: (b)**

  They draw water OUT of the microbial cells by OSMOSIS, so the
  microbes cannot grow.
```

### Q37. Antihistamines do not affect the secretion of acid in the stomach
because
(a) they are not absorbed (b) they act on the H1 receptor while acid secretion
is controlled by the H2 receptor (c) they are destroyed by stomach acid
(d) the stomach has no histamine

**ANSWER: (b)**
```
  Histamine acts through DIFFERENT receptors:

> answers every H1/H2 question in every exam.

# PATTERN 8 — DRUG-TARGET INTERACTION
# =====================================================

### Q39. A drug that binds to the active site of an enzyme and competes with
the substrate is called
(a) an allosteric inhibitor (b) a competitive inhibitor
(c) an agonist (d) an antagonist

**ANSWER: (b)**
```
  COMPETITIVE  -> ACTIVE site, resembles the substrate
  ALLOSTERIC   -> ALLOSTERIC site, changes the SHAPE of the
                  active site
```

---

### Q40. An allosteric inhibitor works by
(a) occupying the active site (b) changing the shape of the active site
(c) destroying the enzyme (d) increasing the substrate concentration

**ANSWER: (b)**

---

### Q41. A drug that mimics the natural chemical messenger and produces the
same response is called
(a) an antagonist (b) an agonist (c) an inhibitor (d) a substrate

**ANSWER: (b)**
```
  AGONIST     = mimics = message SENT
  ANTAGONIST  = blocks = message STOPPED
```

> **SHORTCUT:** **ANT-agonist = ANTI = against = blocks.**
> The other one must therefore be the mimic.

---

### Q42. Cimetidine and ranitidine are examples of
(a) agonists (b) antagonists (c) competitive enzyme inhibitors
(d) allosteric inhibitors

**ANSWER: (b)**
```
  They BLOCK the H2 receptor -> they are RECEPTOR ANTAGONISTS.
  Careful: "inhibitor" is the word used for ENZYMES;
           "antagonist" is the word used for RECEPTORS.
```

---

### Q43. Receptors are
(a) enzymes in the cytoplasm (b) proteins embedded in the cell membrane
(c) carbohydrates on the cell wall (d) lipids in the nucleus

**ANSWER: (b)**

---

### Q44. If a drug binds to an enzyme through a strong covalent bond, the
inhibition is
(a) reversible (b) irreversible (c) competitive (d) allosteric

**ANSWER: (b)**
```
  WEAK bonds (H-bonding, ionic, van der Waals) -> REVERSIBLE
  COVALENT bond                                -> IRREVERSIBLE
```

---

### Q45. Sulpha drugs are classified on the basis of
(a) pharmacological effect (b) drug action (c) chemical structure
(d) molecular targets

**ANSWER: (c)**
```
  All sulphonamides contain the same structural fragment  -SO2-NH-.
  Grouping by a shared structural feature = CHEMICAL STRUCTURE.
```

---

### Q46. The classification of drugs most useful to a medicinal chemist is on
the basis of
(a) pharmacological effect (b) drug action (c) chemical structure
(d) molecular targets

**ANSWER: (d)**
```
  DOCTOR            -> pharmacological effect
  MEDICINAL CHEMIST -> molecular targets
```

### Q48. The by-product of the manufacture of soap is
(a) ethanol (b) glycerol (c) sodium chloride (d) stearic acid

**ANSWER: (b)**
```

```

---

### Q49. In a micelle, the soap molecules are arranged with
(a) tails outside and heads inside (b) heads outside and tails inside
(c) both randomly (d) heads and tails alternating on the surface

**ANSWER: (b)**
```
  HEADS (ionic, water-loving) OUTSIDE in the water.
  TAILS (hydrocarbon, oil-loving) INSIDE in the oil.
```

> **SHORTCUT:** Ask yourself "where is the water?" The water is on the
> OUTSIDE, so the WATER-LOVING heads must be on the outside. This is the
> most commonly reversed answer in the whole chapter.

  2 C17H35COONa + Ca2+ ---> (C17H35COO)2Ca + 2 Na+
                             INSOLUBLE = SCUM
```

### Q51. Glycerol is added to shaving soap to

  ETHANOL  -> transparency
  AIR      -> makes it float

> and therefore **non-biodegradable**.
