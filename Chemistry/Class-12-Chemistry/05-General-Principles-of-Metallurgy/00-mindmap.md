## THE 60-SECOND VERSION

A metal is sitting in the ground **mixed with mud and locked up as a compound**
(usually an oxide, sulphide or carbonate). Metallurgy is just a cleaning job in
four moves:

```
  MOVE 1   THROW AWAY THE MUD              ->  CONCENTRATION
           (washing, magnets, froth, leaching)

  MOVE 2   TURN WHATEVER IS LEFT INTO      ->  CALCINATION  (carbonates, hydrates)
           A SIMPLE OXIDE                      ROASTING     (sulphides)

  MOVE 3   RIP THE OXYGEN OFF THE METAL    ->  REDUCTION
           (carbon, CO, Al, H2, or electricity)

  MOVE 4   CLEAN THE LEFTOVER DIRT         ->  REFINING
           (electrolysis, zone refining, vapour phase)
```

**One sentence that explains the whole chapter:**
> Ore is a compound. The metal in it is in a **positive oxidation state**.
> To get the free metal you must **REDUCE it to zero oxidation state**.
> Everything else is just choosing the cheapest way to do that reduction.

## THE ONE RELATION THAT UNLOCKS THE THEORY MARKS

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   A REDUCTION HAPPENS ON ITS OWN ONLY IF                            |
  |                                                                     |
  |            delta G   =   delta H   -   T  delta S     <   0         |
  |                                                                     |
  |                                                                     |
  |   AND, FOR AN ELECTROLYTIC / CELL PROCESS                           |
  |                                                                     |
  |            delta G   =   -  n  F  E                                 |
  |                                                                     |
  |            n = number of electrons                                  |
  |            F = 96500 C  (Faraday)                                   |
  |            E = EMF of the cell in volts                             |
  |                                                                     |
  |   E positive  ->  delta G negative  ->  reaction is FEASIBLE        |
  |                                                                     |
  +---------------------------------------------------------------------+
```

**How the examiner uses it:**
"Why must aluminium be extracted by electrolysis and not by carbon?"
-> Because Al is highly electropositive; the Al2O3 Ellingham line lies BELOW
the carbon line up to about 2000 degrees C, so carbon cannot reduce alumina at
any workable temperature. Electricity supplies the energy instead.

## THE ELLINGHAM DIAGRAM IN ONE LOOK

```
   delta G (kJ/mol of O2)
        0 +--------------------------------------------------
          |                                          ,-'
          |                                      ,-'   <-- 2C + O2 -> 2CO
     -200 |   ...........................    ,-'          (SLOPES DOWN)
          |   Cu2O line (high, easy)     ,-'
          |  _________________________,-'
     -400 |  ZnO line              ,-'  \
          |  _________________  ,-'      X  = crossing point
          |  MgO / Al2O3     ,-'          \    ABOVE this temperature
     -600 |  lines (low,  ,-'                  carbon WINS and reduces
          |  very stable),-'                   the oxide
          |          ,-'
     -800 |      ,-'
          +---------------------------------------------------> T (deg C)
          0     500    1000    1500    2000    2500

   RULE:  The metal whose line is LOWER can reduce the oxide whose line is HIGHER.
   RULE:  Carbon's line goes DOWNWARD, so if you go hot enough carbon
          eventually drops below EVERY metal line -> carbon can reduce anything,
          if you can afford the temperature.
```

## THE FOUR REACTIONS THAT PAY THE MOST

```
  1)  CALCINATION           ZnCO3 --(heat, no air)-->  ZnO  +  CO2

  2)  ROASTING              2 ZnS  +  3 O2 --(heat, excess air)--> 2 ZnO + 2 SO2

  3)  SMELTING (blast furnace)
                            Fe2O3  +  3 CO  --(heat)-->  2 Fe  +  3 CO2

  4)  SLAG FORMATION        CaCO3 --(heat)--> CaO + CO2
                            CaO  +  SiO2  -->  CaSiO3   (SLAG)
                            FLUX    GANGUE      SLAG
```

## THE 12 WORDS THE EXAMINER LOVES

```
  +-------------------+--------------------------------------------------+
  |  WORD             |  ONE-LINE MEANING                                |
  +-------------------+--------------------------------------------------+
  |  MINERAL          |  any naturally occurring compound of a metal     |
  |  ORE              |  a mineral from which the metal can be extracted |
  |                   |  PROFITABLY and EASILY                           |
  |  GANGUE / MATRIX  |  the earthy unwanted impurity in the ore         |
  |  FLUX             |  substance added to convert gangue into slag     |
  |  SLAG             |  the fusible waste (flux + gangue), floats,      |
  |                   |  is skimmed off                                  |
  |  CALCINATION      |  heating in ABSENCE of air                       |
  |  ROASTING         |  heating in EXCESS of air                        |
  |  SMELTING         |  reduction of the oxide by carbon in a furnace   |
  |  LEACHING         |  dissolving the ore in a chemical to separate it |
  |  MATTE            |  Cu2S + FeS mixture in copper extraction         |
  |  BLISTER COPPER   |  98% pure copper, blistered by escaping SO2      |
  |  ANODE MUD        |  the sludge under the anode in electro-refining, |
  |                   |  contains Ag, Au, Pt, Se, Te                     |
  +-------------------+--------------------------------------------------+
```

## WHAT TO DO IF YOU BLANK OUT IN THE EXAM

```
  If you cannot remember the details of a process, WRITE THE FLOW CHART.
  Examiners give partial marks for the correct sequence of steps even if
  you get a reaction wrong.

      Crushing -> Concentration -> Roasting/Calcination -> Reduction -> Refining

  Then attach whatever you DO remember to the right box.
  Never leave a metallurgy question blank - it is all descriptive,
  and something written is always worth more than nothing written.
```
