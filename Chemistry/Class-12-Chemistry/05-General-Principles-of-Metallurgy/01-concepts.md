# TOPIC 1 — WHY METALLURGY EXISTS AT ALL

## 1.1 The everyday picture

Imagine you want sugar, but the only sugar available is mixed into a bucket of wet
sand and, worse, chemically joined to something else. You would have to:

1. throw out most of the sand,
2. break the chemical joint,
3. clean up what is left.

That is **exactly** what metallurgy is. Metals are almost never lying around as shiny
lumps. They are stuck in rocks as **compounds**, mixed with soil.

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   METALLURGY  =  the whole science and art of extracting a metal      |
  |                  from its ore and refining it for use.               |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 1.2 Why some metals are found free and others are not

```
  LOW REACTIVITY  ->  the metal does not want to combine with anything
                      ->  found as the FREE METAL (native state)

     Gold (Au) , Silver (Ag) , Platinum (Pt) , Copper (Cu, partly)


  HIGH REACTIVITY ->  the metal grabs oxygen / sulphur immediately
                      ->  found only as a COMPOUND

     Na , K , Ca , Mg , Al  ... all found as oxides, chlorides, silicates
```

The connection is simple:

```
   REACTIVITY UP   ->   found as COMPOUND   ->   HARDER to extract
                                            ->   needs a STRONGER method
                                            ->   ends in ELECTROLYSIS
```

> **TRAP:** Students write "gold is found free because it is heavy". Wrong.
> It is found free because it is **least reactive / has a very high positive
> reduction potential**, so its compounds are unstable.

## 1.3 Common form in which each family occurs

| Position of the metal | Usually found as | Reason |
|---|---|---|
| s-block (Na, K, Ca, Mg) | chlorides, carbonates, sulphates, silicates | very electropositive, never free |
| Al | oxide (bauxite) and silicates | strong affinity for oxygen |
| Fe, Mn | oxides | strong affinity for oxygen |
| Cu, Zn, Pb, Hg | sulphides | these metals are "soft acids", they bond well with sulphur |
| Au, Pt, Ag | free (native) | least reactive |

> **TRAP:** A very common 2-mark question is "Why are sulphide ores common for
> copper, zinc, lead and mercury?" **ANSWER:** These metal ions are less
> electropositive and form more covalent, more stable bonds with the large,
> polarisable sulphide ion than with oxide.

# TOPIC 2 — MINERAL, ORE, GANGUE, FLUX AND SLAG

These five words appear in the exam every single year. Get them perfect.

## 2.1 Mineral vs Ore — the most asked 2-mark question

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   MINERAL  -  ANY naturally occurring chemical substance in the      |
  |               earth's crust that contains a metal, obtained by       |
  |               mining.                                                |
  |                                                                      |
  |   ORE      -  a mineral from which the metal can be extracted        |
  |               CONVENIENTLY and PROFITABLY.                           |
  |                                                                      |
  +----------------------------------------------------------------------+

              ALL ORES ARE MINERALS
              BUT ALL MINERALS ARE NOT ORES

        +---------------------------------------+
        |             MINERALS                  |
        |    +-----------------------+          |
        |    |        ORES           |          |
        |    | (economic to extract) |          |
        |    +-----------------------+          |
        |                                       |
        |   (uneconomic minerals live out here) |
        +---------------------------------------+
```

**The standard example the textbook wants:**

```
  Aluminium occurs in TWO minerals:

     BAUXITE   Al2O3 . 2H2O     ->  aluminium is EASY and CHEAP to extract
                                    ->  it IS an ore

     CLAY      Al2O3 . 2SiO2 . 2H2O   ->  extraction is costly and difficult
                                       ->  it is a MINERAL but NOT an ore
```

## 2.2 Gangue (matrix)

```
  GANGUE  (also called MATRIX)  =  the earthy / rocky / sandy impurities
                                   mixed with the ore.

  Typical gangue:  SiO2 (sand/silica) , clay , limestone, mica.
```

## 2.3 Flux and Slag

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   FLUX  -  a substance added to the furnace charge that combines     |
  |            with the GANGUE to form an easily fusible (low melting)   |
  |            product called SLAG.                                      |
  |                                                                      |
  |   SLAG  -  the fusible waste product formed:                         |
  |                                                                      |
  |                   FLUX  +  GANGUE   ------->   SLAG                  |
  |                                                                      |
  |            Slag is LIGHTER, so it FLOATS on the molten metal and     |
  |            is simply skimmed off.                                    |
  |                                                                      |
  +----------------------------------------------------------------------+
```

**Which flux to choose — the one rule:**

```
   ACIDIC GANGUE  (SiO2, P2O5)   ->  add a BASIC FLUX   (CaO, CaCO3, MgO)
   BASIC GANGUE   (CaO, FeO, MgO)->  add an ACIDIC FLUX (SiO2, borax)

   Opposites cancel. That is the entire rule.
```

**The two reactions to remember:**

```
   CaO     +   SiO2    -->   CaSiO3        (calcium silicate slag - blast furnace)
   BASIC       ACIDIC         SLAG
   FLUX        GANGUE

   FeO     +   SiO2    -->   FeSiO3        (ferrous silicate slag - copper extraction)
   BASIC       ACIDIC         SLAG
   GANGUE      FLUX
```

> **TRAP:** In the **blast furnace** the gangue is SiO2 (acidic) so the flux is
> limestone/CaO (basic). In **copper extraction** the impurity is FeO (basic)
> so the flux is silica SiO2 (acidic). Students mix these two up constantly.
> Look at what the impurity is FIRST, then pick the opposite.

## WORKED EXAMPLE 1

**Q. Haematite is Fe2O3. Calculate the percentage of iron in pure haematite.
(Fe = 56, O = 16)**

```
  Molar mass of Fe2O3  =  2(56) + 3(16)
                       =  112 + 48
                       =  160 g/mol

  Mass of Fe in it     =  112 g

                          112
  % of Fe              =  ------  x  100
                          160

                       =  70 %

  ANSWER:  Haematite is 70 % iron.
```

Check: 70% of 160 = 112. Correct.

# TOPIC 3 — THE FIVE STEPS OF METALLURGY

Every extraction in this chapter follows the same five steps. Learn the skeleton,
then hang the details on it.

```
  +---------------------------------------------------------------------------+
  |                                                                           |
  |            ORE                                                            |
  |             |                                                             |
  |             v                                                             |
  |   +--------------------+                                                  |
  |   |  STEP 1            |   Big lumps -> fine powder.                      |
  |   |  CRUSHING and      |   Done in JAW CRUSHERS then a BALL MILL.         |
  |   |  GRINDING          |   Also called PULVERISATION.                     |
  |   |  (pulverisation)   |   WHY: a powder has a huge surface area, so      |
  |   +--------------------+   every later step works faster.                 |
  |             |                                                             |
  |             v                                                             |
  |   +--------------------+                                                  |
  |   |  STEP 2            |   Throw away the GANGUE.                         |
  |   |  CONCENTRATION     |   Methods: hydraulic washing, magnetic           |
  |   |  (dressing /       |            separation, froth flotation,          |
  |   |   benefaction)     |            leaching.                             |
  |   +--------------------+                                                  |
  |             |                                                             |
  |             v                                                             |
  |   +--------------------+                                                  |
  |   |  STEP 3            |   CALCINATION - carbonates and hydrated oxides   |
  |   |  CONVERSION INTO   |   ROASTING    - sulphide ores                    |
  |   |  METAL OXIDE       |   WHY OXIDE?  Oxides are the EASIEST compounds   |
  |   +--------------------+   to reduce with cheap carbon.                   |
  |             |                                                             |
  |             v                                                             |
  |   +--------------------+                                                  |
  |   |  STEP 4            |   Oxide  ->  METAL   (oxidation state falls to 0)|
  |   |  REDUCTION OF THE  |   By C / CO smelting, self reduction, thermite,  |
  |   |  OXIDE TO METAL    |   hydrogen, or ELECTROLYSIS.                     |
  |   +--------------------+                                                  |
  |             |                                                             |
  |             v                                                             |
  |   +--------------------+                                                  |
  |   |  STEP 5            |   Distillation, liquation, poling, electrolytic  |
  |   |  REFINING          |   refining, zone refining, vapour phase,         |
  |   |  (purification)    |   chromatography.                                |

  |                                                                           |
  +---------------------------------------------------------------------------+
```

> (like haematite Fe2O3 or bauxite). That is fine — but say so. Write
> "the ore is already an oxide, so calcination/roasting is not needed for
> reduction, though calcination may still be done to drive off moisture."

# TOPIC 4 — CONCENTRATION OF THE ORE

Concentration = **removing the gangue**. There are four methods and the examiner can
ask for any of them with a diagram. The method chosen depends on a **physical
difference** between the ore and the gangue.

```
  +------------------------+------------------------------------------------+
  |  IF THE DIFFERENCE IS  |  USE THIS METHOD                               |
  +------------------------+------------------------------------------------+
  |  DENSITY               |  Hydraulic washing (gravity separation)        |
  |  MAGNETISM             |  Magnetic separation                           |
  |  WETTABILITY (by oil)  |  Froth flotation                               |
  |  CHEMICAL SOLUBILITY   |  Leaching                                      |
  +------------------------+------------------------------------------------+
```

---

## 4.1 HYDRAULIC WASHING (gravity separation / levigation)

**PRINCIPLE:** The ore particles and the gangue particles have **different
densities**. A strong upward jet of water carries the lighter gangue away, while
the heavier ore settles at the bottom.

**SUITS:** heavy **OXIDE** ores — haematite Fe2O3, tinstone SnO2, and also native
metals such as gold in river sand.

```
       WATER JET IN (upward)
              ^
              |
    +---------|-------------------------------+
    |  ore + gangue fed in here               |
    |    * * * o o *  o                       |
    |     * o  * o *   o                       ---->  LIGHT GANGUE
    |   o  *  o *  o *                        |       WASHED AWAY
    |  =========================              |       over the top
    |  \  o o o o o o o o o  /                |
    |   \  HEAVY ORE SETTLES/                 |
    |    \___________________/                |
    +--------|--------------------------------+
             |
             v
      CONCENTRATED ORE collected

    Legend:   o = heavy ore particle    * = light gangue particle
```

The industrial version is a **shaking / Wilfley table**: an inclined vibrating table
across which water flows. Heavy ore particles collect in the grooves, light gangue is
washed down the slope.

> **TRAP:** Hydraulic washing works only if the ore is **denser** than the gangue.
> It will not work for a sulphide ore whose density is close to the rock around it —
> that is why froth flotation exists.

---

## 4.2 MAGNETIC SEPARATION

**PRINCIPLE:** One of the two components (either the ore or the gangue) is
**magnetic** and the other is not. A magnetic roller pulls the magnetic part into a
separate heap.

**SUITS:**
- Magnetite (Fe3O4) and chromite (FeCr2O4) — the **ORE** is magnetic.
- Cassiterite / tinstone (SnO2) containing wolframite (FeWO4) — the **GANGUE** is
  magnetic, so here the magnet removes the impurity.

```
                 hopper with powdered ore
                        |||||
                        \\|//
                          v
                +-------------------+
                |     ,-------.     |
     leather -->|    |  MAGNETIC |   |
     belt       |    |  ROLLER   |   |
                |     `-------'     |
                +--------|----------+
                    /         \
                   /           \
                  v             v
           +-------------+  +-------------+
           | NON-MAGNETIC|  |  MAGNETIC   |
           |  falls off  |  | sticks and  |
           |   EARLY,    |  | falls LATER,|
           |  lands in   |  | lands in    |
           |   heap 1    |  |   heap 2    |
           +-------------+  +-------------+

   The non-magnetic material flies off in a normal projectile path.
   The magnetic material clings to the belt longer and drops in a
   nearer, separate heap.
```

## 4.3 FROTH FLOTATION — the big 4-mark question

**PRINCIPLE:** **Sulphide ore particles are PREFERENTIALLY WETTED BY OIL, while the
gangue particles are preferentially wetted by WATER.** When air is blown through, the
oil-coated ore particles stick to the air bubbles and rise as a froth. The
water-wetted gangue sinks.

**SUITS:** **SULPHIDE ORES** — zinc blende ZnS, galena PbS, copper pyrites CuFeS2.

```
  +-------------------------------------------------------------------+
  |         F R O T H   F L O T A T I O N   C E L L                   |
  +-------------------------------------------------------------------+

              oo oo ooo oo ooo   <---- FROTH carrying the ORE
             oOoOoOoOoOoOoOoOo         (skimmed off, dried = concentrate)
        +----ooooooooooooooooo----+
        |     ^   ^   ^   ^  ^    |
        |     |   |   |   |  |    |  <-- rising oil-coated ore particles
        |  ~~~~~~~~~~~~~~~~~~~~~  |
        |  ~  WATER + PINE OIL  ~ |     ||  agitator / paddle
        |  ~  + collector       ~ |    ====
        |  ~  + stabiliser      ~ |     ||
        |  ~   * *   *   * *    ~ |
        |  ~     *  *  *   *    ~ |  <-- gangue, wetted by water, SINKS
        |  ~~~~~~*~~*~~~*~~~~~~~~ |
        |   +--------------------+|
        |   |  AIR BLOWN IN      ||
        +---|--- ^^^^^^^^^ ------++
                 |||||||||
              compressed air

     Legend:  o = ore particle (oil-wetted, rises)
              * = gangue particle (water-wetted, sinks)
```

### The four chemicals used (this is where the marks are)

```
  +------------------+------------------------+---------------------------+
  |  ROLE            |  EXAMPLES              |  WHAT IT DOES             |
  +------------------+------------------------+---------------------------+
  |  1. COLLECTOR    |  Pine oil, fatty acids,|  Makes the ORE water-      |
  |     (or          |  xanthates, sodium     |  repellent so it sticks    |
  |     COLLECTORS)  |  ethyl xanthate        |  to the air bubbles.       |
  +------------------+------------------------+---------------------------+
  |  2. FROTH        |  Cresols, aniline,     |  Makes the froth STABLE    |
  |     STABILISER   |  pine oil              |  so the bubbles do not     |
  |                  |                        |  burst before skimming.    |
  +------------------+------------------------+---------------------------+
  |  3. DEPRESSANT   |  NaCN , NaOH           |  STOPS one particular      |
  |                  |                        |  sulphide from floating    |
  |                  |                        |  so two ores can be        |
  |                  |                        |  separated from each other.|
  +------------------+------------------------+---------------------------+
  |  4. FROTHING     |  Pine oil, eucalyptus  |  Produces the froth itself |
  |     AGENT        |  oil, fatty acids      |                            |
  +------------------+------------------------+---------------------------+
```

### The classic depressant question — ZnS separated from PbS

This is asked again and again. Learn the reaction.

```
  PROBLEM:  An ore contains BOTH zinc blende (ZnS) and galena (PbS).
            Both are sulphides, so BOTH would float. Useless.

  SOLUTION: Add SODIUM CYANIDE, NaCN, as a DEPRESSANT.

            4 NaCN  +  ZnS   -->   Na2[Zn(CN)4]  +  Na2S

            NaCN forms a soluble complex ion with ZnS, coating the ZnS
            surface. The ZnS can no longer be wetted by oil, so it
            DOES NOT FLOAT. It sinks.

            PbS is NOT affected, so PbS FLOATS in the froth.

  RESULT:   Froth  =  PbS  (galena)     Bottom  =  ZnS  (zinc blende)
```

```
        Before NaCN                     After NaCN
     ---------------------          ---------------------
      froth: ZnS + PbS   BAD         froth: PbS only    GOOD
      bottom: gangue                 bottom: ZnS + gangue
```

> **TRAP:** Write the **formula of the complex** Na2[Zn(CN)4]. Just writing
> "NaCN depresses ZnS" gets you half the marks; the equation gets you all of them.

## WORKED EXAMPLE 2

**Q. An ore of copper contains CuFeS2 with SiO2 as gangue. Which concentration
method would you choose and why? Explain how the ore rises.**

```
  STEP 1  Identify the ore type:  CuFeS2 is a SULPHIDE.

  STEP 2  Rule: sulphide ore  ->  FROTH FLOTATION.

  STEP 3  Reason: sulphide surfaces are preferentially wetted by OIL,
          while the silica gangue is preferentially wetted by WATER.

  STEP 4  The mechanism:
             - powdered ore + water + pine oil in a tank
             - air blown in through the bottom
             - pine oil (collector) coats the CuFeS2 particles
             - the coated particles attach to the air bubbles
             - being less dense than water, the bubbles rise
             - cresol (stabiliser) keeps the froth from bursting
             - the froth carrying CuFeS2 is skimmed and dried

  ANSWER: FROTH FLOTATION, because the ore is a sulphide and is
          preferentially wetted by oil while SiO2 is wetted by water.
```

## 4.4 LEACHING — chemical concentration

**PRINCIPLE:** The ore is **dissolved** in a suitable chemical (acid, base or a
complexing agent) in which the **gangue is insoluble**. The solution is filtered off
and the metal recovered from it.

**SUITS:** ores where a chemical difference is easier to exploit than a physical one —
bauxite, gold, silver.

```
   powdered ore  +  reagent
          |
          v
   +---------------+
   |   DISSOLVE    |   ore goes into solution
   |   (leaching)  |   gangue stays solid
   +---------------+
          |
          v
   +---------------+
   |    FILTER     |------> insoluble GANGUE thrown away
   +---------------+          (RED MUD, in the Bayer process)
          |
    filtrate contains the metal
          |
          v
   +---------------+
   |  PRECIPITATE  |   recover the metal or its pure compound
   |  or DISPLACE  |
   +---------------+
```

### 4.4a THE BAYER PROCESS — leaching of bauxite

Bauxite Al2O3.2H2O is contaminated with **SiO2, iron oxides (Fe2O3) and TiO2**.
Al2O3 is **amphoteric**, so it dissolves in hot concentrated NaOH; Fe2O3 and TiO2 are
basic and do not.

```
  STEP 1  Digest powdered bauxite with 45% NaOH at 473-523 K (about 200-250 deg C)
          under 35-36 bar pressure:

     Al2O3(s) + 2 NaOH(aq) + 3 H2O(l) --(473-523K)--> 2 Na[Al(OH)4](aq)
                                                       sodium tetrahydroxoaluminate
                                                       (SOLUBLE)

     Fe2O3 and TiO2 do NOT dissolve  ->  filtered off as RED MUD.

  STEP 2  The filtrate is neutralised by passing CO2 gas, and seeded with a
          little freshly prepared Al2O3.xH2O to start the precipitation:

     2 Na[Al(OH)4](aq) + 2 CO2(g) --> Al2O3.x H2O(s) + 2 NaHCO3(aq)

  STEP 3  The hydrated alumina is filtered, dried and heated to 1470 K:

     Al2O3 . x H2O --(1470 K)-->  Al2O3(s)  +  x H2O(g)

  RESULT: pure ALUMINA (Al2O3), ready for the Hall-Heroult cell.
```

```
   BAUXITE (impure)
        |
        |  hot conc. NaOH, 473-523 K, 35 bar
        v
   Na[Al(OH)4] solution  ------ filter ------>  RED MUD (Fe2O3 , TiO2)  discarded
        |
        |  CO2 gas + seeding
        v
   Al2O3 . x H2O  (precipitate)
        |
        |  heat, 1470 K
        v
   PURE Al2O3  (ALUMINA)
```

> **TRAP:** Silica is also amphoteric-ish and dissolves as sodium silicate; it is
> removed later. But for the exam, the two lines to remember are
> "Al2O3 dissolves in NaOH; Fe2O3 and TiO2 do not, and are removed as red mud."

### 4.4b THE CYANIDE PROCESS (MacArthur-Forrest) — gold and silver

```
  STEP 1  LEACHING. The crushed ore is treated with a dilute solution of
          NaCN (0.4 - 0.6 %) with a current of AIR bubbled through:

     4 Au(s) + 8 NaCN(aq) + 2 H2O(l) + O2(g) --> 4 Na[Au(CN)2](aq) + 4 NaOH(aq)
                                                 sodium dicyanoaurate(I)

     (For silver:)
     4 Ag(s) + 8 NaCN(aq) + 2 H2O(l) + O2(g) --> 4 Na[Ag(CN)2](aq) + 4 NaOH(aq)

  STEP 2  DISPLACEMENT. Add zinc dust; Zn is more electropositive so it
          displaces the gold:

     2 Na[Au(CN)2](aq) + Zn(s) --> Na2[Zn(CN)4](aq) + 2 Au(s)

     2 Na[Ag(CN)2](aq) + Zn(s) --> Na2[Zn(CN)4](aq) + 2 Ag(s)
```

```
   WHY IS AIR / O2 NEEDED?
      Because gold has to be OXIDISED from Au(0) to Au(+1) before it can go
      into the complex. Oxygen is the oxidising agent.

   WHY ZINC?
      Zinc is ABOVE gold and silver in the electrochemical series (more
      electropositive), so it displaces them from solution.
      Here zinc acts as the REDUCING AGENT.
```

> **TRAP:** Note NaCN appears TWICE in this chapter and does two DIFFERENT jobs:
> - in froth flotation it is a **DEPRESSANT**
> - in the cyanide process it is a **LEACHING / COMPLEXING agent**
> Read the question carefully before you answer.

### 4.4c Leaching in other cases

```
   SILVER from Ag2S:      Ag2S + 4 NaCN  <-->  2 Na[Ag(CN)2] + Na2S

   Low grade COPPER ore:  Cu2O + 2 H+  -->  Cu2+ + Cu + H2O
                          then    Cu2+ + Fe(s)  -->  Fe2+ + Cu(s)
                          (scrap iron displaces copper)
```

# TOPIC 5 — CONVERSION OF THE CONCENTRATED ORE INTO METAL OXIDE

## 5.1 Why bother turning everything into an oxide?

```
  +---------------------------------------------------------------------+
  |  Because OXIDES ARE THE EASIEST COMPOUNDS TO REDUCE.                |
  |                                                                     |
  |  Carbon is dirt cheap. Carbon happily takes oxygen away from a      |
  |  metal oxide (it forms CO / CO2, both very stable).                 |
  |  Carbon is NOT good at taking sulphur or carbonate away.            |
  |                                                                     |
  |  So:  turn the sulphide / carbonate into an OXIDE first,            |
  |       THEN reduce it cheaply with carbon.                           |
  +---------------------------------------------------------------------+
```

## 5.2 CALCINATION

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   CALCINATION  =  heating the concentrated ore STRONGLY in the      |
  |                   ABSENCE (or limited supply) of air, at a          |
  |                   temperature BELOW the melting point of the metal. |
  |                                                                     |
  +---------------------------------------------------------------------+
```

**Used for:** CARBONATE ores and HYDRATED oxide ores.

**What it achieves:**
- drives off **CO2** from carbonates
- drives off **water of hydration**
- burns away organic matter and volatile impurities (S, As)
- leaves the ore **porous**, so reduction later is faster

**Reactions to learn:**

```
   ZnCO3         --(heat, no air)-->   ZnO    +  CO2      (calamine)
   CaCO3         --(heat, no air)-->   CaO    +  CO2      (limestone)
   FeCO3         --(heat, no air)-->   FeO    +  CO2      (siderite)
   MgCO3         --(heat, no air)-->   MgO    +  CO2      (magnesite)

   Fe2O3 . 3H2O  --(heat)-->   Fe2O3  +  3 H2O            (limonite)
   Al2O3 . 2H2O  --(heat)-->   Al2O3  +  2 H2O            (bauxite)
```

Carried out in a **reverberatory furnace**.

## 5.3 ROASTING

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   ROASTING  =  heating the concentrated ore strongly in the         |
  |                PRESENCE OF EXCESS AIR, at a temperature BELOW the   |
  |                melting point of the metal.                          |
  |                                                                     |
  +---------------------------------------------------------------------+
```

**Used for:** SULPHIDE ores.

**Reactions to learn:**

```
   2 ZnS   +  3 O2  --(heat, excess air)-->  2 ZnO   +  2 SO2
   2 PbS   +  3 O2  --(heat, excess air)-->  2 PbO   +  2 SO2
   2 Cu2S  +  3 O2  --(heat, excess air)-->  2 Cu2O  +  2 SO2

   4 FeS2  + 11 O2  --(heat)-->  2 Fe2O3  +  8 SO2      (iron pyrites)

   Impurities are removed as VOLATILE OXIDES:
       S    + O2   -->  SO2
       4 As + 3 O2 -->  2 As2O3      (volatile, escapes)
       4 P  + 5 O2 -->  P4O10
```

Carried out in a **reverberatory furnace** or a **blast furnace**.

```
     R E V E R B E R A T O R Y   F U R N A C E   (used for both)

        chimney
          ^
          |
     +----|-------------------------------------------------+
     |    |     low arched ROOF reflects the heat DOWN       |
     |   ,'-------------------------------------------.      |
     |  /   <---- radiated heat ---->                  \     |
     | +----------------------------------------------+ |    |
     | |          ORE SPREAD ON THE HEARTH            | |    |
     +-+----------------------------------------------+-+----+
       ^                                                ^
   FIREPLACE                                        ore fed in
   (fuel burns HERE, NOT in contact with the ore)

     KEY IDEA: the fuel and the ore never touch. Heat "reverberates"
               (bounces) off the roof onto the ore.
```

## 5.4 CALCINATION vs ROASTING — the comparison table (guaranteed 4 marks)

| # | CALCINATION | ROASTING |
|---|---|---|
| 1 | Heating in the **ABSENCE** (or limited supply) of air | Heating in the **PRESENCE of EXCESS air** |
| 2 | Applied to **CARBONATE** and **HYDRATED OXIDE** ores | Applied to **SULPHIDE** ores |
| 3 | The main gas evolved is **CO2** (and H2O vapour) | The main gas evolved is **SO2** |
| 4 | It is essentially a **thermal decomposition** — no oxidation | It is an **OXIDATION** reaction |
| 5 | Removes water of crystallisation and volatile organic matter | Removes S, As, Sb as their volatile oxides |
| 6 | Temperature is usually **lower** | Temperature is usually **higher** |
| 7 | Example: `ZnCO3 -> ZnO + CO2` | Example: `2 ZnS + 3 O2 -> 2 ZnO + 2 SO2` |
| 8 | Furnace: reverberatory | Furnace: reverberatory or blast furnace |

```
   ONE-LINE MEMORY HOOK

      CALCINATION  ->  C for CARBONATE , C for CO2 , "Closed" (no air)
      ROASTING     ->  the ore is "roasted" in AIR , gives SO2 from Sulphides
```

> **TRAP:** ZnO is produced from ZnCO3 by **calcination** and from ZnS by
> **roasting**. If the question gives you calamine (ZnCO3), the answer is
> calcination. If it gives zinc blende (ZnS), the answer is roasting.
> Read the FORMULA, not the metal.

# TOPIC 6 — THERMODYNAMIC PRINCIPLES OF METALLURGY

This is the "brainy" part of the chapter. It answers one question:

> **"Given a metal oxide, WHICH reducing agent should I use, and at WHAT temperature?"**

## 6.1 The Gibbs energy criterion

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |         delta G   =   delta H   -   T  delta S                      |
  |                                                                     |
  |    A reaction happens ON ITS OWN (is FEASIBLE / SPONTANEOUS)        |
  |    only when                                                        |
  |                                                                     |
  |                    delta G   <   0    (NEGATIVE)                    |
  |                                                                     |
  |    If delta G = 0  the system is at equilibrium.                    |
  |    If delta G > 0  the reaction will NOT go by itself.              |
  |                                                                     |
  +---------------------------------------------------------------------+
```

Two ways to push delta G negative:

```
   (1) Make delta H more negative  ->  release more heat (strongly exothermic).

   (2) Make T delta S larger       ->  either raise the TEMPERATURE T,
                                       or choose a reaction where delta S is
                                       POSITIVE (gas is produced).

       This is why heating usually helps a reduction: if delta S is positive,
       raising T makes ( - T delta S ) more negative.
```

## 6.2 COUPLING OF REACTIONS — the real trick

Metal oxides are stable. Their decomposition on its own has a **positive** delta G:

```
   MxOy  -->  x M  +  (y/2) O2          delta G is POSITIVE  ->  will not happen
```

So we **couple** it with a second reaction that has a **large negative** delta G,
and add them. If the SUM is negative, the whole thing goes.

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   Reaction 1 (unwanted alone):  MO  -->  M  +  1/2 O2               |
  |                                 delta G(1)  =  + 200 kJ (say)       |
  |                                                                     |
  |   Reaction 2 (the helper):      C  +  1/2 O2  -->  CO               |
  |                                 delta G(2)  =  - 250 kJ (say)       |
  |   ----------------------------------------------------------------  |
  |   COUPLED:                      MO  +  C  -->  M  +  CO             |
  |                                 delta G  =  200 - 250 = - 50 kJ     |
  |                                                                     |
  |                                 NEGATIVE  ->  IT WORKS.             |
  |                                                                     |
  +---------------------------------------------------------------------+
```

**In plain words:** the oxygen released by the metal oxide is immediately grabbed by
the reducing agent, which releases so much energy that it "pays for" the difficult
first step. The reducing agent must have a **greater affinity for oxygen** than the
metal does.

```
   THE ONE-LINE RULE

     Element A can reduce the oxide of metal B
                  IF
     A has a GREATER affinity for oxygen than B,
     i.e. delta G of formation of A's oxide is MORE NEGATIVE
     than delta G of formation of B's oxide, at that temperature.
```

## 6.3 THE ELLINGHAM DIAGRAM

**Definition:**

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   An ELLINGHAM DIAGRAM is a plot of                                 |
  |                                                                     |
  |      delta G (standard Gibbs energy of formation of the oxide)      |
  |            on the Y-AXIS                                            |
  |                                                                     |
  |      versus  TEMPERATURE T                                          |
  |            on the X-AXIS                                            |
  |                                                                     |
  |   All values are quoted PER MOLE OF O2 CONSUMED, so that            |
  |   different metals can be compared fairly.                          |
  |                                                                     |
  +---------------------------------------------------------------------+
```

### The simplified diagram (draw this in the exam)

```
    delta G (kJ per mole of O2)
        |
      0 +----------------------------------------------------------------
        |                                                       ,-'
        |                                                   ,-'
        |                                               ,-'
   -100 |    ..................................     ,-'
        |    2 Cu2O  line  (SHALLOW, HIGH UP) ,-'
        |    _____________________________ ,-'
   -200 |                              ,-'
        |     2 NiO           ______,-'  <-------- 2 C + O2 --> 2 CO
   -300 |     _______________,-'                   THIS LINE SLOPES
        |                 ,-'    \                 *** DOWNWARD ***
   -400 |    2 FeO  ___,-'        \  X1
        |    ______,-'             \                (delta S is POSITIVE:
   -500 |      ,-'   ZnO            \                1 mol gas -> 2 mol gas)
        |  ,-'       ______________  \ X2
   -600 |,-'                          \
        |         2/3 Al2O3            \
   -700 |      ____________________     \ X3
        |                                \
   -800 |         2 MgO                   \
        |      ____________________________\ X4
   -900 |
        +----------------------------------------------------------------> T
        0      500     1000     1500     2000     2500   (degrees C)

   X1, X2, X3, X4 are the CROSSING POINTS with the carbon line.
   ABOVE the crossing temperature, carbon lies LOWER, so carbon CAN
   reduce that oxide.
```

### The five things the examiner wants you to say

**(1) Why do most metal lines slope UPWARD (delta G becomes less negative as T rises)?**

```
   For       2 M(s)  +  O2(g)  -->  2 MO(s)

   A GAS (O2) is being consumed and turned into a SOLID.
   Disorder therefore DECREASES:      delta S  is NEGATIVE.

   delta G = delta H - T delta S
           = (negative) - T (negative)
           = (negative) + (positive number that grows with T)

   So as T rises, delta G becomes LESS NEGATIVE  ->  the line rises.

   Slope of the line = ( - delta S ) , which is POSITIVE  ->  upward line.
```

**(2) Why does the carbon (C -> CO) line slope DOWNWARD?**

```
   For       2 C(s)  +  O2(g)  -->  2 CO(g)

   1 mole of gas becomes 2 moles of gas.
   Disorder INCREASES:                delta S  is POSITIVE.

   delta G = delta H - T delta S
           = (negative) - T (positive)
           = becomes MORE and MORE NEGATIVE as T rises

   So the line slopes DOWNWARD.
```

**(3) What follows from that?**

```
   Because the carbon line goes DOWN while all the metal lines go UP,
   the carbon line must eventually CROSS every metal line.

   ABOVE the crossing temperature, the carbon line is LOWER
      ->  CO is more stable than the metal oxide
      ->  CARBON CAN REDUCE THAT OXIDE.

   THEREFORE: given a high enough temperature, CARBON CAN REDUCE
              ALMOST ANY METAL OXIDE.
```

**(4) How to USE the diagram**

```
   +------------------------------------------------------------------+
   |  STEP 1  Find the line of the oxide you want to reduce.          |
   |  STEP 2  Find any line that lies BELOW it at some temperature.   |
   |  STEP 3  That lower element is a suitable REDUCING AGENT.        |
   |  STEP 4  Read off the temperature at which the two lines CROSS.  |
   |          You must work ABOVE that temperature.                   |
   +------------------------------------------------------------------+

   LOWER LINE  =  more stable oxide  =  stronger affinity for oxygen
                                     =  the REDUCING AGENT

   Examples read straight off the diagram:
      - The Al2O3 line lies BELOW the Cr2O3 and Fe2O3 lines
             ->  Al can reduce Cr2O3 and Fe2O3   (THERMITE PROCESS)
      - The C -> CO line drops below the FeO line above about 1000 K
             ->  carbon reduces FeO in the blast furnace
      - The Al2O3 and MgO lines lie BELOW the carbon line until about
        2000 deg C   ->  carbon CANNOT reduce alumina economically
             ->  aluminium must be obtained by ELECTROLYSIS
```

**(5) The LIMITATIONS of the Ellingham diagram (a standard 2-mark question)**

```
  +---------------------------------------------------------------------+
  |  1. It tells you only about the FEASIBILITY (thermodynamics).       |
  |     It says NOTHING about the RATE (kinetics). A reaction may be    |
  |     feasible but far too slow to be useful.                         |
  |                                                                     |
  |  2. It assumes the reactants and products are in EQUILIBRIUM,       |
  |     which is often not true in a real furnace.                      |
  |                                                                     |
  |  3. It uses delta G values, and the interpretation of a simple      |
  |     coupled reaction can break down when the products react         |
  |     further or form solutions / alloys with each other.             |
  |                                                                     |
  |  4. Above the melting or boiling point of a substance the line      |
  |     BENDS (the phase change changes delta S), which complicates     |
  |     the reading.                                                    |
  +---------------------------------------------------------------------+
```

## WORKED EXAMPLE 4

**Q. Using the Ellingham diagram idea, explain why magnesium can reduce alumina
below 1350 deg C but aluminium can reduce MgO above 1350 deg C.**

```
  STEP 1  Both the MgO line and the Al2O3 line slope UPWARD, but they have
          DIFFERENT slopes, so they CROSS each other at about 1350 deg C.

  STEP 2  BELOW 1350 deg C
             the MgO line lies BELOW the Al2O3 line
             ->  MgO is the more stable oxide
             ->  Mg has the greater affinity for oxygen
             ->  Mg REDUCES Al2O3:     3 Mg + Al2O3 --> 3 MgO + 2 Al

  STEP 3  ABOVE 1350 deg C
             the lines have swapped: the Al2O3 line is now BELOW
             ->  Al2O3 is now the more stable oxide
             ->  Al REDUCES MgO:       2 Al + 3 MgO --> Al2O3 + 3 Mg

  ANSWER: Because the two lines CROSS at about 1350 deg C, so which oxide is
          the more stable depends on the temperature.
```

> **TRAP:** Never say "Al is a stronger reducing agent than Mg" as a blanket
> statement. The Ellingham diagram's whole point is that the answer
> **depends on the temperature**.

# TOPIC 7 — ELECTROCHEMICAL PRINCIPLES OF METALLURGY

## 7.1 The equation

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |            delta G   =   -  n  F  E                                 |
  |                                                                     |
  |     delta G  =  Gibbs energy change (J)                             |
  |     n        =  number of moles of electrons transferred            |
  |     F        =  Faraday constant  =  96500 C / mol                  |
  |     E        =  EMF of the cell (volts)                             |
  |                                                                     |
  |     E POSITIVE   ->   delta G NEGATIVE   ->   FEASIBLE              |
  |                                                                     |
  +---------------------------------------------------------------------+
```

Also, for a displacement reaction,

```
   E(cell)  =  E(cathode)  -  E(anode)
            =  E of the species being REDUCED  -  E of the species being OXIDISED
```

## 7.2 What it tells you about extraction

```
   A metal with a LARGE NEGATIVE reduction potential
        =  very electropositive
        =  hates being an atom, loves being an ion
        =  its ion is very hard to reduce
        =  chemical reducing agents (C, CO, H2) are not strong enough
        =  YOU MUST USE ELECTRICITY

           ->  Na , K , Ca , Mg , Al  are all obtained by ELECTROLYSIS
               (usually of the FUSED / MOLTEN salt or oxide, not of the
                aqueous solution)
```

```
   +-------------------+---------------------------+---------------------+
   |  POSITION IN THE  |  EXAMPLE METALS           |  EXTRACTION METHOD  |
   |  ACTIVITY SERIES  |                           |                     |
   +-------------------+---------------------------+---------------------+
   |  VERY high        |  K, Na, Ca, Mg, Al        |  ELECTROLYSIS of    |
   |  (most reactive)  |                           |  the fused salt/oxide|
   +-------------------+---------------------------+---------------------+
   |  MIDDLE           |  Zn, Fe, Sn, Pb, Cu(part) |  REDUCTION of the   |
   |                   |                           |  oxide by C or CO   |
   +-------------------+---------------------------+---------------------+
   |  LOW              |  Cu, Hg                   |  SELF REDUCTION /   |
   |  (least reactive) |                           |  simple heating     |
   +-------------------+---------------------------+---------------------+
   |  LOWEST           |  Au, Ag, Pt               |  found NATIVE;      |
   |                   |                           |  leaching + Zn      |
   |                   |                           |  displacement       |
   +-------------------+---------------------------+---------------------+
```

## 7.3 Why a MOLTEN salt and not an aqueous solution?

```
   If you electrolyse aqueous NaCl, the H2O is reduced instead of Na+:

        2 H2O + 2 e-  -->  H2 + 2 OH-      E = -0.83 V
        Na+ + e-      -->  Na              E = -2.71 V

   Water is reduced FAR more easily, so you get hydrogen, not sodium.
   ->  Therefore Na must be obtained from MOLTEN (fused) NaCl,
       where there is no water at all.  (Down's process)
```

## WORKED EXAMPLE 5

**Q. Zinc is used to displace silver from the complex Na[Ag(CN)2].
Given E of Ag+/Ag = +0.80 V and E of Zn2+/Zn = -0.76 V, show that the reaction
is feasible and find delta G.**

```
  STEP 1  Write the reaction:
             Zn(s)  +  2 Ag+(aq)  -->  Zn2+(aq)  +  2 Ag(s)
          Zn is oxidised (anode), Ag+ is reduced (cathode).
          n = 2 electrons.

  STEP 2  E(cell) = E(cathode) - E(anode)
                  = ( +0.80 )  -  ( -0.76 )
                  = + 1.56 V                      E is POSITIVE.

  STEP 3  delta G = - n F E
                  = - ( 2 ) ( 96500 ) ( 1.56 )
                  = - 301 080  J
                  = - 301.08  kJ

  ANSWER: E is positive and delta G is about -301 kJ, strongly negative,
          so the displacement of silver by zinc is FEASIBLE.
```

Check: 2 x 96500 = 193000; 193000 x 1.56 = 301080. Correct.

# TOPIC 8 — REDUCTION OF THE OXIDE TO THE METAL

Five methods. Learn one example for each.

## 8.1 SMELTING — reduction by carbon or carbon monoxide

```
  +---------------------------------------------------------------------+
  |  SMELTING  =  reduction of a metal oxide by heating it with         |
  |               CARBON (coke) or CARBON MONOXIDE in a furnace,        |
  |               usually with a FLUX to remove the gangue as slag.     |
  +---------------------------------------------------------------------+

   ZnO   +  C   --(1673 K)-->   Zn   +  CO

   Fe2O3 + 3 CO --(blast furnace)-->  2 Fe  +  3 CO2

   PbO   +  C   --(heat)-->     Pb   +  CO

   SnO2  + 2 C  --(heat)-->     Sn   +  2 CO
```

Cheapest method. Used for **moderately reactive** metals: Zn, Fe, Sn, Pb.

## 8.2 SELF REDUCTION (auto-reduction / air reduction)

Used for **copper and lead**, whose sulphides are partly roasted first. No external
reducing agent is needed at all — the ore reduces itself.

```
  THE IDEA:  Roast only PART of the sulphide to the oxide.
             Then heat the oxide with the REMAINING sulphide.
             The sulphide acts as the reducing agent.

  COPPER
     Step 1 (partial roasting):  2 Cu2S  +  3 O2  -->  2 Cu2O  +  2 SO2
     Step 2 (self reduction):    2 Cu2O  +  Cu2S  --(heat)-->  6 Cu  +  SO2

  LEAD
     Step 1 (partial roasting):  2 PbS   +  3 O2  -->  2 PbO   +  2 SO2
     Step 2 (self reduction):    2 PbO   +  PbS   --(heat)-->  3 Pb  +  SO2

  MERCURY (simplest of all - just roast it)
                                 HgS  +  O2  --(heat)-->  Hg  +  SO2
```

> **TRAP:** Balance these. `2 Cu2O + Cu2S -> 6 Cu + SO2` — count copper:
> 4 + 2 = 6 on the left, 6 on the right. Good. Oxygen: 2 on left, 2 on right. Good.

## 8.3 THE THERMITE / ALUMINOTHERMIC PROCESS (Goldschmidt process)

```
  +---------------------------------------------------------------------+
  |  When the metal oxide CANNOT be reduced by carbon (because carbon   |
  |  would form a CARBIDE, or the temperature needed is too high),      |
  |  use ALUMINIUM POWDER as the reducing agent.                        |
  |                                                                     |
  |  These reactions are HIGHLY EXOTHERMIC - the heat released melts    |
  |  the metal, which is collected in the molten state.                 |
  +---------------------------------------------------------------------+

   Cr2O3   +  2 Al   -->   2 Cr   +   Al2O3        delta H is NEGATIVE

   3 Mn3O4 +  8 Al   -->   9 Mn   +   4 Al2O3

   Fe2O3   +  2 Al   -->   2 Fe   +   Al2O3        (THE THERMITE REACTION)
                                                    used to WELD RAILS
   B2O3    +  2 Al   -->   2 B    +   Al2O3
```

```
        T H E R M I T E   W E L D I N G

     +------------------------+
     |  Mg ribbon  (fuse)     |   <-- BaO2 + Mg ribbon is the IGNITION MIXTURE
     |      |                 |
     |      v                 |
     |  Fe2O3 + Al powder     |   <-- the THERMITE MIXTURE (3:1 by mass)
     |  (thermite mixture)    |
     +-----------|------------+
                 |
        ,--------v--------.
        |  MOLTEN IRON    |    temperature reaches about 3000 deg C
        `--------|--------'
                 v
      ==========/ \=========   <-- poured into the gap between two rails
       RAIL     GAP    RAIL        -> welds them together
```

**Why is a Mg ribbon + BaO2 needed?** The thermite reaction has a **high activation
energy**; it will not start on its own. The burning magnesium supplies the initial
heat, and BaO2 supplies oxygen to keep it burning.

## 8.4 REDUCTION BY HYDROGEN

Used when a very **pure** metal is wanted and the metal does not form a hydride.

```
   WO3   +  3 H2   --(heat)-->   W    +  3 H2O       (tungsten)

   MoO3  +  3 H2   --(heat)-->   Mo   +  3 H2O       (molybdenum)

   Ag2O  +  H2     -->  2 Ag  +  H2O
```

**Limitation:** many metals (the alkali and alkaline earth metals, and Ti) form
**HYDRIDES** with hydrogen, so this method cannot be used for them. It is also
expensive and there is an explosion risk.

## 8.5 ELECTROLYTIC REDUCTION

For the very electropositive metals. Always the **FUSED (molten)** compound.

```
  +----------+-------------------------------+---------------------------+
  |  METAL   |  ELECTROLYTE                  |  PROCESS NAME             |
  +----------+-------------------------------+---------------------------+
  |   Na     |  fused NaCl + CaCl2           |  DOWN'S process           |
  |   Al     |  Al2O3 in molten cryolite     |  HALL-HEROULT process     |
  |   Mg     |  fused MgCl2 + NaCl + CaCl2   |  DOW process              |
  |   Ca     |  fused CaCl2 + CaF2           |  -                        |
  +----------+-------------------------------+---------------------------+

  The metal is always deposited at the CATHODE (reduction).
```

## 8.6 Reduction summary chart

```
  +---------------------------+---------------------------------------------+
  |  METHOD                   |  USE IT WHEN ...                            |
  +---------------------------+---------------------------------------------+
  |  Carbon / CO smelting     |  the metal is moderately reactive           |
  |                           |  (Fe, Zn, Pb, Sn) - the CHEAPEST way        |
  +---------------------------+---------------------------------------------+
  |  Self reduction           |  the ore is a sulphide of a LOW-reactivity  |
  |                           |  metal (Cu, Pb, Hg)                         |
  +---------------------------+---------------------------------------------+
  |  Aluminothermite          |  carbon would form a carbide, or the        |
  |                           |  oxide is very stable (Cr, Mn, B)           |
  +---------------------------+---------------------------------------------+
  |  Hydrogen                 |  a VERY pure metal is wanted and no         |
  |                           |  hydride forms (W, Mo)                      |
  +---------------------------+---------------------------------------------+
  |  Electrolysis             |  the metal is HIGHLY electropositive        |
  |                           |  (Na, K, Ca, Mg, Al)                        |
  +---------------------------+---------------------------------------------+
```

# TOPIC 9 — EXTRACTION OF ALUMINIUM  *** 8-mark favourite ***

Aluminium extraction has **two halves**. Do not confuse them.

```
   BAUXITE (impure)  --[ BAYER PROCESS ]-->  PURE Al2O3
                        (PURIFICATION - chemistry)

   PURE Al2O3        --[ HALL-HEROULT ]-->   Al METAL
                        (REDUCTION - electrolysis)
```

## 9.1 Half one — the BAYER PROCESS (purification of bauxite)

Already covered in Topic 4.4a. The three equations again, because you must be able to
write them without thinking:

```
   1)  Al2O3(s) + 2 NaOH(aq) + 3 H2O(l) --(473-523 K, 35 bar)--> 2 Na[Al(OH)4](aq)

       Fe2O3, TiO2 remain undissolved  ->  filtered off as RED MUD

   2)  2 Na[Al(OH)4](aq) + 2 CO2(g)  -->  Al2O3 . x H2O(s) + 2 NaHCO3(aq)

       (the solution is SEEDED with fresh Al2O3.xH2O to start precipitation)

   3)  Al2O3 . x H2O(s)  --(1470 K)-->  Al2O3(s)  +  x H2O(g)
```

**Alternative (SERPECK'S process, for high-silica bauxite)** — worth one line:

```
   Al2O3 + 3 C + N2  --(1800 deg C)-->  2 AlN + 3 CO
   AlN + 3 H2O  -->  Al(OH)3 + NH3
   2 Al(OH)3  --(heat)-->  Al2O3 + 3 H2O
```

## 9.2 Half two — the HALL-HEROULT PROCESS (electrolytic reduction)

**The problem:** pure Al2O3 melts at about **2323 K (2050 deg C)**. Melting it is
absurdly expensive.

**The solution:** dissolve it in molten **cryolite**. The melting point drops to
about **1140 K (870 deg C)** and the melt conducts electricity well.

### The electrolyte

```
  +-------------------------------------------------------------------+
  |  Pure alumina        Al2O3          -   about 20 %                 |
  |  Cryolite            Na3AlF6        -   about 60 %                 |
  |  Fluorspar           CaF2           -   about 20 %                 |
  |                                                                    |
  |  Temperature         about 1140 K   (about 870 - 950 deg C)        |
  |  Voltage             4 to 6 volts                                  |
  |  Current             very large     (about 1 lakh amperes)         |
  +-------------------------------------------------------------------+
```

### Roles you MUST be able to state

```
  CRYOLITE  Na3AlF6
     - LOWERS the melting point of alumina from ~2323 K to ~1140 K
     - INCREASES the ELECTRICAL CONDUCTIVITY of the melt
     -> saves an enormous amount of energy

  FLUORSPAR  CaF2
     - lowers the melting point FURTHER
     - increases the conductivity / fluidity of the melt

  GRAPHITE (carbon) ANODE
     - conducts the current
     - and is DELIBERATELY consumed: it burns away with the oxygen
       liberated, which LOWERS the voltage needed
       (this is why the anodes must be replaced from time to time)

  IRON TANK LINED WITH GRAPHITE
     - the LINING is the CATHODE
```

### The cell diagram

```
    H A L L - H E R O U L T   C E L L

              O2 / CO / CO2 escape
                   ^     ^     ^
                   |     |     |
        +----------|-----|-----|-------------+
        |    ||    ||    ||    ||   ||       |   <-- GRAPHITE ANODES
        |    ||    ||    ||    ||   ||       |       (dipped in, consumed)
        |    ||    ||    ||    ||   ||       |
        |  ############################      |
        |  #  MOLTEN ELECTROLYTE       #     |   Al2O3 (20%) dissolved in
        |  #  Al2O3 + Na3AlF6 + CaF2   #     |   Na3AlF6 (60%) + CaF2 (20%)
        |  #      at about 1140 K      #     |
        |  ############################      |
        |  ****************************      |   <-- MOLTEN ALUMINIUM
        |  * MOLTEN Al collects here  *      |       (denser, sinks to the
        |  ****************************      |        bottom, tapped off)
        |####################################|   <-- GRAPHITE LINING
        +------------------------------------+       = the CATHODE
         \                                  /
          \______________________________ /   IRON TANK
                       |
                  tap hole for molten Al

     +  terminal  ->  ANODES        - terminal  ->  the LINING (cathode)
```

### The electrode reactions (write these exactly)

```
  IONISATION in the melt:

        Al2O3   -->   2 Al3+   +   3 O2-


  AT THE CATHODE  (reduction, the metal is formed):

        Al3+  +  3 e-   -->   Al(l)


  AT THE ANODE  (oxidation):

        2 O2-   -->   O2   +   4 e-

  and the oxygen immediately attacks the hot carbon anode:

        C(s)   +   O2(g)   -->   CO2(g)

        C(s)   +   1/2 O2(g)  -->  CO(g)


  OVERALL:

        2 Al2O3   +   3 C    -->   4 Al   +   3 CO2
```

> **TRAP:** The question "why are the anodes replaced periodically?" is common.
> **ANSWER:** Because the oxygen liberated at the anode burns the graphite away to
> CO and CO2, so the anodes are gradually consumed.

> **TRAP:** Do NOT say cryolite is the source of aluminium. It is only the SOLVENT.
> The aluminium comes from the Al2O3.

## WORKED EXAMPLE 6

**Q. Calculate the mass of aluminium produced when 3 faradays of charge are
passed through molten alumina. (Al = 27)**

```
  STEP 1  The cathode reaction:     Al3+  +  3 e-  -->  Al

          So 3 moles of electrons  =  3 F  produce  1 mole of Al.

  STEP 2  3 F  ->  1 mole Al  =  27 g

  ANSWER: 27 g of aluminium.

  (Equivalent mass of Al = 27 / 3 = 9. So 1 F gives 9 g.  3 F gives 27 g.
   The two routes agree.)
```

# TOPIC 10 — EXTRACTION OF IRON: THE BLAST FURNACE  *** 8-mark favourite ***

## 10.1 The ore and the charge

```
   MAIN ORE:  HAEMATITE  Fe2O3    (also magnetite Fe3O4)

   THE CHARGE fed in at the top, in the ratio roughly 8 : 4 : 1

   +-------------------+---------------------------------------------+
   |  ROASTED /        |  Fe2O3  -  the source of iron               |
   |  CALCINED ORE     |                                             |
   +-------------------+---------------------------------------------+
   |  COKE             |  C  -  acts as (a) the FUEL and             |
   |                   |        (b) the REDUCING AGENT (via CO)      |
   +-------------------+---------------------------------------------+
   |  LIMESTONE        |  CaCO3  -  the FLUX. On heating it gives    |
   |                   |  CaO which removes the SiO2 gangue as slag. |
   +-------------------+---------------------------------------------+

   Also blown in:  a HOT AIR BLAST at about 1500 K through pipes
                   called TUYERES near the bottom.
```

Before charging, the ore is **calcined/roasted** to remove moisture, CO2, S and As,
and to convert FeO into Fe2O3.

## 10.2 THE BLAST FURNACE DIAGRAM

```
      B L A S T   F U R N A C E   (about 30 m tall)

                  CHARGE:  Fe2O3 + coke + limestone
                            |||||||||
                            \\\|||///
                              \\|//
             +----------------[ ]----------------+  <-- CUP AND CONE
             |                                   |      arrangement
             |     WASTE GASES OUT  <---+        |      (keeps gases in)
             |     (CO, CO2, N2)        |        |
             |                                   |
     ZONE 1  |   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  |   500 - 800 K
     ZONE OF |   Fe2O3 + 3 CO --> 2 Fe + 3 CO2   |   "spongy iron" forms
     REDUCTION|  Fe3O4 + 4 CO --> 3 Fe + 4 CO2   |
             |   CaCO3 --> CaO + CO2             |
             |                                   |
             +-----------------------------------+
             |                                   |
     ZONE 2  |   ################################|   900 - 1500 K
     ZONE OF |   CaO + SiO2 --> CaSiO3  (SLAG)   |
     SLAG    |   FeO + SiO2 --> FeSiO3           |
     FORMATION|  C + CO2 --> 2 CO  (endothermic) |
             |                                   |
             +-----------------------------------+
             |          THE BOSHES                |
     ZONE 3  |   ******************************  |   1500 - 2200 K
     ZONE OF |   C + O2 --> CO2   (exothermic)   |   THE HOTTEST ZONE
     COMBUSTION|  2 C + O2 --> 2 CO               |
             |                                   |
    TUYERES  ==>  HOT AIR BLAST (1500 K)  <==     |
             |                                   |
             +-----------------------------------+
             |   ,,,,,,,,,,,,,,,,,,,,,,,,,,,,,   |
             |   ,,,,,   MOLTEN SLAG   ,,,,,,,   |----> SLAG TAP HOLE
             |   ---------------------------------|      (slag is LIGHTER,
             |   ========= MOLTEN IRON ==========|       floats on top)
             +--------------|--------------------+
                            |
                       IRON TAP HOLE  ---->  MOLTEN PIG IRON
                                              run into moulds ("pigs")
```

## 10.3 ALL the reactions, zone by zone

```
  ==================================================================
  ZONE 3 - ZONE OF COMBUSTION  (bottom, near the tuyeres, 1500-2200 K)
  ==================================================================

      C  +  O2   -->   CO2          delta H is NEGATIVE (exothermic)
                                     this is what HEATS the whole furnace

      Higher up, the CO2 meets more red hot coke:

      CO2  +  C   -->   2 CO        delta H is POSITIVE (endothermic)

      So the reducing agent CO is manufactured inside the furnace itself.


  ==================================================================
  ZONE 2 - ZONE OF SLAG FORMATION  (middle, 900-1500 K)
  ==================================================================

      CaCO3   --(heat)-->   CaO  +  CO2      (limestone decomposes)

      CaO   +   SiO2   -->   CaSiO3          <--- THE SLAG
      FLUX      GANGUE        (calcium silicate)

      FeO   +   SiO2   -->   FeSiO3          (a loss of iron - so the ore
                                              must be well roasted first)

      At this temperature some DIRECT reduction by coke also happens:

      FeO   +   C   -->   Fe   +   CO


  ==================================================================
  ZONE 1 - ZONE OF REDUCTION  (top, 500-800 K)
  ==================================================================

      3 Fe2O3  +  CO   -->   2 Fe3O4  +  CO2

      Fe3O4    +  CO   -->   3 FeO    +  CO2

      FeO      +  CO   -->   Fe       +  CO2

      Overall:      Fe2O3  +  3 CO   -->   2 Fe  +  3 CO2

      The iron formed here is a porous solid called SPONGY IRON.
      As it sinks it absorbs carbon and melts.
```

**Also happening near the top (drying / preheating, below 500 K):** the charge is
dried and any remaining moisture and CO2 are driven off.

## 10.4 The role of limestone — a classic 2-mark question

```
  +---------------------------------------------------------------------+
  |  Limestone CaCO3 is added as a FLUX.                                |
  |                                                                     |
  |  1) It decomposes:     CaCO3  -->  CaO  +  CO2                      |
  |                                                                     |
  |  2) The CaO produced is BASIC. It combines with the ACIDIC          |
  |     silica gangue:                                                  |
  |                        CaO  +  SiO2  -->  CaSiO3                    |
  |                                                                     |
  |  3) The calcium silicate SLAG is fusible and LIGHT. It floats on    |
  |     the molten iron and is drawn off separately, so the iron is     |
  |     protected from re-oxidation.                                    |
  |                                                                     |
  |  Bonus: the CO2 released reacts with coke to give more CO,          |
  |  the reducing agent.                                                |
  +---------------------------------------------------------------------+
```

## 10.5 The four forms of iron — learn this table

```
  +--------------+-----------+---------------------------------------------+
  |  FORM        | % CARBON  |  DESCRIPTION                                |
  +--------------+-----------+---------------------------------------------+
  |  PIG IRON    |  4 %      |  Straight out of the blast furnace.         |
  |              |  (about   |  Contains 4% C plus S, P, Si, Mn.           |
  |              |  4-4.5)   |  Hard and BRITTLE. Cannot be welded.        |
  +--------------+-----------+---------------------------------------------+
  |  CAST IRON   |  3 %      |  Pig iron melted with scrap iron and coke   |
  |              |  (about   |  under a hot air blast.                     |
  |              |  2.5-3.5) |  Hard, brittle, EXPANDS on solidifying, so  |
  |              |           |  it takes a sharp cast. Used for pipes,     |
  |              |           |  railings, engine blocks, manhole covers.   |
  +--------------+-----------+---------------------------------------------+
  |  WROUGHT     |  0.2 -    |  The PUREST form of commercial iron.        |
  |  IRON        |  0.5 %    |  Made by PUDDLING pig iron in a             |
  |  (malleable  |  (lowest) |  reverberatory furnace lined with           |
  |   iron)      |           |  haematite. SOFT, MALLEABLE, DUCTILE,       |
  |              |           |  can be welded. Used for chains, bolts,     |
  |              |           |  cores of electromagnets, wire.             |
  +--------------+-----------+---------------------------------------------+
  |  STEEL       |  0.2 -    |  Pig iron with the carbon reduced to a      |
  |              |  1.5 %    |  CONTROLLED level (Bessemer converter /     |
  |              |           |  L-D process / open hearth).                |
  |              |           |  The most useful form. Strength depends     |
  |              |           |  on the carbon %:                           |
  |              |           |    mild steel  0.2-0.5 %                    |
  |              |           |    hard steel  0.5-1.5 %                    |
  +--------------+-----------+---------------------------------------------+

  CARBON CONTENT ORDER:   pig iron > cast iron > steel > wrought iron
  PURITY ORDER (reverse): wrought iron > steel > cast iron > pig iron
```

**Wrought iron by PUDDLING (one line):** pig iron is melted in a reverberatory
furnace lined with haematite; the Fe2O3 lining oxidises the carbon away as CO:

```
    Fe2O3  +  3 C   -->   2 Fe  +  3 CO
```

**Steel-making, the L-D (basic oxygen) process (one line):** molten pig iron in a
converter is hit with a jet of pure **oxygen** at high pressure through a lance;
the C, Si, Mn and P burn out, and the required amount of carbon is then added back
as **spiegeleisen** (an Fe-Mn-C alloy).

## WORKED EXAMPLE 7

**Q. In the blast furnace, 1 mole of Fe2O3 is reduced by CO. How many moles of CO
are needed and what mass of iron is produced? (Fe = 56, O = 16)**

```
  STEP 1  The equation:      Fe2O3  +  3 CO   -->   2 Fe  +  3 CO2

  STEP 2  1 mole Fe2O3 needs 3 moles of CO.

  STEP 3  1 mole Fe2O3 gives 2 moles of Fe
                            =  2 x 56  =  112 g of iron.

  ANSWER: 3 moles of CO are required; 112 g of iron are produced.

  (Sanity check with Worked Example 1: Fe2O3 is 160 g/mol and 70% iron.
   70 % of 160 = 112 g. The two agree.)
```

# TOPIC 11 — EXTRACTION OF COPPER (in outline)

**Main ore:** copper pyrites, **CuFeS2**.

```
  STEP 1  CRUSHING and CONCENTRATION by FROTH FLOTATION
          (it is a sulphide ore)

  STEP 2  ROASTING in a reverberatory furnace with a limited supply of air

          2 CuFeS2  +  O2   -->   Cu2S  +  2 FeS  +  SO2

          S + O2 -> SO2  and  4 As + 3 O2 -> 2 As2O3   (impurities removed)

  STEP 3  SMELTING in a blast furnace with SILICA (SiO2) as the flux

          2 FeS  +  3 O2   -->   2 FeO  +  2 SO2

          FeO   +   SiO2   -->   FeSiO3        <--- SLAG (removed)
          BASIC     ACIDIC        (ferrous silicate)
          GANGUE    FLUX

          The molten mass left behind is  Cu2S + FeS  =  COPPER MATTE.

  STEP 4  BESSEMERISATION - the matte is put in a BESSEMER CONVERTER,
          lined with silica, and hot air is blown through:

          2 FeS   +  3 O2  -->  2 FeO  +  2 SO2
          FeO     +  SiO2  -->  FeSiO3               (last of the iron removed)

          2 Cu2S  +  3 O2  -->  2 Cu2O  +  2 SO2     (partial roasting)

          2 Cu2O  +  Cu2S  -->  6 Cu    +  SO2       <--- SELF REDUCTION

  RESULT: BLISTER COPPER - about 98 % pure. It is called "blister" because
          the SO2 escaping as it solidifies leaves BLISTERS on the surface.

  STEP 5  REFINING by ELECTROLYSIS  ->  99.95 % pure copper.
```

```
  CuFeS2 --froth--> conc. ore --roast--> Cu2S+FeS --smelt(SiO2)--> MATTE
                                                                     |
                                                            Bessemerisation
                                                                     |
                                                                     v
                                            BLISTER COPPER (98%) --electrolysis--> PURE Cu
```

> **TRAP:** In copper extraction the FLUX is **SiO2 (acidic)** because the impurity
> FeO is **basic**. This is the exact opposite of the blast furnace. Examiners love
> this contrast.

# TOPIC 12 — EXTRACTION OF ZINC (in outline)

**Main ores:** zinc blende **ZnS**, calamine **ZnCO3**.

```
  STEP 1  CONCENTRATION
             ZnS      ->  FROTH FLOTATION   (sulphide)
             ZnCO3    ->  hydraulic washing / hand picking

  STEP 2  CONVERSION TO OXIDE
             ROASTING (from ZnS):    2 ZnS + 3 O2 --> 2 ZnO + 2 SO2
             CALCINATION (from ZnCO3):  ZnCO3 --> ZnO + CO2

  STEP 3  REDUCTION - SMELTING with coke at about 1673 K in a
          fire-clay retort:

             ZnO   +   C   --(1673 K)-->   Zn   +   CO

          Zinc BOILS at 1180 K, so at 1673 K the zinc comes off as a
          VAPOUR. It is condensed in a receiver. The zinc so obtained is
          called SPELTER (about 97-98 % pure).

  STEP 4  REFINING
             - by DISTILLATION (zinc is volatile), or
             - by ELECTROLYTIC REFINING using ZnSO4 + dil. H2SO4
```

```
   WHY IS ZINC A VAPOUR?
      Zinc boils at 1180 K but the reduction needs about 1673 K.
      So the metal is formed ABOVE its boiling point and distils out.
      This is a small mercy: distillation also purifies it.

   NOTE: some zinc vapour is re-oxidised by the CO2 in the furnace gases,
         so the receivers are packed with a little coal dust to keep the
         atmosphere reducing.
```

# TOPIC 13 — REFINING (PURIFICATION) OF METALS

Seven methods. Each is chosen because of one specific property of the metal.

```
  +----------------------+-----------------------------------------------+
  |  METHOD              |  CHOOSE IT WHEN ...                           |
  +----------------------+-----------------------------------------------+
  |  Distillation        |  the METAL is volatile, impurities are not    |
  |  Liquation           |  the METAL melts at a low temperature         |
  |  Poling              |  the impurity is the metal's OWN OXIDE        |
  |  Electrolytic        |  the metal conducts and a soluble salt exists |
  |  Zone refining       |  ULTRA-pure metal is needed (semiconductors)  |
  |  Vapour phase        |  the metal forms an unstable volatile compound|
  |  Chromatography      |  impurities are chemically very similar, or   |
  |                      |  the amounts are tiny                         |
  +----------------------+-----------------------------------------------+
```

## 13.1 DISTILLATION

**Principle:** the metal is **volatile** (low boiling point); the impurities are not.
Heat, let the metal boil off, and condense the vapour.

**Used for:** **zinc, mercury, cadmium.**

```
      +---------------+
      | impure metal  |  heat
      |   heated      |======>  metal VAPOUR
      +---------------+              |
             |                       v
      non-volatile              +----------+
      impurities left           | CONDENSER|
      behind in the             +----------+
      retort                         |
                                     v
                                PURE METAL
```

## 13.2 LIQUATION

**Principle:** the metal has a **low melting point**; the impurities have a high one.
Heat a sloping hearth so the metal melts and **runs down**, leaving the solid
impurities behind.

**Used for:** **tin (Sn), lead, bismuth.**

```
       impure metal placed here
              |
              v
      \  * * * * * * * * *
       \  * impurities *  \        <-- sloping hearth, gently heated
        \   stay behind    \
         \                  \
          \   ~~~~~~~~~~~~~~ \
           \  MOLTEN PURE METAL\
            \    FLOWS DOWN      \
             \____________________\
                     |
                     v
              collected pure
```

## 13.3 POLING

**Principle:** the impurity is the **oxide of the metal itself**. Stir the molten
metal with **green wood poles**. The wood gives off hydrocarbons (like CH4) which
act as **reducing agents** and reduce the oxide back to metal.

**Used for:** **copper (Cu2O impurity)** and **tin (SnO2 impurity)**.

```
        green wood pole  ->  releases CH4 and other hydrocarbons
              ||
              ||
     +--------||---------------+
     |  ~~~~~~||~~~~~~~~~~~~~  |
     |  ~ MOLTEN IMPURE Cu  ~  |
     |  ~ containing Cu2O   ~  |     Cu2O  +  CH4  -->  Cu  +  CO  +  H2O
     |  ~~~~~~~~~~~~~~~~~~~~~  |     (reducing gases from the wood)
     +-------------------------+
```

## 13.4 ELECTROLYTIC REFINING — a guaranteed 4-mark question

**Principle:** the **impure metal is made the ANODE** and a **thin strip of the pure
metal is made the CATHODE**, in a solution of a soluble salt of the metal. On passing
current, the metal dissolves from the anode and plates out pure on the cathode.

```
  +---------------------------------------------------------------------+
  |  ANODE        =  block of IMPURE metal          (connected to +)    |
  |  CATHODE      =  thin sheet of PURE metal       (connected to -)    |
  |  ELECTROLYTE  =  a soluble salt of the metal, usually acidified     |
  |                                                                     |
  |  AT THE ANODE   :   M   -->   M^n+   +   n e-     (DISSOLUTION)     |
  |  AT THE CATHODE :   M^n+  +  n e-   -->  M        (DEPOSITION)      |
  +---------------------------------------------------------------------+
```

### The set-up for copper

```
     E L E C T R O L Y T I C   R E F I N I N G   O F   C O P P E R

          (+) ANODE                        CATHODE (-)
          impure Cu                        thin pure Cu strip
              ||                                ||
        +-----||--------------------------------||-----+
        |     ||                                ||     |
        |  ~~~||~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~||~~~  |
        |  ~   ELECTROLYTE :                      ~    |
        |  ~   CuSO4 solution acidified with      ~    |
        |  ~   dilute H2SO4                       ~    |
        |  ~                                      ~    |
        |  ~   Cu2+ ions travel  ------------->   ~    |
        |  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  |
        |     ,,,,,,,,,,,,,                            |
        |     ,ANODE MUD ,   <-- Ag, Au, Pt, Se, Te    |
        +-----,,,,,,,,,,,,,----------------------------+

     AT THE ANODE:     Cu(s)          -->  Cu2+(aq)  +  2 e-
     AT THE CATHODE:   Cu2+(aq) + 2e- -->  Cu(s)     (99.95 % pure)
```

### ANODE MUD (a favourite 2-mark question)

```
  +---------------------------------------------------------------------+
  |  ANODE MUD (anode sludge) is the insoluble residue that settles     |
  |  BELOW THE ANODE during electrolytic refining.                      |
  |                                                                     |
  |  WHY does it form?                                                  |
  |     The LESS electropositive impurities (Ag, Au, Pt, Se, Te)        |
  |     are NOT oxidised at the anode potential used, so they simply    |
  |     drop off as the copper around them dissolves away.              |
  |                                                                     |
  |  MORE electropositive impurities (Zn, Fe, Ni) DO dissolve, but      |
  |  they are harder to reduce than Cu2+, so they STAY IN SOLUTION      |
  |  and are not deposited on the cathode.                              |
  |                                                                     |
  |  The anode mud is VALUABLE - the recovered silver, gold and         |
  |  platinum often pay for the whole refining operation.               |
  +---------------------------------------------------------------------+
```

Other metals refined this way: **Cu, Ag, Au, Ni, Al, Zn, Pb, Cr.**

```
   Electrolytes used:
      Cu  ->  CuSO4 + dil. H2SO4
      Ag  ->  AgNO3 + dil. HNO3
      Ni  ->  NiSO4 + dil. H2SO4
      Zn  ->  ZnSO4 + dil. H2SO4
```

## 13.5 ZONE REFINING (fractional crystallisation)

**Principle:** **impurities are more soluble in the MOLTEN metal than in the SOLID
metal.** So when a molten zone is moved slowly along a rod, the impurities travel
with it and are swept to one end.

**Used for:** **silicon (Si), germanium (Ge), gallium (Ga), boron (B), indium** —
the SEMICONDUCTOR elements, where purity of the order of 1 part in 10^10 is needed.

```
      Z O N E   R E F I N I N G

    circular mobile heater ------->  moves SLOWLY in this direction
         ______
        (  ##  )
   =====[  ##  ]=================================================
   | SOLID| MOLTEN |  SOLID (already purified metal)           |
   | pure |  ZONE  |                                            |
   ======[  ##  ]=================================================
        (  ##  )
         ------
   ^                                                            ^
   PURE END                                        IMPURITIES PUSHED
   (behind the heater the metal                     TO THIS END and
    re-solidifies PURE)                             cut off and discarded

   The heater is passed along the rod SEVERAL TIMES in the SAME direction.
   Each pass pushes the impurities further towards the far end.
   Finally the impure end is simply CUT OFF.
```

> **TRAP:** The heater must move in **one direction only**, repeatedly. If you move
> it back and forth, you undo the separation.

## 13.6 VAPOUR PHASE REFINING

**Principle:** the metal is converted into a **volatile compound** which is then
**decomposed** to give the pure metal. Two conditions must be met:

```
   1) The metal must form a VOLATILE compound with the reagent.
   2) That compound must be EASILY DECOMPOSED, so the metal is
      recovered easily.
```

### (a) MOND'S PROCESS for NICKEL

```
   STEP 1   Heat the impure nickel in a stream of CARBON MONOXIDE at
            330 - 350 K.  A volatile complex is formed:

            Ni(s)  +  4 CO(g)  --(330-350 K)-->  Ni(CO)4(g)
            impure                                nickel tetracarbonyl
                                                  (VOLATILE, boils at 43 deg C)

            The impurities do NOT form carbonyls and are left behind.

   STEP 2   Heat the vapour to a HIGHER temperature, 450 - 470 K.
            The carbonyl decomposes:

            Ni(CO)4(g)  --(450-470 K)-->  Ni(s)  +  4 CO(g)
                                          PURE      (recycled)
```

```
    impure Ni  --[ CO , 330-350 K ]-->  Ni(CO)4 vapour  --[ 450-470 K ]--> PURE Ni
        |                                                                     ^
        +-- impurities left behind                  CO recycled --------------+
```

### (b) VAN ARKEL METHOD for ZIRCONIUM and TITANIUM

Used to make ultra-pure Zr and Ti for the **nuclear industry**. It removes
**oxygen and nitrogen** impurities, which is what these metals must be free of.

```
   STEP 1   Heat the crude metal with IODINE at about 870 K:

            Zr(s)  +  2 I2(g)  --(870 K)-->  ZrI4(g)
            Ti(s)  +  2 I2(g)  --(heat)-->   TiI4(g)

            The O and N impurities do NOT react with iodine.

   STEP 2   Pass the volatile iodide over a WHITE HOT TUNGSTEN FILAMENT
            at about 1800 K. It decomposes and pure metal deposits on
            the filament:

            ZrI4(g)  --(1800 K, W filament)-->  Zr(s)  +  2 I2(g)
            TiI4(g)  --(1800 K, W filament)-->  Ti(s)  +  2 I2(g)
```

```
      V A N   A R K E L   ( I O D I D E )   P R O C E S S

     +---------------------------------------------+
     |                                             |
     |         ~~~~~~~~~~~~~~~~~~~~~~~~            |
     |         ~   ZrI4  VAPOUR       ~            |
     |         ~        |             ~            |
     |         ~        v             ~            |
     |         ~   |||||||||||        ~   <-- TUNGSTEN FILAMENT
     |         ~   ||  1800 K ||      ~       (white hot)
     |         ~   |||||||||||        ~       PURE Zr deposits ON it
     |         ~                      ~            |
     |         ~~~~~~~~~~~~~~~~~~~~~~~            |
     |     crude Zr + I2 heated at 870 K here     |
     +---------------------------------------------+
                            ^
                   I2 is regenerated and reused
```

> **TRAP:** Mond = **nickel + carbon monoxide**. Van Arkel = **Zr/Ti + iodine +
> tungsten filament**. Students swap the two. Memory hook: "**M**ond uses
> **M**onoxide."

## 13.7 CHROMATOGRAPHIC METHODS

**Principle:** different components of a mixture are **adsorbed to different extents**
on an adsorbent (the **stationary phase**), so a moving solvent (the **mobile phase**)
carries them along at different speeds and separates them.

```
   Mobile phase (solvent) carries the mixture DOWN a column of the
   stationary phase (e.g. Al2O3).

        +----+
        | ** |   <-- mixture put on top
        |    |
        | ## |   ---> the LESS strongly adsorbed component moves FASTER
        | ## |        and comes out FIRST
        | oo |   ---> the MORE strongly adsorbed component lags behind
        |    |
        +-|--+
          v
     collected in fractions (ELUTION)
```

**Used for:** purifying elements available only in **very small amounts**, and for
separating impurities that are **not very different chemically**. Especially useful
for **lanthanoids** and for purifying **germanium**.

**Types:** column chromatography, paper chromatography, gas chromatography.

# TOPIC 14 — USES OF THE FOUR METALS

## ALUMINIUM

```
   - Light, strong alloys (duralumin, magnalium) for AIRCRAFT and vehicles.
   - Electrical transmission cables (light, good conductor, cheap).
   - Aluminium foil for packaging food; cooking utensils.
   - Aluminium powder in PAINTS (silver paint) and in the THERMITE process.
   - Deoxidiser in steel making.
   - Doors, window frames, ladders (corrosion resistant - a protective
     Al2O3 layer forms on the surface).
```

## COPPER

```
   - ELECTRICAL WIRES and cables (best cheap conductor after silver).
   - Water and steam pipes; boilers; calorimeters.
   - Alloys:   BRASS      = Cu + Zn
               BRONZE     = Cu + Sn
               GUN METAL  = Cu + Zn + Sn
               GERMAN SILVER = Cu + Zn + Ni
   - Coins, utensils, electroplating.
```

## ZINC

```
   - GALVANISING iron and steel to prevent rusting (the single biggest use).
   - Making alloys - brass, german silver.
   - The container / negative electrode of DRY CELLS.
   - Zinc dust as a REDUCING AGENT (e.g. displacing Au and Ag in the
     cyanide process).
   - ZnO in white paint, rubber, cosmetics and medicines.
```

## IRON

```
   - CAST IRON  : pipes, railings, engine blocks, manhole covers, stoves.
   - WROUGHT IRON: chains, bolts, horseshoes, wire, cores of electromagnets.
   - STEEL      : buildings, bridges, rails, machinery, tools, vehicles,
                  ships, reinforcement bars.
   - STAINLESS STEEL (Fe + Cr + Ni) : cutlery, utensils, surgical instruments.
   - Iron compounds in medicines (for anaemia) and pigments.
```
