# 0. THE ONLY TWO ACTUAL FORMULAE IN THE CHAPTER

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   1)   delta G   =   delta H   -   T  delta S                       |
  |                                                                     |
  |        A reduction is FEASIBLE only if  delta G  <  0               |
  |                                                                     |
  |                                                                     |
  |   2)   delta G   =   -  n  F  E                                     |
  |                                                                     |
  |        n = moles of electrons                                       |
  |        F = 96500 C / mol                                            |
  |        E = cell EMF in volts                                        |
  |                                                                     |
  |        E POSITIVE  ->  delta G NEGATIVE  ->  FEASIBLE               |
  |                                                                     |
  +---------------------------------------------------------------------+

   Supporting relation:

        E(cell)  =  E(cathode)  -  E(anode)
```

| Formula | When to use |
|---|---|
| `delta G = delta H - T delta S` | "Is this reduction feasible?" / explaining the slope of an Ellingham line |
| `delta G = - n F E` | any question linking cell EMF to spontaneity, or displacement of Au/Ag by Zn |
| `E(cell) = E(cathode) - E(anode)` | to get E before using `delta G = -nFE` |
| `Equivalent mass = atomic mass / n` | Faraday numericals: 1 F deposits 1 equivalent mass |

# 1. THE VOCABULARY TABLE — 6 easy marks live here

| TERM | DEFINITION IN ONE LINE |
|---|---|
| **Metallurgy** | the whole process of extracting a metal from its ore and refining it |
| **Mineral** | any naturally occurring compound of a metal in the earth's crust |
| **Ore** | a mineral from which the metal can be extracted **conveniently and profitably** |
| **Gangue / Matrix** | the earthy, rocky, unwanted impurity mixed with the ore |
| **Flux** | a substance added to combine with the gangue and form a fusible slag |
| **Slag** | the fusible waste formed: `flux + gangue -> slag`; it is lighter and floats |
| **Pulverisation** | crushing and grinding the ore into a fine powder |
| **Concentration / Dressing** | removal of the gangue from the ore |
| **Calcination** | heating the ore strongly in the **absence** of air |
| **Roasting** | heating the ore strongly in **excess** of air |
| **Smelting** | reduction of the oxide by carbon/CO in a furnace, with a flux |
| **Leaching** | dissolving the ore in a chemical in which the gangue is insoluble |
| **Matte** | the molten `Cu2S + FeS` mixture in copper extraction |
| **Blister copper** | 98% pure copper, blistered by escaping SO2 |
| **Anode mud** | insoluble sludge under the anode in electro-refining: Ag, Au, Pt, Se, Te |
| **Spelter** | the impure (97-98%) zinc obtained by smelting |
| **Spongy iron** | the porous solid iron formed in the reduction zone of the blast furnace |
| **Tuyeres** | the pipes through which the hot air blast enters the blast furnace |
| **Refining** | purification of the crude metal |

```
   THE LINE THE EXAMINER WANTS:

        ALL ORES ARE MINERALS, BUT ALL MINERALS ARE NOT ORES.

   THE EXAMPLE THE EXAMINER WANTS:

        BAUXITE  Al2O3.2H2O           ->  an ORE of aluminium (cheap to extract)
        CLAY     Al2O3.2SiO2.2H2O     ->  a MINERAL but NOT an ore (too costly)
```

# 4. CONCENTRATION — which method, and why

```
  +------------------------+-------------------------+--------------------+
  |  METHOD                |  PRINCIPLE              |  SUITS             |
  +------------------------+-------------------------+--------------------+
  |  HYDRAULIC WASHING     |  difference in DENSITY  |  heavy OXIDE ores  |
  |  (gravity separation,  |  (ore heavy, gangue     |  Fe2O3 , SnO2 ,    |
  |   levigation)          |   light, washed away)   |  native gold       |
  +------------------------+-------------------------+--------------------+
  |  MAGNETIC SEPARATION   |  one part is MAGNETIC,  |  Fe3O4 , FeCr2O4   |
  |                        |  the other is not       |  SnO2 with FeWO4   |
  +------------------------+-------------------------+--------------------+
  |  FROTH FLOTATION       |  ore is wetted by OIL,  |  SULPHIDE ores     |
  |                        |  gangue by WATER        |  ZnS, PbS, CuFeS2  |
  +------------------------+-------------------------+--------------------+
  |  LEACHING              |  ore DISSOLVES in a     |  bauxite, gold,    |
  |                        |  reagent, gangue does   |  silver            |
  |                        |  not                    |                    |
  +------------------------+-------------------------+--------------------+
```

## 4.1 Froth flotation — the four reagents

| REAGENT TYPE | EXAMPLES | JOB |
|---|---|---|
| **Collector** | pine oil, fatty acids, xanthates (sodium ethyl xanthate) | makes the ore water-repellent so it clings to air bubbles |
| **Froth stabiliser** | cresols, aniline | keeps the froth from bursting |
| **Depressant** | **NaCN**, NaOH | stops ONE sulphide from floating, so two ores can be separated |
| **Frothing agent** | pine oil, eucalyptus oil, camphor oil | produces the froth |

```
   THE DEPRESSANT EQUATION - write it, don't just describe it:

        4 NaCN   +   ZnS   -->   Na2[Zn(CN)4]   +   Na2S

   ZnS is coated and does NOT float.  PbS floats.
   -> This is how galena (PbS) is separated from zinc blende (ZnS).
```

## 4.2 Leaching — the three cases

```
  (a) BAYER PROCESS - bauxite

      Al2O3 + 2 NaOH + 3 H2O --(473-523 K, 35 bar)--> 2 Na[Al(OH)4]
      Fe2O3 , TiO2 left behind as RED MUD

      2 Na[Al(OH)4] + 2 CO2  -->  Al2O3.xH2O  +  2 NaHCO3

      Al2O3.xH2O  --(1470 K)-->  Al2O3  +  x H2O


  (b) CYANIDE PROCESS (MacArthur-Forrest) - gold and silver

      4 Au  + 8 NaCN + 2 H2O + O2  -->  4 Na[Au(CN)2] + 4 NaOH
      4 Ag  + 8 NaCN + 2 H2O + O2  -->  4 Na[Ag(CN)2] + 4 NaOH

      2 Na[Au(CN)2]  +  Zn  -->  Na2[Zn(CN)4]  +  2 Au
      2 Na[Ag(CN)2]  +  Zn  -->  Na2[Zn(CN)4]  +  2 Ag

      O2 OXIDISES the gold so it can complex.  Zn REDUCES it back out.


  (c) SILVER from argentite

      Ag2S  +  4 NaCN   <-->   2 Na[Ag(CN)2]  +  Na2S
```

# 5. CALCINATION vs ROASTING

| # | CALCINATION | ROASTING |
|---|---|---|
| 1 | **Absence** (or limited supply) of air | **Excess** of air |
| 2 | **Carbonate** and **hydrated oxide** ores | **Sulphide** ores |
| 3 | Gas evolved: **CO2** (and H2O) | Gas evolved: **SO2** |
| 4 | Thermal **decomposition**, no oxidation | An **oxidation** |
| 5 | Removes water of hydration, organic matter | Removes S, As, Sb as volatile oxides |
| 6 | Lower temperature | Higher temperature |
| 7 | `ZnCO3 -> ZnO + CO2` | `2 ZnS + 3 O2 -> 2 ZnO + 2 SO2` |
| 8 | Reverberatory furnace | Reverberatory or blast furnace |

```
   CALCINATION REACTIONS
      ZnCO3          --(heat, no air)-->  ZnO   + CO2       calamine
      CaCO3          --(heat)-->          CaO   + CO2       limestone
      FeCO3          --(heat)-->          FeO   + CO2       siderite
      MgCO3          --(heat)-->          MgO   + CO2       magnesite
      CuCO3.Cu(OH)2  --(heat)-->          2 CuO + CO2 + H2O malachite
      Fe2O3 . 3H2O   --(heat)-->          Fe2O3 + 3 H2O     limonite
      Al2O3 . 2H2O   --(heat)-->          Al2O3 + 2 H2O     bauxite

   ROASTING REACTIONS
      2 ZnS  +  3 O2  -->  2 ZnO   + 2 SO2        zinc blende
      2 PbS  +  3 O2  -->  2 PbO   + 2 SO2        galena
      2 Cu2S +  3 O2  -->  2 Cu2O  + 2 SO2        copper glance
      4 FeS2 + 11 O2  -->  2 Fe2O3 + 8 SO2        iron pyrites
      2 HgS  +  3 O2  -->  2 HgO   + 2 SO2   (then HgO -> Hg + O2)

      Impurities burnt off:
         S    + O2   -->  SO2
         4 As + 3 O2 -->  2 As2O3       (volatile, escapes)
         4 P  + 5 O2 -->  P4O10
```

```
   MEMORY HOOK
      CALCINATION  ->  C for CARBONATE, C for CO2, "Closed" (no air)
      ROASTING     ->  ROAST it in AIR; Sulphide gives SO2
```

# 6. THERMODYNAMICS AND THE ELLINGHAM DIAGRAM

## 6.1 The rules in a box

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   FEASIBLE  <=>  delta G  <  0                                      |
  |                                                                     |
  |   delta G  =  delta H  -  T delta S                                 |
  |                                                                     |
  |   COUPLING:  add a reaction with a large negative delta G to one    |
  |              with a positive delta G. If the SUM is negative,       |
  |              the overall process goes.                              |
  |                                                                     |
  |        MO  ->  M + 1/2 O2        delta G = + 200 kJ  (say)          |
  |        C   + 1/2 O2  ->  CO      delta G = - 250 kJ  (say)          |
  |        --------------------------------------------------           |
  |        MO  +  C   ->   M + CO    delta G = -  50 kJ  ->  GOES       |
  |                                                                     |
  +---------------------------------------------------------------------+
```

## 6.2 The Ellingham diagram — the fact card

```
  +---------------------------------------------------------------------+
  |  Y-AXIS  :  delta G of FORMATION of the oxide,                      |
  |             quoted PER MOLE OF O2 CONSUMED                          |
  |  X-AXIS  :  TEMPERATURE                                             |
  +---------------------------------------------------------------------+
  |  Most metal lines slope UPWARD because                              |
  |     2 M(s) + O2(g) -> 2 MO(s)  destroys a gas                       |
  |     -> delta S is NEGATIVE  -> slope = (-delta S) is POSITIVE       |
  +---------------------------------------------------------------------+
  |  The CARBON line slopes DOWNWARD because                            |
  |     2 C(s) + O2(g) -> 2 CO(g)  turns 1 mol gas into 2 mol gas       |
  |     -> delta S is POSITIVE  -> slope is NEGATIVE                    |
  +---------------------------------------------------------------------+
  |  CONSEQUENCE: the carbon line eventually CROSSES every metal line.  |
  |     Above the crossing temperature, CARBON CAN REDUCE that oxide.   |
  +---------------------------------------------------------------------+
  |  HOW TO READ IT: the element whose line lies LOWER can reduce the   |
  |     oxide whose line lies HIGHER, at that temperature.              |
  +---------------------------------------------------------------------+
```

```
    delta G (kJ per mole of O2)
      0 +--------------------------------------------------------
        |                                              ,-'
        |    Cu2O (highest, easiest to reduce)     ,-'
   -200 |    .................................  ,-'
        |    NiO                            ,-'    <-- 2C + O2 -> 2CO
        |    ___________________________ ,-'           SLOPES DOWN
   -400 |    FeO                      ,-'
        |    ____________________  ,-'  X
        |    ZnO               ,-'
   -600 |    _______________,-'
        |    Al2O3      ,-'
        |    _________,-'
   -800 |    MgO   ,-'
        |    ____,-'
        +--------------------------------------------------------> T
        0     500    1000   1500   2000   2500  (deg C)
```

## 6.3 Limitations of the Ellingham diagram

```
   1. It gives only FEASIBILITY (thermodynamics), NOT the RATE (kinetics).
   2. It assumes reactants and products are at equilibrium - often untrue.
   3. The simple interpretation fails if the products react further or
      form solutions / alloys with one another.
   4. Lines BEND at melting and boiling points (delta S changes there).
```

## 6.4 What the diagram tells you, in five lines

```
   Al2O3 line is BELOW Cr2O3 and Fe2O3   ->  Al reduces Cr2O3, Fe2O3 (THERMITE)
   C -> CO line drops below FeO ~ 1000 K ->  coke reduces FeO in the blast furnace
   MgO and Al2O3 lines are below the C line up to about 2000 deg C
                                          ->  carbon CANNOT reduce them cheaply
                                          ->  Mg and Al need ELECTROLYSIS
   MgO and Al2O3 lines CROSS at ~1350 deg C
                                          ->  Mg reduces Al2O3 BELOW 1350
                                          ->  Al reduces MgO ABOVE 1350
   Ag2O and HgO lines are very HIGH       ->  simple HEATING decomposes them
```

# 7. ELECTROCHEMISTRY OF METALLURGY

```
  +---------------------------------------------------------------------+
  |            delta G  =  - n F E          F = 96500 C/mol             |
  |                                                                     |
  |   E positive -> delta G negative -> the reaction is FEASIBLE        |
  |                                                                     |
  |   A metal with a LARGE NEGATIVE reduction potential is very         |
  |   electropositive -> its ion is very hard to reduce -> no chemical  |
  |   reducing agent is strong enough -> USE ELECTROLYSIS of the        |
  |   FUSED (molten) salt.                                              |
  +---------------------------------------------------------------------+
```

| METAL | ELECTROLYTE | PROCESS NAME | Cathode product |
|---|---|---|---|
| Na | fused NaCl + CaCl2 | **Down's process** | Na |
| Al | Al2O3 in molten Na3AlF6 + CaF2 | **Hall-Heroult** | Al |
| Mg | fused MgCl2 + NaCl + CaCl2 | **Dow process** | Mg |
| Ca | fused CaCl2 + CaF2 | — | Ca |

```
   WHY NOT AN AQUEOUS SOLUTION?
      2 H2O + 2 e- -> H2 + 2 OH-      E = -0.83 V
      Na+   +   e- -> Na              E = -2.71 V
      Water is reduced far more easily, so you get H2, not Na.
      -> ALWAYS use the FUSED salt.
```

# 8. REDUCTION METHODS — all five with equations

## 8.1 Carbon / CO smelting

```
   ZnO   +  C   --(1673 K)-->  Zn  +  CO
   PbO   +  C   --(heat)-->    Pb  +  CO
   SnO2  + 2 C  --(heat)-->    Sn  + 2 CO
   Fe2O3 + 3 CO --(heat)-->  2 Fe  + 3 CO2
   Cu2O  +  C   --(heat)-->  2 Cu  +  CO
```

## 8.2 Self reduction (auto-reduction)

```
   COPPER   2 Cu2S + 3 O2 --> 2 Cu2O + 2 SO2      (partial roasting)
            2 Cu2O + Cu2S --> 6 Cu   +   SO2      (SELF REDUCTION)

   LEAD     2 PbS  + 3 O2 --> 2 PbO  + 2 SO2
            2 PbO  + PbS  --> 3 Pb   +   SO2

   MERCURY    HgS  +  O2  -->   Hg   +   SO2
```

## 8.3 Thermite / aluminothermic (Goldschmidt) process

```
   Cr2O3   + 2 Al  -->  2 Cr  +  Al2O3      (chromium)
   3 Mn3O4 + 8 Al  -->  9 Mn  + 4 Al2O3     (manganese)
   Fe2O3   + 2 Al  -->  2 Fe  +  Al2O3      (THERMITE, welds rails)
   B2O3    + 2 Al  -->  2 B   +  Al2O3      (boron)

   Thermite mixture   =  Fe2O3 + Al powder  (about 3 : 1 by mass)
   Ignition mixture   =  BaO2 + Mg ribbon
   Temperature reached about 3000 deg C - the metal comes out MOLTEN.
   All these reactions are HIGHLY EXOTHERMIC.
```

## 8.4 Hydrogen reduction

```
   WO3  + 3 H2  --(heat)-->  W   + 3 H2O     (tungsten)
   MoO3 + 3 H2  --(heat)-->  Mo  + 3 H2O     (molybdenum)
   Ag2O +   H2  -->  2 Ag  +  H2O

   LIMITATION: alkali, alkaline earth metals and Ti form HYDRIDES with H2,
               so this method cannot be used for them. Also costly + explosive.
```

## 8.5 Electrolytic reduction

See section 7 table. The metal always appears at the **CATHODE**.

## 8.6 Which reduction method — decision table

| The metal is ... | Use | Example |
|---|---|---|
| highly electropositive (Na, K, Ca, Mg, Al) | **electrolysis of the fused salt** | Hall-Heroult |
| moderately reactive (Fe, Zn, Sn, Pb) | **C / CO smelting** | blast furnace |
| a low-reactivity sulphide (Cu, Pb, Hg) | **self reduction** | blister copper |
| forming a carbide with carbon (Cr, Mn, B) | **aluminothermite** | thermite |
| needed ultra-pure, forms no hydride (W, Mo) | **hydrogen** | WO3 + 3H2 |
| very unreactive (Au, Ag, Pt) | **leaching + Zn displacement** | cyanide process |

# 9. EXTRACTION OF ALUMINIUM — the full equation set

## 9.1 Bayer process (purification)

```
   1)  Al2O3 + 2 NaOH + 3 H2O  --(473-523 K, 35 bar)-->  2 Na[Al(OH)4]
                                    Fe2O3 , TiO2  ->  RED MUD (filtered out)

   2)  2 Na[Al(OH)4] + 2 CO2   -->  Al2O3 . x H2O  +  2 NaHCO3
                                    (seeded with fresh Al2O3.xH2O)

   3)  Al2O3 . x H2O  --(1470 K)-->  Al2O3  +  x H2O
```

**Serpeck's process** (for high-silica bauxite):

```
   Al2O3 + 3 C + N2  --(1800 deg C)-->  2 AlN + 3 CO
   AlN   + 3 H2O     -->  Al(OH)3 + NH3
   2 Al(OH)3         --(heat)-->  Al2O3 + 3 H2O
```

## 9.2 Hall-Heroult process (reduction)

```
  +---------------------------------------------------------------------+
  |  ELECTROLYTE     Al2O3        about 20 %                            |
  |                  Na3AlF6      about 60 %   (CRYOLITE)               |
  |                  CaF2         about 20 %   (FLUORSPAR)              |
  |  TEMPERATURE     about 1140 K   (~870-950 deg C)                    |
  |  VOLTAGE         4 - 6 V        CURRENT   very large (~10^5 A)      |
  |  ANODE           GRAPHITE rods (consumed)                           |
  |  CATHODE         the GRAPHITE LINING of the iron tank               |
  +---------------------------------------------------------------------+

  IONISATION      Al2O3   -->  2 Al3+  +  3 O2-

  CATHODE         Al3+  +  3 e-   -->   Al(l)

  ANODE           2 O2-   -->   O2   +   4 e-
                  C  +  O2   -->   CO2
                  C  +  1/2 O2  -->  CO

  OVERALL         2 Al2O3  +  3 C   -->   4 Al  +  3 CO2
```

| ROLE OF | WHAT IT DOES |
|---|---|
| **Cryolite Na3AlF6** | lowers the melting point of Al2O3 from ~2323 K to ~1140 K; increases conductivity |
| **Fluorspar CaF2** | lowers the melting point further; increases fluidity and conductivity |
| **Graphite anode** | conducts current AND is deliberately burnt by the liberated O2, which lowers the voltage needed — so the anodes must be replaced periodically |
| **Graphite lining** | acts as the cathode |

> Cryolite is only a **SOLVENT**. The aluminium comes from the **Al2O3**.

# 10. EXTRACTION OF IRON — the blast furnace fact card

## 10.1 The charge

```
   Roasted / calcined ore  Fe2O3      : 8 parts    - source of iron
   Coke                    C          : 4 parts    - FUEL + REDUCING AGENT
   Limestone               CaCO3      : 1 part     - FLUX
   Hot air blast at 1500 K through the TUYERES near the bottom
```

## 10.2 The three zones, temperatures and reactions

```
  +----------------+-------------+-----------------------------------------+
  |  ZONE          | TEMPERATURE |  REACTIONS                              |
  +----------------+-------------+-----------------------------------------+
  |  ZONE OF       |  500 - 800 K|  3 Fe2O3 + CO --> 2 Fe3O4 + CO2         |
  |  REDUCTION     |             |  Fe3O4   + CO --> 3 FeO   + CO2         |
  |  (TOP)         |             |  FeO     + CO --> Fe      + CO2         |
  |                |             |  CaCO3   --> CaO + CO2                  |
  |                |             |  -> gives porous SPONGY IRON            |
  +----------------+-------------+-----------------------------------------+
  |  ZONE OF SLAG  | 900 - 1500 K|  CaO + SiO2 --> CaSiO3   (SLAG)         |
  |  FORMATION     |             |  FeO + SiO2 --> FeSiO3                  |
  |  (MIDDLE)      |             |  CO2 + C    --> 2 CO     (endothermic)  |
  |                |             |  FeO + C    --> Fe + CO  (direct redn.) |
  +----------------+-------------+-----------------------------------------+
  |  ZONE OF       |1500 - 2200 K|  C   + O2   --> CO2      (EXOTHERMIC -  |
  |  COMBUSTION    |             |                  heats the furnace)     |
  |  (BOTTOM,      |             |  2 C + O2   --> 2 CO                    |
  |   the boshes)  |             |                                         |
  +----------------+-------------+-----------------------------------------+

  OVERALL REDUCTION:   Fe2O3  +  3 CO   -->   2 Fe   +   3 CO2
```

## 10.3 Role of limestone (2-mark answer, word for word)

```
   1)  CaCO3  --(heat)-->  CaO  +  CO2
   2)  CaO (BASIC flux) + SiO2 (ACIDIC gangue)  -->  CaSiO3  (SLAG)
   3)  The slag is fusible and LIGHT, floats on the molten iron, is
       tapped off separately, and protects the iron from re-oxidation.
   4)  The CO2 released reacts with coke to make more CO, the reducing agent.
```

## 10.4 The four forms of iron

| FORM | % CARBON | KEY PROPERTY | USES |
|---|---|---|---|
| **Pig iron** | ~4 % | hardest, most brittle, cannot be welded | raw material for cast iron and steel |
| **Cast iron** | ~3 % (2.5-3.5) | brittle, EXPANDS on solidifying (takes a sharp cast) | pipes, railings, engine blocks, manhole covers |
| **Steel** | 0.2 - 1.5 % | strong, controllable properties | buildings, rails, tools, vehicles |
| **Wrought iron** | 0.2 - 0.5 % | PUREST form; soft, malleable, ductile, weldable | chains, bolts, wire, electromagnet cores |

```
   CARBON:   pig iron > cast iron > steel > wrought iron
   PURITY:   wrought iron > steel > cast iron > pig iron

   Wrought iron is made by PUDDLING pig iron in a reverberatory furnace
   lined with haematite:      Fe2O3 + 3 C  -->  2 Fe + 3 CO

   Steel is made in a Bessemer converter / L-D (basic oxygen) process:
   pure O2 is blown through molten pig iron to burn out C, Si, Mn, P;
   then SPIEGELEISEN (Fe-Mn-C alloy) is added to restore the carbon.

   STAINLESS STEEL  =  Fe + Cr (about 12-18%) + Ni
```

# 11. EXTRACTION OF COPPER — the equation chain

```
   ORE: copper pyrites CuFeS2

   1) FROTH FLOTATION            (concentration - it is a sulphide)

   2) ROASTING (limited air)
         2 CuFeS2 + O2  -->  Cu2S + 2 FeS + SO2
         S + O2 -> SO2 ;  4 As + 3 O2 -> 2 As2O3

   3) SMELTING with SILICA flux in a blast furnace
         2 FeS + 3 O2  -->  2 FeO + 2 SO2
         FeO   + SiO2  -->  FeSiO3          <-- SLAG removed
         Molten Cu2S + FeS left  =  COPPER MATTE

   4) BESSEMERISATION (silica-lined converter, hot air blast)
         2 FeS  + 3 O2 -->  2 FeO + 2 SO2
         FeO    + SiO2 -->  FeSiO3
         2 Cu2S + 3 O2 -->  2 Cu2O + 2 SO2
         2 Cu2O + Cu2S -->  6 Cu   +   SO2   <-- SELF REDUCTION

         Product = BLISTER COPPER, about 98 % pure

   5) ELECTROLYTIC REFINING  ->  99.95 % pure Cu
```

> **FLUX WARNING:** in COPPER extraction the flux is **SiO2 (acidic)** because the
> impurity FeO is basic. In the **BLAST FURNACE** the flux is **CaCO3/CaO (basic)**
> because the gangue SiO2 is acidic. Opposite ways round.

# 12. EXTRACTION OF ZINC — the equation chain

```
   ORES: zinc blende ZnS , calamine ZnCO3

   1) CONCENTRATION      ZnS   -> froth flotation
                         ZnCO3 -> hydraulic washing / hand picking

   2) CONVERSION TO OXIDE
         2 ZnS + 3 O2  --(ROASTING)-->  2 ZnO + 2 SO2
         ZnCO3         --(CALCINATION)-->  ZnO + CO2

   3) REDUCTION (smelting, fire-clay retort, coke)
         ZnO  +  C   --(1673 K)-->   Zn  +  CO

         Zn BOILS at 1180 K, so at 1673 K the zinc distils out as a
         VAPOUR and is condensed.  Product = SPELTER (97-98 % pure).
         Coal dust is added to the receivers to keep the atmosphere
         reducing (else Zn vapour is re-oxidised by CO2).

   4) REFINING           distillation  or  electrolytic refining
                         (electrolyte ZnSO4 + dil. H2SO4)
```

# 13. REFINING — the seven methods

| METHOD | PRINCIPLE | METALS |
|---|---|---|
| **Distillation** | the metal is volatile, impurities are not | **Zn, Hg, Cd** |
| **Liquation** | the metal has a low melting point; it runs down a sloping hearth | **Sn, Pb, Bi** |
| **Poling** | green wood poles release hydrocarbons that reduce the metal's own oxide | **Cu** (Cu2O), **Sn** (SnO2) |
| **Electrolytic refining** | impure metal = anode, pure metal = cathode, salt solution = electrolyte | **Cu, Ag, Au, Ni, Al, Zn, Pb, Cr** |
| **Zone refining** | impurities are more soluble in the MOLTEN metal than the solid | **Si, Ge, Ga, B, In** (semiconductors) |
| **Vapour phase refining** | form a volatile compound, then decompose it | **Ni** (Mond), **Zr, Ti** (van Arkel) |
| **Chromatography** | different components adsorb to different extents | lanthanoids, Ge, tiny quantities |

## 13.1 Electrolytic refining

```
   ANODE       = impure metal block          M  -->  M^n+  +  n e-
   CATHODE     = thin strip of pure metal    M^n+ + n e-  -->  M
   ELECTROLYTE = a soluble salt of the metal

   FOR COPPER:  anode = impure Cu ; cathode = pure Cu strip
                electrolyte = CuSO4 + dilute H2SO4
                Cu  -->  Cu2+ + 2 e-      (anode)
                Cu2+ + 2 e-  -->  Cu      (cathode, 99.95 % pure)

   ANODE MUD (anode sludge) = the insoluble residue under the anode.
      Contains  Ag , Au , Pt , Se , Te
      WHY? These are LESS electropositive than Cu, so they are not
      oxidised at the working anode potential and just drop off.
      MORE electropositive impurities (Zn, Fe, Ni) dissolve but STAY
      in solution because they are harder to reduce than Cu2+.

   Electrolytes:  Cu -> CuSO4 + H2SO4 ;  Ag -> AgNO3 + HNO3
                  Ni -> NiSO4 + H2SO4 ;  Zn -> ZnSO4 + H2SO4
```

## 13.2 Zone refining

```
   A circular mobile heater melts a narrow ZONE and is moved SLOWLY
   along the rod, ALWAYS IN THE SAME DIRECTION, several times.
   Impurities stay in the molten zone and are swept to one end,
   which is then CUT OFF.

   Used for SEMICONDUCTORS: Si, Ge, Ga, B, In - purity ~ 1 in 10^10.
```

## 13.3 Vapour phase refining

```
   MOND'S PROCESS  (NICKEL)
      Ni  +  4 CO   --(330 - 350 K)-->   Ni(CO)4      (volatile carbonyl)
      Ni(CO)4       --(450 - 470 K)-->   Ni  +  4 CO  (CO recycled)

   VAN ARKEL METHOD  (ZIRCONIUM and TITANIUM)
      Zr  +  2 I2   --(870 K)-->     ZrI4
      ZrI4          --(1800 K, tungsten filament)-->  Zr  +  2 I2

      Ti  +  2 I2   --(heat)-->      TiI4
      TiI4          --(1800 K, W filament)-->  Ti  +  2 I2

      Removes O and N impurities. Used for NUCLEAR-grade Zr and Ti.

   MEMORY HOOK:  "Mond uses Monoxide."   Van Arkel uses IODINE.
```
