# 5. THE FOUR CLASSIFICATIONS — ALL ON ONE PAGE
# ==========================================================

## 5.1 By SOURCE

| Class | Meaning | Examples |
|---|---|---|
| **Natural** | occur in nature | starch, cellulose, natural rubber, proteins, nucleic acids, silk, wool |
| **Semi-synthetic** | a natural polymer chemically modified | cellulose acetate (rayon), cellulose nitrate (gun cotton), vulcanised rubber |
| **Synthetic** | made entirely in a laboratory | polythene, PVC, nylon 6,6, Buna-S, Bakelite, Teflon |

## 5.2 By STRUCTURE

```
  LINEAR                 ---O---O---O---O---O---O---O---
                         ---O---O---O---O---O---O---O---
                         close packing, high density, high m.p.,
                         high tensile strength
                         HDPE, PVC, nylon 6,6, polyesters

  BRANCHED                       O       O
                                 |       |
                         ---O---O---O---O---O---O---
                                 |
                                 O
                         loose packing, low density, low m.p.,
                         low tensile strength
                         LDPE, amylopectin, glycogen

  CROSS-LINKED           ---O---O---O---O---O---
                                |         |
                         ---O---O---O---O---O---
                                |         |
                         ---O---O---O---O---O---
                         covalent bridges, hard, rigid, brittle,
                         cannot be remoulded
                         Bakelite, melamine-formaldehyde,
                         urea-formaldehyde, vulcanised rubber
```

## 5.3 By MODE OF POLYMERISATION

| Point | ADDITION (chain growth) | CONDENSATION (step growth) |
|---|---|---|
| Monomer | unsaturated, has C=C | bi- or tri-functional (-OH, -COOH, -NH2) |
| Small molecule lost | **NO** | **YES** — H2O, NH3, HCl, CH3OH |
| Molecular mass | exact multiple of monomer | not an exact multiple |
| Mechanism | free radical / cationic / anionic | ordinary functional group reactions, in steps |
| Speed of mass build-up | very fast, high mass at once | slow and steady |
| Empirical formula | same as the monomer | different from the monomers |
| Examples | polythene, PVC, Teflon, polystyrene, polypropene, Buna-S, Buna-N, neoprene | nylon 6, nylon 6,6, terylene, glyptal, Bakelite, melamine and urea resins, PHBV |

**One-second test:** *does the monomer have a C=C?* Yes -> addition.
Does it have -OH / -COOH / -NH2 instead? -> condensation.

## 5.5 THERMOPLASTIC vs THERMOSETTING (asked on its own)

| THERMOPLASTIC | THERMOSETTING |
|---|---|
| Linear / slightly branched | Heavily cross-linked 3-D network |
| No cross-links | Covalent cross-links |
| **Softens on heating, hardens on cooling** | **Sets permanently on heating** |
| Remoulded any number of times | Moulded only ONCE |
| Recyclable | Not recyclable — it chars |
| Soluble in some organic solvents | Insoluble |
| Soft, less brittle | Hard, rigid, brittle |
| Polythene, PVC, polystyrene, polypropene | Bakelite, urea-formaldehyde, melamine-formaldehyde |

# 6. THE FREE RADICAL MECHANISM — SKELETON TO REPRODUCE
# ==========================================================

```
  Initiator used:  BENZOYL PEROXIDE  (or acetyl peroxide, tert-butyl
                   peroxide)

  ---------------------------------------------------------------
  INITIATION
  ---------------------------------------------------------------
        O               O                        O
        ||              ||                       ||
   C6H5-C-O - O - C-C6H5     --heat-->     2 C6H5-C-O *
                  ||
                  O

        O
        ||
   C6H5-C-O *      ----->     C6H5 *   +   CO2

   C6H5 *  +  CH2 = CH2   ----->   C6H5 - CH2 - CH2 *

  ---------------------------------------------------------------
  PROPAGATION
  ---------------------------------------------------------------
   C6H5-CH2-CH2 *  +  CH2 = CH2  --->  C6H5-CH2-CH2-CH2-CH2 *

                ... repeated n times ...

   ---->  C6H5-(CH2-CH2)n-CH2-CH2 *

  ---------------------------------------------------------------
  TERMINATION
  ---------------------------------------------------------------
   C6H5-(CH2-CH2)n-CH2-CH2 *  +  * CH2-CH2-(CH2-CH2)m-C6H5

        ---->   C6H5-(CH2-CH2)n-CH2-CH2-CH2-CH2-(CH2-CH2)m-C6H5

                          POLYTHENE
  ---------------------------------------------------------------
```

# ==========================================================
# 7. NATURAL RUBBER AND VULCANISATION — FACT BOX
# ==========================================================

```
  +-------------------------------------------------------------------+
  |  Natural rubber  =  CIS - 1,4 - POLYISOPRENE                      |
  |  Monomer         =  isoprene = 2-methyl-1,3-butadiene             |
  |  Source          =  latex of the rubber tree                      |
  |                                                                   |
  |  WHY ELASTIC:  cis double bonds -> chains cannot pack closely ->  |
  |                weak intermolecular forces -> coiled chains can    |
  |                be stretched and spring back                       |
  |                                                                   |
  |  TRANS isomer  =  GUTTA PERCHA  -  hard, tough, NOT elastic       |
  +-------------------------------------------------------------------+

  DRAWBACKS OF RAW NATURAL RUBBER
  1. useful only from 283 K to 335 K
     (soft and sticky above 335 K, brittle below 283 K)
  2. low tensile strength
  3. low abrasion resistance
  4. absorbs a large amount of water
  5. soluble in non-polar solvents
  6. attacked by oxidising agents

  +-------------------------------------------------------------------+
  |  VULCANISATION                                                    |
  |  Heating raw rubber with SULPHUR + an additive at 373 - 415 K,    |
  |  so that sulphur forms CROSS-LINKS between the chains at their    |
  |  reactive double-bond sites.  (Charles Goodyear, 1839)            |
  |                                                                   |
  |   ~~~/\~~~/\~~~/\~~~/\~~~                                         |
  |          |         |          <-- sulphur bridges                 |
  |          S         S                                              |
  |          |         |                                              |
  |   ~~~/\~~~/\~~~/\~~~/\~~~                                         |
  |                                                                   |
  |   about  5 %  sulphur  ->  TYRE rubber                            |
  |   about 30 %  sulphur  ->  BATTERY CASE rubber (ebonite)          |
  |                                                                   |
  |  IMPROVES: tensile strength, controlled elasticity, wider useful  |
  |  temperature range, hardness, resistance to oxidation, abrasion   |
  |  and organic solvents; reduces water absorption                   |
  +-------------------------------------------------------------------+
```

# 10. THE ONLY NUMERICALS IN THE CHAPTER
# ==========================================================

```
  +----------------------------------------------------------------+
  |                                                                |
  |                        SUM ( Ni x Mi )                         |
  |   NUMBER AVERAGE  Mn = ---------------------                   |
  |                          SUM ( Ni )                            |
  |                                                                |
  |                        SUM ( Ni x Mi^2 )                       |
  |   WEIGHT AVERAGE  Mw = ---------------------                   |
  |                        SUM ( Ni x Mi )                         |
  |                                                                |
  |                          Mw                                    |
  |   POLYDISPERSITY  PDI = ------      always  >=  1              |
  |                          Mn                                    |
  |                                                                |
  |   DEGREE OF              mass of POLYMER                       |
  |   POLYMERISATION   n  = --------------------                   |
  |                          mass of MONOMER                       |
  |                                                                |
  +----------------------------------------------------------------+
```

| Formula | When to use |
|---|---|
| `Mn = SUM(Ni Mi) / SUM(Ni)` | question gives numbers/percentages of molecules and their masses and asks for the **number average** |
| `Mw = SUM(Ni Mi^2) / SUM(Ni Mi)` | same data, asks for the **weight average** |
| `PDI = Mw / Mn` | asks how uniform the chain lengths are; = 1 for natural polymers |
| `n = M(polymer) / M(monomer)` | asks for the **degree of polymerisation** of an ADDITION polymer |
| `M(polymer) = n x M(monomer)` | asks for the molecular mass given the degree of polymerisation |

# ==========================================================
# THE 12 FACTS TO WRITE ON YOUR PALM
# ==========================================================

```
   1.  Polymer = macromolecule made of many repeating monomer units
       joined by covalent bonds.

   2.  Degree of polymerisation = number of monomer units in one chain.

   3.  ADDITION: unsaturated monomer, NOTHING eliminated.
       CONDENSATION: bi/tri-functional monomer, SMALL MOLECULE eliminated.

   4.  Structure: LINEAR (HDPE, PVC) / BRANCHED (LDPE) /
       CROSS-LINKED (Bakelite).

   5.  Forces: ELASTOMER weakest  <  thermoplastic  <  FIBRE strongest.
       Thermosetting is held by covalent CROSS-LINKS.

   6.  Thermoplastic softens and can be REMOULDED; thermosetting sets
       ONCE and cannot.

   7.  Free radical mechanism = INITIATION, PROPAGATION, TERMINATION.
       Initiator = benzoyl peroxide.

   8.  Nylon 6,6 = adipic acid + hexamethylenediamine.
       Nylon 6   = caprolactam.
       Terylene  = ethylene glycol + terephthalic acid.
       Bakelite  = phenol + formaldehyde.

   9.  Buna-S = butadiene + styrene (tyres).
       Buna-N = butadiene + acrylonitrile (oil seals).
       Neoprene = chloroprene (oil-resistant, HOMOpolymer).

  10.  Natural rubber = CIS-1,4-polyisoprene. Cis kinks -> loose packing
       -> elastic.

  11.  Vulcanisation = rubber + SULPHUR at 373-415 K -> cross-links ->
       stronger, wider temperature range. 5% S for tyres, 30% for
       battery cases.

  12.  Mn = SUM NiMi / SUM Ni ,  Mw = SUM NiMi^2 / SUM NiMi ,
       PDI = Mw/Mn >= 1.  Biodegradable: PHBV and nylon-2-nylon-6.
```
