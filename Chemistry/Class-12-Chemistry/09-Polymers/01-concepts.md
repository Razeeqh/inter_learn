# ===============================================================
# TOPIC 1 — WHAT IS A POLYMER?
# ===============================================================

## 1.1 The everyday picture

Think of a **paper chain** you made in school. You cut out many identical
paper rings and link them one after another. One ring is small and useless.
Ten thousand rings joined together is a long chain that you can hang across
the room.

```
   O   O   O   O   O          ->      O-O-O-O-O-O-O-O-O-O-O-O-O
   loose rings                        one long chain

   MONOMERS                           POLYMER
```

- **Monomer** = the one small ring. (Greek: *mono* = one, *meros* = part)
- **Polymer** = the long chain. (Greek: *poly* = many, *meros* = part)
- **Polymerisation** = the process of hooking the rings together.

## 1.2 The exam definitions — learn these word for word

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |  POLYMER                                                          |
  |  A polymer is a very high molecular mass substance (a MACRO-      |
  |  MOLECULE) formed by joining a large number of simple repeating   |
  |  structural units through COVALENT bonds.                         |
  |                                                                   |
  |  MONOMER                                                          |
  |  The simple, small molecule from which a polymer is made.         |
  |                                                                   |
  |  POLYMERISATION                                                   |
  |  The process in which a large number of monomer molecules         |
  |  combine to form a polymer.                                       |
  |                                                                   |
  |  REPEATING UNIT                                                   |
  |  The unit that repeats over and over inside the polymer chain,    |
  |  written inside square brackets with a subscript n.               |
  |                                                                   |
  |  DEGREE OF POLYMERISATION  (n)                                    |
  |  The NUMBER of monomer units present in one polymer chain.        |
  |                                                                   |
  +-------------------------------------------------------------------+
```

## 1.3 The very first example — polythene

```
   n  CH2 = CH2      --(high pressure, heat, peroxide)-->

                          H   H
                          |   |
                    -[- C - C -]-
                          |   |
                          H   H       n

       ethene                    polythene
      (MONOMER)                 (POLYMER)

   written more simply:      -[- CH2 - CH2 -]-
                                             n
```

Notice what happened:

```
   BEFORE :   CH2 = CH2      has a DOUBLE bond
   AFTER  :   -CH2 - CH2-    the double bond became a SINGLE bond and the
                             spare bonds reached out to the neighbours
```

That is the whole idea of addition polymerisation. **The double bond is the
hook.** No double bond, no addition polymer.

## 1.4 Degree of polymerisation — the only easy sum

```
                  molecular mass of the POLYMER
   n   =   ----------------------------------------
                  molecular mass of the MONOMER
```

### WORKED EXAMPLE 1.1

A sample of polythene has a molecular mass of 70,000 u.
Find the degree of polymerisation.

```
  STEP 1   Monomer is ethene, CH2 = CH2

           molecular mass  =  (2 x 12) + (4 x 1)  =  24 + 4  =  28 u

  STEP 2                70000
           n   =   -------------   =   2500
                        28

  ANSWER:  degree of polymerisation  n  =  2500

  Meaning: 2500 ethene molecules are joined in one chain.
```

### WORKED EXAMPLE 1.2

PVC has a degree of polymerisation of 800. Find its molecular mass.

```
  STEP 1   Monomer = vinyl chloride,  CH2 = CH - Cl
           mass  =  (2 x 12) + (3 x 1) + 35.5
                 =  24 + 3 + 35.5
                 =  62.5 u

  STEP 2   molecular mass of polymer  =  n x (mass of monomer)
                                      =  800 x 62.5
                                      =  50000 u

  ANSWER:  50,000 u
```

> **TRAP:** This simple multiplication works only for **ADDITION** polymers,
> because nothing is thrown away. In a **CONDENSATION** polymer a small
> molecule (usually H2O) is eliminated at every join, so the polymer mass is
> LESS than n x (mass of monomers). If the question says "condensation",
> subtract the water.

## 1.5 Homopolymer and copolymer — a word you need early

```
  HOMOPOLYMER   -  made from only ONE kind of monomer
                   polythene (only ethene)
                   PVC (only vinyl chloride)

  COPOLYMER     -  made from TWO OR MORE different monomers
                   Buna-S (butadiene + styrene)
                   nylon 6,6 (hexamethylenediamine + adipic acid)
```

# ===============================================================
# TOPIC 2 — CLASSIFICATION BY SOURCE
# ===============================================================

The first way of sorting polymers is the simplest: **where did it come from?**

```
                          POLYMERS
                              |
        +---------------------+---------------------+
        |                     |                     |
     NATURAL           SEMI-SYNTHETIC          SYNTHETIC
   found in nature     natural polymer         made completely
                       chemically modified     in a laboratory
        |                     |                     |
     starch             cellulose acetate       polythene
     cellulose          cellulose nitrate       nylon 6,6
     natural rubber     vulcanised rubber       Buna-S
     proteins                                   PVC
     nucleic acids                              Bakelite
     silk, wool
```

## 2.1 Natural polymers

Made by plants and animals. You eat them, wear them and are made of them.

| Natural polymer | Where it is found | Its monomer |
|---|---|---|
| Starch | rice, potato, wheat | alpha-glucose |
| Cellulose | wood, cotton, paper | beta-glucose |
| Natural rubber | latex of rubber tree | isoprene |
| Proteins | wool, silk, meat, your muscles | alpha-amino acids |
| Nucleic acids (DNA, RNA) | every living cell | nucleotides |

## 2.2 Semi-synthetic polymers

Start with a natural polymer (almost always **cellulose**) and modify it
chemically. It is half-natural, half-man-made — hence *semi*-synthetic.

```
  cellulose  + acetic anhydride  ->  CELLULOSE ACETATE
                                     used for photographic film,
                                     rayon (artificial silk),
                                     spectacle frames

  cellulose  + nitric acid       ->  CELLULOSE NITRATE (gun cotton)
                                     used for explosives, lacquers,
                                     celluloid

  natural rubber + sulphur       ->  VULCANISED RUBBER
                                     used for tyres
```

## 2.3 Synthetic polymers

Man-made from start to finish, out of petroleum chemicals.
Polythene, polypropene, PVC, Teflon, nylon 6,6, terylene, Bakelite,
Buna-S, Buna-N, neoprene — everything else in this chapter.

> **TRAP:** Rayon is often wrongly called "natural" because it feels like
> silk. Rayon is made from **cellulose acetate**, so it is **SEMI-SYNTHETIC**.
> Vulcanised rubber is also semi-synthetic, not natural.

# ===============================================================
# TOPIC 3 — CLASSIFICATION BY STRUCTURE
# ===============================================================

Now ask: **what shape is the chain?** There are three shapes, and the shape
decides whether the plastic is soft, tough or rock hard.

## 3.1 LINEAR POLYMERS

Monomers joined in one long straight line, no side branches.
Because the chains are straight, they **stack together closely**, like
uncooked spaghetti in a packet.

```
   LINEAR
   ------

   ---O---O---O---O---O---O---O---O---O---O---O---
   ---O---O---O---O---O---O---O---O---O---O---O---
   ---O---O---O---O---O---O---O---O---O---O---O---
   ---O---O---O---O---O---O---O---O---O---O---O---

   chains lie flat and close  ->  strong attraction between chains
```

**Result of close packing:**
- high density
- high tensile strength (hard to tear)
- high melting point

**Examples:** high density polythene (HDPE), polyvinyl chloride, nylon 6,6,
polyesters (terylene).

## 3.2 BRANCHED CHAIN POLYMERS

A long main chain with side branches sticking out of it. The branches act
like spikes and **keep the chains apart**, so they cannot pack closely.

```
   BRANCHED
   --------

              O           O
              |           |
   ---O---O---O---O---O---O---O---O---O---
              |               |
              O               O---O
                                  |
        ---O---O---O---O---O---O---O---
                  |
                  O

   spikes hold the chains apart  ->  weak attraction between chains
```

**Result of loose packing:**
- low density
- low tensile strength (tears easily)
- low melting point
- flexible, soft

**Examples:** low density polythene (LDPE), amylopectin (the branched part
of starch), glycogen.

## 3.3 CROSS-LINKED (NETWORK) POLYMERS

Here the chains are chemically **bonded to each other** by strong covalent
bridges. The whole object becomes one single giant molecule — a three
dimensional net.

```
   CROSS-LINKED / NETWORK
   ----------------------

   ---O---O---O---O---O---O---O---O---
          |           |           |
          |           |           |        <-- these vertical bridges are
   ---O---O---O---O---O---O---O---O---         COVALENT bonds, not just
          |           |           |            attractions
          |           |           |
   ---O---O---O---O---O---O---O---O---
          |           |           |
   ---O---O---O---O---O---O---O---O---

   chains are TIED to one another  ->  cannot slide, cannot melt
```

**Result:**
- hard, rigid and **brittle**
- do not melt, do not dissolve
- cannot be remoulded once set

**Examples:** Bakelite, melamine-formaldehyde, urea-formaldehyde,
vulcanised rubber.

## 3.4 The comparison you must be able to write

| Feature | LINEAR | BRANCHED | CROSS-LINKED |
|---|---|---|---|
| Shape | straight chains | main chain + side branches | 3-D network |
| Packing of chains | close | loose | joined by covalent bonds |
| Intermolecular force | strong | weak | irrelevant — chains are bonded |
| Density | high | low | very high rigidity |
| Tensile strength | high | low | very high but brittle |
| Melting point | high | low | does not melt |
| Can it be remoulded? | yes | yes | NO |
| Examples | HDPE, PVC, nylon | LDPE, glycogen, amylopectin | Bakelite, melamine-formaldehyde, vulcanised rubber |

### WORKED EXAMPLE 3.1

*LDPE and HDPE are made from the same monomer, ethene. Why is HDPE harder
and denser than LDPE?*

```
  ANSWER (this is the full 2-mark answer)

  LDPE is a BRANCHED polymer. The branches prevent the chains from coming
  close, so the packing is loose, the intermolecular forces are weak, and
  the polymer is of low density, soft and flexible.

  HDPE is a LINEAR polymer. The straight chains pack very closely, so the
  intermolecular forces are strong, and the polymer is of high density,
  hard and tough.

  So the DIFFERENCE IS THE STRUCTURE, not the monomer.
```

> **TRAP:** The examiner loves this question because students assume the
> monomers must be different. They are the same. The catalyst is different
> (LDPE: peroxide at very high pressure; HDPE: Ziegler-Natta catalyst at
> low pressure), and that changes the STRUCTURE.

# ===============================================================
# TOPIC 4 — CLASSIFICATION BY MODE OF POLYMERISATION
# ===============================================================

Now ask: **how were the monomers joined?** There are exactly two answers.

## 4.1 ADDITION POLYMERISATION (chain growth polymerisation)

Unsaturated monomers (with C=C double bonds) simply **add** to each other
over and over. Nothing is thrown out.

```
   n CH2 = CH2      ------>      -[- CH2 - CH2 -]-
                                                   n

   n CH2 = CH        ------>     -[- CH2 - CH -]-
          |                                |
          Cl                               Cl      n

   The double bond OPENS. The two free ends grab the neighbours.
   Nothing is eliminated  ->  the polymer weighs exactly the same as
   all the monomers put together.
```

The general form, where X is any group:

```
                     H   H                    H   H
                     |   |                    |   |
             n   C = C          ------>   -[- C - C -]-
                     |   |                    |   |
                     H   X                    H   X    n
```

| X is | Monomer name | Polymer |
|---|---|---|
| H | ethene | polythene |
| CH3 | propene | polypropene |
| C6H5 | styrene | polystyrene |
| Cl | vinyl chloride | PVC |
| CN | acrylonitrile | polyacrylonitrile (Orlon) |

## 4.2 CONDENSATION POLYMERISATION (step growth polymerisation)

Two monomers, each carrying **two functional groups** at its two ends,
react again and again. Every time a bond forms, a **small molecule is
thrown out** — usually water.

```
   HOOC-(CH2)4-COOH   +   H2N-(CH2)6-NH2
   adipic acid            hexamethylenediamine

           |  the -OH of the acid and one -H of the amine
           |  leave together as H2O
           v

   ... -CO-(CH2)4-CO-NH-(CH2)6-NH- ...    +    H2O
                    NYLON 6,6

   The new bond  -CO-NH-  is an AMIDE link (also called a peptide link).
```

The small molecule eliminated can be:

```
   H2O    water            (polyesters, polyamides, Bakelite)
   NH3    ammonia
   HCl    hydrogen chloride
   CH3OH  methanol
```

**Why "bi-functional"?** If a molecule has only one reactive end it can join
one partner and then stop. To build a long chain each monomer needs **two**
reactive ends, one for each neighbour.

```
   ONE functional group each  ->  a small molecule, chain STOPS

        A-        -B      ->     A-B    finished

   TWO functional groups each ->  chain KEEPS GROWING

       -A-       -B-      ->    -A-B-A-B-A-B-A-B-  ...
```

If a monomer has **three** functional groups (like phenol, or glycerol) the
chain can grow sideways as well and you get a **cross-linked** polymer such
as Bakelite or glyptal.

## 4.3 THE COMPARISON TABLE — a guaranteed 4-mark question

| # | ADDITION (chain growth) | CONDENSATION (step growth) |
|---|---|---|
| 1 | Monomers are **unsaturated** — they contain a C=C double bond or a triple bond | Monomers are **bi-functional or tri-functional** — they carry two or three functional groups such as -OH, -COOH, -NH2 |
| 2 | Monomers simply **add** to one another | Monomers **condense** with one another |
| 3 | **No** small molecule is eliminated | A **small molecule** (H2O, NH3, HCl, CH3OH) is eliminated |
| 4 | Molecular mass of polymer = **exact multiple** of the monomer mass | Molecular mass is **not** an exact multiple (the eliminated molecules are missing) |
| 5 | Proceeds through **free radicals, cations or anions** (chain carriers) | Proceeds by ordinary functional-group reactions, in **steps** |
| 6 | The chain grows only at its active end, very fast; high molecular mass is reached almost at once | Any two molecules can join at any time; molecular mass builds up **slowly** |
| 7 | Usually the polymer has the **same empirical formula** as the monomer | Empirical formula is different from that of the monomers |
| 8 | Examples: polythene, polypropene, PVC, Teflon, polystyrene, Buna-S, neoprene | Examples: nylon 6, nylon 6,6, terylene, Bakelite, glyptal, melamine-formaldehyde |

### WORKED EXAMPLE 4.1

*Classify as addition or condensation, giving a reason: (a) Teflon
(b) terylene (c) neoprene (d) urea-formaldehyde resin.*

```
  (a) TEFLON              monomer CF2 = CF2 has a C=C double bond
                          ->  ADDITION

  (b) TERYLENE            made from ethylene glycol (two -OH groups) and
                          terephthalic acid (two -COOH groups), water
                          is eliminated
                          ->  CONDENSATION

  (c) NEOPRENE            monomer chloroprene CH2 = C(Cl) - CH = CH2 has
                          double bonds
                          ->  ADDITION

  (d) UREA-FORMALDEHYDE   urea (two -NH2 groups) + formaldehyde,
                          water is eliminated
                          ->  CONDENSATION
```

> **TRAP:** Quick test in the exam hall — **does the monomer have a C=C?**
> If yes it is addition. If instead the monomer has -OH / -COOH / -NH2
> groups, it is condensation.

# ===============================================================
# TOPIC 5 — CLASSIFICATION BY MOLECULAR FORCES
# ===============================================================

This is the classification the examiner asks about most often, because it is
the one that explains **why a rubber band stretches but a comb snaps.**

Everything depends on the **strength of the force between neighbouring
chains**.

```
   WEAK forces        ->  chains slide over each other easily  ->  STRETCHY
   STRONG forces      ->  chains grip each other tightly       ->  STIFF
   COVALENT bridges   ->  chains cannot move at all            ->  RIGID
```

## 5.1 ELASTOMERS — weakest forces

```
   The chains are RANDOMLY COILED, like springs, and are held by only a
   few WEAK van der Waals forces, plus a FEW cross-links here and there
   to pull the chain back.

   RELAXED                          STRETCHED
   -------                          ---------
      /\  /\  /\                    ------------------------
     /  \/  \/  \                   pull
    coiled chains       -------->   chains straighten out
                        <--------
                        release     and then SNAP BACK because the few
                                    cross-links act like memory
```

- **Force:** weakest of all (weak van der Waals)
- **Property:** highly elastic — stretch to many times their length and
  come back
- **Examples:** vulcanised rubber, Buna-S, Buna-N, neoprene
- **Everyday item:** rubber band, tyre, hosepipe

## 5.2 FIBRES — strongest forces

```
   The chains are LONG, THIN, STRAIGHT and lie side by side.
   They are held by STRONG HYDROGEN BONDS or dipole-dipole forces.

   ----C=O ..... H-N----C=O ..... H-N----
       |             |     |         |
   ----N-H ..... O=C----N-H ..... O=C----

   The dotted lines are hydrogen bonds. There are thousands of them,
   so the chains lock together into a crystalline, thread-like solid.
```

- **Force:** strongest (hydrogen bonding, dipole-dipole)
- **Property:** high tensile strength, high melting point, crystalline,
  can be drawn into long threads
- **Examples:** nylon 6, nylon 6,6, terylene (dacron), polyacrylonitrile
  (Orlon), silk
- **Everyday item:** your shirt, a rope, a fishing line

## 5.3 THERMOPLASTIC POLYMERS — in between

```
   Linear or slightly branched chains, forces IN BETWEEN elastomers and
   fibres, and NO cross-links.

        heat                     cool
   solid ----> soft / melts ----> solid again ----> heat again ----> melts
                                                    (over and over)
```

- **Force:** intermediate
- **Property:** **soften on heating and harden on cooling, repeatedly**;
  can be moulded again and again; can be recycled
- **Examples:** polythene, polystyrene, polypropene, PVC
- **Everyday item:** a plastic bucket, a water bottle

## 5.4 THERMOSETTING POLYMERS — cross-linked, one-way street

```
   Made first as a SOFT, semi-fluid, low molecular mass material.
   On heating in a mould, the chains CROSS-LINK covalently and set into
   one giant rigid network — permanently.

        heat in a mould                    heat again
   soft  ------------->  HARD, RIGID  --------------->  it just BURNS,
   resin  cross-links     3-D network                   it does NOT melt
          form                                          and cannot be
                                                        remoulded
```

- **Force:** heavily cross-linked by **covalent bonds**
- **Property:** hard, rigid, brittle, infusible, insoluble; **set only
  once**; cannot be recycled by melting
- **Examples:** Bakelite, urea-formaldehyde resin, melamine-formaldehyde
  resin
- **Everyday item:** an electrical switch, a saucepan handle, a comb

## 5.5 THE FOUR-WAY TABLE — write it exactly like this

| | ELASTOMERS | FIBRES | THERMOPLASTICS | THERMOSETTING |
|---|---|---|---|---|
| **Intermolecular force** | WEAKEST — weak van der Waals | STRONGEST — H-bonding, dipole-dipole | intermediate | held by covalent CROSS-LINKS |
| **Structure of chain** | randomly coiled, a few cross-links | long, straight, closely packed, crystalline | linear or slightly branched, no cross-links | heavily cross-linked 3-D network |
| **Elasticity** | very high | almost none | low | none |
| **Tensile strength** | low | very high | moderate | high but brittle |
| **Melting point** | low | high | moderate | does not melt |
| **Effect of heat** | softens | high m.p., does not soften easily | softens and can be remoulded again and again | sets permanently, cannot be remoulded |
| **Examples** | vulcanised rubber, Buna-S, Buna-N, neoprene | nylon 6,6, terylene, Orlon, silk | polythene, polystyrene, PVC, polypropene | Bakelite, urea-formaldehyde, melamine-formaldehyde |

## 5.6 THERMOPLASTIC vs THERMOSETTING — asked on its own, very often

| # | THERMOPLASTIC | THERMOSETTING |
|---|---|---|
| 1 | Linear or slightly branched chains | Heavily cross-linked, three dimensional network |
| 2 | No cross-links between chains | Covalent cross-links between chains |
| 3 | **Softens on heating and hardens on cooling** | **Sets permanently on heating; does not soften again** |
| 4 | Can be remoulded and reshaped any number of times | Can be moulded only ONCE |
| 5 | Can be recycled | Cannot be recycled by melting; it chars/burns |
| 6 | Soluble in some organic solvents | Insoluble in all solvents |
| 7 | Comparatively soft, less brittle | Hard, rigid and brittle |
| 8 | Polythene, PVC, polystyrene, polypropene | Bakelite, urea-formaldehyde, melamine-formaldehyde |

### WORKED EXAMPLE 5.1

*Why is Bakelite used for electric switches while polythene is used for
carry bags?*

```
  BAKELITE is a THERMOSETTING polymer with a cross-linked 3-D network.
  It is hard, rigid, infusible and a poor conductor of electricity, and
  it will not soften even when the switch gets warm. Perfect for a switch.

  POLYTHENE is a THERMOPLASTIC. It is soft, flexible, tough and can be
  melted and blown into thin films. Perfect for a carry bag.
```

> **TRAP:** Do NOT say "thermosetting polymers are set by heating, so they
> melt on heating." They do the opposite. Heat makes them **set harder**,
> because heat is what forms the cross-links. After that, more heat only
> burns them.

# ===============================================================
# TOPIC 6 — TYPES OF POLYMERISATION IN DETAIL
# ===============================================================

## 6.1 ADDITION POLYMERISATION — the free radical mechanism

This is a favourite 4-mark question. It has **three steps**, and you must
name all three: **INITIATION, PROPAGATION, TERMINATION**.

The catalyst used is an **initiator** — usually **benzoyl peroxide** or
acetyl peroxide or tert-butyl peroxide. Its job is to make the very first
free radical.

### STEP 1 — INITIATION

```
   The peroxide breaks at its weak O-O bond on heating:

        O                O                   O
        ||               ||                  ||
   C6H5-C-O - O-C-C6H5  ---heat--->   2  C6H5-C-O *
                ||
                O
     benzoyl peroxide                  benzoyloxy free radical


   This radical loses CO2 and gives a PHENYL free radical:

        O
        ||
   C6H5-C-O *      ----->     C6H5 *   +   CO2


   The phenyl radical now attacks an ethene molecule. It grabs one
   electron of the double bond, and the OTHER electron is left over
   as a new radical:

                          .            .
   C6H5 *  +  CH2 = CH2   --->   C6H5 - CH2 - CH2 *

                                 the chain has STARTED
```

*(The `*` marks an unpaired electron — a free radical.)*

### STEP 2 — PROPAGATION

```
   The new radical attacks the next ethene, and the next, and the next.
   The radical is handed down the chain like a relay baton:

   C6H5-CH2-CH2 *  +  CH2 = CH2  --->  C6H5-CH2-CH2-CH2-CH2 *

   C6H5-CH2-CH2-CH2-CH2 * + CH2=CH2 --> C6H5-(CH2-CH2)2-CH2-CH2 *

                       ...  repeated thousands of times ...

   C6H5-(CH2-CH2)n-CH2-CH2 *          the growing polymer chain
```

```
   PICTURE OF PROPAGATION

     *                    *                    *
     |                    |                    |
   [C]        +  M  ->  [C-M]      +  M  ->  [C-M-M]      + M -> ...

   the star (the unpaired electron) always sits at the FRONT END,
   and the chain grows only from that end. That is why it is called
   CHAIN GROWTH polymerisation.
```

### STEP 3 — TERMINATION

```
   Two growing radical chains meet and PAIR UP their odd electrons.
   Both chains die at once, and the polymer is finished:

   C6H5-(CH2-CH2)n-CH2-CH2 *   +   * CH2-CH2-(CH2-CH2)m-C6H5

              |
              v

   C6H5-(CH2-CH2)n-CH2-CH2-CH2-CH2-(CH2-CH2)m-C6H5

                   POLYTHENE
```

```
   ALL THREE STEPS ON ONE CARD

   +--------------------------------------------------------------+
   |  INITIATION   peroxide  ->  radical                          |
   |               radical + monomer  ->  new bigger radical      |
   |                                                              |
   |  PROPAGATION  radical + monomer  ->  bigger radical          |
   |               (repeated again and again)                     |
   |                                                              |
   |  TERMINATION  radical + radical  ->  dead polymer chain      |
   +--------------------------------------------------------------+
```

> **TRAP:** Students write only the equations and lose the naming marks.
> **Write the three headings INITIATION / PROPAGATION / TERMINATION in
> capitals.** Each heading carries part of the mark.

## 6.2 The two kinds of polythene

Both come from ethene, but under completely different conditions.

```
  +------------------+-------------------------+------------------------+
  |                  |    LOW DENSITY (LDPE)   |   HIGH DENSITY (HDPE)  |
  +------------------+-------------------------+------------------------+
  | Monomer          |  ethene                 |  ethene (same!)        |
  | Pressure         |  1000 - 2000 atm         |  6 - 7 atm             |
  | Temperature      |  350 - 570 K             |  333 - 343 K           |
  | Catalyst         |  traces of O2 or a       |  ZIEGLER-NATTA:        |
  |                  |  peroxide initiator      |  triethyl aluminium    |
  |                  |  (free radical)          |  + titanium tetra-     |
  |                  |                          |  chloride              |
  | Structure        |  highly BRANCHED         |  LINEAR                |
  | Density          |  low                     |  high                  |
  | Properties       |  chemically inert, tough |  chemically inert,     |
  |                  |  but FLEXIBLE, poor      |  harder, TOUGHER,      |
  |                  |  conductor of electricity|  higher melting point  |
  | Uses             |  insulation of electric  |  buckets, dustbins,    |
  |                  |  wires, squeeze bottles, |  bottles, pipes,       |
  |                  |  toys, flexible pipes    |  house-ware articles   |
  +------------------+-------------------------+------------------------+
```

## 6.3 CONDENSATION POLYMERISATION worked through

### Nylon 6,6 — a POLYAMIDE

```
   n HOOC-(CH2)4-COOH   +   n H2N-(CH2)6-NH2
     adipic acid              hexamethylenediamine
     (6 carbons)              (6 carbons)   <-- hence "6,6"

         --(heat, high pressure, ~553 K)-->

        O                O      H            H
        ||               ||     |            |
   -[- C - (CH2)4 - C - N - (CH2)6 - N -]-      +   2n H2O
                          |
                          amide (peptide) link      n

   short form:   -[- CO-(CH2)4-CO-NH-(CH2)6-NH -]-
                                                   n
```

**Uses:** sheets, bristles for brushes, textile fabrics.

### Nylon 6 — from ONE monomer

```
   Caprolactam is a cyclic amide (a lactam) with 6 carbons.
   Heat it with water at high temperature: the ring opens and the
   molecules join.

           /  (CH2)5  \
          |            |            H2O, 533-543 K
          NH --------- C=O          -------------->

                          n
                NYLON 6
```

```

     ethylene glycol       terephthalic acid

                       |                      n

```

**Uses:** blended with cotton and wool for clothes, safety helmets,

### Glyptal — a cross-linked POLYESTER

```

     ------->     -[- O-CH2-CH2-O-CO-C6H4-CO -]-   +   2n H2O
                                                   n

```

### Bakelite and Novolac — from phenol and formaldehyde

This is a **two-stage** story. Learn the two names in the right order.

```
   STAGE 1   phenol + formaldehyde, acid or base catalyst

        OH                              OH
        |                               |
      (   )   +  HCHO   ------->      (   )-CH2OH
      (   )                           (   )
                                   ortho- or para-
                                   hydroxymethylphenol

   STAGE 2   this reacts with more phenol -> a LINEAR polymer

        OH        OH        OH
        |         |         |
      (   )-CH2-(   )-CH2-(   )- ...          NOVOLAC
      (   )     (   )     (   )
                                       a LINEAR, thermoplastic resin
                                       USE: paints

   STAGE 3   heat NOVOLAC with EXCESS formaldehyde
             -> cross-links form at the remaining ortho and para
                positions -> a 3-D network

        OH        OH
        |         |
   -CH2-(   )-CH2-(   )-CH2-
        (   )     (   )
          |         |
         CH2       CH2
          |         |
   -CH2-(   )-CH2-(   )-CH2-
        (   )     (   )
        |         |
        OH        OH
                                       BAKELITE
                                       a CROSS-LINKED, THERMOSETTING resin
```

**Uses of Bakelite:** combs, phonograph records, electrical switches,
handles of utensils.

> **TRAP:** Novolac and Bakelite have the **same two monomers**
> (phenol + formaldehyde). Novolac is **linear** (used in paints);
> Bakelite is **cross-linked** (used in switches). If asked "how do you get
> Bakelite from Novolac", the answer is: **heat Novolac with excess

# TOPIC 7 — COPOLYMERISATION AND COPOLYMERS
# ===============================================================

```
  +-------------------------------------------------------------------+
  |  COPOLYMERISATION                                                 |
  |  A polymerisation reaction in which a MIXTURE of MORE THAN ONE     |
  |  kind of monomer is allowed to polymerise, so that the product     |
  |  contains multiple units of each monomer in the same chain.       |
  |                                                                   |
  |  COPOLYMER                                                        |
  |  The polymer so formed.                                           |
  +-------------------------------------------------------------------+
```

```
   HOMOPOLYMER   -A-A-A-A-A-A-A-A-A-A-       one monomer only

   COPOLYMER     -A-B-A-A-B-B-A-B-A-B-       two monomers mixed
                                             into the same chain
```

**Why bother?** Because mixing two monomers gives properties that neither
one has by itself. Rubber that resists petrol, or rubber that resists
abrasion.

## 7.1 Buna-S (styrene-butadiene rubber, SBR)

```
   n CH2 = CH - CH = CH2    +    n CH2 = CH
     1,3-butadiene                     |
                                    C6H5
                                    styrene

        --(sodium catalyst)-->

   -[- CH2 - CH = CH - CH2 - CH2 - CH -]-
                                    |
                                   C6H5     n
                    BUNA - S
```

**Uses:** automobile tyres, floor tiles, footwear components, cable
insulation.

## 7.2 Buna-N (nitrile rubber, NBR)

```
   n CH2 = CH - CH = CH2    +    n CH2 = CH
     1,3-butadiene                     |
                                       CN
                                  acrylonitrile

   -[- CH2 - CH = CH - CH2 - CH2 - CH -]-
                                    |
                                    CN      n
                    BUNA - N
```

**Special property:** resistant to the action of petrol, lubricating oil
and organic solvents.
**Uses:** making oil seals, tank lining.

> **Where the name comes from:** **Bu** = **Bu**tadiene, **na** = **Na**trium
> (sodium, the catalyst), **S** = **S**tyrene, **N** = acrylo**N**itrile.
> That one line tells you both monomers of both rubbers. Learn it.

# ===============================================================
# TOPIC 8 — NATURAL RUBBER AND VULCANISATION
# ===============================================================

## 8.1 Where natural rubber comes from

Natural rubber is obtained as a milky white **latex** from the bark of
rubber trees. Chemically it is a **natural addition polymer of ISOPRENE**.

```
   THE MONOMER

   isoprene  =  2-methyl-1,3-butadiene

        CH3
        |
   CH2 = C - CH = CH2

   THE POLYMER

   -[- CH2 - C = CH - CH2 -]-              cis-1,4-polyisoprene
             |               n
             CH3
```

## 8.2 Why it must be CIS — this is the marks-carrying idea

```
   CIS form (natural rubber)          TRANS form (gutta percha)
   ------------------------           -------------------------

    CH2         CH2                    CH2          CH3
       \       /                          \        /
        C  =  C                            C  =  C
       /       \                          /        \
     CH3        H                        H          CH2

   both CH2 groups on the           the CH2 groups are on
   SAME side of the C=C             OPPOSITE sides

           |                                  |
           v                                  v

   the chain is forced into a       the chain is straight and
   BENT, COILED shape               can pack closely

           |                                  |
           v                                  v

   chains cannot come close         chains pack tightly, strong
   -> WEAK intermolecular forces    intermolecular forces

           |                                  |
           v                                  v

   the coiled chains can be         HARD, TOUGH, NON-ELASTIC
   pulled straight and then
   spring back  ->  ELASTIC
```

```
   PICTURE OF THE COIL

   relaxed:      ~~/\~~/\~~/\~~/\~~     (cis kinks make it coil)

   stretched:    ______________________  (pull -> coil straightens)

   released:     ~~/\~~/\~~/\~~/\~~     (springs back)
```

**One-line exam answer:** *In natural rubber the cis double bonds prevent
the chains from packing closely, so the weak intermolecular forces let the
coiled chains be stretched and then return — hence rubber is elastic.*

## 8.3 The drawbacks of raw natural rubber

```
   +-----------------------------------------------------------------+
   |  1. Useful only over a NARROW temperature range, 283 K to 335 K |
   |     -  above 335 K it becomes SOFT and STICKY                   |
   |     -  below 283 K it becomes HARD and BRITTLE                  |
   |                                                                 |
   |  2. LOW tensile strength - tears easily                         |
   |                                                                 |
   |  3. LOW resistance to abrasion (wears out fast)                 |
   |                                                                 |
   |  4. Absorbs a LARGE amount of WATER                             |
   |                                                                 |
   |  5. SOLUBLE in non-polar solvents (petrol, benzene)             |
   |                                                                 |
   |  6. Easily attacked by OXIDISING AGENTS - it perishes           |
   |                                                                 |
   |  7. Too much elasticity - it deforms permanently under load     |
   +-----------------------------------------------------------------+
```

## 8.4 VULCANISATION — the cure

```
  +-------------------------------------------------------------------+
  |  VULCANISATION                                                    |
  |                                                                   |
  |  The process of HEATING RAW NATURAL RUBBER WITH SULPHUR (and a    |
  |  suitable additive) at a temperature between 373 K and 415 K,     |
  |  so that sulphur atoms form CROSS-LINKS between the rubber        |
  |  chains at their reactive double-bond sites.                      |
  |                                                                   |
  |  Discovered by CHARLES GOODYEAR in 1839.                          |
  +-------------------------------------------------------------------+
```

### What sulphur actually does

```
   BEFORE vulcanisation - chains are free to slide past each other

   ~~~/\~~~/\~~~/\~~~/\~~~/\~~~/\~~~
   ~~~/\~~~/\~~~/\~~~/\~~~/\~~~/\~~~
   ~~~/\~~~/\~~~/\~~~/\~~~/\~~~/\~~~


   AFTER vulcanisation - sulphur bridges tie them together

   ~~~/\~~~/\~~~/\~~~/\~~~/\~~~/\~~~
          |         |         |
          S         S         S            <-- SULPHUR CROSS-LINKS
          |         |         |                (mono-, di- or poly-
          S         S         S                 sulphide bridges)
          |         |         |
   ~~~/\~~~/\~~~/\~~~/\~~~/\~~~/\~~~
          |         |         |
          S         S         S
          |         |         |
   ~~~/\~~~/\~~~/\~~~/\~~~/\~~~/\~~~

   The chains can still uncoil a little (so it is still elastic),
   but they can no longer SLIDE APART (so it is now strong).
```

### How much sulphur?

```
   about  5 %  sulphur   ->   TYRE rubber       (flexible, elastic)
   about 30 %  sulphur   ->   BATTERY CASE      (hard, rigid, ebonite)

   more sulphur  =  more cross-links  =  harder rubber
```

### What vulcanisation improves

| Property | Raw rubber | Vulcanised rubber |
|---|---|---|
| Tensile strength | low | **high** |
| Elasticity | too much, deforms | **controlled and springy** |
| Useful temperature range | 283 - 335 K | about **236 - 373 K** — much wider |
| Hardness | soft and sticky | **hard and tough** |
| Water absorption | high | **low** |
| Resistance to oxidation and organic solvents | poor | **good** |
| Abrasion resistance | poor | **high** |

### WORKED EXAMPLE 8.1

*What is vulcanisation? Why is vulcanised rubber better than natural
rubber? (4 marks)*

```
  DEFINITION (1 mark)
  Vulcanisation is the heating of raw natural rubber with sulphur, along
  with a suitable additive, at 373-415 K.

  WHAT HAPPENS (1 mark)
  Sulphur atoms attack the reactive sites next to the C=C double bonds of
  the rubber chains and form sulphur cross-links (bridges) between
  neighbouring chains, converting the linear polymer into a lightly
  cross-linked network.

  IMPROVEMENTS (2 marks - give at least four)
  1. Higher tensile strength.
  2. Elasticity is controlled - it no longer deforms permanently.
  3. Useful over a much wider temperature range.
  4. Does not become soft and sticky in summer or brittle in winter.
  5. Better resistance to oxidation, abrasion and organic solvents.
  6. Absorbs much less water.

  EXTRA MARK LINE
  About 5% sulphur is used for tyre rubber and about 30% for battery
  case rubber.
```

# ===============================================================
# TOPIC 9 — MOLECULAR MASS OF POLYMERS
# ===============================================================

## 9.1 Why a polymer does not have ONE molecular mass

When you make polythene, some chains stop growing after 500 monomers and
some carry on to 5000. So a bag of polythene is a **mixture of chains of
many different lengths**. There is no single molecular mass — only an
**average**. And there are two different ways to take that average.

```
   A jar of marbles, some small some big.

   NUMBER AVERAGE  Mn  -  count the marbles, share the total mass
                          equally between them
                          (every chain counts the SAME)

   WEIGHT AVERAGE  Mw  -  let the HEAVY chains have a bigger say
                          (a chain twice as heavy counts twice)

   So  Mw  is always  >=  Mn.
```

## 9.2 The three formulae

```
  +----------------------------------------------------------------+
  |                                                                |
  |                        SUM ( Ni x Mi )                         |
  |     Mn    =        --------------------------                  |
  |                          SUM ( Ni )                            |
  |                                                                |
  |                                                                |
  |                        SUM ( Ni x Mi^2 )                       |
  |     Mw    =        --------------------------                  |
  |                        SUM ( Ni x Mi )                         |
  |                                                                |
  |                                                                |
  |                        Mw                                      |
  |     PDI   =         --------                                   |
  |                        Mn                                      |
  |                                                                |
  +----------------------------------------------------------------+

   Ni = number of molecules whose molecular mass is Mi
```

## 9.3 What PDI tells you

```
   PDI  =  1        all chains are EXACTLY the same length.
                    The polymer is MONODISPERSE.
                    NATURAL polymers (proteins, DNA) are like this.

   PDI  >  1        chains of many different lengths.
                    The polymer is POLYDISPERSE.
                    SYNTHETIC polymers are always like this.

   The bigger the PDI, the wider the spread of chain lengths.
   PDI can never be LESS than 1.
```

## 9.4 WORKED EXAMPLE 9.1 — the standard numerical

*In a polymerisation reaction, 30% of the molecules have a molecular mass
of 20,000; 40% have 30,000; and 30% have 60,000. Calculate Mn, Mw and the
polydispersity index.*

```
  STEP 1   Take a convenient sample of 100 molecules,
           so the percentages become the actual numbers Ni.

           N1 = 30    M1 = 20000
           N2 = 40    M2 = 30000
           N3 = 30    M3 = 60000


  STEP 2   Build the table.

  +------+---------+-------------------+----------------------------+
  |  Ni  |   Mi    |     Ni x Mi       |        Ni x Mi^2           |
  +------+---------+-------------------+----------------------------+
  |  30  |  20000  |     600 000       |  30 x (2x10^4)^2           |
  |      |         |                   |  = 30 x 4 x 10^8 = 1.2x10^10|
  |  40  |  30000  |   1 200 000       |  40 x 9 x 10^8   = 3.6x10^10|
  |  30  |  60000  |   1 800 000       |  30 x 36 x 10^8  = 1.08x10^11|
  +------+---------+-------------------+----------------------------+
  | SUM  |         |   3 600 000       |        1.56 x 10^11        |
  | 100  |         |  = 3.6 x 10^6     |                            |
  +------+---------+-------------------+----------------------------+

     check on the last column sum:
       1.2 x 10^10  =  0.12 x 10^11
       3.6 x 10^10  =  0.36 x 10^11
       1.08 x 10^11 =  1.08 x 10^11
                       -------------
                       1.56 x 10^11    OK


  STEP 3   NUMBER AVERAGE

                SUM Ni Mi        3.6 x 10^6
      Mn  =  ---------------  =  -------------  =  36 000
                 SUM Ni              100


  STEP 4   WEIGHT AVERAGE

                SUM Ni Mi^2      1.56 x 10^11
      Mw  =  ---------------  =  --------------  =  43 333.3
                SUM Ni Mi          3.6 x 10^6


  STEP 5   POLYDISPERSITY INDEX

                Mw        43333.3
      PDI  =  ------  =  ---------  =  1.2037
                Mn         36000


  ANSWER:   Mn = 36 000 u
            Mw = 43 333 u   (approximately)
            PDI = 1.204

  SANITY CHECK:  Mw > Mn and PDI > 1.  Correct.
```

## 9.5 WORKED EXAMPLE 9.2 — a smaller one

*A polymer sample contains 100 molecules of mass 10,000 u and 200 molecules
of mass 40,000 u. Find Mn, Mw and PDI.*

```
  SUM Ni      =  100 + 200                        =  300

  SUM Ni Mi   =  (100 x 10000) + (200 x 40000)
              =  1 000 000 + 8 000 000            =  9 000 000

  SUM Ni Mi^2 =  100 x (10^4)^2  +  200 x (4x10^4)^2
              =  100 x 10^8      +  200 x 16 x 10^8
              =  1 x 10^10       +  3.2 x 10^11
              =  0.1 x 10^11     +  3.2 x 10^11    =  3.3 x 10^11


           9 000 000
  Mn  =  -------------  =  30 000
              300

           3.3 x 10^11
  Mw  =  --------------  =  36 666.7
            9 x 10^6

              36666.7
  PDI  =   -----------   =   1.222
               30000

  ANSWER:  Mn = 30 000 ,  Mw = 36 667 (approx) ,  PDI = 1.22
```

> **TRAP:** Mn divides by **SUM Ni** (a plain count).
> Mw divides by **SUM Ni Mi** (a mass). If you divide Mw by 100 you will get
> a huge wrong number. Also: the answer for Mw must always come out
> **larger** than Mn — if it does not, you made an arithmetic slip.

# ===============================================================
# TOPIC 10 — BIODEGRADABLE POLYMERS AND POLYMER POLLUTION
# ===============================================================

## 10.1 The problem

Most synthetic polymers (polythene, PVC, polystyrene) are **chemically
inert**. That is exactly why we like them — and exactly why they are a
disaster.

```
   +-------------------------------------------------------------+
   |  POLYMER POLLUTION - why plastics are a problem             |
   |                                                             |
   |  1. They are NON-BIODEGRADABLE. Bacteria in the soil cannot |
   |     break them down, so they stay for hundreds of years.    |
   |  2. They choke drains and sewers, causing water logging and |
   |     mosquito breeding.                                      |
   |  3. Animals swallow plastic bags and die.                   |
   |  4. Burning PVC and similar plastics releases toxic and     |
   |     carcinogenic gases such as dioxins and HCl.             |
   |  5. They pile up as an ever-growing mountain of solid waste.|
   +-------------------------------------------------------------+
```

## 10.2 The remedies

```
   1.  REDUCE  -  use less plastic; carry a cloth or jute bag.
   2.  REUSE   -  use the same container many times.
   3.  RECYCLE -  melt and remould thermoplastics.
   4.  Replace ordinary plastics with BIODEGRADABLE POLYMERS.
   5.  Segregate waste and dispose of it scientifically instead of
       burning it in the open.
```

## 10.3 Biodegradable polymers

```
  +-------------------------------------------------------------------+
  |  A BIODEGRADABLE POLYMER is a polymer that can be broken down     |
  |  by micro-organisms (bacteria) in the environment into simple,    |
  |  harmless substances, so that it does not accumulate as waste.    |
  |                                                                   |
  |  They usually contain ESTER or AMIDE linkages, which enzymes      |
  |  can hydrolyse.                                                   |
  +-------------------------------------------------------------------+
```

### (a) PHBV — poly(beta-hydroxybutyrate - co - beta-hydroxyvalerate)

```
   MONOMERS   3-hydroxybutanoic acid    CH3-CH(OH)-CH2-COOH
              3-hydroxypentanoic acid   CH3-CH2-CH(OH)-CH2-COOH

   TYPE       CONDENSATION copolymerisation - the -OH of one molecule
              esterifies the -COOH of the next

              CH3                      C2H5
              |                        |
   -[- O - CH - CH2 - CO -]- -[- O - CH - CH2 - CO -]-
                                                       n
                          P H B V

   PROPERTY   It behaves like a plastic, but soil bacteria eat it.
              Changing the ratio of the two acids changes how stiff it
              is: more hydroxyvalerate -> more flexible.

   USES       -  speciality packaging
              -  orthopaedic devices
              -  CONTROLLED RELEASE OF DRUGS (the capsule dissolves
                 slowly inside the body)
```

### (b) Nylon-2-nylon-6

```
   MONOMERS   glycine            H2N - CH2 - COOH
              amino caproic acid H2N - (CH2)5 - COOH

   TYPE       CONDENSATION - an ALTERNATING POLYAMIDE copolymer
              ("2" = 2 carbons in glycine, "6" = 6 carbons in
               amino caproic acid)

   -[- NH - CH2 - CO - NH - (CH2)5 - CO -]-
                                           n

   PROPERTY   biodegradable, because the amide links can be
              hydrolysed by enzymes

   USES       biodegradable plastic articles, sutures
```

> **TRAP:** Do not confuse **nylon-2-nylon-6** (biodegradable, from glycine
> and amino caproic acid) with **nylon 6** (tyre cords, from caprolactam)
> or **nylon 6,6** (fabrics, from adipic acid and hexamethylenediamine).
> Three different polymers with confusingly similar names.
