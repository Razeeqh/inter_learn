## THE 60-SECOND VERSION

```
  A POLYMER is a very big molecule made by joining thousands of
  small molecules (MONOMERS) end to end with covalent bonds.

        monomer + monomer + monomer + ...  ->  POLYMER

        n CH2=CH2      ---->     -[- CH2 - CH2 -]-
                                                n
        (ethene)                  (polythene)

  The whole chapter is then just FOUR QUESTIONS asked over and over:

     1.  Where did it come from?     -> natural / semi-synthetic / synthetic
     2.  What shape is the chain?    -> linear / branched / cross-linked
     3.  How was it joined?          -> addition / condensation
     4.  How strong are the forces
         between the chains?         -> elastomer / fibre / thermoplastic /
                                        thermosetting
```

**And then one giant table: polymer -> monomer -> type -> use.**
That table alone is worth more marks than everything else in the chapter.

## THE ONE BOX THAT UNLOCKS THE NUMERICALS

```
  +---------------------------------------------------------------+
  |                                                               |
  |   NUMBER AVERAGE            SUM ( Ni x Mi )                   |
  |   MOLECULAR MASS     Mn = ------------------                  |
  |                              SUM ( Ni )                       |
  |                                                               |
  |                                                               |
  |   WEIGHT AVERAGE            SUM ( Ni x Mi^2 )                 |
  |   MOLECULAR MASS     Mw = --------------------                |
  |                             SUM ( Ni x Mi )                   |
  |                                                               |
  |                                                               |
  |   POLYDISPERSITY            Mw                                |
  |   INDEX             PDI = ------        always  >=  1         |
  |                             Mn                                |
  |                                                               |
  |                                                               |
  |   DEGREE OF                molecular mass of the POLYMER      |
  |   POLYMERISATION    n =  -----------------------------------  |
  |                          molecular mass of the MONOMER        |
  |                                                               |
  +---------------------------------------------------------------+

  Ni  =  number of molecules having molecular mass  Mi

  PDI = 1     ->  all chains are the same length (natural polymers)
  PDI > 1     ->  chains of many different lengths (synthetic polymers)
```

## THE FOUR CLASSIFICATIONS ON ONE CARD

```
  +--------------------+------------------------------------------------+
  |  BY SOURCE         |  natural   -  starch, cellulose, natural        |
  |                    |               rubber, proteins                  |
  |                    |  semi-syn  -  cellulose acetate,                |
  |                    |               cellulose nitrate                 |
  |                    |  synthetic -  polythene, nylon 6,6, Buna-S      |
  +--------------------+------------------------------------------------+
  |  BY STRUCTURE      |  linear       -  HDPE, PVC, nylon               |
  |                    |  branched     -  LDPE, amylopectin, glycogen    |
  |                    |  cross-linked -  Bakelite, melamine-form.,      |
  |                    |                  vulcanised rubber              |
  +--------------------+------------------------------------------------+
  |  BY MODE OF        |  addition (chain growth)    -  polythene,       |
  |  POLYMERISATION    |     no small molecule lost     PVC, Teflon      |
  |                    |  condensation (step growth) -  nylon 6,6,       |
  |                    |     small molecule lost        terylene,        |
  |                    |                                Bakelite         |
  +--------------------+------------------------------------------------+
  |  BY MOLECULAR      |  elastomer      - WEAKEST forces - Buna-S       |
  |  FORCES            |  fibre          - STRONGEST forces - nylon 6,6  |
  |                    |  thermoplastic  - in between - polythene        |
  |                    |  thermosetting  - cross-linked - Bakelite       |
  +--------------------+------------------------------------------------+

  MEMORY for molecular forces, weakest -> strongest:
        "Every  Teacher  Teaches  Faster"
         Elastomer < Thermoplastic < Thermosetting(*) < Fibre

  (*) careful: thermosetting owes its hardness to COVALENT CROSS-LINKS,
      not to intermolecular attraction. In the exam just say
      "elastomers have the weakest forces, fibres have the strongest."
```

## THE POLYMER "FAMILY PHOTO" — learn by the ending of the name

```
  poly + (name of monomer)          ->  ADDITION polymer, always
  ------------------------------        -------------------------
  poly + ethene    = polythene           monomer = ethene
  poly + propene   = polypropene         monomer = propene
  poly + styrene   = polystyrene         monomer = styrene
  poly + vinyl chloride = PVC            monomer = vinyl chloride
  poly + acrylonitrile  = PAN            monomer = acrylonitrile
  poly + tetrafluoroethene = Teflon      monomer = tetrafluoroethene

  If the name has TWO chemicals in it        ->  CONDENSATION polymer
  ------------------------------------           ---------------------
  phenol-formaldehyde   = Bakelite / Novolac
  urea-formaldehyde
  melamine-formaldehyde

  If the name is  "nylon" or "terylene" or "glyptal"  ->  CONDENSATION
  If the name is  "Buna-" or "neoprene"              ->  ADDITION (copolymer)
```

> **This single card answers "name the monomer and the type of polymerisation"
> for about 80% of the polymers you will ever be asked about.**

## THE 8 SENTENCES THAT EARN THE MOST MARKS

```
  1.  A polymer is a high molecular mass macromolecule formed by joining
      a large number of simple repeating units called monomers.

  2.  Degree of polymerisation is the number of monomer units present in
      one polymer chain.

  3.  Addition polymerisation is the repeated addition of unsaturated
      monomers with NO elimination of a small molecule.

  4.  Condensation polymerisation is the repeated condensation of two
      bi-functional or tri-functional monomers WITH elimination of a
      small molecule such as water, ammonia or HCl.

  5.  Elastomers have the WEAKEST intermolecular forces; fibres have the
      STRONGEST.

  6.  Thermoplastics soften on heating and can be remoulded again and
      again; thermosetting polymers set permanently on heating and
      cannot be remoulded.

  7.  Vulcanisation is heating natural rubber with sulphur at 373-415 K
      so that sulphur forms cross-links between the rubber chains.

  8.  Natural rubber is cis-1,4-polyisoprene; the cis double bonds stop
      the chains from packing closely, so the coiled chains can be
      stretched - that is why rubber is elastic.
```
