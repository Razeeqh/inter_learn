# Organic Compounds containing C, H and O — Mind Map

**Chemistry 2nd Year · Chapter 13**
**Every year: 1 long answer (8M) + 2-3 short answers (4M) + 2-4 very short answers (2M)**

---

> **READ THIS BEFORE YOU START.**
> Organic chemistry is **not** scored by understanding everything.
> It is scored by learning **REACTION MAPS**.
>
> A reaction map is just: *this compound + this reagent = this product*.
> That is all the examiner asks. He does not ask "why does the electron move".
> He asks "write the equation".
>
> So your job in this chapter is simple:
> **memorise arrows, reagents and products.** Understanding comes later,
> and honestly it is optional for 50 of the 60 marks.
>
> If you write the correct equation with the correct reagent above the arrow,
> you get the mark. Even if you cannot explain a single word of it.

## THE 60-SECOND VERSION

Every organic compound in this chapter is **a carbon chain wearing a hat**.
The hat is called the **functional group**. The hat decides everything.

```
   HAT              NAME              LOOKS LIKE          MOOD
   ---------------  ----------------  ------------------  ------------------
   -OH on chain     alcohol           CH3-CH2-OH          weakly acidic
   -OH on ring      phenol            C6H5-OH             MORE acidic
   -O- between      ether             CH3-O-CH3           lazy, unreactive
   -CHO at end      aldehyde          CH3-CHO             very reactive
   -CO- in middle   ketone            CH3-CO-CH3          reactive
   -COOH at end     carboxylic acid   CH3-COOH            MOST acidic
```

**The one line that runs through the whole chapter:**

```
   ACIDITY:     R-COOH   >   C6H5-OH   >   H2O   >   R-OH   >   R-C(triple)CH

   OXIDATION LADDER (going right = adding oxygen):

      CH3-CH2-OH   -->   CH3-CHO   -->   CH3-COOH
      alcohol            aldehyde        acid

   REDUCTION goes backwards along the same ladder.
```

Learn that ladder and you can answer half the conversion questions in the paper.

## THE ALPHA-HYDROGEN RULE (this one idea decides 4 questions)

```
   The alpha carbon is the carbon RIGHT NEXT TO the C=O group.
   A hydrogen on that carbon is an ALPHA HYDROGEN.

            H   O                       O
            |   ||                      ||
       H -- C -- C -- H            H -- C -- H
            |                      (HCHO: the carbon holding
            H                       C=O has no neighbour carbon)
        alpha carbon                    NO alpha hydrogen
        has 3 alpha H

   +-----------------------+--------------------+--------------------+
   |  COMPOUND             |  ALPHA HYDROGEN?   |  REACTION IT GIVES |
   +-----------------------+--------------------+--------------------+
   |  HCHO                 |  NO                |  CANNIZZARO        |
   |  C6H5-CHO             |  NO                |  CANNIZZARO        |
   |  (CH3)3C-CHO          |  NO                |  CANNIZZARO        |
   |  CH3-CHO              |  YES (3)           |  ALDOL             |
   |  CH3-CO-CH3           |  YES (6)           |  ALDOL             |
   +-----------------------+--------------------+--------------------+
```

## HONEST ADVICE

You do not need to be clever to score in this chapter.
You need to be **repetitive**.

```
   Reading a reaction        =  0 marks
   Copying a reaction once   =  1 mark maybe
   Writing it from memory
   five times on paper       =  full marks, every time
```

Close the book. Write the reaction. Check. Repeat. That is the whole method.
