# PATTERN 1 — "WHICH REAGENT GIVES WHICH PRODUCT"
# ===============================================================

### Q1
Propene on treatment with B2H6 followed by H2O2/OH- gives:

(a) propan-2-ol  (b) propan-1-ol  (c) propanal  (d) propanone

**ANSWER: (b) propan-1-ol**
```
  CH3-CH=CH2 --(i) B2H6 (ii) H2O2/OH--> CH3-CH2-CH2-OH

  Hydroboration-oxidation is ANTI-MARKOVNIKOV: -OH goes to the carbon
  with MORE hydrogens, giving a PRIMARY alcohol.
```

> **SHORTCUT:** See `B2H6` -> anti-Markovnikov -> primary alcohol.
> See `H2O/H2SO4` -> Markovnikov -> secondary or tertiary alcohol.

---

### Q2
Ethanol heated with conc. H2SO4 at 413 K gives:

(a) ethene  (b) diethyl ether  (c) ethanal  (d) ethanoic acid

**ANSWER: (b) diethyl ether**
```
  413 K (140 C)  ->  ETHER      (lower temperature)
  443 K (170 C)  ->  ALKENE     (higher temperature)

  Memory hook: the HIGHER temperature gives the SMALLER molecule.
```

---

### Q3
The oxidation of a primary alcohol with PCC gives:

(a) a carboxylic acid  (b) a ketone  (c) an aldehyde  (d) an ester

**ANSWER: (c) an aldehyde**
```
  PCC is a MILD oxidising agent and stops at the aldehyde.
  K2Cr2O7/H+ or KMnO4 would go on to the carboxylic acid.
```

---

### Q4
Acetyl chloride on treatment with H2 in presence of Pd-BaSO4 gives:

(a) ethanol  (b) acetaldehyde  (c) acetic acid  (d) ethane

**ANSWER: (b) acetaldehyde**
```
  CH3-CO-Cl --H2 / Pd-BaSO4--> CH3-CHO      (ROSENMUND reduction)

  The catalyst is poisoned so the reduction stops at the aldehyde.
```

---

### Q5
Toluene on treatment with CrO2Cl2 in CS2 followed by hydrolysis gives:

(a) benzoic acid  (b) benzyl alcohol  (c) benzaldehyde  (d) benzene

**ANSWER: (c) benzaldehyde**
```
  ETARD reaction. Chromyl chloride stops at the aldehyde.

  Compare:  C6H5-CH3 --KMnO4/KOH, then H+--> C6H5-COOH  (goes to the ACID)
```

> **SHORTCUT:** For toluene oxidation, memorise just two reagents.
> `CrO2Cl2` or `CrO3/(CH3CO)2O` -> **aldehyde**.
> `KMnO4` -> **acid**.

---

### Q6
Anisole on heating with HI gives:

(a) iodobenzene + methanol
(b) phenol + methyl iodide
(c) benzene + methyl iodide
(d) phenol + methane

**ANSWER: (b) phenol + methyl iodide**
```
  C6H5-O-CH3 + HI --> C6H5-OH + CH3-I

  The bond between oxygen and the RING carbon has partial double bond
  character and never breaks. So the alkyl group takes the iodine and
  phenol is always formed.
```

---

### Q7
Which of the following gives phenol AND acetone as products?

(a) Dow process  (b) cumene process
(c) Reimer-Tiemann reaction  (d) Kolbe reaction

**ANSWER: (b) cumene process**
```
  C6H5-CH(CH3)2 --(i) O2 (ii) dil. H2SO4--> C6H5-OH + CH3-CO-CH3
```

---

### Q8
Phenol on treatment with CHCl3 and aqueous NaOH at 340 K, followed by
hydrolysis, gives:

(a) salicylic acid  (b) salicylaldehyde  (c) benzoic acid  (d) picric acid

**ANSWER: (b) salicylaldehyde**
```
  REIMER-TIEMANN reaction. Intermediate: dichlorocarbene :CCl2

  Contrast with KOLBE (NaOH + CO2), which gives SALICYLIC ACID.
```

> **SHORTCUT:** `CHCl3 + NaOH` -> Reimer-Tiemann -> **CHO** (aldehyde).
> `CO2 + NaOH, pressure` -> Kolbe -> **COOH** (acid).

---

### Q9
Sodium acetate on heating with soda lime gives:

(a) ethane  (b) methane  (c) ethanol  (d) acetone

**ANSWER: (b) methane**
```
  CH3-COONa --NaOH + CaO, heat--> CH4 + Na2CO3

  DECARBOXYLATION removes one carbon. So an acid with n carbons gives a
  hydrocarbon with (n-1) carbons.
```

---

### Q10
Acetic acid reacts with Cl2 in presence of red phosphorus to give:

(a) CH3-CO-Cl  (b) Cl-CH2-COOH  (c) CH3-CCl3  (d) CCl3-COOH

**ANSWER: (b) Cl-CH2-COOH**
```
  HELL-VOLHARD-ZELINSKY reaction. Halogenation occurs at the ALPHA
  carbon, not at the -COOH group.
```

# PATTERN 2 — "WHICH ONE GIVES A POSITIVE TEST"
# ===============================================================

### Q11
Which of the following does NOT give the iodoform test?

(a) CH3-CHO  (b) CH3-CO-CH3  (c) CH3-CH2-OH  (d) CH3-OH

**ANSWER: (d) CH3-OH**
```
  Iodoform needs either  CH3-CO-  or  CH3-CH(OH)-  in the molecule.

  Methanol has neither - the carbon carrying -OH has no other carbon
  attached, so there is no CH3 next to it.
```

> **SHORTCUT for iodoform:** look for a **CH3 group directly attached to
> either a C=O or to a C-OH**. If it is there, the answer is YES.

---

### Q12
Which of the following gives a positive Fehling's test?

(a) C6H5-CHO  (b) CH3-CO-CH3  (c) CH3-CHO  (d) CH3-COOH

**ANSWER: (c) CH3-CHO**
```
  Fehling's works on ALIPHATIC aldehydes only.
  C6H5-CHO is AROMATIC, so it fails Fehling but PASSES Tollens.
  Ketones and acids fail both.
```

---

### Q13
Both Tollens' and Fehling's tests are given by:

(a) acetone  (b) formic acid  (c) benzaldehyde  (d) ethanol

**ANSWER: (b) formic acid**
```
  HCOOH contains a -CHO group as part of its structure (H-COOH), so it
  behaves as an aldehyde and reduces both reagents.

  ** This is why formic acid can be distinguished from acetic acid. **
```

---

### Q14
The reagent that distinguishes all aldehydes and ketones from alcohols is:

(a) Tollens' reagent  (b) Fehling's solution
(c) 2,4-dinitrophenylhydrazine  (d) Lucas reagent

**ANSWER: (c) 2,4-dinitrophenylhydrazine**
```
  2,4-DNP gives an ORANGE/YELLOW precipitate with EVERY aldehyde AND
  EVERY ketone, but not with alcohols.

  Strategy in the lab:  2,4-DNP first (is there a C=O?),
                        then Tollens' (aldehyde or ketone?).
```

---

### Q15
Which reagent distinguishes phenol from ethanol?

(a) Na metal  (b) neutral FeCl3  (c) NaHCO3  (d) Lucas reagent

**ANSWER: (b) neutral FeCl3**
```
  Phenol gives a VIOLET colour. Ethanol gives nothing.

  Na metal fails - BOTH give H2 gas.
  NaHCO3 fails - NEITHER gives CO2.
```

---

### Q16
Which pair can be distinguished using NaHCO3?

(a) phenol and ethanol  (b) phenol and benzoic acid
(c) acetone and propanal  (d) ethanol and methanol

**ANSWER: (b) phenol and benzoic acid**
```
  Benzoic acid -> brisk CO2 effervescence
  Phenol       -> no reaction (weaker than carbonic acid)
```

---

### Q17
Turbidity appears immediately when Lucas reagent is added to:

(a) CH3-CH2-OH  (b) CH3-CH(OH)-CH3  (c) (CH3)3C-OH  (d) CH3-OH

**ANSWER: (c) (CH3)3C-OH**
```
  3deg -> immediate
  2deg -> about 5 minutes
  1deg -> no turbidity in the cold

  The reaction goes through a carbocation, and 3deg carbocations are the
  most stable.
```

# PATTERN 3 — "ALDOL OR CANNIZZARO?"
# ===============================================================

### Q18
Which of the following gives the Cannizzaro reaction?

(a) CH3-CHO  (b) CH3-CH2-CHO  (c) C6H5-CHO  (d) CH3-CO-CH3

**ANSWER: (c) C6H5-CHO**
```
  Cannizzaro requires NO ALPHA HYDROGEN.
  In C6H5-CHO the carbon next to the -CHO is part of the ring and carries
  no hydrogen available for removal.
```

> **SHORTCUT:** The classic no-alpha-H list is short — memorise it:
> `HCHO` , `C6H5-CHO` , `(CH3)3C-CHO` , and other trisubstituted aldehydes.
> Everything else gives ALDOL.

---

### Q19
2 CH3-CHO + dilute NaOH gives:

(a) CH3-CH2-OH + CH3-COONa
(b) CH3-CH(OH)-CH2-CHO
(c) CH3-CH=CH-CH3
(d) no reaction

**ANSWER: (b) CH3-CH(OH)-CH2-CHO**
```
  Acetaldehyde has 3 alpha hydrogens, so it gives the ALDOL.
  On heating, this loses water to give CH3-CH=CH-CHO.
```

---

### Q20
In a crossed Cannizzaro reaction between HCHO and C6H5-CHO, the products
are:

(a) C6H5-COONa + CH3-OH
(b) C6H5-CH2-OH + HCOONa
(c) both alcohols
(d) both acids

**ANSWER: (b) C6H5-CH2-OH + HCOONa**
```
  FORMALDEHYDE is always the better hydride donor, so HCHO is OXIDISED
  (to formate) and the other aldehyde is REDUCED (to the alcohol).
```

---

### Q21
Benzaldehyde reacts with acetaldehyde in dilute NaOH to give mainly:

(a) benzyl alcohol  (b) cinnamaldehyde C6H5-CH=CH-CHO
(c) benzoic acid  (d) a mixture of four aldols

**ANSWER: (b) cinnamaldehyde**
```
  This is a useful CROSS ALDOL because only ONE partner (CH3-CHO) has
  alpha hydrogens. The carbanion from acetaldehyde attacks the
  benzaldehyde carbonyl.

  C6H5-CHO + CH3-CHO --dil. NaOH--> C6H5-CH=CH-CHO + H2O
```

# PATTERN 4 — REACTIVITY AND ACIDITY ORDER
# ===============================================================

### Q22
The correct order of reactivity towards nucleophilic addition is:

(a) HCHO > CH3-CHO > CH3-CO-CH3
(b) CH3-CO-CH3 > CH3-CHO > HCHO
(c) CH3-CHO > HCHO > CH3-CO-CH3
(d) all react equally

**ANSWER: (a) HCHO > CH3-CHO > CH3-CO-CH3**
```
  More alkyl groups = more +I electron push (carbon less positive)
                    + more steric hindrance.
  HCHO has zero alkyl groups, so it is the most reactive of all.
```

> **SHORTCUT:** Count the alkyl/aryl groups on the carbonyl carbon.
> **Fewer groups = more reactive.** That single rule answers the whole family.

---

### Q23
The strongest acid among the following is:

(a) CH3-COOH  (b) ClCH2-COOH  (c) Cl2CH-COOH  (d) Cl3C-COOH

**ANSWER: (d) Cl3C-COOH**
```
  Each Cl withdraws electron density (-I) and stabilises the carboxylate
  ion. Three chlorines give maximum stabilisation.
```

---

### Q24
Which is the strongest acid?

(a) HCOOH  (b) CH3-COOH  (c) CH3-CH2-COOH  (d) (CH3)3C-COOH

**ANSWER: (a) HCOOH**
```
  Alkyl groups RELEASE electrons (+I) and destabilise the anion.
  Formic acid has no alkyl group at all, so it is the strongest.
```

> **SHORTCUT:** In an acidity MCQ, the answer is whichever option has the most
> **electron-withdrawing** groups closest to the -COOH, or the fewest alkyl
> groups.

---

### Q25
Correct order of acidic strength:

(a) C6H5-OH > CH3-COOH > H2O > C2H5-OH
(b) CH3-COOH > C6H5-OH > H2O > C2H5-OH
(c) H2O > CH3-COOH > C6H5-OH > C2H5-OH
(d) C2H5-OH > H2O > C6H5-OH > CH3-COOH

**ANSWER: (b) CH3-COOH > C6H5-OH > H2O > C2H5-OH**
```
  Carboxylate: charge on TWO equivalent oxygens - most stable.
  Phenoxide:   charge delocalised onto ring CARBONS - less stable.
  Alkoxide:    no delocalisation, plus +I from the alkyl group - least.
```

---

### Q26
Which phenol is the most acidic?

(a) phenol  (b) p-cresol  (c) p-nitrophenol  (d) p-methoxyphenol

**ANSWER: (c) p-nitrophenol**
```
  -NO2 withdraws electrons by both -I and -R, stabilising the phenoxide.
  -CH3 and -OCH3 release electrons, so they lower the acidity.
```

---

### Q27
The order of reactivity of alcohols towards HCl (Lucas reagent) is:

(a) 1deg > 2deg > 3deg  (b) 3deg > 2deg > 1deg
(c) 2deg > 3deg > 1deg  (d) all equal

**ANSWER: (b) 3deg > 2deg > 1deg**
```
  The reaction goes through a carbocation, and carbocation stability is
  3deg > 2deg > 1deg.

  NOTE the opposite order for the reaction with SODIUM METAL:
  there it is 1deg > 2deg > 3deg, because that depends on the ACIDITY of
  the O-H bond, not on carbocation stability.
```

> **SHORTCUT:** If the question involves **breaking the C-O bond** (HX,
> dehydration, Lucas), the order is 3deg > 2deg > 1deg.
> If it involves **breaking the O-H bond** (Na metal, esterification), the
> order flips to 1deg > 2deg > 3deg.

---

### Q28
The boiling point order is:

(a) ether > alcohol > acid  (b) acid > alcohol > ether
(c) alcohol > acid > ether  (d) acid > ether > alcohol

**ANSWER: (b) acid > alcohol > ether**
```
  Carboxylic acid forms a DIMER through TWO hydrogen bonds - strongest.
  Alcohol forms single hydrogen bonds.
  Ether has no H on the oxygen, so no hydrogen bonding at all.
```

# PATTERN 5 — GRIGNARD AND PRODUCT PREDICTION
# ===============================================================

### Q29
CH3-MgBr reacts with HCHO followed by hydrolysis to give:

(a) methanol  (b) ethanol  (c) propan-2-ol  (d) tert-butyl alcohol

**ANSWER: (b) ethanol**
```
  HCHO       + RMgX  ->  PRIMARY alcohol
  any other
  aldehyde   + RMgX  ->  SECONDARY alcohol
  ketone     + RMgX  ->  TERTIARY alcohol
  CO2        + RMgX  ->  CARBOXYLIC ACID

  HCHO + CH3MgBr then H3O+ --> CH3-CH2-OH
```

---

### Q30
Acetone reacts with CH3-MgBr followed by hydrolysis to give:

(a) propan-2-ol  (b) 2-methylpropan-2-ol  (c) propanal  (d) acetic acid

**ANSWER: (b) 2-methylpropan-2-ol, (CH3)3C-OH**
```
  A ketone plus a Grignard reagent always gives a TERTIARY alcohol.
```

---

### Q31
CH3-MgBr reacts with dry ice (solid CO2) followed by hydrolysis to give:

(a) methanol  (b) acetaldehyde  (c) acetic acid  (d) acetone

**ANSWER: (c) acetic acid**
```
  CH3-MgBr --(i) CO2 (ii) H3O+--> CH3-COOH

  This is the standard way to ADD ONE CARBON and make an acid.
```

---

### Q32
A Grignard reagent reacts with water to give:

(a) an alcohol  (b) an alkane  (c) an alkene  (d) an acid

**ANSWER: (b) an alkane**
```
  CH3-MgBr + H2O --> CH4 + Mg(OH)Br

  This is why the reaction must be done in DRY ether.
```

---

### Q33
But-2-ene on ozonolysis followed by treatment with Zn/H2O gives:

(a) 2 HCHO  (b) 2 CH3-CHO  (c) CH3-CO-CH3  (d) CH3-COOH

**ANSWER: (b) 2 CH3-CHO**
```
  CH3-CH=CH-CH3 --(i) O3 (ii) Zn/H2O--> 2 CH3-CHO

  Snip the double bond, put an O on each half.
  Zn is present to prevent the H2O2 formed from oxidising the aldehyde.
```

---

### Q34
Ethyne on hydration in presence of H2SO4 and HgSO4 gives:

(a) ethanol  (b) acetaldehyde  (c) acetone  (d) acetic acid

**ANSWER: (b) acetaldehyde**
```
  CH(triple)CH --H2O / H2SO4, HgSO4, 333 K--> CH3-CHO

  ETHYNE is the ONLY alkyne that gives an ALDEHYDE.
  All other alkynes give KETONES.
```

# PATTERN 6 — MECHANISM AND STRUCTURE QUESTIONS

### Q35
The intermediate in the Reimer-Tiemann reaction is:

(a) carbocation  (b) carbanion  (c) dichlorocarbene  (d) free radical

**ANSWER: (c) dichlorocarbene, :CCl2**
```
  CHCl3 + NaOH --> :CCl2 + NaCl + H2O
```

---

### Q36
In the Cannizzaro reaction, the species transferred in the key step is:

(a) a proton  (b) a hydride ion  (c) an electron  (d) a hydroxyl ion

**ANSWER: (b) a hydride ion, H:-**
```
  The tetrahedral intermediate transfers H:- to a second aldehyde
  molecule. That is why one molecule is oxidised and the other reduced.
```

---

### Q37
The hybridisation of the carbonyl carbon in acetaldehyde is:

(a) sp  (b) sp2  (c) sp3  (d) sp3d

**ANSWER: (b) sp2**
```
  The carbonyl group is PLANAR with bond angles of about 120 degrees.
  During nucleophilic addition, the carbon changes from sp2 to sp3.
```

---

### Q38
Which of the following is the correct combination for making
tert-butyl methyl ether by Williamson synthesis?

(a) (CH3)3C-Br + CH3-ONa
(b) CH3-I + (CH3)3C-ONa
(c) (CH3)3C-OH + CH3-OH
(d) (CH3)3C-Br + CH3-OH

**ANSWER: (b) CH3-I + (CH3)3C-ONa**
```
  The HALIDE must be primary or methyl.
  Option (a) would give elimination (an alkene), not the ether, because
  the alkoxide would act as a base on the tertiary halide.
```

---

### Q39
In the acid-catalysed dehydration of an alcohol, the rate determining step
is:

(a) protonation of the -OH group
(b) formation of the carbocation
(c) loss of a beta proton
(d) attack of the acid

**ANSWER: (b) formation of the carbocation**
```
  Step 1 (protonation) is fast, Step 3 (loss of H+) is fast.
  Step 2, in which water leaves and the carbocation forms, is SLOW.

  That is why the ease of dehydration follows carbocation stability:
  3deg > 2deg > 1deg.
```

---

### Q40
Phenol reacts faster than benzene in electrophilic substitution because:

(a) -OH is electron withdrawing
(b) -OH releases electron density into the ring by resonance
(c) phenol is acidic
(d) phenol has a higher boiling point

**ANSWER: (b) -OH releases electron density into the ring by resonance**
```
  The lone pair on oxygen is delocalised into the ring, raising the
  electron density especially at the ORTHO and PARA positions.
  So -OH is an ACTIVATING, ortho/para directing group.

  In contrast, -COOH is DEACTIVATING and META directing.
```

---

### Q41
Which of the following will NOT be oxidised by acidic KMnO4 to benzoic acid?

(a) C6H5-CH3  (b) C6H5-CH2-CH3  (c) C6H5-CH2-CH2-CH3  (d) C6H5-C(CH3)3

**ANSWER: (d) C6H5-C(CH3)3**
```
  Side chain oxidation needs at least one BENZYLIC hydrogen (a hydrogen
  on the carbon directly attached to the ring).

  In C6H5-C(CH3)3 that carbon has three methyl groups and NO hydrogen,
  so the side chain cannot be oxidised.

  All the others, however long the chain, give C6H5-COOH.
```

---

### Q42
Acetophenone (C6H5-CO-CH3) responds to which test?

(a) Tollens' only  (b) Fehling's only
(c) iodoform only  (d) both Tollens' and Fehling's

**ANSWER: (c) iodoform only**
```
  It is a KETONE, so Tollens' and Fehling's both fail.
  But it contains a CH3-CO- group, so the iodoform test is positive
  (yellow CHI3).
  It also gives 2,4-DNP, as every ketone does.
```

```
  |  IF YOU SEE THIS ...             |  THE ANSWER IS ...                 |

  |  O3 then Zn/H2O                  |  ozonolysis, split into 2 carbonyls|
  |  Zn-Hg / conc. HCl               |  CLEMMENSEN, C=O becomes CH2       |

  |  conc. NaOH on an aldehyde       |  CANNIZZARO (needs NO alpha-H)     |
  |  Cl2 / red P on an acid          |  HVZ, alpha halogenation           |
  |  NaOH + CaO, heat                |  DECARBOXYLATION, loses 1 carbon   |
  |  CO2 + RMgX then H3O+            |  CARBOXYLIC ACID                   |
  |  ketone + RMgX then H3O+         |  TERTIARY alcohol                  |
  |  ammoniacal AgNO3                |  TOLLENS -> silver mirror          |
  |  alkaline Cu2+ tartrate          |  FEHLING -> red ppt, aliphatic only|
  |  I2 + NaOH                       |  IODOFORM -> yellow CHI3           |

  |  NaHCO3 fizzing                  |  it is a CARBOXYLIC ACID           |
```

```
  +---------------------------------------------------------------------+
  |  THE FOUR ELIMINATION RULES THAT SAVE TIME                          |
  |                                                                     |
  |  1. Acidity MCQ    ->  pick the option with the most electron-       |
  |                        WITHDRAWING groups nearest the -COOH or -OH.  |
  |                                                                     |
  |  2. Reactivity MCQ ->  count the alkyl groups on the carbonyl.       |
  |                        FEWER groups = MORE reactive.                 |
  |                                                                     |
  |  3. Aldol/Cannizzaro -> count the ALPHA hydrogens first.             |
```
