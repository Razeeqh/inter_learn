# TOPIC 1 — WHAT A FUNCTIONAL GROUP IS

An organic compound is a **chain of carbon atoms**. On its own, a plain carbon
chain (a hydrocarbon) is boring and does almost nothing.

Attach a small group of atoms to that chain and suddenly the compound behaves
in a fixed, predictable way. That small group is called a **FUNCTIONAL GROUP**.

```
   CH3-CH3            ethane           does almost nothing
   CH3-CH2-OH         ethanol          reacts with Na, gets oxidised, forms esters
   CH3-CHO            acetaldehyde     reduces Tollens, gives aldol
   CH3-COOH           acetic acid      turns litmus red, gives CO2 with NaHCO3
```

Same two carbons in every one of them. Only the hat changed.

**The six hats in this chapter:**

```
  +--------------------+-------------------+---------------------------+
  |  FUNCTIONAL GROUP  |  FAMILY NAME      |  EXAMPLE (write it this   |
  |                    |                   |  way in the exam)         |
  +--------------------+-------------------+---------------------------+
  |  -OH on a chain    |  alcohol          |  CH3-CH2-OH               |
  |  -OH on a ring     |  phenol           |  C6H5-OH                  |
  |  -O- in between    |  ether            |  CH3-O-CH3                |
  |  -CHO at the end   |  aldehyde         |  CH3-CHO                  |
  |  -CO- in middle    |  ketone           |  CH3-CO-CH3               |
  |  -COOH at the end  |  carboxylic acid  |  CH3-COOH                 |
  +--------------------+-------------------+---------------------------+
```

> **TRAP:** `C6H5-OH` is a PHENOL, not an alcohol, even though it has -OH.
> The difference is that in phenol the -OH sits directly on the benzene ring.
> If -OH is on a carbon attached to the ring (like C6H5-CH2-OH) it is an
> ALCOHOL (benzyl alcohol), not a phenol. Examiners love this trap.

# TOPIC 2 — CLASSIFICATION AND NOMENCLATURE OF ALCOHOLS

## 2.1 Primary, secondary, tertiary

Look at the carbon carrying the -OH group. Count how many **other carbon atoms**
are attached to it.

```
   ZERO or ONE other carbon   ->  PRIMARY   (1deg)
   TWO other carbons          ->  SECONDARY (2deg)
   THREE other carbons        ->  TERTIARY  (3deg)
```

```
   PRIMARY                SECONDARY                 TERTIARY

   CH3-CH2-OH             CH3-CH(OH)-CH3            CH3
                                                     |
   the C with OH          the C with OH         CH3--C--OH
   touches 1 carbon       touches 2 carbons          |
                                                    CH3

                                                the C with OH
                                                touches 3 carbons
```

This one classification decides:
- the **Lucas test** result
- what you get on **oxidation**
- how fast it reacts with **HX**

So it is worth 10 minutes of your life.

## 2.2 Naming (IUPAC)

```
   RULE 1   Longest chain containing the -OH group = parent chain.
   RULE 2   Drop the final "e" of the alkane and add "ol".
              ethane  ->  ethanol
              propane ->  propanol
   RULE 3   Number the chain so the -OH gets the SMALLEST number.
   RULE 4   Two -OH groups -> "diol";  three -> "triol".
```

```
  +---------------------------+------------------------+------------------+
  |  STRUCTURE                |  IUPAC NAME            |  COMMON NAME     |
  +---------------------------+------------------------+------------------+
  |  CH3-OH                   |  methanol              |  methyl alcohol  |
  |  CH3-CH2-OH               |  ethanol               |  ethyl alcohol   |
  |  CH3-CH2-CH2-OH           |  propan-1-ol           |  n-propyl alc.   |
  |  CH3-CH(OH)-CH3           |  propan-2-ol           |  isopropyl alc.  |
  |  (CH3)3C-OH               |  2-methylpropan-2-ol   |  tert-butyl alc. |
  |  HO-CH2-CH2-OH            |  ethane-1,2-diol       |  ethylene glycol |
  |  C6H5-OH                  |  phenol                |  carbolic acid   |
  |  CH3-O-CH3                |  methoxymethane        |  dimethyl ether  |
  |  CH3-O-C6H5               |  methoxybenzene        |  anisole         |
  |  CH3-CHO                  |  ethanal               |  acetaldehyde    |
  |  CH3-CO-CH3               |  propanone             |  acetone         |
  |  C6H5-CHO                 |  benzaldehyde          |  benzaldehyde    |
  |  CH3-COOH                 |  ethanoic acid         |  acetic acid     |
  |  HCOOH                    |  methanoic acid        |  formic acid     |
  |  C6H5-COOH                |  benzoic acid          |  benzoic acid    |
  +---------------------------+------------------------+------------------+
```

> **TRAP:** In an ether, the SMALLER group becomes the "alkoxy" part and the
> BIGGER group becomes the parent. So CH3-O-CH2-CH3 is **methoxyethane**, not
> ethoxymethane.

# TOPIC 3 — HOW TO MAKE ALCOHOLS (4 methods)

## 3.1 Hydration of alkenes (acid-catalysed) — MARKOVNIKOV product

Water adds across the C=C double bond. The -OH goes to the carbon that already
has FEWER hydrogens (Markovnikov's rule).

```
   CH3-CH=CH2   --H2O / dil. H2SO4-->   CH3-CH(OH)-CH3
   propene                              propan-2-ol   (2deg alcohol)
```

Remember it as: **"the rich get richer"** — the H adds where H is already
plentiful.

## 3.2 Hydroboration-oxidation — ANTI-MARKOVNIKOV product

Same alkene, opposite answer. The -OH goes to the carbon that has MORE
hydrogens.

```
   CH3-CH=CH2   --(i) B2H6  (ii) H2O2 / OH- -->   CH3-CH2-CH2-OH
   propene                                        propan-1-ol  (1deg alcohol)
```

```
  +----------------------------+-----------------+-------------------------+
  |  REAGENT                   |  RULE           |  PRODUCT FROM PROPENE   |
  +----------------------------+-----------------+-------------------------+
  |  H2O / H2SO4               |  Markovnikov    |  CH3-CH(OH)-CH3  (2deg) |
  |  (i) B2H6 (ii) H2O2/OH-    |  anti-Markov.   |  CH3-CH2-CH2-OH  (1deg) |
  +----------------------------+-----------------+-------------------------+
```

> **TRAP:** This pair is asked as a 2-mark question almost every year.
> If the question says B2H6 and you write the Markovnikov product, you get zero.

## 3.3 Reduction of carbonyl compounds

Adding hydrogen to a C=O group turns it into a C-OH group.

```
   CH3-CHO      --H2 / Ni  or  NaBH4  or  LiAlH4-->   CH3-CH2-OH
   aldehyde                                            1deg alcohol

   CH3-CO-CH3   --H2 / Ni  or  NaBH4  or  LiAlH4-->   CH3-CH(OH)-CH3
   ketone                                              2deg alcohol

   CH3-COOH     --LiAlH4  (NOT NaBH4)-->              CH3-CH2-OH
   acid                                                1deg alcohol

   CH3-COOC2H5  --(i) LiAlH4  (ii) H3O+-->  CH3-CH2-OH  +  C2H5-OH
   ester
```

```
   RULE OF THUMB:
      aldehyde  ->  1deg alcohol
      ketone    ->  2deg alcohol
      acid/ester->  1deg alcohol   (needs the strong reagent LiAlH4)
```

> **TRAP:** NaBH4 reduces aldehydes and ketones but **cannot** reduce carboxylic
> acids or esters. LiAlH4 reduces everything. If the question gives an acid,
> write LiAlH4.

## 3.4 Grignard reagents — the most asked preparation

A Grignard reagent is `R-Mg-X` (for example `CH3-MgBr`). It is made by:

```
   CH3-Br  +  Mg   --dry ether-->   CH3-Mg-Br
```

It attacks the carbon of a C=O group and, after adding water/acid, gives an
alcohol. **Which alcohol you get depends on which carbonyl you start with.**

```
  +----------------------+---------------------------+--------------------+
  |  CARBONYL USED       |  PRODUCT AFTER H3O+       |  TYPE OF ALCOHOL   |
  +----------------------+---------------------------+--------------------+
  |  HCHO (formaldehyde) |  CH3-CH2-OH               |  PRIMARY           |
  |  CH3-CHO (any other  |  CH3-CH(OH)-CH3           |  SECONDARY         |
  |    aldehyde)         |                           |                    |
  |  CH3-CO-CH3 (ketone) |  (CH3)3C-OH               |  TERTIARY          |
  |  CO2                 |  CH3-COOH                 |  CARBOXYLIC ACID   |
  +----------------------+---------------------------+--------------------+
```

Written as equations:

```
   HCHO         --(i) CH3MgBr (ii) H3O+-->   CH3-CH2-OH

   CH3-CHO      --(i) CH3MgBr (ii) H3O+-->   CH3-CH(OH)-CH3

   CH3-CO-CH3   --(i) CH3MgBr (ii) H3O+-->   (CH3)3C-OH

   CO2          --(i) CH3MgBr (ii) H3O+-->   CH3-COOH
```

> **TRAP:** Grignard reagents are destroyed by ANY compound with an active
> hydrogen — water, alcohol, acid, amine. That is why the reaction must be done
> in **dry ether**. This "why dry ether?" is a standard 2-mark question.
> Answer: `CH3MgBr + H2O --> CH4 + Mg(OH)Br` — the reagent is wasted as methane.

# TOPIC 4 — HOW TO MAKE PHENOL (4 methods)

```
  ========================= PHENOL PREPARATION MAP ========================

                        chlorobenzene C6H5-Cl
                                |
                        NaOH, 623 K, 300 atm
                        then dilute HCl
                                |
                                v
   benzene       C6H5-SO3H --NaOH fused, then H+-->  C6H5-OH  <-- cumene
   sulphonic                                            ^         process
   acid                                                 |
                                                        |
                        C6H5-N2+Cl- (benzene diazonium chloride)
                                |
                        warm with water (H2O, 283 K, dil. acid)
                                |
                                +---------------------+

  ========================================================================
```

## 4.1 From haloarenes (Dow process)

```
   C6H5-Cl   --NaOH, 623 K, 300 atm-->   C6H5-ONa   --dil. HCl-->   C6H5-OH
```

## 4.2 From benzenesulphonic acid

```
   C6H6   --conc. H2SO4-->   C6H5-SO3H

   C6H5-SO3H  --NaOH-->  C6H5-SO3Na  --NaOH fused, 573 K-->  C6H5-ONa

   C6H5-ONa   --dil. HCl-->   C6H5-OH
```

## 4.3 From diazonium salts (the mildest route)

```
   C6H5-NH2  --NaNO2 + HCl, 273-278 K-->  C6H5-N2+Cl-

   C6H5-N2+Cl-  --H2O, warm (283 K)-->  C6H5-OH  +  N2  +  HCl
```

## 4.4 Cumene process (INDUSTRIAL — remember acetone is the by-product)

```
   C6H6  +  CH3-CH=CH2  --H+-->   C6H5-CH(CH3)2         (cumene)

   C6H5-CH(CH3)2  --O2 (air)-->   cumene hydroperoxide

   cumene hydroperoxide  --dil. H2SO4-->  C6H5-OH  +  CH3-CO-CH3
```

> **TRAP:** "Which industrial process gives phenol AND acetone together?"
> Answer: the **cumene process**. This exact 2-mark question repeats often.

# TOPIC 5 — PHYSICAL PROPERTIES AND HYDROGEN BONDING

## 5.1 Why alcohols boil so high

An -OH group has a hydrogen sitting on a very electronegative oxygen. That
hydrogen is partly positive and is attracted to the oxygen of the next molecule.
That attraction is a **HYDROGEN BOND**.

```
        H          H          H
        |          |          |
   R -- O ..... O -- R ..... O -- R
                |
             (dotted line = hydrogen bond)

   To boil the liquid you must BREAK all these bonds.
   Breaking them needs extra energy  ->  HIGH boiling point.
```

```
  +-------------------------+--------------+----------------------------+
  |  COMPOUND               |  MOL. MASS   |  BOILING POINT (approx.)   |
  +-------------------------+--------------+----------------------------+
  |  CH3-CH2-CH3  (propane) |     44       |     - 42 C                 |
  |  CH3-CHO      (ethanal) |     44       |     + 21 C                 |
  |  CH3-CH2-OH   (ethanol) |     46       |     + 78 C                 |
  +-------------------------+--------------+----------------------------+

  Almost the same mass. Huge difference. The reason is hydrogen bonding.
```

## 5.2 The three-way comparison you will be asked

```
   BOILING POINT:   carboxylic acid  >  alcohol  >  ketone  >  aldehyde  >  ether

   REASON:
      acid     - forms a DIMER through TWO hydrogen bonds  (strongest)
      alcohol  - forms hydrogen bonds (one -OH)
      ketone / aldehyde - only dipole-dipole attraction, no H bonding
                          between their own molecules
      ether    - almost no attraction at all, boils lowest
```

The acid dimer, drawn:

```
                  O ....... H - O
                 //                \
        CH3 -- C                     C -- CH3
                 \                  //
                  O - H ....... O

   Two hydrogen bonds hold two acid molecules together as one big unit.
   That is why acetic acid boils at 118 C while ethanol boils at 78 C.
```

> **TRAP:** Ethers do NOT hydrogen bond with each other (no H on the O), so they
> boil low — but they DO dissolve a little in water, because water can donate a
> hydrogen bond TO the ether oxygen. Both facts are separately examinable.

## 5.3 Solubility

```
   Small alcohols (up to 3-4 carbons)  -  fully soluble in water
   As the carbon chain grows           -  solubility FALLS
   Reason: the long hydrocarbon tail hates water and outweighs the -OH head.

   Phenol - slightly soluble in water, freely soluble in NaOH (forms salt).
```

# TOPIC 6 — ACIDITY: ALCOHOLS versus PHENOLS

This is the single most asked THEORY question of Part 1.

## 6.1 What "acidic" means here

Both alcohols and phenols can release the H of the -OH group:

```
   R-OH        <-->   R-O-      +   H+       (alkoxide ion)
   C6H5-OH     <-->   C6H5-O-   +   H+       (phenoxide ion)
```

**The rule:** whichever leaves behind the MORE STABLE negative ion is the
STRONGER acid.

## 6.2 Why phenol wins

```
   ALKOXIDE ION  (from alcohol)          PHENOXIDE ION  (from phenol)

        CH3-CH2-O(-)                          O(-)
                                              |
   The negative charge is STUCK           +---+---+
   on the one oxygen atom.                |       |     the negative charge
                                          |  ring |     SPREADS into the ring
   Worse still, the alkyl group           |       |     by RESONANCE
   pushes electrons (+I effect)           +-------+     onto the ortho and
   TOWARDS the oxygen, piling up                        para carbons.
   more negative charge.
                                          Charge spread out = STABLE
   Charge concentrated = UNSTABLE
```

The resonance spreading, drawn simply:

```
     O-            O            O            O
     |            ||           ||           ||
   +-+-+        +-+-+        +-+-+        +-+-+
   |   |  <-->  | - |  <-->  |   |  <-->  |   |
   |   |        |   |        |(-)|        |   |
   +---+        +---+        +---+        +-(-)+
  phenoxide    charge on    charge on    charge on
   ion         ortho C      other        para C
                            ortho C

   FOUR resonance structures  ->  charge is shared by 4 atoms  ->  stable.
```

**Model answer (write exactly this in the exam):**

```
   Phenol is more acidic than ethanol because:

   1. On losing H+, phenol gives the PHENOXIDE ion, in which the negative
      charge is delocalised over the benzene ring by resonance. This makes
      the phenoxide ion very stable.

   2. Ethanol gives the ETHOXIDE ion, in which the negative charge stays
      localised on the oxygen atom. There is no resonance.

   3. Also, the ethyl group has an electron-releasing (+I) effect which
      increases the electron density on oxygen and destabilises the
      ethoxide ion.

   A more stable anion means the acid ionises more easily,
   therefore phenol is the stronger acid.
```

## 6.3 The full acidity order

```
   R-COOH   >   H2CO3   >   C6H5-OH   >   H2O   >   R-OH   >   R-C(triple)CH
```

A simple experimental proof:

```
   Phenol   +  NaOH     -->  sodium phenoxide + H2O      (reaction happens)
   Phenol   +  NaHCO3   -->  NO reaction  (no CO2 gas)

   CH3-COOH +  NaHCO3   -->  CH3-COONa + H2O + CO2 (gas evolved)

   ** This is exactly how you distinguish phenol from a carboxylic acid. **
```

## 6.4 Effect of substituents on phenol acidity

```
  +---------------------------+----------------+------------------------+
  |  GROUP ON THE RING        |  EFFECT        |  ACIDITY OF PHENOL     |
  +---------------------------+----------------+------------------------+
  |  -NO2 , -CN , -CHO , -X   |  ELECTRON      |  INCREASES             |
  |  (electron withdrawing)   |  WITHDRAWING   |  (pulls charge away    |
  |                           |  (-I, -R)      |   from O, stabilises   |
  |                           |                |   the phenoxide ion)   |
  +---------------------------+----------------+------------------------+
  |  -CH3 , -C2H5 , -OCH3 ,   |  ELECTRON      |  DECREASES             |
  |  -NH2                     |  RELEASING     |  (pushes charge onto   |
  |  (electron releasing)     |  (+I, +R)      |   O, destabilises the  |
  |                           |                |   phenoxide ion)       |
  +---------------------------+----------------+------------------------+
```

**Acidity order to memorise:**

```
   2,4,6-trinitrophenol  >  4-nitrophenol  >  phenol  >  4-methylphenol
        (picric acid)                                       (p-cresol)

   Position matters too:   ortho- and para-nitrophenol are MORE acidic
   than meta-nitrophenol, because only from ortho and para positions can
   the -NO2 group withdraw charge by RESONANCE as well as by induction.
```

> **TRAP:** Students write "nitro group increases acidity" and stop. You must
> add **why**: it withdraws electron density and stabilises the phenoxide ion.
> The "why" carries the marks.

## 7.1 Reaction with active metals

```
   2 CH3-CH2-OH  +  2 Na   -->   2 CH3-CH2-ONa  +  H2

   Hydrogen gas is released. This shows alcohols are WEAKLY ACIDIC.
   Order of reactivity with sodium:   1deg  >  2deg  >  3deg
```

## 7.2 Esterification

```
   CH3-CH2-OH  +  CH3-COOH   --conc. H2SO4, heat-->  CH3-COO-CH2-CH3  +  H2O
                                                     (ethyl acetate)

   Reversible. Conc. H2SO4 acts as catalyst AND removes water,
   pushing the reaction forward.
```

Phenols react the same way but need a stronger acylating agent:

```
   C6H5-OH  +  (CH3-CO)2O   --pyridine-->   C6H5-OOC-CH3   +  CH3-COOH
                                            (phenyl acetate)
```

## 7.3 Reaction with HX — THE LUCAS TEST

Lucas reagent = **conc. HCl + anhydrous ZnCl2**.

```
   R-OH  +  HCl  --anhyd. ZnCl2-->  R-Cl  +  H2O

   R-Cl is INSOLUBLE in the reagent, so it appears as CLOUDINESS (turbidity).
   The FASTER the cloudiness, the more reactive the alcohol.
```

```
  +----------------+---------------------------+------------------------+
  |  ALCOHOL       |  WHAT YOU SEE             |  WHY                   |
  +----------------+---------------------------+------------------------+
  |  TERTIARY      |  turbidity IMMEDIATELY    |  gives a very stable   |
  |  (CH3)3C-OH    |                           |  3deg carbocation      |
  +----------------+---------------------------+------------------------+
  |  SECONDARY     |  turbidity in about       |  2deg carbocation is   |
  |  CH3-CH(OH)CH3 |  5 minutes                |  moderately stable     |
  +----------------+---------------------------+------------------------+
  |  PRIMARY       |  NO turbidity at room     |  1deg carbocation is   |
  |  CH3-CH2-OH    |  temperature (needs       |  too unstable to form  |
  |                |  heating)                 |                        |
  +----------------+---------------------------+------------------------+
```

```
   REACTIVITY ORDER TOWARDS HX:    3deg  >  2deg  >  1deg  >  CH3-OH
   REACTIVITY ORDER OF THE HX :    HI    >  HBr   >  HCl
```

## 7.4 Dehydration — losing water to form an alkene

```
   CH3-CH2-OH   --conc. H2SO4, 443 K-->   CH2=CH2  +  H2O
```

```
   EASE OF DEHYDRATION:    3deg  >  2deg  >  1deg
   (same order as Lucas, for the same carbocation reason)

   TEMPERATURE DECIDES THE PRODUCT:
      413 K (140 C) + excess alcohol   ->   ETHER
      443 K (170 C) + excess acid      ->   ALKENE
```

**Mechanism of dehydration (E1), step by step:**

```
   STEP 1   Protonation of the -OH  (fast)

            CH3-CH2-OH  +  H+   -->   CH3-CH2-OH2(+)

   STEP 2   Loss of water, forming a CARBOCATION  (slow, rate-determining)

            CH3-CH2-OH2(+)   -->   CH3-CH2(+)   +   H2O

   STEP 3   Loss of a proton from the beta carbon, forming the double bond

            CH3-CH2(+)   -->   CH2=CH2   +   H+
```

## 7.5 Oxidation and dehydrogenation — the 1deg / 2deg / 3deg test

```
  +----------+---------------------------+-----------------------------+
  |  ALCOHOL |  OXIDATION (K2Cr2O7/H+)   |  DEHYDROGENATION (Cu,573 K) |
  +----------+---------------------------+-----------------------------+
  |  1deg    |  aldehyde, then further   |  ALDEHYDE                   |
  |          |  to CARBOXYLIC ACID       |  CH3-CH2-OH --> CH3-CHO     |
  +----------+---------------------------+-----------------------------+
  |  2deg    |  KETONE (stops there)     |  KETONE                     |
  |          |  CH3-CH(OH)-CH3 -->       |  same product               |
  |          |  CH3-CO-CH3               |                             |
  +----------+---------------------------+-----------------------------+
  |  3deg    |  NO reaction in neutral / |  DEHYDRATION to an ALKENE   |
  |          |  mild conditions. Under   |  (no H on the C bearing OH) |
  |          |  strong conditions the    |  (CH3)3C-OH --> (CH3)2C=CH2 |
  |          |  chain BREAKS and gives   |                             |
  |          |  smaller ketones/acids    |                             |
  +----------+---------------------------+-----------------------------+
```

Special mild reagent — **PCC (pyridinium chlorochromate)**:

```
   CH3-CH2-OH   --PCC-->   CH3-CHO     (STOPS at the aldehyde,
                                        does NOT go on to the acid)
```

> **TRAP:** If the question asks for an ALDEHYDE from a primary alcohol, use
> **PCC** or **Cu at 573 K**. If you write K2Cr2O7 you overshoot to the acid
> and lose the mark.

## 8.1 Why phenol is so easily substituted

The -OH group pushes electron density INTO the ring (+R effect). This makes
the ring electron-rich, so it attracts electrophiles strongly.
The extra electron density piles up specially at the **ortho and para**
positions — so -OH is an **ortho/para directing, activating group**.

## 8.2 Kolbe reaction (Kolbe-Schmitt)

```
   C6H5-OH  --NaOH-->  C6H5-ONa

   C6H5-ONa  --CO2, 400 K, 4-7 atm-->  sodium salicylate  --H3O+-->
                                       2-hydroxybenzoic acid (SALICYLIC ACID)
```

Written in short form for the exam:

```
   C6H5-ONa   --(i) CO2, 400 K, 4-7 atm  (ii) H+-->   C6H4(OH)-COOH
                                                      (salicylic acid)
```

Salicylic acid is the starting material for **aspirin**.

## 8.3 Reimer-Tiemann reaction

```
   C6H5-OH   --(i) CHCl3 + aq. NaOH, 340 K  (ii) H3O+-->  C6H4(OH)-CHO
                                                          (salicylaldehyde,
                                                           2-hydroxybenzaldehyde)
```

The attacking species is **dichlorocarbene, :CCl2**, formed from CHCl3 + NaOH.

```
   CHCl3  +  NaOH   -->   :CCl2   +   NaCl   +   H2O
```

> **TRAP:** Kolbe gives an **ACID** (-COOH). Reimer-Tiemann gives an
> **ALDEHYDE** (-CHO). Students swap them constantly.
> Memory hook: **K** for Kolbe, **K** for "karboxylic" acid.

## 8.4 The rest of the phenol reactions

```
   NITRATION (dilute HNO3, 298 K):
        C6H5-OH  --dil. HNO3-->  o-nitrophenol  +  p-nitrophenol

   NITRATION (conc. HNO3):
        C6H5-OH  --conc. HNO3-->  2,4,6-trinitrophenol  (PICRIC ACID)

   BROMINATION in CS2 at 273 K (low polarity solvent):
        C6H5-OH  --Br2 / CS2, 273 K-->  p-bromophenol   (MONO substitution)

   BROMINATION in WATER (polar solvent):
        C6H5-OH  --Br2 water-->  2,4,6-tribromophenol   (WHITE precipitate)

   SULPHONATION:
        C6H5-OH  --conc. H2SO4, 298 K-->  o-phenolsulphonic acid  (mainly)
        C6H5-OH  --conc. H2SO4, 373 K-->  p-phenolsulphonic acid  (mainly)

   WITH ZINC DUST:
        C6H5-OH  +  Zn   --distil-->   C6H6   +   ZnO

   OXIDATION:
        C6H5-OH  --Na2Cr2O7 / H+-->   benzoquinone (a conjugated diketone)

   FeCl3 TEST:
        C6H5-OH  +  neutral FeCl3  -->  VIOLET / purple coloured complex
```

> **TRAP:** In CS2 at 273 K you get MONO-bromination; in WATER you get TRI-
> bromination. The solvent is the whole question. In water, phenol ionises
> slightly to phenoxide, which is far more activated, so all three positions
> react.

# TOPIC 9 — ETHERS

An ether is `R-O-R'`. The oxygen sits between two carbon groups. Ethers are
**lazy** — they hardly react with anything except strong acids.

## 9.1 Williamson synthesis (the standard preparation)

```
   R-X   +   R'-ONa    -->   R-O-R'   +   NaX

   Example:
   CH3-CH2-Br  +  CH3-ONa   -->   CH3-CH2-O-CH3   +   NaBr
```

**The golden rule of Williamson synthesis:**

```
   The HALIDE must be PRIMARY (or methyl).
   The ALKOXIDE may be primary, secondary or tertiary.

   WHY?  Alkoxide ion is a strong BASE. With a 3deg halide it does not
         substitute — it removes a beta hydrogen and gives an ALKENE
         (elimination) instead of the ether.
```

```
   RIGHT WAY to make tert-butyl methyl ether:
        CH3-I   +   (CH3)3C-ONa   -->   (CH3)3C-O-CH3            GOOD

   WRONG WAY:
        (CH3)3C-Br  +  CH3-ONa    -->   (CH3)2C=CH2  +  CH3OH    ALKENE!
```

> **TRAP:** This "which combination is correct" question is asked in both the
> board exam and EAPCET. Always attach the halogen to the SMALLER, primary group.

## 9.2 Dehydration of alcohols

```
   2 CH3-CH2-OH   --conc. H2SO4, 413 K-->   CH3-CH2-O-CH2-CH3  +  H2O

   Works only for PRIMARY alcohols and only for SYMMETRICAL ethers.
   Secondary and tertiary alcohols give alkenes instead.
```

## 9.3 Cleavage by HX — which side breaks?

Ethers are broken by hot concentrated HI or HBr.

```
   R-O-R'   +   HX    -->    R-X   +   R'-OH
```

**Rule for deciding which side becomes the halide:**

```
  +----------------------------------+---------------------------------+
  |  SITUATION                       |  THE HALIDE FORMS FROM ...      |
  +----------------------------------+---------------------------------+
  |  Both groups primary             |  the SMALLER alkyl group        |
  |  (SN2 attack on less hindered C) |                                 |
  +----------------------------------+---------------------------------+
  |  One group is 3deg               |  the TERTIARY group             |
  |  (SN1, stable carbocation)       |                                 |
  +----------------------------------+---------------------------------+
  |  One group is ARYL (anisole)     |  the ALKYL group ALWAYS.        |
  |                                  |  You get PHENOL + alkyl halide. |
  +----------------------------------+---------------------------------+
```

```
   CH3-O-CH2-CH3   +   HI   -->   CH3-I    +   CH3-CH2-OH
                                  (from the SMALLER group)

   (CH3)3C-O-CH3   +   HI   -->   (CH3)3C-I  +  CH3-OH
                                  (from the TERTIARY group)

   C6H5-O-CH3      +   HI   -->   C6H5-OH   +   CH3-I
   (anisole)                      (PHENOL, never C6H5-I)
```

> **TRAP:** Anisole NEVER gives iodobenzene. The C-O bond to the ring has
> partial double bond character and is too strong to break. Phenol is always
> one product.

## 9.4 Electrophilic substitution in anisole

The -OCH3 group is activating and ortho/para directing (same as -OH).

```
   C6H5-O-CH3   --CH3Cl / anhyd. AlCl3-->   o- and p-methylanisole
                                            (FRIEDEL-CRAFTS ALKYLATION)

   C6H5-O-CH3   --CH3COCl / anhyd. AlCl3-->  o- and p-methoxyacetophenone
                                            (FRIEDEL-CRAFTS ACYLATION)

   C6H5-O-CH3   --Br2 / CH3COOH-->   p-bromoanisole  (major)

   C6H5-O-CH3   --conc. HNO3 + conc. H2SO4-->  o- and p-nitroanisole
```

The **para** product is usually the major one, because the ortho positions are
blocked by the bulky -OCH3 group (steric hindrance).

# TOPIC 10 — THE CARBONYL GROUP: ALDEHYDES AND KETONES

## 10.1 What the C=O group is

```
        (delta+)   (delta-)
           C   =   O

   Oxygen is far more electronegative than carbon, so it pulls the shared
   electrons towards itself.

   RESULT:   the CARBON becomes PARTIALLY POSITIVE
             the OXYGEN becomes PARTIALLY NEGATIVE

   A partly positive carbon is a magnet for NUCLEOPHILES
   (electron-rich species like CN-, OH-, RMgX).

   ** This one line explains every addition reaction in the chapter. **
```

The carbonyl carbon is **sp2 hybridised** and the group is **planar**, with
bond angles of about 120 degrees.

## 10.2 The difference between an aldehyde and a ketone

```
   ALDEHYDE:  the C=O carbon carries at least ONE hydrogen
              CH3-CHO ,  HCHO ,  C6H5-CHO

   KETONE:    the C=O carbon carries TWO carbon groups, no hydrogen
              CH3-CO-CH3 ,  CH3-CO-C6H5

   That single hydrogen is the reason aldehydes are OXIDISED so easily
   (Tollens, Fehling) while ketones are not.
```

## 11.1 From alcohols

```
   CH3-CH2-OH        --PCC-->            CH3-CHO
   CH3-CH2-OH        --Cu, 573 K-->      CH3-CHO   +  H2
   CH3-CH(OH)-CH3    --K2Cr2O7 / H+-->   CH3-CO-CH3
```

## 11.2 Ozonolysis of alkenes

Ozone snips the double bond in half and puts an O on each piece.

```
   CH3-CH=CH-CH3   --(i) O3  (ii) Zn / H2O-->   2 CH3-CHO

   CH2=CH2         --(i) O3  (ii) Zn / H2O-->   2 HCHO

   (CH3)2C=CH-CH3  --(i) O3  (ii) Zn / H2O-->   CH3-CO-CH3  +  CH3-CHO
```

> **TRAP:** The Zn dust is essential. Without it, the H2O2 formed would oxidise
> the aldehyde to an acid. Always write "Zn / H2O" in the second step.

## 11.3 From alkynes (hydration)

```
   CH(triple)CH   --H2O / dil. H2SO4 , HgSO4 , 333 K-->   CH3-CHO
   ethyne                                                 (the ONLY alkyne
                                                           giving an aldehyde)

   CH3-C(triple)CH  --H2O / dil. H2SO4 , HgSO4-->   CH3-CO-CH3
   propyne                                          (all other alkynes
                                                     give KETONES)
```

## 11.4 Rosenmund reduction (acyl chloride to aldehyde)

```
   CH3-CO-Cl   --H2 , Pd on BaSO4 (poisoned with S or quinoline)-->  CH3-CHO
```

The catalyst is deliberately **poisoned** (weakened) so the reaction stops at
the aldehyde and does not go on to the alcohol.

## 11.5 Stephen reaction (nitrile to aldehyde)

```
   CH3-CN   --(i) SnCl2 / HCl  (ii) H3O+-->   CH3-CHO
```

Alternative with DIBAL-H:

```
   CH3-CN   --(i) DIBAL-H  (ii) H2O-->   CH3-CHO
```

## 11.6 From esters (DIBAL-H)

```
   CH3-COOC2H5   --(i) DIBAL-H  (ii) H2O-->   CH3-CHO  +  C2H5-OH
```

## 11.7 From nitriles to KETONES (Grignard route)

```
   CH3-CN   --(i) CH3MgBr  (ii) H3O+-->   CH3-CO-CH3
```

## 11.8 Etard reaction (toluene to benzaldehyde)

```
   C6H5-CH3   --(i) CrO2Cl2 in CS2  (ii) H3O+-->   C6H5-CHO
```

Chromyl chloride oxidises **only the side chain**, and stops at the aldehyde.

## 11.9 Gatterman-Koch reaction (benzene to benzaldehyde)

```
   C6H6   --CO + HCl , anhyd. AlCl3 / CuCl-->   C6H5-CHO
```

Think of it as Friedel-Crafts formylation, using CO + HCl in place of HCHO-Cl
(which does not exist as a bottled reagent).

## 11.10 Side-chain oxidation

```
   C6H5-CH3   --CrO3 in (CH3CO)2O , then H3O+-->   C6H5-CHO

   C6H5-CH3   --KMnO4 / KOH , then H3O+-->        C6H5-COOH
                                                  (goes all the way to the ACID)
```

> **TRAP:** CrO2Cl2 (Etard) and CrO3/acetic anhydride stop at the **aldehyde**.
> KMnO4 goes all the way to the **acid**. The examiner picks the reagent
> deliberately.

# TOPIC 12 — THE NUCLEOPHILIC ADDITION MECHANISM

This is the ONE mechanism you must know cold for aldehydes and ketones.

```
  ============== NUCLEOPHILIC ADDITION, STEP BY STEP =====================

   STEP 1   The nucleophile Nu(-) attacks the partly positive carbon of
            the C=O group from above or below the plane.
            The pi electrons shift onto oxygen.
            (This step is SLOW - it decides the rate.)

                 (delta-)
                    O                        O(-)
                    ||                       |
              R --- C --- H       ---->  R - C - H
                    ^                        |
                    |                        Nu
                  Nu(-)
                                        (tetrahedral ALKOXIDE ion)


   STEP 2   The negatively charged oxygen picks up a proton from the
            reaction mixture. (This step is FAST.)

                  O(-)                       OH
                  |                          |
              R - C - H     + H+  ---->  R - C - H
                  |                          |
                  Nu                         Nu

                                        (final ADDITION product)

   NET RESULT:  the C=O double bond has become a C-OH single bond,
                and the nucleophile has attached to the carbon.
                The carbon has changed from sp2 (planar) to sp3
                (tetrahedral).

  ========================================================================
```

## 12.1 Why aldehydes are MORE reactive than ketones

```
   REACTIVITY ORDER:

      HCHO  >  CH3-CHO  >  CH3-CH2-CHO  >  CH3-CO-CH3  >  CH3-CO-C6H5
                                                          >  C6H5-CO-C6H5

   In one sentence:  ALDEHYDES  >  KETONES
```

**Two reasons — you must give BOTH to get full marks.**

```
   REASON 1 : ELECTRONIC (+I effect)

      An alkyl group PUSHES electrons towards the carbonyl carbon.
      This reduces the positive charge on that carbon, so the nucleophile
      is less attracted.

         aldehyde  R-CHO      has ONE alkyl group pushing
         ketone    R-CO-R'    has TWO alkyl groups pushing

      Two pushes > one push  ->  the ketone carbon is less positive
                             ->  the ketone is LESS reactive.


   REASON 2 : STERIC HINDRANCE (crowding)

      The nucleophile has to physically reach the carbon.

         O                       O
         ||                      ||
    R -- C -- H            R  --  C  -- R'
         ^                        ^
      easy to reach          two bulky groups block the path

      In a ketone, TWO bulky alkyl groups block the attack.
      In an aldehyde, one of them is only a small hydrogen atom.
```

**Why is benzaldehyde less reactive than acetaldehyde?**

```
   In C6H5-CHO the benzene ring donates electron density into the
   carbonyl group by RESONANCE (+R effect). The carbonyl carbon becomes
   less positive, so nucleophilic addition is slower.
```

> **TRAP:** In carbonyl chemistry the reactivity order is
> **aldehyde > ketone**, but for **oxidation** it is also aldehyde > ketone,
> while for the **aldol** reaction it is again aldehyde > ketone.
> Almost everything follows the same order — but remember that a ketone
> that HAS alpha-H still gives aldol, and an aldehyde WITHOUT alpha-H does not.

## 13.1 Addition of HCN — cyanohydrin

```
   CH3-CHO   +  HCN   --trace of base (KCN)-->   CH3-CH(OH)-CN
                                                 (2-hydroxypropanenitrile)

   Why a trace of base?  The base produces CN(-) ions, which are the true
   nucleophile. HCN by itself ionises too little and the reaction is slow.
```

## 13.2 Addition of sodium bisulphite

```
   CH3-CHO   +  NaHSO3   -->   CH3-CH(OH)-SO3Na
                               (a WHITE CRYSTALLINE solid)

   USE:  the solid can be filtered off and then heated with dilute acid or
         alkali to give back the pure aldehyde.
         ** This is how aldehydes and methyl ketones are PURIFIED. **

   Note:  only aldehydes and METHYL ketones (and cyclic ketones) react.
          Bulky ketones do not — steric hindrance.
```

## 13.3 Addition of alcohols — hemiacetal and acetal

```
   CH3-CHO  +  C2H5-OH   --dry HCl-->   CH3-CH(OH)-OC2H5    (HEMIACETAL)

   CH3-CH(OH)-OC2H5  +  C2H5-OH  --dry HCl-->  CH3-CH(OC2H5)2  +  H2O
                                               (ACETAL)

   Acetals are stable to bases, so they are used to PROTECT a -CHO group
   while you do something else to the molecule. Dilute acid brings the
   aldehyde back.
```

## 13.4 Reaction with ammonia derivatives (condensation)

The general pattern: **the O of C=O is swapped for =N-Z, and water leaves.**

```
   R2C=O   +   H2N-Z    -->   R2C=N-Z   +   H2O
```

```
  +--------------------------+-----------------+------------------------+
  |  REAGENT  H2N-Z          |  PRODUCT NAME   |  PRODUCT FROM CH3-CHO  |
  +--------------------------+-----------------+------------------------+
  |  NH2-OH (hydroxylamine)  |  OXIME          |  CH3-CH=N-OH           |
  |  NH2-NH2 (hydrazine)     |  HYDRAZONE      |  CH3-CH=N-NH2          |
  |  C6H5-NH-NH2             |  PHENYL-        |  CH3-CH=N-NH-C6H5      |
  |    (phenylhydrazine)     |  HYDRAZONE      |                        |
  |  2,4-dinitrophenyl-      |  2,4-DNP        |  orange / yellow       |
  |    hydrazine             |  derivative     |  PRECIPITATE  ** TEST **|
  |  NH2-NH-CO-NH2           |  SEMICARBAZONE  |  CH3-CH=N-NH-CO-NH2    |
  |    (semicarbazide)       |                 |                        |
  +--------------------------+-----------------+------------------------+
```

These reactions work best in **weakly acidic medium (pH about 3.5)**.
Too much acid protonates the -NH2 and kills the nucleophile; too little acid
and the C=O is not activated.

## 13.5 Reduction

```
   TO ALCOHOL (keep the oxygen):
        CH3-CHO      --NaBH4 or LiAlH4 or H2/Ni-->   CH3-CH2-OH
        CH3-CO-CH3   --NaBH4 or LiAlH4 or H2/Ni-->   CH3-CH(OH)-CH3

   TO HYDROCARBON (remove the oxygen completely):

        CLEMMENSEN REDUCTION   (acidic conditions)
        CH3-CO-CH3   --Zn-Hg / conc. HCl-->   CH3-CH2-CH3

        WOLFF-KISHNER REDUCTION   (basic conditions)
        CH3-CO-CH3   --NH2NH2 , then KOH / ethylene glycol, 453-473 K-->
                                              CH3-CH2-CH3
```

```
  +--------------------+-----------------------+------------------------+
  |  REDUCTION         |  REAGENT              |  USE IT WHEN ...       |
  +--------------------+-----------------------+------------------------+
  |  CLEMMENSEN        |  Zn-Hg amalgam +      |  the molecule can      |
  |                    |  conc. HCl            |  survive ACID          |
  +--------------------+-----------------------+------------------------+
  |  WOLFF-KISHNER     |  NH2-NH2 then         |  the molecule can      |
  |                    |  KOH / ethylene       |  survive BASE          |
  |                    |  glycol, heat         |                        |
  +--------------------+-----------------------+------------------------+

  BOTH give the SAME product:   C=O  becomes  CH2
```

> **TRAP:** Clemmensen is ACIDIC (HCl). Wolff-Kishner is BASIC (KOH).
> Memory hook: **C**lemmensen contains **C**l — acid. Wolff-Kishner uses
> hydra**zine** and KOH — base.

## 13.6 Oxidation

```
   ALDEHYDE  -->  ACID     (easy, happens with mild reagents)
        CH3-CHO   --K2Cr2O7 / H+  or  KMnO4  or  even Tollens-->  CH3-COOH

   KETONE    -->  needs DRASTIC conditions and the CHAIN BREAKS
        CH3-CO-CH2-CH3  --strong KMnO4 , heat-->  mixture of smaller acids

   POPOFF'S RULE:  in ketone oxidation, the C=O group stays with the
                   SMALLER alkyl group.
```

# TOPIC 14 — THE ALDOL CONDENSATION

## 14.1 The rule

```
   REQUIREMENT :  the aldehyde or ketone MUST have at least one ALPHA HYDROGEN.
   REAGENT     :  dilute NaOH  (or dilute KOH)
   PRODUCT     :  a beta-hydroxy aldehyde or beta-hydroxy ketone (the "ALDOL")
   ON HEATING  :  the aldol loses water to give an ALPHA,BETA-UNSATURATED
                  compound.
```

```
   2 CH3-CHO   --dil. NaOH-->   CH3-CH(OH)-CH2-CHO
                                (3-hydroxybutanal, "aldol")

   CH3-CH(OH)-CH2-CHO   --heat, - H2O-->   CH3-CH=CH-CHO
                                           (but-2-enal)


   2 CH3-CO-CH3  --dil. Ba(OH)2-->  (CH3)2C(OH)-CH2-CO-CH3
                                    (4-hydroxy-4-methylpentan-2-one)
```

## 14.2 Mechanism, step by step

```
  ====================== ALDOL MECHANISM =================================

   STEP 1   The base removes an ALPHA hydrogen, forming a CARBANION
            (stabilised by resonance with the C=O group).

                  H                             (-)
                  |                              |
             H -- C -- CHO   + OH(-)  --->   H - C - CHO   +  H2O
                  |                              |
                  H                              H
                                             CARBANION


   STEP 2   The carbanion attacks the carbonyl carbon of a SECOND
            molecule of aldehyde. (Nucleophilic addition.)

              O                                O(-)
              ||                               |
        CH3 - C - H     +   (-)CH2-CHO  --> CH3-C-H
                                               |
                                               CH2-CHO


   STEP 3   The alkoxide picks up a proton from water.

              O(-)                            OH
              |                               |
        CH3 - C - H       + H2O   --->  CH3 - C - H     +  OH(-)
              |                               |
              CH2-CHO                         CH2-CHO

                                       = CH3-CH(OH)-CH2-CHO   (THE ALDOL)


   STEP 4 (on heating)   Loss of water gives the conjugated product.

        CH3-CH(OH)-CH2-CHO   --heat-->   CH3-CH=CH-CHO   +   H2O

  ========================================================================
```

## 14.3 Cross aldol condensation

If you use **two different** carbonyl compounds, each having alpha hydrogens,
you get **four** products — a useless mixture.

```
   CH3-CHO  +  CH3-CH2-CHO   --dil. NaOH-->   FOUR products
```

The reaction is only useful when **one of the two has NO alpha hydrogen**:

```
   C6H5-CHO   +   CH3-CHO   --dil. NaOH-->   C6H5-CH=CH-CHO   +  H2O
   (no alpha-H)   (has alpha-H)              (cinnamaldehyde)

   HCHO       +   CH3-CHO   --dil. NaOH-->   HO-CH2-CH2-CHO
   (no alpha-H)   (has alpha-H)
```

The one WITHOUT alpha-H simply sits there and accepts the carbanion.

# TOPIC 15 — THE CANNIZZARO REACTION

## 15.1 The rule

```
   REQUIREMENT :  the aldehyde must have NO ALPHA HYDROGEN.
   REAGENT     :  CONCENTRATED alkali (50 % NaOH or KOH)
   WHAT HAPPENS:  DISPROPORTIONATION - one molecule is oxidised to the
                  salt of an acid, another is reduced to an alcohol.
```

```
   2 HCHO   --conc. NaOH-->   CH3-OH   +   HCOO-Na
                              (alcohol)    (sodium formate)

   2 C6H5-CHO  --conc. NaOH-->  C6H5-CH2-OH  +  C6H5-COO-Na
                                (benzyl        (sodium benzoate)
                                 alcohol)
```

## 15.2 Mechanism, step by step

```
  ==================== CANNIZZARO MECHANISM ==============================

   STEP 1   OH(-) adds to the carbonyl carbon.

              O                        O(-)
              ||                       |
       C6H5 - C - H   + OH(-)  --> C6H5-C-H
                                       |
                                       OH


   STEP 2   This intermediate transfers a HYDRIDE ION (H:-) to the
            carbonyl carbon of a SECOND aldehyde molecule.
            (This is the key step.)

              O(-)                O                     O
              |                   ||                    ||
       C6H5 - C - H    +   C6H5 - C - H   -->    C6H5 - C - OH
              |                                            +
              OH                                    C6H5-CH2-O(-)


   STEP 3   Proton exchange gives the final products.

       C6H5-COOH  +  C6H5-CH2-O(-)  -->  C6H5-COO(-)  +  C6H5-CH2-OH

   FINAL :   sodium benzoate   +   benzyl alcohol

  ========================================================================
```

## 15.3 CROSSED Cannizzaro

```
   HCHO  +  C6H5-CHO   --conc. NaOH-->   C6H5-CH2-OH  +  HCOO-Na

   FORMALDEHYDE is always the one that gets OXIDISED (it is the better
   hydride donor), so the other aldehyde ends up as the ALCOHOL.
```

> **TRAP:** Aldol needs alpha-H; Cannizzaro needs NO alpha-H. They are mutually
> exclusive. Before answering, count the alpha hydrogens. `HCHO`, `C6H5-CHO`
> and `(CH3)3C-CHO` have none, so they give Cannizzaro.

## 16.1 WHO responds to WHAT — memorise this grid

```
  +-------------------+---------+---------+----------+---------+
  |  COMPOUND         | TOLLENS | FEHLING | IODOFORM | 2,4-DNP |
  +-------------------+---------+---------+----------+---------+
  |  HCHO             |   YES   |   YES   |    NO    |   YES   |
  |  CH3-CHO          |   YES   |   YES   |   YES    |   YES   |
  |  CH3-CH2-CHO      |   YES   |   YES   |    NO    |   YES   |
  |  C6H5-CHO         |   YES   |   NO    |    NO    |   YES   |
  |  CH3-CO-CH3       |   NO    |   NO    |   YES    |   YES   |
  |  CH3-CO-C6H5      |   NO    |   NO    |   YES    |   YES   |
  |  CH3-CH(OH)-CH3   |   NO    |   NO    |   YES    |   NO    |
  |  CH3-CH2-OH       |   NO    |   NO    |   YES    |   NO    |
  |  CH3-OH           |   NO    |   NO    |    NO    |   NO    |
  |  CH3-COOH         |   NO    |   NO    |    NO    |   NO    |
  +-------------------+---------+---------+----------+---------+
```

Three rules explain the whole grid:

```
   TOLLENS  :  ALL aldehydes give it. NO ketone gives it.

   FEHLING  :  ALIPHATIC aldehydes give it.
               AROMATIC aldehydes (C6H5-CHO) DO NOT.

   IODOFORM :  the compound must contain
                    CH3-CO-        (a methyl ketone)
               or   CH3-CH(OH)-    (a methyl carbinol, which gets oxidised
                                    to the methyl ketone by the reagent)
               So ethanol and propan-2-ol DO give it, but methanol does not.

   2,4-DNP  :  EVERY aldehyde and EVERY ketone gives it.
               Alcohols and acids do not.
               -> use it to prove a carbonyl group is present, then use
                  Tollens to decide aldehyde vs ketone.
```

Equations to write:

```
   TOLLENS:
   CH3-CHO  +  2 [Ag(NH3)2]+ + 3 OH-  -->  CH3-COO-  +  2 Ag  + 4 NH3 + 2 H2O
                                                          (silver mirror)

   FEHLING:
   CH3-CHO  +  2 Cu2+  +  5 OH-   -->   CH3-COO-  +  Cu2O  +  3 H2O
                                                     (red ppt)

   IODOFORM:
   CH3-CO-CH3  +  3 I2  +  4 NaOH  -->  CHI3  +  CH3-COONa  + 3 NaI + 3 H2O
                                        (yellow ppt)
```

> **TRAP:** `C6H5-CHO` gives Tollens but NOT Fehling. That single fact is asked
> as a 2-mark question and as an EAPCET MCQ every year.

# TOPIC 18 — ACIDITY OF CARBOXYLIC ACIDS

## 18.1 Why they are the strongest of the three

```
   CH3-COOH   <-->   CH3-COO(-)   +   H+

   The carboxylate ion is stabilised by RESONANCE between TWO EQUIVALENT
   structures:

              O                        O(-)
             //                        |
   CH3 --- C            <-->    CH3 -- C
             \                        //
              O(-)                     O

   BOTH oxygens share the negative charge EQUALLY.
   Both C-O bonds become identical (length between single and double).
   This is a very stable ion.

   In the PHENOXIDE ion, the negative charge is spread over CARBON atoms,
   which are less electronegative and hold the charge less comfortably.
   So the carboxylate ion is more stable than the phenoxide ion.

   ->  CARBOXYLIC ACID  >  PHENOL  >  WATER  >  ALCOHOL
```

## 18.2 Effect of substituents

```
   ELECTRON-WITHDRAWING groups (-I effect: -NO2, -CN, -F, -Cl, -Br)
        pull electron density AWAY from the -COO(-)
        ->  the anion is more stable
        ->  ACIDITY INCREASES

   ELECTRON-RELEASING groups (+I effect: -CH3, -C2H5)
        push electron density TOWARDS the -COO(-)
        ->  the anion is less stable
        ->  ACIDITY DECREASES
```

**Orders you must be able to write:**

```
   1. Number of halogens:
         Cl3C-COOH  >  Cl2CH-COOH  >  ClCH2-COOH  >  CH3-COOH

   2. Nature of the halogen (electronegativity):
         F-CH2-COOH  >  Cl-CH2-COOH  >  Br-CH2-COOH  >  I-CH2-COOH

   3. Distance of the halogen from -COOH (the -I effect FADES with distance):
         CH3-CH2-CHCl-COOH  >  CH3-CHCl-CH2-COOH  >  CH2Cl-CH2-CH2-COOH
              (alpha)              (beta)                 (gamma)

   4. Alkyl chain length (more alkyl = weaker acid):
         HCOOH  >  CH3-COOH  >  CH3-CH2-COOH  >  (CH3)3C-COOH

   5. Aromatic acids:
         C6H5-COOH  >  CH3-COOH        (the ring withdraws by -I)

         p-nitrobenzoic acid  >  benzoic acid  >  p-methylbenzoic acid
```

> **TRAP:** Formic acid `HCOOH` is STRONGER than acetic acid `CH3-COOH`,
> because it has no electron-releasing alkyl group at all. Students always
> get this one backwards.

## 19.1 Salt formation — the identification test

```
   CH3-COOH  +  NaOH      -->   CH3-COONa  +  H2O
   CH3-COOH  +  Na2CO3    -->   CH3-COONa  +  H2O  +  CO2
   CH3-COOH  +  NaHCO3    -->   CH3-COONa  +  H2O  +  CO2   ** BRISK FIZZ **

   Phenol does NOT react with NaHCO3 (it is too weak an acid).
   -> This is how you distinguish a carboxylic acid from a phenol.
```

## 19.2 Formation of derivatives

```
   ACID CHLORIDE:
        CH3-COOH  +  PCl5    -->   CH3-CO-Cl  +  POCl3  +  HCl
        CH3-COOH  +  SOCl2   -->   CH3-CO-Cl  +  SO2  +  HCl
        (SOCl2 is preferred - the by-products are GASES and escape,
         so the product is pure)

   ANHYDRIDE:
        2 CH3-COOH   --P2O5 , heat-->   (CH3-CO)2O   +   H2O

   AMIDE:
        CH3-COOH  +  NH3   -->  CH3-COONH4   --heat, - H2O-->   CH3-CO-NH2

   ESTER:
        CH3-COOH  +  C2H5-OH   --conc. H2SO4-->   CH3-COO-C2H5  +  H2O
```

## 19.3 Reduction

```
   CH3-COOH   --(i) LiAlH4  (ii) H3O+-->   CH3-CH2-OH

   or with B2H6 (diborane).

   NOTE:  NaBH4 CANNOT do this.
          Also, the ester and the acid go all the way to the ALCOHOL -
          they do NOT stop at the aldehyde.
```

## 19.4 Decarboxylation

```
   CH3-COONa   --NaOH + CaO (soda lime) , heat-->   CH4  +  Na2CO3

   The -COOH group is lost as CO2 (as carbonate) and a hydrocarbon with
   ONE FEWER carbon is formed.

   C6H5-COONa  --NaOH + CaO , heat-->   C6H6  +  Na2CO3
```

Also worth knowing (Kolbe electrolysis):

```
   2 CH3-COONa  +  2 H2O   --electrolysis-->  CH3-CH3 + 2 CO2 + H2 + 2 NaOH
```

## 19.5 Hell-Volhard-Zelinsky (HVZ) reaction

```
   CH3-COOH   --(i) Cl2 / red P  (ii) H2O-->   Cl-CH2-COOH
                                               (chloroacetic acid)

   Halogenation happens at the ALPHA carbon only.
   The catalyst is red phosphorus (which really makes PCl3 in situ).

   ** Only acids WITH an alpha hydrogen give HVZ. **
   So HCOOH and C6H5-COOH do NOT give this reaction.
```

## 19.6 Ring substitution in aromatic acids

```
   The -COOH group is DEACTIVATING and META-directing.

   C6H5-COOH  --conc. HNO3 + conc. H2SO4-->   m-nitrobenzoic acid

   C6H5-COOH  --Br2 / FeBr3-->                m-bromobenzoic acid

   Friedel-Crafts reactions DO NOT WORK on benzoic acid, because the -COOH
   group deactivates the ring and also complexes with the AlCl3 catalyst.
```

> **TRAP:** -OH on a ring (phenol) is **ortho/para** directing and activating.
> -COOH on a ring is **meta** directing and deactivating. Do not mix them up.

# TOPIC 21 — CONVERSIONS (how to attack them)

The exam says "Convert A into B". You are not expected to be clever — you walk
along the ladder.

```
   THE LADDER:

     alkene  <--  ALCOHOL  <-->  ALDEHYDE  <-->  ACID
                    |               |
                 haloalkane      ketone (from 2deg alcohol)

   GOING RIGHT  = OXIDATION      ( [O] , K2Cr2O7/H+ , PCC , Cu )
   GOING LEFT   = REDUCTION      ( LiAlH4 , NaBH4 , H2/Ni )
   ADDING A CARBON  =  Grignard + CO2  ,  or  KCN then hydrolysis
   REMOVING A CARBON = decarboxylation (soda lime)
```

Worked examples:

```
   ETHANOL  ->  ACETIC ACID
        CH3-CH2-OH  --KMnO4 / H+-->  CH3-COOH                    (one step)

   ETHANOL  ->  ACETALDEHYDE
        CH3-CH2-OH  --PCC (or Cu, 573 K)-->  CH3-CHO

   PROPAN-1-OL  ->  PROPAN-2-OL
        CH3-CH2-CH2-OH  --conc. H2SO4, 443 K-->  CH3-CH=CH2
        CH3-CH=CH2      --H2O / H2SO4 (Markovnikov)-->  CH3-CH(OH)-CH3

   ETHANOL  ->  PROPANOIC ACID  (add one carbon)
        CH3-CH2-OH  --conc. HI-->  CH3-CH2-I
        CH3-CH2-I   --KCN, alcohol-->  CH3-CH2-CN
        CH3-CH2-CN  --H3O+, heat-->   CH3-CH2-COOH

   BENZENE  ->  PHENOL
        C6H6  --conc. H2SO4-->  C6H5-SO3H
        C6H5-SO3H  --NaOH fused, then H+-->  C6H5-OH

   PHENOL  ->  SALICYLIC ACID
        C6H5-OH  --NaOH-->  C6H5-ONa
        C6H5-ONa --(i) CO2, 400 K, 4-7 atm (ii) H+-->  C6H4(OH)-COOH

   ACETIC ACID  ->  METHANE
        CH3-COOH  --NaOH-->  CH3-COONa
        CH3-COONa --NaOH + CaO, heat-->  CH4

   TOLUENE  ->  BENZALDEHYDE
        C6H5-CH3  --(i) CrO2Cl2 / CS2  (ii) H3O+-->  C6H5-CHO   (Etard)
```
