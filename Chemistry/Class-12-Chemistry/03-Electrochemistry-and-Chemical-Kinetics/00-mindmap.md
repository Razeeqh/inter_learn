## THE 60-SECOND VERSION

**HALF A — ELECTROCHEMISTRY**

```
  A redox reaction is really two half reactions:
      something LOSES electrons   (oxidation)
      something GAINS electrons   (reduction)

  If you let them touch, the electrons jump across and you only get HEAT.

  If you SEPARATE them into two beakers and join them with a WIRE,
  the electrons are forced to travel through the wire.

              ELECTRONS IN A WIRE  =  ELECTRICITY.

  That separated arrangement is a GALVANIC CELL (a battery).
  Run it BACKWARDS by pushing current in, and it becomes an
  ELECTROLYTIC CELL (electroplating, extraction of metals).
```

**HALF B — CHEMICAL KINETICS**

```
  Thermodynamics tells you WHETHER a reaction can happen.
  Kinetics tells you HOW FAST it happens.

  Diamond turning into graphite is allowed by thermodynamics.
  Kinetics says it will take a few billion years. So your ring is safe.

  RATE   =   how fast concentration changes per second

  RATE LAW  =  the equation the experiment gives you:   Rate = k [A]^x [B]^y

  x + y   =   ORDER.  Only two orders matter for your exam:
                 ZERO order   -> straight line of [A] against t
                 FIRST order  -> straight line of log[A] against t
```

**If you understand only those two boxes, you already have half the theory marks.**

## THE FIRST KEY BOX — THE NERNST EQUATION

For the general cell reaction

```
        a A  +  b B   ---->   c C  +  d D           n electrons transferred
```

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   GENERAL FORM (any temperature)                                    |
  |                                                                     |
  |                            2.303 R T          [products]            |
  |     E(cell)  =  E0(cell) - -----------  log  -------------          |
  |                               n F              [reactants]          |
  |                                                                     |
  |                                                                     |
  |   AT 298 K  (25 C)  -  the form you will actually use               |
  |                                                                     |
  |                            0.0591          [C]^c [D]^d              |
  |     E(cell)  =  E0(cell) - --------  log  ---------------           |
  |                               n             [A]^a [B]^b             |
  |                                                                     |
  |                                                                     |
  |   FOR A SINGLE ELECTRODE      M(n+)  +  n e-  ---->  M              |
  |                                                                     |
  |                            0.0591            1                      |
  |     E       =   E0      -  --------  log  --------                  |
  |                               n            [M n+]                   |
  |                                                                     |
  |                            0.0591                                   |
  |             =   E0      +  --------  log [M n+]                     |
  |                               n                                     |
  |                                                                     |
  +---------------------------------------------------------------------+

  n  =  number of electrons transferred
  R  =  8.314 J K-1 mol-1        F  =  96500 C mol-1        T = 298 K
  Solids and pure liquids are written as 1. They never enter the log.
```

Two children of the same box:

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |    delta G   =  - n F E(cell)                                       |
  |                                                                     |
  |    delta G0  =  - n F E0(cell)                                      |
  |                                                                     |
  |                                                                     |
  |    At equilibrium  E(cell) = 0 , so                                 |
  |                                                                     |
  |                          0.0591                                     |
  |        E0(cell)   =   ------------  log K(c)                        |
  |                             n                                       |
  |                                                                     |
  +---------------------------------------------------------------------+
```

## THE SECOND KEY BOX — THE FIRST ORDER RATE EQUATION

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   For   A  ---->  products    obeying  Rate = k [A]                 |
  |                                                                     |
  |                                                                     |
  |               2.303              [A]0                               |
  |     k    =   --------    log   ---------                            |
  |                 t                [A]                                |
  |                                                                     |
  |                                                                     |
  |   [A]0  =  starting concentration                                   |
  |   [A]   =  concentration left after time t                          |
  |                                                                     |
  |   UNIT of k  :   s^-1     (time^-1 ONLY - no concentration term)    |
  |                                                                     |
  |                                                                     |
  |                        0.693                                        |
  |     HALF LIFE   t(1/2) = -------      <- does NOT depend on [A]0    |
  |                           k                                         |
  |                                                                     |
  +---------------------------------------------------------------------+
```

And its zero-order twin, so you never mix them up:

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   ZERO ORDER      [A]  =  [A]0  -  k t                              |
  |                                                                     |
  |                            [A]0  -  [A]                             |
  |                     k  =  ----------------                          |
  |                                  t                                  |
  |                                                                     |
  |                   UNIT of k :  mol L^-1 s^-1                        |
  |                                                                     |
  |                            [A]0                                     |
  |                   t(1/2) = --------      <- DOES depend on [A]0     |
  |                             2 k                                     |
  |                                                                     |
  +---------------------------------------------------------------------+
```

**Write these three boxes on your palm.** Almost every numerical in this
chapter comes out of them.
