# TOPIC 1 — Double salt versus coordination compound

Some compounds are made by mixing two simple salts. When you put them back
in water, two very different things can happen.

```
  DOUBLE SALT                         COORDINATION COMPOUND
  ------------------------------      ------------------------------------
  Exists only in the SOLID state      Exists in the solid state AND in
                                      solution

  In water it breaks COMPLETELY       In water the [ ] part stays TOGETHER
  into all its simple ions            as one big ion

  Example: Mohr's salt                Example: potassium ferrocyanide
     FeSO4.(NH4)2SO4.6H2O                K4[Fe(CN)6]

     gives  Fe2+ , NH4+ , SO4 2-         gives  4 K+  and  [Fe(CN)6]4-
     -> Fe2+ tests POSITIVE              -> Fe2+ tests NEGATIVE
        (it is free)                        (it is locked inside)

  Another: potash alum                 Another: [Cu(NH3)4]SO4
     K2SO4.Al2(SO4)3.24H2O                gives Cu2+? NO. It gives
                                          [Cu(NH3)4]2+  (deep blue)
```

The one-line answer the board wants:

```
  A DOUBLE SALT loses its identity in solution and gives all its simple ions.
  A COORDINATION COMPOUND retains its identity; the complex ion does not
  break up and does not give the usual tests of the metal ion.
```

## WORKED EXAMPLE 1

**Q.** FeSO4.(NH4)2SO4.6H2O and K4[Fe(CN)6] both contain iron. A student adds
NaOH to each. Only one gives a dirty green precipitate of Fe(OH)2. Which one,
and why?

```
  ANSWER

  Mohr's salt is a DOUBLE SALT.
  In water:  FeSO4.(NH4)2SO4.6H2O  ->  Fe2+ + 2 NH4+ + 2 SO4 2- + 6 H2O
  FREE Fe2+ is present, so NaOH gives the dirty green Fe(OH)2 precipitate.

  K4[Fe(CN)6] is a COORDINATION COMPOUND.
  In water:  K4[Fe(CN)6]  ->  4 K+  +  [Fe(CN)6]4-
  The iron is LOCKED inside the coordination sphere. There is no free Fe2+,
  so NO precipitate forms.

  ANSWER: Mohr's salt gives the precipitate.
```

> **TRAP:** Notice how the compound is written.
> A **dot** between the parts (`FeSO4.(NH4)2SO4.6H2O`) = double salt.
> **Square brackets** (`K4[Fe(CN)6]`) = coordination compound.
> The bracket is your clue in one glance.

# TOPIC 2 — Werner's theory (the birth of the subject)

Around 1893, Alfred Werner was staring at a very strange set of compounds.
Cobalt chloride and ammonia react in different ratios and give solids of
different colours. That should not happen if CoCl3 has a fixed valency of 3.

Werner's idea: **a metal has TWO kinds of valency, not one.**

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |   PRIMARY VALENCY                  SECONDARY VALENCY              |
  |   ---------------                  -----------------              |
  |                                                                   |
  |   = the OXIDATION NUMBER           = the COORDINATION NUMBER      |
  |                                                                   |
  |   Satisfied by NEGATIVE IONS       Satisfied by ligands           |
  |   (Cl- , SO4 2- , etc.)            (neutral OR negative)          |
  |                                                                   |
  |   IONISABLE - these ions break     NON-IONISABLE - these do NOT   |
  |   off in water                     break off in water             |
  |                                                                   |
  |   Written OUTSIDE the brackets     Written INSIDE the brackets    |
  |                                                                   |
  |   Shown by DOTTED lines            Shown by SOLID lines           |
  |   in Werner's diagrams             in Werner's diagrams           |
  |                                                                   |
  |   NOT fixed in direction ->        FIXED in direction ->          |
  |   no shape                         gives the complex its SHAPE    |
  |                                                                   |
  +-------------------------------------------------------------------+
```

## The famous CoCl3.nNH3 series

Werner took each compound, dissolved it in water, and added excess AgNO3.
Silver nitrate precipitates only the **free** chloride ions as white AgCl.
Counting the AgCl told him how many chlorides were outside the bracket.

```
  +---------------+----------+---------------+--------------------------+
  | COMPOUND      | COLOUR   | moles of AgCl | WERNER'S FORMULA         |
  |               |          | precipitated  |                          |
  +---------------+----------+---------------+--------------------------+
  | CoCl3.6NH3    | yellow   |      3        | [Co(NH3)6]Cl3            |
  |               |          |               | -> gives 4 ions          |
  +---------------+----------+---------------+--------------------------+
  | CoCl3.5NH3    | purple   |      2        | [Co(NH3)5Cl]Cl2          |
  |               |          |               | -> gives 3 ions          |
  +---------------+----------+---------------+--------------------------+
  | CoCl3.4NH3    | green    |      1        | [Co(NH3)4Cl2]Cl          |
  |               |          |               | -> gives 2 ions          |
  +---------------+----------+---------------+--------------------------+
  | CoCl3.3NH3    | violet   |      0        | [Co(NH3)3Cl3]            |
  |               |          |               | -> gives 0 ions          |
  |               |          |               |    (does not conduct)    |
  +---------------+----------+---------------+--------------------------+

  LOOK AT THE PATTERN:

     PRIMARY   valency of Co  =  3   in ALL FOUR    (Co is +3 always)
     SECONDARY valency of Co  =  6   in ALL FOUR    (always 6 things
                                                     inside the bracket)

     As one NH3 leaves the bracket, one Cl- steps IN to take its place.
     That Cl- is then non-ionisable, so one less AgCl is formed.
```

```
  WERNER'S PICTURE of  [Co(NH3)4Cl2]Cl

                        NH3
                         |
              NH3 ------ Co ------ NH3        the SIX solid lines
                       / |  \                 = secondary valency = 6
                    Cl   |   Cl
                        NH3                   the DOTTED line
                         :                    = primary valency, ionisable
                         :
                        Cl-        <---- this one is precipitated by AgNO3
```

## Werner's postulates (write these for a 4-mark answer)

```
  1. A metal shows TWO types of valency: primary and secondary.

  2. The PRIMARY valency is ionisable, is satisfied by negative ions,
     and equals the oxidation number of the metal.

  3. The SECONDARY valency is non-ionisable, is satisfied by ligands
     (neutral or negative), and equals the coordination number.

  4. The secondary valencies are DIRECTED in space towards fixed positions,
     so they decide the SHAPE (geometry) of the complex.

  5. Every metal tends to satisfy BOTH its primary and its secondary
     valencies.

  6. A negative ion can sometimes satisfy both at the same time
     (it sits inside the bracket AND counts towards the oxidation number).
```

## WORKED EXAMPLE 2

**Q.** A cobalt(III) complex of formula CoCl3.5NH3 gives 3 ions in solution and
2 moles of AgCl with excess AgNO3. Write its formula and its IUPAC name.

```
  ANSWER

  Step 1  2 moles AgCl  ->  2 chlorides are OUTSIDE the bracket.
  Step 2  So 1 chloride must be INSIDE, along with all 5 NH3.
  Step 3  Formula:      [Co(NH3)5Cl] Cl2
  Step 4  Check ions:   [Co(NH3)5Cl]2+  +  2 Cl-   =  3 ions.  Correct.
  Step 5  Name:         pentaamminechloridocobalt(III) chloride
```

> **TRAP:** "Number of ions" and "moles of AgCl" are NOT the same number.
> Moles of AgCl = number of free Cl- ions.
> Number of ions = free Cl- ions **plus one** for the complex ion itself.

# TOPIC 3 — The words you must be able to define

These are pure 2-mark questions. Learn them word for word.

```
  +---------------------+---------------------------------------------------+
  | TERM                | MEANING                                           |
  +---------------------+---------------------------------------------------+
  | CENTRAL METAL       | The metal atom or ion that ACCEPTS lone pairs.    |
  | ATOM / ION          | It is a Lewis ACID. Example: Fe in [Fe(CN)6]4-    |
  +---------------------+---------------------------------------------------+
  | LIGAND              | An ion or molecule bound to the central metal by  |
  |                     | DONATING a lone pair. It is a Lewis BASE.         |
  |                     | Examples: NH3 , H2O , Cl- , CN-                   |
  +---------------------+---------------------------------------------------+
  | DONOR ATOM          | The exact atom of the ligand that gives the lone  |
  |                     | pair. In NH3 it is N. In H2O it is O.             |
  +---------------------+---------------------------------------------------+
  | COORDINATION        | The number of ligand DONOR ATOMS bonded to the    |
  | NUMBER (C.N.)       | central metal, i.e. the number of SIGMA bonds.    |
  |                     | In [Fe(CN)6]4- it is 6. In [PtCl4]2- it is 4.     |
  +---------------------+---------------------------------------------------+
  | COORDINATION        | The central metal TOGETHER WITH its ligands,      |
  | SPHERE              | written inside square brackets [ ].               |
  |                     | It does not ionise in solution.                   |
  +---------------------+---------------------------------------------------+
  | IONISATION SPHERE   | The ions written OUTSIDE the brackets. These DO   |
  |                     | ionise in solution.                               |
  +---------------------+---------------------------------------------------+
  | COORDINATION        | The 3-D SHAPE made by the donor atoms around the  |
  | POLYHEDRON          | metal: octahedron, tetrahedron, square plane.     |
  +---------------------+---------------------------------------------------+
  | OXIDATION NUMBER    | The charge the metal WOULD have if all the ligands|
  | OF CENTRAL ATOM     | were removed along with their electron pairs.     |
  |                     | Written in Roman numerals: Co(III), Fe(II).       |
  +---------------------+---------------------------------------------------+
  | HOMOLEPTIC          | A complex in which the metal is bound to only ONE |
  | COMPLEX             | KIND of ligand.  [Co(NH3)6]3+ , [Ni(CO)4]         |
  +---------------------+---------------------------------------------------+
  | HETEROLEPTIC        | A complex in which the metal is bound to MORE     |
  | COMPLEX             | THAN ONE kind of ligand.                          |
  |                     | [Co(NH3)4Cl2]+ , [Cr(H2O)4Cl2]+                   |
  +---------------------+---------------------------------------------------+
```

The common shapes:

```
  C.N. = 2      LINEAR                 [Ag(NH3)2]+ , [Ag(CN)2]-

                  L ----- M ----- L


  C.N. = 4      TETRAHEDRAL            [NiCl4]2- , [Ni(CO)4] , [MnO4]-

                        L
                        |
                        M
                      / | \
                    L   L  L


  C.N. = 4      SQUARE PLANAR          [Ni(CN)4]2- , [Pt(NH3)2Cl2]

                    L       L
                      \   /
                        M
                      /   \
                    L       L


  C.N. = 6      OCTAHEDRAL             [Co(NH3)6]3+ , [Fe(CN)6]4-

                        L
                        |    L
                        |  /
                  L ----M---- L
                      / |
                    L   |
                        L
```

## WORKED EXAMPLE 3

**Q.** For [Cr(NH3)4Cl2]+ , state (a) the central metal ion (b) the ligands
(c) the coordination number (d) the oxidation number of Cr (e) whether it is
homoleptic or heteroleptic.

```
  ANSWER

  (a) Central metal ion  :  Cr

  (b) Ligands            :  NH3 (neutral, donor atom N)
                            Cl- (negative, donor atom Cl)

  (c) Coordination number:  4 NH3 x 1  +  2 Cl x 1   =   6

  (d) Oxidation number   :  x + 4(0) + 2(-1)  =  +1
                            x - 2 = +1   ->   x = +3      Cr is Cr(III)

  (e) Two different ligands are present   ->   HETEROLEPTIC
```

# TOPIC 4 — Types of ligands

A ligand is a hand offered to the metal. The only question is **how many hands
does one ligand molecule have?**

```
  +---------------+------------------------------------------------------+
  | TYPE          | MEANING                                              |
  +---------------+------------------------------------------------------+
  | UNIDENTATE    | ONE donor atom. Uses one hand.                       |
  | (monodentate) | NH3 , H2O , Cl- , Br- , CN- , OH- , CO , NO2- , py   |
  +---------------+------------------------------------------------------+
  | BIDENTATE     | TWO donor atoms. Grabs the metal with both hands.    |
  |               | en (ethane-1,2-diamine) , C2O4 2- (oxalate) ,        |
  |               | gly (glycinate) , dmg (dimethylglyoximate)           |
  +---------------+------------------------------------------------------+
  | TRIDENTATE    | THREE donor atoms.  dien (diethylenetriamine)        |
  +---------------+------------------------------------------------------+
  | TETRADENTATE  | FOUR donor atoms.  triethylenetetramine (trien)      |
  +---------------+------------------------------------------------------+
  | HEXADENTATE   | SIX donor atoms.  EDTA 4- (2 N atoms + 4 O atoms)    |
  |               | One EDTA can wrap the whole metal by itself.         |
  +---------------+------------------------------------------------------+
  | POLYDENTATE   | ANY ligand with more than one donor atom            |
  |               | (bi, tri, tetra, penta, hexa are all polydentate).   |
  +---------------+------------------------------------------------------+
  | AMBIDENTATE   | Has TWO different donor atoms but can use only ONE   |
  |               | at a time. It can attach through either end.        |
  |               | NO2-  ->  through N (nitrito-N)  or  O (nitrito-O)  |
  |               | SCN-  ->  through S (thiocyanato-S) or N            |
  |               |           (thiocyanato-N / isothiocyanato)          |
  |               | CN-   ->  through C (cyanido) or N (isocyanido)     |
  +---------------+------------------------------------------------------+
  | CHELATING     | A polydentate ligand that BITES the metal and forms  |
  | LIGAND        | a RING. The ring is called a CHELATE ring.           |
  |               | en , oxalate , EDTA , dmg                            |
  +---------------+------------------------------------------------------+
  | BRIDGING      | One ligand joining TWO metal centres. Written with   |
  | LIGAND        | the prefix mu- (mu-hydroxido, mu-chlorido).          |
  +---------------+------------------------------------------------------+
```

Pictures that make it stick:

```
  UNIDENTATE                    BIDENTATE (en)

     M <---- NH3                    H2N ---- CH2
                                     |         |
     one arrow                       M         |     the ligand and the
                                     |         |     metal form a FIVE
                                    H2N ---- CH2     MEMBERED RING
                                                     = a CHELATE ring

  AMBIDENTATE (NO2-)

     M <---- N(=O)-O          "nitrito-N"    bonded through NITROGEN
                                             (yellow complexes)

     M <---- O-N=O            "nitrito-O"    bonded through OXYGEN
                                             (red complexes)

     SAME formula, DIFFERENT compound  ->  LINKAGE ISOMERISM
```

The ligand you must be able to draw: **EDTA 4-**

```
                 -OOC-CH2            CH2-COO-
                          \         /
                           N-CH2-CH2-N
                          /         \
                 -OOC-CH2            CH2-COO-

   DONOR ATOMS:  2 nitrogen atoms + 4 oxygen atoms (one from each COO-)
                 =  6 donor atoms  ->  HEXADENTATE
   One EDTA gives coordination number 6 all by itself.
```

## WORKED EXAMPLE 4

**Q.** Find the coordination number of the metal in
(a) [Co(en)3]3+  (b) [Cr(C2O4)3]3-  (c) [Ca(EDTA)]2-  (d) [Co(en)2Cl2]+

```
  ANSWER   Multiply each ligand by its denticity.

  (a) en is BIDENTATE  ->  3 x 2  =  6         C.N. = 6
  (b) oxalate is BIDENTATE -> 3 x 2 = 6        C.N. = 6
  (c) EDTA is HEXADENTATE  ->  1 x 6 = 6       C.N. = 6
  (d) 2 en x 2 = 4 ,  2 Cl x 1 = 2 ,  4 + 2    C.N. = 6
```

> **TRAP:** In (a) the answer is **NOT 3**. Three ligands, but six hands.
> Every single year somebody loses this mark. Count DONOR ATOMS, not molecules.

# TOPIC 5 — Finding the oxidation number (the 20-second skill)

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |   Let the oxidation number of the metal be  x.                    |
  |                                                                   |
  |   x  +  (sum of ligand charges)  =  charge on the [ ] bracket     |
  |                                                                   |
  +-------------------------------------------------------------------+
```

The charge on the bracket comes from the outside ions:

```
  If the outside is  Cl3     ->  the bracket is  3+
  If the outside is  Cl2     ->  the bracket is  2+
  If the outside is  SO4     ->  the bracket is  2+
  If the outside is  K4      ->  the bracket is  4-
  If the outside is  K3      ->  the bracket is  3-
  If there is NOTHING outside ->  the bracket is  0 (neutral complex)
```

Ligand charges to memorise:

```
  ZERO       NH3   H2O   CO   NO   en   py   dmg(H)   NH2CH3
  MINUS 1    Cl-   Br-   I-   F-   CN-  OH-  NO2-  ONO-  SCN-  NCS-
             CH3COO-    NO3-    gly-
  MINUS 2    C2O4 2- (ox)   CO3 2-   SO4 2-   S2O3 2-   O2-
  MINUS 4    EDTA 4-
  PLUS 1     NO+ (nitrosonium)
```

## WORKED EXAMPLE 5 — six of them, fast

```
  1.  [Co(NH3)6]Cl3
      bracket = 3+     x + 6(0) = +3        x = +3       Co(III)

  2.  K4[Fe(CN)6]
      bracket = 4-     x + 6(-1) = -4       x = +2       Fe(II)

  3.  [Ni(CO)4]
      bracket = 0      x + 4(0) = 0         x =  0       Ni(0)

  4.  [Cr(H2O)4Cl2]+
      bracket = 1+     x + 4(0) + 2(-1) = +1    x = +3   Cr(III)

  5.  K3[Fe(C2O4)3]
      bracket = 3-     x + 3(-2) = -3       x = +3       Fe(III)

  6.  Na3[Co(NO2)6]
      bracket = 3-     x + 6(-1) = -3       x = +3       Co(III)
```

> **TRAP:** CO is CARBON MONOXIDE and its charge is **ZERO**.
> C2O4 2- is OXALATE and its charge is **minus 2**.
> Read the formula slowly. `CO` and `C2O4` are not the same thing.

# TOPIC 6 — IUPAC nomenclature

This is a mechanical procedure. Follow the steps in order and you cannot go wrong.

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |   THE ORDER OF NAMING                                             |
  |                                                                   |
  |   1.  CATION first, then ANION  (same as any ionic salt)          |
  |                                                                   |
  |   2.  Inside the bracket:  LIGANDS first (alphabetically),        |
  |                            then the METAL,                        |
  |                            then its oxidation number in Roman     |
  |                            numerals inside brackets.              |
  |                                                                   |
  |   3.  If the complex ion is an ANION, the metal name ends in      |
  |       -ATE  (and often uses the LATIN name).                      |
  |                                                                   |
  |   4.  The whole complex ion is written as ONE WORD, no spaces.    |
  |                                                                   |
  +-------------------------------------------------------------------+
```

## Rule by rule

```
  RULE 1   Cation is named first, anion second.
           K4[Fe(CN)6]  ->  "potassium ..." then the complex anion.
           [Co(NH3)6]Cl3 -> complex cation first, then "chloride".

  RULE 2   Ligands are named in ALPHABETICAL order,
           IGNORING the multiplying prefixes (di, tri, tetra).
           "ammine" comes before "chlorido" because A before C.
           In tetraamminedichlorido... , you compare a-mmine with c-hlorido.

  RULE 3   NEGATIVE ligands end in  -O  :
              Cl-  -> chlorido        CN-  -> cyanido
              OH-  -> hydroxido       SO4 2- -> sulphato
              C2O4 2- -> oxalato      NO2- -> nitrito-N

  RULE 4   NEUTRAL ligands keep their own names, with FOUR exceptions:
              H2O -> AQUA        NH3 -> AMMINE
              CO  -> CARBONYL    NO  -> NITROSYL

  RULE 5   POSITIVE ligands end in  -IUM  :  NO+ -> nitrosonium

  RULE 6   Number of ligands:
              simple ligands       ->  di , tri , tetra , penta , hexa
              ligands whose OWN name already contains di/tri, or is
              complicated, use    ->  bis , tris , tetrakis
                                      and the ligand goes in brackets

              2 Cl        ->  dichlorido
              2 en        ->  BIS(ethane-1,2-diamine)     [en has "di" in it]
              3 ox        ->  TRIS(oxalato)  or trioxalato
              2 NH2CH3    ->  BIS(methylamine)

  RULE 7   Oxidation number of the metal in ROMAN NUMERALS in round
           brackets, with NO space before it.
              cobalt(III)      iron(II)      nickel(0)

  RULE 8   If the complex is an ANION, add -ATE to the metal:
              Fe -> ferrate      Cu -> cuprate     Ag -> argentate
              Pb -> plumbate     Sn -> stannate    Au -> aurate
              Cr -> chromate     Co -> cobaltate   Ni -> nickelate
              Zn -> zincate      Mn -> manganate   Pt -> platinate

  RULE 9   If the complex is NEUTRAL or a CATION, the metal keeps its
           ordinary English name.   cobalt , iron , nickel , chromium

  RULE 10  Bridging ligands get the prefix  mu-  and are named last
           among the ligands.
```

## NAME ---> FORMULA (the other direction, always asked)

```
  METHOD
     1. Write the metal symbol first inside [ ].
     2. Add the ligands in the order the NAME gives them.
     3. Work out the charge on the bracket:
             charge  =  oxidation number  +  sum of ligand charges
     4. Balance with the outside ion.

  1.  potassium hexacyanidoferrate(III)
      Fe is +3 , 6 CN- = -6 , bracket = 3 - 6 = 3-
      FORMULA:   K3[Fe(CN)6]

  2.  hexaamminecobalt(III) chloride
      Co +3 , 6 NH3 = 0 , bracket = 3+
      FORMULA:   [Co(NH3)6]Cl3

  3.  potassium tetrachloridonickelate(II)
      Ni +2 , 4 Cl- = -4 , bracket = 2-
      FORMULA:   K2[NiCl4]

  4.  tetraammineaquachloridocobalt(III) chloride
      Co +3 , 4 NH3 = 0 , H2O = 0 , Cl- = -1 , bracket = +2
      FORMULA:   [Co(NH3)4(H2O)Cl]Cl2

  5.  dichloridobis(ethane-1,2-diamine)platinum(IV) nitrate
      Pt +4 , 2 Cl- = -2 , 2 en = 0 , bracket = +2
      FORMULA:   [Pt(en)2Cl2](NO3)2

  6.  potassium trioxalatoaluminate(III)
      Al +3 , 3 ox 2- = -6 , bracket = 3-
      FORMULA:   K3[Al(C2O4)3]

  7.  pentaamminenitrito-O-cobalt(III) chloride
      FORMULA:   [Co(NH3)5(ONO)]Cl2

  8.  hexaaquamanganese(II) ion
      FORMULA:   [Mn(H2O)6]2+

  9.  tetracarbonylnickel(0)
      FORMULA:   [Ni(CO)4]

 10.  sodium hexanitrito-N-cobaltate(III)
      Co +3 , 6 NO2- = -6 , bracket = 3-
      FORMULA:   Na3[Co(NO2)6]
```

> **TRAP 1:** Alphabetical order ignores the prefix, so it is
> **tetraaquadichlorido**, NOT dichloridotetraaqua.
> Compare **a**qua with **c**hlorido, not **t**etra with **d**i.

> **TRAP 2:** Use **bis** (not di) with `en`, because the name
> "ethane-1,2-di-amine" already contains "di". Same for
> bis(dimethylglyoximato) and tris(ethane-1,2-diamine).

> **TRAP 3:** The metal is `-ate` **ONLY** when the complex ion is NEGATIVE.
> In [Co(NH3)6]Cl3 the complex is positive, so it is cobalt(III),
> never cobaltate(III).

# TOPIC 9 — Valence Bond Theory (VBT)

**The idea in one line:** the metal ion empties out some orbitals, mixes
(hybridises) them, and the ligands' lone pairs go into those empty hybrid
orbitals.

```
  THE FIXED PROCEDURE  -  do these 6 steps EVERY time

  STEP 1   Find the oxidation number of the metal.
  STEP 2   Write the electron configuration of the METAL ION
           (remove 4s electrons FIRST, then 3d).
  STEP 3   Draw the 3d , 4s , 4p (and 4d if needed) boxes and fill 3d
           by Hund's rule.
  STEP 4   Look at the ligand:
              STRONG field (CN- , CO , NH3 , NO2-)
                 ->  the 3d electrons PAIR UP and free some inner 3d orbitals
              WEAK field (F- , Cl- , Br- , I- , H2O , OH-)
                 ->  the 3d electrons DO NOT pair
  STEP 5   Count how many EMPTY orbitals are available and name the
           hybridisation.
  STEP 6   Count the leftover UNPAIRED electrons -> magnetic behaviour
           and mu = sqrt(n(n+2)).
```

```
  +-------------------+------------------+---------------------------------+
  | HYBRIDISATION     | GEOMETRY         | EXAMPLE                         |
  +-------------------+------------------+---------------------------------+
  | sp                | linear           | [Ag(NH3)2]+ , [Ag(CN)2]-        |
  | sp3               | tetrahedral      | [NiCl4]2- , [Ni(CO)4] , [MnO4]- |
  | dsp2              | square planar    | [Ni(CN)4]2- , [Pt(NH3)2Cl2]     |
  | d2sp3  (INNER)    | octahedral       | [Co(NH3)6]3+ , [Fe(CN)6]4-      |
  | sp3d2  (OUTER)    | octahedral       | [CoF6]3- , [Fe(H2O)6]2+         |
  +-------------------+------------------+---------------------------------+

     INNER ORBITAL complex  =  uses (n-1)d , i.e. 3d  ->  d2sp3
                            =  LOW SPIN  =  usually fewer unpaired electrons

     OUTER ORBITAL complex  =  uses  n d  , i.e. 4d   ->  sp3d2
                            =  HIGH SPIN =  keeps its unpaired electrons
```

## 9A. [Co(NH3)6]3+ — inner orbital, low spin, DIAMAGNETIC

```
  Co (Z = 27)  =  [Ar] 3d7 4s2
  Co3+         =  [Ar] 3d6            (remove 2 from 4s, 1 from 3d)

  FREE Co3+ ion  (before the ligands arrive):

           3 d                            4s         4p
   +----+----+----+----+----+        +----+   +----+----+----+
   | ^v | ^  | ^  | ^  | ^  |        |    |   |    |    |    |
   +----+----+----+----+----+        +----+   +----+----+----+
       4 unpaired electrons

  NH3 is a STRONG field ligand -> it FORCES the 3d electrons to pair up:

           3 d                            4s         4p
   +----+----+----+----+----+        +----+   +----+----+----+
   | ^v | ^v | ^v |    |    |        |    |   |    |    |    |
   +----+----+----+----+----+        +----+   +----+----+----+
                      \____/            |       |    |    |
                        TWO empty 3d  + one 4s + three 4p
                        =  SIX empty orbitals

                        HYBRIDISATION  =  d2sp3

  Now the six NH3 lone pairs come in (shown as xx):

           3 d                            4s         4p
   +----+----+----+----+----+        +----+   +----+----+----+
   | ^v | ^v | ^v | xx | xx |        | xx |   | xx | xx | xx |
   +----+----+----+----+----+        +----+   +----+----+----+
                    \__________ d2sp3 hybrid, 6 pairs from 6 NH3 ______/

  CONCLUSION
     Hybridisation  :  d2sp3
     Geometry       :  OCTAHEDRAL
     Type           :  INNER orbital complex , LOW SPIN
     Unpaired e-    :  n = 0
     Magnetism      :  DIAMAGNETIC ,  mu = 0 BM
```

## 9B. [CoF6]3- — outer orbital, high spin, PARAMAGNETIC

```
  Co3+  =  [Ar] 3d6      (exactly the same ion as above!)

  F- is a WEAK field ligand -> the 3d electrons DO NOT pair.
  So the 3d orbitals stay full-ish and the metal must use OUTER 4d orbitals.

        3 d                        4s        4p                 4d
  +----+----+----+----+----+   +----+  +----+----+----+   +----+----+
  | ^v | ^  | ^  | ^  | ^  |   | xx |  | xx | xx | xx |   | xx | xx |
  +----+----+----+----+----+   +----+  +----+----+----+   +----+----+
      4 unpaired stay put       \______________________________/
                                 one 4s + three 4p + two 4d
                                 HYBRIDISATION  =  sp3d2

  CONCLUSION
     Hybridisation  :  sp3d2
     Geometry       :  OCTAHEDRAL
     Type           :  OUTER orbital complex , HIGH SPIN
     Unpaired e-    :  n = 4
     Magnetism      :  PARAMAGNETIC
     mu  =  sqrt( 4 x 6 )  =  sqrt(24)  =  4.90 BM
```

```
  *** THE CLASSIC EXAM QUESTION ***

  "[Co(NH3)6]3+ is diamagnetic but [CoF6]3- is paramagnetic. Explain."

  ANSWER IN ONE SENTENCE:
     Both contain Co3+ (3d6), but NH3 is a STRONG field ligand and pairs the
     d electrons (d2sp3, inner orbital, n=0, diamagnetic), while F- is a WEAK
     field ligand and does not pair them (sp3d2, outer orbital, n=4,
     paramagnetic).
```

## 9C. [Ni(CN)4]2- — square planar, DIAMAGNETIC

```
  Ni (Z = 28)  =  [Ar] 3d8 4s2
  Ni2+         =  [Ar] 3d8

  FREE Ni2+ :
           3 d                            4s         4p
   +----+----+----+----+----+        +----+   +----+----+----+
   | ^v | ^v | ^v | ^  | ^  |        |    |   |    |    |    |
   +----+----+----+----+----+        +----+   +----+----+----+
                       2 unpaired

  CN- is a STRONG field ligand -> the two unpaired electrons PAIR UP,
  leaving ONE empty 3d orbital:

           3 d                            4s         4p
   +----+----+----+----+----+        +----+   +----+----+----+
   | ^v | ^v | ^v | ^v |    |        | xx |   | xx | xx |    |
   +----+----+----+----+----+        +----+   +----+----+----+
                       \___/            |       |    |
                     one 3d  +  one 4s  +  two 4p   =  FOUR orbitals

  CONCLUSION
     Hybridisation  :  dsp2
     Geometry       :  SQUARE PLANAR
     Unpaired e-    :  n = 0
     Magnetism      :  DIAMAGNETIC ,  mu = 0 BM
```

## 9D. [NiCl4]2- — tetrahedral, PARAMAGNETIC

```
  Ni2+  =  [Ar] 3d8         (the same ion again)

  Cl- is a WEAK field ligand -> NO pairing happens in 3d.
  So the metal uses 4s and 4p only:

           3 d                            4s         4p
   +----+----+----+----+----+        +----+   +----+----+----+
   | ^v | ^v | ^v | ^  | ^  |        | xx |   | xx | xx | xx |
   +----+----+----+----+----+        +----+   +----+----+----+
              2 unpaired stay         \_____________________/
                                       one 4s + three 4p
                                       HYBRIDISATION  =  sp3

  CONCLUSION
     Hybridisation  :  sp3
     Geometry       :  TETRAHEDRAL
     Unpaired e-    :  n = 2
     Magnetism      :  PARAMAGNETIC
     mu  =  sqrt( 2 x 4 )  =  sqrt(8)  =  2.83 BM
```

```
  *** ANOTHER CLASSIC ***

  "Why is [Ni(CN)4]2- square planar and diamagnetic, while [NiCl4]2- is
   tetrahedral and paramagnetic, although both contain Ni2+?"

  n = 2, paramagnetic (mu = 2.83 BM).
```

## 9I. Limitations of VBT (a guaranteed part of the 8-mark answer)

```
  1.  It involves a large number of ASSUMPTIONS.

  2.  It does not give a QUANTITATIVE explanation of magnetic data;
      it only says "paramagnetic" or "diamagnetic".

  3.  It does not explain the COLOUR of coordination compounds at all.

  4.  It does not give a quantitative explanation of the THERMODYNAMIC or
      KINETIC stability of complexes.

  5.  It does not PREDICT in advance whether a 4-coordinate complex will be
      tetrahedral or square planar - you have to know the answer first.

  6.  It does not explain WHY some ligands are strong field and others are
      weak field.

  7.  It cannot explain the TEMPERATURE DEPENDENCE of magnetic behaviour.
```

# TOPIC 10 — Crystal Field Theory (CFT)

**The idea in one line:** treat the metal-ligand bond as **purely ionic** (or
purely electrostatic). The ligands are just negative point charges, and their
repulsion splits the five d orbitals into groups of different energy.

## 10A. The five d orbitals and where they point

```
  dxy  ,  dyz  ,  dzx      point BETWEEN the axes    ->  called  t2g
  dx2-y2  ,  dz2           point ALONG the axes      ->  called  eg
```

In an octahedral complex the six ligands come in **along the axes**.
So the two orbitals pointing along the axes (eg) get hit hard, and the three
pointing between the axes (t2g) get hit less.

## 10B. Octahedral splitting — DRAW THIS DIAGRAM

```
   E
   ^                                              +----+  +----+
   |                                              | eg |  |    |     eg
   |                                              +----+  +----+
   |                                                  ^
   |                                                  |  + 0.6 delta-o
   |    +----+ +----+ +----+ +----+ +----+   ....-----+-----.... barycentre
   |    |    | |    | |    | |    | |    |            |     (average energy)
   |    +----+ +----+ +----+ +----+ +----+            |  - 0.4 delta-o
   |    five degenerate d orbitals                    v
   |    (free metal ion)                       +----+ +----+ +----+
   |                                           |    | |    | |    |    t2g
   |                                           +----+ +----+ +----+
   +----------------------------------------------------------------->

        FREE ION            SPHERICAL FIELD          OCTAHEDRAL FIELD

     eg   =  dx2-y2 , dz2      (2 orbitals, HIGHER energy, + 3/5 delta-o)
     t2g  =  dxy , dyz , dzx   (3 orbitals, LOWER  energy, - 2/5 delta-o)

     The energy gap  =  DELTA-o  =  the CRYSTAL FIELD SPLITTING ENERGY
                                    for an octahedral field
                                    (also written 10 Dq)

     CHECK:   2 x (+0.6) + 3 x (-0.4)  =  1.2 - 1.2  =  0
              The total energy is unchanged. Good.
```

## 10C. The spectrochemical series

The size of `delta-o` depends on the ligand. Arrange ligands by the size of
the splitting they cause and you get the **spectrochemical series**:

```
  WEAK FIELD  (small delta-o)                  STRONG FIELD (large delta-o)
  <-------------------------------------------------------------------->

  I- < Br- < S2- < SCN- < Cl- < NO3- < F- < OH- < C2O4 2- < H2O
     < NCS- < edta 4- < NH3 < en < NO2- < CN- < CO

  MEMORY LINE:
     "I Buy Silver CLothes For Our Home , New Energy , Not CyaNide COmpany"
      I  Br     S  SCN Cl F  ox  H2O   NH3  en    NO2- CN-      CO

  The four you MUST be able to name:
      WEAK FIELD  :   I- , Br- , Cl- , F- , H2O , OH-
      STRONG FIELD:   NH3 , en , NO2- , CN- , CO
```

## 10D. High spin versus low spin — the pairing energy rule

When you fill electrons into the split d orbitals, from d4 onwards there is a
choice: go UP into eg, or PAIR UP in t2g?

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   Let  P  =  PAIRING ENERGY (the energy cost of forcing two         |
  |              electrons into the same orbital)                       |
  |                                                                     |
  |   IF   delta-o  >  P    ->  cheaper to PAIR UP                      |
  |                             ->  LOW SPIN  =  STRONG FIELD complex   |
  |                                                                     |
  |   IF   delta-o  <  P    ->  cheaper to GO UP into eg                |
  |                             ->  HIGH SPIN =  WEAK FIELD complex     |
  |                                                                     |
  +---------------------------------------------------------------------+
```

```
  d4 HIGH SPIN  (weak field, e.g. [Cr(H2O)6]2+ , [Mn(H2O)6]3+)

              +----+  +----+
              | ^  |  |    |          eg
              +----+  +----+
                   delta-o (small)
              +----+  +----+  +----+

              +----+  +----+  +----+

              configuration  t2g3 eg1        n = 4 unpaired
              mu = sqrt(4 x 6) = 4.90 BM

              +----+  +----+  +----+

              +----+  +----+  +----+

              mu = sqrt(2 x 4) = 2.83 BM
```

## 10E. Tetrahedral splitting

In a tetrahedral field the ligands come in **between** the axes, so the
picture is turned upside down: now the **e** set is lower.

```
   E
   ^                            +----+ +----+ +----+
   |                            |    | |    | |    |     t2  (dxy,dyz,dzx)
   |                            +----+ +----+ +----+
   |                                       ^
   |   +----+ +----+ +----+ +----+ +----+  | + 0.4 delta-t
   |   |    | |    | |    | |    | |    |  |
   |   +----+ +----+ +----+ +----+ +----+  |  ....barycentre....
   |   five degenerate d orbitals          | - 0.6 delta-t
   |                                       v
   |                                  +----+ +----+
   |                                  |    | |    |          e  (dx2-y2,dz2)
   |                                  +----+ +----+
   +--------------------------------------------------------------->

        FREE ION                       TETRAHEDRAL FIELD

  +---------------------------------------------------------------+
  |                                                               |
  |            delta-t   =   ( 4 / 9 )  x   delta-o               |
  |                                                               |
  |   delta-t is SMALL because                                    |
  |     (a) there are only 4 ligands instead of 6, and            |
  |     (b) they point BETWEEN the d orbitals, not at them.       |
  |                                                               |
  |   BECAUSE delta-t IS ALWAYS SMALLER THAN THE PAIRING ENERGY,  |
  |   ALL TETRAHEDRAL COMPLEXES ARE **HIGH SPIN**.                |
  |   There is no such thing as a low-spin tetrahedral complex    |
  |   at this level.                                              |
  +---------------------------------------------------------------+

  Note the labels lose the "g" (t2 and e, not t2g and eg) because a
  tetrahedron has no centre of symmetry.
```

## 10F. Colour of coordination compounds

```
  WHY ARE THEY COLOURED?

  1.  The d orbitals are split into t2g (lower) and eg (higher).
  2.  White light falls on the complex.
  3.  An electron in t2g ABSORBS a photon whose energy exactly equals
      delta-o, and JUMPS up to eg.   This is a  d-d TRANSITION.
  4.  That colour is removed from the white light.
  5.  What comes out and reaches your eye is the COMPLEMENTARY COLOUR.

              +----+                    +----+
              |    |  eg                | ^  |  eg
              +----+                    +----+
                ^      absorbs             ^
                |      a photon            |
                |      of energy           |
              +----+   delta-o           +----+
              | ^  |  t2g   ------->     |    |  t2g
              +----+                     +----+
```

```
  +--------------------+---------------------+
  | COLOUR ABSORBED    | COLOUR SEEN         |
  |                    | (complementary)     |
  +--------------------+---------------------+
  | violet             | yellow              |
  | blue               | orange              |
  | green              | red                 |
  | yellow             | violet              |
  | orange             | blue                |
  | red                | green               |
  +--------------------+---------------------+

  THE STANDARD EXAMPLE:  [Ti(H2O)6]3+   is  d1
     It absorbs green-yellow light (around 500 nm) and looks VIOLET.
     On heating, the water is lost, the splitting disappears,
     and the compound becomes COLOURLESS.
```

```
  WHEN IS A COMPLEX COLOURLESS?

     When NO d-d transition is possible, that is when the d subshell is
     EMPTY or COMPLETELY FULL.

        d0    ->  Sc3+ , Ti4+ , [TiF6]2-      COLOURLESS
        d10   ->  Zn2+ , Cu+ , Ag+ , Cd2+     COLOURLESS
                  [Zn(NH3)4]2+ , [Cu(CN)4]3-  COLOURLESS

  STRONGER ligand  ->  BIGGER delta-o  ->  ABSORBS higher energy (shorter
  wavelength) light  ->  the colour CHANGES.

     [Cu(H2O)4]2+   pale blue
     [Cu(NH3)4]2+   deep blue     (NH3 is a stronger field ligand than H2O)
```

## 10G. The spin-only magnetic moment

```
  +---------------------------------------------------------------+
  |                                                               |
  |             mu   =   sqrt(  n ( n + 2 )  )    B.M.            |
  |                                                               |
  |   n = number of UNPAIRED electrons                            |
  |   B.M. = Bohr Magneton (the unit)                             |
  |                                                               |
  +---------------------------------------------------------------+

     n = 0   mu = 0        DIAMAGNETIC
     n = 1   mu = 1.73 BM  |
     n = 2   mu = 2.83 BM  |
     n = 3   mu = 3.87 BM  |  PARAMAGNETIC
     n = 4   mu = 4.90 BM  |
```

## WORKED EXAMPLE 9

**Q.** A complex has a magnetic moment of 3.87 BM. How many unpaired electrons
does it have?

```
  ANSWER   Work backwards.

     3.87   =  sqrt( n(n+2) )
     14.98  =  n(n+2)                (square both sides, 3.87^2 = 14.98)
     n^2 + 2n - 15  =  0
     (n + 5)(n - 3)  =  0
     n = 3          (n cannot be negative)

  ANSWER: 3 unpaired electrons.

  FASTER: just recognise 3.87 from the memorised list.
```

## 10H. Limitations of CFT

```
  1.  It treats the ligands as simple POINT CHARGES and the bond as
      purely IONIC. In reality the metal-ligand bond has an important
      COVALENT character.

  2.  Because of that, it predicts that ANIONIC ligands should produce
      the LARGEST splitting. In fact anionic ligands such as I- and Br-
      sit at the WEAK end of the spectrochemical series, while NEUTRAL
      ligands such as CO and NH3 are at the STRONG end.

  3.  It gives no explanation of WHY CO and CN- are such strong field
      ligands (that needs pi-bonding, which CFT ignores).

  4.  It does not consider the orbitals of the LIGANDS at all, so it
      cannot explain metal-to-ligand or ligand-to-metal charge transfer.

  5.  It cannot explain the relative strengths of ligands in general.
```

# TOPIC 11 — Stability of complexes and the chelate effect

```
  When a complex forms in solution:

     M  +  4 L   <-->   ML4

                     [ML4]
     STABILITY       ------------
     CONSTANT   K =  [M] [L]^4

  A LARGE value of K means a VERY STABLE complex.
```

Factors that make a complex more stable:

```
  1.  HIGH CHARGE on the metal ion.
         [Fe(CN)6]3-  is more stable than  [Fe(CN)6]4-

  2.  SMALL SIZE of the metal ion  ->  higher charge density.

  3.  STRONGER field ligand (higher in the spectrochemical series).
         CN- complexes are more stable than F- complexes.

  4.  Greater BASICITY of the ligand (better lone-pair donor).

  5.  CHELATION - by far the biggest effect.
```

## The chelate effect

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   THE CHELATE EFFECT                                                |
  |                                                                     |
  |   A complex formed by a POLYDENTATE (chelating) ligand is much      |
  |   MORE STABLE than the same complex formed by an equal number of    |
  |   similar UNIDENTATE ligands.                                       |
  |                                                                     |
  |   [Ni(en)3]2+   is FAR more stable than   [Ni(NH3)6]2+              |
  |                                                                     |
  |   even though both have 6 nitrogen donor atoms around Ni2+.         |
  |                                                                     |
  +---------------------------------------------------------------------+

  WHY?   Look at the reaction:

     [Ni(H2O)6]2+  +  6 NH3   ->  [Ni(NH3)6]2+ + 6 H2O
             7 particles          ->            7 particles
             no change in disorder

     [Ni(H2O)6]2+  +  3 en    ->  [Ni(en)3]2+  + 6 H2O
             4 particles          ->            7 particles
             MORE particles  ->  ENTROPY INCREASES  ->  more stable

  ONE-LINE REASON:  chelation increases the ENTROPY of the system, which
  makes delta-G more negative, so the chelate complex is more stable.

  The 5-membered and 6-membered chelate rings are the most stable.
```
