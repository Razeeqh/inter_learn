# 0. THE ANATOMY OF A COMPLEX

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |          K4  [  Fe  (CN)6  ]                                        |
  |          ^      ^     ^                                             |
  |          |      |     |                                             |
  |          |      |     +----  LIGANDS (6 of them, each CN-)          |
  |          |      |                                                   |
  |          |      +----------  CENTRAL METAL ION (Fe)                 |
  |          |                                                          |
  |          +-----------------  IONISATION SPHERE                      |
  |                              (breaks off in water)                  |
  |                                                                     |
  |          [ ..... ]  =  COORDINATION SPHERE                          |
  |                        (does NOT break in water)                    |
  |                                                                     |
  |          Coordination number  =  6                                  |
  |          Oxidation number of Fe  =  +2                              |
  |          Shape (polyhedron)  =  OCTAHEDRAL                          |
  |                                                                     |
  +---------------------------------------------------------------------+
```

# 1. RULE FOR THE OXIDATION NUMBER OF THE CENTRAL METAL

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |     x   +   ( sum of the charges on all ligands )                   |
  |                                =  charge on the [ ] sphere          |
  |                                                                     |
  |     x  =  oxidation number of the central metal                     |
  |                                                                     |
  +---------------------------------------------------------------------+

  STEP 1   Find the charge on the bracket from the OUTSIDE ions.
             K4[...]      ->  bracket is 4-
             K3[...]      ->  bracket is 3-
             Na3[...]     ->  bracket is 3-
             [...]Cl3     ->  bracket is 3+
             [...]Cl2     ->  bracket is 2+
             [...]SO4     ->  bracket is 2+
             [...](NO3)2  ->  bracket is 2+
             [........]   ->  bracket is 0  (nothing outside = neutral)

  STEP 2   Add up the ligand charges (use the table in section 2).

  STEP 3   Solve for x. Write it in ROMAN numerals: Co(III), Fe(II), Ni(0).
```

| Complex | Bracket charge | Equation | Answer |
|---|---|---|---|
| [Co(NH3)6]Cl3 | 3+ | x + 6(0) = +3 | Co is **+3** |
| K4[Fe(CN)6] | 4- | x + 6(-1) = -4 | Fe is **+2** |
| K3[Fe(CN)6] | 3- | x + 6(-1) = -3 | Fe is **+3** |
| [Ni(CO)4] | 0 | x + 4(0) = 0 | Ni is **0** |
| [Cr(H2O)4Cl2]+ | 1+ | x + 0 + 2(-1) = +1 | Cr is **+3** |
| K3[Fe(C2O4)3] | 3- | x + 3(-2) = -3 | Fe is **+3** |
| [Co(en)2Cl2]Cl | 1+ | x + 0 + 2(-1) = +1 | Co is **+3** |
| Na2[Zn(OH)4] | 2- | x + 4(-1) = -2 | Zn is **+2** |
| [Fe(H2O)5(NO)]SO4 | 2+ | x + 0 + (+1) = +2 | Fe is **+1** |
| [Pt(NH3)2Cl2] | 0 | x + 0 + 2(-1) = 0 | Pt is **+2** |

# 2. RULE FOR THE COORDINATION NUMBER

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   COORDINATION NUMBER  =  the number of DONOR ATOMS bonded to the   |
  |                           central metal                             |
  |                        =  the number of SIGMA bonds                 |
  |                                                                     |
  |   C.N. = (no. of unidentate  ligands) x 1                           |
  |        + (no. of bidentate   ligands) x 2                           |
  |        + (no. of tridentate  ligands) x 3                           |
  |        + (no. of tetradentate ligands) x 4                          |
  |        + (no. of hexadentate ligands) x 6                           |
  |                                                                     |
  |   IT IS NOT THE NUMBER OF LIGAND MOLECULES.                         |
  |                                                                     |
  +---------------------------------------------------------------------+
```

| Complex | Working | C.N. |
|---|---|---|
| [Fe(CN)6]4- | 6 x 1 | **6** |
| [Co(en)3]3+ | 3 x 2 | **6** |
| [Cr(C2O4)3]3- | 3 x 2 | **6** |
| [Ca(EDTA)]2- | 1 x 6 | **6** |
| [Co(en)2Cl2]+ | (2 x 2) + (2 x 1) | **6** |
| [Ni(CO)4] | 4 x 1 | **4** |
| [Ag(NH3)2]+ | 2 x 1 | **2** |
| [Pt(en)Cl2] | (1 x 2) + (2 x 1) | **4** |
| [Cr(NH3)3(H2O)3]3+ | 3 + 3 | **6** |

## 3B. Neutral ligands — keep their own name, with 4 exceptions

| Formula | Name as a LIGAND | Charge |
|---|---|---|

# 5. THE IUPAC NOMENCLATURE RULES, IN ORDER

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |  RULE 1   Name the CATION first, then the ANION.                    |
  |           (Same as NaCl = sodium chloride.)                         |
  |                                                                     |
  |  RULE 2   Inside the coordination sphere, name the LIGANDS FIRST,   |
  |           then the METAL.                                           |
  |                                                                     |
  |  RULE 3   Name the ligands in ALPHABETICAL ORDER, ignoring the      |
  |           multiplying prefixes di, tri, tetra, bis, tris.           |
  |                                                                     |
  |  RULE 4   ANIONIC ligands end in  -O                                |
  |              chloride -> chlorido , sulphate -> sulphato            |
  |                                                                     |
  |  RULE 5   NEUTRAL ligands keep their names, EXCEPT                  |
  |              H2O -> aqua , NH3 -> ammine ,                          |
  |              CO  -> carbonyl , NO -> nitrosyl                       |
  |                                                                     |
  |  RULE 6   CATIONIC ligands end in  -IUM  (NO+ -> nitrosonium)       |
  |                                                                     |
  |  RULE 7   Use di , tri , tetra , penta , hexa for SIMPLE ligands.   |
  |           Use bis , tris , tetrakis (with the ligand in brackets)   |
  |           when the ligand's own name already contains di/tri, or    |
  |           when the name is complicated.                             |
  |              2 Cl  -> dichlorido                                    |
  |              2 en  -> bis(ethane-1,2-diamine)                       |
  |              3 en  -> tris(ethane-1,2-diamine)                      |
  |              2 NH2CH3 -> bis(methylamine)                           |
  |                                                                     |
  |  RULE 8   Write the OXIDATION NUMBER of the metal in ROMAN          |
  |           NUMERALS inside round brackets immediately after the      |
  |           metal name, with NO space.     cobalt(III)                |
  |                                                                     |
  |  RULE 9   If the complex ion is an ANION, the metal name ends in    |
  |           -ATE (often using the Latin stem).                        |
  |                                                                     |
  |  RULE 10  If the complex is a CATION or NEUTRAL, use the ordinary   |
  |           English name of the metal.                                |
  |                                                                     |
  |  RULE 11  The whole complex ion is written as ONE WORD - no spaces  |
  |           inside the brackets. A space appears only between the     |
  |           cation and the anion.                                     |
  |                                                                     |
  |  RULE 12  A BRIDGING ligand takes the prefix  mu-  and is named     |
  |           after the other ligands.                                  |
  |                                                                     |
  |  RULE 13  For AMBIDENTATE ligands, show the donor atom:             |
  |              nitrito-N , nitrito-O , thiocyanato-S , thiocyanato-N  |
  |                                                                     |
  +---------------------------------------------------------------------+
```

# 6. THE SPECTROCHEMICAL SERIES

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   WEAK FIELD ligands                        STRONG FIELD ligands    |
  |   (small delta-o , HIGH SPIN)               (large delta-o, LOW SPIN)|
  |   <---------------------------------------------------------------> |
  |                                                                     |
  |   I-  <  Br-  <  S2-  <  SCN-  <  Cl-  <  NO3-  <  F-  <  OH-       |
  |       <  C2O4 2-  <  H2O  <  NCS-  <  EDTA 4-  <  NH3  <  en        |
  |       <  NO2-  <  CN-  <  CO                                        |
  |                                                                     |
  +---------------------------------------------------------------------+

  MEMORY LINE
     "I Br S SCN Cl NO3 F OH ox H2O NCS edta NH3 en NO2 CN CO"

     "I Bring Small Scanty CLothes , NOthing Fine , OH ,
      OXygen , WATer , New Cotton Shirts , EDucaTed AMMonia ,
      ENough , NOT CyaNide , COme"

  YOU ONLY REALLY NEED THE ENDS:

     WEAK   ->   I- , Br- , Cl- , F- , OH- , C2O4 2- , H2O
     STRONG ->   NH3 , en , NO2- , CN- , CO

  ONE-LINE DECIDER
     "If the ligand is a HALIDE or WATER or OH- , it is WEAK.
      If it is NH3 , en , NO2- , CN- or CO , it is STRONG."
```

# 7. HYBRIDISATION AND GEOMETRY

| C.N. | Hybridisation | Geometry | Orbitals used | Example |
|---|---|---|---|---|
| 2 | **sp** | linear | s + p | [Ag(NH3)2]+ , [Ag(CN)2]-, [CuCl2]- |
| 3 | sp2 | trigonal planar | s + 2p | [HgI3]- |
| 4 | **sp3** | tetrahedral | s + 3p | [NiCl4]2- , [Ni(CO)4] , [Zn(NH3)4]2+ |
| 4 | **dsp2** | square planar | (n-1)d + s + 2p | [Ni(CN)4]2- , [Pt(NH3)2Cl2], [Cu(NH3)4]2+ |
| 5 | sp3d | trigonal bipyramidal | s + 3p + d | [Fe(CO)5] |
| 6 | **d2sp3** | octahedral (INNER) | 2 x (n-1)d + s + 3p | [Co(NH3)6]3+ , [Fe(CN)6]4- |
| 6 | **sp3d2** | octahedral (OUTER) | s + 3p + 2 x nd | [CoF6]3- , [Fe(H2O)6]2+ |

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   INNER ORBITAL COMPLEX          OUTER ORBITAL COMPLEX              |
  |   ---------------------          ----------------------             |
  |   uses (n-1)d , i.e. 3d          uses  n d  , i.e. 4d               |
  |   d2sp3                          sp3d2                              |
  |   STRONG field ligand            WEAK field ligand                  |
  |   electrons PAIR UP              electrons DO NOT pair              |
  |   LOW SPIN                       HIGH SPIN                          |
  |   FEWER unpaired electrons       MORE unpaired electrons            |
  |   usually less paramagnetic      more paramagnetic                  |
  |   more STABLE                    less stable                        |
  |                                                                     |
  |   MEMORY:  the d comes BEFORE sp  ->  the d is the INNER one.       |
  |            the d comes AFTER  sp  ->  the d is the OUTER one.       |
  |                                                                     |
  +---------------------------------------------------------------------+
```

# 8. UNPAIRED ELECTRONS AND THE MAGNETIC MOMENT

## 8A. Step 1 — how many unpaired electrons?

```
  METHOD (VBT version)
     1. Oxidation number of the metal.
     2. Configuration of the ION  (REMOVE 4s ELECTRONS FIRST).
     3. STRONG field ligand -> pair up the d electrons as far as possible.
        WEAK   field ligand -> leave them unpaired (Hund's rule).
     4. Count the single arrows.  That is  n.

  METHOD (CFT version, octahedral)
     1. Get the d-electron count of the ion.
     2. STRONG field (delta-o > P)  ->  fill t2g completely first (LOW SPIN)
        WEAK   field (delta-o < P)  ->  fill all five singly first (HIGH SPIN)
     3. Count the single arrows.  That is  n.
```

```
  THE FULL OCTAHEDRAL TABLE - LEARN IT

  +-------+---------------------------+---------------------------+
  |  d^n  |  WEAK FIELD (HIGH SPIN)   |  STRONG FIELD (LOW SPIN)  |
  |       |  config          n        |  config          n        |
  +-------+---------------------------+---------------------------+
  |  d1   |  t2g1 eg0        1        |  t2g1 eg0        1        |
  |  d2   |  t2g2 eg0        2        |  t2g2 eg0        2        |
  |  d3   |  t2g3 eg0        3        |  t2g3 eg0        3        |
  |  d4   |  t2g3 eg1        4        |  t2g4 eg0        2        |
  |  d5   |  t2g3 eg2        5        |  t2g5 eg0        1        |
  |  d6   |  t2g4 eg2        4        |  t2g6 eg0        0        |
  |  d7   |  t2g5 eg2        3        |  t2g6 eg1        1        |
  |  d8   |  t2g6 eg2        2        |  t2g6 eg2        2        |
  |  d9   |  t2g6 eg3        1        |  t2g6 eg3        1        |
  |  d10  |  t2g6 eg4        0        |  t2g6 eg4        0        |
  +-------+---------------------------+---------------------------+

  The two columns DIFFER only for d4 , d5 , d6 , d7.
  For d1-d3 and d8-d10 there is only ONE possible answer.
```

## 8B. Step 2 — the spin-only magnetic moment

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |                                                                     |
  |          mu   =   sqrt (  n  ( n + 2 )  )      Bohr Magneton        |
  |                                                                     |
  |                                                                     |
  |          n  =  number of UNPAIRED electrons                         |
  |                                                                     |
  |          n = 0  ->  DIAMAGNETIC     (repelled by a magnet)          |
  |          n > 0  ->  PARAMAGNETIC    (attracted by a magnet)         |
  |                                                                     |
  +---------------------------------------------------------------------+
```

```
  +-----+-------------+--------------+
  |  n  |  n(n+2)     |  mu  (B.M.)  |
  +-----+-------------+--------------+
  |  0  |    0        |    0.00      |
  |  1  |    3        |    1.73      |
  |  2  |    8        |    2.83      |
  |  3  |   15        |    3.87      |
  |  4  |   24        |    4.90      |
  |  5  |   35        |    5.92      |
  |  6  |   48        |    6.93      |
  +-----+-------------+--------------+

  LEARN THESE SIX NUMBERS. Then you never have to use a calculator,
  and you can also run the question BACKWARDS
  ("mu = 2.83 BM, find n"  ->  n = 2).
```

# 9. CRYSTAL FIELD SPLITTING — THE NUMBERS

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   OCTAHEDRAL FIELD                                                  |
  |                                                                     |
  |      eg   (dx2-y2 , dz2)     energy  =  + 0.6 delta-o   ( +3/5 )    |
  |      t2g  (dxy,dyz,dzx)      energy  =  - 0.4 delta-o   ( -2/5 )    |
  |                                                                     |
  |      gap  =  delta-o  =  10 Dq                                      |
  |                                                                     |
  |                                                                     |
  |   TETRAHEDRAL FIELD  (upside down)                                  |
  |                                                                     |
  |      t2   (dxy,dyz,dzx)      energy  =  + 0.4 delta-t   ( +2/5 )    |
  |      e    (dx2-y2 , dz2)     energy  =  - 0.6 delta-t   ( -3/5 )    |
  |                                                                     |
  |                                                                     |
  |            delta-t   =   ( 4 / 9 )   x   delta-o                    |
  |                                                                     |
  |      ALL tetrahedral complexes are HIGH SPIN, because delta-t is    |
  |      always smaller than the pairing energy P.                      |
  |                                                                     |
  +---------------------------------------------------------------------+
```

```
  CRYSTAL FIELD STABILISATION ENERGY (octahedral)

      CFSE  =  [ (-0.4) x (number of t2g electrons)
                +(+0.6) x (number of eg  electrons) ] x delta-o

      Example  d6 low spin (t2g6 eg0):
         CFSE = (-0.4 x 6) + (0.6 x 0) = -2.4 delta-o
         (very negative = very stable - this is why low-spin d6 complexes
          such as [Co(NH3)6]3+ and [Fe(CN)6]4- are so stable)

  THE HIGH-SPIN / LOW-SPIN DECIDER

      delta-o  >  P     ->   LOW SPIN   (strong field ligand)
      delta-o  <  P     ->   HIGH SPIN  (weak field ligand)

      P = PAIRING ENERGY = the energy cost of putting two electrons
                           into the same orbital
```

# 10. THE EFFECTIVE ATOMIC NUMBER (EAN) RULE

  +---------------------------------------------------------------------+

  |       Ne = 10   Ar = 18   Kr = 36   Xe = 54   Rn = 86               |
  |                                                                     |
  +---------------------------------------------------------------------+

# THE 12 THINGS TO WRITE ON YOUR PALM

```
   1.  x + (sum of ligand charges) = charge on the [ ] bracket

   2.  C.N. = number of DONOR ATOMS  (en = 2 , ox = 2 , EDTA = 6)

   3.  Naming order:  ligands ALPHABETICALLY , then metal , then (Roman)

   4.  -ate on the metal ONLY if the complex ion is NEGATIVE
       (ferrate , cuprate , argentate , plumbate , stannate , aurate)

   5.  H2O = aqua , NH3 = ammine , CO = carbonyl , NO = nitrosyl

   6.  bis / tris  for  en , ox , dmg    (never "dien" for 2 en)

   7.  SPECTROCHEMICAL SERIES ends:
          WEAK   I- Br- Cl- F- OH- ox H2O
          STRONG NH3 en NO2- CN- CO

   8.  d2sp3 = INNER = strong field = LOW spin
       sp3d2 = OUTER = weak field   = HIGH spin

   9.  Octahedral:  t2g LOW (-0.4 delta-o) , eg HIGH (+0.6 delta-o)
       Tetrahedral: e LOW (-0.6 delta-t) , t2 HIGH (+0.4 delta-t)
       delta-t = (4/9) delta-o      ->  tetrahedral is ALWAYS high spin

  10.  delta-o > P -> LOW SPIN        delta-o < P -> HIGH SPIN

  11.  mu = sqrt( n (n+2) ) B.M.
          n =  0    1     2     3     4     5
          mu=  0  1.73  2.83  3.87  4.90  5.92

  12.  EAN = Z - (oxidation number) + 2 x (coordination number)
```
