# PATTERN 1 — Oxidation number and coordination number

### Q1
The oxidation number of cobalt in K[Co(CO)4] is

(a) +1 &nbsp; (b) +3 &nbsp; (c) -1 &nbsp; (d) 0

**ANSWER: (c)**
```
  Bracket charge = 1-  (one K+ outside)
  CO is a NEUTRAL ligand, charge 0.

  x + 4(0) = -1     ->     x = -1
```

---

### Q2
The coordination number and oxidation number of Cr in [Cr(C2O4)3]3- are

(a) 3 and +3 &nbsp; (b) 6 and +3 &nbsp; (c) 6 and +2 &nbsp; (d) 3 and +6

**ANSWER: (b)**
```
  Oxalate is BIDENTATE:  3 x 2  =  6      ->  C.N. = 6
  x + 3(-2) = -3                          ->  x = +3
```

> **SHORTCUT:** whenever you see `en` , `ox` , `gly` or `dmg`,
> multiply the count by **2**. For EDTA multiply by **6**.

---

### Q3
The coordination number of the metal in [Co(en)2(NH3)Cl]2+ is

(a) 4 &nbsp; (b) 5 &nbsp; (c) 6 &nbsp; (d) 8

**ANSWER: (c)** — `(2 en x 2) + (1 NH3 x 1) + (1 Cl x 1) = 4 + 1 + 1 = 6`

---

### Q4
The oxidation number of iron in [Fe(H2O)5(NO)]SO4 (the brown-ring complex) is

(a) +1 &nbsp; (b) +2 &nbsp; (c) +3 &nbsp; (d) 0

**ANSWER: (a)**
```
  SO4 2- outside  ->  bracket is 2+
  In this complex the ligand is NO+ (nitrosonium) , charge +1

  x + 5(0) + (+1) = +2      ->     x = +1
```

---

### Q5
Which of the following has the metal in the ZERO oxidation state?

(a) [Ni(CN)4]2- &nbsp; (b) [Ni(CO)4] &nbsp; (c) [Ni(NH3)6]2+ &nbsp; (d) [NiCl4]2-

**ANSWER: (b)** — CO is neutral and the complex is neutral, so `x = 0`.

# PATTERN 2 — IUPAC nomenclature

### Q6
The IUPAC name of K3[Fe(CN)6] is

(a) potassium hexacyanidoiron(III) &nbsp; (b) potassium hexacyanidoferrate(II)
(c) potassium hexacyanidoferrate(III) &nbsp; (d) tripotassium ferricyanide

**ANSWER: (c)**
```
  The complex ion is an ANION  ->  the metal must end in -ATE
  and Fe uses its Latin stem   ->  FERRATE
  x + 6(-1) = -3   ->   x = +3   ->   ferrate(III)
```

### Q7
The IUPAC name of [Cr(H2O)4Cl2]Cl is

(a) dichloridotetraaquachromium(III) chloride
(b) tetraaquadichloridochromium(III) chloride
(c) tetraaquadichloridochromate(III) chloride
(d) tetraaquadichloridochromium(II) chloride

**ANSWER: (b)**
```
  ALPHABETICAL order, ignoring prefixes:   Aqua  before  Chlorido
  The complex ion is a CATION -> "chromium", NOT "chromate"
  x + 0 + 2(-1) = +1  ->  x = +3  ->  chromium(III)
```

> **SHORTCUT:** in an MCQ, kill the wrong options in this order —
> (1) is the metal correctly `-ate` or not? (2) is the Roman numeral right?
> (3) are the ligands alphabetical? Usually only one option survives.

Which of the following is an ambidentate ligand?

# PATTERN 4 — Werner's theory and the AgNO3 test

### Q16
CoCl3.4NH3 gives how many moles of AgCl with excess AgNO3?

(a) 0 &nbsp; (b) 1 &nbsp; (c) 2 &nbsp; (d) 3

**ANSWER: (b)**
```
  The Werner formula is  [Co(NH3)4Cl2]Cl
  Only the ONE chloride outside the bracket is free  ->  1 mole of AgCl.
```

> **SHORTCUT for the whole CoCl3.nNH3 series:**
> ```
>    6 NH3  ->  3 AgCl  ->  4 ions
>    5 NH3  ->  2 AgCl  ->  3 ions
>    4 NH3  ->  1 AgCl  ->  2 ions
>    3 NH3  ->  0 AgCl  ->  0 ions (non-conducting)
>
>    moles of AgCl = (number of NH3) - 3
> ```

The primary and secondary valencies of cobalt in [Co(NH3)5Cl]Cl2 are

Which of the following is optically active?

The total number of isomers (geometrical + optical) of [Co(en)2Cl2]+ is

The number of isomers of the square planar complex [Pt(NH3)(py)(Cl)(Br)] is

### Q25
Tetrahedral complexes do not show geometrical isomerism because

(a) they are always paramagnetic

# PATTERN 6 — VBT: hybridisation, geometry, magnetism

### Q26
The hybridisation of the central metal in [Co(NH3)6]3+ is

(a) sp3d2 &nbsp; (b) d2sp3 &nbsp; (c) dsp2 &nbsp; (d) sp3

**ANSWER: (b)**
```
  Co3+ = 3d6 .  NH3 is a STRONG field ligand -> the 3d electrons pair up,
  freeing two 3d orbitals.

           3 d                            4s         4p
   +----+----+----+----+----+        +----+   +----+----+----+
   | ^v | ^v | ^v | xx | xx |        | xx |   | xx | xx | xx |
   +----+----+----+----+----+        +----+   +----+----+----+
                    \___________ d2sp3 __________________/
```

> **SHORTCUT:** `d` written FIRST (d2sp3) = **inner** = strong field = low spin.
> `d` written LAST (sp3d2) = **outer** = weak field = high spin.

---

### Q27
The magnetic moment of [CoF6]3- is approximately

(a) 0 BM &nbsp; (b) 1.73 BM &nbsp; (c) 2.83 BM &nbsp; (d) 4.90 BM

**ANSWER: (d)**
```
  Co3+ = 3d6 , F- is a WEAK field ligand -> no pairing -> n = 4
  mu = sqrt(4 x 6) = sqrt(24) = 4.90 B.M.
```

### Q28
[Ni(CN)4]2- is square planar and diamagnetic, while [NiCl4]2- is tetrahedral
and paramagnetic. The reason is

(a) Ni is in different oxidation states
(b) CN- is a strong field ligand and Cl- is a weak field ligand
(c) CN- is bigger than Cl-
(d) [NiCl4]2- has a different coordination number

**ANSWER: (b)**
```
  Both are Ni2+ (3d8).
  CN- (strong) pairs the two unpaired electrons -> dsp2 , square planar , n=0
  Cl- (weak) does not pair them                 -> sp3  , tetrahedral , n=2
```

### Q29
The number of unpaired electrons in [Fe(CN)6]3- is

(a) 0 &nbsp; (b) 1 &nbsp; (c) 3 &nbsp; (d) 5

  Fe3+ = 3d5 .  CN- is a STRONG field ligand  ->  LOW SPIN  ->  t2g5 eg0

     +----+  +----+
     |    |  |    |     eg
     +----+  +----+
     +----+  +----+  +----+
     | ^v |  | ^v |  | ^  |   t2g          n = 1 , mu = 1.73 B.M.
     +----+  +----+  +----+
```

# PATTERN 7 — Crystal field theory

### Q32
In an octahedral crystal field, the d orbitals that are RAISED in energy are

(a) dxy , dyz , dzx &nbsp; (b) dx2-y2 , dz2 &nbsp; (c) all five &nbsp; (d) dz2 only

**ANSWER: (b)**
```
  dx2-y2 and dz2 point ALONG the axes, straight at the ligands,
  so they are repelled MOST  ->  raised  ->  the  eg  set  (+0.6 delta-o)

  dxy , dyz , dzx point BETWEEN the axes
                             ->  lowered ->  the  t2g set  (-0.4 delta-o)
```

---

### Q33
Which of the following ligands causes the LARGEST crystal field splitting?

(a) I- &nbsp; (b) H2O &nbsp; (c) NH3 &nbsp; (d) CO

**ANSWER: (d)** — CO is at the **strong-field end** of the spectrochemical series.

> **SHORTCUT — you only need the two ends:**
> ```
>    WEAKEST   I- < Br- < Cl- < F- < OH- < ox < H2O
>    STRONGEST NH3 < en < NO2- < CN- < CO
> ```

### Q34
The relation between the tetrahedral and octahedral crystal field splitting
energies is

(a) delta-t = delta-o &nbsp; (b) delta-t = (4/9) delta-o
(c) delta-t = (9/4) delta-o &nbsp; (d) delta-t = 2 delta-o

**ANSWER: (b)** — and because delta-t is so small, **all tetrahedral complexes
are high spin**.

### Q35
The electronic configuration of a d6 ion in a STRONG octahedral field is

(a) t2g4 eg2 &nbsp; (b) t2g6 eg0 &nbsp; (c) t2g3 eg3 &nbsp; (d) t2g5 eg1

**ANSWER: (b)**
```
  Strong field -> delta-o > P -> LOW SPIN -> fill t2g completely first.

     +----+  +----+
     |    |  |    |     eg
     +----+  +----+
     +----+  +----+  +----+
     | ^v |  | ^v |  | ^v |   t2g       t2g6 eg0 , n = 0 , diamagnetic
     +----+  +----+  +----+
```

### Q36
The crystal field stabilisation energy (CFSE) of a low-spin d6 octahedral
complex is

(a) -0.4 delta-o &nbsp; (b) -1.2 delta-o &nbsp; (c) -2.4 delta-o &nbsp; (d) -1.8 delta-o

**ANSWER: (c)**
```
  CFSE = (-0.4)(number in t2g) + (+0.6)(number in eg)
       = (-0.4)(6) + (0.6)(0)
       = -2.4 delta-o
```

### Q37
A complex has a spin-only magnetic moment of 5.92 BM. The number of unpaired
electrons is

(a) 2 &nbsp; (b) 3 &nbsp; (c) 4 &nbsp; (d) 5

**ANSWER: (d)**
```
  mu = sqrt(n(n+2))
  5.92^2 = 35 = n(n+2)  ->  n = 5

  MEMORISE THE LADDER:
     n  =  0     1      2      3      4      5
     mu =  0   1.73   2.83   3.87   4.90   5.92
```

### Q38
The high-spin / low-spin distinction does NOT arise for which of these
octahedral configurations?

(a) d4 &nbsp; (b) d5 &nbsp; (c) d3 &nbsp; (d) d6

# PATTERN 8 — Colour, stability, EAN, applications

### Q39
[Ti(H2O)6]3+ is violet in colour because

(a) of a charge-transfer transition &nbsp; (b) of a d-d transition
(c) titanium is a heavy metal &nbsp; (d) water is a strong field ligand

**ANSWER: (b)**
```
  Ti3+ is d1. The single electron absorbs light of energy delta-o
  (around 500 nm, green-yellow) and jumps from t2g to eg.
  The COMPLEMENTARY colour, VIOLET, is what we see.
  On heating, the water is lost and the compound becomes COLOURLESS.
```

Which of the following complexes is COLOURLESS?

(a) [Ti(H2O)6]3+ &nbsp; (b) [Cu(NH3)4]2+ &nbsp; (c) [Zn(NH3)4]2+ &nbsp; (d) [Ni(H2O)6]2+

**ANSWER: (c)**

> **SHORTCUT:** a complex is colourless when the metal ion is **d0** or **d10**,

>    d0  :  Sc3+ , Ti4+ , V5+
>    d10 :  Zn2+ , Cd2+ , Cu+ , Ag+ , Hg2+
> ```

### Q41
The effective atomic number (EAN) of iron in K4[Fe(CN)6] is (Z of Fe = 26)

(a) 34 &nbsp; (b) 35 &nbsp; (c) 36 &nbsp; (d) 38

**ANSWER: (c)**
```
  EAN = Z - (oxidation number) + 2 x (coordination number)
      = 26 - 2 + 2(6)
      = 26 - 2 + 12   =   36        ( = krypton , so the rule is obeyed )
```

**ANSWER: (d)** — `29 - 2 + 8 = 35`, which is not a noble-gas number.
The other three all come to 36 (krypton).

### Q43
[Ni(en)3]2+ is more stable than [Ni(NH3)6]2+ because of

(a) the trans effect &nbsp; (b) the chelate effect
(c) a higher oxidation number &nbsp; (d) a smaller coordination number

**ANSWER: (b)**
```
  Three bidentate en ligands replace six water molecules:
     [Ni(H2O)6]2+ + 3 en  ->  [Ni(en)3]2+ + 6 H2O
        4 particles       ->      7 particles

  The number of free particles INCREASES, so the ENTROPY increases and
  delta-G becomes more negative. Chelate complexes are therefore more stable.
```
