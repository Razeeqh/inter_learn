## THE 60-SECOND VERSION

A **coordination compound** is a metal ion sitting in the middle, with a set of
molecules or ions **holding on to it** by donating lone pairs of electrons.

```
  Think of it like this:

        The metal ion  =  a person with EMPTY HANDS (empty orbitals)
        The ligands    =  people who OFFER a hand (a lone pair)

        They shake hands  ->  that handshake is a COORDINATE BOND.

        The metal + the ligands holding it, written inside [ ]
        =  the COORDINATION SPHERE.   It does NOT break in water.

        Anything written OUTSIDE the [ ]  =  ionisation sphere.
        It DOES break off in water and can be tested with AgNO3.
```

The whole chapter is then just five questions asked about that handshake:

```
  Q1  How many hands?          ->  COORDINATION NUMBER
  Q2  What do we call it?      ->  IUPAC NOMENCLATURE
  Q3  Can the same pieces be
      arranged differently?    ->  ISOMERISM
  Q4  Which orbitals shake
      hands?                   ->  VALENCE BOND THEORY (hybridisation)
  Q5  Why is it coloured and
      magnetic?                ->  CRYSTAL FIELD THEORY (t2g / eg splitting)
```

**Learn those five questions in that order and the chapter is finished.**

## THE KEY BOX — OXIDATION NUMBER AND COORDINATION NUMBER

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   RULE 1 - OXIDATION NUMBER of the central metal                    |
  |   ---------------------------------------------------              |
  |                                                                     |
  |     x  +  (sum of the charges on all the ligands)                   |
  |                          =  charge on the coordination sphere [ ]   |
  |                                                                     |
  |     NEUTRAL ligands (charge 0):  NH3 , H2O , CO , NO , en , py      |
  |     NEGATIVE ligands:  Cl- , Br- , I- , CN- , OH- , NO2- , SCN-     |
  |                        (all -1)                                     |
  |                        C2O4 2- (oxalate) , CO3 2- , SO4 2-  (-2)    |
  |     POSITIVE ligand:   NO+ (nitrosonium) , NH2-NH3 +   (+1)         |
  |                                                                     |
  |     If the WHOLE compound is written with ions outside, the charge  |
  |     on [ ] is fixed by the outside ions.                            |
  |                                                                     |
  |                                                                     |
  |   RULE 2 - COORDINATION NUMBER                                      |
  |   ----------------------------                                      |
  |                                                                     |
  |     C.N.  =  the number of SIGMA BONDS                              |
  |              (the number of DONOR ATOMS attached to the metal)      |
  |                                                                     |
  |     NOT the number of ligand molecules.                             |
  |                                                                     |
  |     C.N. = (unidentate ligands x 1)                                 |
  |          + (bidentate  ligands x 2)                                 |
  |          + (hexadentate ligands x 6)  ...                           |
  |                                                                     |
  +---------------------------------------------------------------------+
```

Two quick checks so you never get these wrong:

```
  EXAMPLE A   K4[Fe(CN)6]

              4 K+ outside  ->  the sphere must be  4-
              x + 6(-1) = -4      ->   x = +2       Fe is  +2
              6 CN- , each unidentate     ->   C.N. = 6


  EXAMPLE B   [Co(en)2Cl2]Cl

              1 Cl- outside  ->  the sphere is  1+
              x + 2(0) + 2(-1) = +1    ->   x = +3   Co is  +3
              en is BIDENTATE:  2 x 2 = 4 , plus 2 Cl = 2
                                     ->   C.N. = 4 + 2 = 6
                                          (NOT 4 ligands = 4)
```

> **THE SINGLE MOST COMMON MISTAKE IN THE WHOLE CHAPTER**
> Counting en, ox or gly as ONE. Each of them uses **TWO** hands.
> EDTA uses **SIX**.

## THE THREE TABLES YOU CANNOT AVOID

```
  1.  LIGAND NAMES         Cl- -> chlorido , CN- -> cyanido , NH3 -> ammine
                           H2O -> aqua , CO -> carbonyl , OH- -> hydroxido

  2.  METAL ANION NAMES    Fe -> ferrate , Cu -> cuprate , Ag -> argentate
                           Pb -> plumbate , Sn -> stannate , Au -> aurate
                           (used ONLY when the complex is an ANION)

  3.  SPECTROCHEMICAL SERIES  (weak field  ->  strong field)

      I- < Br- < S2- < SCN- < Cl- < F- < OH- < ox < H2O < NCS-
      < edta < NH3 < en < CN- < CO
                                    ^^^^^^^^^
                             the strongest field ligands
```

## THE ONE FORMULA IN THE WHOLE CHAPTER

```
  +---------------------------------------------------------------+
  |                                                               |
  |     SPIN-ONLY MAGNETIC MOMENT                                 |
  |                                                               |
  |          mu   =   sqrt(  n ( n + 2 )  )      B.M.             |
  |                                                               |
  |          n  =  number of UNPAIRED electrons                   |
  |          B.M. = Bohr Magneton                                 |
  |                                                               |
  +---------------------------------------------------------------+

  Learn this tiny table and every magnetic-moment question is instant:

     n = 0   ->  mu = 0        ->  DIAMAGNETIC
     n = 1   ->  mu = 1.73 BM
     n = 2   ->  mu = 2.83 BM
     n = 3   ->  mu = 3.87 BM
     n = 4   ->  mu = 4.90 BM
     n = 5   ->  mu = 5.92 BM

  They can also ask it BACKWARDS:
     "mu = 3.87 BM, how many unpaired electrons?"   ->  n = 3
```
