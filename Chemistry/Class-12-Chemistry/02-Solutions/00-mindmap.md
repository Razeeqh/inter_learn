## THE 60-SECOND VERSION

A **solution** is a mixture where one thing (the **solute**, less of it) is spread
evenly inside another (the **solvent**, more of it).

The whole chapter answers only **three questions**:

```
  QUESTION 1   "How much solute is in there?"
                  ->  concentration terms
                      mass %, ppm, mole fraction, MOLARITY, MOLALITY
                      (molality is the exam's favourite - it ignores temperature)

  QUESTION 2   "What pressure does the vapour above it have?"
                  ->  RAOULT'S LAW      p = p0 x     for each liquid
                  ->  HENRY'S LAW       p = KH x     for a dissolved gas
                      Ideal solution = obeys Raoult everywhere.
                      Non-ideal = it does not, so it deviates + or -.

  QUESTION 3   "What did adding the solute CHANGE?"
                  ->  the four COLLIGATIVE PROPERTIES.
                      Vapour pressure goes DOWN
                      Boiling point goes UP
                      Freezing point goes DOWN
                      Osmotic pressure APPEARS
```

And one warning at the end:

```
  WARNING      If the solute BREAKS UP (NaCl -> Na+ + Cl-) or STICKS TOGETHER
               (benzoic acid -> dimer), the number of particles changes,
               so the answer changes.  Fix it with the van't Hoff factor  i.
```

**COLLIGATIVE means: it depends on HOW MANY particles are dissolved,
not on WHAT they are.** 1 mole of sugar and 1 mole of urea do exactly the
same thing. That single sentence is worth 2 marks on its own.

## THE FOUR FORMULAE THAT ARE THE WHOLE CHAPTER

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |   1.  RELATIVE LOWERING OF VAPOUR PRESSURE                        |
  |                                                                   |
  |          p0  -  p                                                 |
  |         ------------  =  x(solute)                                |
  |             p0                                                    |
  |                                                                   |
  |                                                                   |
  |   2.  ELEVATION OF BOILING POINT                                  |
  |                                                                   |
  |         delta Tb  =  Kb  x  m                                     |
  |                                                                   |
  |                                                                   |
  |   3.  DEPRESSION OF FREEZING POINT                                |
  |                                                                   |
  |         delta Tf  =  Kf  x  m                                     |
  |                                                                   |
  |                                                                   |
  |   4.  OSMOTIC PRESSURE                                            |
  |                                                                   |
  |                                    n                              |
  |         pi  =  C R T       =    ------- R T                       |
  |                                    V                              |
  |                                                                   |
  +-------------------------------------------------------------------+

     m  = molality  = moles of solute per KILOGRAM of solvent
     C  = molarity  = moles of solute per LITRE of solution
     Kb = molal elevation constant   (water = 0.52  K kg/mol)
     Kf = molal depression constant  (water = 1.86  K kg/mol)
     R  = 0.0821 L atm / K mol   =   0.083 L bar / K mol
```

**If the solute splits or joins, put `i` in front of every one of them:**

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |    p0 - p                                                         |
  |   --------- = i x(solute)      delta Tb = i Kb m                  |
  |      p0                                                           |
  |                                                                   |
  |   delta Tf = i Kf m            pi = i C R T                       |
  |                                                                   |
  |                                                                   |
  |          number of particles ACTUALLY present                     |
  |    i  =  ---------------------------------------                  |
  |          number of particles you EXPECTED                         |
  |                                                                   |
  |          NORMAL (theoretical) molar mass                          |
  |       =  --------------------------------                         |
  |          OBSERVED (abnormal) molar mass                           |
  |                                                                   |
  +-------------------------------------------------------------------+

     NaCl   -> Na+ + Cl-              i = 2
     CaCl2  -> Ca2+ + 2Cl-            i = 3
     K2SO4  -> 2K+ + SO4 2-           i = 3
     2 CH3COOH -> (CH3COOH)2 dimer    i = 0.5
```

**Write these two boxes on your palm.**

## THE ONE THING STUDENTS ALWAYS GET WRONG

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   MOLARITY  (M)  =  moles of solute  /  LITRES of SOLUTION         |
  |                                        ^^^^^^^^^^^^^^^^^^          |
  |                     VOLUME.  Volume EXPANDS when heated.           |
  |                     ->  MOLARITY CHANGES WITH TEMPERATURE.         |
  |                                                                    |
  |   MOLALITY  (m)  =  moles of solute  /  KILOGRAMS of SOLVENT       |
  |                                        ^^^^^^^^^^^^^^^^^^^^        |
  |                     MASS.  Mass NEVER changes on heating.          |
  |                     ->  MOLALITY DOES NOT CHANGE WITH TEMPERATURE. |
  |                                                                    |
  |   THAT is why every colligative-property formula uses MOLALITY.    |
  |                                                                    |
  +--------------------------------------------------------------------+
```

Also burn this in:

```
   MOLARITY  ->  volume of the WHOLE SOLUTION
   MOLALITY  ->  mass of the SOLVENT ONLY
```

Students lose the mark by dividing by the mass of the *solution* in molality.
**Molality uses the solvent only.**

## IF YOU ONLY HAVE 2 DAYS

```
  DAY 1  (theory + easy marks)

    Morning    Types of solutions + ALL concentration definitions.
               Write each definition with its formula and its unit.
               -> about 4 marks of Section A locked.

    Afternoon  The interconversion sum: "x% w/w, density d -> M, m,
               mole fraction". Do it 8 times with different numbers.
               -> one 4-mark question locked.

    Evening    HENRY'S LAW: statement, p = KH x, meaning of KH,
               temperature effect, 3 applications.
               RAOULT'S LAW: both statements.
               Ideal vs non-ideal + the two graphs + examples.
               Azeotropes: 2 types with 1 example each.
               -> another 4 to 6 marks locked.


  DAY 2  (the numericals - this is where the marks really are)

    Morning    delta Tb = Kb m     and    delta Tf = Kf m
               Learn the molar-mass forms:

                            1000  Kb  w2                1000  Kf  w2
                  M2  =  -----------------      M2  =  ---------------
                          delta Tb  x  w1               delta Tf x w1

               Do 4 sums of each.

    Afternoon  Relative lowering of VP   and   pi = C R T
               Learn:      M2 = w2 R T / (pi  V)
               Do 4 sums of each.

    Evening    van't Hoff factor:
                  i for NaCl, CaCl2, K2SO4, dimer
                  alpha = (i - 1)/(n - 1)         for DISSOCIATION
                  alpha = (1 - i)/(1 - 1/n)       for ASSOCIATION
               Put i in front of all four formulae.
               Then re-read the mind map.

    Last 30    Copy the two palm boxes above onto one sheet of paper
    minutes    and read only that sheet on exam morning.
```

## WHAT TO DO IF YOU FREEZE IN THE EXAM

```
  Cannot remember which way it goes?
  ---------------------------------------------------------------
     Adding salt to water makes it HARDER to boil and HARDER
     to freeze.

     HARDER to boil   ->  boiling point goes UP    ->  delta Tb  is +
     HARDER to freeze ->  freezing point goes DOWN ->  delta Tf  is a
                                                       DEPRESSION

     That is why salt is thrown on icy roads, and why food cooks
     slower in salty water.
  ---------------------------------------------------------------
```
