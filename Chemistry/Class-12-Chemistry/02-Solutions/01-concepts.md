# Solutions — Concepts Explained Simply

Read one topic. Do its worked numerical. Then move to the next.
Nothing here assumes you remember anything from Class 10 or from 1st year.

This chapter is **numerical-heavy**. That is GOOD NEWS for you. Numericals have
fixed steps. If you follow the steps you get the mark — there is no "writing
skill" involved.

# TOPIC 1 — What exactly is a solution?

```
  SOLUTION  =  a HOMOGENEOUS mixture of two or more substances.

  HOMOGENEOUS means: it looks the SAME everywhere. If you take a drop from
  the top and a drop from the bottom, they are identical.
```

Sugar stirred into water is a **solution**. Sand stirred into water is **not** —
the sand settles, so it is not homogeneous.

```
  SOLUTE   -  the substance present in the SMALLER amount (gets dissolved)
  SOLVENT  -  the substance present in the LARGER amount (does the dissolving)

  Sugar in water:      sugar = solute ,  water = solvent
  Salt in water:       salt  = solute ,  water = solvent
```

**BINARY SOLUTION** = a solution made of exactly TWO components
(one solute + one solvent). Almost every exam question is about binary solutions.

**AQUEOUS SOLUTION** = a solution where the solvent is **water**.

> **TRAP:** The solvent is decided by AMOUNT, not by which is a liquid.
> In a 90% alcohol / 10% water mixture, **alcohol is the solvent** and water
> is the solute — even though water is "the usual solvent".

# TOPIC 2 — The nine types of solutions

Solute can be solid, liquid or gas. Solvent can be solid, liquid or gas.
3 x 3 = **9 possible combinations**. This is a favourite 2-mark question,
so learn the table with the examples.

```
  +--------+---------+-------------------------------------------------+
  | SOLUTE | SOLVENT |  EXAMPLE                                        |
  +--------+---------+-------------------------------------------------+
  |  GAS   |  GAS    |  AIR (oxygen + nitrogen + others)               |
  | LIQUID |  GAS    |  water vapour in air (humidity); chloroform     |
  |        |         |  vapour mixed with nitrogen gas                 |
  | SOLID  |  GAS    |  camphor vapour in nitrogen gas; iodine vapour  |
  |        |         |  in air                                         |
  +--------+---------+-------------------------------------------------+
  |  GAS   | LIQUID  |  oxygen dissolved in water; CO2 in soda water   |
  | LIQUID | LIQUID  |  ethanol in water; petrol (mixture of liquids)  |
  | SOLID  | LIQUID  |  sugar in water; common salt in water; glucose  |
  |        |         |  in water                                       |
  +--------+---------+-------------------------------------------------+
  |  GAS   | SOLID   |  hydrogen adsorbed/dissolved in palladium       |
  | LIQUID | SOLID   |  AMALGAM - mercury dissolved in sodium          |
  | SOLID  | SOLID   |  ALLOYS - brass (Cu + Zn), bronze (Cu + Sn)     |
  +--------+---------+-------------------------------------------------+
```

```
  MEMORY:  Row order is always  GAS - LIQUID - SOLID  for the solute,
           and the three blocks are  in GAS , in LIQUID , in SOLID.

           Three answers you must never forget:
              gas in gas     ->  AIR
              solid in liquid ->  SUGAR IN WATER
              solid in solid  ->  BRASS
```

## Worked example 1

**Q. Give one example each of a solution of (a) a gas in a liquid,
(b) a liquid in a solid, (c) a solid in a gas.**

```
  (a)  gas in liquid   ->  carbon dioxide dissolved in soda water
                           (also: oxygen dissolved in river water)

  (b)  liquid in solid ->  sodium amalgam (mercury dissolved in sodium)

  (c)  solid in gas    ->  camphor vapour in nitrogen gas
                           (also: iodine vapour in air)
```

# TOPIC 3 — Concentration, part 1: the percentage terms and ppm

"Concentration" answers one question: **how much solute is in there?**

There are 8 ways to say it. Learn the formula AND the unit for each.

## 3.1 Mass percentage (% w/w)

```
  +---------------------------------------------------------------+
  |                                                               |
  |                          mass of the SOLUTE                   |
  |   mass %  (w/w)  =  ------------------------------  x  100    |
  |                          mass of the SOLUTION                 |
  |                                                               |
  |   mass of solution  =  mass of solute  +  mass of solvent     |
  |                                                               |
  +---------------------------------------------------------------+
```

"A 10% w/w glucose solution" means **10 g of glucose in 100 g of solution**,
i.e. 10 g glucose + 90 g water.

## 3.2 Volume percentage (% v/v)

```
  +---------------------------------------------------------------+
  |                                                               |
  |                          volume of the SOLUTE                 |
  |   volume %  (v/v)  =  ----------------------------  x  100    |
  |                          volume of the SOLUTION               |
  |                                                               |
  +---------------------------------------------------------------+
```

Used for liquid-in-liquid. "35% v/v ethylene glycol antifreeze" = 35 mL of
ethylene glycol in 100 mL of solution.

## 3.3 Mass by volume percentage (% w/v)

```
  +---------------------------------------------------------------+
  |                                                               |
  |                     mass of SOLUTE in grams                   |
  |   mass/volume %  =  -----------------------------  x  100     |
  |                     volume of SOLUTION in mL                  |
  |                                                               |
  +---------------------------------------------------------------+
```

This is the one used in **medicine and pharmacy**. "0.9% w/v NaCl (normal
saline)" = 0.9 g NaCl in 100 mL of solution.

## 3.4 Parts per million (ppm)

Used when the solute is present in a **very tiny amount** — pollutants,
dissolved oxygen, hardness of water, pesticide residue.

```
  +---------------------------------------------------------------+
  |                                                               |
  |               number of parts of the component                |
  |   ppm  =  --------------------------------------  x  10^6     |
  |               total number of parts of solution               |
  |                                                               |
  |   (parts can be mass/mass, volume/volume or mass/volume)       |
  |                                                               |
  +---------------------------------------------------------------+

  1 ppm  =  1 gram of solute in 10^6 grams (= 1000 kg) of solution
         =  1 milligram per litre of water   (because 1 L water = 1 kg)
```

## Worked example 2 — mass percentage

**Q. 15 g of urea is dissolved in 500 g of water. Find the mass percentage
of urea.**

```
  STEP 1  mass of solute   =  15 g
          mass of solvent  =  500 g
          mass of SOLUTION =  15 + 500  =  515 g

  STEP 2                    15
          mass %  =  ---------------  x  100
                          515

                        1500
                  =  ----------   =   2.91 %
                        515
```

> **TRAP:** you divide by **515**, not by 500. The denominator is the
> **solution**, not the solvent. This single slip is the most common error
> in the whole chapter.

## Worked example 3 — ppm

**Q. A 350 g sample of water is found to contain 0.0035 g of dissolved
oxygen. Express this in ppm.**

```
                0.0035
   ppm  =  -------------  x  10^6
                 350

           =  0.00001  x  10^6

           =  10  ppm
```

# TOPIC 4 — Concentration, part 2: mole fraction (x)

```
  +---------------------------------------------------------------+
  |                                                               |
  |                    moles of THAT component                    |
  |   mole fraction = ------------------------------              |
  |                    TOTAL moles of all components              |
  |                                                               |
  |   For a binary solution (solvent = 1 , solute = 2):            |
  |                                                               |
  |               n1                        n2                    |
  |     x1 = ------------        x2  =  ------------              |
  |            n1 + n2                    n1 + n2                 |
  |                                                               |
  |                                                               |
  |          x1  +  x2  =  1        <-- ALWAYS. Use this to check.|
  |                                                               |
  |     MOLE FRACTION HAS NO UNIT.                                |
  |                                                               |
  +---------------------------------------------------------------+

                       given mass         w
       moles   n   =  --------------  =  ----
                       molar mass         M
```

Mole fraction is the concentration term used in **Raoult's law and Henry's law**,
so you cannot avoid it.

## Worked example 4

**Q. 20 g of ethanol (C2H5OH, M = 46 g/mol) is dissolved in 180 g of water
(M = 18 g/mol). Calculate the mole fraction of each.**

```
  STEP 1  moles of ethanol       moles of water

              20                     180
  n2  =  ----------  =  0.4348   n1 = ------  =  10.0
              46                       18

  STEP 2  total moles  =  10.0  +  0.4348  =  10.4348

  STEP 3
                0.4348
   x(ethanol) = ----------  =  0.0417
                10.4348

                 10.0
   x(water)   = ----------  =  0.9583
                10.4348

  CHECK:   0.0417  +  0.9583  =  1.0000     correct
```

> **TRAP:** mole fraction can never be more than 1 and never negative.
> If you get 1.4 or -0.3, you divided by the wrong thing.

# TOPIC 5 — Molarity (M)

```
  +---------------------------------------------------------------+
  |                                                               |
  |                       moles of solute                         |
  |    MOLARITY   M  =  ---------------------                     |
  |                     VOLUME OF SOLUTION                        |
  |                        in LITRES                              |
  |                                                               |
  |                          w2  x  1000                          |
  |               M   =   ---------------------                   |
  |                       M2  x  V(in mL)                         |
  |                                                               |
  |    UNIT:  mol/L  , written  M  , read as "molar"              |
  |                                                               |
  +---------------------------------------------------------------+
```

"0.25 M NaOH" means 0.25 mole of NaOH in **one litre of solution**.

## Worked example 5

**Q. Calculate the molarity of a solution made by dissolving 5.85 g of NaCl
in enough water to make 500 mL of solution. (Na = 23, Cl = 35.5)**

```
  STEP 1  molar mass of NaCl  =  23 + 35.5  =  58.5 g/mol

  STEP 2                    5.85
          moles of NaCl  = --------  =  0.100 mol
                            58.5

  STEP 3  volume of SOLUTION  =  500 mL  =  0.500 L

  STEP 4                0.100
          Molarity  =  --------  =  0.200 M
                        0.500
```

# TOPIC 6 — Molality (m), and why temperature matters

```
  +---------------------------------------------------------------+
  |                                                               |
  |                       moles of solute                         |
  |    MOLALITY   m  =  ---------------------                     |
  |                       MASS OF SOLVENT                         |
  |                       in KILOGRAMS                            |
  |                                                               |
  |                          w2  x  1000                          |
  |               m   =   ---------------------                   |
  |                       M2  x  w1(in grams)                     |
  |                                                               |
  |    UNIT:  mol/kg  , written  m  , read as "molal"             |
  |                                                               |
  +---------------------------------------------------------------+
```

## THE MOST IMPORTANT COMPARISON IN THE CHAPTER

```
  +--------------------------+--------------------------------------+
  |  MOLARITY  (M)           |  MOLALITY  (m)                       |
  +--------------------------+--------------------------------------+
  |  per LITRE of SOLUTION   |  per KILOGRAM of SOLVENT             |
  |  uses VOLUME             |  uses MASS                           |
  |  Volume EXPANDS when     |  Mass NEVER changes when heated      |
  |  heated                  |                                      |
  |  ==> MOLARITY CHANGES    |  ==> MOLALITY DOES NOT CHANGE        |
  |      WITH TEMPERATURE    |      WITH TEMPERATURE                |
  +--------------------------+--------------------------------------+
```

**Say it in the exam like this (2 marks):**

> Molarity is defined per unit **volume of solution**. On heating, the solution
> expands, so the same number of moles now occupies a larger volume and the
> molarity **falls**. Molality is defined per unit **mass of solvent**, and mass
> is independent of temperature, so molality **remains constant**.
> That is why molality is preferred in colligative-property calculations.

## Worked example 6

**Q. 18 g of glucose (M = 180 g/mol) is dissolved in 250 g of water.
Calculate the molality.**

```
  STEP 1                     18
          moles of glucose = ------  =  0.100 mol
                             180

  STEP 2  mass of SOLVENT  =  250 g  =  0.250 kg

  STEP 3                 0.100
          molality  =  ---------  =  0.400  mol/kg   =  0.4 m
                        0.250
```

> **TRAP:** for molality you divide by the mass of the **solvent (250 g)**,
> NOT by the mass of the solution (268 g). Molarity uses the solution,
> molality uses the solvent. Get this the wrong way round and you lose the
> whole question.

# TOPIC 7 — Normality (N)

```
  +---------------------------------------------------------------+
  |                                                               |
  |                      gram equivalents of solute               |
  |    NORMALITY   N  =  --------------------------------         |
  |                      volume of SOLUTION in litres             |
  |                                                               |
  |                                molar mass                     |
  |    equivalent mass       =  ------------------                |
  |                                 n-factor                      |
  |                                                               |
  |    N  =  Molarity  x  n-factor                                |
  |                                                               |
  +---------------------------------------------------------------+

  n-factor:
     ACID    ->  number of replaceable H+ ions
                    HCl = 1 , H2SO4 = 2 , H3PO4 = 3
     BASE    ->  number of OH- ions
                    NaOH = 1 , Ca(OH)2 = 2
     SALT    ->  total positive charge
                    NaCl = 1 , Na2CO3 = 2 , CaCl2 = 2
```

## Worked example 7

**Q. 4.9 g of H2SO4 is dissolved in water to make 500 mL of solution.
Find its normality and molarity. (H = 1, S = 32, O = 16)**

```
  STEP 1  molar mass of H2SO4  =  2(1) + 32 + 4(16)  =  98 g/mol

  STEP 2  n-factor  =  2   (two replaceable H+)
                                  98
          equivalent mass  =  ---------  =  49
                                   2

  STEP 3                            4.9
          gram equivalents  =  ------------  =  0.100
                                    49

  STEP 4                0.100
          Normality  = ---------  =  0.200 N
                        0.500

  STEP 5  Molarity  =  ( 4.9 / 98 ) / 0.500  =  0.05 / 0.5  =  0.100 M

  CHECK:  N  =  M x n-factor  =  0.100 x 2  =  0.200 N     correct
```

# TOPIC 8 — The interconversion sum (a guaranteed 4 marks)

This ONE type of question appears again and again. Learn it as a recipe.

```
  THE RECIPE FOR  "x % w/w , density d  ->  find M , m and mole fraction"

  STEP 1  ASSUME you have exactly 100 g of SOLUTION.
             ->  mass of solute  =  x grams
             ->  mass of solvent =  (100 - x) grams

  STEP 2  moles of solute  =  x / M2

  STEP 3  MOLALITY  =  moles of solute  /  (mass of solvent in kg)

  STEP 4  volume of solution  =  mass / density  =  100 / d   mL
             ->  convert to litres

  STEP 5  MOLARITY  =  moles of solute  /  volume in litres

  STEP 6  moles of solvent  =  (100 - x) / M1
             MOLE FRACTION  =  moles of solute / (total moles)
```

## Worked example 8 (do this sum ten times)

**Q. A solution of glucose in water is labelled as 10% w/w. The density of the
solution is 1.2 g/mL. Calculate the molality, molarity and mole fraction of
glucose. (glucose C6H12O6, M = 180; water M = 18)**

```
  STEP 1  Take 100 g of SOLUTION.
             glucose  =  10 g
             water    =  100 - 10  =  90 g

  STEP 2                       10
          moles of glucose  = ------  =  0.05556 mol
                              180

  STEP 3  mass of solvent  =  90 g  =  0.090 kg

                        0.05556
          MOLALITY  =  ----------  =  0.617  mol/kg
                         0.090

  STEP 4                              mass        100
          volume of solution  =  ------------  =  -----  =  83.33 mL
                                   density        1.2

                              =  0.08333 L

  STEP 5                 0.05556
          MOLARITY  =  ------------  =  0.667  mol/L
                         0.08333

  STEP 6                     90
          moles of water = ------  =  5.000 mol
                             18

          total moles  =  5.000  +  0.05556  =  5.0556

                                  0.05556
          x(glucose)  =  -----------------  =  0.011
                              5.0556

          x(water)    =  1  -  0.011  =  0.989

  ANSWER:  molality = 0.617 m ,  molarity = 0.667 M ,
           x(glucose) = 0.011
```

Two shortcut formulae you may also quote (both give the same answers):

```
  +---------------------------------------------------------------+
  |                                                               |
  |                  1000  x  M                                   |
  |      m   =   ---------------------                            |
  |               1000 d  -  M  x  M2                             |
  |                                                               |
  |                                                               |
  |                 1000  x  m  x  d                              |
  |      M   =   -----------------------                          |
  |               1000  +  m  x  M2                               |
  |                                                               |
  |    d  = density of solution in g/mL                           |
  |    M2 = molar mass of the SOLUTE                              |
  |                                                               |
  +---------------------------------------------------------------+
```

> **TRAP:** density must be in **g/mL** and mass in **grams**. If the density
> is given in kg/L, it is numerically the same number — do not "convert" it
> a second time.

# TOPIC 9 — Solubility of a SOLID in a LIQUID

```
  SOLUBILITY  =  the MAXIMUM amount of a solute that dissolves in a given
                 amount of solvent at a given TEMPERATURE and PRESSURE.

  SATURATED SOLUTION       -  no more solute will dissolve at that temperature
                              (dissolved solute is in EQUILIBRIUM with the
                              undissolved solid)
  UNSATURATED SOLUTION     -  more solute can still dissolve
  SUPERSATURATED SOLUTION  -  contains more than the saturation amount
                              (unstable)
```

## Rule 1 — "LIKE DISSOLVES LIKE"

```
  POLAR solute      dissolves in   POLAR solvent
     (NaCl, sugar)                    (water)

  NON-POLAR solute  dissolves in   NON-POLAR solvent
     (naphthalene, iodine, fat)       (benzene, CCl4, petrol)
```

That is why salt dissolves in water but not in petrol, and why grease
dissolves in petrol but not in water.

## Rule 2 — Effect of TEMPERATURE

```
  Dissolving is an equilibrium:      SOLID  <-->  SOLUTION

  Apply Le Chatelier's principle:

  If dissolving is ENDOTHERMIC (absorbs heat, delta H is POSITIVE)
        ->  heating pushes it FORWARD  ->  SOLUBILITY INCREASES
        Examples: KNO3 , KCl , NaNO3 , most solids

  If dissolving is EXOTHERMIC (gives out heat, delta H is NEGATIVE)
        ->  heating pushes it BACKWARD ->  SOLUBILITY DECREASES
        Examples: Ce2(SO4)3 , Li2SO4
```

```
     s |                                    KNO3   (endothermic,
     o |                                  /         solubility rises
     l |                              /             steeply)
     u |                          /
     b |                      /                NaCl (almost flat)
     i |  ----------------/---------------------------
     l |             /
     i |        /
     t |   /                 Ce2(SO4)3  (exothermic)
     y |  ------____
       |            ------____
       +--------------------------------------------->
                       TEMPERATURE
```

## Rule 3 — Effect of PRESSURE

```
  Solids and liquids are almost INCOMPRESSIBLE.
  ->  PRESSURE HAS NO SIGNIFICANT EFFECT on the solubility of a solid
      in a liquid.
```

# TOPIC 10 — Solubility of a GAS in a liquid: HENRY'S LAW

Gases are different — for gases, **pressure matters enormously**.

## The statement (learn it word for word)

```
  +---------------------------------------------------------------+
  |                                                               |
  |   HENRY'S LAW                                                 |
  |                                                               |
  |   "The partial pressure of a gas in the vapour phase is        |
  |    directly proportional to the mole fraction of the gas       |
  |    in the solution."                                          |
  |                                                               |
  |            p   =   K(H)  x                                    |
  |                                                               |
  |    p    =  partial pressure of the gas above the liquid        |
  |    x    =  mole fraction of the gas IN the liquid              |
  |            (this is its solubility)                            |
  |    K(H) =  HENRY'S CONSTANT                                    |
  |                                                               |
  |   Alternative (older) statement:                              |
  |   "The mass of a gas dissolved in a given volume of liquid     |
  |    at constant temperature is proportional to the pressure     |
  |    of the gas above the liquid."                              |
  |                                                               |
  +---------------------------------------------------------------+
```

Rearranged:

```
                    p
        x     =   ------           so:   HIGH K(H)  ->  LOW solubility
                   K(H)                  LOW  K(H)  ->  HIGH solubility
```

## What K(H) actually means

```
  K(H) has the UNIT OF PRESSURE  (bar , atm , Pa , kbar).

  K(H) is DIFFERENT for every gas and for every temperature.

  K(H) is a measure of how BADLY the gas wants to stay OUT of the liquid.
        Big K(H)  =  the gas hates the liquid  =  poor solubility.
```

```
  +----------+-----------------------+------------------------------+
  |  GAS     |  K(H) at 293 K        |  MEANING                     |
  +----------+-----------------------+------------------------------+
  |  He      |  144.97  kbar         |  very large -> very insoluble|
  |  N2      |   76.48  kbar         |  large -> poorly soluble     |
  |  O2      |   34.86  kbar         |  smaller -> more soluble     |
  |          |                       |  than N2                     |
  |  CO2     |    1.67  kbar         |  small -> quite soluble      |
  +----------+-----------------------+------------------------------+

  Order of solubility in water:   CO2  >  O2  >  N2  >  He
```

## Effect of temperature on the solubility of a gas

```
  Dissolving a gas in a liquid is always EXOTHERMIC
  (the gas loses freedom, energy is released).

           GAS  +  LIQUID  <-->  SOLUTION  +  HEAT

  Heating pushes the equilibrium BACKWARD.

  ==>  SOLUBILITY OF A GAS DECREASES AS TEMPERATURE INCREASES
  ==>  K(H) INCREASES AS TEMPERATURE INCREASES
```

Everyday proof: bubbles appear in a pan of water long before it boils —
the dissolved air is being driven out by heating. Warm soda goes flat faster.
And this is why aquatic animals are more comfortable in cold water: cold
water holds more dissolved oxygen.

## The three applications you MUST be able to write

```
  1.  SCUBA DIVING and "the BENDS"
      ---------------------------------------------------------------
      A diver deep under water breathes air at HIGH pressure.
      By Henry's law, more N2 dissolves in the blood.
      If the diver comes up too fast, the pressure drops suddenly,
      the dissolved N2 comes out as BUBBLES in the blood capillaries,
      blocking them. This painful, dangerous condition is called
      BENDS (decompression sickness).
      REMEDY: divers use tanks filled with air DILUTED WITH HELIUM
      (about 11.7% He, 56.2% N2, 32.1% O2), because helium is far
      less soluble in blood.

  2.  SOFT DRINKS / SODA WATER
      ---------------------------------------------------------------
      Soda bottles are sealed under HIGH CO2 pressure so that a large
      amount of CO2 dissolves. When you open the bottle, the pressure
      above the liquid falls to atmospheric pressure, solubility drops,
      and the excess CO2 fizzes out.

  3.  HIGH ALTITUDE SICKNESS (ANOXIA)
      ---------------------------------------------------------------
      At high altitude the partial pressure of oxygen is LOW, so less
      O2 dissolves in the blood. Climbers become weak, cannot think
      clearly and feel breathless. This is called ANOXIA.
```

## Worked example 9 — Henry's law numerical

**Q. Henry's law constant for CO2 in water is 1.67 x 10^8 Pa at 298 K.
Calculate the quantity of CO2 in 500 mL of soda water when packed under
2.5 atm CO2 pressure at 298 K. (1 atm = 1.01325 x 10^5 Pa)**

```
  STEP 1  Convert the pressure to pascal.

          p  =  2.5  x  1.01325 x 10^5   =  2.533 x 10^5  Pa

  STEP 2  Use Henry's law to get the mole fraction of CO2.

                    p            2.533 x 10^5
          x   =  --------  =  -------------------  =  1.517 x 10^-3
                   K(H)         1.67 x 10^8

  STEP 3  Moles of water in 500 mL.
          (500 mL of water weighs 500 g)

                         500
          n(water)  =  --------  =  27.78 mol
                          18

  STEP 4  Because x(CO2) is tiny,

                     n(CO2)              n(CO2)
          x  =  ----------------  is about  ---------
                 n(CO2)+n(water)          n(water)

          n(CO2)  =  1.517 x 10^-3  x  27.78  =  0.0421 mol

  STEP 5  mass  =  moles  x  molar mass

                =  0.0421  x  44   =   1.85  g

  ANSWER:  about 1.85 g of CO2
```

## Worked example 10

**Q. N2 gas is bubbled through water at 293 K. If the partial pressure of N2
is 0.987 bar and K(H) for N2 at 293 K is 76.48 kbar, how many millimoles of
N2 dissolve in 1 litre of water?**

```
  STEP 1  K(H)  =  76.48 kbar  =  76 480 bar

  STEP 2         p          0.987
          x  = -------  =  ---------  =  1.29 x 10^-5
                K(H)        76480

  STEP 3  1 L of water  =  1000 g  ->  1000/18  =  55.5 mol

  STEP 4  n(N2)  =  1.29 x 10^-5  x  55.5  =  7.16 x 10^-4 mol

                 =  0.716  millimole

  ANSWER:  about 0.72 mmol
```

> **TRAP:** K(H) is given in **kbar** here. 1 kbar = 1000 bar. Forgetting
> the "k" makes your answer 1000 times too big.

# TOPIC 11 — Vapour pressure, and RAOULT'S LAW for two volatile liquids

## What is vapour pressure?

```
  Put a liquid in a closed container. Some molecules escape into the
  space above (evaporate); some come back (condense).
  At equilibrium, the pressure exerted by the vapour is the

              VAPOUR PRESSURE of the liquid.

  It depends only on the LIQUID and the TEMPERATURE.
  A liquid BOILS when its vapour pressure equals the outside pressure.
```

## Raoult's law — statement (for volatile components)

```
  +---------------------------------------------------------------+
  |                                                               |
  |   RAOULT'S LAW                                                |
  |                                                               |
  |   "For a solution of volatile liquids, the partial vapour      |
  |    pressure of each component is directly proportional to      |
  |    its mole fraction in the solution."                        |
  |                                                               |
  |         p(A)   =   p0(A)  .  x(A)                             |
  |         p(B)   =   p0(B)  .  x(B)                             |
  |                                                               |
  |   By Dalton's law of partial pressures:                        |
  |                                                               |
  |         p(total)  =  p(A)  +  p(B)                            |
  |                   =  p0(A) x(A)  +  p0(B) x(B)                |
  |                                                               |
  |   Since  x(A) = 1 - x(B) :                                    |
  |                                                               |
  |         p(total)  =  p0(A)  +  [ p0(B) - p0(A) ]  x(B)        |
  |                                                               |
  |         ( a STRAIGHT LINE in x(B) )                           |
  |                                                               |
  |   p0(A) = vapour pressure of PURE A                           |
  |   p(A)  = partial pressure of A over the solution             |
  |                                                               |
  +---------------------------------------------------------------+
```

## Composition of the VAPOUR

The vapour is always **richer in the more volatile component**.

```
  +---------------------------------------------------------------+
  |                                                               |
  |                     p(A)                p(B)                  |
  |        y(A)  =  ------------    y(B) = ------------           |
  |                   p(total)              p(total)              |
  |                                                               |
  |   y  =  mole fraction in the VAPOUR                           |
  |   x  =  mole fraction in the LIQUID                           |
  |                                                               |
  +---------------------------------------------------------------+
```

## Worked example 11

**Q. At 20 C the vapour pressure of pure benzene is 75 mm Hg and that of pure
toluene is 22 mm Hg. Calculate the total vapour pressure and the composition
of the vapour for a solution containing 1 mole of benzene and 1 mole of
toluene.**

```
  STEP 1  Mole fractions in the LIQUID.

          total moles  =  1 + 1  =  2

                     1                       1
          x(benz) = ---- = 0.5    x(tol) = ---- = 0.5
                     2                       2

  STEP 2  Partial pressures (Raoult's law).

          p(benz)  =  75  x  0.5   =   37.5 mm Hg
          p(tol)   =  22  x  0.5   =   11.0 mm Hg

  STEP 3  Total vapour pressure.

          p(total) =  37.5  +  11.0  =  48.5 mm Hg

  STEP 4  Composition of the VAPOUR.

                      37.5
          y(benz) = --------  =  0.773
                      48.5

                      11.0
          y(tol)  = --------  =  0.227
                      48.5

  NOTICE:  the liquid was 50 % benzene, but the vapour is 77.3 % benzene.
           The vapour is RICHER in the MORE VOLATILE liquid.
           (Benzene is more volatile because 75 > 22.)
```

# TOPIC 12 — Raoult's law for a NON-VOLATILE solute (and the Henry link)

If the solute is **non-volatile** (sugar, glucose, urea, NaCl — they do not
evaporate), then **only the solvent contributes vapour**.

```
  +---------------------------------------------------------------+
  |                                                               |
  |    p(solution)   =   p0(solvent)  .  x(solvent)               |
  |                                                               |
  |    Since x(solvent) is always LESS than 1,                    |
  |    p(solution)  is always LESS than  p0(solvent).             |
  |                                                               |
  |    ADDING A NON-VOLATILE SOLUTE ALWAYS LOWERS THE             |
  |    VAPOUR PRESSURE.                                           |
  |                                                               |
  +---------------------------------------------------------------+
```

**Why?** Solute particles sit on the surface and physically block solvent
molecules from escaping. Fewer molecules escape, so the vapour pressure falls.

```
   PURE SOLVENT                      SOLUTION
   surface is all solvent            surface is partly blocked by solute

     ^  ^  ^  ^  ^  ^                    ^     ^        ^
     |  |  |  |  |  |                    |     |        |
   ================                  ================
   o  o  o  o  o  o  o               o  X  o  o  X  o  o
   o  o  o  o  o  o  o               o  o  X  o  o  o  X
   o  o  o  o  o  o  o               X  o  o  X  o  o  o

   o = solvent molecule              X = non-volatile solute
   MANY escape -> high VP            FEWER escape -> LOWER VP
```

## The relationship between Raoult's law and Henry's law

This is a very commonly asked 2-mark question.

```
  +---------------------------------------------------------------+
  |                                                               |
  |   RAOULT :   p  =  p0  .  x                                   |
  |   HENRY  :   p  =  K(H)  .  x                                 |
  |                                                               |
  |   BOTH say:  partial pressure is PROPORTIONAL to the mole      |
  |              fraction in solution.                            |
  |                                                               |
  |   They are the SAME EQUATION with a different constant.        |
  |                                                               |
  |   RAOULT'S LAW IS A SPECIAL CASE OF HENRY'S LAW               |
  |   in which  K(H)  becomes equal to  p0  ,                     |
  |   i.e. when the solute is VOLATILE and behaves like the        |
  |   solvent (an ideal solution).                                |
  |                                                               |
  +---------------------------------------------------------------+
```

# TOPIC 13 — IDEAL and NON-IDEAL solutions

## Ideal solutions

```
  An IDEAL SOLUTION is one that obeys RAOULT'S LAW over the
  ENTIRE range of concentration.

  Its three conditions:

     1.   p(A) = p0(A) x(A)     and    p(B) = p0(B) x(B)   for ALL x

     2.   delta H (mixing)  =  0      no heat given out or taken in

     3.   delta V (mixing)  =  0      volumes are exactly additive
                                      (50 mL + 50 mL = 100 mL)

  WHY?  Because the A-B attraction is exactly the SAME strength as
        the A-A and B-B attractions.

              A - B    =    A - A    =    B - B
```

```
  EXAMPLES OF IDEAL SOLUTIONS
     benzene       +  toluene
     n-hexane      +  n-heptane
     bromoethane   +  chloroethane
     chlorobenzene +  bromobenzene
     carbon tetrachloride + silicon tetrachloride
```

## The ideal-solution graph (learn to draw this)

```
   V   |
   A   |                                              o  p0(A)
   P   |                                       . '
   O   |  p0(B) o                       . '     TOTAL (a STRAIGHT line)
   U   |        |  ' .           . '          |
   R   |        |      ' .  . '               |
       |        |        . o .                |
   P   |        |   . '       ' .             |
   R   |        | '   p(A)        ' .  p(B)   |
   E   |        o                     ' .     |
   S   |      .'                          ' . |
   S   |    .'                                o
   U   |  .'                                    ' .
   R   o '                                          ' o
   E   +--------------------------------------------------->
      x(A) = 0                                     x(A) = 1
      x(B) = 1                                     x(B) = 0

   p(A) rises as a STRAIGHT line from 0 up to p0(A)
   p(B) falls as a STRAIGHT line from p0(B) down to 0
   p(total) is the STRAIGHT LINE joining p0(B) to p0(A)

   >>> ALL THREE LINES ARE STRAIGHT. That is what "ideal" means. <<<
```

## Non-ideal solutions

```
  A NON-IDEAL SOLUTION does NOT obey Raoult's law over the whole range.
  Its total vapour pressure curve BENDS away from the straight line.

  There are two ways to bend:  UP (positive) or DOWN (negative).
```

## POSITIVE DEVIATION

```
  +---------------------------------------------------------------+
  |                                                               |
  |  OBSERVED vapour pressure is HIGHER than Raoult predicts.      |
  |                                                               |
  |  CAUSE:  the A - B attraction is WEAKER than A - A and B - B.  |
  |          Molecules escape MORE easily.                        |
  |                                                               |
  |          A - B   <   A - A   ,   B - B                        |
  |                                                               |
  |  delta H (mixing)  is  POSITIVE   (absorbs heat, cools down)   |
  |  delta V (mixing)  is  POSITIVE   (volume increases)           |
  |                                                               |
  |  EXAMPLES:                                                    |
  |     ethanol  +  water                                         |
  |     ethanol  +  acetone                                       |
  |     acetone  +  carbon disulphide                             |
  |     carbon tetrachloride  +  chloroform                       |
  |     acetone  +  benzene                                       |
  |                                                               |
  +---------------------------------------------------------------+
```

Why ethanol + water? Pure ethanol molecules are held by strong hydrogen
bonds to each other. Water molecules break those ethanol-ethanol hydrogen
bonds and do not replace them with anything as strong. So ethanol escapes
more easily than expected.

```
   POSITIVE DEVIATION GRAPH  -  the curve BULGES UPWARD

   V |
   A |                       _ - - - _                 o  p0(A)
   P |                  _ -           - _        . '
   O |             _ -                     - _'
   U |  p0(B) o - '        OBSERVED           ' o
   R |        |      . '                      |
     |        |  . '   IDEAL (dashed straight)|
   P |        o '                             |
   R |       .                                |
   E |     .                                  |
   S |   .                                    |
   S | .                                      |
   U o                                        |
   R +----------------------------------------o------->
   E  x(A)=0                              x(A)=1

   The solid curve (observed) lies ABOVE the dashed straight line
   (ideal Raoult prediction) at every intermediate composition.
```

## NEGATIVE DEVIATION

```
  +---------------------------------------------------------------+
  |                                                               |
  |  OBSERVED vapour pressure is LOWER than Raoult predicts.       |
  |                                                               |
  |  CAUSE:  the A - B attraction is STRONGER than A - A and B - B |
  |          (usually a NEW hydrogen bond forms).                 |
  |          Molecules are held back and escape LESS easily.      |
  |                                                               |
  |          A - B   >   A - A   ,   B - B                        |
  |                                                               |
  |  delta H (mixing)  is  NEGATIVE   (gives out heat, warms up)   |
  |  delta V (mixing)  is  NEGATIVE   (volume decreases)           |
  |                                                               |
  |  EXAMPLES:                                                    |
  |     chloroform  +  acetone      (new H-bond forms)            |
  |     nitric acid  +  water                                     |
  |     hydrochloric acid  +  water                               |
  |     phenol  +  aniline                                        |
  |     chloroform  +  benzene                                    |
  |                                                               |
  +---------------------------------------------------------------+
```

The classic: **chloroform + acetone**. The lone H on chloroform forms a
hydrogen bond with the O of acetone — a bond that did not exist in either
pure liquid. The molecules now cling together, so fewer escape.

```
        Cl                        CH3
         \                        /
    Cl -- C -- H  . . . . .  O = C            <-- NEW hydrogen bond
         /                        \
        Cl                        CH3
```

```
   NEGATIVE DEVIATION GRAPH  -  the curve SAGS DOWNWARD

   V |
   A |                                              o  p0(A)
   P |                                       . '
   O |  p0(B) o                       . '   IDEAL (dashed straight)
   U |        | ' .            . '
   R |        |     ' _     . '
     |        |         ' - _ '
   P |        |       - _      OBSERVED
   R |        |            ' - _
   E |        |                   ' - _
   S |        |                         ' - _
   S |        |                               ' -
   U |        |                                    ' .
   R |        o                                        o
   E +------------------------------------------------------>
      x(A)=0                                       x(A)=1

   The solid curve (observed) lies BELOW the dashed straight line.
```

## The comparison table (write this in the exam)

```
  +--------------------+---------------------+---------------------+
  |  PROPERTY          |  POSITIVE DEVIATION |  NEGATIVE DEVIATION |
  +--------------------+---------------------+---------------------+
  |  A-B force vs      |  WEAKER             |  STRONGER           |
  |  A-A and B-B       |                     |                     |
  |  Observed VP       |  HIGHER than Raoult |  LOWER than Raoult  |
  |  delta H (mixing)  |  POSITIVE (+)       |  NEGATIVE (-)       |
  |  delta V (mixing)  |  POSITIVE (+)       |  NEGATIVE (-)       |
  |  Boiling point     |  LOWER than expected|  HIGHER than exp.   |
  |  Type of azeotrope |  MINIMUM boiling    |  MAXIMUM boiling    |
  |  Example           |  ethanol + water    | chloroform + acetone|
  +--------------------+---------------------+---------------------+
```

> **TRAP:** high vapour pressure means the liquid boils EASILY, so a
> **positive** deviation gives a **LOWER** boiling point. Students mix up
> "positive" with "higher boiling point". Remember: **more vapour = boils
> sooner.**

# TOPIC 14 — AZEOTROPES

```
  AZEOTROPE (constant boiling mixture)
  =  a binary mixture that boils at a CONSTANT temperature and
     distils over WITHOUT any change in composition
     (the vapour has the SAME composition as the liquid).

  ==>  AN AZEOTROPE CANNOT BE SEPARATED BY FRACTIONAL DISTILLATION.
```

```
  +------------------------+--------------------------------------+
  |  MINIMUM BOILING       |  MAXIMUM BOILING                     |
  |  AZEOTROPE             |  AZEOTROPE                           |
  +------------------------+--------------------------------------+
  |  formed by solutions   |  formed by solutions showing a large |
  |  showing a large       |  NEGATIVE deviation                  |
  |  POSITIVE deviation    |                                      |
  |                        |                                      |
  |  Boils at a temperature|  Boils at a temperature HIGHER than  |
  |  LOWER than either     |  either pure component               |
  |  pure component        |                                      |
  |                        |                                      |
  |  EXAMPLE:              |  EXAMPLE:                            |
  |  ETHANOL + WATER       |  NITRIC ACID + WATER                 |
  |  95 % ethanol by volume|  68 % HNO3 by mass                   |
  |  boils at 351.1 K      |  boils at 393.5 K                    |
  +------------------------+--------------------------------------+
```

**This is why you can never get 100% pure ethanol by simple distillation.**
Once you reach 95% ethanol, the mixture boils as one substance and the
composition stops changing. That 95% mixture is called **rectified spirit**.

```
   MEMORY LINK:

     POSITIVE deviation  ->  MORE vapour  ->  boils EASILY
                         ->  MINIMUM boiling azeotrope
                         ->  ethanol + water

     NEGATIVE deviation  ->  LESS vapour  ->  boils with DIFFICULTY
                         ->  MAXIMUM boiling azeotrope
                         ->  nitric acid + water
```

# TOPIC 15 — COLLIGATIVE PROPERTIES: the big idea

```
  +---------------------------------------------------------------+
  |                                                               |
  |   COLLIGATIVE PROPERTY                                        |
  |   = a property of a solution that depends ONLY on the         |
  |     NUMBER of solute particles present,                       |
  |     and NOT on the NATURE (identity, size, mass) of those     |
  |     particles.                                                |
  |                                                               |
  |   ("colligative" comes from a Latin word meaning              |
  |    "depending on the collection / number")                    |
  |                                                               |
  +---------------------------------------------------------------+
```

1 mole of glucose, 1 mole of urea and 1 mole of sucrose in 1 kg of water
all lower the freezing point by **exactly the same amount**, even though
their molar masses are 180, 60 and 342. Only the NUMBER matters.

```
  THE FOUR COLLIGATIVE PROPERTIES

     1.  RELATIVE LOWERING OF VAPOUR PRESSURE
     2.  ELEVATION OF BOILING POINT
     3.  DEPRESSION OF FREEZING POINT
     4.  OSMOTIC PRESSURE

  MEMORY:  "V B F O"  ->  "Very Big Fat Onion"
```

**Every one of them can be used to find the MOLAR MASS of an unknown solute.**
That is what the exam actually asks for.

```
   THE ONE PICTURE THAT EXPLAINS THREE OF THEM

   P  |                             LIQUID
   R  |                                        . solvent
   E  |                              .  '   .' solution
   S  |                        .  '     .'
   S  |   1 atm ---------------o-------o----------------
   U  |               .  '   .'        |
   R  |          . '      .'           |
   E  |       .'       .'              |
      |     .'      .'                 |
      +----o-------o-------------------+------------------>
        Tf'    Tf(0)                Tb(0)  Tb'
           TEMPERATURE

    The solution curve lies BELOW the pure solvent curve everywhere,
    because the solute lowered the vapour pressure.

    ->  to reach 1 atm you must go to a HIGHER temperature
              ->  BOILING POINT RISES     ( delta Tb )

    ->  the solution curve meets the solid curve at a LOWER temperature
              ->  FREEZING POINT FALLS    ( delta Tf )
```

# TOPIC 16 — Colligative property 1: RELATIVE LOWERING OF VAPOUR PRESSURE

```
  +---------------------------------------------------------------+
  |                                                               |
  |   LOWERING of vapour pressure        =   p0  -  p             |
  |                                                               |
  |                                          p0  -  p             |
  |   RELATIVE LOWERING of vapour pr.  =  --------------          |
  |                                             p0                |
  |                                                               |
  |   RAOULT'S LAW (second form):                                 |
  |                                                               |
  |        p0  -  p                                               |
  |      -------------   =   x2   =   mole fraction of SOLUTE     |
  |            p0                                                 |
  |                                                               |
  |                                       n2                      |
  |                             =   -------------                 |
  |                                   n1  +  n2                   |
  |                                                               |
  |   For a DILUTE solution  n2 is very small compared with n1 :  |
  |                                                               |
  |        p0  -  p            n2         w2   x   M1             |
  |      -------------   =   ------   =  ---------------          |
  |            p0              n1         M2   x   w1             |
  |                                                               |
  |   which rearranges to the MOLAR MASS formula:                 |
  |                                                               |
  |                    w2  x  M1  x  p0                           |
  |        M2   =   --------------------------                    |
  |                    w1  x  ( p0  -  p )                        |
  |                                                               |
  |   1 = solvent , 2 = solute                                    |
  |   w = mass in grams ,  M = molar mass                         |
  |                                                               |
  +---------------------------------------------------------------+
```

Relative lowering has **no unit** (it is a ratio of two pressures).

## Worked example 13

**Q. The vapour pressure of pure water at 293 K is 17.535 mm Hg. Calculate
the vapour pressure at 293 K of a solution made by dissolving 25 g of glucose
(M = 180) in 450 g of water.**

```
  STEP 1                     25
          n2 (glucose)  =  ------  =  0.1389 mol
                            180

                            450
          n1 (water)    =  ------  =  25.00 mol
                             18

  STEP 2  Mole fraction of the SOLUTE.

                       0.1389             0.1389
          x2  =  ------------------  =  ----------  =  0.005525
                  25.00  +  0.1389        25.1389

  STEP 3  Apply Raoult's law.

          p0  -  p
        -------------  =  0.005525
             p0

          p0  -  p  =  17.535  x  0.005525  =  0.0969 mm Hg

  STEP 4  p  =  17.535  -  0.097   =   17.438  mm Hg

  ANSWER:  17.44 mm Hg
```

## Worked example 14 — finding the molar mass

**Q. The vapour pressure of pure benzene at a certain temperature is
0.850 bar. When 0.5 g of a non-volatile, non-electrolyte solid is added to
39.0 g of benzene (M = 78 g/mol), the vapour pressure of the solution becomes
0.845 bar. Calculate the molar mass of the solid.**

```
  STEP 1  p0  -  p  =  0.850  -  0.845  =  0.005 bar

  STEP 2   p0 - p        0.005
          ---------  =  --------  =  5.882 x 10^-3
             p0          0.850

  STEP 3  For a dilute solution,

           p0 - p          n2         w2 / M2
          ---------  =   ------  =  -----------
             p0            n1        w1 / M1

  STEP 4  n1 (benzene)  =  39.0 / 78  =  0.500 mol

          n2  =  5.882 x 10^-3  x  0.500  =  2.941 x 10^-3 mol

  STEP 5                w2           0.5
          M2   =   ----------  =  -------------
                       n2          2.941x10^-3

               =   170  g/mol

  ANSWER:  170 g/mol
```

> **TRAP:** the exact form uses `x2 = n2/(n1+n2)`. The dilute approximation
> uses `n2/n1`. In the exam either is accepted for dilute solutions, but if
> the solute amount is LARGE you must use the exact form.

# TOPIC 17 — Colligative property 2: ELEVATION OF BOILING POINT

```
  A liquid BOILS when its vapour pressure equals atmospheric pressure.
  A non-volatile solute LOWERS the vapour pressure.
  So you must HEAT IT MORE to get back to atmospheric pressure.

  ==>  THE BOILING POINT RISES.
```

```
  +---------------------------------------------------------------+
  |                                                               |
  |     delta Tb   =   Tb   -   Tb(0)                             |
  |                                                               |
  |     delta Tb   =   Kb  x  m                                   |
  |                                                               |
  |     Kb = MOLAL ELEVATION CONSTANT                             |
  |        = EBULLIOSCOPIC CONSTANT                               |
  |        unit:  K kg / mol                                      |
  |                                                               |
  |     Substituting  m = (w2 x 1000)/(M2 x w1) :                 |
  |                                                               |
  |                        1000  x  Kb  x  w2                     |
  |          M2    =   ----------------------------               |
  |                        delta Tb   x   w1                      |
  |                                                               |
  |     w1 = mass of SOLVENT in grams                             |
  |     w2 = mass of SOLUTE in grams                              |
  |                                                               |
  |     Kb from thermodynamics:                                   |
  |                                                               |
  |                    R  x  M1  x  Tb(0)^2                       |
  |          Kb   =   --------------------------                  |
  |                    1000  x  delta H(vap)                      |
  |                                                               |
  +---------------------------------------------------------------+
```

**Meaning of Kb:** it is the elevation of boiling point produced when
**1 mole** of a solute is dissolved in **1 kg** of that solvent.

```
  +------------------+----------+----------+---------------------+
  |  SOLVENT         |   Kb     |   Kf     |  b.p. / f.p.        |
  |                  | K kg/mol | K kg/mol |                     |
  +------------------+----------+----------+---------------------+
  |  Water           |   0.52   |   1.86   |  373.15 / 273.15 K  |
  |  Benzene         |   2.53   |   5.12   |  353.23 / 278.65 K  |
  |  Acetic acid     |   3.07   |   3.90   |  391.1  / 289.6  K  |
  |  Chloroform      |   3.63   |   4.79   |  334.4  / 209.6  K  |
  |  Carbon          |   5.03   |  29.8    |  349.9  / 250.5  K  |
  |  tetrachloride   |          |          |                     |
  |  Camphor         |   5.95   |  39.7    |  481.2  / 452.0  K  |
  +------------------+----------+----------+---------------------+

  WATER:   Kb = 0.52   ,   Kf = 1.86     <-- memorise these two
```

## Worked example 15

**Q. 18 g of glucose (M = 180) is dissolved in 1 kg of water. At what
temperature will the solution boil? Kb for water = 0.52 K kg/mol, and water
boils at 373.15 K.**

```
  STEP 1                     18
          moles of glucose = -----  =  0.100 mol
                             180

  STEP 2                0.100
          molality  =  --------  =  0.100  mol/kg
                          1

  STEP 3  delta Tb  =  Kb  x  m  =  0.52  x  0.100  =  0.052 K

  STEP 4  boiling point  =  373.15  +  0.052  =  373.202 K

  ANSWER:  373.20 K   (that is 100.05 C - a very small rise)
```

## Worked example 16 — molar mass from boiling point

**Q. The boiling point of benzene is 353.23 K. When 1.80 g of a non-volatile
solute is dissolved in 90 g of benzene, the boiling point rises to 354.11 K.
Calculate the molar mass of the solute. Kb for benzene = 2.53 K kg/mol.**

```
  STEP 1  delta Tb  =  354.11  -  353.23  =  0.88 K

  STEP 2  Use the molar mass formula.

                     1000  x  Kb  x  w2
          M2   =   ------------------------
                     delta Tb   x   w1

                     1000  x  2.53  x  1.80
               =   ----------------------------
                        0.88   x   90

  STEP 3  numerator    =  1000 x 2.53 x 1.80  =  4554
          denominator  =  0.88  x  90         =  79.2

  STEP 4               4554
          M2   =   -----------  =  57.5   g/mol
                       79.2

  ANSWER:  about 58 g/mol
```

> **TRAP:** `w1` is the mass of the **SOLVENT** in **GRAMS** (90 g here),
> not in kg, because the formula already has the 1000 in it.

# TOPIC 18 — Colligative property 3: DEPRESSION OF FREEZING POINT

```
  A liquid FREEZES at the temperature where the vapour pressure of the
  liquid equals the vapour pressure of the solid.
  A solute LOWERS the vapour pressure of the liquid.
  So that meeting point moves to a LOWER temperature.

  ==>  THE FREEZING POINT FALLS.
```

```
  +---------------------------------------------------------------+
  |                                                               |
  |     delta Tf   =   Tf(0)   -   Tf                             |
  |                                                               |
  |     delta Tf   =   Kf  x  m                                   |
  |                                                               |
  |     Kf = MOLAL DEPRESSION CONSTANT                            |
  |        = CRYOSCOPIC CONSTANT                                  |
  |        unit:  K kg / mol                                      |
  |                                                               |
  |                        1000  x  Kf  x  w2                     |
  |          M2    =   ----------------------------               |
  |                        delta Tf   x   w1                      |
  |                                                               |
  |                    R  x  M1  x  Tf(0)^2                       |
  |          Kf   =   --------------------------                  |
  |                    1000  x  delta H(fus)                      |
  |                                                               |
  +---------------------------------------------------------------+
```

**Real life:** salt is spread on icy roads because the salt solution freezes
below 0 C, so the ice melts. Ethylene glycol is added to car radiators as
antifreeze for the same reason (and it also raises the boiling point).

## Worked example 17

**Q. 45 g of ethylene glycol (C2H6O2, M = 62 g/mol) is mixed with 600 g of
water. Calculate (a) the depression of freezing point, and (b) the freezing
point of the solution. Kf for water = 1.86 K kg/mol; water freezes at 273.15 K.**

```
  STEP 1                           45
          moles of glycol  =  ---------  =  0.7258 mol
                                  62

  STEP 2  mass of solvent  =  600 g  =  0.600 kg

                        0.7258
          molality  =  ---------  =  1.2097  mol/kg
                         0.600

  STEP 3  delta Tf  =  Kf  x  m

                    =  1.86  x  1.2097   =   2.25  K

  STEP 4  freezing point  =  273.15  -  2.25  =  270.90 K

  ANSWER:  (a) 2.25 K      (b) 270.90 K   (about -2.25 C)
```

## Worked example 18 — molar mass from freezing point

**Q. 1.00 g of a non-electrolyte solute dissolved in 50 g of benzene lowers

Find the molar mass of the solute.**

```
                     1000  x  Kf  x  w2
          M2   =   ------------------------
                     delta Tf   x   w1

               =   ---------------------------
                        0.40   x   50

                        5120
               =   --------------   =   256  g/mol
                        20

```

# TOPIC 19 — Colligative property 4: OSMOSIS AND OSMOTIC PRESSURE

## What is osmosis?

```
  SEMIPERMEABLE MEMBRANE (SPM)
     = a membrane with holes big enough to let SOLVENT molecules
       through, but too small for SOLUTE molecules.
     Examples: parchment paper, animal bladder, cell membrane,
               copper ferrocyanide  Cu2[Fe(CN)6]  (artificial SPM)

  OSMOSIS
     = the spontaneous flow of SOLVENT molecules through a
       semipermeable membrane FROM a solution of LOWER concentration
       TO a solution of HIGHER concentration
       (i.e. from pure solvent into the solution).

  OSMOTIC PRESSURE  (pi)
     = the EXTRA pressure that must be applied ON THE SOLUTION side
       to JUST STOP osmosis.
```

## The diagram (draw this in the exam)

```
                        applied pressure = pi
                                 | |
                                 | |
                                 v v
                            +---------+
                            |         |
                            |         |
       +---------+          |  ~~~~~  |  <-- level RISES here
       |         |          |  SUGAR  |
       |  PURE   |          | SOLUTION|
       |  WATER  |          |         |
       |  ~~~~~  |          |         |
       |         |          |         |
       |         |          |         |
       +----+----+----------+----+----+
            |     ||     ||      |
            |     || SPM ||      |
            +=====++=====++======+
                    ^
                    |
       water molecules move THIS WAY  ------->
       (from PURE WATER into the SOLUTION)

   The solution side rises until the extra weight of liquid
   exactly balances the tendency of water to enter.
   That balancing pressure IS the osmotic pressure, pi.
```

## The formula

```
  +---------------------------------------------------------------+
  |                                                               |
  |     pi  =  C R T                                              |
  |                                                               |
  |                n2                                             |
  |     pi  =   ------- R T          (C = molarity = n2 / V)      |
  |                V                                              |
  |                                                               |
  |     pi V  =  n2 R T                                           |
  |                                                               |
  |     Substituting  n2 = w2 / M2 :                              |
  |                                                               |
  |                   w2  R  T                                    |
  |         M2   =  --------------                                |
  |                   pi   x   V                                  |
  |                                                               |
  |     R  =  0.0821 L atm / K mol                                |
  |        =  0.083  L bar / K mol                                |
  |        =  8.314  J / K mol                                    |
  |                                                               |
  |     T must be in KELVIN.  V must be in LITRES.                |
  |                                                               |
  +---------------------------------------------------------------+
```

## Why osmotic pressure is the BEST method for molar mass

```
  1.  It can be measured at ROOM TEMPERATURE  -  no heating needed,
      so delicate substances (proteins, polymers, blood pigments)
      are NOT DESTROYED.

  2.  The magnitude of pi is LARGE and easy to measure accurately,
      even for a very dilute solution.
      (A solution that raises the boiling point by only 0.001 K can
      have an osmotic pressure of several atmospheres.)

  3.  It uses MOLARITY, so the measurement is done in one step.

  ==>  OSMOTIC PRESSURE IS USED FOR BIOMOLECULES AND POLYMERS
       OF VERY HIGH MOLAR MASS.
```

## Worked example 19

**Q. Calculate the osmotic pressure at 300 K of a solution containing 36 g of
glucose (M = 180) per litre of solution. R = 0.0821 L atm / K mol.**

```
  STEP 1                       36
          moles of glucose = ------  =  0.200 mol
                              180

  STEP 2                0.200
          C   =    -------------  =  0.200  mol/L
                       1.000

  STEP 3  pi  =  C R T

              =  0.200  x  0.0821  x  300

              =  4.926  atm

  ANSWER:  4.93 atm
```

## Worked example 20 — molar mass of a protein

**Q. 200 cm3 of an aqueous solution of a protein contains 1.26 g of the
protein. The osmotic pressure of the solution at 300 K is 2.57 x 10^-3 bar.
Calculate the molar mass of the protein. R = 0.083 L bar / K mol.**

```
  STEP 1  V  =  200 cm3  =  0.200 L
          w2 =  1.26 g
          pi =  2.57 x 10^-3 bar
          T  =  300 K

  STEP 2               w2  R  T
          M2   =   ----------------
                       pi  x  V

                    1.26  x  0.083  x  300
               =  ----------------------------
                   ( 2.57 x 10^-3 )  x  0.200

  STEP 3  numerator    =  1.26 x 0.083 x 300   =  31.374
          denominator  =  2.57x10^-3 x 0.200   =  5.14 x 10^-4

  STEP 4               31.374
          M2   =   -------------   =   6.10 x 10^4   g/mol
                    5.14x10^-4

  ANSWER:  about 61 000 g/mol
```

> **TRAP:** if `pi` is given in **bar**, use R = 0.083. If in **atm**, use
> R = 0.0821. Mixing them makes your answer wrong by about 1.3%, and in a
> tough correction that costs a mark.

# TOPIC 20 — Isotonic solutions, and REVERSE OSMOSIS

## The three "-tonic" words

```
  +--------------+------------------------------------------------+
  |  ISOTONIC    |  Two solutions having the SAME osmotic pressure|
  |              |  at the same temperature.                      |
  |              |  NO osmosis happens between them.              |
  |              |  Example: 0.9 % w/v NaCl (normal saline) is    |
  |              |  isotonic with human blood cells. This is why  |
  |              |  it is used for intravenous drips.             |
  +--------------+------------------------------------------------+
  |  HYPERTONIC  |  A solution with HIGHER osmotic pressure than   |
  |              |  the one it is compared with.                  |
  |              |  Put a cell in it -> water flows OUT ->         |
  |              |  the cell SHRINKS (plasmolysis / crenation).   |
  |              |  This is why raw mango shrivels in brine and   |
  |              |  why salt/sugar preserves food.                |
  +--------------+------------------------------------------------+
  |  HYPOTONIC   |  A solution with LOWER osmotic pressure.        |
  |              |  Put a cell in it -> water flows IN ->          |
  |              |  the cell SWELLS and may BURST (haemolysis).   |
  |              |  This is why a dried raisin swells in water.   |
  +--------------+------------------------------------------------+
```

```
  FOR TWO ISOTONIC SOLUTIONS:      pi(1)  =  pi(2)

                                   C1 R T  =  C2 R T

                                   C1      =  C2

              w1                 w2
          ----------   =    -----------          (same volume)
           M1  x  V           M2  x  V
```

## REVERSE OSMOSIS

```
  Normal osmosis:  solvent moves  PURE SOLVENT  ->  SOLUTION

  If you apply a pressure on the solution side that is GREATER than
  its osmotic pressure, the flow REVERSES:

                   SOLUTION  ->  PURE SOLVENT

  This is REVERSE OSMOSIS.

  CONDITION:   applied pressure   >   osmotic pressure
```

```
        HUGE applied pressure (more than about 30 atm)
                          | |
                          v v
                     +---------+
                     |  SEA    |
                     | WATER   |
       +---------+   | (salty) |
       |  PURE   |   |         |
       | WATER   |   |         |
       | comes   |   |         |
       | out     |   |         |
       +----+----+---+----+----+
            |    || SPM ||    |
            +====++=====++====+
                    ^
                    |
      PURE WATER is squeezed OUT of the sea water,
      leaving the salt behind.     <------- flow direction

      MEMBRANE USED:  cellulose acetate film
      (permeable to water, impermeable to dissolved salts)
```

```
  MAIN USE:  DESALINATION OF SEA WATER
             - converting salty sea water into drinking water.
             The osmotic pressure of sea water is about 30 atm,
             so a pressure greater than 30 atm must be applied.

  Also used in domestic "RO" water purifiers.
```

# TOPIC 21 — ABNORMAL MOLAR MASS and the VAN'T HOFF FACTOR

## The problem

```
  When you find the molar mass of NaCl by depression of freezing point,
  you get about 29.25 instead of 58.5    -->   HALF the true value.

  When you find the molar mass of benzoic acid in benzene, you get
  about 244 instead of 122               -->   TWICE the true value.

  These wrong values are called ABNORMAL MOLAR MASSES.
```

## The reason

```
  Colligative properties count PARTICLES.

  DISSOCIATION  -  the solute BREAKS UP into ions
                   NaCl  ->  Na+  +  Cl-
                   1 particle became 2  ->  MORE particles than expected
                   ->  colligative effect is BIGGER
                   ->  calculated molar mass comes out TOO SMALL

  ASSOCIATION   -  solute molecules JOIN together
                   2 CH3COOH  ->  (CH3COOH)2       (a DIMER)
                   2 particles became 1  ->  FEWER particles
                   ->  colligative effect is SMALLER
                   ->  calculated molar mass comes out TOO LARGE
```

Why does benzoic acid dimerise in benzene? Because benzene is non-polar and
cannot solvate the -COOH group, so two acid molecules hydrogen bond to each
other instead:

```
                O  . . . . H - O
               //                \
      C6H5 - C                    C - C6H5
               \                 //
                O - H . . . . O

              a DIMER  -  two molecules acting as ONE particle
```

## The van't Hoff factor, i

```
  +---------------------------------------------------------------+
  |                                                               |
  |          number of particles ACTUALLY present in solution     |
  |   i  =  ----------------------------------------------------  |
  |          number of particles EXPECTED (before dissoc./assoc.) |
  |                                                               |
  |          OBSERVED value of the colligative property           |
  |     =  ------------------------------------------------       |
  |          CALCULATED (normal) value                            |
  |                                                               |
  |          NORMAL (theoretical) molar mass                      |
  |     =  ---------------------------------------                |
  |          OBSERVED (abnormal) molar mass                       |
  |                                                               |
  |   i  =  1    ->  NORMAL  (no dissociation, no association)    |
  |   i  >  1    ->  DISSOCIATION (the solute split up)           |
  |   i  <  1    ->  ASSOCIATION  (the solute joined up)          |
  |                                                               |
  +---------------------------------------------------------------+
```

## The modified formulae

```
  +---------------------------------------------------------------+
  |                                                               |
  |      p0  -  p                                                 |
  |     -----------  =   i  .  x2                                 |
  |         p0                                                    |
  |                                                               |
  |     delta Tb   =   i  .  Kb  .  m                             |
  |                                                               |
  |     delta Tf   =   i  .  Kf  .  m                             |
  |                                                               |
  |     pi         =   i  .  C  .  R  .  T                        |
  |                                                               |
  +---------------------------------------------------------------+
```

## Values of i for complete dissociation

```
  +-----------------+----------------------------+-------+
  |  SOLUTE         |  BREAKS INTO               |   i   |
  +-----------------+----------------------------+-------+
  |  glucose, urea  |  does not break            |   1   |
  |  sucrose        |                            |       |
  |  NaCl           |  Na+  +  Cl-               |   2   |
  |  KCl            |  K+   +  Cl-               |   2   |
  |  MgSO4          |  Mg2+ +  SO4 2-            |   2   |
  |  CaCl2          |  Ca2+ +  2 Cl-             |   3   |
  |  MgCl2          |  Mg2+ +  2 Cl-             |   3   |
  |  K2SO4          |  2 K+ +  SO4 2-            |   3   |
  |  Na2SO4         |  2 Na+ + SO4 2-            |   3   |
  |  AlCl3          |  Al3+ +  3 Cl-             |   4   |
  |  K3[Fe(CN)6]    |  3 K+ + [Fe(CN)6] 3-       |   4   |
  |  Al2(SO4)3      |  2 Al3+ + 3 SO4 2-         |   5   |
  +-----------------+----------------------------+-------+
  |  acetic acid or |  2 molecules join to form  |  0.5  |
  |  benzoic acid   |  ONE dimer                 |       |
  |  in BENZENE     |                            |       |
  +-----------------+----------------------------+-------+

  RULE:  i  =  just COUNT the ions in the formula.
         CaCl2 -> 1 Ca + 2 Cl  =  3 particles  ->  i = 3
```

## Degree of dissociation and association

```
  +---------------------------------------------------------------+
  |                                                               |
  |   DISSOCIATION   (one molecule gives n particles)             |
  |                                                               |
  |                      i  -  1                                  |
  |          alpha  =  ------------                               |
  |                      n  -  1                                  |
  |                                                               |
  |          also:     i  =  1  +  ( n - 1 ) alpha                |
  |                                                               |
  |                                                               |
  |   ASSOCIATION    (n molecules join to give one particle)      |
  |                                                               |
  |                      1  -  i                 n ( 1 - i )      |
  |          alpha  =  --------------    =    ----------------    |
  |                     1  -  ( 1/n )              n  -  1        |
  |                                                               |
  |          also:     i  =  1  -  alpha  +  ( alpha / n )        |
  |                                                               |
  +---------------------------------------------------------------+
```

## Worked example 21 — i used forwards

**Q. Calculate the freezing point of a 0.100 molal aqueous NaCl solution,
assuming NaCl is completely dissociated. Kf for water = 1.86 K kg/mol,
freezing point of water = 273.15 K.**

```
  STEP 1  NaCl  ->  Na+  +  Cl-     so   i  =  2

  STEP 2  delta Tf  =  i  x  Kf  x  m

                    =  2  x  1.86  x  0.100

                    =  0.372  K

  STEP 3  freezing point  =  273.15  -  0.372  =  272.78 K

  ANSWER:  272.78 K   (about -0.37 C)

  NOTE:  without dissociation it would only have been 0.186 K.
         The salt gives DOUBLE the effect because it makes
         DOUBLE the particles.
```

## Worked example 22 — degree of DISSOCIATION

**Q. A 0.100 molal aqueous solution of acetic acid freezes at 272.946 K.
Calculate the van't Hoff factor and the degree of dissociation of acetic acid.
Kf(water) = 1.86 K kg/mol; freezing point of pure water = 273.150 K.**

```
  STEP 1  OBSERVED depression (what really happened)

          delta Tf(obs)   =  273.150  -  272.946   =   0.204  K

  STEP 2  CALCULATED depression, assuming NO dissociation

          delta Tf(calc)  =  Kf  x  m  =  1.86  x  0.100  =  0.186  K

  STEP 3            observed          0.204
          i   =  ---------------  =  ---------  =  1.097
                   calculated         0.186

          i is MORE than 1  ->  DISSOCIATION.  Good.

  STEP 4  CH3COOH  ->  CH3COO-  +  H+       so  n = 2

                     i - 1        1.097 - 1        0.097
          alpha  =  -------  =  ------------  =  ---------  =  0.097
                     n - 1          2 - 1            1

  ANSWER:  i = 1.10 ,  alpha = 0.097  =  about 9.7 % dissociated

  SENSE CHECK:  acetic acid is a WEAK acid, so only a small fraction
  should ionise. 9.7 % is exactly what we expect.
```

## Worked example 23 — degree of ASSOCIATION

**Q. 2 g of benzoic acid (C6H5COOH) dissolved in 25 g of benzene shows a
depression in freezing point of 1.62 K. Kf for benzene = 4.9 K kg/mol.
What is the percentage association of benzoic acid in benzene?**

```
  STEP 1  Find the OBSERVED molar mass.

                        1000  x  Kf  x  w2
          M2(obs)  =  -----------------------
                        delta Tf   x   w1

                        1000  x  4.9  x  2
                   =  -----------------------
                          1.62  x  25

                        9800
                   =  ----------   =   241.98  g/mol
                        40.5

  STEP 2  The NORMAL molar mass of benzoic acid C6H5COOH

          C7H6O2  =  7(12) + 6(1) + 2(16)  =  84 + 6 + 32  =  122 g/mol

  STEP 3            normal M2         122
          i   =  ---------------  =  --------  =  0.504
                  observed M2        241.98

          i is LESS than 1  ->  ASSOCIATION.   Good.

  STEP 4  Two molecules form one dimer, so  n = 2.

                       1  -  i            1  -  0.504
          alpha  =  --------------  =  ------------------
                     1  -  ( 1/n )      1  -  ( 1/2 )

                       0.496
                 =  -----------   =   0.992
                       0.500

  ANSWER:  i = 0.504 ,  alpha = 0.992  =  99.2 % associated
           (almost all of the benzoic acid exists as the dimer)
```

## Worked example 24 — i for CaCl2

**Q. A 0.0100 molal aqueous solution of CaCl2 freezes at 273.1041 K.
Calculate the van't Hoff factor and the degree of dissociation of CaCl2.
Kf(water) = 1.86 K kg/mol, freezing point of water = 273.1500 K.**

```
  STEP 1  delta Tf(obs)   =  273.1500  -  273.1041   =   0.0459  K

  STEP 2  delta Tf(calc)  =  Kf x m  =  1.86 x 0.0100  =  0.0186  K

  STEP 3             0.0459
          i   =   ------------   =   2.47
                    0.0186

  STEP 4  CaCl2  ->  Ca2+  +  2 Cl-        so   n = 3

                     i - 1        2.47 - 1        1.47
          alpha  =  -------  =  ------------  =  --------  =  0.735
                     n - 1          3 - 1           2

  ANSWER:  i = 2.47 ,  alpha = 0.735  =  73.5 % dissociated

  SENSE CHECK:  for CaCl2 the largest possible i is 3.
  We got 2.47, which is between 1 and 3.  The answer is sensible.
```

> **THE CHECK THAT SAVES YOU MARKS:**
> `i` must lie between the limits set by the formula.
> For NaCl: `1 <= i <= 2`. For CaCl2 and K2SO4: `1 <= i <= 3`.
> For a dimerising acid: `0.5 <= i <= 1`.
> If your `i` falls outside those limits, you made an arithmetic mistake.
> **Say so on the answer sheet and re-check — examiners give credit for
> spotting it.**
