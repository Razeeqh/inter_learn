# Haloalkanes and Haloarenes — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The compounds change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — CLASSIFY THE HALIDE                                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Classify the following as primary, secondary, tertiary,
            allylic, benzylic, vinylic or aryl."
  METHOD    1. Find the carbon that carries the halogen.
            2. Is it sp3 or sp2?
                  sp2 and on a ring        -> ARYL
                  sp2 and on a C=C         -> VINYLIC
            3. If sp3, look at its neighbour:
                  next to a C=C            -> ALLYLIC
                  next to a benzene ring   -> BENZYLIC
            4. If plain sp3, count the carbons attached to it:
                  0 or 1 -> PRIMARY   2 -> SECONDARY   3 -> TERTIARY
  TRAP      C6H5-Cl is ARYL, C6H5-CH2-Cl is BENZYLIC. One CH2 changes
            everything. Aryl is inert; benzylic is the most reactive of all.
```

```
  PATTERN 2 — GEMINAL versus VICINAL DIHALIDE                     2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between gem- and vic- dihalides" or a formula
            with two halogens.
  METHOD    GEMINAL - both X on the SAME carbon.   CH3-CHCl2
                      (alkylidene halide)
            VICINAL - X on ADJACENT carbons.       CH2Cl-CH2Cl
                      (alkylene halide)
            ALWAYS give an example - it carries half the mark.
  SHORTCUT  GEM = a gem set in ONE place. VIC = vicinity = next door.
  TRAP      A vicinal dihalide + Zn dust gives an ALKENE (dehalogenation).
            A geminal dihalide + 2 alc. KOH gives an ALKYNE.
```

```
  PATTERN 3 — IUPAC NAME FROM A STRUCTURE                         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the IUPAC name of ..."
  METHOD    1. Longest chain THROUGH the carbon bearing the halogen.
            2. Number to give the LOWEST SET of locants.
            3. If the two ends tie, give the lower number to the group
               that comes FIRST ALPHABETICALLY.
            4. Write substituents alphabetically (ignore di, tri when
               alphabetising, but keep them in the name).
  EXAMPLE   CH3-CH(Cl)-CH2-CH(CH3)-CH3  ->  2-chloro-4-methylpentane
  TRAP      Do not number to give the halogen priority automatically.
            The rule is LOWEST LOCANT SET first; alphabet only breaks ties.
```

```
  PATTERN 4 — THE C-X BOND: LENGTH, STRENGTH, POLARITY            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange in order of bond length / bond enthalpy / dipole
            moment / reactivity."
  METHOD    Bond LENGTH   :  C-F  <  C-Cl  <  C-Br  <  C-I
            Bond ENTHALPY :  C-F  >  C-Cl  >  C-Br  >  C-I
            REACTIVITY    :  R-I  >  R-Br  >  R-Cl  >  R-F
            DIPOLE MOMENT :  CH3Cl > CH3F > CH3Br > CH3I
  TRAP      The dipole moment order is NOT the electronegativity order.
            CH3Cl beats CH3F because dipole = charge x DISTANCE, and the
            C-Cl bond is much longer. This is asked to catch you out.
```

```
  PATTERN 5 — PREPARE A HALOALKANE FROM AN ALCOHOL                4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is ... prepared from ...ol?" or "Give all the methods."
  METHOD    Write ALL FOUR:
              R-OH + HX / anhyd. ZnCl2  -> R-X + H2O
              R-OH + PCl5               -> R-Cl + POCl3 + HCl
              3 R-OH + PCl3             -> 3 R-Cl + H3PO3
              R-OH + SOCl2 / pyridine   -> R-Cl + SO2 + HCl
            Add the two orders:
              acid   HI > HBr > HCl
              alcohol 3deg > 2deg > 1deg
  TRAP      Balance the PCl3 equation - it needs THREE alcohol molecules.
            And always name SOCl2 as the PREFERRED reagent with the reason.
```

```
  PATTERN 6 — WHY IS SOCl2 PREFERRED?                             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is thionyl chloride preferred over PCl5 / PCl3?"
  METHOD    Write the equation, then the sentence:
              R-OH + SOCl2 --pyridine--> R-Cl + SO2 + HCl
            "Both by-products, SO2 and HCl, are GASES. They escape from
             the reaction mixture, so the alkyl chloride is obtained in a
             PURE state without any separation step."
            Contrast: PCl5 gives POCl3, a LIQUID that must be separated.
  TRAP      Saying only "the product is pure" without naming the gases
            loses half the mark. Name SO2 and HCl explicitly.
```

```
  PATTERN 7 — MARKOVNIKOV: PREDICT THE PRODUCT                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   An unsymmetrical alkene + HX, with NO peroxide mentioned.
  METHOD    1. Count the H's on each double-bond carbon.
            2. H goes to the carbon with MORE hydrogens.
            3. X goes to the carbon with FEWER hydrogens.
            4. Justify with carbocation stability: 3deg > 2deg > 1deg.
  EXAMPLE   CH3-CH=CH2 + HBr -> CH3-CHBr-CH3 (2-bromopropane)
  TRAP      For a SYMMETRICAL alkene (but-2-ene) both routes give the same
            product, so Markovnikov does not apply. Say so if asked.
```

```
  PATTERN 8 — THE PEROXIDE EFFECT WITH MECHANISM                  4 marks
  ------------------------------------------------------------------------
  TRIGGER   The words "peroxide", "benzoyl peroxide", "anti-Markovnikov"
            or "Kharasch effect".
  METHOD    1. Give the equation:
                 CH3-CH=CH2 + HBr --peroxide--> CH3-CH2-CH2-Br
            2. Write the FOUR mechanistic steps:
                 peroxide splits -> C6H5.
                 C6H5. + HBr -> C6H6 + Br.
                 Br. adds to the TERMINAL carbon (gives the stable 2deg
                     radical)
                 radical + HBr -> product + Br.
            3. State the reason: it goes through the MORE STABLE FREE
               RADICAL, 3deg. > 2deg. > 1deg.
            4. State: HBr ONLY.
  TRAP      Not saying "HBr only" and not giving the reason (HCl bond too
            strong; iodine radicals recombine to I2) throws away a mark
            that is almost always allotted.
```

```
  PATTERN 9 — NAME THE HALOGEN-EXCHANGE REACTION                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   NaI + dry acetone, or AgF / SbF3 / Hg2F2 / CoF2 appears.
  METHOD    FINKELSTEIN:  R-Cl + NaI --dry acetone--> R-I + NaCl
                          Reason: NaI dissolves in acetone, NaCl does not,
                          so NaCl precipitates and drives it forward.
            SWARTS:       R-Br + AgF --> R-F + AgBr
                          Industrial: CCl4 + 2 SbF3 -> CCl2F2 + 2 SbCl3
  SHORTCUT  Finkelste-I-n -> Iodide.  Swarts (SbF3) -> Fluoride.
  TRAP      Forgetting to write "DRY ACETONE" on the Finkelstein arrow.
            The solvent IS the reason the reaction works, so it is marked.
```

```
  PATTERN 10 — SANDMEYER versus GATTERMANN                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   A diazonium salt C6H5-N2+Cl- with copper in any form.
  METHOD    Diazotisation first:
              C6H5NH2 + NaNO2 + HCl --273-278 K--> C6H5N2(+)Cl(-)
            SANDMEYER  = CUPROUS HALIDE (CuCl / CuBr / CuCN) + HX
            GATTERMANN = COPPER POWDER + HX
            Both liberate N2 gas. Sandmeyer gives better yields.
            For the IODIDE, no copper at all - just warm with KI.
  TRAP      Writing "Cu" for Sandmeyer or "CuCl" for Gattermann. Also
            forgetting the 273-278 K for diazotisation.
```

```
  PATTERN 11 — LIST THE PRODUCTS OF NUCLEOPHILIC SUBSTITUTION     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the products when ethyl bromide reacts with ..."
            followed by a list of reagents.
  METHOD    Run down the memorised table:
              aq. KOH   -> alcohol         alc. KOH -> ALKENE
              NaOR'     -> ether           KCN      -> nitrile R-CN
              AgCN      -> isocyanide R-NC KNO2     -> R-O-N=O
              AgNO2     -> R-NO2           NH3      -> R-NH2
              R'COOAg   -> ester           LiAlH4   -> alkane
              NaI/acetone -> R-I           Mg/ether -> Grignard
              Na/ether  -> Wurtz (R-R)
  TRAP      Two traps in one question: (i) aqueous vs alcoholic KOH,
            (ii) silver vs potassium salt. Read both words before writing.
```

```
  PATTERN 12 — AMBIDENT NUCLEOPHILE: KCN vs AgCN, KNO2 vs AgNO2   2 marks
  ------------------------------------------------------------------------
  TRIGGER   Both a potassium salt and a silver salt appear in the same
            question, or "why do KCN and AgCN give different products?"
  METHOD    1. Say the nucleophile is AMBIDENT - it has two atoms with
               lone pairs that can attack.
            2. KCN is IONIC -> free CN- -> attacks through CARBON ->
               R-CN, a NITRILE.
            3. AgCN is COVALENT -> the C end is locked in the Ag-C bond ->
               only NITROGEN can attack -> R-NC, an ISOCYANIDE.
            4. Same logic: KNO2 -> R-O-N=O ; AgNO2 -> R-NO2.
  SHORTCUT  SILVER always attacks through NITROGEN.
  TRAP      Do not write "nitrile" for AgCN. The follow-up question is
            usually about what the product reduces to:
               R-CN + LiAlH4 -> 1deg amine with ONE MORE carbon
               R-NC + LiAlH4 -> 2deg amine (R-NH-CH3)
```

```
  PATTERN 13 — DRAW THE SN2 MECHANISM                           4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the SN2 mechanism" or "explain with mechanism the
            hydrolysis of methyl bromide".
  METHOD    1. Expand the name: Substitution Nucleophilic BIMOLECULAR.
            2. Say ONE STEP, no intermediate.
            3. DRAW back-side attack, 180 degrees from the leaving group.
            4. DRAW the transition state with the carbon bonded to FIVE
               groups and the three unchanged groups drawn FLAT.
            5. rate = k[RX][Nu-], SECOND order.
            6. INVERSION of configuration (Walden inversion) - use the
               umbrella-in-the-wind picture.
            7. Order CH3 > 1deg > 2deg > 3deg, because of STERIC HINDRANCE.
  TRAP      Calling the five-coordinate species an "intermediate". It is a
            TRANSITION STATE. Examiners deduct for this word.
            Also: an SN2 answer without a DIAGRAM rarely gets full marks.
```

```
  PATTERN 14 — DRAW THE SN1 MECHANISM                           4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the SN1 mechanism" or a tertiary halide with water.
  METHOD    1. Expand: Substitution Nucleophilic UNIMOLECULAR.
            2. STEP 1 (SLOW): C-X breaks -> CARBOCATION + X-.
               Label it FLAT, sp2, trigonal planar, 120 degrees.
            3. STEP 2 (FAST): nucleophile attacks from BOTH faces.
            4. rate = k[RX], FIRST order; [Nu-] has NO effect.
            5. RACEMISATION -> product optically INACTIVE.
            6. Order 3deg > 2deg > 1deg > CH3, because of CARBOCATION
               STABILITY (+I effect and hyperconjugation).
  TRAP      Drawing the carbocation as pyramidal. It MUST be flat - that
            flatness is the entire explanation of racemisation.
```

```
  PATTERN 15 — COMPARE SN1 AND SN2                              4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between SN1 and SN2" or "compare with respect to
            kinetics, stereochemistry and substrate."
  METHOD    Draw a TABLE. Cover, in order:
              steps / intermediate / rate law / order / molecularity /
              effect of [Nu-] / substrate order / reason for order /
              stereochemistry / optical activity of product / solvent /
              nucleophile / rearrangement / example
            End with the killer line: "the two substrate orders are
            EXACTLY OPPOSITE."
  TRAP      Mixing up which order belongs to which. Anchor it:
               SN1 = ONE molecule breaking = needs a stable carbocation
                     = TERTIARY is fastest
               SN2 = TWO molecules colliding = needs room
                     = METHYL is fastest
```

```
  PATTERN 16 — GIVEN THE KINETICS, NAME THE MECHANISM             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "The rate doubles when [RX] doubles but does not change when
            [OH-] doubles."
  METHOD    Nucleophile ABSENT from the rate law  ->  SN1  ->  first order
                                                  ->  racemisation
            Nucleophile PRESENT in the rate law   ->  SN2  ->  second order
                                                  ->  inversion
            Then confirm with the substrate: tertiary fits SN1, methyl or
            primary fits SN2.
  TRAP      The question usually then asks for the STEREOCHEMICAL OUTCOME.
            Always add it, even if not asked - it is often a marked point.
```

```
  PATTERN 17 — EFFECT OF SOLVENT AND NUCLEOPHILE                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Which solvent favours SN1?" or DMSO / acetone / DMF appears.
  METHOD    POLAR PROTIC (water, ethanol, formic acid) -> favours SN1,
              because it solvates and stabilises both the carbocation and
              the departing halide ion.
            POLAR APROTIC (acetone, DMSO, DMF) -> favours SN2, because it
              solvates the cation but leaves the ANION bare and highly
              reactive.
            Strong, concentrated nucleophile -> SN2.
            Weak nucleophile / just the solvent -> SN1.
  TRAP      "Protic" means it HAS an O-H or N-H. Acetone has no O-H, so it
            is APROTIC even though it is very polar.
```

```
  PATTERN 18 — SUBSTITUTION OR ELIMINATION?                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   KOH appears. Look at the SOLVENT word.
  METHOD    AQUEOUS  KOH  ->  SUBSTITUTION  ->  R-OH, an ALCOHOL
            ALCOHOLIC KOH ->  ELIMINATION   ->  an ALKENE
            Also:  1deg + strong nucleophile -> substitution
                   3deg + strong base + heat -> elimination
                   bulky base ((CH3)3CO-)    -> elimination
  TRAP      This single word decides the whole answer, and it is the most
            common careless-error in the entire chapter. Circle it.
```

```
  PATTERN 19 — SAYTZEFF: WHICH ALKENE IS MAJOR?                   4 marks
  ------------------------------------------------------------------------
  TRIGGER   Alcoholic KOH with a halide that has beta hydrogens on more
            than one side.
  METHOD    1. Mark the ALPHA carbon (the one carrying X).
            2. Find every BETA carbon (neighbours of alpha) that has an H.
            3. Write the alkene from each.
            4. The MORE SUBSTITUTED alkene is the MAJOR product.
               (equivalently: pull the H from the beta carbon with FEWER
                hydrogens - "the poor get poorer")
            5. Justify: more substituted = more stable (hyperconjugation).
  EXAMPLE   CH3-CH2-CHBr-CH3 -> but-2-ene MAJOR, but-1-ene minor
  TRAP      Writing but-1-ene as the major product. Also: CH3-Br has NO
            beta hydrogen, so it cannot eliminate at all.
```

```
  PATTERN 20 — GRIGNARD: WHICH PRODUCT?                         2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   R-MgX appears, or "Mg / dry ether", or "(i) ... (ii) H3O+".
  METHOD    Match the partner:
                 H2O or any active H   ->  ALKANE
                 HCHO                  ->  1deg ALCOHOL
                 any other aldehyde    ->  2deg ALCOHOL
                 ketone                ->  3deg ALCOHOL
                 ester (2 mol RMgX)    ->  3deg ALCOHOL
                 CO2                   ->  CARBOXYLIC ACID (one C MORE)
            Always write the second stage: (ii) H3O+.
  TRAP      Forgetting the hydrolysis step. The first product is the
            alkoxide salt R-O-MgX, NOT the alcohol. Write both stages.
```

```
  PATTERN 21 — WHY DRY ETHER FOR A GRIGNARD REAGENT?              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is a Grignard reagent prepared in dry ether?" or "why
            can it not be stored?"
  METHOD    Write the destroying equation:
                 CH3-Mg-Br + H2O  ->  CH4 + Mg(OH)Br
            Then: "A Grignard reagent reacts instantly with any compound
            containing an ACTIVE HYDROGEN (water, alcohols, ammonia,
            acids), being converted into an alkane. Even a trace of
            moisture destroys it, so anhydrous ether must be used and the
            reagent must be used immediately."
  TRAP      Just saying "because it reacts with water" without the
            equation. The equation is where the mark is.
```

```
  PATTERN 22 — WURTZ / WURTZ-FITTIG / FITTIG                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   Sodium metal in dry ether.
  METHOD    Look at what the two halides are:
                 alkyl + alkyl  ->  WURTZ         ->  alkane
                 aryl  + alkyl  ->  WURTZ-FITTIG  ->  alkylbenzene
                 aryl  + aryl   ->  FITTIG        ->  biaryl (biphenyl)
            Write the balanced equation with "dry ether" on the arrow.
  TRAP      Wurtz LIMITATION (often the second half of the question): two
            different alkyl halides give a MIXTURE OF THREE products, so
            it is only good for symmetrical alkanes, and the product
            always has an EVEN number of carbons.
```

```
  PATTERN 23 — IS IT OPTICALLY ACTIVE?                            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Which of the following is optically active?" or "identify the
            chiral carbon."
  METHOD    1. Take each sp3 carbon in turn.
            2. List its FOUR attachments.
            3. If all four are DIFFERENT -> that carbon is CHIRAL (mark C*)
               -> the compound is optically active.
            4. If any two are the same -> not chiral at that carbon.
  EXAMPLE   CH3-CHCl-C2H5 : the C-Cl carbon holds Cl, H, CH3, C2H5.
            All different -> OPTICALLY ACTIVE.
  TRAP      2-chloropropane looks similar but has TWO CH3 groups, so it is
            INACTIVE. Always list all four groups; do not eyeball it.
```

```
  PATTERN 24 — DEFINE THE OPTICAL-ISOMERISM TERMS                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define chirality / enantiomers / racemic mixture /
            racemisation / retention / inversion."
  METHOD    CHIRALITY    - non-superimposable on its mirror image
                           (like your two hands)
            ENANTIOMERS  - the pair of non-superimposable mirror images;
                           identical in every physical property except the
                           DIRECTION of optical rotation
            d / (+)      - dextrorotatory, rotates the plane to the RIGHT
            l / (-)      - laevorotatory, rotates the plane to the LEFT
            RACEMIC MIXTURE - equal 50:50 mixture of (+) and (-);
                           optically INACTIVE by EXTERNAL COMPENSATION
            RACEMISATION - conversion of a pure enantiomer into a racemic
                           mixture (this is what SN1 does)
            RETENTION    - the arrangement of groups is unchanged
            INVERSION    - the arrangement is turned inside out
                           (Walden inversion; this is what SN2 does)
            ALWAYS give an example (2-chlorobutane) - it carries marks.
  TRAP      Saying a racemic mixture is "optically active but cancels out".
            It is optically INACTIVE. Use the exact word.
```

```
  PATTERN 25 — WHY ARE HALOARENES UNREACTIVE?                   4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is chlorobenzene less reactive than chloroethane towards
            nucleophilic substitution?"
  METHOD    Give FIVE reasons; three plus a diagram usually gets full
            marks:
              1. RESONANCE - draw the four structures; the C-Cl bond gets
                 PARTIAL DOUBLE BOND character.
              2. SHORTER, STRONGER BOND - 169 pm vs 178 pm.
              3. sp2 CARBON - 33 % s character vs 25 %, more
                 electronegative, grips the halogen harder.
              4. UNSTABLE PHENYL CATION - its empty orbital is in the
                 plane of the ring, perpendicular to the pi cloud, so
                 there is no resonance stabilisation.
              5. REPULSION - electron-rich ring repels the electron-rich
                 nucleophile.
            Finish with the evidence: chlorobenzene needs NaOH at 623 K
            and 300 atm; chloroethane reacts with dilute NaOH at room
            temperature.
  TRAP      Writing only "because of resonance". That is one reason out of
            five. Give the numbers 169 pm and 178 pm - they are cheap marks.
```

```
  PATTERN 26 — EFFECT OF -NO2 ON ARYL HALIDE REACTIVITY           4 marks
  ------------------------------------------------------------------------
  TRIGGER   Nitrochlorobenzenes, or "arrange in order of ease of
            hydrolysis."
  METHOD    1. Order: chlorobenzene < p-nitro < 2,4-dinitro < 2,4,6-trinitro
            2. Give the conditions table (623 K/300 atm -> 443 K -> 368 K
               -> warm water).
            3. REASON: attack of the nucleophile puts a NEGATIVE charge on
               the ring; from ORTHO and PARA that charge is delocalised
               onto the OXYGEN atoms of the nitro group, stabilising the
               intermediate.
            4. State that a META nitro group gives NO activation, because
               the charge can never reach that carbon.
  TRAP      Saying "-NO2 is meta directing so meta doesn't work". That is
            about ELECTROPHILIC substitution and is the wrong reason here.
```

```
  PATTERN 27 — DEACTIVATING YET ORTHO-PARA DIRECTING              4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Halogens are deactivating but o,p directing. Explain."
  METHOD    Two effects, opposite in direction:
              -I EFFECT (inductive)  -> pulls density OUT of the whole
                 ring -> ring is electron poor -> reaction is SLOWER than
                 benzene -> DEACTIVATING. It controls the RATE.
              +R EFFECT (resonance)  -> pushes the lone pair INTO the
                 ring, and the extra density appears only at ORTHO and
                 PARA -> those positions are attacked. It controls the
                 POSITION.
            Then give two example reactions (nitration, halogenation)
            showing o- and p- products.
  TRAP      Do not say the halogen is "electron donating overall". It is
            net electron WITHDRAWING; only the RESONANCE component donates.
```

```
  PATTERN 28 — REACTION MAP: IDENTIFY A, B, C                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "An organic compound A of formula ... on treatment with X
            gives B, and with Y gives C. Identify A, B and C."
  METHOD    1. Work out the degree of unsaturation / list the isomers of
               the given formula.
            2. Use the KEY CLUE to pick A. Common clues:
                 "optically active"    -> A has a chiral carbon
                 "aqueous KOH"         -> B is an alcohol
                 "alcoholic KOH"       -> C is an alkene (Saytzeff!)
                 "gives a 1deg amine"  -> the KCN route
                 "gives one more C"    -> KCN or CO2/Grignard
                 "no reaction with Na" -> no O-H present
            3. Write every step as a full equation.
  EXAMPLE   C4H9Br, optically active -> A = 2-bromobutane
            aq. KOH -> B = butan-2-ol ; alc. KOH -> C = but-2-ene
  TRAP      Picking tert-butyl bromide because it "looks special".
            (CH3)3C-Br has three identical methyls, so it is NOT chiral.
```

```
  PATTERN 29 — PHYSICAL PROPERTY ORDER WITH REASON                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange in increasing order of boiling point / density /
            solubility" or "give the reason for ..."
  METHOD    b.p. vs alkane      : R-X higher (polar C-X, dipole-dipole)
            b.p. same R         : R-I > R-Br > R-Cl > R-F (polarisability)
            b.p. same X         : rises with chain length
            b.p. isomers        : n- > iso- > sec- > tert- (branching
                                  lowers it - more spherical, less contact)
            m.p. of C6H4X2      : PARA >> ortho, meta (symmetry, packing)
            density             : R-I > R-Br > R-Cl
            solubility in water : very low - cannot form H-bonds with water
  TRAP      The ORDER alone gets half marks. The REASON gets the other
            half. Always write "van der Waals / polarisability /
            symmetrical packing / hydrogen bonding" explicitly.
```

```
  PATTERN 30 — CHLOROFORM: THE FULL QUESTION                  2, 4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   CHCl3, phosgene, dark bottles, bleaching powder, chloral.
  METHOD    PREPARATION (3 steps from ethanol + bleaching powder):
                 CH3CH2OH + Cl2 -> CH3CHO + 2 HCl        (oxidation)
                 CH3CHO + 3 Cl2 -> CCl3CHO (CHLORAL) + 3 HCl
                 2 CCl3CHO + Ca(OH)2 -> 2 CHCl3 + (HCOO)2Ca
            OXIDATION IN AIR:
                 2 CHCl3 + O2 --sunlight--> 2 COCl2 (PHOSGENE) + 2 HCl
            STORAGE: DARK bottle (keeps light out) FILLED TO THE BRIM
                 (keeps air/oxygen out), plus 1 % ethanol.
            OTHER REACTIONS: chloropicrin with HNO3, carbylamine test.
            USES: solvent, making Freon-12, formerly an anaesthetic.
  TRAP      Giving only ONE reason for the dark bottle. There are TWO
            (light AND air) and both are marked. Also NAME phosgene.
```

```
  PATTERN 31 — POLYHALOGEN COMPOUND: USES AND HAZARDS             2 marks
  ------------------------------------------------------------------------
  TRIGGER   CH2Cl2, CHI3, CCl4, freons, DDT.
  METHOD    One use + one hazard for each:
              CH2Cl2  paint remover / propellant     - harms the CNS, eyes
              CHCl3   solvent, made Freon-12         - phosgene, liver
              CHI3    antiseptic (liberates iodine)  - foul smell
              CCl4    fire extinguisher (PYRENE)     - phosgene when hot,
                                                       liver, ozone
              FREONS  refrigerant, propellant        - OZONE HOLE
              DDT     insecticide (malaria, typhus)  - non-biodegradable,
                                                       accumulates in fat
  TRAP      "Freons deplete ozone" is worth only half a mark. Write the
            chain: CCl2F2 -UV-> Cl. ; Cl. + O3 -> ClO. + O2 ;
            ClO. + O -> Cl. + O2, and name the MONTREAL PROTOCOL.
```

```
  PATTERN 32 — TOLUENE: RING OR SIDE CHAIN?                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   Toluene + Cl2, with either "sunlight" or "FeCl3 / dark".
  METHOD    SUNLIGHT / hv, no catalyst   ->  SIDE CHAIN, free radical
                                             -> C6H5-CH2Cl (benzyl chloride)
            DARK + Lewis acid (FeCl3)    ->  RING, electrophilic
                                             -> o- and p-chlorotoluene
  SHORTCUT  "Light hits the side, dark hits the ring."
  TRAP      Excess Cl2 in sunlight goes further: C6H5-CHCl2 (benzal
            chloride) and C6H5-CCl3 (benzotrichloride).
```
