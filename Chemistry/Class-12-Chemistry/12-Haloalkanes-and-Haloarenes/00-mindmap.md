and 2-3 very short answers (2M).**

Why this chapter matters: it is the **gateway chapter of organic chemistry**. Alcohols,
ethers, amines, aldehydes, acids — all of them are made from halides or turn back into
halides. If you learn this chapter properly, Chapters 12, 13 and 14 stop being three
chapters and become one connected map. And SN1/SN2 is the single most repeated
mechanism question in all of 2nd year Chemistry.

## THE 60-SECOND VERSION

A haloalkane is just an alkane where one hydrogen has been swapped for a halogen.

```
        CH3-CH3          ->        CH3-CH2-Cl
        ethane                     chloroethane
```

That one change makes the molecule **reactive**, because the C-X bond is polar:

```
        delta+      delta-
          C   ------   X          carbon is electron POOR
                                  halogen is electron RICH
```

Everything in the chapter follows from that one picture:

```
   STEP 1   Carbon is delta+  ==>  anything with a lone pair (a NUCLEOPHILE)
              |                    attacks the carbon and kicks out X-
              |                    ==>  NUCLEOPHILIC SUBSTITUTION (SN1, SN2)
              v
   STEP 2   If the attacking species is a strong BASE instead, it grabs an
              |  H from the NEXT carbon
              |  ==>  ELIMINATION, you get an ALKENE
              v
   STEP 3   If you use a METAL (Mg or Na) the polarity FLIPS:
              |  carbon becomes delta- ==> GRIGNARD REAGENT, a carbanion
              |  ==> now it can attack other carbons and BUILD chains
              v
   STEP 4   In an ARYL halide the lone pair of X goes into the ring
              (resonance). The C-X bond gets partial DOUBLE bond character.
              ==>  aryl halides REFUSE to do nucleophilic substitution.
```

**Alkyl halide = reactive. Aryl halide = stubborn. Learn the reason and you have
the 8-mark question.**

## THE ONE BOX THAT UNLOCKS MOST QUESTIONS

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   SN2  needs an OPEN carbon    ->  fastest for  CH3-X > 1deg > 2deg  |
  |        one step, back attack       slowest for 3deg                 |
  |        INVERSION of configuration                                   |
  |                                                                     |
  |   SN1  needs a STABLE carbocation -> fastest for 3deg > 2deg > 1deg  |
  |        two steps, flat carbocation    slowest for CH3-X             |
  |        RACEMISATION                                                 |
  |                                                                     |
  |   ==>  THE TWO ORDERS ARE EXACTLY OPPOSITE. That single fact         |
  |        answers half the objective questions in this chapter.        |
  |                                                                     |
  |   REACTIVITY OF THE HALOGEN (both mechanisms, C-X bond strength):    |
  |                                                                     |
  |          R-I  >  R-Br  >  R-Cl  >  R-F                              |
  |          (weakest C-X bond breaks first; I- is the best leaving      |
  |           group, F- is the worst)                                   |
  |                                                                     |
  |   REACTIVITY BY CARBON TYPE (nucleophilic substitution, overall):    |
  |                                                                     |
  |          allyl , benzyl  >  3deg  >  2deg  >  1deg  >  vinyl , aryl  |
  |                                                                     |
  +---------------------------------------------------------------------+
```

## THE SECOND KEY BOX — THE NUCLEOPHILE TABLE

Learn these ten lines and you can answer any "what is the product" question.

```
  +------------------------------------------------------------------+
  |   R-X   +   ...              ->   PRODUCT                        |
  +------------------------------------------------------------------+
  |   aq. KOH / NaOH             ->   R-OH        alcohol            |
  |   alc. KOH                   ->   ALKENE      (elimination!)     |
  |   NaOR'                      ->   R-O-R'      ether (Williamson) |
  |   KCN  (alcoholic)           ->   R-CN        nitrile            |
  |   AgCN                       ->   R-NC        isocyanide         |
  |   KNO2                       ->   R-O-N=O     alkyl nitrite      |
  |   AgNO2                      ->   R-NO2       nitroalkane        |
  |   NH3 (excess, ethanol)      ->   R-NH2       amine              |
  |   R'COOAg                    ->   R'COO-R     ester              |
  |   Mg / dry ether             ->   R-Mg-X      Grignard reagent   |
  |   Na / dry ether             ->   R-R         Wurtz              |
  +------------------------------------------------------------------+

  THE SILVER RULE:  a K/Na salt attacks through the atom with the
  NEGATIVE charge; a SILVER salt is covalent, so attack happens through
  the atom with the LONE PAIR.
        KCN  -> C attacks -> R-CN        AgCN  -> N attacks -> R-NC
        KNO2 -> O attacks -> R-ONO       AgNO2 -> N attacks -> R-NO2
```

## WHAT TO WRITE IF YOU ARE STUCK IN THE EXAM

```
  Asked anything about R-X and you have gone blank? Write this. It earns
  partial marks in almost every question of this chapter:

     "In R-X the halogen is more electronegative than carbon, so the C-X
      bond is polar with a partial positive charge on carbon. A nucleophile
      attacks this carbon and the halide ion leaves as a leaving group.
      This is nucleophilic substitution."

  Then draw the relevant equation. Never leave the answer blank.
```
