# 1. THE STRUCTURES YOU MUST BE ABLE TO DRAW FROM MEMORY

## 1.1 GLUCOSE — open chain (Fischer projection)

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |        C1        CHO                                                |
  |                   |                                                 |
  |        C2       H-C-OH                                              |
  |                   |                    D - ( + ) - GLUCOSE          |
  |        C3      HO-C-H                                               |
  |                   |                    an ALDOHEXOSE                |
  |        C4       H-C-OH                                              |
  |                   |                    short form:                  |
  |        C5       H-C-OH                 CHO-(CHOH)4-CH2OH            |
  |                   |                                                 |
  |        C6        CH2OH                                              |
  |                                                                     |
  |   ONE -CHO  +  FIVE -OH  +  SIX carbons in a straight chain          |
  |                                                                     |
  |   "D" because the -OH on C5 (the last chiral carbon) is on the RIGHT |
  |   "(+)" because it rotates polarised light to the right              |
  |                                                                     |
  +---------------------------------------------------------------------+

  ONLY C3 HAS ITS -OH ON THE LEFT. Memorise that one exception and you
  can draw glucose correctly every time.
```

## 1.2 GLUCOSE — cyclic Haworth projections

```
  +---------------------------------------------------------------------+
  |         a l p h a - D - ( + ) - G L U C O P Y R A N O S E            |
  |                                                                     |
  |                      6 CH2OH                                        |
  |                         |                                           |
  |                         C5 --------------- O                        |
  |                        /                     \                      |
  |                       /                       \                     |
  |                  4  C4                         C1 ---- H            |
  |                     /  \                      /   \                 |
  |                    /    \                    /     OH   <-- ALPHA:  |
  |                  OH      \                  /            OH is DOWN |
  |                           C3 ------------ C2                        |
  |                          /  \            /  \                       |
  |                        OH    H          H    OH                     |
  |                                                                     |
  +---------------------------------------------------------------------+
  |          b e t a - D - ( + ) - G L U C O P Y R A N O S E             |
  |                                                                     |
  |                      6 CH2OH                                        |
  |                         |                                           |
  |                         C5 --------------- O                        |
  |                        /                     \                      |
  |                       /                       \                     |
  |                  4  C4                         C1 ---- OH  <-- BETA:|
  |                     /  \                      /   \        OH is UP |
  |                    /    \                    /     H                |
  |                  OH      \                  /                       |
  |                           C3 ------------ C2                        |
  |                          /  \            /  \                       |
  |                        OH    H          H    OH                     |
  |                                                                     |
  +---------------------------------------------------------------------+

  WHERE EVERY GROUP GOES (alpha-D-glucopyranose):

       C1 -OH    DOWN      <-- this alone decides alpha or beta
       C2 -OH    DOWN
       C3 -OH    UP
       C4 -OH    DOWN
       C5 CH2OH  UP

  The ring closes because the -OH on C5 attacks the -CHO on C1.
  The product is a cyclic HEMIACETAL. C1 becomes the ANOMERIC CARBON.
  A SIX-membered sugar ring is called a PYRANOSE ring.
```

## 1.3 FRUCTOSE — open chain and ring

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |        C1        CH2OH                                              |
  |                    |                                                |
  |        C2        C = O    <-- KETO group at C2                      |
  |                    |                                                |
  |        C3      HO-C-H                  D - ( - ) - FRUCTOSE         |
  |                    |                                                |
  |        C4       H-C-OH                 a KETOHEXOSE                 |
  |                    |                                                |
  |        C5       H-C-OH                 anomeric carbon = C2         |
  |                    |                                                |
  |        C6        CH2OH                                              |
  |                                                                     |
  +---------------------------------------------------------------------+

           b e t a - D - F R U C T O F U R A N O S E   (5-membered)

                HOCH2              O              CH2OH
                 (C1) \                       /   (C6)
                       \                     /
                        C2 ---------------- C5
                       /  \                /  \
                     OH    \              /    H
                            C3 -------- C4
                           /  \        /  \
                          H    OH    OH    H

  The -OH on C5 attacks the keto group on C2 -> FIVE-membered ring.
  A five-membered sugar ring is a FURANOSE ring.
  MEMORY :  Fructose -> Furanose      Glucose -> Pyranose
```

## 1.4 THE ZWITTER ION

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |         R                                    R                      |
  |         |          internal proton transfer  |                      |
  |  H2N -- CH -- COOH   ------------------>  H3N -- CH -- COO          |
  |                                           (+)           (-)         |
  |                                                                     |
  |     neutral form                       ZWITTER ION (dipolar ion)    |
  |     (does not really exist)            positive AND negative on the |
  |                                        SAME molecule, net charge 0   |
  |                                                                     |
  |  For GLYCINE (R = H):        H3N -- CH2 -- COO                       |
  |                              (+)            (-)                     |
  |                                                                     |
  +---------------------------------------------------------------------+

  IN ACID (pH below pI)     H3N(+)-CHR-COOH     CATION  -> moves to CATHODE
  AT THE ISOELECTRIC POINT  H3N(+)-CHR-COO(-)   ZWITTER -> does NOT move
  IN BASE (pH above pI)     H2N-CHR-COO(-)      ANION   -> moves to ANODE
```

# 2. GLUCOSE — THE REACTION TABLE

**This table IS the 4-mark question "how was the structure of glucose established".**

```
  +---+---------------------+-----------------------+----------------------+
  | # |  REAGENT            |  PRODUCT              |  CONCLUSION          |
  +---+---------------------+-----------------------+----------------------+
  | 1 | HI + red P,         | n-HEXANE              | 6 carbons in a       |
  |   | prolonged heating   | CH3(CH2)4CH3          | STRAIGHT chain       |
  +---+---------------------+-----------------------+----------------------+
  | 2 | NH2OH               | glucose OXIME         | a CARBONYL group     |
  |   | (hydroxylamine)     | CH=N-OH               | >C=O is present      |
  +---+---------------------+-----------------------+----------------------+
  | 3 | HCN                 | glucose CYANOHYDRIN   | only ONE carbonyl    |
  |   |                     |                       | group (1 HCN adds)   |
  +---+---------------------+-----------------------+----------------------+
  | 4 | Br2 water           | GLUCONIC ACID         | the carbonyl is an   |
  |   | (MILD oxidant)      | COOH-(CHOH)4-CH2OH    | ALDEHYDE at C1       |
  +---+---------------------+-----------------------+----------------------+
  | 5 | (CH3CO)2O           | glucose PENTAACETATE  | FIVE -OH groups, one |
  |   | acetic anhydride    |                       | on each of 5 carbons |
  +---+---------------------+-----------------------+----------------------+
  | 6 | conc. HNO3          | SACCHARIC ACID        | a primary -CH2OH at  |
  |   | (STRONG oxidant)    | COOH-(CHOH)4-COOH     | the far end (C6)     |
  +---+---------------------+-----------------------+----------------------+
  | 7 | Tollens' reagent    | SILVER MIRROR + the   | free -CHO group;     |
  |   | [Ag(NH3)2]OH        | gluconic acid salt    | glucose is REDUCING  |
  +---+---------------------+-----------------------+----------------------+
  | 8 | Fehling's solution  | RED ppt of Cu2O +     | free -CHO group;     |
  |   |                     | gluconic acid         | glucose is REDUCING  |
  +---+---------------------+-----------------------+----------------------+

  THE ONE-LINE MEMORY HOOK:
     HI      -> Hexane        (chain length)
     NH2OH   -> Oxime         (carbonyl)
     Br2 aq  -> Gluconic      (aldehyde)      "Br is mild - ONE acid group"
     HNO3    -> Saccharic     (di-acid)       "HNO3 is strong - TWO acid groups"
     Ac2O    -> Pentaacetate  (five -OH)
```

## 2.1 The reactions the open chain could NOT explain

```
  +------------------------------------+--------------------------------+
  |  OBSERVATION                       |  WHY IT MATTERS                |
  +------------------------------------+--------------------------------+
  |  Does NOT give SCHIFF'S test       |  a genuine free -CHO would      |
  |                                    |  turn Schiff's reagent pink     |
  +------------------------------------+--------------------------------+
  |  Does NOT form the bisulphite      |  ordinary aldehydes add NaHSO3  |
  |  addition product with NaHSO3      |                                |
  +------------------------------------+--------------------------------+
  |  Does NOT react with NH3 as an     |  a free -CHO would              |
  |  ordinary aldehyde does            |                                |
  +------------------------------------+--------------------------------+
  |  Glucose PENTAACETATE does not     |  once the -OH groups are        |
  |  react with NH2OH                  |  blocked, the -CHO disappears   |
  +------------------------------------+--------------------------------+
  |  TWO crystalline forms exist       |  an open chain cannot give two  |
  |  (alpha and beta)                  |  such forms                     |
  +------------------------------------+--------------------------------+
  |  MUTAROTATION                      |  the two forms interconvert     |
  +------------------------------------+--------------------------------+

  ALL OF THESE ARE EXPLAINED BY THE CYCLIC HEMIACETAL (PYRANOSE) STRUCTURE.
```

# 7. AMINO ACIDS — THE FACTS

```
  GENERAL STRUCTURE OF AN ALPHA-AMINO ACID

                     R
                     |
              H2N -- C -- COOH        the alpha carbon carries
                     |                R , H , -NH2 and -COOH
                     H

  * about 20 amino acids occur in proteins
  * ALL except GLYCINE are optically active (glycine has R = H, so two
    of the four groups are the same)
  * the naturally occurring ones are all L-amino acids
  * they exist as ZWITTER IONS: high melting solids, water soluble,
    AMPHOTERIC
```

```
  +------------------------------+-------------------------------------+

```

```
  ISOELECTRIC POINT (pI)

     the pH at which the amino acid exists ENTIRELY as the zwitter ion,
     net charge is ZERO and it does NOT migrate to either electrode

     pH < pI   ->  CATION   ->  moves to the CATHODE
     pH = pI   ->  ZWITTER  ->  no movement , minimum solubility
     pH > pI   ->  ANION    ->  moves to the ANODE

     glycine pI = 6.0 , acidic amino acids pI ~ 3 , basic ones pI ~ 9-10
```

```
  DENATURATION

     definition : the loss of biological activity of a protein caused by
                  the destruction of its SECONDARY and TERTIARY structure,
                  the PRIMARY structure remaining intact

     causes     : heat , change of pH , heavy metal ions , alcohol , urea ,
                  UV radiation , violent shaking
     examples   : coagulation of egg white on boiling ,
                  curdling of milk (casein) by lactic acid
     reversible?: normally NO
```

```
  ENZYMES

     what        : biocatalysts; chemically they are GLOBULAR PROTEINS
     mechanism   : substrate binds at the ACTIVE SITE -> enzyme-substrate
                   complex -> activation energy lowered -> product
                   released -> enzyme free again    (LOCK AND KEY)
                        E + S <-> ES -> E + P
     efficiency  : rate increased by 10^6 to 10^20 times
     specificity : one enzyme, one reaction (urease acts only on urea)
     optimum T   : 298 - 310 K ; above this the enzyme is DENATURED
     optimum pH  : 5 to 7 for most (pepsin is the exception, ~pH 2)
     naming      : substrate + "ase"   maltose -> maltase
     helpers     : co-enzymes / activators (vitamins, metal ions)
     poisons     : inhibitors block the active site
```

```
  THE BASES

  +-------------------------+---------------------------------------------+
  |  PURINES (2 rings)      |  ADENINE (A)  ,  GUANINE (G)                |
  |                         |  present in BOTH DNA and RNA                |
  +-------------------------+---------------------------------------------+
  |  PYRIMIDINES (1 ring)   |  CYTOSINE (C)  - in both                    |
  |                         |  THYMINE  (T)  - DNA ONLY                   |
  |                         |  URACIL   (U)  - RNA ONLY                   |
  +-------------------------+---------------------------------------------+

  MEMORY :  "PURE As Gold"  ->  PURines = A and G
            "CUT the pie"   ->  PYrimidines = C, U, T
```

```
  BASE PAIRING AND CHARGAFF'S RULE

     A  ==  T      2 hydrogen bonds
     G  ==  C      3 hydrogen bonds
     A  ==  U      in RNA

     % A  =  % T        and        % G  =  % C
     % A + % T + % G + % C  =  100

     a PURINE always pairs with a PYRIMIDINE, so the helix stays
     exactly 2 nm wide all the way along
```

```
  FUNCTIONS

     REPLICATION    DNA -> DNA     (the helix unzips, each strand is a
                                    template, two identical copies result)
     TRANSCRIPTION  DNA -> m-RNA   (the message is copied, with U in place
                                    of T)
     TRANSLATION    m-RNA -> PROTEIN (the ribosome reads three bases at a
                                    time - a CODON - and t-RNA brings the
                                    matching amino acid)

     THE CENTRAL DOGMA :   DNA  --->  RNA  --->  PROTEIN
```
