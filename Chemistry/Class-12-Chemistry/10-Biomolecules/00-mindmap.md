## THE 60-SECOND VERSION

```
  A living body is a chemical factory. Four kinds of molecules run it:

  CARBOHYDRATES  =  the FUEL.       Rice, sugar, bread.
                    Made of glucose units joined together.

  PROTEINS       =  the MACHINES and the BUILDING BRICKS.
                    Made of amino acids joined by PEPTIDE BONDS.
                    Enzymes are proteins too.

  VITAMINS       =  the tiny HELPERS. The body cannot make them,
                    so you must eat them. Miss one -> get a disease.

  NUCLEIC ACIDS  =  the INSTRUCTION MANUAL. DNA stores the plan,
                    RNA carries it to the workshop and proteins get built.

  HORMONES       =  the MESSENGERS that tell organs what to do and when.
```

**One sentence to remember the whole thing:**
*Carbohydrates burn, proteins build, vitamins help, nucleic acids instruct,
hormones command.*

## HOW TO WRITE ANSWERS IN THIS CHAPTER (marks technique)

```
  1.  DEFINE FIRST.  Every answer starts with a one-line definition.
      The examiner has "definition ... 1 mark" printed on the key.

  2.  ALWAYS GIVE AN EXAMPLE.  "Reducing sugar - e.g. glucose, maltose."
      Examples carry half a mark each, and they are free.

  3.  DRAW SOMETHING.  A structure, even a rough one, earns marks that
      words alone will not. Label the anomeric carbon, the peptide bond,
      the glycosidic linkage.

  4.  USE THE TECHNICAL WORD.  Write "glycosidic linkage", not "joint".
      Write "zwitter ion", not "charged form". The key looks for the word.

  5.  TABLES.  For any "difference between" question, draw a two-column
      table. It is faster and the examiner can count the points.

  6.  NEVER LEAVE IT BLANK.  This chapter is descriptive - partial
      knowledge still earns partial marks. Write whatever you know.
```
