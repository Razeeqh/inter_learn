# TOPIC 0 — WHAT IS A BIOMOLECULE?

Your body is not magic. It is chemistry in a bag of water.

**Biomolecules** are the organic compounds that build up living organisms and
run all the processes inside them.

```
  +------------------------------------------------------------------+
  |                                                                  |
  |   BIOMOLECULE  =  an organic compound present in a living cell,   |
  |                   essential for its structure and its working     |
  |                                                                  |
  +------------------------------------------------------------------+

  The five you must know:

  +---------------+-------------------------+------------------------+
  |  CLASS        |  BUILT FROM             |  MAIN JOB              |
  +---------------+-------------------------+------------------------+
  |  Carbohydrate |  monosaccharides        |  energy + structure    |
  |  Protein      |  amino acids            |  building + enzymes    |
  |  Vitamin      |  (small, varied)        |  helper molecules      |
  |  Nucleic acid |  nucleotides            |  storing instructions  |
  |  Hormone      |  (steroid/peptide/AA)   |  chemical messages     |
  +---------------+-------------------------+------------------------+
```

**Everyday analogy — the body as a factory:**

```
  CARBOHYDRATES  =  the diesel in the generator
  PROTEINS       =  the machines, the walls, and the workers
  ENZYMES        =  the specialised tools each worker holds
  VITAMINS       =  the grease and the small spare parts
  NUCLEIC ACIDS  =  the blueprint locked in the manager's cabinet
  HORMONES       =  the announcements on the factory loudspeaker
```

# TOPIC 1 — CARBOHYDRATES: WHAT THEY ARE

## 1.1 The old name and the modern definition

Long ago chemists saw that sugars had the formula `Cx(H2O)y` — carbon plus water —
so they called them **carbohydrates** ("hydrates of carbon").

```
  Glucose   C6H12O6   =  C6 (H2O)6      looks like carbon + water
  Sucrose   C12H22O11 =  C12 (H2O)11
```

That old idea **fails**, so do not use it as a definition:

```
  Rhamnose  C6H12O5   -  IS a carbohydrate but the formula is NOT Cx(H2O)y
  Acetic acid CH3COOH = C2(H2O)2  -  FITS the formula but is NOT a carbohydrate
  Formaldehyde HCHO   = C(H2O)    -  FITS the formula but is NOT a carbohydrate
```

**The definition you write in the exam:**

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   CARBOHYDRATES are optically active POLYHYDROXY ALDEHYDES or       |
  |   POLYHYDROXY KETONES, or compounds which give these on HYDROLYSIS. |
  |                                                                    |
  +--------------------------------------------------------------------+

  Break that up:
     poly-hydroxy   -> many  -OH  groups
     aldehyde       -> a     -CHO group   (glucose)
     ketone         -> a     >C=O group   (fructose)
     or on hydrolysis -> sucrose itself is neither, but it breaks into
                         glucose and fructose which are.
```

> **TRAP:** If you define carbohydrates as "hydrates of carbon, Cx(H2O)y" you
> lose the mark. The examiner is looking for the words **polyhydroxy aldehydes
> or ketones**.

## 1.2 The general "sugar / non-sugar" split

```
  SUGARS      -  sweet in taste, crystalline solids, soluble in water
                 e.g. glucose, fructose, sucrose, maltose, lactose

  NON-SUGARS  -  tasteless, amorphous, insoluble in water
                 e.g. starch, cellulose, glycogen
```

# TOPIC 2 — CLASSIFICATION OF CARBOHYDRATES

This is the most frequently asked 2- and 4-mark question in the chapter.
Learn the tree, learn the numbers, learn one example of each.

```
                          C A R B O H Y D R A T E S
                    (classified by what HYDROLYSIS gives)
                                     |
        +----------------------------+----------------------------+
        |                            |                            |
  MONOSACCHARIDES            OLIGOSACCHARIDES             POLYSACCHARIDES
  cannot be hydrolysed       give 2 to 10 mono-           give a LARGE number
  into simpler sugars        saccharide units             of monosaccharide
                                     |                    units
        |                            |                            |
   glucose                    +------+------+               starch
   fructose                   |      |      |               cellulose
   galactose             DI-  TRI-  TETRA-                  glycogen
   ribose                (2)  (3)   (4)
                          |     |     |
                      sucrose raffinose stachyose
                      maltose
                      lactose
```

## 2.1 The four ways of classifying — put ALL of them in a 4-mark answer

```
  +----+-------------------+---------------------------------------------+
  | 1  | BY HYDROLYSIS     |  mono / oligo (di, tri...) / poly           |
  +----+-------------------+---------------------------------------------+
  | 2  | BY TASTE          |  sugars (sweet, crystalline)                |
  |    |                   |  non-sugars (tasteless, amorphous)          |
  +----+-------------------+---------------------------------------------+
  | 3  | BY REDUCING POWER |  reducing sugars   - reduce Tollens/Fehling |
  |    |                   |  non-reducing      - do not                 |
  +----+-------------------+---------------------------------------------+
  | 4  | BY FUNCTIONAL     |  ALDOSE - contains -CHO   (glucose)         |
  |    | GROUP             |  KETOSE - contains >C=O   (fructose)        |
  +----+-------------------+---------------------------------------------+

  A monosaccharide is also named by HOW MANY CARBONS it has:

  +---------+---------+-------------+----------------+------------------+
  | CARBONS |  NAME   |  ALDOSE     |  KETOSE        |  EXAMPLE         |
  +---------+---------+-------------+----------------+------------------+
  |    3    |  triose |  aldotriose |  ketotriose    | glyceraldehyde   |
  |    4    |  tetrose|  aldotetrose|  ketotetrose   | erythrose        |
  |    5    |  pentose|  aldopentose|  ketopentose   | ribose           |
  |    6    |  hexose |  aldohexose |  ketohexose    | GLUCOSE / FRUCTOSE|
  +---------+---------+-------------+----------------+------------------+

  GLUCOSE  = aldohexose  (6 carbons, -CHO)
  FRUCTOSE = ketohexose  (6 carbons, >C=O)
```

## 2.2 Reducing and non-reducing sugars

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  A REDUCING SUGAR is a carbohydrate that REDUCES Tollens' reagent   |
  |  (giving a silver mirror) and Fehling's solution (giving a red      |
  |  precipitate of Cu2O), because it has a FREE aldehyde or ketone     |
  |  group (a free anomeric carbon).                                    |
  |                                                                    |
  +--------------------------------------------------------------------+

  REDUCING      : ALL monosaccharides (glucose, fructose, galactose,
                  ribose...) , plus MALTOSE and LACTOSE
  NON-REDUCING  : SUCROSE , and the polysaccharides (starch, cellulose)
```

**The tests, written as reactions:**

```
  Tollens' test:
     glucose + 2 [Ag(NH3)2]OH  ---->  gluconic acid + 2 Ag (silver mirror)

  Fehling's test:
     glucose + 2 Cu2+ (in alkali)  --->  gluconic acid + Cu2O (red ppt)
```

> **TRAP:** Everyone forgets that **fructose is a KETOSE and still reducing**.
> A question "which of these is a reducing sugar" with fructose in the options
> is designed to catch you. See Topic 7 for why.

## WORKED EXAMPLE 2.1

**Q. Classify the following and say whether each is reducing:
sucrose, maltose, fructose, cellulose.**

```
  STEP 1  Ask: how many units does hydrolysis give?

     sucrose    ->  2 units (glucose + fructose)   ->  DISACCHARIDE
     maltose    ->  2 units (glucose + glucose)    ->  DISACCHARIDE
     fructose   ->  cannot be hydrolysed           ->  MONOSACCHARIDE
     cellulose  ->  very many glucose units        ->  POLYSACCHARIDE

  STEP 2  Ask: is there a FREE aldehyde/ketone (free anomeric carbon)?

     sucrose    ->  BOTH anomeric carbons are used in the linkage
                    ->  NON-REDUCING
     maltose    ->  one anomeric carbon is free    ->  REDUCING
     fructose   ->  free keto group, and it isomerises in alkali
                    ->  REDUCING
     cellulose  ->  the free ends are negligible   ->  NON-REDUCING

  ANSWER
     sucrose   - disaccharide  - non-reducing
     maltose   - disaccharide  - reducing
     fructose  - monosaccharide (ketohexose) - reducing
     cellulose - polysaccharide - non-reducing
```

# TOPIC 3 — GLUCOSE: PREPARATION

Glucose is also called **dextrose**, **grape sugar** and **blood sugar**.
Formula **C6H12O6**, molar mass 180.

## 3.1 From sucrose (cane sugar) — the laboratory method

```
  Boil sucrose with dilute HCl or dilute H2SO4 in ALCOHOLIC solution.

    C12H22O11  +  H2O  --(dil. HCl / H+)-->   C6H12O6   +   C6H12O6
      sucrose                                 GLUCOSE      FRUCTOSE

  Glucose is insoluble in alcohol, so it CRYSTALLISES OUT first
  and can be filtered off, leaving fructose in solution.
```

## 3.2 From starch — the commercial (industrial) method

```
  Hydrolyse starch (from maize, potato, rice) with dilute H2SO4:

    (C6H10O5)n  +  n H2O   --------------------->   n C6H12O6
       starch                393 K , 2-3 atm            GLUCOSE
                             dil. H2SO4

  CONDITIONS YOU MUST WRITE:  393 K temperature , 2 to 3 atmosphere
                              pressure , dilute H2SO4
```

> **TRAP:** In the sucrose method the important extra words are
> **"in alcoholic solution"** (that is what makes glucose separate out).
> In the starch method the important extra words are **"393 K, 2-3 atm"**.
> One mark is given for the condition alone.

# TOPIC 4 — HOW THE OPEN-CHAIN STRUCTURE OF GLUCOSE WAS PROVED

This is the classic **4-mark question**: *"Give the reactions which show the
structure of glucose"* or *"How is the open chain structure of glucose
established?"*

There are seven pieces of evidence. Learn them as a story: each experiment
answers one question.

```
  +-----+---------------------------+-------------------------------------+
  |  #  |  EXPERIMENT               |  WHAT IT PROVES                     |
  +-----+---------------------------+-------------------------------------+
  |  1  |  elemental analysis       |  molecular formula is C6H12O6       |
  |  2  |  HI , prolonged heating   |  6 carbons in a STRAIGHT chain      |
  |  3  |  NH2OH -> oxime           |  a CARBONYL group ( >C=O ) exists   |
  |     |  HCN   -> cyanohydrin     |                                     |
  |  4  |  bromine water -> gluconic|  the carbonyl is an ALDEHYDE -CHO   |
  |     |  acid (6 C acid)          |                                     |
  |  5  |  acetic anhydride ->      |  FIVE  -OH groups, one on each of   |
  |     |  glucose PENTAacetate     |  five different carbons             |
  |  6  |  conc. HNO3 -> saccharic  |  a primary -CH2OH at the far end    |
  |     |  acid (di-acid)           |  from the -CHO                      |
  |  7  |  Tollens' / Fehling's     |  confirms the free -CHO             |
  +-----+---------------------------+-------------------------------------+
```

## Evidence 1 — the formula

Elemental analysis plus molecular mass determination gives **C6H12O6**.

## Evidence 2 — prolonged heating with HI gives n-hexane

```
  C6H12O6   --(HI , red P , prolonged heating, 373 K)-->   CH3(CH2)4CH3
   glucose                                                   n-HEXANE

  HI strips off every oxygen. What is left is a STRAIGHT six-carbon chain.

  CONCLUSION : the six carbon atoms of glucose are in an unbranched chain.
```

## Evidence 3 — reaction with hydroxylamine and with HCN

```
  Glucose  +  NH2OH   ------>   glucose OXIME   (C6H12O6 = NOH)
                                 |
                                 +-- an oxime is formed only by >C=O

  Glucose  +  HCN     ------>   glucose CYANOHYDRIN
                                 |
                                 +-- only ONE molecule of HCN adds,
                                     so there is only ONE carbonyl group

  CONCLUSION : glucose contains ONE carbonyl group.
```

Written as structures:

```
     CHO                          CH=N-OH                     CN
      |          NH2OH             |           HCN            |
   (CHOH)4      -------->       (CHOH)4      -------->     H-C-OH
      |                            |                          |
    CH2OH                        CH2OH                     (CHOH)4
                                                              |
                                                            CH2OH
```

## Evidence 4 — bromine water gives gluconic acid

```
     CHO                                    COOH
      |          Br2 water (mild oxidising)   |
   (CHOH)4      ------------------------->  (CHOH)4
      |                                       |
    CH2OH                                   CH2OH
    glucose                              GLUCONIC ACID
                                     (a SIX-carbon monocarboxylic acid)

  Bromine water is a MILD oxidising agent - it oxidises only -CHO.
  The product still has SIX carbons, so the -CHO was at the END of the chain.

  CONCLUSION : the carbonyl group is an ALDEHYDE group, and it is at C1.
```

## Evidence 5 — acetic anhydride gives glucose pentaacetate

```
  Glucose  +  5 (CH3CO)2O   ------>   GLUCOSE PENTAACETATE  +  5 CH3COOH

  FIVE acetyl groups go in  ->  glucose has FIVE  -OH groups.

  And because the compound is STABLE, the five -OH groups must be on
  FIVE DIFFERENT carbon atoms. (Two -OH on the same carbon is a gem-diol,
  which is unstable and loses water at once.)

  CONCLUSION : five -OH groups, one each on C2, C3, C4, C5 and C6.
```

## Evidence 6 — oxidation with nitric acid gives saccharic acid

```
     CHO                                   COOH
      |            conc. HNO3                |
   (CHOH)4       ------------------>      (CHOH)4
      |          (strong oxidation)          |
    CH2OH                                  COOH
    glucose                            SACCHARIC ACID
                                    (a DIcarboxylic acid, 6 carbons)

  Nitric acid is a STRONG oxidising agent - it oxidises BOTH the -CHO
  AND the primary alcohol -CH2OH into -COOH groups.

  The product is a DI-acid, so glucose must have had a -CHO at one end
  and a PRIMARY alcohol -CH2OH at the other end.

  CONCLUSION : glucose is a straight chain with -CHO at C1 and -CH2OH at C6.
```

## Putting it all together — THE OPEN CHAIN STRUCTURE

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |          C1      CHO                                               |
  |                   |                                                |
  |          C2     H-C-OH                                             |
  |                   |                                                |
  |          C3    HO-C-H            D-(+)-GLUCOSE                     |
  |                   |              (also called dextrose)            |
  |          C4     H-C-OH                                             |
  |                   |                                                |
  |          C5     H-C-OH                                             |
  |                   |                                                |
  |          C6      CH2OH                                             |
  |                                                                    |
  |   short form :   CHO - (CHOH)4 - CH2OH                             |
  |                                                                    |
  |   IUPAC-ish name : 2,3,4,5,6-pentahydroxyhexanal                   |
  |                                                                    |
  +--------------------------------------------------------------------+

  Why "D" ?   Because the -OH on the LAST chiral carbon (C5) is written
              on the RIGHT in the Fischer projection.
  Why "(+)" ? Because a solution of glucose rotates plane polarised light
              to the RIGHT (dextrorotatory).

  D and (+) are INDEPENDENT ideas. D is about the arrangement of groups,
  (+) is about the direction of optical rotation.
```

> **TRAP:** "D" does NOT mean dextrorotatory. Fructose is **D-(−)-fructose** —
> D configuration but laevorotatory. If a question says "the D in D-glucose
> stands for dextrorotatory", it is FALSE.

## WORKED EXAMPLE 4.1

**Q. Glucose reacts with bromine water to give a compound A, and with
concentrated HNO3 to give a compound B. Identify A and B, and say what
each tells you about the structure of glucose. (4 marks)**

```
  STEP 1  Bromine water is a MILD oxidising agent.
          It attacks only the -CHO group.

          A  =  GLUCONIC ACID  ,  COOH-(CHOH)4-CH2OH

  STEP 2  What does it prove?
          The product has SIX carbons and ONE -COOH.
          -> the carbonyl group in glucose is an ALDEHYDE, sitting at
             the end of the chain (C1).

  STEP 3  Concentrated HNO3 is a STRONG oxidising agent.
          It attacks the -CHO AND the terminal -CH2OH.

          B  =  SACCHARIC ACID  ,  COOH-(CHOH)4-COOH

  STEP 4  What does it prove?
          The product is a DIcarboxylic acid of six carbons.
          -> there is a PRIMARY alcohol group -CH2OH at the other end
             of the chain (C6).

  ANSWER  A = gluconic acid  (proves the -CHO group)
          B = saccharic acid (proves the terminal -CH2OH group)
```

# TOPIC 5 — WHAT THE OPEN-CHAIN STRUCTURE COULD NOT EXPLAIN

The open chain structure was a triumph — and then five awkward facts appeared.
If glucose really had a free `-CHO` group, all of these should have worked.
None of them did.

```
  +---+----------------------------------------------------------------+
  | 1 | Glucose does NOT give the SCHIFF'S test.                        |
  |   | (Schiff's reagent goes pink with a genuine free aldehyde.)      |
  +---+----------------------------------------------------------------+
  | 2 | Glucose does NOT form the hydrogensulphite addition product     |
  |   | with NaHSO3, though ordinary aldehydes do.                      |
  +---+----------------------------------------------------------------+
  | 3 | Glucose does NOT react with AMMONIA (NH3) the way an ordinary   |
  |   | aldehyde does.                                                  |
  +---+----------------------------------------------------------------+
  | 4 | GLUCOSE PENTAACETATE does NOT react with hydroxylamine.         |
  |   | If a free -CHO existed it would still form an oxime. So once    |
  |   | the five -OH groups are blocked, the aldehyde has vanished.     |
  +---+----------------------------------------------------------------+
  | 5 | Glucose exists in TWO crystalline forms, alpha and beta, with   |
  |   | different melting points and different specific rotations.      |
  |   | An open chain cannot give two such forms.                       |
  +---+----------------------------------------------------------------+
  | 6 | MUTAROTATION - the specific rotation of a fresh solution        |
  |   | slowly CHANGES until it settles at a fixed value.               |
  +---+----------------------------------------------------------------+
```

**The two crystalline forms — learn these numbers:**

```
  +------------------------+---------------------+---------------------+
  |                        |  alpha-D-glucose    |  beta-D-glucose     |
  +------------------------+---------------------+---------------------+
  |  How it is obtained    |  crystallised from  |  crystallised from  |
  |                        |  a concentrated     |  a hot saturated    |
  |                        |  solution at 303 K  |  solution at 371 K  |
  |  Melting point         |  419 K              |  423 K              |
  |  Specific rotation     |  + 111 degrees      |  + 19.2 degrees     |
  |  -OH at C1 (Haworth)   |  DOWN (below ring)  |  UP (above ring)    |
  +------------------------+---------------------+---------------------+

  Both, kept in water, drift to  + 52.5 degrees.
```

**The explanation:** glucose is not really an open chain in solution.
The `-OH` on C5 attacks the `-CHO` on C1 and closes a **six-membered ring**.
That is the cyclic hemiacetal structure.

# TOPIC 6 — THE CYCLIC STRUCTURE, ANOMERS AND MUTAROTATION

## 6.1 Why the ring forms

```
  An -OH group and a -CHO group in the SAME molecule can react with each
  other to give a HEMIACETAL:

          -OH   +   -CHO   ---->   -C-OH        (a hemiacetal carbon:
                                    |            it carries both an -OH
                                   -O-           and an -O- )

  In glucose the -OH on C5 reaches round and attacks the -CHO on C1.
  That closes a SIX-membered ring (5 carbons + 1 oxygen).

  A six-membered sugar ring is called a PYRANOSE ring
  (after the compound "pyran"). Hence:  GLUCOPYRANOSE.
```

## 6.2 The anomeric carbon and the two anomers

```
  When C1 becomes part of the ring, it turns into a NEW chiral centre.
  Its -OH can point DOWN or UP. Two different compounds result.

  +--------------------------------------------------------------------+
  |                                                                    |
  |   ANOMERIC CARBON  =  the carbon that was the carbonyl carbon and   |
  |                       became a new chiral centre on ring closure    |
  |                       (C1 in glucose, C2 in fructose)               |
  |                                                                    |
  |   ANOMERS  =  two cyclic forms of a sugar that differ ONLY in the   |
  |               configuration at the anomeric carbon                  |
  |                                                                    |
  |        alpha  -  the C1 -OH is BELOW the plane of the ring          |
  |        beta   -  the C1 -OH is ABOVE the plane of the ring          |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## 6.3 The HAWORTH projection — draw this, it earns marks

```
    a l p h a - D - ( + ) - G L U C O P Y R A N O S E

                     6 CH2OH
                        |
                        |
                        C5 --------------- O
                       /                     \
                      /                       \
                     /                         \
              4    C4                           C1  ---- H
                  /  \                         /   \
                 /    \                       /     OH        <-- alpha :
               OH      \                     /                    OH is DOWN
                        C3 --------------- C2
                       /  \               /  \
                     OH    H            H     OH


    b e t a - D - ( + ) - G L U C O P Y R A N O S E

                     6 CH2OH
                        |
                        |
                        C5 --------------- O
                       /                     \
                      /                       \
                     /                         \
              4    C4                           C1  ---- OH   <-- beta :
                  /  \                         /   \              OH is UP
                 /    \                       /     H
               OH      \                     /
                        C3 --------------- C2
                       /  \               /  \
                     OH    H            H     OH


  QUICK RULE FOR WHERE EACH GROUP GOES (alpha-D-glucopyranose):

      C1 -OH   ->  DOWN     (this is what makes it ALPHA)
      C2 -OH   ->  DOWN
      C3 -OH   ->  UP
      C4 -OH   ->  DOWN
      C5 CH2OH ->  UP

  For BETA, everything is the same EXCEPT the C1 -OH, which points UP.
```

**The whole equilibrium in one picture:**

```
                          OPEN CHAIN
                       (only ~0.02% present)
                            CHO
                             |
                          (CHOH)4
                             |
                           CH2OH
                         /        \
                        /          \
                       v            v
        alpha-D-glucopyranose   beta-D-glucopyranose
             (about 36%)             (about 64%)
             [a]D = +111             [a]D = +19.2

        Mixture at equilibrium :  [a]D  =  + 52.5 degrees
```

## 6.4 MUTAROTATION — learn this definition word for word

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   MUTAROTATION is the spontaneous CHANGE in the specific optical    |
  |   rotation of a freshly prepared solution of a sugar until it       |
  |   reaches a constant equilibrium value.                             |
  |                                                                    |
  |   It happens because the alpha form and the beta form interconvert  |
  |   through the small amount of OPEN CHAIN form present in solution,  |
  |   until an equilibrium mixture of the two anomers is reached.       |
  |                                                                    |
  +--------------------------------------------------------------------+

  In numbers, for glucose:

     pure alpha form dissolved :  +111  --> falls  --> settles at +52.5
     pure beta  form dissolved :  +19.2 --> rises  --> settles at +52.5
```

> **TRAP:** Mutarotation is **not** the same as inversion of cane sugar.
> Mutarotation = one sugar changing between its own two anomers.
> Inversion = sucrose being hydrolysed into two different sugars.
> Examiners love putting both in the same paper.

---

## WORKED EXAMPLE 6.1

**Q. A freshly prepared solution of alpha-D-glucose has a specific rotation
of +111 degrees. After a few hours the value is +52.5 degrees. Explain.
(4 marks)**

```
  STEP 1  Name the phenomenon.
          This is MUTAROTATION.

  STEP 2  Say why the alpha form does not stay alpha.
          In water the ring opens at the anomeric carbon (C1) to give a
          small amount of the OPEN CHAIN aldehyde form.

  STEP 3  Say what the open chain does.
          The open chain can re-close in EITHER direction, giving the
          alpha form (OH down at C1) or the beta form (OH up at C1).

  STEP 4  Say where it stops.
          The process continues until an equilibrium is set up:
                 about 36 % alpha  ( [a]D = +111 )
                 about 64 % beta   ( [a]D = +19.2 )
          The observed rotation of that mixture is + 52.5 degrees,
          and it does not change any further.

  ANSWER  The fall from +111 to +52.5 is mutarotation: alpha-D-glucose
          converts partly into beta-D-glucose through the open chain
          form until the equilibrium mixture (36% alpha + 64% beta,
          [a]D = +52.5) is reached.
```

# TOPIC 7 — FRUCTOSE

```
  Fructose  -  C6H12O6  -  a KETOHEXOSE  -  D-(-)-fructose
               also called FRUIT SUGAR or LAEVULOSE
               the SWEETEST natural sugar
               found in honey and fruits; with glucose it makes sucrose
```

## 7.1 Open chain structure

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |          C1      CH2OH                                             |
  |                    |                                               |
  |          C2      C = O          <-- the KETO group, at C2          |
  |                    |                                               |
  |          C3    HO-C-H                                              |
  |                    |                D-(-)-FRUCTOSE                 |
  |          C4     H-C-OH                                             |
  |                    |                                               |
  |          C5     H-C-OH                                             |
  |                    |                                               |
  |          C6      CH2OH                                             |
  |                                                                    |
  +--------------------------------------------------------------------+

  Note: fructose has the same molecular formula as glucose (C6H12O6)
  but the carbonyl is a KETONE at C2, not an aldehyde at C1.
  -> glucose and fructose are FUNCTIONAL ISOMERS.
```

## 7.2 The ring form is a FIVE-membered FURANOSE ring

```
  In fructose the -OH on C5 attacks the keto group on C2.
  That closes a FIVE-membered ring (4 carbons + 1 oxygen) called a
  FURANOSE ring. The anomeric carbon is C2.

        b e t a - D - F R U C T O F U R A N O S E

                  HOCH2            O            CH2OH  (C6)
                   (C1)  \                  /
                          \                /
                           C2 ---------- C5
                          /  \          /  \
                        OH    \        /    H
                               C3 -- C4
                              /  \  /  \
                             H   OH OH  H

  MEMORY HOOK :   Fructose -> Furanose   (both start with F)
                  Glucose  -> Pyranose   (the bigger, 6-membered ring)
```

## 7.3 Why is fructose a REDUCING sugar even though it is a ketone?

This is a favourite 2-mark and MCQ question.

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  Tollens' and Fehling's reagents are ALKALINE (basic).              |
  |                                                                    |
  |  In an alkaline medium fructose ISOMERISES: the keto group at C2    |
  |  shifts through an ENEDIOL intermediate and fructose is converted   |
  |  into GLUCOSE (and mannose), which contain a free -CHO group.       |
  |                                                                    |
  |  The -CHO group then reduces Tollens' and Fehling's reagents.       |
  |                                                                    |
  |  Therefore fructose, though a ketose, IS a reducing sugar.          |
  |                                                                    |
  +--------------------------------------------------------------------+

      CH2OH               CHOH                 CHO
       |                   ||                   |
       C=O   --(OH-)-->    C-OH   --------->  H-C-OH
       |                   |                    |
     (CHOH)3            (CHOH)3              (CHOH)3
       |                   |                    |
      CH2OH               CH2OH                CH2OH
    FRUCTOSE            ENEDIOL              GLUCOSE
```

> **TRAP:** Fructose does **not** decolourise bromine water. Bromine water is
> NEUTRAL, so no isomerisation happens and the keto group is untouched.
> **That is exactly how you distinguish glucose from fructose**:
> bromine water oxidises glucose but not fructose.

# TOPIC 8 — DISACCHARIDES

```
  A DISACCHARIDE gives TWO monosaccharide units on hydrolysis.
  The two units are joined by an oxygen bridge called a
  GLYCOSIDIC LINKAGE, formed by the loss of a water molecule between
  the -OH groups of the two units.

        Sugar-1 - OH  +  HO - Sugar-2   ----->   Sugar-1 - O - Sugar-2  + H2O
                                                          ^
                                                    glycosidic linkage
```

## 8.1 SUCROSE — cane sugar, table sugar

```
  +--------------------------------------------------------------------+
  |  SUCROSE   C12H22O11                                               |
  |                                                                    |
  |  Units      :  alpha-D-glucose  +  beta-D-fructose                 |
  |  Linkage    :  C1 of glucose  --O--  C2 of fructose                |
  |                (an alpha-1,2 glycosidic linkage)                    |
  |  Reducing?  :  NO - it is NON-REDUCING                              |
  |  Rotation   :  + 66.5 degrees  (dextrorotatory)                     |
  +--------------------------------------------------------------------+

  Schematically:

     [ alpha-D-GLUCOSE ] -- C1 -- O -- C2 -- [ beta-D-FRUCTOSE ]
             (pyranose)                            (furanose)

  WHY IS SUCROSE NON-REDUCING?
     Because the linkage uses the ANOMERIC CARBON of BOTH sugars
     (C1 of glucose AND C2 of fructose). Neither unit can open into
     a free aldehyde or ketone, so there is nothing left to reduce
     Tollens' or Fehling's reagent.
```

## 8.2 INVERSION and INVERT SUGAR

```
  Hydrolyse sucrose with dilute acid, or with the enzyme INVERTASE:

     C12H22O11  +  H2O  ------>   C6H12O6   +   C6H12O6
      sucrose                      glucose      fructose
     [a] = +66.5                   +52.5         -92.4

  The rotation of the equimolar product mixture:

              ( +52.5 ) + ( -92.4 )       -39.9
              ---------------------  =  --------- = about  -20 degrees
                        2                   2

  +--------------------------------------------------------------------+
  |                                                                    |
  |  INVERSION OF CANE SUGAR :                                          |
  |  On hydrolysis the optical rotation changes from DEXTROrotatory     |
  |  (+66.5) to LAEVOrotatory (about -20). This SIGN CHANGE is called    |
  |  INVERSION, and the product mixture is called INVERT SUGAR.         |
  |                                                                    |
  |  Reason: fructose is much more strongly laevorotatory (-92.4) than  |
  |  glucose is dextrorotatory (+52.5), so the mixture is net negative. |
  |                                                                    |
  +--------------------------------------------------------------------+

  HONEY is mainly invert sugar - which is why honey is sweeter than
  cane sugar (fructose is the sweetest sugar).
```

## 8.3 MALTOSE — malt sugar

```
  +--------------------------------------------------------------------+
  |  MALTOSE   C12H22O11                                               |
  |                                                                    |
  |  Units     :  TWO alpha-D-glucose units                            |
  |  Linkage   :  C1 of the first  --O--  C4 of the second             |
  |               (an ALPHA-1,4 glycosidic linkage)                     |
  |  Reducing? :  YES - the C1 of the SECOND glucose is FREE            |
  |  Source    :  produced when starch is hydrolysed (malt, barley)     |
  +--------------------------------------------------------------------+

     [ alpha-D-GLUCOSE ] -- C1 -- O -- C4 -- [ alpha-D-GLUCOSE ]
                                                     |
                                            its C1 is FREE -> reducing
```

## 8.4 LACTOSE — milk sugar

```
  +--------------------------------------------------------------------+
  |  LACTOSE   C12H22O11                                               |
  |                                                                    |
  |  Units     :  beta-D-GALACTOSE  +  beta-D-GLUCOSE                  |
  |  Linkage   :  C1 of galactose  --O--  C4 of glucose                |
  |               (a BETA-1,4 glycosidic linkage)                       |
  |  Reducing? :  YES - the C1 of glucose is FREE                       |
  |  Source    :  milk (about 5% of cow's milk)                         |
  +--------------------------------------------------------------------+

     [ beta-D-GALACTOSE ] -- C1 -- O -- C4 -- [ beta-D-GLUCOSE ]
                                                      |
                                             its C1 is FREE -> reducing
```

```
  +----------+------------------+--------------+-----------+------------+
  |  SUGAR   |  UNITS           |  LINKAGE     | REDUCING? |  SOURCE    |
  +----------+------------------+--------------+-----------+------------+
  | SUCROSE  | glucose+fructose | alpha 1 -> 2 |    NO     | sugarcane  |
```

## WORKED EXAMPLE 8.1

**Q. Why is sucrose non-reducing while maltose is reducing? (2 marks)**

```
  ANSWER
  In SUCROSE the glycosidic linkage is formed between C1 of glucose
  (its anomeric carbon) and C2 of fructose (its anomeric carbon).
  BOTH anomeric carbons are blocked, so neither ring can open to give a
  free -CHO or >C=O group. Hence sucrose is non-reducing.

  In MALTOSE the linkage is between C1 of the first glucose and C4 of the
  second glucose. The anomeric carbon (C1) of the SECOND glucose unit is
  still FREE, so that ring can open to give a free -CHO group.
  Hence maltose is reducing.
```

```
  A POLYSACCHARIDE gives a LARGE NUMBER of monosaccharide units on
```

## 9.1 STARCH — the food store of plants

```
  Formula  (C6H10O5)n     Source: rice, wheat, potato, maize
  Starch is the main dietary source of carbohydrate for humans.

  Starch is a MIXTURE of TWO polysaccharides:

  +----------------+------------------------+-------------------------+
  |                |  AMYLOSE               |  AMYLOPECTIN            |
  +----------------+------------------------+-------------------------+
  |  % of starch   |  15 - 20 %             |  80 - 85 %              |
  |  Structure     |  LINEAR, unbranched    |  BRANCHED               |
  |                |  (coiled into a helix) |                         |
  |  Linkage       |  alpha-1,4 only        |  alpha-1,4 in the chain |
  |                |                        |  + alpha-1,6 at each    |
  |                |                        |  BRANCH POINT           |
  |  Units         |  200 - 1000 glucose    |  many thousands         |
  |  Water soluble |  SOLUBLE in hot water  |  INSOLUBLE              |
  +----------------+------------------------+-------------------------+

  AMYLOSE (straight chain):

     G--G--G--G--G--G--G--G--G--G--G--G--G          all alpha 1->4

  AMYLOPECTIN (branched):

     G--G--G--G--G--G--G--G--G--G--G--G--G--G
                 |                    |
                 G                    G            <-- alpha 1->6
                 |                    |                branch points
                 G--G--G              G--G--G
                       |
                       G
                       |
                       G--G--G

  TEST :  starch + iodine solution  ->  deep BLUE colour
```

## 9.2 CELLULOSE — the structural material of plants

```
  Formula  (C6H10O5)n
  The MOST ABUNDANT organic substance in the plant world.
  Cotton is about 90% cellulose; wood, paper and jute are largely cellulose.

  +--------------------------------------------------------------------+
  |  CELLULOSE                                                         |
  |                                                                    |
  |  Units    :  only BETA-D-glucose                                   |
  |  Linkage  :  C1 --O-- C4 , a BETA-1,4 glycosidic linkage           |
  |  Shape    :  STRAIGHT chains, no branching                         |
  |  Held by  :  hydrogen bonds BETWEEN neighbouring chains, which is   |
  |              why it is a strong, rigid FIBRE                        |
  |  Function :  the CELL WALL of plants - structural, not food         |
  +--------------------------------------------------------------------+

      G --- G --- G --- G --- G --- G      all BETA 1->4, perfectly straight
      |     |     |     |     |     |
     ~~~~ hydrogen bonds to the next chain ~~~~
      |     |     |     |     |     |
      G --- G --- G --- G --- G --- G

  WHY CAN'T HUMANS DIGEST CELLULOSE?
     Human digestive enzymes can break ALPHA-1,4 linkages (starch) but
     NOT BETA-1,4 linkages (cellulose). Cows and termites can, because
     bacteria in their gut supply the enzyme cellulase.
     Cellulose in our food acts as DIETARY FIBRE (roughage).
```

## 9.5 IMPORTANCE OF CARBOHYDRATES

```
  1.  ENERGY.  Carbohydrates are the chief source of energy for plants
      and animals. 1 gram of carbohydrate gives about 4 kcal.
      Glucose is the fuel that the brain runs on.

  2.  STORAGE.  Starch stores energy in plants; glycogen stores it in
      animals.

  3.  STRUCTURE.  Cellulose builds the cell wall of plants. Chitin
      builds the shells of insects and crustaceans.

  4.  PART OF NUCLEIC ACIDS.  D-ribose and 2-deoxy-D-ribose are the
      sugars in RNA and DNA.

  5.  IN THE CELL MEMBRANE.  Carbohydrates combine with proteins
      (glycoproteins) and lipids (glycolipids) in cell membranes and
      are involved in cell recognition, including blood groups.

  6.  INDUSTRY.  Cellulose gives us paper, cotton textiles, rayon,
      cellulose nitrate and cellulose acetate.
```

# TOPIC 10 — AMINO ACIDS

## 10.1 What they are

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  An AMINO ACID contains BOTH an amino group (-NH2) and a            |
  |  carboxyl group (-COOH) in the same molecule.                       |
  |                                                                    |
  |  All naturally occurring amino acids are ALPHA-AMINO ACIDS:         |
  |  the -NH2 group is on the carbon NEXT TO the -COOH group            |
  |  (the alpha carbon).                                                |
  |                                                                    |
  +--------------------------------------------------------------------+

  GENERAL STRUCTURE:

                     R
                     |
              H2N -- C -- COOH
                     |
                     H

              the carbon carrying R, H, NH2 and COOH is the ALPHA carbon

  R is the SIDE CHAIN and it is what makes one amino acid different
  from another:

       R = H          ->  GLYCINE     (the simplest; NOT chiral)
       R = CH3        ->  ALANINE
       R = CH2-C6H5   ->  PHENYLALANINE
       R = CH2SH      ->  CYSTEINE

  There are about 20 amino acids that occur in proteins.
  EXCEPT GLYCINE, all of them are OPTICALLY ACTIVE (the alpha carbon
  has four different groups). Naturally occurring ones are L-amino acids.
```

## 10.2 Classification by the side chain

```
  ACIDIC     -  the side chain has an extra -COOH
                e.g. aspartic acid , glutamic acid

  BASIC      -  the side chain has an extra -NH2
                e.g. lysine , arginine

  NEUTRAL    -  equal numbers of -NH2 and -COOH
                e.g. glycine , alanine , valine
```

## 10.3 ESSENTIAL and NON-ESSENTIAL amino acids

```
  |                                                                    |
```

## 10.4 THE ZWITTER ION

An amino acid has an acid group and a base group in the *same molecule*.
So one end donates its proton to the other end.

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |          R                                R                        |
  |          |            proton transfer     |                        |
  |   H2N -- CH -- COOH    ------------->  H3N -- CH -- COO             |
  |                                        (+)            (-)          |
  |                                                                    |
  |     neutral form                     ZWITTER ION                    |
  |     (does NOT really                 (the form actually present     |
  |      exist in the solid)              in the solid and in           |
  |                                       neutral solution)             |
  |                                                                    |
  +--------------------------------------------------------------------+

  A ZWITTER ION (German: "twin ion", also called a DIPOLAR ION) is a
  species that carries a POSITIVE and a NEGATIVE charge on different
  atoms of the SAME molecule, so it is overall ELECTRICALLY NEUTRAL.
```

**What the zwitter ion explains:**

```
  1.  Amino acids are CRYSTALLINE SOLIDS with HIGH melting points -
      because they are really ionic (salt-like), not covalent.
  2.  They are SOLUBLE IN WATER but poorly soluble in organic solvents.
  3.  They are AMPHOTERIC - they react with both acids and bases.
```

## 10.5 AMPHOTERIC BEHAVIOUR

```
  IN ACID SOLUTION (add H+):  the -COO(-) picks up the proton
                              -> the ion becomes a CATION

           R                              R
           |                              |
      H3N--CH--COO      + H+   ---->  H3N--CH--COOH
      (+)       (-)                   (+)
                                      CATION - moves to the CATHODE

  IN BASIC SOLUTION (add OH-): the -NH3(+) gives up its proton
                               -> the ion becomes an ANION

           R                              R
           |                              |
      H3N--CH--COO      + OH-  ---->   H2N--CH--COO     + H2O
      (+)       (-)                              (-)
                                       ANION - moves to the ANODE
```

## 10.6 ISOELECTRIC POINT

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  The ISOELECTRIC POINT (pI) of an amino acid is the pH at which     |
  |  it exists ENTIRELY as the ZWITTER ION - the positive and negative  |
  |  charges are exactly balanced, the net charge is ZERO, and the      |
  |  amino acid does NOT migrate towards either electrode in an         |
  |  electric field.                                                    |
  |                                                                    |
  +--------------------------------------------------------------------+

  At the isoelectric point:
     * net charge = 0
     * NO migration in electrophoresis
     * solubility is MINIMUM
     * the amino acid is most easily precipitated

  Rough values:  neutral amino acids  pI ~ 5.5 to 6.3  (glycine 6.0)
                 acidic  amino acids  pI ~ 3           (glutamic acid)
                 basic   amino acids  pI ~ 9 to 10     (lysine)
```

---

## WORKED EXAMPLE 10.1

**Q. Glycine has an isoelectric point of 6.0. In which direction will it
move during electrophoresis at pH 2, at pH 6 and at pH 11? (4 marks)**

```
  RULE : pH BELOW pI  -> extra H+ around  -> molecule picks up H+
                      -> becomes POSITIVE -> goes to the CATHODE
         pH EQUAL pI  -> zwitter ion, net charge zero -> NO movement
         pH ABOVE pI  -> extra OH- around -> molecule loses H+
                      -> becomes NEGATIVE -> goes to the ANODE

  At pH 2  (below 6.0):   glycine exists as   H3N(+)-CH2-COOH
                          net charge  +1  ->  moves to the CATHODE

  At pH 6  (equal to pI): glycine exists as   H3N(+)-CH2-COO(-)
                          net charge   0  ->  does NOT move

  At pH 11 (above 6.0):   glycine exists as   H2N-CH2-COO(-)
                          net charge  -1  ->  moves to the ANODE
```

# TOPIC 11 — THE PEPTIDE BOND AND PROTEINS

## 11.1 How the peptide bond is made

```
  The -COOH of one amino acid reacts with the -NH2 of the next,
  and a molecule of WATER is eliminated. The C-N bond formed is the
  PEPTIDE BOND (also called an amide linkage, -CO-NH-).

       R1                            R2
        |                             |
  H2N - CH - C - OH   +   H -  N  -  CH - COOH
              ||               |
              O                H
                        |
                        |  - H2O
                        v

       R1        O    H     R2
        |        ||   |      |
  H2N - CH - C --------N --- CH - COOH
                 \________/
                     ^
              THE PEPTIDE BOND  ( -CO-NH- )

  +--------------------------------------------------------------------+
  |                                                                    |
  |  PEPTIDE BOND  =  the -CO-NH- linkage formed between the -COOH      |
  |                   group of one amino acid and the -NH2 group of     |
  |                   another, with the elimination of a water molecule |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## 11.2 Building up to a protein

```
  2 amino acids  ->  DIPEPTIDE      (1 peptide bond)
  3 amino acids  ->  TRIPEPTIDE     (2 peptide bonds)
  4 to 10        ->  OLIGOPEPTIDE
  more than 10   ->  POLYPEPTIDE
  molar mass above ~10000 and a definite 3-D shape  ->  PROTEIN

  RULE :  number of peptide bonds  =  (number of amino acid units) - 1
          water molecules lost     =  (number of amino acid units) - 1

  PROTEINS are polymers of alpha-amino acids joined by peptide bonds.
  The word comes from the Greek "proteios" = of prime importance.
```

## 11.3 FIBROUS and GLOBULAR proteins

```
  +---------------------+------------------------+---------------------+
  |                     |  FIBROUS PROTEINS      |  GLOBULAR PROTEINS  |
  +---------------------+------------------------+---------------------+
  |  Shape              |  long thread-like      |  spherical / ball   |
  |                     |  chains lying parallel |  shaped, chains     |
  |                     |                        |  coiled up          |
  |  Held together by   |  hydrogen bonds and    |  hydrogen bonds,    |
  |                     |  disulphide bonds      |  ionic, vdW forces  |
  |                     |  between chains        |  within one chain   |
  |  Solubility in water|  INSOLUBLE             |  SOLUBLE            |
  |  Stability to heat  |  stable                |  easily denatured   |
  |  Function           |  STRUCTURAL - they      |  FUNCTIONAL -       |
  |                     |  build tissue          |  enzymes, hormones, |
  |                     |                        |  transport          |
  |  Examples           |  KERATIN (hair, nails, |  INSULIN, ALBUMIN   |
  |                     |  wool), MYOSIN (muscle)|  (egg), HAEMOGLOBIN,|
  |                     |  COLLAGEN (tendon),    |  all ENZYMES        |
  |                     |  FIBROIN (silk)        |                     |
  +---------------------+------------------------+---------------------+

  MEMORY :  FIBROUS = FIBRE = hair, silk, muscle = insoluble
            GLOBULAR = GLOBE = round = dissolves = does the work
```

# TOPIC 12 — THE FOUR LEVELS OF PROTEIN STRUCTURE

This is the single most likely **4-mark** question in the chapter.
Learn all four names, one line for each, and the force that holds each.

```
                    STRUCTURE OF PROTEINS
                             |
     +-----------+-----------+-----------+-----------+
     |           |                       |           |
  PRIMARY    SECONDARY               TERTIARY   QUATERNARY
  sequence   local shape             overall     several
  of amino   (helix / sheet)         3-D fold    sub-units
  acids
```

## 12.1 PRIMARY structure

```
  +--------------------------------------------------------------------+
  |  The PRIMARY structure is the exact NUMBER and SEQUENCE (order) of  |
  |  the amino acids in the polypeptide chain, from the free -NH2 end   |
  |  to the free -COOH end.                                             |
  |                                                                    |
  |  HELD BY :  PEPTIDE BONDS (covalent, strong)                        |
  +--------------------------------------------------------------------+

     H2N - Gly - Ala - Val - Leu - Ser - Phe - ... - COOH
           |
           the ORDER matters. Change one amino acid and you change the
           protein completely. In sickle-cell anaemia ONE amino acid in
           haemoglobin is wrong (valine instead of glutamic acid) and the
           whole red blood cell deforms.
```

## 12.2 SECONDARY structure

```
  +--------------------------------------------------------------------+
  |  The SECONDARY structure is the shape the polypeptide chain takes   |
  |  up LOCALLY by folding or coiling, held together by HYDROGEN BONDS  |
  |  between the C=O of one peptide bond and the N-H of another.         |
  |                                                                    |
  |  There are TWO types:  the ALPHA HELIX  and  the BETA PLEATED SHEET |
  +--------------------------------------------------------------------+
```

**(a) The alpha helix**

```
    The chain coils up like a spiral staircase or a telephone cord.
    It is a RIGHT-HANDED coil.
    Held by INTRAmolecular hydrogen bonds: the C=O of one amino acid
    hydrogen-bonds to the N-H of the amino acid FOUR residues ahead
    in the SAME chain.

            /-----\
           |       |          C = O . . . . . H - N
            \-----/                  H-bond
           |       |          C = O . . . . . H - N
            \-----/
           |       |          C = O . . . . . H - N
            \-----/
        the coiled chain      the bonds holding it, drawn flat

    EXAMPLES : keratin (wool, hair), myosin (muscle)
```

**(b) The beta pleated sheet**

```
    The chains are STRETCHED OUT side by side and held to each other
    by INTERmolecular hydrogen bonds. Seen edge-on the sheet looks
    folded like the pleats of a saree or a paper fan.

     chain 1   -- N - C - C - N - C - C - N - C - C --
                    |       |       |       |
                    H       O       H       O
                    .       .       .       .          hydrogen bonds
                    .       .       .       .
                    O       H       O       H
                    |       |       |       |
     chain 2   -- C - C - N - C - C - N - C - C - N --

    Seen from the side:      /\    /\    /\    /\
                            /  \  /  \  /  \  /  \      the "pleats"
                                \/    \/    \/

    EXAMPLE : fibroin (silk)
```

## 12.3 TERTIARY structure

```
  +--------------------------------------------------------------------+
  |  The TERTIARY structure is the OVERALL three-dimensional shape of   |
  |  the whole polypeptide chain - the way the helices and sheets       |
  |  further fold and bend on one another.                              |
  |                                                                    |
  |  HELD BY :  hydrogen bonds                                          |
  |             DISULPHIDE bridges  ( -S-S- , covalent, the strongest ) |
  |             IONIC bonds / salt bridges ( -COO(-) ... (+)H3N- )      |
  |             van der Waals and hydrophobic interactions              |
  |                                                                    |
  |  It gives TWO main molecular shapes: FIBROUS and GLOBULAR.          |
  +--------------------------------------------------------------------+

       -----helix-----
      /               \        -S-S-  disulphide bridge
     |     folded       |------------------|
      \    back        /                   |
       ----sheet-------                    |
                |___________ionic bond_____|
```

## 12.4 QUATERNARY structure

```
  +--------------------------------------------------------------------+
  |  Some proteins are built from TWO OR MORE separate polypeptide      |
  |  chains (sub-units). The QUATERNARY structure is the way these      |
  |  sub-units are ARRANGED with respect to one another.                |
  |                                                                    |
  |  HELD BY :  the same weak forces - hydrogen bonds, ionic bonds,     |
  |             van der Waals and hydrophobic interactions              |
  |                                                                    |
  |  EXAMPLE :  HAEMOGLOBIN - four sub-units (two alpha and two beta)   |
  |             packed together. Insulin has two chains joined by       |
  |             disulphide bridges.                                     |
  +--------------------------------------------------------------------+

          +-----+   +-----+
          |  a  |   |  b  |          four sub-units fitting together
          +-----+   +-----+          like the pieces of a jigsaw
          +-----+   +-----+
          |  b  |   |  a  |          = one haemoglobin molecule
          +-----+   +-----+
```

## 12.5 The summary table — write THIS in the exam

```
  +------------+---------------------------+-------------------------+
  |  LEVEL     |  WHAT IT IS               |  FORCE HOLDING IT       |
  +------------+---------------------------+-------------------------+
  | PRIMARY    | the sequence/order of the |  PEPTIDE BONDS          |
  |            | amino acids               |  (covalent)             |
  +------------+---------------------------+-------------------------+
  | SECONDARY  | alpha helix or beta       |  HYDROGEN BONDS         |
  |            | pleated sheet             |  (C=O ... H-N)          |
```

> **TRAP:** The alpha helix is held by **INTRA**molecular hydrogen bonds

> common mistake in this question.

# TOPIC 13 — DENATURATION OF PROTEINS

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  DENATURATION is the process in which a protein loses its           |
  |  BIOLOGICAL ACTIVITY because its SECONDARY and TERTIARY structures  |
  |  are destroyed, while the PRIMARY structure (the sequence of        |
  |  amino acids) remains INTACT.                                       |
  |                                                                    |
  +--------------------------------------------------------------------+

  A protein in its natural working state is called a NATIVE PROTEIN.
  After denaturation it becomes a DENATURED PROTEIN.

  WHAT CAUSES IT
     * heat (boiling)
     * change of pH (adding acid or alkali)
     * heavy metal ions (Pb2+, Hg2+)
     * alcohol, urea, strong salt solutions
     * ultraviolet radiation, violent shaking

  WHAT IS LOST                          WHAT SURVIVES
     * the alpha helix uncoils             * the PEPTIDE BONDS
     * the globular shape unfolds          * the PRIMARY structure
     * the hydrogen bonds break              (sequence of amino acids)
     * biological activity is LOST
     * solubility falls, it coagulates

  IS IT REVERSIBLE?  Usually NO. Denaturation is normally irreversible.
                     You cannot un-boil an egg.
```

**Everyday examples — always give at least two:**

```
  1.  BOILING AN EGG.  The clear soluble globular protein ALBUMIN in
      egg white becomes a white, solid, insoluble mass. The peptide
      bonds are unchanged - only the folding has been destroyed.

  2.  CURDLING OF MILK.  Lactic acid produced by bacteria lowers the pH,
      and the milk protein CASEIN coagulates into curd.

  3.  Adding lemon juice or vinegar to milk - the same acid denaturation.

  4.  Cooking meat, or a hard-boiled egg turning rubbery.

  5.  A fever above 42 degrees C is dangerous because body enzymes
      (which are proteins) start to denature.
```

# TOPIC 14 — ENZYMES

## 14.1 What they are

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  ENZYMES are BIOCATALYSTS - protein molecules produced by living    |
  |  cells that catalyse the biochemical reactions in the body.         |
  |                                                                    |
  |  Chemically almost all enzymes are GLOBULAR PROTEINS.               |
  |                                                                    |
  +--------------------------------------------------------------------+

  NAMING :  usually the substrate + "ase"
       maltose  -> MALTASE       urea    -> UREASE
       lactose  -> LACTASE       starch  -> AMYLASE (diastase)
       sucrose  -> SUCRASE/INVERTASE      proteins -> PEPSIN, TRYPSIN

  Some examples of what they do:
       INVERTASE :  sucrose  --->  glucose + fructose
       ZYMASE    :  glucose  --->  ethanol + CO2
       UREASE    :  urea     --->  ammonia + CO2
       PTYALIN   :  starch (in saliva) ---> maltose
```

## 14.2 The mechanism of enzyme action (in outline)

```
  Every enzyme has a small region on its surface with exactly the right
  SHAPE and the right chemical groups to grip one particular substrate.
  That region is the ACTIVE SITE.

  STEP 1   The substrate fits into the active site like a key into a
           lock, and an ENZYME-SUBSTRATE COMPLEX is formed.

  STEP 2   Inside the complex the substrate is strained and the
           activation energy of the reaction is LOWERED. The reaction
           takes place.

  STEP 3   The product no longer fits the active site, so it is
           RELEASED, and the free enzyme is available again.

           E   +   S   <---->   ES   ---->   E   +   P
        enzyme  substrate     complex      enzyme  product

  PICTURE (lock and key) :

         SUBSTRATE                                 PRODUCTS
            /\                                      /  \
           /  \                                     |  |
       ____\  /____        ______________        ___|__|___
      |     \/     |      |      /\      |      |          |
      |  active    |  ->  |     /  \     |  ->  |          |
      |   site     |      |    \    /    |      |          |
      |____________|      |______\/______|      |__________|
         ENZYME              ES COMPLEX          ENZYME free again

  ENERGY PICTURE:

     E |    ....  uncatalysed path (high hill)
     N |   .    .
     E |  .      .
     R | .   ___  .
     G | .  /   \  .   <-- catalysed path (low hill) - enzyme lowers Ea
     Y |._/     \_.
       |__________________
             reaction ->
```

## 14.3 Characteristics of enzyme catalysis

```
  1.  HIGHLY EFFICIENT.  One enzyme molecule can transform a million
      substrate molecules per minute. Enzymes increase reaction rates
      by factors of 10^6 to 10^20 compared with the uncatalysed reaction.

  2.  HIGHLY SPECIFIC.  Each enzyme catalyses ONE reaction, or one type
      of reaction, and no other. Urease acts only on urea and will not
      touch any other amide. (This is the "lock and key" specificity.)

  3.  ACTIVE AT AN OPTIMUM TEMPERATURE.  Activity is maximum at about
      298 - 310 K (roughly body temperature, 37 degrees C). Below it the
      rate falls; above it the enzyme is DENATURED and destroyed.

  4.  ACTIVE AT AN OPTIMUM pH.  Most enzymes work best between pH 5 and
      7. Away from the optimum the activity collapses.
      (Pepsin in the stomach is the exception - it likes about pH 2.)

  5.  NEEDED IN VERY SMALL AMOUNTS, and they are not used up.

  6.  ACTIVITY IS INCREASED BY ACTIVATORS / CO-ENZYMES.  Many enzymes
      need a small non-protein helper: a vitamin, or a metal ion such as
      Na+, Mn2+, Co2+, Cu2+.

  7.  POISONED BY INHIBITORS.  Heavy metal ions and certain chemicals
      block the active site and stop the enzyme working. Many drugs and
      poisons work exactly this way.
```

> **TRAP:** "Enzymes lower the activation energy" — correct.
> "Enzymes change the equilibrium constant / make an impossible reaction
> possible" — WRONG. A catalyst only makes a possible reaction FASTER.

# TOPIC 17 — THE DOUBLE HELIX AND BASE PAIRING

## 17.1 The Watson-Crick model of DNA (1953)

```
  1.  DNA consists of TWO polynucleotide chains wound round each other
      to form a RIGHT-HANDED DOUBLE HELIX, like a twisted ladder.

  2.  The two strands are ANTIPARALLEL - one runs 5' to 3' and the other
      runs 3' to 5'.

  3.  The SUGAR-PHOSPHATE backbones are on the OUTSIDE; the BASES point
      INWARDS, stacked like the rungs of the ladder.

  4.  The two strands are held together by HYDROGEN BONDS between the
      bases. The pairing is COMPLEMENTARY and fixed:

              a PURINE always pairs with a PYRIMIDINE
              A  pairs only with  T   -  TWO   hydrogen bonds
              G  pairs only with  C   -  THREE hydrogen bonds

  5.  Because of this, the amount of A always equals the amount of T,
      and the amount of G always equals the amount of C.
      (This is CHARGAFF'S RULE.)
```

## 17.2 THE PICTURE — draw this in the exam

```
                        T H E   D O U B L E   H E L I X
              (drawn untwisted, as a flat ladder, for clarity)

         5' end                                            3' end
           |                                                  |
           P                                                  P
           |                                                  |
           S ---- A  = = = = = = = = = = = = = = T ---- S
           |            (2 hydrogen bonds)                    |
           P                                                  P
           |                                                  |
           S ---- T  = = = = = = = = = = = = = = A ---- S
           |            (2 hydrogen bonds)                    |
           P                                                  P
           |                                                  |
           S ---- G  = = = = = = = = = = = = = = C ---- S
           |            (3 hydrogen bonds)                    |
           P                                                  P
           |                                                  |
           S ---- C  = = = = = = = = = = = = = = G ---- S
           |            (3 hydrogen bonds)                    |
           P                                                  P
           |                                                  |
         3' end                                            5' end

           ^                                                  ^
      sugar-phosphate                                 sugar-phosphate
      BACKBONE (outside)                              BACKBONE (outside)

           S = deoxyribose sugar        P = phosphate group

      Note the two strands run in OPPOSITE directions - ANTIPARALLEL.
```

**And with the twist put back in:**

```
              ______
             /      \
            |   ()   |          The two backbones spiral around a
             \      /           common axis. One complete turn of the
              |    |            helix contains about 10 base pairs and
             /      \           is about 3.4 nanometres long.
            |   ()   |          Diameter of the helix = 2 nm.
```

## 17.3 THE BASE PAIRS — the hydrogen bonds drawn out

```
  A D E N I N E   pairs with   T H Y M I N E      -  2 HYDROGEN BONDS
  (purine, 2 rings)            (pyrimidine, 1 ring)

           +---+---+                    CH3
           |   |   |  N - H . . . . . O   \
           | A |   | /                 \\  |
           |   |   |                    \  |
           |   |   | N . . . . . . H - N   |
           +---+---+                       +---+
                                           | T |
                                           +---+
                     two dotted lines = 2 H-bonds


  G U A N I N E   pairs with   C Y T O S I N E     -  3 HYDROGEN BONDS
  (purine, 2 rings)            (pyrimidine, 1 ring)

           +---+---+
           |   |   |  O . . . . . . H - N
           | G |   | //                  \
           |   |   |                      \
           |   |   |  N - H . . . . . . N  |
           |   |   |                      |
           |   |   |  N - H . . . . . O    +---+
           +---+---+                       | C |
                                           +---+
                     three dotted lines = 3 H-bonds


  +--------------------------------------------------------------------+
  |                                                                    |
  |      A  ==  T        2 hydrogen bonds                               |
  |      G  ==  C        3 hydrogen bonds     (the stronger pair)       |
  |                                                                    |
  |   In RNA, URACIL takes the place of thymine:   A == U               |
  |                                                                    |
  +--------------------------------------------------------------------+

  WHY DOES A PURINE ALWAYS PAIR WITH A PYRIMIDINE?
     A purine has two rings, a pyrimidine has one. One big + one small
     always gives the SAME total width, so the ladder stays exactly
     2 nm wide all the way along. Two purines would bulge, two
     pyrimidines would pinch.

  WHY IS DNA RICH IN G-C MORE STABLE?
     Because each G-C pair has THREE hydrogen bonds instead of two,
     so more energy (a higher temperature) is needed to separate the
     strands.
```

## WORKED EXAMPLE 17.1

**Q. A sample of double-stranded DNA contains 30% adenine. Find the
percentage of thymine, guanine and cytosine.**

```

  STEP 3  A + T + G + C = 100
          30 + 30 + G + C = 100
                    G + C = 40

  STEP 4  Since %G = %C ,      G = C = 40 / 2 = 20

  ANSWER  Thymine = 30 % , Guanine = 20 % , Cytosine = 20 %

  CHECK   30 + 30 + 20 + 20 = 100    correct.
```

**The three types of RNA:**

```
  m-RNA  MESSENGER RNA  -  carries the coded message from the DNA in the
                           nucleus to the ribosome
  t-RNA  TRANSFER RNA   -  brings the correct amino acid to the ribosome
                           (also called soluble RNA)
  r-RNA  RIBOSOMAL RNA  -  forms part of the ribosome itself, the actual
                           workbench where the protein is assembled
```

## 18.2 The biological functions

**(a) REPLICATION — DNA copying itself**

```
  Before a cell divides, its DNA must be copied so each daughter cell
  gets a full set.

  STEP 1  The hydrogen bonds break and the double helix UNZIPS into
          two separate strands.
  STEP 2  Each old strand acts as a TEMPLATE. Free nucleotides line up
          against it, obeying the base pairing rules (A with T, G with C).
  STEP 3  The new nucleotides are joined up, giving TWO new double
          helices, each containing ONE old strand and ONE new strand.

          old  ====================
                    | unzip
                    v
          old  --------------------  + new nucleotides -> new double helix
          old  --------------------  + new nucleotides -> new double helix

  Result: two DNA molecules identical to the original.
  This is how hereditary characters pass from parent to offspring.
```

**(b) TRANSCRIPTION — DNA to m-RNA**

```
  The message in one DNA strand is copied into a strand of m-RNA,
  using the same pairing rules except that URACIL replaces thymine.

       DNA strand    :  A   T   G   C   A   T
       m-RNA formed  :  U   A   C   G   U   A

  The m-RNA then leaves the nucleus and travels to a ribosome.
```

**(c) TRANSLATION — m-RNA to PROTEIN (protein synthesis)**

```
  At the ribosome, the m-RNA is read three bases at a time.
  Each group of three bases is a CODON and it names ONE amino acid.

       m-RNA :   A U G | G C U | U U A | ...
                  |       |       |
                 codon   codon   codon
                  |       |       |
       t-RNA brings the matching amino acid for each codon

       amino acid 1 - amino acid 2 - amino acid 3 - ...  = POLYPEPTIDE

  The chain of amino acids folds up into the finished protein.

  THE CENTRAL DOGMA, in one line:

       DNA  --(replication)--> DNA
       DNA  --(transcription)--> RNA  --(translation)--> PROTEIN
```

**(d) Summary of functions**

```
  1.  DNA is the storehouse of hereditary (genetic) information; it
      passes characters from one generation to the next.
  2.  DNA controls the synthesis of RNA (transcription).
```

# TOPIC 19 — HORMONES (in brief)

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  HORMONES are chemical messengers secreted DIRECTLY INTO THE BLOOD  |
  |  by the ENDOCRINE (ductless) glands. They travel to a target organ  |
  |  and control and coordinate its activity.                           |
  |                                                                    |
  |  They are NOT enzymes: an enzyme speeds up a reaction, a hormone    |
  |  gives an instruction.                                              |
  |                                                                    |
  +--------------------------------------------------------------------+

  +---------------------+---------------------------------------------+
  |  STEROID hormones   |  testosterone , estradiol , progesterone ,  |
  |                     |  cortisone (from cholesterol)               |

  |  POLYPEPTIDE /      |  INSULIN , GLUCAGON , oxytocin , vasopressin|
  |  PROTEIN hormones   |                                             |
  +---------------------+---------------------------------------------+
  |  AMINO-ACID         |  ADRENALINE (epinephrine) , noradrenaline , |
  |  DERIVED hormones   |  THYROXINE                                  |
  +---------------------+---------------------------------------------+

  THE FOUR YOU MUST BE ABLE TO NAME

  +--------------+--------------+----------------------------------------+
  | HORMONE      | GLAND        | WHAT IT DOES / WHAT GOES WRONG         |
  +--------------+--------------+----------------------------------------+
  | INSULIN      | pancreas     | LOWERS blood glucose.                  |
  |              |              | Too little -> DIABETES MELLITUS        |
  +--------------+--------------+----------------------------------------+
  | GLUCAGON     | pancreas     | RAISES blood glucose (opposite of      |
  |              |              | insulin)                               |
  +--------------+--------------+----------------------------------------+
  | ADRENALINE   | adrenal      | the "fight or flight" hormone - raises |
  |              | gland        | heart rate, blood pressure and glucose |
  +--------------+--------------+----------------------------------------+
  | THYROXINE    | thyroid      | controls the rate of metabolism.       |

  | ESTRADIOL    | ovaries      | female sex hormone (steroid)           |
  +--------------+--------------+----------------------------------------+
```

> **TRAP:** Enzymes vs hormones vs vitamins is a classic mix-up question.
> **Enzyme** = protein catalyst, made by the cell where it acts.
> **Hormone** = chemical messenger, made in a gland and carried by the blood.
> **Vitamin** = small molecule that must come from the diet.
> Insulin is a hormone AND a protein. Enzymes are proteins. Vitamins are not.
