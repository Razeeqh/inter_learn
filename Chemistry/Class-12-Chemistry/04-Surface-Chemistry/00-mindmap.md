## THE 60-SECOND VERSION

Everything in this chapter happens **at a boundary** — where a solid meets a gas,
or a liquid meets a liquid. Bulk chemistry ignores surfaces. Surface chemistry is
all about them.

```
  IDEA 1   ADSORPTION
           Molecules STICK to a surface and pile up there.
           Surface atoms have unsatisfied bonds -> they grab passing molecules.
           Weak grip = PHYSISORPTION.   Strong grip = CHEMISORPTION.
                            |
                            v
  IDEA 2   CATALYSIS
           A catalyst is just adsorption put to work.
           Reactant molecules stick to the surface, get weakened,
           react easily, and let go.
           Lower activation energy -> faster reaction -> catalyst unchanged.
                            |
                            v
  IDEA 3   COLLOIDS
           Particles too big to dissolve, too small to settle (1-1000 nm).
           They have HUGE surface area, so surface effects rule them:
           they scatter light (Tyndall), they carry charge, and adding
           an electrolyte kills the charge and they crash out (coagulation).
```

**One sentence for the whole chapter:**
*Small particles have big surfaces, and big surfaces change everything.*

## THE ONE BOX THAT UNLOCKS THE NUMERICALS

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |            FREUNDLICH ADSORPTION ISOTHERM                         |
  |                                                                   |
  |                  x                                                |
  |                 ---   =   k  P^(1/n)              n > 1           |
  |                  m                                                |
  |                                                                   |
  |     x  = mass of gas adsorbed                                     |
  |     m  = mass of adsorbent                                        |
  |     P  = equilibrium pressure of the gas                          |
  |     k, n = constants for that gas-adsorbent pair at that temp     |
  |                                                                   |
  |     TAKE log ON BOTH SIDES:                                       |
  |                                                                   |
  |             x                        1                            |
  |        log ---   =   log k    +     ---  log P                    |
  |             m                        n                            |
  |                                                                   |
  |        Straight line:   y = c + (slope) x                         |
  |                                                                   |
  |             SLOPE      =  1/n                                     |
  |             INTERCEPT  =  log k                                   |
  |                                                                   |
  +-------------------------------------------------------------------+
```

```
  For SOLUTIONS, replace pressure P by concentration C:

              x
             ---   =   k  C^(1/n)
              m
```

**Write this box on your palm.** It is the only formula in the chapter that
can appear as a numerical.

## THE THREE ONE-LINERS THAT ANSWER HALF THE PAPER

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |  1.  ADSORPTION is on the SURFACE only.                           |
  |      ABSORPTION is uniform THROUGHOUT the bulk.                   |
  |      SORPTION   = both happening together.                        |
  |                                                                   |
  |  2.  PHYSISORPTION = van der Waals, weak (20-40 kJ/mol),          |
  |          reversible, not specific, multilayer, LOW temperature.   |
  |      CHEMISORPTION = chemical bond, strong (80-240 kJ/mol),       |
  |          irreversible, highly specific, monolayer, HIGH temp.     |
  |                                                                   |
  |  3.  HARDY-SCHULZE RULE: the HIGHER the CHARGE on the ion of      |
  |      OPPOSITE sign to the sol, the STRONGER it coagulates it.     |
  |          Al3+  >  Ba2+  >  Na+     on a NEGATIVE sol              |
  |          [Fe(CN)6]4- > PO4^3- > SO4^2- > Cl-  on a POSITIVE sol   |
  |                                                                   |
  +-------------------------------------------------------------------+
```

## THE MEMORY HOOKS

```
  ADSORPTION  vs  ABSORPTION
      "ADsorption = ADheres, sticks on top like an ADvertisement on a wall"
      "ABsorption = goes ABout inside, like a sponge"

  PHYSISORPTION  =  PHYSICAL forces  =  weak, reversible, cold-loving
  CHEMISORPTION  =  CHEMICAL bonds   =  strong, irreversible, heat-needing

  LYOPHILIC   =  "lyo" (solvent) + "philic" (loving)  ->  FRIENDLY, stable
  LYOPHOBIC   =  "lyo" (solvent) + "phobic" (fearing) ->  UNSTABLE, needs help

  GOLD NUMBER:  SMALL number  =  STRONG protection.
      "The best bodyguard needs the fewest men."
      GELATIN has the smallest gold number  ->  the BEST protective colloid.

  8 COLLOIDAL SYSTEMS:  remember the MEDIUM first, then the phase.
      medium GAS    -> AEROSOL   (smoke, fog)
      medium LIQUID -> SOL, EMULSION, FOAM
      medium SOLID  -> SOLID SOL, GEL, SOLID FOAM
      GAS in GAS is NOT a colloid (it just mixes).
```
