## THE 60-SECOND VERSION

A solid is just **balls packed in a box, repeated forever**.

```
  STEP 1   Take one small ball  (an atom / ion / molecule)
              |
              v
  STEP 2   Pack the balls as tightly as you can
              |          -> hcp or ccp, 74% full, coordination number 12
              v
  STEP 3   Draw the smallest repeating box around them  =  UNIT CELL
              |          -> SC, BCC or FCC
              v
  STEP 4   Count how many balls really belong to that box  =  Z
              |          -> SC = 1 , BCC = 2 , FCC = 4
              v
  STEP 5   Weigh the box and divide by its volume  =  DENSITY
              |
              |                Z x M
              |          d = -----------
              |               a^3 x NA
              v
  STEP 6   Real crystals have MISTAKES (defects), and those mistakes
           explain colour, conductivity and magnetism.
```

**Everything numerical in this chapter is Step 4 and Step 5. Learn those two cold
and you cannot fail this chapter.**

## THE ONE BOX THAT UNLOCKS THE WHOLE CHAPTER

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |                              Z  x  M                                |
  |        DENSITY      d  =  ----------------                          |
  |                             a^3  x  NA                              |
  |                                                                     |
  |        d  = density in  g/cm^3                                      |
  |        Z  = number of atoms per unit cell  (1 , 2 or 4)             |
  |        M  = atomic / molar mass in  g/mol                           |
  |        a  = edge length in  cm      (1 pm = 10^-10 cm)              |
  |        NA = 6.022 x 10^23  /mol                                     |
  |                                                                     |
  +---------------------------------------------------------------------+

  +---------------------------------------------------------------------+
  |                                                                     |
  |     TYPE      Z      EDGE vs RADIUS        PACKING     C.N.         |
  |   ---------------------------------------------------------------   |
  |     SC        1      a = 2 r               52.4 %        6          |
```

## THE TEN LINES THAT ARE ALWAYS WORTH MARKS

```
   1.  Amorphous solids are PSEUDO SOLIDS / SUPERCOOLED LIQUIDS. Example: glass.
   2.  Crystalline solids are ANISOTROPIC; amorphous solids are ISOTROPIC.
   3.  Z:   SC = 1 ,  BCC = 2 ,  FCC = 4.
   4.  Packing efficiency:  SC 52.4% ,  BCC 68% ,  FCC = HCP = 74%.
   5.  d = Z M / (a^3 NA).
   6.  For N close packed atoms:  2N tetrahedral voids and N octahedral voids.
   7.  Schottky = a PAIR of ions missing -> DENSITY FALLS. (NaCl, KCl, CsCl, AgBr)
   8.  Frenkel = an ion MOVES to an interstitial site -> DENSITY UNCHANGED.
                 (ZnS, AgCl, AgBr, AgI)
   9.  Metal excess defect -> anion vacancy holds an electron -> F-CENTRE -> COLOUR.
  10.  Group 15 dopant -> n-type (extra electron).
       Group 13 dopant -> p-type (electron hole).
```
