# PATTERN 1 — Crystalline versus amorphous

### Q1
Which of the following is an amorphous solid?

(a) Quartz &nbsp; (b) Diamond &nbsp; (c) Glass &nbsp; (d) NaCl

**ANSWER: (c)**
```
  Glass has only SHORT range order  ->  amorphous (pseudo solid).
  Quartz, diamond and NaCl are all crystalline.
```

---

### Q2
Amorphous solids are

(a) anisotropic &nbsp; (b) isotropic &nbsp; (c) true solids &nbsp; (d) have sharp m.p.

**ANSWER: (b)**
```
  Random arrangement -> every direction is statistically identical
  -> ISOTROPIC.
  Crystalline solids are ANISOTROPIC.
```

> **SHORTCUT:** Amorphous = **I**sotropic (both start with a vowel sound "a-m-o-r"
> and "i-s-o"). Crystalline = Anisotropic.

---

### Q3
Which of the following pairs consists of the same substance in crystalline and
amorphous forms?

(a) NaCl and KCl &nbsp; (b) Quartz and quartz glass &nbsp; (c) Ice and water &nbsp; (d) Fe and steel

**ANSWER: (b)**
```
  Both quartz and quartz glass are SiO2.
  Quartz is CRYSTALLINE; quartz glass is AMORPHOUS.
```

### Q5
Which solid conducts electricity in the solid state?

(a) NaCl &nbsp; (b) Diamond &nbsp; (c) Graphite &nbsp; (d) Ice

# PATTERN 3 — Number of atoms per unit cell (the free mark)

### Q8
The number of atoms per unit cell in a body centred cubic lattice is

(a) 1 &nbsp; (b) 2 &nbsp; (c) 4 &nbsp; (d) 6

**ANSWER: (b)** — `8 x 1/8 + 1 = 2`

---

### Q9
The number of atoms in a face centred cubic unit cell is

(a) 1 &nbsp; (b) 2 &nbsp; (c) 4 &nbsp; (d) 8

**ANSWER: (c)** — `8 x 1/8 + 6 x 1/2 = 1 + 3 = 4`

---

### Q10
A compound has atoms of A at the corners of a cube and atoms of B at the face
centres. The formula is

(a) AB &nbsp; (b) AB2 &nbsp; (c) AB3 &nbsp; (d) A3B

**ANSWER: (c)**
```
  A  =  8 x 1/8  =  1
  B  =  6 x 1/2  =  3        ->    AB3
```

---

### Q11
In a cubic cell, X is at the corners, Y at the body centre and Z at the edge centres.
The formula is

(a) XYZ &nbsp; (b) XYZ3 &nbsp; (c) X2YZ &nbsp; (d) XY3Z

**ANSWER: (b)**
```
  X  =  8 x 1/8   =  1
  Y  =  1 x 1     =  1
  Z  = 12 x 1/4   =  3        ->    X Y Z3
```

> **SHORTCUT:** Corners 8→1, faces 6→3, edges 12→3, body 1→1. Memorise these
> four finished numbers and you never have to multiply.

---

### Q12
In a sodium chloride unit cell, the number of Na+ ions is

(a) 2 &nbsp; (b) 4 &nbsp; (c) 6 &nbsp; (d) 8

**ANSWER: (b)**
```
  Cl-  occupies fcc positions :  8 x 1/8 + 6 x 1/2  =  4
  Na+  occupies all octahedral voids:
              12 edge centres x 1/4  +  1 body centre  =  3 + 1  =  4

  So NaCl has 4 formula units per unit cell.
```

# PATTERN 4 — Edge length and radius

### Q13
A metal crystallises in an fcc lattice with an edge length of 400 pm. Its atomic
radius is

(a) 100 pm &nbsp; (b) 141.4 pm &nbsp; (c) 173.2 pm &nbsp; (d) 200 pm

**ANSWER: (b)**
```
  fcc:   a = 2 sqrt(2) r     ->    r = a / (2 sqrt2) = 400 / 2.828

         r  =  141.4 pm
```

---

### Q14
Sodium crystallises in a bcc lattice with an edge length of 4.29 A. The radius of
a sodium atom is

(a) 1.86 A &nbsp; (b) 2.15 A &nbsp; (c) 3.72 A &nbsp; (d) 1.52 A

**ANSWER: (a)**
```
  bcc:   r  =  sqrt(3) a / 4  =  (1.732 x 4.29) / 4

         r  =  7.430 / 4  =  1.857 A   approx  1.86 A
```

---

### Q15
The edge length of the fcc unit cell of an element whose atomic radius is 144 pm is

(a) 288 pm &nbsp; (b) 332 pm &nbsp; (c) 407 pm &nbsp; (d) 576 pm

**ANSWER: (c)**
```
  a  =  2 sqrt(2) r  =  2.828 x 144  =  407.2 pm
```

---

### Q16
The distance between the two nearest neighbours in a body centred cubic lattice of
edge length a is

(a) a &nbsp; (b) a/2 &nbsp; (c) sqrt(3) a / 2 &nbsp; (d) a / sqrt(2)

**ANSWER: (c)**
```
  In bcc the nearest neighbour is the BODY CENTRE atom, at half the
  body diagonal:
        (1/2) x sqrt(3) a  =  sqrt(3) a / 2   =  0.866 a
```

```
  NEAREST NEIGHBOUR DISTANCES - learn all three

        SC   :  a
        BCC  :  sqrt(3) a / 2   =  0.866 a
        FCC  :  a / sqrt(2)     =  0.707 a
```

In a close packed structure containing N spheres, the number of tetrahedral voids is

(a) N &nbsp; (b) 2N &nbsp; (c) N/2 &nbsp; (d) 4N

**ANSWER: (b)** — tetrahedral = 2N, octahedral = N.

### Q22
The total number of voids in 0.5 mol of a compound forming a ccp lattice is

(a) 3.011 x 10^23 &nbsp; (b) 6.022 x 10^23 &nbsp; (c) 9.033 x 10^23 &nbsp; (d) 1.2 x 10^24

**ANSWER: (c)**
```
  number of atoms  =  0.5 x 6.022x10^23  =  3.011 x 10^23

  octahedral voids   =  3.011 x 10^23
  tetrahedral voids  =  6.022 x 10^23
                        -----------------
  total              =  9.033 x 10^23
```

### Q23
Atoms of Y form a ccp lattice and atoms of X occupy 1/3 of the tetrahedral voids.
The formula of the compound is

(a) XY &nbsp; (b) X2Y3 &nbsp; (c) X3Y2 &nbsp; (d) XY3

**ANSWER: (b)**
```
  Y  =  N
  tetrahedral voids  =  2N ;  X  =  (1/3)(2N)  =  2N/3

  X : Y  =  2/3 : 1  =  2 : 3      ->     X2 Y3
```

### Q24
A compound has O2- in ccp with the cation M in ALL the octahedral voids. The formula is

```
  O2- (ccp)          =  4
  octahedral voids   =  4, all filled by M

  M : O  =  4 : 4  =  1 : 1      ->     MO
```

                   93              93

### Q36
Schottky defect in a crystal is observed when

(a) an ion leaves its site and occupies an interstitial site
(b) unequal numbers of cations and anions are missing
(c) equal numbers of cations and anions are missing
(d) an extra cation occupies an interstitial site

**ANSWER: (c)**

### Q37
Which of the following shows the Frenkel defect?

(a) NaCl &nbsp; (b) CsCl &nbsp; (c) AgBr &nbsp; (d) KCl

**ANSWER: (c)**
```
  Ag+ is small and Br- is large -> large size difference
  -> the cation slips into an interstitial site.
  AgBr in fact shows BOTH Schottky and Frenkel defects.
```

---

### Q38
The defect that DOES NOT change the density of a crystal is

(a) Schottky &nbsp; (b) Frenkel &nbsp; (c) vacancy &nbsp; (d) metal deficiency

**ANSWER: (b)**
```
  In the Frenkel defect nothing leaves the crystal - the ion only
  moves inside. Mass unchanged, volume unchanged -> density unchanged.
```

---

### Q39
The yellow colour of NaCl heated in sodium vapour is due to

(a) excess Cl- ions &nbsp; (b) F-centres &nbsp; (c) Frenkel defect &nbsp; (d) impurity of Na2O

**ANSWER: (b)**
```
  An electron trapped in a Cl- vacancy = F-CENTRE.
  It absorbs visible light  ->  the crystal appears YELLOW.
```

---

### Q40
Fe0.95O is an example of

(a) a stoichiometric defect &nbsp; (b) a Frenkel defect &nbsp; (c) a metal deficiency defect &nbsp; (d) an F-centre

**ANSWER: (c)**
```
  Some Fe2+ sites are vacant and the charge is balanced by Fe3+.
       3 Fe2+  ->  2 Fe3+  +  one cation vacancy
  This is a metal deficiency (non-stoichiometric) defect ->  p-type.
```

### Q41
NaCl is doped with 10^-4 mol of SrCl2 per mole. The number of cation vacancies per
mole is

(a) 6.022 x 10^19 &nbsp; (b) 6.022 x 10^23 &nbsp; (c) 1.2 x 10^20 &nbsp; (d) 6.022 x 10^17

**ANSWER: (a)**
```
  Each Sr2+ creates ONE cation vacancy.

  vacancies  =  10^-4  x  6.022 x 10^23  =  6.022 x 10^19
```

### Q42
Which defect increases the density of a crystal?

**ANSWER: (c)** — an extra particle squeezed in adds mass at constant volume.
