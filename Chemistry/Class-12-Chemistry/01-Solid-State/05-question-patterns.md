# Solid State — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The numbers change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — CRYSTALLINE vs AMORPHOUS                        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Differentiate between crystalline and amorphous solids",
            "Why is glass called a pseudo solid?",
            "Which of these is amorphous?"
  METHOD    Give the differences in a TABLE. Always include these five:
              1. long range order   vs   short range order
              2. SHARP melting point vs no sharp melting point
              3. definite heat of fusion vs indefinite
              4. clean cleavage vs irregular break
              5. ANISOTROPIC vs ISOTROPIC
            Finish with:  true solid  vs  PSEUDO SOLID / SUPERCOOLED LIQUID
            Give an example of each: NaCl and GLASS.
  TRAP      Quartz is CRYSTALLINE, quartz GLASS is AMORPHOUS - both are
            SiO2. Do not confuse them.
            Amorphous = ISOTROPIC (many students write the opposite).
```

```
  PATTERN 2 — CLASSIFY A LIST OF SOLIDS                       2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Classify the following as ionic / metallic / molecular /
            covalent: SiC, I2, P4, brass, Rb, LiBr, Si ..."
  METHOD    Ask ONE question of each substance:
              metal or alloy?              -> METALLIC
              metal + non-metal?           -> IONIC
              only non-metal atoms in a
              giant network (C, Si, SiC,
              SiO2, AlN)?                  -> COVALENT NETWORK
              discrete molecules?          -> MOLECULAR
                 non-polar (H2, I2, CO2)   -> London forces
                 polar (HCl, SO2)          -> dipole-dipole
                 has O-H / N-H / H-F (ice) -> hydrogen bonded
            Name the FORCE too; it carries half the marks.
  TRAP      P4 and I2 are MOLECULAR, not covalent network.
            Graphite is a covalent solid that CONDUCTS and is SOFT.
```

```
  PATTERN 3 — WHY DOES SOLID X BEHAVE LIKE THAT?              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why do ionic solids conduct only when molten?"
            "Why is diamond hard but graphite soft?"
            "Why are ionic solids brittle?"
  METHOD    Answer in TWO lines: state the STRUCTURE, then the CONSEQUENCE.
              ionic + molten     -> ions become FREE to move
              diamond            -> sp3, all 4 electrons bonded, 3-D network
              graphite           -> sp2, 4th electron delocalised, layers
                                    slide (weak van der Waals)
              ionic brittle      -> a shifted layer brings LIKE charges
                                    face to face -> repulsion -> cracks
  TRAP      Never just say "because of strong forces". Name the force.
```

```
  PATTERN 4 — DEFINE LATTICE / UNIT CELL / PARAMETERS         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define crystal lattice / unit cell", "What parameters
            characterise a unit cell?"
  METHOD    LATTICE   - regular 3-D arrangement of points, each point
                        showing a particle; all points have identical
                        surroundings.
            UNIT CELL - the SMALLEST repeating portion which on repetition
                        in 3-D generates the whole lattice.
            PARAMETERS- three edges  a, b, c
                        three angles alpha (b^c), beta (a^c), gamma (a^b)
  TRAP      "Smallest repeating portion" is the phrase that earns the mark.
            Do not forget that there are SIX parameters, not three.
```

```
  PATTERN 5 — NAME THE CRYSTAL SYSTEM FROM ITS PARAMETERS     2 marks
  ------------------------------------------------------------------------
  TRIGGER   "a = b /= c , alpha = beta = 90 , gamma = 120. Name the system."
  METHOD    Match against the table:
              a=b=c , all 90            -> CUBIC          (3 lattices)
              a=b/=c , all 90           -> TETRAGONAL     (2)
              a/=b/=c , all 90          -> ORTHORHOMBIC   (4)
              a=b/=c , 90,90,120        -> HEXAGONAL      (1)
              a=b=c , all equal /= 90   -> RHOMBOHEDRAL   (1)
              a/=b/=c , 90,90,beta      -> MONOCLINIC     (2)
              a/=b/=c , all different   -> TRICLINIC      (1)
            Always add ONE example.
  TRAP      Total = 14 Bravais lattices in 7 systems. Cubic has 3, but
            ORTHORHOMBIC has the most (4).
```

```
  PATTERN 6 — HOW MANY ATOMS PER UNIT CELL                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the number of atoms in a bcc / fcc unit cell."
  METHOD    Use the sharing rule and SHOW the arithmetic:
              corner 1/8 , edge 1/4 , face 1/2 , body 1
              SC   :  8 x 1/8                =  1
              BCC  :  8 x 1/8 + 1            =  2
              FCC  :  8 x 1/8 + 6 x 1/2      =  4
              END  :  8 x 1/8 + 2 x 1/2      =  2
  TRAP      Write the multiplication out. "Z = 4" alone gets 1 mark;
            with the working it gets 2.
```

```
  PATTERN 7 — FIND THE FORMULA FROM POSITIONS IN THE CELL     2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A is at the corners, B at the face centres. Find the formula."
  METHOD    1. Count each element with the sharing rule.
            2. Write the ratio.
            3. Reduce to the smallest whole numbers.
            Finished numbers to memorise:
                 8 corners      ->  1
                 6 face centres ->  3
                12 edge centres ->  3
                 1 body centre  ->  1
  TRAP      If an atom is REMOVED from one corner, that element becomes
            7 x 1/8 = 7/8, and the formula becomes A7B8.
```

```
  PATTERN 8 — FIND THE FORMULA FROM VOID OCCUPANCY            4 marks
  ------------------------------------------------------------------------
  TRIGGER   "B forms an hcp lattice and A occupies 2/3 of the tetrahedral
            voids. Find the formula."
  METHOD    1. Let the close packed atoms be N.
            2. tetrahedral voids = 2N ,  octahedral voids = N.
            3. Multiply by the fraction occupied.
            4. Write the ratio and clear the fractions.
                 A = (2/3)(2N) = 4N/3 ,  B = N   ->  4 : 3  ->  A4B3
  TRAP      Do NOT use N for tetrahedral voids. Tetrahedral = 2N.
            "All tetrahedral voids filled in ccp" gives XY2 (fluorite),
            "all octahedral voids filled" gives XY (rock salt).
```

```
  PATTERN 9 — RELATION BETWEEN a AND r                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the atomic radius from the edge length" or
            "Calculate the edge length from the atomic radius."
  METHOD    Identify the lattice first, then use:
              SC  : atoms touch along the EDGE
                       a = 2 r          ->  r = a/2
              BCC : atoms touch along the BODY DIAGONAL
                       sqrt(3) a = 4r   ->  r = 1.732 a / 4
              FCC : atoms touch along the FACE DIAGONAL
                       sqrt(2) a = 4r   ->  r = a / 2.828
  TRAP      Mixing up sqrt(2) and sqrt(3). Remember:
            FACE diagonal = sqrt(2) a  (2 sides make a face)
            BODY diagonal = sqrt(3) a  (3 sides make the body)
```

```
  PATTERN 10 — DERIVE THE PACKING EFFICIENCY                  4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive / calculate the packing efficiency of ... "
            "What percentage of space is empty in ... ?"
  METHOD    1. State the definition and the formula
                 P.E. = 100 x Z (4/3) pi r^3 / a^3
            2. DRAW the cube or the face and show where the atoms touch.
            3. Get a in terms of r.
            4. Substitute and simplify to the standard fraction:
                 SC   pi/6            = 52.4 %
                 BCC  pi sqrt(3)/8    = 68   %
                 FCC  pi/(3 sqrt2)    = 74   %
            5. Free space = 100 - P.E.
  TRAP      The diagram carries marks. An answer with no figure loses 1-2.
            Do not forget the Z: 1, 2 and 4 respectively.
```

```
  PATTERN 11 — DENSITY: GIVEN a AND M, FIND d                 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Copper crystallises in fcc with edge 361 pm. Calculate its
            density."
  METHOD    1. Read the lattice type -> Z  (SC 1, BCC 2, FCC 4).
            2. Convert a to CENTIMETRES:   1 pm = 10^-10 cm
            3. Cube it.
            4.      Z M
                d = --------
                    a^3 NA
            5. Write the unit  g/cm^3.
  TRAP      Converting pm to METRES instead of cm. That is the single
            most common mistake in this chapter.
```

```
  PATTERN 12 — DENSITY: GIVEN d AND a, FIND Z (NAME LATTICE)  4 marks
  ------------------------------------------------------------------------
  TRIGGER   "An element with molar mass 27 forms a cubic cell of edge
            405 pm and density 2.7. What is the nature of the cell?"
  METHOD    1.  Z = d a^3 NA / M
            2.  Round to the NEAREST WHOLE NUMBER.
            3.  Name it:  1 -> simple cubic
                          2 -> body centred cubic
                          4 -> face centred cubic
  TRAP      Z MUST be a whole number. 1.99 means 2. 3.89 means 4.
            If you get something like 2.6 you have made an arithmetic
            slip - recheck a^3.
            Always finish with the NAME of the lattice, not just Z.
```

```
  PATTERN 13 — DENSITY: FIND THE ATOMIC MASS                  4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Silver crystallises in fcc, edge 4.077x10^-8 cm, density
            10.5. Calculate the atomic mass."
  METHOD          d  a^3  NA
             M =  ------------
                       Z
            Write the unit  g/mol  (or u).
  TRAP      If the edge is already in cm, do NOT convert again.
            Check the answer is sensible - an atomic mass of 0.1 or
            5000 means you slipped a power of ten.
```

```
  PATTERN 14 — DENSITY: FIND THE EDGE LENGTH                  4 marks
  ------------------------------------------------------------------------
  TRIGGER   "An element of mass 60 u, fcc, density 6.23. Find the edge
            length of the unit cell."
  METHOD    1.  a^3 = Z M / ( d NA )
            2.  Write the answer as  (something) x 10^-24 cm^3
                so the cube root of the power is clean (10^-8).
            3.  Take the cube root of the number part.
                Useful cubes:  3^3=27 , 3.3^3=35.9 , 3.6^3=46.7 ,
                               4^3=64 , 4.5^3=91.1 , 5^3=125
            4.  Convert to pm if asked (x 10^10).
  TRAP      Splitting the power wrongly. Always arrange the volume as
            n x 10^-24 so that the cube root is n^(1/3) x 10^-8.
```

```
  PATTERN 15 — HOW MANY ATOMS / UNIT CELLS IN w GRAMS         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How many atoms are present in 208 g of the element?"
            "How many unit cells are in 1 g of gold?"
  METHOD    ROUTE A (mass -> atoms):
                 atoms = (w / M) x NA
                 unit cells = atoms / Z
            ROUTE B (density -> volume):
                 volume = w / d
                 cells  = volume / a^3
                 atoms  = cells x Z
            Either route is accepted. Use the one matching the data given.
  TRAP      Dividing when you should multiply by Z. Atoms = cells x Z;
            cells = atoms / Z.
```

```
  PATTERN 16 — VOIDS: NUMBER AND SIZE                         2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are tetrahedral and octahedral voids?"
            "How many voids are there in 0.5 mol of ...?"
  METHOD    Define both with a diagram (4 spheres / 6 spheres).
            For N spheres:   tetrahedral = 2N , octahedral = N ,
                             total = 3N
            Sizes:           r(tet)/r = 0.225 , r(oct)/r = 0.414
            For a mole question: N = (moles) x 6.022x10^23 first.
  TRAP      "TETRA is TWO in number but TINY; OCTA is ONE in number but
            OPEN." Students always swap the count and the size.
```

```
  PATTERN 17 — RADIUS RATIO -> COORDINATION NUMBER            2 marks
  ------------------------------------------------------------------------
  TRIGGER   Two ionic radii are given, or a ratio like 0.52 is given.
  METHOD    1. ratio = r(cation) / r(anion)   - CATION ON TOP
            2. Place it in the range:
                 0.155 - 0.225  ->  C.N. 3 , trigonal planar
                 0.225 - 0.414  ->  C.N. 4 , tetrahedral   (ZnS)
                 0.414 - 0.732  ->  C.N. 6 , octahedral    (NaCl)
                 0.732 - 1.000  ->  C.N. 8 , bcc           (CsCl)
            3. Name the structure type as well.
  TRAP      Flipping the fraction. If your ratio is above 1 you have
            divided the wrong way round.
            The reverse question ("minimum radius of B- in an AB solid
            of NaCl type") uses the LOWER limit 0.414.
```

```
  PATTERN 18 — CLOSE PACKING IN 1, 2 AND 3 DIMENSIONS         8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain close packing in solids", "What are hcp and ccp?"
  METHOD    1-D  : a row, C.N. 2
            2-D  : square packing  - AAAA , C.N. 4 , 52.4 %
                   hexagonal       - ABAB , C.N. 6 , 60.4 %  (better)
            3-D  : hcp  ABAB...  -> hexagonal cell, Z = 6
                   ccp  ABCABC.. -> fcc cell,       Z = 4
                   both C.N. 12 and 74 %
            Explain C.N. 12 as  6 (same layer) + 3 (above) + 3 (below).
            Finish with the two kinds of void.
  TRAP      hcp and ccp differ ONLY in the stacking sequence. Saying
            one is "more efficient" is wrong - both are 74 %.
```

```
  PATTERN 19 — DEFINE / COMPARE SCHOTTKY AND FRENKEL          2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is a Schottky defect?", "Distinguish between Schottky
            and Frenkel defects."
  METHOD    Schottky - an EQUAL number of cations AND anions MISSING;
                       high C.N., small size difference;
                       DENSITY DECREASES;  NaCl, KCl, KBr, CsCl, AgBr
            Frenkel  - the SMALLER ion MOVES to an INTERSTITIAL site;
                       low C.N., large size difference;
                       DENSITY UNCHANGED, dielectric constant INCREASES;
                       ZnS, AgCl, AgBr, AgI
            Draw both little ion grids. Both keep the crystal NEUTRAL.
  TRAP      The DENSITY line is the mark-carrying line. Never omit it.
            AgBr shows BOTH defects.
```

```
  PATTERN 20 — WHICH DEFECT CHANGES THE DENSITY?              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Which defect lowers / raises / does not change the density?"
  METHOD    Vacancy and SCHOTTKY  ->  DECREASE (mass lost, volume same)
            INTERSTITIAL          ->  INCREASE (mass gained)
            FRENKEL               ->  NO CHANGE (nothing leaves)
            Impurity (SrCl2/NaCl) ->  slight decrease
            Always give the ONE LINE REASON, not just the name.
  TRAP     "Frenkel decreases density" is the classic wrong answer.
```

```
  PATTERN 21 — METAL EXCESS, F-CENTRES AND COLOUR             2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are F-centres?", "Why is NaCl yellow when heated in
            sodium vapour?", "Why does ZnO turn yellow?"
  METHOD    F-CENTRE = an ELECTRON trapped in an ANION VACANCY.
            NaCl route:  Na (vap) -> Na+ + e- ; the e- fills a Cl- hole
                         -> Na(1+x)Cl , YELLOW
                         KCl -> VIOLET ,  LiCl -> PINK
            ZnO route:   ZnO --(heat)--> Zn2+ + (1/2)O2 + 2e-
                         Zn2+ and e- go into INTERSTITIAL sites
                         -> Zn(1+x)O , WHITE turns YELLOW
            Both make the solid an n-TYPE semiconductor.
  TRAP      Write the ZnO equation - it is worth a mark by itself.
            The colour arises because the TRAPPED ELECTRON absorbs
            visible light, not because sodium metal is coloured.
```

```
  PATTERN 22 — METAL DEFICIENCY / NON-STOICHIOMETRY           2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   A fractional formula appears:  Fe(0.95)O , Cu(1.97)S ,
            "why is FeO never exactly FeO?"
  METHOD    Some cation sites are EMPTY; the missing positive charge is
            supplied by neighbouring ions in a HIGHER oxidation state.
                 3 Fe2+  ->  2 Fe3+  +  one cation vacancy
            Composition ranges from Fe(0.93)O to Fe(0.96)O.
            The holes give p-TYPE semiconduction.
  TRAP      Metal EXCESS -> n-type.  Metal DEFICIENCY -> p-type.
            Do not swap them.
```

```
  PATTERN 23 — IMPURITY DEFECT / VACANCY COUNT                2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "NaCl doped with 10^-3 mol % SrCl2. Find the number of cation
            vacancies."
  METHOD    1. One Sr2+ replaces TWO Na+ but fills only ONE site
                 -> ONE cation vacancy per Sr2+.
            2. Convert "mol %" to moles per mole of NaCl:
                 x mol %  =  x/100 mol per mole
            3. vacancies = (moles of dopant) x 6.022 x 10^23
  TRAP      "mol %" means per HUNDRED moles. 10^-3 mol % = 10^-5 mol
            per mole. Forgetting the /100 costs the whole answer.
```

```
  PATTERN 24 — BAND THEORY: CONDUCTOR / SEMICONDUCTOR /       4 or 8 marks
               INSULATOR
  ------------------------------------------------------------------------
  TRIGGER   "Explain the electrical properties of solids on the basis of
            band theory."
  METHOD    Define valence band, conduction band, forbidden gap.
            DRAW the three band diagrams side by side.
              conductor     - bands OVERLAP / partly filled
              semiconductor - SMALL gap, 0.5 to 3 eV
              insulator     - LARGE gap, more than 3 eV
            Add the conductivity ranges and the heating behaviour:
              metal DOWN on heating , semiconductor UP on heating.
  TRAP      The diagram is compulsory. Also mention that a semiconductor
            is INTRINSIC when pure and EXTRINSIC after doping.
```

```
  PATTERN 25 — n-TYPE AND p-TYPE BY DOPING                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Si doped with As gives which type?", "Explain n-type and
            p-type semiconductors."
  METHOD    Si / Ge belong to GROUP 14 (4 valence electrons).
              + GROUP 15 (P, As, Sb, Bi) -> one SPARE electron -> n-TYPE
              + GROUP 13 (B, Al, Ga, In) -> one HOLE            -> p-TYPE
            Draw the little Si network with the dopant in the centre.
            "15 GIVES , 13 TAKES."
  TRAP      An n-type crystal is still electrically NEUTRAL overall;
            "n" describes the CARRIER, not a net charge.
```

```
  PATTERN 26 — 13-15 AND 12-16 COMPOUND SEMICONDUCTORS        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "GaAs is an example of ...", "Give two 12-16 compounds."
  METHOD    The AVERAGE number of valence electrons must be 4.
              13-15 :  InSb , AlP , GaAs , GaP     (3+5)/2 = 4
              12-16 :  ZnS , CdS , CdSe , HgTe     (2+6)/2 = 4
            12-16 compounds have more IONIC character.
            GaAs is used in LEDs and fast transistors.
  TRAP      Note the group numbers, not the old "III-V" names. ZnS
            appears in BOTH this list and the Frenkel-defect list.
```

```
  PATTERN 27 — THE FIVE MAGNETIC TYPES                        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Classify MnO / Fe3O4 / TiO2 ...", "Explain the magnetic
            properties of solids."
  METHOD    Give the ALIGNMENT, the BEHAVIOUR and an EXAMPLE for each:
              PARA        unpaired e-, random   weakly ATTRACTED  O2, Cu2+
              DIA         all paired            weakly REPELLED   NaCl,H2O
              FERRO       ^^^^^^ all parallel   STRONGLY attracted Fe,Co,Ni
              ANTIFERRO   ^v^v equal opposite   net ZERO          MnO
              FERRI       ^^v^^v unequal        SMALL net moment  Fe3O4
            Draw the arrow rows - they carry marks.
  TRAP      Fe3O4 is FERRImagnetic, not ferromagnetic.
            Above the CURIE temperature ferromagnetic -> PARAMAGNETIC.
```

```
  PATTERN 28 — STRUCTURE-TYPE RECALL                          2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the coordination number in CsCl / NaCl / ZnS?"
            "Describe the rock salt structure."
  METHOD    NaCl (rock salt)  Cl- ccp , Na+ in ALL octahedral voids
                              C.N. 6:6 , Z = 4
            ZnS (zinc blende) S2- ccp , Zn2+ in HALF the tetrahedral voids
                              C.N. 4:4 , Z = 4
            CaF2 (fluorite)   Ca2+ ccp , F- in ALL tetrahedral voids
                              C.N. 8:4 , Z = 4
            Na2O (antifluorite)  O2- ccp , Na+ in all tetrahedral voids
                              C.N. 4:8
            CsCl              Cl- corners , Cs+ body centre , C.N. 8:8, Z=1
  TRAP      Fluorite is 8:4 and antifluorite is 4:8 - the numbers swap.
```
