## THE 60-SECOND VERSION

The p-block is the **six columns on the right of the periodic table**. Groups 15,
16, 17 and 18 are the last four of them.

```
  GROUP 15   ns2 np3   needs 3 more electrons   N  P  As  Sb  Bi
  GROUP 16   ns2 np4   needs 2 more electrons   O  S  Se  Te  Po
  GROUP 17   ns2 np5   needs 1 more electron    F  Cl Br  I   At
  GROUP 18   ns2 np6   needs NOTHING            He Ne Ar Kr Xe Rn
```

Everything in 60 pages boils down to **four master ideas**:

```
  IDEA 1 - SIZE GROWS DOWNWARDS.
           Bigger atom -> electron held loosely -> IE falls, EN falls,
           bonds get longer and weaker -> hydrides get less stable,
           more acidic and better reducing agents as you go DOWN.

  IDEA 2 - THE INERT PAIR EFFECT.
           The ns2 pair gets "lazy" going down because the d and f
           electrons under it shield the nucleus badly. So the LOWER
           oxidation state becomes more stable at the bottom.
              N +5 is fine  ->  Bi +5 is a savage oxidiser (BiCl5 barely exists)
              S +6 is fine  ->  Po +6 is unstable
              Pb2+ > Pb4+ ,  Tl+ > Tl3+   (same reason, other groups)

  IDEA 3 - THE FIRST MEMBER IS ALWAYS A REBEL.
           N, O and F are tiny, super electronegative and have NO d
           ORBITALS. So they cannot expand their octet, and they form
           p-pi - p-pi MULTIPLE BONDS that their heavier cousins cannot.
              N2 has a TRIPLE bond -> a gas.   P exists as solid P4.
              O2 has a DOUBLE bond -> a gas.   S exists as solid S8.

  IDEA 4 - NOBLE GASES DO NOTHING because their octet is already full.
           Only Xe (biggest, lowest IE) reacts, and only with the two
           nastiest elements: FLUORINE and OXYGEN.
```

```
  ONE SENTENCE TO REMEMBER THE WHOLE CHAPTER:

     "Going DOWN a group: atoms get BIGGER, so bonds get WEAKER,
      so hydrides get LESS STABLE, MORE ACIDIC and BETTER REDUCERS,
      and the LOWER oxidation state takes over."
```

## THE INERT PAIR EFFECT — the one idea examiners love

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   INERT PAIR EFFECT                                                  |
  |                                                                      |
  |   DEFINITION (write exactly this for 2 marks):                       |
  |     "The reluctance of the ns2 electron pair to take part in bond    |
  |      formation, because of the poor shielding of the nucleus by the  |
  |      intervening d and f electrons, is called the inert pair effect. |
  |      As a result the stability of the LOWER oxidation state          |
  |      (group valency minus 2) INCREASES down the group."              |
  |                                                                      |
  |   PICTURE:                                                           |
  |                                                                      |
  |      GROUP 15         top    N   +5 stable  ------+                  |
  |                              P   +5 stable        |  +5 gets         |
  |                              As  +5 ok            |  WEAKER          |
  |                              Sb  +3 preferred     |  going           |
  |                       bottom Bi  +3 STRONGLY      v  DOWN            |
  |                                     preferred                        |
  |                                                                      |
  |      CONSEQUENCE:  BiCl3 is stable, BiCl5 hardly exists.             |
  |                    Bi(V) compounds are POWERFUL OXIDISING AGENTS,    |
  |                    because Bi(V) is desperate to fall back to Bi(III)|
  |                                                                      |
  |      SAME STORY:   Group 13   Tl+  >  Tl3+                           |
  |                    Group 14   Pb2+ >  Pb4+  (PbO2 is an oxidiser)    |
  |                    Group 16   Po +4 > Po +6                          |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## THE TREND CHEAT SHEET (one glance before you enter the hall)

| GOING DOWN THE GROUP | GROUP 15 | GROUP 16 | GROUP 17 | GROUP 18 |
|---|---|---|---|---|
| Atomic radius | UP | UP | UP | UP |
| Ionisation enthalpy | DOWN | DOWN | DOWN | DOWN |
| Electronegativity | DOWN | DOWN | DOWN | — |
| Melting point | UP to As, then DOWN at Bi | UP to Te, then DOWN at Po | UP all the way | UP all the way |
| Metallic character | UP (N,P non-metal; As,Sb metalloid; Bi metal) | UP (O,S non-metal; Se,Te metalloid; Po metal) | all non-metals | all gases |
| Stability of higher oxidation state | DOWN (inert pair) | DOWN (inert pair) | DOWN | — |
| Hydride stability | DOWN | DOWN | DOWN | — |
| Hydride bond angle | DOWN | DOWN | — | — |
| Hydride reducing power | UP | UP | UP | — |
| Hydride acidity | UP (basicity DOWN) | UP | UP | — |

```
  THE ONLY TWO EXCEPTIONS THAT GET ASKED:

     1. Electron gain enthalpy of  F  is LESS negative than that of  Cl.
        (F is so small that the incoming electron is repelled by the
         electrons already crowded in the tiny 2p shell.)

     2. Bond dissociation enthalpy:  Cl2 > Br2 > F2 > I2.
        (F2 is abnormally LOW because the two tiny F atoms sit so close
         that their lone pairs repel each other and loosen the bond.)
```
