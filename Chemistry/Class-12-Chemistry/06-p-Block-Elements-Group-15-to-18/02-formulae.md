| GROUP | CONFIG | ELEMENTS (top to bottom) | METALLIC CHARACTER |
|---|---|---|---|
| 15 | ns2 np3 | N, P (non-metals) · As, Sb (metalloids) · Bi (metal) | non-metal -> metal |
| 16 | ns2 np4 | O, S (non-metals) · Se, Te (metalloids) · Po (metal, radioactive) | non-metal -> metal |
| 17 | ns2 np5 | F, Cl, Br, I (all non-metals) · At (radioactive) | all non-metals |
| 18 | ns2 np6 | He, Ne, Ar, Kr, Xe (gases) · Rn (radioactive) | all monoatomic gases |

# 1.2 Oxidation states — and how to work them out

```
  THE RULE:
     MAXIMUM POSITIVE state = the GROUP NUMBER minus 10
     MINIMUM NEGATIVE state = the GROUP NUMBER minus 18
     COMMON LOWER positive state = (maximum minus 2)  <- inert pair effect

     GROUP 15:  max = 15 - 10 = +5     min = 15 - 18 = -3
     GROUP 16:  max = 16 - 10 = +6     min = 16 - 18 = -2
     GROUP 17:  max = 17 - 10 = +7     min = 17 - 18 = -1
     GROUP 18:  0  (Xe forces +2, +4, +6, +8 only with F and O)
```

| GROUP | STATES SHOWN | THE EXCEPTIONS YOU MUST QUOTE |
|---|---|---|
| 15 | -3, +3, +5 (also +1, +2, +4 in oxides) | N cannot exceed +5; N shows ALL states -3 to +5 |
| 16 | -2, +2, +4, +6 | **O shows only -2 and -1** (peroxide) and -1/2 (superoxide); **+2 only in OF2** |
| 17 | -1, +1, +3, +5, +7 | **F shows ONLY -1**, never positive |
| 18 | 0 | only Xe (and a little Kr) forms real compounds |

```
  WHY DOES OXYGEN NOT SHOW +6, AND FLUORINE NOT SHOW +7 ?

     Because both are in PERIOD 2 and have NO d ORBITALS in their
     valence shell. They cannot promote electrons to expand the octet.
     Also both are so electronegative that no other atom can pull
     electrons away from them  ->  no positive oxidation state.

     Exception to remember: in OF2 oxygen is +2, because F is MORE
     electronegative than O. That is the ONLY case.
```

# PART 2 — TREND TABLES, EACH WITH ITS REASON

These four tables are the raw material of every "explain the trend" question.
Learn the REASON column, not just the arrow.

# 2.1 GROUP 15 — the nitrogen family

| PROPERTY | N -> Bi | REASON (write this line) |
|---|---|---|
| Atomic / ionic radius | **INCREASES** | a new shell is added at every step |
| Ionisation enthalpy | **DECREASES** | bigger atom + more shielding -> outer electron held less tightly |
| Electronegativity | **DECREASES** | bigger atom, weaker pull on the shared pair |
| Metallic character | **INCREASES** | IE falls, so electrons are given up more easily |
| Melting point | UP to As, then **DOWN at Bi** | packing improves to As; the very large Bi atom bonds weakly |
| Boiling point | increases steadily | bigger atom -> stronger dispersion forces |
| Catenation | **DECREASES** (N and P only) | E-E bond gets longer and weaker down the group |
| Stability of +5 | **DECREASES** | INERT PAIR EFFECT |
| Stability of +3 | **INCREASES** | INERT PAIR EFFECT |
| Stability of -3 | **DECREASES** | EN falls, so the element is less able to hold 3 extra electrons |

```
  IONISATION ENTHALPY ANOMALY WORTH KNOWING:
     Group 15 elements have HIGHER ionisation enthalpies than the
     group 14 and group 16 elements of the same period.
     REASON: the ns2 np3 configuration is EXACTLY HALF FILLED, which is
     an extra-stable, symmetrical arrangement, so it resists ionisation.
        Example:  IE of N  >  IE of O   (even though O comes after N)
```

# 2.2 GROUP 16 — the oxygen family / chalcogens

| PROPERTY | O -> Po | REASON |
|---|---|---|
| Atomic radius | **INCREASES** | new shell each step |
| Ionisation enthalpy | **DECREASES** | size up, shielding up |
| Electronegativity | **DECREASES** | O is second only to F in the whole table |
| Electron gain enthalpy | O is **LESS negative** than S | O is so small that the incoming electron feels strong repulsion from the crowded 2p electrons |
| Melting / boiling point | **INCREASE** (Po dips) | molecule size and dispersion forces grow |
| Metallic character | **INCREASES** | O, S non-metals; Se, Te metalloids; Po metal |
| Stability of +6 | **DECREASES** | INERT PAIR EFFECT (+4 takes over at Po) |
| Oxidising power of the element | **DECREASES** | O2 is a strong oxidiser, Te is weak |

# 2.3 GROUP 17 — the halogens

| PROPERTY | F -> I | REASON |
|---|---|---|
| Atomic radius | **INCREASES** | new shell each step (F is the smallest of all halogens) |
| Ionisation enthalpy | **DECREASES** | size and shielding grow; halogens still have very HIGH IE overall |
| Electronegativity | **DECREASES** | **F is the most electronegative element in the periodic table** |
| Electron gain enthalpy | **Cl > F > Br > I** (Cl most negative) | see the box below - a certain exam question |
| Bond dissociation enthalpy of X2 | **Cl2 > Br2 > F2 > I2** | F2 is abnormally low - see the box below |
| Melting / boiling point | **INCREASE** | bigger molecule -> stronger van der Waals forces (F2, Cl2 gas; Br2 liquid; I2 solid) |
| Colour | pale yellow -> greenish yellow -> red brown -> violet black | the energy gap for absorption falls, so heavier halogens absorb visible light more easily |
| Oxidising power | **F2 > Cl2 > Br2 > I2** | F2 has the most negative overall enthalpy of hydration + low bond enthalpy |
| Acid strength of HX | **HF < HCl < HBr < HI** | H-X bond gets longer and weaker |

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE TWO FLUORINE ANOMALIES  (both are guaranteed 2-mark questions) |
  |                                                                      |
  |   (a) WHY IS THE ELECTRON GAIN ENTHALPY OF F LESS NEGATIVE           |
  |       THAN THAT OF Cl ?                                              |
  |                                                                      |
  |       Because the fluorine atom is EXTREMELY SMALL. Its 2p subshell  |
  |       is already very compact and crowded, so the incoming electron  |
  |       experiences STRONG INTER-ELECTRONIC REPULSION.                 |
  |       Less energy is therefore released.                             |
  |       Chlorine's 3p subshell is larger and more spread out, so the   |
  |       incoming electron is accommodated comfortably.                 |
  |                                                                      |
  |       ORDER:   Cl  >  F  >  Br  >  I                                 |
  |                (most negative -----> least negative)                 |
  |                                                                      |
  |   (b) WHY IS THE BOND DISSOCIATION ENTHALPY OF F2 SO LOW ?           |
  |                                                                      |
  |       The two F atoms are so small that the F-F bond is very short.  |
  |       The three LONE PAIRS on each atom are pushed very close        |
  |       together and REPEL each other strongly, weakening the bond.    |
  |                                                                      |
  |       ORDER:   Cl2  >  Br2  >  F2  >  I2                             |
  |                                                                      |
  |   AND YET F2 IS THE STRONGEST OXIDISING AGENT. Why?                  |
  |       Because the low bond enthalpy makes F2 easy to split, AND      |
  |       the tiny F- ion has a very high (very negative) hydration      |
  |       enthalpy. Both terms favour  F2 + 2e- -> 2F-  overwhelmingly.  |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# 2.4 GROUP 18 — the noble gases

| PROPERTY | He -> Rn | REASON |
|---|---|---|
| Atomic radius | **INCREASES** | new shell each step (these are van der Waals radii, so they look large) |
| Ionisation enthalpy | **DECREASES** | **He has the highest IE of any element**; Xe's is low enough to react |
| Electron gain enthalpy | **POSITIVE** for all | the shell is already full - adding an electron costs energy |
| Melting / boiling point | **INCREASE** | dispersion forces grow with size; **He has the lowest b.p. of any substance, 4.2 K** |
| Solubility in water | **INCREASES** | larger, more polarisable atoms interact better with water |
| Reactivity | **INCREASES** (only Xe matters) | IE falls enough for F and O to attack Xe |

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   WHY ARE THE NOBLE GASES CHEMICALLY INERT ?  (3 points = 2 marks)   |
  |                                                                      |
  |   1. COMPLETELY FILLED outermost shell,  ns2 np6  (He = 1s2).        |
  |      This is the most stable electronic arrangement possible.        |
  |                                                                      |
  |   2. VERY HIGH IONISATION ENTHALPY - the highest in each period -    |
  |      so they will not LOSE an electron.                              |
  |                                                                      |
  |   3. POSITIVE ELECTRON GAIN ENTHALPY - energy must be SUPPLIED to    |
  |      push an electron in - so they will not GAIN one either.         |
  |                                                                      |
  |   No urge to lose, gain or share  ->  no bonds  ->  MONOATOMIC gas.  |
  |                                                                      |
  |   WHY DOES XENON REACT AT ALL ?                                      |
  |      Xe is large and its outer electrons are poorly shielded, so its |
  |      ionisation enthalpy is LOW ENOUGH for the two most oxidising    |
  |      elements - FLUORINE and OXYGEN - to strip electrons from it.    |
  |      (Neil Bartlett, 1962:  Xe + PtF6  ->  Xe+[PtF6]- )              |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# PART 3 — THE INERT PAIR EFFECT

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   DEFINITION - write these exact words:                              |
  |                                                                      |
  |     "The reluctance of the ns2 electron pair to participate in bond  |
  |      formation, owing to the POOR SHIELDING of the nucleus by the    |
  |      intervening d and f electrons, is called the INERT PAIR EFFECT. |
  |      As a result, the stability of the LOWER oxidation state         |
  |      (group valency minus 2) INCREASES down the group, while the     |
  |      higher oxidation state becomes less stable."                    |
  |                                                                      |
  |   THE MECHANISM IN ONE LINE:                                         |
  |      d and f electrons are poor at screening  ->  the effective      |
  |      nuclear charge felt by the ns2 pair is HIGH  ->  that pair is   |
  |      pulled in tightly and refuses to bond.                          |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| GROUP | HIGHER STATE | LOWER STATE | EVIDENCE TO QUOTE |
|---|---|---|---|
| 13 | +3 | +1 | Tl+ is more stable than Tl3+ |
| 14 | +4 | +2 | Pb2+ > Pb4+; **PbO2 is a strong oxidiser** |
| 15 | +5 | +3 | **BiCl3 stable, BiCl5 barely exists; Bi(V) is a powerful oxidiser** |
| 16 | +6 | +4 | Po(IV) is more stable than Po(VI) |

```
  THE STANDARD FOLLOW-UP QUESTION:

  Q. Why is Bi(V) a stronger oxidising agent than Sb(V) ?
  A. Because of the inert pair effect, Bi(V) is very unstable and is
     desperate to drop back to the stable Bi(III) state. To do that it
     must ACCEPT electrons - which is exactly what an oxidising agent
     does. Sb(V) is comparatively stable, so it oxidises less strongly.

  Q. Why is BiH3 the strongest reducing agent among group 15 hydrides?
  A. The Bi-H bond is the longest and weakest, so BiH3 gives up its
     hydrogen most easily.
```

# PART 4 — ANOMALOUS BEHAVIOUR OF THE FIRST MEMBER

Every group's first member (N, O, F) misbehaves, and it is **always for the
same three reasons**. Learn the three reasons once and reuse them.

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE THREE UNIVERSAL REASONS  (quote all three, every time)         |
  |                                                                      |
  |     REASON 1 :  SMALL ATOMIC SIZE                                    |
  |     REASON 2 :  HIGH ELECTRONEGATIVITY and high ionisation enthalpy  |
  |     REASON 3 :  ABSENCE OF d ORBITALS in the valence shell           |
  |                                                                      |
  |   CONSEQUENCE OF REASON 3 (the big one):                             |
  |     - the octet CANNOT be expanded  ->  covalency limited to 4       |
  |     - the small size lets p orbitals overlap sideways, so the        |
  |       first member forms  p-pi - p-pi  MULTIPLE BONDS that the       |
  |       heavier members cannot form.                                   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# 4.1 Nitrogen

| ANOMALY | REASON |
|---|---|
| N2 is a **GAS**, P is a solid (P4) | N forms a **p-pi - p-pi triple bond**, N(triple bond)N, giving small discrete molecules; P atoms are too big for sideways p overlap, so P forms single bonds and builds a P4 tetrahedron |
| N2 is **almost inert at room temperature** | the N(triple)N bond enthalpy is 941.4 kJ/mol - one of the strongest bonds known |
| Maximum covalency of N is **4**, not 5 | no d orbitals -> cannot expand the octet. **NCl5 does not exist, PCl5 does** |
| N does not form **pentahalides** | same reason |
| **NH3 forms hydrogen bonds**, PH3 does not | N is small and highly electronegative |
| N shows **all** oxidation states from -3 to +5 | small size and high EN |
| **NF3 is not hydrolysed**, NCl3 is | no d orbitals to accept the lone pair of water; also N-F is very strong and F has no vacant orbital |
| N forms stable **catenated** chains only rarely | N-N single bond is weak (lone pair repulsion), while P-P is stronger |

# 4.2 Oxygen

| ANOMALY | REASON |
|---|---|
| O2 is a **GAS**, S is a solid (S8) | O forms a **p-pi - p-pi double bond** O=O; S prefers single bonds and forms an S8 crown ring |
| Maximum covalency of O is **2** (rarely 4 by coordination) | no d orbitals |
| O shows **only -2 and -1**, never +6 | no d orbitals + very high EN |
| **H2O is a liquid**, H2S is a gas | strong intermolecular HYDROGEN BONDING in water |
| Oxides of O-containing acids are much stronger | small size concentrates the charge |

# 4.3 Fluorine

| ANOMALY | REASON |
|---|---|
| Electron gain enthalpy is **less negative than Cl** | tiny 2p shell -> strong electron-electron repulsion |
| F-F bond enthalpy is **abnormally low** | lone pair repulsion across the very short bond |
| F shows **only -1**, never a positive state | most electronegative element; no d orbitals |
| **HF is a liquid**, HCl is a gas | HF molecules are strongly HYDROGEN BONDED |
| **HF is a WEAK acid**, HCl/HBr/HI are strong | the H-F bond is very strong (short, high bond enthalpy) so H+ is not released easily |
| F forms only ONE oxoacid (**HOF**), unstable | no d orbitals, no positive oxidation state |
| Metal fluorides are mostly **ionic**, other halides more covalent | F- is small and hard, not easily polarised |
| **AgF is soluble** in water, AgCl/AgBr/AgI are not | small F- has a very high hydration enthalpy |

# 5.2 The bond angles — the exact numbers

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   GROUP 15                      GROUP 16                             |
  |     NH3   107.8 deg               H2O   104.5 deg                    |
  |     PH3    93.6 deg               H2S    92.1 deg                    |
  |     AsH3   91.8 deg               H2Se   91.0 deg                    |
  |     SbH3   91.3 deg               H2Te   90.0 deg                    |
  |     BiH3   ~90   deg                                                 |
  |                                                                      |
  |   ORDER:  NH3 > PH3 > AsH3 > SbH3 > BiH3                             |
  |           H2O > H2S > H2Se > H2Te                                    |
  |                                                                      |
  |   THE REASON (write BOTH halves):                                    |
  |                                                                      |
  |     (i)  ELECTRONEGATIVITY falls sharply from N to Bi. In NH3 the    |
  |          very electronegative N pulls the bond pairs CLOSE to        |
  |          itself, so the bond pairs are near each other and repel     |
  |          strongly, opening the angle out to 107.8 deg.               |
  |          In PH3, AsH3, SbH3 the central atom is a poor puller, the   |
  |          bond pairs lie far away near the H atoms, bond pair - bond  |
  |          pair repulsion is small, and the angle collapses.           |
  |                                                                      |
  |     (ii) HYBRIDISATION dies out down the group. In NH3 the orbitals  |
  |          are properly sp3 hybridised (ideal 109.5 deg, reduced to    |
  |          107.8 by the lone pair). In PH3 and below, the central      |
  |          atom uses almost PURE p ORBITALS, and pure p orbitals are   |
  |          at 90 deg to each other - which is exactly what is seen.    |
  |                                                                      |
  |   NOTE: NH3 is 107.8 and not 109.5 because the LONE PAIR on N        |
  |         repels the bond pairs harder than they repel each other.     |
  |         (lp-lp > lp-bp > bp-bp)                                      |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# 5.3 The boiling point anomaly — NH3 vs PH3

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   WHY DOES NH3 HAVE A HIGHER BOILING POINT THAN PH3 ?                |
  |   (certain 2-mark question - the answer is HYDROGEN BONDING)         |
  |                                                                      |
  |     NH3 boils at  239.7 K  (-33.3 deg C)                             |
  |     PH3 boils at  185.5 K  (-87.7 deg C)                             |
  |                                                                      |
  |   Nitrogen is SMALL and HIGHLY ELECTRONEGATIVE (EN = 3.0). The N-H   |
  |   bond is therefore strongly polar and the H carries a large partial |
  |   positive charge. That H is attracted to the LONE PAIR on the       |
  |   nitrogen of the next molecule:                                     |
  |                                                                      |
  |        H          H          H                                       |
  |         \          \          \                                      |
  |      H - N ..... H - N ..... H - N                                   |
  |         /          /          /                                      |
  |        H          H          H                                       |
  |            ^            ^                                            |
  |         hydrogen bond (strong)  -> molecules stick together          |
  |                                                                      |
  |   These INTERMOLECULAR HYDROGEN BONDS must be broken before NH3      |
  |   can boil, so a lot of extra energy is needed.                      |
  |                                                                      |
  |   Phosphorus is much LARGER and has a LOW electronegativity (2.1,    |
  |   almost the same as hydrogen's 2.1). The P-H bond is essentially    |
  |   NON-POLAR, so PH3 has NO hydrogen bonding - only weak van der      |
  |   Waals forces. It therefore boils at a much lower temperature.      |
  |                                                                      |
  |   THE SAME ARGUMENT, WORD FOR WORD, EXPLAINS:                        |
  |       H2O boils higher than H2S                                      |
  |       HF  boils higher than HCl                                      |
  |                                                                      |
  |   > TRAP: after NH3 the boiling points RISE again -                  |
  |     PH3 < AsH3 < SbH3 - because of increasing van der Waals forces   |
  |     with molecular size. So the order is  NH3 > SbH3 > AsH3 > PH3.   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# 5.4 Why is NF3 less basic than NH3?

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   BASICITY = the willingness of the LONE PAIR on nitrogen to be      |
  |              DONATED to a proton or a Lewis acid.                    |
  |                                                                      |
  |   IN NH3:                                                            |
  |      Hydrogen (EN 2.1) is LESS electronegative than N (EN 3.0), so   |
  |      the three H atoms PUSH electron density TOWARDS nitrogen.       |
  |      The lone pair is therefore rich in electron density, held       |
  |      loosely, and readily donated.  -> STRONGLY BASIC.               |
  |                                                                      |
  |         H  ->  N  <-  H          arrows point INTO N                 |
  |                |  ..             lone pair is fat and available      |
  |                H                                                     |
  |                                                                      |
  |   IN NF3:                                                            |
  |      Fluorine (EN 4.0) is MORE electronegative than N (EN 3.0), so   |
  |      the three F atoms PULL electron density AWAY from nitrogen      |
  |      (strong -I effect). The lone pair is contracted, tightly held   |
  |      and reluctant to be donated. -> VERY WEAKLY BASIC.              |
  |                                                                      |
  |         F  <-  N  ->  F          arrows point AWAY from N            |
  |                |  ..             lone pair is starved                |
  |                F                                                     |
  |                                                                      |
  |   SECOND POINT worth a mark: the two bond dipoles and the lone pair  |
  |   dipole in NF3 point in OPPOSITE directions and partly cancel, so   |
  |   NF3 has a very small dipole moment (0.24 D) compared with NH3      |
  |   (1.46 D) - further evidence that the lone pair is not projecting   |
  |   outwards the way it does in ammonia.                               |
  |                                                                      |
  |   BASICITY ORDER:   NH3  >  NF3       and       NH3 > NCl3           |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# PART 6 — GROUP 15 REACTIONS, GROUPED BY COMPOUND

# 6.1 Dinitrogen, N2

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  LABORATORY PREPARATION  (the standard one)                          |
  |                                                                      |
  |     NH4Cl(aq) + NaNO2(aq)  --(heat)-->  N2 + 2 H2O + NaCl            |
  |                                                                      |
  |  OTHER PREPARATIONS                                                  |
  |                                                                      |
  |     (NH4)2Cr2O7  --(heat)-->  N2 + 4 H2O + Cr2O3   ("volcano")       |
  |                                                                      |

# 6.6 Allotropes of phosphorus

| | **WHITE (yellow) P4** | **RED P** | **BLACK P** |
|---|---|---|---|
| Structure | discrete **P4 tetrahedra**, P-P-P angle **60 deg** | **polymeric** - P4 tetrahedra linked in chains | layered / puckered sheets |
| Appearance | translucent white waxy solid | dark red powder | greyish black, metallic look |
| Smell / toxicity | garlic smell, **VERY POISONOUS** | odourless, **non-poisonous** | non-poisonous |

| Storage | **UNDER WATER** | ordinary bottle | ordinary bottle |

```
  WHY IS WHITE PHOSPHORUS MORE REACTIVE THAN RED PHOSPHORUS ?
  (a certain 2-mark question)

     In white phosphorus the four P atoms sit at the corners of a
     TETRAHEDRON, which forces the P-P-P bond angle down to 60 degrees.
     The natural angle for p-orbital overlap is about 90-109 degrees,
     so the bonds are severely BENT and the molecule carries a large
     amount of ANGULAR STRAIN (ring strain). The P-P bonds are
     therefore weak and break easily -> HIGH REACTIVITY.

     In red phosphorus the tetrahedra are OPENED UP and joined into a
     long POLYMERIC CHAIN, which relieves the strain. It is a giant
     covalent structure with strong bonds -> LOW REACTIVITY.

           WHITE P4 - strained            RED P - polymeric
                 P                      ... P4 - P4 - P4 - P4 ...
                /|\                          strain relieved,
               / | \    60 deg               chains are stable
              P--|--P
               \ | /
                 P

  WHY IS WHITE PHOSPHORUS STORED UNDER WATER ?
     Its ignition temperature is only 303 K (30 deg C), which is below
     a normal summer room temperature in Andhra Pradesh. Left in air it
     would spontaneously catch fire. It is insoluble in water, so water
     keeps the air away safely.

  CONVERSIONS
     white P  --(573 K, inert atmosphere, several hours)-->  red P
     white P  --(473 K, high pressure)-->  black P (alpha form)
```

# 7.2 CLASSIFICATION OF OXIDES

| TYPE | DEFINITION | EXAMPLES | KEY REACTION |
|---|---|---|---|
| **ACIDIC** | oxide of a NON-METAL; reacts with base | CO2, SO2, SO3, N2O5, P4O10, Cl2O7 | CO2 + 2 NaOH --> Na2CO3 + H2O |
| **BASIC** | oxide of a METAL; reacts with acid | Na2O, K2O, CaO, MgO, BaO | CaO + 2 HCl --> CaCl2 + H2O |
| **AMPHOTERIC** | reacts with BOTH acid and base | **Al2O3, ZnO, PbO, SnO2, BeO** | see the box below |
| **NEUTRAL** | reacts with neither | **CO, NO, N2O, H2O** | — |
| **MIXED** | behaves as two simpler oxides | **Pb3O4 (= 2PbO + PbO2), Fe3O4 (= FeO + Fe2O3)** | — |
| **PEROXIDE** | contains the O-O linkage, O is -1 | Na2O2, BaO2, H2O2 | Na2O2 + 2 H2O --> 2 NaOH + H2O2 |
| **SUPEROXIDE** | contains O2-, O is -1/2 | **KO2, RbO2, CsO2** | 4 KO2 + 2 H2O --> 4 KOH + 3 O2 |

     Na2O    MgO    Al2O3        SiO2   P4O10   SO3   Cl2O7
     basic  basic  amphoteric    ----- acidic, getting stronger ----->

  |      and unstable, so heat would decompose it straight back to O2.   |
  |      A silent discharge supplies the energy without the heat.        |
  |                                                                      |
  |   YIELD: about 10 % O3 in O2 ("ozonised oxygen"). Pure O3 is a pale  |
  |   blue gas, dark blue liquid, violet black solid; PUNGENT smell.     |
  |   Concentrated ozone is EXPLOSIVE.                                   |
  |                                                                      |
  |   STRUCTURE - ANGULAR (bent), sp2 hybridised, ONE lone pair on the   |
  |               central O, bond angle 117 degrees (some books 116.8).  |
  |                                                                      |
  |                       O                                              |
  |                     // \\           BOTH O-O bonds = 128 pm          |
  |                    //   \\          (equal length)                   |
  |                   O       O                                          |
  |                    117 deg                                           |
  |                                                                      |
  |   WHY ARE BOTH O-O BONDS EQUAL, AND WHY 128 pm ?                     |
  |      Because ozone is a RESONANCE HYBRID of the two structures       |
  |      below. The double bond is not stuck on one side - it is         |
  |      DELOCALISED over both. So each bond is IDENTICAL and its        |
  |      length (128 pm) lies BETWEEN a pure O-O single bond (148 pm)    |
  |      and a pure O=O double bond (121 pm).                            |
  |                                                                      |
  |          O                    O                                      |
  |        // \        <-->      /  \\                                   |
  |       O     O               O      O                                 |
  |                                                                      |
  |   Ozone has a small but NON-ZERO dipole moment (0.53 D) because it   |
  |   is bent - a linear molecule would have zero. This is the proof     |
  |   that the shape is angular.                                         |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```

  OXYGEN readily:

        O3  -->  O2 + [O]           E0 = +2.07 V in acid solution
        (only F2 and a couple of others beat it)

```
  STRUCTURE:  TETRAHEDRAL around S, sp3 hybridised.

                   O
                   ||
             HO -  S  - OH

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   FACE 1 - STRONG DIBASIC ACID  (in dilute solution)                 |
  |                                                                      |
  |      H2SO4 + H2O  -->  H3O+ + HSO4-      Ka1 is very large           |
  |      HSO4- + H2O  -->  H3O+ + SO4 2-     Ka2 = 1.2 x 10^-2           |
  |                                                                      |
  |      It forms TWO series of salts:                                   |
  |         NaHSO4 (sodium HYDROGENSULPHATE - acid salt)                 |
  |         Na2SO4 (sodium sulphate - normal salt)                       |
  |                                                                      |
  |      It displaces weaker/more volatile acids from their salts:       |
  |         2 NaCl   + H2SO4  -->  Na2SO4 + 2 HCl                        |
  |         2 KNO3   + H2SO4  -->  K2SO4  + 2 HNO3                       |
  |         CaF2     + H2SO4  -->  CaSO4  + 2 HF                         |
  |         Na2CO3   + H2SO4  -->  Na2SO4 + H2O + CO2                    |
  |                                                                      |
  |                                                                      |
  |   FACE 2 - DEHYDRATING AGENT  (it removes the ELEMENTS of water)     |
  |                                                                      |
  |      SUGAR TO CARBON - the famous "black snake" demonstration:       |
  |         C12H22O11  --(conc. H2SO4)-->  12 C  +  11 H2O               |
  |         White sugar turns into a swelling BLACK spongy mass of       |
  |         carbon, and the beaker gets HOT.                             |
  |                                                                      |
  |      OXALIC ACID:                                                    |
  |         (COOH)2  --(conc. H2SO4)-->  CO + CO2 + H2O                  |
  |                                                                      |
  |      FORMIC ACID:                                                    |
  |         HCOOH  --(conc. H2SO4)-->  CO + H2O                          |
  |                                                                      |
  |      ETHANOL:                                                        |
  |         C2H5OH  --(conc. H2SO4, 443 K)-->  C2H4 + H2O                |
  |                                                                      |
  |      HYDRATED SALTS lose their water of crystallisation:             |
  |         CuSO4 . 5H2O  --(conc. H2SO4)-->  CuSO4 + 5 H2O              |
  |            BLUE crystals turn WHITE.                                 |
  |                                                                      |
  |      NOTE: the sugar and oxalic acid molecules do NOT contain any    |
  |      water. H2SO4 has such a huge affinity for water that it pulls   |
  |      the H and O OUT of the molecule as water. That is what makes    |
  |      it a DEHYDRATING agent rather than merely a drying agent.       |
  |                                                                      |
  |                                                                      |
  |   FACE 3 - OXIDISING AGENT  (hot concentrated H2SO4 only)            |
  |                                                                      |
  |      It is itself reduced to SO2:                                    |
  |                                                                      |
  |         Cu + 2 H2SO4(conc.)  -->  CuSO4 + SO2 + 2 H2O                |
  |         C  + 2 H2SO4(conc.)  -->  CO2   + 2 SO2 + 2 H2O              |
  |         S  + 2 H2SO4(conc.)  -->  3 SO2 + 2 H2O                      |
  |         2 HBr + H2SO4        -->  Br2 + SO2 + 2 H2O                  |
  |         8 HI  + H2SO4        -->  4 I2 + H2S + 4 H2O                 |
  |                                                                      |
  |      (This is exactly why HBr and HI CANNOT be prepared by heating   |
  |       KBr or KI with concentrated H2SO4 - the acid oxidises the      |
  |       product. Use phosphoric acid instead.)                         |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```

     - lead-acid storage batteries

# 8.2 BLEACHING ACTION OF CHLORINE

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   Chlorine bleaches ONLY IN THE PRESENCE OF MOISTURE.                |
  |   Dry chlorine does not bleach at all. That is the key point.        |
  |                                                                      |
  |   STEP 1   Cl2 + H2O   -->  HCl + HOCl     (hypochlorous acid)       |
  |                                                                      |
  |   STEP 2   HOCl        -->  HCl + [O]      (NASCENT OXYGEN)          |
  |                                                                      |
  |   STEP 3   coloured substance + [O]  -->  COLOURLESS substance       |
  |                                                                      |
  |   OVERALL:                                                           |
  |            Cl2 + H2O  -->  2 HCl + [O]                               |
  |                                                                      |
  |   Chlorine bleaches by OXIDATION. The nascent oxygen chemically      |
  |   DESTROYS the coloured dye molecule, so the colour can never come   |
  |   back. Hence the bleaching is PERMANENT.                            |
  |                                                                      |
  |   Used for: cotton, linen, wood pulp, paper.                         |
  |   NOT used for wool and silk, which chlorine would attack and ruin.  |
  |                                                                      |
  |   +--------------------+----------------------------------------+    |
  |   |   CHLORINE         |   SULPHUR DIOXIDE                      |    |
  |   +--------------------+----------------------------------------+    |
  |   |   bleaches by      |   bleaches by                          |    |
  |   |   OXIDATION        |   REDUCTION                            |    |
  |   |   gives [O]        |   gives [H]                            |    |
  |   |   PERMANENT        |   TEMPORARY (air restores the colour)  |    |
  |   |   cotton, paper    |   wool, silk, straw                    |    |
  |   +--------------------+----------------------------------------+    |
  |                                                                      |
  |   > TRAP: never write "Cl2 bleaches by reduction". Half the class    |
  |     writes it. The nascent species is OXYGEN, and oxygen OXIDISES.   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| TYPE | GENERAL | Cl EXAMPLE | NAME | OX. STATE |
|---|---|---|---|---|
| Hypohalous | HOX | **HOCl** | hypochlorous acid | **+1** |
| Halous | HOXO | **HClO2** | chlorous acid | **+3** |

  +----------------------------------------------------------------------+
  |                                                                      |
  |   ACID STRENGTH  (down the list, as oxygens are added)               |
  |                                                                      |
  |        HOCl  <  HClO2  <  HClO3  <  HClO4        INCREASES           |
  |         +1       +3        +5        +7                              |
  |                                                                      |
  |   TWO REASONS - write both:                                          |
  |     (i)  each extra highly electronegative OXYGEN pulls electron     |
  |          density away from the O-H bond (-I effect), weakening it,   |
  |          so the proton leaves more easily;                           |
  |     (ii) the anion left behind spreads its negative charge over      |
  |          MORE oxygen atoms - better RESONANCE STABILISATION - so     |
  |          the more oxygens, the more stable the conjugate base and    |
  |          the stronger the acid.                                      |
  |                                                                      |
  |   HClO4 is one of the STRONGEST acids known.                         |
  |                                                                      |
  |                                                                      |
  |   ACID STRENGTH ACROSS THE HALOGENS, same type:                      |
  |                                                                      |
  |        HOCl  >  HOBr  >  HOI                     DECREASES           |
  |        HClO4 > HBrO4 > HIO4                                          |
  |                                                                      |
  |   REASON: Cl is the most electronegative of the three, so it pulls   |
  |   electron density from the O-H bond most strongly.                  |
  |                                                                      |
  |                                                                      |
  |   OXIDISING POWER GOES THE OPPOSITE WAY:                             |
  |                                                                      |
  |        HOCl  >  HClO2  >  HClO3  >  HClO4        DECREASES           |
  |                                                                      |
  |   The acid with the FEWEST oxygens releases its oxygen most easily.  |
  |                                                                      |
  |   > TRAP: HClO4 is the STRONGEST ACID but the WEAKEST OXIDISER of    |
  |     the four. Do not mix the two ladders up.                         |
  |                                                                      |
  |   FLUORINE forms only HOF, and even that is unstable - F has no d    |
  |   orbitals and cannot take a positive oxidation state.               |
  |                                                                      |
  +----------------------------------------------------------------------+
```

  WHY ARE INTERHALOGENS MORE REACTIVE THAN THE HALOGENS
  (except F2, which is the most reactive substance of all)?

     The X-X' bond joins two DIFFERENT atoms of different size and
     electronegativity, so it is POLAR and WEAKER than the pure,
     non-polar X-X bond in an ordinary halogen molecule.
     A weaker bond breaks more easily  ->  greater reactivity.

  HYDROLYSIS gives the halide of the SMALLER halogen and an oxoacid
  of the LARGER one:
        ClF3 + 2 H2O  -->  3 HF + HClO2

        enrichment:   U + 3 ClF3  -->  UF6 + 3 ClF

# 9.1 THE HABER PROCESS — manufacture of ammonia

```

  |                                                                      |
  |             dH  =  - 46.1 kJ / mol    (EXOTHERMIC)                   |
  |             dS  =  NEGATIVE   (4 moles of gas -> 2 moles of gas)     |
  |                                                                      |
  |   THE CONDITIONS  -  memorise these four numbers                     |
  |                                                                      |
  |      PRESSURE      :  200 atm    ( = 200 x 10^5 Pa )                 |
  |      TEMPERATURE   :  700 K      (about 673 - 773 K)                 |
  |      CATALYST      :  IRON OXIDE (finely divided iron)               |
  |      PROMOTERS     :  K2O  and  Al2O3                                |
  |                                                                      |
  |   RAW MATERIALS: N2 from liquid air; H2 from the water-gas shift     |
  |   reaction or from natural gas.                                      |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   LE CHATELIER REASONING  -  justify EVERY condition                 |
  |   (This is what the 8-mark answer is really testing.)                |
  |                                                                      |
  |   LE CHATELIER'S PRINCIPLE:                                          |
  |     "If a system at equilibrium is disturbed, the equilibrium        |
  |      shifts in the direction that opposes the disturbance."          |
  |                                                                      |
  |   ---------------------------------------------------------------    |
  |   (a) WHY HIGH PRESSURE (200 atm) ?                                  |
  |                                                                      |
  |         LEFT side  :  1 + 3  =  4 moles of gas                       |
  |         RIGHT side :          2 moles of gas                         |
  |                                                                      |
  |       The forward reaction DECREASES the number of gas moles.        |
  |       Raising the pressure squeezes the system, and the system       |
  |       relieves that squeeze by moving to the side with FEWER         |
  |       molecules - the RIGHT. So high pressure = more NH3.            |
  |                                                                      |
  |   ---------------------------------------------------------------    |
  |   (b) WHY IS THE TEMPERATURE ONLY MODERATE (700 K) AND NOT LOW ?     |
  |       ** This is the point most students miss. **                    |
  |                                                                      |
  |       The reaction is EXOTHERMIC, so by Le Chatelier a LOW           |
  |       temperature would give the BEST YIELD of ammonia.              |
  |                                                                      |
  |       BUT at a low temperature the RATE is hopelessly slow - the     |
  |       N(triple)N bond (941 kJ/mol) will not break, and equilibrium   |
  |       would take years to arrive.                                    |
  |                                                                      |
  |       So 700 K is a COMPROMISE - the "optimum temperature":          |
  |            low enough for a reasonable YIELD,                        |
  |            high enough for a reasonable RATE.                        |
  |                                                                      |
  |       WRITE THAT WORD: "optimum temperature" or "compromise".        |
  |                                                                      |
  |   ---------------------------------------------------------------    |
  |   (c) WHY A CATALYST ?                                               |
  |                                                                      |
  |       Iron provides a surface with a LOWER ACTIVATION ENERGY, so     |
  |       equilibrium is REACHED FASTER. A catalyst speeds up the        |
  |       forward and backward reactions EQUALLY, so it does NOT         |
  |       change the yield or the value of Kp - it only saves time.      |
  |       The PROMOTERS K2O and Al2O3 increase the catalyst's            |
  |       efficiency and its working life.                               |
  |                                                                      |
  |   ---------------------------------------------------------------    |
  |   (d) WHY IS AMMONIA REMOVED CONTINUOUSLY ?                          |
  |                                                                      |
  |       The gas mixture is cooled and the NH3 LIQUEFIES (b.p. 239.7 K) |
  |       while N2 and H2 stay gaseous. Removing a PRODUCT shifts the    |
  |       equilibrium to the RIGHT to replace it, so more NH3 forms.     |
  |       The unreacted N2 and H2 are RECYCLED back into the converter.  |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# 9.2 THE OSTWALD PROCESS — manufacture of nitric acid

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE PRINCIPLE: catalytic oxidation of AMMONIA (which itself comes  |
  |   from the Haber process) in three steps.                            |
  |                                                                      |
  |   STEP 1 - CATALYTIC OXIDATION OF AMMONIA                            |
  |                                                                      |
  |     4 NH3(g) + 5 O2(g)  <=(Pt/Rh gauze, 500 K, 9 bar)=> 4 NO + 6 H2O |
  |                                                                      |
  |       Catalyst : PLATINUM - RHODIUM GAUZE                            |
  |       Temp     : 500 K                                               |
  |       Pressure : 9 bar                                               |
  |       Contact time is only about a MILLISECOND. If the gas stays     |
  |       longer, the NO decomposes back to N2 and the yield falls.      |
  |       The reaction is exothermic and once started it is              |
  |       SELF-SUSTAINING - the gauze glows red hot.                     |
  |                                                                      |
  |   STEP 2 - OXIDATION OF NITRIC OXIDE  (cool to about 300 K first)    |
  |                                                                      |
  |     2 NO(g) + O2(g)  <==>  2 NO2(g)                                  |
  |                                                                      |
  |       This one is favoured by LOW temperature and HIGH pressure.     |
  |       Colourless NO turns BROWN as NO2 forms.                        |
  |                                                                      |
  |   STEP 3 - ABSORPTION IN WATER                                       |
  |                                                                      |
  |     3 NO2(g) + H2O(l)  -->  2 HNO3(aq)  +  NO(g)                     |
  |                                                                      |
  |       The NO produced here is FED BACK into step 2, so nothing is    |
  |       wasted. (Modern plants use  4 NO2 + O2 + 2 H2O -> 4 HNO3.)     |
  |                                                                      |
  |   CONCENTRATION                                                      |
  |       The acid obtained is about 68 % by mass. Simple distillation   |
  |       cannot go past this because 68 % HNO3 is an AZEOTROPE          |
  |       (constant boiling mixture, b.p. 393 K).                        |
  |       To reach 98 % ("fuming nitric acid") the 68 % acid is          |
  |       DEHYDRATED with CONCENTRATED SULPHURIC ACID.                   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  THE THREE EQUATIONS ON ONE LINE EACH - if you remember nothing else:

     4 NH3 + 5 O2  --(Pt/Rh, 500 K, 9 bar)-->  4 NO + 6 H2O
     2 NO  + O2    -------------------------->  2 NO2
     3 NO2 + H2O   -------------------------->  2 HNO3 + NO
```

# 9.3 THE CONTACT PROCESS — manufacture of sulphuric acid

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   STEP 1 - BURN SULPHUR OR ROAST SULPHIDE ORE TO GET SO2             |
  |                                                                      |
  |        S + O2  -->  SO2                                              |
  |        4 FeS2 + 11 O2  -->  2 Fe2O3 + 8 SO2   (iron pyrites)         |
  |                                                                      |
  |   STEP 2 - PURIFY THE SO2   (**the step students forget**)           |
  |                                                                      |
  |        The gas is passed through a dust precipitator, a cooling      |
  |        pipe, a scrubber, a drying tower (conc. H2SO4) and an         |
  |        arsenic purifier. Dust and especially ARSENIC compounds must  |
  |        be removed because they POISON the catalyst. The gas must     |
  |        also be DRY.                                                  |
  |                                                                      |
  |   STEP 3 - CATALYTIC OXIDATION TO SO3  (the heart of the process)    |
  |                                                                      |
  |        2 SO2(g) + O2(g)  <=(V2O5, 720 K, 2 bar)=>  2 SO3(g)          |
  |                                                                      |
  |                 dH = - 196.6 kJ / mol   (EXOTHERMIC)                 |
  |                                                                      |
  |        Catalyst    : VANADIUM PENTOXIDE, V2O5                        |
  |        Temperature : 720 K   (about 723 K)                           |
  |        Pressure    : 2 bar                                           |
  |                                                                      |
  |   STEP 4 - ABSORB SO3 IN CONCENTRATED H2SO4 TO GIVE OLEUM            |
  |                                                                      |
  |        SO3 + H2SO4  -->  H2S2O7      (OLEUM / pyrosulphuric acid,    |
  |                                       also called fuming H2SO4)      |
  |                                                                      |
  |   STEP 5 - DILUTE THE OLEUM WITH WATER                               |
  |                                                                      |
  |        H2S2O7 + H2O  -->  2 H2SO4    (96 - 98 % pure)                |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE TWO QUESTIONS ALWAYS ASKED ABOUT THE CONTACT PROCESS           |
  |                                                                      |
  |   Q. WHY IS SO3 NOT ABSORBED DIRECTLY IN WATER ?                     |
  |   A. SO3 + H2O -> H2SO4 is VIOLENTLY exothermic. It produces a       |
  |      dense, choking MIST/FOG of sulphuric acid droplets which        |
  |      neither condenses nor can be handled, so most of the product    |
  |      is lost. Dissolving SO3 in existing H2SO4 to make OLEUM is      |
  |      smooth and controllable; the oleum is then safely diluted.      |
  |                                                                      |
  |   Q. JUSTIFY THE CONDITIONS BY LE CHATELIER.                         |
  |   A. Step 3 is exothermic and goes from 3 moles of gas to 2 moles.   |
  |        - LOW temperature favours the YIELD, but the rate would be    |
  |          too slow, so 720 K is the COMPROMISE (optimum) value.       |
  |        - HIGH pressure favours the yield (3 mol -> 2 mol), but the   |
  |          conversion at 2 bar is ALREADY about 97 %, so there is no   |
  |          economic point in paying for higher pressure.               |
  |        - V2O5 does not change the yield; it just gets there faster.  |
  |        - EXCESS AIR (excess O2) pushes the equilibrium right.        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  THE FLOW LINE  -  five boxes, easy to draw

    S or FeS2 --> [BURN in air] --> SO2 --> [PURIFY + DRY] -->
       --> [CONVERTER  V2O5, 720 K, 2 bar] --> SO3 -->
       --> [ABSORPTION TOWER  in conc. H2SO4] --> OLEUM H2S2O7 -->
       --> [DILUTE with water] --> H2SO4 (98 %)
```

  STEP 3  leftovers / 2  =  number of LONE PAIRS.

# PART 11 — EVERY "ORDER" ASKED IN THE EXAM, IN ONE PLACE

# 11.1 ACID STRENGTH orders

| SERIES | ORDER | REASON |
|---|---|---|
| Group 15 hydrides | NH3 < PH3 < AsH3 < SbH3 < BiH3 | E-H bond weakens down the group |
| Group 16 hydrides | H2O < H2S < H2Se < H2Te | H-E bond weakens down the group |
| Halogen acids | **HF < HCl < HBr < HI** | H-X bond length increases, enthalpy falls |
| Oxoacids of Cl | **HOCl < HClO2 < HClO3 < HClO4** | more O atoms -> stronger -I effect + better resonance stabilisation of the anion |
| Hypohalous acids | **HOCl > HOBr > HOI** | Cl is most electronegative |
| Oxoacids of N | HNO2 < HNO3 | more oxygens, higher oxidation state |
| Oxoacids of S | H2SO3 < H2SO4 | more oxygens, higher oxidation state |
| Group 15 trioxides | N2O3 (acidic) > P2O3 > As2O3 (amphoteric) > Sb2O3 > Bi2O3 (basic) | metallic character increases down the group |
| Oxides of the same element | **N2O5 > N2O3** and **SO3 > SO2** | the higher the oxidation state, the more acidic the oxide |

# 11.2 THERMAL STABILITY orders

| SERIES | ORDER | REASON |
|---|---|---|
| Group 15 hydrides | **NH3 > PH3 > AsH3 > SbH3 > BiH3** | E-H bond enthalpy falls as the atom gets bigger |
| Group 16 hydrides | **H2O > H2S > H2Se > H2Te > H2Po** | same reason |
| Halogen acids | **HF > HCl > HBr > HI** | same reason (HF bond enthalpy 567 kJ/mol, HI only 299) |
| Halides of a metal | fluoride > chloride > bromide > iodide | ionic character falls, so lattice energy falls |
| Xenon fluorides | XeF2 > XeF4 > XeF6 | more strained as the fluorine count rises |
| Higher oxidation state in a group | decreases down (N > P > As > Sb > Bi for +5) | inert pair effect |

# 11.3 BOND ANGLE orders

| SERIES | ORDER + VALUES | REASON |
|---|---|---|
| Group 15 hydrides | **NH3 (107.8) > PH3 (93.6) > AsH3 (91.8) > SbH3 (91.3) > BiH3 (~90)** | electronegativity of the central atom falls, so bond-pair repulsion falls; hybridisation gives way to pure p orbitals (90 deg) |
| Group 16 hydrides | **H2O (104.5) > H2S (92.1) > H2Se (91) > H2Te (90)** | same two reasons |
| NH3 vs NF3 | NH3 (107.8) > NF3 (102.5) | in NF3 the bond pairs are pulled away towards F, so they repel each other less |
| Same-shape comparisons | CH4 (109.5) > NH3 (107.8) > H2O (104.5) | lone pairs: 0, 1, 2. Each extra lone pair squeezes the angle further (lp-lp > lp-bp > bp-bp) |
| Ozone / SO2 | O3 (117) < SO2 (119.5) | both sp2 with one lone pair; O is smaller so its lone pair squeezes harder |

# 11.4 REDUCING CHARACTER orders

| SERIES | ORDER | REASON |
|---|---|---|
| Group 15 hydrides | **BiH3 > SbH3 > AsH3 > PH3 > NH3** | weakest E-H bond gives up hydrogen most easily |
| Group 16 hydrides | **H2Te > H2Se > H2S > H2O** | same reason |
| Halogen acids | **HI > HBr > HCl > HF** | same reason - HI is such a good reducer that H2SO4 oxidises it to I2 |
| Oxoacids of P | **H3PO2 > H3PO3 > H3PO4 (not reducing)** | 2 P-H bonds, then 1, then none |
| Halide ions | I- > Br- > Cl- > F- | the biggest ion loses its electron most easily |

# 11.5 OXIDISING character orders

| SERIES | ORDER | REASON |
|---|---|---|
| Halogens | **F2 > Cl2 > Br2 > I2** | F2 has a low bond enthalpy and F- has a very high hydration enthalpy |
| Oxoacids of Cl | **HOCl > HClO2 > HClO3 > HClO4** | the fewer the oxygens, the more easily oxygen is released |
| Group 15 +5 compounds | Bi(V) > Sb(V) > As(V) | inert pair effect makes Bi(V) desperate to fall to Bi(III) |
| Common oxidisers here | **O3 (+2.07 V) is beaten only by F2 (+2.87 V)** | ozone gives nascent oxygen readily |

        Bi  >  Sb  >  As  >  P  >  N

  |       stable down the group.  Bi(III) > Bi(V), Pb(II) > Pb(IV).      |
  |                                                                      |
  |   3.  THE FIRST MEMBER IS A REBEL for THREE reasons:                 |
  |       small size, high electronegativity, NO d ORBITALS.             |
  |       So N and O form p-pi - p-pi MULTIPLE bonds and are GASES,      |
  |       while P and S form single bonds and are SOLIDS (P4 and S8).    |
  |                                                                      |
  |   4.  HABER                                                          |
  |       N2 + 3 H2 <=> 2 NH3,  dH = -46.1 kJ                            |
  |       200 atm , 700 K , Fe catalyst , K2O + Al2O3 promoters          |
  |       High pressure because 4 mol -> 2 mol. 700 K is a COMPROMISE.   |
  |                                                                      |
  |   5.  OSTWALD - the three lines                                      |
  |       4 NH3 + 5 O2 --(Pt/Rh, 500 K, 9 bar)--> 4 NO + 6 H2O           |
  |       2 NO + O2 --> 2 NO2                                            |
  |       3 NO2 + H2O --> 2 HNO3 + NO       (68 % azeotrope)             |
  |                                                                      |
  |   6.  CONTACT                                                        |
  |       2 SO2 + O2 <=(V2O5, 720 K, 2 bar)=> 2 SO3,  dH = -196.6 kJ     |
  |       SO3 + H2SO4 --> H2S2O7 (OLEUM) ;  H2S2O7 + H2O --> 2 H2SO4     |
  |       NEVER put SO3 straight into water - it makes an acid FOG.      |
  |                                                                      |
  |   7.  DEACON                                                         |
  |       4 HCl + O2 --(CuCl2, 723 K)--> 2 Cl2 + 2 H2O                   |
  |                                                                      |
  |   8.  COPPER WITH NITRIC ACID                                        |
  |       3 Cu + 8 HNO3(dil)  --> 3 Cu(NO3)2 + 2 NO  + 4 H2O             |
  |         Cu + 4 HNO3(conc) -->   Cu(NO3)2 + 2 NO2 + 2 H2O             |
  |       CONCENTRATED always gives BROWN NO2. NEVER hydrogen.           |
  |                                                                      |
  |   9.  PCl5 HYDROLYSIS                                                |
  |       PCl5 + H2O(limited) --> POCl3 + 2 HCl                          |
  |       PCl5 + 4 H2O(excess) --> H3PO4 + 5 HCl                         |
  |       Solid PCl5 is IONIC: [PCl4]+ [PCl6]-  (sp3 and sp3d2)          |
  |       Gas PCl5 is TRIGONAL BIPYRAMIDAL sp3d, axial 240 pm            |
  |       longer/weaker than equatorial 202 pm.                          |
  |                                                                      |
  |  10.  BASICITY OF THE PHOSPHORUS OXOACIDS = number of O-H groups     |
  |       H3PO2  +1  2 P-H  MONObasic  strong reducer                    |
  |       H3PO3  +3  1 P-H  DIbasic    reducer                           |
  |       H3PO4  +5  0 P-H  TRIbasic   NOT a reducer                     |
  |                                                                      |
  |  11.  OZONE                                                          |
  |       3 O2 --(silent electric discharge)--> 2 O3,  dH = +142 kJ      |
  |       ANGULAR, sp2, 117 deg, both bonds 128 pm EQUAL (resonance).    |
  |       Test: PbS + 4 O3 --> PbSO4 + 4 O2  (black to white).           |
  |                                                                      |
  |  12.  THE THREE FACES OF H2SO4                                       |
  |       ACID       : 2 NaCl + H2SO4 --> Na2SO4 + 2 HCl                 |
  |       DEHYDRATING: C12H22O11 --(conc H2SO4)--> 12 C + 11 H2O         |
  |       OXIDISING  : Cu + 2 H2SO4 --> CuSO4 + SO2 + 2 H2O              |
  |                                                                      |
  |  13.  BLEACHING                                                      |
  |       Cl2 + H2O --> 2 HCl + [O]     OXIDATION -> PERMANENT           |
  |       SO2 + 2 H2O --> H2SO4 + 2[H]  REDUCTION -> TEMPORARY           |
  |       Chlorine needs MOISTURE; dry chlorine does not bleach.         |
  |                                                                      |
  |  14.  THE TWO FLUORINE ANOMALIES                                     |
  |       egH:  Cl > F > Br > I    (F's 2p shell is small and crowded)   |
  |       B.E.: Cl2 > Br2 > F2 > I2 (lone pair repulsion in tiny F2)     |
  |       And yet F2 is still the STRONGEST oxidising agent.             |
  |                                                                      |
  |  15.  THE FOUR XENON SHAPES                                          |
  |       XeF2  LINEAR              sp3d    (3 lone pairs)               |
  |       XeF4  SQUARE PLANAR       sp3d2   (2 lone pairs)               |
  |       XeF6  DISTORTED OCTAHEDRAL sp3d3  (1 lone pair)                |
  |       XeO3  PYRAMIDAL           sp3     (1 lone pair)                |
  |       (bonus: XeOF4 SQUARE PYRAMIDAL sp3d2, 1 lone pair)             |
