# p-Block Elements — Groups 15 to 18 — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The wording changes every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps to write
- **TRAP** — where the marks get lost

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   READ THIS FIRST                                                    |
  |                                                                      |
  |   This chapter has NO numericals. Not one. So the "method" for       |
  |   almost every pattern is the same thing:                            |
  |                                                                      |
  |        WRITE THESE EXACT POINTS, IN THIS EXACT ORDER.                |
  |                                                                      |
  |   That is very good news for a weak student. You cannot make an      |
  |   arithmetic mistake in a chapter with no arithmetic. Every mark     |
  |   here is a MEMORY mark, and memory can be built in an evening.      |
  |                                                                      |
  |   THE FOUR THINGS THE EXAMINER PAYS FOR:                             |
  |        1. a BALANCED equation with CONDITIONS on the arrow           |
  |        2. an ORDER (A > B > C) with a one-line REASON                |
  |        3. a SHAPE plus its HYBRIDISATION                             |
  |        4. a labelled DIAGRAM or flow chart                           |
  |                                                                      |
  |   An equation with a bare arrow loses half a mark EVERY TIME.        |
  |   Write the catalyst, the temperature and the pressure. Even         |
  |   "high pressure" earns more than a blank arrow.                     |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  PATTERN 1 — DEFINE THE INERT PAIR EFFECT                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the inert pair effect?"
            "Why is the +3 state more stable than +5 down group 15?"
            "Why is Bi(V) a stronger oxidising agent than Sb(V)?"
  METHOD    1. Write the definition WORD FOR WORD:
               "The reluctance of the ns2 electron pair to take part in
                bond formation, because the nucleus is poorly shielded
                by the intervening d and f electrons, is called the
                INERT PAIR EFFECT."
            2. State the consequence:
               "As a result, the stability of the LOWER oxidation state
                (group valency minus 2) INCREASES down the group."
            3. GIVE AN EXAMPLE - this is worth a full mark:
                  group 15   BiCl3 is stable, BiCl5 hardly exists
                  group 14   Pb2+ beats Pb4+ ; PbO2 is a strong oxidiser
                  group 13   Tl+ beats Tl3+
            4. If the question is about OXIDISING POWER, add:
               "An unstable HIGH oxidation state is desperate to fall
                back down, and to fall it must ACCEPT electrons - which
                is exactly what an oxidising agent does."
  TRAP      Writing only "the s electrons do not take part". You must
            say WHY - POOR SHIELDING by d and f electrons. And you must
            give an EXAMPLE. Definition alone = 1 mark out of 2.
```

```
  PATTERN 2 — EXPLAIN A TREND DOWN A GROUP                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the trend in ionisation enthalpy / electronegativity
            / metallic character / atomic radius in group 15 (or 16, 17,
            18)."
  METHOD    1. State the DIRECTION first: "It INCREASES / DECREASES."
            2. Give the ONE cause: "because a new shell is added at every
               step, so the atom gets bigger and shielding increases."
            3. Give the CONSEQUENCE line that the property needs:
                  radius UP        -> new shell each step
                  IE DOWN          -> bigger atom, more shielding
                  EN DOWN          -> weaker pull on the shared pair
                  metallic UP      -> IE falls, electrons given up easily
                  catenation DOWN  -> E-E bond gets longer and weaker
            4. Quote the first and last member as evidence:
                  "N is a non-metal, Bi is a metal."
  TRAP      Do not write "because size increases" and stop. The examiner
            wants size AND shielding AND what that does to the electron.
            Also remember the ONE anomaly worth marks:
               IE of N > IE of O, because ns2 np3 is EXACTLY HALF FILLED
               and therefore extra stable.
```

```
  PATTERN 3 — ANOMALOUS BEHAVIOUR OF THE FIRST MEMBER         2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why does nitrogen differ from the rest of group 15?"
            "Why is N2 a gas but P a solid?"
            "Why does oxygen differ from sulphur?"
            "Why does NCl5 not exist while PCl5 does?"
  METHOD    1. ALWAYS open with the THREE UNIVERSAL REASONS:
                  (i)   SMALL ATOMIC SIZE
                  (ii)  HIGH ELECTRONEGATIVITY and high ionisation
                        enthalpy
                  (iii) ABSENCE OF d ORBITALS in the valence shell
            2. Then apply reason (iii) to whatever was asked:
                  no d orbitals -> the octet CANNOT be expanded ->
                  maximum covalency of N is 4 -> NCl5 impossible.
            3. Then apply reason (i):
                  small size -> sideways p-orbital overlap is possible
                  -> N forms p-pi - p-pi MULTIPLE bonds.
                  So N2 is a small discrete molecule with a TRIPLE bond
                  -> a GAS. Phosphorus is too big for sideways overlap,
                  so it forms SINGLE bonds and builds a P4 tetrahedron
                  -> a SOLID.
            4. Same argument, word for word, for O2 (gas, O=O) versus
               S8 (solid, crown ring of single bonds).
  TRAP      Forgetting to name the bond type. The examiner is looking
            for the exact phrase "p-pi - p-pi multiple bonding". Write it.
```

```
  PATTERN 4 — BOND ANGLE ORDER WITH REASON                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange NH3, PH3, AsH3, SbH3 in order of bond angle and
            give the reason."   Or the same for H2O, H2S, H2Se, H2Te.
  METHOD    1. Write the order WITH the numbers:
                  NH3 107.8 > PH3 93.6 > AsH3 91.8 > SbH3 91.3 > BiH3 ~90
                  H2O 104.5 > H2S 92.1 > H2Se 91 > H2Te 90
            2. Give BOTH halves of the reason - each is worth a mark:
               (i)  ELECTRONEGATIVITY of the central atom FALLS down the
                    group. In NH3 the very electronegative N pulls the
                    bond pairs CLOSE to itself, so they crowd each other
                    and repel strongly, opening the angle out.
                    Lower down, the bond pairs sit far away near the H
                    atoms, repel very little, and the angle collapses.
               (ii) HYBRIDISATION dies out. NH3 is properly sp3
                    (ideal 109.5, cut to 107.8 by the lone pair). PH3 and
                    below use almost PURE p ORBITALS, which are 90 deg
                    apart - which is what is observed.
            3. If asked why NH3 is 107.8 and not 109.5, add:
                  the LONE PAIR repels the bond pairs harder than they
                  repel each other  (lp-lp > lp-bp > bp-bp).
  TRAP      Giving only the electronegativity half. Two-part reason,
            two marks. Also do not confuse this with NH3 (107.8) vs
            NF3 (102.5) - there the bond pairs are pulled AWAY towards
            F, so they repel LESS and the angle CLOSES.
```

```
  PATTERN 5 — THE BOILING POINT ANOMALY                           2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why does NH3 have a higher boiling point than PH3?"
            "Why is H2O a liquid but H2S a gas?"
            "Why is HF a liquid but HCl a gas?"
  METHOD    1. Name the cause immediately: INTERMOLECULAR HYDROGEN
               BONDING.
            2. Justify it: N (or O, or F) is SMALL and HIGHLY
               ELECTRONEGATIVE, so the N-H bond is strongly polar and
               the hydrogen carries a large partial positive charge.
               That H is attracted to the LONE PAIR of the next molecule.
            3. Say what that costs: these hydrogen bonds must be BROKEN
               before the liquid can boil, so a lot of extra energy is
               needed.
            4. Contrast: P (2.1) has almost the same electronegativity
               as H (2.1), so the P-H bond is essentially NON-POLAR and
               PH3 has only weak van der Waals forces.
            5. Quote the numbers if you can: NH3 239.7 K, PH3 185.5 K.
  TRAP      Then being asked for the FULL ORDER and writing
            NH3 > PH3 > AsH3 > SbH3. WRONG. After NH3 the boiling points
            RISE again with molecular size, so the true order is
                  NH3 > SbH3 > AsH3 > PH3     (a V-shape)
```

```
  PATTERN 6 — WHY IS NF3 LESS BASIC THAN NH3?                     2 marks
  ------------------------------------------------------------------------
  TRIGGER   "NH3 is basic but NF3 is not. Explain."
            "Compare the basicity of NH3 and NF3."
  METHOD    1. Define basicity for this context: the willingness of the
               LONE PAIR on nitrogen to be DONATED.
            2. NH3: H (EN 2.1) is LESS electronegative than N (EN 3.0),
               so the H atoms PUSH electron density TOWARDS nitrogen.
               The lone pair is rich, loosely held, easily donated.
               -> STRONGLY BASIC.
            3. NF3: F (EN 4.0) is MORE electronegative than N, so the F
               atoms PULL electron density AWAY from nitrogen (-I
               effect). The lone pair is contracted and reluctant to be
               donated. -> VERY WEAKLY BASIC.
            4. Bonus mark: dipole moments. NH3 = 1.46 D, NF3 = 0.24 D.
               In NF3 the bond dipoles and the lone-pair dipole point in
               OPPOSITE directions and partly cancel.
  TRAP      Writing "F is more electronegative" and stopping. You must
            say WHICH WAY the electron density moves and WHAT that does
            to the LONE PAIR. The lone pair is the whole answer.
```

```
  PATTERN 7 — THE TWO FLUORINE ANOMALIES                          2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is the electron gain enthalpy of F less negative than
            that of Cl?"
            "Why is the bond dissociation enthalpy of F2 lower than that
            of Cl2?"
            "F2 is the strongest oxidising agent although its bond
            enthalpy is low. Explain."
  METHOD    (a) ELECTRON GAIN ENTHALPY
                1. F is EXTREMELY SMALL, so its 2p subshell is compact
                   and crowded.
                2. The incoming electron feels STRONG INTER-ELECTRONIC
                   REPULSION, so less energy is released.
                3. ORDER:  Cl > F > Br > I   (most negative first).
            (b) BOND DISSOCIATION ENTHALPY
                1. The two F atoms are tiny, so the F-F bond is very
                   SHORT.
                2. The three lone pairs on each atom are forced close
                   together and REPEL strongly, weakening the bond.
                3. ORDER:  Cl2 > Br2 > F2 > I2.
            (c) WHY F2 IS STILL THE BEST OXIDISER
                low bond enthalpy (easy to split) PLUS the very high
                hydration enthalpy of the tiny F- ion. Both favour
                F2 + 2e- -> 2F- overwhelmingly.
  TRAP      Mixing the two orders up. They are DIFFERENT:
                egH        Cl > F  > Br > I
                bond enth. Cl2 > Br2 > F2 > I2
            In one F is second, in the other F2 is third.
```

```
  PATTERN 8 — WHY ARE THE NOBLE GASES INERT?                  2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why are noble gases chemically inert / monoatomic?"
            "Why does xenon form compounds but helium does not?"
  METHOD    THREE points, one mark each if the question is worth more:
            1. COMPLETELY FILLED outermost shell, ns2 np6 (He = 1s2) -
               the most stable arrangement possible.
            2. VERY HIGH IONISATION ENTHALPY - the highest in each
               period - so they will not LOSE an electron.
            3. POSITIVE ELECTRON GAIN ENTHALPY - energy must be supplied
               to push an electron in - so they will not GAIN one.
            Conclusion line: no urge to lose, gain or share -> no bonds
            -> MONOATOMIC gases.
            FOR XENON add: Xe is LARGE and its outer electrons are
            poorly shielded, so its ionisation enthalpy is LOW ENOUGH
            for the two most oxidising elements - FLUORINE and OXYGEN -
            to strip electrons from it.
            (Neil Bartlett, 1962:  Xe + PtF6 -> Xe+[PtF6]- )
  TRAP      Saying only "their octet is complete". That is one point out
            of three. Add the ionisation enthalpy and the electron gain
            enthalpy.
```

```
  PATTERN 9 — LABORATORY PREPARATION OF A GAS                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is N2 / NH3 / PH3 / O2 / O3 / SO2 / Cl2 / HCl prepared
            in the laboratory? Give the equation."
  METHOD    1. Write the BALANCED equation with the CONDITION on the
               arrow.
            2. Add one line on how the gas is DRIED or COLLECTED if the
               question is worth 4.
            THE LIST TO MEMORISE:
               N2   NH4Cl + NaNO2 --(heat)--> N2 + 2 H2O + NaCl
                    (very pure N2: Ba(N3)2 --(heat)--> Ba + 3 N2)
               NH3  2 NH4Cl + Ca(OH)2 --(heat)--> 2 NH3 + 2 H2O + CaCl2
                    DRIED OVER QUICK LIME, CaO
               PH3  Ca3P2 + 6 H2O --> 3 Ca(OH)2 + 2 PH3
               O2   2 KClO3 --(MnO2, heat)--> 2 KCl + 3 O2
               O3   3 O2 <=(silent electric discharge)=> 2 O3
               SO2  Na2SO3 + H2SO4(dil) --> Na2SO4 + H2O + SO2
               Cl2  MnO2 + 4 HCl --(heat)--> MnCl2 + Cl2 + 2 H2O
               HCl  NaCl + H2SO4 --(420 K)--> NaHSO4 + HCl
  TRAP      Ammonia is dried over QUICKLIME ONLY. Never over conc.
            H2SO4, P4O10 or CaCl2 - all three REACT with the basic
            ammonia. This exact point is asked as a 2-marker.
            And ozone needs a SILENT discharge, not a spark - a spark
            makes heat, and heat decomposes the endothermic ozone.
```

```
  PATTERN 10 — THE HABER PROCESS, IN FULL                         8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Describe the manufacture of ammonia by the Haber process
            with conditions and justify them."
  METHOD    1. THE EQUATION with all the data:
                  N2(g) + 3 H2(g) <==> 2 NH3(g)
                  dH = - 46.1 kJ/mol (EXOTHERMIC)
                  dS is NEGATIVE (4 mol of gas -> 2 mol of gas)
            2. THE FOUR CONDITIONS:
                  PRESSURE     200 atm
                  TEMPERATURE  700 K
                  CATALYST     iron (finely divided / iron oxide)
                  PROMOTERS    K2O and Al2O3
            3. JUSTIFY EACH BY LE CHATELIER - this is the real marks:
               (a) HIGH PRESSURE: 4 moles of gas become 2, so squeezing
                   the system pushes it to the side with FEWER
                   molecules - the right - and more NH3 forms.
               (b) 700 K IS A COMPROMISE: the reaction is exothermic, so
                   a LOW temperature gives the best YIELD, but at low
                   temperature the N(triple)N bond (941 kJ/mol) will not
                   break and the RATE is hopeless. Write the word
                   "OPTIMUM" or "COMPROMISE".
               (c) CATALYST: lowers the ACTIVATION ENERGY so equilibrium
                   is reached FASTER. It speeds the forward and backward
                   reactions EQUALLY, so it does NOT change the yield or
                   Kp. Promoters improve its efficiency and life.
               (d) NH3 IS REMOVED CONTINUOUSLY: cooling liquefies NH3
                   (b.p. 239.7 K) while N2 and H2 stay gaseous. Removing
                   a PRODUCT shifts the equilibrium right. Unreacted
                   gases are RECYCLED.
            4. DRAW THE FLOW DIAGRAM - compressor, catalyst chamber,
               condenser, recycle loop. Worth about 2 of the 8 marks.
  TRAP      Saying "low temperature is used because the reaction is
            exothermic". It is NOT low - it is 700 K, deliberately
            higher than ideal, for the sake of RATE. That single
            sentence is what separates a 5 from an 8.
```

```
  PATTERN 11 — THE OSTWALD PROCESS                            4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is nitric acid manufactured?" / "Ostwald process"
  METHOD    THREE steps, one equation each:
            STEP 1  CATALYTIC OXIDATION OF AMMONIA
                4 NH3 + 5 O2 --(Pt/Rh gauze, 500 K, 9 bar)--> 4 NO + 6 H2O
                Contact time about a MILLISECOND - longer and the NO
                decomposes back to N2. Exothermic and self-sustaining;
                the gauze glows red hot.
            STEP 2  OXIDATION OF NITRIC OXIDE (cool to ~300 K first)
                2 NO + O2 <==> 2 NO2
                Favoured by LOW temperature and HIGH pressure.
                Colourless NO turns BROWN.
            STEP 3  ABSORPTION IN WATER
                3 NO2 + H2O --> 2 HNO3 + NO
                The NO is fed BACK into step 2 - nothing is wasted.
            CONCENTRATION: the acid is 68 % by mass, which is an
            AZEOTROPE (b.p. 393 K), so distillation cannot go further.
            To reach 98 % you DEHYDRATE it with concentrated H2SO4.
  TRAP      Writing the catalyst as "Pt" only. It is PLATINUM-RHODIUM
            GAUZE. And do not forget the word AZEOTROPE - it is often
            a separate mark.
```

```
  PATTERN 12 — THE CONTACT PROCESS                            4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is sulphuric acid manufactured?" / "Contact process"
  METHOD    FIVE steps:
            1. GET SO2:   S + O2 --> SO2
                          4 FeS2 + 11 O2 --> 2 Fe2O3 + 8 SO2
            2. PURIFY AND DRY THE SO2. Dust and especially ARSENIC
               compounds POISON the catalyst. (Students skip this step
               and lose a whole mark.)
            3. CATALYTIC OXIDATION - the heart of it:
                  2 SO2 + O2 <=(V2O5, 720 K, 2 bar)=> 2 SO3
                  dH = - 196.6 kJ/mol
            4. ABSORB SO3 IN CONC. H2SO4:
                  SO3 + H2SO4 --> H2S2O7   (OLEUM)
            5. DILUTE THE OLEUM:
                  H2S2O7 + H2O --> 2 H2SO4   (96-98 %)
            THE TWO STANDARD FOLLOW-UPS:
            (a) Why is SO3 not put straight into water? Because
                SO3 + H2O is VIOLENTLY exothermic and throws up a dense
                choking MIST of acid droplets that cannot be collected.
            (b) Justify the conditions: exothermic and 3 mol -> 2 mol,
                so LOW temperature and HIGH pressure favour the yield -
                but 720 K is the COMPROMISE for rate, and 2 bar is
                enough because conversion is already about 97 %.
  TRAP      Forgetting the OLEUM step and writing SO3 + H2O -> H2SO4 as
            the industrial step. That is the one thing the process
            deliberately avoids.
```

```
  PATTERN 13 — DEACON'S PROCESS                                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is Deacon's process?" / "How is chlorine manufactured?"
  METHOD    1. The equation with conditions:
                  4 HCl + O2 --(CuCl2, 723 K)--> 2 Cl2 + 2 H2O
            2. The point of it: HCl is a cheap WASTE product of organic
               chlorination plants, and this turns waste back into
               valuable chlorine.
            3. If asked for the modern route as well:
                  2 NaCl + 2 H2O --(electrolysis of brine)-->
                       2 NaOH + Cl2 (at the ANODE) + H2 (at the cathode)
  TRAP      Writing Ni as the catalyst. Ni + CO is the MOND process
            from the metallurgy chapter. Deacon = CUPRIC CHLORIDE.
```

```
  PATTERN 14 — METAL + NITRIC ACID: WHICH GAS?                2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What happens when Cu reacts with dilute / concentrated
            HNO3?"  "Why does HNO3 not give hydrogen with metals?"
  METHOD    1. Identify DILUTE or CONCENTRATED, and the metal.
            2. Apply the rule:
                  CONCENTRATED -> always NO2 (dense reddish BROWN fumes)
                  DILUTE + a noble-ish metal (Cu) -> NO (colourless,
                          turns brown at the tube mouth: 2 NO + O2 ->
                          2 NO2)
                  DILUTE + an active metal (Zn) -> N2O
            3. Write the balanced equation:
                  3 Cu + 8 HNO3(dil)  -> 3 Cu(NO3)2 + 2 NO  + 4 H2O
                    Cu + 4 HNO3(conc) ->   Cu(NO3)2 + 2 NO2 + 2 H2O
                  4 Zn + 10 HNO3(dil) -> 4 Zn(NO3)2 + N2O + 5 H2O
                    Zn + 4 HNO3(conc) ->   Zn(NO3)2 + 2 NO2 + 2 H2O
            4. If asked WHY NO HYDROGEN: HNO3 is a powerful OXIDISING
               AGENT; the NO3- ion is a better electron acceptor than
               H+, so NO3- is reduced instead of H+.
            5. PASSIVITY, if asked: Cr, Al and Fe are made PASSIVE by
               conc. HNO3 because a thin, tough OXIDE LAYER forms.
  TRAP      Writing H2 as a product. Never, except with very dilute
            HNO3 and Mg or Mn. Also remember Au and Pt need AQUA REGIA.
```

```
  PATTERN 15 — WHITE vs RED PHOSPHORUS                        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is white phosphorus more reactive than red?"
            "Why is white phosphorus stored under water?"
            "Compare the allotropes of phosphorus."
  METHOD    1. STRUCTURE first - the reason lives there:
               White P is discrete P4 TETRAHEDRA. The P-P-P angle is
               forced down to 60 degrees, far below the natural
               90-109 deg, so the bonds are severely BENT and carry a
               large ANGULAR STRAIN. Strained bonds break easily
               -> HIGH REACTIVITY.
               Red P is POLYMERIC - the tetrahedra are opened up and
               linked into long chains, which RELIEVES the strain
               -> LOW REACTIVITY.
            2. FOR "STORED UNDER WATER": its ignition temperature is
               only 303 K (30 deg C), below a normal summer room
               temperature, so in air it would spontaneously catch fire.
               It is insoluble in water, so water keeps the air away.
            3. FOR A COMPARISON TABLE, cover these rows:
                  structure, smell, toxicity, solubility in CS2,
                  ignition temperature, glow in the dark, stability.
                  White: garlic smell, VERY POISONOUS, soluble in CS2,
                         303 K, GLOWS, least stable.
                  Red:   odourless, non-poisonous, insoluble in CS2,
                         543 K, no glow, more stable.
  TRAP      Saying "white P is more reactive because it is a molecule".
            The mark is for the words ANGULAR STRAIN and 60 DEGREES.
```

```
  PATTERN 16 — ALLOTROPES OF SULPHUR / TRANSITION TEMPERATURE  2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the transition temperature of sulphur?"
            "Distinguish rhombic and monoclinic sulphur."
  METHOD    1. TRANSITION TEMPERATURE = 369 K (96 deg C).
               Definition: the temperature at which the two allotropic
               forms are in EQUILIBRIUM and are interconvertible.
                  rhombic (alpha) <=(369 K)=> monoclinic (beta)
            2. Rhombic is stable BELOW 369 K (octahedral crystals,
               yellow, density 2.06). Monoclinic is stable ABOVE 369 K
               (needle shaped, pale yellow, density 1.98).
            3. THE POINT THAT EARNS THE SECOND MARK: BOTH forms contain
               the SAME S8 CROWN-SHAPED RING (S-S-S angle 105 deg,
               bond length 204 pm). Only the PACKING of the rings in the
               crystal differs.
  TRAP      Saying the two forms have different molecules. They do not.
            Bonus fact: at above 1000 K sulphur exists as S2, which is
            PARAMAGNETIC like O2 (two unpaired electrons in pi* orbitals).
```

```
  PATTERN 17 — PCl5: STRUCTURE AND HYDROLYSIS                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Describe the structure of PCl5." / "Why are the axial bonds
            longer?" / "What happens when PCl5 is hydrolysed?"
  METHOD    1. GAS PHASE: TRIGONAL BIPYRAMIDAL, sp3d.
                  3 EQUATORIAL P-Cl bonds = 202 pm (shorter, stronger)
                  2 AXIAL      P-Cl bonds = 240 pm (longer,  weaker)
            2. WHY: each AXIAL bond is repelled by THREE equatorial bond
               pairs at 90 deg, whereas each EQUATORIAL bond is repelled
               by only TWO at 90 deg. More repulsion -> the axial bonds
               are pushed out longer and are WEAKER. This is why PCl5 is
               so reactive and why it decomposes on heating:
                  PCl5 --(heat)--> PCl3 + Cl2
            3. SOLID STATE: IONIC, [PCl4]+ [PCl6]-
                  [PCl4]+  TETRAHEDRAL  sp3
                  [PCl6]-  OCTAHEDRAL   sp3d2
               (Solid PBr5 is [PBr4]+ Br- - six big Br will not fit.)
            4. HYDROLYSIS - both stages:
                  LIMITED water:  PCl5 + H2O   -> POCl3 + 2 HCl
                  EXCESS  water:  PCl5 + 4 H2O -> H3PO4 + 5 HCl
               Why it hydrolyses so easily: P has VACANT 3d ORBITALS
               which accept the lone pair of water. Nitrogen has none,
               which is why NF3 is not hydrolysed.
  TRAP      Giving only the excess-water equation when the question says
            "limited amount of water". POCl3 (phosphoryl chloride) is
            the answer there, and it is a favourite one-mark trap.
```

```
  PATTERN 18 — OXOACIDS OF PHOSPHORUS: STRUCTURE AND BASICITY     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Draw the structures of H3PO2, H3PO3 and H3PO4 and give
            their basicity." / "Why is H3PO3 dibasic though it has three
            hydrogens?" / "Why is H3PO4 not a reducing agent?"
  METHOD    1. STATE THE GOLDEN RULE:
                  BASICITY = the number of O-H groups.
               A hydrogen bonded straight to PHOSPHORUS cannot leave as
               H+, because P (2.1) and H (2.1) have almost the same
               electronegativity, so the P-H bond is NON-POLAR.
            2. DRAW ALL THREE - the marks are in the P-H bonds:

                    O                  O                    O
                    ||                 ||                   ||
                H - P - OH         H - P - OH          HO - P - OH
                    |                  |                    |
                    H                  OH                   OH

                 H3PO2  +1          H3PO3  +3           H3PO4  +5
                 2 P-H, 1 O-H       1 P-H, 2 O-H        0 P-H, 3 O-H
                 MONOBASIC          DIBASIC             TRIBASIC
            3. REDUCING POWER comes from the P-H BOND:
                  H3PO2 (2 P-H) > H3PO3 (1 P-H) > H3PO4 (none, NOT a
                  reducing agent). Also P is already at its maximum +5
                  in H3PO4, so it cannot be oxidised further.
               Evidence equation:
                  4 AgNO3 + 2 H2O + H3PO2 -> 4 Ag + 4 HNO3 + H3PO4
            4. DISPROPORTIONATION ON HEATING:
                  4 H3PO3 --(heat)--> 3 H3PO4 + PH3
  TRAP      Counting the hydrogens in the FORMULA. All three have three
            hydrogens; only the position matters. Draw before you count.
```

```
  PATTERN 19 — OZONE: PREPARATION, STRUCTURE, TESTS               4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is ozone prepared?" / "Why is a silent electric
            discharge used?" / "Why are both O-O bonds in ozone equal?"
            / "Give two tests for ozone."
  METHOD    1. PREPARATION:
                  3 O2 <=(silent electric discharge)=> 2 O3
                  dH = +142 kJ/mol (ENDOTHERMIC)
               WHY SILENT AND NOT A SPARK: a spark produces a lot of
               HEAT; ozone is endothermic and unstable, so heat would
               decompose it straight back to O2.
               Yield about 10 % ("ozonised oxygen").
            2. STRUCTURE: ANGULAR / BENT, sp2, ONE lone pair on the
               central O, bond angle 117 deg, both O-O bonds 128 pm.
               WHY EQUAL: ozone is a RESONANCE HYBRID; the double bond
               is DELOCALISED over both bonds, so each is identical and
               its length lies BETWEEN a single O-O (148 pm) and a
               double O=O (121 pm).
               Non-zero dipole moment (0.53 D) proves it is bent.
            3. TESTS:
                  PbS + 4 O3 --> PbSO4 + 4 O2    (BLACK to WHITE)
                  Hg + O3 --> HgO + O2   TAILING OF MERCURY - the shiny
                        mobile mercury goes dull and sticks to the glass
            4. ESTIMATION:
                  O3 + 2 KI + H2O --> 2 KOH + I2 + O2
                  Titrate the liberated iodine against standard sodium
                  thiosulphate with starch as the indicator.
            5. OZONE HOLE, if asked:
                  CF2Cl2 --(UV)--> Cl* + CF2Cl*
                  Cl* + O3 --> ClO* + O2 ;  ClO* + O --> Cl* + O2
                  The Cl radical is REGENERATED, so one Cl atom destroys
                  thousands of ozone molecules.
  TRAP      Writing "electric spark". The word SILENT is worth a mark
            on its own, and the reason (no heat) is worth another.
```

```
  PATTERN 20 — BLEACHING: CHLORINE vs SULPHUR DIOXIDE         2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the bleaching action of chlorine."
            "Why is the bleaching by SO2 temporary?"
            "Why does dry chlorine not bleach?"
  METHOD    CHLORINE - three lines:
                  Cl2 + H2O  -->  HCl + HOCl
                  HOCl       -->  HCl + [O]     <- NASCENT OXYGEN
                  dye + [O]  -->  colourless
               Overall: Cl2 + H2O --> 2 HCl + [O]
               Chlorine bleaches by OXIDATION. The nascent oxygen
               DESTROYS the dye molecule, so the colour can never come
               back -> PERMANENT.
               MOISTURE IS ESSENTIAL - water is needed to make the HOCl,
               so DRY chlorine does not bleach at all.
            SULPHUR DIOXIDE - two lines:
                  SO2 + 2 H2O --> H2SO4 + 2 [H]  <- NASCENT HYDROGEN
                  dye + 2 [H] --> colourless
               SO2 bleaches by REDUCTION. It merely ADDS hydrogen to the
               dye without destroying it, so atmospheric OXYGEN
               re-oxidises it later and the ORIGINAL COLOUR RETURNS
               -> TEMPORARY.
            USES: Cl2 for cotton, linen, wood pulp, paper.
                  SO2 for delicate things chlorine would ruin - wool,
                  silk, straw.
  TRAP      Writing "chlorine bleaches by reduction". Half the class
            writes it. The nascent species is OXYGEN, and oxygen
            OXIDISES. If you can only remember one word, remember that
            Cl2 = OXIDATION = PERMANENT.
```

```
  PATTERN 21 — THE THREE FACES OF SULPHURIC ACID              4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the acidic, dehydrating and oxidising properties of
            H2SO4 with equations."
  METHOD    Head the answer with the three words, then two equations each.
            FACE 1 - STRONG DIBASIC ACID
                  H2SO4 + H2O -> H3O+ + HSO4- ;  HSO4- -> H3O+ + SO4 2-
                  Two series of salts: NaHSO4 (acid) and Na2SO4 (normal)
                  Displaces more volatile acids:
                     2 NaCl + H2SO4 --> Na2SO4 + 2 HCl
                     2 KNO3 + H2SO4 --> K2SO4 + 2 HNO3
            FACE 2 - DEHYDRATING AGENT (removes the ELEMENTS of water)
                  C12H22O11 --(conc. H2SO4)--> 12 C + 11 H2O  (sugar to
                        a swelling BLACK spongy carbon - the "black snake")
                  (COOH)2 --(conc. H2SO4)--> CO + CO2 + H2O
                  HCOOH   --(conc. H2SO4)--> CO + H2O
                  CuSO4.5H2O --> CuSO4 + 5 H2O  (BLUE to WHITE)
                  Note: sugar contains no water; H2SO4 pulls the H and O
                  OUT as water. That is what makes it DEHYDRATING rather
                  than merely drying.
            FACE 3 - OXIDISING AGENT (hot concentrated only, itself
                     reduced to SO2)
                  Cu + 2 H2SO4 --> CuSO4 + SO2 + 2 H2O
                  C  + 2 H2SO4 --> CO2 + 2 SO2 + 2 H2O
                  S  + 2 H2SO4 --> 3 SO2 + 2 H2O
            SAFETY LINE THE EXAMINER LIKES: always add ACID TO WATER
            slowly with stirring; dilution is strongly exothermic.
  TRAP      Being asked "why can HBr and HI not be made from KBr/KI and
            conc. H2SO4?" The answer is FACE 3 - the acid OXIDISES the
            product (2 HBr + H2SO4 -> Br2 + SO2 + 2 H2O). Use phosphoric
            acid instead.
```

```
  PATTERN 22 — CLASSIFY THE OXIDES                            2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Classify oxides with examples." / "What is an amphoteric
            oxide? Give the reactions." / "Which of these is neutral?"
  METHOD    1. Give the seven types with one example each:
                  ACIDIC      CO2, SO2, SO3, N2O5, P4O10, Cl2O7
                  BASIC       Na2O, CaO, MgO, BaO
                  AMPHOTERIC  Al2O3, ZnO, PbO, SnO2, BeO, As2O3
                  NEUTRAL     CO, NO, N2O, H2O
                  MIXED       Pb3O4 (= 2PbO + PbO2), Fe3O4 (= FeO+Fe2O3)
                  PEROXIDE    Na2O2, BaO2, H2O2   (O is -1)
                  SUPEROXIDE  KO2, RbO2, CsO2     (O is -1/2)
            2. For AMPHOTERIC you MUST write BOTH reactions:
                  ZnO + 2 HCl  --> ZnCl2 + H2O        (acting as a base)
                  ZnO + 2 NaOH --> Na2ZnO2 + H2O      (acting as an acid)
               Or for aluminium:
                  Al2O3 + 6 HCl + 9 H2O --> 2 [Al(H2O)6]3+ + 6 Cl-
                  Al2O3 + 6 NaOH + 3 H2O --> 2 Na3[Al(OH)6]
            3. The two trends:
                  ACROSS a period  BASIC -> AMPHOTERIC -> ACIDIC
                  DOWN a group     ACIDIC -> AMPHOTERIC -> BASIC
                  (both because of what happens to METALLIC CHARACTER)
  TRAP      Writing only ONE equation for an amphoteric oxide. The whole
            point of "amphoteric" is BOTH, so one equation is one mark.
```

```
  PATTERN 23 — INTERHALOGEN COMPOUNDS                             4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are interhalogen compounds? Give their types, shapes
            and hybridisation." / "Why are they more reactive than the
            halogens?"
  METHOD    1. DEFINITION: compounds formed between TWO DIFFERENT
               halogens, of general formula X X'n where n = 1, 3, 5 or 7
               (always ODD). X is the LARGER, less electronegative one.
            2. THE TABLE - draw it, it is most of the marks:
                  XX'   ClF, BrCl, ICl, IBr  LINEAR              sp3
                  XX'3  ClF3, BrF3, ICl3     BENT T-SHAPED       sp3d
                  XX'5  ClF5, BrF5, IF5      SQUARE PYRAMIDAL    sp3d2
                  XX'7  IF7                  PENTAGONAL BIPYR.   sp3d3
            3. WHY MORE REACTIVE (except F2): the X-X' bond joins two
               DIFFERENT atoms of different size and electronegativity,
               so it is POLAR and WEAKER than the pure non-polar X-X
               bond. A weaker bond breaks more easily.
            4. HYDROLYSIS gives the HALIDE of the SMALLER halogen and an
               OXOACID of the LARGER:
                  ClF3 + 2 H2O --> 3 HF + HClO2
            5. USES: fluorinating agents; ClF3 and BrF3 make UF6 for
               uranium enrichment:  U + 3 ClF3 --> UF6 + 3 ClF
  TRAP      Answering "trigonal planar" for XX'3. Three bonds plus TWO
            lone pairs can never be trigonal planar. XX'3 is a BENT T.
```

```
  PATTERN 24 — ACID STRENGTH OF THE HALOGEN OXOACIDS          2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange HOCl, HClO2, HClO3, HClO4 in order of acid strength
            and explain." / "Which is the strongest oxidising agent among
            them?"
  METHOD    1. ACID STRENGTH increases with the number of oxygens:
                  HOCl < HClO2 < HClO3 < HClO4
                   +1      +3      +5      +7
            2. TWO reasons, write both:
               (i)  each extra electronegative OXYGEN pulls electron
                    density off the O-H bond (-I effect), so H+ leaves
                    more easily;
               (ii) the anion left behind spreads its charge over MORE
                    oxygen atoms - better RESONANCE STABILISATION - so
                    the conjugate base is more stable.
            3. ACROSS the halogens with the SAME number of oxygens,
               compare ELECTRONEGATIVITY:
                  HOCl > HOBr > HOI  ;  HClO4 > HBrO4 > HIO4
            4. OXIDISING POWER RUNS THE OPPOSITE WAY:
                  HOCl > HClO2 > HClO3 > HClO4
               because the acid with the FEWEST oxygens releases oxygen
               most easily.
            5. FLUORINE forms only HOF, and even that is unstable - no d
               orbitals, no positive oxidation state.
  TRAP      Mixing the two ladders. HClO4 is the STRONGEST ACID but the
            WEAKEST OXIDISER of the four. Say it out loud twice.
```

```
  PATTERN 25 — XENON COMPOUNDS: PREPARATION AND STRUCTURE     4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "How are XeF2, XeF4 and XeF6 prepared?" / "Draw the
            structures of the xenon fluorides / XeO3 / XeOF4 and give
            the hybridisation."
  METHOD    1. PREPARATION - the ratios and conditions:
                  Xe : F2 =  2 : 1  --(673 K, 1 bar)-->      XeF2
                  Xe : F2 =  1 : 5  --(873 K, 7 bar)-->      XeF4
                  Xe : F2 =  1 : 20 --(573 K, 60-70 bar)-->  XeF6
                  XeF4 + O2F2 --(143 K)--> XeF6 + O2
            2. WORK OUT EACH SHAPE - do not just recite it:
                  lone pairs = (8 - number of bonds) / 2
                  XeF2  2 bp + 3 lp = 5 -> sp3d   -> LINEAR
                  XeF4  4 bp + 2 lp = 6 -> sp3d2  -> SQUARE PLANAR
                  XeF6  6 bp + 1 lp = 7 -> sp3d3  -> DISTORTED OCTAHEDRAL
                  XeO3  3 bp + 1 lp = 4 -> sp3    -> PYRAMIDAL
                  XeO4  4 bp + 0 lp = 4 -> sp3    -> TETRAHEDRAL
                  XeOF4 5 bp + 1 lp = 6 -> sp3d2  -> SQUARE PYRAMIDAL
            3. DRAW the pictures. Diagrams carry marks of their own.
            4. If asked about Lewis behaviour:
                  XeF6 + NaF  --> Na+[XeF7]-   (XeF6 ACCEPTS fluoride)
                  XeF2 + PF5  --> [XeF]+[PF6]- (XeF2 DONATES fluoride)
  TRAP      Saying XeF2 is "sp" because it is linear. Shape and
            hybridisation are decided separately: hybridisation from
            bp + lp, shape from bp only. XeF2 is LINEAR and sp3d.
            Also: XeF6 is DISTORTED octahedral, never a regular
            octahedron, because of that one lone pair.
```

```
  PATTERN 26 — HYDROLYSIS OF THE XENON FLUORIDES                  4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What happens when XeF2 / XeF4 / XeF6 is hydrolysed?"
            "Give an example of disproportionation in xenon chemistry."
  METHOD    Learn the five equations as a block:
                  2 XeF2 + 2 H2O   -->  2 Xe + 4 HF + O2
                  6 XeF4 + 12 H2O  -->  4 Xe + 2 XeO3 + 24 HF + 3 O2
                                        <- a DISPROPORTIONATION, because
                                        Xe(+4) goes BOTH to Xe(0) and
                                        Xe(+6)
                  XeF6 + 3 H2O(complete) -->  XeO3 + 6 HF
                  XeF6 + H2O (partial)   -->  XeOF4 + 2 HF
                  XeF6 + 2 H2O(partial)  -->  XeO2F2 + 4 HF
            Always name the disproportionation explicitly - it is often
            a separate mark.
  TRAP      Giving the complete-hydrolysis product when the question
            says "partial hydrolysis". XeF6 + 1 H2O gives XeOF4;
            XeF6 + 2 H2O gives XeO2F2. Count the water molecules in the
            question before you answer.
```

```
  PATTERN 27 — WORK OUT A SHAPE FROM SCRATCH (VSEPR)              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Give the shape and hybridisation of ClF3 / BrF5 / SO2 /
            NH3 / XeF4 / [PCl6]- ..."
  METHOD    THE FOUR-STEP MACHINE - it never fails:
            1. Count the VALENCE electrons of the CENTRAL atom.
            2. Subtract 1 for every atom singly bonded to it.
            3. What is left, divided by 2 = the number of LONE PAIRS.
            4. bond pairs + lone pairs = STERIC NUMBER:
                  2 -> sp     3 -> sp2    4 -> sp3
                  5 -> sp3d   6 -> sp3d2  7 -> sp3d3
               Then DELETE the lone pairs to read off the SHAPE.
            WORKED: XeF4. Xe has 8 valence electrons; 4 go into 4 Xe-F
            bonds, leaving 4 -> 2 LONE PAIRS. 4 + 2 = 6 -> sp3d2,
            octahedral electron geometry. The 2 lone pairs go opposite
            each other, so the 4 F atoms lie in a plane -> SQUARE PLANAR.
            LONE PAIRS ALWAYS TAKE EQUATORIAL POSITIONS in a trigonal
            bipyramid - that is why XeF2 is linear and ClF3 is a bent T.
  TRAP      Confusing ELECTRON GEOMETRY with SHAPE. XeF4 has an
            OCTAHEDRAL electron geometry but a SQUARE PLANAR shape.
            The question almost always wants the SHAPE.
```

```
  PATTERN 28 — AQUA REGIA                                         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is aqua regia? Why does it dissolve gold?"
  METHOD    1. COMPOSITION: 3 parts conc. HCl : 1 part conc. HNO3
               (by volume). Latin for "royal water".
            2. WHY IT WORKS - both halves earn marks:
               (i)  the HNO3 is a powerful OXIDISING AGENT and oxidises
                    the gold atom to its ion;
               (ii) the HCl supplies Cl- ions which lock that ion away
                    as a very stable COMPLEX, removing it from solution
                    and driving the reaction forward (Le Chatelier).
            3. The equation:
                  Au + 4 H+ + NO3- + 4 Cl- --> AuCl4- + NO + 2 H2O
            4. Uses: refining gold, dissolving noble metals, etching.
  TRAP      Writing the ratio the wrong way round. It is 3 HCl : 1 HNO3.
            Remember "more of the cheap one".
```

```
  PATTERN 29 — THE BROWN RING TEST                                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Describe the brown ring test." / "How do you detect the
            nitrate ion?"
  METHOD    1. Say the procedure: add freshly prepared FeSO4 solution to
               the nitrate solution, then add concentrated H2SO4 SLOWLY
               DOWN THE SIDE of the tube so it forms a separate layer.
            2. Write both equations:
                  NO3- + 3 Fe2+ + 4 H+ --> NO + 3 Fe3+ + 2 H2O
                  [Fe(H2O)6]2+ + NO --> [Fe(H2O)5(NO)]2+ + H2O
            3. State the observation: a BROWN RING appears at the
               JUNCTION of the two layers. That confirms NO3-.
  TRAP      Forgetting "down the side of the tube". Without the two
            separate layers there is no ring, and that phrase is what
            the examiner is scanning for.
```

```
  PATTERN 30 — HOLME'S SIGNAL AND MARSH GAS                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is Holme's signal?" / "Why does PH3 catch fire
            spontaneously?" / "Explain the will-o'-the-wisp."
  METHOD    1. Containers of CALCIUM PHOSPHIDE and CALCIUM CARBIDE are
               thrown into the sea. Water attacks both:
                  Ca3P2 + 6 H2O --> 3 Ca(OH)2 + 2 PH3
                  CaC2  + 2 H2O --> Ca(OH)2 + C2H2
            2. The PH3 carries traces of P2H4 (diphosphine), which make
               it SPONTANEOUSLY INFLAMMABLE.
            3. So the escaping acetylene catches fire and burns as a
               bright flame on the water - a signal to ships.
            4. The same trick explains MARSH GAS / will-o'-the-wisp
               flames over marshes and graveyards.
  TRAP      Forgetting to name P2H4. "Traces of P2H4 make PH3
            spontaneously inflammable" IS the answer - without it the
            story is not chemistry.
```

```
  PATTERN 31 — COMPLETE THE REACTION / WRITE THE EQUATION         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What happens when ... ?" / "Complete: PCl5 + H2O -> " /
            "Write the equation for ..."
  METHOD    1. Identify the REAGENT TYPE first - that fixes the product:
                  water on a halide     -> oxoacid + HX
                  water on a nitride/
                     phosphide/carbide  -> hydroxide + hydride gas
                  conc. HNO3 on a metal -> nitrate + NO2
                  hot conc. H2SO4       -> the oxidised product + SO2
                  cold dil. NaOH on Cl2 -> hypochlorite (+1)
                  hot conc. NaOH on Cl2 -> chlorate (+5)
            2. BALANCE it. Count each element on both sides.
            3. PUT THE CONDITIONS ON THE ARROW - heat, catalyst,
               concentration, temperature. Half a mark every time.
            4. Add the OBSERVATION if there is a famous one - brown
               fumes, white fumes, black to white, blue solution.
  TRAP      A bare unbalanced arrow. Also: "dilute" and "concentrated"
            are not decoration - they change the product completely
            (Cu + HNO3, Cl2 + NaOH, PCl5 + H2O all depend on it).
```

```
  PATTERN 32 — USES OF A COMPOUND OR ELEMENT                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write any four uses of ammonia / nitric acid / sulphuric
            acid / chlorine / the noble gases."
  METHOD    Write FOUR SHORT BULLETS. Never a paragraph.
               NH3     fertilisers (urea, ammonium sulphate), HNO3
                       manufacture, Solvay process, refrigerant
               HNO3    fertilisers, explosives (TNT, nitroglycerine),

               H2SO4   fertilisers (superphosphate of lime), petroleum

               Cl2     purifying drinking water, bleaching wood pulp and

               O3      germicide, sterilising water, bleaching oils and

               He      weather balloons (light and NON-flammable),
                       He-O2 for divers (avoids the "bends"), coolant
                       for MRI superconducting magnets
               Ne      neon signs and aircraft beacons
               Ar      inert atmosphere in welding, filling light bulbs
               Rn      radiotherapy for cancer
  TRAP      Giving vague uses like "used in industry". Name the actual
            product or the actual job. And for helium, the mark is for
```
