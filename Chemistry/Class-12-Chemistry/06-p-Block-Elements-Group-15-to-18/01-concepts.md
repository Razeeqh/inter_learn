# TOPIC 1 — What "p-block" means, and who lives there

The periodic table is split into blocks by **which orbital the last electron
enters**.

```
  s-BLOCK  ->  last electron enters an  s  orbital   (Groups 1, 2)
  p-BLOCK  ->  last electron enters a   p  orbital   (Groups 13 to 18)
  d-BLOCK  ->  last electron enters a   d  orbital   (Groups 3 to 12)
  f-BLOCK  ->  last electron enters an  f  orbital   (lanthanoids, actinoids)
```

A p subshell holds a maximum of **6 electrons**, so the p-block is exactly
**6 columns wide**. This chapter is the last four of those six columns.

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   GROUP 15   ns2 np3    N   P   As   Sb   Bi        "pnictogens"    |
  |              NITROGEN FAMILY                                        |
  |                                                                     |
  |   GROUP 16   ns2 np4    O   S   Se   Te   Po        "chalcogens"    |
  |              OXYGEN FAMILY                          (= ore forming) |
  |                                                                     |
  |   GROUP 17   ns2 np5    F   Cl  Br   I    At        "halogens"      |
  |              HALOGEN FAMILY                         (= salt makers) |
  |                                                                     |
  |   GROUP 18   ns2 np6    He  Ne  Ar   Kr   Xe   Rn   "noble gases"   |
  |              (helium is the odd one: 1s2, not ns2 np6)              |
  |                                                                     |
  +---------------------------------------------------------------------+
```

```
  MEMORY SENTENCES

    GROUP 15   "Nick Print As Sab Bina"          ->  N  P  As Sb Bi
    GROUP 16   "Oh Sir, Se Te Po"                ->  O  S  Se Te Po
    GROUP 17   "F Cl Br I At"  = "Fir Clear      ->  F  Cl Br I  At
                Bright Iodine Attack"
    GROUP 18   "He Never Argues, Krishna         ->  He Ne Ar Kr Xe Rn
                Xerox Ran"
```

## Why the group number tells you the configuration

```
  GROUP NUMBER  minus  10   =  number of valence electrons

      Group 15  ->  5 valence electrons  ->  ns2 np3
      Group 16  ->  6 valence electrons  ->  ns2 np4
      Group 17  ->  7 valence electrons  ->  ns2 np5
      Group 18  ->  8 valence electrons  ->  ns2 np6
```

That single rule saves you from memorising four separate things.

**WORKED EXAMPLE 1**

> **Q. Write the electronic configuration of arsenic (Z = 33) and state its group.**
>
> **ANSWER:**
>
> ```
>   Step 1: fill in order 1s 2s 2p 3s 3p 4s 3d 4p
>
>       As (33)  =  1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p3
>
>   Step 2: write it in shorthand using the previous noble gas (Ar, Z = 18)
>
>       As (33)  =  [Ar] 3d10 4s2 4p3
>
>   Step 3: the valence shell is  4s2 4p3  ->  5 valence electrons
>           ->  GROUP 15,  PERIOD 4.
> ```

> **TRAP:** Helium is in Group 18 but its configuration is **1s2**, not ns2 np6.
> It has no p electrons at all. If a question says "the general configuration of
> Group 18 is ns2 np6", you must add "**except helium, which is 1s2**". That
> single phrase has been worth a mark many times.

# TOPIC 2 — Group 15: who they are and where they are found

```
  ELEMENT     Z     CONFIGURATION        NATURE
  ---------------------------------------------------------------
  N   (7)     7     [He] 2s2 2p3         non-metal  (a GAS)
  P   (15)   15     [Ne] 3s2 3p3         non-metal  (a SOLID)
  As  (33)   33     [Ar] 3d10 4s2 4p3    METALLOID
  Sb  (51)   51     [Kr] 4d10 5s2 5p3        METALLOID
  Bi  (83)   83     [Xe] 4f14 5d10 6s2 6p3   METAL
```

```
  METALLIC CHARACTER INCREASES DOWN THE GROUP:

     N , P        As , Sb          Bi
     |            |                |
     NON-METALS   METALLOIDS       METAL
     (they gain   (in between,     (typical metal:
      electrons)   semiconductors)  shiny, conducts)

  WHY? Going down, the atom is bigger and the ionisation enthalpy falls,
       so it becomes easier to LOSE electrons - and losing electrons is
       exactly what "being a metal" means.
```

|---|---|---|

```

# TOPIC 3 — Group 15 trends, and the REASON behind each

Never write only the trend in an exam. Always write the **reason**. Half the
marks in a trends question are for the reason.

## 3.1 Atomic and ionic radii

| PROPERTY | TREND | REASON |
|---|---|---|
| Covalent radius | INCREASES down: N < P < As < Sb < Bi | A new shell is added at each step. |
| Jump from N to P | LARGE | Going from period 2 to period 3 adds a whole shell. |
| Jump from As to Sb, Sb to Bi | SMALL | The filled d (and f for Bi) orbitals shield the nucleus poorly, so the nucleus pulls the outer shell in and cancels most of the increase. |

```
  This "poor shielding by d and f electrons" idea appears THREE times in
  this chapter. Learn it once:

      d and f orbitals are DIFFUSE (spread out, oddly shaped).
      They do a BAD job of hiding the nucleus from the outer electrons.
             |
             v
      The outer electrons feel a LARGER effective nuclear charge
      than you would expect.
             |
             +--> atomic size increases LESS than expected  (this topic)
             +--> ionisation enthalpy does NOT fall as fast as expected
             +--> the ns2 pair is held very tightly  ->  INERT PAIR EFFECT
```

## 3.2 Ionisation enthalpy

| POINT | STATEMENT | REASON |
|---|---|---|
| Trend | DECREASES down the group: N > P > As > Sb > Bi | Size increases, so the outer electron is farther and more shielded. |
| Compared to Group 14 and 16 | Group 15 IE is HIGHER than both its neighbours | Its ns2 np3 configuration is **exactly half filled**, which is extra stable, so removing an electron costs more. |
| N vs O | IE of N > IE of O — an exception to the "across a period IE rises" rule | Same half-filled stability of nitrogen's 2p3. |

```
  THE HALF-FILLED STABILITY ARGUMENT

       N   2p3   ->   [up][up][up]      half filled, symmetric, EXTRA STABLE
       O   2p4   ->   [ud][up][up]      one orbital doubly occupied,
                                        electron-electron repulsion,
                                        so that electron LEAVES easily

    Result:  IE1 of N  >  IE1 of O.
    Same reason:  Group 15 has a higher IE than Group 16 across the board.
```

## 3.3 Electronegativity

```
  DECREASES down the group:   N > P > As > Sb > Bi

  Reason: the atom gets bigger, so the nucleus grips a shared electron
          pair less tightly.

  N (3.0) is the SECOND most electronegative element after F and O.
  This is why NH3, HNO3 and the nitrogen oxides behave so differently
  from their phosphorus versions.
```

## 3.4 Melting and boiling point — the one trend with a twist

```
  MELTING POINT:      N  <  P  <  As   THEN IT FALLS:  As > Sb > Bi
                      |_______________|                |____________|
                        rises                            falls

  Why does it rise first?
      From N to As the atoms get bigger and heavier, the solids become
      more strongly held together (N2 is a small gas molecule with only
      weak forces; As is a giant covalent-metallic solid).

  Why does it fall at Bi?
      Bi is a metal, and its metallic bonding is WEAK because the 6s2
      inert pair does not join in - only the three 6p electrons do.
      Fewer electrons in the "sea" -> weaker metallic bond -> lower m.p.

  BOILING POINT rises steadily down the group (bigger atoms, stronger
  van der Waals forces).
```

**WORKED EXAMPLE 2**

> **Q. Arrange N, P, As, Sb, Bi in order of increasing ionisation enthalpy and
> justify. (2 marks)**
>
> **ANSWER:**
>
> ```
>   Bi  <  Sb  <  As  <  P  <  N
>
>   Reason: down the group the atomic size increases and the outer
>   electrons are increasingly shielded from the nucleus, so less
>   energy is needed to remove an electron. Nitrogen, being the
>   smallest with a stable half-filled 2p3 configuration, has the
>   highest ionisation enthalpy.
> ```

> **TRAP:** Students write the reverse order because they read "ionisation
> enthalpy decreases down the group" and then list the elements top to bottom.
> The question asked for **increasing** order, so you must start from the
> **bottom** element. Read the direction word twice before you write.

# TOPIC 4 — Oxidation states and the INERT PAIR EFFECT

Group 15 has 5 valence electrons (ns2 np3). It can therefore:

```
  GAIN 3 electrons     ->  -3   (as in NH3, PH3, Mg3N2)
  LOSE / SHARE 3       ->  +3   (as in NCl3, PCl3, Bi2O3)
  LOSE / SHARE all 5   ->  +5   (as in HNO3, PCl5, H3PO4)
```

## 4.1 The -3 state gets WEAKER down the group

```
  Forming M3- means squeezing 3 extra electrons onto one atom.
  That is only possible if the atom is SMALL and ELECTRONEGATIVE.

     N3-  exists (Mg3N2, Li3N)   ->  fine
     P3-  exists but harder (Ca3P2)
     As3-, Sb3-, Bi3-           ->  essentially do not form

  So:  stability of the -3 state DECREASES down the group.
```

## 4.2 The +5 state also gets weaker — this is the INERT PAIR EFFECT

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   INERT PAIR EFFECT  -  learn this definition word for word          |
  |                                                                      |
  |   "The reluctance of the ns2 electron pair to participate in bond    |
  |    formation, due to the poor shielding of the nucleus by the        |
  |    intervening d and f electrons, is called the inert pair effect.   |
  |    Because of it, the stability of the LOWER oxidation state         |
  |    (group valency - 2) increases down the group."                    |
  |                                                                      |
  +----------------------------------------------------------------------+
```

Here is the mechanism drawn out:

```
   TOP OF GROUP  (N, P)                 BOTTOM OF GROUP  (Sb, Bi)

     ns [ud]  np [u][u][u]                ns [ud]  np [u][u][u]
        ^                                    ^
        |                                    |
   the ns pair can be                   between this ns pair and the
   "promoted" and used                  nucleus sit filled 3d, 4d,
   in bonding easily                    4f orbitals. They shield BADLY.
        |                                    |
        v                                    v
   ALL 5 electrons bond                 The nucleus grips the ns2 pair
   ->  +5 is common and stable          very hard. Only the 3 np
                                        electrons bond.
                                        ->  +3 is what you actually get
```

| ELEMENT | PREFERRED STATE | EVIDENCE |
|---|---|---|
| N | +5 and +3 both common | HNO3 (+5), HNO2 (+3) both stable |
| P | +5 dominant | H3PO4, PCl5 stable |
| As | +5 still fine | H3AsO4 exists |
| Sb | +3 preferred | SbCl3 stable, SbCl5 less so |
| Bi | +3 strongly preferred | BiCl3 stable; **Bi(V) compounds are powerful oxidising agents** because Bi(V) wants to drop to Bi(III) |

```
  THE SAME EFFECT IN OTHER GROUPS (often asked as a comparison):

      GROUP 13   Tl+  is more stable than  Tl3+
      GROUP 14   Pb2+ is more stable than  Pb4+   (PbO2 is an oxidiser)
      GROUP 15   Bi3+ is more stable than  Bi5+   (NaBiO3 is an oxidiser)
      GROUP 16   Po +4 is more stable than Po +6
```

**WORKED EXAMPLE 3**

> **Q. BiCl5 does not exist but PCl5 does. Explain. (2 marks)**
>
> **ANSWER:**
>
> ```
>   In bismuth the 6s2 electron pair is very tightly held because the
>   filled 4f and 5d orbitals shield the nucleus poorly (INERT PAIR
>   EFFECT). Therefore Bi uses only its three 6p electrons for bonding
>   and shows a stable +3 state, giving BiCl3.
>
>   In phosphorus there are no f electrons and only a small shielding
>   problem, so the 3s2 pair is easily promoted to a 3d orbital and all
>   five valence electrons are used. Hence PCl5 (+5) is stable.
> ```

> **TRAP:** Do NOT say "Bi is a metal so it cannot show +5". Metals show high
> oxidation states all the time. The mark is for the phrase **inert pair
> effect** plus **poor shielding by d and f electrons**. If those two phrases
> are missing, you get nothing.

# TOPIC 5 — Why the FIRST MEMBER of every group is a rebel

N, O and F behave very differently from the elements below them. This is the
"anomalous behaviour of the first member" question, and it is worth 4 marks in
every one of the four groups.

```
  +----------------------------------------------------------------------+
  |  THE THREE UNIVERSAL REASONS  (memorise as "SEN-D")                  |
  |                                                                      |
  |   S  =  SMALL SIZE                                                   |
  |   E  =  high ELECTRONEGATIVITY (and high ionisation enthalpy)        |
  |   N  =  (they are in period 2 so) ... they have                      |
  |   D  =  NO d ORBITALS in the valence shell                           |
  |                                                                      |
  |   CONSEQUENCE 1: no d orbitals -> CANNOT expand the octet            |
  |                  -> maximum covalency is FOUR                        |
  |                  -> NF5, OF6, ClF3-type expansion is impossible for  |
  |                     N, O, F                                          |
  |                                                                      |
  |   CONSEQUENCE 2: small size -> the 2p orbitals sideways-overlap well |
  |                  -> N, O, F form  p-pi - p-pi MULTIPLE BONDS         |
  |                  -> N2 (triple), O2 (double), and so they are GASES  |
  |                                                                      |
  |                  P, S have big diffuse 3p orbitals that overlap      |
  |                  sideways badly, so they form SINGLE bonds and       |
  |                  CATENATE into big molecules: P4 and S8 - SOLIDS.    |
  +----------------------------------------------------------------------+
```

## Anomalous behaviour of NITROGEN — the standard 4-mark answer

| POINT | NITROGEN | PHOSPHORUS AND BELOW |
|---|---|---|
| Physical state | Gas, diatomic N2 | Solid, P4, As4 etc. |
| Bonding | Forms p-pi–p-pi multiple bonds (N≡N triple bond) | Forms only single bonds; catenates instead |
| d orbitals | **Absent** — maximum covalency 4 | Present — covalency up to 6 |
| Pentahalides | NCl5, NF5 do **not** exist | PCl5, PF5 exist |
| Catenation | Very poor (weak N–N single bond) | P shows good catenation |
| Hydride | NH3 is hydrogen bonded, high b.p., strongly basic | PH3 not H-bonded, low b.p., weakly basic |
| Bond angle in hydride | 107.8° (large) | PH3 93.6° (near 90°) |

**WORKED EXAMPLE 4**

> **Q. NF3 is not hydrolysed but NCl3 is. Why? (2 marks)**
>
> **ANSWER:**
>
> ```
>   In NCl3, chlorine has vacant 3d orbitals which can accept the lone
>   pair of the attacking water molecule, so hydrolysis proceeds:
>
>        NCl3 + 3 H2O  -->  NH3 + 3 HOCl
>
>   In NF3, fluorine has NO d orbitals, so water cannot attack. Also the
>   N-F bond is very strong. Hence NF3 resists hydrolysis.
> ```

> **TRAP:** Note carefully whose d orbitals matter here. Nitrogen has none in
> both molecules; it is the **halogen's** d orbitals that make the difference.
> Cl has 3d, F does not.

**WORKED EXAMPLE 5**

> **Q. Nitrogen exists as a diatomic gas but phosphorus exists as a P4 solid.
> Explain. (2 marks)**
>
> **ANSWER:**
>
> ```
>   Nitrogen is small, so its 2p orbitals overlap sideways very
>   effectively and form strong p-pi - p-pi multiple bonds. Two N atoms
>   therefore join by a TRIPLE bond to give a small, light, non-polar
>   N2 molecule which is a GAS.
>
>   Phosphorus atoms are larger, their 3p orbitals are diffuse and
>   overlap sideways poorly, so pi bonding is not possible. Instead P
>   forms three SINGLE bonds and joins into a tetrahedral P4 molecule.
>   P4 is much heavier with stronger van der Waals forces, so it is a
>   SOLID.
> ```

# TOPIC 6 — Hydrides of Group 15: the four trends

The five hydrides are **NH3, PH3, AsH3, SbH3, BiH3**. All are **pyramidal**
(3 bond pairs + 1 lone pair on the central atom).

```
  SHAPE OF EVERY GROUP-15 HYDRIDE:  TRIGONAL PYRAMIDAL

                     ..            <- lone pair
                     N
                   / | \
                  H  H  H

     4 electron pairs around N -> tetrahedral electron geometry
     but one is a LONE PAIR -> the SHAPE is PYRAMIDAL
     lone pair pushes harder, so the angle drops below 109.5 deg
```

## The master table (learn this — it is asked every year)

| PROPERTY | ORDER | REASON |
|---|---|---|
| **Bond angle** | NH3 (107.8°) > PH3 (93.6°) > AsH3 (91.8°) > SbH3 (91.3°) > BiH3 (~90°) | Electronegativity of the central atom falls down the group, so the bond pairs sit farther from it and repel each other less; also the central atom uses almost pure p orbitals lower down (angle nears 90°). |
| **Thermal stability** | NH3 > PH3 > AsH3 > SbH3 > BiH3 (DECREASES) | The E–H bond length increases and bond dissociation enthalpy decreases down the group. |
| **Basicity** | NH3 > PH3 > AsH3 > SbH3 > BiH3 (DECREASES) | The lone pair is in a bigger, more diffuse orbital down the group, so it is less available for donation. |
| **Reducing character** | NH3 < PH3 < AsH3 < SbH3 < BiH3 (INCREASES) | Weaker E–H bonds break more easily, releasing hydrogen which does the reducing. |
| **Boiling point** | PH3 < AsH3 < NH3 < SbH3 < BiH3 | Normally rises with size (van der Waals), but **NH3 jumps out of order because of HYDROGEN BONDING**. |

```
  WHY NH3 BOILS HIGHER THAN PH3  (a favourite 2-mark question)

      NH3 :   N is highly electronegative + small
              ->  N-H bonds are very polar
              ->  molecules stick together by HYDROGEN BONDING
              ->  a lot of energy needed to separate them
              ->  boiling point 239.6 K  (high for its size)

      PH3 :   P is barely more electronegative than H
              ->  P-H bond is almost non-polar
              ->  only weak van der Waals forces
              ->  boiling point 185.5 K  (the LOWEST of the five)

      After PH3 the boiling points climb again (AsH3 < SbH3 < BiH3)
      simply because the molecules get heavier.
```

**WORKED EXAMPLE 6**

> **Q. Explain why the bond angle in NH3 (107.8°) is much larger than in
> PH3 (93.6°). (2 marks)**
>
> **ANSWER:**
>
> ```
>   In NH3, nitrogen is small and highly electronegative, so the three
>   bond pairs are pulled CLOSE to the nitrogen atom. Being close, they
>   repel one another strongly and push the H-N-H angle open to 107.8 deg.
>
>   In PH3, phosphorus is larger and much less electronegative, so the
>   bond pairs sit FAR from the central atom and repel each other only
>   weakly. The lone pair therefore squeezes the angle right down to
>   93.6 deg, close to the 90 deg of pure p orbitals.
> ```

> **TRAP:** Never say "NH3 is sp3 and PH3 is sp2". Both are essentially sp3 (or
> in PH3's case nearly unhybridised p). The mark comes from **electronegativity
> of the central atom** and **lone pair–bond pair repulsion**.

# TOPIC 7 — Dinitrogen (N2)

## Laboratory preparation

```
  1.  From ammonium chloride and sodium nitrite (the standard method):

         NH4Cl + NaNO2  --(warm)-->  N2 + NaCl + 2 H2O

      (In practice NH4NO2 is formed first and then decomposes:
         NH4NO2  --(heat)-->  N2 + 2 H2O )

  2.  From ammonium dichromate  - the "volcano" experiment:

         (NH4)2Cr2O7  --(heat)-->  N2 + Cr2O3 + 4 H2O

  3.  VERY PURE nitrogen, from barium azide or sodium azide:

         Ba(N3)2  --(heat)-->  Ba + 3 N2
```

## Industrial preparation

```
  Liquefy air, then FRACTIONALLY DISTIL it.
  N2 boils at 77 K, O2 boils at 90 K, so NITROGEN COMES OFF FIRST.
```

## Properties

| PROPERTY | FACT |
|---|---|
| Appearance | Colourless, odourless, tasteless, non-toxic gas |
| Solubility | Slightly soluble in water |
| Reactivity | **Very inert at room temperature** |
| Bond | N≡N triple bond, dissociation enthalpy **941.4 kJ/mol** (one of the strongest bonds known) |

```
  WHY IS N2 SO UNREACTIVE?   (guaranteed 2-mark question)

      The two nitrogen atoms are joined by a TRIPLE BOND whose bond
      dissociation enthalpy is 941.4 kJ/mol - extremely high.
      Breaking that bond needs enormous energy, so at ordinary
      temperature nitrogen does not react.

      At HIGH temperature it does react:

         N2 + 3 H2  <=(Fe, 700 K, 200 atm)=>  2 NH3
         N2 + O2    --(about 2000 K)-->       2 NO
         N2 + 3 Mg  --(heat)-->               Mg3N2
         N2 + 6 Li  -->                       2 Li3N
```

## Uses of dinitrogen

```
  - Manufacture of AMMONIA (Haber process) and hence of fertilisers
  - Inert atmosphere in iron/steel industry and in packing food
  - LIQUID NITROGEN as a refrigerant: preserving biological samples,
    freezing food, cryosurgery
  - Filling electric bulbs and mercury thermometers above the mercury
```

> **TRAP:** "Why is nitrogen used in food packets?" The answer is **not** "it is
> a gas". It is: nitrogen is **chemically inert**, so it displaces oxygen and
> prevents oxidation and microbial spoilage.

# TOPIC 8 — Ammonia and the HABER PROCESS

**This is an 8-mark question. Learn it completely.**

## 8.1 Laboratory preparation

```
  Heat any ammonium salt with a strong alkali:

     2 NH4Cl + Ca(OH)2  --(heat)-->  2 NH3 + CaCl2 + 2 H2O

  Or hydrolyse a nitride:

     Mg3N2 + 6 H2O  -->  3 Mg(OH)2 + 2 NH3

  DRYING:  ammonia is dried over QUICKLIME (CaO).

     It is NOT dried over conc. H2SO4, P4O10 or CaCl2, because ammonia
     is BASIC and reacts with the acidic driers, and it forms the
     complex CaCl2.8NH3 with calcium chloride.
```

## 8.2 THE HABER PROCESS — the manufacture

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |      N2(g)  +  3 H2(g)   <==>   2 NH3(g)     dH = -46.1 kJ/mol       |
  |                                                                      |
  |      PRESSURE     :  200 atm   (200 x 10^5 Pa)                       |
  |      TEMPERATURE  :  700 K     (about 673 - 773 K)                   |
  |      CATALYST     :  finely divided IRON OXIDE                       |
  |      PROMOTERS    :  K2O  and  Al2O3                                 |
  |                                                                      |
  +----------------------------------------------------------------------+
```

**Why those conditions? (this reasoning carries the marks)**

```
   THE REACTION:      N2  +  3 H2   <==>   2 NH3        dH = NEGATIVE
                      1 vol + 3 vol  =  4 vol  ->  2 vol
                      (the number of gas molecules FALLS)

   +-------------------+--------------------------------------------------+
   | HIGH PRESSURE     | The forward reaction reduces the number of gas   |
   | (200 atm)         | molecules from 4 to 2. By Le Chatelier's         |
   |                   | principle, raising the pressure pushes the       |
   |                   | equilibrium FORWARD. More NH3.                   |
   +-------------------+--------------------------------------------------+
   | LOW TEMPERATURE   | The forward reaction is EXOTHERMIC, so a LOW     |
   | would favour NH3  | temperature would give more NH3 at equilibrium.  |
   | BUT...            |                                                  |
   +-------------------+--------------------------------------------------+
   | 700 K IS A        | At low temperature the reaction is far too SLOW  |
   | COMPROMISE        | and the catalyst does not work. 700 K is the     |
   | ("optimum         | OPTIMUM temperature: a good yield obtained in a  |
   |  temperature")    | reasonable time.                                 |
   +-------------------+--------------------------------------------------+
   | CATALYST          | Iron oxide speeds up the reaction so equilibrium |
   |                   | is reached quickly. It does NOT change the yield.|
   +-------------------+--------------------------------------------------+
   | PROMOTERS         | K2O and Al2O3 increase the efficiency and the    |
   |                   | life of the iron catalyst.                       |
   +-------------------+--------------------------------------------------+

   THE AMMONIA IS REMOVED BY LIQUEFACTION, and the unreacted N2 and H2
   are RECYCLED back into the converter. Removing the product keeps
   pulling the equilibrium forward.
```

```
   FLOW CHART (draw this - it earns marks on its own)

     N2 (from liquid air)          H2 (from natural gas / water gas)
            |                                    |
            +----------------+-------------------+
                             |
                    +--------v---------+
                    |   COMPRESSOR     |    raise to 200 atm
                    +--------+---------+
                             |
                    +--------v---------+

## 8.3 Properties of ammonia

```
  PHYSICAL
     Colourless gas with a sharp, pungent smell
     Highly soluble in water (because of hydrogen bonding)
     Easily liquefied; liquid NH3 is used as a refrigerant
     STRUCTURE: sp3 hybridised, TRIGONAL PYRAMIDAL, H-N-H = 107.8 deg,
                one lone pair on nitrogen
```

```
  CHEMICAL

  1.  BASIC - it is a Lewis base and a Bronsted base:

         NH3 + H2O  <=>  NH4+ + OH-        Kb = 1.8 x 10^-5

         NH3 + HCl  -->  NH4Cl   (dense white fumes - the TEST for NH3)

  2.  PRECIPITATES METAL HYDROXIDES (because it supplies OH-):

         ZnSO4 + 2 NH4OH  -->  Zn(OH)2 (white ppt) + (NH4)2SO4

  3.  FORMS COMPLEXES - the lone pair is donated to metal ions:

         Cu2+ + 4 NH3  -->  [Cu(NH3)4]2+     DEEP BLUE  (test for Cu2+)

```

  - Cleaning agents (household ammonia)

**WORKED EXAMPLE 7**

> **Q. Ammonia is dried by quicklime and not by concentrated sulphuric acid.
> Why? (2 marks)**
>
> **ANSWER:**
>
> ```
>   Ammonia is a BASE. Concentrated H2SO4 is an acid, so it would react
>   with the ammonia instead of merely drying it:
>
>        2 NH3 + H2SO4  -->  (NH4)2SO4
>
>   Quicklime (CaO) is basic, so it absorbs only the water and does not

> ```

# TOPIC 9 — Oxides of nitrogen

Nitrogen forms an oxide in **every** oxidation state from +1 to +5. That is
unique, and it is why nitrogen chemistry is so rich.

| OXIDE | NAME | OX. STATE OF N | HOW IT IS MADE | NATURE |
|---|---|---|---|---|
| N2O | Dinitrogen oxide (laughing gas) | +1 | NH4NO3 --(heat)--> N2O + 2H2O | **Neutral** |
| NO | Nitrogen monoxide (nitric oxide) | +2 | 2NaNO2 + 2FeSO4 + 3H2SO4 --> Fe2(SO4)3 + 2NaHSO4 + 2H2O + 2NO | **Neutral** |
| N2O3 | Dinitrogen trioxide | +3 | 2NO + N2O4 --(250 K)--> 2N2O3 | **Acidic** (anhydride of HNO2) |
| NO2 | Nitrogen dioxide | +4 | 2Pb(NO3)2 --(673 K)--> 4NO2 + 2PbO + O2 | **Acidic** |
| N2O4 | Dinitrogen tetroxide | +4 | 2NO2 <=(cool)=> N2O4 | **Acidic** |
| N2O5 | Dinitrogen pentoxide | +5 | 4HNO3 + P4O10 --> 4HPO3 + 2N2O5 | **Acidic** (anhydride of HNO3) |

```
  THE FOUR FACTS MOST OFTEN ASKED

   1. N2O is called LAUGHING GAS. Used as a mild anaesthetic.
      It is a NEUTRAL oxide.

   2. NO and NO2 are ODD-ELECTRON molecules (they have an unpaired
      electron), so they are PARAMAGNETIC.
      NO2 dimerises to N2O4 (which is diamagnetic) on cooling,
      because pairing up the odd electron is more stable:

           2 NO2 (brown, paramagnetic)  <=>  N2O4 (colourless, diamagnetic)
             favoured by HEATING              favoured by COOLING

   3. NO2 is the BROWN gas you see when concentrated nitric acid acts
      on a metal. It is poisonous and a major air pollutant.

   4. N2O3 is the anhydride of HNO2 (nitrous acid);
      N2O5 is the anhydride of HNO3 (nitric acid).
```

```
  MEMORY LADDER FOR THE OXIDATION STATES

      N2O   +1     "one"     N-2-O    ->   2 N share 1 O
      NO    +2     "two"
      N2O3  +3     "three"
      NO2   +4     "four"
      N2O5  +5     "five"

      Notice: the SUBSCRIPT PATTERN alternates N2 / N / N2 / N / N2
      and the oxidation number simply climbs 1,2,3,4,5.
```

> **TRAP:** N2O and NO are **neutral** oxides — they do not turn litmus at all
> and form no acid with water. Every other nitrogen oxide is acidic. Students
> routinely write "all oxides of nitrogen are acidic". That is wrong.

## 10.2 THE OSTWALD PROCESS

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  STEP 1  CATALYTIC OXIDATION OF AMMONIA                              |
  |                                                                      |
  |     4 NH3(g) + 5 O2(g)  --(Pt/Rh gauze, 500 K, 9 bar)-->             |
  |                                        4 NO(g) + 6 H2O(g)            |
  |                                                                      |

  |     (contact time about one millisecond)                             |
  |                                                                      |
  |  STEP 2  OXIDATION OF NITRIC OXIDE  (cool the gases first)           |
  |                                                                      |
  |     2 NO(g) + O2(g)  <==>  2 NO2(g)                                  |
  |                                                                      |
  |  STEP 3  ABSORPTION IN WATER                                         |
  |                                                                      |
  |     3 NO2(g) + H2O(l)  -->  2 HNO3(aq) + NO(g)                       |
  |                                                                      |
  |     The NO produced is RECYCLED back to step 2 - nothing wasted.     |
  |                                                                      |
  |  CONCENTRATION                                                       |
  |     Distillation gives at most a 68 % acid - an AZEOTROPE, which     |
  |     cannot be concentrated further by distilling.                    |

  |                                                                      |
  +----------------------------------------------------------------------+
```

## 10.3 Properties of nitric acid

```
  PHYSICAL
     Pure HNO3 is a colourless liquid, b.p. 355.6 K.
     Laboratory acid is about 68 % and looks yellow because dissolved
     NO2 (from slight decomposition) colours it:

        4 HNO3  --(light / heat)-->  4 NO2 + 2 H2O + O2

  STRUCTURE OF HNO3 (in the gas phase, PLANAR)

              O
              ||
         HO - N -> O          nitrogen is sp2 hybridised,
                              the molecule is PLANAR
```

```
  AS AN ACID
     In water it is a STRONG monobasic acid:
        HNO3 + H2O  -->  H3O+ + NO3-
     Neutralises bases, dissolves carbonates, etc.

  AS AN OXIDISING AGENT  -  this is its real personality
     Concentrated HNO3 is a POWERFUL oxidiser.
        - It oxidises iodine to iodic acid, carbon to CO2,
          sulphur to H2SO4, phosphorus to H3PO4.

        C + 4 HNO3(conc)   -->  CO2 + 4 NO2 + 2 H2O
        S8 + 48 HNO3(conc) -->  8 H2SO4 + 48 NO2 + 16 H2O
        P4 + 20 HNO3(conc) -->  4 H3PO4 + 20 NO2 + 4 H2O
```

## 10.4 HNO3 with metals — the four cases you MUST know

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  GOLDEN RULE:  nitric acid does NOT normally give H2 gas with a      |
  |  metal, because the NO3- ion is such a good oxidising agent that     |
  |  it grabs the hydrogen and is itself reduced to an oxide of          |
  |  nitrogen. (The two exceptions are Mg and Mn with VERY dilute        |
  |  HNO3, which do give H2.)                                            |
  |                                                                      |
  |  COPPER                                                              |
  |     dilute :  3 Cu + 8 HNO3  -->  3 Cu(NO3)2 + 2 NO  + 4 H2O        |
  |     conc.  :    Cu + 4 HNO3  -->    Cu(NO3)2 + 2 NO2 + 2 H2O        |
  |                                                                      |
  |  ZINC                                                                |
  |     dilute :  4 Zn + 10 HNO3 -->  4 Zn(NO3)2 +   N2O + 5 H2O        |
  |     conc.  :    Zn + 4 HNO3  -->    Zn(NO3)2 + 2 NO2 + 2 H2O        |
  |                                                                      |
  |  PATTERN:  CONCENTRATED acid always gives the BROWN gas NO2.         |
  |            DILUTE acid gives a more reduced product                  |
  |            (NO with copper, N2O with the more reactive zinc).        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  PASSIVITY  (a 2-mark favourite)

     Cr, Al and Fe do NOT dissolve in CONCENTRATED nitric acid.
     A thin, hard, unreactive layer of METAL OXIDE forms on the surface
     and protects the metal underneath. This is called PASSIVITY.

     That is why concentrated HNO3 can be transported in aluminium tanks.
```

```
  BROWN RING TEST  -  the test for the NITRATE ion

     Add freshly prepared FeSO4 solution to the nitrate solution, then
     add concentrated H2SO4 slowly down the side of the tube.
     A BROWN RING appears where the two liquids meet.

        NO3- + 3 Fe2+ + 4 H+  -->  NO + 3 Fe3+ + 2 H2O
        [Fe(H2O)6]2+ + NO     -->  [Fe(H2O)5(NO)]2+ + H2O
                                      BROWN ring
```

## 10.5 Uses of nitric acid

```
  - Manufacture of AMMONIUM NITRATE fertiliser
  - Manufacture of EXPLOSIVES: TNT, nitroglycerine, picric acid
  - Manufacture of nitrates and of adipic acid (for nylon)
  - As an oxidiser in rocket fuel
  - Pickling of stainless steel; etching of metals
  - Purification of gold and silver (aqua regia)
```

**WORKED EXAMPLE 8**

> **Q. Write the equations for the action of dilute and concentrated nitric
> acid on copper. (4 marks)**
>
> **ANSWER:**
>
> ```
>   With DILUTE nitric acid, colourless NITRIC OXIDE is evolved:
>
>       3 Cu + 8 HNO3(dilute)  -->  3 Cu(NO3)2 + 2 NO + 4 H2O
>
>       (the NO turns brown at the mouth of the tube because it
>        immediately meets air:  2 NO + O2 -> 2 NO2 )
>
>   With CONCENTRATED nitric acid, brown NITROGEN DIOXIDE is evolved:
>
>       Cu + 4 HNO3(conc.)  -->  Cu(NO3)2 + 2 NO2 + 2 H2O
>
>   In both cases the solution turns BLUE because of Cu(NO3)2, and
>   NO hydrogen gas is produced, since the nitrate ion oxidises the
>   hydrogen that would otherwise be released.
> ```

> **TRAP:** Balance these carefully. The dilute-copper equation is **3 Cu : 8
> HNO3 : 2 NO** and the dilute-zinc equation is **4 Zn : 10 HNO3 : 1 N2O**.
> Examiners deduct for unbalanced equations. Write them out ten times.

# TOPIC 11 — Allotropes of phosphorus

**Allotropes** = different physical forms of the SAME element in the SAME
physical state.

```
  WHITE PHOSPHORUS  -  the P4 molecule

                        P
                       /|\
                      / | \
                     /  P  \          A REGULAR TETRAHEDRON.
                    / /   \ \         Each P is bonded to the other three.
                   P---------P        P-P-P bond angle = 60 degrees.

     That 60 degree angle is FAR below the 109.5 deg that sp3 bonds want,
     so the molecule is under enormous ANGULAR STRAIN.
     THAT STRAIN IS WHY WHITE PHOSPHORUS IS SO REACTIVE.
```

| PROPERTY | WHITE (yellow) P | RED P | BLACK P |
|---|---|---|---|
| Structure | Discrete P4 tetrahedral molecules | Polymeric — chains of P4 tetrahedra linked together | Layered, most tightly packed |
| Appearance | Translucent white waxy solid, turns yellow | Iron-grey lustrous powder | Black, metallic looking |
| Smell | Garlic smell | Odourless | Odourless |
| Toxicity | **Very poisonous** | Non-poisonous | Non-poisonous |
| Solubility | Insoluble in water, **soluble in CS2** | Insoluble in water AND in CS2 | Insoluble |
| Glow in dark | **Yes — chemiluminescence / phosphorescence** | No | No |
| Ignition temperature | ~303 K (catches fire in air on its own) | ~543 K | High |
| Reactivity | **Most reactive** | Much less reactive | **Most stable / least reactive** |
| Storage | **Kept under water** | Kept normally | Kept normally |

```
  HOW THEY ARE INTERCONVERTED

     White P  --(heat to 573 K in an INERT atmosphere, several hours)-->  RED P

     Red P  --(heat to 803 K under HIGH PRESSURE)-->  beta-BLACK P
     White P --(heat to 473 K under very high pressure)--> alpha-BLACK P
```

```
  WHY IS WHITE PHOSPHORUS KEPT UNDER WATER?   (2-mark classic)

     Its ignition temperature is only about 303 K (30 deg C), which is
     roughly room temperature in India. Left in air it catches fire on
     its own. Water cuts off the air. It is stored under water because
     it is insoluble in water.
```

## Reaction of white phosphorus with alkali

```
     P4 + 3 NaOH + 3 H2O  --(inert atmosphere)-->  PH3 + 3 NaH2PO2
                                                  phosphine   sodium
                                                              hypophosphite

  This is a DISPROPORTIONATION: phosphorus goes from 0 to -3 (in PH3)
  and to +1 (in NaH2PO2) at the same time.
```

> **TRAP:** Red phosphorus is *insoluble in CS2* — this is the standard way to
> tell it from white phosphorus, which *dissolves* in CS2. Do not mix them up.

# TOPIC 12 — Phosphine (PH3)

## Preparation

```
  1.  From calcium phosphide (the usual laboratory route):

         Ca3P2 + 6 H2O   -->  3 Ca(OH)2 + 2 PH3
         Ca3P2 + 6 HCl   -->  3 CaCl2   + 2 PH3

  2.  From white phosphorus and hot concentrated alkali:

         P4 + 3 NaOH + 3 H2O  -->  PH3 + 3 NaH2PO2

  3.  Pure phosphine, by heating phosphonium iodide with alkali:

         PH4I + KOH  -->  KI + H2O + PH3
```

## Properties

| PROPERTY | FACT |
|---|---|
| Appearance | Colourless gas with a **rotten-fish smell** |
| Toxicity | Highly poisonous |
| Solubility | **Sparingly soluble** in water (unlike NH3, which is very soluble — PH3 cannot hydrogen bond) |
| Basicity | Very weak base, far weaker than NH3 |
| Shape | Pyramidal, H–P–H = 93.6° |
| Burning | Burns in oxygen: PH3 + 2 O2 --> H3PO4 |

```
  THE SPONTANEOUS-COMBUSTION POINT  (asked very often)

     PURE PH3 is NOT spontaneously inflammable.

     But PH3 prepared from Ca3P2 or from P4 + NaOH carries traces of
     DIPHOSPHINE (P2H4). P2H4 catches fire on its own in air, and it
     sets the phosphine alight.

     That is why the gas from Ca3P2 burns with a luminous flame the
     moment it hits air, forming smoke rings of P4O10.
```

```
  HOLME'S SIGNALS   (a 2-mark question in its own right)

     Containers holding CALCIUM PHOSPHIDE (Ca3P2) and CALCIUM CARBIDE
     (CaC2) are thrown into the sea near a rock or shoal.
     Water reacts with them:
          Ca3P2 + H2O  ->  PH3   (which ignites because of P2H4)
          CaC2  + H2O  ->  C2H2  (acetylene, which burns)
     The burning gases give a BRIGHT FLAME that marks the danger spot
     for approaching ships. This is called HOLME'S SIGNAL.

     The same reaction is used to make SMOKE SCREENS in warfare.
```

```
  BASICITY:   NH3  >>  PH3

     PH3 does react with HI:      PH3 + HI  -->  PH4I
     but it does NOT react with water to give an alkaline solution the
     way NH3 does. Phosphine solution is neutral to litmus.
```

**WORKED EXAMPLE 9**

> **Q. PH3 is less soluble in water than NH3. Give the reason. (2 marks)**
>
> **ANSWER:**
>
> ```
>   NH3 forms strong HYDROGEN BONDS with water molecules because
>   nitrogen is small and highly electronegative. These hydrogen bonds
>   pull ammonia into the water, so NH3 is extremely soluble.
>
>   In PH3, phosphorus is large and has almost the same electronegativity
>   as hydrogen, so the P-H bond is nearly non-polar and phosphine
>   CANNOT hydrogen bond with water. Hence PH3 is only sparingly soluble.
> ```

# TOPIC 13 — Phosphorus halides: PCl3 and PCl5

## 13.1 Phosphorus trichloride, PCl3

```
  PREPARATION

     P4 + 6 Cl2      -->  4 PCl3            (dry chlorine over white P)
     P4 + 8 SOCl2    -->  4 PCl3 + 4 SO2 + 2 S2Cl2   (thionyl chloride route)

  STRUCTURE:   sp3 hybridised, TRIGONAL PYRAMIDAL (3 bond pairs + 1 lone pair)

                     ..
                     P
                   / | \
                 Cl  Cl Cl        Cl-P-Cl about 100 deg
```

```
  REACTIONS

  1.  HYDROLYSIS (fumes in moist air):

         PCl3 + 3 H2O  -->  H3PO3 + 3 HCl

  2.  WITH ALCOHOLS - a very important organic reagent:

         3 C2H5OH + PCl3  -->  3 C2H5Cl + H3PO3

  3.  WITH CARBOXYLIC ACIDS:

         3 CH3COOH + PCl3  -->  3 CH3COCl + H3PO3
```

## 13.2 Phosphorus pentachloride, PCl5

```
  PREPARATION

     P4 + 10 Cl2      -->  4 PCl5
     P4 + 10 SO2Cl2   -->  4 PCl5 + 10 SO2     (sulphuryl chloride route)
```

```
  STRUCTURE IN THE GAS / LIQUID PHASE:
       sp3d hybridised,  TRIGONAL BIPYRAMIDAL

                      Cl
                      |          <- AXIAL bond, 240 pm, LONGER and WEAKER
                      |
             Cl       |
               \      |
                \     |
                 \    |
                  ---(P)---  Cl      <- EQUATORIAL bonds, 202 pm,
                 /    |                  SHORTER and STRONGER
                /     |
               /      |
             Cl       |
                      |
                      Cl         <- AXIAL bond, 240 pm

     Equatorial angles: 120 deg      Axial-equatorial angles: 90 deg
```

```
  WHY ARE THE TWO AXIAL BONDS LONGER?   (2-mark classic)

     Each AXIAL bond pair is repelled by THREE equatorial bond pairs
     at 90 degrees. Each EQUATORIAL bond pair is repelled by only TWO
     bond pairs at 90 degrees (the two axial ones).
     More repulsion -> the axial bonds are pushed out further ->
     they are LONGER (240 pm) and WEAKER.

     CONSEQUENCE: the axial bonds break easily, so PCl5 is very
     REACTIVE and readily gives up chlorine.
```

```
  STRUCTURE IN THE SOLID STATE  -  a favourite 2-mark question

     Solid PCl5 is IONIC:      [PCl4]+  [PCl6]-

          [PCl4]+   ->  TETRAHEDRAL   (sp3)
          [PCl6]-   ->  OCTAHEDRAL    (sp3d2)

     Solid PBr5 is different:  [PBr4]+ Br-
     (Br- is too big for six of them to fit around one P atom.)
```

```
  REACTIONS OF PCl5

  1.  HYDROLYSIS - it happens in TWO stages:

         PCl5 + H2O   -->  POCl3 + 2 HCl       (limited water)
         POCl3 + 3 H2O -->  H3PO4 + 3 HCl      (excess water)

         Overall:  PCl5 + 4 H2O  -->  H3PO4 + 5 HCl

  2.  WITH ALCOHOLS:

         C2H5OH + PCl5  -->  C2H5Cl + POCl3 + HCl

  3.  WITH CARBOXYLIC ACIDS:

         CH3COOH + PCl5  -->  CH3COCl + POCl3 + HCl

  4.  ON HEATING it decomposes:

         PCl5  --(heat)-->  PCl3 + Cl2

  5.  WITH METALS - it chlorinates them:

         2 Ag + PCl5  -->  2 AgCl  + PCl3
         Sn  + 2 PCl5 -->  SnCl4   + 2 PCl3
```

**WORKED EXAMPLE 10**

> **Q. Write the hydrolysis reactions of PCl3 and PCl5 and name the acids
> produced. (4 marks)**
>
> **ANSWER:**
>
> ```
>   PCl3 + 3 H2O  -->  H3PO3 + 3 HCl
>                      (PHOSPHOROUS acid, P in +3 - same as in PCl3)
>
>   PCl5 + H2O    -->  POCl3 + 2 HCl        (partial hydrolysis,
>                      phosphoryl chloride / phosphorus oxychloride)
>
>   POCl3 + 3 H2O -->  H3PO4 + 3 HCl
>                      (ORTHOPHOSPHORIC acid, P in +5 - same as in PCl5)
>
>   Overall:  PCl5 + 4 H2O  -->  H3PO4 + 5 HCl
>
>   NOTE: hydrolysis does NOT change the oxidation state of phosphorus.
>   PCl3 (+3) gives the +3 acid; PCl5 (+5) gives the +5 acid.
> ```

> **TRAP:** Do not write "PCl3 gives H3PO4". The oxidation state cannot change
> in a simple hydrolysis. **PCl3 → H3PO3** and **PCl5 → H3PO4**. Count the
> oxidation number to check yourself every time.

# TOPIC 14 — Oxoacids of phosphorus

An **oxoacid** is an acid containing oxygen. Phosphorus makes several, and the
examiner loves asking about their **basicity**.

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE ONE RULE THAT ANSWERS EVERY QUESTION HERE:                     |
  |                                                                      |
  |     BASICITY  =  the number of  P - O - H  groups                    |
  |                  (that is, the number of  O-H  hydrogens)            |
  |                                                                      |
  |     A hydrogen bonded DIRECTLY to phosphorus  (a P-H bond)           |
  |     is NOT ionisable and does NOT count towards basicity.            |
  |     But P-H bonds DO make the acid a REDUCING AGENT.                 |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## The three that matter

```
  H3PO2   HYPOPHOSPHOROUS ACID          H3PO3   PHOSPHOROUS ACID
  P = +1                                P = +3

            O                                     O
            ||                                    ||
       H  - P - O - H                        H  - P - O - H
            |                                     |
            H                                     O
                                                  |
      1 (O-H)  ->  MONOBASIC                      H
      2 (P-H)  ->  STRONG REDUCING AGENT
                                            2 (O-H) ->  DIBASIC
                                            1 (P-H) ->  REDUCING AGENT


  H3PO4   ORTHOPHOSPHORIC ACID
  P = +5
            O
            ||
     H - O -P - O - H          3 (O-H)  ->  TRIBASIC
            |                  0 (P-H)  ->  NOT a reducing agent
            O
            |
            H
```

| ACID | FORMULA | OX. STATE OF P | O–H BONDS | P–H BONDS | BASICITY | REDUCING? |
|---|---|---|---|---|---|---|
| Hypophosphorous | H3PO2 | +1 | 1 | 2 | **Mono**basic | Yes, strongly |
| Phosphorous | H3PO3 | +3 | 2 | 1 | **Di**basic | Yes |
| Orthophosphoric | H3PO4 | +5 | 3 | 0 | **Tri**basic | **No** |
| Pyrophosphoric | H4P2O7 | +5 | 4 | 0 | Tetrabasic | No |
| Metaphosphoric | (HPO3)n | +5 | n | 0 | — | No |
| Hypophosphoric | H4P2O6 | +4 | 4 | 0 | Tetrabasic | — |

```
  H3PO2 AS A REDUCING AGENT  (it reduces silver salts to silver metal)

     4 AgNO3 + 2 H2O + H3PO2  -->  4 Ag + 4 HNO3 + H3PO4

  DISPROPORTIONATION OF H3PO3 ON HEATING  (a favourite 2-mark equation)

     4 H3PO3  --(heat)-->  3 H3PO4 + PH3

     P goes from +3  to  +5 (in H3PO4)  and  to  -3 (in PH3).
     Both up and down at once = DISPROPORTIONATION.
```

**WORKED EXAMPLE 11**

> **Q. H3PO3 contains three hydrogen atoms but is only dibasic. Explain.
> (2 marks)**
>
> **ANSWER:**
>
> ```
>   In H3PO3 only TWO of the three hydrogen atoms are attached to oxygen
>   as O-H (P-O-H) groups. The third hydrogen is bonded DIRECTLY to
>   phosphorus (a P-H bond).
>
>   Only hydrogen attached to a highly electronegative oxygen can ionise
>   and be replaced by a metal. The P-H hydrogen is not acidic because
>   P and H have nearly the same electronegativity.
>
>   Hence H3PO3 releases only two protons and is DIBASIC.
> ```

> **TRAP:** Basicity is **never** "the number of hydrogens in the formula". Draw
> the structure, count the **O–H** groups, and answer from the drawing. This
> single habit protects you in every acid question in the paper.

## Occurrence

| ELEMENT | WHERE FOUND | FORMULA |
|---|---|---|
| O | Free in air (20.9 % by volume); most abundant element of the earth's crust (~46.6 % by mass) | O2 |
| S | Free (volcanic regions); gypsum | CaSO4.2H2O |
| S | Epsom salt | MgSO4.7H2O |

## Trends

| PROPERTY | TREND | REASON / NOTE |
|---|---|---|
| Atomic radius | INCREASES down | New shell added each time |
| Ionisation enthalpy | DECREASES down | Bigger and better shielded |
| **Compared with Group 15** | Group 16 IE is **LOWER** than Group 15 | Group 15 has the extra-stable half-filled np3 |
| Electronegativity | DECREASES down | O is the **second most electronegative element** after F |
| Electron gain enthalpy | **O is LESS negative than S** | O is so small that the incoming electron is repelled by the electrons already crowded in the tiny 2p shell |
| Melting/boiling point | INCREASE up to Te, then fall at Po | Bigger molecules, stronger van der Waals forces |
| Metallic character | INCREASES down | O, S non-metal; Se, Te metalloid; Po metal |
| Catenation | S > Se > Te; O only forms peroxides | S–S bond is strong; O–O is weak |

## Oxidation states

```
     -2   in oxides and sulphides (O2-, S2-)
     +2   in SF2, OF2
     +4   in SO2, SeO2, TeO2
     +6   in SO3, H2SO4, SF6

  OXYGEN IS THE EXCEPTION:  it shows only -2 (and -1 in peroxides,
  -1/2 in superoxides, and +2 in OF2). It CANNOT show +4 or +6,
  because it has NO d ORBITALS to expand its octet, and because
  only F is more electronegative than O.

  The stability of the +6 state DECREASES down the group and +4
  becomes more stable, because of the INERT PAIR EFFECT.
```

## Anomalous behaviour of oxygen

| POINT | OXYGEN | SULPHUR AND BELOW |
|---|---|---|
| State | Gas, diatomic O2 | Solid, S8 rings |
| Bonding | p-pi–p-pi double bond (O=O) | Only single bonds; catenates into S8 |
| d orbitals | **Absent** — maximum covalency 4 | Present — SF6, H2SO4 with covalency 6 |
| Max oxidation state | Only −2 (basically) | +6 available |
| Hydride | H2O is a **liquid**, hydrogen bonded | H2S is a gas |
| Catenation | Very poor | Very good |

**WORKED EXAMPLE 12**

> **Q. The electron gain enthalpy of oxygen is less negative than that of
> sulphur. Why? (2 marks)**
>
> **ANSWER:**
>
> ```
>   The oxygen atom is very small, so its 2p subshell is already very
>   compact and crowded with electrons. An extra electron entering that
>   small shell experiences strong ELECTRON-ELECTRON REPULSION, and
>   this cancels much of the energy released.
>
>   Sulphur is larger, its 3p subshell is roomier, and the incoming
>   electron feels much less repulsion. Hence sulphur releases more
>   energy and its electron gain enthalpy is more negative.
> ```

> **TRAP:** The identical argument explains why **fluorine's** electron gain
> enthalpy is less negative than **chlorine's**. It is the same one-mark idea
> reused in Group 17. Learn it once, use it twice.

# TOPIC 16 — Hydrides of Group 16

```
   H2O ,  H2S ,  H2Se ,  H2Te ,  H2Po

   SHAPE OF ALL OF THEM:  BENT / ANGULAR / V-SHAPED
   (2 bond pairs + 2 lone pairs on the central atom)

                    ..  ..     <- two lone pairs
                     \  /
                      O
                    /   \
                   H     H      H-O-H = 104.5 degrees
```

| PROPERTY | ORDER | REASON |
|---|---|---|
| **Bond angle** | H2O 104.5° > H2S 92.1° > H2Se 91° > H2Te 90° | Same as Group 15: electronegativity of the central atom falls, bond pairs move away and repel less. |
| **Thermal stability** | H2O > H2S > H2Se > H2Te > H2Po (DECREASES) | E–H bond length increases, bond enthalpy decreases down the group. |
| **Acidic character** | H2O < H2S < H2Se < H2Te (INCREASES) | Weaker E–H bond → the proton is released more easily. |
| **Reducing character** | H2O < H2S < H2Se < H2Te (INCREASES) | Weaker bonds break more easily. |
| **Boiling point** | H2S < H2Se < H2Te < H2O | Normally rises with size, but **H2O jumps to the top because of hydrogen bonding**. |
| Volatility | H2S is the most volatile | Weakest intermolecular forces |

```
  WHY IS WATER A LIQUID BUT H2S A GAS?   (a certain 2-mark question)

     Oxygen is small and very electronegative, so the O-H bond is
     strongly polar and water molecules bind to one another by
     HYDROGEN BONDS. A water molecule is held by up to four such bonds.
     Breaking that network takes a lot of energy, so water boils at
     373 K and is a LIQUID at room temperature.

     Sulphur is much larger and far less electronegative, so H2S
     CANNOT hydrogen bond. Only weak van der Waals forces hold H2S
     molecules together, so it boils at 212.8 K and is a GAS.
```

```
  ACIDITY EXPLAINED PROPERLY  (do not get this backwards)

     Acid strength depends on how easily the  H-E  bond BREAKS.

        H-O  bond   ->  short and STRONG    ->  hard to break -> weak acid
        H-Te bond   ->  long and WEAK       ->  easy to break -> stronger acid

     So acid strength INCREASES down the group even though
     electronegativity DECREASES. Bond strength wins, not
     electronegativity. This is the same reason HF < HCl < HBr < HI.
```

# TOPIC 17 — Dioxygen and the classification of oxides

## 17.1 Preparation of dioxygen

```
  1.  Heating oxygen-rich salts with a catalyst:

  2.  Decomposition of hydrogen peroxide:

```

## 17.2 CLASSIFICATION OF OXIDES — a standard 4-mark answer

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  1. ACIDIC OXIDES                                                    |
  |     Dissolve in water to give ACIDS; react with bases to give salts. |
  |     Formed by NON-METALS.                                            |
  |        SO2 , SO3 , CO2 , N2O5 , P4O10 , Cl2O7                        |
  |        SO2 + H2O -> H2SO3        CO2 + 2NaOH -> Na2CO3 + H2O         |
  |                                                                      |
  |  2. BASIC OXIDES                                                     |
  |     Dissolve in water to give BASES; react with acids to give salts. |
  |     Formed by METALS (especially s-block).                           |
  |        Na2O , CaO , MgO , BaO , K2O                                  |
  |        CaO + H2O -> Ca(OH)2      Na2O + 2HCl -> 2NaCl + H2O          |
  |                                                                      |
  |  3. AMPHOTERIC OXIDES                                                |
  |     React with BOTH acids AND bases.                                 |
  |        Al2O3 , ZnO , PbO , SnO , BeO                                 |
  |                                                                      |
  |        Al2O3 + 6 HCl + 9 H2O  -->  2 [Al(H2O)6]Cl3                   |
  |        Al2O3 + 6 NaOH + 3 H2O -->  2 Na3[Al(OH)6]                    |
  |                                                                      |
  |  4. NEUTRAL OXIDES                                                   |
  |     Neither acidic nor basic. No reaction with acid or base.         |
  |        CO , NO , N2O , H2O (nearly)                                  |
  |                                                                      |
  |  5. MIXED OXIDES  (extra, sometimes asked)                           |
  |     Behave as if made of two simpler oxides.                         |
  |        Pb3O4 = 2PbO + PbO2     Fe3O4 = FeO + Fe2O3                   |
  |                                                                      |
  |  6. PEROXIDES and SUPEROXIDES                                        |
  |        Na2O2 (peroxide, O2 2-)   KO2 (superoxide, O2 -)              |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  THE PATTERN TO REMEMBER

     METAL oxide      ->  usually BASIC
     NON-METAL oxide  ->  usually ACIDIC
     METALLOID / borderline metal oxide  ->  often AMPHOTERIC

     ACROSS a period, oxides go BASIC -> AMPHOTERIC -> ACIDIC
         Na2O   MgO   Al2O3   SiO2   P4O10   SO3   Cl2O7
         basic  basic amphot. acidic acidic  acidic acidic

     DOWN a group, oxides become MORE BASIC
     (because metallic character increases)
```

**WORKED EXAMPLE 13**

> **Q. What are amphoteric oxides? Give two examples with equations.
> (2 marks)**
>
> **ANSWER:**
>
> ```
>   Oxides that react with BOTH acids and bases to form salt and water
>   are called AMPHOTERIC OXIDES.
>
>   Example 1 - Al2O3:
>       Al2O3 + 6 HCl   -->  2 AlCl3 + 3 H2O          (behaves as a base)
>       Al2O3 + 2 NaOH  -->  2 NaAlO2 + H2O           (behaves as an acid)
>
>   Example 2 - ZnO:
>       ZnO + 2 HCl     -->  ZnCl2 + H2O

> ```

# TOPIC 18 — OZONE (O3)

## Preparation

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |     3 O2  --(SILENT ELECTRIC DISCHARGE)-->  2 O3                     |
  |                                                                      |
  |     dH = +142 kJ/mol   (ENDOTHERMIC)                                 |
  |                                                                      |
  |     A "silent" (soundless) discharge is used because ordinary        |
  |     sparking produces HEAT, and heat decomposes the ozone back       |
  |     to oxygen.                                                       |
  |                                                                      |
  |     Only about 10 % of the oxygen is converted, giving               |
  |     "OZONISED OXYGEN".                                               |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## Structure

```
                    O
                   / \                Bond angle  =  117 degrees
                  /   \               Both O-O bonds  =  128 pm  (EQUAL)
                 O     O              Central O is  sp2  hybridised
                                      Shape: ANGULAR / BENT
                117 deg

  WHY ARE BOTH BONDS EQUAL?  Because ozone is a RESONANCE HYBRID:

        O                O                  the real molecule is
       / \\      <-->   // \                 neither structure; it is
      O    O           O    O                the average of both, so
     single double     double single         both bonds are identical
                                             (intermediate between a
                                              single and a double bond)
```

## Properties

```
  PHYSICAL
     Pale blue gas, dark blue liquid, violet-black solid.
     Characteristic pungent smell (you smell it near sparking machines).
     In small amounts it is harmless; in larger amounts it causes
     headache and nausea.

  THERMODYNAMICS
     Its formation is ENDOTHERMIC (dH = +142 kJ/mol) and dG is positive,
     so ozone is THERMODYNAMICALLY UNSTABLE and decomposes back to O2.
     Concentrated ozone is EXPLOSIVE.
```

## Ozone as a powerful oxidising agent

```
  The reason ozone oxidises so strongly:

        O3  -->  O2 + [O]        it easily gives up ONE nascent
                                 oxygen atom, which is a fierce oxidiser

  THE STANDARD REACTIONS

  1.  With potassium iodide - the TEST FOR OZONE:

         2 KI + H2O + O3  -->  2 KOH + I2 + O2

         The liberated iodine turns STARCH-IODIDE PAPER BLUE.

  2.  With mercury - "TAILING OF MERCURY":

         Ozone makes mercury lose its meniscus and stick to glass,
         because Hg2O is formed on the surface.

  3.  Oxidises lead sulphide to lead sulphate (used to restore
      blackened old paintings):

         PbS + 4 O3  -->  PbSO4 + 4 O2

  4.  Oxidises ferrous to ferric, sulphite to sulphate, nitrite to
      nitrate:

         O3 + 2 Fe2+ + 2 H+  -->  2 Fe3+ + H2O + O2
```

## Estimation of ozone

```
     O3 + 2 KI + H2O  -->  2 KOH + I2 + O2

  The liberated I2 is titrated against standard sodium thiosulphate.
```

## Ozone in the atmosphere — the ozone hole

```
  GOOD OZONE (stratosphere, 20-35 km up) shields the earth from
  harmful ULTRAVIOLET radiation, which causes skin cancer and
  damages plants.

  IT IS DESTROYED BY:

     (a) NITRIC OXIDE from high-flying jet aircraft:

            NO + O3  -->  NO2 + O2

     (b) CHLOROFLUOROCARBONS (freons) from refrigerators and aerosols.
         UV light breaks them and frees chlorine atoms, and one Cl
         atom destroys thousands of ozone molecules:

            CF2Cl2  --(UV)-->  Cl. + .CF2Cl
            Cl. + O3  -->  ClO. + O2
            ClO. + O -->  Cl. + O2      (the Cl. is regenerated!)
```

## Uses of ozone

```
  - Germicide and DISINFECTANT for sterilising drinking water
  - Bleaching oils, ivory, flour, starch, delicate fabrics
  - In the manufacture of potassium permanganate
  - As an oxidising agent in organic chemistry (OZONOLYSIS, which
    tells you where a double bond sits in an alkene)
```

**WORKED EXAMPLE 14**

> **Q. Ozone is thermodynamically unstable with respect to oxygen. Justify.
> (2 marks)**
>
> **ANSWER:**
>
> ```
>   For the conversion  3 O2 --> 2 O3 ,   dH = +142 kJ/mol and dG is
>   also POSITIVE. The reverse reaction  2 O3 --> 3 O2  therefore has a
>   large NEGATIVE dG and a large negative dH, so it is spontaneous and
>   releases heat.
>
>   Because of this ozone decomposes readily to oxygen, and once
>   started the heat released speeds up the decomposition further -
>   which is why concentrated ozone is EXPLOSIVE.
> ```

> **TRAP:** Do not write "the ozone layer is bad for us". The **stratospheric**
> ozone layer protects us; **ground-level** ozone is a pollutant. If the
> question mentions the ozone hole, it is the protective layer being destroyed.

# TOPIC 19 — Allotropes of sulphur

```
  Sulphur has many allotropes, but only TWO are stable enough to matter:

     RHOMBIC SULPHUR  =  alpha-sulphur     (also called octahedral)
     MONOCLINIC SULPHUR = beta-sulphur     (also called prismatic)
```

| PROPERTY | RHOMBIC (α) | MONOCLINIC (β) |
|---|---|---|
| Colour | Yellow | Colourless / pale yellow |
| Shape of crystals | Octahedral | Needle shaped, prismatic |
| Melting point | 385.8 K | 393 K |
| Density | 2.06 g/cm3 | 1.98 g/cm3 |
| Solubility in CS2 | Soluble | Soluble |
| Stable | **Below 369 K** | **Above 369 K** |
| How prepared | Evaporating a solution of roll sulphur in CS2 | Melting rhombic S in a dish, cooling till a crust forms, piercing the crust and draining the liquid |

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   TRANSITION TEMPERATURE  =  369 K   (96 degrees C)                  |
  |                                                                      |
  |      RHOMBIC (alpha)   <==(369 K)==>   MONOCLINIC (beta)             |
  |                                                                      |
  |   At exactly 369 K the two forms are in equilibrium and are          |
  |   equally stable. That temperature is called the TRANSITION          |
  |   TEMPERATURE. This is a 2-mark question on its own.                 |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## Structure — BOTH forms contain the S8 CROWN

```
  THE S8 PUCKERED RING  ("crown shaped")

           S ----- S
          /         \                  8 sulphur atoms in a ring
         S           S                 The ring is NOT flat - it is
         |           |                 PUCKERED, like a crown.
         S           S
          \         /                  S-S bond length = 204 pm
           S ----- S                   S-S-S bond angle = 105 degrees

     BOTH rhombic and monoclinic sulphur are built from S8 rings.
     They differ only in HOW THE RINGS ARE PACKED in the crystal.
```

```
  OTHER FORMS WORTH A LINE

     S6  -  "engel's sulphur", a CHAIR-shaped six-membered ring.

     S2  -  at about 1000 K sulphur vapour contains S2 molecules.
            S2, like O2, has TWO UNPAIRED ELECTRONS in antibonding
            pi* orbitals, so S2 is PARAMAGNETIC.
            (This is a favourite trick question: sulphur vapour is
             paramagnetic at high temperature.)
```

**WORKED EXAMPLE 15**

> **Q. What is the transition temperature of sulphur? Which allotrope is
> stable at room temperature? (2 marks)**
>
> **ANSWER:**
>
> ```
>   The transition temperature of sulphur is 369 K (96 deg C). At this
>   temperature rhombic and monoclinic sulphur are in equilibrium and
>   are equally stable.
>
>   Room temperature (about 298 K) is BELOW 369 K, so RHOMBIC
>   (alpha) SULPHUR is the stable form at room temperature.
> ```

# TOPIC 20 — Sulphur dioxide (SO2)

## Preparation

```
  1.  Burning sulphur in air:           S + O2  -->  SO2

  2.  Roasting sulphide ores (industrial):

         4 FeS2 + 11 O2  --(heat)-->  2 Fe2O3 + 8 SO2

  3.  LABORATORY - a sulphite plus a dilute acid:

         Na2SO3 + H2SO4  -->  Na2SO4 + H2O + SO2

  4.  Copper with hot concentrated sulphuric acid:

         Cu + 2 H2SO4(conc)  -->  CuSO4 + SO2 + 2 H2O
```

## Structure

```
                    ..           <- one lone pair on sulphur
                    S
                  //  \\
                 O      O        Bond angle = 119.5 degrees
                                 Shape: ANGULAR / BENT
              119.5 deg          Hybridisation: sp2
                                 Both S-O bonds are EQUAL (resonance)

     Like ozone, SO2 is a RESONANCE HYBRID, so both S-O bonds have
     the same length even though a single Lewis picture shows one
     double and one dative bond.
```

## Properties

```
  PHYSICAL
     Colourless gas with a suffocating, choking smell.
     Highly soluble in water.
     Easily liquefied (b.p. 263 K); liquid SO2 is a solvent.
     POISONOUS - and a major air pollutant that causes ACID RAIN.

  CHEMICAL

  1.  ACIDIC OXIDE - dissolves in water to give sulphurous acid:

         SO2 + H2O  <=>  H2SO3

         SO2 + 2 NaOH  -->  Na2SO3 + H2O

  2.  REDUCING AGENT in the presence of moisture (S goes +4 -> +6):

         SO2 + 2 H2O + Cl2  -->  H2SO4 + 2 HCl
         5 SO2 + 2 KMnO4 + 2 H2O  -->  K2SO4 + 2 MnSO4 + 2 H2SO4
              (this DECOLOURISES acidified KMnO4 - the TEST for SO2)

  3.  Turns acidified potassium dichromate solution from
      ORANGE to GREEN.
```

## BLEACHING ACTION OF SO2 — and why it is TEMPORARY

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   SO2 + 2 H2O  -->  H2SO4 + 2 [H]        nascent HYDROGEN            |
  |                                                                      |
  |   coloured substance + 2 [H]  -->  colourless substance              |
  |                                                                      |
  |   SO2 BLEACHES BY REDUCTION.                                         |
  |                                                                      |
  |   The bleaching is TEMPORARY, because on standing in air the         |
  |   colourless (reduced) product is OXIDISED BACK by the oxygen        |
  |   of the air, and the colour RETURNS.                                |
  |                                                                      |
  |   COMPARE WITH CHLORINE:                                             |
  |                                                                      |
  |      Cl2 bleaches by OXIDATION  ->  PERMANENT                        |
  |      SO2 bleaches by REDUCTION  ->  TEMPORARY                        |
  |                                                                      |
  |   Because it is gentle, SO2 is used to bleach delicate things that   |
  |   chlorine would destroy: WOOL, SILK, STRAW, PAPER PULP.             |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## Uses of SO2

```
  - Manufacture of sulphuric acid (Contact process)
  - Bleaching wool, silk and straw
  - As a disinfectant, fumigant and food preservative
  - Refining petroleum and sugar
  - Liquid SO2 as a solvent and a refrigerant
```

> **TRAP:** "SO2 bleaches by oxidation" is wrong and is the most common error in
> this topic. Chlorine oxidises; sulphur dioxide **reduces**. Get the pair the
> right way round and you also get the permanent/temporary distinction right.

# TOPIC 22 — Sulphuric acid and the CONTACT PROCESS

**The third of the three big 8-mark processes. H2SO4 is called the "KING OF
CHEMICALS" because a country's industrial strength used to be measured by how
much of it the country consumed.**

## 22.1 THE CONTACT PROCESS

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  STEP 1  BURN SULPHUR OR ROAST PYRITES TO GET SO2                    |
  |                                                                      |
  |      S + O2  -->  SO2                                                |
  |      or     4 FeS2 + 11 O2  -->  2 Fe2O3 + 8 SO2                     |
  |                                                                      |
  |      THE GAS MUST BE PURIFIED - dust, arsenic compounds and          |
  |      moisture would POISON the catalyst.                             |
  |                                                                      |
  |  STEP 2  CATALYTIC OXIDATION OF SO2 TO SO3  (the key step)           |
  |                                                                      |
  |      2 SO2(g) + O2(g)  <==>  2 SO3(g)     dH = -196.6 kJ/mol         |
  |                                                                      |
  |      Catalyst    :  VANADIUM PENTOXIDE  V2O5                         |
  |      Temperature :  720 K                                            |
  |      Pressure    :  2 bar                                            |
  |                                                                      |
  |  STEP 3  ABSORB SO3 IN CONCENTRATED H2SO4 TO GIVE OLEUM              |
  |                                                                      |
  |      SO3 + H2SO4  -->  H2S2O7     (OLEUM, fuming sulphuric acid)     |
  |                                                                      |
  |  STEP 4  DILUTE THE OLEUM WITH WATER                                 |
  |                                                                      |
  |      H2S2O7 + H2O  -->  2 H2SO4          purity 96 - 98 %            |
  |                                                                      |

  WHY IS SO3 NOT ABSORBED DIRECTLY IN WATER?   (guaranteed 2-mark question)

## 22.3 THE THREE FACES OF SULPHURIC ACID

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  FACE 1 :  A STRONG DIBASIC ACID                                     |
  |                                                                      |
  |      It ionises in TWO steps:                                        |
  |         H2SO4 + H2O  -->  H3O+ + HSO4-      (complete, very strong)  |
  |         HSO4- + H2O  <=>  H3O+ + SO4 2-     (Ka2 = 1.2 x 10^-2)      |
  |                                                                      |
  |      So it forms TWO series of salts:                                |
  |         NaHSO4  (sodium hydrogen sulphate / bisulphate)              |
  |         Na2SO4  (sodium sulphate - normal salt)                      |
  |                                                                      |
  |      Being a HIGH BOILING acid, it displaces more volatile acids     |
  |      from their salts:                                               |
  |         2 NaCl  + H2SO4  -->  Na2SO4 + 2 HCl                         |
  |         2 KNO3  + H2SO4  -->  K2SO4  + 2 HNO3                        |
  |                                                                      |
  |  FACE 2 :  AN OXIDISING AGENT  (hot and concentrated)                |
  |                                                                      |
  |      Cu + 2 H2SO4  -->  CuSO4 + SO2 + 2 H2O                          |
  |      C  + 2 H2SO4  -->  CO2   + 2 SO2 + 2 H2O                        |
  |      S  + 2 H2SO4  -->  3 SO2 + 2 H2O                                |
  |                                                                      |
  |      (in every case S is reduced from +6 to +4)                      |
  |                                                                      |
  |  FACE 3 :  A DEHYDRATING AGENT                                       |
  |                                                                      |
  |      It has such a strong affinity for water that it rips the        |
  |      elements of water OUT of other compounds.                       |
  |                                                                      |
  |      SUGAR turns into a black spongy mass of CARBON:                 |
  |         C12H22O11  --(conc H2SO4)-->  12 C + 11 H2O                  |
  |                                                                      |
  |      FORMIC acid  -> carbon monoxide:                                |
  |         HCOOH  --(conc H2SO4)-->  CO + H2O                           |
  |                                                                      |
  |      OXALIC acid -> CO and CO2:                                      |
  |         (COOH)2  --(conc H2SO4)-->  CO + CO2 + H2O                   |
  |                                                                      |
  |      Blue copper sulphate crystals turn WHITE:                       |
  |         CuSO4.5H2O  --(conc H2SO4)-->  CuSO4 + 5 H2O                 |

```

```

```
  "HALOGEN" means SALT PRODUCER. All of them are DIATOMIC (X2)
  and all are COLOURED. The colour deepens down the group because
  the bigger molecules absorb light of longer wavelength.
```

## Occurrence

| ELEMENT | SOURCE | FORMULA |
|---|---|---|
| F | Fluorspar / fluorite | CaF2 |
| F | Cryolite | Na3AlF6 |
| F | Fluorapatite | 3Ca3(PO4)2.CaF2 |
| Cl | Rock salt, sea water | NaCl |
| Cl | Carnallite | KCl.MgCl2.6H2O |
| Br | Bromides in sea water and salt lakes | — |
| I | Sea weeds; sodium iodate in Chile saltpetre | NaIO3 |

## Trends

| PROPERTY | TREND | NOTE |
|---|---|---|
| Atomic / ionic radius | INCREASES down | **Halogens have the SMALLEST atomic radius in their period** |
| Ionisation enthalpy | DECREASES down | Halogens have **very high** IE (they do not want to lose electrons) |
| Electronegativity | DECREASES down | **F is the most electronegative element of all** |
| Electron gain enthalpy | Cl > F > Br > I (most negative is **Cl**) | F is the exception, due to its tiny size and electron–electron repulsion |
| Bond dissociation enthalpy of X2 | Cl2 > Br2 > F2 > I2 | **F2 is abnormally LOW** — see below |
| Melting / boiling point | INCREASE down | Bigger molecules → stronger van der Waals forces |
| Oxidising power | F2 > Cl2 > Br2 > I2 (DECREASES) | F2 is the **strongest oxidising agent known** |

```
  WHY IS F2 SUCH A STRONG OXIDISING AGENT DESPITE ITS ODD egH?
  Three things add up:

     (1) LOW bond dissociation enthalpy of F2 (158.8 kJ/mol) -
         the F-F bond snaps easily,
     (2) high electronegativity,
     (3) VERY HIGH hydration enthalpy of the small F- ion.

     Together these make the overall reduction of F2 to F-
     enormously favourable.
```

## THE FLUORINE ANOMALIES — a standard 4-mark answer

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  WHY FLUORINE IS DIFFERENT:                                          |
  |     - smallest size                                                  |
  |     - highest electronegativity                                      |
  |     - NO d ORBITALS in the valence shell                             |
  |     - very LOW F-F bond dissociation enthalpy                        |
  |                                                                      |
  |  THE SIX CONSEQUENCES YOU SHOULD LIST:                               |
  |                                                                      |
  |  1. Fluorine shows ONLY the -1 oxidation state. The others show      |
  |     +1, +3, +5, +7 as well, because they have d orbitals.            |
  |                                                                      |
  |  2. HF is a LIQUID (b.p. 293 K) while HCl, HBr, HI are gases,        |
  |     because of HYDROGEN BONDING in HF.                               |
  |                                                                      |
  |  3. HF is a WEAK acid; HCl, HBr, HI are strong acids.                |
  |     (The H-F bond is very strong and hard to break.)                 |
  |                                                                      |
  |  4. The electron gain enthalpy of F is LESS negative than that of    |
  |     Cl, because of electron-electron repulsion in the small 2p shell.|
  |                                                                      |
  |  5. AgF is SOLUBLE in water, while AgCl, AgBr and AgI are            |
  |     INSOLUBLE. (Reverse of the usual pattern.)                       |
  |     CaF2 is INSOLUBLE, while CaCl2, CaBr2, CaI2 are SOLUBLE.         |
  |                                                                      |
  |  6. Fluorine cannot form polyhalide ions like I3-, and it forms no   |
  |     oxoacids except HOF.                                             |
  |                                                                      |
  +----------------------------------------------------------------------+
```

**WORKED EXAMPLE 17**

> **Q. The bond dissociation enthalpy of F2 is lower than that of Cl2. Why?
> (2 marks)**
>
> **ANSWER:**
>
> ```
>   The fluorine atom is extremely small, so in the F2 molecule the two
>   nuclei and their LONE PAIRS are forced very close together. The
>   strong repulsion between the lone pairs on the two fluorine atoms
>   weakens the F-F bond.
>
>   Chlorine atoms are larger, the lone pairs are farther apart and the
>   repulsion is much smaller, so the Cl-Cl bond is stronger.
>
>   Hence:  Cl2 (242.6) > Br2 (192.8) > F2 (158.8) > I2 (151.1) kJ/mol.
> ```

> **TRAP:** The full order **Cl2 > Br2 > F2 > I2** is the answer, not
> "F2 < Cl2 < Br2 < I2". F2 sits out of place, and I2 is still the lowest
> because its bond is long. Memorise the order as written.

# TOPIC 24 — Hydrogen halides (HF, HCl, HBr, HI)

| PROPERTY | ORDER | REASON |
|---|---|---|
| Acid strength | HF < HCl < HBr < HI (INCREASES) | H–X bond gets longer and weaker down the group, so H+ is released more easily |
| Thermal stability | HF > HCl > HBr > HI (DECREASES) | Bond dissociation enthalpy falls: HF 574 > HCl 432 > HBr 363 > HI 295 kJ/mol |
| Boiling point | HCl < HBr < HI < **HF** | Rises with molecular size, but **HF jumps to the top** because it is hydrogen bonded |
| Reducing power | HF < HCl < HBr < HI (INCREASES) | Weaker bond → gives up H more easily |

```
  WHY IS HF A WEAK ACID BUT HI A STRONG ONE?

     Acidity depends on how easily the H-X bond BREAKS, NOT on the
     electronegativity of X.

        H-F   574 kJ/mol   very strong bond   ->  hardly ionises  -> WEAK
        H-I   295 kJ/mol   weak bond          ->  ionises fully   -> STRONG

     Additionally, in HF the H-F...H-F hydrogen bonding holds the
     molecules together and forms the stable HF2- ion, which further
     reduces the free H+ available.
```

```
  HF ATTACKS GLASS - a 2-mark fact worth remembering:

     SiO2 + 4 HF   -->  SiF4 + 2 H2O
     Na2SiO3 + 6 HF -->  Na2SiF6 + 3 H2O

     That is why HF is stored in WAX-COATED bottles or plastic
     containers, and why it is used for ETCHING GLASS.
```

# TOPIC 25 — Chlorine: preparation, bleaching, uses

## Preparation

```
  1.  LABORATORY - manganese dioxide with concentrated HCl:

        MnO2 + 4 HCl  --(heat)-->  MnCl2 + Cl2 + 2 H2O

  2.  From common salt (cheaper laboratory version):

        4 NaCl + MnO2 + 4 H2SO4 --> MnCl2 + 4 NaHSO4 + 2 H2O + Cl2

  3.  From bleaching powder:

        CaOCl2 + 2 HCl  -->  CaCl2 + H2O + Cl2

  4.  DEACON'S PROCESS (industrial, from waste HCl):

        4 HCl + O2  --(CuCl2, 723 K)-->  2 Cl2 + 2 H2O

  5.  ELECTROLYTIC - the main industrial source. Electrolysis of brine
      gives Cl2 at the ANODE (and NaOH + H2 as by-products).
      This is the chlor-alkali industry.
```

## Properties

```
  PHYSICAL
     Greenish yellow gas with a sharp, choking, suffocating smell.
     About 2.5 times heavier than air. Poisonous.
     Soluble in water, giving CHLORINE WATER.
     Easily liquefied (b.p. 239 K).

  CHEMICAL

  1.  With water:   Cl2 + H2O  -->  HCl + HOCl   (hypochlorous acid)

  2.  With COLD DILUTE alkali:

        Cl2 + 2 NaOH(cold, dilute)  -->  NaCl + NaOCl + H2O

  3.  With HOT CONCENTRATED alkali:

        3 Cl2 + 6 NaOH(hot, conc.)  -->  5 NaCl + NaClO3 + 3 H2O

      (Both are DISPROPORTIONATIONS: Cl goes from 0 to -1 and to +1
       or +5 at the same time.)

  4.  With dry slaked lime - BLEACHING POWDER:

        Ca(OH)2 + Cl2  -->  CaOCl2 + H2O
                            bleaching powder

  5.  With ammonia:

        excess NH3 :   8 NH3 + 3 Cl2  -->  N2 + 6 NH4Cl
        excess Cl2 :   NH3 + 3 Cl2    -->  NCl3 + 3 HCl
                                            (explosive)

  6.  With hydrocarbons - substitution:

        CH4 + Cl2  --(sunlight)-->  CH3Cl + HCl
```

## BLEACHING ACTION OF CHLORINE

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |     Cl2 + H2O   -->  2 HCl + [O]        nascent OXYGEN               |
  |     (via  Cl2 + H2O -> HCl + HOCl ;  HOCl -> HCl + [O] )             |
  |                                                                      |
  |     coloured substance + [O]  -->  colourless substance              |
  |                                                                      |
  |     CHLORINE BLEACHES BY OXIDATION, so the bleaching is PERMANENT.   |
  |     The colour never comes back.                                     |
  |                                                                      |
  |     TWO IMPORTANT CONDITIONS:                                        |
  |       (a) MOISTURE IS ESSENTIAL. Dry chlorine does NOT bleach,       |
  |           because without water no HOCl and no [O] can form.         |
  |       (b) It is too harsh for delicate fibres like wool and silk,    |
  |           which it would destroy. Use SO2 for those.                 |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## Uses of chlorine

```
  - BLEACHING wood pulp (paper industry), cotton and textiles
  - STERILISING drinking water and swimming pools
  - Manufacture of dyes, drugs and organic compounds:
       CHCl3 , CCl4 , DDT , refrigerants
  - Extraction of gold and platinum
  - Manufacture of POISON GASES:
       phosgene (COCl2), tear gas (CCl3NO2), mustard gas (ClC2H4SC2H4Cl)
```

**WORKED EXAMPLE 18**

> **Q. Dry chlorine does not bleach a coloured flower but moist chlorine does.
> Explain. (2 marks)**
>
> **ANSWER:**
>
> ```
>   Chlorine bleaches by OXIDATION, using the nascent oxygen it
>   liberates from WATER:
>
>       Cl2 + H2O  -->  2 HCl + [O]
>       coloured matter + [O]  -->  colourless matter
>
>   Dry chlorine has no water available, so no nascent oxygen is
>   produced and no bleaching takes place. Moisture is therefore
>   essential for the bleaching action of chlorine.
> ```

# TOPIC 27 — Oxoacids of the halogens

```
  Fluorine forms only ONE oxoacid, HOF (hypofluorous acid), and even
  that is unstable. The reason: F has NO d ORBITALS and is the most
  electronegative element, so it cannot take a positive oxidation state.

  Cl, Br and I each form FOUR types.
```

| TYPE | GENERAL FORMULA | CHLORINE EXAMPLE | NAME | OX. STATE OF Cl |
|---|---|---|---|---|
| Hypohalous | HOX | HOCl | Hypochlorous acid | +1 |
| Halous | HOXO | HOClO (HClO2) | Chlorous acid | +3 |
| Halic | HOXO2 | HOClO2 (HClO3) | Chloric acid | +5 |
| Perhalic | HOXO3 | HOClO3 (HClO4) | Perchloric acid | +7 |

```
  ACID STRENGTH  -  down one element, as oxygen atoms are added:

     HOCl  <  HClO2  <  HClO3  <  HClO4        INCREASES

  WHY?  Each extra oxygen is highly electronegative and pulls electron
        density away from the O-H bond. The O-H bond therefore weakens
        and the proton comes off more easily. Also, the anion left
        behind spreads its negative charge over more oxygen atoms
        (better resonance stabilisation), so it is more stable.

        HClO4 is one of the STRONGEST acids known.


  ACID STRENGTH  -  across the halogens, same type:

     HOCl  >  HOBr  >  HOI                      DECREASES

  WHY?  Cl is the most electronegative of the three, so it pulls
        electron density away from O-H most strongly.
```

```
  OXIDISING POWER of the oxoacids goes the OTHER WAY:

     HOCl  >  HClO2  >  HClO3  >  HClO4         DECREASES

     The one with the fewest oxygens gives up its oxygen most readily.
```

> **TRAP:** Acid strength and oxidising power run in **opposite** directions.
> HClO4 is the strongest acid but the weakest oxidiser of the four; HOCl is the
> weakest acid but the strongest oxidiser. Do not mix these two ladders.

# TOPIC 28 — Interhalogen compounds

```
  DEFINITION:  compounds formed between TWO DIFFERENT HALOGENS,
               of general formula  X X'n   where n = 1, 3, 5 or 7,
               X is the LARGER (less electronegative) halogen and
               X' is the SMALLER (more electronegative) one.

  n is always an ODD number.
```

| TYPE | EXAMPLES | SHAPE | HYBRIDISATION | LONE PAIRS ON X |
|---|---|---|---|---|
| XX' | ClF, BrF, BrCl, ICl, IBr | **Linear** | sp3 | 3 |
| XX'3 | ClF3, BrF3, IF3, ICl3 | **Bent T-shaped** | sp3d | 2 |
| XX'5 | ClF5, BrF5, IF5 | **Square pyramidal** | sp3d2 | 1 |
| XX'7 | **IF7** | **Pentagonal bipyramidal** | sp3d3 | 0 |

```
  THE THREE SHAPES DRAWN OUT

  ClF3  BENT T-SHAPE (sp3d)          BrF5  SQUARE PYRAMIDAL (sp3d2)

            F                                     F
            |                                     |
            |                                     Br
       ..--Cl--..    <- 2 lone pairs            / /|\ \
            |          in the equatorial       F  F F  F
            |          plane                   (four F in a square plane,
            F                                   one F on top)
                                                + 1 lone pair below
     Angle slightly less than 90 deg
     because of lone pair repulsion


  IF7  PENTAGONAL BIPYRAMIDAL (sp3d3)

               F
               |
          F    |    F
            \  |  /
             \ | /
        F-----(I)-----F        five F in a PENTAGON around the middle,
             / | \             two F above and below
            /  |  \
          F    |    F
               |
               F
```

```
  WHY ARE INTERHALOGENS MORE REACTIVE THAN THE HALOGENS?
  (except F2, which is the most reactive substance of all)

     The X-X' bond is between two DIFFERENT atoms of different size
     and electronegativity, so it is POLAR and WEAKER than the
     X-X bond in an ordinary halogen molecule.
     A weaker bond breaks more easily  ->  more reactive.
```

```
  PROPERTIES AND USES

     - All are covalent, mostly volatile solids or liquids
       (except ClF which is a gas).
     - They hydrolyse to give a halide ion of the SMALLER halogen and
       an oxoacid of the LARGER one:

           ClF3 + 2 H2O  -->  3 HF + HClO2

     - Used as FLUORINATING AGENTS.
     - ClF3 and BrF3 are used to make UF6 for the enrichment of uranium:

           U + 3 ClF3  -->  UF6 + 3 ClF
```

**WORKED EXAMPLE 19**

> **Q. Give the shape and hybridisation of ClF3 and IF7. (2 marks)**
>
> **ANSWER:**
>
> ```
>   ClF3:
>     Cl has 7 valence electrons; 3 are used in bonding to 3 F atoms,
>     leaving 2 lone pairs. Total electron pairs = 5.
>     -> sp3d hybridisation, trigonal bipyramidal ELECTRON geometry.
>     The 2 lone pairs occupy equatorial positions, so the SHAPE is
>     BENT T-SHAPED.
>
>   IF7:
>     I has 7 valence electrons; all 7 are used in bonding to 7 F atoms,
>     leaving 0 lone pairs. Total electron pairs = 7.
>     -> sp3d3 hybridisation, shape is PENTAGONAL BIPYRAMIDAL.
> ```

> **TRAP:** "Electron geometry" and "shape" are different. ClF3 has a *trigonal
> bipyramidal electron geometry* but a *T-shaped molecular shape*. When the
> question says "shape", ignore the lone pairs in your final answer but count
> them when working out the hybridisation.

# TOPIC 29 — Group 18: why the noble gases do nothing

```
  ELEMENT     Z      CONFIGURATION            ABUNDANCE IN AIR
  ------------------------------------------------------------------
  He  (2)     2      1s2                      trace (found in natural gas)
  Ne  (10)   10      [He] 2s2 2p6             trace
  Ar  (18)   18      [Ne] 3s2 3p6             0.934 % - the MOST abundant
                                              noble gas in the atmosphere
  Kr  (36)   36      [Ar] 3d10 4s2 4p6        trace
  Xe  (54)   54      [Kr] 4d10 5s2 5p6        trace
  Rn  (86)   86      [Xe] 4f14 5d10 6s2 6p6   RADIOACTIVE, from the decay
                                              of radium
```

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   WHY ARE THE NOBLE GASES CHEMICALLY INERT?   (certain 2-mark Q)     |
  |                                                                      |
  |   1. Their outermost shell is COMPLETELY FILLED (ns2 np6, or 1s2     |
  |      for helium). This is the most stable arrangement possible.      |
  |                                                                      |
  |   2. They therefore have VERY HIGH IONISATION ENTHALPIES -           |
  |      the highest in their respective periods - so they will not      |
  |      lose an electron.                                               |
  |                                                                      |
  |   3. Their ELECTRON GAIN ENTHALPY IS POSITIVE (energy must be        |
  |      SUPPLIED to add an electron), so they will not gain one either. |
  |                                                                      |
  |   With no urge to lose, gain or share electrons, they do not bond.   |
  |   They exist as MONOATOMIC gases.                                    |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  OTHER TRENDS

     Atomic radius INCREASES down the group.
     Ionisation enthalpy DECREASES down the group
        (He has the HIGHEST IE of any element).
     Melting and boiling points INCREASE down the group
        (bigger atoms -> stronger dispersion forces).
     He has the LOWEST BOILING POINT of any known substance (4.2 K).
     Solubility in water increases down the group.
```

```
  WHY DOES ONLY XENON FORM COMPOUNDS?

     Xe is large, so its outer electrons are far from the nucleus and
     poorly shielded -> its ionisation enthalpy is LOW ENOUGH for a
     really greedy element to pull an electron away.

     And it does so ONLY with the two most electronegative and
     oxidising elements:  FLUORINE  and  OXYGEN.

     Radon would react even more readily, but it is intensely
     radioactive and short lived, so its chemistry is barely studied.

     HISTORY POINT: Neil Bartlett made the first noble gas compound
     in 1962. He noticed that O2 and Xe have almost the SAME ionisation
     enthalpy, and since PtF6 had oxidised O2 to give O2+[PtF6]-, he
     tried it with xenon and got Xe+[PtF6]-.
```

## 30.2 THE FIVE STRUCTURES — this is the 8-mark answer

```
  HOW TO WORK ANY OF THEM OUT (do this, do not just memorise):

     total electron pairs = (bond pairs) + (lone pairs)
     lone pairs on Xe = (8 - number of bonds) / 2      [Xe starts with 8]
```

```
  1.  XeF2      Xe makes 2 bonds -> lone pairs = (8-2)/2 = 3
                Total pairs = 2 + 3 = 5  ->  sp3d
                Electron geometry: trigonal bipyramidal
                3 lone pairs go EQUATORIAL  ->  SHAPE IS LINEAR

                     F
                     |
                     |          F - Xe - F  is a straight line
                 ..--Xe--..     (the three dots around Xe are the
                     |           three lone pairs in the equator)
                     |
                     F

                SHAPE: LINEAR        HYBRIDISATION: sp3d


  2.  XeF4      Xe makes 4 bonds -> lone pairs = (8-4)/2 = 2
                Total pairs = 4 + 2 = 6  ->  sp3d2
                Electron geometry: octahedral
                2 lone pairs go above and below  ->  SHAPE IS SQUARE PLANAR

                       ..           <- lone pair above
                  F         F
                    \     /
                      Xe            all F-Xe-F angles = 90 degrees
                    /     \
                  F         F
                       ..           <- lone pair below

                SHAPE: SQUARE PLANAR   HYBRIDISATION: sp3d2


  3.  XeF6      Xe makes 6 bonds -> lone pairs = (8-6)/2 = 1
                Total pairs = 6 + 1 = 7  ->  sp3d3
                SHAPE: DISTORTED OCTAHEDRAL
                (the single lone pair pushes the octahedron out of shape)

                        F   F
                         \ /
                     F -- Xe -- F        + 1 LONE PAIR sticking out
                         / \               through one face, which
                        F   F              distorts the octahedron

                SHAPE: DISTORTED OCTAHEDRAL  HYBRIDISATION: sp3d3


  4.  XeO3      Xe makes 3 sigma bonds -> 1 lone pair
                Total pairs = 3 + 1 = 4  ->  sp3
                SHAPE: PYRAMIDAL

                       ..          <- lone pair on top
                       Xe
                     / | \
                    O  O  O

                SHAPE: PYRAMIDAL (trigonal pyramidal)  HYBRIDISATION: sp3


  5.  XeOF4     Xe makes 5 sigma bonds (1 to O + 4 to F) -> 1 lone pair
                Total pairs = 5 + 1 = 6  ->  sp3d2
                SHAPE: SQUARE PYRAMIDAL

                        O
                        ||
                        Xe
                      / /|\ \
                     F  F F  F       four F in a SQUARE PLANE,
                        ..           O on top, lone pair below
                                     
                SHAPE: SQUARE PYRAMIDAL   HYBRIDISATION: sp3d2
```

     A helium-oxygen mixture is used instead of air, because NITROGEN

**WORKED EXAMPLE 20**

> **Q. Explain the structure of XeF4 and XeOF4 with hybridisation. (4 marks)**
>
> **ANSWER:**
>
> ```
>   XeF4
>     Xe has 8 valence electrons. Four are used to bond to four F atoms,
>     so 4 remain as 2 LONE PAIRS.
>     Total electron pairs = 4 bond pairs + 2 lone pairs = 6.
>     -> sp3d2 hybridisation, OCTAHEDRAL electron geometry.
>     The two lone pairs take opposite (axial) positions to be as far
>     apart as possible, so the four F atoms are left in one plane.
>     SHAPE: SQUARE PLANAR, all F-Xe-F angles 90 degrees.
>
>   XeOF4
>     Xe forms four sigma bonds to F and one sigma bond to O, so 5
>     bond pairs, and 1 LONE PAIR remains.
>     Total electron pairs = 5 + 1 = 6.
>     -> sp3d2 hybridisation, OCTAHEDRAL electron geometry.
>     The lone pair occupies one axial position, oxygen the other,
>     and the four F atoms form a square plane.
>     SHAPE: SQUARE PYRAMIDAL.
>
>   XeOF4 is obtained by the PARTIAL hydrolysis of XeF6:
>       XeF6 + H2O  -->  XeOF4 + 2 HF
> ```

> **TRAP:** XeF4 is **square planar**, not tetrahedral. XeOF4 is **square
> pyramidal**, not octahedral. The lone pair is invisible in the drawing but it
> decides the shape. Always count lone pairs first, name the shape last.
