# TOPIC 1 — WHY CARBON? TETRAVALENCY AND CATENATION

## 1.1 The problem

There are about **118 elements**. Together, all of them make maybe a few lakh
compounds. **Carbon alone makes more than 10 million.** Why?

## 1.2 Reason 1 — TETRAVALENCY

Carbon is element number 6.

```
  Carbon:   Z = 6
  Configuration:  1s2  2s2  2p2
  Valence electrons: 4     (the 2s2 2p2)

  It needs 4 more to complete the octet.
  It is too small to lose 4 electrons (would need enormous energy).
  It is too small to gain 4 electrons (4 negative charges on a tiny
  atom = unstable).

  So it does the only remaining thing:   IT SHARES.
  Carbon forms exactly FOUR COVALENT BONDS.
```

**Everyday analogy:** carbon is a person with exactly four hands. Every carbon
atom in every organic molecule you will ever draw is holding four things. If your
drawn carbon has 3 bonds or 5 bonds, **the structure is wrong** — check it before
writing the name.

## 1.3 Reason 2 — CATENATION

**Catenation** = the ability of an element's atoms to link with atoms of the
**same element** to form long chains and rings.

```
  Why carbon is the champion of catenation:

  +---------------------------------------------------------------+
  |   BOND         BOND ENTHALPY (kJ/mol)      RESULT             |
  +---------------------------------------------------------------+
  |   C - C            348                     very strong        |
  |   Si - Si          297                     weaker             |
  |   N - N            163                     weak               |
  |   O - O            146                     very weak          |
  |   S - S            266                     moderate           |
  +---------------------------------------------------------------+

  C-C is SHORT and STRONG because carbon is a SMALL atom, so the two
  nuclei come close and the shared pair is held tightly.

  As you go down group 14 the atom gets bigger, the bond gets longer
  and weaker, so long chains fall apart.
```

Extra advantages carbon has:

```
  1. It bonds to itself by SINGLE, DOUBLE and TRIPLE bonds.
  2. It bonds strongly to H, O, N, S, P and the halogens.
  3. C-H bonds (414 kJ/mol) are strong, so hydrocarbons are stable at
     room temperature.
  4. It forms CHAINS (straight and branched) AND RINGS.
```

> **TRAP:** In a 2-mark question "Why does carbon form a large number of
> compounds?", you must write **BOTH** reasons — tetravalency **and** catenation.
> One reason = 1 mark only. Add "and it can form multiple bonds" for safety.

### WORKED EXAMPLE 1.1

**Q. Silicon is also tetravalent and is in the same group. Why does silicon not
form millions of compounds like carbon?**

**ANSWER:**
```
  1. Si-Si bond enthalpy is only 297 kJ/mol against 348 for C-C,
     so silicon chains are weak and break easily.

  2. Si is a bigger atom -> longer bond -> weaker overlap.

  3. Si-H bonds are easily attacked by water and air (silanes catch
     fire in air), whereas C-H bonds are inert.

  4. Silicon does not form stable p(pi)-p(pi) multiple bonds with
     itself, so there is no Si=Si chemistry like C=C chemistry.

  Result: catenation in silicon stops at chains of about 7-8 atoms.
```

# TOPIC 2 — SHAPES OF ORGANIC MOLECULES (HYBRIDISATION)

Carbon's ground state is `1s2 2s2 2p2` — that shows only **2** unpaired electrons,
which would predict 2 bonds. But carbon makes 4. So first one 2s electron is
promoted to the empty 2p orbital:

```
  GROUND STATE                  EXCITED STATE
  2s [ up down ]                2s [ up      ]
  2p [ up ][ up ][    ]         2p [ up ][ up ][ up ]

     2 unpaired                    4 unpaired  ->  4 bonds possible
```

But these four orbitals are not identical (one s, three p), yet all four C-H bonds
in methane are **identical**. The fix is **HYBRIDISATION**: the orbitals mix to
give a set of new, identical orbitals.

**Everyday analogy:** you have 1 glass of milk and 3 glasses of water. Pour them
all into one jug and re-pour into 4 glasses. Now all 4 glasses are identical
(each is 25% milk). That is sp3 hybridisation — 25% s character in each.

## 2.1 sp3 HYBRIDISATION — TETRAHEDRAL — 109 deg 28 min

```
  1 s orbital  +  3 p orbitals   ->   4 sp3 hybrid orbitals
  s character = 1/4 = 25%

  The 4 orbitals repel each other and go as far apart as possible
  in 3-D space -> corners of a TETRAHEDRON.

  METHANE   CH4
                     H
                     |
                     C            all H-C-H angles = 109 deg 28 min
                   / | \          C-H bond length  = 109 pm
                  H  H  H         all 4 bonds are SIGMA bonds
                                  formed by sp3(C) - 1s(H) overlap

  3-D picture (wedge and dash):

                     H
                     |
                     C.....H          (dotted = going back)
                    / \
                   H   H              (bold wedge = coming forward)
                       ^
                    solid wedge
```

Any carbon with **four single bonds** is sp3. So all alkanes, all alcohols
(the C bearing OH), all amines, all alkyl halides have sp3 carbons.

## 2.2 sp2 HYBRIDISATION — TRIGONAL PLANAR — 120 deg

```
  1 s orbital  +  2 p orbitals   ->   3 sp2 hybrid orbitals
  s character = 1/3 = 33.3%
  ONE p orbital is LEFT UNHYBRIDISED, standing perpendicular.

  The 3 sp2 orbitals lie in ONE PLANE at 120 degrees.

  ETHENE  C2H4     (CH2 = CH2)

           H            H
            \          /
             C ====== C            all angles about 120 deg
            /          \           (H-C-H is 117.6, C-C-H is 121.7)
           H            H          C=C length = 134 pm
                                   C-H length = 108 pm
                                   MOLECULE IS PLANAR

   Side view showing the pi bond:

           p           p              the two unhybridised p orbitals
          (  )        (  )            overlap SIDEWAYS above and below
        ---C-----------C---           the plane -> this is the PI BOND
          (  )        (  )
           p           p

   So C=C  =  1 SIGMA (sp2-sp2 head-on)  +  1 PI (p-p sideways)
```

## 2.3 sp HYBRIDISATION — LINEAR — 180 deg

```
  1 s orbital  +  1 p orbital   ->   2 sp hybrid orbitals
  s character = 1/2 = 50%
  TWO p orbitals are LEFT UNHYBRIDISED, mutually perpendicular.

  ETHYNE  C2H2     (CH (triple) CH)

       H ----- C (triple) C ----- H

       All four atoms in a STRAIGHT LINE.  Angle = 180 degrees.
       C(triple)C length = 120 pm
       C-H length        = 106 pm

   The two pi bonds:

                 pz                pz
                (  )              (  )
       py (  )    |     py (  )     |
   H --- C ------------- C --- H
       py (  )    |     py (  )     |
                (  )              (  )
                 pz                pz

   So C(triple)C = 1 SIGMA + 2 PI
```

## 2.4 THE MASTER TABLE

```
  +--------+---------+---------+--------+---------+--------------------+
  | HYBRID | % s     | SHAPE   | ANGLE  | SIGMA+PI| EXAMPLE            |
  +--------+---------+---------+--------+---------+--------------------+
  |  sp3   |  25 %   | tetra-  | 109.5  | 4 s     | CH4, C2H6, CH3OH   |
  |        |         | hedral  |        |         | CH3Cl, diamond     |
  +--------+---------+---------+--------+---------+--------------------+
  |  sp2   |  33.3 % | trigonal| 120    | 3 s+1 p | C2H4, benzene,     |
  |        |         | planar  |        |         | HCHO, graphite,    |
  |        |         |         |        |         | carbocation        |
  +--------+---------+---------+--------+---------+--------------------+
  |  sp    |  50 %   | linear  | 180    | 2 s+2 p | C2H2, HCN, CO2,    |
  |        |         |         |        |         | allene central C   |
  +--------+---------+---------+--------+---------+--------------------+
```

## 2.5 CONSEQUENCES OF s CHARACTER (this is asked)

```
  MORE s CHARACTER  ->  electrons held CLOSER to the nucleus
                    ->  SHORTER bond
                    ->  MORE electronegative carbon
                    ->  MORE acidic C-H

  BOND LENGTH:       sp3-H (109 pm) > sp2-H (108) > sp-H (106)
  C-C LENGTH:        C-C (154) > C=C (134) > C(triple)C (120)
  BOND STRENGTH:     sp > sp2 > sp3
  ELECTRONEGATIVITY: sp > sp2 > sp3
  ACIDITY of C-H:    HC(triple)CH  >  H2C=CH2  >  H3C-CH3
                     (this is why ethyne reacts with Na to give
                      sodium acetylide, but ethane does not)
```

### WORKED EXAMPLE 2.1

**Q. State the hybridisation of every carbon in `CH3 - CH = CH - C(triple)N`.**

**ANSWER:**
```
  Number the carbons:      C1   C2    C3     C4
                          CH3 - CH  = CH  -  C (triple) N

  C1  -  4 single bonds (3 H + 1 C)          ->  sp3
  C2  -  part of a DOUBLE bond               ->  sp2
  C3  -  part of a DOUBLE bond               ->  sp2
  C4  -  part of a TRIPLE bond               ->  sp
  N   -  part of a TRIPLE bond               ->  sp

  Sigma bonds: count every single line and ONE line of each
  multiple bond.
```

> **TRAP:** Students say the C in `-COOH` is sp3 because "it has 3 different
> things attached". It has a **C=O double bond**, so it is **sp2**. Look for
> multiple bonds first, always.

# TOPIC 3 — HOW TO DRAW ORGANIC COMPOUNDS

There are four accepted ways. You must be able to convert between all of them.

## 3.1 COMPLETE STRUCTURAL FORMULA (every bond shown)

```
  n-BUTANE   C4H10

        H   H   H   H
        |   |   |   |
    H - C - C - C - C - H
        |   |   |   |
        H   H   H   H
```

Accurate but slow. Use it when the question says "draw the structure showing all
bonds", or when you are counting hydrogens.

## 3.2 CONDENSED FORMULA (bonds squeezed out)

```
    CH3 - CH2 - CH2 - CH3       or even     CH3CH2CH2CH3
                                            or   CH3(CH2)2CH3

  Branches go in brackets:

    2-methylbutane  =  CH3 - CH(CH3) - CH2 - CH3
                    =  CH3CH(CH3)CH2CH3
```

## 3.3 BOND-LINE (ZIG-ZAG) FORMULA — learn to read this

```
  RULES:
    * Each LINE is a bond.
    * Each END and each CORNER (vertex) is a CARBON ATOM.
    * Carbon and hydrogen atoms are NOT written.
    * Every carbon is assumed to carry enough H to make 4 bonds.
    * Other atoms (O, N, Cl, Br...) ARE written.

  n-butane                       2-methylbutane

      /\  /                          /\  /
     /    \                         /    \
                                       |
  4 vertices/ends = 4 carbons        (methyl branch)

  Drawn in text form:

    C1        C3                    CH3
      \      /  \                    |
       \    /    \             CH3 - CH - CH2 - CH3
        C2         C4

  Rings are drawn as plain polygons:

     cyclopropane      cyclobutane       cyclohexane      benzene
                                                          _____
        /\             +------+           /\  /\         /     \
       /__\            |      |          |      |       |  ( ) |
                       +------+           \/  \/         \_____/
                                                        (circle inside
                                                         = delocalised)
```

## 3.4 THREE-DIMENSIONAL (WEDGE AND DASH) REPRESENTATION

Used when the shape in space matters (tetrahedral carbon, optical isomers).

```
  +-----------------------------------------------------------------+
  |   solid line   ----    bond IN THE PLANE of the paper           |
  |   bold wedge   ===>    bond COMING TOWARDS you                  |
  |   dashed line  ....    bond GOING AWAY from you                 |
  +-----------------------------------------------------------------+

  METHANE in 3-D:

                    H
                    |
                    |
                    C
                 .' | '.
              .'    |    '.
        H....       |       ===>  H     (wedge, towards you)
                    |
                    H                   (plain line, in plane)

  Standard exam drawing of a tetrahedral carbon:

              a
              |
              C ------ b        a and b : in the plane
             / \
            /   \
        c(wedge) d(dash)        c towards you, d away from you
```

### WORKED EXAMPLE 3.1

**Q. Write the condensed and the bond-line formula of
`CH3-CH2-CH(CH3)-CH2-CH2-OH`.**

**ANSWER:**
```
  Condensed:      CH3CH2CH(CH3)CH2CH2OH
                  (molecular formula C6H14O)

  Bond-line:      count the main chain = 5 carbons + OH,
                  branch = CH3 on carbon 3 from the OH end.

                         \    /\
                          \  /   \
                           \/     OH
                           |
                          CH3  (shown as a short line going down)

  In plain text the skeleton is:

        C - C - C - C - C - OH
                |
                C
```

> **TRAP:** In bond-line formulas, students forget that the **end** of a line is
> also a carbon. A zig-zag with 3 line segments has **4** carbons, not 3.

# TOPIC 4 — CLASSIFICATION OF ORGANIC COMPOUNDS

```
                        ORGANIC COMPOUNDS
                               |
             +-----------------+-----------------+
             |                                   |
      ACYCLIC (OPEN CHAIN)                  CYCLIC (CLOSED CHAIN)
      also called ALIPHATIC                        |
             |                        +------------+------------+
      straight or branched            |                         |
             |                    CARBOCYCLIC              HETEROCYCLIC
      CH3CH2CH3  (propane)        (ring = only C)      (ring has O, N or S)
      CH3CH(CH3)CH3                    |                         |
      (isobutane)             +--------+--------+       +--------+--------+
                              |                 |       |                 |
                        ALICYCLIC          AROMATIC   alicyclic       aromatic
                        (behaves like     (benzene    heterocyclic   heterocyclic
                         an aliphatic      like)          |                 |
                         compound)            |      tetrahydro-       furan,
                              |          BENZENOID    furan,          pyrrole,
                        cyclohexane      (contains    piperidine      thiophene,
                        cyclopropane      a benzene                    pyridine
                                          ring)
                                             |
                                        NON-BENZENOID
                                        (aromatic but
                                         no benzene ring,
                                         e.g. tropolone)
```

**Aromatic** does not mean "smells nice". It means the ring obeys **Huckel's rule**:
planar, cyclic, fully conjugated, with **(4n + 2) pi electrons** (n = 0, 1, 2, ...).
Benzene has 6 pi electrons -> n = 1 -> aromatic.

```
  BENZENE                    PYRIDINE (heterocyclic aromatic)

      H                            H
      |                            |
      C                            C
   //   \                       //   \
  C       C - H              H-C       C - H
  |       |                    |       |
  C       C - H              H-C       C - H
   \\   //                      \\   //
      C                            N
      |
      H                       (one CH replaced by N)
```

# TOPIC 5 — FUNCTIONAL GROUPS AND HOMOLOGOUS SERIES

## 5.1 FUNCTIONAL GROUP

**Definition:** An atom or a group of atoms present in a molecule which largely
determines the **chemical properties** of the compound.

**Analogy:** the carbon chain is the *body* of the molecule; the functional group
is the *hand* that does the reacting. Change the hand and the chemistry changes
completely, even if the body is identical.

```
  THE TABLE YOU MUST MEMORISE
  ===========================

  +--------------+------------------+-----------+-------------+-----------+
  | CLASS        | FUNCTIONAL GROUP | PREFIX    | SUFFIX      | EXAMPLE   |
  +--------------+------------------+-----------+-------------+-----------+
  | Alkane       |  (none)          |    -      | -ane        | CH3CH3    |
  | Alkene       |  -C=C-           |    -      | -ene        | CH2=CH2   |
  | Alkyne       |  -C(triple)C-    |    -      | -yne        | HC:CH     |
  | Haloalkane   |  -X (F,Cl,Br,I)  | halo-     |    -        | CH3Cl     |
  | Alcohol      |  -OH             | hydroxy-  | -ol         | CH3OH     |
  | Ether        |  -O-             | alkoxy-   |    -        | CH3OCH3   |
  | Aldehyde     |  -CHO            | oxo- /    | -al         | CH3CHO    |
  |              |                  | formyl-   |             |           |
  | Ketone       |  >C=O            | oxo-      | -one        | CH3COCH3  |

  |   acid       |                  |           |             |           |

## 5.2 HOMOLOGOUS SERIES

**Definition:** A series of organic compounds having the **same functional group**,
in which each successive member differs from the previous one by a **-CH2-** unit
and which can all be represented by **one general formula**.

```
  THE ALKANE SERIES
  -----------------
     CH4          methane        16 u
     C2H6         ethane         30 u      difference = 14 u  (CH2)
     C3H8         propane        44 u      difference = 14 u
     C4H10        butane         58 u      difference = 14 u
     C5H12        pentane        72 u
     General formula:   CnH(2n+2)

  GENERAL FORMULAS TO REMEMBER
  +---------------------+-----------------+
  | Alkane              |  CnH(2n+2)      |
  | Alkene              |  CnH(2n)        |
  | Alkyne              |  CnH(2n-2)      |
  | Cycloalkane         |  CnH(2n)        |
  | Alcohol             |  CnH(2n+1)OH    |
  | Aldehyde            |  CnH(2n+1)CHO   |
  | Ketone              |  CnH(2n+1)COCnH(2n+1) |
  | Carboxylic acid     |  CnH(2n+1)COOH  |
  | Amine (primary)     |  CnH(2n+1)NH2   |
  +---------------------+-----------------+
```

**CHARACTERISTICS OF A HOMOLOGOUS SERIES (this is a full 2-mark answer):**

```
  1. All members have the SAME general formula.
  2. Successive members differ by -CH2-  (14 u in molecular mass).
  3. All members have the SAME functional group, therefore
     SIMILAR CHEMICAL PROPERTIES.
  4. Physical properties (boiling point, melting point, density)
     change GRADUALLY and REGULARLY as molecular mass increases.
  5. All members can be prepared by the SAME general method.
  6. Members are called HOMOLOGUES.
```

## 5.3 CLASSIFYING CARBON ATOMS: 1 deg, 2 deg, 3 deg

Count how many **other carbons** are attached to it.

```
  +------------------+--------------------------------+
  | PRIMARY   (1 deg)| attached to 1 other carbon     |
  | SECONDARY (2 deg)| attached to 2 other carbons    |
  | TERTIARY  (3 deg)| attached to 3 other carbons    |
  | QUATERNARY(4 deg)| attached to 4 other carbons    |
  +------------------+--------------------------------+

  Example:  2,2-dimethylbutane

                   CH3
                    |
          CH3 ---- C ---- CH2 ---- CH3
                    |
                   CH3

     the three CH3 on the left and the CH3 on the right = 1 deg
     the CH2                                            = 2 deg
     the central C (bonded to 4 carbons)                = 4 deg (quaternary)
```

This classification is used constantly for alcohols, amines, carbocations and
free radicals, so learn it now.

# TOPIC 6 — IUPAC NOMENCLATURE (the biggest scoring block)

IUPAC = International Union of Pure and Applied Chemistry.

## 6.1 THE SHAPE OF EVERY IUPAC NAME

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   SECONDARY   +   PREFIX   +   WORD ROOT   +   PRIMARY  + SECONDARY  |
  |   PREFIX                                       SUFFIX     SUFFIX     |
  |                                                                      |
  |   (substituents)  (cyclo,   (number of      (saturated  (functional  |
  |    chloro, methyl  etc.)     carbons)        or not)      group)     |
  |                                                                      |
  +----------------------------------------------------------------------+

  Example:      3 - chloro  -  but  -  an  -  ol
                 ^^^^^^^^^     ^^^     ^^     ^^
                 substituent   root    C-C    functional
                 (prefix)      4 C     single  group -OH
                                       bonds
```

**WORD ROOTS — memorise the first ten:**

```
  +------+---------+  +------+---------+
  | 1 C  | Meth    |  | 6 C  | Hex     |
  | 2 C  | Eth     |  | 7 C  | Hept    |
  | 3 C  | Prop    |  | 8 C  | Oct     |
  | 4 C  | But     |  | 9 C  | Non     |
  | 5 C  | Pent    |  | 10 C | Dec     |
  +------+---------+  +------+---------+

  MEMORY: "Me Eat Peanut Butter Peanut Hot Hot Only Nine Days"
          (Meth Eth Prop But Pent Hex Hept Oct Non Dec)
```

**PRIMARY SUFFIX:**
```
   all single bonds  ->  -ane
   one double bond   ->  -ene
   one triple bond   ->  -yne
```

## 6.2 THE RULES, IN ORDER — DO THEM IN THIS SEQUENCE

```
  ======================================================================
  RULE 1 : FIND THE LONGEST CONTINUOUS CHAIN (the PARENT chain)
  ======================================================================
     * It need NOT be a straight horizontal line - it can turn corners.
     * If the compound has a functional group, the parent chain
       MUST CONTAIN that functional group, even if a longer chain exists
       without it.
     * If two chains are of equal length, choose the one with MORE
       substituents.

  ======================================================================
  RULE 2 : NUMBER THE CHAIN TO GIVE THE LOWEST LOCANTS
  ======================================================================
     PRIORITY OF WHAT GETS THE LOWEST NUMBER:
        1st  the PRINCIPAL FUNCTIONAL GROUP  (the suffix group)
        2nd  the DOUBLE or TRIPLE bond
        3rd  the SUBSTITUENTS (prefixes)

     If there is still a tie, use the RULE OF FIRST POINT OF DIFFERENCE:
     compare the two locant sets term by term; the set with the smaller
     number at the first difference wins.
        e.g.  (2,3,5)  beats  (2,4,5)   because 3 < 4

  ======================================================================
  RULE 3 : NAME AND ORDER THE SUBSTITUENTS ALPHABETICALLY
  ======================================================================
     * Write substituents in ALPHABETICAL order, not numerical order.
     * Multiplying prefixes di, tri, tetra are IGNORED for alphabetising.
          "3-ethyl-2,2-dimethyl..."   ->  E before M   (ignore "di")
     * BUT iso, neo, cyclo ARE counted for alphabetising.
     * Use di, tri, tetra for repeated identical substituents, and
       repeat the locant for each:   2,2-dimethyl (not 2-dimethyl)
     * Separate numbers by commas, numbers from letters by hyphens.

  ======================================================================
  RULE 4 : IF THERE IS MORE THAN ONE FUNCTIONAL GROUP,
           THE HIGHEST PRIORITY ONE BECOMES THE SUFFIX,
           ALL THE OTHERS BECOME PREFIXES
  ======================================================================
```

## 6.5 WORKED NAMING EXAMPLES — WORK THROUGH EVERY ONE

### WORKED EXAMPLE 6.1 — a branched alkane

```
  Structure:
                       CH3
                        |
        CH3 - CH2 - CH - CH - CH2 - CH3
                        |
                       CH3        <- wait, redraw clearly:

                  CH3      CH3
                   |        |
        CH3 - CH2- CH ---- CH - CH2 - CH3
```

**ANSWER:**
```
  STEP 1  Longest chain: count left to right
             CH3-CH2-CH-CH-CH2-CH3  = 6 carbons  ->  HEXANE

  STEP 2  Number for lowest locants.
             From the LEFT :  methyls on C3 and C4  ->  set (3,4)
             From the RIGHT:  methyls on C3 and C4  ->  set (3,4)
             Tie - both give (3,4). Either direction is fine.

  STEP 3  Two identical methyl groups -> "dimethyl", repeat locants.

  NAME:   3,4-dimethylhexane
```

### WORKED EXAMPLE 6.2 — the longest chain is not the straight line

```
                         CH3
                          |
        CH3 - CH2 - CH2 - CH - CH2 - CH2 - CH3
                          |
                         CH2
                          |
                         CH2
                          |
                         CH3
```

**ANSWER:**
```
  Tempting answer: the horizontal chain = 7 carbons -> heptane. WRONG-ish;
  we must check every path.

  Path A (all horizontal)                  = 7 carbons
  Path B (left 3 C -> centre -> down 3 C)  = 3 + 1 + 3 = 7 carbons
  Path C (right 3 C -> centre -> down 3 C) = 7 carbons

  All are 7. Rule: when chains tie in length, pick the one with the
  GREATER NUMBER OF SUBSTITUENTS.

  Path A leaves 1 methyl + 1 propyl attached? No - Path A leaves the
  CH2CH2CH3 branch and the CH3 branch = 2 substituents.
  Path B leaves a CH3 and a propyl    = 2 substituents.  Tie again.

  Take the horizontal chain (heptane), substituents methyl and propyl
  both on C4.

  NAME:   4-methyl-4-propylheptane

  (alphabetical: Methyl before Propyl)
```

### WORKED EXAMPLE 6.3 — alkene

```
        CH3 - CH2 - CH = CH - CH3
```

**ANSWER:**

# TOPIC 7 — ISOMERISM

**ISOMERS** = compounds with the **same molecular formula** but **different
properties** because the atoms are arranged differently.

```
                             ISOMERISM
                                 |
              +------------------+------------------+
              |                                     |
      STRUCTURAL ISOMERISM                  STEREOISOMERISM
   (different ORDER of bonding)          (same order of bonding,
              |                           different ARRANGEMENT
              |                              IN SPACE)
     +--------+--------+                        |
     |    |     |    |   |              +-------+-------+
   chain pos. func. meta- tauto-        |               |
              tional merism merism  GEOMETRICAL      OPTICAL
                                     (cis / trans)   (d / l)
```

## 7.1 CHAIN ISOMERISM

Difference in the **carbon skeleton** (straight vs branched).

```
  C4H10  ->  TWO chain isomers

     n-butane                     isobutane (2-methylpropane)

     CH3-CH2-CH2-CH3                    CH3
                                         |
                                  CH3 - CH - CH3

     b.p. 273 K                    b.p. 261 K
     (straight chain always boils HIGHER - more surface contact)
```

```
  C5H12  ->  THREE chain isomers

  1.  n-pentane          CH3-CH2-CH2-CH2-CH3

  2.  isopentane                CH3
      (2-methylbutane)           |
                          CH3 - CH - CH2 - CH3

  3.  neopentane                CH3
      (2,2-dimethylpropane)      |
                          CH3 - C - CH3
                                 |
                                CH3
```

## 7.2 POSITION ISOMERISM

Same skeleton, same functional group, but the group sits at a **different position**.

```
  C3H8O alcohols:

     propan-1-ol                  propan-2-ol
     CH3-CH2-CH2-OH               CH3-CH(OH)-CH3

  C3H6 with Cl (C3H7Cl):

     1-chloropropane              2-chloropropane
     CH3-CH2-CH2-Cl               CH3-CHCl-CH3

  C4H8 alkenes (position of the double bond):

     but-1-ene                    but-2-ene
     CH2=CH-CH2-CH3               CH3-CH=CH-CH3
```

## 7.3 FUNCTIONAL ISOMERISM

Same molecular formula, **completely different functional group**.

```
  +----------+------------------------------+---------------------------+
  | FORMULA  | ISOMER 1                     | ISOMER 2                  |
  +----------+------------------------------+---------------------------+
  | C2H6O    | ethanol   CH3CH2OH           | methoxymethane CH3-O-CH3  |
  |          | (alcohol, b.p. 351 K)        | (ether, b.p. 249 K)       |
  +----------+------------------------------+---------------------------+
  | C3H6O    | propanal  CH3CH2CHO          | propanone  CH3COCH3       |
  |          | (aldehyde)                   | (ketone)                  |
  +----------+------------------------------+---------------------------+
  | C2H4O2   | ethanoic acid CH3COOH        | methyl methanoate HCOOCH3 |
  |          | (acid)                       | (ester)                   |
  +----------+------------------------------+---------------------------+
  | C3H9N    | propan-1-amine CH3CH2CH2NH2  | N,N-dimethylmethanamine   |
  |          | (1 deg amine)                | (CH3)3N  (3 deg amine)    |
  +----------+------------------------------+---------------------------+
  | C3H6     | propene CH2=CH-CH3           | cyclopropane (ring)       |
  +----------+------------------------------+---------------------------+
```

## 7.4 METAMERISM

Same functional group, but **unequal distribution of carbon atoms on either side
of the functional group**. Found in **ethers, ketones, esters, secondary amines** —
groups that sit *in the middle* of the molecule.

```
  C4H10O  ETHERS:

     CH3 - O - CH2CH2CH3        methoxypropane   (1 C | 3 C)
     CH3CH2 - O - CH2CH3        ethoxyethane     (2 C | 2 C)

     These two are METAMERS.

  C5H10O  KETONES:

     CH3 - CO - CH2CH2CH3       pentan-2-one     (1 C | 3 C)
     CH3CH2 - CO - CH2CH3       pentan-3-one     (2 C | 2 C)
```

> **TRAP:** Metamerism is a **special case of chain isomerism**, but if the question
> says "metamerism", you must use an ether/ketone/ester/amine example. An alkane
> example scores zero.

## 7.5 TAUTOMERISM

Two isomers that exist **in dynamic equilibrium** and interconvert by the shifting
of an **atom (usually H) and a double bond**.

```
  KETO - ENOL TAUTOMERISM

           O                                OH
           ||                               |
   CH3 - C - CH3       <====>       CH3 - C = CH2

     KETO form                        ENOL form
   (propanone, ~99.99%)             (prop-1-en-2-ol, trace)

  What moved?
     * an H atom moved from the alpha-carbon to the oxygen
     * the C=O double bond became a C=C double bond

  The enol content is small for simple ketones, but large where the
  enol is stabilised (e.g. acetylacetone ~ 76% enol).
```

```
  A second example - ethanal:

        O                             OH
        ||                            |
  CH3 - C - H       <====>      CH2 = C - H
       keto                        enol (ethenol)
```

## 7.6 GEOMETRICAL (CIS-TRANS) ISOMERISM — stereoisomerism

Caused by **restricted rotation about a C=C double bond** (or about a ring).

```
  CONDITION FOR GEOMETRICAL ISOMERISM:
  each of the two doubly bonded carbons must carry TWO DIFFERENT groups.

           a           c
            \         /
             C ===== C          needs   a NOT EQUAL b
            /         \                 c NOT EQUAL d
           b           d
```

```
  BUT-2-ENE   CH3-CH=CH-CH3

     CIS  (same side)                TRANS (opposite sides)

      CH3       CH3                   CH3       H
        \       /                       \       /
         C === C                         C === C
        /       \                       /       \
       H         H                     H         CH3

     cis-but-2-ene                   trans-but-2-ene
     b.p. 277 K                      b.p. 274 K
     m.p. 134 K                      m.p. 168 K
     has a DIPOLE MOMENT             dipole moment = ZERO
     (the two CH3 pull the same way) (the two pulls cancel)
     LESS stable (CH3 groups         MORE stable (groups far apart,
      crowd each other)               no steric strain)
```

**Compounds that do NOT show geometrical isomerism:**

```
     CH2 = CH2      (both carbons carry 2 identical H)
     CH2 = CH-CH3   (the left carbon carries H and H - identical)
     CH2 = C(CH3)2  (the left carbon carries H and H)
     Any ALKYNE     (linear, no "sides")
     Any ALKANE     (free rotation about C-C)
```

## 7.7 OPTICAL ISOMERISM — a brief introduction

```
  CHIRAL CARBON (asymmetric carbon)
     = a carbon attached to FOUR DIFFERENT groups.
     Marked with a star  C*

  Example: 2-chlorobutane

                    Cl
                    |
          CH3 - C* - CH2 - CH3
                    |
                    H

     The starred C carries:  CH3 , Cl , C2H5 , H   -> all four different
     -> the molecule is CHIRAL -> it shows OPTICAL ISOMERISM.
```

```
  WHAT "OPTICAL" MEANS

  Ordinary light vibrates in all planes. A polariser lets through
  vibration in ONE plane -> PLANE POLARISED LIGHT.

  Pass it through a solution of a chiral compound:

      light source --> [polariser] --> ||| --> [sample] --> rotated |||

     rotation to the RIGHT  (clockwise)  = DEXTROROTATORY  (d) or (+)
     rotation to the LEFT   (anti-clock) = LAEVOROTATORY   (l) or (-)

  The two forms are called ENANTIOMERS. They are NON-SUPERIMPOSABLE
  MIRROR IMAGES of each other, like your LEFT and RIGHT HAND.

              MIRROR
       a        |        a
       |        |        |
       C        |        C
      /|\       |       /|\
     b | d      |      d | b
       c        |        c

     rotate all you like - you can never make them coincide.

  A 50:50 mixture of d and l is a RACEMIC MIXTURE (dl or +/-).
  Its net rotation is ZERO - it is OPTICALLY INACTIVE by
  EXTERNAL COMPENSATION.
```

# TOPIC 8 — FUNDAMENTAL CONCEPTS IN REACTION MECHANISM

## 8.1 FISSION OF A COVALENT BOND

A covalent bond `A : B` has a shared pair. When it breaks, the pair either
**splits** or **stays together**.

```
  ==================== HOMOLYTIC FISSION ====================

     A : B    --(heat / UV light / peroxide)-->    A .   +   . B

     Each atom takes ONE electron. ("homo" = equal share)
     The half-headed arrow (fish-hook) shows ONE electron moving.

     PRODUCTS: FREE RADICALS  (neutral, one unpaired electron)

     Example:   CH3 - CH3  --(heat)-->  2 CH3 .
                Cl - Cl    --(UV)-->    2 Cl .

     Conditions: non-polar solvent, high temperature, UV light,
                 or a peroxide initiator.


  ==================== HETEROLYTIC FISSION ==================

     A : B    --(polar solvent)-->    A+   +   :B-

     ONE atom takes BOTH electrons. ("hetero" = unequal)
     The full-headed curved arrow shows a PAIR of electrons moving.

     PRODUCTS: IONS - a CATION and an ANION

     Example:   CH3 - Br   -->   CH3+   +   :Br-
                                 carbocation
                CH3 - Li   -->   CH3:-  +   Li+
                                 carbanion

     Conditions: polar solvent, polar bond.
```

## 8.2 FREE RADICALS

```
  DEFINITION: a neutral species with an ODD (unpaired) electron.

  METHYL FREE RADICAL   CH3 .

     SHAPE   :  PLANAR (trigonal planar)
     HYBRID  :  sp2   (with the odd electron in the unhybridised p orbital)
     ANGLE   :  120 degrees

              .           <- odd electron in p orbital, above and below
             ( )
              |
              C
            / | \
          H   H   H       (all in one plane, 120 deg apart)
             ( )
              .

  STABILITY ORDER:

     3 deg      >     2 deg     >    1 deg    >    methyl

    (CH3)3C.       (CH3)2CH.      CH3CH2.        CH3.
     9 alpha H      6 alpha H     3 alpha H      0 alpha H

  REASON: more alkyl groups = more +I electron release AND more
          HYPERCONJUGATION structures = the odd electron is spread
          over more atoms = more stable.

  Allyl and benzyl radicals are even more stable than 3 deg
  because of RESONANCE:
     CH2=CH-CH2.   <-->   .CH2-CH=CH2
```

## 8.3 CARBOCATIONS (carbonium ions)

```
  DEFINITION: a species with a POSITIVELY charged carbon carrying
              only SIX electrons (electron deficient).

  METHYL CARBOCATION   CH3+

     SHAPE   :  PLANAR (trigonal planar)
     HYBRID  :  sp2
     ANGLE   :  120 degrees
     The unhybridised p orbital is EMPTY.

             empty p
              ( )
               |
               C+
             / | \
           H   H   H       (planar, 120 deg)
              ( )
             empty p

     Because the p orbital is empty on BOTH faces, a nucleophile can
     attack from either side - this is why SN1 reactions racemise.

  STABILITY ORDER:

     3 deg      >     2 deg      >    1 deg     >    methyl

    (CH3)3C+       (CH3)2CH+      CH3CH2+        CH3+
     most stable                                 least stable

  REASONS (write BOTH in the exam):
     1. INDUCTIVE EFFECT: alkyl groups are +I, they PUSH electron
        density towards the electron-deficient carbon and reduce the
        positive charge. More alkyl groups = more push = more stable.
     2. HYPERCONJUGATION: the more alpha C-H bonds available, the
        more no-bond resonance structures, the more the charge is
        dispersed.
        3 deg has 9 alpha H, 2 deg has 6, 1 deg has 3, CH3+ has 0.

  EXTRA STABLE CARBOCATIONS (resonance stabilised):
     benzyl  C6H5-CH2+     and     allyl  CH2=CH-CH2+
     are comparable to or more stable than 3 deg.

     Resonance in the allyl cation:

        CH2 = CH - CH2+    <-->    +CH2 - CH = CH2
```

## 8.4 CARBANIONS

```
  DEFINITION: a species with a NEGATIVELY charged carbon carrying a
              LONE PAIR (eight electrons, electron rich).

  METHYL CARBANION   CH3 :-

     SHAPE   :  PYRAMIDAL (trigonal pyramidal, like ammonia)
     HYBRID  :  sp3   (the lone pair occupies one sp3 orbital)
     ANGLE   :  a little less than 109.5 degrees

               lone pair
                 ( : )
                   |
                   C -
                 / | \
               H   H   H      (pyramid, H pushed down)

  STABILITY ORDER  - THE REVERSE OF THE CARBOCATION ORDER:

     methyl   >   1 deg    >    2 deg     >    3 deg

     CH3:-      CH3CH2:-     (CH3)2CH:-     (CH3)3C:-
     most stable                            least stable

  REASON: the carbon already carries a NEGATIVE charge. Alkyl groups
          are +I - they PUSH MORE electron density onto an already
          electron-rich centre, INTENSIFYING the charge and
          DESTABILISING it. So fewer alkyl groups = more stable.

  Carbanions ARE stabilised by -I and by resonance with -R groups:
          -NO2 , -CN , -CHO , -COOH  next door make a carbanion stable.
```

## 8.6 ELECTROPHILES AND NUCLEOPHILES

```
  ELECTROPHILE  ("electron loving")
     = an electron-DEFICIENT species that ACCEPTS an electron pair.
     = a LEWIS ACID.
     = attacks the electron-RICH part of a molecule.

     POSITIVE electrophiles:  H+ , Cl+ , Br+ , NO2+ , NO+ ,
                              R+ (carbocation), R-C(=O)+ (acylium)
     NEUTRAL electrophiles:   BF3 , AlCl3 , FeCl3 , SO3 , ZnCl2 ,
                              carbenes  :CH2 ,  >C=O carbon


  NUCLEOPHILE  ("nucleus loving")
     = an electron-RICH species that DONATES an electron pair.
     = a LEWIS BASE.
     = attacks the electron-DEFICIENT (positive) part of a molecule.

     NEGATIVE nucleophiles:   OH- , CN- , Cl- , Br- , I- , RO- ,
                              RCOO- , NH2- , R- (carbanion), HS-
     NEUTRAL nucleophiles:    H2O , NH3 , ROH , RNH2 , R2NH , R3N ,
                              R-O-R  (anything with a LONE PAIR)


  THE ONE-LINE TEST:
        Has a LONE PAIR or a NEGATIVE charge  ->  NUCLEOPHILE
        Has an EMPTY orbital or a POSITIVE charge -> ELECTROPHILE
```

```
  AMBIDENT NUCLEOPHILES - can attack through either of two atoms:

      cyanide    :C(triple)N:-      through C  ->  R-CN  (nitrile)
                                    through N  ->  R-NC  (isocyanide)

      nitrite    O=N-O:-            through N  ->  R-NO2 (nitroalkane)
                                    through O  ->  R-O-N=O (alkyl nitrite)
```

### WORKED EXAMPLE 8.1

**Q. Classify as electrophile or nucleophile: `BF3`, `NH3`, `CN-`, `NO2+`,
`H2O`, `AlCl3`, `CH3-`.**

**ANSWER:**
```
  BF3    -> B has only 6 electrons, EMPTY p orbital  ->  ELECTROPHILE
  NH3    -> N has a lone pair                        ->  NUCLEOPHILE
  CN-    -> negative + lone pair                     ->  NUCLEOPHILE
  NO2+   -> positive, electron deficient             ->  ELECTROPHILE
  H2O    -> O has two lone pairs                     ->  NUCLEOPHILE
  AlCl3  -> Al has 6 electrons, incomplete octet     ->  ELECTROPHILE
  CH3-   -> carbanion, lone pair + negative charge   ->  NUCLEOPHILE
```

# TOPIC 9 — ELECTRONIC DISPLACEMENT EFFECTS

These four effects explain **every** stability order and **every** reactivity
order in organic chemistry. Learn each one as: **cause -> what moves -> effect**.

## 9.1 INDUCTIVE EFFECT (I effect)

```
  CAUSE:      a difference in ELECTRONEGATIVITY between two bonded atoms.
  WHAT MOVES: the SIGMA bond electrons, only PARTIALLY DISPLACED
              (not fully transferred).
  NATURE:     PERMANENT.  Present in the molecule at all times.
  TRANSMITS:  through the SIGMA bond chain, but DIES OUT quickly -
              negligible beyond the THIRD carbon.
```

```
  EXAMPLE - chloroethane:

     dd+      d+       d-
     CH3 ---- CH2 ---- Cl

     Cl is more electronegative -> pulls the C-Cl electrons ->
     C2 becomes d+ -> C2 now pulls the C1-C2 electrons ->
     C1 becomes dd+ (a much smaller charge).

     Magnitude:   d-  >  d+  >  dd+  >  ddd+  (~0)

     THAT IS WHY IT DIES OUT AFTER 3 CARBONS.
```

```
  -I EFFECT  (ELECTRON WITHDRAWING) - group pulls electrons AWAY
  --------------------------------------------------------------
  Any group more electron-attracting than hydrogen.

  ORDER (strongest first):

     -NH3+  >  -NO2  >  -CN  >  -SO3H  >  -CHO  >  -CO-  >  -COOH
        >  -COCl  >  -CONH2  >  -F  >  -Cl  >  -Br  >  -I
        >  -OH  >  -OR  >  -NH2  >  -C6H5  >  -H  (reference)


  +I EFFECT  (ELECTRON RELEASING) - group pushes electrons TOWARDS
  ---------------------------------------------------------------
  Any group less electron-attracting than hydrogen.

  ORDER (strongest first):

     -O-  >  -COO-  >  -C(CH3)3  >  -CH(CH3)2  >  -CH2CH3  >  -CH3  >  -H

     i.e.  tert-butyl > isopropyl > ethyl > methyl
     MORE ALKYL GROUPS = MORE +I PUSH
```

**WHAT THE INDUCTIVE EFFECT EXPLAINS:**

```
  (a) ACID STRENGTH.  -I groups pull electrons away from -COOH,
      weaken the O-H bond, and stabilise the RCOO- anion formed.
      -I groups therefore INCREASE acidity.

         Cl3C-COOH > Cl2CH-COOH > ClCH2-COOH > CH3-COOH
         (pKa 0.7)     (1.3)        (2.9)        (4.76)

         F-CH2COOH > Cl-CH2COOH > Br-CH2COOH > I-CH2COOH
         (F is the most electronegative -> strongest -I)

         And the CLOSER the halogen, the stronger the effect:
         CH3CH2CHCl-COOH  >  CH3CHCl-CH2COOH  >  CH2Cl-CH2CH2COOH
              (alpha)             (beta)               (gamma)

      +I groups DECREASE acidity:
         HCOOH > CH3COOH > CH3CH2COOH > (CH3)3C-COOH

  (b) CARBOCATION STABILITY.  +I alkyl groups feed electrons into
      the electron-poor C+.
         3 deg > 2 deg > 1 deg > CH3+

  (c) CARBANION STABILITY (reverse).  +I groups make it worse.
         CH3- > 1 deg > 2 deg > 3 deg

  (d) BASICITY OF AMINES in the gas phase:
         (CH3)3N > (CH3)2NH > CH3NH2 > NH3   (more +I = more basic)
```

## 9.2 ELECTROMERIC EFFECT (E effect)

```
  CAUSE:      the approach of an ATTACKING REAGENT.
  WHAT MOVES: the PI electrons of a multiple bond, COMPLETELY
              TRANSFERRED to one of the two atoms.
  NATURE:     TEMPORARY.  It exists ONLY while the reagent is near.
              The moment the reagent is removed, the molecule
              goes back to normal.
  SYMBOL:     a full curved arrow from the pi bond to one atom.
```

```
  +E EFFECT  - pi electrons transferred TOWARDS the atom to which
               the attacking reagent finally ATTACHES.

     Example: addition of H+ to ethene

              H+
              |
        CH2 = CH2    -->    CH2 - CH2+           then Cl- attacks
                             |
                             H
     (the pi pair went to the LEFT carbon, which took the H+)


  -E EFFECT  - pi electrons transferred AWAY from the atom to which
               the reagent attaches.

     Example: addition of CN- to a carbonyl

           O                        O-
           ||                       |
     CH3 - C - CH3   +  CN-  -->  CH3-C-CH3
                                     |
                                    CN
     (the pi pair of C=O went to OXYGEN, away from the carbon
      that the CN- attached to)
```

```
  INDUCTIVE vs ELECTROMERIC - the exam comparison table

  +----------------+----------------------+------------------------+
  |                | INDUCTIVE (I)        | ELECTROMERIC (E)       |
  +----------------+----------------------+------------------------+
  | Electrons      | SIGMA                | PI                     |
  | Transfer       | PARTIAL              | COMPLETE               |
  | Nature         | PERMANENT            | TEMPORARY              |
  | Needs a reagent| NO                   | YES                    |
  | Requires a     | NO                   | YES (must have a       |
  | multiple bond  |                      | double/triple bond)    |
  | Distance       | dies after 3 C       | not applicable         |
  +----------------+----------------------+------------------------+
```

## 9.3 RESONANCE (mesomeric effect)

```
  DEFINITION: when a single Lewis structure cannot describe a molecule
  properly, the real molecule is described as a RESONANCE HYBRID of
  two or more structures called CANONICAL STRUCTURES or
  RESONANCE STRUCTURES.

  KEY IDEA:  the resonance structures are IMAGINARY.
             ONLY THE HYBRID IS REAL.
             The molecule does NOT flip between them.
```

**Analogy:** a mule is a hybrid of a horse and a donkey. It is not a horse on
Monday and a donkey on Tuesday. It is always a mule. Horse and donkey are just
the two things we describe it with.

```
  BENZENE - the classic example

      H                        H
      |                        |
      C                        C
   //   \                    /   \\
  C       C-H              HC      C-H
  |       |         <-->    ||      |
  C       C-H              HC      C-H
   \\   //                    \   //
      C                        C
      |                        |
      H                        H

     Kekule structure I     Kekule structure II

  THE REAL BENZENE:
     * all six C-C bonds are IDENTICAL, length 139 pm
       (between C-C 154 pm and C=C 134 pm)
     * regular hexagon, all angles 120 deg, sp2 carbons
     * the six pi electrons are DELOCALISED in a ring above and
       below the plane
     * drawn as a hexagon with a CIRCLE inside
```

```
  CARBONATE ION  CO3 2-  - three equivalent structures

         O               O-              O-
         ||              |               |
     -O- C -O-   <-->  -O-C=O   <-->    O=C-O-

  All three C-O bonds are identical in the real ion.
```

```
  NITROMETHANE / the nitro group

        O                  O-
        //                 |
  CH3-N          <-->  CH3-N+
        \\                 \\
        O-                  O

  PHENOL - the OH lone pair goes into the ring (+R effect)

        OH              +OH             +OH             +OH
        |               ||              ||              ||
       / \             / \             / \             / \
      |   |    <-->   |   |-    <-->  |   |     <-->  |   |
       \ /             \ /             \ /-            \ /
                                                        -

     (negative charge appears at ORTHO, ORTHO and PARA positions
      - which is exactly why phenol is o,p-directing and activated)
```

### RULES FOR WRITING RESONANCE STRUCTURES

```
  +----------------------------------------------------------------------+
  |  1. Only ELECTRONS move. ATOMS AND NUCLEI DO NOT MOVE.               |
  |     (If an atom moved, it is TAUTOMERISM, not resonance.)            |
  |                                                                      |
  |  2. The number of PAIRED and UNPAIRED electrons must stay the        |
  |     SAME in every structure.                                         |
  |                                                                      |
  |  3. All the structures must have the SAME total charge and the       |
  |     same molecular formula.                                          |
  |                                                                      |
  |  4. All the atoms taking part must lie in ONE PLANE, and the         |
  |     p orbitals must be parallel (CONJUGATION is essential:           |
  |     alternate single and multiple bonds, or a lone pair /            |
  |     empty orbital next to a multiple bond).                          |
  |                                                                      |
  |  5. Structures with more COVALENT BONDS are more stable and          |
  |     contribute more to the hybrid.                                   |
  |                                                                      |
  |  6. Structures in which all atoms have a COMPLETE OCTET are          |
  |     more stable.                                                     |
  |                                                                      |
  |  7. Structures with SEPARATED CHARGES are less stable.               |
  |                                                                      |
  |  8. LIKE CHARGES on adjacent atoms make a structure very unstable.   |
  |                                                                      |
  |  9. A negative charge is best placed on the MOST electronegative     |
  |     atom, and a positive charge on the LEAST electronegative.        |
  |                                                                      |
  | 10. Structures of nearly EQUAL energy contribute EQUALLY.            |
  +----------------------------------------------------------------------+
```

### RESONANCE ENERGY

```
  RESONANCE ENERGY
      = (energy of the most stable canonical structure)
        - (actual energy of the resonance hybrid)

      = the EXTRA STABILITY the molecule gets from delocalisation.

  BENZENE:
     Predicted heat of hydrogenation for 3 isolated C=C
                     = 3 x 119.7  =  359 kJ/mol
     OBSERVED heat of hydrogenation of benzene
                     = 208.6 kJ/mol

     RESONANCE ENERGY  =  359  -  208.6  =  about 150 kJ/mol

  The bigger the resonance energy, the more stable the molecule.
  This is WHY benzene refuses to undergo addition reactions - adding
  would destroy 150 kJ/mol of stabilisation. Benzene prefers
  SUBSTITUTION, which keeps the ring intact.
```

```
  +R  (or +M) GROUPS  - DONATE electrons INTO the system (have a lone pair)
      -OH , -OR , -NH2 , -NHR , -NR2 , -SH , -X (halogens) , -NHCOR
      -> activate the benzene ring, ortho-para directing

  -R  (or -M) GROUPS  - WITHDRAW electrons FROM the system
      -NO2 , -CN , -CHO , -COR , -COOH , -COOR , -SO3H , -CONH2
      -> deactivate the benzene ring, meta directing
```

> **TRAP:** Resonance vs tautomerism is a favourite 2-mark question.
> **RESONANCE: only electrons shift, structures are imaginary, one real hybrid.**
> **TAUTOMERISM: an ATOM (H) actually moves, both forms are REAL and separable in
> principle, they exist in equilibrium.**

## 9.4 HYPERCONJUGATION

```
  DEFINITION: the delocalisation of SIGMA electrons of a C-H bond of an
  ALPHA carbon with the adjacent EMPTY p orbital (carbocation),
  half-filled p orbital (free radical), or PI orbital (alkene).

  It is called "NO-BOND RESONANCE" or the "BAKER-NATHAN EFFECT"
  because in the contributing structures the C-H bond DOES NOT EXIST -
  the H is shown as H+ with no bond drawn to it.

  ALPHA CARBON  = the carbon directly attached to the
                  charged / radical / doubly-bonded carbon.
  ALPHA HYDROGEN= a hydrogen on that alpha carbon.

  CONDITION: there must be AT LEAST ONE alpha hydrogen.
```

```
  HYPERCONJUGATION IN A CARBOCATION - ethyl cation CH3-CH2+

       H                     H+                  H+                H+
       |                                                    
   H - C - CH2+     <-->  H - C = CH2   <-->  H - C = CH2  <--> ...
       |                     |                    |
       H                     H                    H+ (each H in turn)

   The sigma pair of a C-H bond of the CH3 group jumps into the
   empty p orbital of the C+. The positive charge spreads onto the
   hydrogens. Charge spread out = more stable.

   NUMBER OF HYPERCONJUGATIVE (no-bond) STRUCTURES
        =  number of ALPHA hydrogens  +  1  (the normal structure)

   CH3+           0 alpha H  ->  no hyperconjugation
   CH3CH2+ (1deg) 3 alpha H  ->  3 hyperconjugative structures
   (CH3)2CH+(2deg)6 alpha H  ->  6
   (CH3)3C+ (3deg)9 alpha H  ->  9      MOST STABLE
```

```
  HYPERCONJUGATION IN AN ALKENE - propene

       H                        H+
       |                        |
   H - C - CH = CH2   <-->  H - C = CH - CH2 -
       |                        |
       H                        H

   ALKENE STABILITY ORDER (count the alpha H):

   (CH3)2C=C(CH3)2  >  (CH3)2C=CHCH3 > CH3CH=CHCH3 > CH3CH=CH2 > CH2=CH2
      12 alpha H          9              6             3           0
   most stable                                              least stable

   GENERAL RULE:  THE MORE SUBSTITUTED THE ALKENE, THE MORE STABLE.
   (This is the basis of SAYTZEFF'S RULE in elimination reactions.)
```

```
  HYPERCONJUGATION IN FREE RADICALS - same order:
        (CH3)3C.  >  (CH3)2CH.  >  CH3CH2.  >  CH3.

  HYPERCONJUGATION IN TOLUENE - explains why -CH3 is
  ortho/para directing and RING ACTIVATING:

     H                            H+
     |                            |
 H - C - C6H5      <-->      H - C = C6H5 (-)
     |                            |
     H                            H

  the CH3 pushes electron density into the ring.
```

```
  CONSEQUENCES OF HYPERCONJUGATION (write these in a 4-mark answer):

  1. Explains the stability order of carbocations and free radicals.
  2. Explains the stability order of alkenes (Saytzeff's rule).
  3. Explains why -CH3 is an activating, o/p-directing group.
  4. Explains BOND LENGTHS: in propene the C-C single bond is
     shortened (149 pm instead of 154 pm) because it gains partial
     double bond character.
  5. Explains the dipole moment of propene (0.35 D) - a hydrocarbon
     should have zero, but hyperconjugation creates a small one.
```

# TOPIC 10 — TYPES OF ORGANIC REACTIONS (outline)

```
  1. SUBSTITUTION - one atom or group is REPLACED by another.
     Skeleton unchanged. Typical of ALKANES and AROMATIC compounds.

        CH4  +  Cl2  --(UV light)-->  CH3Cl  +  HCl     (free radical)

        CH3-Br + OH-  -->  CH3-OH  +  Br-        (nucleophilic, SN)

        C6H6 + HNO3 --(conc H2SO4, 330K)--> C6H5NO2 + H2O
                                            (electrophilic, SE)

     Sub-types: free radical (SR), nucleophilic (SN1, SN2),
                electrophilic (SE)


  2. ADDITION - two molecules JOIN into one. Requires a MULTIPLE BOND.
     A pi bond is destroyed and two sigma bonds are made.

        CH2=CH2  +  Br2   -->  CH2Br-CH2Br
        CH2=CH2  +  HBr   -->  CH3-CH2Br
        CH3CHO   +  HCN   -->  CH3-CH(OH)-CN

     MARKOVNIKOV'S RULE: in the addition of HX to an unsymmetrical
     alkene, the H goes to the carbon carrying MORE hydrogens
     (because that gives the more stable carbocation).

        CH3-CH=CH2 + HBr -->  CH3-CHBr-CH3   (2-bromopropane, major)


  3. ELIMINATION - a small molecule is REMOVED, creating a
     multiple bond. The OPPOSITE of addition.

        CH3-CH2-Br + alc. KOH --> CH2=CH2 + KBr + H2O  (dehydrohalogen.)
        CH3-CH2-OH --(conc H2SO4, 443K)--> CH2=CH2 + H2O (dehydration)

     SAYTZEFF'S RULE: the major product is the MORE SUBSTITUTED
     (more stable) alkene.


  4. REARRANGEMENT - the atoms REORGANISE within the SAME molecule.
     Molecular formula is unchanged; the skeleton or the positions
     change.

        NH4CNO  --(heat)-->  NH2-CO-NH2      (urea - Wohler, 1828)

        1,2-hydride shift in a carbocation:

           CH3-CH-CH2+     -->     CH3-C+-CH3
               |                        |
              CH3                      CH3
           (1 deg, unstable)      (3 deg, stable)
```

# TOPIC 11 — PURIFICATION OF ORGANIC COMPOUNDS

**THE ONE PRINCIPLE BEHIND ALL OF THEM:**
choose a **physical property in which the compound and the impurity DIFFER**.

## 11.1 SUBLIMATION

```
  PRINCIPLE: some solids change DIRECTLY from solid to vapour on heating
             without passing through the liquid state, and condense
             back to solid on cooling.

  USED FOR:  a SUBLIMABLE solid contaminated with a NON-SUBLIMABLE
             impurity.

  EXAMPLES:  camphor, naphthalene, anthracene, benzoic acid,
             ammonium chloride, iodine.

  APPARATUS:

          +------------------+
          |  cold water in   |     <- inverted funnel / watch glass
          +------------------+
             \    ....    /         .... = pure crystals collect here
              \  ......  /
               \________/
              |  vapour  |
              +----------+
              |  impure  |
              |  solid   |
              +----------+
                  /\/\
                 HEAT
```

## 11.2 CRYSTALLISATION

```
  PRINCIPLE: the difference in the SOLUBILITY of the compound and the
             impurity in a suitable solvent. The compound must be
             SPARINGLY soluble at ROOM TEMPERATURE but HIGHLY soluble
             in the HOT solvent, while the impurity behaves oppositely.

  STEPS:
     1. Dissolve the impure solid in the MINIMUM amount of HOT solvent.
     2. FILTER hot (removes insoluble impurities).
     3. COOL slowly -> pure crystals separate out; soluble impurities
        stay in the MOTHER LIQUOR.
     4. Filter, wash, dry.
     5. Repeat if necessary (fractional crystallisation).

  If the compound is coloured by impurities, boil with ANIMAL CHARCOAL
  which adsorbs the colour, then filter.

  EXAMPLE: purification of impure benzoic acid from water;
           potash alum from water.
```

## 11.3 SIMPLE DISTILLATION

```
  PRINCIPLE: difference in BOILING POINTS. The liquid is boiled and the
             vapour is condensed back to liquid in a separate vessel.

  USED FOR:  (a) liquids with a NON-VOLATILE impurity, and
             (b) two liquids whose boiling points differ APPRECIABLY
                 (usually more than about 25-30 K).

  EXAMPLES:  chloroform (b.p. 334 K) from aniline (b.p. 457 K);
             ether (b.p. 308 K) from toluene (b.p. 384 K);
             pure water from sea water.

              thermometer
                  |
              +---+---+
              |       |======= condenser (cold water jacket) =====\
              |flask  |                                            \
              | ~~~~  |                                          +--v--+
              | ~~~~  |                                          |     |
              +-------+                                          |pure |
                 /\/\                                            |liq. |
                HEAT                                             +-----+
                                                                 receiver
```

## 11.4 FRACTIONAL DISTILLATION

```
  PRINCIPLE: same as distillation, but a FRACTIONATING COLUMN is fitted
             between the flask and the condenser. The column gives many
             surfaces on which the vapour condenses and re-evaporates
             again and again. Each cycle enriches the vapour in the
             MORE VOLATILE component.

  USED FOR:  liquids whose boiling points are CLOSE TOGETHER
             (difference less than about 25 K).

  EXAMPLES:  * separating the fractions of CRUDE PETROLEUM
             * acetone (b.p. 329 K) from methanol (b.p. 338 K)
             * separating liquid air components

              +===+
              |   |  <- fractionating column packed with glass
              |o o|     beads / rings (many surfaces)
              |o o|
              |o o|===== condenser ====>
              +===+
              |flask|
                /\/\
```

## 11.5 DISTILLATION UNDER REDUCED PRESSURE (VACUUM DISTILLATION)

```
  PRINCIPLE: a liquid boils when its VAPOUR PRESSURE equals the
             EXTERNAL pressure. If you LOWER the external pressure,
             the liquid boils at a LOWER TEMPERATURE.

  USED FOR:  liquids that DECOMPOSE at or below their normal
             boiling point.

  EXAMPLES:  * GLYCEROL - decomposes at its normal b.p. 563 K, but
               distils safely at 453 K under reduced pressure
             * concentrating SUGARCANE JUICE in a vacuum evaporator
               (sugar would char at normal boiling temperature)
```

## 11.6 STEAM DISTILLATION

```
  PRINCIPLE: when a mixture of two IMMISCIBLE liquids is heated, each
             exerts its OWN vapour pressure independently. The mixture
             boils when

                  p(compound)  +  p(water)  =  atmospheric pressure

             This happens BELOW 373 K, i.e. below the boiling point of
             water and far below the boiling point of the compound.

  CONDITIONS the compound must satisfy:
             1. INSOLUBLE (immiscible) in water
             2. VOLATILE IN STEAM
             3. must have an appreciable vapour pressure at 373 K
             4. must not react with water

  USED FOR:  separating a steam-volatile compound from a
             NON-VOLATILE impurity.

  EXAMPLES:  ANILINE (b.p. 457 K - distils over at about 371 K),
             o-nitrophenol (separated from p-nitrophenol, which is
             NOT steam volatile because of intermolecular H-bonding),
             essential oils, turpentine, nitrobenzene, bromobenzene.

     STEAM ---> [ flask with water + impure compound ] ---> condenser
                             /\/\  heat                        |
                                                               v
                                        receiver: two layers -
                                        compound + water, then
                                        separated by a separating funnel
```

## 11.7 DIFFERENTIAL EXTRACTION

```
  PRINCIPLE: an organic compound distributes itself between two
             IMMISCIBLE liquid layers in a fixed ratio. If the compound
             is MUCH more soluble in the organic solvent than in water,
             shaking the aqueous solution with the organic solvent
             pulls the compound out of the water.

  USED FOR:  recovering an organic compound DISSOLVED IN WATER.

  APPARATUS: SEPARATING FUNNEL.

     +-----------+
     |  ether    |  <- upper layer (lighter, contains the compound)
     |  layer    |
     +-----------+
     |  aqueous  |  <- lower layer, run out through the stopcock
     |  layer    |
     +-----+-----+
           |X|   <- stopcock
           \_/

  IMPORTANT PRACTICAL POINT:
     It is FAR more efficient to extract SEVERAL TIMES WITH SMALL
     PORTIONS of solvent than ONCE with the whole quantity.
     (3 x 20 mL beats 1 x 60 mL.)

  Finally the solvent is distilled off to leave the pure compound.
```

## 11.8 CHROMATOGRAPHY

```
  The name: Greek "chroma" = colour, "graphein" = to write
            (Tswett first separated plant pigments, 1906).

  BASIC IDEA: the mixture is placed on a STATIONARY PHASE and a
  MOBILE PHASE is allowed to move over it. The components move at
  DIFFERENT SPEEDS and therefore get separated.

                        CHROMATOGRAPHY
                              |
              +---------------+---------------+
              |                               |
      ADSORPTION CHROMATOGRAPHY       PARTITION CHROMATOGRAPHY
      (differential ADSORPTION        (differential PARTITION -
       on a SOLID adsorbent)          the components distribute
              |                       between two LIQUID phases)
              |                               |
       +------+------+                        |
       |             |                   PAPER
    COLUMN         THIN LAYER            CHROMATOGRAPHY
    CHROMATO-      CHROMATOGRAPHY
    GRAPHY         (TLC)
```

```
  (A) COLUMN CHROMATOGRAPHY

  PRINCIPLE: different components of the mixture are adsorbed to
             DIFFERENT EXTENTS on an adsorbent.

  Adsorbent (stationary phase): alumina Al2O3 or silica gel, packed
                                in a glass column.
  Mobile phase (eluant)       : a solvent flowing down the column.

     +-----+
     |mixt.|  <- mixture placed on top
     |=====|
     | ooo |  <- band 1 : MOST strongly adsorbed -> moves SLOWEST
     | ooo |               -> stays at the TOP
     | xxx |  <- band 2 : moderately adsorbed
     | ooo |
     | +++ |  <- band 3 : LEAST adsorbed -> moves FASTEST
     | ooo |               -> comes out FIRST
     +--v--+
        |     each band collected separately = ELUTION


  (B) THIN LAYER CHROMATOGRAPHY (TLC)

  A thin layer (about 0.2 mm) of silica gel or alumina is spread on a
  glass plate (the "chromaplate"). A spot of the mixture is put near
  the bottom, and the plate stands in a shallow pool of solvent.
  The solvent rises by capillary action and carries the components
  different distances.

     +---------------------+  <- solvent front
     |          o          |
     |     o               |
     |               o     |
     | - - - - - - - - - - |  <- base line where the spot was applied
     +---------------------+
        [ solvent pool ]

  RETARDATION FACTOR:

  +---------------------------------------------------------------+
  |                                                               |
  |            distance moved by the SUBSTANCE from the base line |
  |     Rf  =  ---------------------------------------------------|
  |            distance moved by the SOLVENT FRONT from the base  |
  |                                                               |
  |     Rf has NO UNITS.  Rf is always between 0 and 1.           |
  |                                                               |
  +---------------------------------------------------------------+

  Colourless spots are located with iodine vapour, or under UV light,
  or by spraying a suitable reagent.


  (C) PARTITION / PAPER CHROMATOGRAPHY

  PRINCIPLE: continuous DIFFERENTIAL PARTITIONING (distribution) of the
             components between a STATIONARY LIQUID phase and a
             MOBILE LIQUID phase.

  Stationary phase : WATER trapped in the pores of the chromatography
                     paper (the paper itself is only the support).
  Mobile phase     : the developing solvent that rises up the paper.

  The strip with the separated spots is called a CHROMATOGRAM.
  Rf values are measured exactly as in TLC.
```

### WORKED EXAMPLE 11.1

**Q. In a TLC experiment the solvent front moved 8.0 cm from the base line while
compound A moved 3.2 cm and compound B moved 6.0 cm. Calculate the Rf of each and
say which is more strongly adsorbed.**

**ANSWER:**
```
            3.2
  Rf(A)  =  -----  =  0.40
            8.0

            6.0
  Rf(B)  =  -----  =  0.75
            8.0

  A moved LESS, so A is held MORE strongly by the adsorbent.
  B moved further, so B is less strongly adsorbed and would come out
  FIRST in a column.
```

## 11.9 CHOOSING THE RIGHT METHOD (exam decision table)

| The compound is ... | Use |
|---|---|
| a solid that sublimes | Sublimation |
| a solid, solubility differs from the impurity | Crystallisation |
| a liquid with a non-volatile impurity | Simple distillation |
| a liquid, b.p. differs by more than ~25 K | Simple distillation |
| a liquid, b.p. differs by less than ~25 K | Fractional distillation |
| a liquid that decomposes on boiling | Distillation under reduced pressure |
| steam-volatile and immiscible with water | Steam distillation |
| dissolved in water, soluble in ether | Differential extraction |
| a mixture of many similar compounds, small amount | Chromatography |

# TOPIC 12 — QUALITATIVE ANALYSIS (which elements are present?)

## 12.1 DETECTION OF CARBON AND HYDROGEN

```
  METHOD: heat the organic compound with dry COPPER(II) OXIDE, CuO,
          in a hard glass tube.

     C  +  2 CuO   --(heat)-->   2 Cu  +  CO2
    2 H  +   CuO   --(heat)-->     Cu  +  H2O

  TEST FOR CARBON  (as CO2):
     pass the gas into LIME WATER (Ca(OH)2)

         CO2  +  Ca(OH)2   -->   CaCO3 (white ppt)  +  H2O

     OBSERVATION: lime water turns MILKY  ->  CARBON is present.

  TEST FOR HYDROGEN  (as H2O):
     pass the vapour over ANHYDROUS COPPER SULPHATE (white)

         CuSO4  +  5 H2O   -->   CuSO4 . 5H2O   (BLUE)

     OBSERVATION: white anhydrous CuSO4 turns BLUE
                  -> HYDROGEN is present.
     (Anhydrous calcium chloride in a U-tube gains mass - also used.)
```

## 12.2 LASSAIGNE'S TEST (sodium fusion test) — for N, S, X and P

```
  WHY IT IS NEEDED:
  N, S, X and P are held by COVALENT bonds in an organic compound.
  Covalent compounds do not ionise, so they give no ionic tests.
  We must first CONVERT them into IONIC sodium salts.

  PREPARATION OF THE SODIUM FUSION EXTRACT (Lassaigne's extract):
     * A small piece of dry SODIUM METAL is heated in an ignition tube
       until it melts.
     * The organic compound is added and the tube is heated to
       RED HOT.
     * The red-hot tube is plunged into DISTILLED WATER in a china dish.
     * The mixture is boiled, then FILTERED.
     * The clear filtrate is the SODIUM FUSION EXTRACT.

  THE FUSION REACTIONS:

     Na  +  C  +  N            --(fuse)-->   NaCN
    2Na  +  S                  --(fuse)-->   Na2S
     Na  +  X   (X = Cl,Br,I)  --(fuse)-->   NaX
     Na  +  C  +  N  +  S      --(fuse)-->   NaSCN
                                             (when BOTH N and S present)
     P   +  5 Na (then oxidised)-->  Na3PO4 (as sodium phosphate)
```

### (a) TEST FOR NITROGEN

```
  To the extract add FeSO4 solution, BOIL, cool, then add
  concentrated H2SO4 (or dilute).

     6 NaCN  +  FeSO4   -->   Na4[Fe(CN)6]  +  Na2SO4
                              sodium hexacyanoferrate(II)

     3 Na4[Fe(CN)6]  +  4 Fe3+  -->  Fe4[Fe(CN)6]3  +  12 Na+
                                     FERRIC FERROCYANIDE

  OBSERVATION:  a PRUSSIAN BLUE colour or precipitate
                (sometimes green if the amount is small)
                ->  NITROGEN is present.

  FAILURE CASE (asked in exams):
     DIAZONIUM SALTS give a NEGATIVE Lassaigne test for nitrogen
     because they lose nitrogen as N2 gas on gentle heating,
     before fusion can occur.
```

### (b) TEST FOR SULPHUR

```
  TEST 1 - sodium nitroprusside:

     Na2S  +  Na2[Fe(CN)5NO]   -->   Na4[Fe(CN)5NOS]

     OBSERVATION: deep VIOLET / PURPLE colour  ->  SULPHUR present.

  TEST 2 - lead acetate:
     acidify the extract with acetic acid, then add lead acetate

     Na2S  +  (CH3COO)2Pb   -->   PbS  +  2 CH3COONa
                                  BLACK precipitate

     OBSERVATION: BLACK precipitate of lead sulphide -> SULPHUR present.
```

### (c) TEST WHEN NITROGEN AND SULPHUR ARE BOTH PRESENT

```
  If sodium is in EXCESS, NaSCN is destroyed and normal NaCN and Na2S
  tests work. If sodium is NOT in excess, NaSCN survives and gives:

     3 NaSCN  +  FeCl3   -->   Fe(SCN)3  +  3 NaCl

     OBSERVATION: BLOOD RED colour  ->  BOTH N and S are present.
                  (No Prussian blue is obtained in this case.)
```

### (d) TEST FOR HALOGENS

```
  Acidify the sodium fusion extract with DILUTE NITRIC ACID
  (this destroys any NaCN or Na2S - VERY IMPORTANT, they would
  otherwise give white AgCN / black Ag2S and spoil the test),
  BOIL it off, then add SILVER NITRATE solution.

     NaX  +  AgNO3   -->   AgX  +  NaNO3

  +---------+------------------------+---------------------------+
  | HALOGEN | PRECIPITATE            | SOLUBILITY IN NH4OH       |
  +---------+------------------------+---------------------------+
  |  Cl     | WHITE   (AgCl)         | completely soluble        |
  |  Br     | PALE YELLOW (AgBr)     | sparingly soluble         |
  |  I      | YELLOW  (AgI)          | INSOLUBLE                 |
  +---------+------------------------+---------------------------+

  Fluorine is NOT detected this way - AgF is soluble in water.
```

### (e) TEST FOR PHOSPHORUS

```
  The compound is heated with an oxidising agent - sodium peroxide -
  which converts phosphorus into SODIUM PHOSPHATE.
  The solution is boiled with conc. HNO3 and AMMONIUM MOLYBDATE
  is added.

  Na3PO4 + 12 (NH4)2MoO4 + 21 HNO3
        -->  (NH4)3PO4 . 12 MoO3  +  21 NH4NO3  +  12 H2O
             ammonium phosphomolybdate

  OBSERVATION:  a YELLOW precipitate  ->  PHOSPHORUS is present.
```

### THE FULL COLOUR SUMMARY

```
  +--------------+---------------------------+---------------------+
  |  ELEMENT     |  REAGENT                  |  OBSERVATION        |
  +--------------+---------------------------+---------------------+
  |  Carbon      |  CuO then lime water      |  milky              |
  |  Hydrogen    |  CuO then anhy. CuSO4     |  white -> BLUE      |
  |  Nitrogen    |  FeSO4 + H2SO4            |  PRUSSIAN BLUE      |
  |  Sulphur     |  sodium nitroprusside     |  VIOLET             |
  |  Sulphur     |  lead acetate             |  BLACK ppt          |
  |  N and S     |  FeCl3                    |  BLOOD RED          |
  |  Chlorine    |  HNO3 + AgNO3             |  WHITE ppt          |
  |  Bromine     |  HNO3 + AgNO3             |  PALE YELLOW ppt    |
  |  Iodine      |  HNO3 + AgNO3             |  YELLOW ppt         |
  |  Phosphorus  |  HNO3 + ammonium molybdate|  YELLOW ppt         |
  +--------------+---------------------------+---------------------+
```

> **TRAP:** If you forget to boil the halide test solution with dilute HNO3 first,
> cyanide and sulphide ions also precipitate with AgNO3 and you get a false
> positive. Examiners give a whole mark for mentioning this step.

# TOPIC 13 — QUANTITATIVE ANALYSIS (how much of each element?)

Every one of these is the same idea:

```
  Convert the element into a WEIGHABLE (or MEASURABLE) compound,
  weigh it, then scale back using the atomic masses.

              mass of element in the product      100
   % element = ------------------------------  x  ----
              molar mass of the product           mass of compound taken
                        x  mass of product
```

## 13.1 ESTIMATION OF CARBON AND HYDROGEN (Liebig's method)

```
  A known mass of the compound is burnt in a stream of dry oxygen
  over hot CuO. All the carbon -> CO2 , all the hydrogen -> H2O.

     * the H2O is absorbed in a weighed U-tube of ANHYDROUS CaCl2
     * the CO2 is absorbed in a weighed bulb of KOH solution
     (the CaCl2 tube MUST come first, otherwise KOH absorbs the water too)

  +----------------------------------------------------------------+
  |                                                                |
  |                12       mass of CO2 formed                     |
  |     % C   =  ------ x  ---------------------- x 100            |
  |                44       mass of compound (w)                   |
  |                                                                |
  |                                                                |
  |                 2        mass of H2O formed                    |
  |     % H   =  ------ x  ---------------------- x 100            |
  |                18       mass of compound (w)                   |
  |                                                                |
  +----------------------------------------------------------------+

  WHERE THE NUMBERS COME FROM:
     CO2 has molar mass 44, of which 12 is carbon.
     H2O has molar mass 18, of which 2 is hydrogen (TWO H atoms!).
```

### WORKED EXAMPLE 13.1

**Q. 0.246 g of an organic compound on combustion gave 0.198 g of CO2 and 0.1014 g
of H2O. Calculate the percentages of carbon and hydrogen.**

**ANSWER:**
```
            12       0.198
  % C  =  ------ x  --------- x 100
            44       0.246

          =  0.27273 x 0.80488 x 100

          =  21.95 %          about 21.95 % carbon


             2       0.1014
  % H  =  ------ x  --------- x 100
            18       0.246

          =  0.11111 x 0.41220 x 100

          =  4.58 %           about 4.58 % hydrogen
```

## 13.2 ESTIMATION OF NITROGEN — METHOD 1: DUMAS METHOD

```
  PRINCIPLE: the compound is heated with EXCESS COPPER OXIDE in an
  atmosphere of CO2. The nitrogen of the compound is set free as
  N2 gas (any oxides of nitrogen formed are reduced back to N2 by
  passing over HOT COPPER GAUZE). The N2 is collected over a
  concentrated KOH solution (which absorbs the CO2) and its volume
  is measured.

     C(x)H(y)N(z)  +  (2x + y/2) CuO
              -->  x CO2  +  (y/2) H2O  +  (z/2) N2  +  (2x + y/2) Cu

  +----------------------------------------------------------------+
  |                                                                |
  |                28   x   V (volume of N2 at STP, in mL)         |
  |     % N   =  -------------------------------------- x 100      |
  |                22400   x   w (mass of compound, g)             |
  |                                                                |
  |   28    = molar mass of N2                                     |
  |   22400 = volume in mL occupied by 1 mole of gas at STP        |
  |                                                                |
  +----------------------------------------------------------------+

  IF THE VOLUME IS NOT MEASURED AT STP, first correct it:

              P1 V1        P2 V2                    P1 V1 T2
             -------  =   -------      so    V2  =  ---------
               T1           T2                       T1 P2

     with P2 = 760 mm , T2 = 273 K.
     REMEMBER to subtract the AQUEOUS TENSION (vapour pressure of
     water) from the measured pressure if the gas was collected
     over water.
```

### WORKED EXAMPLE 13.2

**Q. In a Dumas estimation, 0.35 g of an organic compound gave 55 mL of nitrogen
collected at 300 K and 715 mm pressure. Calculate the percentage of nitrogen.
(Aqueous tension at 300 K = 15 mm.)**

**ANSWER:**
```
  STEP 1 - correct the pressure:
      P1 = 715 - 15 = 700 mm      V1 = 55 mL      T1 = 300 K

  STEP 2 - convert the volume to STP:

              P1 V1 T2         700 x 55 x 273
      V2  =  ----------   =  -------------------
              T1 P2            300 x 760

              10510500
          =  -----------   =   46.10 mL at STP
               228000

  STEP 3 - apply the formula:

               28  x  46.10
      % N  =  ---------------- x 100
               22400  x  0.35

               1290.8
          =  ----------- x 100
                7840

          =  16.46 %          about 16.5 % nitrogen
```

## 13.3 ESTIMATION OF NITROGEN — METHOD 2: KJELDAHL'S METHOD

```
  PRINCIPLE: the compound is heated with CONCENTRATED H2SO4 (with
  K2SO4 to raise the boiling point and CuSO4 as catalyst). All the
  nitrogen is converted into AMMONIUM SULPHATE. The mixture is then
  made alkaline with NaOH and the liberated AMMONIA is distilled into
  a KNOWN EXCESS of standard acid. The acid left over is
  back-titrated with standard alkali.

     Organic compound  +  H2SO4  --(heat)-->  (NH4)2SO4

     (NH4)2SO4  +  2 NaOH   -->   Na2SO4  +  2 NH3  +  2 H2O

     2 NH3  +  H2SO4   -->   (NH4)2SO4

  +----------------------------------------------------------------+
  |                                                                |
  |                1.4  x  M(acid)  x  V(acid used, mL)  x  basicity|
  |     % N   =  ---------------------------------------------------|
  |                          w  (mass of compound, g)              |
  |                                                                |
  |   (with NORMALITY instead of molarity:)                        |
  |                                                                |
  |                1.4  x  N(acid)  x  V(acid used in mL)          |
  |     % N   =  -------------------------------------------       |
  |                          w                                     |
  |                                                                |
  |   V(acid used) = V(acid taken)  -  V(acid neutralised by the   |
  |                                     NaOH in the back titration)|
  |                                                                |
  |   The 1.4 comes from:  14 (atomic mass of N) x 100 / 1000       |
  +----------------------------------------------------------------+

  KJELDAHL'S METHOD DOES NOT WORK FOR:
     * compounds containing N in a RING (pyridine, quinoline)
     * AZO compounds (-N=N-)
     * NITRO compounds (-NO2)
     because their nitrogen is not converted to ammonium sulphate.

  IT IS THE STANDARD METHOD for proteins, food, fertilisers and soils.
```

### WORKED EXAMPLE 13.3

**Q. 0.5 g of an organic compound was Kjeldahlised and the ammonia evolved was
absorbed in 50 mL of 1 N H2SO4. The excess acid required 30 mL of 1 N NaOH.
Find the percentage of nitrogen.**

**ANSWER:**
```
  Acid taken            =  50 mL of 1 N
  Acid neutralised by NaOH (unused) = 30 mL of 1 N
  Acid ACTUALLY used by the ammonia = 50 - 30 = 20 mL of 1 N

             1.4  x  1  x  20        28
   % N  =  -------------------  =  ------  =  56 %
                  0.5               0.5

   % N = 56 %
```

```

## 13.7 ESTIMATION OF OXYGEN

```
  Oxygen is usually found BY DIFFERENCE:

  +----------------------------------------------------------------+
  |                                                                |
  |   % O  =  100  -  ( %C + %H + %N + %S + %X + %P + ... )        |
  |                                                                |
  +----------------------------------------------------------------+

  DIRECT METHOD (rarely asked): the compound is decomposed by heating
  in a stream of nitrogen. The mixture of gases is passed over
  RED HOT COKE, turning all the oxygen into CO, which is then passed
  over warm IODINE PENTOXIDE, I2O5:

       2 C  +  O2   --(1373 K)-->   2 CO
       I2O5  +  5 CO   -->   I2  +  5 CO2

  +----------------------------------------------------------------+
  |               32         mass of CO2 formed                    |
  |    % O   =  -------  x  --------------------  x  100           |
  |               88         mass of compound                      |
  |                                                                |
  |  (5 CO2 = 220 carry 5 O of the compound = 80, i.e. 32/88 per   |
  |   CO2 of 44)                                                   |
  +----------------------------------------------------------------+
```

### WORKED EXAMPLE 13.6 — full analysis to an empirical formula

**Q. An organic compound contains 40.0 % C, 6.7 % H and the rest oxygen. Its
molecular mass is 180. Find its empirical and molecular formula.**

**ANSWER:**
```
  STEP 1  % O  =  100 - (40.0 + 6.7)  =  53.3 %

  STEP 2  divide each percentage by the atomic mass:

           C :  40.0 / 12   =  3.33
           H :   6.7 / 1    =  6.70
           O :  53.3 / 16   =  3.33

  STEP 3  divide by the SMALLEST (3.33):

           C :  3.33 / 3.33  =  1
           H :  6.70 / 3.33  =  2.01  ~  2
           O :  3.33 / 3.33  =  1

  EMPIRICAL FORMULA  =  CH2O
  Empirical formula mass = 12 + 2 + 16 = 30

  STEP 4       molecular mass       180
        n  =  ------------------ = ------  =  6
              empirical mass         30

  MOLECULAR FORMULA  =  (CH2O)6  =  C6H12O6      (glucose)
```

> **TRAP:** In `% H = (2/18) x ...` the numerator is **2**, not 1, because one
> molecule of water carries **two** hydrogen atoms. Writing 1/18 is the single most
> common arithmetic slip in this chapter.
