# Organic Chemistry — Basic Principles — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The molecule changes every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — WHY DOES CARBON FORM SO MANY COMPOUNDS?         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define catenation", "Why is carbon unique?",
            "Why does carbon form a large number of compounds?"
  METHOD    Write ALL of these, one line each:
              1. TETRAVALENCY - 4 valence electrons, 4 covalent bonds
              2. CATENATION - C-C bond is short and strong
                 (348 kJ/mol) so chains and rings of any length form
              3. It forms SINGLE, DOUBLE and TRIPLE bonds
              4. It bonds strongly to H, O, N, S and halogens
  TRAP      Giving only ONE reason. Two reasons = two marks.
            If asked "why not silicon?", add: Si-Si is only
            297 kJ/mol and Si-H is attacked by air and water.
```

```
  PATTERN 2 — HYBRIDISATION OF A GIVEN CARBON                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   A structure with mixed bonds, "state the hybridisation of
            each carbon in ...".
  METHOD    Look ONLY at the bonds on that carbon:
              4 single bonds ............... sp3  (109 deg 28 min)
              part of ONE double bond ...... sp2  (120 deg)
              part of a TRIPLE bond ........ sp   (180 deg)
              between TWO double bonds ..... sp   (allene centre)
            Always quote the SHAPE and the ANGLE with the answer.
  TRAP      The carbon of -COOH , -CHO , >C=O is sp2, NOT sp3.
            It has a C=O double bond. Look for multiple bonds FIRST.
```

```
  PATTERN 3 — SHAPES OF CH4 / C2H4 / C2H2                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the shapes of methane, ethene and ethyne on the
            basis of hybridisation."
  METHOD    For EACH molecule write five things:
              1. which orbitals mix (1s + 3p / 1s + 2p / 1s + 1p)
              2. how many hybrid orbitals and the % s character
              3. the SHAPE and the ANGLE
              4. how many sigma and pi bonds and how they are formed
              5. the bond lengths (109 / 134 / 120 pm) and a DIAGRAM
  TRAP      Forgetting to say that in ethene ONE p orbital and in
            ethyne TWO p orbitals stay UNHYBRIDISED - that is where
            the pi bonds come from and it carries a mark.
```

```
  PATTERN 4 — CONVERT BETWEEN STRUCTURAL / CONDENSED /
              BOND-LINE FORMULAS                              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the bond-line formula of ...", "Expand the
            condensed formula ...".
  METHOD    Bond-line rules:
              every LINE = a bond
              every END and CORNER = a CARBON
              C and H are not written; O, N, X ARE written
              add H mentally until every carbon has 4 bonds
  TRAP      Forgetting that the END of a zig-zag is a carbon too.
            A 3-segment zig-zag is BUTANE (4 C), not propane.
```

```
  PATTERN 5 — WRITE THE IUPAC NAME OF A STRUCTURE           2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Any structure with "give the IUPAC name".
  METHOD    1. Find the LONGEST chain that CONTAINS the functional
               group. It may turn corners.
            2. Identify the PRINCIPAL functional group by PRIORITY:
               COOH > SO3H > COOR > COX > CONH2 > CN > CHO > C=O
               > OH > NH2 > C=C > C(triple)C
               (-R, -X, -NO2, -OR are prefixes ONLY)
            3. NUMBER so the functional group gets the lowest locant;
               then the multiple bond; then the substituents.
            4. Name substituents ALPHABETICALLY, ignore di/tri.
            5. Assemble:
               prefix + root + primary suffix + secondary suffix
  TRAP      * -CHO and -COOH carbons are C1 and are INSIDE the chain.
            * Alphabetical, NOT numerical, order of substituents.
            * Repeat locants: "2,2-dimethyl", never "2-dimethyl".
```

```
  PATTERN 6 — WRITE THE STRUCTURE FROM A NAME                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the structure of 3-methylbut-1-yne."
  METHOD    1. Read the ROOT -> draw that many carbons in a row.
            2. Read the SUFFIX -> put the double/triple bond or the
               functional group at the stated number.
            3. Hang the PREFIX substituents on the stated carbons.
            4. Fill in hydrogens until EVERY carbon has 4 bonds.
  TRAP      Not checking the four-bond rule at the end. A carbon with
            5 bonds costs the whole mark.
```

```
  PATTERN 7 — SPOT THE WRONG IUPAC NAME                       objective
  ------------------------------------------------------------------------
  TRIGGER   "Which of the following names is incorrect?"
  METHOD    Check in this order:
              1. could the locant have been SMALLER from the other end?
              2. are the substituents in ALPHABETICAL order?
              3. is the parent chain really the LONGEST one containing
                 the functional group?
              4. are locants repeated for di/tri prefixes?
  TRAP      "3-methylbutane" and "2-ethylpropane" are the two classic
            wrong names (correct: 2-methylbutane, 2-methylbutane).
```

```
  PATTERN 8 — DEFINE A HOMOLOGOUS SERIES / FUNCTIONAL GROUP   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is a homologous series? Give its characteristics."
  METHOD    Definition + at least THREE characteristics:
              same general formula
              successive members differ by CH2 (14 u)
              same functional group -> similar chemical properties
              physical properties change gradually
              same general method of preparation
            Always add ONE example series with formulas.
  TRAP      Writing only the definition. The word "characteristics"
            means a LIST is expected.
```

```
  PATTERN 9 — CLASSIFY THE COMPOUND                           2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Classify as acyclic / alicyclic / aromatic /
            heterocyclic", "distinguish alicyclic from aromatic".
  METHOD    open chain           -> ACYCLIC (aliphatic)
            ring of carbon only  -> CARBOCYCLIC
                 not conjugated  -> ALICYCLIC (cyclohexane)
                 (4n+2) pi, planar -> AROMATIC (benzene)
            ring with O, N or S  -> HETEROCYCLIC (pyridine, furan)
  TRAP      "Aromatic" is not about smell. Quote HUCKEL'S RULE:
            planar + cyclic + fully conjugated + (4n+2) pi electrons.
```

```
  PATTERN 10 — NAME THE TYPE OF ISOMERISM IN A GIVEN PAIR     2 marks
  ------------------------------------------------------------------------
  TRIGGER   Two structures side by side, "what is the relationship
            between them?"
  METHOD    Ask in this order:
              same functional group?  NO  -> FUNCTIONAL isomers
              skeleton different?     YES -> CHAIN isomers
              group at a different position? -> POSITION isomers
              group in the MIDDLE with an unequal alkyl split?
                                             -> METAMERS
              differ by a shifted H and a shifted double bond?
                                             -> TAUTOMERS
              same connections, different 3-D arrangement?
                                             -> STEREOISOMERS
  TRAP      Metamerism only applies to ETHERS, KETONES, ESTERS and
            SECONDARY AMINES. Do not use an alkane example.
```

```
  PATTERN 11 — DRAW ALL THE ISOMERS OF A FORMULA            2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write all the isomers of C4H10O / C4H9Br / C5H12."
  METHOD    1. Work out the DEGREE OF UNSATURATION first:
                 DoU = (2C + 2 + N - H - X) / 2
              2. Draw ALL the CARBON SKELETONS (straight, then each
                 branched one).
              3. On EACH skeleton, put the functional group at every
                 DISTINCT position.
              4. If the class allows a different functional group
                 (alcohol/ether, aldehyde/ketone, acid/ester),
                 do that family too.
              5. Cross out duplicates by mentally rotating.
              6. NAME every isomer - the names carry marks.
  TRAP      * Counting the SAME compound twice (1-bromobutane drawn
              from the other end).
            * "Structural isomers" means DO NOT count cis and trans.
            Known counts: C4H10 = 2, C5H12 = 3, C4H9Br = 4,
                          C3H8O = 3, C4H10O = 7 (4 alcohols+3 ethers)
```

```
  PATTERN 12 — DOES IT SHOW GEOMETRICAL ISOMERISM?            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Which of these shows cis-trans isomerism?"
  METHOD    1. Is there a C=C (or a ring)? If not -> NO.
            2. Look at EACH doubly bonded carbon separately.
               Each must carry TWO DIFFERENT groups.
            3. Draw both forms and label cis (same side) and trans
               (opposite sides).
            4. Add the properties: trans is MORE STABLE, has a HIGHER
               melting point and ZERO dipole moment (for identical
               groups); cis has a net dipole moment.
  TRAP      CH2=CH-R never shows it - the CH2 carbon carries two
            identical hydrogens. Same for CH2=CR2.
```

```
  PATTERN 13 — IS IT OPTICALLY ACTIVE?                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Which compound contains a chiral carbon?",
            "Which is optically active?"
  METHOD    1. Test each carbon: list its FOUR attachments.
            2. Any repeat -> not chiral. All four different -> CHIRAL.
            3. Number of optical isomers = 2^n (n = chiral centres).
            4. Vocabulary that earns marks: enantiomers,
               non-superimposable mirror images, dextrorotatory (d/+),
               laevorotatory (l/-), racemic mixture (optically
               inactive by external compensation), plane polarised
               light.
  TRAP      Counting H as "different" from another H. Two hydrogens on
            the same carbon kill chirality immediately.
```

```
  PATTERN 14 — HOMOLYTIC vs HETEROLYTIC FISSION               2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define homolytic and heterolytic fission."
  METHOD    HOMOLYTIC   - pair splits EQUALLY, one electron each
                        - FISH-HOOK (half-headed) arrows
                        - gives FREE RADICALS
                        - conditions: UV light, heat, peroxides,
                          non-polar solvent
                        - example: Cl2 --(UV)--> 2 Cl.
            HETEROLYTIC - ONE atom takes BOTH electrons
                        - full CURVED arrow
                        - gives IONS (carbocation + anion)
                        - conditions: polar bond, polar solvent
                        - example: CH3Br --> CH3+ + Br-
  TRAP      Forgetting to name the PRODUCT type. "Free radicals" and
            "ions" are each worth a mark.
```

```
  PATTERN 15 — SHAPE OF A CARBOCATION / CARBANION /
               FREE RADICAL                                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Give the shape and hybridisation of a carbanion."
  METHOD    CARBOCATION  sp2 , PLANAR   , 120 deg , empty p orbital
            FREE RADICAL sp2 , PLANAR   , 120 deg , odd e- in p
            CARBANION    sp3 , PYRAMIDAL, ~109 deg, lone pair in sp3
            Draw the little diagram - it earns the second mark.
  TRAP      Saying the carbanion is planar. It is PYRAMIDAL, like
            ammonia, because of the LONE PAIR.
```

```
  PATTERN 16 — STABILITY ORDER OF INTERMEDIATES             2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange in increasing order of stability ...",
            "Which carbocation is most stable?"
  METHOD    CARBOCATION and FREE RADICAL:
                3 deg > 2 deg > 1 deg > methyl
                REASON 1: +I effect of alkyl groups
                REASON 2: HYPERCONJUGATION (9, 6, 3, 0 alpha H)
            CARBANION:
                methyl > 1 deg > 2 deg > 3 deg   (REVERSED)
                REASON: +I push worsens an already negative centre
            Benzyl and allyl beat 3 deg because of RESONANCE.
  TRAP      Giving only ONE reason for the carbocation order. Write
            BOTH +I and hyperconjugation.
            Writing the carbanion order the same way round as the
            carbocation order - the most punished error in the chapter.
```

```
  PATTERN 17 — ELECTROPHILE OR NUCLEOPHILE?                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define electrophile and nucleophile", "classify the
            following species".
  METHOD    lone pair or NEGATIVE charge  -> NUCLEOPHILE (Lewis base)
                OH-, CN-, X-, NH3, H2O, ROH, R3N
            empty orbital or POSITIVE     -> ELECTROPHILE (Lewis acid)
                H+, NO2+, R+, BF3, AlCl3, FeCl3, SO3, :CH2
            Give ONE cationic/anionic AND one NEUTRAL example each.
  TRAP      Calling BF3 or AlCl3 a nucleophile because they "have no
            charge". Charge is irrelevant - the INCOMPLETE OCTET makes
            them electrophiles.
```

```
  PATTERN 18 — INDUCTIVE EFFECT AND ACID STRENGTH           2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange in order of acid strength", "explain the
            inductive effect".
  METHOD    1. Define: PERMANENT, PARTIAL displacement of SIGMA
               electrons; dies out after 3 carbons.
            2. -I groups WITHDRAW -> stabilise RCOO- -> MORE acidic
               order: NO2 > CN > COOH > F > Cl > Br > I > OH > OR
            3. +I groups RELEASE -> LESS acidic
               order: (CH3)3C > (CH3)2CH > C2H5 > CH3 > H
            4. MORE -I groups = stronger acid
               CLOSER to -COOH = stronger acid
  TRAP      Forgetting the DISTANCE rule. An alpha-chloro acid is much
            stronger than a gamma-chloro acid of the same formula.
```

```
  PATTERN 19 — ELECTROMERIC EFFECT                          2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the electromeric effect? Explain +E and -E."
  METHOD    Definition: COMPLETE transfer of a PI electron pair to one
            atom, ONLY in the presence of an attacking reagent,
            TEMPORARY.
            +E : pi electrons move TOWARDS the atom the reagent
                 attaches to.   CH2=CH2 + H+ -> CH3-CH2+
            -E : pi electrons move AWAY from it.
                 >C=O + CN- -> the pair goes to OXYGEN
            Finish with the comparison table against the inductive
            effect (sigma/pi, partial/complete, permanent/temporary,
            reagent needed or not).
  TRAP      Saying it is permanent. The word TEMPORARY is the mark.
```

```
  PATTERN 20 — RESONANCE: RULES AND RESONANCE ENERGY          4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is resonance? Write the rules." / "Define resonance
            energy."
  METHOD    1. Define: hybrid of canonical structures; only the
               HYBRID is real.
            2. Give at least SIX rules:
               only electrons move; atoms do not move; same number of
               paired electrons; all atoms in one plane; more covalent
               bonds = more stable; complete octet = more stable;
               separated charges = less stable; negative charge on the
               most electronegative atom.
            3. Draw the TWO Kekule structures of benzene.
            4. Resonance energy = energy of the most stable canonical
               form minus the actual energy of the hybrid.
               Benzene: 359 - 208.6 = about 150 kJ/mol.
            5. Consequence: all C-C bonds 139 pm; benzene prefers
               SUBSTITUTION over addition.
  TRAP      Saying the molecule "oscillates between" the structures.
            It does NOT. It is ONE hybrid at all times.
```

```
  PATTERN 21 — RESONANCE vs TAUTOMERISM                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between resonance and tautomerism."
  METHOD    RESONANCE      only ELECTRONS shift
                           structures are IMAGINARY
                           only the hybrid is real
                           arrow  <-->
            TAUTOMERISM    an ATOM (usually H) actually MIGRATES
                           both forms are REAL
                           dynamic EQUILIBRIUM
                           arrow  <====>
            Give keto-enol as the tautomerism example and benzene as
            the resonance example.
  TRAP      Drawing keto-enol with a resonance arrow, or benzene with
            an equilibrium arrow. The ARROW itself carries a mark.
```

```
  PATTERN 22 — HYPERCONJUGATION                             2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is hyperconjugation?", "Why is (CH3)3C+ more stable
            than CH3+?", "arrange the alkenes in order of stability".
  METHOD    1. Define: delocalisation of SIGMA (C-H) electrons of an
               ALPHA carbon into an adjacent empty p / half-filled p /
               pi orbital.
            2. Say it is NO-BOND RESONANCE (Baker-Nathan effect) and
               explain WHY that name - the C-H bond is shown broken.
            3. COUNT ALPHA HYDROGENS. Structures = alpha H.
            4. Draw at least one no-bond structure.
            5. State what it explains: carbocation order, radical
               order, alkene order (Saytzeff), -CH3 activating the
               benzene ring, shortened C-C in propene (149 pm),
               dipole moment of propene.
  TRAP      Counting hydrogens on the WRONG carbon. ALPHA = the carbon
            NEXT TO the charged / radical / doubly bonded carbon.
```

```
  PATTERN 23 — IDENTIFY THE TYPE OF REACTION                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   An equation with "name the type of reaction".
  METHOD    something REPLACED, skeleton same    -> SUBSTITUTION
            two molecules become ONE, pi lost    -> ADDITION
            small molecule LOST, pi formed       -> ELIMINATION
            same formula, atoms rearranged       -> REARRANGEMENT
            Then name the RULE if one applies:
               addition of HX  -> MARKOVNIKOV
               HX + peroxide   -> ANTI-MARKOVNIKOV (HBr only)
               elimination     -> SAYTZEFF
  TRAP      "Alcoholic KOH" gives ELIMINATION; "aqueous KOH" gives
            SUBSTITUTION. One word changes the answer.
```

```
  PATTERN 24 — WHICH PURIFICATION METHOD AND WHY?           2 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "How would you purify ...?", "Why is aniline purified by
            steam distillation?"
  METHOD    Match the clue to the method:
              sublimes ................ SUBLIMATION
              solubility differs ...... CRYSTALLISATION
              b.p. gap > 25 K ......... SIMPLE DISTILLATION
              b.p. gap < 25 K ......... FRACTIONAL DISTILLATION
              decomposes on boiling ... REDUCED PRESSURE DISTILLATION
              immiscible + steam
                volatile .............. STEAM DISTILLATION
              dissolved in water ...... DIFFERENTIAL EXTRACTION
              complex mixture ......... CHROMATOGRAPHY
            ALWAYS write: PRINCIPLE + WHAT IT IS USED FOR + EXAMPLE.
            For the 8-mark version, add a labelled ASCII diagram for
            sublimation, distillation and the separating funnel.
  TRAP      Giving the method with no PRINCIPLE. The principle is
            usually worth more than the name.
```

```
  PATTERN 25 — CHROMATOGRAPHY AND Rf                        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the principle of chromatography", "calculate the
            Rf value".
  METHOD    1. Principle: components move at different speeds over a
               stationary phase under a mobile phase.
            2. ADSORPTION (solid stationary phase) -> COLUMN and TLC
               PARTITION (liquid stationary phase) -> PAPER
               In paper chromatography the stationary phase is WATER
               held in the paper pores.
            3.        distance moved by the substance
               Rf = ------------------------------------
                     distance moved by the solvent front
            4. SMALL Rf = strongly adsorbed = elutes LAST.
  TRAP      Saying the paper itself is the stationary phase in paper
            chromatography. It is the WATER in the paper.
```

```
  PATTERN 26 — DETECTION OF CARBON AND HYDROGEN               2 marks
  ------------------------------------------------------------------------
  TRIGGER   "How do you detect carbon and hydrogen in an organic
            compound?"
  METHOD    Heat with dry CuO.
              C + 2CuO -> 2Cu + CO2 ;  2H + CuO -> Cu + H2O
              CO2 + Ca(OH)2 -> CaCO3 : lime water turns MILKY
              white anhydrous CuSO4 -> BLUE CuSO4.5H2O
  TRAP      Writing the observation without the EQUATION, or the
            equation without the observation. Both are needed.
```

```
  PATTERN 27 — LASSAIGNE'S TEST                             2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is nitrogen / sulphur / a halogen detected?"
  METHOD    1. Say WHY: the elements are COVALENTLY bound, so they
               must be converted into IONIC sodium salts.
            2. Preparation of the sodium fusion extract (fuse with Na,
               plunge into water, boil, filter).
                 Na+C+N -> NaCN ; 2Na+S -> Na2S ; Na+X -> NaX ;
                 Na+C+N+S -> NaSCN
            3. Then the specific test with EQUATION and COLOUR:
                 N   : FeSO4 + H2SO4  -> PRUSSIAN BLUE
                 S   : nitroprusside  -> VIOLET
                       lead acetate   -> BLACK PbS
                 N+S : FeCl3          -> BLOOD RED
                 X   : dil HNO3 then AgNO3 ->
                       Cl WHITE / Br PALE YELLOW / I YELLOW
                 P   : HNO3 + ammonium molybdate -> YELLOW
  TRAP      Forgetting to BOIL WITH DILUTE HNO3 before the AgNO3 test.
            Without it, CN- and S2- give false precipitates.
            Also remember: DIAZONIUM SALTS give a negative N test.
```

```
  PATTERN 28 — ESTIMATION OF CARBON AND HYDROGEN (numerical) 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "x g of a compound gave y g of CO2 and z g of H2O."
  METHOD          12     mass of CO2
            %C = ---- x -------------- x 100      (12/44 = 0.2727)
                  44    mass of compound

                   2     mass of H2O
            %H = ---- x -------------- x 100      (2/18  = 0.1111)
                  18    mass of compound

            Then  %O = 100 - (%C + %H + everything else)
  TRAP      Writing 1/18 instead of 2/18. Water has TWO hydrogens.
            This single slip is the most common error in the chapter.
```

```
  PATTERN 29 — DUMAS METHOD NUMERICAL                       2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "... gave V mL of nitrogen at T K and P mm pressure."
  METHOD    1. If not at STP, correct the pressure first:
                 P1 = measured P - AQUEOUS TENSION
              2. Convert to STP:
                          P1 x V1 x 273
                 V(STP) = ---------------
                            T1 x 760
              3.              28 x V(STP in mL)
                 % N  =  ------------------------ x 100
                            22400 x w
  TRAP      Forgetting the aqueous tension when the gas was collected
            over water, or forgetting to convert to STP at all.
            Keep the volume in mL to match the 22400.
```

```
  PATTERN 30 — KJELDAHL METHOD NUMERICAL                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "The ammonia was absorbed in V1 mL of N1 acid; the excess
            required V2 mL of alkali."
  METHOD    1. Acid USED = V1 - V2  (in the same normality)
              2.          1.4 x N(acid) x V(acid used)
                 % N  =  ------------------------------
                                    w
  TRAP      Using the acid TAKEN instead of the acid USED.
            Also remember Kjeldahl FAILS for ring nitrogen, azo and
            nitro compounds - that is a separate 2-mark question.
```

```
  PATTERN 31 — CARIUS / SULPHUR / PHOSPHORUS NUMERICAL      2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "... gave m g of AgCl / BaSO4 / Mg2P2O7."
  METHOD          at. mass of X     mass of AgX
            %X = --------------- x -------------- x 100
                  molar mass AgX   mass of compound
                 Cl 35.5/143.5 , Br 80/188 , I 127/235

                  32    mass of BaSO4
            %S = ---- x --------------- x 100
                  233   mass of compound

                  62    mass of Mg2P2O7
            %P = ---- x ----------------- x 100
                  222   mass of compound
  TRAP      Using 31/222 for phosphorus. Mg2P2O7 contains TWO
            phosphorus atoms, so the numerator is 62.
            Similarly BaSO4 = 233, not 137.
```

```
  PATTERN 32 — EMPIRICAL AND MOLECULAR FORMULA              4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "A compound contains x% C, y% H ... its molecular mass /
            vapour density is ..."
  METHOD    1. If oxygen is not given, %O = 100 - (all the others).
              2. Divide each PERCENTAGE by its ATOMIC MASS.
              3. Divide all the answers by the SMALLEST one.
              4. If fractions remain (0.5, 0.33), multiply ALL by
                 2 or 3.  -> EMPIRICAL FORMULA
              5. Molecular mass = 2 x vapour density (if V.D. given).
                 n = molecular mass / empirical formula mass
                 MOLECULAR FORMULA = (empirical formula) x n
  TRAP      Rounding 2.5 down to 2. Multiply everything by 2 instead.
            Forgetting M = 2 x V.D.
```

```
  PATTERN 33 — DEGREE OF UNSATURATION                        objective
  ------------------------------------------------------------------------
  TRIGGER   "How many rings / double bonds does CxHyNzXw have?"
  METHOD              2C + 2 + N - H - X
            DoU  =  ---------------------      (ignore oxygen)
                             2
            0 -> saturated open chain
            1 -> one ring OR one C=C
            2 -> one triple bond, or two of ring/double
            4 -> suspect a BENZENE ring
  TRAP      Including oxygen in the formula. Oxygen NEVER counts.
            Halogens count like hydrogen (subtract them).
```
