## THE 60-SECOND VERSION

Organic chemistry is the chemistry of **carbon compounds**. There are over 10 million
of them, and only ONE reason why:

```
  CARBON IS SPECIAL BECAUSE OF TWO THINGS
  ---------------------------------------

  1. TETRAVALENCY   - carbon has 4 valence electrons, so it makes
                      exactly 4 strong covalent bonds.

  2. CATENATION     - carbon atoms join to OTHER CARBON ATOMS in
                      chains and rings of unlimited length.
                      (C-C bond is short and strong: 348 kJ/mol)

  Nothing else in the periodic table does both well.
  Silicon tries -> Si-Si bond is weak, chains break.
```

Then the chapter answers five questions, in this order:

```
  1. What shape is the molecule?      ->  HYBRIDISATION  (sp3, sp2, sp)
  2. How do I draw it?                ->  structural / condensed / bond-line
  3. What do I call it?               ->  IUPAC NOMENCLATURE
  4. Same formula, different molecule? ->  ISOMERISM
  5. Why does it react the way it does? -> BOND FISSION + ELECTRONIC EFFECTS
```

And then the last third of the chapter is **laboratory work**: how to purify an
organic compound, how to find which elements are in it, and how to find how much.

**If you understand only "carbon = 4 bonds + catenation", you already have the
opening line of the 8-mark question.**

## THE KEY BOX — THE TWO THINGS THAT UNLOCK MOST QUESTIONS

**BOX 1 — the hybridisation table. Half the objective questions die here.**

```
  +--------+----------------+---------+----------+---------------+----------+
  | HYBRID | s : p mixing   | SHAPE   | ANGLE    | BOND TYPES    | EXAMPLE  |
  +--------+----------------+---------+----------+---------------+----------+
  |  sp3   | 1 s + 3 p      | tetra-  | 109 deg  | 4 sigma       |  CH4     |
  |        | 25% s char.    | hedral  | 28 min   | (all single)  |  C2H6    |
  +--------+----------------+---------+----------+---------------+----------+
  |  sp2   | 1 s + 2 p      | trigonal| 120 deg  | 3 sigma       |  C2H4    |
  |        | 33.3% s char.  | planar  |          | + 1 pi        |  benzene |
  +--------+----------------+---------+----------+---------------+----------+
  |  sp    | 1 s + 1 p      | linear  | 180 deg  | 2 sigma       |  C2H2    |
  |        | 50% s char.    |         |          | + 2 pi        |  HCN     |
  +--------+----------------+---------+----------+---------------+----------+

  SHORTCUT to spot hybridisation of any carbon:
       4 single bonds ................ sp3
       1 double bond (+2 single) ..... sp2
       1 triple bond (+1 single) ..... sp
       2 double bonds  (C=C=C) ....... sp
```

## THE STABILITY LADDERS (learn as one picture)

Almost every 4-mark "explain the order" question is one of these four ladders,
and they are all explained by the SAME two ideas (+I effect and hyperconjugation).

```
  CARBOCATION  (electron DEFICIENT - wants electron push)

      3 deg   >   2 deg   >   1 deg   >   CH3+
     (CH3)3C+   (CH3)2CH+   CH3CH2+
      most                              least stable
      REASON:  more alkyl groups = more +I push + more hyperconjugation

  FREE RADICAL  (same order, same reason)

      3 deg   >   2 deg   >   1 deg   >   CH3.

  CARBANION  (electron RICH - alkyl groups DESTABILISE it)

      CH3-   >   1 deg   >   2 deg   >   3 deg
                                       ORDER IS REVERSED

  ALKENE STABILITY (hyperconjugation - count alpha H)

      (CH3)2C=C(CH3)2  >  CH3-CH=CH-CH3  >  CH3-CH=CH2  >  CH2=CH2
       12 alpha H          6 alpha H        3 alpha H      0 alpha H
```

> **The single most common mistake in the whole chapter:** writing the carbanion
> order the same way as the carbocation order. It is BACKWARDS. Carbanion already
> has a negative charge; pushing MORE electrons onto it makes it WORSE.

```

                            -> filtered water extract

  +-----------+---------------------------+-------------------------------+
  | ELEMENT   | REAGENT ADDED             | OBSERVATION                   |
  +-----------+---------------------------+-------------------------------+
  | NITROGEN  | FeSO4, then boil, then    | PRUSSIAN BLUE / green         |
  |           | H2SO4                     | (Fe4[Fe(CN)6]3)               |
  +-----------+---------------------------+-------------------------------+
  | SULPHUR   | sodium nitroprusside      | VIOLET / purple               |
  |           | lead acetate              | BLACK ppt (PbS)               |
  +-----------+---------------------------+-------------------------------+
  | N AND S   | FeCl3                     | BLOOD RED (Fe(SCN)3)          |
  | together  |                           |                               |
  +-----------+---------------------------+-------------------------------+
  | HALOGEN   | HNO3, then AgNO3          | Cl -> WHITE ppt, sol. in NH3  |
```

## IF YOU ONLY HAVE 3 DAYS

```
  DAY 1   MORNING   Tetravalency + catenation + the hybridisation table.
                    Bond-line notation - practise reading 20 structures.
          AFTERNOON Functional group table (memorise) + homologous series.
          EVENING   *** IUPAC NOMENCLATURE *** - the 4 rules.
                    Name 30 compounds. Write structures for 15 names.
          -> secures about 6 marks (2 in Section A, 4 in Section B)

  DAY 2   MORNING   Isomerism: draw ALL isomers of C4H10, C5H12, C4H9Br,
                    C4H10O, C3H6O. Chain / position / functional /
                    metamerism / tautomerism. Then cis-trans.
          AFTERNOON Bond fission -> free radical, carbocation, carbanion.
                    SHAPES + STABILITY ORDERS + reasons.
                    Electrophiles vs nucleophiles.
          EVENING   *** ELECTRONIC EFFECTS *** I, E, R, Hyperconjugation.
                    Write each definition + one example + what it explains.
          -> secures about 8 more marks

  DAY 3   MORNING   *** PURIFICATION *** - 8 methods, one line of principle
                    and one line of "used for" each. This is the easiest
                    8-mark answer in the entire syllabus. Pure recall.
          AFTERNOON Lassaigne's test - 4 equations, 4 colours.
                    Test for C and H.
          EVENING   The 7 percentage formulas + work 6 numericals.
          -> secures the 8-mark long answer

  IF YOU ONLY HAVE 1 DAY:
      Hybridisation table  +  IUPAC rules  +  Purification methods
      +  Lassaigne colours.  That is still 10+ marks. Do not panic.
```
