# PATTERN 1 — HYBRIDISATION, SHAPE AND BOND ANGLE
# ===============================================================

### Q1
The hybridisation of the carbon atoms in `CH3-CH=CH-C(triple)CH` from left to
right is:

(a) sp3, sp2, sp2, sp, sp  (b) sp3, sp3, sp2, sp, sp
(c) sp2, sp2, sp, sp, sp3  (d) sp3, sp2, sp2, sp2, sp

**ANSWER: (a)**
```
   C1 has 4 single bonds       -> sp3
   C2 and C3 are in a C=C      -> sp2
   C4 and C5 are in a triple   -> sp
```

> **SHORTCUT:** 4 singles = sp3, one double = sp2, one triple = sp.
> Never think about orbitals in the exam hall — just count multiple bonds.

---

### Q2
Which of the following has a bond angle of 180 degrees?

(a) CH4  (b) C2H4  (c) C2H2  (d) NH3

**ANSWER: (c)**
```
   sp -> linear -> 180 deg.  Ethyne is the only sp carbon here.
   CH4 = 109 deg 28 min , C2H4 = 120 deg , NH3 = 107 deg.
```

---

### Q3
The percentage of s character in an sp2 hybrid orbital is:

(a) 25 %  (b) 33.3 %  (c) 50 %  (d) 75 %

**ANSWER: (b)**
```
   sp2 = 1 s + 2 p = 3 orbitals ; s share = 1/3 = 33.3 %
   sp3 = 25 % , sp = 50 %
```

---

### Q4
The correct order of C-C bond length is:

(a) ethane > ethene > ethyne  (b) ethyne > ethene > ethane
(c) ethene > ethane > ethyne  (d) all equal

**ANSWER: (a)**
```
   C-C 154 pm  >  C=C 134 pm  >  C(triple)C 120 pm
   More s character = electrons held closer = shorter bond.
```

---

### Q5
The carbon-carbon bond length in benzene is:

(a) 154 pm  (b) 134 pm  (c) 120 pm  (d) 139 pm

**ANSWER: (d)**
```
   All six bonds are identical at 139 pm - between a single bond
   (154) and a double bond (134) - because of RESONANCE.
```

# PATTERN 2 — COUNTING SIGMA AND PI BONDS
# ===============================================================

### Q6
The number of sigma and pi bonds in `CH2=CH-C(triple)CH` is:

(a) 7 sigma, 3 pi  (b) 6 sigma, 3 pi  (c) 7 sigma, 2 pi  (d) 8 sigma, 3 pi

**ANSWER: (a)**
```
   Structure:  CH2 = CH - C (triple) CH        (C4H4)

   C-H bonds  :  2 + 1 + 0 + 1  =  4 sigma
   C-C bonds  :  3 links        =  3 sigma
   TOTAL SIGMA = 7

   pi bonds   :  1 (from the double) + 2 (from the triple) = 3 pi
```

> **SHORTCUT:**
> sigma = (total number of bond LINES counting each multiple bond as ONE)
> pi = (number of doubles) + 2 x (number of triples)

---

### Q7
The number of sigma and pi bonds in benzene is:

(a) 12 sigma, 3 pi  (b) 6 sigma, 3 pi  (c) 12 sigma, 6 pi  (d) 9 sigma, 3 pi

**ANSWER: (a)**
```
   6 C-C sigma  +  6 C-H sigma  =  12 sigma
   3 alternating double bonds   =   3 pi
```

# PATTERN 3 — IUPAC NAME FROM A STRUCTURE
# ===============================================================

### Q8
The IUPAC name of `(CH3)3C-CH2-CH3` is:

(a) 2,2-dimethylbutane  (b) 3,3-dimethylbutane
(c) 2-methylpentane     (d) neohexane

**ANSWER: (a)**
```
   Expand:            CH3
                       |
             CH3 - C - CH2 - CH3
                       |
                      CH3

   Longest chain = 4 C (butane). Two methyls on C2 counting from
   the left. Locant set (2,2) beats (3,3).
```

---

### Q9
The IUPAC name of `CH3-CH(OH)-CH2-CHO` is:

(a) 3-hydroxybutanal  (b) 2-hydroxybutanal
(c) 3-hydroxybutan-1-al  (d) 1-hydroxybutan-3-al

**ANSWER: (a)**
```
   -CHO beats -OH, so -CHO takes the suffix -al and its carbon is C1.
   Numbering from CHO:  C1 = CHO , C2 = CH2 , C3 = CH(OH) , C4 = CH3
   -OH becomes the prefix "hydroxy" on C3.
```

### Q10
The IUPAC name of `CH3-CH=CH-COOH` is:

(a) but-2-enoic acid  (b) but-3-enoic acid
(c) 2-butenoic acid   (d) crotonic acid

**ANSWER: (a)**
```
   -COOH carbon is ALWAYS C1.
   C1 = COOH , C2 = CH , C3 = CH , C4 = CH3
   Double bond begins at C2  ->  but-2-enoic acid.
   ("Crotonic acid" is the trivial name, not the IUPAC name.)
```

### Q11
The correct IUPAC name of the compound with a methyl on C3, an ethyl on C3 and
a chain of 6 carbons is:

(a) 3-ethyl-3-methylhexane  (b) 3-methyl-3-ethylhexane
(c) 4-ethyl-4-methylhexane  (d) 3,3-ethylmethylhexane

**ANSWER: (a)**
```
   Substituents go in ALPHABETICAL order: Ethyl before Methyl.
```

> **SHORTCUT:** alphabetise ignoring di/tri/tetra, but DO count iso, neo and cyclo.

### Q12
Which is the correct IUPAC name for `CH3-CH2-CH(CH3)-CH2-CH(CH3)-CH3`?

(a) 2,4-dimethylhexane  (b) 3,5-dimethylhexane
(c) 2,4-dimethylpentane (d) 3-methylheptane

**ANSWER: (a)**
```
   Longest chain = 6 C -> hexane. Methyls sit on C2 and C4 from the
   right, or C3 and C5 from the left.
   Compare (2,4) with (3,5): at the FIRST POINT OF DIFFERENCE 2 < 3,
   so (2,4) wins.
```

The molecular formula of 3-methylbut-1-yne is:

### Q17
The number of monochlorination products (ignoring stereoisomers) obtained from
2-methylbutane is:

(a) 2  (b) 3  (c) 4  (d) 5

**ANSWER: (c)**
```
   2-methylbutane:   CH3 - CH(CH3) - CH2 - CH3
                      C1     C2       C3    C4

   Distinct kinds of hydrogen:
     * the two methyls on C2 are EQUIVALENT -> 1-chloro-2-methylbutane
     * the C2 hydrogen                      -> 2-chloro-2-methylbutane
     * the C3 hydrogens                     -> 2-chloro-3-methylbutane
     * the C4 hydrogens                     -> 1-chloro-3-methylbutane

   4 products.
```

> **SHORTCUT:** count the number of **distinct types of hydrogen**, not the number
> of hydrogens.

# PATTERN 6 — GEOMETRICAL AND OPTICAL ISOMERISM
# ===============================================================

### Q20
Which of the following exhibits geometrical isomerism?

(a) 1-butene  (b) 2-butene  (c) 2-methyl-1-propene  (d) propene

**ANSWER: (b)**
```
   Condition: EACH doubly bonded carbon must carry TWO DIFFERENT groups.

   but-2-ene :  CH3-CH=CH-CH3 -> each carbon carries H and CH3. YES.
   but-1-ene :  CH2=CH-... -> the CH2 carbon carries H and H. NO.
   2-methylpropene : CH2=C(CH3)2 -> the CH2 carbon carries H and H. NO.
   propene   :  same problem. NO.
```

---

### Q21
The dipole moment of trans-but-2-ene is:

(a) maximum  (b) zero  (c) equal to that of cis  (d) 1.8 D

**ANSWER: (b)**
```
   In the trans form the two identical CH3 groups pull in OPPOSITE
   directions, so the bond moments cancel exactly.
   The cis form has a small net dipole moment.
   Consequence: trans has a HIGHER melting point (packs better) and
   is MORE STABLE (less steric crowding).
```

---

### Q22
Which of the following contains a chiral carbon?

(a) CH3CH2CH2Cl  (b) CH3CHClCH3  (c) CH3CHClCH2CH3  (d) CCl4

**ANSWER: (c)**
```
   2-chlorobutane: the C2 carries CH3 , Cl , C2H5 and H
   -> FOUR DIFFERENT groups -> CHIRAL -> optically active.

   In (b) the carbon carries two identical CH3 groups.
```

> **SHORTCUT:** put your finger on the suspect carbon and list its four
> attachments. Any repeat kills chirality.

---

### Q23
A compound has 2 dissimilar chiral centres. The number of optical isomers is:

(a) 2  (b) 3  (c) 4  (d) 8

**ANSWER: (c)**
```
   number of optical isomers  =  2^n  =  2^2  =  4
```

# PATTERN 7 — STABILITY OF INTERMEDIATES
# ===============================================================

### Q24
The most stable carbocation among the following is:

(a) CH3+  (b) CH3CH2+  (c) (CH3)2CH+  (d) (CH3)3C+

**ANSWER: (d)**
```
   3 deg > 2 deg > 1 deg > methyl.
   Reasons: (i) +I push of the alkyl groups reduces the positive
   charge, (ii) hyperconjugation - 9 alpha H against 6, 3 and 0.
```

---

### Q25
The correct order of stability of carbanions is:

(a) 3 deg > 2 deg > 1 deg > CH3-  (b) CH3- > 1 deg > 2 deg > 3 deg
(c) 1 deg > 2 deg > 3 deg > CH3-  (d) all are equally stable

**ANSWER: (b)**
```
   THE ORDER IS REVERSED for carbanions. The carbon already carries a
   negative charge; the +I effect of alkyl groups pushes MORE
   electron density onto it, intensifying the charge and
   DESTABILISING it.
```

> **SHORTCUT:** cation and radical follow 3>2>1>CH3. Carbanion is the ONLY one
> that is backwards. Exam setters live on this.

---

### Q26
The shape of a carbanion is:

(a) planar  (b) linear  (c) pyramidal  (d) tetrahedral

**ANSWER: (c)**
```
   Carbanion : sp3 , PYRAMIDAL (like NH3), angle a little under 109.5
   Carbocation and free radical : sp2 , PLANAR , 120 deg
```

---

### Q27
Which free radical is the most stable?

(a) CH3.  (b) C6H5-CH2.  (c) CH3CH2.  (d) (CH3)2CH.

**ANSWER: (b)**
```
   The BENZYL radical is stabilised by RESONANCE with the ring (the
   odd electron is delocalised over the ortho and para positions), and
   resonance is STRONGER than hyperconjugation.

   Full order: benzyl ~ allyl > 3 deg > 2 deg > 1 deg > methyl
```

# PATTERN 8 — ELECTROPHILE OR NUCLEOPHILE
# ===============================================================

### Q28
Which of the following is NOT a nucleophile?

(a) NH3  (b) H2O  (c) BF3  (d) CN-

**ANSWER: (c)**
```
   BF3 has only 6 electrons on boron and an EMPTY p orbital, so it
   ACCEPTS an electron pair -> ELECTROPHILE (Lewis acid).
   NH3, H2O and CN- all have lone pairs -> nucleophiles.
```

### Q29
The species `NO2+` acts as:

(a) a nucleophile  (b) an electrophile  (c) a free radical  (d) a base

**ANSWER: (b)**
```
   Positively charged and electron deficient -> ELECTROPHILE.
   It is the attacking species in the NITRATION of benzene.
```

---

### Q30
An ambident nucleophile among the following is:

(a) OH-  (b) CN-  (c) Cl-  (d) H2O

**ANSWER: (b)**
```
   CN- can attack through CARBON (giving R-CN, a nitrile) or through
   NITROGEN (giving R-NC, an isocyanide). NO2- is the other common
   ambident nucleophile.
```

# ===============================================================

### Q31
The strongest acid among the following is:

(a) CH3COOH  (b) ClCH2COOH  (c) Cl2CHCOOH  (d) Cl3CCOOH

**ANSWER: (d)**
```
   More -I chlorine atoms pull more electron density away from the
   -COOH group, weaken the O-H bond and stabilise the carboxylate
   anion formed.

   Cl3CCOOH > Cl2CHCOOH > ClCH2COOH > CH3COOH
   (pKa   0.7   <   1.3   <   2.9    <   4.76)
```

### Q32
Arrange in decreasing order of acid strength:
`FCH2COOH` , `ClCH2COOH` , `BrCH2COOH` , `ICH2COOH`

(a) F > Cl > Br > I  (b) I > Br > Cl > F
(c) Cl > F > Br > I  (d) all equal

**ANSWER: (a)**
```
   The -I effect follows electronegativity: F > Cl > Br > I.
   The stronger the -I effect, the stronger the acid.
```

```
   More alkyl carbons = more electron push.
```

# ===============================================================

### Q34
The resonance energy of benzene is approximately:

(a) 36 kJ/mol  (b) 150 kJ/mol  (c) 208 kJ/mol  (d) 359 kJ/mol

**ANSWER: (b)**
```
   expected heat of hydrogenation  =  3 x 119.7  =  359 kJ/mol
   observed heat of hydrogenation  =            208.6 kJ/mol
   RESONANCE ENERGY = 359 - 208.6 = about 150 kJ/mol
```

### Q35
According to Huckel's rule, a compound is aromatic if it is planar, cyclic,
fully conjugated and contains:

(a) 4n pi electrons  (b) (4n + 2) pi electrons
(c) 2n pi electrons  (d) (2n + 1) pi electrons

**ANSWER: (b)**
```
   Benzene: 6 pi electrons -> 4n + 2 = 6 -> n = 1 -> AROMATIC.
   Systems with 4n pi electrons (like cyclobutadiene, 4) are
   ANTIAROMATIC and unstable.
```

---

### Q36
Which statement about resonance is FALSE?

(a) only electrons move  (b) the canonical structures are imaginary
(c) atoms change position (d) all contributing atoms lie in one plane

**ANSWER: (c)**
```
   In RESONANCE the ATOMS NEVER MOVE - only electrons are
   redistributed. If an atom moves, it is TAUTOMERISM.
```

---

### Q37
Which group is ortho-para directing AND ring activating?

(a) -NO2  (b) -CN  (c) -NH2  (d) -COOH

**ANSWER: (c)**
```
   -NH2 has a lone pair, shows a +R effect, pushes electron density
   into the ring at the ORTHO and PARA positions -> ACTIVATING and
   o,p-DIRECTING.
   -NO2, -CN and -COOH are -R, deactivating, META directing.
```

### Q38
The number of hyperconjugative (no-bond resonance) structures for the
tert-butyl carbocation `(CH3)3C+` is:

(a) 3  (b) 6  (c) 9  (d) 12

The most stable alkene among the following is:

(a) CH2=CH2  (b) CH3-CH=CH2  (c) CH3-CH=CH-CH3  (d) (CH3)2C=C(CH3)2

# PATTERN 13 — CHOOSING THE PURIFICATION METHOD
# ===============================================================

### Q42
A liquid that decomposes at its normal boiling point is best purified by:

(a) simple distillation  (b) steam distillation
(c) distillation under reduced pressure  (d) sublimation

**ANSWER: (c)**
```
   Lowering the external pressure lowers the boiling temperature, so
   the compound distils before it can decompose.
   Classic example: GLYCEROL (563 K normally, 453 K under vacuum).
```

---

### Q43
Aniline is purified by:

(a) crystallisation  (b) steam distillation
(c) sublimation  (d) fractional distillation

**ANSWER: (b)**
```
   Aniline is IMMISCIBLE with water and VOLATILE IN STEAM. Its normal
   boiling point is 457 K, but in steam distillation the mixture
   boils at about 371 K, well below 373 K, so it distils over safely.
```

---

### Q44
Two liquids whose boiling points differ by 8 K are best separated by:

(a) simple distillation  (b) fractional distillation
(c) sublimation  (d) differential extraction

**ANSWER: (b)**
```
   Simple distillation needs a gap of about 25 K or more. Below that
   a FRACTIONATING COLUMN is required - it provides repeated
   condensation/evaporation cycles.
```

---

### Q45
Camphor is purified by:

(a) crystallisation  (b) sublimation
(c) distillation  (d) chromatography

**ANSWER: (b)**
```
   Camphor SUBLIMES. Other sublimable solids: naphthalene, anthracene,
   benzoic acid, ammonium chloride, iodine.
```

---

### Q46
In column chromatography the component that is MOST strongly adsorbed:

(a) comes out first  (b) comes out last
(c) has the highest Rf  (d) does not move at all

**ANSWER: (b)**
```
   Strongly adsorbed = held tightly = moves SLOWLY = elutes LAST
   and has a SMALL Rf value.
```

---

### Q47
In paper chromatography the stationary phase is:

(a) the cellulose of the paper  (b) water held in the paper pores
(c) the developing solvent  (d) silica gel

**ANSWER: (b)**
```
   Paper chromatography is PARTITION chromatography. The stationary
   phase is WATER trapped in the pores of the paper; the paper itself
   is only the support.
```

### Q49
A yellow precipitate insoluble in ammonium hydroxide on adding AgNO3 to the
acidified sodium fusion extract indicates:

(a) chlorine  (b) bromine  (c) iodine  (d) fluorine

**ANSWER: (c)**
```
   AgCl  - WHITE      , fully soluble in NH4OH
   AgBr  - PALE YELLOW, sparingly soluble
   AgI   - YELLOW     , INSOLUBLE in NH4OH
```

### Q50
Which compound gives a NEGATIVE Lassaigne test for nitrogen even though it
contains nitrogen?

(a) urea  (b) aniline  (c) a diazonium salt  (d) nitrobenzene

```
   Diazonium salts lose their nitrogen as N2 GAS on gentle heating,
   before the sodium fusion can form NaCN.
```

### Q51
The sodium fusion extract is boiled with dilute nitric acid before adding
AgNO3 in order to:

(a) dissolve the silver halide  (b) destroy cyanide and sulphide ions

(a) 5 %  (b) 10 %  (c) 14 %  (d) 20 %

**ANSWER: (b)**
```
              28  x  22.4                627.2
   % N  =  ------------------ x 100  = ---------- x 100
             22400  x  0.28               6272

        =  0.1 x 100  =  10 %
```

### Q56
A compound contains 40 % C, 6.7 % H and 53.3 % O with a molecular mass of 180.
Its molecular formula is:

(a) CH2O  (b) C2H4O2  (c) C6H12O6  (d) C3H6O3

**ANSWER: (c)**
```
   C : 40/12   = 3.33  ->  3.33/3.33 = 1
   H : 6.7/1   = 6.70  ->  6.70/3.33 = 2
   O : 53.3/16 = 3.33  ->  3.33/3.33 = 1
   Empirical formula = CH2O  (mass 30)

   n = 180 / 30 = 6   ->   C6H12O6   (glucose)
```

### Q58
`CH3-CH=CH2 + HBr --> CH3-CHBr-CH3` is an example of:

(a) elimination following Saytzeff's rule
(b) electrophilic addition following Markovnikov's rule
(c) nucleophilic substitution
(d) free radical substitution

**ANSWER: (b)**
```
   The H adds to the carbon carrying MORE hydrogens, giving the more
   stable SECONDARY carbocation, so Br ends up on C2.
   That is MARKOVNIKOV'S RULE.
```

---

### Q59
`CH3CH2Br + alcoholic KOH --> CH2=CH2` is:

(a) substitution  (b) addition  (c) elimination  (d) rearrangement

**ANSWER: (c)**
```
   HBr is removed and a double bond is formed -> ELIMINATION
   (dehydrohalogenation). With AQUEOUS KOH it would be SUBSTITUTION
   giving ethanol instead - watch the word "alcoholic".
```

---

### Q60
The conversion `NH4CNO --(heat)--> NH2CONH2` is an example of:

(a) substitution  (b) addition  (c) elimination  (d) rearrangement

**ANSWER: (d)**
```
   Same molecular formula, atoms reorganised inside the molecule
   -> REARRANGEMENT. (This is Wohler's famous 1828 synthesis of urea,
   which destroyed the vital force theory.)
```
