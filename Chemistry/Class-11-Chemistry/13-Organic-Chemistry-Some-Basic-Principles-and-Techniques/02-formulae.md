  +--------+---------+-----------+----------+---------+---------------+

  |        |         |            | 28 min  |         | diamond       |
  +--------+---------+-----------+----------+---------+---------------+

  |        |         | planar     |         | + 1 pi  | HCHO, R3C+,   |
  |        |         |            |         |         | R3C. radical  |

```

| Fact | When to use |
|---|---|
| 4 single bonds -> sp3 | identifying hybridisation of any carbon |
| 1 double bond -> sp2 | identifying hybridisation of any carbon |
| 1 triple bond or 2 doubles -> sp | identifying hybridisation of any carbon |
| more s character = shorter, stronger bond | bond length / strength ordering |
| more s character = more electronegative C | acidity of alkyne vs alkene vs alkane |

```
  BOND DATA TO QUOTE
  +----------------------+-----------+-------------------------------+
  |  C - C               |  154 pm   |  348 kJ/mol                   |
  |  C = C               |  134 pm   |  ethene                       |
  |  C (triple) C        |  120 pm   |  ethyne                       |
  |  C - C in benzene    |  139 pm   |  all six identical            |
  |  C - H  (sp3)        |  109 pm   |  methane, 414 kJ/mol          |

```
  DEGREE OF UNSATURATION  (very useful for isomer questions)

  +-----------------------------------------------------------------+
  |                                                                 |
  |                        2C + 2 + N - H - X                       |
  |     DoU   =   --------------------------------                  |
  |                             2                                   |
  |                                                                 |
  |     C = carbon atoms, H = hydrogens, N = nitrogens,             |
  |     X = halogens.  Oxygen is IGNORED.                           |
  |                                                                 |
  |     DoU = 0  ->  saturated, open chain                          |
  |     DoU = 1  ->  ONE ring OR ONE double bond                    |
  |     DoU = 2  ->  two of (ring / double bond) OR one triple bond |
  |     DoU = 4  ->  suspect a BENZENE RING                         |
  +-----------------------------------------------------------------+

  Example: C4H8   ->  (8 + 2 - 8)/2 = 1  -> one ring OR one C=C
           C6H6   ->  (12 + 2 - 6)/2 = 4 -> benzene

```
  +----------------------------------------------------------------------+
  |   HIGHEST                                                            |
  |     1  -COOH        acid          -oic acid                          |
  |     2  -SO3H        sulphonic     -sulphonic acid                    |
  |     3  -COOR        ester         alkyl -oate                        |
  |     4  -COX         acid halide   -oyl halide                        |
  |     5  -CONH2       amide         -amide                             |
  |     6  -CN          nitrile       -nitrile                           |
  |     7  -CHO         aldehyde      -al                                |
  |     8  >C=O         ketone        -one                               |
  |     9  -OH          alcohol       -ol                                |
  |    10  -NH2         amine         -amine                             |
  |    11  C=C          alkene        -ene                               |
  |    12  C(triple)C   alkyne        -yne                               |
  |                                                                      |
  |    ALWAYS PREFIX:  -R  -X  -NO2  -OR                                 |
  |   LOWEST                                                             |
  +----------------------------------------------------------------------+

  MEMORY:  Acid  Sulphonic  Ester  Acid-halide  Amide  Nitrile
           Aldehyde  Ketone  Alcohol  Amine  Ene  Yne
```

**THE NUMBERING PRIORITY (which gets the lowest locant):**

```
   1st  principal FUNCTIONAL GROUP  (the suffix)
   2nd  DOUBLE / TRIPLE bond
   3rd  SUBSTITUENTS (prefixes)
   4th  if still tied -> FIRST POINT OF DIFFERENCE (2,3,5 beats 2,4,5)
   5th  if still tied -> the group first in ALPHABETICAL order
```

# 5. TYPES OF ISOMERISM — the decision table

| Type | What differs | Test example |
|---|---|---|
| CHAIN | the carbon skeleton (straight vs branched) | n-butane / isobutane |
| POSITION | the position of the group or the double bond | propan-1-ol / propan-2-ol |
| FUNCTIONAL | the functional group itself | ethanol / methoxymethane |
| METAMERISM | unequal alkyl split across the group | CH3-O-C3H7 / C2H5-O-C2H5 |
| TAUTOMERISM | an H atom actually migrates, equilibrium | keto / enol |
| GEOMETRICAL | arrangement about a C=C | cis- / trans-but-2-ene |
| OPTICAL | mirror images about a chiral carbon | d- / l-2-chlorobutane |

```
  CONDITIONS - memorise these two lines:

  GEOMETRICAL ISOMERISM needs:  a C=C  AND  each doubly bonded carbon
                                carrying TWO DIFFERENT groups.

  OPTICAL ISOMERISM needs:      a CHIRAL (asymmetric) carbon -
                                one carbon bonded to FOUR DIFFERENT
                                groups.

  NUMBER OF OPTICAL ISOMERS  =  2^n     where n = number of
                                        dissimilar chiral centres
```

```
  +----------------+--------------+-------------+---------------+
  |                | FREE RADICAL | CARBOCATION | CARBANION     |
  +----------------+--------------+-------------+---------------+
  | Symbol         |  R .         |  R+         |  R :-         |
  | Charge         |  neutral     |  +1         |  -1           |
  | e- on carbon   |  7           |  6          |  8            |
  | Hybridisation  |  sp2         |  sp2        |  sp3          |
  | Shape          |  PLANAR      |  PLANAR     |  PYRAMIDAL    |
  | Bond angle     |  120 deg     |  120 deg    |  ~109 deg     |
  | Formed by      |  HOMOLYTIC   |  HETEROLYTIC|  HETEROLYTIC  |
  |                |  fission     |  fission    |  fission      |
  | Arrow used     |  fish hook   |  full curved|  full curved  |
  |                |  (half head) |  arrow      |  arrow        |
  | Stability      | 3>2>1>CH3    | 3>2>1>CH3   | CH3>1>2>3     |
  |                |              |             |  (REVERSED)   |
  +----------------+--------------+-------------+---------------+
```

| Fact | When to use |
|---|---|
| homolytic -> radicals; needs UV, heat, peroxide | "which fission occurs in Cl2 + UV?" |
| heterolytic -> ions; needs a polar bond/solvent | "what forms when CH3Br ionises?" |
| carbocation and radical are FLAT (sp2) | shape questions, SN1 racemisation |
| carbanion is PYRAMIDAL (sp3) | shape questions |
| carbanion order is REVERSED | the classic trick question |
| allyl and benzyl are resonance stabilised, very stable | ranking questions |

# 7. ELECTROPHILES AND NUCLEOPHILES

```
  ELECTROPHILE = electron deficient = LEWIS ACID = accepts a pair

     Cationic : H+ , Cl+ , Br+ , I+ , NO2+ , NO+ , R+ , RCO+ , C6H5N2+
     Neutral  : BF3 , AlCl3 , FeCl3 , ZnCl2 , SO3 , CO2 ,
                carbene :CH2 , the C of >C=O

  NUCLEOPHILE = electron rich = LEWIS BASE = donates a pair

     Anionic  : OH- , OR- , CN- , X- , RCOO- , NH2- , R- , HS- , H-
     Neutral  : H2O , ROH , NH3 , RNH2 , R2NH , R3N , R-O-R , R-SH

  ONE-LINE TEST:
     lone pair or negative charge  ->  NUCLEOPHILE
     empty orbital or positive     ->  ELECTROPHILE

  AMBIDENT NUCLEOPHILES:
     CN-   -> attacks by C (gives R-CN) or by N (gives R-NC)
     NO2-  -> attacks by N (gives R-NO2) or by O (gives R-ONO)
```

# 8. THE FOUR ELECTRONIC EFFECTS

```
  +---------------+-----------+-----------+-----------+---------------+
  | EFFECT        | ELECTRONS | TRANSFER  | NATURE    | NEEDS         |
  +---------------+-----------+-----------+-----------+---------------+
  | INDUCTIVE  I  | sigma     | PARTIAL   | permanent | electroneg.   |
  |               |           |           |           | difference    |
  | ELECTROMERIC E| pi        | COMPLETE  | TEMPORARY | an attacking  |
  |               |           |           |           | reagent       |
  | RESONANCE  R  | pi/lone   | delocalised| permanent| conjugation + |
  |  (mesomeric M)| pair      |           |           | planarity     |
  | HYPERCON-     | sigma C-H | delocalised| permanent| >= 1 ALPHA H  |
  |  JUGATION     |           |           |           |               |
  +---------------+-----------+-----------+-----------+---------------+

  STRENGTH:   RESONANCE  >  HYPERCONJUGATION  >  INDUCTIVE
```

```
  -I  (electron WITHDRAWING) - strongest first
  -----------------------------------------------------------------
  -NH3+ > -NO2 > -CN > -SO3H > -CHO > -CO- > -COOH > -COCl > -CONH2
        > -F > -Cl > -Br > -I > -OH > -OR > -NH2 > -C6H5 > -H

  +I  (electron RELEASING) - strongest first
  -----------------------------------------------------------------
  -O- > -COO- > -C(CH3)3 > -CH(CH3)2 > -CH2CH3 > -CH3 > -H

  +R / +M  (DONATE into the system, need a lone pair)
  -----------------------------------------------------------------
  -O- > -NH2 > -NHR > -OH > -OR > -NHCOR > -X (F>Cl>Br>I)
     -> ACTIVATE the benzene ring , ORTHO-PARA directing
     (halogens are the exception: deactivating but still o,p-directing)

  -R / -M  (WITHDRAW from the system)
  -----------------------------------------------------------------
  -NO2 > -CN > -SO3H > -CHO > -COR > -COOH > -COOR > -CONH2
     -> DEACTIVATE the benzene ring , META directing
```

| Effect | What it explains |
|---|---|
| -I | acid strength increases: Cl3CCOOH > Cl2CHCOOH > ClCH2COOH > CH3COOH |
| +I | carbocation stability 3>2>1; carbanion stability reversed |
| +I | basicity of amines in gas phase (CH3)3N > (CH3)2NH > CH3NH2 > NH3 |
| E effect | electrophilic addition to alkenes, nucleophilic addition to C=O |
| Resonance | benzene bond lengths all equal (139 pm), acidity of phenol, o/p direction |
| Resonance | why benzoic acid > acetic acid; why carboxylate is stable |
| Hyperconjugation | stability of alkenes (Saytzeff), carbocations, radicals; -CH3 activating |

```
  RESONANCE ENERGY

  +-----------------------------------------------------------------+
  |                                                                 |
  |  Resonance energy = (energy of the most stable canonical form)   |
  |                     - (actual energy of the hybrid)             |
  |                                                                 |
  |  BENZENE:  expected DH(hydrogenation) = 3 x 119.7 = 359 kJ/mol  |
  |            observed  DH(hydrogenation) =         208.6 kJ/mol   |
  |            RESONANCE ENERGY  =  359 - 208.6  =  ~150 kJ/mol     |
  |                                                                 |
  +-----------------------------------------------------------------+
```

```
  HYPERCONJUGATIVE STRUCTURE COUNT

  +-----------------------------------------------------------------+
  |   number of no-bond structures  =  number of ALPHA hydrogens    |
  |   (total contributing structures = alpha H + 1)                 |
  +-----------------------------------------------------------------+

     CH3+      0 alpha H       (CH3)2CH+  6 alpha H
     CH3CH2+   3 alpha H       (CH3)3C+   9 alpha H   <- most stable

     CH2=CH2         0        CH3-CH=CH2        3
     CH3CH=CHCH3     6        (CH3)2C=C(CH3)2  12    <- most stable alkene
```

# 9. TYPES OF ORGANIC REACTIONS

| Type | What happens | Example |
|---|---|---|
| SUBSTITUTION | one group replaced by another | `CH4 + Cl2 --(UV)--> CH3Cl + HCl` |
| ADDITION | two molecules become one, pi bond destroyed | `CH2=CH2 + Br2 --> CH2Br-CH2Br` |
| ELIMINATION | small molecule removed, pi bond formed | `CH3CH2Br + alc.KOH --> CH2=CH2 + KBr + H2O` |
| REARRANGEMENT | atoms reorganise inside the same molecule | `NH4CNO --(heat)--> NH2CONH2` |

```
  TWO RULES THAT DECIDE THE MAJOR PRODUCT

  MARKOVNIKOV'S RULE  (ADDITION of HX to an unsymmetrical alkene)
       the H adds to the carbon with MORE hydrogens
       (because that gives the MORE STABLE carbocation)

       CH3-CH=CH2  +  HBr  -->  CH3-CHBr-CH3   (2-bromopropane, major)

  ANTI-MARKOVNIKOV (peroxide / Kharasch effect, HBr ONLY)
       CH3-CH=CH2 + HBr --(peroxide)--> CH3-CH2-CH2Br  (major)
       Works with HBr only, NOT with HCl or HI.

  SAYTZEFF'S RULE  (ELIMINATION)
       the MORE SUBSTITUTED (more stable) alkene is the major product

       CH3-CH2-CHBr-CH3 + alc.KOH --> CH3-CH=CH-CH3 (major, 2-butene)
                                    + CH2=CH-CH2CH3 (minor)
```

# 10. PURIFICATION TECHNIQUES — principle and use

| Method | Principle | Used for | Example |
|---|---|---|---|
| SUBLIMATION | solid -> vapour -> solid, no liquid stage | sublimable solid + non-sublimable impurity | camphor, naphthalene, benzoic acid, NH4Cl, anthracene |
| CRYSTALLISATION | difference in SOLUBILITY in a solvent | solid + soluble impurities | benzoic acid from water; charcoal removes colour |
| SIMPLE DISTILLATION | difference in BOILING POINT (large) | liquid + non-volatile impurity | chloroform (334 K) from aniline (457 K) |
| FRACTIONAL DISTILLATION | repeated condensation-evaporation in a column | b.p. difference LESS than ~25 K | crude oil fractions; acetone (329 K) + methanol (338 K) |
| REDUCED PRESSURE | lower external pressure -> lower b.p. | liquid that DECOMPOSES at its b.p. | glycerol (563 K -> 453 K); sugarcane juice |
| STEAM DISTILLATION | p(compound) + p(water) = atmospheric, so boils below 373 K | steam-volatile, water-immiscible compound + non-volatile impurity | aniline, o-nitrophenol, essential oils |
| DIFFERENTIAL EXTRACTION | different solubility in two immiscible solvents | compound dissolved in water | shake with ether in a separating funnel |
| CHROMATOGRAPHY | differential ADSORPTION or PARTITION | complex mixtures, small quantities | column, TLC, paper |

```
