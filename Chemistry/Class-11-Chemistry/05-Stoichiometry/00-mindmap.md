## THE 60-SECOND VERSION

Atoms are far too small to count one by one. So chemists invented a
**counting unit** called the **mole** — exactly like a "dozen", but much bigger.

```
   1 dozen  =  12 things
   1 mole   =  6.022 x 10^23 things            <- Avogadro's number
```

Once you can convert **grams -> moles**, you can convert **anything into
anything**, because a balanced chemical equation is really a recipe written
in moles.

```
   grams  ---divide by molar mass--->  MOLES  ---mole ratio from equation--->
   MOLES of product  ---multiply by molar mass--->  grams of product
```

**The mole is the middle station. Every road in this chapter passes through it.**

The last part of the chapter (redox) is different: there you track **oxidation
numbers** and make sure electrons lost = electrons gained.

## THE KEY BOX — LEARN THIS ONE THING AND HALF THE CHAPTER IS DONE

```
  +===============================================================+
  |                                                               |
  |                       given mass in g                         |
  |     MOLES    n   =   ------------------                       |
  |                       molar mass  g/mol                       |
  |                                                               |
  |                       number of particles                     |
  |               n   =   ----------------------                  |
  |                        6.022 x 10^23                          |
  |                                                               |
  |                       volume of gas in L at STP               |
  |               n   =   ---------------------------             |
  |                              22.4                             |
  |                                                               |
  |                                                               |
  |     ONE MOLE OF ANY SUBSTANCE                                 |
  |        = 6.022 x 10^23 particles                              |
  |        = molar mass in grams                                  |
  |        = 22.4 litres  (ONLY if it is a GAS, ONLY at STP)      |
  |                                                               |
  +===============================================================+
```

And the second box, for solutions:

```
  +===============================================================+
  |                                                               |
  |                       moles of solute                         |
  |     MOLARITY   M  =  ----------------------                   |
  |                       volume of SOLUTION in litres            |
  |                                                               |
  |                       moles of solute                         |
  |     MOLALITY   m  =  ----------------------                   |
  |                       mass of SOLVENT in kg                   |
  |                                                               |
  |                     10  x  density  x  mass%                  |
  |     LINK:      M = ----------------------------               |
  |                        molar mass of solute                   |
  |                        (density in g/mL)                      |
  |                                                               |
  +===============================================================+
```

**Write both boxes on your palm. Nearly every numerical starts here.**

## THE THREE THINGS BEGINNERS ALWAYS GET WRONG

```
  1.  MOLARITY uses the volume of the SOLUTION, not the solvent.
      MOLALITY uses the mass of the SOLVENT, not the solution.

  2.  22.4 L works ONLY for a GAS and ONLY at STP.
      Never use it for water, salt, or any solid or liquid.

  3.  In a balanced equation the coefficients are MOLE ratios,
      NOT gram ratios. Convert to moles FIRST, always.
```
