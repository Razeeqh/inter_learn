# Stoichiometry — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The numbers change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — STATE A LAW OF CHEMICAL COMBINATION                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "State the law of ... . Give one example."
  METHOD    1. Write the STATEMENT in one clean sentence.
            2. Name the SCIENTIST (Lavoisier, Proust, Dalton, Richter,
               Gay-Lussac, Avogadro).
            3. Give ONE numerical example with actual masses or volumes.
  TRAP      An example WITHOUT numbers scores half marks. Always show the
            actual figures: "12 g of C with 16 g of O in CO and 32 g of O
            in CO2, ratio 1 : 2".
```

```
  PATTERN 2 — VERIFY A LAW FROM GIVEN DATA                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Masses of two compounds of the same two elements are given and
            you are asked "which law does this illustrate / verify it".
  METHOD    1. FIX the mass of one element (usually make it the same
               number in both compounds by scaling).
            2. Compare the masses of the OTHER element.
            3. If they are in a simple whole-number ratio -> LAW OF
               MULTIPLE PROPORTIONS.
            4. Write the ratio clearly, e.g. 16 : 32 = 1 : 2.
  TRAP      You MUST scale one element to the same mass first. Comparing
            raw data without fixing one element proves nothing.
            Two compounds of the SAME pair of elements -> multiple
            proportions. THREE elements involved -> reciprocal proportions.
```

```
  PATTERN 3 — DALTON'S ATOMIC THEORY                          2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State the postulates of Dalton's atomic theory" /
            "What are its limitations?"
  METHOD    Postulates (5): indivisible atoms; identical atoms of the same
            element; different elements have different atoms; fixed whole
            number ratios in compounds; atoms not created or destroyed.
            Drawbacks: atoms ARE divisible; isotopes break postulate 2;
            isobars break postulate 3; nothing about bonding;
            non-stoichiometric compounds; nuclear reactions.
  TRAP      If the question says "explain which law each postulate
            explains", you must link them: postulate 5 -> conservation of
            mass, postulate 4 -> definite and multiple proportions.
```

```
  PATTERN 4 — AVERAGE ATOMIC MASS FROM ISOTOPES                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   Isotope masses with percentages or fractional abundances.
  METHOD                (m1 x %1) + (m2 x %2) + ...
            average = ---------------------------------
                                    100
            If FRACTIONS are given instead of percentages (they add to 1),
            just multiply and add - do NOT divide by 100.
  TRAP      Check that the percentages add up to 100 before you start.
            If only one abundance is given, the other is (100 - that one).
```

```
  PATTERN 5 — CALCULATE MOLECULAR / FORMULA MASS                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the molecular mass of ..."
  METHOD    Multiply each atomic mass by the number of that atom, then add.
            Show each line separately - it earns method marks.
  TRAP      BRACKETS. Ca(NO3)2 has 2 N and 6 O. Al2(SO4)3 has 3 S and 12 O.
            The DOT in CuSO4.5H2O means "plus 5 water molecules",
            so add 5 x 18 = 90.
            Say "FORMULA mass" for ionic solids like NaCl, not
            "molecular mass".
```

```
  PATTERN 6 — MASS  <->  MOLES                                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "How many moles are present in ... g of ...?" or the reverse.
  METHOD                 given mass (g)
             n   =   ----------------------      mass = n x molar mass
                      molar mass (g/mol)
  TRAP      Compute the molar mass FIRST and write it down. Most lost marks
            here are simple addition mistakes, not concept mistakes.
```

```
  PATTERN 7 — MOLES  <->  NUMBER OF PARTICLES                     2 marks
  ------------------------------------------------------------------------
  TRIGGER   The words "molecules", "atoms", "ions", "formula units",
            "6.022 x 10^23".
  METHOD    1. Convert the given mass to MOLES.
            2. molecules  =  n  x  6.022 x 10^23
            3. If ATOMS are asked, multiply again by the number of atoms
               in one molecule.
  TRAP      "Molecules" and "atoms" are NOT the same. 1 mole of CO2 has
            6.022 x 10^23 MOLECULES but 3 x 6.022 x 10^23 ATOMS.
            Read the question twice.
```

```
  PATTERN 8 — GAS VOLUME AT STP                                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "at STP", "volume of the gas liberated", "22.4".
  METHOD    n  =  V(L) / 22.4          V(L)  =  n x 22.4
  TRAP      22.4 L applies ONLY to a GAS and ONLY at STP. It is useless for
            solids and liquids.
            If the question gives a temperature and pressure that are NOT
            STP, use  P V = n R T  with R = 0.0821 L atm / (K mol).
            Convert mL to L before using 22.4.
```

```
  PATTERN 9 — MASS OF A SINGLE ATOM OR MOLECULE                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the mass of ONE atom / ONE molecule of ..."
  METHOD                     molar mass
             mass   =   --------------------
                         6.022 x 10^23
            The reverse question ("mass of one atom is X, find the atomic
            mass") is:  atomic mass = X x 6.022 x 10^23
  TRAP      The answer must be a very small number, around 10^-23 g.
            If your answer is bigger than 1, you divided the wrong way.
```

```
  PATTERN 10 — PERCENTAGE COMPOSITION                             4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the percentage composition of ..." or "the % of
            nitrogen in ...".
  METHOD    1. Molar mass of the compound.
            2. For each element:
                          (number of atoms) x (atomic mass)
               %  =  ---------------------------------------  x 100
                                   molar mass
            3. Add them up as a check.
  TRAP      Your percentages must add up to about 100. If they do not,
            you made an arithmetic slip - fix it before writing the answer.
            This free check is worth doing every single time.
```

```
  PATTERN 11 — EMPIRICAL FORMULA FROM PERCENTAGES                 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Percentages (or masses) of the elements are given and a formula
            is asked.
  METHOD    1. Divide each % by that element's ATOMIC MASS.
            2. Divide every result by the SMALLEST one.
            3. Clear any remaining fraction by multiplying ALL of them:
                  .5   -> x2      .33 or .67 -> x3
                  .25 or .75 -> x4        .2/.4/.6/.8 -> x5
            4. Write as subscripts.
            ALWAYS draw the 5-column table - it earns method marks.
  TRAP      Never round 1.5 down to 1 or 2.5 up to 3. Multiply instead.
            If a % is missing, it is (100 - sum of the others), usually
            oxygen.
```

```
  PATTERN 12 — MOLECULAR FORMULA FROM EMPIRICAL FORMULA           4 marks
  ------------------------------------------------------------------------
  TRIGGER   Percentages AND a molecular mass (or vapour density) are given.
  METHOD    1. Get the empirical formula (Pattern 11).
            2. Add up the empirical formula MASS.
            3. n  =  molecular mass / empirical formula mass
            4. Multiply every subscript by n.
            If VAPOUR DENSITY is given:  molecular mass = 2 x V.D.
  TRAP      n must come out a WHOLE NUMBER. If you get 5.9, round to 6 -
            small rounding errors in the percentages cause this.
            If you get 2.5, you made a mistake earlier.
```

```
  PATTERN 13 — MASS-MASS / MASS-VOLUME FROM AN EQUATION           4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How much X is produced from Y grams of Z?"
  METHOD    1. Write and BALANCE the equation.
            2. Convert the GIVEN mass into MOLES.
            3. Apply the coefficient ratio to get moles of the WANTED
               substance.
            4. Convert back: x molar mass -> grams
                             x 22.4       -> litres of gas at STP
  TRAP      The coefficients are MOLE ratios, NOT gram ratios. Students who
            multiply grams by the coefficient lose all the marks.
            An UNBALANCED equation makes every later step wrong.
```

```
  PATTERN 14 — PURITY AND PERCENTAGE YIELD                        4 marks
  ------------------------------------------------------------------------
  TRIGGER   The words "impure", "90% pure", "actual yield", "the reaction
            is 80% efficient".
  METHOD    PURITY  : first convert the impure mass into the PURE mass
                      pure mass = (given mass) x (purity %) / 100
                      then do Pattern 13 with the pure mass.
            YIELD   : do Pattern 13 to get the THEORETICAL yield, then
                                       actual
                      % yield  =  ----------------  x 100
                                    theoretical
  TRAP      Apply the purity BEFORE the stoichiometry, and the yield AFTER
            it. Doing it the other way round gives a wrong answer.
```

```
  PATTERN 15 — LIMITING REAGENT                                   4 marks
  ------------------------------------------------------------------------
  TRIGGER   The amounts of TWO OR MORE reactants are given.
            (If only one amount is given, the other is "in excess" and this
            is NOT a limiting reagent problem.)
  METHOD    1. Balance the equation.
            2. Convert EVERY given mass to moles.
            3. For each reactant compute  (moles) / (its coefficient).
            4. The SMALLEST value identifies the LIMITING reagent.
            5. Calculate the product from the LIMITING reagent ONLY.
            6. If asked, excess left = moles taken - moles actually used.
  TRAP      Do NOT compare raw moles. Do NOT assume the reactant with the
            smaller mass is limiting. Always divide by the coefficient.
```

```
  PATTERN 16 — MOLARITY CALCULATION                               2 marks
  ------------------------------------------------------------------------
  TRIGGER   A mass of solute and a VOLUME of solution are given.
  METHOD              moles of solute            mass x 1000
             M   =  --------------------  =  ---------------------
                     volume of solution        Mw  x  V in mL
                        in LITRES
  TRAP      Convert mL to L (divide by 1000). Use the volume of the
            SOLUTION, never the volume of the solvent.
```

```
  PATTERN 17 — MOLALITY CALCULATION                               2 marks
  ------------------------------------------------------------------------
  TRIGGER   A mass of solute and a MASS of solvent (usually water) given.
  METHOD              moles of solute
             m   =  ----------------------
                     kg of SOLVENT
  TRAP      Use the SOLVENT mass in KILOGRAMS, not the solution mass.
            If the question gives the mass of the SOLUTION,
            solvent = solution - solute.
```

```
  PATTERN 18 — MOLE FRACTION                                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the mole fraction of ..."
  METHOD    1. Convert BOTH components to moles.
            2. x(A) = n(A) / (n(A) + n(B))
            3. Check that x(A) + x(B) = 1.
  TRAP      Mole fraction has NO UNIT - do not write mol/L.
            Do not forget to convert the solvent mass to moles too
            (water: divide by 18).
```

```
  PATTERN 19 — MASS PERCENT AND ppm                               2 marks
  ------------------------------------------------------------------------
  TRIGGER   "% by mass", "ppm", "parts per million", trace pollutants.
  METHOD    mass %  =  (mass of solute / mass of SOLUTION) x 100
            ppm     =  (mass of solute / mass of SOLUTION) x 10^6
            To convert:   mass %  =  ppm / 10^4
  TRAP      The denominator is the SOLUTION (solute + solvent), not the
            solvent. "20 g of sugar in 80 g of water" is 20% (solution is
            100 g), not 25%.
```

```
  PATTERN 20 — INTERCONVERSION OF CONCENTRATION TERMS             4 marks
  ------------------------------------------------------------------------
  TRIGGER   A density AND a mass percent (or a molarity) are given, and a
            different concentration term is asked.
  METHOD    SAFEST ROUTE - take exactly 100 g of solution:
              1. mass of solute = the mass %  ->  convert to moles
              2. mass of solvent = 100 - solute mass  ->  gives MOLALITY
              3. volume = 100 / density (in mL)       ->  gives MOLARITY
              4. moles of solvent                     ->  gives MOLE
                                                          FRACTION
            SHORTCUT FORMULAS (use them as a cross-check):
                     10 x d x mass%                  1000 M
              M  =  -----------------      m  =  --------------------
                          Mw                      1000d - (M x Mw)
  TRAP      The density must be in g/mL for the shortcut to work.
            Always cross-check the shortcut answer against the 100 g
            method - if they disagree, you slipped somewhere.
```

```
  PATTERN 21 — DILUTION AND TITRATION                        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "diluted to ... mL", "how much water must be added",
            "neutralised by ... mL of ...".
  METHOD    M1 V1  =  M2 V2          or          N1 V1  =  N2 V2

            For a reaction  a A  +  b B  ->  products :
                 (M1 V1) / a   =   (M2 V2) / b

            "Water to be ADDED" = final volume - initial volume.
  TRAP      Use the SAME unit of volume on both sides (mL with mL is fine).
            Use N1V1 = N2V2 only when both are given as NORMALITY.
            If molarities are given for an acid-base pair that is not 1:1,
            you must include the a and b coefficients.
```

```
  PATTERN 22 — EFFECT OF TEMPERATURE ON CONCENTRATION             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is molality preferred over molarity?" /
            "Which of these depends on temperature?"
  METHOD    Answer in three lines:
              1. Molarity uses VOLUME; volume expands on heating.
              2. So molarity DECREASES as temperature rises.
              3. Molality uses MASS, which is unaffected, so molality is
                 CONSTANT. So are mass %, mole fraction and ppm.
  TRAP      Normality also depends on temperature (it uses volume too).
            Students often forget to include it.
```

```
  PATTERN 23 — EQUIVALENT WEIGHT AND NORMALITY               2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   The words "equivalent weight", "normality", "N solution",
            "gram equivalents".
  METHOD    1. Find the n-factor:
                 acid  -> basicity (replaceable H+)
                 base  -> acidity (number of OH-)
                 salt  -> total positive charge
                 redox -> electrons gained or lost
            2. Eq. wt.  =  molar mass / n-factor
            3. N  =  M  x  n-factor
            4. gram equivalents = mass / equivalent weight
  TRAP      For KMnO4 the n-factor DEPENDS ON THE MEDIUM:
                 acidic 5 , neutral 3 , strongly basic 1.
            Read the medium before writing the equivalent weight.
```

```
  PATTERN 24 — FIND THE OXIDATION NUMBER                          2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Calculate the oxidation number of ... in ..."
  METHOD    1. Write the KNOWN values: H = +1, O = -2, group 1 = +1, etc.
            2. Let the unknown be x and multiply by the number of atoms.
            3. Set the total = 0 for a molecule, = the CHARGE for an ion.
            4. Solve.
  TRAP      For an ION the total is the CHARGE, not zero. MnO4^- gives +7,
            not +8.
            Watch the exceptions: H is -1 in NaH; O is -1 in peroxides,
            -1/2 in superoxides, +2 in OF2.
            A fractional answer (Fe3O4 gives +8/3) is CORRECT - it is an
            average, not a mistake.
```

```
  PATTERN 25 — IDENTIFY THE OXIDISING AND REDUCING AGENTS         2 marks
  ------------------------------------------------------------------------
  TRIGGER   A reaction is given: "identify the oxidising agent / the
            substance oxidised".
  METHOD    1. Assign oxidation numbers to every element on both sides.
            2. The element whose number GOES UP is OXIDISED -> that
               compound is the REDUCING agent.
            3. The element whose number GOES DOWN is REDUCED -> that
               compound is the OXIDISING agent.
  TRAP      The names are SWAPPED from what feels natural. The substance
            that is OXIDISED is the REDUCING agent. Write "O I L R I G" in
            the margin before you answer.
            Name the whole COMPOUND (CuSO4), not just the ion, unless the
            question is ionic.
```

```
  PATTERN 26 — TYPE OF REDOX REACTION / DISPROPORTIONATION        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Identify the type of redox reaction" or "What is
            disproportionation? Give an example."
  METHOD    many -> one, with an element reactant   =  COMBINATION
            one -> many, with an element product    =  DECOMPOSITION
            element replaces another element        =  DISPLACEMENT
            SAME element goes both up and down      =  DISPROPORTIONATION
            Standard examples to quote:
              2 H2O2 -> 2 H2O + O2
              Cl2 + 2 NaOH -> NaCl + NaOCl + H2O
              P4 + 3 NaOH + 3 H2O -> PH3 + 3 NaH2PO2
  TRAP      Disproportionation needs an INTERMEDIATE oxidation state.
            Fluorine can never disproportionate (its only states are 0
            and -1).
```

```
  PATTERN 27 — BALANCE REDOX BY THE OXIDATION-NUMBER METHOD       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Balance by the oxidation number method" (a MOLECULAR, not
            ionic, equation is usually given).
  METHOD    1. Assign oxidation numbers to all atoms.
            2. Identify the element going UP and the element going DOWN.
            3. Total increase and total decrease per formula unit.
            4. Cross-multiply so INCREASE = DECREASE.
            5. Balance the remaining atoms by inspection; do O and H last.
            6. Verify every element AND the charge.
  TRAP      Only the atoms that CHANGE state count in step 3. In
            Cu + HNO3 -> Cu(NO3)2 + NO2 + H2O, the nitrogen in the nitrate
            is still +5 and does NOT count; only the N that becomes NO2
            has changed.
```

```
  PATTERN 28 — ION-ELECTRON METHOD, ACIDIC MEDIUM         4 or *** 8 *** M
  ------------------------------------------------------------------------
  TRIGGER   "Balance by the ion-electron / half-reaction method in acidic
            medium." Ionic species with charges are given.
  METHOD    1. Split into an oxidation half and a reduction half.
            2. Balance all atoms except H and O.
            3. Balance O with H2O.
            4. Balance H with H+.
            5. Balance charge with electrons.
            6. Multiply the halves to equalise electrons.
            7. Add and cancel duplicates.
  TRAP      The final answer must contain NO OH- and NO free electrons.
            You must check BOTH the atom count AND the total charge on
            both sides - the examiner looks for that final check line.
  NOTE      *** THIS IS THE MOST FREQUENTLY ASKED LONG-ANSWER SHAPE IN
            THIS CHAPTER. ***
```

```
  PATTERN 29 — ION-ELECTRON METHOD, BASIC MEDIUM          4 or *** 8 *** M
  ------------------------------------------------------------------------
  TRIGGER   The words "in basic medium" / "in alkaline medium" /
            "in the presence of OH-".
  METHOD    Do the ENTIRE acidic procedure first (Pattern 28), then:
            8. Add as many OH- to BOTH sides as there are H+.
            9. Combine H+ + OH- into H2O on that side.
           10. Cancel any H2O that now appears on both sides.
  TRAP      The final answer must contain NO H+ anywhere. If an H+ survives
            in your answer, you skipped step 8.
            Add the OH- to BOTH sides - adding it to one side only breaks
            the balance.
```

```
  THE HONEST BOTTOM LINE

  You do not have to be clever to score in this chapter. You have to be
  ACCURATE. Nearly every mark lost here is one of these five mistakes:

     1.  A wrong molar mass (bad addition, or a missed bracket).
     2.  Forgetting to convert grams to moles before using the equation.
     3.  Using mL where litres were needed.
     4.  Confusing molarity (solution volume) with molality (solvent mass).
     5.  Forgetting the final check on a balanced redox equation.

  Fix those five habits and this chapter becomes free marks.
```
