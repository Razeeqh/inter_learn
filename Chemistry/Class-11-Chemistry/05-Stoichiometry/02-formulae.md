# 1. LAWS OF CHEMICAL COMBINATION (statement form, no algebra)

```
  +----------------------------+---------------------------------------+
  |  LAW                       |  ONE-LINE STATEMENT                   |
  +----------------------------+---------------------------------------+
  |  Conservation of mass      |  mass of reactants = mass of products |
  |  (Lavoisier)               |                                       |
  +----------------------------+---------------------------------------+
  |  Definite proportions      |  A pure compound always has the same  |
  |  (Proust)                  |  elements in the same mass ratio      |
  +----------------------------+---------------------------------------+
  |  Multiple proportions      |  Masses of B combining with a fixed   |
  |  (Dalton)                  |  mass of A are in a simple whole      |
  |                            |  number ratio                         |
  +----------------------------+---------------------------------------+
  |  Reciprocal proportions    |  Masses of B and C that combine with  |
  |  (Richter)                 |  a fixed mass of A are in the same    |
  |                            |  ratio (or a simple multiple) as the  |
  |                            |  ratio in which B and C combine       |
  +----------------------------+---------------------------------------+
  |  Gaseous volumes           |  Gases react in simple whole-number   |
  |  (Gay-Lussac)              |  VOLUME ratios at same T and P        |
  +----------------------------+---------------------------------------+
  |  Avogadro's law            |  Equal volumes of all gases at the    |
  |                            |  same T and P contain equal numbers   |
  |                            |  of MOLECULES                         |
  +----------------------------+---------------------------------------+
```

  +----------------------------------------------------------------------+

  |                                                                      |
  |   average atomic mass  =  m1 f1  +  m2 f2  +  ...                    |

  |   MOLECULAR MASS  =  sum of atomic masses of all atoms in            |
  |                      one molecule                                    |
  |                                                                      |

  |                      (NaCl, CaO, Na2CO3)                             |

|---------|-------------|
| `average = sum(mass x %) / 100` | isotopic abundances are given |
| `molecular mass = sum of atomic masses` | any covalent molecule |
| `formula mass` | ionic solids — never say "molecular mass" for NaCl |
| `molecular mass = 2 x vapour density` | when vapour density is given instead of M |

# 3. THE MOLE CONCEPT  *** the box that answers most numericals ***

```
  +======================================================================+
  |                                                                      |
  |                     given mass in grams                              |
  |     n   =   ----------------------------------                       |
  |                  molar mass in g/mol                                 |
  |                                                                      |
  |                                                                      |
  |                     number of particles                              |
  |     n   =   ----------------------------------                       |
  |                     6.022 x 10^23                                    |
  |                                                                      |
  |                                                                      |
  |                     volume of GAS in litres at STP                   |
  |     n   =   -----------------------------------------                |
  |                              22.4                                    |
  |                                                                      |
  +======================================================================+

  THE ONE-LINE SUMMARY

     1 mole  =  6.022 x 10^23 particles
             =  molar mass in grams
             =  22.4 L  (GAS ONLY, at STP ONLY)
```

```
  DERIVED SHORTCUTS

  +----------------------------------------------------------------------+
  |                                                                      |
  |                                     molar mass                       |
  |   mass of ONE atom/molecule  =  --------------------                 |
  |                                    6.022 x 10^23                     |
  |                                                                      |
  |                                                                      |
  |                              given mass                              |
  |   number of particles  =  ----------------  x  6.022 x 10^23         |
  |                             molar mass                               |
  |                                                                      |
  |                                                                      |
  |   number of ATOMS in a molecular substance                           |
  |         =  (moles)  x  (atoms per molecule)  x  6.022 x 10^23        |
  |                                                                      |
  |                                                                      |
  |   volume of a gas at STP  =  n  x  22.4  litres                      |
  |                                                                      |
  |   For non-STP conditions use the gas equation:   P V  =  n R T       |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| Formula | When to use |
|---------|-------------|
| `n = mass / molar mass` | the default starting move for ANY numerical |
| `n = particles / 6.022e23` | question mentions atoms, molecules, ions |
| `n = V(L) / 22.4` | question mentions a GAS at STP |
| `V = n x 22.4` | asked for volume of gas produced |
| `PV = nRT` | conditions are NOT STP |
| `mass of one atom = M / N(A)` | "find the mass of a single atom / molecule" |

# 5. EMPIRICAL AND MOLECULAR FORMULA

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |     MOLECULAR FORMULA   =   n   x   EMPIRICAL FORMULA                |
  |                                                                      |
  |                     molecular mass                                   |
  |          n   =   --------------------------                          |
  |                  empirical formula mass                              |
  |                                                                      |
  |     n is always a WHOLE NUMBER                                       |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  THE 5-STEP RECIPE

    1.  % of each element          (or mass of each element)
    2.  divide each by its ATOMIC MASS        ->  relative moles
    3.  divide every result by the SMALLEST   ->  simple ratio
    4.  multiply all by 2, 3 or 4 to clear fractions
    5.  write as subscripts -> EMPIRICAL FORMULA

  MULTIPLY-BY TABLE for step 4

  +-------------------+----------------+
  |  If you get ...   |  Multiply by   |
  +-------------------+----------------+
  |  x.5   (1.5, 2.5) |       2        |
  |  x.33  or  x.67   |       3        |
  |  x.25  or  x.75   |       4        |
  |  x.2 , x.4 , x.8  |       5        |
  +-------------------+----------------+
```

| Formula | When to use |
|---------|-------------|
| `moles = % / atomic mass` | step 2 of every empirical formula sum |
| `n = molecular mass / empirical mass` | molecular mass is also given |
| `molecular mass = 2 x vapour density` | vapour density is given instead |

# 7. LIMITING REAGENT

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |    For each reactant compute                                         |
  |                                                                      |
  |                        moles of that reactant                        |
  |         ratio   =   ------------------------------                   |
  |                      its coefficient in the equation                 |
  |                                                                      |
  |    The reactant with the SMALLEST ratio is the LIMITING REAGENT.     |

  TEMPERATURE DEPENDENCE - remember this table, it is a 2-mark question

  +--------------------+-------------------+----------------------------+
  |  QUANTITY          |  CHANGES WITH T?  |  WHY                       |
  +--------------------+-------------------+----------------------------+
  |  Mass percent      |       NO          |  only masses involved      |
  |  Mole fraction     |       NO          |  only moles involved       |
  |  Molality          |       NO          |  uses MASS of solvent      |
  |  ppm               |       NO          |  only masses involved      |
  |  MOLARITY          |      YES          |  uses VOLUME, which        |

  |  NORMALITY         |      YES          |  uses VOLUME too           |
  +--------------------+-------------------+----------------------------+
```

| Formula | When to use |
|---------|-------------|
| `M = n / V(L)` | volume of solution given, asked for molarity |
| `M = mass x 1000 / (Mw x V mL)` | mass and mL are given directly |
| `m = n / kg of solvent` | mass of solvent (water) is given |
| `M = 10 d (mass%) / Mw` | density and mass % of a commercial acid given |
| `m = 1000 M / (1000d - M Mw)` | convert a given molarity into molality |
| `N = M x n-factor` | question switches between N and M |
| `M1V1 = M2V2` | dilution or a 1:1 titration |
| `ppm = mass ratio x 10^6` | pollutants, trace impurities in water |

# 11. BALANCING REDOX EQUATIONS

```
  METHOD 1 - OXIDATION NUMBER METHOD
  +----------------------------------------------------------------------+
  |  1.  Write the skeletal equation.                                    |
  |  2.  Assign oxidation numbers; find which element goes UP and which  |
  |      goes DOWN.                                                      |
  |  3.  Compute TOTAL increase and TOTAL decrease.                      |
  |  4.  Cross-multiply so that  INCREASE = DECREASE.                    |
  |  5.  Balance the rest by inspection; add H2O / H+ / OH- last.        |
  +----------------------------------------------------------------------+


  METHOD 2 - ION-ELECTRON (HALF-REACTION) METHOD
  +----------------------------------------------------------------------+
  |  1.  Write the skeletal IONIC equation.                              |
  |  2.  Split into an OXIDATION half and a REDUCTION half.              |
  |  3.  Balance all atoms EXCEPT H and O.                               |
  |  4.  Balance O by adding H2O.                                        |
  |  5.  Balance H by adding H+.                                         |
  |  6.  Balance CHARGE by adding electrons.                             |
  |  7.  Equalise electrons, add the halves, cancel duplicates.          |
  |                                                                      |
  |  BASIC MEDIUM - one extra step:                                      |
  |  8.  Add as many OH- to BOTH sides as there are H+.                  |
  |      H+ + OH- -> H2O , then cancel duplicate H2O.                    |
  +----------------------------------------------------------------------+
```

```
  THE HALF-REACTIONS THAT KEEP COMING BACK - memorise these four

  +----------------------------------------------------------------------+
  |                                                                      |
  |  MnO4^-  + 8 H+  + 5 e-   ->   Mn2+   + 4 H2O      (acidic)          |
  |                                                                      |
  |  MnO4^-  + 2 H2O + 3 e-   ->   MnO2   + 4 OH-      (basic/neutral)   |
  |                                                                      |
  |  Cr2O7^2- + 14 H+ + 6 e-  ->   2 Cr3+ + 7 H2O      (acidic)          |
  |                                                                      |
  |  Fe2+                     ->   Fe3+  +  e-                           |
  |                                                                      |
  |  2 I^-                    ->   I2    + 2 e-                          |
  |                                                                      |
  |  C2O4^2- (oxalate)        ->   2 CO2 + 2 e-                          |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  AND THE FIVE ONE-LINERS THAT ANSWER MOST 2-MARK THEORY QUESTIONS

    1.  1 mole = 6.022 x 10^23 particles = molar mass in grams
        = 22.4 L for a gas at STP

    2.  Molarity uses volume of SOLUTION; molality uses mass of SOLVENT.

    3.  Molarity changes with temperature; molality does NOT.

    4.  Oxidation = loss of electrons = oxidation number increases.
        (O I L   R I G)

    5.  Disproportionation = the SAME element is both oxidised and
        reduced in the same reaction.
```
