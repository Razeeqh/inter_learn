# PATTERN 1 — Moles, mass, particles, volume

### Q1
The number of molecules present in 11.2 litres of CO2 at STP is

(a) 6.022 x 10^23 &nbsp; (b) 3.011 x 10^23 &nbsp; (c) 1.2 x 10^24 &nbsp; (d) 6.022 x 10^22

**ANSWER: (b)**
```
          11.2
   n  =  --------  =  0.5  mol
          22.4

   molecules  =  0.5  x  6.022 x 10^23  =  3.011 x 10^23
```

### Q2
Which of the following contains the largest number of ATOMS?

(a) 1 g of H2 &nbsp; (b) 1 g of O2 &nbsp; (c) 1 g of N2 &nbsp; (d) 1 g of Ag

**ANSWER: (a)**
```
   H2 :  1/2  = 0.500 mol molecules  x 2 atoms  =  1.000 mol atoms
   O2 :  1/32 = 0.031 mol            x 2        =  0.062 mol atoms
   N2 :  1/28 = 0.036 mol            x 2        =  0.072 mol atoms
   Ag :  1/108= 0.009 mol atoms                 =  0.009 mol atoms
```
> **RULE:** for equal MASSES, the LIGHTEST substance always has the most moles.
> You do not need to compute — just pick the smallest molar mass.

### Q3
The total number of electrons present in 1.6 g of methane is

(a) 6.022 x 10^22 &nbsp; (b) 6.022 x 10^23 &nbsp; (c) 1.0 x 10^23 &nbsp; (d) 3.01 x 10^23

**ANSWER: (b)**
```
   n(CH4)  =  1.6 / 16  =  0.1  mol

   electrons per CH4  =  6 (C)  +  4 (H)  =  10

   total  =  0.1  x  10  x  6.022 x 10^23  =  6.022 x 10^23
```

### Q5
The number of oxygen ATOMS in 0.25 mole of Al2(SO4)3 is

(a) 1.8 x 10^24 &nbsp; (b) 1.8 x 10^23 &nbsp; (c) 3.0 x 10^23 &nbsp; (d) 6.0 x 10^23

**ANSWER: (a)**
```
   Al2(SO4)3 has  3 x 4  =  12  oxygen atoms per formula unit.

   moles of O atoms  =  0.25  x  12  =  3  mol

   atoms  =  3  x  6.022 x 10^23  =  1.807 x 10^24
```
> **TRAP:** the subscript 3 outside the bracket multiplies BOTH the S and
> the O inside. Al2(SO4)3 has 3 sulphurs and 12 oxygens, not 4.

### Q7
The vapour density of a gas is 32. Its molecular mass is

(a) 16 &nbsp; (b) 32 &nbsp; (c) 64 &nbsp; (d) 128

**ANSWER: (c)** — `molecular mass = 2 x vapour density = 2 x 32 = 64`

### Q8
One litre of a gas at STP weighs 1.97 g. The gas is

(a) N2 &nbsp; (b) O2 &nbsp; (c) CO2 &nbsp; (d) SO2

**ANSWER: (c)**
```

   ->  CO2  (molar mass 44)

> **SHORTCUT:** molar mass of a gas = (density at STP in g/L) x 22.4

### Q12
A compound contains 24.24% C, 4.04% H and 71.72% Cl. Its molar mass is 99.
Its molecular formula is

(a) CH2Cl &nbsp; (b) C2H4Cl2 &nbsp; (c) C3H6Cl3 &nbsp; (d) CHCl3

**ANSWER: (b)**
```
   C  :  24.24 / 12   =  2.02
   H  :   4.04 / 1    =  4.04
   Cl :  71.72 / 35.5 =  2.02

   Divide by 2.02  ->  C 1 : H 2 : Cl 1     ->  EF = CH2Cl

   EF mass  =  12 + 2 + 35.5  =  49.5

   n  =  99 / 49.5  =  2       ->   MF = C2H4Cl2
```

### Q14
The mass of CaO obtained by heating 200 g of pure CaCO3 is

(a) 56 g &nbsp; (b) 100 g &nbsp; (c) 112 g &nbsp; (d) 200 g

**ANSWER: (c)**
```
   CaCO3  ->  CaO  +  CO2

   mass  =  2  x  56  =  112 g
```

### Q15
The volume of oxygen at STP required for the complete combustion of
2.24 litres of methane measured at STP is

(a) 2.24 L &nbsp; (b) 4.48 L &nbsp; (c) 11.2 L &nbsp; (d) 22.4 L

**ANSWER: (b)**
```
   CH4  +  2 O2  ->  CO2  +  2 H2O

   For gases at the same T and P, VOLUME ratio = MOLE ratio (Avogadro).

   O2  =  2  x  2.24  =  4.48  L
```
> **SHORTCUT:** if EVERYTHING is a gas at the same conditions, work directly
> with volumes. Do not convert to moles at all — it wastes 40 seconds.

# PATTERN 5 — Limiting reagent

### Q17
1 mole of N2 is mixed with 4 moles of H2. The maximum number of moles of
NH3 that can be formed is

(a) 1 &nbsp; (b) 2 &nbsp; (c) 2.67 &nbsp; (d) 4

**ANSWER: (b)**
```
   N2  +  3 H2  ->  2 NH3

   N2 :  1 / 1  =  1.00
   H2 :  4 / 3  =  1.33

   Smaller value belongs to N2  ->  N2 is LIMITING

   n(NH3)  =  2  x  1  =  2  mol
```

---

### Q18
2 g of H2 reacts with 32 g of O2. The mass of water formed is

(a) 34 g &nbsp; (b) 36 g &nbsp; (c) 18 g &nbsp; (d) 9 g

**ANSWER: (c)**
```
   2 H2  +  O2  ->  2 H2O

   n(H2) = 2/2  = 1 mol   ->   1 / 2  =  0.5      <- SMALLER, limiting
   n(O2) = 32/32= 1 mol   ->   1 / 1  =  1.0

   From H2 :  n(H2O)  =  1 mol       mass  =  18 g
```
> **RULE:** always divide moles by the COEFFICIENT before comparing.
> Comparing raw moles (1 and 1 here) gives the wrong answer.

### Q23
On raising the temperature of a solution,

(a) molarity increases &nbsp; (b) molarity decreases
(c) molality increases &nbsp; (d) molality decreases

**ANSWER: (b)**
```
   Heating expands the VOLUME but not the MASS.

   Molarity = moles / volume     ->  volume up   ->  MOLARITY DOWN
   Molality = moles / mass       ->  mass fixed  ->  MOLALITY UNCHANGED
```

# PATTERN 7 — Oxidation numbers

### Q25
The oxidation number of sulphur in H2S2O7 is

(a) +4 &nbsp; (b) +5 &nbsp; (c) +6 &nbsp; (d) +7

**ANSWER: (c)**
```
   2(+1)  +  2x  +  7(-2)  =  0
       2  +  2x  -  14     =  0
              2x           =  12       ->      x  =  +6
```

---

### Q26
The oxidation number of carbon in acetic acid, CH3COOH, is

(a) 0 &nbsp; (b) +2 &nbsp; (c) -2 &nbsp; (d) +4

**ANSWER: (a)**
```
   2x  +  4(+1)  +  2(-2)  =  0
   2x  +  4  -  4  =  0       ->     x  =  0

   (An AVERAGE. The two carbons are really -3 and +3.)
```

---

### Q27
The oxidation number of oxygen in potassium superoxide, KO2, is

(a) -2 &nbsp; (b) -1 &nbsp; (c) -1/2 &nbsp; (d) 0

**ANSWER: (c)**
```
   (+1)  +  2x  =  0     ->     2x = -1     ->     x = -1/2

   REMEMBER THE OXYGEN LADDER:
        normal oxide   O2-     ->  -2
        peroxide       O2^2-   ->  -1      (H2O2 , Na2O2 , BaO2)
        superoxide     O2^-    ->  -1/2    (KO2 , RbO2 , CsO2)
        OF2                    ->  +2      (fluorine is more
                                            electronegative)
```

# PATTERN 8 — Oxidising agent, reducing agent

### Q30
In the reaction  Zn + CuSO4 -> ZnSO4 + Cu , the oxidising agent is

(a) Zn &nbsp; (b) CuSO4 &nbsp; (c) ZnSO4 &nbsp; (d) Cu

**ANSWER: (b)**
```
   Zn :  0  ->  +2      oxidation number goes UP    ->  Zn is OXIDISED
                                                    ->  Zn is the REDUCING
                                                        AGENT
   Cu : +2  ->   0      oxidation number goes DOWN  ->  Cu2+ is REDUCED
                                                    ->  CuSO4 is the
                                                        OXIDISING AGENT
```
> **RULE:** the species that is REDUCED is the OXIDISING agent.
> The species that is OXIDISED is the REDUCING agent. They are always
> opposite — this is the single most common trick in this pattern.

---

### Q31
Which of the following can act BOTH as an oxidising and as a reducing agent?

(a) HNO3 &nbsp; (b) H2O2 &nbsp; (c) F2 &nbsp; (d) KMnO4

**ANSWER: (b)**
```
   In H2O2 oxygen is at -1, which is an INTERMEDIATE state:
        it can go DOWN to -2  (H2O)   ->  acting as an OXIDISING agent
        it can go UP   to  0  (O2)    ->  acting as a REDUCING agent

   HNO3 (N = +5), F2 (F only goes to -1) and KMnO4 (Mn = +7) are at
   their HIGHEST state, so they can only be OXIDISING agents.
```
> **RULE:** an element in its HIGHEST oxidation state can only OXIDISE.
> In its LOWEST state it can only REDUCE. In an INTERMEDIATE state it can
> do BOTH — and it can also disproportionate.

# PATTERN 9 — Disproportionation

### Q32
Which of the following is a disproportionation reaction?

(a) Zn + CuSO4 -> ZnSO4 + Cu
(b) Cl2 + 2 NaOH -> NaCl + NaOCl + H2O
(c) 2 Mg + O2 -> 2 MgO
(d) Fe + S -> FeS

**ANSWER: (b)**
```
   Chlorine starts at 0 and ends up at
        -1  in NaCl   (reduced)     AND
        +1  in NaOCl  (oxidised)

   Same element, both oxidised and reduced  ->  DISPROPORTIONATION.
```

---

### Q33
Which of the following elements does NOT undergo disproportionation?

(a) Cl &nbsp; (b) Br &nbsp; (c) F &nbsp; (d) I

**ANSWER: (c)**
```
   Fluorine has only two oxidation states: 0 and -1.
   It is the most electronegative element, so it can never go to a
   POSITIVE state. With nowhere to go UP, it cannot disproportionate.
```

# PATTERN 10 — Balanced redox coefficients

### Q34
In the balanced equation

MnO4^- + C2O4^2- + H+ -> Mn2+ + CO2 + H2O

the coefficient of H+ is

(a) 5 &nbsp; (b) 8 &nbsp; (c) 16 &nbsp; (d) 2

**ANSWER: (c)**
```
   Reduction :  MnO4^- + 8 H+ + 5 e-  ->  Mn2+ + 4 H2O        ( x 2 )
   Oxidation :  C2O4^2-  ->  2 CO2 + 2 e-                     ( x 5 )

   2 MnO4^- + 5 C2O4^2- + 16 H+  ->  2 Mn2+ + 10 CO2 + 8 H2O

   Coefficient of H+  =  16
```

### Q35
The number of electrons involved when one mole of Cr2O7^2- is reduced to
Cr3+ in acidic medium is

(a) 3 &nbsp; (b) 4 &nbsp; (c) 6 &nbsp; (d) 7

**ANSWER: (c)**
```
   Cr goes from +6 to +3  ->  3 electrons per Cr atom
   There are TWO Cr atoms in Cr2O7^2-   ->   2 x 3  =  6 electrons

   Cr2O7^2- + 14 H+ + 6 e-  ->  2 Cr3+ + 7 H2O
```

### Q36
The equivalent weight of KMnO4 when it acts as an oxidising agent in

### Q38
Gay-Lussac's law of gaseous volumes was explained by

(a) Dalton's atomic theory &nbsp; (b) Avogadro's law
(c) Boyle's law &nbsp; (d) the law of conservation of mass

**ANSWER: (b)**
```

### Q40
The number of significant figures in 0.0025 is

(a) 2 &nbsp; (b) 3 &nbsp; (c) 4 &nbsp; (d) 5

**ANSWER: (a)**
```
   Leading zeros are NOT significant. Only the 2 and the 5 count.

   RULES IN ONE LINE:
      leading zeros    -> never significant  (0.0025 has 2)
      captive zeros    -> always significant (1.008 has 4)
      trailing zeros after a decimal point -> significant (2.500 has 4)
```
