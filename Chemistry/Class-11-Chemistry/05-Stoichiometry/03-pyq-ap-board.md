## Topic: Laws of chemical combination

### Q A1
State the law of conservation of mass. Give one example.

**ANSWER:**
```
  STATEMENT
  In any chemical reaction, matter is neither created nor destroyed.
  The total mass of the reactants is equal to the total mass of the
  products.
                          (Proposed by Lavoisier, 1789)

  EXAMPLE
       2 H2   +   O2    ->    2 H2O
        4 g   +  32 g          36 g

       Mass of reactants = 4 + 32 = 36 g
       Mass of products  = 36 g            ->  they are EQUAL.
```

---

### Q A2
State the law of multiple proportions with a suitable example.

**ANSWER:**
```
  STATEMENT
  When two elements combine to form more than one compound, the masses of
  one element that combine with a FIXED mass of the other element bear a
  SIMPLE WHOLE-NUMBER ratio to one another.
                          (Proposed by Dalton, 1803)

  EXAMPLE  -  carbon and oxygen form CO and CO2

       In CO  :  12 g of carbon combines with 16 g of oxygen
       In CO2 :  12 g of carbon combines with 32 g of oxygen

       For the SAME 12 g of carbon,   oxygen : oxygen  =  16 : 32  =  1 : 2

       A simple whole-number ratio.  The law is obeyed.
```

---

### Q A3
State Gay-Lussac's law of gaseous volumes. Give one example.

**ANSWER:**
```
  STATEMENT
  When gases react together, they do so in volumes which bear a simple
  whole-number ratio to one another and to the volumes of the gaseous
  products, provided all volumes are measured at the SAME temperature
  and pressure.

  EXAMPLE
       H2    +    Cl2    ->    2 HCl
      1 vol      1 vol         2 vol          ratio  1 : 1 : 2
```

---

### Q A4
State Avogadro's law. What is its most important consequence?

**ANSWER:**
```
  STATEMENT
  Equal volumes of all gases, under the same conditions of temperature
  and pressure, contain an EQUAL NUMBER OF MOLECULES.

  CONSEQUENCE
  It proved that the molecules of hydrogen, oxygen, nitrogen and chlorine
  gases are DIATOMIC (H2, O2, N2, Cl2), and it explained Gay-Lussac's law
  of gaseous volumes, which Dalton's theory could not.
```

## Topic: The mole concept

### Q A7
Define a mole. How many particles are present in one mole of a substance?

**ANSWER:**
```
  A MOLE is the amount of a substance that contains as many elementary
  particles (atoms, molecules or ions) as there are atoms in exactly
  12 g of carbon-12.

  One mole contains  6.022 x 10^23  particles.
  This number is called AVOGADRO'S NUMBER, N(A).

  1 mole of a substance also weighs its molar mass in grams, and
  occupies 22.4 L if it is a GAS at STP.
```

### Q A15
Why does molarity change with temperature while molality does not?

**ANSWER:**
```
  MOLARITY  =  moles of solute / VOLUME of solution.
  When the temperature rises, the solution EXPANDS, so the volume
  increases while the moles stay the same. Therefore molarity DECREASES.

  MOLALITY  =  moles of solute / MASS of solvent.
  Mass does not change with temperature. Therefore molality is
  INDEPENDENT of temperature.

  This is why molality is preferred in accurate work.
```

### Q A16
Define mole fraction. What is its unit?

**ANSWER:**
```
  MOLE FRACTION of a component is the ratio of the number of moles of that
  component to the TOTAL number of moles of all the components present.

                    n(A)                            n(B)
     x(A)  =  ---------------      x(B)  =  ---------------
                n(A) + n(B)                   n(A) + n(B)

  It has NO UNIT (it is a pure ratio).
  Also,  x(A)  +  x(B)  =  1
```

### Q A18
Calculate the oxidation number of (a) S in H2SO4 (b) Cr in K2Cr2O7
(c) Mn in KMnO4.

**ANSWER:**
```
  (a)  H2SO4 :   2(+1) + x + 4(-2) = 0
                 2 + x - 8 = 0        ->    x = +6

  (b)  K2Cr2O7 : 2(+1) + 2x + 7(-2) = 0
                 2 + 2x - 14 = 0      ->    2x = 12   ->   x = +6

  (c)  KMnO4 :   (+1) + x + 4(-2) = 0
                 1 + x - 8 = 0        ->    x = +7
```

### Q A19
Define oxidation and reduction in terms of oxidation number.

**ANSWER:**
```
  OXIDATION  -  a reaction in which the oxidation number of an element
                INCREASES (loss of electrons).
                Example:  Zn (0)  ->  Zn2+ (+2)

  REDUCTION  -  a reaction in which the oxidation number of an element
                DECREASES (gain of electrons).
                Example:  Cu2+ (+2)  ->  Cu (0)

  MEMORY:  O I L   R I G
           Oxidation Is Loss , Reduction Is Gain (of electrons)
```

---

### Q A20
What is a disproportionation reaction? Give one example.

**ANSWER:**
```
  A DISPROPORTIONATION reaction is a redox reaction in which the SAME
  element in the SAME oxidation state is SIMULTANEOUSLY oxidised and
  reduced.

  EXAMPLE
       2 H2O2   ->   2 H2O   +   O2

       Oxygen in H2O2 is  -1.
       In H2O it becomes  -2   ->  REDUCED
       In O2  it becomes   0   ->  OXIDISED

  ANOTHER EXAMPLE
       Cl2  +  2 NaOH  ->  NaCl  +  NaOCl  +  H2O
       Chlorine goes from 0 to -1 (in NaCl) and to +1 (in NaOCl).
```

---

### Q A21
What is a limiting reagent? Why is it important?

**ANSWER:**
```
  The LIMITING REAGENT is the reactant that is completely consumed FIRST
  in a chemical reaction. Once it is used up, the reaction stops.

  IMPORTANCE: the amount of product formed is decided ENTIRELY by the
  limiting reagent. Any other reactant present in excess simply remains
  unreacted, so all product calculations must be based on the limiting
  reagent.
```

### Q B8
Balance the following equation by the ion-electron method in acidic medium:

MnO4^- + Fe2+ -> Mn2+ + Fe3+

**ANSWER:**
```
  STEP 1   SPLIT INTO HALF REACTIONS
              Reduction :  MnO4^-  ->  Mn2+
              Oxidation :  Fe2+    ->  Fe3+

  STEP 2   BALANCE THE REDUCTION HALF
              Mn is already balanced.
              Balance O by adding 4 H2O on the right:
                    MnO4^-  ->  Mn2+  +  4 H2O
              Balance H by adding 8 H+ on the left:
                    MnO4^- + 8 H+  ->  Mn2+ + 4 H2O
              Balance charge: left = -1 + 8 = +7 , right = +2
              Add 5 electrons on the LEFT:
                    MnO4^- + 8 H+ + 5 e-  ->  Mn2+ + 4 H2O

  STEP 3   BALANCE THE OXIDATION HALF
                    Fe2+  ->  Fe3+  +  e-

  STEP 4   EQUALISE ELECTRONS - multiply the oxidation half by 5
                    5 Fe2+  ->  5 Fe3+  +  5 e-

  STEP 5   ADD THE TWO HALVES (the 5 electrons cancel)

              MnO4^- + 8 H+ + 5 Fe2+  ->  Mn2+ + 5 Fe3+ + 4 H2O

  CHECK    Atoms : Mn 1/1 , O 4/4 , H 8/8 , Fe 5/5
           Charge: left  = -1 + 8 + 10 = +17
                   right = +2 + 15     = +17          BALANCED
```

### Q B9
Balance the following equation by the ion-electron method in basic medium:

MnO4^- + I^- -> MnO2 + I2

**ANSWER:**
```
  STEP 1   REDUCTION HALF (balance as if acidic first)
              MnO4^-  ->  MnO2
              add 2 H2O on the right :   MnO4^-  ->  MnO2 + 2 H2O
              add 4 H+ on the left   :   MnO4^- + 4 H+  ->  MnO2 + 2 H2O
              charge: left -1 + 4 = +3 , right 0
              add 3 e- on the LEFT   :   MnO4^- + 4 H+ + 3 e- -> MnO2 + 2 H2O

  STEP 2   CONVERT TO BASIC MEDIUM
              Add 4 OH- to BOTH sides:
                 MnO4^- + 4 H+ + 4 OH- + 3 e-  ->  MnO2 + 2 H2O + 4 OH-
              H+ + OH- becomes H2O:
                 MnO4^- + 4 H2O + 3 e-  ->  MnO2 + 2 H2O + 4 OH-
              Cancel 2 H2O from both sides:
                 MnO4^- + 2 H2O + 3 e-  ->  MnO2 + 4 OH-

  STEP 3   OXIDATION HALF
                 2 I^-  ->  I2  +  2 e-

  STEP 4   EQUALISE ELECTRONS (LCM of 3 and 2 is 6)
                 reduction x 2 :  2 MnO4^- + 4 H2O + 6 e- -> 2 MnO2 + 8 OH-
                 oxidation x 3 :  6 I^-  ->  3 I2  +  6 e-

  STEP 5   ADD

              2 MnO4^- + 6 I^- + 4 H2O  ->  2 MnO2 + 3 I2 + 8 OH-

  CHECK    Mn 2/2 , I 6/6 , H 8/8 , O : 8 + 4 = 12  and  4 + 8 = 12
           Charge: left = -2 - 6 = -8 , right = -8        BALANCED
```


### Q B13
State any four postulates of Dalton's atomic theory and give any two of
its drawbacks.

**ANSWER:**
```
  POSTULATES  (any four)

    1.  All matter is made up of extremely small indivisible particles
        called atoms.
    2.  All atoms of a given element are identical in mass and in
        chemical properties.
    3.  Atoms of different elements differ in mass and properties.
    4.  Compounds are formed when atoms of different elements combine in
        a fixed simple whole-number ratio.
    5.  Atoms can neither be created nor destroyed in a chemical reaction.

  DRAWBACKS  (any two)

    1.  Atoms are NOT indivisible - they contain electrons, protons and
        neutrons.
    2.  Atoms of the same element are NOT always identical in mass -
        isotopes exist (Cl-35 and Cl-37).
    3.  Atoms of different elements can have the same mass -
        isobars exist (Ar-40, K-40, Ca-40).
    4.  It cannot explain non-stoichiometric compounds or allotropy.
```

### Q B14
Explain the four types of redox reactions with one example each.

**ANSWER:**
```
  1.  COMBINATION REACTION
      Two or more substances combine to form one product; at least one
      reactant must be an element.
             C + O2  ->  CO2         (C: 0 -> +4 , O: 0 -> -2)

  2.  DECOMPOSITION REACTION
      One compound breaks down into two or more products; at least one
      product must be an element.
             2 KClO3  ->  2 KCl  +  3 O2

  3.  DISPLACEMENT REACTION
      An atom or ion in a compound is replaced by another element.
        (a) metal displacement :  Zn + CuSO4  ->  ZnSO4 + Cu
        (b) non-metal displacement : Cl2 + 2 KBr  ->  2 KCl + Br2

  4.  DISPROPORTIONATION REACTION
      The same element in the same oxidation state is both oxidised and
      reduced.
             2 H2O2  ->  2 H2O  +  O2      (O:  -1  ->  -2 and 0)
```

### Q C2
What is a redox reaction? Explain the balancing of redox reactions by the
ion-electron method. Balance the following in acidic medium:

Cr2O7^2- + SO2 -> Cr3+ + SO4^2-

**MODEL ANSWER:**
```
  PART 1  -  WHAT IS A REDOX REACTION                        [1 mark]

     A REDOX reaction is one in which OXIDATION and REDUCTION occur
     simultaneously. Electrons lost by one species are exactly equal to
     the electrons gained by the other.

        OXIDATION = loss of electrons = oxidation number INCREASES
        REDUCTION = gain of electrons = oxidation number DECREASES


  PART 2  -  THE STEPS OF THE ION-ELECTRON METHOD            [3 marks]

     1.  Write the skeletal ionic equation.
     2.  Split it into an OXIDATION half reaction and a REDUCTION
         half reaction.
     3.  Balance all atoms other than H and O.
     4.  Balance OXYGEN by adding H2O to the deficient side.
     5.  Balance HYDROGEN by adding H+ to the deficient side.
     6.  Balance the CHARGE by adding electrons to the more positive side.
     7.  Multiply the halves so that the electrons cancel, then add them
         and cancel any species common to both sides.
     (For BASIC medium, add as many OH- to both sides as there are H+;
      H+ + OH- gives H2O, then cancel duplicate water molecules.)


  PART 3  -  THE WORKED PROBLEM                              [4 marks]

     REDUCTION HALF

         Cr2O7^2-  ->  2 Cr3+
         add 7 H2O on the right :
              Cr2O7^2-  ->  2 Cr3+ + 7 H2O
         add 14 H+ on the left :
              Cr2O7^2- + 14 H+  ->  2 Cr3+ + 7 H2O
         charge:  left = -2 + 14 = +12 ,  right = +6
         add 6 electrons on the LEFT :
              Cr2O7^2- + 14 H+ + 6 e-  ->  2 Cr3+ + 7 H2O

     OXIDATION HALF

         SO2  ->  SO4^2-
         add 2 H2O on the left :
              SO2 + 2 H2O  ->  SO4^2-
         add 4 H+ on the right :
              SO2 + 2 H2O  ->  SO4^2- + 4 H+
         charge:  left = 0 ,  right = -2 + 4 = +2
         add 2 electrons on the RIGHT :
              SO2 + 2 H2O  ->  SO4^2- + 4 H+ + 2 e-

     EQUALISE AND ADD  (multiply the oxidation half by 3)

         Cr2O7^2- + 14 H+ + 6 e-          ->  2 Cr3+ + 7 H2O
         3 SO2 + 6 H2O                    ->  3 SO4^2- + 12 H+ + 6 e-
         -------------------------------------------------------------
         Cr2O7^2- + 14 H+ + 3 SO2 + 6 H2O ->  2 Cr3+ + 3 SO4^2-
                                              + 12 H+ + 7 H2O

     CANCEL:   12 H+ from both sides -> 2 H+ remain on the LEFT
               6 H2O from both sides -> 1 H2O remains on the RIGHT

     FINAL EQUATION

         Cr2O7^2- + 3 SO2 + 2 H+  ->  2 Cr3+ + 3 SO4^2- + H2O

     CHECK  charge:  left = -2 + 2 = 0 ,  right = +6 - 6 = 0    BALANCED
```

### Q C3
State and explain the laws of chemical combination with suitable examples.

**MODEL ANSWER (mark split: about 1.5 marks per law):**
```
  1.  LAW OF CONSERVATION OF MASS  (Lavoisier)                [1.5]

      Matter is neither created nor destroyed in a chemical reaction.
      Mass of reactants = mass of products.

           2 H2  +  O2  ->  2 H2O
            4 g     32 g       36 g          36 g = 36 g


  2.  LAW OF DEFINITE (CONSTANT) PROPORTIONS  (Proust)        [1.5]

      A given compound always contains the same elements combined in the
      same fixed ratio by mass, whatever its source.

           In water, H : O is ALWAYS 1 : 8 by mass.
           In CO2 , C : O is ALWAYS 3 : 8 by mass.


  3.  LAW OF MULTIPLE PROPORTIONS  (Dalton)                   [1.5]

      When two elements form more than one compound, the masses of one
      element combining with a fixed mass of the other bear a simple
      whole-number ratio.

           CO  : 12 g C combines with 16 g O
           CO2 : 12 g C combines with 32 g O
           16 : 32  =  1 : 2


  4.  LAW OF RECIPROCAL PROPORTIONS  (Richter)                [1.5]

      The masses of two elements B and C which separately combine with a
      fixed mass of a third element A are in the same ratio, or a simple
      multiple of it, as the ratio in which B and C combine together.

           In H2O :  2 g H combines with 16 g O
           In H2S :  2 g H combines with 32 g S
                     so  O : S  =  16 : 32  =  1 : 2
           In SO2 :  32 g S combines with 32 g O , so S : O = 1 : 1
           Comparing:  (1/2) : (1/1)  =  1 : 2      simple ratio.


  5.  GAY-LUSSAC'S LAW OF GASEOUS VOLUMES                     [1]

      Gases react in simple whole-number volume ratios at the same
      temperature and pressure.

           H2  +  Cl2  ->  2 HCl        1 vol : 1 vol : 2 vol


  6.  AVOGADRO'S LAW                                          [1]

      Equal volumes of all gases at the same temperature and pressure
      contain an equal number of molecules.
      It explained Gay-Lussac's law and proved that hydrogen, oxygen,
      nitrogen and chlorine gases are DIATOMIC.
```

### Q C5
Explain oxidation number. State the rules for assigning oxidation numbers.
Calculate the oxidation number of the underlined element in K2Cr2O7,
KMnO4, H2SO4, Na2S2O3 and Fe3O4.

**MODEL ANSWER:**
```
  PART 1  -  WHAT IS AN OXIDATION NUMBER                      [1 mark]

     The oxidation number of an atom in a compound is the charge that the
     atom would carry if all the bonds in the compound were assumed to be
     completely ionic (that is, if the shared electrons were given
     entirely to the more electronegative atom).


  PART 2  -  THE RULES                                        [4 marks]

     1.  An element in its free (uncombined) state has oxidation
         number ZERO.       Na , H2 , O2 , Cl2 , P4 , S8

     2.  For a monatomic ion the oxidation number equals its charge.
         Na+ = +1 ,  Cl- = -1 ,  Al3+ = +3

     3.  Hydrogen is +1, except in metal hydrides (NaH, CaH2) where
         it is -1.

     4.  Oxygen is -2, except in peroxides (H2O2, Na2O2) where it is -1,
         in superoxides (KO2) where it is -1/2, and in OF2 where it
         is +2.

     5.  Fluorine is ALWAYS -1.

     6.  Group 1 metals are +1, Group 2 metals are +2, aluminium is +3.

     7.  The algebraic sum of the oxidation numbers of all atoms in a
         neutral molecule is ZERO; in a polyatomic ion it equals the
         charge on the ion.


  PART 3  -  THE CALCULATIONS                             [3 marks]

     K2Cr2O7 (Cr) :   2(+1) + 2x + 7(-2) = 0
                      2 + 2x - 14 = 0  ->  2x = 12  ->  x = +6

     KMnO4 (Mn)   :   (+1) + x + 4(-2) = 0
                      1 + x - 8 = 0    ->  x = +7

     H2SO4 (S)    :   2(+1) + x + 4(-2) = 0
                      2 + x - 8 = 0    ->  x = +6

     Na2S2O3 (S)  :   2(+1) + 2x + 3(-2) = 0
                      2 + 2x - 6 = 0   ->  2x = 4  ->  x = +2
                      (an AVERAGE value)

     Fe3O4 (Fe)   :   3x + 4(-2) = 0
                      3x = 8   ->   x = +8/3
                      (a fractional AVERAGE; Fe3O4 is really FeO.Fe2O3,
                       containing one Fe(+2) and two Fe(+3))
```
