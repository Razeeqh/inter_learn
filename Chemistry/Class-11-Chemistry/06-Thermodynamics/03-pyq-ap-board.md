## Topic: Basic terms

### Q A1
Define a system and its surroundings. What is a boundary?

**ANSWER:**
```
  SYSTEM       - the part of the universe chosen for study
                 (e.g. the reaction mixture in a beaker).

  SURROUNDINGS - everything in the universe outside the system.

  BOUNDARY     - the real or imaginary surface that separates the system
                 from the surroundings.

  SYSTEM + SURROUNDINGS = UNIVERSE
```

---

### Q A2
What are the types of system? Give one example of each.

**ANSWER:**
```
  OPEN      - exchanges BOTH matter and energy with the surroundings.
              Example: hot tea in an open cup.

  CLOSED    - exchanges ENERGY but NOT matter.
              Example: water sealed in a closed steel container.

  ISOLATED  - exchanges NEITHER matter NOR energy.
              Example: hot coffee in a (perfect) thermos flask.
```

---

### Q A3
Distinguish between extensive and intensive properties with two examples of each.

**ANSWER:**
```
  EXTENSIVE - depends on the AMOUNT of substance present.
              Examples: mass, volume, internal energy U, enthalpy H,
                        entropy S, heat capacity.

  INTENSIVE - does NOT depend on the amount of substance.
              Examples: temperature, pressure, density, molarity,
                        specific heat, boiling point.

  QUICK TEST: take half the sample. If the number changes -> extensive.
```

---

### Q A4
What is a state function? Give two examples. Name the two path functions.

**ANSWER:**
```
  STATE FUNCTION - a property whose value depends ONLY on the initial and
  final states of the system, and NOT on the path followed.

     Examples:  internal energy U, enthalpy H, entropy S, Gibbs energy G,
                pressure p, volume V, temperature T.

  PATH FUNCTIONS - HEAT (q) and WORK (w). Their values depend on the route
  taken, but their SUM (q + w = delta U) is a state function.
```

---

### Q A5
Define an isothermal process and an adiabatic process.

**ANSWER:**
```
  ISOTHERMAL - a process carried out at CONSTANT TEMPERATURE (delta T = 0).
               For an ideal gas delta U = 0, so  q = - w.

  ADIABATIC  - a process in which NO HEAT is exchanged between the system
               and the surroundings (q = 0).
               Therefore  delta U = w.
```

---

### Q A6
What is an isochoric process? What is a cyclic process?

**ANSWER:**
```
  ISOCHORIC - a process carried out at CONSTANT VOLUME (delta V = 0).
              Since w = - p delta V = 0,   delta U = q(v).

  CYCLIC    - a process in which the system returns to its initial state
              after a series of changes.
              Since U and H are state functions,
                    delta U = 0  and  delta H = 0 ,  therefore  q = - w.
```

---

### Q A7
Distinguish between a reversible and an irreversible process.

**ANSWER:**
```
  REVERSIBLE     - carried out infinitely slowly in infinitesimal steps;
                   the system is in equilibrium with the surroundings at
                   every stage; it can be reversed by an infinitesimal
                   change; it gives the MAXIMUM work. It is an IDEAL process.

  IRREVERSIBLE   - occurs in a single rapid step with a large driving force;
                   the system is not in equilibrium during the change;
                   it cannot be reversed by an infinitesimal change.
                   ALL real, natural processes are irreversible.
```

## Topic: First law

### Q A8
State the first law of thermodynamics and give its mathematical form.

**ANSWER:**
```
  STATEMENT: Energy can neither be created nor destroyed; it can only be
  converted from one form into another. The total energy of an isolated
  system remains constant.

  MATHEMATICAL FORM:      delta U  =  q  +  w

     delta U = change in internal energy of the system
     q       = heat ABSORBED BY the system
     w       = work done ON the system
```

---

### Q A9
State the sign convention for heat and work used in thermodynamics.

**ANSWER:**
```
  Rule:  what the SYSTEM GAINS is POSITIVE.

     q = + ve   heat ABSORBED BY the system   (endothermic)
     q = - ve   heat RELEASED BY the system   (exothermic)
     w = + ve   work done ON the system       (compression)
     w = - ve   work done BY the system       (expansion)
```

---

### Q A10
A system absorbs 500 J of heat and 200 J of work is done on it.
Calculate the change in internal energy.

**ANSWER:**
```
  q  =  + 500 J   (absorbed)
  w  =  + 200 J   (done ON the system)

  delta U  =  q + w  =  500 + 200  =  + 700 J
```

---

### Q A11
A gas expands and does 300 J of work while absorbing 100 J of heat.
Find delta U.

**ANSWER:**
```
  Work done BY the system  ->  w = - 300 J
  Heat absorbed            ->  q = + 100 J

  delta U  =  100 + ( - 300 )  =  - 200 J

  The internal energy DECREASED by 200 J.
```

---

### Q A12
What is internal energy? Why can its absolute value not be determined?

**ANSWER:**
```
  INTERNAL ENERGY (U) is the total energy stored in a system - the sum of
  its translational, rotational, vibrational, electronic, nuclear and
  chemical bond energies.

  Its ABSOLUTE value cannot be measured because we can never strip a
  substance of every form of energy to reach a true zero. Only the CHANGE,
  delta U = U(final) - U(initial), can be measured experimentally.
```

## Topic: Work of expansion

### Q A13
A gas expands from 5 L to 10 L against a constant external pressure of 1 atm.
Calculate the work done.

**ANSWER:**
```
  w  =  - p(ext) ( V2 - V1 )
     =  - 1 ( 10 - 5 )   =   - 5  L atm

     =  - 5 x 101.3   =   - 506.5  J

  Negative -> work is done BY the gas (it expanded). Correct.
```

---

### Q A14
Why is the work done in a free expansion zero?

**ANSWER:**
```
  A free expansion is expansion into a VACUUM, so the external pressure
  p(ext) = 0.

           w  =  - p(ext) x delta V  =  - 0 x delta V  =  0

  There is nothing outside for the gas to push against, so no work is done.
```

## Topic: Enthalpy

### Q A15
Define enthalpy. Write the relation between delta H and delta U.

**ANSWER:**
```
  ENTHALPY (H) is the total heat content of a system at constant pressure:

              H  =  U  +  p V

  It is a state function and an extensive property.

  RELATION:   delta H  =  delta U  +  delta n(g)  R  T

  where delta n(g) = (moles of gaseous products) - (moles of gaseous
  reactants). It equals the heat absorbed at constant pressure: q(p) = delta H.
```

---

### Q A16
Under what conditions is delta H equal to delta U?

**ANSWER:**
```
  When  delta n(g) = 0 , i.e. when the number of moles of GAS is the same
  on both sides of the equation, the term delta n(g) R T vanishes.

     Example:   H2(g) + Cl2(g) -> 2 HCl(g)     ( 2 - 2 = 0 )
                C(s)  + O2(g)  -> CO2(g)       ( 1 - 1 = 0 )

  It is also true for reactions involving only solids and liquids, and for
  any process at constant volume.
```

### Q A17
Calculate delta n(g) for:
(a) CaCO3(s) -> CaO(s) + CO2(g)
(b) N2(g) + 3 H2(g) -> 2 NH3(g)
(c) C6H6(l) + 15/2 O2(g) -> 6 CO2(g) + 3 H2O(l)

**ANSWER:**
```
  Count GASES only. Ignore solids and liquids.

  (a)  products 1 (CO2)  ,  reactants 0        ->  delta n(g) = + 1
  (b)  products 2 (NH3)  ,  reactants 4        ->  delta n(g) = - 2
  (c)  products 6 (CO2)  ,  reactants 7.5 (O2) ->  delta n(g) = - 1.5
```

### Q A18
Define the enthalpy of combustion. Why is it always negative?

**ANSWER:**
```
  ENTHALPY OF COMBUSTION - the enthalpy change when ONE MOLE of a substance
  is COMPLETELY BURNT in excess oxygen, all substances being in their
  standard states.

      CH4(g) + 2 O2(g) -> CO2(g) + 2 H2O(l)   delta H(c) = - 890.3 kJ/mol

  It is ALWAYS NEGATIVE because combustion always RELEASES heat
  (it is always an exothermic reaction).
```

---

### Q A19
Define the enthalpy of neutralisation. Why is it almost constant
(about -57.1 kJ/mol) for all strong acid + strong base pairs?

**ANSWER:**
```
  ENTHALPY OF NEUTRALISATION - the enthalpy change when ONE MOLE of water
  is formed by the neutralisation of an acid by a base in dilute solution.

  Strong acids and strong bases are COMPLETELY IONISED in solution, so the
  only reaction actually taking place is always the same:

              H+(aq)  +  OH-(aq)  ->  H2O(l)      delta H = - 57.1 kJ/mol

  For a WEAK acid or base the value is less negative, because part of the
  energy is consumed in ionising the weak electrolyte.
```

---

### Q A20
Define the enthalpy of formation. What is delta H(f) of O2(g) and of
C(graphite)?

**ANSWER:**
```
  ENTHALPY OF FORMATION - the enthalpy change when ONE MOLE of a compound
  is formed from its ELEMENTS in their standard states.

      C(graphite) + 2 H2(g) -> CH4(g)     delta H(f) = - 74.8 kJ/mol

  By convention, the standard enthalpy of formation of any ELEMENT in its
  standard state is ZERO.

      delta H(f) of O2(g)        =  0
      delta H(f) of C(graphite)  =  0
```

---

### Q A21
Define bond enthalpy and lattice enthalpy.

**ANSWER:**
```
  BOND ENTHALPY - the enthalpy change required to BREAK one mole of a
  particular bond in the GASEOUS state. It is always POSITIVE.

        H2(g)  ->  2 H(g)        bond enthalpy of H-H = + 435 kJ/mol

  LATTICE ENTHALPY - the enthalpy change when ONE MOLE of an ionic solid is
  completely separated into its GASEOUS IONS, infinitely far apart.

        NaCl(s)  ->  Na+(g) + Cl-(g)      delta H = + 788 kJ/mol
```

## Topic: Hess's law

### Q A22
State Hess's law of constant heat summation.

**ANSWER:**
```
  HESS'S LAW: The total enthalpy change of a reaction is the SAME whether
  the reaction takes place in ONE STEP or in SEVERAL STEPS.

  It follows directly from the fact that ENTHALPY IS A STATE FUNCTION -
  delta H depends only on the initial and final states, not on the route.

           delta H  =  delta H1 + delta H2 + delta H3 + ...
```

## Topic: Spontaneity, entropy, Gibbs energy

### Q A23
What is a spontaneous process? Give two examples.

**ANSWER:**
```
  A SPONTANEOUS process is one that takes place ON ITS OWN, without any
  external help, once initiated. It says NOTHING about the speed.

  Examples:  - flow of heat from a hot body to a cold body
             - water flowing downhill
             - dissolution of sugar in water
             - rusting of iron
```

---

### Q A24
Define entropy. What is its unit?

**ANSWER:**
```
  ENTROPY (S) is a measure of the DISORDER or RANDOMNESS of a system.
  The greater the disorder, the higher the entropy.

              delta S  =  q(reversible) / T

  UNIT:  J K^-1 mol^-1   (joule per kelvin per mole)

  Order of entropy:   S(gas)  >  S(liquid)  >  S(solid)
```

---

### Q A25
State the second law of thermodynamics.

**ANSWER:**
```
  Any ONE of the following is accepted:

  1. The entropy of the universe always INCREASES in a spontaneous process.
                     delta S(total) > 0 for a spontaneous change

  2. Heat cannot flow of its own accord from a colder body to a hotter body.

  3. It is impossible to convert heat completely into work without leaving
     some change somewhere.
```

---

### Q A26
State the third law of thermodynamics. What is its use?

**ANSWER:**
```
  THIRD LAW: The entropy of a PERFECTLY CRYSTALLINE substance is ZERO at
  ABSOLUTE ZERO temperature (0 K).

  Reason: at 0 K every particle is fixed in one exact position with no
  motion, so there is only one possible arrangement and no randomness.

  USE: it provides a true zero from which ABSOLUTE entropies of substances
  can be calculated (unlike U and H, where only changes can be measured).
```

---

### Q A27
Write the Gibbs equation and state the criterion of spontaneity.

**ANSWER:**
```
              G  =  H  -  T S

              delta G  =  delta H  -  T delta S

  CRITERION:
        delta G  <  0    ->   SPONTANEOUS
        delta G  =  0    ->   EQUILIBRIUM
        delta G  >  0    ->   NON-SPONTANEOUS
```

### Q A30
Write the relation between the standard Gibbs energy change and the

**ANSWER:**
```
        delta G (standard)  =  -  R T  ln K

     delta G positive  ->  K < 1  ->  reactants favoured
```

### Q B1
State the first law of thermodynamics. Explain its application to
isothermal, adiabatic, isochoric and cyclic processes.

**ANSWER:**
```
  STATEMENT: Energy can neither be created nor destroyed, only converted
  from one form to another. The energy of an isolated system is constant.

              delta U  =  q  +  w

  APPLICATIONS

  1. ISOTHERMAL process (T constant).
     For an ideal gas U depends only on T, so delta U = 0.
             0 = q + w      ->      q = - w
     All the heat absorbed is converted into work.

  2. ADIABATIC process (no heat exchange, q = 0).
             delta U = w
     Work is done at the expense of internal energy, so an adiabatic
     EXPANSION cools the gas and a compression heats it.

  3. ISOCHORIC process (V constant, so w = - p delta V = 0).
             delta U = q(v)
     The heat measured in a rigid sealed vessel is exactly delta U.

  4. CYCLIC process (system returns to its initial state).
     U is a state function, so delta U = 0.
             q = - w
     The net heat absorbed equals the net work done by the system.
```

---

### Q B2
Derive the expression for the work done in a reversible isothermal
expansion of an ideal gas.

**ANSWER:**
```
  STEP 1  In a reversible change the external pressure differs from the gas
          pressure only infinitesimally, so we may write

                    p(ext)  =  p  =  n R T / V

  STEP 2  The small work done ON the gas for a small volume change dV is

                    dw  =  -  p(ext) dV   =   - ( n R T / V ) dV

  STEP 3  Integrate from V1 to V2. The process is isothermal, so T is
          constant and n R T comes outside the integral:

                    w  =  -  n R T  INT (V1 to V2) dV / V

                    w  =  -  n R T  [ ln V ] (V1 to V2)

  STEP 4              w  =  -  n R T  ln ( V2 / V1 )

  STEP 5  Converting to logarithms to base 10 ( ln x = 2.303 log x ):

          +---------------------------------------------------------+
          |     w  =  -  2.303  n R T  log ( V2 / V1 )              |
          |                                                         |
          |     using Boyle's law p1V1 = p2V2 :                     |
          |                                                         |
          |     w  =  -  2.303  n R T  log ( p1 / p2 )              |
          +---------------------------------------------------------+

  Since delta U = 0 for an isothermal ideal gas,
                    q  =  - w  =  + 2.303 n R T log ( V2 / V1 )
```

### Q B3
Calculate the work done when 2 moles of an ideal gas expand isothermally
and reversibly at 300 K from a volume of 2 L to 20 L. Also find q and delta U.

**ANSWER:**
```
  w  =  - 2.303 n R T log ( V2 / V1 )
     =  - 2.303 x 2 x 8.314 x 300 x log ( 20 / 2 )

     log 10  =  1

     2.303 x 2      =  4.606
     4.606 x 8.314  =  38.29
     38.29 x 300    =  11487

  w  =  - 11487 J  =  - 11.49 kJ

  ISOTHERMAL + ideal gas   ->   delta U = 0

  q  =  - w  =  + 11.49 kJ

  ANSWER:  w = -11.49 kJ ,  delta U = 0 ,  q = +11.49 kJ
```

### Q B4
Two moles of an ideal gas at 300 K expand from 1 L to 10 L
(a) reversibly and isothermally, (b) irreversibly against a constant
external pressure of 1 atm. Compare the work done and comment.

**ANSWER:**
```
  (a) REVERSIBLE

      w  =  - 2.303 x 2 x 8.314 x 300 x log ( 10 / 1 )
         =  - 11487 J   =   - 11.49 kJ

  (b) IRREVERSIBLE

      w  =  - p(ext) ( V2 - V1 )  =  - 1 ( 10 - 1 )  =  - 9 L atm
         =  - 9 x 101.3  =  - 911.7 J  =  - 0.91 kJ

  COMMENT
      The initial and final states are IDENTICAL in both cases, yet the
      work is completely different. This PROVES that work is a PATH
      FUNCTION.
      Also | w(rev) | > | w(irrev) |, showing that a reversible process
      yields the MAXIMUM possible work.
```

### Q B5
Derive the relation delta H = delta U + delta n(g) R T.

**ANSWER:**
```
  By definition of enthalpy,          H  =  U  +  p V

  For a change at constant pressure,

              delta H  =  delta U  +  p delta V            ... (1)

  Let the reaction involve gases. Assume ideal behaviour.

      For the gaseous reactants:      p V1  =  n1 R T
      For the gaseous products:       p V2  =  n2 R T

  Subtracting,      p ( V2 - V1 )  =  ( n2 - n1 ) R T

                    p delta V      =  delta n(g) R T       ... (2)

  Substituting (2) into (1):

          +---------------------------------------------------------+
          |        delta H  =  delta U  +  delta n(g) R T           |
          +---------------------------------------------------------+

  where delta n(g) = (moles of gaseous products) - (moles of gaseous
  reactants). Solids and liquids are not counted, as their volumes are
  negligible compared with those of gases.
```

### Q B6
The enthalpy of combustion of benzene at constant volume and 298 K is
-3263.9 kJ/mol. Calculate delta H.
`C6H6(l) + 15/2 O2(g) -> 6 CO2(g) + 3 H2O(l)`

**ANSWER:**
```
  STEP 1  Count GASES only.
          Products : 6 mol CO2 (H2O is a LIQUID - not counted)
          Reactants: 7.5 mol O2 (C6H6 is a LIQUID - not counted)

          delta n(g)  =  6  -  7.5  =  - 1.5

  STEP 2  delta n(g) R T
          =  ( - 1.5 ) x ( 8.314 x 10^-3 kJ/K/mol ) x ( 298 K )
          =  ( - 1.5 ) x 2.4776
          =  - 3.72 kJ/mol

  STEP 3  delta H  =  delta U  +  delta n(g) R T
                   =  - 3263.9  +  ( - 3.72 )
                   =  - 3267.6 kJ/mol

  ANSWER:  delta H = - 3267.6 kJ/mol
```

### Q B7
For the reaction N2(g) + 3 H2(g) -> 2 NH3(g), delta H = -92.4 kJ at 298 K.

**ANSWER:**
```

           =  - 92.4  -  ( - 2 )( 8.314 x 10^-3 )( 298 )
           =  - 92.4  +  2 ( 2.4776 )
           =  - 92.4  +  4.955

  delta U  =  - 87.44 kJ
```

### Q B8
Derive the relation Cp - Cv = R for one mole of an ideal gas.

**ANSWER:**
```
  STEP 1  At CONSTANT VOLUME no work is done, so all the heat supplied
          raises the internal energy. For one mole:

                     Cv  =  ( dU / dT ) at constant V

  STEP 2  At CONSTANT PRESSURE the heat supplied equals the enthalpy
          change. For one mole:

                     Cp  =  ( dH / dT ) at constant p

  STEP 3  By definition,        H  =  U  +  p V

          For one mole of an ideal gas,   p V  =  R T ,   so

                     H  =  U  +  R T

  STEP 4  Differentiate with respect to T:

                     dH / dT  =  dU / dT  +  R

  STEP 5  Substituting from steps 1 and 2:

          +---------------------------------------------------------+
          |               Cp  -  Cv   =   R                         |
          +---------------------------------------------------------+

  PHYSICAL MEANING: at constant pressure the gas must also do work in
  pushing back the atmosphere as it expands. The extra heat needed for
  that work is exactly R per mole per kelvin. This is also why Cp is
  ALWAYS greater than Cv.
```

### Q B9
Describe the bomb calorimeter and explain how delta U is measured.
1.00 g of graphite burnt in a bomb calorimeter raises the temperature from
298.0 K to 299.0 K. If the heat capacity of the calorimeter is 20.7 kJ/K,
find delta U per mole.

**ANSWER:**
```
     +-------------------------------------------+
     |          insulated outer jacket           |
     |   +-----------------------------------+   |
     |   |   water   [thermometer] [stirrer] |   |
     |   |    +-------------------------+    |   |
     |   |    |   STEEL BOMB (rigid)    |    |   |
     |   |    |  sample + excess O2     |    |   |
     |   |    |  ignition wires         |    |   |
     |   |    +-------------------------+    |   |
     |   +-----------------------------------+   |
     +-------------------------------------------+

  WORKING
   1. A weighed sample is sealed inside the rigid steel bomb along with
      excess oxygen at high pressure.
   2. The bomb is immersed in a known mass of water in an insulated jacket.
   3. The sample is ignited electrically and the temperature rise of the
      water is measured.
   4. Because the steel bomb is RIGID, delta V = 0, so w = 0 and the heat
      measured is exactly  delta U.

  CALCULATION

     Heat absorbed by the calorimeter = C x delta T
                                      = 20.7 x ( 299.0 - 298.0 ) = 20.7 kJ

     This heat came OUT of the reaction, so   q = - 20.7 kJ  for 1.00 g.

     Moles of carbon  =  1.00 / 12  =  0.0833 mol

     delta U  =  - 20.7 / 0.0833  =  - 248.4 kJ/mol

  ANSWER: delta U = - 2.48 x 10^2 kJ/mol
```

### Q B10
State Hess's law and use it to calculate the enthalpy of formation of
carbon monoxide from:
```
   C(s) + O2(g)  ->  CO2(g)             delta H = - 393.5 kJ
   CO(g) + 1/2 O2(g)  ->  CO2(g)        delta H = - 283.0 kJ
```

**ANSWER:**
```
  HESS'S LAW: The total enthalpy change of a reaction is the same whether
  it occurs in one step or in several steps.

  TARGET:   C(s) + 1/2 O2(g)  ->  CO(g)

  STEP 1  Keep equation (i) as it is (C is on the left in the target):

              C(s) + O2(g)  ->  CO2(g)            delta H = - 393.5

  STEP 2  REVERSE equation (ii) and change the sign
          (CO must be on the RIGHT in the target):

              CO2(g)  ->  CO(g) + 1/2 O2(g)       delta H = + 283.0

  STEP 3  ADD, cancelling CO2 from both sides:

              C(s) + 1/2 O2(g)  ->  CO(g)

  STEP 4  delta H  =  ( - 393.5 ) + ( + 283.0 )  =  - 110.5 kJ

  ANSWER: delta H(f) of CO(g) = - 110.5 kJ/mol
```

### Q B11
Calculate the standard enthalpy of formation of CH4(g) from:
```
   C(s) + O2(g) -> CO2(g)                     delta H = - 393.5 kJ

### Q B17
Explain the limitations of the first law of thermodynamics and how the
concept of entropy overcomes them.

**ANSWER:**
```
  LIMITATIONS OF THE FIRST LAW

  1. It only says energy is conserved. It does NOT tell us the DIRECTION
     in which a process will go.
     Heat flowing from a cold body to a hot body would also conserve
     energy, yet it never happens - the first law cannot forbid it.

  2. It gives no criterion for SPONTANEITY (feasibility).

  3. It does not explain why energy cannot be completely converted
     from heat into work.

  4. Exothermicity (delta H negative) is NOT a reliable criterion either:
     melting of ice, evaporation of water and dissolution of NH4Cl are all
     ENDOTHERMIC yet spontaneous.

     ENTROPY (S) measures the disorder or randomness of a system.

              delta S  =  q(rev) / T

     The SECOND LAW then supplies the missing direction:

              delta S(total) = delta S(system) + delta S(surroundings)

              delta S(total) > 0   ->  SPONTANEOUS
              delta S(total) = 0   ->  EQUILIBRIUM
              delta S(total) < 0   ->  NON-SPONTANEOUS

     Combining entropy with enthalpy gives the practical criterion
              delta G = delta H - T delta S  ,  spontaneous when dG < 0.
```

### Q C1
State the first law of thermodynamics. Explain the sign convention for
heat and work. Derive expressions for the work done in (a) an irreversible
isothermal expansion and (b) a reversible isothermal expansion of an ideal
gas. What is free expansion?

**MODEL ANSWER (mark split shown):**

```
  ------------------------------------------------ STATEMENT  [1 mark]
  Energy can neither be created nor destroyed; it can only be converted
  from one form into another. The total energy of an isolated system
  remains constant.

              delta U  =  q  +  w

     delta U = change in internal energy
     q       = heat ABSORBED BY the system
     w       = work done ON the system

  ------------------------------------------ SIGN CONVENTION  [1.5 marks]
  The rule is: WHAT THE SYSTEM GAINS IS POSITIVE.

     q = + ve   heat absorbed BY the system   (endothermic)
     q = - ve   heat released BY the system   (exothermic)
     w = + ve   work done ON the system       (COMPRESSION)
     w = - ve   work done BY the system       (EXPANSION)

  ----------------------------- (a) IRREVERSIBLE EXPANSION  [2.5 marks]

  Consider a gas in a cylinder fitted with a frictionless, weightless
  piston of area A, against a constant external pressure p(ext).

                    |     |
                    |     |  <- piston, area A
       p(ext) --->  +-----+  --->  moves out by  dl
                    | GAS |
                    +-----+

  Force on the piston      F  =  p(ext) x A

  Work done BY the gas     =  F x dl  =  p(ext) x A x dl  =  p(ext) x dV

  Work done ON the system is the negative of this:

              dw  =  -  p(ext) dV

  For a finite change against a CONSTANT external pressure:

          +---------------------------------------------------------+
          |          w  =  -  p(ext) ( V2  -  V1 )                  |
          +---------------------------------------------------------+

  Expansion (V2 > V1) gives w NEGATIVE; compression gives w POSITIVE.

  ------------------------------- (b) REVERSIBLE EXPANSION  [2.5 marks]

  In a reversible process the external pressure is only infinitesimally
  smaller than the pressure of the gas, so

              p(ext)  =  p  =  n R T / V

              dw  =  -  ( n R T / V ) dV

  Integrating from V1 to V2 at constant T:

              w  =  -  n R T  INT (V1 to V2)  dV / V

              w  =  -  n R T  ln ( V2 / V1 )

          +---------------------------------------------------------+
          |     w  =  -  2.303 n R T  log ( V2 / V1 )               |
          |                                                         |
          |     w  =  -  2.303 n R T  log ( p1 / p2 )               |
          +---------------------------------------------------------+

  Since delta U = 0 for an isothermal ideal gas,  q = - w.

  The magnitude of the reversible work is always GREATER than that of
  the irreversible work between the same two states, so a reversible
  expansion gives the MAXIMUM work. This also shows that w is a PATH
  FUNCTION.

  ------------------------------------------- FREE EXPANSION  [0.5 mark]
  Free expansion is expansion into a VACUUM, where p(ext) = 0.

              w  =  - 0 x delta V  =  0

  No work is done in a free expansion. If it is also adiabatic (q = 0),
  then delta U = 0 and the temperature of an ideal gas does not change.
```

### Q C2
Define enthalpy. Derive delta H = delta U + delta n(g) R T. Define the
enthalpies of formation, combustion, neutralisation, atomisation and
bond enthalpy with one example each.

**MODEL ANSWER (mark split shown):**

```
  ------------------------------------------------- ENTHALPY  [1 mark]
  Enthalpy is the total heat content of a system at constant pressure:

              H  =  U  +  p V

  It is a state function and an extensive property. Only its CHANGE can
  be measured. At constant pressure the heat absorbed equals delta H:
              q(p)  =  delta H
  and at constant volume the heat absorbed equals delta U:
              q(v)  =  delta U

  -------------------------------------------------- DERIVATION [2.5 marks]
  From          H  =  U  +  p V

  at constant p:   delta H  =  delta U  +  p delta V          ... (1)

  For ideal gases,   p V(reactants) = n1 R T
                     p V(products)  = n2 R T

  Subtracting,       p ( V2 - V1 )  =  ( n2 - n1 ) R T
                     p delta V      =  delta n(g) R T         ... (2)

  Substituting (2) into (1):

          +---------------------------------------------------------+
          |        delta H  =  delta U  +  delta n(g) R T           |
          +---------------------------------------------------------+

  delta n(g) = (moles of gaseous products) - (moles of gaseous reactants).
  Solids and liquids are not counted; their volumes are negligible.

  If delta n(g) = 0 then delta H = delta U.

  ----------------------------------------------- DEFINITIONS  [4.5 marks]

  1. ENTHALPY OF FORMATION, delta H(f)
     The enthalpy change when ONE MOLE of a compound is formed from its
     ELEMENTS in their standard states.
        C(graphite) + 2 H2(g) -> CH4(g)      delta H(f) = - 74.8 kJ/mol
     For any element in its standard state, delta H(f) = 0.

  2. ENTHALPY OF COMBUSTION, delta H(c)
     The enthalpy change when ONE MOLE of a substance is completely burnt
     in excess oxygen. It is always NEGATIVE.
        CH4(g) + 2 O2(g) -> CO2(g) + 2 H2O(l)  delta H(c) = -890.3 kJ/mol

  3. ENTHALPY OF NEUTRALISATION
     The enthalpy change when ONE MOLE of water is formed by neutralising
     an acid with a base in dilute solution.
        HCl(aq) + NaOH(aq) -> NaCl(aq) + H2O(l)   delta H = -57.1 kJ/mol
     It is constant for all strong acid + strong base pairs because the
     only real reaction is  H+(aq) + OH-(aq) -> H2O(l).

  4. ENTHALPY OF ATOMISATION, delta H(a)
     The enthalpy change when ONE MOLE of a substance is completely broken
     into GASEOUS ATOMS. Always positive.
        CH4(g) -> C(g) + 4 H(g)              delta H(a) = +1665 kJ/mol

  5. BOND ENTHALPY
     The enthalpy change required to break ONE MOLE of a particular bond
     in the gaseous state. Always positive.
        H2(g) -> 2 H(g)                      H-H bond enthalpy = +435 kJ/mol
     For polyatomic molecules the MEAN bond enthalpy is used; the mean
     C-H bond enthalpy in methane is 1665 / 4 = 416 kJ/mol.
```

### Q C3
State Hess's law of constant heat summation. Explain how it is used to
calculate reaction enthalpies. Describe the Born-Haber cycle for sodium
chloride and use it to obtain the lattice enthalpy.

**MODEL ANSWER (mark split shown):**

```
  ------------------------------------------------ STATEMENT  [1.5 marks]
  HESS'S LAW: The total enthalpy change of a reaction is the SAME whether
  the reaction takes place in ONE STEP or in SEVERAL STEPS.

  It is a direct consequence of enthalpy being a STATE FUNCTION: delta H
  depends only on the initial and final states, not on the route taken.

                      delta H (direct)
        A  --------------------------------------->  D
        |                                            ^
        | dH1                                        | dH3
        v                  dH2                       |
        B  ------------------------------->  C  -----+

              delta H  =  dH1  +  dH2  +  dH3

  ----------------------------------------------------- USE  [2.5 marks]
  Hess's law allows us to find enthalpy changes that CANNOT be measured
  directly (for example the formation of CO, or a lattice enthalpy).

  RULES for manipulating thermochemical equations:
     1. Reversing an equation reverses the SIGN of delta H.
     2. Multiplying an equation by n multiplies delta H by n.
     3. Adding equations adds their delta H values.

  EXAMPLE
     Given   C(s) + O2(g) -> CO2(g)            delta H = - 393.5 kJ
             CO(g) + 1/2 O2(g) -> CO2(g)       delta H = - 283.0 kJ

     Keep the first, reverse the second:
             C(s) + O2(g) -> CO2(g)                    - 393.5
             CO2(g) -> CO(g) + 1/2 O2(g)               + 283.0
             -----------------------------------------------
             C(s) + 1/2 O2(g) -> CO(g)                 - 110.5 kJ

     Hence delta H(f) of CO = - 110.5 kJ/mol.

  ------------------------------------------- BORN-HABER CYCLE  [4 marks]
  The Born-Haber cycle applies Hess's law to the formation of an ionic
  solid, and is used to find the LATTICE ENTHALPY, which cannot be
  measured directly.

                         delta H(f) = - 411 kJ/mol
     Na(s) + 1/2 Cl2(g) ---------------------------->  NaCl(s)
        |                                                 ^
        | S  = sublimation of Na            + 108.7        |
        v                                                  |
     Na(g) + 1/2 Cl2(g)                                    |
        |                                                  |  U = lattice
        | IE = ionisation of Na             + 495.6        |  enthalpy of
        v                                                  |  formation
     Na+(g) + 1/2 Cl2(g)                                   |
        |                                                  |
        | D/2 = half the Cl-Cl bond energy  + 121          |
        v                                                  |
     Na+(g) + Cl(g)                                        |
        |                                                  |
        | EA = electron gain enthalpy       - 348.6        |
        v                                                  |
     Na+(g) + Cl-(g)  ----------------------------------->-+

  By Hess's law, the direct route must equal the sum of the steps:

          +---------------------------------------------------------+
          |     delta H(f)  =  S  +  IE  +  ( D / 2 )  +  EA  +  U  |
          +---------------------------------------------------------+

  SUBSTITUTING
          - 411  =  108.7 + 495.6 + 121 + ( - 348.6 ) + U
          - 411  =  376.7  +  U
              U  =  - 411  -  376.7   =   - 787.7 kJ/mol

  So the lattice enthalpy of formation of NaCl is - 787.7 kJ/mol; i.e.
  + 787.7 kJ/mol is required to separate one mole of NaCl(s) into
  gaseous Na+ and Cl- ions.
```

### Q C4
What is a spontaneous process? Explain why the first law is inadequate as
a criterion of spontaneity. Define entropy and state the second law.
Derive the Gibbs criterion and discuss the four cases of delta H and
delta S. Relate delta G to the equilibrium constant.

**MODEL ANSWER (mark split shown):**

```
  ------------------------------------------------ SPONTANEITY  [1 mark]
  A SPONTANEOUS process is one that takes place ON ITS OWN, without any
  external help, once initiated. It says nothing about the SPEED - the
  rusting of iron is spontaneous but very slow.

  Examples: heat flowing from a hot to a cold body; water flowing downhill;
  a gas filling its container; sugar dissolving in water.

  ---------------------------- WHY THE FIRST LAW IS INADEQUATE  [1 mark]
  The first law only states that energy is conserved. Heat flowing from a
  cold body to a hot body would ALSO conserve energy, yet it never occurs.
  So the first law gives no information about the DIRECTION or the
  FEASIBILITY of a change.

  Nor is exothermicity a valid criterion: melting of ice, evaporation of
  water and the dissolution of NH4Cl are all ENDOTHERMIC yet spontaneous.

  --------------------------------------------------- ENTROPY  [1.5 marks]
  ENTROPY (S) is a measure of the DISORDER or RANDOMNESS of a system.

              delta S  =  q(reversible) / T          unit: J K^-1 mol^-1

  It is a state function and an extensive property.
              S(gas)  >  S(liquid)  >  S(solid)

  For a phase change at constant temperature:
              delta S(fus) = delta H(fus) / T(f)
              delta S(vap) = delta H(vap) / T(b)

  For a reaction:  delta S = SUM S(products) - SUM S(reactants).

  ------------------------------------------------ SECOND LAW  [1 mark]
  The entropy of the universe always INCREASES in a spontaneous process.

              delta S(total) = delta S(system) + delta S(surroundings)

              delta S(total) > 0   ->  SPONTANEOUS
              delta S(total) = 0   ->  EQUILIBRIUM
              delta S(total) < 0   ->  NON-SPONTANEOUS

  ------------------------------------------- GIBBS CRITERION  [2 marks]
  The entropy criterion is awkward because it needs information about the
  surroundings. Gibbs energy removes that problem.

              G  =  H  -  T S          (a state function, extensive)

  At constant T and p, the surroundings receive the heat lost by the
  system, so
              delta S(surroundings)  =  -  delta H / T

              delta S(total)  =  delta S  -  delta H / T

  Multiplying throughout by ( - T ):

              - T delta S(total)  =  delta H  -  T delta S

          +---------------------------------------------------------+
          |        delta G  =  delta H  -  T delta S                |
          |        delta G  =  -  T delta S(total)                  |
          +---------------------------------------------------------+

  Since T is always positive, "delta S(total) positive" is exactly the
  same statement as "delta G negative".

              delta G  <  0   ->  SPONTANEOUS
              delta G  =  0   ->  EQUILIBRIUM
              delta G  >  0   ->  NON-SPONTANEOUS

  delta G also equals the maximum useful (non-expansion) work obtainable.

  --------------------------------------------- THE FOUR CASES  [1 mark]

  +---------+---------+---------------------------+---------------------+
  | delta H | delta S |        delta G            |   SPONTANEOUS ?     |
  +---------+---------+---------------------------+---------------------+
  |    -    |    +    | negative at all T         | YES at ALL temps    |
  |    +    |    -    | positive at all T         | NEVER               |
  |    -    |    -    | negative if T < dH/dS     | YES at LOW temp     |
  |    +    |    +    | negative if T > dH/dS     | YES at HIGH temp    |
  +---------+---------+---------------------------+---------------------+

  The changeover temperature is  T = delta H / delta S.

  ------------------------------- delta G AND EQUILIBRIUM  [1.5 marks]
  For a reaction at equilibrium the free energy change is zero, giving

          +---------------------------------------------------------+
          |   delta G (standard)  =  -  R T ln K                    |
          |                       =  -  2.303 R T log K             |
          +---------------------------------------------------------+

     delta G negative  ->  K > 1  ->  products favoured
     delta G zero      ->  K = 1  ->  at equilibrium
     delta G positive  ->  K < 1  ->  reactants favoured

  EXAMPLE: if delta G(standard) = - 13.6 kJ/mol at 298 K, then
              log K = 13600 / 5705 = 2.384 , so K = 2.42 x 10^2.
```

### Q C5
Define heat capacity, specific heat and molar heat capacity. Derive
Cp - Cv = R. Describe the bomb calorimeter and the coffee-cup calorimeter
and state which thermodynamic quantity each one measures.

**MODEL ANSWER (mark split shown):**

```
  ---------------------------------------------- DEFINITIONS  [2 marks]
  HEAT CAPACITY (C) - the quantity of heat required to raise the
  temperature of the WHOLE sample by 1 K.
              q = C delta T                     unit: J/K   (EXTENSIVE)

  SPECIFIC HEAT (s) - the heat required to raise the temperature of
  1 GRAM of a substance by 1 K.
              q = m s delta T                   unit: J/g/K (INTENSIVE)

              q = n Cm delta T                  unit: J/mol/K (INTENSIVE)

  Cv is the molar heat capacity at constant VOLUME; Cp at constant
  PRESSURE. Cp is always greater than Cv.

  ----------------------------------------------- DERIVATION  [3 marks]
  At constant volume no work is done, so all the heat raises U:
              Cv  =  ( dU / dT ) at constant V

  At constant pressure the heat supplied equals delta H:
              Cp  =  ( dH / dT ) at constant p

  By definition,          H  =  U  +  p V

  For one mole of an ideal gas   p V = R T , so

                          H  =  U  +  R T

  Differentiating with respect to T:

                    dH / dT  =  dU / dT  +  R

          +---------------------------------------------------------+
          |               Cp  -  Cv   =   R                         |
          +---------------------------------------------------------+

  The extra heat R per mole per kelvin is exactly the work the gas must
  do in pushing back the atmosphere as it expands at constant pressure.

  --------------------------------------------- CALORIMETRY  [3 marks]

  (a) BOMB CALORIMETER  ->  measures  delta U  (constant VOLUME)

     +-------------------------------------------+
     |          insulated outer jacket           |
     |   +-----------------------------------+   |
     |   |   water   [thermometer] [stirrer] |   |
     |   |    +-------------------------+    |   |
     |   |    |   STEEL BOMB (rigid)    |    |   |
     |   |    |  sample + excess O2     |    |   |
     |   |    +-------------------------+    |   |
     |   +-----------------------------------+   |
     +-------------------------------------------+

     A weighed sample is sealed in the rigid steel bomb with excess
     oxygen, immersed in a known mass of water inside an insulated
     jacket, and ignited electrically. The temperature rise is measured.

     Because the bomb is RIGID, delta V = 0, therefore w = 0 and

              q(v)  =  delta U  =  -  C(calorimeter) x delta T
                                    (per mole of substance)

     Used for enthalpies (energies) of COMBUSTION.

  (b) COFFEE-CUP CALORIMETER -> measures delta H (constant PRESSURE)

            [thermometer]     [stirrer]
                 |               |
         +-------|---------------|-------+
         |    +--v---------------v--+    |   <- loose lid, so the

     pressure is CONSTANT and

              q(p)  =  delta H  =  -  ( m s delta T ) / moles

     Used for enthalpies of NEUTRALISATION, SOLUTION and DILUTION.
