## THE 60-SECOND VERSION

Thermodynamics answers **two questions only**:

```
  QUESTION 1:  "How much heat / work is involved in this change?"
                       |
                       v
               FIRST LAW  ->  delta U = q + w
                       |
               and its partner    delta H = delta U + delta n(g) R T

  QUESTION 2:  "Will this reaction happen on its own, without me pushing it?"
                       |
                       v
               GIBBS ENERGY  ->  delta G = delta H - T delta S
                       |
               If delta G is NEGATIVE  ->  YES it happens (spontaneous)
               If delta G is POSITIVE  ->  NO it does not
               If delta G is ZERO      ->  it is at EQUILIBRIUM
```

Everything else in the chapter is either a **definition** feeding into these two,
or a **method of measuring** the numbers you put into them.

```
  Energy is CONSERVED     ->  1st law  ->  tells you HOW MUCH
  Energy SPREADS OUT      ->  2nd law  ->  tells you WHICH WAY
  Perfect order = zero S  ->  3rd law  ->  lets you find absolute S
```

## STUDY THIS ORDER

```
  STEP 1   THE VOCABULARY
              system / surroundings / boundary
              open, closed, isolated
              extensive vs intensive
              state function vs path function
              |          (pure memory, but it feeds EVERY later question)
              v
  STEP 2   TYPES OF PROCESS
              isothermal, adiabatic, isobaric, isochoric, cyclic,
              reversible, irreversible
              |          (you must recognise these words instantly)
              v
  STEP 3   *** FIRST LAW ***     delta U = q + w
              + THE SIGN CONVENTION (get this wrong and you lose every mark)
              |
              v
  STEP 4   WORK OF EXPANSION
              irreversible:  w = - p(ext) delta V
              reversible  :  w = - 2.303 n R T log(V2 / V1)
              free expansion: w = 0
              |          <-- 4-mark derivation lives here
              v
  STEP 5   ENTHALPY   H = U + pV
              delta H = delta U + delta n(g) R T
              q(v) = delta U   and   q(p) = delta H
              |
              v
  STEP 6   HEAT CAPACITY  ->  Cp - Cv = R   ->  CALORIMETRY
              |          (bomb = constant volume = delta U
              |           coffee cup = constant pressure = delta H)
              v
  STEP 7   TYPES OF ENTHALPY CHANGE (formation, combustion, ...)
              |          (definitions = free 2-mark questions)
              v
  STEP 8   *** HESS'S LAW ***  + delta H from formation enthalpies
              + delta H from bond enthalpies + Born-Haber cycle
              |
              v
  STEP 9   ENTROPY   delta S = q(rev) / T    ->   SECOND LAW
              |
              v
  STEP 10  *** GIBBS ENERGY ***  delta G = delta H - T delta S
              four sign cases  ->  delta G = -2.303 R T log K
              ->  THIRD LAW
```

## THE BOX THAT UNLOCKS THE WHOLE CHAPTER

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   FIRST  LAW        delta U  =  q  +  w                             |
  |                                                                     |
  |   ENTHALPY          delta H  =  delta U  +  delta n(g) R T          |
  |                                                                     |
  |   GIBBS             delta G  =  delta H  -  T delta S               |
  |                                                                     |
  |   EQUILIBRIUM       delta G(standard)  =  - 2.303 R T log K         |
  |                                                                     |
  +---------------------------------------------------------------------+

     R = 8.314 J / K / mol        (use this when the answer is in joules)
     R = 2 cal / K / mol  (approx 1.987)  (use when the answer is in calories)
     R = 0.0821 L atm / K / mol  (use when p is in atm and V in litres)

     1 L atm  =  101.3 J       0 degC = 273 K       1 cal = 4.184 J
```

**Write that box on your palm.** Four lines. They carry most of the marks.

## THE SIGN CONVENTION — THE SINGLE BIGGEST MARK-LOSER

Learn it as "**what the SYSTEM gains is POSITIVE**".

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |                        S U R R O U N D I N G S                     |
  |                                                                    |
  |          q = +ve                              w = +ve              |
  |        (heat GOES IN)                    (work done ON it,         |
  |              |                            gas COMPRESSED)          |
  |              v                                  |                  |
  |         +---------------------------------------v-------+          |
  |         |                                               |          |
  |         |              T H E   S Y S T E M              |          |
  |         |                                               |          |
  |         +---------|-------------------------|-----------+          |
  |                   |                         |                      |
  |                   v                         v                      |
  |             q = -ve                    w = -ve                     |
  |         (heat GOES OUT)          (work done BY it,                 |
  |                                   gas EXPANDS)                     |
  |                                                                    |
  +--------------------------------------------------------------------+

  ONE-LINE MEMORY:
       "IN is PLUS, OUT is MINUS."
       EXPANSION always gives NEGATIVE work (that is why w = -p dV).
```

## THE FOUR SPONTANEITY CASES (learn this table cold)

```
  +---------+---------+------------------+------------------------------+
  | delta H | delta S |     delta G      |   SPONTANEOUS ?              |
  +---------+---------+------------------+------------------------------+
  |    -    |    +    |  always -ve      |  YES, at ALL temperatures    |
  |    +    |    -    |  always +ve      |  NEVER, at any temperature   |
  |    -    |    -    |  -ve if T small  |  YES at LOW temperature      |
  |    +    |    +    |  -ve if T large  |  YES at HIGH temperature     |
  +---------+---------+------------------+------------------------------+

  Row 1 is the dream case. Row 2 is impossible. Rows 3 and 4 depend on T,
  and the switch-over temperature is        T  =  delta H / delta S
```

## THE FIVE SENTENCES YOU MUST BE ABLE TO WRITE FROM MEMORY

```
  1. FIRST LAW    - "Energy can neither be created nor destroyed, it can
                     only be converted from one form to another. The total
                     energy of an isolated system remains constant."

  2. HESS'S LAW   - "The total enthalpy change of a reaction is the same
                     whether it takes place in one step or in several
                     steps."

  3. SECOND LAW   - "The entropy of the universe increases in every
                     spontaneous process."   (dS(total) > 0)

  4. THIRD LAW    - "The entropy of a perfectly crystalline substance is
                     zero at absolute zero temperature (0 K)."

  5. SPONTANEITY  - "A process is spontaneous when delta G is negative."
```
