### Q21

> ```

### Q28
The number of UNPAIRED electrons in Fe2+ (Z = 26) is

(a) 2 &nbsp; (b) 4 &nbsp; (c) 5 &nbsp; (d) 6

**ANSWER: (b)**
```
  Fe    ->  [Ar] 3d6 4s2

  Fe2+  ->  remove the 4s electrons FIRST  ->  [Ar] 3d6

     +----+ +---+ +---+ +---+ +---+

```

> remove the **4s** electrons BEFORE the 3d electrons — even though 4s
> was filled first.

# PATTERN 10 — Isotope / isobar / isotone / isoelectronic identification

> This pattern is pure definition-matching. Do it in ten seconds by
> calculating Z, A and the neutron count for each option.

### Q30
Which of the following pairs are ISOBARS?

(a) C-12 and C-13 &nbsp; (b) Ar-40 and Ca-40 &nbsp; (c) Na-23 and Mg-24 &nbsp; (d) H-1 and H-2

**ANSWER: (b)**
```
  ISOBARS = same MASS NUMBER A , different Z.

  Ar-40  ->  Z = 18 , A = 40
  Ca-40  ->  Z = 20 , A = 40      same A , different Z    ISOBARS

  (a) and (d) are isotopes ;  (c) are isotones.
```

---

### Q31
Which of the following pairs are ISOTONES?

(a) Na-23 and Mg-24 &nbsp; (b) Cl-35 and Cl-37 &nbsp; (c) Ar-40 and K-40 &nbsp; (d) Ne and Na+

**ANSWER: (a)**
```
  ISOTONES = same number of NEUTRONS.

  Na-23 :  23 - 11  =  12 neutrons
  Mg-24 :  24 - 12  =  12 neutrons        SAME    ->  ISOTONES
```

---

### Q32
Which of the following is NOT isoelectronic with neon?

(a) Na+ &nbsp; (b) O2- &nbsp; (c) Al3+ &nbsp; (d) Cl-

**ANSWER: (d)**
```
  Ne   = 10 electrons
  Na+  = 11 - 1  = 10        O2- =  8 + 2 = 10
  Al3+ = 13 - 3  = 10        Cl- = 17 + 1 = 18     <-- the odd one out

  Cl- is isoelectronic with ARGON, not neon.
```
> **SHORTCUT:** for an ion, electrons `= Z - charge`. A minus charge ADDS.

# PATTERN 11 — Photoelectric GRAPHS

> Almost every year one question is a graph rather than a calculation.
> There are only three graphs, so learn their slopes and intercepts.

### Q35
In the graph of maximum kinetic energy against frequency of incident light,
the SLOPE of the straight line is equal to

(a) the work function &nbsp; (b) Planck's constant &nbsp; (c) the threshold frequency &nbsp; (d) `h / e`

**ANSWER: (b)**
```
   KE  =  h nu  -  W0

   Compare with  y = m x + c :
        y = KE ,  x = nu ,  slope m = h ,  intercept c = -W0

   The slope is the SAME for every metal - that is how Planck's
   constant was first measured experimentally.
```

---

### Q36
In the same graph, the intercept on the FREQUENCY axis gives

(a) `h` &nbsp; (b) the work function &nbsp; (c) the threshold frequency &nbsp; (d) zero

**ANSWER: (c)** — where the line crosses the frequency axis, `KE = 0`,
so `h nu = W0`, i.e. `nu = nu(0)`.

---

### Q37
The graph of maximum kinetic energy of photoelectrons against the INTENSITY
of the incident light (frequency kept constant) is

(a) a straight line through the origin &nbsp; (b) a horizontal straight line
(c) a parabola &nbsp; (d) a straight line with negative slope

**ANSWER: (b)**
```
     KE ^
        |------------------------------   FLAT
        +------------------------------>  intensity

  Intensity changes only the NUMBER of electrons, never their energy.
```

---

### Q38
Two metals A and B are studied. Their KE-versus-frequency graphs are parallel
straight lines that cut the frequency axis at different points. This shows
that they have

(a) different values of h &nbsp; (b) the same work function
(c) different work functions but the same value of h &nbsp; (d) no photoelectric effect

**ANSWER: (c)** — parallel means the same slope `h` (a universal constant);
different intercepts mean different threshold frequencies and therefore
different work functions.

---

### Q39
The slope of a graph of stopping potential `V0` against frequency `nu` is

(a) `h` &nbsp; (b) `h / e` &nbsp; (c) `e / h` &nbsp; (d) `W0 / e`

**ANSWER: (b)**
```
   e V0  =  h nu  -  W0

                h            W0

# PATTERN 12 — ORBITAL angular momentum (not the same as Bohr's)

> **THE TRAP THAT CATCHES EVERYONE.** There are TWO different angular
> momenta in this chapter and they use different formulas:
> ```
>    BOHR'S angular momentum of the ORBIT   =   n h / 2 pi     (uses n)
>
>    ORBITAL angular momentum of an ORBITAL =   sqrt( l (l+1) ) x h/2pi
>                                                                (uses l)
> ```

### Q40
The orbital angular momentum of an electron in a 3s orbital is

(a) `h / 2pi` &nbsp; (b) `sqrt(2) h / 2pi` &nbsp; (c) zero &nbsp; (d) `3h / 2pi`

**ANSWER: (c)**
```
  For any s orbital,  l = 0 , so

     sqrt( l ( l + 1 ) )  =  sqrt( 0 x 1 )  =  0

  An s electron has ZERO orbital angular momentum. This is true for
  1s, 2s, 3s, 4s - all of them.
```

---

### Q41
The orbital angular momentum of a 3d electron is

(a) `sqrt(2) h/2pi` &nbsp; (b) `sqrt(6) h/2pi` &nbsp; (c) `sqrt(12) h/2pi` &nbsp; (d) `3 h/2pi`

**ANSWER: (b)**
```
  3d  ->  l = 2

     sqrt( l ( l + 1 ) )  =  sqrt( 2 x 3 )  =  sqrt 6

  So the orbital angular momentum is  sqrt(6) x h / 2 pi .
```

---

### Q42
The orbital angular momentum of a 2p electron is

**ANSWER:**
```
  2p  ->  l = 1

     sqrt( 1 x 2 )  x  h/2pi   =   sqrt(2)  h / 2 pi
```
> **NOTICE:** the answer depends only on the LETTER (s, p, d, f), never on
> the number in front. A 2p and a 4p electron have the SAME orbital
> angular momentum.

---

### Q43
The angular momentum of an electron in the 3rd Bohr ORBIT is

(a) `sqrt(6) h/2pi` &nbsp; (b) `3h / 2pi` &nbsp; (c) `sqrt(12) h/2pi` &nbsp; (d) `h/2pi`

**ANSWER: (b)**
```
  The question says ORBIT , so use Bohr's rule:   m v r = n h / 2 pi

     n = 3   ->   3 h / 2 pi   =   3 x 1.0546x10^-34
                              =   3.16 x 10^-34  kg m^2/s
```
> **READ THE WORD:** "orbit" -> use n. "orbital" -> use l.

# PATTERN 13 — Comparing DIFFERENT hydrogen-like species

> Everything here comes from three proportionalities. Write them at the
> top of the rough sheet before you start:
> ```
>      r  is proportional to   n^2 / Z
>      E  is proportional to  - Z^2 / n^2
>      v  is proportional to    Z / n
> ```

### Q44
Which of these has the SAME orbit radius as the first orbit of hydrogen?

(a) He+ , n = 2 &nbsp; (b) Li2+ , n = 3 &nbsp; (c) Be3+ , n = 2 &nbsp; (d) He+ , n = 1

**ANSWER: (c)**
```
  Compare the value of  n^2 / Z  for each:

     H    n=1 , Z=1  ->  1 / 1  =  1
  (a) He+ n=2 , Z=2  ->  4 / 2  =  2
  (b) Li2+n=3 , Z=3  ->  9 / 3  =  3
  (c) Be3+n=2 , Z=4  ->  4 / 4  =  1        <-- MATCHES
  (d) He+ n=1 , Z=2  ->  1 / 2  =  0.5
```

### Q45
The energy of the electron in the 2nd orbit of He+ is equal to the energy of
the electron in which orbit of hydrogen?

(a) n = 1 &nbsp; (b) n = 2 &nbsp; (c) n = 3 &nbsp; (d) n = 4

**ANSWER: (a)**
```
   He+ , n = 2  :   E = -13.6 x 4 / 4  =  -13.6 eV
   H   , n = 1  :   E = -13.6 x 1 / 1  =  -13.6 eV        EQUAL

   GENERAL RULE:  the energies match whenever  Z^2 / n^2  is the same,
   that is whenever n / Z is the same.
```

# PATTERN 14 — QUANTUM-NUMBER VALIDITY AND COUNTING

> Run the same four-line checklist every single time:
> ```
>    n  a positive whole number, never 0
>    l  from 0 to (n - 1)
>    m  from -l to +l
>    s  exactly +1/2 or -1/2
> ```

### Q50
Which set of quantum numbers is NOT permitted?

(a) n=4, l=3, m=-3, s=+1/2 &nbsp; (b) n=3, l=2, m=-3, s=-1/2
(c) n=2, l=1, m=0, s=+1/2 &nbsp; (d) n=5, l=0, m=0, s=-1/2

**ANSWER: (b)** — with `l = 2`, m can only be `-2, -1, 0, +1, +2`.
`m = -3` is out of range.

---

### Q51
Which of the following orbitals does NOT exist?

(a) 2p &nbsp; (b) 3f &nbsp; (c) 4d &nbsp; (d) 5s

**ANSWER: (b)**
```
  For an f orbital,  l = 3 , which needs  n  to be at least 4.
  So 4f exists but 3f does not.

  The same rule kills 1p (needs n >= 2) and 2d (needs n >= 3).
```

---

### Q52
The maximum number of electrons that can have `n = 4` and `l = 1` is

(a) 2 &nbsp; (b) 6 &nbsp; (c) 10 &nbsp; (d) 14

**ANSWER: (b)** — that is the 4p subshell: `2(2l + 1) = 2(3) = 6`.

---

### Q53
The maximum number of electrons in an atom that can have `n = 3` and `m = +1` is

(a) 2 &nbsp; (b) 4 &nbsp; (c) 6 &nbsp; (d) 10

**ANSWER: (b)**
```
  Which orbitals in the third shell can have m = +1 ?

      3s  ( l = 0 )  ->  m = 0 only         NO
      3p  ( l = 1 )  ->  m = -1, 0, +1      YES - one orbital
      3d  ( l = 2 )  ->  m = -2..+2         YES - one orbital

  Two orbitals qualify, and each holds 2 electrons   ->   4
```

---

### Q54
The total number of electrons in an atom for which `n + l = 3` is

(a) 6 &nbsp; (b) 8 &nbsp; (c) 10 &nbsp; (d) 18

**ANSWER: (b)**
```
  List every (n , l) pair that adds to 3:

      n = 2 , l = 1   ->   2p   ->   6 electrons
      n = 3 , l = 0   ->   3s   ->   2 electrons
      (n = 1 , l = 2 is impossible, since l must be < n)

  TOTAL  =  6 + 2  =  8
```

---

### Q55
The number of electrons in an atom having `n = 3` and `s = -1/2` is

(a) 9 &nbsp; (b) 18 &nbsp; (c) 6 &nbsp; (d) 3

**ANSWER: (a)**
```
  The third shell has  n^2 = 9  orbitals. Each orbital holds exactly ONE
  electron with s = -1/2 , so the answer is 9.
```

# PATTERN 15 — Node and orbital-shape speed questions

### Q56
An orbital has 1 radial node and 2 angular nodes. It is

(a) 3d &nbsp; (b) 4d &nbsp; (c) 4p &nbsp; (d) 5f

**ANSWER: (b)**
```
  angular nodes = l = 2   ->   it is a d orbital
  radial nodes  = n - l - 1 = 1
        n - 2 - 1 = 1   ->   n = 4

  So it is 4d .   CHECK: total = 1 + 2 = 3 = n - 1 = 3   OK
```

---

### Q57
The number of NODAL PLANES in a `dxy` orbital is

(a) 0 &nbsp; (b) 1 &nbsp; (c) 2 &nbsp; (d) 3

**ANSWER: (c)** — nodal planes `= l`, and for a d orbital `l = 2`.
For dxy they are the xz and yz planes.

---

### Q58
Which of the following orbitals has the greatest TOTAL number of nodes?

(a) 3d &nbsp; (b) 4s &nbsp; (c) 3p &nbsp; (d) 2p

**ANSWER: (b)**
```
  Total nodes = n - 1 , and nothing else matters.
