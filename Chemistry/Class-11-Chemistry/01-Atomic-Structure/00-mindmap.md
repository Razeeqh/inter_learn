## THE 60-SECOND VERSION

This chapter tells the story of **how scientists figured out what is inside an atom**.
It moves in four steps, and each step fixes the problem in the step before it.

```
  STEP 1   Thomson    -  atom is a "plum pudding"
              |           PROBLEM: could not explain the gold foil experiment
              v
  STEP 2   Rutherford -  tiny dense nucleus, electrons around it
              |           PROBLEM: electrons should spiral in and the atom
              |                    should collapse
              v
  STEP 3   Bohr       -  electrons live in FIXED orbits with FIXED energy
              |           PROBLEM: only works for hydrogen-like atoms
              v
  STEP 4   Quantum    -  electrons live in ORBITALS (probability clouds)
           model         WORKS for everything
```

**If you understand only that ladder, you already have half the theory marks.**

## THE TWO NUMBERS THAT UNLOCK EVERYTHING

For a hydrogen-like atom (one electron only: H, He+, Li2+, Be3+):

```
  +---------------------------------------------------------------+
  |                                                               |
  |                         0.529  n^2                            |
  |     RADIUS      r(n)  = ------------  angstrom                |
  |                              Z                                |
  |                                                               |
  |                                                               |
  |                         - 13.6  Z^2                           |
  |     ENERGY      E(n)  = ------------  electron volt           |
  |                              n^2                              |
  |                                                               |
  +---------------------------------------------------------------+

  n = shell number (1, 2, 3, ...)        Z = atomic number
```

Almost every numerical in this chapter comes from these two boxes.
**Write them on your palm.**
