```
  +--------+------------+-----+---------------------------+-------------+
```

| PROPERTY | B | Al | Ga | In | Tl |
|---|---|---|---|---|---|
| Atomic number Z | 5 | 13 | 31 | 49 | 81 |
| Atomic (metallic) radius / pm | 85 | **143** | **135** | 167 | 170 |
| Ionic radius M3+ / pm | 27 | 53.5 | 62 | 80 | 88.5 |
| Ionic radius M+ / pm | — | — | — | — | 140 |
| IE1 / kJ mol-1 | 801 | **577** | **579** | **558** | **589** |
| IE2 / kJ mol-1 | 2427 | 1816 | 1979 | 1820 | 1971 |
| IE3 / kJ mol-1 | 3659 | 2744 | 2962 | 2704 | 2877 |
| Electronegativity | 2.0 | **1.5** | 1.6 | 1.7 | 1.8 |
| Melting point / K | 2453 | 933 | **303** | 430 | 576 |
| Boiling point / K | 3923 | 2740 | **2676** | 2353 | 1730 |
| Density / g cm-3 | 2.35 | 2.70 | 5.90 | 7.31 | 11.85 |

```
  THE FOUR ANOMALIES IN THIS TABLE - memorise them, they are 2-markers

     1.  Ga (135 pm) is SMALLER than Al (143 pm).
             REASON: the ten 3d electrons of Ga shield the nuclear
             charge POORLY (d-block contraction), so the outer
             electrons are pulled in.

     2.  IE1 does not fall smoothly:  B > Tl > Ga > Al > In
                                     801  589  579  577  558
             REASON: poor shielding by 3d10 (Ga) and by 4f14 + 5d10 (Tl).

     3.  m.p. of Ga is only 303 K - it MELTS IN THE HAND - yet its
         b.p. is 2676 K, the WIDEST LIQUID RANGE of any element.
             REASON: solid Ga is made of Ga2 DIATOMIC MOLECULES held
             by weak forces. Melting breaks only the weak forces;
             boiling must break the strong Ga-Ga covalent bond.
             USE: high-temperature thermometers.

     4.  Electronegativity DIPS at Al (2.0 -> 1.5) and then RISES
         again (1.6 -> 1.7 -> 1.8).
             REASON: B is tiny so it pulls hard; after Al the poor
             shielding by d and f electrons raises Zeff again.
```

```
  SUM OF THE FIRST THREE IONISATION ENTHALPIES OF BORON

        801 + 2427 + 3659  =  6887 kJ mol-1

        Far too large ever to be repaid by lattice or hydration energy.

        *** THEREFORE B3+ NEVER EXISTS AND ALL BORON COMPOUNDS ARE
            COVALENT. ***
```

# 3. TRENDS — the direction AND the reason

| PROPERTY | DIRECTION DOWN THE GROUP | REASON |
|---|---|---|
| Atomic / metallic radius | **INCREASES, but IRREGULARLY** (Ga < Al) | A new shell each period; but 3d10 shields poorly, so Ga contracts |
| Ionic radius M3+ | INCREASES | Same reason |
| Ionisation enthalpy | **DECREASES, but NOT smoothly** (Al < Ga, In < Tl) | Bigger atom and better shielding; spoiled by poor d and f shielding |
| Electronegativity | **DECREASES B to Al, then INCREASES** | B is very small; then poor d/f shielding raises Zeff again |
| Melting point | **DECREASES B to Ga, then INCREASES** | Giant covalent B, then metals; Ga is anomalously low (Ga2 molecules) |
| Boiling point | DECREASES | Metallic bonding gets weaker as atoms grow |
| Density | **INCREASES** | Atomic mass rises faster than atomic volume |
| Metallic character | **INCREASES** | IE falls, so electrons are lost more easily |
| Stability of +3 state | **DECREASES** | Inert pair effect |
| Stability of +1 state | **INCREASES** | Inert pair effect |
| Oxidising power of M(III) | **INCREASES** | +3 becomes unstable at the bottom, so it grabs electrons |
| Basic character of the oxide M2O3 | INCREASES (acidic -> amphoteric -> basic) | Metallic character rises |
| Ionic character of the halides MX3 | INCREASES | Electropositive character rises |
| Reducing power of the element | INCREASES down to Al, then falls | Al is the strong reducing agent (thermite) |

```
  COMPARISON WITH GROUP 2 (worth a mark in a general question)

      IE1 of group 13  <  IE1 of the group 2 element of the same period.
          Be 899 > B 801        Mg 737 > Al 577

      REASON: in group 13 the electron removed comes from a p orbital,
      which is higher in energy and better shielded, whereas group 2
      must break into a stable, completely filled ns2 sub-shell.


  COMPARISON WITH GROUP 14 (the companion chapter)

      Group 13 atoms are BIGGER than group 14 atoms of the same period,
      and their ionisation enthalpies are LOWER.
      REASON: lower nuclear charge across the period.
```

# 4. OXIDATION STATES AND THE INERT PAIR EFFECT

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   INERT PAIR EFFECT                                                  |
  |                                                                      |
  |   DEFINITION : the reluctance of the ns2 electron pair to take part  |
  |                in bond formation, which increases down a p-block     |
  |                group, making the LOWER oxidation state more stable.  |
  |                                                                      |
  |   CAUSE      : filled d (3d10, 4d10, 5d10) and f (4f14) subshells    |
  |                shield the nuclear charge POORLY, so the ns2 pair is  |
  |                held very tightly and is not available for bonding.   |
  |                Promoting an ns electron to np costs more energy      |
  |                than the two extra (long, weak) bonds give back.      |
  |                                                                      |
  |   IN GROUP 13 : the +1 state becomes more and more stable            |
  |                 the +3 state becomes less and less stable            |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| ELEMENT | STABLE STATE | OTHER STATE | BEHAVIOUR |
|---|---|---|---|
| B | **+3 only** | — | Never +1. Only covalent compounds, no B3+ ion |
| Al | **+3** | +1 (only at high temperature) | Normal trivalent metal |
| Ga | +3 | +1 | Ga(I) **disproportionates**: `3 Ga+ -> 2 Ga + Ga3+` |
| In | +3 | +1 | In(I) exists and is a **reducing agent** |
| Tl | **+1** | +3 | Tl(III) is a strong **oxidising agent** |

```
  STABILITY ORDERS TO MEMORISE

      +1 STATE :        Al  <  Ga  <  In  <  Tl        (rises down)
      +3 STATE :        Al  >  Ga  >  In  >  Tl        (falls down)
      OXIDISING POWER OF M3+ :   Al3+ < Ga3+ < In3+ << Tl3+

  THE FOUR PROOFS

      1.  TlCl3  --(heat)-->  TlCl  +  Cl2       Tl(III) falls to Tl(I)
          Tl2O3  --(heat)-->  Tl2O  +  O2

      2.  TlI3 is NOT thallium(III) iodide - it is Tl+ (I3)- ,
          thallium(I) TRI-IODIDE, because Tl3+ would instantly oxidise
          I- to I2.

      3.  3 Ga+  -->  2 Ga  +  Ga3+              disproportionation

      4.  TlOH is a STRONG base, comparable with NaOH.
```

# 5. NATURE OF THE OXIDES AND HYDROXIDES

| COMPOUND | NATURE | KEY EQUATION |
|---|---|---|
| `B2O3` | **ACIDIC** | `B2O3 + 6 NaOH -> 2 Na3BO3 + 3 H2O` |
| `Al2O3` | **AMPHOTERIC** | acid and base — see section 8 |
| `Ga2O3` | AMPHOTERIC | |
| `In2O3` | BASIC | |
| `Tl2O3` | BASIC (and an oxidiser) | `Tl2O3 --(heat)--> Tl2O + O2` |
| `Tl2O` | **STRONGLY BASIC** | dissolves in water giving TlOH |
| `B(OH)3` | **ACIDIC** (it IS boric acid) | `B(OH)3 + 2 H2O -> [B(OH)4]- + H3O+` |
| `Al(OH)3` | **AMPHOTERIC** | `Al(OH)3 + NaOH -> Na[Al(OH)4]` |
| `TlOH` | STRONG BASE, like NaOH | |

```
      ACIDIC  --------------------------------------------->  BASIC
      B2O3      Al2O3      Ga2O3      In2O3      Tl2O3 / Tl2O

      REASON: metallic character INCREASES down the group.
              A non-metal oxide is acidic, a metal oxide is basic,
              and the ones in between are amphoteric.
```

# 6. REACTIVITY TOWARDS AIR (OXYGEN AND NITROGEN)

| REACTION | EQUATION | NOTES |
|---|---|---|
| With dioxygen (general) | `2 E + 3/2 O2 --(heat)--> E2O3` | E = B, Al, Ga, In, Tl |
| Boron burns | `2 B + 3/2 O2 --(heat)--> B2O3` | Amorphous B burns; crystalline B is nearly inert |
| Aluminium burns | `4 Al + 3 O2 --(heat)--> 2 Al2O3` | Very exothermic |
| With dinitrogen | `2 B + N2 --(high temp)--> 2 BN` | **BN = boron nitride, "inorganic graphite"** |
| | `2 Al + N2 --(high temp)--> 2 AlN` | |
| Aluminium + steam | `2 Al + 3 H2O --(steam)--> Al2O3 + 3 H2` | Boron does not react with water |

```
  WHY DOES AN ALUMINIUM VESSEL NOT CORRODE AWAY?

      Aluminium instantly forms a THIN, HARD, CONTINUOUS, IMPERVIOUS
      layer of Al2O3 that clings to the surface and seals the metal
      off from further attack. The metal is said to be PASSIVE.

      Thickening that layer deliberately by electrolysis = ANODISING.

  BORON NITRIDE, BN
      *  Isoelectronic and isostructural with GRAPHITE - flat sheets
         of alternating B and N atoms; a white slippery solid, used
         as a HIGH-TEMPERATURE LUBRICANT.
      *  Its cubic form, BORAZON, is one of the HARDEST substances
         known - used as an abrasive.
      *  Hydrolysed by water:  BN + 3 H2O -> H3BO3 + NH3
```

|---|---|---|


# 9. REACTIVITY TOWARDS HALOGENS — THE TRIHALIDES

| FACT | DETAIL |
|---|---|
| General reaction | `2 E + 3 X2 --> 2 EX3` |
| Boron | `2 B + 3 Cl2 --> 2 BCl3` (monomeric, planar) |
| Aluminium | `2 Al + 3 Cl2 --> Al2Cl6` (**dimer**) |
| Shape of `BX3` | **sp2, TRIGONAL PLANAR, 120 degrees, NON-POLAR** |
| Electron count on B | only **SIX** — a **SEXTET**, one empty 2p orbital |
| Therefore | `BX3` is **ELECTRON DEFICIENT** and a **LEWIS ACID** |
| Max covalency of B | **FOUR** — `[BF4]-` exists, `[BF6]3-` NEVER does |
| Max covalency of Al | **SIX** — `[AlF6]3-`, `[Al(H2O)6]3+` (Al has vacant 3d) |
| The exception to quote | **`TlI3` is NOT Tl(III) iodide — it is `Tl+ (I3)-`** |
| `AlF3` | **IONIC**, high melting, does **NOT** dimerise (F is too small) |
| `AlCl3`, `AlBr3`, `AlI3` | Covalent, **DIMERIC** `Al2X6` |

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   *** THE LEWIS ACID ORDER - THE MOST ASKED QUESTION ***             |
  |                                                                      |
  |            BF3   <   BCl3   <   BBr3   <   BI3                       |
  |                                                                      |
  |                LEWIS ACID STRENGTH INCREASES                         |
  |                                                                      |
  |   REASON:  p(pi) - p(pi)  BACK BONDING.                              |
  |                                                                      |
  |   A FILLED p orbital of the halogen donates its lone pair sideways   |
  |   into the EMPTY 2p orbital of boron. This partly fills the empty    |
  |   orbital and REDUCES boron's electron deficiency.                   |
  |                                                                      |
  |   Effective sideways overlap needs orbitals of SIMILAR SIZE:         |
  |                                                                      |
  |       BF3   F uses 2p  - SAME SIZE as B's 2p - BEST overlap          |
  |                        - STRONGEST back bonding - WEAKEST acid       |
  |       BCl3  Cl uses 3p - poorer                                      |
  |       BBr3  Br uses 4p - poorer still                                |
  |       BI3   I uses 5p  - far too big - almost NO back bonding        |
  |                        - boron stays fully deficient                 |
  |                        - STRONGEST acid                              |
  |                                                                      |
  |   EVIDENCE: the B-F bond in BF3 is only 130 pm, SHORTER than a       |
  |   normal single bond, because of the partial double-bond character   |
  |   produced by back bonding.                                          |
  |                                                                      |
  |   *** DO NOT ANSWER "F is most electronegative so BF3 is the         |
  |       strongest acid". That is the trap. ***                         |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| LEWIS ACID REACTION | EQUATION | PRODUCT |
|---|---|---|
| With ammonia | `BF3 + NH3 -> F3B <- NH3` | Adduct, boron becomes sp3 tetrahedral |
| With fluoride ion | `BF3 + F- -> [BF4]-` | Tetrahedral, sp3 |
| With amine | `BF3 + NMe3 -> F3B <- NMe3` | Adduct |
| Hydrolysis of BCl3 | `BCl3 + 3 H2O -> H3BO3 + 3 HCl` | **COMPLETE** hydrolysis |
| Hydrolysis of BF3 | `4 BF3 + 3 H2O -> 3 H3O+ + 3 [BF4]- + B(OH)3` | Only **PARTIAL** (strong B-F bond) |
| Hydrolysis of AlCl3 | `AlCl3 + 3 H2O -> Al(OH)3 + 3 HCl` | Solution turns litmus red |

# 10. THE ANOMALOUS BEHAVIOUR OF BORON

```
  THE FIVE REASONS (the CAUSE - write these first)

     1.  VERY SMALL SIZE                   85 pm (Al = 143 pm)
     2.  VERY HIGH IONISATION ENTHALPY     801 ; sum of 3 = 6887 kJ/mol
     3.  HIGH ELECTRONEGATIVITY            2.0 (Al = 1.5)
     4.  ONLY FOUR ORBITALS AVAILABLE      2s + 2px + 2py + 2pz
                                           -> MAX COVALENCY = 4
     5.  NO d ORBITALS in the valence shell -> cannot expand its octet
```

| # | BORON | Al, Ga, In, Tl |
|---|---|---|
| 1 | **NON-METAL**; hard, black, high melting, semiconductor | **METALS**; soft, shiny, conductors |
| 2 | **Only COVALENT** compounds; B3+ never exists | Ionic compounds; M3+ ions exist |
| 3 | Maximum covalency **4** — `[BF4]-` | Covalency **6** — `[AlF6]3-` |
| 4 | Trihalides are **monomeric, planar** `BX3` | `AlCl3` is a **dimer**, `Al2Cl6` |
| 5 | `B(OH)3` is **ACIDIC** | `Al(OH)3` amphoteric, `TlOH` strongly basic |
| 6 | `B2O3` is an **ACIDIC** oxide | `Al2O3` amphoteric, `Tl2O3` basic |
| 7 | Forms many stable **electron-deficient BORANES** | Their hydrides are unstable and ill-defined |
| 8 | Halides **completely hydrolysed** | `AlCl3` only partially hydrolysed |
| 9 | Shows **only +3** | Show +3 **and +1**; Tl prefers +1 |
| 10 | Does not react with acids or alkalis under mild conditions | Al reacts with **both** (amphoteric) |
| 11 | Has **allotropes** (crystalline and amorphous) | No such allotropy in the syllabus |

# 11. THE DIAGONAL RELATIONSHIP: BORON AND SILICON

```
       Li ---> Be ---> B ---> C
        \       \       \
       Na ---> Mg ---> Al ---> Si

       THE THREE PAIRS :    Li-Mg    Be-Al    B-Si

       WHY? Across a period size falls and EN rises; down a group size
       rises and EN falls. Along a diagonal the two effects CANCEL, so
       the pair have almost the same SIZE, ELECTRONEGATIVITY and
       CHARGE-TO-RADIUS RATIO.

             B   85 pm   EN 2.0
             Si  118 pm  EN 1.8
```

| # | SIMILARITY | EQUATIONS / EXAMPLES |
|---|---|---|
| 1 | Both are non-metallic **SEMICONDUCTORS**, hard and high melting | B non-metal, Si metalloid |
| 2 | Both form **only COVALENT** compounds | B3+ and Si4+ never exist |
| 3 | Both form volatile, **spontaneously flammable hydrides** that are hydrolysed | BORANES `B2H6` and SILANES `SiH4` |
| 4 | Both hydrides hydrolysed by water | `B2H6 + 6H2O -> 2H3BO3 + 6H2`; `SiH4 + 4H2O -> Si(OH)4 + 4H2` |
| 5 | Both halides **completely hydrolysed** | `BCl3 + 3H2O -> H3BO3 + 3HCl`; `SiCl4 + 4H2O -> Si(OH)4 + 4HCl` |
| 6 | Both oxides are **ACIDIC** and dissolve in alkali; both form glasses | `B2O3 + 6NaOH -> 2Na3BO3 + 3H2O`; `SiO2 + 2NaOH -> Na2SiO3 + H2O` |
| 7 | Both form **polymeric** ring, chain and sheet structures | BORATES and SILICATES |
| 8 | Both form hard, refractory binary compounds with metals | **BORIDES** and **SILICIDES** |
| 9 | Both carbides are extremely hard abrasives | `B4C` and `SiC` (carborundum) |
| 10 | Both acids are **very weak** | boric acid and silicic acid |

# 12. BORAX, `Na2B4O7.10H2O`

| FACT | DETAIL |
|---|---|
| Names | Sodium tetraborate decahydrate; native form = **TINCAL** |
| Simple formula | `Na2B4O7 . 10 H2O` |
| **Real formula** | **`Na2[B4O5(OH)4] . 8 H2O`** — 4 of the 10 "waters" are `-OH` on boron |
| Anion | `[B4O5(OH)4]2-` — **two sp2 BO3 triangles + two sp3 BO4 tetrahedra** |
| Charge | The 2- charge sits on the two **tetrahedral** borons |
| Appearance | White crystalline solid; sparingly soluble in cold water, freely in hot |
| Solution | **ALKALINE** (salt of strong base + weak acid) — used as a buffer |

```
                    STRUCTURE OF  [B4O5(OH)4]2-
                                                                    2-
                              O H
                               |
                               B                 <--  sp2, TRIGONAL
                             /   \                    PLANAR (BO3)
                            /     \
                           O       O
                          /         \
              H O ---- B             B ---- O H  <--  sp3, TETRAHEDRAL
                          \         /                 (BO4), carries
                           \       /                  the 2- charge
                            O     O
                             \   /
                               B                 <--  sp2, TRIGONAL
                               |                      PLANAR (BO3)
                              O H

              PLUS one CENTRAL BRIDGING OXYGEN joining the two
              tetrahedral borons:     B(sp3) --- O --- B(sp3)
```

| REACTION | EQUATION |
|---|---|
| **Preparation from colemanite** | `Ca2B6O11 + 2 Na2CO3 -> 2 CaCO3 + Na2B4O7 + 2 NaBO2` |
| then recover the metaborate | `4 NaBO2 + CO2 -> Na2B4O7 + Na2CO3` |
| Preparation from boric acid | `4 H3BO3 + Na2CO3 -> Na2B4O7 + CO2 + 6 H2O` |
| **Hydrolysis (why it is alkaline)** | `Na2B4O7 + 7 H2O -> 2 NaOH + 4 H3BO3` |
| **With acid — makes boric acid** | `Na2B4O7 + 2 HCl + 5 H2O -> 2 NaCl + 4 H3BO3` |
| with sulphuric acid | `Na2B4O7 + H2SO4 + 5 H2O -> Na2SO4 + 4 H3BO3` |

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   *** ACTION OF HEAT ON BORAX - THREE STAGES ***                     |
  |                                                                      |
  |   1.  Na2B4O7 . 10 H2O  --(heat, ~373 K)-->  Na2B4O7  +  10 H2O      |
  |       It SWELLS into a light, white, PUFFY, POROUS mass.             |
  |                                                                      |
  |   2.  The puffy mass MELTS to a clear liquid.                        |
  |                                                                      |
  |   3.  Na2B4O7   --(red heat, ~1000 K)-->   2 NaBO2   +   B2O3        |
  |                                          sodium       boric          |
  |                                          metaborate   anhydride      |
  |                                                                      |
  |       On cooling this melt sets to a TRANSPARENT GLASSY BEAD.        |
  |       *** THE BEAD = NaBO2 + B2O3 ***                                |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## THE BORAX BEAD TEST

```
  THE METHOD (five steps)
    1.  Make a loop at the end of a clean PLATINUM wire (inert, no
        colour of its own, very high melting point).
    2.  Heat it red hot, dip in borax powder, heat until a clear
        TRANSPARENT GLASSY BEAD of NaBO2 + B2O3 forms.
    3.  Touch the hot bead to a trace of the metal salt.
    4.  Heat in the OXIDISING flame (outer, blue, non-luminous) -
        note the colour hot and cold.
    5.  Heat in the REDUCING flame (inner, luminous) - note again.

  THE CHEMISTRY
        B2O3   +   CuO   --(heat)-->   Cu(BO2)2      blue-green
        B2O3   +   CoO   --(heat)-->   Co(BO2)2      deep blue
        CuSO4  +   B2O3  --(heat)-->   Cu(BO2)2  +  SO3

  THE PRINCIPLE IN ONE SENTENCE:
        BORIC ANHYDRIDE IN THE BEAD REACTS WITH THE METAL OXIDE TO
        GIVE A COLOURED METAL METABORATE M(BO2)n, AND THE COLOUR
        IDENTIFIES THE METAL.
```

| METAL ION | OXIDISING FLAME | REDUCING FLAME |
|---|---|---|
| **Copper, Cu(II)** | **blue-green** (green hot, blue cold) | **red, opaque** (copper metal / `Cu2O`) |
| **Cobalt, Co(II)** | **deep blue** | **deep blue** |
| **Chromium, Cr(III)** | **green** | **green** |
| **Iron, Fe(III)** | **yellowish-brown** | **bottle green** |
| Manganese, Mn(II) | violet / amethyst | colourless |
| Nickel, Ni(II) | brown | grey / colourless |

```
  MEMORY LINE:  "COBALT and CHROMIUM do NOT change - blue and green in
                 BOTH flames. COPPER and IRON DO change."

  LIMITATION:   the test works only for COLOURED (transition) metal
                ions. It is useless for Na+, K+, Ca2+, Mg2+.
```

# 13. ORTHOBORIC ACID, `H3BO3`

| FACT | DETAIL |
|---|---|
| Other names | Boric acid, `B(OH)3`; natural form = **sassolite** |
| Appearance | White, soft, shiny, needle-like crystals, **SOAPY / SLIPPERY** |
| Solubility | Sparingly soluble in cold water, much more in hot water |
| Structure | **Planar sp2 BO3 units, 120 degrees, joined into 2-D SHEETS by HYDROGEN BONDS**; the sheets are held by weak van der Waals forces and SLIDE |
| Why soapy? | Because the layers slide over one another — exactly like graphite |
| Basicity | **MONOBASIC** (not tribasic!) |
| Type of acid | **LEWIS acid** — it accepts `OH-`, it does NOT donate `H+` |
| Strength | **VERY WEAK**, Ka about `5.8 x 10^-10` |

```
     THE LAYER STRUCTURE OF H3BO3  (  :  =  HYDROGEN BOND )

        H            H            H            H
         \            \            \            \
          O            O            O            O
          |            |            |            |
          B            B            B            B
        /   \        /   \        /   \        /   \
       O     O      O     O      O     O      O     O
       |     |      |     |      |     |      |     |
       H     H      H     H      H     H      H     H
       :     :      :     :      :     :      :     :
       :     :      :     :      :     :      :     :
       O     O      O     O      O     O      O     O
       |     |      |     |      |     |      |     |
        \   /        \   /        \   /        \   /
          B            B            B            B
          |            |            |            |
          O            O            O            O
         /            /            /            /
        H            H            H            H

     Each boron : sp2, TRIGONAL PLANAR, 3 x -OH at 120 degrees.
     The -OH groups HYDROGEN BOND into a flat two-dimensional sheet.
     The SHEETS are held only by WEAK VAN DER WAALS FORCES and SLIDE
     over each other  ->  SOAPY, SLIPPERY, used as a LUBRICANT.
```

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   *** WHY IS H3BO3 MONOBASIC AND WEAK? ***                           |
  |                                                                      |
  |   It does NOT give away its own protons. Boron has only SIX          |
  |   electrons and an EMPTY 2p orbital, so it acts as a LEWIS ACID      |
  |   and ACCEPTS a hydroxide ion from a water molecule, setting free    |
  |   exactly ONE H3O+ ion:                                              |
  |                                                                      |
  |       B(OH)3   +   2 H2O    -->    [B(OH)4]-    +    H3O+            |
  |                                                                      |
  |   ONE H3O+ per molecule  ->  MONOBASIC.                              |
  |   Only a tiny fraction reacts  ->  VERY WEAK.                        |
  |                                                                      |
  |   It cannot be titrated directly against NaOH; adding GLYCEROL or    |
  |   MANNITOL (a cis-diol) makes it a much stronger acid so that it     |
  |   can be titrated sharply.                                           |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| REACTION | EQUATION |

# 14. DIBORANE, `B2H6`, AND THE BORANES

| FACT | DETAIL |
|---|---|
| Family name | Boron hydrides are called **BORANES** |
| Two series | **NIDO** `BnH(n+4)` — `B2H6`, `B5H9`, `B6H10`; **ARACHNO** `BnH(n+6)` — `B4H10`, `B5H11` |
| State | Colourless, **highly toxic** gas; b.p. 180 K |
| Key property | **Catches fire spontaneously in air**, burns with a green flame |
| Electron count | **12 available, 14 needed → ELECTRON DEFICIENT** |
| Hybridisation | Each boron is **sp3** |
| The bridges | **THREE-CENTRE TWO-ELECTRON (3c-2e) "BANANA" BONDS** |
| Bond lengths | `B-Ht` = **119 pm** ; `B-Hb` = **133 pm** (longer, weaker) |
| Bond angles | `Ht-B-Ht` = **121.5 deg** ; `Hb-B-Hb` = **97 deg** |
| Geometry | 2 B + **4 terminal H in ONE PLANE**; **2 bridging H PERPENDICULAR** to it |
| Warning | **There is NO B-B bond in diborane** |

```
              THE STRUCTURE OF DIBORANE   B2H6

        Ht                                          Ht
          \                                       /
           \                                     /
            \                Hb                 /
             \             /    \              /
              \          /        \           /
               B                             B
              /          \        /           \
             /             \    /              \
            /                Hb                 \
           /                                     \
          /                                       \
        Ht                                          Ht

        Ht = TERMINAL hydrogen  (FOUR of them, normal 2c-2e bonds)
        Hb = BRIDGING hydrogen  (TWO of them, 3c-2e BANANA bonds)


        SIDE VIEW - looking along the B ... B axis:

                      Hb        <- ABOVE the plane
                       |
        Ht ---- B ---- + ---- B ---- Ht      <- THE PLANE
        Ht ----'               `---- Ht         (2 B + 4 terminal H)
                       |
                      Hb        <- BELOW the plane
```

```
  THE ELECTRON COUNT (write this whenever "electron deficient" appears)

      AVAILABLE :  2 B x 3  +  6 H x 1   =  6 + 6   =  12 electrons
      NEEDED    :  6 B-H bonds + 1 B-B bond = 7 bonds x 2 = 14 electrons

      12  <  14      ->  TWO ELECTRONS SHORT  ->  ELECTRON DEFICIENT

      SOLUTION: two hydrogens BRIDGE the borons, each bridge holding
      THREE atoms with only TWO electrons  =  a 3c-2e BANANA BOND.
```

# 15. ALUMINIUM CHLORIDE AND THE DIMER `Al2Cl6`

| REACTION | EQUATION |
|---|---|
| **Preparation (dry chlorine over hot Al)** | `2 Al + 3 Cl2 --(heat)--> Al2Cl6` |
| From alumina, coke and chlorine | `Al2O3 + 3 C + 3 Cl2 --(heat)--> 2 AlCl3 + 3 CO` |
| From dry HCl over hot aluminium | `2 Al + 6 HCl --(heat)--> 2 AlCl3 + 3 H2` |
| **Hydrolysis (why the dry route is needed)** | `AlCl3 + 3 H2O -> Al(OH)3 + 3 HCl` |
| Friedel-Crafts alkylation | `C6H6 + CH3Cl --(anhyd. AlCl3)--> C6H5CH3 + HCl` |
| Friedel-Crafts acylation | `C6H6 + CH3COCl --(anhyd. AlCl3)--> C6H5COCH3 + HCl` |

```
                      STRUCTURE OF  Al2Cl6

          Cl                    Cl                    Cl
             \                /    \                /
               \            /        \            /
                 \        /            \        /
                   Al                    Al
                 /        \            /        \
               /            \        /            \
             /                \    /                \
          Cl                    Cl                    Cl

       4 TERMINAL Cl (202 pm)  +  2 BRIDGING Cl (221 pm)
       Each Al is sp3 HYBRIDISED and TETRAHEDRAL.
       The two tetrahedra share an EDGE.

  *** WHY DOES IT DIMERISE? ***
       In AlCl3 the aluminium has only SIX electrons - a SEXTET.
       It is ELECTRON DEFICIENT. To complete its OCTET it accepts a
       LONE PAIR from a chlorine of a second AlCl3 molecule through a
       COORDINATE bond. Two chlorine BRIDGES form and both aluminium
       atoms then have EIGHT electrons.
            2 AlCl3  ==  Al2Cl6
       The dimer exists in the VAPOUR and in NON-POLAR SOLVENTS such
       as benzene; above about 1073 K it splits into planar monomers.
```

```
  THE HALIDE EXCEPTION:
      AlF3 is IONIC and high melting and does NOT dimerise, because
      fluorine is too small to bridge and the Al-F bond is strongly
      ionic. Only AlCl3, AlBr3 and AlI3 give the Al2X6 dimer.
```

| Why is Al preferred to Cu for power lines? | Weight for weight it conducts about **twice as well** and is cheaper |
