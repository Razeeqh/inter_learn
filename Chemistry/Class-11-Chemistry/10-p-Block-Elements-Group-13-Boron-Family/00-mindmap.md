## THE 60-SECOND VERSION

Group 13 is the **first column of the p-block**. Five elements:

```
  B  ->  Al  ->  Ga  ->  In  ->  Tl

  NON-METAL   METAL   METAL   METAL   METAL
      B         Al      Ga      In      Tl

  All of them have the SAME outer configuration:   ns2 np1
       B   [He] 2s2 2p1
       Al  [Ne] 3s2 3p1
       Ga  [Ar] 3d10 4s2 4p1          <- 3d10 has arrived
       In  [Kr] 4d10 5s2 5p1
       Tl  [Xe] 4f14 5d10 6s2 6p1     <- 4f14 AND 5d10 have arrived
```

Almost every fact in this chapter comes from **three root causes**:

```
  ROOT CAUSE 1 :  BORON IS TINY, WITH ONLY FOUR ORBITALS AND NO d ORBITALS

        only 2s + three 2p = FOUR orbitals
                       ->  maximum covalency is FOUR, never six
                       ->  [BF4]- exists, [BF6]3- does NOT
        only three electrons to share in BX3
                       ->  a SEXTET, not an octet -> ELECTRON DEFICIENT
                       ->  BX3 and B2H6 are LEWIS ACIDS
        tiny + high IE ->  B3+ is never formed -> boron is always COVALENT


  ROOT CAUSE 2 :  d AND f ELECTRONS SHIELD BADLY

        3d10 arrives at Ga  ->  Ga is SMALLER than Al (135 < 143 pm)
                            ->  IE of Ga is HIGHER than Al
        4f14 + 5d10 at Tl   ->  IE of Tl is HIGHER than In
                            ->  the ns2 pair gets gripped very tightly
                            ->  INERT PAIR EFFECT


  ROOT CAUSE 3 :  THE INERT PAIR EFFECT

        the ns2 pair refuses to bond
                       ->  the +1 state becomes MORE stable going down
                       ->  Tl+ is the stable state of thallium
                       ->  Tl3+ is a strong OXIDISING agent
```

**If you understand only those three boxes, you can reason out most of the paper.**

## THE OXIDATION-STATE LADDER (one box, several marks)

```
     STATE        B        Al        Ga        In        Tl
     -----------------------------------------------------------------
     +3        only      stable    stable    fair      UNSTABLE
               state
     +1        none      rare      rare      fair      MOST STABLE

                <----------- +3 stability FALLS -----------
                ----------- +1 stability RISES ----------->

     STABILITY OF +1 :   Al  <  Ga  <  In  <  Tl


  THEREFORE:
       Tl3+ , Tl2O3 , TlCl3    are STRONG OXIDISING AGENTS
                               (they want to drop to Tl+)
             TlCl3  --(heat)-->  TlCl  +  Cl2
             TlI3 is NOT Tl(III) iodide - it is Tl+ (I3)- !

       Ga+ and In+ DISPROPORTIONATE because the middle members
       do not like +1 much:
             3 Ga+   -->   2 Ga  +  Ga3+

       Boron NEVER shows +1 - it has no inert pair to hide.

  CAUSE:  INERT PAIR EFFECT - the ns2 pair is pulled in so tightly by a
          badly shielded nucleus that it will not take part in bonding.
```

## THE KEY BOX — the three ideas that unlock most questions

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   KEY IDEA 1 :  BORON IS ELECTRON DEFICIENT                          |
  |                                                                      |
  |      In BX3 and BH3 the boron atom has only SIX electrons around     |
  |      it - a SEXTET, not an octet. It is therefore desperate for a    |
  |      lone pair.                                                      |
  |                                                                      |
  |      This ONE sentence answers:                                      |
  |         *  Why is BF3 a Lewis acid?                                  |
  |         *  Why does BF3 form [BF4]- with F- ?                        |
  |         *  Why does BF3 form the adduct F3B <- NH3 ?                 |
  |         *  Why does BH3 dimerise to B2H6 ?                           |
  |         *  Why does AlCl3 dimerise to Al2Cl6 ?                       |
  |                                                                      |
  +----------------------------------------------------------------------+

  +----------------------------------------------------------------------+
  |                                                                      |
  |   KEY IDEA 2 :  BACK BONDING IN BX3                                  |
  |                                                                      |
  |      A filled p orbital of the halogen donates its lone pair         |
  |      SIDEWAYS into the empty 2p orbital of boron.                    |
  |      This is p(pi) - p(pi) BACK BONDING. It partly fills the         |
  |      boron's empty orbital, so boron becomes LESS hungry.            |
  |                                                                      |
  |      F is 2p - SAME SIZE as boron's 2p -> BEST overlap               |
  |                                       -> STRONGEST back bonding      |
  |                                       -> WEAKEST Lewis acid          |
  |      I is 5p - HUGE compared to 2p    -> WORST overlap               |
  |                                       -> almost NO back bonding      |
  |                                       -> STRONGEST Lewis acid        |
  |                                                                      |
  |               BF3  <  BCl3  <  BBr3  <  BI3                          |
  |                     Lewis acid strength INCREASES                    |
  |                                                                      |
  +----------------------------------------------------------------------+

  +----------------------------------------------------------------------+
  |                                                                      |
  |   KEY IDEA 3 :  INERT PAIR EFFECT                                    |
  |                                                                      |
  |      Going down the group the intervening d (3d10, 4d10, 5d10) and   |
  |      f (4f14) electrons shield badly. The nucleus therefore grips    |
  |      the ns2 pair very tightly. That pair becomes "inert" and stops  |
  |      taking part in bonding, so only the single np1 electron is      |
  |      used and the element shows +1.                                  |
  |                                                                      |
  |      Result:  +1 state becomes MORE stable down the group            |
  |               +3 state becomes LESS stable down the group            |
  |                                                                      |
  |      This ONE idea answers:                                          |
  |         *  Why is Tl(I) more stable than Tl(III)?                    |
  |         *  Why is TlCl3 / Tl2O3 a strong oxidising agent?            |
  |         *  Why does TlI3 not exist as a thallium(III) compound?      |
  |         *  Why is TlOH as strong a base as NaOH?                     |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## THE EIGHT EQUATIONS TO WRITE ON YOUR PALM

```
  1.   Na2B4O7.10H2O  --(heat)-->  Na2B4O7  +  10 H2O
       Na2B4O7        --(red heat)-->  2 NaBO2  +  B2O3      (GLASSY BEAD)

  2.   CuO  +  B2O3  --(heat)-->  Cu(BO2)2                   (BLUE-GREEN bead)

  3.   Na2B4O7  +  2 HCl  +  5 H2O  -->  2 NaCl  +  4 H3BO3   (making H3BO3)

  4.   H3BO3  --(370 K)--> HBO2  --(430 K)--> H2B4O7 --(red heat)--> B2O3

  5.   B(OH)3  +  2 H2O  -->  [B(OH)4]-  +  H3O+        (WHY IT IS MONOBASIC)

  6.   2 NaBH4  +  I2  -->  B2H6  +  2 NaI  +  H2            (making diborane)
       B2H6  +  6 H2O  -->  2 H3BO3  +  6 H2                 (hydrolysis)

  7.   2 Al  +  2 NaOH  +  6 H2O  -->  2 Na[Al(OH)4]  +  3 H2  (AMPHOTERIC)
       2 Al  +  6 HCl   -->  2 AlCl3  +  3 H2

  8.   2 AlCl3   ==   Al2Cl6         (DIMER - to complete the octet)
```
