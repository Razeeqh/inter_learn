score here even without loving chemistry, because it is really just careful arithmetic.

## THE 60-SECOND VERSION

Everything in this chapter is a fight between two things:

```
  +-------------------------------+   vs   +-------------------------------+
  |   INTERMOLECULAR FORCES       |        |   THERMAL ENERGY              |
  |   pull molecules TOGETHER     |        |   pushes molecules APART      |
  |   (the "glue")                |        |   (the "kicking")             |
  +-------------------------------+        +-------------------------------+

     FORCES WIN            ->   SOLID
     FORCES ~ THERMAL      ->   LIQUID
     THERMAL WINS          ->   GAS
```

Then the chapter does three things in order:

```
  STEP 1   MEASURE gases  ->  Boyle, Charles, Gay-Lussac, Avogadro
              |               put together: P V = n R T
              v
  STEP 2   EXPLAIN gases ->  Kinetic Molecular Theory
              |               (molecules are tiny hard balls flying about)
              v
  STEP 3   FIX the theory -> Real gases are NOT ideal.
                             Molecules DO attract and DO occupy volume.
                             van der Waals equation repairs P V = n R T.
                             Cool + compress a real gas -> LIQUID.
```

**If you can write P V = n R T and use it, you already have most of the numerical marks.**

## THE FORMULAS THAT UNLOCK EVERYTHING

```
  +-----------------------------------------------------------------------+
  |                                                                       |
  |     THE MASTER EQUATION                                               |
  |                                                                       |
  |                     P V   =   n R T                                   |
  |                                                                       |
  |     R = 0.0821 L atm K^-1 mol^-1      (when P in atm, V in litres)    |
  |     R = 8.314  J K^-1 mol^-1          (SI units)                      |
  |                                                                       |
  |                                                                       |
  |     THE COMBINED GAS LAW  (when the AMOUNT of gas does not change)    |
  |                                                                       |
  |                    P1 V1        P2 V2                                 |
  |                   -------  =   -------                                |
  |                     T1           T2                                   |
  |                                                                       |
  |                                                                       |
  |     THE SPEED FORMULA                                                 |
  |                                                                       |
  |                            +--------------                            |
  |                           /   3 R T                                   |
  |                u(rms) =  /   ---------                                |
  |                        \/        M                                    |
  |                                                                       |
  |     (T ALWAYS in kelvin.  M in kg/mol if you use R = 8.314)           |
  |                                                                       |
  +-----------------------------------------------------------------------+
```

**Three boxes. Write them on your palm. They answer roughly 70% of every numerical
that has ever been asked from this chapter.**

## THE ONE CONVERSION TABLE YOU MUST NEVER GET WRONG

```
  +--------------------------------------------------------------+
  |   T (kelvin)   =   t (celsius)  +  273.15    ~   t + 273     |
  |                                                              |
  |   1 atm  =  760 mm Hg  =  760 torr  =  101325 Pa             |
  |          =  101.325 kPa  =  1.01325 bar                      |
  |                                                              |
  |   1 bar  =  10^5 Pa                                          |
  |   1 L    =  1000 mL  =  10^-3 m^3  =  1 dm^3                 |
  |                                                              |
  |   STP (old)  :  0 degC (273.15 K) and 1 atm  ->  Vm = 22.4 L |
  |   STP (IUPAC):  0 degC (273.15 K) and 1 bar  ->  Vm = 22.7 L |
  |                                                              |
  |   AP Inter uses 22.4 L unless the question says "1 bar".     |
  +--------------------------------------------------------------+
```

> **The single most common reason students lose marks in this chapter:
> forgetting to convert degrees Celsius into kelvin.** Every single time you
> see a temperature, add 273 before you do anything else.

## IF YOU ONLY HAVE 2 DAYS

```
  DAY 1  MORNING
     - Intermolecular forces: the 4 types, one example each,
       and "forces vs thermal energy decides the state".
     - The three-state comparison table above.
     - Boyle, Charles, Gay-Lussac, Avogadro: statement + formula + graph.
       Draw each graph 3 times on paper.
       -> this alone is 6 to 8 marks

  DAY 1  EVENING
     - P V = n R T. Do 10 numericals. Nothing else.
     - Combined gas law P1V1/T1 = P2V2/T2. Do 5 numericals.
     - d = P M / R T. Do 3 numericals.
       -> another 4 to 6 marks, and this is where EAPCET marks live

  DAY 2  MORNING
     - Kinetic molecular theory: write the 6 postulates from memory.
     - u(rms) = sqrt(3RT/M) ; the ratio 1 : 1.128 : 1.224 ;
       draw the Maxwell curve with two temperatures.
     - Graham's law: rate proportional to 1/sqrt(M).
       -> this is one whole 8-mark question

  DAY 2  EVENING
     - Real gases: Z = PV/nRT , the Z-vs-P plot, why gases deviate,
       van der Waals equation with the meaning and units of a and b.
     - Critical temperature / pressure / volume in one line each.
     - Liquid state: vapour pressure, boiling point, surface tension,
       viscosity - four short definitions with units.
       -> another 6 to 8 marks

  DO NOT try to derive the kinetic gas equation from scratch if you are short
  of time. Learn to STATE it and USE it. The derivation is rarely asked in full.
```

## THE THREE SENTENCES THE EXAMINER WANTS TO SEE

```
  1.  "At constant temperature, the volume of a fixed mass of gas is
       inversely proportional to its pressure."            (Boyle)

  2.  "Equal volumes of all gases under the same conditions of temperature
       and pressure contain an equal number of molecules."  (Avogadro)

  3.  "The average kinetic energy of gas molecules is directly proportional
       to the absolute temperature."                        (KMT)
```

Learn those three word for word. Examiners give full marks for the exact wording
and cut marks for vague paraphrases.
