# PATTERN 1 — Writing the equilibrium constant expression

### Q1
For the reaction `CaCO3(s) <==> CaO(s) + CO2(g)`, the equilibrium constant Kp is

(a) `p(CaO) p(CO2) / p(CaCO3)` &nbsp; (b) `p(CO2)` &nbsp;
(c) `1 / p(CO2)` &nbsp; (d) `p(CaO) p(CO2)`

**ANSWER: (b)**
```
  PURE SOLIDS are omitted from K expressions. Only CO2 is a gas.
```

---

### Q2
For `2SO2(g) + O2(g) <==> 2SO3(g)`, Kc equals

(a) `[SO3]^2 / ([SO2]^2 [O2])` &nbsp; (b) `[SO2]^2 [O2] / [SO3]^2` &nbsp;
(c) `[SO3] / ([SO2][O2])` &nbsp; (d) `[SO3]^2 [O2] / [SO2]^2`

**ANSWER: (a)** — products on top, coefficients as powers.

---

### Q3
The units of Kc for `N2 + 3H2 <==> 2NH3` are

(a) mol L^-1 &nbsp; (b) L mol^-1 &nbsp; (c) L^2 mol^-2 &nbsp; (d) no units

**ANSWER: (c)**
```
  dn = 2 - 4 = -2      units of Kc = (mol L^-1)^-2 = L^2 mol^-2
```

> **SHORTCUT:** Units of Kc = `(mol/L)^dn`, units of Kp = `(atm)^dn`.
> Whenever dn = 0, the answer is "no units".

# PATTERN 2 — Converting between Kp and Kc

### Q4
For which reaction is Kp equal to Kc?

(a) `N2 + 3H2 <==> 2NH3` &nbsp; (b) `H2 + I2 <==> 2HI` &nbsp;
(c) `PCl5 <==> PCl3 + Cl2` &nbsp; (d) `2SO2 + O2 <==> 2SO3`

**ANSWER: (b)** — `Kp = Kc` only when `dn = 0`, and `2 - (1+1) = 0`.

---

### Q5
For `2NOCl(g) <==> 2NO(g) + Cl2(g)`, the value of dn is

(a) 0 &nbsp; (b) +1 &nbsp; (c) -1 &nbsp; (d) +2

**ANSWER: (b)** — `dn = 3 - 2 = +1`.

---

### Q6
For `PCl5 <==> PCl3 + Cl2` at 500 K, Kc = 0.0434 mol/L. The value of Kp
(R = 0.0821) is about

(a) 1.78 atm &nbsp; (b) 0.0434 atm &nbsp; (c) 17.8 atm &nbsp; (d) 3.56 atm

**ANSWER: (a)**
```
  dn = +1
  Kp = Kc (RT)^1 = 0.0434 x (0.0821 x 500) = 0.0434 x 41.05 = 1.78 atm
```

---

### Q7
For `N2 + 3H2 <==> 2NH3` at 500 K, Kc = 0.061. Kp is

(a) 3.62 x 10^-5 &nbsp; (b) 2.5 &nbsp; (c) 0.061 &nbsp; (d) 103

**ANSWER: (a)**
```
  dn = -2 ,   RT = 0.0821 x 500 = 41.05

  Kp = 0.061 / (41.05)^2 = 0.061 / 1685 = 3.62 x 10^-5 atm^-2
```

> **SHORTCUT:** if dn is NEGATIVE, Kp is SMALLER than Kc. That alone
> eliminates (b), (c) and (d) instantly.

# PATTERN 3 — Manipulating K

### Q8
If Kc for `A + B <==> C + D` is 16, then Kc for `C + D <==> A + B` is

(a) 16 &nbsp; (b) 256 &nbsp; (c) 0.0625 &nbsp; (d) 4

**ANSWER: (c)** — reversing gives `1/K = 1/16 = 0.0625`.

---

### Q9
If K for `N2 + 3H2 <==> 2NH3` is K, then K for
`(1/2)N2 + (3/2)H2 <==> NH3` is

(a) K &nbsp; (b) K^2 &nbsp; (c) sqrt(K) &nbsp; (d) 1/K

**ANSWER: (c)** — halving the equation takes the square root of K.

---

### Q10
`A <==> B` has K1 = 2 and `B <==> C` has K2 = 5. K for `A <==> C` is

(a) 7 &nbsp; (b) 10 &nbsp; (c) 2.5 &nbsp; (d) 0.4

**ANSWER: (b)** — adding reactions MULTIPLIES their constants: `2 x 5 = 10`.

# PATTERN 4 — Q versus K, direction of reaction

### Q11
For a reaction Kc = 50. At a certain instant Q = 80. The reaction will

(a) move forward &nbsp; (b) move backward &nbsp; (c) be at equilibrium &nbsp;
(d) stop

**ANSWER: (b)** — `Q > K` means too many products, so it goes BACKWARD.

---

### Q12
For `H2 + I2 <==> 2HI`, Kc = 64. If [H2] = [I2] = 0.5 M and [HI] = 2 M, then

(a) it is at equilibrium &nbsp; (b) more HI forms &nbsp;
(c) HI decomposes &nbsp; (d) cannot be predicted

**ANSWER: (b)**
```
  Q = (2)^2 / (0.5 x 0.5) = 4 / 0.25 = 16
  Q (16) < K (64)  ->  moves FORWARD, more HI is formed.
```

---

### Q13
For a reaction at 300 K, K = 1. The value of delta G(standard) is

(a) positive &nbsp; (b) negative &nbsp; (c) zero &nbsp; (d) infinity

**ANSWER: (c)** — `dG = -RT ln K` and `ln 1 = 0`.

---

### Q14
If delta G(std) for a reaction is negative, then

(a) K < 1 &nbsp; (b) K = 1 &nbsp; (c) K > 1 &nbsp; (d) K = 0

**ANSWER: (c)** — negative dG means the products are favoured, so K > 1.

# PATTERN 5 — Le Chatelier's principle (the most-asked pattern)

### Q15
For `N2 + 3H2 <==> 2NH3` (dH = -92 kJ), the yield of ammonia is increased by

(a) high T, high P &nbsp; (b) low T, high P &nbsp;
(c) low T, low P &nbsp; (d) high T, low P

**ANSWER: (b)**
```
  EXOTHERMIC  ->  LOW temperature favours the forward reaction
  4 moles -> 2 moles  ->  HIGH pressure favours the forward reaction
```

> **SHORTCUT for every Le Chatelier MCQ:**
> ```
>   dH negative (exothermic)  ->  LOW temperature
>   dH positive (endothermic) ->  HIGH temperature
>   fewer moles on the right  ->  HIGH pressure
>   more moles on the right   ->  LOW pressure
> ```

---

Increasing the pressure has NO effect on which equilibrium?

(a) `N2O4 <==> 2NO2` &nbsp; (b) `2SO2 + O2 <==> 2SO3` &nbsp;
(c) `H2(g) + I2(g) <==> 2HI(g)` &nbsp; (d) `PCl5 <==> PCl3 + Cl2`

**ANSWER: (c)** — `dn = 0`, equal gas moles on both sides.

### Q17
Adding an inert gas at CONSTANT VOLUME to a gaseous equilibrium

(a) shifts it forward &nbsp; (b) shifts it backward &nbsp;
(c) has no effect &nbsp; (d) changes K

**ANSWER: (c)** — partial pressures and concentrations are unchanged.

---

### Q18
Adding argon at CONSTANT PRESSURE to `N2 + 3H2 <==> 2NH3` will

(a) increase the yield of NH3 &nbsp; (b) decrease the yield of NH3 &nbsp;
(c) have no effect &nbsp; (d) change Kp

**ANSWER: (b)**
```
  Constant pressure -> volume expands -> everything is diluted
  -> equilibrium shifts to the side with MORE gas moles
  -> backward (4 moles side) -> less NH3.
```

---

### Q19
A catalyst added to a system at equilibrium

(a) increases the yield &nbsp; (b) increases K &nbsp;
(c) shifts the equilibrium forward &nbsp;
(d) only makes equilibrium arrive sooner

**ANSWER: (d)** — it lowers both activation energies equally.

### Q20
Which factor changes the VALUE of the equilibrium constant?

(a) pressure &nbsp; (b) catalyst &nbsp; (c) temperature &nbsp;
(d) initial concentration

**ANSWER: (c)** — temperature is the ONLY one. Learn this line.

### Q21
For an ENDOTHERMIC reaction, raising the temperature

(a) decreases K &nbsp; (b) increases K &nbsp; (c) does not change K &nbsp;
(d) makes K zero

**ANSWER: (b)** — heat behaves like a reactant, so heating drives it forward.

### Q22
In the Contact process `2SO2 + O2 <==> 2SO3` (exothermic), the catalyst used is

# PATTERN 6 — Degree of dissociation numericals

### Q23
For `A(g) <==> 2B(g)`, A is 50 % dissociated at a total pressure P.
The value of Kp is

(a) P/3 &nbsp; (b) 2P/3 &nbsp; (c) 4P/3 &nbsp; (d) 3P/4

**ANSWER: (c)**
```
             4 alpha^2 P        4 (0.5)^2 P        4 (0.25) P       P
    Kp  =  ---------------  =  --------------  =  -----------  =  ------
             1 - alpha^2         1 - 0.25             0.75          0.75

        =  1.333 P   =   4P / 3
```

---

### Q24
1 mole of PCl5 in a 1 L vessel is 40 % dissociated. Kc is

(a) 0.267 &nbsp; (b) 0.4 &nbsp; (c) 0.16 &nbsp; (d) 0.6

**ANSWER: (a)**
```
                 PCl5   <==>   PCl3   +   Cl2
   Equilibrium    0.6           0.4        0.4        (V = 1 L)

           (0.4)(0.4)      0.16
   Kc  =  ------------  = ------  =  0.267 mol/L
              0.6           0.6
```

---

### Q25
For `A + B <==> C + D`, Kc = 4. Starting with 1 mole each of A and B in
1 litre, the equilibrium concentration of C is

(a) 0.33 M &nbsp; (b) 0.50 M &nbsp; (c) 0.67 M &nbsp; (d) 0.80 M

**ANSWER: (c)**
```
                A     +     B    <==>    C   +   D
   Equilib    1 - x       1 - x           x       x

          x^2                           x
   4 = -----------   ->  take sqrt:   ------- = 2   ->  x = 2 - 2x
       (1 - x)^2                       1 - x

   3x = 2   ->   x = 0.667 M

   CHECK: (0.667)^2 / (0.333)^2 = 0.4449 / 0.1109 = 4.01   CORRECT
```

> **SHORTCUT:** when both sides are perfect squares, square-root the whole
> equation instead of forming a quadratic.

# PATTERN 7 — pH of strong acids and bases

### Q26
The pH of 0.001 M NaOH is

(a) 3 &nbsp; (b) 11 &nbsp; (c) 7 &nbsp; (d) 12

**ANSWER: (b)** — `pOH = 3`, so `pH = 14 - 3 = 11`.

> **SHORTCUT:** for a BASE, first find pOH, then subtract from 14. If your
> answer for a base is below 7, you have made this mistake.

---

### Q27
The pH of 0.002 M HCl is

(a) 3.00 &nbsp; (b) 2.70 &nbsp; (c) 3.30 &nbsp; (d) 2.00

**ANSWER: (b)**
```
   pH = - log ( 2 x 10^-3 ) = 3 - log 2 = 3 - 0.301 = 2.70
```

> **SHORTCUT:** `-log(a x 10^-n) = n - log a`. It is always **less** than n,
> never more. Option (c) is the classic trap answer.

---

### Q28
The pH of 0.005 M Ca(OH)2 is

(a) 2 &nbsp; (b) 2.3 &nbsp; (c) 12 &nbsp; (d) 11.7

**ANSWER: (c)**
```
   Ca(OH)2 gives TWO OH- ions:   [OH-] = 2 x 0.005 = 0.01 = 10^-2
   pOH = 2   ->   pH = 12
```

---

### Q29
100 mL of 0.2 M HCl is mixed with 100 mL of 0.1 M NaOH. The pH of the
resulting solution is

(a) 1.0 &nbsp; (b) 1.3 &nbsp; (c) 7.0 &nbsp; (d) 12.7

**ANSWER: (b)**
```
   moles HCl  = 0.100 L x 0.2 = 0.02 mol
   moles NaOH = 0.100 L x 0.1 = 0.01 mol
   excess H+  = 0.02 - 0.01 = 0.01 mol

   TOTAL VOLUME = 200 mL = 0.2 L

   [H+] = 0.01 / 0.2 = 0.05 M

   pH = - log ( 5 x 10^-2 ) = 2 - 0.699 = 1.30
```

---

### Q30
The pH of 10^-8 M HCl is

(a) 8 &nbsp; (b) 7 &nbsp; (c) slightly less than 7 &nbsp;
(d) slightly more than 7

**ANSWER: (c)**
```
   An ACID can never have pH above 7. At this dilution the H+ from
   WATER (10^-7) dominates:

   [H+] = 10^-8 + 10^-7 = 1.1 x 10^-7   ->   pH = 6.96
```

> **SHORTCUT:** if an acid's concentration is below 10^-6 M, the answer is
> always "just under 7". Never pick a pH above 7 for an acid.

---

### Q31
If the pH of a solution is 4.5, then [H+] is

(a) 3.16 x 10^-5 M &nbsp; (b) 4.5 x 10^-5 M &nbsp;
(c) 3.16 x 10^-4 M &nbsp; (d) 10^-4.5 is not defined

**ANSWER: (a)** — `[H+] = 10^-4.5 = 10^0.5 x 10^-5 = 3.16 x 10^-5 M`.

# PATTERN 8 — pH of weak acids and bases

### Q32
The pH of a 0.1 M weak acid with Ka = 1.0 x 10^-5 is

(a) 1 &nbsp; (b) 3 &nbsp; (c) 5 &nbsp; (d) 7

**ANSWER: (b)**
```
   [H+] = sqrt ( Ka C ) = sqrt ( 10^-5 x 10^-1 ) = sqrt ( 10^-6 ) = 10^-3

   pH = 3
```

---

### Q33
The degree of ionisation of the acid in Q32 is

(a) 0.1 % &nbsp; (b) 1 % &nbsp; (c) 10 % &nbsp; (d) 100 %

**ANSWER: (b)**
```
   alpha = sqrt ( Ka / C ) = sqrt ( 10^-5 / 10^-1 ) = sqrt ( 10^-4 ) = 0.01

   = 1 %
```

---

### Q34
A 0.01 M solution of a weak acid is 5 % ionised. Its Ka is

(a) 2.5 x 10^-5 &nbsp; (b) 5 x 10^-4 &nbsp; (c) 2.5 x 10^-3 &nbsp;
(d) 5 x 10^-2

**ANSWER: (a)**
```
   Ka = C alpha^2 = 0.01 x (0.05)^2 = 0.01 x 2.5 x 10^-3 = 2.5 x 10^-5
```

---

### Q35
On dilution, the degree of ionisation of a WEAK electrolyte

(a) decreases &nbsp; (b) increases &nbsp; (c) stays the same &nbsp;
(d) becomes zero

**ANSWER: (b)** — Ostwald's dilution law, `alpha = sqrt(Ka/C)`.
Note that Ka itself is UNCHANGED.

### Q36
The conjugate base of `H2PO4-` is

(a) `H3PO4` &nbsp; (b) `HPO4 2-` &nbsp; (c) `PO4 3-` &nbsp; (d) `P2O5`

**ANSWER: (b)** — conjugate base = acid minus one H+.

Ka of a weak acid is 1.0 x 10^-5. The Kb of its conjugate base is

(a) 10^-5 &nbsp; (b) 10^-9 &nbsp; (c) 10^-14 &nbsp; (d) 10^-19

**ANSWER: (b)** — `Kb = Kw / Ka = 10^-14 / 10^-5 = 10^-9`.

Which of these is NOT amphoteric?

act as a base.

### Q39
Which of the following is NOT a Lewis acid?

(a) `BF3` &nbsp; (b) `AlCl3` &nbsp; (c) `NH3` &nbsp; (d) `SO3`

**ANSWER: (c)** — NH3 has a lone pair, so it is a Lewis BASE.

### Q40
The strongest conjugate base among these is the one derived from

(a) `HCl` &nbsp; (b) `CH3COOH` &nbsp; (c) `HNO3` &nbsp; (d) `H2SO4`

**ANSWER: (b)**

# PATTERN 10 — Buffers and the Henderson equation

### Q41
Which of the following is a buffer solution?

(a) `HCl + NaCl` &nbsp; (b) `CH3COOH + CH3COONa` &nbsp;
(c) `NaOH + NaCl` &nbsp; (d) `HCl + NaOH`

**ANSWER: (b)** — a buffer needs a WEAK acid (or base) plus its salt.
`HCl + NaCl` is a strong acid with its salt — that is NOT a buffer.

---

### Q42
The pH of a buffer containing equal molar amounts of a weak acid
(pKa = 4.74) and its sodium salt is

(a) 4.74 &nbsp; (b) 7.00 &nbsp; (c) 9.26 &nbsp; (d) 2.37

**ANSWER: (a)** — `log(1) = 0`, so `pH = pKa`.

---

### Q43
0.10 mole of CH3COOH and 0.05 mole of NaOH are dissolved in 1 L of water.
Ka = 1.8 x 10^-5. The pH is

(a) 3.37 &nbsp; (b) 4.74 &nbsp; (c) 5.04 &nbsp; (d) 8.87

**ANSWER: (b)**
```
   NaOH converts 0.05 mol of acid into 0.05 mol of salt.

        acid left  =  0.10 - 0.05  =  0.05 mol
        salt made  =                  0.05 mol

   Equal amounts -> HALF NEUTRALISATION -> pH = pKa = 4.74
```

> **SHORTCUT:** "half of the weak acid neutralised" always means `pH = pKa`.
> Spot it and answer in five seconds.

---

### Q44
The pH of a basic buffer with 0.1 M NH4OH and 0.1 M NH4Cl
(Kb = 1.8 x 10^-5) is

(a) 4.74 &nbsp; (b) 7.00 &nbsp; (c) 9.26 &nbsp; (d) 11.13

**ANSWER: (c)**
```
   pOH = pKb + log ( [salt]/[base] ) = 4.74 + log 1 = 4.74
   pH  = 14 - 4.74 = 9.26
```

---

### Q45
On DILUTING a buffer with water, its pH

(a) increases &nbsp; (b) decreases &nbsp; (c) is practically unchanged &nbsp;
(d) becomes 7

**ANSWER: (c)** — dilution divides BOTH [salt] and [acid] by the same
factor, so the ratio in the Henderson equation is unchanged.

**ANSWER: (a)**

The pH of 0.1 M CH3COONa (pKa = 4.74) is

# PATTERN 12 — Solubility product

### Q51
The solubility of a salt AB is s mol/L. Its Ksp is

(a) s &nbsp; (b) s^2 &nbsp; (c) 4s^3 &nbsp; (d) 27s^4

**ANSWER: (b)**

---

### Q52
For `Ag2CrO4`, the relation between solubility s and Ksp is

(a) `Ksp = s^2` &nbsp; (b) `Ksp = 2s^3` &nbsp; (c) `Ksp = 4s^3` &nbsp;
(d) `Ksp = 27s^4`

**ANSWER: (c)** — `(2s)^2 (s) = 4s^3`.

---

### Q53
The Ksp of AgBr is 5.0 x 10^-13. Its solubility in mol/L is

(a) 5.0 x 10^-13 &nbsp; (b) 7.1 x 10^-7 &nbsp; (c) 2.5 x 10^-6 &nbsp;
(d) 1.0 x 10^-6

**ANSWER: (b)**
```
   AB type:  s = sqrt ( Ksp ) = sqrt ( 5.0 x 10^-13 )
                             = sqrt ( 50 x 10^-14 )
                             = 7.07 x 10^-7  mol/L
```

> **SHORTCUT:** before square-rooting, make the power of 10 an EVEN number.
> `5 x 10^-13` becomes `50 x 10^-14`, and `sqrt(50) = 7.07`.

---

### Q54
Ksp of AgCl is 1.8 x 10^-10 and of Ag2CrO4 is 1.1 x 10^-12. Which is more
soluble in water?

(a) AgCl &nbsp; (b) Ag2CrO4 &nbsp; (c) equal &nbsp; (d) cannot be compared

**ANSWER: (b)**
```
   AgCl:      s = sqrt(1.8 x 10^-10)              = 1.34 x 10^-5 mol/L
   Ag2CrO4:   4s^3 = 1.1 x 10^-12 -> s^3 = 2.75 x 10^-13
                                  -> s   = 6.50 x 10^-5 mol/L

   Ag2CrO4 has the SMALLER Ksp but the LARGER solubility.
```

> **SHORTCUT / TRAP:** you may compare Ksp values DIRECTLY only for salts of
> the SAME type. AgCl is AB, Ag2CrO4 is A2B — you must convert both to s.
> This is one of the most common traps in EAPCET.

---

### Q55
Equal volumes of 0.02 M `AgNO3` and 0.02 M `NaCl` are mixed.
(Ksp of AgCl = 1.8 x 10^-10)

(a) no precipitate &nbsp; (b) a precipitate forms &nbsp;
(c) the solution is exactly saturated &nbsp; (d) AgCl dissolves

**ANSWER: (b)**
```
   After mixing:  [Ag+] = [Cl-] = 0.01 M

   Qsp = (10^-2)(10^-2) = 10^-4    which is >> Ksp = 1.8 x 10^-10

   Qsp > Ksp  ->  PRECIPITATE.
```

---

### Q56
The solubility of AgCl (Ksp = 1.8 x 10^-10) in 0.10 M NaCl is

(a) 1.34 x 10^-5 M &nbsp; (b) 1.8 x 10^-9 M &nbsp; (c) 1.8 x 10^-10 M &nbsp;
(d) 1.8 x 10^-11 M

**ANSWER: (b)**
```
   [Cl-] = 0.10 M from the fully ionised NaCl

   s = Ksp / [Cl-] = 1.8 x 10^-10 / 0.10 = 1.8 x 10^-9 mol/L
```

---

### Q57
The solubility of AgCl (Ksp = 1.8 x 10^-10) in 0.01 M `CaCl2` is

(a) 9.0 x 10^-9 M &nbsp; (b) 1.8 x 10^-8 M &nbsp; (c) 1.8 x 10^-9 M &nbsp;
(d) 1.34 x 10^-5 M

**ANSWER: (a)**
```
   CaCl2 gives TWO Cl- per formula unit:  [Cl-] = 2 x 0.01 = 0.02 M

   s = 1.8 x 10^-10 / 0.02 = 9.0 x 10^-9 mol/L
```

> **SHORTCUT:** always check how many of the common ion each formula unit
> releases. `CaCl2` gives 2 Cl-, `Na2SO4` gives 2 Na+, and so on.

# PATTERN 13 — Common ion effect

### Q58
The addition of `CH3COONa` to an acetic acid solution causes

(a) [H+] to increase &nbsp; (b) [H+] to decrease &nbsp;
(c) Ka to increase &nbsp; (d) Ka to decrease

**ANSWER: (b)** — the common ion `CH3COO-` suppresses the ionisation, so
[H+] falls and pH rises. **Ka never changes** (only temperature changes it).

### Q59
H2S is passed through a solution acidified with HCl in qualitative
analysis in order to

(a) increase [S2-] &nbsp; (b) decrease [S2-] &nbsp;
(c) increase the pH &nbsp; (d) dissolve the precipitate

**ANSWER: (b)** — the common ion H+ from HCl suppresses the ionisation of
H2S, keeping [S2-] low so only group II sulphides precipitate.

### Q60
The solubility of a sparingly soluble salt in the presence of a common ion

(a) increases &nbsp; (b) decreases &nbsp; (c) is unchanged &nbsp;
(d) becomes infinite

**ANSWER: (b)** — Le Chatelier pushes the dissolution equilibrium backwards.
