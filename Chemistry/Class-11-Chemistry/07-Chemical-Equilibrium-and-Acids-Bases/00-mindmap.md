## THE 60-SECOND VERSION

**PART 1 — EQUILIBRIUM**

A reversible reaction never finishes. It reaches a point where the forward reaction
and the backward reaction happen at **exactly the same speed**. Nothing looks like it
is changing, but underneath both reactions are still running. That is **equilibrium**
— it is *dynamic*, not dead.

At that point the concentrations settle into a fixed ratio called **K**:

```
   for      a A  +  b B   <==>   c C  +  d D

                  [C]^c  [D]^d
        Kc  =  --------------------      (concentrations at EQUILIBRIUM only)
                  [A]^a  [B]^b
```

If you then **disturb** the system (add stuff, squeeze it, heat it), it shifts to
undo the disturbance. That one sentence is **Le Chatelier's principle** and it is
worth 8 marks.

**PART 2 — ACIDS AND BASES**

Water itself splits a tiny bit: `H2O <==> H+ + OH-`, and the product of the two
concentrations is always `10^-14` at 25 C. So if you know `[H+]`, you know everything.
`pH = -log[H+]` just turns an ugly number like `10^-3` into a friendly `3`.

Everything else in Part 2 — weak acids, buffers, hydrolysis, solubility product —
is the same equilibrium idea from Part 1, applied to ions in water.

```
   PART 1  gives you    K = products / reactants
                                |
                                v
   PART 2  is just      the SAME thing, where the "reaction" is
                        an acid splitting up in water.

   LEARN PART 1 PROPERLY AND PART 2 IS ALMOST FREE.
```

## THE ONE-LINE VERSION OF LE CHATELIER

```
  +-------------------------------------------------------------------+
  |                                                                   |
  |   "If you disturb a system at equilibrium, it shifts in the        |
  |    direction that UNDOES the disturbance."                         |
  |                                                                   |
  |    Add something   ->  shifts AWAY from it (uses it up)            |
  |    Remove something ->  shifts TOWARDS it (makes more)             |
  |    Increase pressure ->  shifts to the side with FEWER gas moles   |
  |    Increase temperature -> shifts in the ENDOTHERMIC direction     |
  |    Catalyst          ->  NO SHIFT AT ALL (only faster)             |
  |    Inert gas at constant VOLUME -> NO SHIFT                        |
  |                                                                   |
  +-------------------------------------------------------------------+
```

## THE FIVE DEFINITIONS EXAMINERS ASK OVER AND OVER

```
  1. EQUILIBRIUM        rate of forward reaction = rate of backward reaction,
                        concentrations become constant, reaction is dynamic.

  2. LAW OF MASS ACTION rate of a reaction is proportional to the product of
                        the ACTIVE MASSES of the reactants, each raised to
                        the power of its stoichiometric coefficient.

  3. pH                 the negative logarithm to base 10 of the hydrogen ion
                        concentration in mol/L.      pH = -log[H+]

  4. BUFFER             a solution that resists a change in pH when a small
                        amount of acid or base is added to it.

  5. SOLUBILITY PRODUCT the product of the molar concentrations of the ions of
                        a sparingly soluble salt in its SATURATED solution,
                        each raised to the power of its coefficient.
```

Learn these five word-for-word. They appear every single year.
