## Topic: Nature of equilibrium

### Q A1
What is chemical equilibrium? Why is it called dynamic?

**ANSWER:**
```
  CHEMICAL EQUILIBRIUM - the stage of a reversible reaction at which the
  RATE OF THE FORWARD REACTION becomes EQUAL to the RATE OF THE BACKWARD
  REACTION, so that the concentrations of all species remain constant.

  It is called DYNAMIC because both reactions are still going on at
  equal speeds. Nothing changes on the outside, but molecules keep
  reacting in both directions.
```

### Q A2
State the law of mass action.

**ANSWER:**
```
  "At a given temperature, the rate of a chemical reaction is directly
   proportional to the product of the ACTIVE MASSES of the reactants,
   each raised to the power of its stoichiometric coefficient."

  ACTIVE MASS = molar concentration (moles per litre), written [X].
```

### Q A4
Write the Kc expression for `CaCO3(s) <==> CaO(s) + CO2(g)`. Why?

**ANSWER:**
```
     Kc  =  [ CO2 ]           Kp  =  p(CO2)

  Because CaCO3 and CaO are PURE SOLIDS. The concentration of a pure
  solid (or pure liquid) is a fixed quantity determined by its density
  and molar mass, so it is absorbed into the constant and left out.
```

## Topic: Kp, Kc and dn

### Q A5
Write the relation between Kp and Kc. What is dn?

**ANSWER:**
```
     Kp   =   Kc  ( R T ) ^ dn

  dn  =  (number of moles of GASEOUS products)
         - (number of moles of GASEOUS reactants)

  If dn = 0 , Kp = Kc.
```

### Q A6
Find dn for each of these reactions:
(i) `2SO2 + O2 <==> 2SO3` (ii) `H2 + I2 <==> 2HI`
(iii) `PCl5 <==> PCl3 + Cl2` (iv) `CaCO3(s) <==> CaO(s) + CO2(g)`

**ANSWER:**
```
  (i)    dn  =  2 - (2 + 1)  =  -1        ->  Kp < Kc
  (ii)   dn  =  2 - (1 + 1)  =   0        ->  Kp = Kc
  (iii)  dn  =  (1 + 1) - 1  =  +1        ->  Kp > Kc
  (iv)   dn  =  1 - 0        =  +1        (SOLIDS ARE NOT COUNTED)
```

### Q A8
For a reaction Kc = 4.0 at 500 K. What is Kc for the reverse reaction and
for the reaction written with all coefficients doubled?

**ANSWER:**
```
  REVERSED       ->    K'  =  1 / K   =  1 / 4  =  0.25

  DOUBLED (n=2)  ->    K'' =  K ^ 2   =  4^2    =  16
```

## Topic: Reaction quotient and Gibbs energy

### Q A9
What is the reaction quotient Q? How does it predict the direction of a
reaction?

**ANSWER:**
```
  Q has the SAME form as K but uses the concentrations AT ANY INSTANT,
  not necessarily equilibrium ones.

      Q  <  K   ->  reaction proceeds FORWARD  (more products form)
      Q  =  K   ->  system is AT EQUILIBRIUM
      Q  >  K   ->  reaction proceeds BACKWARD (more reactants form)
```

---

### Q A10
Write the relation between the standard Gibbs energy change and the
equilibrium constant. What does a negative delta G mean?

**ANSWER:**
```
     delta G(std)  =  - R T ln K   =  - 2.303 R T log K

  A NEGATIVE delta G(std) means K > 1, so the products are favoured
  and the forward reaction is spontaneous.
```

## Topic: Le Chatelier's principle

### Q A11
State Le Chatelier's principle.

**ANSWER:**
```
  "If a system at equilibrium is subjected to a change in concentration,
   pressure or temperature, the equilibrium shifts in the direction that
   tends to NULLIFY the effect of that change."
```

---

### Q A12
What is the effect of a catalyst on the position of an equilibrium?

**ANSWER:**
```
  A catalyst has NO EFFECT on the position of equilibrium, on K, or on
  the yield.

  It lowers the activation energy of the forward AND the backward
  reaction by the SAME amount, so both rates increase equally and
  equilibrium is simply reached FASTER.
```

---

### Q A13
What happens to the equilibrium `N2 + 3H2 <==> 2NH3` when an inert gas
such as argon is added (a) at constant volume and (b) at constant pressure?

**ANSWER:**
```
  (a) CONSTANT VOLUME - NO SHIFT.
      The partial pressures and concentrations of N2, H2 and NH3 are
      unchanged, so Q is unchanged.

  (b) CONSTANT PRESSURE - the volume must expand, which dilutes all the
      gases. This acts like a pressure DECREASE, so the equilibrium
      shifts TOWARDS THE SIDE WITH MORE GAS MOLES, i.e. BACKWARD
      (towards N2 and H2).
```

---

### Q A14
The reaction `2SO2 + O2 <==> 2SO3` is exothermic. What is the effect of
(a) increasing the pressure and (b) increasing the temperature?

**ANSWER:**
```
  (a) 3 moles of gas  ->  2 moles of gas. Increasing pressure shifts the
      equilibrium FORWARD (to the side with fewer moles), so MORE SO3.

  (b) The forward reaction is EXOTHERMIC, so increasing the temperature
      shifts it BACKWARD. Yield of SO3 FALLS and Kp DECREASES.
```

### Q A21
Define pH. Calculate the pH of 0.001 M HCl.

**ANSWER:**
```
  pH  =  - log10 [ H+ ]      (the negative logarithm to base 10 of the
                              hydrogen ion concentration in mol/L)

  HCl is a STRONG acid, fully ionised:   [H+] = 0.001 = 10^-3 M

  pH  =  - log ( 10^-3 )  =  3
```

```
  pH   =  14  -  pOH  =  14 - 2  =  12
```

### Q B1
Derive the relation `Kp = Kc (RT)^dn`.

**ANSWER:**
```
  Consider the gaseous equilibrium

              a A  +  b B   <==>   c C  +  d D

                     p(C)^c  p(D)^d
  By definition  Kp = ---------------                 ... (1)
                     p(A)^a  p(B)^b

  For an ideal gas    P V = n R T

                       n
              P  =  ( --- ) R T   =   [ concentration ]  x  R T
                       V

  So      p(A) = [A] RT ,  p(B) = [B] RT ,  and so on.

  Substituting into (1):

              ( [C] RT )^c  ( [D] RT )^d
      Kp  =  -------------------------------
              ( [A] RT )^a  ( [B] RT )^b

              [C]^c [D]^d
          =  --------------  x  ( RT ) ^ ( c + d - a - b )
              [A]^a [B]^b

  The first factor is Kc, and putting  dn = (c + d) - (a + b) :

              +------------------------------+
              |     Kp   =   Kc  ( R T )^dn  |
              +------------------------------+

  CASES:   dn > 0 -> Kp > Kc      dn = 0 -> Kp = Kc      dn < 0 -> Kp < Kc
```

### Q B2
Write any four characteristics of the equilibrium constant.

**ANSWER:**
```
  1. K depends ONLY on TEMPERATURE. It does not depend on pressure,
     volume, catalyst, or the initial concentrations.

  2. If the reaction is REVERSED, the new constant is 1/K.
     If the equation is multiplied by n, the new constant is K^n.

  3. If two reactions are ADDED, their equilibrium constants MULTIPLY:
     K = K1 x K2.

  4. The MAGNITUDE of K tells you the extent of the reaction:
        K > 10^3   ->  products dominate, reaction nearly complete
        K < 10^-3  ->  reactants dominate, reaction hardly proceeds

  5. A catalyst does NOT change K.

  6. K has units (mol/L)^dn for Kc and (atm)^dn for Kp; it is
     dimensionless when dn = 0.
```

### Q B3
State Le Chatelier's principle and explain the effect of temperature and
pressure on the Haber process for the manufacture of ammonia.

**ANSWER:**
```
  STATEMENT: If a system at equilibrium is disturbed by a change in
  concentration, pressure or temperature, the equilibrium shifts in the
  direction that NULLIFIES the disturbance.

  HABER PROCESS:

        N2(g)  +  3 H2(g)   <==>   2 NH3(g)      dH = - 92.4 kJ

        4 moles of gas  -->  2 moles of gas    (dn = -2), EXOTHERMIC

  EFFECT OF PRESSURE
     The product side has FEWER gas moles. So INCREASING the pressure
     shifts the equilibrium FORWARD and increases the yield of NH3.
     Industry uses 200 - 300 atm.

  EFFECT OF TEMPERATURE
     The forward reaction is EXOTHERMIC. So a LOW temperature would give
     a higher equilibrium yield. But at low temperature the reaction is
     far too SLOW. Industry therefore compromises at 673 - 773 K.

  CATALYST
     Finely divided IRON with molybdenum as a promoter. It does NOT
     change the yield; it only makes equilibrium arrive faster.

  REMOVAL OF PRODUCT
     Ammonia is liquefied and removed continuously, which keeps pulling
     the equilibrium to the right.
```

### Q B4
Explain the conditions used in the Contact process using Le Chatelier's
principle.

**ANSWER:**
```
        2 SO2(g)  +  O2(g)   <==>   2 SO3(g)     dH = - 196 kJ

        3 moles of gas  -->  2 moles of gas   (dn = -1), EXOTHERMIC

  PRESSURE      Fewer moles on the right, so higher pressure favours
                SO3. But the yield is already about 97 % at ordinary
                pressure, so only 1 - 2 atm is used (cheaper).

  TEMPERATURE   Exothermic, so a low temperature favours SO3, but is
                too slow. A moderate 720 - 723 K (about 450 C) is used.

  CATALYST      V2O5 (vanadium pentoxide) speeds it up without changing
                the yield.

  EXCESS AIR    Excess O2 is a common reactant added in surplus; by
                Le Chatelier it pushes the equilibrium to the right.

  SO3 is then absorbed in H2SO4 to give oleum (H2S2O7), which is diluted
  to give H2SO4. SO3 is NOT put straight into water because that forms
  an uncondensable acid mist.
```

### Q B5
Derive Ostwald's dilution law for a weak acid.

**ANSWER:**
```
  Let a weak acid HA of concentration C have a degree of ionisation a.

                 HA      <==>    H+     +     A-
  Initial         C               0            0
  Ionised        C a             C a          C a
  At equilib   C ( 1 - a )       C a          C a

            [ H+ ] [ A- ]      ( C a )( C a )        C a^2
    Ka  =  ---------------  =  ---------------  =  ---------
               [ HA ]            C ( 1 - a )         1 - a

  For a WEAK acid  a << 1 , so ( 1 - a ) is nearly 1 :

            Ka  =  C a^2

                        Ka
            a  =  sqrt( ---- )      and since C = 1 / V ,
                         C

            a  =  sqrt ( Ka V )

  So the degree of ionisation is inversely proportional to the square
  root of the concentration - it INCREASES ON DILUTION.

  LIMITATION: fails for STRONG electrolytes, which are completely
  ionised and have strong inter-ionic attractions.
```

### Q B6
Explain the Bronsted-Lowry concept of acids and bases with examples.
What are conjugate acid-base pairs?

**ANSWER:**
```
  BRONSTED ACID  =  a substance that DONATES a proton (H+)
  BRONSTED BASE  =  a substance that ACCEPTS a proton

        HCl   +   H2O   <==>   H3O+    +   Cl-
        acid1     base2        acid2       base1

        NH3   +   H2O   <==>   NH4+    +   OH-
        base1     acid2        acid1       base2

  CONJUGATE PAIR: two species that differ by EXACTLY ONE PROTON.
        HCl / Cl-       H2O / OH-       H3O+ / H2O      NH4+ / NH3

  CONJUGATE ACID  =  base  +  H+
  CONJUGATE BASE  =  acid  -  H+

  RULE: the STRONGER the acid, the WEAKER its conjugate base.
        HCl is very strong, so Cl- is a very weak base.

  LIMITATION: cannot explain reactions in which no proton is transferred,
              such as  BF3 + NH3 --> BF3.NH3 .
```

### Q B7
Explain the Lewis concept of acids and bases with examples. Give its
limitations.

**ANSWER:**
```
  LEWIS ACID  =  ELECTRON PAIR ACCEPTOR
  LEWIS BASE  =  ELECTRON PAIR DONOR

  Neutralisation is the formation of a COORDINATE BOND:

        BF3    +   :NH3   -->   F3B <- NH3
      (acid)      (base)        adduct

        Ag+    +  2 :NH3  -->   [ Ag(NH3)2 ]+

  TYPES OF LEWIS ACID
     1. incomplete octet          BF3 , BCl3 , AlCl3 , BeCl2
     2. all simple cations        H+ , Ag+ , Cu2+ , Fe3+
     3. can expand their octet    SiF4 , PF5 , SF4
     4. multiple bond to an
        electronegative atom      CO2 , SO2 , SO3

  TYPES OF LEWIS BASE
     1. all anions                OH- , CN- , Cl-
     2. lone-pair molecules       NH3 , H2O , R-OH , R3N , CO
     3. pi-electron systems       ethene , benzene

  LIMITATIONS
     1. It does not explain the relative STRENGTHS of acids and bases.
     2. Ordinary protonic acids (HCl, H2SO4) do not accept electron
        pairs, yet are clearly acids.
     3. Lewis acid-base reactions are often slow, while true
        neutralisations are instantaneous.
```

### Q B8
What is a buffer solution? Explain the buffer action of an acidic buffer.

**ANSWER:**
```
  A BUFFER is a solution that resists a change in pH when a small amount
  of a strong acid or a strong base is added, or when it is diluted.

  ACIDIC BUFFER: a WEAK ACID + its SALT with a STRONG BASE.
       Example:  CH3COOH  +  CH3COONa

  The acid supplies a reservoir of CH3COOH; the salt (fully ionised)
  supplies a reservoir of CH3COO-.

  WHEN A STRONG ACID (H+) IS ADDED:

       CH3COO-  +  H+   -->   CH3COOH

       The acetate ions mop up the added H+ and convert it into
       un-ionised acetic acid, so [H+] hardly rises and pH is nearly
       unchanged.

  WHEN A STRONG BASE (OH-) IS ADDED:

       CH3COOH  +  OH-   -->   CH3COO-  +  H2O

       The reserve of acetic acid neutralises the added OH-, so [OH-]
       hardly rises and pH is nearly unchanged.

                            [ salt ]
       pH   =   pKa  +  log ----------      (Henderson-Hasselbalch)
                            [ acid ]
```

### Q B9
Explain the hydrolysis of salts. Discuss the four types with examples.

**ANSWER:**
```
  SALT HYDROLYSIS is the reaction of the cation or the anion of a salt
  with water to give an acidic or a basic solution. It is the reverse
  of neutralisation. Only the ion from the WEAK partner hydrolyses.

  1. STRONG ACID + STRONG BASE     e.g. NaCl , KNO3
     Neither ion hydrolyses.       ->  NEUTRAL , pH = 7

  2. WEAK ACID + STRONG BASE       e.g. CH3COONa
     CH3COO- + H2O <==> CH3COOH + OH-      (ANIONIC hydrolysis)
     OH- is produced               ->  BASIC , pH > 7 ,  Kh = Kw / Ka

  3. STRONG ACID + WEAK BASE       e.g. NH4Cl
     NH4+ + H2O <==> NH4OH + H+            (CATIONIC hydrolysis)
     H+ is produced                ->  ACIDIC , pH < 7 ,  Kh = Kw / Kb

  4. WEAK ACID + WEAK BASE         e.g. CH3COONH4
     CH3COO- + NH4+ + H2O <==> CH3COOH + NH4OH
     BOTH ions hydrolyse.  Kh = Kw / ( Ka Kb )
         Ka > Kb  ->  acidic       Ka < Kb  ->  basic
         Ka = Kb  ->  neutral

  MEMORY LINE:  "the STRONGER partner decides the nature."
```

### Q B10
Derive the relation between solubility and solubility product for a salt

```

        Mg(OH)2  <==>  Mg2+  +  2 OH-

        Ksp  =  4 s^3   =   1.2 x 10^-11

               1.2 x 10^-11
        s^3 = --------------- = 3.0 x 10^-12  =  3000 x 10^-15
```

### Q B20
Explain the effect of adding an inert gas on a gaseous equilibrium
(a) at constant volume and (b) at constant pressure.

**ANSWER:**
```
  (a) AT CONSTANT VOLUME
      Adding argon raises the TOTAL pressure but the number of moles of
      each reacting gas and the volume are unchanged, so every PARTIAL
      PRESSURE and every CONCENTRATION stays the same.
      Q is unchanged, so Q still equals K.
      ->  NO SHIFT WHATSOEVER.

  (b) AT CONSTANT PRESSURE
      To keep the total pressure fixed while extra gas is added, the
      VOLUME must increase. This dilutes all the reacting gases, which
      is equivalent to lowering the pressure.
      ->  The equilibrium SHIFTS TOWARDS THE SIDE WITH MORE GAS MOLES.
      ->  If dn = 0 there is still no shift.

  Example:  for N2 + 3H2 <==> 2NH3 (4 moles -> 2 moles), adding argon
  at constant pressure shifts the equilibrium BACKWARD, decreasing the
  yield of ammonia. That is why inert gases are removed in the Haber
  process.
```

### Q C1
State Le Chatelier's principle. Discuss the effect of concentration,
pressure, temperature, inert gas and catalyst on a chemical equilibrium.
Apply it to the manufacture of ammonia by the Haber process.

**MODEL ANSWER — mark split shown**

```
  (1) STATEMENT                                                  [1 mark]

      "If a system at equilibrium is subjected to a change in
       concentration, pressure or temperature, the equilibrium shifts in
       the direction that tends to NULLIFY the effect of that change."

  (2) EFFECT OF CONCENTRATION                                     [1 mark]

      Adding a REACTANT  ->  equilibrium shifts FORWARD.
      Adding a PRODUCT   ->  equilibrium shifts BACKWARD.
      Removing a PRODUCT ->  equilibrium shifts FORWARD.
      K is UNCHANGED; only the position moves.

  (3) EFFECT OF PRESSURE / VOLUME                                 [1.5 marks]

      Applies only to GASES.
      Increasing pressure (decreasing volume) shifts the equilibrium to
      the side with the SMALLER number of gas moles.
      Decreasing pressure shifts it to the side with MORE gas moles.
      If dn = 0 (equal moles both sides), pressure has NO effect.

          N2 + 3H2 <==> 2NH3     (4 -> 2)   high P favours NH3
          H2 + I2  <==> 2HI      (2 -> 2)   pressure has NO effect

  (4) EFFECT OF TEMPERATURE                                       [1.5 marks]

      Treat heat as a reactant or product.
      EXOTHERMIC  (dH < 0): raising T shifts BACKWARD , K DECREASES.
      ENDOTHERMIC (dH > 0): raising T shifts FORWARD  , K INCREASES.
      TEMPERATURE IS THE ONLY FACTOR THAT CHANGES THE VALUE OF K.

  (5) EFFECT OF INERT GAS                                         [1 mark]

      At CONSTANT VOLUME  -> partial pressures unchanged -> NO SHIFT.
      At CONSTANT PRESSURE -> the volume expands, everything is diluted
      -> shifts towards the side with MORE gas moles.

  (6) EFFECT OF CATALYST                                          [1 mark]

      Lowers the activation energy of the forward and backward reactions
      EQUALLY. Both rates rise equally, so the POSITION of equilibrium
      and the value of K are UNCHANGED. Equilibrium is only reached
      FASTER.

  (7) APPLICATION - THE HABER PROCESS                             [1 mark]

          N2(g)  +  3 H2(g)  <==>  2 NH3(g)     dH = -92.4 kJ

          dn = -2 (fewer moles on the right) and EXOTHERMIC.

          PRESSURE     high pressure favours NH3  ->  200-300 atm
          TEMPERATURE  low T favours NH3 but is too slow; a compromise
                       of 673-773 K is used
          CATALYST     finely divided Fe with Mo as promoter (speed only)
          PRODUCT      NH3 is liquefied and removed continuously
          INERT GAS    removed, because at constant pressure it would
                       shift the equilibrium backward
```

### Q C2
Explain the Arrhenius, Bronsted-Lowry and Lewis concepts of acids and
bases, with examples and the limitations of each.

**MODEL ANSWER**

```
  (A) ARRHENIUS CONCEPT (1884)                              [2.5 marks]

      ACID - a substance that gives H+ ions in aqueous solution.
      BASE - a substance that gives OH- ions in aqueous solution.

           HCl  --(water)-->  H+  +  Cl-             ACID
           NaOH --(water)-->  Na+ +  OH-             BASE

      Neutralisation:   H+  +  OH-  -->  H2O

      LIMITATIONS
        1. Applies only to AQUEOUS solutions.
        2. Cannot explain the basic nature of NH3 (no OH- group).
        3. Cannot explain the acidic nature of CO2 or AlCl3 (no H+).
        4. Fails in non-aqueous solvents such as liquid NH3, benzene.
        5. A free proton cannot exist in water; it is really H3O+.

  (B) BRONSTED-LOWRY CONCEPT (1923)                          [3 marks]

      ACID - a PROTON DONOR.
      BASE - a PROTON ACCEPTOR.

           HCl  +  H2O  <==>  H3O+  +  Cl-
           acid1   base2      acid2    base1

           NH3  +  H2O  <==>  NH4+  +  OH-
           base1   acid2      acid1    base2

      CONJUGATE ACID-BASE PAIRS differ by exactly ONE PROTON:
           HCl / Cl-      H2O / OH-      NH4+ / NH3     H3O+ / H2O

      Conjugate acid = base + H+ ;  conjugate base = acid - H+.
      The stronger the acid, the weaker its conjugate base.

      Water is AMPHOTERIC - a base with HCl, an acid with NH3.

      LIMITATION
        Cannot explain acid-base reactions in which NO proton is
        involved, e.g.  BF3 + NH3 --> BF3.NH3 , or AlCl3 acting as
        an acid.

  (C) LEWIS CONCEPT (1923)                                   [2.5 marks]

      ACID - an ELECTRON PAIR ACCEPTOR.
      BASE - an ELECTRON PAIR DONOR.
      Neutralisation = formation of a COORDINATE BOND.

              F              H            F   H
              |              |            |   |
         F -- B   +    : N - H   -->   F--B<--N--H
              |              |            |   |
              F              H            F   H

      LEWIS ACIDS:  incomplete octet  (BF3, AlCl3, BeCl2)
                    all cations       (H+, Ag+, Fe3+)
                    expandable octet  (SiF4, PF5)
                    multiple bonds    (CO2, SO2, SO3)

      LEWIS BASES:  all anions        (OH-, CN-, Cl-)
                    lone-pair species (NH3, H2O, R-OH, CO)
                    pi systems        (ethene, benzene)

      LIMITATIONS
        1. Does not explain the relative STRENGTH of acids and bases.
        2. Protonic acids like HCl do not accept electron pairs, yet
           are certainly acids.
        3. Lewis acid-base reactions are often slow, whereas real
           neutralisations are instantaneous.

  CONCLUDING TABLE (worth drawing)

    +--------------+----------------+----------------+---------------+
    | CONCEPT      | ACID           | BASE           | SCOPE         |
    +--------------+----------------+----------------+---------------+
    | Arrhenius    | gives H+       | gives OH-      | water only    |
    | Bronsted     | proton donor   | proton acceptor| protic systems|
    | Lewis        | e- pair        | e- pair donor  | widest of all |
    |              | acceptor       |                |               |
    +--------------+----------------+----------------+---------------+
```

### Q C3
State the law of mass action and derive the expression for the
equilibrium constant. Derive `Kp = Kc (RT)^dn`. Discuss the units and the
significance of the magnitude of K.

**MODEL ANSWER**

```
  (1) LAW OF MASS ACTION                                     [1.5 marks]

      "At a given temperature, the rate of a chemical reaction is
       directly proportional to the product of the ACTIVE MASSES of the
       reactants, each raised to the power of its stoichiometric
       coefficient."   Active mass = molar concentration.

  (2) DERIVATION OF Kc                                        [2 marks]

      For       a A  +  b B   <==>   c C  +  d D

      Forward rate    Rf  =  kf [A]^a [B]^b
      Backward rate   Rb  =  kb [C]^c [D]^d

      At equilibrium  Rf = Rb :

          kf [A]^a [B]^b   =   kb [C]^c [D]^d

           kf          [C]^c [D]^d
          ----   =   --------------   =   Kc
           kb          [A]^a [B]^b

  (3) DERIVATION OF Kp = Kc (RT)^dn                           [2.5 marks]

      For gases,  Kp = p(C)^c p(D)^d / ( p(A)^a p(B)^b )

      From  PV = nRT ,   p = ( n / V ) RT = [ concentration ] RT

              ( [C] RT )^c ( [D] RT )^d
      Kp  =  -----------------------------
              ( [A] RT )^a ( [B] RT )^b

              [C]^c [D]^d
          =  --------------  ( RT ) ^ ( c + d - a - b )
              [A]^a [B]^b

          =  Kc ( RT ) ^ dn ,  where dn = gaseous products - gaseous
                               reactants

  (4) UNITS OF K                                              [1 mark]

      Units of Kc = ( mol L^-1 ) ^ dn
      Units of Kp = ( atm ) ^ dn
      When dn = 0 , K is dimensionless.

  (5) SIGNIFICANCE OF THE MAGNITUDE OF K                      [1 mark]

      K > 10^3    -> products dominate; reaction nearly complete
      10^-3 < K < 10^3 -> comparable amounts of both
      K < 10^-3   -> reactants dominate; reaction hardly proceeds

      Examples:  2H2 + O2 <==> 2H2O   K = 2.4 x 10^47   (goes right)
                 N2  + O2 <==> 2NO    K = 4.8 x 10^-31  (barely goes)

  (6) CHARACTERISTICS OF K                                    [1 mark]

      Depends only on TEMPERATURE.
      Reversing the reaction gives 1/K ; multiplying by n gives K^n ;
      adding two reactions multiplies their constants.
      A catalyst does not change K.
```
