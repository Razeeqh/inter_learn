## Topic: Octet rule and Lewis structures

### Q A1
State the octet rule. Give two of its limitations.

**ANSWER:**
```
  OCTET RULE - atoms gain, lose or share electrons so that each atom
  attains EIGHT electrons in its outermost (valence) shell, giving it
  the stable configuration of a noble gas.

  LIMITATIONS (any two):
     1. INCOMPLETE octet   -  BeCl2 (4 e-) , BF3 (6 e-)
     2. EXPANDED octet     -  PCl5 (10 e-) , SF6 (12 e-)
     3. ODD-electron       -  NO (11 e-) , NO2 (17 e-)
     4. It says nothing about the SHAPE or the ENERGY of the molecule.
```

### Q A3
Define formal charge. Calculate the formal charge on each oxygen in ozone O3.

**ANSWER:**
```
  FORMAL CHARGE  =  V  -  L  -  B/2

  where V = valence electrons of the free atom
        L = lone-pair electrons
        B = bonding electrons

  For O3   O(1) - O(2) = O(3)

     Central O(2)  :  6 - 2 - 6/2  =  +1
     Singly bonded O(1) :  6 - 6 - 2/2  =  -1
     Doubly bonded O(3) :  6 - 4 - 4/2  =   0

     Sum = 0 , which matches the neutral molecule.
```

### Q A5
Define bond order. What is the bond order of N2, O2 and F2?

**ANSWER:**
```
  BOND ORDER - the number of covalent bonds (shared electron pairs)
  present between two atoms in a molecule.

  In MOT:      B.O.  =  ( Nb  -  Na ) / 2

     N2  ->  ( 10 - 4 ) / 2  =  3
     O2  ->  ( 10 - 6 ) / 2  =  2
     F2  ->  ( 10 - 8 ) / 2  =  1
```

### Q A6
What is resonance? Give one example.

**ANSWER:**
```
  RESONANCE - when a single Lewis structure cannot describe a molecule
  properly, the molecule is represented by TWO OR MORE structures that
  differ only in the position of ELECTRONS. The real molecule is the
  RESONANCE HYBRID of them all.

  Example - ozone O3 :

        O                   O
       / \\      <->      // \
      O    O             O    O

  Both O-O bonds are actually equal (128 pm), bond order 1.5.
```

### Q A7
Why are all the C-O bond lengths in the carbonate ion CO3 2- equal?

**ANSWER:**
```
  Because of RESONANCE. The carbonate ion has three equivalent resonance
  structures. The double bond is not fixed on one oxygen; it is
  DELOCALISED over all three C-O positions.

  Each bond therefore has the same character:

       bond order  =  4 bonds / 3 positions  =  1.33

  and all three bond lengths are identical (129 pm).
```

### Q A8
Define bond enthalpy and bond length. How are they related to bond order?

**ANSWER:**
```
  BOND ENTHALPY - the energy required to break ONE MOLE of bonds of a
  particular type in the gaseous state. Unit kJ/mol.

  BOND LENGTH - the equilibrium distance between the nuclei of two
  bonded atoms. Unit pm or angstrom.

  RELATION:   bond order UP  ->  bond length DOWN  ->  bond enthalpy UP

  Example:  C-C 154 pm  >  C=C 134 pm  >  C#C 120 pm
```

## Topic: Polarity and dipole moment

### Q A9
Define dipole moment. Give its unit.

**ANSWER:**
```
  DIPOLE MOMENT - the product of the magnitude of the separated charge
  and the distance between the two charges.

        mu  =  q  x  d

  It is a VECTOR quantity, directed from the positive to the negative end.

  UNIT:  debye (D)      1 D  =  3.336 x 10^-30  C m
```

### Q A10
Although the B-F bond is polar, BF3 has zero dipole moment. Explain.

**ANSWER:**
```
  BF3 is TRIGONAL PLANAR (sp2 hybridised) with all F-B-F angles of 120
  degrees, and boron carries NO lone pair.

              F
              |
              B
             / \
            F   F

  The three B-F bond dipoles are equal in size and arranged
  symmetrically at 120 degrees, so their VECTOR SUM is ZERO.

  Hence BF3 is a NON-POLAR molecule with polar bonds.
```

### Q A11
Why is CO2 non-polar while H2O is polar, although both have two polar bonds?

**ANSWER:**
```
  CO2 :  O = C = O        LINEAR , angle 180
         The two C=O dipoles are equal and exactly opposite,
         so they CANCEL.        mu = 0     NON-POLAR

  H2O :        O          BENT , angle 104.5 (two lone pairs on O)
              / \
             H   H
         The two O-H dipoles do NOT cancel; they add to a resultant.
                                mu = 1.85 D    POLAR
```

### Q A12
The dipole moment of NH3 (1.47 D) is greater than that of NF3 (0.24 D).
Give the reason.

**ANSWER:**
```
  Both are pyramidal with one lone pair on nitrogen.

  NH3 : N is MORE electronegative than H, so the bond dipoles point
        TOWARDS N, the same direction as the lone-pair dipole.
        They ADD  ->  large dipole moment.

  NF3 : F is MORE electronegative than N, so the bond dipoles point
        AWAY from N, OPPOSITE to the lone-pair dipole.
        They partly CANCEL  ->  small dipole moment.
```

### Q A13
What is the shape of NH3 and what is its bond angle? Why is the angle
less than 109.5 degrees?

**ANSWER:**
```
  NH3 has 3 bond pairs and 1 LONE PAIR (4 electron pairs in all), so
  the electron geometry is TETRAHEDRAL but the SHAPE is
  TRIGONAL PYRAMIDAL.

  Bond angle  =  107 degrees.

  REASON: lone pair - bond pair repulsion is STRONGER than bond pair -
  bond pair repulsion, so the lone pair pushes the three N-H bonds
  closer together, reducing 109.5 to 107 degrees.
```

## Topic: MOT and hydrogen bonding

### Q A16
Why does He2 not exist while H2 does?

**ANSWER:**
```
  H2  :  sigma1s2                 Nb = 2 , Na = 0
         B.O. = (2 - 0)/2 = 1     ->  a stable bond, H2 EXISTS

  He2 :  sigma1s2 sigma*1s2       Nb = 2 , Na = 2
         B.O. = (2 - 2)/2 = 0     ->  the antibonding electrons cancel
                                      the bonding ones completely,
                                      so He2 DOES NOT EXIST.
```

### Q A17
Explain why O2 is paramagnetic on the basis of molecular orbital theory.

**ANSWER:**
```
  O2 has 16 electrons. Its MO configuration is

     sigma1s2 sigma*1s2 sigma2s2 sigma*2s2 sigma2pz2
              ( pi2px2 = pi2py2 ) ( pi*2px1 = pi*2py1 )

  The last two electrons occupy the two DEGENERATE pi* orbitals
  SINGLY with parallel spins (Hund's rule).

  Two UNPAIRED electrons  ->  O2 is PARAMAGNETIC.
```

### Q A18
What is hydrogen bonding? Name its two types.

**ANSWER:**
```
  HYDROGEN BOND - the electrostatic attraction between a hydrogen atom
  covalently bonded to a small highly electronegative atom (F, O or N)
  and a lone pair on another such atom.

        O - H  . . . .  O - H

  TYPES:
     1. INTERMOLECULAR - between different molecules (H2O, HF, alcohols)
     2. INTRAMOLECULAR - within the same molecule (o-nitrophenol)
```

### Q A19
Why does water have a much higher boiling point than H2S?

**ANSWER:**
```
  In water, oxygen is small and highly electronegative, so strong
  INTERMOLECULAR HYDROGEN BONDS link the molecules into large clusters.
  Extra energy is needed to break these bonds, so the boiling point is
  high (373 K).

  Sulphur is much larger and far less electronegative, so H2S has NO
  hydrogen bonding - only weak van der Waals forces. It boils at 213 K
  and is a gas at room temperature.
```

State Fajans' rules.

**ANSWER:**

  Covalent character in an ionic compound INCREASES when:

     1. the CATION is SMALL
     2. the ANION is LARGE
     3. the CHARGE on either ion is HIGH
     4. the cation has a PSEUDO NOBLE-GAS (18-electron) configuration

```

### Q B1
Explain the formation of an ionic bond with NaCl as the example, and give
the factors that favour ionic bond formation.

**ANSWER:**
```
  FORMATION

     Na  (2,8,1)  ->  Na+  (2,8)     +  e-      loses 1 electron
     Cl  (2,8,7)  +  e-  ->  Cl-  (2,8,8)       gains 1 electron

     Na .  +  : Cl :     ->     Na+  [ : Cl : ]-
                . .                      . .

     The oppositely charged ions are held by strong ELECTROSTATIC
     attraction. In the solid, this repeats in three dimensions to give
     a giant IONIC LATTICE - each Na+ surrounded by 6 Cl- and vice versa.

  FACTORS FAVOURING IONIC BOND FORMATION

     1. LOW ionisation enthalpy of the metal
           - the metal must give up its electron easily (Group 1, 2)

     2. HIGH negative electron gain enthalpy of the non-metal
           - the non-metal must want the electron badly (halogens, O)

     3. HIGH lattice enthalpy of the product
           - small, highly charged ions give a very stable lattice, and
             this released energy pays for the ionisation step

     4. LARGE electronegativity difference (about 1.7 or more)
```

### Q B2
Explain the terms lattice enthalpy and Born-Haber cycle.

**ANSWER:**
```
  LATTICE ENTHALPY - the energy required to completely separate ONE MOLE
  of a solid ionic compound into its gaseous ions.

        NaCl (s)  ->  Na+ (g)  +  Cl- (g)      dH = + 788 kJ/mol

  It cannot be measured directly, so the BORN-HABER CYCLE is used.
  It applies Hess's law: since enthalpy is a state function, the direct
  route and the indirect route must give the same total.

        Na (s) + 1/2 Cl2 (g)  --- dH(formation) --->  NaCl (s)
           |                                              ^
           |  S  (sublimation)                            |
           v                                              |  U (lattice)
        Na (g)                                            |
           |  IE (ionisation)                             |
           v                                              |
        Na+ (g)   +   Cl- (g)  <---- EA ---- Cl (g) <--- 1/2 D
                                                       (dissociation)

        dH(formation)  =  S  +  IE  +  (1/2) D  +  EA  +  U

  Everything except U can be measured, so U is obtained by difference.
  A large lattice enthalpy means a hard, high-melting, stable solid.
```

### Q B3
Write the resonance structures of the carbonate ion and of ozone, and
explain the meaning of resonance energy.

**ANSWER:**
```
  CARBONATE ION  CO3 2-   (three equivalent structures)

      : O :            : O :             : O
        ||               |                 |
        C        <->     C         <->     C
       /  \             / \\              // \
    : O    O :       : O    O :        : O    O :

     Real bond order of each C-O bond = 4 / 3 = 1.33
     All three bonds equal (129 pm).


  OZONE  O3   (two equivalent structures)

        O                    O
       / \\      <->       // \
      O    O              O    O

     Real bond order = 3 / 2 = 1.5 , both bonds 128 pm.


  RESONANCE ENERGY

     = ( energy of the actual molecule )
        - ( energy of the most stable single contributing structure )

     It is the EXTRA STABILITY the molecule gains because the electrons
     are delocalised over a larger region. Benzene's resonance energy is
     about 150 kJ/mol, which is why it resists addition reactions.

  CONDITIONS: the atoms must stay in the SAME positions, only electrons
  move; all structures must have the same number of electrons.
```

### Q B4
State the postulates of VSEPR theory.

**ANSWER:**
```
  1. The shape of a molecule depends on the number of VALENCE SHELL
     ELECTRON PAIRS (bonding and non-bonding) around the central atom.

  2. Electron pairs repel one another and therefore arrange themselves
     as FAR APART as possible, minimising repulsion.

  3. The valence shell is treated as a sphere, and the pairs sit on its
     surface at points of maximum separation.

  4. A LONE PAIR occupies MORE space than a bond pair, because it is
     under the influence of only ONE nucleus.

  5. The order of repulsion is

           lone pair - lone pair  >  lone pair - bond pair
                                  >  bond pair - bond pair

  6. A multiple bond is treated as a SINGLE electron pair for shape,
     though it repels slightly more than a single bond.

  7. If the central atom is bonded to atoms of different
     electronegativity, the bond angles change accordingly.
```

### Q B5
Predict the shapes of CH4, NH3 and H2O using VSEPR theory and explain
the decreasing order of their bond angles.

**ANSWER:**
```
  All three have FOUR electron pairs around the central atom, so all are
  based on a TETRAHEDRAL arrangement.

  +---------+-----+-----+----------------------+------------+
  | MOLECULE| bp  | lp  | SHAPE                | BOND ANGLE |
  +---------+-----+-----+----------------------+------------+
  |  CH4    |  4  |  0  | Tetrahedral          |   109.5    |
  |  NH3    |  3  |  1  | Trigonal pyramidal   |   107.0    |
  |  H2O    |  2  |  2  | Bent / angular       |   104.5    |
  +---------+-----+-----+----------------------+------------+

           H              : :                : :  : :
           |               N                    O
           C             / | \                 / \
         / | \          H  H  H               H   H
        H  H  H

     109.5             107.0                 104.5

  EXPLANATION
     A lone pair spreads out more than a bond pair because it is held by
     only one nucleus. So

          lp-lp  >  lp-bp  >  bp-bp

     CH4 has no lone pair, so the perfect tetrahedral 109.5 survives.
     NH3 has ONE lone pair, which pushes the three N-H bonds together
     ->  107 degrees.
     H2O has TWO lone pairs, pushing even harder  ->  104.5 degrees.
```

### Q B6
Distinguish between a sigma bond and a pi bond.

**ANSWER:**
```
  +---------------------------------+---------------------------------+
  |  SIGMA BOND                     |  PI BOND                        |
  +---------------------------------+---------------------------------+
  |  Formed by HEAD-ON (axial)      |  Formed by SIDEWAYS (lateral)   |
  |  overlap of orbitals            |  overlap of p orbitals          |
  +---------------------------------+---------------------------------+
  |  Overlap is LARGE, so the bond  |  Overlap is SMALL, so the bond  |
  |  is STRONGER                    |  is WEAKER                      |
  +---------------------------------+---------------------------------+
  |  Electron cloud is symmetrical  |  Electron cloud lies ABOVE and  |
  |  about the internuclear axis    |  BELOW the internuclear axis    |
  +---------------------------------+---------------------------------+
  |  FREE ROTATION is possible      |  NO free rotation               |
  +---------------------------------+---------------------------------+
  |  Can exist INDEPENDENTLY        |  Exists only ALONG WITH a       |
  |                                 |  sigma bond                     |
  +---------------------------------+---------------------------------+
  |  s-s , s-p , p-p overlaps       |  p-p , p-d overlaps only        |
  +---------------------------------+---------------------------------+

  Single bond = 1 sigma
  Double bond = 1 sigma + 1 pi
  Triple bond = 1 sigma + 2 pi
```

### Q B7
Explain sp, sp2 and sp3 hybridisation with one example each.

**ANSWER:**
```
  sp HYBRIDISATION
     One s + one p orbital mix to give TWO sp hybrid orbitals at
     180 degrees.  Shape: LINEAR.  50 % s character.
        Example: BeCl2       Cl ---- Be ---- Cl     (180 degrees)
        Also C2H2 : each carbon is sp, giving  H-C#C-H

  sp2 HYBRIDISATION
     One s + two p orbitals mix to give THREE sp2 hybrids in a plane at
     120 degrees.  Shape: TRIGONAL PLANAR.  33 % s character.
        Example: BF3                F
                                    |
                                    B          (all angles 120)
                                   / \
                                  F   F
        Also C2H4 : each carbon sp2, one unhybridised p forms the pi bond.

  sp3 HYBRIDISATION
     One s + three p orbitals mix to give FOUR sp3 hybrids pointing to
     the corners of a tetrahedron at 109.5 degrees.  25 % s character.
        Example: CH4                H
                                    |
                                    C          (109.5 degrees)
                                  / | \
                                 H  H  H
        Also NH3 and H2O are sp3, but lone pairs distort the angle.
```

Calculate the bond order of O2, O2+, O2- and O2 2- and arrange them in

### Q B9
Explain intermolecular and intramolecular hydrogen bonding with examples,
and state their effects.

**ANSWER:**
```
  INTERMOLECULAR HYDROGEN BONDING
     Occurs BETWEEN two or more separate molecules. The molecules become
     linked into large associated clusters.

           H              H              H
            \              \              \
             O ---- H . . . O ---- H . . . O ---- H

     Examples: H2O , HF , NH3 , alcohols , carboxylic acids ,
               p-nitrophenol
     Effects:  RAISES boiling point and melting point
               INCREASES solubility in water
               increases viscosity

  INTRAMOLECULAR HYDROGEN BONDING
     Occurs WITHIN the SAME molecule, closing a ring. The molecules
     remain separate from one another.

           O - H
          /     :
         C       :          o-nitrophenol
        / \      :
       C   C -- N
            \  // \\
             O     O

     Examples: o-nitrophenol , salicylaldehyde , o-hydroxybenzoic acid
     Effects:  LOWERS boiling point (compared with the para isomer)
               DECREASES solubility in water
               increases volatility (o-nitrophenol is steam volatile)
```

### Q B10
Explain the metallic bond using the electron-sea model and state the
properties it explains.

**ANSWER:**
```
  ELECTRON-SEA MODEL

     Metal atoms lose their loosely held valence electrons, leaving
     positively charged KERNELS arranged in a regular lattice. The freed
     electrons are DELOCALISED and move freely through the whole crystal.

        e-        e-         e-
           (+)       (+)        (+)
        e-        e-         e-
           (+)       (+)        (+)

     "Positive kernels immersed in a sea of mobile electrons."

  PROPERTIES EXPLAINED

     ELECTRICAL CONDUCTIVITY - free electrons drift under a potential
     THERMAL CONDUCTIVITY    - free electrons carry kinetic energy fast
     METALLIC LUSTRE         - free electrons absorb and re-emit light
     MALLEABILITY & DUCTILITY- layers of kernels slide over one another
                               without breaking the bond, since the
                               electron sea simply flows with them
     HIGH MELTING POINT      - strong kernel-electron attraction

  Metallic bond strength increases with MORE valence electrons per atom
  and SMALLER kernel size:   Na  <  Mg  <  Al
```

### Q B12
State Fajans' rules and use them to explain why LiCl is more covalent
than NaCl, and why AlCl3 is more covalent than MgCl2.

**ANSWER:**
```
  FAJANS' RULES - covalent character in an ionic compound increases when

     1. the CATION is SMALL          (greater polarising power)
     2. the ANION is LARGE           (more easily polarised)
     3. the CHARGE on either ion is HIGH
     4. the cation has a PSEUDO NOBLE-GAS 18-electron configuration

  APPLICATION 1 :  LiCl  versus  NaCl
     Li+ (76 pm) is much smaller than Na+ (102 pm). With the same charge,
     the smaller cation has greater CHARGE DENSITY and distorts the Cl-
     electron cloud more strongly. So LiCl has MORE covalent character
     and a lower melting point than NaCl.

  APPLICATION 2 :  AlCl3  versus  MgCl2
     Al3+ carries a higher charge and is smaller than Mg2+, so its
     polarising power is much greater. AlCl3 is therefore largely
     COVALENT - it is a low-melting solid soluble in organic solvents,
     while MgCl2 is a typical high-melting ionic solid.

  Order of covalent character:   NaCl  <  MgCl2  <  AlCl3
```

### Q B14
Give reasons: (a) H2O is a liquid but H2S is a gas.
(b) Ice floats on water. (c) o-nitrophenol is steam volatile but
p-nitrophenol is not. (d) HF has a higher boiling point than HCl.

**ANSWER:**
```
  (a) Oxygen is small and highly electronegative, so water molecules are
      linked by strong INTERMOLECULAR HYDROGEN BONDS. Sulphur is large
      and much less electronegative, so H2S has no hydrogen bonding -
      only weak van der Waals forces. Hence H2O is a liquid (373 K) and
      H2S a gas (213 K).

  (b) In ICE each water molecule is hydrogen bonded to four others in an
      OPEN CAGE-LIKE structure containing large empty spaces. This makes
      ice LESS DENSE than liquid water, so it floats.

  (c) o-nitrophenol has INTRAmolecular hydrogen bonding, which closes a
      ring inside the molecule and leaves the molecules unassociated ->
      low boiling point, steam volatile.
      p-nitrophenol has INTERmolecular hydrogen bonding, so its molecules
      are associated -> high boiling point, not steam volatile.

  (d) Fluorine is the most electronegative element, so HF forms strong
      intermolecular hydrogen bonds and exists as associated clusters.
      Chlorine is larger and less electronegative, so HCl has no hydrogen
      bonding. Hence HF boils at 293 K while HCl boils at 188 K.
```

### Q C1  *** MOST FREQUENTLY ASKED ***
State the postulates of VSEPR theory. Predict and explain the shapes of
BeCl2, BF3, CH4, PCl5, SF6, NH3 and H2O on its basis.

**MODEL ANSWER (with the mark split shown)**

```
  ------------------------------------------------------  [ 3 MARKS ]
  PART 1 - POSTULATES OF VSEPR THEORY
  ------------------------------------------------------

   1. The shape of a molecule depends on the number of valence-shell
      electron pairs (bonding + non-bonding) around the central atom.

   2. Electron pairs repel one another and arrange themselves as far
      apart as possible so that the repulsion is minimum.

   3. The valence shell is treated as a sphere; the pairs occupy
      positions of maximum separation on its surface.

   4. A LONE PAIR occupies more space than a bond pair because it is
      influenced by only ONE nucleus.

   5. Repulsion order:
            lp - lp   >   lp - bp   >   bp - bp

   6. A multiple bond is counted as ONE electron pair for shape
      purposes, but repels slightly more than a single bond.

   7. Bond angles are also affected by the electronegativity of the
      surrounding atoms.


  ------------------------------------------------------  [ 3 MARKS ]
  PART 2 - MOLECULES WITH NO LONE PAIRS
  ------------------------------------------------------

  +--------+-----+-----+--------------------------+-------------+
  |MOLECULE| bp  | lp  |  SHAPE                   | BOND ANGLE  |
  +--------+-----+-----+--------------------------+-------------+
  | BeCl2  |  2  |  0  | Linear                   |   180       |
  | BF3    |  3  |  0  | Trigonal planar          |   120       |
  | CH4    |  4  |  0  | Tetrahedral              |   109.5     |
  | PCl5   |  5  |  0  | Trigonal bipyramidal     |  90 and 120 |
  | SF6    |  6  |  0  | Octahedral               |    90       |
  +--------+-----+-----+--------------------------+-------------+

     Cl -- Be -- Cl            F                    H
                               |                    |
      180 degrees              B                    C
                              / \                 / | \
                             F   F               H  H  H
                           120 degrees         109.5 degrees


           Cl                          F   F
            |                           \  |
       Cl   |                            \ |
         \  |                       F ---- S ---- F
          \ |                              /|
           P ---- Cl                      / |
          / |                            F  F
        Cl  |
            Cl                        all 90 degrees
      90 and 120 degrees


  ------------------------------------------------------  [ 2 MARKS ]
  PART 3 - MOLECULES WITH LONE PAIRS
  ------------------------------------------------------

  +--------+-----+-----+--------------------------+-------------+
  |MOLECULE| bp  | lp  |  SHAPE                   | BOND ANGLE  |
  +--------+-----+-----+--------------------------+-------------+
  | NH3    |  3  |  1  | Trigonal pyramidal       |   107       |
  | H2O    |  2  |  2  | Bent (angular)           |   104.5     |
  +--------+-----+-----+--------------------------+-------------+

              : :                     : :  : :
               N                         O
             / | \                      / \
            H  H  H                    H   H
             107                       104.5

  Both are based on the tetrahedral arrangement of four electron pairs.
  Because lone-pair repulsion is stronger than bond-pair repulsion, the
  bond angle falls from 109.5 (CH4) to 107 (NH3, one lone pair) to
  104.5 (H2O, two lone pairs).
```

### Q C2  *** ASKED VERY OFTEN ***
What is hybridisation? Explain sp, sp2, sp3, sp3d and sp3d2 hybridisation
with the shape, bond angle and one example of each.

**MODEL ANSWER (with the mark split shown)**

```
  ------------------------------------------------------  [ 2 MARKS ]
  DEFINITION AND FEATURES
  ------------------------------------------------------

  HYBRIDISATION is the intermixing of atomic orbitals of slightly
  different energies belonging to the SAME atom, producing a NEW set of
  orbitals that are EQUAL in energy, IDENTICAL in shape and oriented in
  definite directions in space. These are called HYBRID ORBITALS.

  CHARACTERISTICS
     - the number of hybrid orbitals formed = the number of atomic
       orbitals mixed
     - hybrid orbitals are always equivalent in energy and shape
     - they are more directional than pure orbitals, so they overlap
       better and form STRONGER bonds
     - only orbitals of nearly the same energy can hybridise
     - hybrid orbitals arrange themselves at maximum separation, which
       fixes the shape of the molecule


  ------------------------------------------------------  [ 5 MARKS ]
  THE FIVE TYPES  (1 mark each)
  ------------------------------------------------------

  +---------+------------+-------+---------------------+------------+
  | TYPE    | ORBITALS   | HYBR- | SHAPE               | BOND ANGLE |
  |         | MIXED      | IDS   |                     |            |
  +---------+------------+-------+---------------------+------------+
  | sp      | s + p      |   2   | Linear              | 180        |
  | sp2     | s + 2p     |   3   | Trigonal planar     | 120        |
  | sp3     | s + 3p     |   4   | Tetrahedral         | 109.5      |
  | sp3d    | s + 3p + d |   5   | Trigonal bipyramidal| 90 and 120 |
  | sp3d2   | s + 3p +2d |   6   | Octahedral          | 90         |
  +---------+------------+-------+---------------------+------------+

  +---------+------------------------------------------------------+
  | TYPE    |  EXAMPLES                                            |
  +---------+------------------------------------------------------+
  | sp      |  BeCl2 , BeF2 , CO2 , C2H2 , HgCl2                   |
  | sp2     |  BF3 , BCl3 , AlCl3 , C2H4 , SO3 , CO3 2- , NO3 -    |
  | sp3     |  CH4 , CCl4 , NH3 , H2O , NH4+ , SO4 2- , diamond    |
  | sp3d    |  PCl5 , PF5 , SF4 , ClF3 , XeF2                      |
  | sp3d2   |  SF6 , PF6 - , XeF4 , BrF5                           |
  +---------+------------------------------------------------------+

  DIAGRAMS

    sp                sp2                  sp3
   Cl--Be--Cl          F                     H
                       |                     |
    180                B                     C
                      / \                  / | \
                     F   F                H  H  H
                      120                  109.5


    sp3d                             sp3d2

          |                              \  |
     Cl   |                               \ |
       \  |                          F ---- S ---- F
        P ---- Cl                          /|
       /  |                                F  F
     Cl   |
          Cl                            all 90


  ------------------------------------------------------  [ 1 MARK ]
  THE QUICK METHOD (worth writing down - examiners like it)
  ------------------------------------------------------

### Q C3  *** ASKED VERY OFTEN ***
Explain the molecular orbital theory. Draw the molecular orbital energy
diagram of the oxygen molecule, calculate its bond order and explain its
magnetic behaviour.

**MODEL ANSWER (with the mark split shown)**

```
  ------------------------------------------------------  [ 3 MARKS ]
  PART 1 - THE MAIN FEATURES OF MOT
  ------------------------------------------------------

   1. Atomic orbitals of the combining atoms overlap and lose their
      identity, forming MOLECULAR ORBITALS that belong to the WHOLE
      molecule.

   2. Molecular orbitals are formed by the LINEAR COMBINATION OF ATOMIC
      ORBITALS (LCAO).

        ADDITION    ->  BONDING molecular orbital     (lower energy)
        SUBTRACTION ->  ANTIBONDING molecular orbital (higher energy,
                        marked with a star)

   3. The number of molecular orbitals formed equals the number of
      atomic orbitals combined.

   4. Conditions for combination: comparable energy, same symmetry about
      the molecular axis, and proper overlap.

   5. Molecular orbitals are filled following the AUFBAU principle, the
      PAULI exclusion principle and HUND'S rule.

        +-------------------------+--------------------------+
        |  BONDING MO             |  ANTIBONDING MO          |
        +-------------------------+--------------------------+
        |  formed by addition     |  formed by subtraction   |
        |  LOW energy , stable    |  HIGH energy , unstable  |
        |  high electron density  |  NODE between nuclei     |
        |  between the nuclei     |                          |
        |  favours bonding        |  opposes bonding         |
        +-------------------------+--------------------------+


  ------------------------------------------------------  [ 3 MARKS ]
  PART 2 - THE MO DIAGRAM OF O2  (16 electrons)
  ------------------------------------------------------

   For O2 and beyond, sigma2pz lies BELOW the pi2p orbitals.

   ENERGY
     ^
     |     ________                         sigma*2pz  (empty)
     |
     |     ___^____  ___^____               pi*2px , pi*2py
     |                                      ONE electron each,
     |                                      parallel spins (Hund)
     |     ___^v___  ___^v___               pi 2px , pi 2py
     |
     |     ___^v___                         sigma 2pz
     |
     |     ___^v___                         sigma*2s
     |
     |     ___^v___                         sigma 2s
     |
     |     ___^v___                         sigma*1s
     |
     |     ___^v___                         sigma 1s

   ELECTRONIC CONFIGURATION OF O2

      sigma1s2  sigma*1s2  sigma2s2  sigma*2s2  sigma2pz2
                ( pi2px2 = pi2py2 )  ( pi*2px1 = pi*2py1 )


  ------------------------------------------------------  [ 1 MARK ]
  PART 3 - BOND ORDER
  ------------------------------------------------------

      Nb  =  2 + 2 + 2 + 2 + 2  =  10       (bonding electrons)
      Na  =  2 + 2 + 1 + 1      =   6       (antibonding electrons)

                    Nb - Na        10 - 6
      BOND ORDER = ----------  =  --------  =  2
                       2             2

      A bond order of 2 means a DOUBLE BOND, in agreement with
      experiment (O=O, bond length 121 pm, enthalpy 498 kJ/mol).


  ------------------------------------------------------  [ 1 MARK ]
  PART 4 - MAGNETIC BEHAVIOUR
  ------------------------------------------------------

      The two highest electrons occupy the DEGENERATE pi*2px and pi*2py
      orbitals SINGLY with parallel spins.

      TWO UNPAIRED ELECTRONS  ->  O2 is PARAMAGNETIC.

      The simple Lewis structure  : O = O :  shows all electrons paired
      and wrongly predicts O2 to be diamagnetic. Liquid oxygen is in fact
      attracted by a magnet. Explaining this is the greatest success of
      molecular orbital theory.
```

### Q C4
Explain the formation of the ionic bond, define lattice enthalpy and
describe the Born-Haber cycle for NaCl. Also state Fajans' rules.

**MODEL ANSWER (with the mark split shown)**

```
  ------------------------------------------------------  [ 2 MARKS ]
  PART 1 - FORMATION OF THE IONIC BOND
  ------------------------------------------------------

     Na (2,8,1)  ->  Na+ (2,8)  + e-        ionisation , endothermic
     Cl (2,8,7)  + e-  ->  Cl- (2,8,8)      electron gain , exothermic

     Na .  +  : Cl :   ->   Na+  [ : Cl : ]-
                 . .                  . .

     The oppositely charged ions attract electrostatically. In the solid
     this repeats endlessly to form a giant three-dimensional IONIC
     LATTICE, each Na+ surrounded by 6 Cl- and each Cl- by 6 Na+.

     FACTORS FAVOURING IT
        low ionisation enthalpy of the metal
        high negative electron gain enthalpy of the non-metal
        high lattice enthalpy of the product
        large electronegativity difference


  ------------------------------------------------------  [ 2 MARKS ]
  PART 2 - LATTICE ENTHALPY
  ------------------------------------------------------

     LATTICE ENTHALPY is the energy required to separate ONE MOLE of a
     solid ionic compound completely into its gaseous ions.

        NaCl (s)  ->  Na+ (g) + Cl- (g)      dH = + 788 kJ/mol

     It increases with HIGHER ionic charge and SMALLER ionic size:

              q(+) x q(-)
        U  proportional to  -------------------
              r(+)  +  r(-)

        Order:   MgO  >  NaF  >  NaCl  >  NaBr  >  NaI

     A high lattice enthalpy means a hard, brittle, high-melting solid.


  ------------------------------------------------------  [ 2 MARKS ]
  PART 3 - THE BORN-HABER CYCLE FOR NaCl
  ------------------------------------------------------

        Na (s) + 1/2 Cl2 (g) ---- dH(formation) ----> NaCl (s)
           |                                              ^
           | S = +108 kJ/mol   (sublimation)              |
           v                                              |  U
        Na (g)                                            |
           | IE = +496 kJ/mol  (ionisation)               |
           v                                              |
        Na+ (g)  +  Cl- (g) <--- EA = -349 ---- Cl (g) <-- 1/2 D = +121

        dH f  =  S  +  IE  +  (1/2) D  +  EA  +  U

        - 411  =  108 + 496 + 121 - 349 + U

             U  =  - 787 kJ/mol
                   (so the lattice enthalpy for BREAKING it is +787)

     This works because enthalpy is a STATE FUNCTION (Hess's law), so
     the direct route and the step-by-step route must add to the same
     total. It is the only practical way to obtain lattice enthalpy.


  ------------------------------------------------------  [ 2 MARKS ]
  PART 4 - FAJANS' RULES
  ------------------------------------------------------

     No bond is 100 % ionic. A cation polarises (distorts) the electron
     cloud of an anion, introducing COVALENT CHARACTER.

     Covalent character increases when
        1. the CATION is SMALL
        2. the ANION is LARGE
        3. the CHARGE on either ion is HIGH
        4. the cation has a PSEUDO NOBLE-GAS (18-electron) shell

     Examples
        LiCl  >  NaCl  >  KCl        (covalent character, smaller cation)
        LiI   >  LiBr  >  LiCl > LiF (larger anion)
        AlCl3 >  MgCl2 >  NaCl       (higher cation charge)
        CuCl  >  NaCl                (18-electron Cu+)
```

### Q C5
Explain bond parameters (bond length, bond angle, bond enthalpy, bond
order) and resonance. Explain the polarity of bonds and dipole moment
with suitable examples.

**MODEL ANSWER (with the mark split shown)**

```
  ------------------------------------------------------  [ 3 MARKS ]
  PART 1 - BOND PARAMETERS
  ------------------------------------------------------

   BOND LENGTH - the equilibrium distance between the nuclei of two
   bonded atoms, measured in pm or angstrom.
        C-C 154 pm  >  C=C 134 pm  >  C#C 120 pm

   BOND ANGLE - the angle between two adjacent bonds at the central
   atom. It fixes the shape of the molecule.
        CH4 109.5 , NH3 107 , H2O 104.5 degrees

   BOND ENTHALPY - the energy required to break one mole of bonds of a
   given type in the gaseous state. Always positive.
        H-H 435 , O=O 498 , N#N 946 kJ/mol

   BOND ORDER - the number of bonds between two atoms.
        In MOT,   B.O. = ( Nb - Na ) / 2
        H2 = 1 , O2 = 2 , N2 = 3

   MASTER RELATION
        bond order UP  ->  bond length DOWN  ->  bond enthalpy UP
                                              ->  stability UP


  ------------------------------------------------------  [ 2 MARKS ]
  PART 2 - RESONANCE
  ------------------------------------------------------

   When one Lewis structure cannot describe a molecule, it is written as
   two or more structures that differ ONLY in the positions of
   ELECTRONS. The true molecule is the RESONANCE HYBRID.

        O                    O
       / \\      <->       // \             ozone O3
      O    O              O    O

   Both O-O bonds are equal (128 pm), bond order 1.5.

   RESONANCE ENERGY = ( energy of the actual molecule )
                        - ( energy of the most stable single structure )
   It is the extra stability due to delocalisation.

   CONDITIONS: atoms stay in the same positions, only electrons move;
   all structures must have the same number of electrons.


  ------------------------------------------------------  [ 3 MARKS ]
  PART 3 - POLARITY AND DIPOLE MOMENT
  ------------------------------------------------------

   When two bonded atoms differ in electronegativity, the shared pair
   lies nearer the more electronegative atom, producing partial charges.

                 d+        d-
                  H -----> Cl        a POLAR covalent bond

   DIPOLE MOMENT       mu  =  q  x  d
   Unit: debye (D) ,  1 D = 3.336 x 10^-30 C m.  It is a VECTOR.

   A molecule's dipole moment is the VECTOR SUM of its bond dipoles.

   EXAMPLE 1 - CO2 versus H2O

      O = C = O   linear , the two dipoles are exactly opposite
                  and CANCEL              mu = 0     NON-POLAR

           O      bent (104.5) , the two dipoles ADD
          / \                             mu = 1.85 D    POLAR
         H   H

   EXAMPLE 2 - BF3 versus NH3

           F      trigonal planar , symmetric ,
           |      the three dipoles cancel     mu = 0     NON-POLAR
           B
          / \
         F   F

          : :     pyramidal , bond dipoles and the lone-pair dipole
           N      point the same way and ADD   mu = 1.47 D   POLAR
         / | \
        H  H  H

   PERCENTAGE IONIC CHARACTER

                          mu (observed)
        % ionic  =  100 x -----------------
                          mu (100 % ionic)

        For HCl:  100 x (1.03 / 6.10)  =  16.9 %
```
