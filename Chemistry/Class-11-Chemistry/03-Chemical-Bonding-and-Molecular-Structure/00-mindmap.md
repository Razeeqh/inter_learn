## THE 60-SECOND VERSION

Atoms bond for **one reason only: to become more stable (lower in energy)**.
They do it in three ways, and the whole chapter is those three ways plus
"what shape does the result have".

```
  WAY 1   IONIC BOND      - one atom GIVES electrons, the other TAKES them
             |              metal + non-metal.  Na+ Cl-
             |              Held by electrostatic attraction.
             v
  WAY 2   COVALENT BOND   - both atoms SHARE electrons
             |              non-metal + non-metal.  H-H , O=O , N#N
             |
             v
  WAY 3   METALLIC BOND   - positive kernels floating in a "sea of electrons"
                            explains conduction, lustre, malleability
```

Then three theories explain the covalent bond, each fixing the one before:

```
  LEWIS / OCTET    -> dots and lines. Simple. FAILS for BF3, PCl5, NO.
        |
        v
  VSEPR            -> tells you the SHAPE. Electron pairs repel and
        |             spread out as far as possible.
        |             FAILS to explain WHY the bond forms.
        v
  VALENCE BOND     -> bonds = overlap of atomic orbitals.
  (hybridisation)     Explains shape + strength. FAILS on O2 magnetism.
        |
        v
  MOLECULAR        -> atomic orbitals combine into MOLECULAR orbitals
  ORBITAL THEORY      spread over the whole molecule.
                      Explains bond order, He2 not existing, and
                      why O2 is PARAMAGNETIC.
```

**If you can say that ladder out loud, you already own the theory marks.**

## THE TWO BOXES THAT UNLOCK EVERYTHING

```
  +---------------------------------------------------------------+
  |                                                               |
  |   FORMAL CHARGE on an atom in a Lewis structure               |
  |                                                               |
  |   FC =  (valence electrons of the free atom)                  |
  |             -  (number of lone-pair electrons)                |
  |             -  (1/2) x (number of bonding electrons)          |
  |                                                               |
  |   Short form:      FC  =  V  -  L  -  (B / 2)                 |
  |                                                               |
  +---------------------------------------------------------------+

  +---------------------------------------------------------------+
  |                                                               |
  |   BOND ORDER  (Molecular Orbital Theory)                      |
  |                                                               |
  |                    Nb  -  Na                                  |
  |        B.O.  =   -------------                                |
  |                        2                                      |
  |                                                               |
  |     Nb = electrons in BONDING molecular orbitals              |
  |     Na = electrons in ANTIBONDING molecular orbitals          |
  |                                                               |
  |     B.O. = 0   ->  molecule DOES NOT EXIST                    |
  |     higher B.O. -> shorter bond, stronger bond, more energy   |
  |                                                               |
  +---------------------------------------------------------------+
```

**Write both of these on your palm.**

## THE STERIC NUMBER TRICK (fastest marks in the chapter)

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |                     1                                                |
  |     STERIC NO.  =  ---  [  V  +  M  -  C  +  A  ]                    |
  |         (X)         2                                                |
  |                                                                      |
  |     V = valence electrons of the CENTRAL atom                        |
  |     M = number of MONOVALENT atoms attached (H, F, Cl, Br, I)        |
  |     C = charge if the ion is POSITIVE (subtract it)                  |
  |     A = charge if the ion is NEGATIVE (add it)                       |
  |                                                                      |
  +----------------------------------------------------------------------+

     X = 2  ->  sp        X = 5  ->  sp3d
     X = 3  ->  sp2       X = 6  ->  sp3d2
     X = 4  ->  sp3       X = 7  ->  sp3d3

  NOTE: oxygen and sulphur attached by DOUBLE bonds count as ZERO
        (they take nothing and give nothing in this count).
```

## THE BOND ANGLE LADDER (asked almost every year)

```
     CH4          NH3          H2O
    109.5   ->   107.0   ->   104.5   degrees
     |            |             |
   0 lone      1 lone        2 lone pairs on the central atom

   RULE:  lone pair - lone pair  >  lone pair - bond pair  >  bond pair - bond pair

   More lone pairs  ->  more squeezing  ->  SMALLER bond angle.
```

## THE ONE-LINE ANSWERS THAT KEEP COMING BACK

```
  Why is BF3 non-polar though B-F bonds are polar?
      -> trigonal planar, symmetric, the three bond dipoles cancel.

  Why is CO2 non-polar but H2O polar?
      -> CO2 is LINEAR (dipoles cancel), H2O is BENT (they add up).

  Why is O2 paramagnetic?
      -> MOT: two unpaired electrons in the pi*2px and pi*2py orbitals.

  Why does He2 not exist?
      -> bond order = (2 - 2)/2 = 0.

  Why is the H2O boiling point so high?
      -> intermolecular HYDROGEN BONDING.

  Why is o-nitrophenol more volatile than p-nitrophenol?
      -> ortho has INTRAmolecular H-bonding, para has INTERmolecular.

  Why is the NH3 bond angle 107 and not 109.5?
      -> one lone pair pushes the bond pairs closer together.
```
