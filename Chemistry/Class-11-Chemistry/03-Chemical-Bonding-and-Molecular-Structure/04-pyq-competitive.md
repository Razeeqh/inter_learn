# PATTERN 1 — Octet rule, Lewis structures, formal charge

### Q1
Which of the following does NOT obey the octet rule?

(a) CH4 &nbsp; (b) NH3 &nbsp; (c) BF3 &nbsp; (d) H2O

**ANSWER: (c)**
```
  Boron in BF3 has only 3 + 3 = 6 electrons around it.
  INCOMPLETE OCTET (electron deficient).
```

---

### Q2
Which of the following is an odd-electron molecule?

(a) CO2 &nbsp; (b) NO &nbsp; (c) SO2 &nbsp; (d) H2O

**ANSWER: (b)**
```
  NO :  N (5) + O (6)  =  11 valence electrons - an ODD number.
  Pairing every electron is impossible, so NO is PARAMAGNETIC.
  Others: NO2 (17 e-) and ClO2 are the other standard examples.
```

---

### Q3
The formal charge on the central oxygen atom of ozone is

(a) 0 &nbsp; (b) +1 &nbsp; (c) -1 &nbsp; (d) +2

**ANSWER: (b)**
```
  FC = V - L - B/2 = 6 - 2 - 6/2 = 6 - 2 - 3 = +1
```

> **SHORTCUT:** For a neutral molecule, the formal charges must add to
> ZERO. If three options give a non-zero total, they are wrong instantly.

---

### Q4
Which species has an expanded octet?

(a) NCl3 &nbsp; (b) PCl5 &nbsp; (c) CCl4 &nbsp; (d) BeCl2

**ANSWER: (b)**
```
  Phosphorus is in PERIOD 3, so it has vacant 3d orbitals and can hold
  10 electrons. Nitrogen is in period 2 with NO d orbitals, which is
  exactly why NCl5 does not exist but PCl5 does.
```

# PATTERN 2 — Shapes from VSEPR

### Q5
The shape of the SF4 molecule is

(a) tetrahedral &nbsp; (b) square planar &nbsp; (c) see-saw &nbsp; (d) trigonal bipyramidal

**ANSWER: (c)**
```
  X = (1/2)[6 + 4] = 5   ->  sp3d , 4 bond pairs + 1 LONE PAIR
  5 pairs with 1 lone pair  ->  SEE-SAW
  (the lone pair always takes an EQUATORIAL position)
```

---

### Q6
The shape of the XeF4 molecule is

(a) tetrahedral &nbsp; (b) square planar &nbsp; (c) octahedral &nbsp; (d) see-saw

**ANSWER: (b)**
```
  X = (1/2)[8 + 4] = 6   ->  sp3d2 , 4 bond pairs + 2 LONE PAIRS
  The two lone pairs go OPPOSITE each other (above and below)
     ->  SQUARE PLANAR
```

---

### Q7
ClF3 has the shape

(a) trigonal planar &nbsp; (b) pyramidal &nbsp; (c) T-shaped &nbsp; (d) linear

**ANSWER: (c)**
```
  X = (1/2)[7 + 3] = 5   ->  sp3d , 3 bond pairs + 2 lone pairs
     ->  T-SHAPED
```

---

### Q8
The I3 - ion is

(a) bent &nbsp; (b) linear &nbsp; (c) T-shaped &nbsp; (d) trigonal planar

**ANSWER: (b)**
```
  X = (1/2)[7 + 2 - 0 + 1] = 5   ->  sp3d , 2 bond pairs + 3 lone pairs
  All three lone pairs sit in the equatorial plane
     ->  LINEAR   (same as XeF2)
```

---

### Q9
Which of the following is NOT planar?

(a) BF3 &nbsp; (b) CO3 2- &nbsp; (c) NO3 - &nbsp; (d) NH3

**ANSWER: (d)**
```
  BF3 , CO3 2- , NO3 -  are all sp2  ->  TRIGONAL PLANAR
  NH3 is sp3 with one lone pair      ->  TRIGONAL PYRAMIDAL (3-D)
```

---

### Q10
The shape of ClO3 - is

(a) trigonal planar &nbsp; (b) pyramidal &nbsp; (c) tetrahedral &nbsp; (d) T-shaped

**ANSWER: (b)**
```
  X = (1/2)[7 + 0 - 0 + 1] = 4   (the three Cl=O count zero)
     ->  sp3 with 3 bond pairs + 1 lone pair  ->  PYRAMIDAL
```

> **SHORTCUT — the two-step shape machine:**
> ```
>   1.  X = (1/2)[ V + M - C + A ]   ->  gives hybridisation
>   2.  lone pairs = X - (number of atoms attached)
>       ->  then read the shape off the VSEPR table
> ```

# PATTERN 3 — Bond angle comparisons

### Q11
The correct order of bond angle is

(a) H2O > NH3 > CH4 &nbsp; (b) CH4 > NH3 > H2O
(c) NH3 > CH4 > H2O &nbsp; (d) CH4 > H2O > NH3

**ANSWER: (b)**
```
  CH4  109.5  (0 lone pairs)
  NH3  107.0  (1 lone pair)
  H2O  104.5  (2 lone pairs)

  MORE LONE PAIRS  ->  SMALLER ANGLE.  Every time.
```

---

### Q12
The correct order of bond angle is

(a) NH3 > PH3 > AsH3 &nbsp; (b) PH3 > NH3 > AsH3
(c) AsH3 > PH3 > NH3 &nbsp; (d) all are equal

**ANSWER: (a)**
```
  NH3 107  >  PH3 93.5  >  AsH3 92  >  SbH3 91

  Going DOWN the group the central atom gets BIGGER and less
  electronegative, so the bond pairs sit further away and repel
  each other less  ->  smaller angle.
```

---

### Q13
Which has the SMALLEST bond angle?

(a) H2O &nbsp; (b) H2S &nbsp; (c) H2Se &nbsp; (d) H2Te

**ANSWER: (d)**
```
  H2O 104.5 > H2S 92 > H2Se 91 > H2Te 90
  Same reason: larger central atom, weaker repulsion.
```

---

### Q14
The bond angle in NF3 is LESS than in NH3 because

(a) F is bigger than H &nbsp; (b) F is more electronegative than H
(c) NF3 is planar &nbsp; (d) NF3 has two lone pairs

**ANSWER: (b)**
```
  Fluorine pulls the bonding electrons AWAY from nitrogen, so the bond
  pairs are further from the central atom and repel each other less.
  The lone pair then squeezes them harder.

     NH3  107      NF3  102
```

# PATTERN 4 — Hybridisation (the fastest marks in the paper)

### Q15
The hybridisation of the carbon atom in CO3 2- is

(a) sp &nbsp; (b) sp2 &nbsp; (c) sp3 &nbsp; (d) sp3d

**ANSWER: (b)**
```
  X = (1/2)[4 + 0 - 0 + 2] = 3   ->  sp2   (trigonal planar)
```

---

### Q16
The hybridisation of sulphur in SO4 2- is

(a) sp2 &nbsp; (b) sp3 &nbsp; (c) sp3d &nbsp; (d) sp3d2

**ANSWER: (b)**
```
  X = (1/2)[6 + 0 - 0 + 2] = 4   ->  sp3   (tetrahedral)
  The S=O oxygens contribute ZERO to the count.
```

---

### Q17
The hybridisation of xenon in XeF2 is

(a) sp2 &nbsp; (b) sp3 &nbsp; (c) sp3d &nbsp; (d) sp3d2

**ANSWER: (c)**
```
  X = (1/2)[8 + 2] = 5   ->  sp3d
  3 lone pairs + 2 bond pairs  ->  the SHAPE is LINEAR.
```

---

### Q18
In which of the following is the central atom sp3 hybridised?

(a) BF3 &nbsp; (b) PCl5 &nbsp; (c) H3O+ &nbsp; (d) SF6

**ANSWER: (c)**
```
  H3O+ :  X = (1/2)[6 + 3 - 1] = 4  ->  sp3 , pyramidal
  BF3 sp2 , PCl5 sp3d , SF6 sp3d2
```

---

### Q19
The percentage of s character in an sp hybrid orbital is

(a) 25 % &nbsp; (b) 33.3 % &nbsp; (c) 50 % &nbsp; (d) 75 %

**ANSWER: (c)**
```
  sp    = 1 s in 2 orbitals  ->  50 %
  sp2   = 1 s in 3 orbitals  ->  33.3 %
  sp3   = 1 s in 4 orbitals  ->  25 %
```

---

### Q20
The correct order of C-H bond length is

(a) C2H2 < C2H4 < C2H6 &nbsp; (b) C2H6 < C2H4 < C2H2
(c) C2H4 < C2H2 < C2H6 &nbsp; (d) all equal

**ANSWER: (a)**
```
  sp (50 % s) holds electrons CLOSEST to the nucleus  ->  SHORTEST bond

     C2H2 (sp)  <  C2H4 (sp2)  <  C2H6 (sp3)

  The same order gives ACIDITY:  HC#CH > H2C=CH2 > H3C-CH3
```

> **SHORTCUT — hybridisation in 5 seconds:**
> ```
>    X  =  (1/2) [ V + M - C + A ]
>
>       V = valence electrons of the CENTRAL atom
>       M = monovalent atoms attached (H, F, Cl, Br, I)
>       C = subtract the charge if it is a CATION
>       A = add the charge if it is an ANION
>       double-bonded O and S count as ZERO
>
>       2 -> sp   3 -> sp2   4 -> sp3   5 -> sp3d   6 -> sp3d2
> ```

# PATTERN 5 — Sigma and pi bond counting

### Q21
The number of sigma and pi bonds in benzene C6H6 is

(a) 6 and 3 &nbsp; (b) 12 and 3 &nbsp; (c) 12 and 6 &nbsp; (d) 9 and 3

**ANSWER: (b)**
```
  6 C-C sigma  +  6 C-H sigma  =  12 sigma
  3 double bonds contribute      =   3 pi
```

---

### Q22
The number of pi bonds in CH2 = CH - C # N is

(a) 1 &nbsp; (b) 2 &nbsp; (c) 3 &nbsp; (d) 4

**ANSWER: (c)**
```
  C = C  ->  1 pi
  C # N  ->  2 pi
  TOTAL      3 pi     (and 6 sigma)
```

> **SHORTCUT:**
> ```
>   pi bonds  =  (number of double bonds) + 2 x (number of triple bonds)
>   sigma bonds = total number of BOND LINES you can draw between atoms
> ```

# PATTERN 6 — Dipole moment and polarity

### Q23
Which of the following has ZERO dipole moment?

(a) H2O &nbsp; (b) NH3 &nbsp; (c) CO2 &nbsp; (d) CHCl3

**ANSWER: (c)**
```
  CO2 is LINEAR and symmetric, so the two equal C=O dipoles point in
  exactly opposite directions and cancel.
```

---

### Q24
Which of these is a POLAR molecule?

(a) BF3 &nbsp; (b) CCl4 &nbsp; (c) SF6 &nbsp; (d) NH3

**ANSWER: (d)**
```
  BF3 , CCl4 , SF6 are all SYMMETRIC with no lone pair on the central
  atom  ->  mu = 0
  NH3 is pyramidal with a lone pair  ->  mu = 1.47 D
```

> **SHORTCUT — the symmetry test:**
> ```
>   NO lone pair on the central atom AND all outer atoms identical
>          ->  SYMMETRIC  ->  dipole moment = ZERO
>
>   Zero-dipole classics: CO2 , CS2 , BF3 , BCl3 , CH4 , CCl4 ,
>                         PCl5 , SF6 , XeF4 , C6H6 , trans isomers
> ```

---

### Q25
The dipole moment of NF3 is smaller than that of NH3 because

(a) NF3 is planar &nbsp; (b) N-F bonds are non-polar
(c) the bond dipoles oppose the lone-pair dipole in NF3
(d) NF3 has no lone pair

**ANSWER: (c)**
```
  NH3 : bond dipoles point TOWARDS N , same as the lone-pair dipole
        ->  they ADD       ->  1.47 D

  NF3 : F is more electronegative, so bond dipoles point AWAY from N ,
        OPPOSITE to the lone-pair dipole
        ->  they partly CANCEL  ->  0.24 D
```

---

### Q26
The correct order of dipole moment is

(a) HI > HBr > HCl > HF &nbsp; (b) HF > HCl > HBr > HI
(c) HCl > HF > HBr > HI &nbsp; (d) all equal

**ANSWER: (b)**
```
  HF 1.91 > HCl 1.03 > HBr 0.79 > HI 0.38  (in debye)
  Follows the ELECTRONEGATIVITY DIFFERENCE, which falls down the group.
```

### Q27
The dipole moment of HBr is 0.79 D and the bond length is 1.41 A.
The percentage ionic character is about

(a) 12 % &nbsp; (b) 17 % &nbsp; (c) 23 % &nbsp; (d) 45 %

**ANSWER: (a)**
```
  mu (100 % ionic) = e x d
                   = (4.8 x 10^-10 esu)(1.41 x 10^-8 cm)
                   = 6.77 x 10^-18 esu cm  =  6.77 D

                       0.79
  % ionic = 100 x  ------------  =  11.7 %  , about 12 %
                       6.77
```

# PATTERN 7 — Fajans' rules and ionic character

### Q28
Which of the following has the MOST covalent character?

(a) LiF &nbsp; (b) LiCl &nbsp; (c) LiBr &nbsp; (d) LiI

**ANSWER: (d)**
```
  Same cation, so compare the ANIONS. The BIGGER the anion, the more
  easily it is polarised.
       I-  >  Br-  >  Cl-  >  F-
  So LiI is the most covalent.
```

---

### Q29
Which has the greatest polarising power?

(a) Na+ &nbsp; (b) Mg2+ &nbsp; (c) Al3+ &nbsp; (d) K+

**ANSWER: (c)**
```
  Polarising power  goes as   charge / size

  Al3+ has the highest charge AND the smallest size of the four.
  That is why AlCl3 is essentially covalent while NaCl is ionic.
```

---

### Q30
The lattice enthalpy is HIGHEST for

(a) NaF &nbsp; (b) NaCl &nbsp; (c) NaBr &nbsp; (d) NaI

**ANSWER: (a)**
```
                          q(+) x q(-)
   Lattice energy goes as -------------
                          r(+) + r(-)

   F- is the smallest anion  ->  smallest interionic distance
                             ->  HIGHEST lattice energy.
```

# PATTERN 9 — MOT: bond order, stability, magnetism

### Q33
Which of the following is PARAMAGNETIC?

(a) N2 &nbsp; (b) O2 &nbsp; (c) F2 &nbsp; (d) C2

**ANSWER: (b)**
```
  O2 : ... sigma2pz2 (pi2px2 = pi2py2) (pi*2px1 = pi*2py1)
       TWO unpaired electrons in the pi* orbitals  ->  PARAMAGNETIC

  N2 , F2 , C2 all have every electron paired  ->  DIAMAGNETIC.
  (B2 is the OTHER paramagnetic one in the series - remember B2 and O2.)
```

---

### Q34
The bond order of the O2 - ion is

(a) 1 &nbsp; (b) 1.5 &nbsp; (c) 2 &nbsp; (d) 2.5

**ANSWER: (b)**
```
  O2 - has 17 electrons.  Nb = 10 , Na = 7

     B.O. = (10 - 7)/2 = 1.5
```

> **SHORTCUT for the oxygen family — count from O2 and step by 0.5:**
> ```
>       O2 +   ->  2.5          (take an electron OUT of pi*)
>       O2     ->  2.0
>       O2 -   ->  1.5          (put one INTO pi*)
>       O2 2-  ->  1.0
>
>   Bond length:   O2+ < O2 < O2- < O2 2-
>   Stability:     O2+ > O2 > O2- > O2 2-
>
>   Only O2 2- is DIAMAGNETIC; the other three are paramagnetic.
> ```

---

### Q35
Which molecule does NOT exist according to MOT?

(a) H2 &nbsp; (b) Li2 &nbsp; (c) Be2 &nbsp; (d) B2

**ANSWER: (c)**
```
  Be2 : sigma1s2 sigma*1s2 sigma2s2 sigma*2s2
        Nb = 4 , Na = 4   ->  B.O. = 0   ->  DOES NOT EXIST

  The other zero-bond-order species: He2 and Ne2.
```

---

### Q36
The species with the HIGHEST bond order is

(a) O2 &nbsp; (b) N2 &nbsp; (c) F2 &nbsp; (d) Li2

**ANSWER: (b)**
```
  N2 = 3 , O2 = 2 , F2 = 1 , Li2 = 1
  N2 therefore has the shortest bond (110 pm) and the highest bond
  enthalpy (946 kJ/mol) - which is why it is so unreactive.
```

---

### Q37
Which pair has the SAME bond order?

(a) N2 and CO &nbsp; (b) O2 and N2 &nbsp; (c) F2 and O2 &nbsp; (d) H2 and He2

**ANSWER: (a)**
```
  N2  : 14 electrons  ->  B.O. = 3
  CO  : 14 electrons  ->  B.O. = 3
  Also isoelectronic with CN - and NO + , all bond order 3.
```

> **SHORTCUT:** For a HETERO-nuclear diatomic like CO, NO or CN -, just
> add up the total electrons and use the SAME diagram as the homonuclear
> molecule with that electron count.
> ```
>     CO , CN - , NO + , N2   ->  14 electrons  ->  B.O. 3 , diamagnetic
>     NO , O2 +               ->  15 electrons  ->  B.O. 2.5 , paramagnetic
> ```

---

### Q38
The molecular orbital energy order changes at

(a) B2 &nbsp; (b) N2 &nbsp; (c) O2 &nbsp; (d) F2

**ANSWER: (c)**
```
  Up to and including N2 :   pi2p  is BELOW  sigma2pz
  From O2 onwards        :   sigma2pz is BELOW pi2p

  Cause: s-p mixing is strong in the lighter molecules and pushes
  sigma2pz above the pi orbitals. By oxygen the 2s-2p gap is too big
  for mixing.
```

# PATTERN 10 — Hydrogen bonding

### Q39
Which of the following shows INTRAmolecular hydrogen bonding?

(a) p-nitrophenol &nbsp; (b) o-nitrophenol &nbsp; (c) water &nbsp; (d) HF

**ANSWER: (b)**
```
  In o-nitrophenol the -OH and -NO2 groups are next to each other, so
  the hydrogen bond closes a RING INSIDE the molecule.
  Result: molecules stay separate  ->  LOWER boiling point,
  steam volatile, LESS soluble in water than the para isomer.
```

---

### Q40
The correct order of boiling point is

(a) H2O > HF > NH3 > H2S &nbsp; (b) HF > H2O > NH3 > H2S
(c) H2S > NH3 > HF > H2O &nbsp; (d) NH3 > H2O > HF > H2S

**ANSWER: (a)**
```
  H2O 373 K  >  HF 293 K  >  NH3 240 K  >  H2S 213 K

  Water wins because EACH molecule can form FOUR hydrogen bonds
  (2 through its H atoms + 2 through its lone pairs).
  HF forms only one per molecule. H2S has none at all.
```

---

### Q41
Ice floats on water because

(a) ice is a solid &nbsp; (b) hydrogen bonds give ice an open cage structure
(c) water is polar &nbsp; (d) ice has covalent bonds

**ANSWER: (b)**
```
  In ice, every water molecule is hydrogen bonded to FOUR others in an
  OPEN, cage-like lattice with large empty spaces.
  Less mass per unit volume  ->  ice is LESS DENSE  ->  it floats.
```

### Q42
The number of LONE PAIRS on the central atom of XeF4 is

(a) 0 &nbsp; (b) 1 &nbsp; (c) 2 &nbsp; (d) 3

**ANSWER: (c)**
```
  X = (1/2)[8 + 4] = 6 ;  atoms attached = 4

### Q43
Which of the following is isostructural with (has the same shape as) NH3?

(a) BF3 &nbsp; (b) PCl3 &nbsp; (c) CO3 2- &nbsp; (d) SO3

**ANSWER: (b)**
```
  PCl3 :  X = (1/2)[5 + 3] = 4  ->  sp3 , 3 bp + 1 lp  ->  PYRAMIDAL
  BF3 , CO3 2- , SO3 are all sp2  ->  trigonal PLANAR
```

---

### Q44
Which has the highest melting point?

(a) NaCl &nbsp; (b) MgO &nbsp; (c) AlCl3 &nbsp; (d) CCl4

**ANSWER: (b)**
```
  MgO has 2+ and 2- ions that are also small, so its lattice enthalpy is
  enormous (about 3800 kJ/mol) and its melting point is about 3125 K.
  AlCl3 is largely covalent (Fajans) and CCl4 is molecular.
```

---

### Q45
The C-C bond length is shortest in

(a) ethane &nbsp; (b) ethene &nbsp; (c) ethyne &nbsp; (d) benzene

**ANSWER: (c)**
```
     ethyne   120 pm   (bond order 3)      SHORTEST
     ethene   134 pm   (bond order 2)
     benzene  139 pm   (bond order 1.5)
     ethane   154 pm   (bond order 1)      LONGEST

  Higher bond order ALWAYS means a shorter bond.
```
