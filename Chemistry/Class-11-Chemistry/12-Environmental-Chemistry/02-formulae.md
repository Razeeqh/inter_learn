# 1. THE VOCABULARY TABLE

| Term | Definition (write it like this) | Example | When to use |
|---|---|---|---|
| **Pollution** | Undesirable change in the physical, chemical or biological character of air, water or soil that harms life | — | opening line of any definition question |
| **Pollutant** | A substance present in a concentration **higher than its natural level**, causing harm | excess CO2, SO2 | "define pollutant" (2M) |
| **Contaminant** | A substance that does **not occur in nature there at all**, introduced by human activity | DDT in a river | contrast question with pollutant |
| **Receptor** | The medium or organism **affected by** the pollutant | man, plants, a lake | 2-mark definition |
| **Sink** | The medium that **retains / absorbs** the pollutant for a long time | ocean for CO2; marble for H2SO4 | 2-mark definition, very common |
| **Speciation** | The different **chemical forms** in which an element exists, since toxicity depends on the form | Cr(III) harmless, Cr(VI) toxic | 2-mark definition |
| **Dose** | The amount of chemical that actually **enters the body** | — | pairs with TLV |
| **Threshold limit value (TLV)** | The **minimum dose** producing a detectable harmful effect | — | pairs with dose |
| **Biodegradable pollutant** | Decomposed **rapidly** by micro-organisms into harmless substances | sewage, cow dung, paper, vegetable waste | comparison question |
| **Non-biodegradable pollutant** | **Not** decomposed by micro-organisms; persists and accumulates in the food chain | plastics, DDT, Hg, Pb, glass, radioactive waste | comparison question |

> **THE ONE-LINE DISCRIMINATOR:**
> **Contaminant** = should not be there **at all**.
> **Pollutant** = belongs there, but there is now **too much**.

# 4. GASEOUS POLLUTANTS — THE MASTER TABLE

| Pollutant | Main source | Harmful effect | Key phrase for full marks |
|---|---|---|---|
| **SO2** | burning coal, thermal power plants, smelting sulphide ores, oil refining | irritates eyes/throat/lungs, breathlessness, bronchitis; in plants **chlorosis** and stiffness of flower buds which fall off; **acid rain** | "chlorosis" + "H2SO4" |
| **SO3** | oxidation of SO2 in air | dissolves in rain to give H2SO4 directly | `SO3 + H2O -> H2SO4` |
| **NO / NO2 (NOx)** | vehicle engines (`N2 + O2` at high temperature), lightning, power stations | lung irritation, bronchitis; damages leaves, retards photosynthesis; **photochemical smog**; **acid rain (HNO3)**; fades fabric | "high temperature in the engine" |
| **CO** | **INCOMPLETE** combustion of fuel; petrol engines are the biggest source; cigarette smoke | binds haemoglobin **~300x** more strongly than O2 forming **carboxyhaemoglobin**; headache, dizziness, coma, death | "carboxyhaemoglobin" |
| **CO2** | **COMPLETE** combustion, respiration, deforestation | the main **greenhouse gas** -> global warming, melting ice, rising sea level | "greenhouse gas" |
| **Hydrocarbons (CH4, PAHs)** | unburnt petrol/diesel, petroleum leaks, burning agricultural waste | **carcinogenic**; cause ageing, shedding of leaves and flowers; feed photochemical smog; CH4 is a greenhouse gas | "carcinogenic" |
| **O3 (at ground level)** | **secondary** — made from NO2 + sunlight | irritates eyes and nose, headache, chest pain, dry throat; damages crops; **cracks rubber** | "good up high, bad down here" |

```
  PRIMARY vs SECONDARY POLLUTANTS  (asked directly)

  PRIMARY    emitted AS SUCH from the source
             ->  SO2 , NO , NO2 , CO , unburnt hydrocarbons , particulates

  SECONDARY  FORMED IN THE AIR by reaction between primary pollutants
             ->  O3 , PAN , formaldehyde , acrolein , H2SO4 aerosol
```

# 6. ACID RAIN — THE EQUATION SET

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   NORMAL RAIN   pH = 5.6        CO2 + H2O --> H2CO3                 |
  |                                                                     |
  |   ACID  RAIN    pH < 5.6        due to  H2SO4  and  HNO3            |
  |                                 (roughly 60 % : 40 %)               |
  |                                                                     |
  +---------------------------------------------------------------------+
```

```
  SULPHUR ROUTE                          NITROGEN ROUTE

   S    +  O2   -->  SO2                  N2  +  O2  --(high T)-->  2 NO
   2 SO2 + O2   -->  2 SO3                2 NO  +  O2  -->  2 NO2
   SO3  +  H2O  -->  H2SO4                4 NO2 + O2 + 2 H2O --> 4 HNO3
   SO2  +  H2O  -->  H2SO3                3 NO2 + H2O --> 2 HNO3 + NO
```

| Affected thing | Effect | Equation / keyword |
|---|---|---|
| **Buildings, statues** | marble and limestone eaten away — **"stone leprosy"**; the **Taj Mahal** is the standard example | `CaCO3 + H2SO4 -> CaSO4 + H2O + CO2` |
| **Metals** | corrosion of iron and steel structures | — |
| **Soil** | leaches out Ca, Mg, K nutrients; releases toxic **Al3+**; soil turns infertile | — |
| **Plants** | damages waxy leaf coating, yellowing, stunted growth, forest death | — |
| **Aquatic life** | below **pH 5** fish eggs fail; below **pH 4** most fish die; "dead lakes" | — |

# 7. GREENHOUSE EFFECT AND GLOBAL WARMING

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   MECHANISM IN ONE SENTENCE:                                        |
  |                                                                     |
  |   Greenhouse gases are TRANSPARENT to incoming SHORT-wavelength     |
  |   sunlight but OPAQUE to the outgoing LONG-wavelength INFRARED      |
  |   radiation from the Earth, so the heat is trapped.                 |
  |                                                                     |
  |   Without it, Earth would be at about  -18 C  instead of  +15 C .   |
  |   The problem is the ENHANCED effect caused by human emissions.     |
  |                                                                     |
  +---------------------------------------------------------------------+
```

| Rank | Gas | Approx share | Main source |
|---|---|---|---|
| 1 | **CO2** | ~50–60 % | fossil fuels, deforestation |
| 2 | **CH4** | ~20 % | paddy fields, cattle, marshes, landfills |
| 3 | **CFCs** | ~14 % | refrigerants, aerosol propellants |
| 4 | **N2O** | ~6 % | nitrogen fertilisers, vehicles |
| 5 | **O3, water vapour** | remainder | photochemical reactions, evaporation |

```
  ORDER:   CO2  >  CH4  >  CFCs  >  N2O  >  O3

  CAREFUL:  CO2 contributes MOST OVERALL (because there is so much of it)
            but PER MOLECULE, CFCs and CH4 are far more powerful.
            Read whether the question says "most" or "most effective".

  CONSEQUENCES:  temperature rise, polar ice melts, SEA LEVEL RISES,
                 coastal flooding, changed rainfall, drought, crop
                 failure, spread of tropical diseases, coral death.
```

# 8. SMOG — THE COMPARISON THEY ASK EVERY YEAR

| Point | CLASSICAL SMOG | PHOTOCHEMICAL SMOG |
|---|---|---|
| Other name | **London** smog, sulphurous smog | **Los Angeles** smog |
| Chemical nature | **REDUCING** | **OXIDISING** |
| Climate needed | **cool and humid** | **warm, dry and sunny** |
| Sunlight required | **NO** | **YES — essential** |
| Main pollutants | SO2 + smoke + fog | NO2 + unburnt hydrocarbons |
| Chief source | burning **coal** | **automobile exhaust** |
| Products formed | **H2SO4 aerosol** | **O3, PAN, aldehydes, acrolein** |
| Appearance | grey-black thick fog | **brown haze** |
| Time of day | early morning | midday / afternoon |
| Chief harm | bronchitis, breathing trouble | eye irritation, plant damage |

**MEMORY:** *London is cold and damp -> classical, reducing.
Los Angeles is hot and sunny -> photochemical, oxidising.*

```
  PHOTOCHEMICAL SMOG — THE FOUR EQUATIONS

     N2  +  O2   --(high temp in engine)-->   2 NO
     2 NO  +  O2                        -->   2 NO2

     NO2   --(sunlight, hv)-->   NO  +  O          <-- the PHOTO step
     O   +   O2              -->   O3              <-- OZONE formed
     NO  +   O3              -->   NO2  +  O2      <-- cycle turns

     hydrocarbons + O3 / O   -->   formaldehyde HCHO
                                   acrolein  CH2=CH-CHO
                                   PAN
```

```
  +---------------------------------------------------------------------+
  |   PAN  =  PEROXYACETYL NITRATE  ,  CH3 - CO - OO - NO2              |
  |                                                                     |
  |   * powerful EYE IRRITANT (the thing that makes eyes water)         |
  |   * highly TOXIC TO PLANTS - bronzing and glazing of leaves         |
  +---------------------------------------------------------------------+
```

| Control measure for photochemical smog | Why it works |
|---|---|
| **Catalytic converters** in vehicles | convert NO and CO into N2 and CO2 before release |
| **Unleaded petrol** | lead poisons the converter's catalyst |
| Plant **Pinus, Juniperus, Quercus, Pyrus, Vitis** | these trees metabolise oxides of nitrogen |
| Control the **primary** pollutants NO2 and hydrocarbons | without precursors, O3 and PAN cannot form |
| CNG, public transport, better engines | fewer emissions at source |

# 9. THE OZONE LAYER AND ITS DEPLETION

```
  NATURAL BALANCE  (dynamic equilibrium)

     FORMATION:      O2   --(UV)-->   O  +  O
                     O  +  O2   -->   O3

     DESTRUCTION:    O3   --(UV)-->   O2  +  O
                     O3  +  O   -->   2 O2

     rate of formation  =  rate of destruction  ->  the layer is stable
```

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   THE CFC CHAIN  -  WRITE ALL THREE STEPS                           |
  |                                                                     |
  |     CF2Cl2   --(UV)-->    Cl*   +   *CF2Cl                          |
  |                                                                     |
  |     Cl*   +   O3    -->   ClO*  +   O2                              |
  |                                                                     |
  |     ClO*  +   O     -->   Cl*   +   O2      <-- Cl* IS REGENERATED  |
  |                                                                     |
  |   The last two steps repeat as a CHAIN. Chlorine acts as a          |
  |   CATALYST. ONE Cl* destroys about 100 000 ozone molecules.         |
  |                                                                     |
  +---------------------------------------------------------------------+
```

| Fact about CFCs | Detail |
|---|---|
| Other name | **freons** |
| Examples | `CFCl3` (freon-11), `CF2Cl2` (freon-12) |
| Uses | refrigerants, aerosol propellants, foam blowing, electronic cleaning |
| Why they reach the stratosphere | they are **unreactive** — nothing destroys them lower down |
| Replacement | **HFCs** (no chlorine), HCFCs |
| Treaty | **Montreal Protocol, 1987** |

```
  THE OZONE HOLE OVER ANTARCTICA  -  the four-step story

  1.  ANTARCTIC WINTER: a polar vortex isolates very cold air (< -80 C).
  2.  POLAR STRATOSPHERIC CLOUDS (ice clouds) form.
  3.  On the cloud surfaces the unreactive "reservoir" compounds react:
          ClONO2  +  H2O   -->  HOCl  +  HNO3
          ClONO2  +  HCl   -->  Cl2   +  HNO3
      The HNO3 stays locked in the ice, so it cannot re-trap the chlorine.
  4.  SPRING (Sept-Oct): sunlight returns and splits the stored chlorine:
          HOCl --(sunlight)--> *OH + Cl*
          Cl2  --(sunlight)--> 2 Cl*
      A burst of Cl* destroys ozone rapidly  ->  the OZONE HOLE.
```

| Effect of extra UV | On what |
|---|---|
| **Skin cancer**, sunburn, ageing of skin, weakened immunity | humans |
| **Cataract** of the eye, blindness | humans |
| Reduced photosynthesis, lower yields of wheat/rice/cotton | plants |
| Kills **phytoplankton** — base of the marine food chain | oceans |
| Fading of paints and dyes; degradation of plastics, rubber, fabric | materials |

# 10. WATER POLLUTION — THE NUMBERS AND THE TERMS

| Term | Meaning | Clean value | Polluted value |
|---|---|---|---|
| **DO** (dissolved oxygen) | oxygen dissolved in the water | **6–8 ppm** | below 6 ppm growth hindered; below 4 ppm fish die |
| **BOD** (biochemical oxygen demand) | oxygen **required by bacteria** to decompose the organic matter (5 days, 20 C) | **less than 5 ppm** | **17 ppm or more** |
| **DOD** (dissolved oxygen demand) | oxygen actually **consumed** from the water by decomposition | low | high |

> **HIGH BOD = DIRTY WATER.** BOD is the oxygen **demanded**, not the oxygen
> present. Students get this backwards every year.

```
  WHY HIGH BOD IS BAD  -  the chain

  organic waste --> bacteria multiply --> they consume the dissolved
  oxygen --> DO crashes --> fish suffocate --> anaerobic bacteria take
  over --> foul H2S, CH4 and NH3 --> the water body is dead.
```

```
  EUTROPHICATION  -  the seven-step chain

  1. nitrates and phosphates (fertiliser, detergent) wash into the lake
  2. the lake becomes over-enriched with NUTRIENTS
  3. explosive growth of algae  ->  ALGAL BLOOM covers the surface
  4. sunlight is BLOCKED from the plants below, which die
  5. algae die too; bacteria decompose all the dead matter
  6. decomposition CONSUMES the dissolved oxygen; BOD shoots up
  7. FISH AND AQUATIC LIFE DIE; the lake becomes a stinking swamp
```

| Pollutant in water | Effect | Signature keyword |
|---|---|---|
| **Pathogens** (E. coli, Streptococcus faecalis) from sewage | cholera, typhoid, dysentery, jaundice, gastroenteritis, polio | "human and animal excreta" |
| **Organic waste** | raises BOD, kills fish by oxygen depletion | "BOD" |
| **Pesticides (DDT, BHC, aldrin)** | non-biodegradable, fat-soluble, **biomagnification** up the food chain; nerve and liver damage, cancer, thin eggshells | "biomagnification" |
| **Mercury Hg** | converted by bacteria to **methyl mercury**, accumulates in fish; **MINAMATA DISEASE** — numbness, brain damage, blindness | "Minamata" |
| **Lead Pb** | damages kidney, liver, brain, CNS; anaemia; reduced intelligence in children | "leaded petrol, lead pipes" |
| **Cadmium Cd** | kidney damage, **itai-itai disease** (soft bones) | "itai-itai" |
| **Fluoride F-** | 1 ppm prevents tooth decay (forms **fluorapatite**); >2 ppm **brown mottling** of teeth; >10 ppm **skeletal fluorosis** | "mottling" |
| **Nitrate NO3-** | >50 ppm causes **methaemoglobinaemia** = **BLUE BABY SYNDROME** | "blue baby" |
| **Sulphate SO4 2-** | >500 ppm gives a **laxative effect** | "laxative" |

```
  +---------------------------------------------------------------------+
  |   INTERNATIONAL STANDARDS FOR DRINKING WATER  -  the four numbers   |
  +---------------------------------------------------------------------+
  |                                                                     |
  |      FLUORIDE   F-        1   ppm                                   |
  |      LEAD       Pb        50  ppb      <-- ppb , NOT ppm !          |
  |      NITRATE    NO3-      50  ppm                                   |
  |      SULPHATE   SO4 2-    500 ppm                                   |
  |                                                                     |
  |   MEMORY:  1 , 50 tiny , 50 , 500                                   |
  |            ppm = mg/L    ppb = microgram/L  (1000 times smaller)    |
  |                                                                     |
  +---------------------------------------------------------------------+
```

# 11. SOIL POLLUTION — THE PESTICIDE FAMILY

| Class | What it kills | Examples | Harmful effect |
|---|---|---|---|
| **Insecticides** (organochlorine) | insects | **DDT**, BHC (gammexane), aldrin, dieldrin, endrin | **non-biodegradable**, persist for years, fat-soluble, biomagnify, insects develop resistance, kill useful bees and earthworms |
| **Insecticides** (organophosphate) | insects | malathion, parathion | biodegradable but **acutely toxic** — attack the nervous system |
| **Herbicides** | weeds | sodium chlorate `NaClO3`, sodium arsenite `Na3AsO3`, **2,4-D**, 2,4,5-T | arsenic-based ones highly toxic to mammals; kill soil micro-organisms; some are teratogenic |
| **Fungicides** | fungi | **organomercury compounds**, Bordeaux mixture (`CuSO4` + lime) | organomercury decomposes to give toxic **mercury** — brain and kidney damage |

```
  THE THREE SAFE EXAMPLES TO MEMORISE  (one per class)

     INSECTICIDE  ->  DDT
     HERBICIDE    ->  2,4-D   (or sodium chlorate)
     FUNGICIDE    ->  organomercury compound

  Giving an insecticide when a herbicide is asked = ZERO marks.
```

```
  INDUSTRIAL WASTE IN SOIL

     * fly ash, slag, plastics, glass, metal scrap, chemical sludge
     * heavy metals Pb, Hg, Cd, As, Cr accumulate and enter crops
     * acids and alkalis change soil pH and kill soil micro-organisms
     * tannery, paper mill and textile mill waste makes soil barren
     * radioactive waste is extremely persistent

     RESULT: loss of fertility, lower crop yield, toxins move up the
             food chain into human food.
```

# 12. CONTROL STRATEGIES AND WASTE MANAGEMENT

| Stage | What is done |
|---|---|
| **Collection** | segregate at source into biodegradable and non-biodegradable bins; municipal collection |
| **Disposal — landfill** | dumped in low-lying land and covered with soil; cheap but can pollute groundwater |
| **Disposal — composting** | biodegradable waste rotted into useful **manure** |
| **Disposal — incineration** | burnt at high temperature; cuts volume greatly, gases must be scrubbed |
| **Recycling** | paper, glass, plastic, aluminium, iron scrap returned to industry as raw material |

```
  AIR   :  electrostatic precipitators, cyclone collectors, scrubbers,
           bag filters, catalytic converters, low-sulphur fuel,
           unleaded petrol, CNG, solar/wind energy, afforestation

  WATER :  treat effluent before discharge, sewage treatment plants,
           ban phosphate detergents, controlled fertiliser use

  SOIL  :  biofertilisers and biopesticides, crop rotation,
           organic manure, proper industrial solid waste disposal

  THE 3 R's :   REDUCE  ,  REUSE  ,  RECYCLE
```

# 13. GREEN CHEMISTRY

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   GREEN CHEMISTRY  =  using the existing knowledge and principles   |
  |   of chemistry to DESIGN processes and products so that harmful     |
  |   substances are NEVER PRODUCED in the first place, minimising      |
  |   damage to the environment.                                        |
  |                                                                     |
  |   Old thinking: clean up the pollution afterwards.                  |
  |   Green thinking: do not create the pollution at all.               |
  |                                                                     |
  +---------------------------------------------------------------------+
```

| Principle (short form) | Meaning |
|---|---|
| **Prevent waste** | better to prevent than to treat afterwards |
| **Atom economy** | maximise the atoms of reactant that end up in the product |
| **Less hazardous synthesis** | use and make substances of low toxicity |
| **Safer chemicals** | design products that work but are non-toxic |
| **Safer solvents** | prefer **water**, or no solvent at all |
| **Energy efficiency** | run reactions at room temperature and pressure |
| **Renewable feedstock** | raw materials from plants, not petroleum |
| **Reduce derivatives** | avoid needless protection/deprotection steps |
| **Catalysis** | use catalysts (small amount, reusable) not stoichiometric reagents |
| **Design for degradation** | products should break down harmlessly after use |
| **Real-time monitoring** | watch the process to stop pollution forming |
| **Accident prevention** | choose substances that minimise fires and explosions |

### THE THREE APPLICATIONS — the exam asks for these by name

| Application | OLD chemical (bad) | GREEN chemical (good) | Why better |
|---|---|---|---|
| **Dry cleaning of clothes** | tetrachloroethene `Cl2C=CCl2` | **liquefied CO2** + suitable detergent | old one contaminates groundwater and is **carcinogenic**; liquid CO2 is non-toxic and leaves no residue |
| **Bleaching of paper** | **chlorine gas** | **hydrogen peroxide H2O2** + catalyst | Cl2 makes toxic chlorinated compounds; H2O2 gives only water and oxygen |
| **Synthesis in aqueous medium** | toxic organic solvents | **water** as solvent | `CH2=CH2 + O2 --(Pd(II)/Cu(II) in water)--> CH3CHO`, ~90 % yield; water is cheap, non-toxic, non-flammable |

```
  ALSO WORTH A LINE:
     * H2O2 used for bleaching clothes - better results, less water
     * CFL / LED lamps instead of filament bulbs - energy saving
     * bio-pesticides (neem based) instead of persistent chemicals
     * ethanol-blended petrol - less CO and hydrocarbon emission
```
