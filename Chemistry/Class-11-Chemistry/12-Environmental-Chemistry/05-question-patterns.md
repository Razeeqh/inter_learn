# Environmental Chemistry — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The wording changes every year. The shape does not.

In a numerical chapter a pattern is a calculation method. In THIS chapter a
pattern is a **recall skeleton** — the fixed set of points that earns the marks.
Learn the skeleton and you can write the answer even on a bad day.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed points to write, in order
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — DEFINE A BASIC TERM                                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is a sink / receptor / pollutant / contaminant /
            speciation / threshold limit value?"
  METHOD    1. One clean sentence of definition.
            2. ONE example.
            That is the whole answer. Two lines.
                sink      - the medium that RETAINS the pollutant
                            (ocean for CO2)
                receptor  - the thing AFFECTED (man, a lake)
                pollutant - present ABOVE its natural level, causing harm
                contaminant - NOT naturally present there at all
                speciation - the different CHEMICAL FORMS of an element
                            (Cr III harmless, Cr VI toxic)
  TRAP      Forgetting the example. In a 2-mark definition the example is
            usually the second mark. Never skip it.
```

```
  PATTERN 2 — CONTRAST TWO TERMS                                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between ..." / "Differentiate ..."
            pollutant vs contaminant ; biodegradable vs non-biodegradable ;
            viable vs non-viable ; primary vs secondary ; DO vs BOD
  METHOD    1. Write BOTH definitions, one under the other.
            2. Give ONE example of each.
            3. If space allows, add the one-line consequence.
  TRAP      Defining only one of them. You must show BOTH sides for a
            "distinguish" question, even if one seems obvious.
```

```
  PATTERN 3 — NAME THE SEGMENTS OR THE LAYERS                     2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Name the segments of the environment" /
            "Name the layers of the atmosphere"
  METHOD    SEGMENTS:  atmosphere, hydrosphere, lithosphere, biosphere
                       (one line of description each)
            LAYERS (bottom to top):
                       troposphere    0-10 km    temperature DECREASES
                       stratosphere  10-50 km    temperature INCREASES
                       mesosphere    50-85 km    temperature DECREASES
                       thermosphere  above 85 km temperature INCREASES
  TRAP      Getting the ORDER wrong, or forgetting the temperature
            behaviour, which is half the answer. Memory: "The Sun Makes
            Toast" and the pattern DOWN-UP-DOWN-UP.
```

```
  PATTERN 4 — SOURCE AND EFFECT OF A NAMED GASEOUS POLLUTANT   2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the sources and harmful effects of SO2 / NOx / CO /
            CO2 / hydrocarbons."
  METHOD    Always answer under THREE headings:
                1. SOURCE      - where it comes from
                2. EFFECT ON MAN
                3. EFFECT ON PLANTS or on the ENVIRONMENT
            Add the acid-rain or smog link if it applies.
  TRAP      Writing only the effect on man. For SO2 the word CHLOROSIS
            (effect on plants) is usually a separate mark.
```

```
  PATTERN 5 — WHY IS CARBON MONOXIDE POISONOUS?                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is CO poisonous?" / "What is carboxyhaemoglobin?"
  METHOD    1. CO binds to HAEMOGLOBIN, about 300 TIMES more strongly
               than oxygen.
            2. Write:   Hb + CO --> CARBOXYHAEMOGLOBIN
            3. That haemoglobin can no longer carry oxygen.
            4. Result: headache, dizziness, unconsciousness, death by
               suffocation.
  TRAP      Writing "CO reacts with oxygen in the blood". WRONG. It
            reacts with HAEMOGLOBIN. Spell "carboxyhaemoglobin" right -
            it IS the mark.
```

```
  PATTERN 6 — PARTICULATE POLLUTANTS: TYPES                       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are particulate pollutants? Explain the types."
  METHOD    1. Definition: tiny SOLID or LIQUID particles suspended in air.
            2. The five types, each with its ORIGIN and an EXAMPLE:
                  DUST  - crushing/grinding of solids (fly ash, sand)
                  MIST  - condensation or spraying of liquids
                  FUMES - condensation of metal or solvent VAPOURS
                  SMOKE - COMBUSTION of organic matter
                  SMOG  - smoke + fog
            3. Viable (living: bacteria, fungi, algae, moulds) vs
               non-viable (dust, mist, fumes, smoke).
            4. Effect: particles below 1 micrometre reach the alveoli and
               stay -> asthma, bronchitis, lung cancer.
  TRAP      Confusing FUMES (from vapours) with SMOKE (from combustion).
            They are different origins, and examiners test exactly this.
```

```
  PATTERN 7 — ACID RAIN                                        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is acid rain?" / "How is it formed?" / "Effects of
            acid rain"
  METHOD    1. DEFINITION: rain with pH BELOW 5.6 (normal rain is 5.6
               because of dissolved CO2 forming H2CO3).
            2. CAUSE: H2SO4 and HNO3 from SO2 and NO2.
            3. EQUATIONS:
                  2 SO2 + O2 --> 2 SO3 ;  SO3 + H2O --> H2SO4
                  2 NO + O2 --> 2 NO2 ;  4 NO2 + O2 + 2 H2O --> 4 HNO3
            4. FOUR EFFECTS, one line each:
                  buildings  - CaCO3 + H2SO4 --> CaSO4 + H2O + CO2
                               (stone leprosy; the Taj Mahal)
                  soil       - nutrients leached, toxic Al3+ released
                  plants     - leaves damaged, forests destroyed
                  water      - below pH 4 fish die, "dead lakes"
  TRAP      Writing "pH less than 7". The number that scores is 5.6.
```

```
  PATTERN 8 — GREENHOUSE EFFECT AND GLOBAL WARMING             2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the greenhouse effect?" / "Explain global warming"
  METHOD    1. Earth absorbs sunlight, re-radiates it as INFRARED.
            2. Greenhouse gases are TRANSPARENT to incoming short-
               wavelength sunlight but ABSORB outgoing long-wavelength
               infrared -> heat is trapped.
            3. Name the gases in ORDER:
                  CO2 (50-60%) > CH4 (20%) > CFC (14%) > N2O (6%) > O3
            4. Natural effect is ESSENTIAL (-18 C without it). The
               problem is the ENHANCED effect.
            5. Consequences: ice melts, sea level rises, coastal
               flooding, changed rainfall, crop failure, disease spread.
  TRAP      Do not say the greenhouse effect is entirely bad. Stating
            that it is natural and necessary, and that the PROBLEM is
            the enhanced effect, often carries a mark.
```

```
  PATTERN 9 — CLASSICAL vs PHOTOCHEMICAL SMOG                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between classical and photochemical smog"
            (THE most-asked question of this chapter)
  METHOD    Draw a TABLE with these rows - do not write prose:
                  other name    London        /  Los Angeles
                  nature        REDUCING      /  OXIDISING
                  climate       cool + humid  /  warm + dry + sunny
                  sunlight      not needed    /  essential
                  pollutants    SO2+smoke+fog /  NO2 + hydrocarbons
                  source        coal          /  automobile exhaust
                  products      H2SO4 aerosol /  O3, PAN, aldehydes
                  appearance    grey-black    /  brown haze
  TRAP      Swapping reducing and oxidising. Anchor it:
            SO2 is a REDUCING agent -> classical is reducing.
            O3 and PAN are OXIDISING agents -> photochemical is oxidising.
```

```
  PATTERN 10 — CHEMISTRY OF PHOTOCHEMICAL SMOG                    4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is photochemical smog formed? Write the reactions."
  METHOD    Write the equations IN ORDER - they carry most of the marks:
                  N2 + O2 --(high temp in engine)--> 2 NO
                  2 NO + O2 --> 2 NO2
                  NO2 --(sunlight, hv)--> NO + O          <-- photo step
                  O + O2 --> O3
                  NO + O3 --> NO2 + O2
                  hydrocarbons + O3/O --> HCHO, acrolein, PAN
            Then name PAN in full: PEROXYACETYL NITRATE, CH3-CO-OO-NO2.
  TRAP      Leaving out the sunlight condition on the NO2 arrow. That
            step is WHY it is called PHOTOchemical - it is the key mark.
```

```
  PATTERN 11 — EFFECTS AND CONTROL OF PHOTOCHEMICAL SMOG          4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Harmful effects of photochemical smog" / "How is it
            controlled?"
  METHOD    EFFECTS (five points):
                  1. severe eye irritation (PAN, formaldehyde)
                  2. nose and throat irritation, cough, chest pain
                  3. plant damage - PAN bronzes and glazes the leaves
                  4. ozone CRACKS RUBBER, corrodes metal and stone
                  5. reduced visibility, brown air
            CONTROL (four points):
                  1. CATALYTIC CONVERTERS - convert NO and CO to N2, CO2
                  2. unleaded petrol, CNG, public transport
                  3. plant Pinus, Juniperus, Quercus, Pyrus, Vitis -
                     they metabolise oxides of nitrogen
                  4. control the PRIMARY pollutants so the SECONDARY
                     ones cannot form
  TRAP      Forgetting the plant names. They look trivial but they are a
            distinct, easily awarded mark.
```

```
  PATTERN 12 — PRIMARY vs SECONDARY POLLUTANTS                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are secondary pollutants? Give examples."
  METHOD    PRIMARY   - emitted AS SUCH from the source
                        SO2, NO, NO2, CO, unburnt hydrocarbons
            SECONDARY - FORMED IN THE AIR by reaction between primaries
                        O3, PAN, formaldehyde, acrolein, H2SO4 aerosol
  TRAP      Listing SO2 or CO as secondary. They come straight out of
            the chimney or tailpipe - always primary.
```

```
  PATTERN 13 — THE OZONE LAYER AND ITS NATURAL BALANCE            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is ozone formed in the stratosphere?" / "Why is the
            ozone layer important?"
  METHOD    1. It is a shield absorbing harmful UV-B and UV-C radiation.
            2. FORMATION:    O2 --(UV)--> O + O ;  O + O2 --> O3
            3. DESTRUCTION:  O3 --(UV)--> O2 + O ;  O3 + O --> 2 O2
            4. The two rates are EQUAL, so the amount stays constant -
               a dynamic equilibrium.
  TRAP      Writing only the formation. The examiner wants both halves,
            because the whole point is the BALANCE that CFCs upset.
```

```
  PATTERN 14 — OZONE DEPLETION BY CFCs                            4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How do CFCs deplete the ozone layer?"
            (the second most-asked question of the chapter)
  METHOD    1. CFCs are UNREACTIVE, so they survive and drift up into
               the stratosphere.
            2. Write ALL THREE equations:
                  CF2Cl2 --(UV)--> Cl* + *CF2Cl
                  Cl*  + O3 --> ClO* + O2
                  ClO* + O  --> Cl*  + O2
            3. State explicitly: the Cl* radical is REGENERATED, so the
               last two steps repeat as a CHAIN REACTION.
            4. Chlorine acts as a CATALYST; ONE Cl* destroys about
               100 000 ozone molecules.
            5. Destruction now outruns formation -> the layer thins.
  TRAP      Stopping after step 2. The REGENERATION in step 3 is the
            entire point of the question. Without it you have written
            an ordinary reaction, not a chain.
```

```
  PATTERN 15 — THE OZONE HOLE OVER ANTARCTICA                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the ozone hole? How is it formed?" / "Why over
            Antarctica?"
  METHOD    1. Definition: a region of SEVERELY DEPLETED stratospheric
               ozone over ANTARCTICA, appearing in SPRING.
            2. Winter: a polar vortex isolates air below -80 C.
            3. POLAR STRATOSPHERIC CLOUDS (ice clouds) form.
            4. On their surfaces the reservoir compounds react:
                  ClONO2 + H2O --> HOCl + HNO3
                  ClONO2 + HCl --> Cl2  + HNO3
               (the HNO3 stays trapped in the ice)
            5. Spring sunlight splits them:
                  HOCl --(hv)--> *OH + Cl*  ;  Cl2 --(hv)--> 2 Cl*
            6. A burst of Cl* destroys ozone rapidly.
  TRAP      Calling it a physical hole, or placing it over the ARCTIC.
            It is ANTARCTICA, and it is a THINNING, not a hole.
```

```
  PATTERN 16 — EFFECTS OF OZONE DEPLETION                      2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Harmful effects of ozone layer depletion / of increased UV"
  METHOD    Answer under FOUR headings:
                  HUMANS    - skin cancer, ageing of skin, sunburn,
                              CATARACT, weakened immunity
                  PLANTS    - less photosynthesis, lower crop yields,
                              death of marine PHYTOPLANKTON
                  MATERIALS - paints and dyes fade; plastics, rubber and
                              fabrics degrade
                  CLIMATE   - higher surface temperature, more evaporation
            Add: the MONTREAL PROTOCOL (1987) banned CFCs; HFCs replace
            them.
  TRAP      Giving only the human effects. Four headings, four marks.
```

```
  PATTERN 17 — BOD, DOD AND DISSOLVED OXYGEN                   2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is BOD?" / "Why is a high BOD harmful?" / "Distinguish
            DO and BOD"
  METHOD    1. BOD = oxygen REQUIRED BY BACTERIA to decompose the organic
               matter in a given volume of water (5 days at 20 C).
            2. DOD = the dissolved oxygen actually CONSUMED by that
               decomposition.
            3. DO  = the oxygen actually PRESENT; clean water 6-8 ppm.
            4. Numbers:  clean water BOD < 5 ppm ; polluted BOD >= 17 ppm
            5. Why high BOD is bad - write the chain:
                  organic waste -> bacteria multiply -> they consume the
                  dissolved oxygen -> DO crashes -> fish suffocate ->
                  anaerobic decay -> H2S, CH4, NH3, foul water
  TRAP      Saying BOD is the oxygen PRESENT. It is the oxygen DEMANDED.
            HIGH BOD = DIRTY WATER. Students reverse this every year.
```

```
  PATTERN 18 — EUTROPHICATION                                  2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is eutrophication?" / "Explain how a lake dies"
  METHOD    Write the CHAIN in order - each arrow is worth marks:
                  1. nitrates and phosphates (fertiliser, detergent)
                     wash into the lake
                  2. the water becomes over-enriched with NUTRIENTS
                  3. explosive algal growth -> ALGAL BLOOM
                  4. sunlight blocked -> plants below die
                  5. algae die; bacteria decompose the dead matter
                  6. decomposition CONSUMES the dissolved oxygen,
                     BOD rises
                  7. fish and aquatic life DIE; the lake becomes a
                     stinking swamp
  TRAP      Writing only "excess nutrients cause algae to grow" and
            stopping. The marks are in the OXYGEN DEPLETION at the end -
            that is why eutrophication kills.
```

```
  PATTERN 19 — CAUSES OF WATER POLLUTION                          4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are the causes of water pollution?"
  METHOD    Six numbered headings, one or two lines each:
                  1. PATHOGENS - from sewage; E. coli, Streptococcus
                     faecalis; cholera, typhoid, dysentery, jaundice
                  2. ORGANIC WASTES - raise the BOD, strip the oxygen
                  3. INORGANIC WASTES - heavy metals, acids, salts
                  4. AGRICULTURAL CHEMICALS - fertiliser (eutrophication)
                     and pesticides (biomagnification)
                  5. INDUSTRIAL EFFLUENTS, including hot water
                     (thermal pollution)
                  6. OIL SPILLS
  TRAP      Writing a vague paragraph about "dirty water". Numbered
            headings with a named example each is what scores.
```

```
  PATTERN 20 — A SPECIFIC WATER POISON AND ITS DISEASE            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What causes Minamata disease / blue baby syndrome /
            itai-itai / mottling of teeth?"
  METHOD    Learn these five pairs and the mechanism in one line:
                  MERCURY  -> methyl mercury in fish -> MINAMATA disease
                              (numbness, brain damage, blindness)
                  CADMIUM  -> ITAI-ITAI disease (soft bones), kidney
                  LEAD     -> kidney, liver, brain, CNS damage, anaemia
                  NITRATE  -> above 50 ppm, BLUE BABY SYNDROME
                              (methaemoglobinaemia)
                  FLUORIDE -> above 2 ppm mottling; above 10 ppm bone
                              and kidney damage
  TRAP      Mixing up Minamata (mercury) with itai-itai (cadmium).
            Memory: M for Minamata, M for Mercury.
```

```
  PATTERN 21 — DRINKING WATER STANDARDS                           2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Give the international standards for drinking water for
            fluoride / lead / nitrate / sulphate."
  METHOD    Write the four numbers WITH their consequence:
                  FLUORIDE  1 ppm     ->  >2 ppm mottling of teeth,
                                          >10 ppm bone and kidney damage
                  LEAD      50 ppb    ->  kidney, liver, brain damage
                  NITRATE   50 ppm    ->  blue baby syndrome
                  SULPHATE  500 ppm   ->  laxative effect
  TRAP      Writing lead as 50 ppm. It is 50 parts per BILLION - a
            thousand times stricter. Also remember that about 1 ppm of
            fluoride is BENEFICIAL, not harmful.
```

```
  PATTERN 22 — CLASSIFY A PESTICIDE                               2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Give an example of a herbicide / insecticide / fungicide"
            or "Classify DDT / 2,4-D / Bordeaux mixture"
  METHOD    INSECTICIDE (kills insects) - DDT, BHC, aldrin, dieldrin,
                                          endrin, malathion, parathion
            HERBICIDE   (kills weeds)   - 2,4-D, 2,4,5-T, NaClO3,
                                          Na3AsO3
            FUNGICIDE   (kills fungi)   - organomercury compounds,
                                          Bordeaux mixture (CuSO4 + lime)
  TRAP      Answering with an insecticide when a herbicide is asked.
            Zero marks. Memorise ONE safe example per class:
            DDT / 2,4-D / organomercury.
```

```
  PATTERN 23 — SOIL POLLUTION BY PESTICIDES                       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write a note on soil pollution" / "Effects of pesticides"
  METHOD    1. Three classes with examples (see Pattern 22).
            2. ORGANOCHLORINES (DDT, BHC) are NON-BIODEGRADABLE, fat-
               soluble, and BIOMAGNIFY up the food chain to man.
            3. Insects develop RESISTANCE, so doses keep rising.
            4. ORGANOPHOSPHATES are biodegradable but ACUTELY TOXIC to
               the nervous system.
            5. Herbicides based on ARSENIC are highly toxic; some are
               teratogenic.
            6. Fungicides based on organomercury release toxic MERCURY.
            7. Add industrial waste: heavy metals, acids, fly ash make
               the soil barren.
  TRAP      Forgetting the word BIOMAGNIFICATION. It is the single
            technical term the examiner is scanning for.
```

```
  PATTERN 24 — STRATEGIES TO CONTROL POLLUTION                    4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How can environmental pollution be controlled?" /
            "Explain waste management"
  METHOD    Three stages:
                  COLLECTION - segregate at source into biodegradable
                               and non-biodegradable
                  DISPOSAL   - landfill, COMPOSTING into manure,
                               incineration, sewage treatment
                  RECYCLING  - paper, glass, plastic, metal returned to
                               industry as raw material
            Add one line each for air (precipitators, catalytic
            converters, clean fuel, afforestation), water (effluent
            treatment, ban phosphate detergents) and soil (biofertilisers,
            biopesticides).
            Finish with the three R's: REDUCE, REUSE, RECYCLE.
  TRAP      Writing only "we should not pollute". Name the SPECIFIC
            methods - composting, incineration, landfill, recycling.
```

```
  PATTERN 25 — GREEN CHEMISTRY: DEFINITION AND PRINCIPLES      2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is green chemistry?" / "State its principles"
  METHOD    1. DEFINITION: using the knowledge and principles of
               chemistry to DESIGN processes and products so that
               harmful substances are NEVER PRODUCED, minimising damage
               to the environment.
            2. It uses non-toxic reagents, safe solvents (preferably
               water) and maximum ATOM ECONOMY.
            3. If principles are asked, give at least four:
                  prevent waste ; atom economy ; safer solvents ;
                  energy efficiency ; renewable feedstock ; catalysis ;
                  design for degradation
  TRAP      Describing pollution CONTROL instead. Green chemistry is
            PREVENTION at the design stage, not cleaning up afterwards.
            Say that contrast explicitly - it usually earns a mark.
```

```
  PATTERN 26 — GREEN CHEMISTRY APPLICATIONS                       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain the applications of green chemistry"
  METHOD    For EACH application give THREE things: the OLD chemical,
            the NEW chemical, and WHY the new one is better.
                  1. DRY CLEANING
                     old: tetrachloroethene Cl2C=CCl2 (carcinogenic,
                          pollutes groundwater)
                     new: LIQUEFIED CO2 + a suitable detergent
                     why: non-toxic, leaves no residue
                  2. BLEACHING PAPER
                     old: chlorine gas (toxic chlorinated by-products)
                     new: HYDROGEN PEROXIDE H2O2 + catalyst
                     why: gives only water and oxygen
                  3. SYNTHESIS IN AQUEOUS MEDIUM
                     old: toxic organic solvents
                     new: WATER as the solvent
                     eg:  CH2=CH2 + O2 --(Pd(II)/Cu(II) in water)-->
                          CH3CHO , about 90 % yield
  TRAP      Naming the new chemical but not the old one, or not saying
            WHY it is better. The comparison IS the answer.
```

```
  PATTERN 27 — TROPOSPHERIC POLLUTION ESSAY                       8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write an essay on tropospheric pollution" (rare in Section C)
  METHOD    1. Definition + the two divisions (gaseous, particulate).
            2. GASEOUS - the six pollutants, each with SOURCE and
               EFFECT: SO2, NOx, CO, CO2, hydrocarbons, O3.       ~4 marks
            3. PARTICULATE - dust, mist, fumes, smoke, smog;
               viable vs non-viable; size and lung damage.        ~2 marks
            4. The consequences that follow - acid rain, greenhouse
               effect, smog.                                      ~1 mark
            5. One line of introduction and conclusion.           ~1 mark
  TRAP      Spending the whole answer on one pollutant. Spread the ink
            evenly - the marks are spread evenly.
```

```
  PATTERN 28 — "GIVE REASONS" / ONE-LINE WHY QUESTIONS             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why does ...?" - a short causal question.
  METHOD    Learn these standard answers verbatim:
              Why does the stratosphere get warmer with height?
                 -> ozone absorbs UV and releases the energy as heat
              Why is classical smog reducing?
                 -> it contains SO2, a reducing agent
              Why is photochemical smog oxidising?
                 -> it contains O3, NO2 and PAN, all oxidising agents
              Why do CFCs reach the stratosphere?
                 -> they are chemically unreactive, so nothing destroys
                    them in the troposphere
              Why is the ozone hole over Antarctica?
                 -> polar stratospheric clouds form in the very cold
                    winter vortex and release chlorine in the spring
              Why is a high BOD harmful?
                 -> bacteria strip the dissolved oxygen and fish
                    suffocate
              Why is 1 ppm fluoride added to water?
                 -> it converts tooth enamel into harder fluorapatite
                    and prevents tooth decay
  TRAP      Answering "because it is harmful". Every one of these wants
            a MECHANISM, not a value judgement.
```

```
  PATTERN 29 — MATCH / MCQ RECALL                              objective
  ------------------------------------------------------------------------
  TRIGGER   Any competitive-exam question in this chapter.
  METHOD    Match by SIGNATURE KEYWORD - one word decides the answer:
              carboxyhaemoglobin -> CO
              chlorosis          -> SO2
              5.6                -> acid rain
              London / reducing  -> classical smog
              Los Angeles / PAN  -> photochemical smog
              Antarctica/ spring -> ozone hole
              Montreal           -> CFCs and ozone
              Kyoto / Paris      -> greenhouse gases
              50 ppb             -> lead
              blue baby          -> nitrate
              Minamata           -> mercury
              itai-itai          -> cadmium
              2,4-D              -> herbicide
              liquid CO2         -> green dry cleaning
  TRAP      Overthinking. These are pure recall. If you know the
            keyword, answer in 10 seconds and move on.
```

```
  PATTERN 30 — MIXED "SHORT NOTES" QUESTION                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write short notes on: (a) ... (b) ..."
  METHOD    Give each note the SAME structure:
                  1. one-line definition
                  2. cause or mechanism (with an equation if one exists)
                  3. two or three effects
            Never write more than about six lines per note.
  TRAP      Writing a long essay on the first note and running out of
            time for the second. Split the time equally - the marks are
            split equally.
```

# GUARANTEED-MARKS PLAN FOR THIS CHAPTER

```
  STEP 1   Accept the honest arithmetic.

           This chapter gives you ONE Section A question (2 marks) and
           ONE Section B question (4 marks) in a typical paper.
           Maximum realistic haul: 6 marks out of 60.
           You need 21 marks to pass.

           So this chapter alone is about a QUARTER of your pass mark,
           and it contains no calculations at all. For a student who
           struggles with numericals, nothing else in the syllabus is
           this cheap.
```
