# TOPIC 1 — What environmental chemistry actually is

**Environmental chemistry** is the study of the chemical reactions and chemical
species (the actual substances) found in the air, water and soil around us, and
of how human activity changes them.

Think of the Earth as a house you live in. Environmental chemistry is the study
of what you are dumping in the house, where it collects, and who gets sick.

```
  +-------------------------------------------------------------------+
  |  ENVIRONMENT  =  everything around a living organism               |
  |                  (air + water + soil + all other living things)    |
  +-------------------------------------------------------------------+
```

## The four segments of the environment

```
        +----------------------------------------------------------+
        |  ATMOSPHERE   -  the blanket of AIR around the Earth      |
        |                  (N2 78% , O2 21% , Ar 0.9% , CO2 0.03%)  |
        +----------------------------------------------------------+
        |  HYDROSPHERE  -  ALL the WATER: oceans, rivers, lakes,     |
        |                  glaciers, groundwater. About 97% of it   |
        |                  is salty sea water.                       |
        +----------------------------------------------------------+
        |  LITHOSPHERE  -  the solid CRUST of the Earth: rocks,      |
        |                  soil, minerals, mountains.                |
        +----------------------------------------------------------+
        |  BIOSPHERE    -  ALL LIVING THINGS, and the thin zone     |
        |                  where the other three segments overlap    |
        |                  and life is possible.                     |
        +----------------------------------------------------------+
```

**MEMORY HOOK:** *A-H-L-B* -> **A**ir, **H**2O, **L**and, **B**iology.

> **TRAP:** Students write "biosphere = plants and animals" and stop. Add the
> phrase *"and the region of the Earth where life exists — the zone where the
> atmosphere, hydrosphere and lithosphere meet"*. That second half is often
> worth the second mark.

## WORKED EXAMPLE — a full 2-mark answer

**Question:** Name the segments of the environment.

**Model answer (write exactly this):**
```
  The environment has four segments:

  1. ATMOSPHERE   -  the layer of air surrounding the Earth.
  2. HYDROSPHERE  -  all the water on Earth (oceans, rivers, lakes,
                     groundwater, glaciers).
  3. LITHOSPHERE  -  the solid crust of the Earth: soil, rocks, minerals.
  4. BIOSPHERE    -  all living organisms and the region where the other
                     three segments interact to support life.
```
Four named segments, one line each. That is the full 2 marks. Do not write an
essay — the examiner is counting names, not sentences.

# TOPIC 2 — The vocabulary of pollution (learn these word for word)

This is the highest-value half-hour in the chapter. These exact definitions
appear as 2-mark questions again and again.

```
  +-----------------+---------------------------------------------------+
  |  TERM           |  MEANING                                           |
  +-----------------+---------------------------------------------------+
  |  POLLUTION      |  the undesirable change in the physical, chemical  |
  |                 |  or biological characteristics of air, water or    |
  |                 |  soil that harms living organisms.                 |
  +-----------------+---------------------------------------------------+
  |  POLLUTANT      |  a substance present in the environment in a       |
  |                 |  concentration HIGHER than its natural level,      |
  |                 |  which produces a harmful effect.                  |
  |                 |  Example: CO2 is natural, but too much of it is a  |
  |                 |  pollutant.                                        |
  +-----------------+---------------------------------------------------+
  |  CONTAMINANT    |  a substance that does NOT occur in nature there   |
  |                 |  at all, but is introduced by human activity.      |
  |                 |  Example: DDT in a river.                          |
  +-----------------+---------------------------------------------------+
  |  RECEPTOR       |  the medium or organism that is AFFECTED by the    |
  |                 |  pollutant.                                        |
  |                 |  Example: man is the receptor of air pollutants.   |
  +-----------------+---------------------------------------------------+
  |  SINK           |  the medium that RETAINS, absorbs or interacts     |
  |                 |  with the pollutant for a long period.             |
  |                 |  Example: the ocean is a sink for CO2 ;            |
  |                 |           marble of buildings is a sink for H2SO4  |
  |                 |           in acid rain.                            |
  +-----------------+---------------------------------------------------+
  |  SPECIATION     |  the different chemical FORMS in which an element  |
  |                 |  exists in the environment, because its toxicity   |
  |                 |  depends on the form.                              |
  |                 |  Example: Cr(III) is not very harmful, but         |
  |                 |           Cr(VI) is highly toxic and carcinogenic. |
  +-----------------+---------------------------------------------------+
  |  DOSE           |  the amount of a chemical that actually enters the |
  |                 |  body of an organism.                              |
  +-----------------+---------------------------------------------------+
  |  THRESHOLD      |  the MINIMUM dose that produces a detectable       |
  |  LIMIT VALUE    |  harmful effect. Below it, no visible harm.        |
  +-----------------+---------------------------------------------------+
```

> **TRAP — pollutant vs contaminant.** This is the single most confused pair in
> the chapter. Remember it like this:
> **CONTAMINANT** = it should not be there **at all** (a stranger in the house).
> **POLLUTANT** = it belongs there, but there is now **too much** of it
> (a guest who invited 500 friends).
> A contaminant *becomes* a pollutant once it starts causing harm.

## Biodegradable vs non-biodegradable pollutants

```
  +--------------------------+--------------------------------------------+
  |  BIODEGRADABLE           |  NON-BIODEGRADABLE                          |
  +--------------------------+--------------------------------------------+
  |  Broken down by micro-   |  NOT broken down by micro-organisms.        |
  |  organisms (bacteria)    |  They persist for years or centuries.       |
  |  into simple harmless    |                                             |
  |  substances.             |                                             |
  +--------------------------+--------------------------------------------+
  |  Degrade FAST            |  Degrade very slowly or never                |
  +--------------------------+--------------------------------------------+
  |  Less dangerous in the   |  MORE dangerous - they accumulate and enter |
  |  long run                |  the food chain (biomagnification)          |
  +--------------------------+--------------------------------------------+
  |  Examples:               |  Examples:                                  |
  |   sewage, domestic       |   plastics, DDT, mercury, lead, arsenic,    |
  |   waste, vegetable       |   glass, polythene bags, metal cans,        |
  |   peels, paper, cow dung |   radioactive waste, insecticides           |
  +--------------------------+--------------------------------------------+
```

## WORKED EXAMPLE — a full 2-mark answer

**Question:** Distinguish between a biodegradable and a non-biodegradable
pollutant with one example each.

**Model answer:**
```
  BIODEGRADABLE POLLUTANTS are those which are decomposed rapidly by
  micro-organisms into simple, harmless substances.
      Example:  domestic sewage.

  NON-BIODEGRADABLE POLLUTANTS are those which cannot be decomposed by
  micro-organisms. They persist in the environment for a very long time,
  accumulate in the food chain and are therefore more harmful.
      Example:  DDT  (or plastics, or mercury salts).
```

## Why CO is so deadly — the mechanism, explained

```
  NORMAL:      Hb   +   O2    -->   OXYHAEMOGLOBIN     (a LOOSE bond)
                                    carries oxygen to your cells and
                                    lets go of it easily

  POISONING:   Hb   +   CO    -->   CARBOXYHAEMOGLOBIN (a VERY TIGHT bond,
                                    about 300 times stronger than with O2)
                                    it does NOT let go

  RESULT:      Fewer and fewer haemoglobin molecules are left free to
               carry oxygen.  The person suffocates even while breathing.
```

```
  What the symptoms look like as the level of carboxyhaemoglobin rises:

     3 - 4 %   ->   reduced ability of blood to carry oxygen
     small %   ->   headache, nervousness, drowsiness
    higher %   ->   dizziness, unconsciousness
    very high  ->   coma and DEATH
```

> **TRAP:** Do not write "CO reacts with oxygen in the blood". It does not.
> It reacts with **haemoglobin**, and the product is **carboxyhaemoglobin**.
> Spell that word correctly — it is the mark.

> **TRAP:** CO comes from **INCOMPLETE** combustion; CO2 comes from
> **COMPLETE** combustion. Examiners swap these deliberately.

## WORKED EXAMPLE — a full 2-mark answer

**Question:** Why is carbon monoxide a poisonous gas?

**Model answer:**
```
  Carbon monoxide binds to the haemoglobin of the blood about 300 times
  more strongly than oxygen does, forming a stable complex called
  CARBOXYHAEMOGLOBIN.

           Hb  +  CO   ---->   carboxyhaemoglobin

  Haemoglobin bound in this way can no longer carry oxygen to the body
  cells. The oxygen-carrying capacity of blood falls, causing headache,
  dizziness, unconsciousness and finally death by suffocation.
```

# TOPIC 5 — Tropospheric pollution: the PARTICULATE pollutants

Particulates are the tiny solid or liquid particles floating in air. If you have
ever seen a sunbeam through a window and noticed the dust dancing in it, you
have seen particulates.

```
  +----------+------------------------------------------------------------+
  |  DUST    |  SOLID particles (over 1 micrometre) produced by CRUSHING,  |
  |          |  GRINDING or blowing of solid material.                     |
  |          |  Examples: sand, fly ash from a chimney, cement dust,       |
  |          |            pollen, sawdust, stone-crusher dust.             |
  +----------+------------------------------------------------------------+
  |  MIST    |  LIQUID droplets formed by CONDENSATION of vapour in air,   |
  |          |  or by spraying a liquid.                                   |
  |          |  Examples: sprayed herbicide and insecticide mists,         |
  |          |            sulphuric acid mist.                             |
  +----------+------------------------------------------------------------+
  |  FUMES   |  Solid particles formed by the CONDENSATION of VAPOURS of   |
  |          |  metals or organic solvents.                                |
  |          |  Examples: fumes from boiling of organic solvents,          |
  |          |            oxides of metals condensing above a furnace.     |
  +----------+------------------------------------------------------------+
  |  SMOKE   |  Solid or liquid particles produced by the COMBUSTION of    |
  |          |  organic matter.                                            |
  |          |  Examples: cigarette smoke, oil smoke, smoke from burning   |
  |          |            coal, wood or garbage.                            |
  +----------+------------------------------------------------------------+
  |  SMOG    |  SMOKE + FOG.  A thick, low-lying haze that reduces          |

## Effects of particulates on health

```
  PARTICLE SIZE decides how deep it gets into your lungs:

     larger than 5 micrometre   ->  trapped in the nose and throat,
                                    coughed or sneezed out
     1 to 5 micrometre          ->  reach the middle of the lungs
     smaller than 1 micrometre  ->  reach the deepest air sacs (alveoli)
                                    and STAY there - the most dangerous

  RESULT:  irritation of the eyes and throat, coughing, asthma,
           bronchitis, lung cancer (especially with metal or asbestos
           particles), and reduced visibility on the roads.
```

# TOPIC 6 — ACID RAIN

## What it is

Normal rain is already slightly acidic, because carbon dioxide from the air
dissolves in it:

```
   CO2  +  H2O   ---->   H2CO3   (carbonic acid, a weak acid)

   That gives normal rain a pH of about  5.6
```

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |     ACID RAIN  =  rain with a pH LOWER than 5.6                     |
  |                                                                     |
  |     Caused mainly by  H2SO4  and  HNO3  dissolved in rain water     |
  |     (roughly a 60 : 40 contribution)                                |
  |                                                                     |
  +---------------------------------------------------------------------+
```

## How it forms — the equations you must write

```
  FROM SULPHUR  (mainly from burning coal)

      S      +   O2        --->   SO2
      2 SO2  +   O2        --->   2 SO3         (in air, catalysed by
                                                 particulates)
      SO3    +   H2O       --->   H2SO4         <-- SULPHURIC ACID
      (also  SO2  +  H2O   --->   H2SO3  , sulphurous acid)


  FROM NITROGEN  (mainly from vehicle engines and lightning)

      N2     +   O2   --(high temperature)-->   2 NO
      2 NO   +   O2                       -->   2 NO2
      4 NO2  +   O2   +  2 H2O            -->   4 HNO3    <-- NITRIC ACID
      (also  3 NO2 + H2O  --->  2 HNO3 + NO)
```

```
  THE WHOLE STORY AS A PICTURE

        factories        vehicles
          |  |             |  |
          v  v             v  v
        SO2, SO3          NO, NO2
             \              /
              \            /
               v          v
          oxidised in the air and dissolved in water droplets
                        |
                        v
                 H2SO4   +   HNO3
                        |
                        v
              R A I N   with pH < 5.6
             /      |        |        \
            v       v        v         v
       buildings  soil    plants    lakes/rivers
```

## Harmful effects — learn four headings

```
  +---------------+-----------------------------------------------------+
  |  ON BUILDINGS |  Marble and limestone (CaCO3) are eaten away:        |
  |  AND STATUES  |     CaCO3 + H2SO4  -->  CaSO4 + H2O + CO2           |
  |               |  This is called STONE LEPROSY. The Taj Mahal is     |
  |               |  the standard Indian example (from the Mathura       |
  |               |  refinery). Iron and steel structures corrode.       |
  +---------------+-----------------------------------------------------+
  |  ON SOIL      |  The acid dissolves and washes away the nutrients    |
  |               |  (Ca, Mg, K). It also releases toxic aluminium ions  |
  |               |  from soil minerals. Soil becomes infertile.        |
  +---------------+-----------------------------------------------------+
  |  ON PLANTS    |  Damages the waxy leaf surface, causes yellowing     |
  |               |  and death of leaves, stunts growth, reduces crop    |
  |               |  yield, destroys whole forests.                      |
  +---------------+-----------------------------------------------------+
  |  ON AQUATIC   |  Lake water becomes acidic. Below about pH 5 fish    |
  |  LIFE         |  eggs do not hatch; below pH 4 most fish die.        |
  |               |  Whole lakes become "dead lakes".                    |
  +---------------+-----------------------------------------------------+
```

## WORKED EXAMPLE — a full 4-mark answer

**Question:** What is acid rain? How is it formed? Mention its effects.

**Model answer:**
```
  DEFINITION
  Rain water having a pH less than 5.6 is called acid rain. (Normal rain
  has pH 5.6 because of dissolved CO2 forming carbonic acid.) The acidity
  is due to sulphuric acid and nitric acid formed from SO2 and NO2 in air.

  FORMATION
      2 SO2  +  O2   -->  2 SO3
      SO3    +  H2O  -->  H2SO4

      2 NO   +  O2   -->  2 NO2
      4 NO2  +  O2  +  2 H2O  -->  4 HNO3

  These acids come down dissolved in rain water.

  EFFECTS
  1. Corrodes marble and limestone buildings and statues -
        CaCO3 + H2SO4 --> CaSO4 + H2O + CO2   (damage to the Taj Mahal).
  2. Makes soil acidic, removes nutrients, releases toxic aluminium,
        and so reduces fertility.
  3. Damages leaves, stunts plant growth and destroys forests.
  4. Lowers the pH of lakes and rivers so that fish and other aquatic
        life die.
```

> **TRAP:** The number **5.6** is worth a mark on its own. Never write "acid
> rain has pH less than 7" — technically true, but it will not get the mark.

# TOPIC 7 — The GREENHOUSE EFFECT and GLOBAL WARMING

## The everyday analogy

Think of a car parked in the sun with the windows shut. Sunlight goes *in*
through the glass, the seats get hot, and the heat cannot get back *out*
through the glass. The car becomes an oven.

Certain gases in the atmosphere behave exactly like that glass.

```
  THE MECHANISM

                        \  |  /
                         \ | /            SUNLIGHT
                          \|/         (short wavelength,
                           v           passes straight through)
   - - - - - - - - - - - - | - - - - - - - - - - - - - - - - - -
                           |             LAYER OF GREENHOUSE
        ^   ^   ^   ^      |             GASES: CO2, CH4, H2O
        |   |   |   |      |             vapour, O3, CFCs, N2O
        |   |   |   |      |
   - - -|- -|- -|- -|- - - | - - - - - - - - - - - - - - - - - -
        |   |   |   |      |
        |   |   |   |      v
      TRAPPED HEAT       absorbed by the ground
      (INFRARED,           |
       long wavelength,    v
       CANNOT escape)   Earth's surface warms and re-radiates
                        the energy as INFRARED (heat) radiation
                           |
                           +--> greenhouse gases ABSORB this infrared
                                and radiate it BACK DOWN

   RESULT:  the lower atmosphere gets warmer and warmer  ->  GLOBAL WARMING
```

```
  KEY POINT TO WRITE:

     Greenhouse gases are TRANSPARENT to incoming short-wavelength
     sunlight, but OPAQUE to the outgoing long-wavelength infrared
     radiation from the Earth. That one-way behaviour traps the heat.
```

**Important balance point:** the greenhouse effect itself is *natural and
necessary*. Without it the average temperature of the Earth would be about
**-18 C** instead of about **15 C** and life would be impossible. The problem is
the **enhanced** greenhouse effect caused by human emissions.

## The greenhouse gases, in order of contribution

```
  +------+---------------------+------------------+---------------------+
  | RANK |  GAS                | APPROX SHARE OF  |  MAIN SOURCE        |
  |      |                     |  THE EFFECT      |                     |
  +------+---------------------+------------------+---------------------+
  |  1   |  CARBON DIOXIDE CO2 |  about 50 - 60 % |  burning of fossil  |
  |      |                     |                  |  fuels, deforest-   |
  |      |                     |                  |  ation             |
  +------+---------------------+------------------+---------------------+
  |  2   |  METHANE  CH4       |  about 20 %      |  paddy fields,      |
  |      |                     |                  |  cattle, marshes,   |
  |      |                     |                  |  landfills          |
  +------+---------------------+------------------+---------------------+
  |  3   |  CFCs (freons)      |  about 14 %      |  refrigerants,      |
  |      |                     |                  |  aerosol sprays     |
  +------+---------------------+------------------+---------------------+
  |  4   |  NITROUS OXIDE N2O  |  about 6 %       |  nitrogen fertil-   |
  |      |                     |                  |  isers, vehicles    |
  +------+---------------------+------------------+---------------------+
  |  5   |  OZONE  O3 and      |  the remainder   |  photochemical      |
  |      |  WATER VAPOUR       |                  |  reactions, evapor- |
  |      |                     |                  |  ation             |
  +------+---------------------+------------------+---------------------+

  MEMORY ORDER:  CO2  >  CH4  >  CFCs  >  N2O  >  O3
                 "Cows Make Cold Nitrogen Ozone"
```

> **TRAP:** CO2 is the **largest contributor overall** because there is so much
> of it — but molecule for molecule, **methane and CFCs are far more powerful**
> absorbers of infrared. If a question asks "which gas contributes most", the
> answer is CO2. If it asks "which is the most effective per molecule", it is
> the CFCs. Read the wording carefully.

## Consequences of global warming

```
  1.  Rise in the average temperature of the Earth.
  2.  Melting of polar ice caps and glaciers  ->  RISE IN SEA LEVEL
      ->  low-lying coastal cities and islands get flooded.
  3.  Change in rainfall patterns  ->  floods in some regions,
      droughts and desertification in others.
  4.  Reduced agricultural output; crops fail; food shortage.
  5.  Spread of tropical diseases (malaria, dengue) to new regions.
  6.  Death of coral reefs and loss of biodiversity.
  7.  More frequent and more violent storms and cyclones.
```

## WORKED EXAMPLE — a full 4-mark answer

**Question:** What is the greenhouse effect? How does it lead to global warming?

**Model answer:**
```
  About 75 % of the sunlight reaching the Earth is absorbed by its
  surface, which warms up and re-emits the energy as long-wavelength
  INFRARED radiation.

  Gases such as CO2, CH4, water vapour, O3, N2O and CFCs allow the short
  wavelength sunlight to pass IN, but ABSORB the outgoing infrared
  radiation and re-radiate it back towards the Earth. The heat is
  therefore trapped in the lower atmosphere.

  This warming of the Earth by the trapping of infrared radiation is
  called the GREENHOUSE EFFECT, and the gases responsible are called
  GREENHOUSE GASES. It works just like the glass of a greenhouse.

  The natural greenhouse effect is essential - without it the Earth
  would be at about -18 C. But because of the burning of fossil fuels
  and deforestation the concentration of CO2 has increased sharply, so
  more heat is trapped. This continuous rise in the average temperature
  of the Earth is called GLOBAL WARMING.

  Consequences: melting of polar ice, rise in sea level, flooding of
  coastal areas, changed rainfall, crop failure and spread of disease.
```

  +-------------------+------------------------+-------------------------+
```

**MEMORY HOOK:** *London is cold and damp -> classical, reducing.
Los Angeles is hot and sunny -> photochemical, oxidising.*

## The chemistry of photochemical smog — the four equations

```
  STEP 1   Vehicle engines run hot enough for nitrogen to burn:

              N2  +  O2  --(high temp in engine)-->  2 NO
              2 NO  +  O2  -->  2 NO2

  STEP 2   Sunlight breaks NO2 apart (this is the PHOTOCHEMICAL step):

              NO2  --(sunlight, hv)-->  NO  +  O
                                              (free oxygen atom)

  STEP 3   The free oxygen atom attacks an oxygen molecule to make OZONE:

              O  +  O2  -->  O3

  STEP 4   Ozone attacks the NO, and the cycle keeps turning:

              NO  +  O3  -->  NO2  +  O2

  STEP 5   O3 and O also attack the UNBURNT HYDROCARBONS in the exhaust,
           giving the eye-watering products:

              hydrocarbons  +  O3 / O  -->  formaldehyde (HCHO)
                                            acrolein (CH2=CH-CHO)
                                            PAN

  NET RESULT:   a brown haze full of  O3 , NO2 , HCHO , acrolein and PAN.
                These are all OXIDISING agents - hence "oxidising smog".
```

## PAN — peroxyacetyl nitrate

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   PAN  =  PEROXYACETYL NITRATE                                      |
  |                                                                     |
  |        Formula:   CH3 - CO - OO - NO2      (i.e. CH3COOONO2)        |
  |                                                                     |
  |   Formed from acetaldehyde/hydrocarbons reacting with NO2 in         |
  |   photochemical smog.                                                |
  |                                                                     |
  |   EFFECTS:  * powerful EYE IRRITANT - the thing that makes your      |
  |               eyes water in smog                                     |
  |             * highly TOXIC TO PLANTS - attacks the young leaves,     |
  |               causes bronzing and glazing of leaf surfaces, kills    |
  |               the plant                                              |
  |                                                                     |
  +---------------------------------------------------------------------+
```

## Harmful effects of photochemical smog

```
  1.  Serious irritation of the EYES (mainly from PAN and formaldehyde) -
      the eyes water and burn.
  2.  Irritation of the nose and throat; dry cough; difficulty in
      breathing; headache; chest pain.
  3.  Damages plants - PAN causes bronzing and glazing of leaves.
  4.  CRACKS RUBBER (ozone attacks the double bonds in rubber) and
      corrodes metals, stone, painted surfaces and fabrics.
  5.  Reduces visibility and gives the air a brown colour.
```

## How photochemical smog is controlled

```
  1.  CATALYTIC CONVERTERS in motor vehicles - they convert NO and CO
      in the exhaust into harmless N2 and CO2 before it leaves the
      tailpipe. This attacks the problem at the source.

  2.  Use of unleaded petrol (lead poisons the catalyst in the converter).

  3.  Plant certain trees which metabolise nitrogen oxides -
      examples: PINUS (pine), JUNIPERUS (juniper), QUERCUS (oak),
                PYRUS (pear), VITIS (grape vine).

  4.  Control of the primary precursors NO2 and hydrocarbons - if the
      precursors are not there, the secondary pollutants (O3, PAN)
      can never form.

  5.  Use of public transport, CNG vehicles and better engine design.
```

> **TRAP — primary vs secondary pollutants.** This distinction is asked directly.
> **PRIMARY** pollutants are emitted *as such* (NO, NO2, unburnt hydrocarbons,
> SO2, CO). **SECONDARY** pollutants are *made in the air* by reactions between
> primary pollutants (**O3, PAN, formaldehyde, acrolein**). Photochemical smog is
> famous precisely because its worst components are *secondary*.

## WORKED EXAMPLE — a full 4-mark answer

**Question:** What is photochemical smog? How is it formed? How can it be
controlled?

**Model answer:**
```
  DEFINITION
  The oxidising smog formed in warm, dry and sunny climates by the action
  of sunlight on the oxides of nitrogen and unburnt hydrocarbons released
  from automobile exhaust is called PHOTOCHEMICAL SMOG. It was first
  observed in Los Angeles, and it is oxidising in nature.

  FORMATION
      N2 + O2  --(hot engine)-->  2 NO ;   2 NO + O2 --> 2 NO2
      NO2  --(sunlight)-->  NO  +  O
      O  +  O2  -->  O3
      NO  +  O3  -->  NO2  +  O2
      hydrocarbons + O3 / O --> formaldehyde, acrolein and PAN
                                (peroxyacetyl nitrate, CH3COOONO2)

  The ozone, PAN, aldehydes and NO2 together form a brown, oxidising haze.

  CONTROL
  1. Fit catalytic converters to vehicles so that NO and CO are converted
     into N2 and CO2 before release.
  2. Use unleaded petrol, CNG and public transport.
  3. Plant trees such as Pinus, Juniperus, Quercus, Pyrus and Vitis which
     metabolise oxides of nitrogen.
  4. Control the primary pollutants (NO2 and hydrocarbons) - without them
     the secondary pollutants O3 and PAN cannot form.
```

# TOPIC 9 — STRATOSPHERIC POLLUTION: the ozone layer

## Why the ozone layer matters

Twenty to thirty kilometres above your head there is a thin layer of ozone gas.
If you brought all of it down to sea level it would be only about **3 mm thick**
— and that 3 mm is the only thing standing between you and the Sun's ultraviolet
radiation.

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   The OZONE LAYER acts as a PROTECTIVE SHIELD, absorbing the        |
  |   harmful UV-B and UV-C ultraviolet radiation from the Sun before   |
  |   it can reach the Earth's surface.                                 |
  |                                                                     |
  +---------------------------------------------------------------------+
```

## How ozone is made and destroyed NATURALLY (a balance)

```
  FORMATION                       (in the stratosphere, by UV light)

       O2   --(UV, hv)-->   O  +  O          (oxygen molecule is split)

       O  +  O2   -->   O3                   (ozone is formed)


  DESTRUCTION                     (also by UV light)

       O3   --(UV, hv)-->   O2  +  O

       O3  +  O   -->   2 O2


  These two happen at the SAME RATE, so the amount of ozone stays
  CONSTANT. This is called the DYNAMIC EQUILIBRIUM of ozone.

       rate of formation   =   rate of destruction    ->  layer is stable
```

**The problem:** man-made chemicals shift this balance so that destruction wins.

# TOPIC 10 — OZONE DEPLETION by chlorofluorocarbons

## What CFCs are

**Chlorofluorocarbons (CFCs)**, also called **freons**, are compounds of carbon
with chlorine and fluorine. Examples: `CFCl3` (freon-11) and `CF2Cl2` (freon-12).

They were used as:
```
  * refrigerants in refrigerators and air conditioners
  * propellants in aerosol spray cans
  * blowing agents in making plastic foam
  * cleaning solvents for electronic circuits
```

They were chosen precisely because they are **non-toxic, non-flammable and
chemically unreactive** — and that turned out to be the disaster. Being
unreactive, nothing destroys them in the troposphere, so they slowly drift
upward into the stratosphere, where the fierce UV light finally breaks them.

## THE CHAIN REACTION — write every step

```
  STEP 1   UV light breaks a C-Cl bond and releases a CHLORINE FREE RADICAL

              CF2Cl2   --(UV)-->   Cl*   +   *CF2Cl


  STEP 2   The chlorine radical attacks ozone

              Cl*  +  O3   -->   ClO*   +   O2
                                (chlorine monoxide radical)


  STEP 3   The ClO* radical reacts with a free oxygen atom
           and GIVES THE CHLORINE RADICAL BACK

              ClO*  +  O   -->   Cl*   +   O2
                                  ^
                                  |
              the SAME Cl* is now free to attack another ozone molecule


  STEP 4   Steps 2 and 3 repeat over and over - a CHAIN REACTION.

  +---------------------------------------------------------------------+
  |                                                                     |
  |   Because the chlorine radical is REGENERATED, ONE chlorine atom     |
  |   can destroy about 100 000 ozone molecules before it is finally     |
  |   removed. The chlorine acts as a CATALYST for the destruction of    |
  |   ozone - it is not used up.                                         |
  |                                                                     |
  +---------------------------------------------------------------------+
```

```
  THE CYCLE DRAWN AS A LOOP

                       O3
                        |
             Cl*  ------+------>  ClO*  +  O2
              ^                     |
              |                     |  + O
              |                     v
              +-------------------  Cl*  +  O2

         The loop never stops until the Cl* meets something else.
```

## The OZONE HOLE over Antarctica

**Why over Antarctica and nowhere else?** Because of the special conditions
there in winter and spring.

```
  STEP 1   In the ANTARCTIC WINTER, a "polar vortex" of very cold air
           (below -80 C) is isolated over the South Pole for months.

  STEP 2   At that temperature, ice clouds form high in the stratosphere.
           These are called POLAR STRATOSPHERIC CLOUDS (PSCs).

  STEP 3   Normally the chlorine is locked away in unreactive "reservoir"
           compounds - chlorine nitrate ClONO2 and hydrogen chloride HCl.
           But on the SURFACE of the polar stratospheric clouds these
           react:

              ClONO2  +  H2O   -->   HOCl  +  HNO3
              ClONO2  +  HCl   -->   Cl2   +  HNO3

           The HNO3 stays trapped in the ice, so it cannot mop the
           chlorine back up.

  STEP 4   In the ANTARCTIC SPRING (September - October) the sunlight
           returns. It splits the stored HOCl and Cl2:

              HOCl  --(sunlight)-->  *OH  +  Cl*
              Cl2   --(sunlight)-->  2 Cl*

  STEP 5   A huge burst of chlorine radicals is released all at once and
           destroys the ozone very rapidly.

              Cl*  +  O3  -->  ClO*  +  O2      (repeated endlessly)

  RESULT:  a large region of severely thinned ozone over Antarctica -
           the OZONE HOLE.
```

> **TRAP:** The ozone hole is **not a physical hole**. Write "a region where the
> concentration of ozone in the stratosphere has been severely depleted" — not
> "a hole in the sky".

> **TRAP:** The hole appears over **Antarctica (the South Pole)**, in **spring**,
> not in winter. The cold winter *prepares* the chemicals; the returning spring
> *sunlight* triggers the destruction.

## Effects of the increased UV radiation reaching the Earth

```
  +---------------+-----------------------------------------------------+
  |  ON HUMANS    |  * SKIN CANCER (UV-B damages DNA)                    |
  |               |  * ageing of skin, sunburn, wrinkles                 |
  |               |  * CATARACT of the eye, leading to blindness         |
  |               |  * weakening of the immune system                    |
  +---------------+-----------------------------------------------------+
  |  ON PLANTS    |  * damages the leaves and reduces PHOTOSYNTHESIS     |
  |               |  * lower crop yields (wheat, rice, cotton)           |
  |               |  * kills PHYTOPLANKTON in the sea, which is the base |
  |               |    of the whole marine food chain -> less fish       |
  +---------------+-----------------------------------------------------+
  |  ON MATERIALS |  * paints and dyes FADE faster                       |
  |               |  * plastics, rubber and fabrics degrade and crack    |
  +---------------+-----------------------------------------------------+
  |  ON CLIMATE   |  * more UV increases the surface temperature and     |
  |               |    causes evaporation, adding to global warming      |
  +---------------+-----------------------------------------------------+
```

**The cure:** the **Montreal Protocol (1987)** — an international agreement to
stop the production of CFCs. They are being replaced by **HFCs**
(hydrofluorocarbons, which contain no chlorine) and HCFCs.

## WORKED EXAMPLE — a full 4-mark answer

**Question:** How do chlorofluorocarbons deplete the ozone layer? Explain with
equations.

**Model answer:**
```
  CFCs (freons) such as CF2Cl2 are unreactive in the troposphere, so they
  slowly diffuse up into the stratosphere. There the intense UV radiation
  breaks the C-Cl bond and releases a chlorine free radical:

        CF2Cl2   --(UV)-->   Cl*   +   *CF2Cl

  This chlorine radical attacks ozone:

        Cl*   +   O3   -->   ClO*   +   O2

  The chlorine monoxide radical then reacts with a free oxygen atom and
  REGENERATES the chlorine radical:

        ClO*  +   O    -->   Cl*    +   O2

  Because the Cl* radical is produced again, the last two steps repeat as
  a CHAIN REACTION, and a single chlorine atom can destroy nearly
  100 000 ozone molecules. The chlorine acts as a catalyst and is not
  consumed. This continuous destruction thins the ozone layer.
```

# TOPIC 11 — WATER POLLUTION

Water covers most of the Earth, but only about **0.006 %** of it is fresh water
available to us in rivers and lakes. Polluting that tiny fraction is a serious
matter.

## The main causes

```
  +---------------------+-----------------------------------------------+
  |  CAUSE              |  DETAIL                                        |
  +---------------------+-----------------------------------------------+
  |  1. PATHOGENS       |  Disease-causing micro-organisms - bacteria    |
  |     (the most       |  and viruses - that come from HUMAN and ANIMAL |

  |                     |  Example organisms: Escherichia coli,          |
  |                     |  Streptococcus faecalis.                       |
  |                     |  Diseases: cholera, typhoid, dysentery,        |

  +---------------------+-----------------------------------------------+
  |  3. INORGANIC       |  Heavy metals (Pb, Hg, Cd, As, Ni), acids,     |
  |     WASTES          |  alkalis, salts, nitrates, phosphates,         |

```

## DISSOLVED OXYGEN, BOD and DOD

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   DISSOLVED OXYGEN (DO)                                             |
  |       The oxygen dissolved in the water. Fish need it to breathe.   |
  |       CLEAN water:  DO is about  6 to 8  ppm (mg per litre)         |
  |       If DO falls below about  6 ppm  the growth of fish is         |
  |       hindered; below about 4 ppm they start to die.                |
  |                                                                     |
  +---------------------------------------------------------------------+
  |                                                                     |
  |   BIOCHEMICAL OXYGEN DEMAND (BOD)                                   |
  |       The amount of OXYGEN required by BACTERIA to break down the   |
  |       ORGANIC MATTER present in a certain volume of water           |
  |       (usually measured over 5 days at 20 C).                       |
  |                                                                     |
  |       CLEAN water   ->  BOD less than 5 ppm                         |
  |       POLLUTED water ->  BOD of 17 ppm or more                      |
  |                                                                     |
  |       BOD is therefore a MEASURE of how much organic pollution      |
  |       the water carries.                                            |
  |                                                                     |
  +---------------------------------------------------------------------+
  |                                                                     |
  |   DISSOLVED OXYGEN DEMAND (DOD)                                     |
  |       The amount of dissolved oxygen actually CONSUMED from the     |
  |       water by the decomposition of the organic waste in it.        |
  |       A high DOD means the water is losing its oxygen fast.         |
  |                                                                     |
  +---------------------------------------------------------------------+
```

**Why is a HIGH BOD bad?** Follow the chain:

```
   lots of organic waste in the water
            |
            v
   bacteria multiply and feed on it
            |
            v
   bacteria consume the DISSOLVED OXYGEN   <-- this is the "demand"
            |
            v
   dissolved oxygen level CRASHES
            |
            v
   fish and other aquatic animals SUFFOCATE and die
            |
            v
   anaerobic bacteria take over, producing foul-smelling
   H2S, CH4 and NH3   ->  the water stinks and is dead
```

So: **high BOD = a lot of organic pollution = very little oxygen left for fish.**

> **TRAP:** BOD is not "the oxygen in the water" — that is DO. BOD is the oxygen
> **needed** (demanded). High BOD means **dirty** water, low BOD means clean.
> Students routinely get this backwards.

## EUTROPHICATION — step by step

```
  STEP 1   Fertilisers containing NITRATES and PHOSPHATES are washed off
           the farm fields into a lake or pond by rain.
              (detergents containing phosphates do the same thing)
                       |
                       v
  STEP 2   These are NUTRIENTS. The lake becomes over-rich in nutrients.
           This over-enrichment is what the word EUTROPHICATION means.
                       |
                       v
  STEP 3   ALGAE and other water plants grow explosively on the surface -
           an ALGAL BLOOM. The lake turns green and is covered over.
                       |
                       v
  STEP 4   The thick mat of algae BLOCKS THE SUNLIGHT from reaching the
           plants below the surface, which then die.
                       |
                       v
  STEP 5   The algae themselves die after a short life. Bacteria attack
           all this dead organic matter and DECOMPOSE it.
                       |
                       v
  STEP 6   The decomposing bacteria CONSUME the dissolved oxygen.
           BOD shoots up. The dissolved oxygen falls almost to zero.
                       |
                       v
  STEP 7   FISH AND OTHER AQUATIC ANIMALS DIE of suffocation.
           The lake becomes a stinking, lifeless swamp.
```

```
  ONE-LINE DEFINITION TO MEMORISE:

     EUTROPHICATION is the process in which a water body becomes
     over-enriched with nutrients (nitrates and phosphates), causing
     excessive growth of algae, which on decomposition consumes the
     dissolved oxygen and kills the aquatic life.
```

# TOPIC 12 — SOIL POLLUTION

Soil pollution is mainly caused by **pesticides** and by **industrial waste**.

## The pesticide family

A **pesticide** is any chemical used to kill an unwanted organism. The family
splits into three branches by what they kill:

```
                        P E S T I C I D E S
                              |
        +---------------------+---------------------+
        |                     |                     |
   INSECTICIDES          HERBICIDES            FUNGICIDES
   kill INSECTS          kill WEEDS            kill FUNGI
        |                     |                     |
   DDT                   Sodium chlorate       Organomercury
   BHC (gammexane)       NaClO3                 compounds
   Aldrin                Sodium arsenite        (e.g. methyl
   Dieldrin              Na3AsO3                 mercury)
   Endrin                2,4-D  (2,4-dichloro-  Bordeaux mixture
   Malathion             phenoxyacetic acid)    (CuSO4 + lime)
   Parathion             2,4,5-T
```

```
  +---------------+-----------------------------------------------------+
  |  TYPE         |  EXAMPLES AND HARMFUL EFFECTS                        |
  +---------------+-----------------------------------------------------+
  |  INSECTICIDES |  DDT, BHC, aldrin, dieldrin, endrin (organochlorine) |
  |               |  and malathion, parathion (organophosphates).       |
  |               |  * DDT and BHC are NON-BIODEGRADABLE - they stay in  |
  |               |    the soil for years and enter the food chain.      |
  |               |  * They dissolve in fat and accumulate in the body.  |
  |               |  * Insects develop RESISTANCE, so more and stronger  |
  |               |    doses are needed each year.                       |
  |               |  * Organophosphates are biodegradable but far more   |
  |               |    acutely TOXIC - they attack the nervous system    |
  |               |    and have poisoned many farm workers.              |
  |               |  * They kill the useful insects (bees, earthworms)   |
  |               |    along with the pests.                             |
  +---------------+-----------------------------------------------------+
  |  HERBICIDES   |  Sodium chlorate NaClO3, sodium arsenite Na3AsO3,    |
  |  (weed        |  2,4-D, 2,4,5-T.                                     |
  |   killers)    |  * The ARSENIC-based ones are highly TOXIC to        |
  |               |    mammals and to man.                               |
  |               |  * Most are biodegradable, but they poison the soil  |
  |               |    micro-organisms and reduce fertility.             |
  |               |  * Some are teratogenic (cause birth defects).       |
  +---------------+-----------------------------------------------------+
  |  FUNGICIDES   |  Organomercury compounds, Bordeaux mixture.         |
  |               |  * Organomercury compounds decompose in the soil to  |
  |               |    give MERCURY, which is highly toxic - it damages  |
  |               |    the brain and kidney.                             |
  +---------------+-----------------------------------------------------+
```

## Industrial waste in soil

```
  * Solid and liquid waste from factories - fly ash, slag, plastics,
    glass, metal scrap, chemical sludge.
  * Heavy metals (Pb, Hg, Cd, As, Cr) accumulate in the soil and enter
    crops, then the human body.
  * Acids and alkalis change the soil pH and destroy the useful soil
    micro-organisms.
  * Waste from tanneries, paper mills and textile mills makes soil barren.
  * Radioactive waste is extremely persistent and very dangerous.

  END RESULT: the soil loses its fertility, crop yield falls, and the
  toxins move up the food chain into our food.
```

> **TRAP:** Learn **one example per category**. Examiners ask "give an example of
> a herbicide" and a wrong-category answer scores zero. The safest three to
> memorise: **insecticide = DDT, herbicide = 2,4-D (or sodium chlorate),
> fungicide = organomercury compound.**

# TOPIC 13 — STRATEGIES TO CONTROL ENVIRONMENTAL POLLUTION

## Waste management — the three stages

```
  STAGE 1   COLLECTION
              * Segregate the waste AT SOURCE into separate bins:
                    - biodegradable  (kitchen waste, garden waste)
                    - non-biodegradable  (plastic, glass, metal)
              * Do not throw domestic waste on the roads or in drains.
              * Municipal collection vehicles carry it to the disposal
                site.

  STAGE 2   DISPOSAL
              * LANDFILL - waste is dumped in low-lying land and covered
                with soil. Cheap, but leachate can pollute groundwater.
              * COMPOSTING - biodegradable waste is allowed to rot into
                MANURE, which is a useful product.
              * INCINERATION - burning at high temperature; reduces the
                volume greatly but produces gases that must be scrubbed.
              * SEWAGE TREATMENT before releasing water into rivers.

  STAGE 3   RECYCLING
              * Paper, glass, plastic, aluminium and iron scrap are sent
                back to industry as raw material.
              * Saves natural resources and energy AND removes the
                waste at the same time.
```

## Other control measures

```
  AIR   :  * chimneys fitted with electrostatic precipitators, cyclone
             collectors, scrubbers and bag filters to trap particulates
           * catalytic converters on vehicles
           * use of low-sulphur fuel, unleaded petrol, CNG
           * shift to solar, wind and hydro energy
           * afforestation - plant trees, they absorb CO2

  WATER :  * treat industrial effluent BEFORE discharge
           * sewage treatment plants
           * ban on phosphate detergents
           * controlled use of fertiliser and pesticide

  SOIL  :  * use biofertilisers and biopesticides instead of chemicals
           * crop rotation, organic manure
           * proper disposal of industrial solid waste

  THE 3 R's :   REDUCE  -  use less in the first place
                REUSE   -  use the same item again
                RECYCLE -  turn the waste back into raw material
```

# TOPIC 14 — GREEN CHEMISTRY

## The idea in one sentence

Every method so far in this chapter has been about **cleaning up pollution after
it has been made**. Green chemistry asks a smarter question: *why make the
pollutant at all?*

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   GREEN CHEMISTRY is a way of thinking that uses the existing       |
  |   knowledge and principles of chemistry to DESIGN chemical          |
  |   processes so that they produce the least possible pollution -     |
  |   ideally none - and cause the least damage to the environment.     |
  |                                                                     |
  |   It uses non-toxic starting materials and reagents, safe           |
  |   solvents, and aims for products that are biodegradable.           |
  |                                                                     |
  +---------------------------------------------------------------------+
```

**Analogy:** end-of-pipe treatment is mopping the floor while the tap is
running. Green chemistry turns off the tap.

## The principles, in plain terms

```
   1.  PREVENT waste rather than treat it after it is formed.
   2.  ATOM ECONOMY - design the reaction so that the maximum number of
       atoms of the reactants end up in the PRODUCT, not in the waste.
   3.  Use and generate substances of LOW or NO TOXICITY.
   4.  Design SAFER CHEMICALS that still do the job.
   5.  Use SAFER SOLVENTS - preferably water, or no solvent at all.
   6.  Design for ENERGY EFFICIENCY - run reactions at room temperature
       and pressure wherever possible.
   7.  Use RENEWABLE raw materials (from plants) rather than petroleum.
   8.  Avoid unnecessary protection/deprotection steps.
   9.  Use CATALYSTS (used in small amounts, again and again) rather
       than stoichiometric reagents (used up completely).
  10.  Design products that DEGRADE harmlessly after use.
  11.  Monitor the process in REAL TIME to prevent pollution forming.
  12.  Choose substances and processes that minimise the chance of
       ACCIDENTS, fires and explosions.
```

If you can only remember three, remember: **prevent waste, atom economy, safe
solvents.**

## APPLICATIONS — the three the exam actually asks for

```
  +---------------------------------------------------------------------+
  |  1.  DRY CLEANING OF CLOTHES                                        |
  +---------------------------------------------------------------------+
  |  OLD WAY:  tetrachloroethene  Cl2C=CCl2  was used as the solvent.   |
  |            It contaminates groundwater and is CARCINOGENIC          |
  |            (suspected to cause cancer).                              |
  |                                                                     |
  |  GREEN WAY: LIQUEFIED CARBON DIOXIDE is used as the solvent,        |
  |            together with a suitable DETERGENT.                       |
  |                                                                     |
  |  WHY BETTER: liquid CO2 is non-toxic and non-carcinogenic; it       |
  |            simply evaporates back into the air afterwards and        |
  |            leaves no harmful residue; it does not pollute            |
  |            groundwater.                                              |
  |                                                                     |
  |  ALSO: H2O2 is now used for the bleaching of clothes, which gives   |
  |            better results and uses less water.                       |
  +---------------------------------------------------------------------+

  +---------------------------------------------------------------------+
  |  2.  BLEACHING OF PAPER                                             |
  +---------------------------------------------------------------------+
  |  OLD WAY:  CHLORINE GAS was used to bleach wood pulp. It produces   |
  |            toxic chlorinated organic compounds (dioxins) in the      |
  |            waste water, which are highly poisonous and persistent.   |
  |                                                                     |
  |  GREEN WAY: HYDROGEN PEROXIDE  H2O2  with a suitable CATALYST.      |
  |                                                                     |
  |  WHY BETTER: H2O2 decomposes into WATER and OXYGEN only -            |
  |            H2O2 --> H2O + [O]  - so there is no toxic by-product     |
  |            at all. The bleaching is also more efficient.             |
  +---------------------------------------------------------------------+

  +---------------------------------------------------------------------+
  |  3.  SYNTHESIS OF CHEMICALS IN AQUEOUS MEDIUM                       |
  +---------------------------------------------------------------------+
  |  EXAMPLE: ETHANAL (acetaldehyde, CH3CHO) is now made in one step    |
  |           by the oxidation of ethene in an AQUEOUS medium using a    |
  |           palladium(II) / copper(II) catalyst:                      |
  |                                                                     |
  |     CH2=CH2  +  O2  --(Pd(II)/Cu(II) in water)-->  CH3CHO           |
  |                                                                     |
  |  The yield is about 90 %.                                            |
  |                                                                     |
  |  WHY BETTER: WATER is used as the solvent instead of a toxic,        |
  |           flammable organic solvent. Water is cheap, non-toxic,      |
  |           non-flammable and causes no pollution.                     |
  +---------------------------------------------------------------------+
```

## Other green chemistry facts worth a line

```
  * Using compact fluorescent lamps (CFLs) instead of filament bulbs
    saves energy - but note CFLs contain mercury and need careful
    disposal, so LEDs are better still.
  * Neem-based and other bio-pesticides replace persistent chemical
    pesticides.
  * Ethanol blended petrol reduces the emission of CO and hydrocarbons.
```

## WORKED EXAMPLE — a full 4-mark answer

**Question:** What is green chemistry? Explain any two of its applications.

**Model answer:**
```
  DEFINITION
  Green chemistry is the use of the existing knowledge and principles of
  chemistry to design chemical processes and products in such a way that
  the generation of harmful substances is prevented and the damage to
  the environment is minimised. It uses non-toxic reagents, safe solvents
  and aims for the maximum atom economy.

  APPLICATION 1 - DRY CLEANING OF CLOTHES
  Tetrachloroethene (Cl2C=CCl2) was formerly used as the dry-cleaning
  solvent, but it contaminates groundwater and is carcinogenic. It has
  been replaced by LIQUEFIED CARBON DIOXIDE with a suitable detergent.
  Liquid CO2 is non-toxic, leaves no harmful residue and does not
  pollute groundwater.

  APPLICATION 2 - BLEACHING OF PAPER
  Chlorine gas was formerly used to bleach paper pulp and produced toxic
  chlorinated organic compounds in the effluent. It has been replaced by
  HYDROGEN PEROXIDE with a suitable catalyst. H2O2 breaks down only into
  water and oxygen, so no toxic by-product is formed.

  (Third application, if asked: the synthesis of ethanal from ethene in
   an AQUEOUS medium using a Pd(II)/Cu(II) catalyst, in about 90 % yield,
   which avoids the use of toxic organic solvents.)
```

# THE MOST COMMON MISTAKES IN THIS CHAPTER

```
  1.  Writing "pollutant" where "contaminant" is wanted, or vice versa.
  2.  Writing "acid rain pH less than 7" instead of "less than 5.6".
  3.  Saying CO reacts with oxygen in the blood - it reacts with
      HAEMOGLOBIN, forming CARBOXYHAEMOGLOBIN.
  4.  Mixing up classical (reducing, London, cold) and photochemical
      (oxidising, Los Angeles, sunny) smog.
  5.  Saying BOD is the oxygen present in water. It is the oxygen
      DEMANDED. High BOD = dirty water.
  6.  Quoting the lead standard as 50 ppm. It is 50 ppb.
  7.  Forgetting to show that the Cl* radical is REGENERATED in the
      ozone-depletion chain. That regeneration IS the answer.
  8.  Writing the ozone hole as being over the Arctic. It is ANTARCTICA.
  9.  Giving an insecticide when a herbicide is asked for.
 10.  Writing long paragraphs where the examiner wants a list. In this
      chapter, POINTS score. Paragraphs waste time.
```
