## THE 60-SECOND VERSION

The whole chapter is one sentence repeated in four places:

> **Human activity puts something into air, water or soil that does not belong
> there, in an amount nature cannot clean up, and living things suffer.**

Everything else is just filling in the blanks:

```
  WHERE            WHAT WE ADD                WHAT GOES WRONG
  --------------   ------------------------   ---------------------------
  TROPOSPHERE      SO2, NOx, CO, CO2,         acid rain, smog, global
  (0-10 km)        hydrocarbons, dust         warming, breathing disease

  STRATOSPHERE     CFCs (freons)              ozone layer thins, UV gets
  (10-50 km)                                  through, skin cancer

  WATER            sewage, fertiliser,        BOD rises, fish die,
                   pesticides, Pb, Hg         eutrophication, poisoning

  SOIL             pesticides, industrial     soil goes barren, poisons
                   waste                      enter the food chain

  THE CURE         GREEN CHEMISTRY            design the process so that
                                              the pollutant is never made
```

**If you can reproduce that table, you already have most of the 2-mark answers.**

## THE KEY BOX — the facts that unlock most questions

There is no formula in this chapter. These four boxes do the job of a formula:

```
  +-----------------------------------------------------------------------+
  |                                                                       |
  |  1.  ACID RAIN                                                        |
  |          pH of normal rain  =  5.6      (dissolved CO2)               |
  |          pH of ACID rain    <  5.6      (H2SO4 + HNO3)                |
  |                                                                       |
  |          2 SO2 + O2 --> 2 SO3 ;  SO3 + H2O --> H2SO4                  |
  |          4 NO2 + O2 + 2 H2O --> 4 HNO3                                |
  |                                                                       |
  +-----------------------------------------------------------------------+
  |                                                                       |
  |  2.  CARBON MONOXIDE                                                  |
  |          Hb + CO  -->  CARBOXYHAEMOGLOBIN                             |
  |          CO binds haemoglobin about 300 times more strongly           |
  |          than O2  ->  blood cannot carry oxygen  ->  suffocation      |
  |                                                                       |
  +-----------------------------------------------------------------------+
  |                                                                       |
  |  3.  PHOTOCHEMICAL SMOG (the chain to memorise)                       |
  |          NO2 --(sunlight)--> NO + O                                   |
  |          O + O2 --> O3                                                |
  |          NO + O3 --> NO2 + O2                                         |
  |          Hydrocarbons + O3 / O --> aldehydes, ketones, PAN            |
  |                                                                       |
  +-----------------------------------------------------------------------+
  |                                                                       |
  |  4.  OZONE DEPLETION (the chain to memorise)                          |
  |          CF2Cl2 --(UV)--> Cl* + *CF2Cl                                |
  |          Cl* + O3 --> ClO* + O2                                       |
  |          ClO* + O --> Cl* + O2         <-- Cl* comes BACK             |
  |          ONE chlorine radical destroys about 100000 ozone molecules   |
  |                                                                       |
  +-----------------------------------------------------------------------+
```

## THE FOUR LAYERS OF THE ATMOSPHERE — learn to draw this ladder

```
        ALTITUDE
           ^
    500 km |                                        THERMOSPHERE
           |                                        temperature RISES
           |                                        (up to 1200 C)
     85 km |----------------- mesopause ------------------------
           |                                        MESOSPHERE
           |                                        temperature FALLS
           |                                        (coldest layer, -100 C)
     50 km |----------------- stratopause ----------------------
           |                                        STRATOSPHERE
           |     * OZONE LAYER lives here *         temperature RISES
           |       (about 20 - 30 km)               (ozone absorbs UV)
     10 km |----------------- tropopause -----------------------
           |     clouds, weather, we live here      TROPOSPHERE
           |     ALL pollution starts here          temperature FALLS
      0 km +----------------------------------------------------->  EARTH

  MEMORY:  "The Sun Makes Toast"   ->  Troposphere, Stratosphere,
                                       Mesosphere, Thermosphere

  TEMPERATURE PATTERN:  DOWN , UP , DOWN , UP     (alternates every layer)
```

## THE ONE COMPARISON THEY LOVE TO ASK

```
  +----------------------+----------------------+-----------------------+
  |                      |  CLASSICAL SMOG      |  PHOTOCHEMICAL SMOG   |
  +----------------------+----------------------+-----------------------+
  |  Other name          |  London smog         |  Los Angeles smog     |
  |  Chemical nature     |  REDUCING            |  OXIDISING            |
  |  Weather needed      |  cool + humid        |  warm + dry + sunny   |
  |  Main culprits       |  SO2 + smoke + fog   |  NO2 + hydrocarbons   |
  |  Needs sunlight?     |  NO                  |  YES                  |
  |  Key products        |  H2SO4 aerosol       |  O3 , PAN , aldehydes |
  +----------------------+----------------------+-----------------------+

  MEMORY:  London is COLD and DAMP  ->  classical, reducing
           Los Angeles is HOT and SUNNY ->  photochemical, oxidising
```

## THE ONE-LINE SUMMARY OF EACH TOPIC (revise the night before)

```
  Pollutant          - a substance present in a harmful amount
  Contaminant        - a substance not normally present at all
  Sink               - the medium that absorbs / retains the pollutant
  Receptor           - the thing that is affected by the pollutant
  Acid rain          - rain with pH below 5.6, from H2SO4 and HNO3
  Greenhouse effect  - IR trapped by CO2, CH4, H2O, O3, CFCs -> warming
  Classical smog     - reducing, SO2 + fog, cold and damp
  Photochemical smog - oxidising, NO2 + hydrocarbons + sunlight -> O3, PAN
  PAN                - peroxyacetyl nitrate; eye irritant, kills plants
  Ozone hole         - thinning of stratospheric ozone over Antarctica
  BOD                - oxygen needed by bacteria to break down organic waste
  Eutrophication     - fertiliser -> algal bloom -> oxygen falls -> fish die
  Green chemistry    - design chemistry so the pollutant is never produced
```
