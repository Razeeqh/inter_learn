# TOPIC 1 — What hydrogen actually is

Hydrogen is the **simplest atom that exists**.

```
  +-----------------------------------------------------------------+
  |                                                                 |
  |     ATOMIC NUMBER  Z = 1                                        |
  |     CONFIGURATION      1s1                                      |
  |                                                                 |
  |     ONE proton in the nucleus.                                  |
  |     ONE electron going round it.                                |
  |     NO neutron at all (in ordinary hydrogen).                   |
  |                                                                 |
  |            (+)  <----  1 proton                                 |
  |             .                                                   |
  |              \                                                  |
  |               (-)  <----  1 electron in the 1s orbital          |
  |                                                                 |
  +-----------------------------------------------------------------+
```

It is the **most abundant element in the UNIVERSE** — about 70% of all the
matter in the universe by mass is hydrogen. Our Sun is mostly hydrogen.

But on **EARTH** it is different:

```
  IN THE UNIVERSE   ->  hydrogen is NUMBER 1 (about 70% by mass)

  ON THE EARTH      ->  hydrogen is only about the 9th or 10th most
                        abundant element BY MASS (about 0.15%),
                        because hydrogen atoms are so LIGHT.

                        BUT if you count the NUMBER OF ATOMS, hydrogen
                        is about 15.4% of all atoms in the earth's crust
                        and oceans - third by number.
```

> **TRAP:** "Most abundant element in the universe" = hydrogen.
> "Most abundant element in the earth's crust" = **oxygen**, not hydrogen.
> Examiners love to swap these two.

## Where hydrogen is found (occurrence)

```
  FREE hydrogen (as H2 gas)  ->  almost NONE on earth.

     WHY?  H2 is the LIGHTEST gas of all. Its molecules move so fast
           that they escape the earth's gravitational pull and leak
           away into space. Also, whatever remains reacts.

     Traces are found in volcanic gases and in the upper atmosphere.

  COMBINED hydrogen  ->  EVERYWHERE.

     WATER            H2O          (the biggest single store)
     ACIDS            HCl, H2SO4, HNO3
     ALKALIS          NaOH, KOH, NH3
     HYDROCARBONS     CH4 (natural gas), petroleum, coal
     LIVING THINGS    carbohydrates, proteins, fats, DNA - all contain H
     MINERALS         clays and hydrated salts, CaSO4.2H2O
```

## The three ways hydrogen can bond — remember these, everything follows

```
  1.  LOSE its electron       H  -  e-   ->   H+     (a bare PROTON)
                              behaves like  Na+ , K+     ->  METAL-like

  2.  GAIN an electron        H  +  e-   ->   H-     (HYDRIDE ion)
                              behaves like  Cl- , F-     ->  HALOGEN-like

  3.  SHARE its electron      H . + . Cl  ->  H : Cl     ->  COVALENT
                              this is what it does most of the time
```

```
  NOTE ON H+ :
      A bare H+ is just a proton with NO electrons around it. It is
      unbelievably small (radius about 1.5 x 10^-3 pm, compared with
      about 50-200 pm for a normal ion) and so it has an ENORMOUS
      charge density.

      It therefore CANNOT exist alone in water. It immediately grabs
      a lone pair on a water molecule:

           H+  +  H2O  ->  H3O+       (hydronium / hydroxonium ion)

      So "H+ in solution" really always means H3O+.
```

# TOPIC 2 — THE POSITION OF HYDROGEN IN THE PERIODIC TABLE

**This is a guaranteed 4-mark question.** It is asked almost every year in some
form. Learn it as TWO LISTS plus a CONCLUSION.

The problem is simple: hydrogen behaves partly like a Group 1 metal and partly
like a Group 17 halogen, and perfectly like neither. So no one can agree where
to put it.

```
                        H Y D R O G E N   (1s1)
                                 |
              +------------------+------------------+
              |                                     |
     RESEMBLES ALKALI METALS              RESEMBLES HALOGENS
        (Group 1 , ns1)                     (Group 17 , ns2 np5)
              |                                     |
        "I have ONE electron                 "I am ONE electron
         to give away"                        short of a full shell"
```

## PART A — Resemblance to the ALKALI METALS (Group 1)

| # | POINT | HYDROGEN | ALKALI METALS |
|---|---|---|---|
| 1 | Electronic configuration | 1s1 — one electron in the outermost shell | ns1 — one electron in the outermost shell |
| 2 | Valency | 1 | 1 |
| 3 | Ion formed | loses one electron to give H+ | lose one electron to give M+ |
| 4 | Oxidation state | +1 | +1 |
| 5 | Reducing nature | H2 is a good reducing agent: CuO + H2 -> Cu + H2O | Na, K are strong reducing agents |
| 6 | Halides | forms HCl, HBr, HI | form NaCl, KBr, etc. |
| 7 | Oxides | forms H2O | form Na2O, K2O |
| 8 | Sulphides | forms H2S | form Na2S |
| 9 | Electropositive character | releases electrons at the cathode? no — it is LIBERATED at the cathode during electrolysis, just as Na+ would be | metal ions are discharged at the cathode |

```
  WRITE IT LIKE THIS IN THE EXAM (any 4 points is enough for full marks):

     1. Both have ns1 configuration (H is 1s1, alkali metals are ns1).
     2. Both show a valency of ONE and an oxidation state of +1.
     3. Both form unipositive ions:  H -> H+ + e-  ;  Na -> Na+ + e-
     4. Both are good REDUCING agents.
     5. Both form halides (HCl / NaCl), oxides (H2O / Na2O) and
        sulphides (H2S / Na2S) of similar formula type.
     6. Both are liberated at the CATHODE in electrolysis.
```

## PART B — Resemblance to the HALOGENS (Group 17)

| # | POINT | HYDROGEN | HALOGENS |
|---|---|---|---|
| 1 | Electrons short of noble gas | 1 short of He (1s2) | 1 short of the next noble gas |
| 2 | Molecule | DIATOMIC: H2 | DIATOMIC: F2, Cl2, Br2, I2 |
| 3 | Anion formed | H- (hydride ion) | Cl-, F- (halide ion) |
| 4 | Oxidation state | shows −1 in NaH, CaH2 | show −1 in NaCl, CaCl2 |
| 5 | Ionisation enthalpy | 1312 kJ/mol — VERY HIGH, close to halogens (F is 1680, Cl is 1255) and nowhere near Li (520) or Na (496) | high |
| 6 | Physical nature | non-metal, a gas | non-metals, gases/liquid/solid |
| 7 | Electronegativity | 2.1 — closer to the non-metals | high |
| 8 | Compounds with non-metals | covalent: CH4, NH3, H2O | covalent: CCl4, NCl3, Cl2O |
| 9 | Compounds with metals | ionic hydrides NaH, CaH2 with the H- ion | ionic halides NaCl, CaCl2 |
| 10 | Atomicity in the free state | H2 | X2 |

```
  WRITE IT LIKE THIS IN THE EXAM:

     1. Like halogens, hydrogen is ONE electron short of the nearest
        noble gas configuration (He, 1s2).
     2. Both exist as DIATOMIC molecules: H2 and Cl2.
     3. Both form uninegative ions: H- and Cl-.
     4. Both show the -1 oxidation state in metal compounds:
            NaH  (Na+ H-)      and     NaCl  (Na+ Cl-)
     5. The ionisation enthalpy of hydrogen (1312 kJ/mol) is HIGH,
        like a halogen, and completely unlike an alkali metal.
     6. Both are non-metals and both form covalent compounds with
        non-metals.
```

## PART C — Why the position is ANOMALOUS (the conclusion)

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |  WHERE IT DOES NOT FIT WITH GROUP 1                                    |
  |                                                                        |
  |   - Hydrogen is a NON-METAL and a GAS. Alkali metals are soft,         |
  |     shiny SOLID METALS.                                                |
  |   - Its ionisation enthalpy (1312 kJ/mol) is MUCH higher than any      |
  |     alkali metal (Li 520, Na 496, Cs 376). So H+ forms far less        |
  |     easily than Na+.                                                   |
  |   - H+ is a BARE PROTON with no electron shell at all, so it cannot    |
  |     exist free in water. Na+ exists happily in water.                  |
  |   - Hydrogen mostly forms COVALENT compounds; alkali metals form       |
  |     IONIC compounds.                                                   |
  |                                                                        |
  |  WHERE IT DOES NOT FIT WITH GROUP 17                                   |
  |                                                                        |
  |   - Halogens have SEVEN outer electrons; hydrogen has ONE.             |
  |   - Halogens have lone pairs; hydrogen has none.                       |
  |   - The tendency of hydrogen to form H- is very SMALL. It forms H-     |
  |     only with the most electropositive metals. Halogens form X-        |
  |     readily with almost everything.                                    |
  |   - Hydrogen is much less electronegative (2.1) than the halogens.     |
  |   - Hydrogen forms H+ ; halogens essentially never do.                 |
  |                                                                        |
  |  CONCLUSION (write this line - it earns the last mark)                 |
  |                                                                        |
  |     Because hydrogen resembles BOTH Group 1 and Group 17 but           |
  |     belongs FULLY to neither, its position in the periodic table       |
  |     is said to be ANOMALOUS or CONTROVERSIAL. By convention it is      |
  |     placed at the TOP OF GROUP 1, but this is only a convenience,      |
  |     not a statement that hydrogen is an alkali metal.                  |
  |                                                                        |
  +------------------------------------------------------------------------+
```

> **TRAP:** The question is almost never "where does hydrogen belong?" It is
> "**justify** the position" or "hydrogen resembles both alkali metals and
> halogens — explain". So you must give **BOTH lists**, then the conclusion.
> Giving only one list caps you at 2 out of 4.

# TOPIC 3 — THE ISOTOPES OF HYDROGEN

**Isotopes** = atoms of the same element with the **same number of protons** but
**different numbers of neutrons**.

Hydrogen has exactly three, and they are the only isotopes in the whole
periodic table that get their own separate names and symbols.

```
  +--------------------+--------------------+--------------------+
  |     PROTIUM        |     DEUTERIUM      |     TRITIUM        |
  |       1H1          |       1H2  (D)     |       1H3  (T)     |
  +--------------------+--------------------+--------------------+
  |                    |                    |                    |
  |     (p)            |     (p n)          |     (p n n)        |
  |       \            |       \            |       \            |
  |        e-          |        e-          |        e-          |
  |                    |                    |                    |
  |   1 proton         |   1 proton         |   1 proton         |
  |   0 neutrons       |   1 neutron        |   2 neutrons       |
  |   mass number 1    |   mass number 2    |   mass number 3    |
  |                    |                    |                    |
  +--------------------+--------------------+--------------------+
```

## THE COMPARISON TABLE — learn this cold

| PROPERTY | PROTIUM 1H1 | DEUTERIUM 1H2 (D) | TRITIUM 1H3 (T) |
|---|---|---|---|
| Other name | ordinary hydrogen / light hydrogen | heavy hydrogen | — |
| Protons | 1 | 1 | 1 |
| Neutrons | 0 | 1 | 2 |
| Mass number | 1 | 2 | 3 |
| Relative atomic mass | 1.008 | 2.014 | 3.016 |
| Abundance in nature | 99.985 % | 0.0156 % (about 1 in 6000 H atoms) | about 1 atom in 10^18 H atoms — a trace |
| Radioactive? | NO — stable | NO — stable | **YES — radioactive** |
| Type of radiation | — | — | beta (β⁻) emitter, very low energy |
| Half-life | — | — | 12.33 years |
| Molecule | H2 | D2 | T2 |
| Oxide | H2O (water) | D2O (**heavy water**) | T2O (super-heavy / tritiated water) |
| Boiling point of the molecule | 20.4 K | 23.5 K | 25.0 K |
| Bond enthalpy | 435.9 kJ/mol | 443.4 kJ/mol | — |
| Main use | fuel, ammonia, hydrogenation | moderator in nuclear reactors; tracer in reaction-mechanism studies | radioactive tracer; in hydrogen (fusion) bombs; luminous paints and self-powered signs |

```
  MEMORY LINE:
      "PROTIUM has none, DEUTERIUM has one, TRITIUM has two -
       and only TRITIUM shoots."     (neutrons ... and radioactivity)
```

## Why the isotopes behave slightly differently

```
  Chemically, all three isotopes behave THE SAME, because chemistry is
  decided by the ELECTRONS, and all three have exactly one electron.

  PHYSICALLY they differ, because they differ in MASS - and deuterium
  is TWICE as heavy as protium. That is the biggest mass ratio of any
  pair of isotopes anywhere in the periodic table (2:1). For, say,
  chlorine-35 and chlorine-37 the ratio is only 1.06:1.

  CONSEQUENCE:  D2 and D2O react MORE SLOWLY than H2 and H2O.
                This is called the KINETIC ISOTOPE EFFECT, and it is
                exactly why deuterium is useful as a TRACER for
                working out reaction mechanisms.
```

## HEAVY WATER, D2O

```
  +------------------------------------------------------------------+
  |                                                                  |
  |   HEAVY WATER  =  DEUTERIUM OXIDE  =  D2O                        |
  |                                                                  |
  |   HOW IT IS MADE:                                                |
  |      by the PROLONGED ELECTROLYSIS of ordinary water containing   |
  |      a little alkali. H2O decomposes faster than D2O, so D2O      |
  |      is left behind and slowly becomes concentrated in the cell.  |
  |      Starting from about 30 litres of water you finally get       |
  |      about 1 mL of pure D2O. Also obtained by fractional          |
  |      distillation and by exchange processes.                      |
  |                                                                  |
  +------------------------------------------------------------------+

  PHYSICAL COMPARISON WITH ORDINARY WATER
```

| PROPERTY | ORDINARY WATER H2O | HEAVY WATER D2O |
|---|---|---|
| Molar mass | 18 g/mol | 20 g/mol |
| Melting point | 273.0 K (0 °C) | 276.8 K (3.8 °C) |
| Boiling point | 373.0 K (100 °C) | 374.4 K (101.4 °C) |
| Density (at 298 K) | 0.997 g/cm3 | 1.106 g/cm3 |
| Temperature of maximum density | 277 K (4 °C) | 284.2 K (11.2 °C) |
| Dielectric constant | 78.4 | 78.1 |
| Effect on living things | essential for life | **harmful** — slows down biological reactions; plants and animals die in it |

```
  USES OF HEAVY WATER  (a standard 2-mark answer):

     1. As a MODERATOR in nuclear reactors - it slows down fast
        neutrons so that they can cause further fission, WITHOUT
        absorbing them (this is why D2O beats ordinary water).
     2. As a source of DEUTERIUM for making deuterated compounds
        (e.g. D2O + Ca -> Ca(OD)2 + D2 ).
     3. As a TRACER for studying reaction mechanisms.
     4. In NMR spectroscopy as a solvent.
```

```
  DEUTERIUM EXCHANGE REACTIONS (small but examinable):

      2 Na  +  2 D2O   ->  2 NaOD  +  D2
      CaC2  +  2 D2O   ->  C2D2    +  Ca(OD)2
      SO3   +   D2O    ->  D2SO4
      Al4C3 +  12 D2O  ->  3 CD4   +  4 Al(OD)3
```

## WORKED EXAMPLE 1

**Q. A sample of hydrogen gas contains protium and deuterium only. If the
average atomic mass of the sample is 1.008 u, and the atomic masses of
protium and deuterium are 1.000 u and 2.000 u, find the percentage of
deuterium in the sample.**

```
  STEP 1   Let the fraction of deuterium be  x  (as a decimal).
           Then the fraction of protium is   (1 - x).

  STEP 2   Average atomic mass  =  (mass of D)(x)  +  (mass of H)(1 - x)

              1.008  =  2.000 x  +  1.000 (1 - x)

  STEP 3   Expand:

              1.008  =  2.000 x  +  1.000  -  1.000 x
              1.008  =  1.000 x  +  1.000

  STEP 4   Solve:

              1.000 x  =  0.008
                     x  =  0.008

  STEP 5   Convert to a percentage:

              % deuterium  =  0.008 x 100  =  0.8 %

  CHECK:  0.8% of 2.000 + 99.2% of 1.000
        =  0.016 + 0.992  =  1.008    CORRECT.
```

> **TRAP:** the REAL natural abundance of deuterium is 0.0156%, not 0.8%.
> The number above is only for this made-up sample. In a theory question
> always quote **0.0156 %**.

# TOPIC 4 — PREPARATION OF DIHYDROGEN, H2

Dihydrogen just means the molecule **H2** (two hydrogen atoms bonded together).
There are laboratory methods (small scale) and commercial methods (large scale).

## 4.1 LABORATORY PREPARATION

### METHOD 1 — Metal + dilute acid (the standard method)

```
  Granulated ZINC is dropped into DILUTE SULPHURIC ACID (or dilute HCl)
  in a Woulfe's bottle / flask fitted with a thistle funnel.

      Zn  +  dil H2SO4   ->   ZnSO4  +  H2

      Zn  +  2 HCl       ->   ZnCl2  +  H2

  APPARATUS (draw this if a diagram is asked)

           thistle              delivery tube
           funnel                    |
              ||                     |
         _____||_____________________|________
        |     ||                              |
        |     ||                              |----> H2 collected by
        |  ---||------------------------      |      DOWNWARD DISPLACEMENT
        |   dilute H2SO4                |     |      OF WATER
        |  o  o  o   granulated zinc    |     |
        |__o__o__o______________________|_____|

  WHY zinc?
      Zinc is the right speed - not violent like sodium, not too slow
      like iron. It is cheap and safe. GRANULATED zinc (not zinc dust)
      is used to control the rate.

  WHY DILUTE acid, and why NOT nitric acid?
      Concentrated H2SO4 and nitric acid of ANY strength are OXIDISING
      agents. They oxidise the H2 that forms and give oxides of sulphur
      or oxides of nitrogen instead. So you get SO2 or NO2, not H2.
      EXCEPTION: very dilute (about 1%) HNO3 with Mg or Mn does give H2.
```

### METHOD 2 — Metal + alkali (for amphoteric metals)

```
  Metals whose oxides are AMPHOTERIC (Zn, Al, Sn, Pb) also react with
  hot concentrated ALKALI to give H2.

      Zn   +  2 NaOH   ->   Na2ZnO2   +   H2
                            sodium zincate

      2 Al +  2 NaOH  +  2 H2O  ->  2 NaAlO2  +  3 H2
                                    sodium
                                    metaaluminate

      Sn   +  2 NaOH   ->   Na2SnO2   +   H2
                            sodium stannite

  (In modern notation the zincate is written Na2[Zn(OH)4] :
       Zn + 2 NaOH + 2 H2O  ->  Na2[Zn(OH)4] + H2
   Either version is accepted; the older one is what the AP textbook uses.)
```

### METHOD 3 — Very pure hydrogen

```
  For HIGH PURITY dihydrogen (99.9%):

      Electrolysis of warm barium hydroxide solution between
      NICKEL electrodes.

      Or:   reaction of a metal hydride with water
                NaH  +  H2O   ->   NaOH  +  H2
                CaH2 +  2 H2O ->   Ca(OH)2 + 2 H2   (called HYDROLITH)
```

## 4.2 COMMERCIAL / INDUSTRIAL PREPARATION

### METHOD A — Steam over hot coke (the WATER GAS process)

```
  +------------------------------------------------------------------+
  |                                                                  |
  |    C(s)  +  H2O(g)  --(1270 K)-->   CO(g)  +  H2(g)              |
  |    coke     steam                                                 |
  |                                                                  |
  |    The mixture  CO + H2  is called  WATER GAS  or  SYNTHESIS GAS |
  |    or SYNGAS.                                                     |
  |                                                                  |
  |    The reaction is strongly ENDOTHERMIC, so the coke bed cools    |
  |    down. Air is blown in from time to time to reheat it.          |
  |                                                                  |
  +------------------------------------------------------------------+

  IF THE STARTING MATERIAL IS COAL instead of coke, the same process
  is called  COAL GASIFICATION.
```

### METHOD B — The WATER GAS SHIFT REACTION

```
  The CO in water gas is a nuisance - you want only the H2.
  So MORE steam is passed over the mixture with a catalyst:

  +------------------------------------------------------------------+
  |                                                                  |
  |   CO(g) + H2O(g) --(673 K , Fe2O3 + Cr2O3 catalyst)--> CO2 + H2  |
  |                                                                  |
  |          THIS IS THE  WATER GAS SHIFT REACTION.                  |
  |                                                                  |
  +------------------------------------------------------------------+

  The CO2 is then removed by scrubbing with water under pressure
  (CO2 is much more soluble than H2), or with sodium arsenite solution,
  leaving pure H2 behind.

  FULL FLOW CHART - draw this in the 8-mark answer:

    +--------+   steam 1270 K   +-----------+  more steam, 673 K  +------+
    |  COKE  |----------------->| WATER GAS |------------------->| CO2  |
    |  (C)   |                  | CO + H2   |  Fe2O3/Cr2O3       |  +   |
    +--------+                  +-----------+                    | H2   |
                                                                 +--+---+
                                                                    |
                                              scrub with water      |
                                              under pressure        v
                                                              +-----------+
                                                              | PURE H2   |
                                                              +-----------+
```

### METHOD C — From hydrocarbons (steam reforming)

```
   CH4(g) + H2O(g)  --(1270 K , Ni catalyst)-->  CO(g) + 3 H2(g)

   This is how MOST of the world's hydrogen is actually made today,
   from natural gas. Follow it with the shift reaction to get more H2.
```

### METHOD D — ELECTROLYSIS OF WATER

```
  +------------------------------------------------------------------+
  |                                                                  |
  |   2 H2O(l)  --(electrolysis, traces of acid or alkali)-->        |
  |                                    2 H2(g)  +  O2(g)             |
  |                                                                  |
  |   AT THE CATHODE (-) :   2 H2O + 2 e-  ->  H2  +  2 OH-          |
  |   AT THE ANODE   (+) :   2 H2O         ->  O2  +  4 H+  +  4 e-  |
  |                                                                  |
  |   VOLUME RATIO COLLECTED:   H2 : O2  =  2 : 1                    |
  |                                                                  |
  +------------------------------------------------------------------+

  WHY add a trace of acid or alkali?
      PURE water is a very poor conductor (it hardly ionises), so
      electrolysis would be impossibly slow. The acid or alkali supplies
      ions and makes the water conduct. It is NOT consumed.

  This gives VERY PURE hydrogen, but it is EXPENSIVE because
  electricity is expensive.
```

### METHOD E — As a BY-PRODUCT of the CHLOR-ALKALI process

```
  When BRINE (concentrated aqueous NaCl) is electrolysed, the main
  products wanted are NaOH and Cl2. Hydrogen comes free with them.

  +------------------------------------------------------------------+
  |                                                                  |
  |   2 NaCl(aq) + 2 H2O --(electrolysis)-->                         |
  |                            2 NaOH(aq) + Cl2(g) + H2(g)           |
  |                                                                  |
  |   AT THE CATHODE :  2 H2O + 2 e-  ->  H2  +  2 OH-               |
  |   AT THE ANODE   :  2 Cl-         ->  Cl2 +  2 e-                |
  |                                                                  |
  |   This is the CHLOR-ALKALI INDUSTRY. Hydrogen is a BY-PRODUCT.   |
  |                                                                  |
  +------------------------------------------------------------------+
```

### METHOD F — By-product of petroleum refining

```
  Hydrogen is also released during the CRACKING and REFORMING of
  hydrocarbons in petroleum refineries. It is cheap but usually
  used up again inside the refinery.
```

## SUMMARY TABLE — all the preparations in one place

| METHOD | EQUATION | CONDITIONS | PURITY / NOTE |
|---|---|---|---|
| Zn + dilute acid | Zn + H2SO4 -> ZnSO4 + H2 | room temp | lab standard |
| Zn + alkali | Zn + 2NaOH -> Na2ZnO2 + H2 | hot conc. alkali | for amphoteric metals |
| Metal hydride + water | CaH2 + 2H2O -> Ca(OH)2 + 2H2 | room temp | very pure; "hydrolith" |
| Steam over coke | C + H2O -> CO + H2 | 1270 K | gives WATER GAS |
| Shift reaction | CO + H2O -> CO2 + H2 | 673 K, Fe2O3/Cr2O3 | removes the CO |
| Steam reforming | CH4 + H2O -> CO + 3H2 | 1270 K, Ni | the main industrial route |
| Electrolysis of water | 2H2O -> 2H2 + O2 | acidified/alkaline water | very pure but costly |
| Chlor-alkali | 2NaCl + 2H2O -> 2NaOH + Cl2 + H2 | electrolysis of brine | H2 is a by-product |

## WORKED EXAMPLE 2

**Q. 6.5 g of zinc is treated with excess dilute sulphuric acid. What volume
of dihydrogen is liberated at STP? (Zn = 65, molar volume at STP = 22.4 L)**

```
  STEP 1   Write the balanced equation.

              Zn  +  H2SO4   ->   ZnSO4  +  H2

  STEP 2   Read the mole ratio from it.

              1 mole Zn  gives  1 mole H2

  STEP 3   Convert the mass of Zn to moles.

              moles of Zn  =  mass / molar mass
                           =  6.5 / 65
                           =  0.1 mol

  STEP 4   Use the ratio.

              moles of H2  =  0.1 mol

  STEP 5   Convert moles of gas to volume at STP.

              volume  =  0.1  x  22.4 L
                      =  2.24 L   =   2240 mL

  ANSWER:  2.24 litres of H2 at STP.

  CHECK: 6.5 g is one tenth of the molar mass of Zn, so we expect
         one tenth of a molar volume. 22.4/10 = 2.24 L. CORRECT.
```

# TOPIC 5 — PROPERTIES OF DIHYDROGEN

## 5.1 PHYSICAL PROPERTIES

| PROPERTY | VALUE / DESCRIPTION |
|---|---|
| Colour, smell, taste | colourless, odourless, tasteless |
| Nature | non-toxic, highly combustible (burns with a pale blue flame) |
| Density | 0.09 g/L at STP — the **LIGHTEST** substance known |
| Melting point | 13.96 K |
| Boiling point | 20.39 K |
| Solubility in water | almost insoluble (about 1.8 mL per 100 mL water) |
| Solubility in metals | dissolves readily in Pd, Pt, Ni — **palladium can absorb about 900 times its own volume of H2** (occlusion) |
| Bond length (H–H) | 74 pm |
| Bond dissociation enthalpy | **435.88 kJ/mol** — the highest for any single bond between two atoms |
| Ionisation enthalpy | 1312 kJ/mol |
| Electronegativity | 2.1 |

```
  OCCLUSION (2-mark question):
      The ABSORPTION of a gas by a metal is called OCCLUSION.
      Palladium, platinum and nickel occlude hydrogen.
      Palladium can occlude about 900 times its own volume of H2.
      This is the basis of hydrogen STORAGE in metal hydrides.
```

## 5.2 WHY IS DIHYDROGEN SO UNREACTIVE AT ROOM TEMPERATURE?

**This is a standard 2-mark question with a one-line answer.**

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |     H2(g)   ->   2 H(g)          delta H  =  + 435.88 kJ/mol           |
  |                                                                        |
  |  The H-H bond dissociation enthalpy is 435.88 kJ/mol, the HIGHEST      |
  |  for any single bond between two atoms.                                |
  |                                                                        |
  |  To react at all, the H-H bond usually has to break first. That        |
  |  costs an enormous amount of energy. At ORDINARY temperature there     |
  |  is nowhere near enough energy available.                              |
  |                                                                        |
  |  THEREFORE dihydrogen is chemically INERT / UNREACTIVE at room         |
  |  temperature, and every reaction of dihydrogen needs one of:           |
  |         HIGH TEMPERATURE  ,  a CATALYST  ,  or an ELECTRIC ARC.        |
  |                                                                        |
  |  CONSEQUENCE: ATOMIC hydrogen (H) or NASCENT hydrogen is far MORE      |
  |  reactive than molecular H2, because the expensive bond-breaking       |
  |  step has already been paid for.                                       |
  |                                                                        |
  +------------------------------------------------------------------------+
```

## 5.3 CHEMICAL PROPERTIES — the reactions to memorise

### (a) With METALS — forms ionic hydrides

```
   2 Na  +  H2   --(673 K)-->    2 NaH        sodium hydride
     Ca  +  H2   --(heat)-->      CaH2        calcium hydride
   2 Li  +  H2   --(heat)-->     2 LiH        lithium hydride

   Here hydrogen is the OXIDISING agent - it takes an electron and
   becomes H- .  Oxidation state of H = -1.
```

### (b) With HALOGENS — forms hydrogen halides

```
   H2  +  F2    ->  2 HF     EXPLOSIVE even in the dark, even at low temp
   H2  +  Cl2   ->  2 HCl    explosive in SUNLIGHT / UV light
   H2  +  Br2   ->  2 HBr    needs HEAT (about 573 K)
   H2  +  I2    ->  2 HI     needs heat AND a catalyst; REVERSIBLE,
                             never goes to completion

   ORDER OF REACTIVITY:   F2  >  Cl2  >  Br2  >  I2      (decreases down)

   REASON: bond dissociation enthalpy of X-X increases and the
           H-X bond formed gets weaker down the group, so the
           reaction becomes less and less favourable.
```

### (c) With OXYGEN — the most famous reaction

```
   2 H2  +  O2   --(spark / 773 K / Pt catalyst)-->  2 H2O
                                       delta H = -285.9 kJ/mol

   HIGHLY EXOTHERMIC and EXPLOSIVE if the mixture is 2:1 by volume
   ("detonating gas" / "oxy-hydrogen mixture").

   THIS IS WHY H2 IS A FUEL - it releases a huge amount of energy and
   the only product is WATER.
```

### (d) With NITROGEN — the HABER PROCESS

```
   N2(g)  +  3 H2(g)  <--(673-773 K, 200 atm, Fe catalyst + Mo promoter)-->
                                                            2 NH3(g)
                                       delta H = -92.6 kJ/mol

   REVERSIBLE, EXOTHERMIC, and it goes with a DECREASE in the number
   of moles of gas (4 -> 2). So by Le Chatelier:
        HIGH PRESSURE helps    (fewer moles on the right)
        LOW temperature helps the yield, but is too slow, so a
        MODERATE temperature (about 700 K) plus a CATALYST is used.

   This is the single biggest use of dihydrogen in the world.
```

### (e) With METAL OXIDES — hydrogen as a REDUCING agent

```
   Hydrogen removes oxygen from the oxides of metals that are BELOW
   hydrogen in the reactivity series.

       CuO   +  H2  --(heat)-->   Cu   +  H2O
       black                      red-brown

       ZnO   +  H2  --(heat)-->   Zn   +  H2O
       PbO   +  H2  --(heat)-->   Pb   +  H2O
       Fe3O4 + 4 H2 --(heat)-->  3 Fe  + 4 H2O

   BUT it does NOT reduce the oxides of very reactive metals:
       Na2O , K2O , CaO , MgO , Al2O3   are NOT reduced by H2.
       (Those metals hold their oxygen far too strongly.)
```

### (f) With CARBON MONOXIDE — methanol and hydrocarbons

```
   CO  +  2 H2  --(573 K, 300 atm, ZnO-Cr2O3)-->  CH3OH
                                                  methanol

   n CO + (2n+1) H2 --(Co catalyst)--> CnH(2n+2) + n H2O
                                       synthetic petrol
                                       (FISCHER-TROPSCH process)
```

### (g) With UNSATURATED HYDROCARBONS — HYDROGENATION

```
   CH2=CH2  +  H2  --(Ni, 573 K)-->  CH3-CH3
   ethene                            ethane

   VEGETABLE OIL (unsaturated, liquid) + H2 --(Ni, 473-523 K)-->
                                    VANASPATI GHEE (saturated, solid)

   The C=C double bonds are turned into C-C single bonds, so the
   molecules pack better and the oil solidifies.
```

### (h) With SULPHUR and other non-metals

```
   H2  +  S    --(heat)-->   H2S        (rotten-egg gas)
   3 H2 + 2 P  --(heat)-->  2 PH3
```

### (i) With ACTIVE METAL solutions — reduction of salts

```
   PdCl2  +  H2   ->   Pd  +  2 HCl
   2 AgNO3 + H2   ->  2 Ag  +  2 HNO3      (silver mirror)
```

# TOPIC 6 — ORTHO AND PARA HYDROGEN

This looks strange the first time you meet it, but it is only **one idea**.

```
  Every proton SPINS. A spinning charge acts like a tiny magnet.
  In an H2 molecule there are TWO protons, so there are TWO tiny magnets.
  They can be lined up in only two ways.
```

```
  +---------------------------------+---------------------------------+
  |         ORTHO HYDROGEN          |         PARA HYDROGEN           |
  +---------------------------------+---------------------------------+
  |                                 |                                 |
  |     H -------- H                |     H -------- H                |
  |     ^          ^                |     ^          v                |
  |     |          |                |     |          |                |
  |                                 |                                 |
  |   nuclear spins are             |   nuclear spins are             |
  |   PARALLEL (same direction)     |   ANTI-PARALLEL (opposite)      |
  |                                 |                                 |
  |   HIGHER energy                 |   LOWER energy (more stable)    |
  |                                 |                                 |
  +---------------------------------+---------------------------------+
```

## The facts to remember

| POINT | ORTHO | PARA |
|---|---|---|
| Nuclear spins | parallel (same direction) | anti-parallel (opposite) |
| Energy | higher | **lower — more stable** |
| Amount at ordinary temperature (298 K) | **75 %** | **25 %** |
| Amount at 0 K (absolute zero) | **0 %** | **100 %** |
| Amount at very high temperature | maximum 75 % — it never goes above 3:1 | minimum 25 % |
| Melting point | 13.95 K | 13.83 K (slightly lower) |
| Boiling point | 20.39 K | 20.26 K (slightly lower) |
| Thermal conductivity | lower | **higher** (about 50% higher) |
| Vapour pressure | lower | higher |
| Chemical properties | **identical** | **identical** |

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |  THE THREE STATEMENTS THAT EARN THE MARKS                              |
  |                                                                        |
  |   1. ORDINARY DIHYDROGEN AT ROOM TEMPERATURE IS A MIXTURE OF           |
  |      75% ORTHO AND 25% PARA  (that is, ortho : para = 3 : 1).          |
  |                                                                        |
  |   2. AS THE TEMPERATURE IS LOWERED, THE PROPORTION OF PARA             |
  |      INCREASES. AT ABSOLUTE ZERO (0 K) THE GAS IS 100% PARA,           |
  |      because para is the lower-energy form.                            |
  |                                                                        |
  |   3. THE PROPORTION OF ORTHO CAN NEVER EXCEED 75%, HOWEVER HIGH        |
  |      THE TEMPERATURE, because the 3:1 statistical limit is fixed.      |
  |                                                                        |
  |   THEIR CHEMICAL PROPERTIES ARE IDENTICAL. Only PHYSICAL properties    |
  |   (m.p., b.p., thermal conductivity, vapour pressure) differ.          |
  |                                                                        |
  +------------------------------------------------------------------------+
```

```
  TEMPERATURE PICTURE

     100% para  |  *
                |    *
     % para     |       *
                |          *
                |              *
      25% para  |                  * * * * * * * * * * * *
                +--------------------------------------------
                0 K                                    high T

     -> para falls from 100% at 0 K to a floor of 25% at ordinary
        and higher temperatures.
```

```
  HOW PURE PARA HYDROGEN IS OBTAINED:
      By cooling ordinary hydrogen to very low temperature (near 20 K)
      in the presence of a CATALYST such as ACTIVATED CHARCOAL, which
      helps the ortho form flip into the para form.

  PURE ORTHO HYDROGEN CANNOT BE OBTAINED - the best you can ever get
  is 75% ortho.
```

> **TRAP:** Do not say the *electron* spins differ. It is the **NUCLEAR
> (proton) spins**. Saying "electron spin" loses the mark.

## WORKED EXAMPLE 3

**Q. Why is the atomic hydrogen torch hotter than the oxy-hydrogen torch?**

```
  STEP 1   In the OXY-HYDROGEN torch, energy comes from BURNING:
                2 H2 + O2 -> 2 H2O         about 2800 K

  STEP 2   In the ATOMIC HYDROGEN torch, H2 is first SPLIT in an
           electric arc:
                H2  ->  2 H       (this ABSORBS 435.88 kJ/mol)

  STEP 3   The hydrogen ATOMS then hit the cold metal surface and
           recombine there:
                2 H  ->  H2       (this RELEASES 435.88 kJ/mol,
                                   all of it, right at the surface)

  STEP 4   Because that entire 435.88 kJ/mol is dumped in one small
           spot instead of being spread through a flame, the local
           temperature reaches about 4000 K.

  ANSWER:  The atomic hydrogen torch is hotter because the very large
           H-H bond enthalpy (435.88 kJ/mol) is released instantly and
           locally when hydrogen atoms recombine on the workpiece.
```

# TOPIC 8 — HYDRIDES

A **HYDRIDE** is a binary compound of hydrogen with another element.

Hydrogen combines with almost every element **except** the noble gases and a few
metals in the middle of the d-block. Which **KIND** of hydride you get depends
only on **where the partner element sits in the periodic table**.

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |                          H Y D R I D E S                               |
  |                                 |                                      |
  |        +------------------------+------------------------+             |
  |        |                        |                        |             |
  |     IONIC                   COVALENT                 METALLIC          |
  |    (SALINE)                (MOLECULAR)             (INTERSTITIAL)      |
  |        |                        |                        |             |
  |   s-block metals           p-block elements        d and f block       |
  |   (Group 1 and 2,          (Groups 13-17)          (transition and     |
  |    except Be, Mg)          + Be and Mg              inner-transition)  |
  |        |                        |                        |             |
  |   NaH, KH, CaH2,           CH4, NH3, H2O, HF,      TiH1.73, ZrH1.30,   |
  |   BaH2, LiH, SrH2          B2H6, SiH4, PH3,        VH0.56, LaH2.87,    |
  |                            H2S, HCl, BeH2, MgH2    PdH0.6, NiH         |
  |                                                                        |
  +------------------------------------------------------------------------+
```

## 8.1 IONIC (SALINE) HYDRIDES

```
  WHO FORMS THEM:  the most electropositive metals - Group 1 (all)
                   and Group 2 (Ca, Sr, Ba).
                   NOT Be and Mg (they are too small and too
                   polarising, so their hydrides come out covalent
                   / polymeric instead).

  HOW THEY FORM:   the metal gives its electron to hydrogen
                       2 Na + H2  ->  2 Na+ H-
                   Hydrogen is in the -1 oxidation state.
```

| PROPERTY | IONIC HYDRIDES |
|---|---|
| Bonding | ionic — M+ and H− |
| State | crystalline solids, white or greyish |
| Melting point | high |
| Volatility | non-volatile |
| Electrical conduction | conduct **only when molten** (ions become free) |
| Electrolysis | give **H2 at the ANODE** — this proves the hydride ion H− exists |
| Reaction with water | violent, gives H2 and the alkali |
| Nature | strong REDUCING agents and strong BASES |
| Density | denser than the parent metal (hydrogen fits into the lattice holes) |
| Examples | LiH, NaH, KH, RbH, CsH, CaH2, SrH2, BaH2 |

```
  KEY REACTIONS

     NaH   +  H2O    ->   NaOH     +  H2
     CaH2  +  2 H2O  ->   Ca(OH)2  +  2 H2      ("HYDROLITH", used to
                                                  generate H2 in the field)

     2 NaH  --(electrolysis, molten)-->  2 Na  +  H2 (AT THE ANODE)

     They reduce metal oxides and chlorides:
     2 NaH  +  TiCl4 ...  and    4 LiH + AlCl3 -> LiAlH4 + 3 LiCl
                                 2 LiH + B2H6  -> 2 LiBH4

     LiAlH4 (lithium aluminium hydride) and NaBH4 (sodium borohydride)
     are COMPLEX HYDRIDES - the two most important reducing agents in
     all of organic chemistry.
```

> **TRAP:** In electrolysis of a molten ionic hydride, hydrogen is released
> at the **ANODE**, not the cathode — because it is present as the **negative**
> hydride ion H−. Getting this backwards is a classic mark loss.

## 8.2 COVALENT (MOLECULAR) HYDRIDES

```
  WHO FORMS THEM:  the p-block non-metals (Groups 13 to 17),
                   plus Be and Mg.

  BONDING:  hydrogen SHARES electrons. Discrete small molecules held
            together only by weak van der Waals forces.
```

| PROPERTY | COVALENT HYDRIDES |
|---|---|
| Bonding | covalent, discrete molecules |
| State | mostly gases or volatile liquids |
| Melting / boiling point | LOW (weak intermolecular forces) |
| Electrical conduction | non-conductors |
| Examples | B2H6, CH4, SiH4, NH3, PH3, H2O, H2S, HF, HCl |

**They are sub-divided by counting the electrons available for bonding:**

```
  +----------------------+------------------+----------------------------+
  |   TYPE               |  GROUPS          |  EXAMPLES                  |
  +----------------------+------------------+----------------------------+
  | ELECTRON DEFICIENT   |  Group 13        |  B2H6 (diborane), AlH3     |
  |  fewer electrons     |                  |  -> so they form BRIDGES   |
  |  than needed for     |                  |     (3-centre 2-electron   |
  |  normal bonds        |                  |     bonds) and act as      |
  |                      |                  |     LEWIS ACIDS            |
  +----------------------+------------------+----------------------------+
  | ELECTRON PRECISE     |  Group 14        |  CH4, SiH4, GeH4, SnH4     |
  |  exactly the right   |                  |  -> tetrahedral, no lone   |
  |  number              |                  |     pairs, neutral         |
  +----------------------+------------------+----------------------------+
  | ELECTRON RICH        |  Groups 15,16,17 |  NH3, PH3 (1 lone pair)    |
  |  more electrons than |                  |  H2O, H2S (2 lone pairs)   |
  |  needed - they have  |                  |  HF, HCl  (3 lone pairs)   |
  |  LONE PAIRS          |                  |  -> act as LEWIS BASES     |
  +----------------------+------------------+----------------------------+
```

```
  WHY NH3, H2O and HF HAVE ABNORMALLY HIGH BOILING POINTS:
      N, O and F are small and highly electronegative, so their
      hydrides form HYDROGEN BONDS between molecules. Extra energy
      is needed to break those, so the boiling point jumps.

      Compare:   H2O  373 K     but   H2S  213 K
                 NH3  240 K     but   PH3  185 K
                 HF   293 K     but   HCl  188 K
```

## 8.3 METALLIC (INTERSTITIAL) HYDRIDES

```
  WHO FORMS THEM:  the d-block and f-block (transition and inner
                   transition) metals.

  WHAT HAPPENS:  hydrogen atoms simply SLIP INTO THE HOLES
                 (interstices) between the metal atoms in the
                 crystal lattice. The metal keeps its metallic
                 structure and its metallic properties.

     +---+---+---+---+          +---+---+---+---+
     | M | M | M | M |          | M h M h M h M |
     +---+---+---+---+   + H2   +---+---+---+---+
     | M | M | M | M |  ------> | h M h M h M h |
     +---+---+---+---+          +---+---+---+---+
        pure metal                 h = H atom sitting in a hole
```

| PROPERTY | METALLIC HYDRIDES |
|---|---|
| Bonding | metallic; H atoms occupy interstitial sites |
| Composition | **NON-STOICHIOMETRIC** — the formula is not a whole-number ratio |
| Examples | TiH1.73, ZrH1.30, VH0.56, NiH0.6-0.7, PdH0.6, LaH2.87, CeH2.7 |
| Appearance | look like the metal, hard, brittle |
| Conductivity | **conduct electricity** (unlike ionic and covalent hydrides) |
| Density | LESS dense than the parent metal (the lattice expands) |
| Use | **hydrogen storage** — the hydride absorbs H2 and releases it on heating |

```
  *** THE HYDRIDE GAP *** (a standard 2-mark question)

  +------------------------------------------------------------------+
  |                                                                  |
  |   The elements of GROUPS 7, 8 and 9 of the d-block               |
  |   (Mn, Tc, Re ; Fe, Ru, Os ; Co, Rh, Ir)                         |
  |   DO NOT form hydrides at all.                                    |
  |                                                                  |
  |   This blank region in the middle of the periodic table is        |
  |   called the  H Y D R I D E   G A P .                             |
  |                                                                  |
  |   (Small exceptions exist - chromium of Group 6 forms CrH -       |
  |   but for the exam, quote GROUPS 7, 8 AND 9.)                    |
  |                                                                  |
  +------------------------------------------------------------------+
```

|---|---|---|---|

# TOPIC 9 — WATER: STRUCTURE

Water is the most important compound on earth, and the AP paper asks about its
**structure** and its **anomalous behaviour** very regularly.

## 9.1 Structure of a single water molecule (gas phase)

```
  +------------------------------------------------------------------+
  |                                                                  |
  |     The oxygen atom is  sp3 HYBRIDISED.                          |
  |     It has 2 BOND PAIRS and 2 LONE PAIRS.                        |
  |     Electron geometry: TETRAHEDRAL                               |
  |     Molecular SHAPE:   BENT / ANGULAR / V-SHAPED                 |
  |                                                                  |
  |              lone pair    lone pair                              |
  |                   \        /                                     |
  |                    \      /                                      |
  |                     ( O )                                        |
  |                     /     \                                      |
  |            95.7 pm /       \ 95.7 pm                             |
  |                   /         \                                    |
  |                  H           H                                   |
  |                                                                  |
  |                 <-- 104.5 deg -->                                |
  |                                                                  |
  |     BOND ANGLE H-O-H  =  104.5 degrees                           |
  |     BOND LENGTH O-H   =  95.7 pm                                 |
  |                                                                  |
  |  WHY 104.5 and not the ideal 109.5 of a tetrahedron?             |
  |     Because LONE PAIR - LONE PAIR repulsion is stronger than     |
  |     lone pair - bond pair, which is stronger than bond pair -    |
  |     bond pair. The two lone pairs squeeze the two O-H bonds      |
  |     closer together, shrinking the angle from 109.5 to 104.5.    |
  |                                                                  |
  |  WATER IS POLAR:  O is much more electronegative than H, so      |
  |     each O-H bond has a dipole, and because the molecule is      |
  |     BENT the two dipoles do NOT cancel.                          |
  |          dipole moment = 1.84 D                                  |
  |                                                                  |
  |              O (delta -)                                         |
  |             / \                                                  |
  |            /   \        net dipole points from the H's           |
  |           H     H       up towards the O                         |
  |       (delta +) (delta +)                                        |
  |                                                                  |
  +------------------------------------------------------------------+
```

> **TRAP:** In the **gas phase** the angle is 104.5°. In **ICE** the angle
> opens up slightly to about **109.5°** because the hydrogen bonding pulls the
> molecule into a proper tetrahedral arrangement. If the question says
> "structure of water in the gas phase", the answer is 104.5°.

## 9.2 HYDROGEN BONDING IN LIQUID WATER

```
  Each water molecule has:
      TWO hydrogen atoms  ->  can DONATE 2 hydrogen bonds
      TWO lone pairs      ->  can ACCEPT 2 hydrogen bonds

  So EACH water molecule can make FOUR hydrogen bonds.
  That is the whole secret of water.

                    H
                    |
             H - O  |
                  \ |
                   \|
             H - O ... H - O - H  ....  O - H
                  /                     |
                 /                      H
              H

  (the dotted lines are HYDROGEN BONDS, about 5-10 times weaker
   than an ordinary covalent bond but far stronger than an
   ordinary van der Waals force)

  In LIQUID water these hydrogen bonds are constantly BREAKING and
  RE-FORMING, so molecules can slide past each other and pack
  reasonably closely.
```

```
  |                    |             |                                     |
  |                    .             .                                     |
  |                    |             |                                     |
  |                    O             O      ... and it repeats in 3D       |
  |                                                                        |
  |         (solid line = covalent O-H-O linkage direction)                |
  |         (dotted line = hydrogen bond)                                  |
  |         Note the LARGE HOLE in the middle of every hexagon.            |
  |                                                                        |
  +------------------------------------------------------------------------+
```

## 9.4 WHY ICE IS LESS DENSE THAN WATER — and why it matters

**This is a favourite 2-mark and 4-mark question.**

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |   THE ARGUMENT IN FOUR STEPS - write all four:                         |
  |                                                                        |
  |   1. In ICE, every water molecule is locked by FOUR hydrogen bonds     |
  |      into a rigid TETRAHEDRAL arrangement.                             |
  |                                                                        |
  |   2. This forces the molecules into an OPEN HEXAGONAL CAGE with        |
  |      LARGE EMPTY SPACES (holes) inside it. The molecules are held      |
  |      FURTHER APART than they would like to be.                         |
  |                                                                        |
  |   3. So the SAME MASS of water occupies a GREATER VOLUME as ice.       |
  |      Since density = mass / volume, the DENSITY FALLS.                 |
  |                                                                        |
  |   4. When ice melts, about 15% of the hydrogen bonds break, the        |
  |      cage COLLAPSES, molecules fall into the holes and pack more       |
  |      closely - so LIQUID water is DENSER than ice.                     |
  |                                                                        |
  |         density of ice at 273 K    =  0.917 g/cm3                      |
  |         density of water at 273 K  =  0.9998 g/cm3                     |
  |         density of water at 277 K  =  1.000 g/cm3   <- MAXIMUM         |
  |                                                                        |
  |   THEREFORE ICE FLOATS ON WATER, with about 9/10 of it submerged.      |
  |                                                                        |
  +------------------------------------------------------------------------+
```

```
  WHY WATER HAS ITS MAXIMUM DENSITY AT 277 K (4 degrees C)

     From 273 K upwards, TWO opposite things happen at once:

       (a) the leftover ice-like cage keeps COLLAPSING
           -> volume DECREASES -> density INCREASES

       (b) ordinary thermal expansion
           -> volume INCREASES -> density DECREASES

     Below 277 K, effect (a) wins, so warming water gets DENSER.
     Above 277 K, effect (b) wins, so warming water gets LIGHTER.
     At exactly 277 K they balance -> MAXIMUM DENSITY.
```

```
  WHY IT MATTERS (the "significance" part of the question)

     In winter, the surface of a lake cools, gets denser, and sinks -
     until the whole lake reaches 277 K. Cooling further makes the
     surface water LIGHTER, so it stays on top and freezes there.

     The ice layer then acts as an INSULATING BLANKET.

         ~~~~~~~~ air , -20 deg C ~~~~~~~~
        ==================================  <- ICE floats on top
        |                                |
        |    liquid water at about 4 C   |  <- fish and plants
        |    (277 K)                     |     survive here
        |________________________________|

     If ice were DENSER than water it would sink, the lake would
     freeze SOLID from the bottom up, and every fish, plant and
     micro-organism in it would die. AQUATIC LIFE SURVIVES WINTER
     ONLY BECAUSE ICE FLOATS.
```

# TOPIC 10 — PHYSICAL PROPERTIES AND ANOMALOUS BEHAVIOUR OF WATER

| PROPERTY | VALUE | WHY IT IS UNUSUAL |
|---|---|---|
| Melting point | 273.0 K (0 °C) | H2S melts at 187 K — water should melt around there but is 86 K higher |
| Boiling point | 373.0 K (100 °C) | H2S boils at 213 K; water is 160 K higher |
| Density (max) | 1.000 g/cm3 at 277 K | maximum density is **not** at the freezing point |
| Density of ice | 0.917 g/cm3 | the solid is LIGHTER than the liquid — almost unique |
| Specific heat capacity | 4.18 J/g/K | one of the highest known — huge climate-moderating effect |
| Enthalpy of vaporisation | 40.7 kJ/mol | very high |
| Enthalpy of fusion | 6.01 kJ/mol | high |
| Surface tension | 72.75 dyne/cm at 293 K | very high — allows capillary rise in plants, insects to walk on water |
| Dielectric constant | 78.4 | very high — that is why water dissolves ionic salts so well |
| Dipole moment | 1.84 D | polar |

```
  THE SINGLE REASON BEHIND ALL OF THIS:  H Y D R O G E N   B O N D I N G

     Every "anomalous" property of water traces back to one thing.
     Water molecules cling to each other with 4 hydrogen bonds each.
     Breaking them costs energy. Therefore:

        high melting point         (must break the cage)
        high boiling point         (must break all the H-bonds)
        high specific heat         (heat goes into the H-bonds, not
                                    into raising temperature)
        high enthalpy of vaporisation
        high surface tension       (surface molecules pulled inwards)
        low density of ice         (the H-bond cage is OPEN)
```

```
  WATER AS THE UNIVERSAL SOLVENT

     Because of its HIGH DIELECTRIC CONSTANT (78.4) and its POLARITY,
     water reduces the electrostatic attraction between the ions in a
     crystal by a factor of about 78, so the crystal falls apart.

     Then each ion is surrounded by water molecules - HYDRATION.

           Na+ pulled at by the OXYGEN (delta -) ends
           Cl- pulled at by the HYDROGEN (delta +) ends

             H     H                       H
              \   /                         \
               O ... Na+ ... O               O - H ... Cl-
              /                              /
             H                              H
```

# TOPIC 11 — CHEMICAL PROPERTIES OF WATER

Four headings. Learn one equation under each and you have a 4-mark answer.

## 11.1 AMPHOTERIC NATURE

Water can act as an **ACID** (donate a proton) or a **BASE** (accept a proton).
A substance that can do both is called **AMPHOTERIC** (or amphiprotic).

```
  AS AN ACID (donates H+ to a stronger base):

      H2O  +  NH3   <-->   NH4+   +   OH-
      acid    base         acid       base

  AS A BASE (accepts H+ from a stronger acid):

      H2O  +  H2S   <-->   H3O+   +   HS-
      base    acid         acid       base

  SELF-IONISATION (autoprotolysis) - it does both to ITSELF:

      H2O  +  H2O   <-->   H3O+   +   OH-
                           Kw = 1 x 10^-14 at 298 K
```

## 11.2 REDOX REACTIONS (water gets oxidised or reduced)

```
  (a) WATER AS AN OXIDISING AGENT - it takes electrons, giving H2

      2 Na  +  2 H2O    ->  2 NaOH     +  H2      (violent, cold water)
        Ca  +  2 H2O    ->    Ca(OH)2  +  H2      (cold water, slow)
      3 Fe  +  4 H2O    ->    Fe3O4    +  4 H2    (red-hot iron + steam)
        Mg  +    H2O    ->    MgO      +  H2      (steam)
        C   +    H2O    ->    CO       +  H2      (1270 K - water gas)
      2 F2  +  2 H2O    ->    4 HF     +  O2      <- here water is OXIDISED

  (b) WATER AS A REDUCING AGENT - it gives electrons, giving O2

      2 H2O  +  2 F2   ->  4 HF  +  O2
      6 CO2  + 12 H2O  --(sunlight, chlorophyll)--> C6H12O6 + 6 H2O + 6 O2
                                          PHOTOSYNTHESIS - the biggest
                                          redox reaction on the planet
```

## 11.3 HYDROLYSIS REACTIONS

Because water is amphoteric and has lone pairs, it splits many covalent
compounds apart. This is **hydrolysis**.

```
  P4O10  +  6 H2O   ->  4 H3PO4
  SO3    +    H2O   ->    H2SO4
  N2O5   +    H2O   ->  2 HNO3
  CO2    +    H2O   ->    H2CO3
     (NON-METAL oxides + water  ->  ACIDS)

  Na2O   +    H2O   ->  2 NaOH
  CaO    +    H2O   ->    Ca(OH)2                (slaking of lime)
     (METAL oxides + water  ->  BASES)

  SiCl4  +  2 H2O   ->  SiO2   +  4 HCl
  P4     + ...
  PCl5   +  4 H2O   ->  H3PO4  +  5 HCl
  AlCl3  +  3 H2O   ->  Al(OH)3 + 3 HCl
  CaC2   +  2 H2O   ->  C2H2   +  Ca(OH)2       (acetylene from carbide)
  Al4C3  + 12 H2O   ->  3 CH4  +  4 Al(OH)3
  Mg3N2  +  6 H2O   ->  3 Mg(OH)2 + 2 NH3

  BUT:  CCl4 does NOT hydrolyse.
        REASON: carbon has NO vacant d-orbitals, so water cannot
        attack it. Silicon does have vacant 3d-orbitals, so SiCl4
        hydrolyses easily. (Classic 2-mark question.)
```

## 11.4 HYDRATE FORMATION

Many salts crystallise from water carrying water molecules inside the crystal.
That water is called **WATER OF CRYSTALLISATION**, and the salt is a **HYDRATE**.

```
  THREE TYPES OF WATER OF CRYSTALLISATION:

  +-----------------------+----------------------------+------------------+

  |  HYDROGEN-BONDED      |  hydrogen bonded to the    |  CuSO4.5H2O      |
```

# TOPIC 12 — HARD WATER AND SOFT WATER

## 12.1 What hardness IS

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |   SOFT WATER  =  water that lathers EASILY with soap.                  |
  |                  (rain water, distilled water)                         |
  |                                                                        |
  |   HARD WATER  =  water that does NOT lather easily with soap and       |
  |                  forms a white curdy SCUM instead.                     |
  |                                                                        |
  |   CAUSE OF HARDNESS: dissolved salts of CALCIUM and MAGNESIUM -        |
  |                      their bicarbonates, chlorides and sulphates.      |
  |                                                                        |
  |   WHY SOAP FAILS: soap is sodium stearate, C17H35COONa. The Ca2+ and   |
  |   Mg2+ ions replace the Na+ and form INSOLUBLE stearates:              |
  |                                                                        |
  |     2 C17H35COONa  +  CaCl2  ->  (C17H35COO)2Ca  +  2 NaCl            |
  |          soap                    INSOLUBLE SCUM                        |
  |                                                                        |
  |     2 C17H35COONa  +  MgSO4  ->  (C17H35COO)2Mg  +  Na2SO4            |
  |                                                                        |
  |   All the soap is wasted making scum before any lather can form.       |
  |                                                                        |
  +------------------------------------------------------------------------+
```

## 12.2 The two kinds of hardness

| | TEMPORARY HARDNESS | PERMANENT HARDNESS |
|---|---|---|
| Also called | carbonate hardness | non-carbonate hardness |
| Caused by | **BICARBONATES** of Ca and Mg: Ca(HCO3)2, Mg(HCO3)2 | **CHLORIDES and SULPHATES** of Ca and Mg: CaCl2, MgCl2, CaSO4, MgSO4 |
| Removed by boiling? | **YES** | **NO** |
| Removed by | boiling, Clark's method | washing soda, calgon, permutit, resins |

```
  MEMORY LINE:
     "TEMPORARY = TEMPORARY guests = BICARBONATES = boil them out.
      PERMANENT = they STAY = CHLORIDES and SULPHATES."
```

## 12.3 Disadvantages of hard water

```
  1.  IN THE HOUSE
      - Wastes soap: a huge amount of soap is destroyed as scum before
        any lather forms.
      - The sticky scum spoils the fabric being washed and sticks to
        the skin and hair.
      - Food (especially pulses and dal) does not cook properly in
        hard water; it takes longer and uses more fuel.
      - Hard water tastes unpleasant.

  2.  IN BOILERS  ***SCALE FORMATION***
      - On heating, CaCO3, CaSO4 and Mg(OH)2 deposit as a hard crust
        called SCALE or FUR on the inside of the boiler.
      - Scale is a very poor conductor of heat, so much more fuel is
        needed - WASTE OF FUEL.
      - Scale can block pipes and valves.
      - Uneven heating under a thick scale can crack the boiler plate
        and lead to a BOILER EXPLOSION. This is the most serious one.

  3.  IN INDUSTRY
      - Useless for dyeing, tanning, paper, sugar and textile industry:
        the Ca2+ and Mg2+ ions spoil the dyes and the products.
      - In the laundry industry it makes clothes look dull and grey.
```

## 12.4 REMOVING TEMPORARY HARDNESS

### METHOD 1 — BOILING

```
  On boiling, the soluble BICARBONATES decompose to INSOLUBLE
  carbonates (or hydroxide) which settle out and can be filtered off.

  +------------------------------------------------------------------+
  |                                                                  |
  |   Ca(HCO3)2  --(boil)-->  CaCO3 (insoluble)  +  H2O  +  CO2      |
  |                                                                  |
  |   Mg(HCO3)2  --(boil)-->  Mg(OH)2 (insoluble) +  2 CO2           |
  |                                                                  |
  +------------------------------------------------------------------+

  Note the difference: calcium gives the CARBONATE,
                       magnesium gives the HYDROXIDE
                       (because Mg(OH)2 is even less soluble
                        than MgCO3).

  ONLY works for TEMPORARY hardness. Too costly for large volumes.
```

### METHOD 2 — CLARK'S METHOD (slaked lime)

```
  A calculated quantity of SLAKED LIME, Ca(OH)2, is added.

  +------------------------------------------------------------------+
  |                                                                  |
  |   Ca(HCO3)2  +  Ca(OH)2   ->   2 CaCO3 (down)  +  2 H2O          |
  |                                                                  |
  |   Mg(HCO3)2  +  2 Ca(OH)2 ->   2 CaCO3 (down)  +  Mg(OH)2 (down) |
  |                                                    +  2 H2O      |
  |                                                                  |
  +------------------------------------------------------------------+

  It looks strange to add MORE calcium to remove calcium, but the
  Ca(OH)2 converts the SOLUBLE bicarbonate into INSOLUBLE carbonate,
  which is filtered off. Both calciums end up in the precipitate.

  *** THE CALCULATED QUANTITY MATTERS ***
      Too little lime -> hardness is not fully removed.
      Too much lime   -> the EXCESS Ca(OH)2 itself makes the water
                         hard again (and alkaline).

  ONLY works for TEMPORARY hardness.
```

## 12.5 REMOVING BOTH KINDS OF HARDNESS

### METHOD 3 — WASHING SODA METHOD

```
  Sodium carbonate, Na2CO3.10H2O, is added. It throws the Ca2+ and
  Mg2+ out as insoluble carbonates.

  +------------------------------------------------------------------+
  |                                                                  |
  |   CaCl2   +  Na2CO3   ->   CaCO3 (down)   +  2 NaCl              |
  |   CaSO4   +  Na2CO3   ->   CaCO3 (down)   +  Na2SO4              |
  |   MgCl2   +  Na2CO3   ->   MgCO3 (down)   +  2 NaCl              |
  |   MgSO4   +  Na2CO3   ->   MgCO3 (down)   +  Na2SO4              |
  |                                                                  |
  |   and for the temporary hardness too:                            |
  |   Ca(HCO3)2 + Na2CO3  ->   CaCO3 (down)   +  2 NaHCO3            |
  |                                                                  |
  +------------------------------------------------------------------+

  Removes BOTH temporary and permanent hardness.
  Drawback: it leaves the water full of sodium salts, and a
  precipitate has to be filtered off.
```

### METHOD 4 — THE CALGON METHOD

```
  +------------------------------------------------------------------+
  |                                                                  |
  |   CALGON = SODIUM HEXAMETAPHOSPHATE                              |
  |                                                                  |
  |   Formula:   Na6P6O18   ,  written for reactions as              |
  |                                                                  |
  |              Na2 [ Na4 (PO3)6 ]                                  |
  |                                                                  |
  |   The name comes from "CALcium GONe".                            |
  |                                                                  |
  +------------------------------------------------------------------+

  In water it ionises:

      Na2[Na4(PO3)6]   ->   2 Na+   +   [Na4(PO3)6] 2-

  The complex anion then TRAPS the Ca2+ and Mg2+ ions inside itself:

  +------------------------------------------------------------------+
  |                                                                  |
  |   2 CaSO4  +  Na2[Na4(PO3)6]  ->  Na2[Ca2(PO3)6]  +  2 Na2SO4    |
  |                                                                  |
  |   2 MgSO4  +  Na2[Na4(PO3)6]  ->  Na2[Mg2(PO3)6]  +  2 Na2SO4    |
  |                                                                  |
  |   in ionic form:                                                 |
  |   2 Ca2+  +  [Na4(PO3)6] 2-   ->  [Ca2(PO3)6] 2-  +  4 Na+       |
  |                                                                  |
  +------------------------------------------------------------------+

  *** THE BIG ADVANTAGE ***
      The Ca2+ and Mg2+ are locked inside a SOLUBLE COMPLEX.
      NO PRECIPITATE IS FORMED AT ALL, so there is nothing to filter
      and no sludge or scale in the boiler.

      This is why calgon is the preferred treatment for BOILER water.
```

### METHOD 5 — THE ION-EXCHANGE / PERMUTIT (ZEOLITE) METHOD

```
  +------------------------------------------------------------------+
  |                                                                  |
  |   ZEOLITE = hydrated sodium aluminium silicate                   |
  |                                                                  |
  |        Na2Al2Si2O8 . x H2O     (also written NaAlSiO4)           |
  |                                                                  |
  |   The artificial form is called PERMUTIT.                        |
  |   For short, write it as   Na2Z   (Z = the zeolite skeleton).    |
  |                                                                  |
  +------------------------------------------------------------------+

  HOW IT WORKS: hard water is passed down a tall tank packed with
  permutit granules. The zeolite SWAPS its sodium for the calcium
  and magnesium in the water.

  +------------------------------------------------------------------+
  |                                                                  |
  |   Na2Z  +  Ca2+   ->   CaZ   +   2 Na+                           |
  |   Na2Z  +  Mg2+   ->   MgZ   +   2 Na+                           |
  |                                                                  |
  |   or in full:                                                    |
  |   Na2Al2Si2O8 + CaCl2  ->  CaAl2Si2O8  +  2 NaCl                 |
  |                                                                  |
  +------------------------------------------------------------------+

  THE APPARATUS

         hard water in
              |
              v
        +-----------+
        | o o o o o |
        | o o o o o |   <-- bed of PERMUTIT granules
        | o o o o o |
        | o o o o o |
        +-----------+
              |
              v
         SOFT water out


  *** REGENERATION *** (always asked - do not leave it out)

      When all the sodium has been used up the bed is "exhausted"
      (it is now CaZ / MgZ). It is REGENERATED by washing it with a
      concentrated solution of BRINE (10% NaCl):

  +------------------------------------------------------------------+
  |                                                                  |
  |   CaZ  +  2 NaCl   ->   Na2Z   +   CaCl2                         |
  |   MgZ  +  2 NaCl   ->   Na2Z   +   MgCl2                         |
  |                                                                  |
  |   The CaCl2 and MgCl2 are washed away, and the bed is as good    |
  |   as new. The same permutit can be used again and again.         |
  |                                                                  |
  +------------------------------------------------------------------+

  DRAWBACK: the softened water still contains Na+ ions. It is soft,
  but it is NOT pure / de-ionised water.
```

### METHOD 6 — THE SYNTHETIC RESIN (DE-IONISATION) METHOD

```
  This one removes ALL the ions, not just Ca2+ and Mg2+, and gives
  water as pure as distilled water. TWO columns are used.

  +------------------------------------------------------------------+
  |                                                                  |
  |   COLUMN 1 - CATION EXCHANGE RESIN                               |
  |      A resin carrying acidic -SO3H or -COOH groups. Write it     |
  |      as  RSO3H  (R = the giant organic skeleton).                |
  |                                                                  |
  |      2 RSO3H  +  Ca2+   ->   (RSO3)2Ca   +   2 H+                |
  |      2 RSO3H  +  Mg2+   ->   (RSO3)2Mg   +   2 H+                |
  |      RSO3H    +  Na+    ->    RSO3Na     +     H+                |
  |                                                                  |
  |      -> all CATIONS are removed, H+ is released,                 |
  |         so the water leaving column 1 is ACIDIC.                 |
  |                                                                  |
  +------------------------------------------------------------------+
  |                                                                  |
  |   COLUMN 2 - ANION EXCHANGE RESIN                                |
  |      A resin carrying basic -NH2 or quaternary ammonium groups.  |
  |      Write it as  RNH3OH  or  RNH2 .                             |
  |                                                                  |
  |      RNH2  +  H2O   ->   RNH3+  +  OH-                           |
  |      RNH3+ OH-  +  Cl-      ->  RNH3+ Cl-      +  OH-            |
  |      2 RNH3+ OH- + SO4 2-   ->  (RNH3)2 SO4    + 2 OH-           |
  |                                                                  |
  |      -> all ANIONS are removed, OH- is released.                 |
  |                                                                  |
  +------------------------------------------------------------------+
  |                                                                  |
  |   FINALLY, the H+ from column 1 and the OH- from column 2        |
  |   simply neutralise each other:                                  |
  |                                                                  |
  |          H+   +   OH-    ->    H2O                               |
  |                                                                  |
  |   The result is DE-MINERALISED / DE-IONISED water, essentially   |
  |   as pure as distilled water.                                    |
  |                                                                  |
  +------------------------------------------------------------------+

  THE FLOW DIAGRAM

     hard water
         |
         v
   +-------------+     acidic       +-------------+
   |   CATION    |     water        |   ANION     |
   |  EXCHANGER  |  ------------>   |  EXCHANGER  |  ---->  DE-IONISED
   |   RSO3H     |    (has H+)      |   RNH3OH    |          WATER
   +-------------+                  +-------------+

  REGENERATION:
      cation resin  ->  wash with dilute H2SO4 or HCl  (puts H+ back)
      anion resin   ->  wash with dilute NaOH          (puts OH- back)
```

## 12.6 SUMMARY TABLE OF ALL SIX METHODS

| # | METHOD | REAGENT USED | REMOVES | KEY EQUATION |
|---|---|---|---|---|
| 1 | Boiling | heat only | temporary only | Ca(HCO3)2 -> CaCO3 + H2O + CO2 |
| 2 | Clark's | Ca(OH)2 (slaked lime) | temporary only | Ca(HCO3)2 + Ca(OH)2 -> 2CaCO3 + 2H2O |

## WORKED EXAMPLE 4

**Q. A sample of water contains 16.2 mg of Ca(HCO3)2 per litre. Calculate the
hardness in terms of ppm of CaCO3. (Ca(HCO3)2 = 162, CaCO3 = 100)**

```
  STEP 1   Hardness is always REPORTED as if it were CaCO3, because
           CaCO3 has the convenient molar mass of 100.

  STEP 2   Set up the equivalence from the mole ratio:
                1 mole Ca(HCO3)2  is equivalent to  1 mole CaCO3
                so       162 g    is equivalent to       100 g

  STEP 3   Convert 16.2 mg of Ca(HCO3)2 into its CaCO3 equivalent:

              mass of CaCO3  =  16.2 mg  x  (100 / 162)
                             =  16.2 x 0.6173
                             =  10.0 mg

  STEP 4   ppm means "parts per million" = mg per litre (because
           1 litre of water is 10^6 mg).

              hardness  =  10 mg per litre  =  10 ppm

  ANSWER:  10 ppm of CaCO3.

  CHECK: 162/100 = 1.62, and 16.2/1.62 = 10. CORRECT.
```

# TOPIC 13 — HYDROGEN PEROXIDE, H2O2 : PREPARATION AND STRUCTURE

Hydrogen peroxide is **the single biggest item in this chapter**. It can carry an
entire 8-mark question on its own.

## 13.1 PREPARATION

### METHOD 1 — From BARIUM PEROXIDE (the laboratory / classical method)

```
  Hydrated barium peroxide is added SLOWLY, in small amounts, to
  ICE-COLD DILUTE sulphuric acid.

  +------------------------------------------------------------------+
  |                                                                  |
  |   BaO2 . 8H2O  +  H2SO4   ->   BaSO4 (down)  +  H2O2  +  8 H2O   |
  |                                                                  |
  +------------------------------------------------------------------+

  The BaSO4 is INSOLUBLE and is simply filtered off, leaving a
  dilute solution of H2O2 behind. That is why sulphuric acid is
  chosen - the by-product removes itself.

  WHY HYDRATED BaO2 AND NOT DRY BaO2?
      Dry (anhydrous) BaO2 gets coated with a layer of insoluble
      BaSO4 which stops the acid getting to the rest of it - the
      reaction dies. The hydrated form does not cake up like this.

  WHY ICE-COLD, AND WHY ADD IT SLOWLY?
      H2O2 decomposes on warming. The reaction is exothermic, so
      the mixture must be kept cold and the addition kept slow.

  ALTERNATIVE ACIDS:
      BaO2 + 2 HCl    ->  BaCl2 + H2O2     (but BaCl2 is SOLUBLE,
                                            so it is hard to remove)
      BaO2 + H2CO3    ->  BaCO3 (down) + H2O2
      BaO2 + H3PO4    ->  Ba3(PO4)2 (down) + H2O2
      2 Na2O2 + H2SO4 ->  2 NaOH ... / Na2O2 + 2H2O -> 2NaOH + H2O2
```

### METHOD 2 — By ELECTROLYSIS of sulphuric acid (Merck's process)

```
  50% sulphuric acid (or a solution of ammonium sulphate in
  sulphuric acid) is electrolysed at a HIGH CURRENT DENSITY using
  PLATINUM electrodes.

  +------------------------------------------------------------------+
  |                                                                  |
  |  STEP 1  AT THE ANODE - two hydrogen sulphate ions join up:      |
  |                                                                  |
  |     2 HSO4-   ->   H2S2O8   +   2 e-                             |
  |                    PEROXODISULPHURIC ACID (Marshall's acid)      |
  |                                                                  |
  |          AT THE CATHODE:   2 H+  +  2 e-  ->  H2                 |
  |                                                                  |
  |  STEP 2  The H2S2O8 is then HYDROLYSED (distilled under          |
  |          reduced pressure):                                      |
  |                                                                  |
  |     H2S2O8  +  H2O   ->   H2SO5   +   H2SO4                      |
  |                           PEROXOMONOSULPHURIC ACID (Caro's acid) |
  |                                                                  |
  |     H2SO5   +  H2O   ->   H2SO4   +   H2O2                       |
  |                                                                  |
  |  OVERALL:  H2S2O8  +  2 H2O   ->   2 H2SO4  +  H2O2              |
  |                                                                  |
  |  The H2SO4 is recycled back into the cell.                       |
  |                                                                  |
  +------------------------------------------------------------------+

  MEMORY:  "MARSHALL is the DOUBLE one (peroxoDIsulphuric, H2S2O8),
            CARO is the SINGLE one (peroxoMONOsulphuric, H2SO5)."
```

### METHOD 3 — THE INDUSTRIAL 2-ETHYLANTHRAQUINOL AUTOXIDATION ROUTE

```
  This is how virtually all commercial H2O2 is made today. It is a
  beautiful process because the organic compound is RECYCLED - the
  only things consumed are HYDROGEN and AIR.

  +------------------------------------------------------------------+
  |                                                                  |
  |  STEP 1  AUTOXIDATION                                            |
  |                                                                  |
  |    2-ethylanthraquinOL  +  O2  --(air)-->                        |
  |                             2-ethylanthraquinONE  +  H2O2        |
  |                                                                  |
  |  STEP 2  REGENERATION (the quinone is hydrogenated back)         |
  |                                                                  |
  |    2-ethylanthraquinONE  +  H2  --(Pd catalyst)-->               |
  |                             2-ethylanthraquinOL                  |
  |                                                                  |
  |  OVERALL, adding the two:                                        |
  |                                                                  |
  |         H2   +   O2    ->    H2O2                                |
  |                                                                  |
  |  The quinol/quinone pair is just a CARRIER. It is not used up.   |
  |                                                                  |
  +------------------------------------------------------------------+

  THE CYCLE, drawn:

              +----> 2-ethylanthraquinOL ----+
              |                              |
        H2 + Pd                            + O2 (air)
              |                              |
              +---- 2-ethylanthraquinONE <---+
                                             |
                                             +---> H2O2 extracted
                                                   with water

  CONCENTRATION:
      The dilute H2O2 obtained (about 1%) is concentrated by
      DISTILLATION UNDER REDUCED PRESSURE (never at atmospheric
      pressure - it would decompose or explode). About 30% solution
      is sold as "perhydrol". Higher purity is reached by careful
      distillation and then by crystallisation.

  ELECTROLYSIS OF 50% H2SO4 gives about 30% H2O2.
```

## 13.2 THE STRUCTURE OF HYDROGEN PEROXIDE — the "OPEN BOOK"

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |   H2O2 IS  NON-PLANAR.  Its shape is described as an OPEN BOOK.        |
  |                                                                        |
  |   The two O-H bonds lie in TWO DIFFERENT PLANES, like the two          |
  |   pages of a half-open book, with the O-O bond as the SPINE.           |
  |                                                                        |
  |                                                                        |
  |            THE OPEN BOOK PICTURE                                       |
  |                                                                        |
  |                 H                                                      |
  |                  \                                                     |
  |                   \                         <---- page 1               |
  |                    O -------------- O                                  |
  |                    |     SPINE      |\                                 |
  |                    |    (O-O bond)  | \                                |
  |                    |                |  \                               |
  |                    |                |   H       <---- page 2           |
  |                    |                |                                  |
  |                                                                        |
  |            SEEN ALONG THE O-O BOND (looking down the spine):           |
  |                                                                        |
  |                          H                                             |
  |                           \                                            |
  |                            \                                           |
  |                        (O,O)  ) dihedral angle                         |
  |                            /                                           |
  |                           /                                            |
  |                          H                                             |
  |                                                                        |
  |            The angle between the two "pages" is the                    |
  |            DIHEDRAL ANGLE (also called the torsion angle).             |
  |                                                                        |
  +------------------------------------------------------------------------+
```

### THE NUMBERS — learn all six

```
  +----------------------------+-------------------+-------------------+
  |                            |   GAS PHASE       |   SOLID PHASE     |
  |                            |                   |   (at 110 K)      |
  +----------------------------+-------------------+-------------------+
  |  O - O bond length         |    147.5 pm       |    145.8 pm       |
  |  O - H bond length         |     95.0 pm       |     98.8 pm       |
  |  O - O - H bond angle      |     94.8 deg      |    101.9 deg      |
  |  DIHEDRAL angle            |    111.5 deg      |     90.2 deg      |
  +----------------------------+-------------------+-------------------+

  WHY DO THE SOLID VALUES DIFFER?
      In the solid, the molecules are HYDROGEN BONDED to each other.
      Those hydrogen bonds pull the O-H groups round and change both
      the angles and the bond lengths.

  MEMORY LINE:
      "In the GAS the book is open WIDER (111.5),
       in the SOLID hydrogen bonds SQUEEZE it nearly shut (90.2)."
```

```
  BONDING NOTE:
      Each oxygen is roughly sp3 hybridised, with two lone pairs.
      Oxidation state of oxygen in H2O2 is  -1
      (compare: -2 in H2O, 0 in O2, -1/2 in the superoxide ion).

      IT IS BECAUSE OXYGEN IS AT THE MIDDLE OXIDATION STATE (-1)
      THAT H2O2 CAN ACT BOTH AS AN OXIDISING AGENT (going down to -2)
      AND AS A REDUCING AGENT (going up to 0). Remember this - it is
      the reason behind the whole of TOPIC 14.

           -2            -1             0
          H2O   <----   H2O2   ---->   O2
                 H2O2 is           H2O2 is
                 OXIDISED here?    no -
                 no - REDUCED,     H2O2 is OXIDISED,
                 so H2O2 acts      so H2O2 acts
                 as an OXIDISING   as a REDUCING
                 agent             agent
```

## 14.2 DECOMPOSITION AND STORAGE

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |   H2O2 IS THERMODYNAMICALLY UNSTABLE. IT DISPROPORTIONATES:            |
  |                                                                        |
  |        2 H2O2(l)   ->   2 H2O(l)   +   O2(g)                           |
  |                              delta H  =  -196 kJ/mol                   |
  |                                                                        |
  |   (This is a DISPROPORTIONATION: oxygen at -1 goes DOWN to -2 in       |
  |    water and UP to 0 in O2 at the same time.)                          |
  |                                                                        |
  |   IT IS SPED UP BY:                                                    |
  |        - LIGHT (especially sunlight / UV)                              |
  |        - HEAT                                                          |
  |        - ALKALI (basic conditions)                                     |
  |        - ROUGH SURFACES and DUST                                       |
  |        - traces of METAL IONS (Fe, Cu, Mn) and metal surfaces          |
  |        - the enzyme CATALASE (this is why a cut fizzes when you        |
  |          pour peroxide on it)                                          |
  |                                                                        |
  +------------------------------------------------------------------------+
```

### WHY IT IS STORED THE WAY IT IS — a guaranteed 2-mark question

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |  1.  STORED IN DARK COLOURED (brown / opaque plastic) BOTTLES          |
  |      -> because LIGHT catalyses its decomposition.                     |
  |                                                                        |
  |  2.  STORED IN WAX-LINED GLASS or PLASTIC bottles                      |
  |      -> ordinary glass is slightly ALKALINE and alkali speeds up       |
  |         the decomposition. Rough glass surfaces also catalyse it.      |
  |                                                                        |
  |  3.  KEPT IN A COOL PLACE, AWAY FROM DUST                              |
  |      -> heat and dust particles both catalyse decomposition.           |
  |                                                                        |
  |  4.  A STABILISER IS ADDED, in very small amount:                      |
  |         UREA  ,  PHOSPHORIC ACID  ,  GLYCEROL  ,  ACETANILIDE ,        |
  |         sodium stannate or sodium pyrophosphate                        |
  |      -> the stabiliser keeps the solution faintly ACIDIC and           |
  |         traps trace metal ions, both of which slow decomposition.      |
  |                                                                        |
  |  5.  BOTTLES ARE ONLY LOOSELY STOPPERED / vented                       |
  |      -> the oxygen slowly given off must escape, or the pressure       |
  |         will burst the container.                                      |
  |                                                                        |
  +------------------------------------------------------------------------+
```

## 14.3 CHEMICAL PROPERTIES — the four boxes

Because oxygen in H2O2 is at the **middle** oxidation state (−1), H2O2 can go
either way. This gives **FOUR** situations, and the exam asks for equations from
all four.

```
  +---------------------+---------------------------+------------------------+
  |                     |   ACIDIC MEDIUM           |   BASIC MEDIUM         |
  +---------------------+---------------------------+------------------------+
  |  AS AN OXIDISING    |   H2O2 + 2H+ + 2e-        |   H2O2 + 2e-           |
  |  AGENT              |          -> 2 H2O         |          -> 2 OH-      |
  |  (H2O2 is REDUCED)  |                           |                        |
  +---------------------+---------------------------+------------------------+
  |  AS A REDUCING      |   H2O2 -> O2 + 2H+ + 2e-  |   H2O2 + 2OH-          |
  |  AGENT              |                           |     -> O2 + 2H2O + 2e- |
  |  (H2O2 is OXIDISED) |                           |                        |
  +---------------------+---------------------------+------------------------+

  IN EVERY CASE, WHEN H2O2 ACTS AS A REDUCING AGENT, OXYGEN GAS IS
  RELEASED. That is the giveaway - if you see O2 among the products,
  H2O2 was the REDUCING agent.
```

### (a) OXIDISING AGENT IN **ACIDIC** MEDIUM

```
  2 Fe2+  +  2 H+  +  H2O2   ->   2 Fe3+  +  2 H2O
  green                           yellow

  2 I-    +  2 H+  +  H2O2   ->   I2   +  2 H2O
                                  (brown - starch turns blue)

  PbS     +  4 H2O2          ->   PbSO4   +  4 H2O
  BLACK                           WHITE
       *** This is the reaction used to RESTORE OLD PAINTINGS.
           The white lead pigment turns black as PbS with time;
           dilute H2O2 turns it back to white PbSO4. ***

  Na2SO3  +  H2O2            ->   Na2SO4  +  H2O
  2 KI    +  H2SO4 + H2O2    ->   K2SO4   +  I2  +  2 H2O
  H2S     +  H2O2            ->   S       +  2 H2O   (S turns milky)
```

### (b) OXIDISING AGENT IN **BASIC** MEDIUM

```
  2 Fe2+   +   H2O2   ->   2 Fe3+   +   2 OH-

  Mn2+     +   H2O2   ->   Mn4+     +   2 OH-
                           (MnO2 is precipitated)

  CrCl3 + 3 H2O2 + 10 KOH -> 2 K2CrO4 + 3 KCl + 8 H2O   (yellow chromate)

  Also the famous CHROMIC PEROXIDE test:
  Cr2O7 2- + 4 H2O2 + 2 H+  ->  2 CrO5 + 5 H2O
       CrO5 = chromium peroxide, a DEEP BLUE colour extracted into
       ether. This is the standard TEST for H2O2 (or for chromate).
```

### (c) REDUCING AGENT IN **ACIDIC** MEDIUM

```
  2 KMnO4 + 3 H2SO4 + 5 H2O2  ->  K2SO4 + 2 MnSO4 + 8 H2O + 5 O2
  purple                                   colourless        gas

  in ionic form:
  2 MnO4-  +  6 H+  +  5 H2O2  ->  2 Mn2+  +  8 H2O  +  5 O2

  *** The purple colour of KMnO4 is DISCHARGED and O2 bubbles off.
      This is the standard TITRATION used to find the strength of
      an H2O2 solution. ***

  HOCl  +  H2O2   ->   H3O+  +  Cl-  +  O2

  Cl2   +  H2O2   ->   2 HCl  +  O2

  Ag2O  +  H2O2   ->   2 Ag   +  H2O  +  O2      (silver mirror)
```

### (d) REDUCING AGENT IN **BASIC** MEDIUM

```
  I2   +   H2O2  +  2 OH-   ->   2 I-   +  2 H2O  +  O2
  brown                          colourless

  2 MnO4-  +  3 H2O2   ->   2 MnO2  +  3 O2  +  2 H2O  +  2 OH-

  2 K3[Fe(CN)6] + 2 KOH + H2O2 -> 2 K4[Fe(CN)6] + 2 H2O + O2
```

```
  +------------------------------------------------------------------------+
  |  THE FOUR EQUATIONS TO WRITE IF YOU CAN ONLY REMEMBER FOUR:            |
  |                                                                        |
  |   OXIDISING / ACID  :  2 Fe2+ + 2 H+ + H2O2  ->  2 Fe3+ + 2 H2O        |
  |   OXIDISING / BASE  :  2 Fe2+ + H2O2         ->  2 Fe3+ + 2 OH-        |
  |   REDUCING  / ACID  :  2 MnO4- + 6H+ + 5 H2O2 -> 2 Mn2+ + 8 H2O + 5 O2 |
  |   REDUCING  / BASE  :  I2 + H2O2 + 2 OH-      -> 2 I- + 2 H2O + O2     |
  |                                                                        |
  |  Notice how the Fe2+ example works in BOTH acid and base with only     |
  |  a tiny change - it is the cheapest pair to memorise.                  |
  +------------------------------------------------------------------------+
```

### (e) OTHER REACTIONS

```
  AS AN ACID (H2O2 is a very weak dibasic acid, Ka1 = 1.55 x 10^-12):

     H2O2  +  2 NaOH   ->   Na2O2  +  2 H2O
     H2O2  +  Ba(OH)2  ->   BaO2   +  2 H2O
     H2O2  +  H2O      ->   H3O+   +  HO2-

  BLEACHING ACTION (this is WHY it bleaches):

     H2O2   ->   H2O   +   [O]        nascent oxygen

     The NASCENT OXYGEN attacks the coloured matter and oxidises it
     to a colourless substance. Because it works by OXIDATION and not
     by reduction, the bleaching is PERMANENT.

     It bleaches delicate things that chlorine would destroy - hair,
     silk, wool, ivory, feathers, old oil paintings.
```

## 14.4 STRENGTH OF A HYDROGEN PEROXIDE SOLUTION

There are three ways to state how strong an H2O2 solution is.

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |  WAY 1  -  PERCENTAGE STRENGTH                                         |
  |            "30 % H2O2"  means  30 g of H2O2 in 100 mL of solution.     |
  |                                                                        |
  |  WAY 2  -  STRENGTH IN g/L                                             |
  |            grams of H2O2 in one litre of solution.                     |
  |                                                                        |
  |  WAY 3  -  *** VOLUME STRENGTH *** (the one the exam wants)            |
  |                                                                        |
  |     "x VOLUME H2O2" means:                                             |
  |                                                                        |
  |        1 mL of that solution, when completely decomposed,              |
  |        gives  x  mL of OXYGEN GAS measured at STP.                     |
  |                                                                        |
  |     So "20 volume H2O2" -> 1 mL of it gives 20 mL of O2 at STP,        |
  |     and 1 litre of it gives 20 litres of O2 at STP.                    |
  |                                                                        |
  +------------------------------------------------------------------------+
```

### DERIVING THE CONVERSION FORMULA (understand it once, then just use it)

```
  START from the decomposition equation:

        2 H2O2   ->   2 H2O   +   O2

  STEP 1   Mole ratio:   2 moles H2O2   give   1 mole O2

  STEP 2   Put in the numbers:
              2 x 34 g = 68 g of H2O2   give   22400 mL of O2 at STP

  STEP 3   Therefore 1 mL of O2 comes from
                 68 / 22400   =   0.003035 g   of H2O2

  STEP 4   A solution of volume strength x gives x mL of O2 per mL
           of solution, i.e. 1000x mL of O2 per litre.
           So the mass of H2O2 in one litre is

               strength (g/L)  =  1000 x  *  0.003035
                               =  3.035 x
                               =  x  *  17 / 5.6
                            (because 17/5.6 = 3.0357)

  +------------------------------------------------------------------------+
  |                                                                        |
  |    STRENGTH in g/L    =    VOLUME STRENGTH   x   17 / 5.6              |
  |                                                                        |
  |    STRENGTH in g/L    =    VOLUME STRENGTH   x   3.035                 |
  |                                                                        |
  |    NORMALITY          =    VOLUME STRENGTH   /   5.6                   |
  |                                                                        |
  |    MOLARITY           =    VOLUME STRENGTH   /   11.2                  |
  |                                                                        |
  |    NORMALITY          =    2  x  MOLARITY                              |
  |                                                                        |
  |    % strength (w/V)   =    STRENGTH in g/L   /   10                    |
  |                                                                        |
  +------------------------------------------------------------------------+

  WHERE 5.6 AND 11.2 COME FROM:
      Equivalent mass of H2O2 = molar mass / 2 = 34/2 = 17 g
      17 / 3.035 = 5.6         -> normality  = V / 5.6
      Molar mass 34 ; 34/3.035 = 11.2  -> molarity = V / 11.2
      Or simply: 1 mole H2O2 gives 1/2 mole O2 = 11.2 L at STP.
```

## WORKED EXAMPLE 5

**Q. Calculate the strength in g/L, the molarity and the normality of
"20 volume" hydrogen peroxide.**

```
  GIVEN     volume strength  =  20

  STEP 1    Strength in g/L
                 =  volume strength  x  17 / 5.6
                 =  20  x  17 / 5.6
                 =  340 / 5.6
                 =  60.71 g/L

  STEP 2    Molarity
                 =  volume strength / 11.2
                 =  20 / 11.2
                 =  1.786 M

            (cross-check:  60.71 g/L  /  34 g/mol  =  1.786 M   CORRECT)

  STEP 3    Normality
                 =  volume strength / 5.6
                 =  20 / 5.6
                 =  3.571 N

            (cross-check:  N = 2 x M = 2 x 1.786 = 3.571   CORRECT)

  ANSWER:  strength = 60.71 g/L , molarity = 1.786 M ,
           normality = 3.571 N.
```

## WORKED EXAMPLE 6

**Q. A bottle of hydrogen peroxide is labelled "30 % (w/V)". Find its volume
strength.**

```
  STEP 1    "30 % (w/V)" means 30 g of H2O2 in 100 mL of solution.
            Convert to per litre:
                 30 g in 100 mL  =  300 g in 1000 mL  =  300 g/L

  STEP 2    Use the formula backwards:
                 strength (g/L)  =  volume strength  x  17 / 5.6

                 300  =  V  x  17 / 5.6

  STEP 3    Solve for V:
                 V  =  300  x  5.6 / 17
                    =  1680 / 17
                    =  98.8

  ANSWER:  the solution is about  100 VOLUME  hydrogen peroxide.

  CHECK:   100 volume x 3.035 = 303.5 g/L, and we wanted 300 g/L.
           So V is just under 100, i.e. 98.8. CORRECT.

  (This is why commercial 30% H2O2 is sold as "100 volume peroxide".)
```

## WORKED EXAMPLE 7

**Q. 10 mL of a hydrogen peroxide solution required 20 mL of 0.1 N KMnO4
solution for complete oxidation in acidic medium. Find the volume strength
of the H2O2.**

```
  STEP 1    In a titration the equivalents must be equal:

                 N1 V1  =  N2 V2
              (H2O2)      (KMnO4)

  STEP 2    Substitute:

                 N1  x  10   =   0.1  x  20
                 N1  x  10   =   2
                 N1          =   0.2 N

  STEP 3    Convert normality to volume strength:

                 Normality  =  volume strength / 5.6
            so   volume strength  =  Normality  x  5.6
                                  =  0.2  x  5.6
                                  =  1.12

  ANSWER:  the solution is  1.12 volume  H2O2.

  CHECK:   strength = 1.12 x 3.035 = 3.4 g/L = 0.1 mol/L = 0.1 M,
           and N = 2M = 0.2 N. CORRECT.
```

## WORKED EXAMPLE 8

**Q. What volume of oxygen at STP is liberated when 100 mL of "10 volume"
H2O2 decomposes completely? How many grams of H2O2 does the sample contain?**

```
  PART 1 - VOLUME OF OXYGEN

  STEP 1    "10 volume" means 1 mL gives 10 mL of O2.
  STEP 2    So 100 mL gives  100 x 10  =  1000 mL  =  1 litre of O2.

  ANSWER (part 1):  1 litre = 1000 mL of O2 at STP.


  PART 2 - MASS OF H2O2

  STEP 1    strength (g/L)  =  10  x  17/5.6  =  30.36 g/L
  STEP 2    In 100 mL (= 0.1 L):
                 mass  =  30.36  x  0.1  =  3.04 g

  ANSWER (part 2):  about 3.04 g of H2O2.

  CHECK BY MOLES:  2 H2O2 -> 2 H2O + O2
                   1 L of O2 at STP = 1/22.4 = 0.04464 mol
                   needs 2 x 0.04464 = 0.08929 mol of H2O2
                   mass = 0.08929 x 34 = 3.04 g.   CORRECT.
```

## 15.1 Why hydrogen is a wonderful fuel


## 15.2 The problems

```
  1.  STORAGE AND TRANSPORT
      H2 is a very light gas, so a useful amount takes up an enormous
      volume. It must be either compressed to very high pressure or
      liquefied at 20 K, both of which are difficult and expensive.
      A litre of petrol carries far more energy than a litre of H2 gas.

  2.  SAFETY
      Hydrogen-air mixtures are EXPLOSIVE over a very wide range of
      compositions (4% to 75% H2). It burns with an almost invisible
      flame. It leaks through very small gaps.

  3.  COST OF PRODUCTION
      Electrolysis gives pure H2 but needs a lot of electricity - and
      if that electricity comes from coal, the pollution has just been
      moved somewhere else. Most H2 today is made from natural gas,
      which produces CO2.

  4.  METAL EMBRITTLEMENT
      Hydrogen diffuses into steel and makes it brittle, so special
      containers and pipelines are needed.
```

## 15.3 Storing hydrogen — metal hydrides

```
  The most promising solution is to store hydrogen INSIDE a metal
  as an INTERSTITIAL HYDRIDE, and heat it to get the hydrogen back.

      M   +   H2   <-->   MH2      (absorbed on cooling / pressure,
                                    released on heating)

  Alloys used:  LaNi5 ,  FeTi ,  Mg2Ni

  ADVANTAGE:  a hydride tank can hold MORE hydrogen atoms per litre
              than the same volume of LIQUID hydrogen, and it is safe
              (no high pressure, no cryogenic tank).

  DISADVANTAGE: the tank is HEAVY, because most of it is metal.
```

## 15.4 The HYDROGEN FUEL CELL

```
  A FUEL CELL converts the chemical energy of a fuel DIRECTLY into
  electricity, without burning it. So it is not limited by the
  Carnot efficiency of a heat engine and can be 60-70% efficient
  instead of the 25-30% of a petrol engine.

  +------------------------------------------------------------------------+
  |                                                                        |
  |            H2 in                              O2 (air) in              |
  |              |                                    |                    |
  |              v                                    v                    |
  |        +-----------+     KOH electrolyte    +-----------+              |
  |        |  ANODE    |  ....................  |  CATHODE  |              |
  |        |   (-)     |                        |    (+)    |              |
  |        | porous C  |                        | porous C  |              |
  |        | with Pt   |                        | with Pt   |              |
  |        +-----------+                        +-----------+              |
  |              |                                    |                    |
  |              +--------[ ELECTRIC LOAD ]-----------+                    |
  |                            e- flow                                     |
  |                                                                        |
  |    AT THE ANODE  :  2 H2 + 4 OH-  ->  4 H2O  +  4 e-                   |
  |    AT THE CATHODE:  O2  + 2 H2O + 4 e-  ->  4 OH-                      |
  |    ---------------------------------------------------------           |
  |    OVERALL       :  2 H2  +  O2   ->   2 H2O                           |
  |                                                                        |
  |    OUTPUT: electricity + heat + DRINKABLE WATER. Nothing else.         |
  |                                                                        |
  +------------------------------------------------------------------------+

  USES: the Apollo spacecraft used hydrogen-oxygen fuel cells, and the
        astronauts drank the water produced. Fuel-cell buses and cars
        now run in several countries.
```

## 15.5 THE HYDROGEN ECONOMY

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |   DEFINITION (learn this sentence):                                    |
  |                                                                        |
  |     The HYDROGEN ECONOMY is the idea of TRANSPORTING and STORING       |
  |     energy in the form of LIQUID or GASEOUS DIHYDROGEN instead of      |
  |     as electricity, so that energy can be moved and used with          |
  |     minimum loss and with water as the only waste product.             |
  |                                                                        |
  |   THE IDEA IN ONE PICTURE:                                             |
  |                                                                        |
  |     SOLAR / WIND / NUCLEAR                                             |
  |          |                                                             |
  |          v                                                             |
  |     electricity  ---> ELECTROLYSIS of water ---> H2                    |
  |                                                  |                     |
  |                          store it (metal hydride, tank, pipeline)      |
  |                                                  |                     |
  |                                                  v                     |
  |               burn it in an engine   OR   run a FUEL CELL              |
  |                                                  |                     |
  |                                                  v                     |
  |                                    energy  +  WATER (recycled)         |
  |                                                                        |
  |   NOTE: hydrogen is NOT a source of energy. It is an energy            |
  |   CARRIER - a rechargeable chemical battery. You must spend            |
  |   energy to make it. That is the single most important sentence        |
  |   in this topic and it is often the point of the question.             |
  |                                                                        |
  +------------------------------------------------------------------------+

  OTHER CURRENT USES OF HYDROGEN AS A FUEL:
     - 5% H2 blended into CNG for buses (called HCNG). Delhi has
       run trial fleets on this.
     - hydrogen-fuelled internal combustion engines in demonstration
       cars.
     - hydrogen fuel cells in buses and trains.
```
