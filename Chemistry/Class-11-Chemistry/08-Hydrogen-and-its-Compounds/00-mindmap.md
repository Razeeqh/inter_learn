## THE 60-SECOND VERSION

Hydrogen is **one proton and one electron**. That is the entire atom. From that
single fact everything in the chapter follows.

```
  It has 1 electron  ->  it can LOSE it     ->  H+   (like Na+, like a METAL)
                     ->  it can GAIN one    ->  H-   (like Cl-, like a HALOGEN)
                     ->  it can SHARE it    ->  H-Cl , H2O , CH4  (covalent)

  So hydrogen behaves a bit like Group 1 and a bit like Group 17,
  and belongs perfectly to NEITHER. That is the "anomalous position".
```

```
  THE THREE ISOTOPES = same 1 proton, different number of NEUTRONS.

      PROTIUM    1H1   0 neutrons   99.985%   ordinary hydrogen
      DEUTERIUM  1H2   1 neutron    0.0156%   heavy hydrogen , D
      TRITIUM    1H3   2 neutrons   1 in 10^18  RADIOACTIVE , T
```

```
  THE H-H BOND IS THE STRONGEST SINGLE BOND BETWEEN TWO ATOMS:
      bond dissociation enthalpy = 435.88 kJ/mol

  THAT ONE NUMBER EXPLAINS:  why H2 gas is chemically LAZY at room
  temperature, and why every reaction of H2 needs HEAT, a CATALYST,
  or an ELECTRIC ARC.
```

```
  HYDROGEN COMBINES WITH ALMOST EVERY ELEMENT -> HYDRIDES, and which
  KIND of hydride you get depends only on WHERE the partner sits:

      LEFT  (s-block)      ->  IONIC / SALINE       NaH, CaH2
      RIGHT (p-block)      ->  COVALENT / MOLECULAR CH4, NH3, H2O, HF
      MIDDLE (d,f-block)   ->  METALLIC / INTERSTITIAL  TiH1.73, LaH2.87
```

**And then the two star compounds of hydrogen: WATER and HYDROGEN PEROXIDE.
Between them they own most of the marks in this chapter.**

## THE KEY BOX — the two things that unlock most of the chapter

```
  +------------------------------------------------------------------------+
  |                                                                        |
  |  1.  THE H-H BOND DISSOCIATION ENTHALPY                                |
  |                                                                        |
  |         H2(g)  ->  2 H(g)        delta H = + 435.88 kJ/mol             |
  |                                                                        |
  |      HIGHEST for any single bond between two atoms.                    |
  |      USE IT AS THE ANSWER TO:                                          |
  |         - Why is H2 unreactive at ordinary temperature?                |
  |         - Why does every reaction of H2 need heat / catalyst / arc?    |
  |         - Why is atomic hydrogen a much stronger reducing agent?       |
  |                                                                        |
  +------------------------------------------------------------------------+
  |                                                                        |
  |  2.  VOLUME STRENGTH OF HYDROGEN PEROXIDE                              |
  |                                                                        |
  |         2 H2O2  ->  2 H2O  +  O2                                       |
  |                                                                        |
  |         "x volume H2O2"  =  1 mL of it gives x mL of O2 at STP         |
  |                                                                        |
  |     +----------------------------------------------------------+       |
  |     |                                                          |       |
  |     |   Strength (g/L)  =  volume strength  x  17 / 5.6        |       |
  |     |                   =  volume strength  x  3.035           |       |
  |     |                                                          |       |
  |     |   Molarity        =  volume strength / 11.2              |       |
  |     |                                                          |       |
  |     |   Normality       =  volume strength / 5.6               |       |
  |     |                                                          |       |
  |     |   Normality       =  2  x  Molarity                      |       |
  |     |                                                          |       |
  |     +----------------------------------------------------------+       |
  |                                                                        |
  |      WHERE 17 and 5.6 COME FROM:                                       |
  |         molar mass of H2O2 = 34 g ; 2 mol H2O2 (68 g) give 1 mol O2    |
  |         1 mol O2 = 22400 mL at STP                                     |
  |         so 22400 mL O2 needs 68 g H2O2                                 |
  |         so 1 mL O2 needs 68/22400 g = 0.003035 g                       |
  |         so x mL O2 per mL solution -> x * 3.035 g per litre.           |
  |         Equivalent mass of H2O2 = 34/2 = 17 ; 17/3.035 = 5.6           |
  |                                                                        |
  +------------------------------------------------------------------------+
```

```

  |          +---------------------+---------------------------+           |
  |          |  TEMPORARY HARDNESS |  PERMANENT HARDNESS       |           |
```

```
              |   Write all seven equations five times BY HAND.
```
