# 1. POSITION OF HYDROGEN — THE TWO LISTS

## 1.1 Resemblance to ALKALI METALS (Group 1)

| # | PROPERTY | HYDROGEN | ALKALI METALS |
|---|---|---|---|
| 1 | Configuration | 1s1 | ns1 |
| 2 | Valency | 1 | 1 |
| 3 | Ion | H+ | M+ (Na+, K+) |
| 4 | Oxidation state | +1 | +1 |
| 5 | Nature | reducing agent | reducing agents |
| 6 | Halides | HCl, HBr, HI | NaCl, KBr, KI |
| 7 | Oxides | H2O | Na2O, K2O |
| 8 | Sulphides | H2S | Na2S |
| 9 | Electrolysis | liberated at the CATHODE | discharged at the CATHODE |

## 1.2 Resemblance to HALOGENS (Group 17)

| # | PROPERTY | HYDROGEN | HALOGENS |
|---|---|---|---|
| 1 | Electrons short of noble gas | 1 (short of He) | 1 |
| 2 | Molecule | diatomic H2 | diatomic X2 |
| 3 | Anion | H− (hydride) | X− (halide) |
| 4 | Oxidation state with metals | −1 (NaH, CaH2) | −1 (NaCl, CaCl2) |
| 5 | Ionisation enthalpy | 1312 kJ/mol — HIGH | high (F 1680, Cl 1255) |
| 6 | Metallic character | non-metal | non-metals |
| 7 | Compounds with non-metals | covalent (CH4, NH3) | covalent (CCl4, NCl3) |
| 8 | Compounds with metals | ionic (NaH) | ionic (NaCl) |

## 1.3 Why the position is ANOMALOUS

| DOES NOT FIT GROUP 1 BECAUSE | DOES NOT FIT GROUP 17 BECAUSE |
|---|---|
| it is a non-metal and a GAS | it has ONE outer electron, not seven |
| IE is 1312, far higher than Li 520 or Na 496 | it has NO lone pairs |
| H+ is a bare proton — cannot exist free in water | it forms H− only with the most electropositive metals |
| it forms mostly COVALENT compounds | it is far less electronegative (2.1) |
| | it forms H+, which halogens never do |

```
  CONCLUSION: hydrogen resembles BOTH but belongs to NEITHER.
  By convention it is placed at the top of Group 1, but only
  as a convenience.
```

# 3. PREPARATION OF DIHYDROGEN — every equation

## 3.1 LABORATORY

```
  +---------------------------------------------------------------------+
  |  METAL + DILUTE ACID  (the standard method)                         |
  |                                                                     |
  |     Zn  +  dil H2SO4   ->   ZnSO4  +  H2                            |
  |     Zn  +  2 HCl       ->   ZnCl2  +  H2                            |
  |     Fe  +  H2SO4       ->   FeSO4  +  H2                            |
  |                                                                     |
  |  NEVER use nitric acid or conc. H2SO4 - they are OXIDISING and      |
  |  give SO2 / NO2 instead of H2.                                      |
  +---------------------------------------------------------------------+
  |  METAL + ALKALI  (amphoteric metals only: Zn, Al, Sn, Pb)           |
  |                                                                     |
  |     Zn   + 2 NaOH             ->  Na2ZnO2  +  H2   (sodium zincate) |
  |     2 Al + 2 NaOH + 2 H2O     -> 2 NaAlO2  + 3 H2  (metaaluminate)  |
  |     Sn   + 2 NaOH             ->  Na2SnO2  +  H2   (stannite)       |
  |                                                                     |
  |  modern form:  Zn + 2NaOH + 2H2O -> Na2[Zn(OH)4] + H2               |
  +---------------------------------------------------------------------+
  |  METAL HYDRIDE + WATER  (for VERY PURE H2)                          |
  |                                                                     |
  |     NaH  +   H2O   ->   NaOH     +   H2                             |
  |     CaH2 + 2 H2O   ->   Ca(OH)2  +  2 H2      ("HYDROLITH")         |
  |                                                                     |
  |  or: electrolysis of warm Ba(OH)2 solution with Ni electrodes       |
  |      (gives 99.9% pure H2)                                          |
  +---------------------------------------------------------------------+
```

## 3.2 COMMERCIAL

| ROUTE | EQUATION | CONDITIONS |
|---|---|---|
| Steam over hot coke (**water gas**) | C + H2O --> CO + H2 | 1270 K |
| **Coal gasification** | C(coal) + H2O --> CO + H2 | 1270 K |
| **Water gas SHIFT** | CO + H2O --> CO2 + H2 | 673 K, Fe2O3 + Cr2O3 |
| Steam reforming of methane | CH4 + H2O --> CO + 3 H2 | 1270 K, Ni |
| Electrolysis of water | 2 H2O --> 2 H2 + O2 | acidified / alkaline water |
| **Chlor-alkali** (by-product) | 2 NaCl + 2 H2O --> 2 NaOH + Cl2 + H2 | electrolysis of brine |
| Petroleum refining | by-product of cracking / reforming | — |

```
  DEFINITIONS TO WRITE WORD FOR WORD:

  WATER GAS / SYNGAS  =  the mixture of CARBON MONOXIDE and DIHYDROGEN
                         obtained by passing STEAM over RED-HOT COKE
                         at 1270 K.
                             C + H2O --(1270 K)--> CO + H2

  COAL GASIFICATION   =  the same process carried out with COAL instead
                         of coke.

  WATER GAS SHIFT     =  the conversion of the CO of water gas into CO2
  REACTION               by passing MORE STEAM at 673 K over an iron
                         chromate catalyst, so that more H2 is produced.
                             CO + H2O --(673 K, Fe2O3/Cr2O3)--> CO2 + H2

  The CO2 is then removed by SCRUBBING with water under pressure
  (or with sodium arsenite), leaving pure H2.
```

```
  ELECTRODE REACTIONS TO KNOW

  ELECTROLYSIS OF WATER
      cathode (-) :  2 H2O + 2 e-  ->  H2  +  2 OH-
      anode   (+) :  2 H2O         ->  O2  +  4 H+  +  4 e-
      volume ratio collected  H2 : O2  =  2 : 1

  ELECTROLYSIS OF BRINE (chlor-alkali)
      cathode (-) :  2 H2O + 2 e-  ->  H2  +  2 OH-
      anode   (+) :  2 Cl-         ->  Cl2 +  2 e-
```

# 6. WHY DIHYDROGEN IS UNREACTIVE — the one-line answer

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |     H2(g)  ->  2 H(g)      delta H  =  + 435.88 kJ/mol              |
  |                                                                     |
  |  The H-H bond dissociation enthalpy is the HIGHEST for any single   |
  |  bond between two atoms. At ordinary temperature there is not       |
  |  enough energy to break it, so H2 is chemically UNREACTIVE.         |
  |                                                                     |
  |  Every reaction of H2 therefore needs HEAT, a CATALYST, or an       |
  |  ELECTRIC ARC.                                                      |
  |                                                                     |
  |  ATOMIC / NASCENT hydrogen is far more reactive because the         |
  |  bond has already been broken.                                      |
  |                                                                     |
  +---------------------------------------------------------------------+
```

# 7. ORTHO AND PARA HYDROGEN

| POINT | ORTHO | PARA |
|---|---|---|
| Nuclear spins | **parallel** (same direction) | **anti-parallel** (opposite) |
| Energy | higher | lower — more stable |
| Amount at room temperature (298 K) | **75 %** | **25 %** |
| Amount at 0 K | 0 % | **100 %** |
| Maximum possible amount | 75 % (never more) | 100 % (at 0 K) |
| Melting point | 13.95 K | 13.83 K |
| Boiling point | 20.39 K | 20.26 K |
| Thermal conductivity | lower | **higher** (about 50 % more) |
| Vapour pressure | lower | higher |
| Chemical properties | **identical to para** | **identical to ortho** |

```
  THREE SENTENCES THAT EARN THE MARKS:

    1. Ordinary hydrogen at room temperature is 75% ORTHO and
       25% PARA (ratio 3 : 1).
    2. Lowering the temperature INCREASES the para form; at 0 K
       hydrogen is 100% PARA.
    3. The ortho form can NEVER exceed 75%, no matter how high
       the temperature.

  Pure PARA hydrogen is obtained by cooling H2 to about 20 K in
  the presence of ACTIVATED CHARCOAL as catalyst.
  Pure ORTHO hydrogen CANNOT be obtained.

  IT IS THE NUCLEAR (PROTON) SPIN, NOT THE ELECTRON SPIN.
```

# 9. HYDRIDES — the full classification table

| FEATURE | IONIC (SALINE) | COVALENT (MOLECULAR) | METALLIC (INTERSTITIAL) |
|---|---|---|---|
| Formed by | s-block metals (Group 1 all; Group 2 Ca, Sr, Ba) | p-block Groups 13–17, **plus Be and Mg** | d-block and f-block metals |
| Oxidation state of H | **−1** | about +1 (shared) | not defined |
| Bonding | ionic (M+ H−) | covalent, discrete molecules | metallic; H in the interstices |
| Physical state | crystalline white solids | gases or volatile liquids | metal-like solids, hard, brittle |
| Stoichiometry | definite | definite | **NON-STOICHIOMETRIC** |
| Melting point | high | low | high |
| Electrical conduction | only when MOLTEN | non-conductors | **conduct as solids** |
| Density vs parent metal | **greater** | — | **less** (lattice expands) |
| Reaction with water | violent → H2 + alkali | mostly stable; some hydrolyse | generally unreactive |
| Nature | strong reducing agents, basic | acidic (HCl) to basic (NH3) | hydrogen STORES |
| Examples | LiH, NaH, KH, RbH, CsH, CaH2, SrH2, BaH2 | B2H6, CH4, SiH4, NH3, PH3, H2O, H2S, HF, HCl, BeH2, MgH2 | TiH1.73, ZrH1.30, VH0.56, NiH0.6, PdH0.6, LaH2.87, CeH2.7 |

## 9.1 Sub-types of COVALENT hydrides

| SUB-TYPE | GROUP | WHY | EXAMPLES |
|---|---|---|---|
| **ELECTRON DEFICIENT** | 13 | fewer electrons than needed → form 3-centre-2-electron BRIDGES; act as LEWIS ACIDS | B2H6, AlH3, Al2Cl6-type bridging |
| **ELECTRON PRECISE** | 14 | exactly enough electrons; tetrahedral, no lone pairs; neutral | CH4, SiH4, GeH4, SnH4 |
| **ELECTRON RICH** | 15, 16, 17 | extra electrons appear as LONE PAIRS; act as LEWIS BASES | NH3, PH3 (1 lp); H2O, H2S (2 lp); HF, HCl (3 lp) |

## 9.2 KEY HYDRIDE REACTIONS

```
  NaH   +   H2O    ->   NaOH      +   H2
  CaH2  +  2 H2O   ->   Ca(OH)2   +  2 H2       "HYDROLITH"

  2 NaH  --(electrolysis of the MELT)-->  2 Na  +  H2 AT THE ANODE
       *** hydrogen at the ANODE proves the H- ion exists ***

  4 LiH  +  AlCl3   ->   LiAlH4   +  3 LiCl     lithium aluminium hydride
  2 LiH  +  B2H6    ->  2 LiBH4                 lithium borohydride
       *** LiAlH4 and NaBH4 are COMPLEX HYDRIDES - the two great
           reducing agents of organic chemistry ***
```

# 10. WATER — STRUCTURE AND PHYSICAL DATA

| QUANTITY | GAS PHASE (single molecule) | ICE |
|---|---|---|
| Hybridisation of O | sp3 | sp3 |
| Shape | BENT / angular / V-shaped | tetrahedral network |
| H–O–H bond angle | **104.5°** | about 109.5° |
| O–H bond length | **95.7 pm** | 101 pm (covalent) |
| Hydrogen bond length | — | about **175 pm** |
| Lone pairs on O | 2 | 2 |
| Dipole moment | 1.84 D | — |
| Coordination | — | each O surrounded **TETRAHEDRALLY by 4 others** |

```
  WHY 104.5 AND NOT 109.5?
      lone pair - lone pair repulsion  >  lone pair - bond pair
                                       >  bond pair - bond pair
      The 2 lone pairs squeeze the O-H bonds together.
```

## 10.1 PHYSICAL PROPERTIES OF WATER

| PROPERTY | VALUE | WHY UNUSUAL |
|---|---|---|
| Melting point | 273.0 K | H2S melts at 187 K |
| Boiling point | 373.0 K | H2S boils at 213 K |
| Density of ice (273 K) | **0.917 g/cm3** | solid is LIGHTER than liquid |
| Density of water (273 K) | 0.9998 g/cm3 | |
| **Maximum density** | 1.000 g/cm3 at **277 K (4 °C)** | not at the freezing point |
| Specific heat capacity | 4.18 J/g/K | among the highest known |
| Enthalpy of fusion | 6.01 kJ/mol | high |
| Enthalpy of vaporisation | 40.7 kJ/mol | very high |
| Surface tension (293 K) | 72.75 dyne/cm | very high |
| Dielectric constant | 78.4 | very high — dissolves ionic salts |
| Dipole moment | 1.84 D | polar |

```
  EVERY ONE OF THESE ANOMALIES HAS THE SAME CAUSE:
                    H Y D R O G E N   B O N D I N G
  (each H2O has 2 H atoms to donate and 2 lone pairs to accept,
   so it makes FOUR hydrogen bonds)
```

## 10.2 WHY ICE FLOATS — the four-step answer

```
  1.  In ice, each O is tetrahedrally H-bonded to FOUR others.
  2.  This gives an OPEN HEXAGONAL CAGE with LARGE HOLES.
  3.  Same mass occupies MORE volume  ->  density FALLS to 0.917.
  4.  On melting, about 15% of H-bonds break, the cage collapses,
      molecules fill the holes -> liquid is DENSER.

  SIGNIFICANCE: ice floats and insulates the lake, so water below
  stays at 277 K and aquatic life survives the winter. If ice sank,
  lakes would freeze solid from the bottom and everything would die.
```

# 12. HARD WATER — causes, effects and ALL SIX cures

## 12.1 The two kinds

| | TEMPORARY HARDNESS | PERMANENT HARDNESS |
|---|---|---|
| Also called | carbonate hardness | non-carbonate hardness |
| Caused by | **BICARBONATES**: Ca(HCO3)2, Mg(HCO3)2 | **CHLORIDES and SULPHATES**: CaCl2, MgCl2, CaSO4, MgSO4 |
| Removed by boiling? | **YES** | **NO** |
| Cures | boiling, Clark's method | washing soda, calgon, permutit, resins |

```
  WHY SOAP FAILS IN HARD WATER (soap = sodium stearate C17H35COONa):

    2 C17H35COONa + CaCl2 -> (C17H35COO)2Ca (SCUM, insoluble) + 2 NaCl
    2 C17H35COONa + MgSO4 -> (C17H35COO)2Mg (SCUM, insoluble) + Na2SO4
```

## 12.2 Disadvantages

```
  DOMESTIC   : wastes soap , scum on clothes and skin , pulses do not
               cook properly , unpleasant taste , more fuel used

  BOILERS    : SCALE / FUR of CaCO3, CaSO4, Mg(OH)2 forms inside;
               scale is a bad conductor -> WASTE OF FUEL;
               blocks pipes and valves;
               uneven heating can crack the plate -> BOILER EXPLOSION

  INDUSTRY   : ruins dyeing, tanning, paper, sugar and textile
               processes; laundry output looks grey and dull
```

## 12.3 ALL SIX REMOVAL METHODS WITH EQUATIONS

| # | METHOD | REAGENT | REMOVES | KEY EQUATION(S) |
|---|---|---|---|---|
| 1 | **Boiling** | heat only | temporary | Ca(HCO3)2 → CaCO3↓ + H2O + CO2 ; Mg(HCO3)2 → Mg(OH)2↓ + 2CO2 |

| 4 | **Calgon** | Na2[Na4(PO3)6] | both | 2CaSO4 + Na2[Na4(PO3)6] → Na2[Ca2(PO3)6] + 2Na2SO4 |

  NAMES TO REMEMBER IN THE ELECTROLYTIC ROUTE:

# 14. HYDROGEN PEROXIDE — STRUCTURE

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   SHAPE:  NON-PLANAR ,  described as an  OPEN BOOK                  |
  |           The two O-H bonds lie in two different planes,            |
  |           like the two pages of a half-open book,                   |
  |           with the O-O bond as the SPINE.                           |
  |                                                                     |
  |              H                                                      |
  |               \                                                     |
  |                \                          <-- page 1                |
  |                 O -------------- O                                  |
  |                 |     SPINE      |\                                 |
  |                 |   (O-O bond)   | \                                |
  |                 |                |  H     <-- page 2                |
  |                                                                     |
  |   Oxidation state of O in H2O2  =  -1  (the MIDDLE state),          |
  |   which is exactly why H2O2 can act BOTH ways:                      |
  |                                                                     |
  |        H2O (-2)  <-- REDUCED --  H2O2 (-1)  -- OXIDISED -->  O2 (0) |
  |        so H2O2 is the           so H2O2 is the                      |
  |        OXIDISING agent          REDUCING agent                      |
  |                                                                     |
  +---------------------------------------------------------------------+
```

| PARAMETER | GAS PHASE | SOLID PHASE (110 K) |
|---|---|---|
| O–O bond length | **147.5 pm** | 145.8 pm |
| O–H bond length | 95.0 pm | 98.8 pm |
| O–O–H bond angle | **94.8°** | 101.9° |
| **DIHEDRAL angle** | **111.5°** | **90.2°** |

```
  WHY THE SOLID VALUES DIFFER: in the solid the molecules are
  HYDROGEN BONDED to each other, which twists the O-H groups round.

  MEMORY: "GAS = book open WIDER (111.5) ; SOLID = H-bonds
           squeeze it nearly shut (90.2)."
```

# 16. HYDROGEN PEROXIDE — THE FOUR REACTION BOXES

```
  +----------------------+------------------------------+--------------------------+
  |                      |  ACIDIC MEDIUM               |  BASIC MEDIUM            |
  +----------------------+------------------------------+--------------------------+
  |  OXIDISING AGENT     |  H2O2 + 2H+ + 2e- -> 2 H2O   |  H2O2 + 2e- -> 2 OH-     |
  |  (H2O2 is reduced)   |                              |                          |
  +----------------------+------------------------------+--------------------------+
  |  REDUCING AGENT      |  H2O2 -> O2 + 2H+ + 2e-      |  H2O2 + 2OH-             |
  |  (H2O2 is oxidised)  |                              |   -> O2 + 2H2O + 2e-     |
  +----------------------+------------------------------+--------------------------+

  RULE OF THUMB: IF O2 GAS APPEARS AMONG THE PRODUCTS, H2O2 WAS
  ACTING AS THE REDUCING AGENT.
```

## 16.1 OXIDISING AGENT in ACIDIC medium

```
  2 Fe2+  +  2 H+  +  H2O2   ->   2 Fe3+  +  2 H2O
  2 I-    +  2 H+  +  H2O2   ->   I2      +  2 H2O
  2 KI    +  H2SO4 +  H2O2   ->   K2SO4   +  I2  +  2 H2O
  PbS     +  4 H2O2          ->   PbSO4   +  4 H2O    BLACK -> WHITE
  Na2SO3  +  H2O2            ->   Na2SO4  +  H2O
  H2S     +  H2O2            ->   S       +  2 H2O
```

## 16.2 OXIDISING AGENT in BASIC medium

```
  2 Fe2+  +  H2O2   ->   2 Fe3+  +  2 OH-
  Mn2+    +  H2O2   ->   Mn4+    +  2 OH-        (MnO2 precipitates)
  CrCl3 + 3 H2O2 + 10 KOH -> 2 K2CrO4 + 3 KCl + 8 H2O

  THE CHROMIC PEROXIDE TEST (blue colour, extracted into ether):
      Cr2O7 2-  +  4 H2O2  +  2 H+   ->   2 CrO5  +  5 H2O
```

## 16.3 REDUCING AGENT in ACIDIC medium

```
  2 KMnO4 + 3 H2SO4 + 5 H2O2 -> K2SO4 + 2 MnSO4 + 8 H2O + 5 O2
  ionic :  2 MnO4- + 6 H+ + 5 H2O2 -> 2 Mn2+ + 8 H2O + 5 O2
           *** the TITRATION used to find the strength of H2O2 ***

  HOCl   +  H2O2   ->   H3O+   +  Cl-  +  O2
  Cl2    +  H2O2   ->   2 HCl  +  O2
  Ag2O   +  H2O2   ->   2 Ag   +  H2O  +  O2
```

## 16.4 REDUCING AGENT in BASIC medium

```
  I2  +  H2O2  +  2 OH-   ->   2 I-   +  2 H2O  +  O2
  2 MnO4-  +  3 H2O2      ->   2 MnO2 +  3 O2  +  2 H2O  +  2 OH-
  2 K3[Fe(CN)6] + 2 KOH + H2O2 -> 2 K4[Fe(CN)6] + 2 H2O + O2
```

## 16.5 AS AN ACID, AND BLEACHING

```
  H2O2  +  2 NaOH    ->   Na2O2  +  2 H2O
  H2O2  +  Ba(OH)2   ->   BaO2   +  2 H2O

  BLEACHING:   H2O2  ->  H2O  +  [O]      (nascent oxygen)
  The nascent oxygen OXIDISES the colouring matter to a colourless
  substance, so the bleaching is PERMANENT.
```

# 17. *** THE ONLY FORMULA IN THE CHAPTER *** — VOLUME STRENGTH

```
  +---------------------------------------------------------------------+
  |                                                                     |
  |   DEFINITION                                                        |
  |     "x VOLUME H2O2"  means  1 mL of the solution, on complete       |
  |     decomposition, liberates  x  mL of OXYGEN at STP.               |
  |                                                                     |
  |             2 H2O2   ->   2 H2O   +   O2                            |
  |                                                                     |
  +---------------------------------------------------------------------+
  |                                                                     |
  |     STRENGTH (g/L)   =   VOLUME STRENGTH   x   17 / 5.6             |
  |                                                                     |
  |     STRENGTH (g/L)   =   VOLUME STRENGTH   x   3.035                |
  |                                                                     |
  |     NORMALITY        =   VOLUME STRENGTH   /   5.6                  |
  |                                                                     |
  |     MOLARITY         =   VOLUME STRENGTH   /   11.2                 |
  |                                                                     |
  |     NORMALITY        =   2   x   MOLARITY                           |
  |                                                                     |
  |     % strength (w/V) =   STRENGTH (g/L)  /  10                      |
  |                                                                     |
  |     VOLUME STRENGTH  =   NORMALITY  x  5.6  =  MOLARITY  x  11.2    |
  |                                                                     |
  +---------------------------------------------------------------------+

  WHERE THE NUMBERS COME FROM
      Molar mass of H2O2 = 34 g ; equivalent mass = 34/2 = 17 g
      2 mol H2O2 (68 g) give 1 mol O2 = 22400 mL at STP
      1 mL of O2 therefore needs 68/22400 = 0.003035 g of H2O2
      1000 x that per litre  ->  3.035 = 17/5.6
      1 mol H2O2 gives 1/2 mol O2 = 11.2 L  ->  molarity = V/11.2
      17 / 3.035 = 5.6                      ->  normality = V/5.6
```
