## THE 60-SECOND VERSION

The chapter answers one question: **why do elements repeat their behaviour?**

```
  STEP 1   Dobereiner   -  found groups of THREE with a weight pattern
              |             PROBLEM: only 3 or 4 triads existed
              v
  STEP 2   Newlands     -  every 8th element repeats (law of octaves)
              |             PROBLEM: broke down after calcium
              v
  STEP 3   Lothar Meyer -  atomic volume vs atomic weight curve;
              |             similar elements sit at similar points
              v
  STEP 4   MENDELEEV    -  properties are a periodic function of
              |             ATOMIC WEIGHT. Left gaps, predicted elements.
              |             PROBLEM: H has no fixed place, isotopes have
              |                      no place, Ar-K and Te-I are reversed
              v
  STEP 5   MOSELEY      -  X-ray study proved ATOMIC NUMBER, not weight,
              |             is the true fundamental property
              v
  STEP 6   MODERN LAW   -  "Properties of elements are a periodic function
                            of their ATOMIC NUMBERS."
                            -> the LONG FORM table, 7 periods, 18 groups
                            -> s, p, d, f blocks
                            -> and then ALL the trends follow from ONE idea:
```

```
  +------------------------------------------------------------------+
  |   THE ONE IDEA THAT EXPLAINS EVERY TREND IN THIS CHAPTER         |
  |                                                                  |
  |        Z(eff)   =   Z   -   S                                    |
  |                                                                  |
  |   Z(eff) = effective nuclear charge = the pull actually felt     |
  |            by the outermost electron                             |
  |   Z      = nuclear charge (number of protons)                    |
  |   S      = screening / shielding by the inner electrons          |
  |                                                                  |
  |   ACROSS a period : Z goes up, S stays almost the SAME           |
  |                     ->  Z(eff) INCREASES  ->  atom is squeezed   |
  |                                                                  |
  |   DOWN a group    : a WHOLE NEW SHELL is added, S shoots up      |
  |                     ->  Z(eff) barely changes  ->  atom is bigger|
  +------------------------------------------------------------------+
```

**Every "why" question in this chapter is answered with nuclear charge versus shielding.**

## THE KEY BOX — ALL THE TRENDS IN ONE ARROW DIAGRAM

```
  +--------------------------------------------------------------------------+
  |                                                                          |
  |     IONISATION ENTHALPY , ELECTRONEGATIVITY , NON-METALLIC CHARACTER ,    |
  |     ELECTRON GAIN ENTHALPY (more negative) , ACIDIC NATURE OF OXIDES ,    |
  |     EFFECTIVE NUCLEAR CHARGE   ------------  I N C R E A S E  ---------> |
  |                                                                          |
  |     A T O M I C   R A D I U S   <----------  D E C R E A S E S           |
  |                                                                          |
  |   +------------------------------------------------------------------+   |
  |   |                                                                  |   |
  | | |   Li   Be   B    C    N    O    F    Ne                          |   |
  | | |                                                                  |   |
  | | |   Na   Mg   Al   Si   P    S    Cl   Ar                          | | |
  | | |                                                                  | | |
  | | |   K    Ca   Ga   Ge   As   Se   Br   Kr                          | | |
  | v |                                                                  | v |
  |   |   Rb   Sr   In   Sn   Sb   Te   I    Xe                          |   |
  |   |                                                                  |   |
  |   |   Cs   Ba   Tl   Pb   Bi   Po   At   Rn                          |   |
  |   +------------------------------------------------------------------+   |
  |                                                                          |
  |   DOWN A GROUP (left arrow)        DOWN A GROUP (right arrow)            |
  |   ATOMIC RADIUS      INCREASES     IONISATION ENTHALPY    DECREASES      |
  |   METALLIC CHARACTER INCREASES     ELECTRONEGATIVITY      DECREASES      |
  |   BASIC NATURE OF                  ELECTRON GAIN ENTHALPY becomes        |
  |   OXIDES             INCREASES        LESS NEGATIVE                      |
  |                                    NON-METALLIC CHARACTER DECREASES      |
  |                                                                          |
  +--------------------------------------------------------------------------+
```

```
  READ IT AS ONE SENTENCE AND YOU CAN NEVER FORGET IT:

     "GOING RIGHT the atom gets SMALLER and MEANER
      (holds its own electrons harder, steals other people's harder).

      GOING DOWN the atom gets FATTER and MORE GENEROUS
      (gives its electrons away easily)."

  Only ATOMIC RADIUS behaves 'backwards'. Everything else follows radius
  in the opposite direction. Learn RADIUS, then flip it for the rest.
```

```
     *** THE BIG ONE - PERIODIC TRENDS ***
     - Z(eff) = Z - S  and shielding
     - atomic radius, ionic radius (cation < atom < anion, isoelectronic rule)
     - ionisation enthalpy + the Be/B and N/O exceptions WITH REASONS
     - electron gain enthalpy + the O/S and F/Cl exceptions WITH REASONS
     - electronegativity (Pauling, F = 4.0 highest, Cs = 0.7 lowest)
     -> secures the 8-mark long answer

  DAY 2  (evening)
     - Metallic vs non-metallic character
     - Nature of oxides across period 3: Na2O basic -> Al2O3 amphoteric
       -> Cl2O7 strongly acidic
     - Anomalous 2nd period + diagonal relationship
     - Then read 05-question-patterns.md straight through, twice.
     -> secures the remaining 4-mark answers
```

```
  ONE LAST THING BEFORE YOU CLOSE THIS FILE

  In this chapter the examiner is NOT testing whether you are clever.
  He is testing whether you wrote the REASON after the TREND.

     "Atomic radius decreases across a period."          ->  half marks
     "Atomic radius decreases across a period BECAUSE
      the nuclear charge increases while the electrons
      are added to the same shell, so the effective
      nuclear charge increases and pulls the electron
      cloud inwards."                                     ->  full marks

  Same length of writing. Double the marks. That is the whole game.
```
