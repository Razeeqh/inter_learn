# Classification and Periodicity — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The elements change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — STATE A PERIODIC LAW                                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "State the modern periodic law" / "State Mendeleev's
            periodic law" / "State the law of octaves".
  METHOD    Write the sentence EXACTLY. One line only.

            MENDELEEV : "The physical and chemical properties of the
                         elements are a periodic function of their
                         ATOMIC WEIGHTS."

            MODERN    : "The physical and chemical properties of the
                         elements are a periodic function of their
                         ATOMIC NUMBERS."

            OCTAVES   : "When elements are arranged in increasing order
                         of atomic weight, the properties of every
                         EIGHTH element repeat those of the first."
  TRAP      The ONLY difference between Mendeleev's and the modern law
            is WEIGHT vs NUMBER. Writing the wrong one loses the mark.
```

```
  PATTERN 2 — EARLY ATTEMPTS AT CLASSIFICATION                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is a Dobereiner triad?" / "law of octaves" /
            "Lothar Meyer curve".
  METHOD    DOBEREINER  wt(middle) = [ wt(first) + wt(third) ] / 2
                        example Li 6.9 , Na 23.0 , K 39.1
                        limitation: only 3 or 4 triads exist

            NEWLANDS    every 8th element repeats
                        limitation: valid only up to CALCIUM,
                        no place for noble gases

            LOTHAR MEYER  plot ATOMIC VOLUME against ATOMIC WEIGHT
                        ALKALI METALS occupy the PEAKS
                        conclusion: properties are a periodic
                        function of atomic weight
  TRAP      Always give the EXAMPLE and the LIMITATION. Each is worth
            about half of the two marks.
```

```
  PATTERN 3 — MERITS OF MENDELEEV'S TABLE                         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are the merits / advantages / achievements of
            Mendeleev's periodic table?"
  METHOD    Write FOUR headings, one line of explanation each:
            1. Systematic study of 63 elements
            2. Correction of doubtful atomic weights (Be 13.5 -> 9)
            3. PREDICTION of undiscovered elements
                  eka-boron     -> scandium
                  eka-aluminium -> gallium
                  eka-silicon   -> germanium
            4. Noble gases fitted in later as a ZERO GROUP without
               disturbing the table
  TRAP      Merit 3 is the one the examiner wants most. Name all THREE
            eka-elements and their modern names.
```

```
  PATTERN 4 — DEMERITS OF MENDELEEV'S TABLE                       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Defects / demerits / limitations of Mendeleev's table."
  METHOD    Five headings with a one-line reason each:
            1. No fixed position for HYDROGEN (resembles IA and VIIA)
            2. No place for ISOTOPES (different weights, same element)
            3. ANOMALOUS PAIRS - heavier placed before lighter:
                  Ar before K , Co before Ni , Te before I , Th before Pa
            4. Similar elements separated (Cu, Hg) and dissimilar
               ones together (alkali metals with coinage metals)
            5. No proper place for LANTHANIDES and ACTINIDES
            (6. The cause of periodicity was not explained.)
  TRAP      You must NAME the anomalous pairs with their weights.
            "Some elements were in the wrong order" gets no mark.
```

```
  PATTERN 5 — MOSELEY AND THE MODERN PERIODIC LAW                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is Moseley's contribution?" / "Why was atomic weight
            replaced by atomic number?"
  METHOD    1. Moseley studied the characteristic X-ray spectra of
               the elements.
            2. He found     sqrt ( nu )  =  a ( Z - b )
            3. The frequency depended on ATOMIC NUMBER, not weight.
            4. Hence Z is the fundamental property -> MODERN LAW.
            5. This automatically fixed the isotope problem and the
               anomalous pairs.
  TRAP      Write the equation. It is half the answer.
```

```
  PATTERN 6 — WHY DOES A PERIOD HAVE THAT MANY ELEMENTS?          2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why does period 2 contain 8 elements?" / "Which is the
            longest period and why?"
  METHOD    Number of elements = number of electrons that fill the
            orbitals of that period.

               Period 1 : 1s                 =  2
               Period 2 : 2s 2p              =  2 + 6      =  8
               Period 3 : 3s 3p              =  2 + 6      =  8
               Period 4 : 4s 3d 4p           =  2 + 10 + 6 = 18
               Period 5 : 5s 4d 5p           =  2 + 10 + 6 = 18
               Period 6 : 6s 4f 5d 6p        = 2+14+10+6   = 32
               Period 7 : 7s 5f 6d 7p        = 2+14+10+6   = 32
  TRAP      3d fills in PERIOD 4, and 4f fills in PERIOD 6.
            The (n + l) rule decides the order, not the shell number.
```

```
  PATTERN 7 — FIND THE PERIOD, GROUP AND BLOCK             *** 2 or 4 ***
  ------------------------------------------------------------------------
  TRIGGER   A configuration or an atomic number is given and you are
            asked "to which period, group and block does it belong?"
  METHOD    1. If Z is given, WRITE the configuration first, using
               1s 2s 2p 3s 3p 4s 3d 4p 5s 4d 5p 6s 4f 5d 6p ...
            2. PERIOD = the highest value of n.
            3. BLOCK  = the subshell that got the LAST electron.
            4. GROUP  :
                  s-block  ->  number of ns electrons
                  p-block  ->  10 + (ns + np electrons)
                               (short cut: 12 + number of p electrons)
                  d-block  ->  (n-1)d electrons + ns electrons
                  f-block  ->  always group 3
            5. Name the element if you can - it earns goodwill.
  TRAP      The BLOCK is decided by where the LAST electron ENTERED,
            not by the outermost shell.
            [Ar] 3d10 4s1 is copper - a d-BLOCK element in GROUP 11,
            NOT an s-block group 1 element.
```

```
  PATTERN 8 — REVERSE: POSITION GIVEN, FIND THE ELEMENT           2 marks
  ------------------------------------------------------------------------
  TRIGGER   "An element belongs to period 3 and group 16. Write its
            electronic configuration and identify it."
  METHOD    1. Period gives n. Group gives the number of outer electrons.
                  group 1 or 2   -> ns1 or ns2
                  group 13 to 18 -> ns2 np(group - 10 - 2)
                  group 3 to 12  -> (n-1)d(group - 2) ns2
            2. Fill the inner shells with the nearest noble gas core.
            3. Add up the electrons to get Z and name the element.

            EXAMPLE : period 3, group 16
                  n = 3 ; p electrons = 16 - 12 = 4
                  configuration = [Ne] 3s2 3p4 ,  Z = 16  ->  SULPHUR
  TRAP      Group 13 has np1, not np3. Subtract 12, not 10, to get the
            number of p electrons.
```

```
  PATTERN 9 — THE FOUR BLOCKS AND THEIR CHARACTERISTICS      4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Classify the elements into s, p, d and f blocks" /
            "Write the general configuration of the d-block".
  METHOD    For each block give (i) the groups, (ii) the general
            configuration, (iii) two or three properties.
                s : gp 1-2   , ns1-2      , soft reactive metals,
                               ionic compounds, basic oxides
                p : gp 13-18 , ns2 np1-6  , metals + metalloids +
                               non-metals, noble gases at the end
                d : gp 3-12  , (n-1)d1-10 ns1-2 , transition metals,
                               variable oxidation states, coloured
                               ions, complexes, catalysts
                f : group 3  , (n-2)f1-14 (n-1)d0-1 ns2 ,
                               inner transition, lanthanoids 58-71,
                               actinoids 90-103, actinoids radioactive
            DRAW the block diagram. It carries marks.
  TRAP      Helium is 1s2 but sits in GROUP 18, not group 2.
```

```
  PATTERN 10 — IUPAC NAME AND SYMBOL FOR Z ABOVE 100              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the IUPAC name and symbol of the element with
            atomic number 107 / 112 / 120."
  METHOD    ROOTS:  0 nil(n) 1 un(u) 2 bi(b) 3 tri(t) 4 quad(q)
                    5 pent(p) 6 hex(h) 7 sept(s) 8 oct(o) 9 enn(e)
            1. Split Z into digits.
            2. Replace each digit by its root, in order.
            3. Add "-ium".
            4. Symbol = first letter of each root, three letters.
            Spelling: drop the "n" of "enn" before "nil";
                      drop the "i" of "bi" and "tri" before "ium".
            EXAMPLE : 107 -> un + nil + sept + ium = Unnilseptium, Uns
  TRAP      The symbol has THREE letters and only the FIRST is capital.
            "Uns" is correct ; "UNS" and "uns" are both wrong.
```

```
  PATTERN 11 — SCREENING EFFECT / EFFECTIVE NUCLEAR CHARGE        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the screening effect?" / "Define effective
            nuclear charge."
  METHOD    SCREENING (SHIELDING) EFFECT - the decrease in the force of
            attraction between the nucleus and the outermost electron
            caused by the repulsion of the inner electrons.

                    Z(eff)  =  Z  -  S

            Screening power within a shell :  s > p > d > f
  NOTE      *** THIS IS THE REASON BEHIND EVERY TREND IN THE CHAPTER.
            Use the words "effective nuclear charge" in every trend
            answer you write. ***
```

```
  PATTERN 12 — DEFINE THE THREE ATOMIC RADII                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define covalent radius / van der Waals radius / metallic
            radius."
  METHOD    COVALENT  - half the distance between the nuclei of two
                        IDENTICAL atoms joined by a SINGLE COVALENT bond
            VAN DER WAALS - half the distance between the nuclei of two
                        adjacent atoms of two NEIGHBOURING MOLECULES
                        in the solid state
            METALLIC  - half the distance between the nuclei of two
                        adjacent atoms in a METALLIC CRYSTAL

            SIZE ORDER :  van der Waals > metallic > covalent
  TRAP      The words "one half of" and "two identical atoms" both
            carry marks. Do not paraphrase loosely.
```

```
  PATTERN 13 — ARRANGE IN ORDER OF ATOMIC SIZE (WITH REASON) 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange Na, Mg, Al, Si in increasing order of atomic
            radius" / "Why does the atomic radius decrease across a
            period?"
  METHOD    1. Check whether the elements are in the SAME PERIOD or
               the SAME GROUP.
            2. SAME PERIOD -> size DECREASES as you go right.
               REASON: Z increases, electrons enter the same shell,
               shielding is nearly constant, so Z(eff) increases and
               the cloud is pulled in.
            3. SAME GROUP -> size INCREASES as you go down.
               REASON: a new shell is added; the rise in shell number
               and shielding outweighs the rise in nuclear charge.
            4. Quote data if you remember it:
               Li 152 > Be 111 > B 88 > C 77 > N 74 > O 66 > F 64 pm
  TRAP      Noble gases look bigger than the halogen before them only
            because their VAN DER WAALS radius is quoted. It is not a
            break in the trend.
```

```
  PATTERN 14 — CATION VERSUS ANION SIZE                           2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is Na+ smaller than Na?" / "Why is Cl- larger
            than Cl?"
  METHOD    CATION SMALLER because
                (a) usually one whole shell is lost
                (b) the same nuclear charge holds FEWER electrons,
                    so Z(eff) per electron rises and the cloud shrinks
                Na 186 pm -> Na+ 95 pm
            ANION LARGER because
                (a) the same nuclear charge must hold MORE electrons
                (b) extra electron-electron REPULSION expands the cloud
                Cl 99 pm -> Cl- 181 pm
            For the same element :  Fe > Fe2+ > Fe3+
  TRAP      Give BOTH reasons. One reason = half marks.
```

```
  PATTERN 15 — ISOELECTRONIC SPECIES                              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are isoelectronic species?" / "Arrange N3-, O2-, F-,
            Na+, Mg2+, Al3+ in order of size."
  METHOD    1. Definition: species with the SAME number of electrons
               but DIFFERENT nuclear charges.
            2. Count the electrons to confirm they really are
               isoelectronic (all 10 here).
            3. RULE: same electrons -> bigger Z means smaller ion.
            4. Write them in order of INCREASING Z and the size order
               comes out automatically in DECREASING order.

               N3- > O2- > F- > Ne > Na+ > Mg2+ > Al3+
               171   140   136       95    65     50   pm
  TRAP      Do not sort by charge alone; sort by NUCLEAR CHARGE Z.
```

```
  PATTERN 16 — DEFINE IONISATION ENTHALPY / WHY IE2 > IE1         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define ionisation enthalpy" / "Why is the second
            ionisation enthalpy greater than the first?"
  METHOD    DEFINITION (every underlined word carries a mark):
            "the MINIMUM energy required to remove the MOST LOOSELY
             BOUND electron from an ISOLATED NEUTRAL GASEOUS atom in
             its GROUND STATE to form a gaseous cation."
                  M(g) + IE1 -> M+(g) + e-      unit kJ/mol, always +ve

            WHY IE2 > IE1 : after the first electron leaves, the ion
            is smaller and positively charged, the same nuclear charge
            acts on fewer electrons, so Z(eff) per electron is larger
            and the next electron is held more tightly.
  TRAP      Ionisation enthalpy is ALWAYS POSITIVE. A negative sign
            anywhere in this answer is wrong.
```

```
  PATTERN 17 — ORDER OF IONISATION ENTHALPY + THE EXCEPTIONS      4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Arrange in order of IE" / "Why is IE of Be greater than
            B?" / "Why is IE of N greater than O?"
  METHOD    General trend: INCREASES across a period (Z(eff) up, size
            down), DECREASES down a group (size and shielding up).

            EXCEPTION 1   Be (899) > B (801)   [also Mg > Al]
              (a) Be loses an electron from a FULLY FILLED, stable 2s2.
              (b) B loses a 2p electron, which is higher in energy,
                  LESS PENETRATING and shielded by the 2s2 pair.

            EXCEPTION 2   N (1402) > O (1314)  [also P > S]
              (a) N has an exactly HALF-FILLED, symmetrical 2p3, which
                  is extra stable.
              (b) In O the 4th 2p electron must PAIR UP; the resulting
                  electron-electron repulsion makes it easy to remove.
            DRAW the 2p box diagrams for N and O.
  TRAP      Giving only "half-filled is stable" and not explaining why
            OXYGEN is low loses half the marks. Both halves are needed.
```

```
  PATTERN 18 — SUCCESSIVE IE VALUES -> FIND THE GROUP          objective
  ------------------------------------------------------------------------
  TRIGGER   A list of IE1, IE2, IE3, IE4 values with one huge jump.
  METHOD    Count how many ionisations occur BEFORE the huge jump.
            That number = the number of VALENCE electrons = the group.

            Example : 577 , 1820 , 2750 , 11600
                      jump after the THIRD -> 3 valence electrons
                      -> group 13 -> aluminium
  SHORTCUT  Jump after 1 -> group 1 ; after 2 -> group 2 ;
            after 3 -> group 13 ; after 4 -> group 14.
```

```
  PATTERN 19 — DEFINE ELECTRON GAIN ENTHALPY / ITS SIGN           2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define electron gain enthalpy" / "Why is the second
            electron gain enthalpy of oxygen positive?"
  METHOD    DEFINITION: "the enthalpy change when an electron is added
            to an ISOLATED NEUTRAL GASEOUS atom in its GROUND STATE to
            form a gaseous anion."
                  X(g) + e- -> X-(g)  ;  delta(eg)H , unit kJ/mol

            SIGN: usually NEGATIVE (energy released).
                  POSITIVE for noble gases (filled ns2 np6) and for
                  group 2 (filled ns2).
                  The SECOND value is ALWAYS POSITIVE, because the
                  electron is forced into an already negative ion
                  against repulsion.
                  O(g)+e- -> O-(g)   -141 kJ/mol
                  O-(g)+e- -> O2-(g) +780 kJ/mol
  TRAP      "MORE NEGATIVE" means "LARGER". Cl (-349) accepts an
            electron MORE readily than F (-328).
```

```
  PATTERN 20 — THE ELECTRON GAIN ENTHALPY EXCEPTIONS              4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is the electron gain enthalpy of F less negative than
            that of Cl?" / "... of O less negative than that of S?"
  METHOD    ONE reason answers both:
            F and O are the SMALLEST atoms in their groups. Their 2p
            subshell is very small and COMPACT and already crowded.
            The incoming electron therefore suffers strong
            ELECTRON-ELECTRON REPULSION, which cancels much of the
            energy released.
            Cl and S have a larger 3p subshell, the incoming electron
            has more room, the repulsion is small, and more energy is
            released.

            Correct orders :  Cl > F > Br > I    and    S > Se > O > Te
            Chlorine has the most negative value of ALL elements.
  TRAP      Do not say "fluorine is more electronegative so it should
            be higher". Electronegativity and electron gain enthalpy
            are different properties.
```

```
  PATTERN 21 — ELECTRONEGATIVITY                             2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define electronegativity" / "Distinguish between electron
            gain enthalpy and electronegativity" / "Arrange in order
            of electronegativity."
  METHOD    DEFINITION: "the tendency of an atom IN A CHEMICAL COMPOUND
            (a BONDED atom) to attract the SHARED PAIR OF ELECTRONS
            towards itself." Relative quantity, NO UNITS.

            PAULING SCALE : F 4.0 highest , Cs 0.7 lowest
                            F > O > N = Cl > Br > C = S = I > H
            MULLIKEN      : EN = (IE + electron gain enthalpy) / 2

            TRENDS: increases across a period (size down, Z(eff) up),
                    decreases down a group (size and shielding up).

            DIFFERENCE TABLE:
               electron gain enthalpy : FREE atom, measurable, kJ/mol
               electronegativity      : BONDED atom, not measurable,
                                        no units, relative
  TRAP      The words "bonded" and "shared pair" are the marks. A
            definition without them reads like electron gain enthalpy.
```

```
  PATTERN 22 — VALENCE AND OXIDATION STATE                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "How does valence vary across period 2?" / "Why does
            fluorine show only -1?"
  METHOD    Valence = number of valence electrons, or 8 minus that
            number, whichever is SMALLER.
               Li 1 , Be 2 , B 3 , C 4 , N 3 , O 2 , F 1 , Ne 0
            Across a period : 1,2,3,4 then 3,2,1,0
            Down a group    : CONSTANT

            Fluorine shows only -1 because it is the most
            electronegative element and has NO vacant d orbitals, so
            it cannot show positive oxidation states. Cl, Br and I
            have vacant d orbitals and show +1, +3, +5 and +7.

            d-block elements show VARIABLE oxidation states because
            the (n-1)d and ns electrons are close in energy.
  TRAP      Valence goes UP and then DOWN. Do not write 1 to 7.
```

```
  PATTERN 23 — METALLIC CHARACTER AND CHEMICAL REACTIVITY         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How does metallic character vary?" / "Why is reactivity
            highest at the two ends of a period?"
  METHOD    METALLIC character = tendency to LOSE electrons,
              high when IE is LOW.
            NON-METALLIC character = tendency to GAIN electrons,
              high when electron gain enthalpy is strongly negative.

            Across a period : metallic DOWN, non-metallic UP (IE rises)
            Down a group    : metallic UP, non-metallic DOWN (IE falls)
            Most metallic Cs ; most non-metallic F.
            Metalloids on the staircase: B, Si, Ge, As, Sb, Te, Po.

            REACTIVITY across a period is HIGH at BOTH ENDS and LOW in
            the MIDDLE: the left loses electrons very easily, the right
            gains them very readily, the middle does neither.
            Down a group: metals become MORE reactive, non-metals LESS.
  TRAP      Group 18 is inert - do not call it "the most reactive
            right-hand end".
```

```
  PATTERN 24 — ANOMALOUS 2nd PERIOD + DIAGONAL RELATIONSHIP  2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why do the second period elements behave differently?" /
            "What is a diagonal relationship?" / "Why does N not form
            NCl5?"
  METHOD    FOUR REASONS for the anomaly:
               1. very small size
               2. high ionisation enthalpy
               3. high electronegativity
               4. NO VACANT d ORBITALS in the valence shell
                  -> maximum covalency 4
                  -> NCl5, OF6 and FCl3 do not exist, but PCl5, SF6
                     and ICl3 do

            DIAGONAL RELATIONSHIP : Li~Mg , Be~Al , B~Si
               CAUSE: going across a period the size falls and EN
               rises; going down a group the opposite happens; a
               DIAGONAL move cancels both, so the pair have nearly the
               same size, electronegativity and charge-to-radius ratio.
               EVIDENCE (Li and Mg): both form nitrides Li3N and Mg3N2,
               both form only normal oxides, both carbonates decompose
               on heating, both chlorides dissolve in alcohol.
               EVIDENCE (Be and Al): both oxides amphoteric, both
               chlorides covalent Lewis acids, both passivated by
               concentrated HNO3.
  TRAP      The diagonal pairs are ONLY Li-Mg, Be-Al and B-Si.
            "Li and Na" or "B and Al" are group relationships, not
            diagonal ones.
```

```
  PATTERN 25 — NATURE OF THE OXIDES                               4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How does the nature of the oxides change across period 3?"
            / "What is an amphoteric oxide? Give an example."
  METHOD    1. Write the row and label each oxide:
               Na2O   MgO   Al2O3    SiO2    P4O10   SO3    Cl2O7
               strongly basic  AMPHOTERIC  weakly  acidic  strongly
               basic                       acidic          acidic
            2. Give the REASON: across the period the element changes
               from metallic (ionic, basic oxide) to non-metallic
               (covalent, acidic oxide); the borderline element Al
               gives an amphoteric oxide.
            3. WRITE THE EQUATIONS:
               Na2O  + 2 HCl   -> 2 NaCl   + H2O
               SO3   + 2 NaOH  -> Na2SO4   + H2O
               Al2O3 + 6 HCl   -> 2 AlCl3  + 3 H2O
               Al2O3 + 2 NaOH  -> 2 NaAlO2 + H2O
            4. Down a group the oxides become MORE BASIC
               (N2O3 acidic -> As2O3 amphoteric -> Bi2O3 basic).
  TRAP      For an amphoteric oxide you MUST write BOTH equations,
            one with acid and one with alkali. One equation = one mark.
```

# GUARANTEED-MARKS PLAN FOR THIS CHAPTER

Learn these six things and you comfortably secure **10 to 14 marks out of 60**:

```
  1.  Z(eff) = Z - S  and the two-line across/down explanation
      -> this ONE paragraph is the reason inside every other answer

  2.  Pattern 26 - the full periodic trends answer
      -> the 8-mark long answer, and it also covers patterns
         13, 14, 15, 16, 17, 19, 20, 21

  3.  Mendeleev's 4 merits and 5 demerits (patterns 3 and 4)
      -> a 4-mark answer that is pure memory, no understanding needed

  4.  Period / group / block from a configuration (pattern 7)
      -> appears as a 2-mark or 4-mark question almost every year,
         and it is the easiest mark in the whole paper

  5.  The exception list, said out loud until it is automatic:
         IE      : Be > B  ,  N > O  ,  Mg > Al  ,  P > S
         eg-enth : Cl > F  ,  S > O
         size    : isoelectronic -> bigger Z means smaller ion
         2nd period: no d orbitals -> max covalency 4
         diagonal : Li~Mg , Be~Al , B~Si

  6.  IUPAC roots for Z > 100 (pattern 10) and the oxide row
      Na2O -> Al2O3 -> Cl2O7 (pattern 25)
      -> two more easy marks each, for about twenty minutes of work
```
