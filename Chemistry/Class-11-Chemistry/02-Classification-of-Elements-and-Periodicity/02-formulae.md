# 0. THE THREE LAWS — WORD FOR WORD

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  NEWLANDS' LAW OF OCTAVES                                            |
  |     "When the elements are arranged in the increasing order of       |
  |      their atomic weights, the properties of every EIGHTH element    |
  |      are a repetition of the properties of the first element."       |
  |                                                                      |
  |  MENDELEEV'S PERIODIC LAW                                            |
  |     "The physical and chemical properties of the elements are a      |
  |      periodic function of their ATOMIC WEIGHTS."                     |
  |                                                                      |
  |  MODERN PERIODIC LAW  (Moseley)                                      |
  |     "The physical and chemical properties of the elements are a      |
  |      periodic function of their ATOMIC NUMBERS."                     |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  MOSELEY'S EQUATION  (the only real equation in the chapter)

  +----------------------------------------------------------------------+
  |                                                                      |
  |             sqrt ( nu )   =   a  ( Z  -  b )                         |
  |                                                                      |
  |    nu = frequency of the characteristic X-rays                       |
  |    Z  = atomic number                                                |
  |    a , b = constants                                                 |
  |                                                                      |
  |    Meaning: the X-ray frequency depends on ATOMIC NUMBER,            |
  |             not on atomic weight. So Z is the fundamental property.  |
  +----------------------------------------------------------------------+
```

```
  DOBEREINER'S TRIAD RULE

                                   wt(first)  +  wt(third)
        atomic weight (middle)  =  -----------------------
                                             2
```

```
  CAUSE OF PERIODICITY

     The repetition of similar OUTERMOST (valence) SHELL ELECTRONIC
     CONFIGURATIONS after regular intervals of atomic number.
```

# 3. HOW TO FIND PERIOD, BLOCK AND GROUP  *** the most useful rule set ***

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |  PERIOD  =  the HIGHEST value of n in the electronic configuration   |
  |                                                                      |
  |  BLOCK   =  the subshell that received the LAST electron             |
  |                                                                      |
  |  GROUP   :                                                           |
  |                                                                      |
  |     s-block   group  =  (number of ns electrons)         [1 or 2]    |
  |                                                                      |
  |     p-block   group  =  10  +  (ns electrons + np electrons)         |
  |               i.e.   =  12  +  (number of np electrons)              |
  |                                                                      |
  |     d-block   group  =  (n-1)d electrons  +  ns electrons            |
  |                                                                      |
  |     f-block   group  =  3   (always)                                 |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| Configuration ends in | Block | Group formula | Example |
|-----------------------|-------|---------------|---------|
| ns1 | s | 1 | 3s1 → group 1 (Na) |
| ns2 | s | 2 | 4s2 → group 2 (Ca) |
| ns2 np1 | p | 10 + 3 = 13 | 3s2 3p1 → 13 (Al) |
| ns2 np2 | p | 10 + 4 = 14 | 3s2 3p2 → 14 (Si) |
| ns2 np3 | p | 10 + 5 = 15 | 2s2 2p3 → 15 (N) |
| ns2 np4 | p | 10 + 6 = 16 | 2s2 2p4 → 16 (O) |
| ns2 np5 | p | 10 + 7 = 17 | 3s2 3p5 → 17 (Cl) |
| ns2 np6 | p | 10 + 8 = 18 | 3s2 3p6 → 18 (Ar) |
| (n-1)d1 ns2 | d | 1 + 2 = 3 | 3d1 4s2 → 3 (Sc) |
| (n-1)d5 ns1 | d | 5 + 1 = 6 | 3d5 4s1 → 6 (Cr) |
| (n-1)d6 ns2 | d | 6 + 2 = 8 | 3d6 4s2 → 8 (Fe) |
| (n-1)d10 ns1 | d | 10 + 1 = 11 | 3d10 4s1 → 11 (Cu) |
| (n-1)d10 ns2 | d | 10 + 2 = 12 | 3d10 4s2 → 12 (Zn) |

> **TRAP:** helium is 1s2 but belongs to **group 18**, not group 2, because its
> outermost shell is completely filled and it behaves like a noble gas.

# 5. EFFECTIVE NUCLEAR CHARGE — THE MASTER IDEA

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |            Z ( eff )   =   Z   -   S                                 |
  |                                                                      |
  |     Z(eff) = net pull actually felt by the outermost electron        |
  |     Z      = nuclear charge = atomic number = number of protons      |
  |     S      = screening (shielding) constant, roughly the number      |
  |              of inner electrons                                      |
  |                                                                      |
  |     SCREENING POWER within the same shell :   s  >  p  >  d  >  f    |
  |     (an s electron penetrates closest to the nucleus)                |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  +---------------------+----------------+----------------+---------------+
  |  MOVING             |  Z             |  S             |  Z(eff)       |
  +---------------------+----------------+----------------+---------------+
  |  ACROSS a period    |  increases     |  almost SAME   |  INCREASES    |
  |  (left to right)    |  by 1 each step|  (same shell)  |  strongly     |
  +---------------------+----------------+----------------+---------------+
  |  DOWN a group       |  increases a   |  increases a   |  almost       |
  |                     |  lot           |  lot (new      |  UNCHANGED    |
  |                     |                |  shell added)  |  (but farther)|
  +---------------------+----------------+----------------+---------------+
```

**Every "why" answer in this chapter is one of these two rows.**

# 7. ATOMIC RADIUS — TYPES, TREND, REASON, EXCEPTION

```
  +-------------------+--------------------------------------------------+
  |  TYPE             |  DEFINITION                                      |
  +-------------------+--------------------------------------------------+
  |  COVALENT radius  |  half the distance between the nuclei of two     |
  |                   |  identical atoms bonded by a SINGLE covalent bond|
  +-------------------+--------------------------------------------------+
  |  VAN DER WAALS    |  half the distance between the nuclei of two     |
  |  radius           |  adjacent atoms of two NEIGHBOURING MOLECULES    |
  |                   |  in the solid state                              |
  +-------------------+--------------------------------------------------+
  |  METALLIC radius  |  half the distance between the nuclei of two     |
  |                   |  adjacent atoms in a METALLIC CRYSTAL            |
  +-------------------+--------------------------------------------------+

        SIZE ORDER :   van der Waals  >  metallic  >  covalent
```

| Direction | Trend | REASON | Exception |
|-----------|-------|--------|-----------|
| Across a period | decreases | Z increases, electrons enter the same shell, shielding almost constant → Z(eff) rises → cloud pulled in | noble gases appear larger (van der Waals radius quoted, not covalent) |
| Down a group | increases | a new shell is added; the rise in shell number and shielding outweighs the rise in Z | in the d-block the change is very small (poor shielding by inner d) |

```
  DATA TO QUOTE (covalent radius, pm)

     PERIOD 2 :  Li 152 > Be 111 > B 88 > C 77 > N 74 > O 66 > F 64
     GROUP 1  :  Li 152 < Na 186 < K 231 < Rb 244 < Cs 262
```

# 8. IONIC RADIUS — THE THREE RULES

```
  +----------------------------------------------------------------------+
  |  RULE 1 :  CATION  <  parent ATOM                                    |
  |     because it has one shell fewer, fewer electrons for the same     |
  |     nuclear charge (higher Z(eff) per electron) and less repulsion.  |
  |            Na 186 pm  ->  Na+ 95 pm                                  |
  |                                                                      |
  |  RULE 2 :  ANION   >  parent ATOM                                    |
  |     because the same nuclear charge must now hold MORE electrons     |
  |     and the extra electron-electron repulsion expands the cloud.     |
  |            Cl 99 pm   ->  Cl- 181 pm                                 |
  |                                                                      |
  |  RULE 3 :  ISOELECTRONIC SERIES (same number of electrons)           |
  |     radius DECREASES as the nuclear charge Z INCREASES.              |
  |                                                                      |
  |         N3-  >  O2-  >  F-  >  Ne  >  Na+  >  Mg2+  >  Al3+          |
  |         171     140     136          95      65        50   (pm)     |
  |          Z=7    Z=8     Z=9   Z=10   Z=11    Z=12      Z=13          |
  |                                                                      |
  |  For the SAME element :   Fe  >  Fe2+  >  Fe3+                       |
  +----------------------------------------------------------------------+
```

# 9. IONISATION ENTHALPY

```
  +----------------------------------------------------------------------+
  |  DEFINITION - QUOTE WORD FOR WORD                                    |
  |                                                                      |
  |  "The MINIMUM energy required to remove the MOST LOOSELY BOUND       |
  |   electron from an ISOLATED NEUTRAL GASEOUS ATOM in its GROUND       |
  |   STATE, to form a gaseous cation."                                  |
  |                                                                      |
  |        M (g)  +  IE(1)   ---->   M+ (g)  +  e-                       |
  |                                                                      |
  |  Unit : kJ/mol      Sign : ALWAYS POSITIVE (endothermic)             |
  |                                                                      |
  |  SUCCESSIVE :   IE(1)  <  IE(2)  <  IE(3)  <  IE(4) ...              |
  |     because the ion becomes smaller and more positive each time,     |
  |     so Z(eff) on the remaining electrons is larger.                  |
  +----------------------------------------------------------------------+
```

| Factor | Effect | Reason |
|--------|--------|--------|
| larger atomic size | IE decreases | outer electron farther, weakly held |
| larger nuclear charge | IE increases | stronger attraction |
| more shielding | IE decreases | inner electrons block the pull |
| half-filled / fully-filled subshell | IE increases | extra symmetry stability |
| better penetration (s > p > d > f) | IE increases | s electron sits closer to the nucleus |

```
  IE1 VALUES (kJ/mol) - the ones to quote

     PERIOD 2 : Li 520 , Be 899 , B 801 , C 1086 , N 1402 ,
                O 1314 , F 1681 , Ne 2081

     PERIOD 3 : Na 496 , Mg 737 , Al 577 , Si 786 , P 1012 ,
                S 1000 , Cl 1256 , Ar 1520
```

```
  +----------------------------------------------------------------------+
  |  THE FOUR FAMOUS EXCEPTIONS                                          |
  |                                                                      |
  |     Be > B        Mg > Al        N > O        P > S                  |
  |                                                                      |
  |  REASON for Be > B :                                                 |
  |     Be has a fully-filled, stable 2s2. In B the electron comes       |
  |     from a 2p orbital which is higher in energy, less penetrating    |
  |     and shielded by the 2s2 pair - so it is easier to remove.        |
  |                                                                      |
  |  REASON for N > O :                                                  |
  |     N has an exactly half-filled, symmetrical and stable 2p3.        |
  |     In O the fourth 2p electron must PAIR UP, and the resulting      |
  |     electron-electron repulsion makes it easier to remove.           |
  +----------------------------------------------------------------------+
```

# 10. ELECTRON GAIN ENTHALPY

```
  +----------------------------------------------------------------------+
  |  DEFINITION - QUOTE WORD FOR WORD                                    |
  |                                                                      |
  |  "The ENTHALPY CHANGE that takes place when an electron is added     |
  |   to an ISOLATED NEUTRAL GASEOUS ATOM in its GROUND STATE to form    |
  |   a gaseous negative ion."                                           |
  |                                                                      |
  |        X (g)  +  e-   ---->   X- (g)      ;   delta(eg)H             |
  |                                                                      |
  |  Unit : kJ/mol                                                       |
  |  Sign : usually NEGATIVE (energy released)                           |
  |         POSITIVE for noble gases (filled ns2 np6) and                |
  |                  group 2 elements (filled ns2)                       |
  |  SECOND electron gain enthalpy is ALWAYS POSITIVE, because the       |
  |  electron is forced into an already negative ion against repulsion.  |
  +----------------------------------------------------------------------+
```

| Direction | Trend | Reason |
|-----------|-------|--------|
| Across a period | becomes more negative | size decreases, Z(eff) increases → stronger pull on the incoming electron |
| Down a group | becomes less negative | size increases → incoming electron is far from the nucleus |

```
  VALUES (kJ/mol)

     H  -73      F  -328     O  -141     Be, Mg  positive
                 Cl -349     S  -200     noble gases positive
                 Br -325     Se -195     N  about zero (slightly +ve,
                 I  -295     Te -190        because 2p3 is half-filled)
```

```
  +----------------------------------------------------------------------+
  |  THE TWO FAMOUS EXCEPTIONS                                           |
  |                                                                      |
  |     Cl  is MORE negative than  F     ( -349 vs -328 )                |
  |     S   is MORE negative than  O     ( -200 vs -141 )                |
  |                                                                      |
  |  ONE REASON COVERS BOTH:                                             |
  |     F and O are very SMALL atoms with a compact 2p subshell that     |
  |     is already crowded. The incoming electron suffers strong         |
  |     ELECTRON-ELECTRON REPULSION, which cancels much of the energy    |
  |     released. Cl and S are larger (3p), so the extra electron has    |
  |     more room, feels less repulsion, and more energy is released.    |
  |                                                                      |
  |  ACTUAL ORDERS :   Cl > F > Br > I        S > Se > O > Te            |
  +----------------------------------------------------------------------+
```

  |                                                                      |

# 13. ANOMALOUS BEHAVIOUR AND THE DIAGONAL RELATIONSHIP

```
  WHY THE 2nd PERIOD ELEMENTS ARE ODD - FOUR REASONS
     1. very small atomic and ionic size
     2. high ionisation enthalpy
     3. high electronegativity
     4. ABSENCE of vacant d orbitals in the valence shell
        -> maximum covalency is 4
        -> NCl5, OF6, FCl3 do NOT exist, but PCl5, SF6, ICl3 do
```

```
  DIAGONAL PAIRS :      Li ~ Mg        Be ~ Al        B ~ Si

  REASON : moving across a period decreases size and increases EN,
           while moving down a group does the opposite. A diagonal
           move cancels both, so the pair end up with nearly the
           same SIZE, ELECTRONEGATIVITY and CHARGE-TO-RADIUS RATIO.
```

| Pair | Shared evidence |
|------|-----------------|
| Li–Mg | both form nitrides (Li3N, Mg3N2); both form normal oxides; carbonates decompose on heating; chlorides soluble in alcohol |
| Be–Al | both oxides amphoteric; both chlorides covalent Lewis acids; both passivated by conc. HNO3; both dissolve in alkali |
| B–Si | both metalloids/semiconductors; both form acidic oxides; both give spontaneously flammable hydrides |

# 15. REACTIVITY
