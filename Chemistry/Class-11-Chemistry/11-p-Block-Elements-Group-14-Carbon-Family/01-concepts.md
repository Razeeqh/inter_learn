# TOPIC 0 — WHAT IS THE p-BLOCK? (the 2-minute introduction)

The periodic table is cut into blocks according to **which orbital the last
electron enters**.

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   s-BLOCK   last electron enters an  s  orbital   Groups 1, 2      |
  |   p-BLOCK   last electron enters a   p  orbital   Groups 13 to 18  |
  |   d-BLOCK   last electron enters a   d  orbital   Groups 3 to 12   |
  |   f-BLOCK   last electron enters an  f  orbital   Ln and An        |
  |                                                                    |
  +--------------------------------------------------------------------+
```

**The p-block is the six columns on the RIGHT of the periodic table.**

```
    GROUP    13        14        15        16        17        18
    CONFIG   ns2np1    ns2np2    ns2np3    ns2np4    ns2np5    ns2np6
    NAME     Boron     Carbon    Nitrogen  Oxygen    Halogen   Noble
             family    family    family    family    family    gases

             B         C         N         O         F         He/Ne
             Al        Si        P         S         Cl        Ar
             Ga        Ge        As        Se        Br        Kr
             In        Sn        Sb        Te        I         Xe
             Tl        Pb        Bi        Po        At        Rn
```

Three facts about the p-block that you can write in any general question:

```
  1.  General configuration is  ns2 np(1-6)  (helium, 1s2, is the exception).

  2.  The p-block contains METALS, METALLOIDS and NON-METALS all together.
      It is the only block that does.

  3.  The FIRST member of every p-block group behaves ABNORMALLY compared
      with the rest of its own group, because it is very small, has a high
      electronegativity and has NO d ORBITALS.
          B is odd in group 13 . C is odd in group 14 . N is odd in group 15.
```

That third point is the reason "Anomalous behaviour of carbon" is a question
every single year.

> **TRAP:** Do not say "the p-block starts at group 13 so it has 6 groups
> including the noble gases" and then forget helium. Helium sits in group 18
> but its configuration is `1s2`, which is an **s-block** configuration. It is
> placed in group 18 because of its **properties** (full valence shell), not
> its configuration.

# TOPIC 1 — GROUP 14: THE MEMBERS, CONFIGURATION AND OCCURRENCE

## 1.1 The five members

```
  +---------+--------+-----+------------------------+-------------------+
  | ELEMENT | SYMBOL |  Z  |  CONFIGURATION         |  NATURE           |
  +---------+--------+-----+------------------------+-------------------+
  | Carbon  |   C    |  6  |  [He] 2s2 2p2          |  NON-METAL        |
  | Silicon |   Si   | 14  |  [Ne] 3s2 3p2          |  METALLOID        |
  | German. |   Ge   | 32  |  [Ar] 3d10 4s2 4p2     |  METALLOID        |
  | Tin     |   Sn   | 50  |  [Kr] 4d10 5s2 5p2     |  METAL            |
  | Lead    |   Pb   | 82  |  [Xe] 4f14 5d10 6s2 6p2|  METAL            |
  +---------+--------+-----+------------------------+-------------------+

  GENERAL ELECTRONIC CONFIGURATION  =   ns2 np2
```

Notice how the configuration is built:

```
      ns2 np2   means  TWO electrons in the s orbital of the outer shell
                       TWO electrons in the p orbitals of the outer shell
                       = FOUR valence electrons in total

      Orbital picture of the ground state of carbon:

              2s              2p
           +------+     +----+----+----+
           | up dn|     | up | up |    |
           +------+     +----+----+----+

      Only TWO unpaired electrons -> you would expect a valency of 2.
      But carbon shows a valency of FOUR. Why?
      Because one 2s electron is PROMOTED to the empty 2p orbital:

              2s              2p                (EXCITED STATE)
           +------+     +----+----+----+
           |  up  |     | up | up | up |
           +------+     +----+----+----+

      Now there are FOUR unpaired electrons -> valency 4.
      The small energy spent on promotion is more than repaid by forming
      two extra bonds. This is why carbon is TETRAVALENT.
```

**An everyday analogy:** think of each atom as a person with four hands
(four valence electrons). Carbon is a small person with four very strong,
short arms — it grips other carbons so tightly that it can form endless
chains. Lead is a huge person with four long, floppy arms — it can barely
hold on to anything, so it prefers to just hand over two electrons and
become Pb2+.

## 1.2 Occurrence — where these elements are found

```
  +-----------+-----------------------------------------------------------+
  |  CARBON   |  Only 0.02 % of the earth's crust.                        |
  |           |  FREE   : diamond, graphite, coal                         |
  |           |  COMBINED: carbonates (CaCO3 limestone, MgCO3 magnesite,  |
  |           |            dolomite MgCO3.CaCO3), CO2 in air (0.03 %),    |
  |           |            petroleum, natural gas, all living matter      |
  |           |  ISOTOPES: 12C (98.9 %), 13C (1.1 %), 14C (radioactive,   |
  |           |            half life ~5770 years, used for carbon dating) |
  +-----------+-----------------------------------------------------------+
  |  SILICON  |  27.7 % of the earth's crust by mass.                     |
  |           |  ** SECOND MOST ABUNDANT ELEMENT after OXYGEN **          |
  |           |  Never found free. Found as SILICA (SiO2 - sand, quartz)  |
  |           |  and as SILICATES (clay, feldspar, mica, asbestos).       |
  +-----------+-----------------------------------------------------------+
  | GERMANIUM |  Very rare - only traces. Found in some coals and in      |
  |           |  the mineral argyrodite. Recovered as a by-product.       |
  +-----------+-----------------------------------------------------------+
  |   TIN     |  Chief ore CASSITERITE / tin stone,  SnO2                 |
  +-----------+-----------------------------------------------------------+
  |   LEAD    |  Chief ore GALENA,  PbS                                   |
  +-----------+-----------------------------------------------------------+
```

**WORKED EXAMPLE 1**

> *Q. Write the general electronic configuration of group 14 elements. Name
> the most abundant element of this group in the earth's crust and give its
> percentage. Which member is a non-metal?*

```
  STEP 1 : General configuration     ->   ns2 np2

  STEP 2 : The five members          ->   C , Si , Ge , Sn , Pb

  STEP 3 : Most abundant in the crust ->  SILICON , 27.7 % by mass.
           It is the SECOND most abundant element in the crust overall,
           after oxygen.

  STEP 4 : The non-metal             ->   CARBON.
           (Si and Ge are metalloids ; Sn and Pb are metals.)
```

> **TRAP:** Silicon is the most abundant element **of this group**, and the
> second most abundant element **in the earth's crust**. It is NOT the most
> abundant element in the universe (that is hydrogen) or in the atmosphere.
> Read which one is asked.

# TOPIC 2 — ATOMIC AND IONIC RADII

## 2.1 The trend

```
  COVALENT RADIUS (pm)

      C      Si     Ge     Sn     Pb
      77 ->  118 -> 122 -> 140 -> 146

      |<-41->|<-4->|<-18->|<-6->|
       BIG    tiny   big   tiny
       jump   jump   jump  jump
```

**RULE: atomic and ionic radii INCREASE down the group.**

**REASON:** a brand new electron shell is added at every step down, so the
outermost electron sits further and further from the nucleus.

## 2.2 The bit that carries the extra marks — the irregular jump

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   The increase from C to Si is LARGE (77 -> 118 pm).                 |
  |   From Si to Ge it is very SMALL (118 -> 122 pm).                    |
  |   From Sn to Pb it is again SMALL (140 -> 146 pm).                   |
  |                                                                      |
  |   WHY?                                                               |
  |                                                                      |
  |   Between Si and Ge, ten 3d electrons are filled in.                 |
  |   Between Sn and Pb, fourteen 4f electrons are filled in.            |
  |                                                                      |
  |   d and f orbitals are DIFFUSE (spread out, oddly shaped), so they   |
  |   SHIELD the outer electrons very POORLY.                            |
  |                                                                      |
  |   Poor shielding -> the outer electron feels a bigger effective      |
  |   nuclear charge -> it is pulled IN -> the expected size increase    |
  |   is largely cancelled.                                              |
  |                                                                      |
  |   This is called the  d-BLOCK CONTRACTION  and the                   |
  |                       LANTHANOID CONTRACTION.                        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

**Everyday analogy for shielding:** imagine the nucleus is a heater and the
outer electron is you. Inner electrons are people standing between you and
the heater, blocking the warmth. s and p electrons stand in a neat wall and
block well. d and f electrons stand in a scattered, gappy crowd — a lot of
heat leaks through. So the outer electron feels more pull than it should.

> **TRAP:** "Radius increases down the group" alone gets you half marks.
> The reason ("a new shell is added each period") must be written, and if
> the question says *"explain the irregular trend"* you must mention the
> d-block and lanthanoid contractions.

# TOPIC 3 — IONISATION ENTHALPY AND ELECTRONEGATIVITY

## 3.1 Ionisation enthalpy

**Definition reminder:** ionisation enthalpy is the energy needed to pull the
outermost electron completely away from an isolated gaseous atom.

```
  FIRST IONISATION ENTHALPY  (kJ / mol)

      C      Si     Ge     Sn     Pb
     1086 -> 786 -> 761 -> 708 -> 715
      |                            ^
      |                            |
      BIG DROP                 IT GOES UP AGAIN !
```

**RULE: ionisation enthalpy DECREASES down the group** (C to Sn).

**REASON:** the atom gets bigger, so the outer electron is further from the
nucleus and is better shielded — it is easier to remove.

**THE EXCEPTION you must quote:**

```
      IE1 of Pb (715) is slightly HIGHER than IE1 of Sn (708).

      REASON:  In lead, fourteen 4f electrons and ten 5d electrons lie
               between the nucleus and the 6s2 6p2 valence shell.
               These f and d electrons shield very POORLY, so the 6s
               and 6p electrons feel an unusually LARGE effective
               nuclear charge and are held more tightly than expected.
```

Also worth a mark: ionisation enthalpies of group 14 are **higher** than the
corresponding group 13 elements, because group 14 atoms are smaller and have
a higher nuclear charge.

## 3.2 Electronegativity

```
  ELECTRONEGATIVITY (Pauling)

      C      Si     Ge     Sn     Pb
     2.5 -> 1.8 -> 1.8 -> 1.8 -> 1.9

      BIG DROP from C to Si, then almost CONSTANT.
```

```
  RULE   :  Electronegativity DECREASES sharply from C to Si and is then
            almost the same for Si, Ge, Sn and Pb.

  REASON :  Carbon is very small, so its nucleus pulls the shared pair of
            a covalent bond strongly. After silicon the atoms are all
            fairly large and the small size differences hardly matter.
```

**Why does this matter?** Because carbon's high electronegativity (2.5) is one
of the four reasons its behaviour is anomalous — see Topic 6.

**WORKED EXAMPLE 2**

> *Q. Ionisation enthalpy decreases down group 14, yet Pb has a higher first
> ionisation enthalpy than Sn. Explain.*

```
  STEP 1 : State the normal rule and its reason.
           Down a group a new shell is added -> the atom gets bigger ->
           the outer electron is farther away and better shielded ->
           less energy is needed to remove it -> IE falls.
           C (1086) > Si (786) > Ge (761) > Sn (708).

  STEP 2 : State the exception with numbers.
           But IE1 of Pb = 715 kJ/mol , which is HIGHER than Sn = 708.

  STEP 3 : Give the reason - POOR SHIELDING.
           Lead has filled 4f14 and 5d10 subshells lying inside its
           valence shell. f and d orbitals are diffuse and shield the
           nuclear charge very poorly.

  STEP 4 : Conclude.
           So the 6s2 6p2 electrons of Pb experience a larger effective
           nuclear charge, are held more tightly, and need slightly more
           energy to remove than the 5s2 5p2 electrons of Sn.
```

> **TRAP:** Never write "Pb is bigger so IE is bigger". Size and IE move in
> **opposite** directions. The whole answer here is **poor shielding by d and
> f electrons**.

# TOPIC 4 — MELTING POINT, BOILING POINT, DENSITY AND METALLIC CHARACTER

## 4.1 Melting and boiling points

```
  MELTING POINT (K)

      C (diamond)   4373      <-- ENORMOUS
      Si            1693
      Ge            1218
      Sn             505
      Pb             600      <-- goes UP again

  BOILING POINT (K)

      Si  3550  >  Ge  3123  >  Sn  2896  >  Pb  2024
```

```
  RULE   :  Melting and boiling points DECREASE down the group.

  REASON :  C, Si and Ge form GIANT COVALENT (network) structures. Melting
            them means breaking millions of strong covalent bonds, which
            needs huge energy. As you go down, the atoms get bigger, the
            covalent bonds get longer and WEAKER, so less energy is needed.
            Sn and Pb are METALS with ordinary metallic bonding, which is
            far weaker than a covalent network - so their melting points
            collapse.

  EXCEPTION : m.p. of Pb (600 K) > m.p. of Sn (505 K).
              REASON: the two metals have DIFFERENT CRYSTAL STRUCTURES,
              so the trend does not hold for this pair.
```

## 4.2 Density

```
      C (diamond) 3.51  ,  C (graphite) 2.22
      Si  2.34  ->  Ge  5.32  ->  Sn  7.26  ->  Pb  11.34   g/cm3

      DENSITY INCREASES DOWN THE GROUP.
      REASON: atomic MASS rises much faster than atomic VOLUME.

      Note diamond is DENSER than graphite (3.51 vs 2.22) because diamond's
      atoms are packed into a tight 3-D network while graphite has wide
      empty gaps of 340 pm between its layers.
```

## 4.3 Metallic character — the headline trend of the group

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |     C        Si        Ge        Sn        Pb                      |
  |   NON-      METAL-    METAL-    METAL     METAL                    |
  |   METAL     LOID      LOID                                         |
  |                                                                    |
  |   <----------------- METALLIC CHARACTER INCREASES ----------->     |
  |                                                                    |
  |   REASON:  going down, the atom gets bigger and the ionisation     |
  |            enthalpy falls, so the atom loses electrons more        |
  |            easily -> it behaves more like a metal.                 |
  |                                                                    |
  |   EVIDENCE you can quote:                                          |
  |     *  C and Si are always covalent ; they never form simple ions. |
  |     *  Ge forms a few compounds in the +2 state.                   |
  |     *  Sn and Pb form definite Sn2+ and Pb2+ IONS and are typical  |
  |        shiny, malleable, conducting metals.                        |
  |     *  Oxides go ACIDIC (CO2, SiO2) -> AMPHOTERIC (GeO2, SnO2,     |
  |        PbO2). Acidic oxide = non-metal ; basic oxide = metal.      |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## 4.4 One more property worth two marks — electrical behaviour

```
      C (diamond)  INSULATOR      (all four electrons locked in sigma bonds)
      C (graphite) CONDUCTOR      (one delocalised electron per atom)
      Si , Ge      SEMICONDUCTORS (that is why they run every computer chip)
      Sn , Pb      GOOD CONDUCTORS (true metals)
```

> **TRAP:** Do not write "melting point decreases down the group" and stop.
> The examiner wants **why it collapses at Sn** — the change from a giant
> covalent network to metallic bonding. And mention the Pb > Sn exception.

# TOPIC 5 — OXIDATION STATES AND THE INERT PAIR EFFECT

This is the single most reliable 4-mark question in the chapter.

## 5.1 The two oxidation states

Group 14 has four valence electrons (`ns2 np2`). It can use:

```
      ALL FOUR electrons        ->   +4 oxidation state
      only the TWO p electrons  ->   +2 oxidation state
                                     (the ns2 pair stays behind)
```

## 5.2 What actually happens down the group

```
  +----------+---------------------------+---------------------------+
  | ELEMENT  |  +4 STATE                 |  +2 STATE                 |
  +----------+---------------------------+---------------------------+
  |    C     |  the ONLY normal state    |  very rare (CO)           |
  |    Si    |  the ONLY normal state    |  very rare                |
  |    Ge    |  stable                   |  exists, strongly reducing|
  |    Sn    |  stable                   |  stable, reducing         |
  |    Pb    |  UNSTABLE, oxidising      |  ** MOST STABLE **        |
  +----------+---------------------------+---------------------------+

           +4 stability   <------------ FALLS ------------
           +2 stability   ------------- RISES ----------->
```

## 5.3 THE INERT PAIR EFFECT — explained properly

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   DEFINITION                                                         |
  |                                                                      |
  |   THE INERT PAIR EFFECT is the RELUCTANCE OF THE ns2 ELECTRON PAIR   |
  |   TO TAKE PART IN BOND FORMATION, which increases as we go DOWN a    |
  |   p-block group. Because of it, the lower oxidation state (+2 in     |
  |   group 14) becomes more stable than the higher one (+4).            |
  |                                                                      |
  +----------------------------------------------------------------------+

  THE MECHANISM - write these four steps:

     1.  Going down the group, filled d (3d10, 4d10, 5d10) and f (4f14)
         subshells come in between the nucleus and the valence shell.

     2.  d and f orbitals are DIFFUSE and shield the nuclear charge very
         POORLY.

     3.  So the ns2 pair of the heavier elements feels an unusually LARGE
         effective nuclear charge. It is pulled in close, its energy is
         lowered, and the s orbital is now much lower in energy than p.

     4.  It therefore costs too much energy to UNPAIR and PROMOTE one of
         those ns electrons into the np orbital. Without that promotion
         the atom can only use its two p electrons -> valency 2 -> the
         +2 state.

  ALTERNATIVE WORDING FOR THE SAME ANSWER (also accepted):
     The energy released by forming two extra bonds in the +4 state is no
     longer enough to pay for unpairing the ns2 electrons, because the M-X
     bond enthalpy gets smaller as the atom gets bigger.
```

```
  A PICTURE OF THE INERT PAIR

        CARBON (small, well shielded)      LEAD (big, badly shielded)

         2s  +------+                        6s  +------+
             | up dn|  <- easy to promote        | up dn|  <- LOCKED IN
             +------+                            +------+     (INERT PAIR)
                                                       |
              small energy gap                    HUGE energy gap
                                                       |
         2p  +--+--+--+                        6p  +--+--+--+
             |  |  |  |                            |up|up|  |
             +--+--+--+                            +--+--+--+

        -> uses all 4 electrons              -> uses only the 2 p electrons
        -> +4 state                          -> +2 state
```

## 5.4 The consequences — oxidising and reducing character

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   RULE OF THUMB:                                                     |
  |     A compound in an UNSTABLE oxidation state will CHANGE to the     |
  |     stable one - and in doing so it acts as an oxidiser or reducer.  |
  |                                                                      |
  |   Pb(IV) is UNSTABLE -> it wants to become Pb(II) -> it must GAIN    |
  |   electrons -> Pb(IV) compounds are STRONG OXIDISING AGENTS.         |
  |        PbO2 , PbCl4 , Pb(SO4)2  are powerful oxidisers.              |
  |                                                                      |
  |   Sn(II) and Ge(II) are the UNSTABLE ones for those elements -> they |
  |   want to become Sn(IV) / Ge(IV) -> they must LOSE electrons ->      |
  |   Sn(II) and Ge(II) compounds are GOOD REDUCING AGENTS.              |
  |        SnCl2 , GeCl2  are reducers.                                  |
  |                                                                      |
  +----------------------------------------------------------------------+

  EQUATIONS TO QUOTE:

      SnCl2  +  2 HgCl2   -->   SnCl4  +  Hg2Cl2        (SnCl2 reduces)
      SnCl2  +  Hg2Cl2    -->   SnCl4  +  2 Hg
      2 SnCl2 + O2 + 4 HCl -->  2 SnCl4 + 2 H2O

      PbO2  +  4 HCl      -->   PbCl2  +  Cl2  +  2 H2O  (PbO2 oxidises)
      2 PbO2 --(heat)-->  2 PbO  +  O2       (PbO2 decomposes readily)

  STABILITY ORDER OF THE DIHALIDES:   GeX2  <  SnX2  <  PbX2
  STABILITY ORDER OF THE TETRAHALIDES: GeX4 >  SnX4  >  PbX4
```

**WORKED EXAMPLE 3**

> *Q. PbO2 is a strong oxidising agent while SnCl2 is a good reducing agent.
> Explain on the basis of the inert pair effect.*

```
  STEP 1 : State the effect.
           Down group 14 the ns2 pair becomes reluctant to bond (INERT
           PAIR EFFECT), because badly shielding d and f electrons let
           the nucleus grip it tightly. So +2 becomes more stable and
           +4 less stable as we go down.

  STEP 2 : Apply it to lead.
           Lead is at the BOTTOM, so Pb(II) is the stable state and
           Pb(IV) is unstable. In PbO2 lead is in the +4 state. It
           readily accepts 2 electrons and drops to Pb(II).
           Accepting electrons = OXIDISING the other substance.
                PbO2 + 4 HCl --> PbCl2 + Cl2 + 2 H2O

  STEP 3 : Apply it to tin.
           Tin is higher up, so for tin the +4 state is still the stable
           one. In SnCl2 tin is in the unstable +2 state. It readily
           gives away 2 electrons and rises to Sn(IV).
           Giving electrons = REDUCING the other substance.
                SnCl2 + 2 HgCl2 --> SnCl4 + Hg2Cl2

  STEP 4 : One-line conclusion.
           PbO2 is an OXIDISER because +4 is unstable for lead ;
           SnCl2 is a REDUCER because +2 is unstable for tin.
```

> **TRAP:** Students mix up the direction. Remember:
> **bottom of the group + high oxidation state = OXIDISER** (PbO2).
> **top-ish of the group + low oxidation state = REDUCER** (SnCl2).
> Also remember `PbI4` does **not exist at all**, because the strongly
> oxidising Pb4+ would immediately oxidise the strongly reducing I- ion
> to iodine. `PbF4` and `PbCl4` do exist, but PbCl4 decomposes on gentle
> warming into PbCl2 + Cl2.

# TOPIC 6 — THE ANOMALOUS BEHAVIOUR OF CARBON

## 6.1 What "anomalous" means

Carbon, the first member of group 14, behaves quite differently from Si, Ge,
Sn and Pb. That is what "anomalous behaviour" means.

## 6.2 THE FOUR REASONS — learn these as a numbered list

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   1.  VERY SMALL ATOMIC SIZE      (covalent radius only 77 pm)       |
  |                                                                      |
  |   2.  HIGH ELECTRONEGATIVITY      (2.5 , the highest in the group)   |
  |                                                                      |
  |   3.  HIGH IONISATION ENTHALPY    (1086 kJ/mol , far above the rest) |
  |                                                                      |
  |   4.  ABSENCE OF d ORBITALS IN THE VALENCE SHELL                     |
  |       Carbon's valence shell is n = 2, which has only 2s and 2p.     |
  |       There is no 2d subshell. Si onwards DO have vacant d orbitals. |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 6.3 THE CONSEQUENCES — what those four reasons actually cause

| # | CONSEQUENCE | WHICH REASON CAUSES IT |
|---|---|---|
| 1 | Maximum covalency of carbon is **4**. Si, Ge, Sn, Pb can go up to **6** (e.g. `[SiF6]2-`, `[SnCl6]2-`). `[CF6]2-` does not exist. | No d orbitals |
| 2 | Carbon forms strong **p(pi)-p(pi) multiple bonds** with itself, with O and with N (C=C, C=C=C, C=O, C=N). Si, Ge, Sn, Pb hardly form pi bonds at all. | Small size lets the p orbitals overlap sideways properly |
| 3 | **CO2 is a discrete gas molecule** O=C=O, while **SiO2 is a giant 3-D solid**. | pi bonding available to C, not to Si |
| 4 | Carbon has the **greatest tendency to catenate** (C-C = 348 kJ/mol). | Small size gives a strong, short C-C bond |
| 5 | `CCl4` is **not hydrolysed** by water, but `SiCl4` is hydrolysed at once. | No d orbitals on C to accept the lone pair of water |
| 6 | Carbon forms **millions** of compounds — the whole of organic chemistry. | Catenation + pi bonding + strong C-H bonds |
| 7 | Carbon exists in several **allotropic forms** (diamond, graphite, fullerene). | Different hybridisations are possible |
| 8 | Carbides of carbon differ: `CaC2` gives acetylene, but `Be2C` and `Al4C3` give methane. | Small size / high EN |

**WORKED EXAMPLE 4**

> *Q. Explain the anomalous behaviour of carbon. (4 marks)*

```
  MODEL ANSWER  (write the reasons first, then the consequences)

  Carbon, the first member of group 14, differs from the rest of the group
  for FOUR reasons:
      (i)   its very small atomic size (covalent radius 77 pm)
      (ii)  its high electronegativity (2.5)
      (iii) its high ionisation enthalpy (1086 kJ/mol)
      (iv)  the absence of d orbitals in its valence shell (n = 2)

  Because of these:
      1.  Its maximum covalency is 4. It cannot expand its octet, so ions
          such as [CF6]2- do not exist, although [SiF6]2- does.
      2.  It readily forms p(pi)-p(pi) multiple bonds with itself, with
          oxygen and with nitrogen. The heavier members do not.
      3.  CO2 is therefore a simple gaseous molecule (O=C=O) while SiO2
          is a giant covalent solid.
      4.  It shows the maximum tendency for catenation, forming long
          chains and rings - the basis of organic chemistry.
      5.  CCl4 is not hydrolysed by water whereas SiCl4 is, because carbon
          has no vacant d orbital to accept the lone pair of water.
      6.  It shows allotropy - diamond, graphite and fullerenes.
```

> **TRAP:** Write the **reasons** and the **consequences** separately. Many
> students write only "carbon is small" and lose three marks. Four reasons +
> four consequences = full marks.

# TOPIC 7 — CATENATION

## 7.1 Definition

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   CATENATION is the property of an element by which its own atoms    |
  |   link together through covalent bonds to form long straight         |
  |   chains, branched chains or closed rings.                           |
  |                                                                      |
  |   Carbon shows this property to the maximum extent of any element.   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  WHAT CATENATION LOOKS LIKE

     STRAIGHT CHAIN     C - C - C - C - C - C

                              C
                              |
     BRANCHED CHAIN     C - C - C - C
                              |
                              C

                          C - C
                        /       \
     RING               C         C
                        \       /
                          C - C
```

## 7.2 The order

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |     C   >>   Si   >   Ge   ~   Sn   >   Pb                           |
  |                                                                      |
  |   (Lead shows practically NO catenation at all.)                     |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 7.3 The reason — bond enthalpy is the whole answer

```
   M - M  BOND ENTHALPY  (kJ / mol)

      C - C     348      <-- very strong
      Si - Si   297
      Ge - Ge   260
      Sn - Sn   240
      Pb - Pb   weak / practically nil

   REASON FOR THE FALL:
       Going down the group the atoms get BIGGER.
       Bigger atoms -> the bonding orbitals overlap over a LONGER distance
                    -> the overlap is POORER
                    -> the M-M bond is LONGER and WEAKER
                    -> the chain breaks easily
                    -> catenation falls.
```

**Two more facts that earn marks:**

```
  1.  Carbon chains can be extremely long (thousands of atoms), silicon
      chains rarely go beyond about 6-8 atoms, and lead forms none.

  2.  Sulphur and phosphorus also catenate, but far less than carbon.
      So the correct statement is "carbon shows catenation to the
      MAXIMUM extent", not "only carbon catenates".
```

**WORKED EXAMPLE 5**

> *Q. What is catenation? Why does it decrease down group 14?*

```
  STEP 1 : Definition.
           Catenation is the self-linking of like atoms by covalent bonds
           to form chains and rings.

  STEP 2 : Order.
           C >> Si > Ge ~ Sn > Pb   (Pb: practically none)

  STEP 3 : The reason, with numbers.
           Catenation depends on the strength of the M-M bond.
              C-C  348 , Si-Si 297 , Ge-Ge 260 , Sn-Sn 240 kJ/mol
           Down the group the atomic size increases, the orbitals overlap
           poorly over the longer distance, so the M-M bond becomes
           longer and weaker and the chain cannot survive.

  STEP 4 : Consequence.
           This is why carbon alone gives millions of compounds and an
           entire branch of chemistry (organic chemistry).
```

> **TRAP:** The reason is **bond enthalpy / size**, not electronegativity and
> not "carbon is a non-metal". Always quote at least the two numbers
> C-C = 348 and Si-Si = 297 kJ/mol. Numbers impress examiners.

# TOPIC 8 — ALLOTROPY AND THE STRUCTURE OF DIAMOND

## 8.1 What is allotropy?

```
  ALLOTROPY = the existence of an element in TWO OR MORE different
              physical forms in the SAME physical state, the forms
              having different structures and properties.

  Each form is called an ALLOTROPE.

  CARBON'S ALLOTROPES
      CRYSTALLINE  :  DIAMOND , GRAPHITE , FULLERENES
      AMORPHOUS    :  coal, coke, charcoal, lampblack, carbon black
                      (these are really microcrystalline graphite)
```

## 8.2 DIAMOND — the structure

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   *  Each carbon atom is  sp3 HYBRIDISED.                            |
  |   *  It forms FOUR sigma bonds to FOUR other carbon atoms.           |
  |   *  The four bonds point to the corners of a REGULAR TETRAHEDRON.   |
  |   *  Bond angle = 109 degrees 28 minutes  (109.5 degrees)            |
  |   *  C - C bond length = 154 pm                                      |
  |   *  This repeats endlessly in three dimensions -> a GIANT COVALENT  |
  |      (network) SOLID. The whole crystal is one huge molecule.        |
  |   *  There are NO free electrons anywhere.                           |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
                    THE TETRAHEDRAL UNIT OF DIAMOND

                                  C
                                  |
                                  |  154 pm
                                  |
                                  C            all angles 109.5 degrees
                                / | \
                              /   |   \
                            /     |     \
                          C       C       C

              Now imagine EVERY one of those outer carbons is itself
              the centre of another identical tetrahedron ... forever.


                    THE 3-D NETWORK (a slice through it)

                 C-------C           C-------C
                /         \         /         \
               C           C-------C           C
                \         /         \         /
                 C-------C           C-------C
                /         \         /         \
               C           C-------C           C
                \         /         \         /
                 C-------C           C-------C

              Every line is a STRONG COVALENT SIGMA BOND.
              Every carbon uses all FOUR of its electrons.
```

## 8.3 The properties of diamond — and WHY

| PROPERTY | REASON |
|---|---|
| **Hardest known natural substance** (Mohs 10) | A rigid three-dimensional network of very strong C-C covalent bonds, all of the same length, extending through the whole crystal. To scratch it you must break covalent bonds. |
| **Very high melting point (~4373 K)** | Melting means breaking a huge number of strong covalent bonds. |
| **Does NOT conduct electricity** (insulator) | All four valence electrons of every carbon are locked into sigma bonds. There are no free or delocalised electrons to carry current. |
| **High density (3.51 g/cm3)** | Atoms are packed tightly in the 3-D network. |
| **Very high refractive index (2.42), sparkles** | Light entering is totally internally reflected many times before it escapes. |
| **Chemically inert, insoluble in everything** | The network is completely bonded; there is nothing to attack. |
| **Good conductor of HEAT** | The rigid lattice transmits vibrations extremely efficiently. |

## 8.4 Uses of diamond

```
  1.  As a GEMSTONE / jewellery  (because of its brilliance and hardness).
  2.  As an ABRASIVE - for cutting, grinding and polishing.
  3.  In DRILL BITS and rock-drilling tools for mining and oil wells.
  4.  In DIES for drawing thin metal wires.
  5.  For SHARPENING very hard tools and for cutting glass.
  6.  As a heat sink in some electronic devices (excellent thermal
      conductor but an electrical insulator).
```

> **TRAP:** "Diamond is hard because of strong covalent bonds" is only half
> the answer. Graphite has **even stronger** bonds inside its layers. The
> complete reason is **"a rigid THREE-DIMENSIONAL network of strong covalent
> bonds"** — it is the 3-D rigidity, not just the bond strength, that makes
> diamond hard.

# TOPIC 9 — GRAPHITE

## 9.1 The structure

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   *  Each carbon atom is  sp2 HYBRIDISED.                            |
  |   *  It forms THREE sigma bonds to three other carbons, in a FLAT    |
  |      plane, at 120 degrees.                                          |
  |   *  This gives endless flat sheets of HEXAGONS (like chicken wire). |
  |   *  C - C bond length INSIDE a layer = 141.5 pm                     |
  |      (SHORTER than diamond's 154 pm - so it has partial double bond  |
  |       character.)                                                    |
  |   *  The FOURTH electron of each carbon sits in an unhybridised      |
  |      p orbital perpendicular to the sheet. All of these overlap      |
  |      sideways to make a huge DELOCALISED pi CLOUD above and below    |
  |      each layer. These electrons are FREE TO MOVE.                   |
  |   *  The layers are stacked 340 pm apart and are held together only  |
  |      by WEAK VAN DER WAALS FORCES.                                   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
              ONE LAYER OF GRAPHITE  (view from above)

              C-------C           C-------C
             /         \         /         \
            C           C-------C           C
             \         /         \         /
              C-------C           C-------C
             /         \         /         \
            C           C-------C           C
             \         /         \         /
              C-------C           C-------C

            all bond angles = 120 degrees , C-C = 141.5 pm


              THE STACK OF LAYERS  (view from the side)

     layer 1  ====================================
                                                     ^
                     weak van der Waals forces       | 340 pm
                                                     v
     layer 2  ====================================

                     weak van der Waals forces

     layer 3  ====================================

     Each "====" is a strongly bonded sheet.
     The GAPS between the sheets are large and the forces across them
     are WEAK, so the sheets SLIDE over one another like a pack of cards.
```

```
              WHERE THE FREE ELECTRON LIVES

                 p orbital cloud  (above the sheet)
              ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
              ------------------------------------   the sigma-bonded sheet
              ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
                 p orbital cloud  (below the sheet)

              These delocalised electrons move freely ALONG the sheet
              -> graphite conducts electricity IN THE PLANE of the layers,
                 but very poorly PERPENDICULAR to them.
```

## 9.2 The properties of graphite — and WHY

| PROPERTY | REASON |
|---|---|
| **Soft, slippery, greasy to touch** | The layers are held only by weak van der Waals forces and slide over each other easily. |
| **Good conductor of electricity** | Each carbon has one delocalised electron in an unhybridised p orbital; these are free to move along the layer. |
| **Very high melting point** | Melting means breaking the strong covalent bonds inside the layers. |
| **Low density (2.22 g/cm3)** | The 340 pm gaps between layers make the structure open and airy. |
| **Grey-black with a metallic lustre, opaque** | The delocalised electrons absorb and re-emit visible light. |
| **Thermodynamically the MOST STABLE allotrope of carbon** | It is the reference form; the standard enthalpy of formation of graphite is taken as zero. |
| **Chemically more reactive than diamond** | The layers can be attacked at their edges and other atoms can slip between the layers. |

## 9.3 Uses of graphite

```
  1.  As a LUBRICANT for machinery working at high temperature, where oils
      would burn away.  (Because the layers slide.)
  2.  As ELECTRODES in dry cells and in electrolysis (e.g. the extraction
      of aluminium).  (Because it conducts and is chemically inert.)
  3.  In PENCIL "LEADS" - graphite mixed with clay. The layers rub off
      onto the paper.  (There is no lead in a pencil at all.)
  4.  As a MODERATOR in nuclear reactors - it slows down neutrons.
  5.  In making CRUCIBLES that must stand very high temperatures.
  6.  As black PIGMENT in paints and printing ink (carbon black).
```

**WORKED EXAMPLE 6**

> *Q. Diamond is the hardest substance known while graphite is one of the
> softest. Both are made only of carbon. Explain.*

```
  STEP 1 : Say that the difference is in the STRUCTURE, not the element.

  STEP 2 : DIAMOND.
           Every carbon is sp3 hybridised and joined by four strong sigma
           bonds to four others, tetrahedrally (109.5 degrees, 154 pm).
           This repeats in THREE DIMENSIONS, giving one rigid giant
           covalent network. To scratch it you must break covalent bonds
           in every direction. Hence it is extremely hard.

  STEP 3 : GRAPHITE.
           Every carbon is sp2 hybridised with three sigma bonds at 120
           degrees, giving flat hexagonal SHEETS (141.5 pm). The sheets
           are 340 pm apart and are held to each other only by WEAK VAN
           DER WAALS FORCES. So the sheets slide over one another very
           easily under a small force. Hence graphite is soft and
           slippery, and is used as a lubricant.

  STEP 4 : One-line conclusion.
           Diamond is hard because its bonding is 3-DIMENSIONAL ;
           graphite is soft because its strong bonding is only
           2-DIMENSIONAL and the sheets are loosely stacked.
```

**WORKED EXAMPLE 7**

> *Q. Graphite conducts electricity but diamond does not. Give reasons.*

```
  DIAMOND   Each carbon is sp3 hybridised and uses ALL FOUR of its
            valence electrons to form four sigma bonds. No electron is
            left over. There are NO free or mobile electrons, so no
            current can flow. Diamond is an INSULATOR.

  GRAPHITE  Each carbon is sp2 hybridised and uses only THREE electrons
            for sigma bonds. The FOURTH electron stays in an unhybridised
            p orbital perpendicular to the layer. All these p orbitals
            overlap sideways to form a DELOCALISED pi CLOUD spread over
            the whole layer. These electrons are MOBILE, so graphite
            CONDUCTS ELECTRICITY along the plane of its layers.
```

> **TRAP:** Graphite conducts **along** the layers, hardly at all across
> them. If the question says "explain the anisotropy" or "why does graphite
> conduct in only one direction", that is the point being tested.

# TOPIC 10 — FULLERENES

## 10.1 What they are

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   FULLERENES are cage-like, hollow, spherical molecules of carbon    |
  |   with the general formula Cn , where n is an even number            |
  |   (C60 , C70 , C76 , C84 ...).                                       |
  |                                                                      |
  |   The most famous is  C60 , called BUCKMINSTERFULLERENE or the       |
  |   "BUCKY BALL", named after the architect Buckminster Fuller whose   |
  |   geodesic domes it resembles.                                       |
  |                                                                      |
  |   ** FULLERENE IS THE ONLY PURE ALLOTROPE OF CARBON. **              |
  |      Reason: it is made only of closed rings, so there are NO        |
  |      "dangling" or unsatisfied bonds at any edge where impurity      |
  |      atoms could attach. Diamond and graphite both have edges with   |
  |      dangling bonds that pick up other atoms.                        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 10.2 How C60 is made (preparation)

```
  METHOD:  Heat GRAPHITE in an ELECTRIC ARC in an atmosphere of an INERT
           GAS (helium or argon).

  WHAT HAPPENS:
       The graphite vaporises. The vapour condenses to a SOOTY material
       which contains mainly C60 together with a smaller amount of C70
       and traces of larger fullerenes.

  SEPARATION:
       The soot is extracted with an organic solvent such as BENZENE or
       TOLUENE, in which C60 dissolves giving a MAGENTA (deep purple)
       solution. It is then separated by chromatography.

       graphite  --(electric arc, He or Ar)-->  sooty C60 + C70 + ...
```

## 10.3 The structure of C60

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   *  C60 contains  TWENTY  six-membered rings (hexagons)             |
  |            and    TWELVE  five-membered rings (pentagons).           |
  |                                                                      |
  |   *  Total faces = 32.  This is exactly the shape of a FOOTBALL      |
  |      (soccer ball). Hence "bucky ball".                              |
  |                                                                      |
  |   *  Each six-membered ring is fused to both hexagons and pentagons; |
  |      each five-membered ring is fused ONLY to hexagons.              |
  |                                                                      |
  |   *  ALL 60 CARBON ATOMS ARE EQUIVALENT. Each is sp2 HYBRIDISED,     |
  |      forming THREE sigma bonds to three neighbours.                  |
  |                                                                      |
  |   *  The remaining electron of each carbon goes into a delocalised   |
  |      molecular orbital -> the molecule has DELOCALISED pi electrons  |
  |      spread over the whole sphere -> aromatic character.             |
  |                                                                      |
  |   *  Bond lengths: 143.5 pm for the C-C bonds within a six-membered  |
  |      ring, and 138.3 pm at the ring fusions (6:6 junctions).         |
  |                                                                      |
  |   *  The sphere is about 700 pm (7 Angstrom) across and is HOLLOW.   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
                  C60 - THE BUCKY BALL (flattened sketch)

                            _.-'''''''-._
                        .-'   /-----\    '-.
                      .'     /       \      '.
                     /   ___/  HEX    \___    \
                    /   /   \         /   \    \
                   |   | PENT|--HEX--| PENT|    |
                   |    \___/         \___/     |
                   |     |    HEX       |       |
                   |    /   \         /   \     |
                    \  | PENT|--HEX--| PENT|   /
                     \  \___/         \___/   /
                      '.     \       /      .'
                        '-._  \-----/   _.-'
                            '''''''''

           20 HEXAGONS  +  12 PENTAGONS  =  32 faces , 60 carbon atoms
           Every carbon: sp2 , 3 sigma bonds , 1 delocalised electron

           MEMORY:  "a football has black pentagons and white hexagons -
                     C60 has 12 pentagons and 20 hexagons"
```

## 10.4 Properties and uses of fullerenes

```
  PROPERTIES
     *  It is a MOLECULAR solid (discrete C60 molecules held by weak van
        der Waals forces) - so it is SOFT, and it DISSOLVES in organic
        solvents such as benzene and toluene, giving a magenta solution.
        (Diamond and graphite dissolve in nothing.)
     *  It is a SEMICONDUCTOR. When doped with potassium, K3C60 becomes
        a SUPERCONDUCTOR at low temperature.
     *  It behaves as an ELECTRON-DEFICIENT ALKENE: it readily adds
        halogens, hydrogen and free radicals across its double bonds.
     *  It can trap other atoms or ions INSIDE its hollow cage.
     *  Density about 1.65 g/cm3 - much lower than diamond or graphite.

  USES
     *  In superconductor research (doped fullerides).
     *  As a lubricant - the balls act like microscopic ball bearings.
     *  In nanotechnology; related forms are carbon NANOTUBES.
     *  In medicine as a possible drug-delivery cage.
     *  As a catalyst and in organic photovoltaic (solar) cells.
```

> **TRAP:** Remember the numbers in the right order: **20 hexagons and
> 12 pentagons**, not the other way round. And the hybridisation is `sp2`
> (like graphite), **not** `sp3`. The atoms are not perfectly planar because
> the sheet is curved into a ball, so it is often described as "slightly
> pyramidalised sp2".

# TOPIC 12 — CHEMICAL REACTIVITY: OXYGEN, WATER AND HALOGENS

## 12.1 Reactivity towards OXYGEN

All group 14 elements form **two kinds of oxide**: a monoxide `MO` and a
dioxide `MO2`.

```
     C   +  O2 (excess)  --(burn)-->   CO2
   2 C   +  O2 (limited) --(burn)-->  2 CO
     Si  +  O2  --(1173 K)-->  SiO2
     Ge  +  O2  --(heat)-->    GeO2
     Sn  +  O2  --(heat)-->    SnO2
   2 Pb  +  O2  --(heat)-->   2 PbO      (lead gives the MONOXIDE)
```

**The acid-base character of these oxides is a favourite 2-mark question:**

```
  +--------+-----------+-----------------+-----------------------------+
  | OXIDE  |  STATE    |  CHARACTER      |  EVIDENCE                   |
  +--------+-----------+-----------------+-----------------------------+
  |  CO    |  MO       |  NEUTRAL        |  no reaction with acid/base |
  |  CO2   |  MO2      |  ACIDIC         |  CO2 + H2O -> H2CO3         |
  |  SiO2  |  MO2      |  ACIDIC         |  SiO2 + 2NaOH -> Na2SiO3    |
  |  GeO2  |  MO2      |  weakly ACIDIC /|  dissolves in alkali        |
  |        |           |  AMPHOTERIC     |                             |
  |  SnO2  |  MO2      |  AMPHOTERIC     |  reacts with acid AND base  |
  |  PbO2  |  MO2      |  AMPHOTERIC     |  reacts with acid AND base  |
  |  GeO   |  MO       |  AMPHOTERIC     |                             |
  |  SnO   |  MO       |  AMPHOTERIC     |                             |
  |  PbO   |  MO       |  AMPHOTERIC     |                             |
  +--------+-----------+-----------------+-----------------------------+

  TREND:   ACIDIC  ->  AMPHOTERIC  ->  (BASIC) as you go DOWN.
  REASON:  metallic character increases down the group, and metallic
           oxides are basic while non-metallic oxides are acidic.

  ALSO:  for the SAME element, MO2 is MORE ACIDIC than MO,
         because the higher oxidation state means a greater positive
         charge and a stronger pull on the oxide's electrons.
```

```
  PROOF THAT SnO2 AND PbO IS AMPHOTERIC (equations to quote)

      PbO  +  2 HNO3   -->   Pb(NO3)2  +  H2O            (acts as a BASE)
      PbO  +  2 NaOH   -->   Na2PbO2   +  H2O            (acts as an ACID)

      SnO2 +  2 NaOH  +  2 H2O  -->  Na2[Sn(OH)6]        (acts as an ACID)
```

## 12.2 Reactivity towards WATER

```
  +----------+-----------------------------------------------------------+
  |  CARBON  |  NO reaction with water in the cold.                      |
  |          |  But RED HOT COKE reacts with steam:                      |
  |          |      C + H2O --(1273 K)--> CO + H2   = ** WATER GAS **    |
  |          |      (also called SYNTHESIS GAS or SYN GAS)               |
  +----------+-----------------------------------------------------------+
  | SILICON  |  NOT attacked by water, acids or steam under ordinary     |
  |          |  conditions. It IS attacked by hot alkali:                |
  |          |      Si + 2NaOH + H2O --> Na2SiO3 + 2 H2                  |
  +----------+-----------------------------------------------------------+
  |GERMANIUM |  NOT attacked by water. Unaffected by dilute acids/alkali.|
  +----------+-----------------------------------------------------------+
  |   TIN    |  Not attacked by cold water, but decomposes STEAM:        |
  |          |      Sn + 2 H2O --(steam)--> SnO2 + 2 H2                  |
  +----------+-----------------------------------------------------------+
  |   LEAD   |  NOT attacked by water, because a thin protective layer   |
  |          |  of PbO (or basic lead carbonate in air) forms on the     |
  |          |  surface and stops any further attack.                    |
  +----------+-----------------------------------------------------------+
```

```
  THE TWO INDUSTRIAL GASES YOU MUST KNOW

      WATER GAS      C  +  H2O  --(steam over red hot coke, ~1273 K)-->
                     CO  +  H2            a MIXTURE of CO and H2

      PRODUCER GAS   2 C  +  O2  +  4 N2  --(air over red hot coke)-->
                     2 CO  +  4 N2        a MIXTURE of CO and N2

      Both are FUEL GASES. Water gas is also called SYNTHESIS GAS.
```

## 12.3 Reactivity towards HALOGENS

```
      M  +  2 X2   -->   MX4          (X = F , Cl , Br , I)

      C  + 2 Cl2 --(sunlight/heat)--> CCl4
      Si + 2 Cl2 --(heat)-->          SiCl4
      Sn + 2 Cl2 -->                  SnCl4
      Pb + Cl2  -->                   PbCl2    (only the DI-halide easily)
```

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   FACTS ABOUT THE TETRAHALIDES  MX4                                  |
  |                                                                      |
  |   1.  All MX4 are COVALENT, TETRAHEDRAL and sp3 hybridised.          |
  |   2.  They are mostly colourless liquids or low-melting solids       |
  |       (SnI4 and PbI2 are coloured).                                  |
  |   3.  Their stability FALLS down the group (inert pair effect):      |
  |            CX4 > SiX4 > GeX4 > SnX4 > PbX4                           |
  |   4.  PbCl4 exists but decomposes easily:                            |
  |            PbCl4 --(heat)--> PbCl2 + Cl2                             |
  |   5.  PbBr4 and PbI4 DO NOT EXIST AT ALL.                            |
  |       REASON: Pb4+ is strongly OXIDISING and Br- / I- are strongly   |
  |       REDUCING, so they would immediately react with each other:     |
  |            Pb4+  +  2 I-   -->   Pb2+  +  I2                         |
  |       (PbF4 and PbCl4 exist because F- and Cl- are hard to oxidise.) |
  |   6.  All MX4 except CX4 are HYDROLYSED by water.                    |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 12.4 *** THE STAR QUESTION: WHY IS CCl4 NOT HYDROLYSED BUT SiCl4 IS? ***

This is the most-asked 4-mark question in the chapter. Learn it word for word.

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE FACTS                                                          |
  |                                                                      |
  |      CCl4   +  H2O   -->   NO REACTION                               |
  |               (CCl4 does not even mix with water)                    |
  |                                                                      |
  |      SiCl4  +  4 H2O  -->  Si(OH)4  +  4 HCl                         |
  |               (violent, fumes of HCl ; Si(OH)4 is silicic acid,      |
  |                which then loses water to give hydrated silica)       |
  |                                                                      |
  |   THE REASON  -  IT IS ALL ABOUT VACANT d ORBITALS                   |
  |                                                                      |
  |   *  Hydrolysis begins when the LONE PAIR of the oxygen of a water   |
  |      molecule ATTACKS the central atom and forms a bond with it.     |
  |      For that, the central atom must have a VACANT ORBITAL of low    |
  |      energy to accept the lone pair.                                 |
  |                                                                      |
  |   *  CARBON is in period 2. Its valence shell (n = 2) has ONLY 2s    |
  |      and 2p orbitals - there is NO 2d subshell. In CCl4 all four     |
  |      of carbon's orbitals are already used. Carbon has NO vacant     |
  |      orbital to accept the water's lone pair, and it cannot expand   |
  |      its octet beyond 4. Also the carbon atom is small and is        |
  |      completely surrounded (sterically shielded) by four big Cl      |
  |      atoms. So water cannot attack, and CCl4 is NOT hydrolysed.      |
  |                                                                      |
  |   *  SILICON is in period 3. Its valence shell (n = 3) HAS empty     |
  |      3d ORBITALS. The oxygen lone pair of water can enter a vacant   |
  |      3d orbital, giving a 5- or 6-coordinate intermediate. Silicon   |
  |      can EXPAND ITS OCTET. Silicon is also bigger, so water can      |
  |      reach it. The Si-Cl bonds then break and SiCl4 is hydrolysed    |
  |      readily.                                                        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
              THE ATTACK, DRAWN OUT

     CCl4                              SiCl4

           Cl                                Cl
           |                                 |
     Cl -- C -- Cl                     Cl -- Si -- Cl
           |                                 |
           Cl                                Cl
                                             .
      H2O  X  BLOCKED                        .  <-- H2O lone pair enters
           (no vacant orbital,               .      a VACANT 3d ORBITAL
            octet cannot expand)            H2O
                                             |
                                             v
                                     Si(OH)4  +  4 HCl
```

**WORKED EXAMPLE 8**

> *Q. CCl4 is not hydrolysed by water but SiCl4 is readily hydrolysed. Give
> reasons. (4 marks)*

```
  1.  Both are covalent, tetrahedral, sp3 hybridised molecules.

  2.  Hydrolysis needs the lone pair of the oxygen of water to attack the
      central atom. The central atom must therefore have a vacant orbital
      to accept that lone pair, i.e. it must be able to expand its octet.

  3.  Carbon belongs to period 2. Its valence shell has only 2s and 2p
      orbitals - there are NO d ORBITALS. In CCl4 all four orbitals are
      used up, so carbon cannot accept the lone pair and cannot expand
      its covalency beyond 4. The small carbon atom is also completely
      screened by the four large chlorine atoms.
      Hence  CCl4 + H2O --> NO REACTION.

  4.  Silicon belongs to period 3 and HAS VACANT 3d ORBITALS. Water's
      lone pair enters a vacant 3d orbital, silicon expands its octet,
      and the Si-Cl bonds are broken.
      Hence  SiCl4 + 4 H2O --> Si(OH)4 + 4 HCl.

  5.  The same reasoning explains why [SiF6]2- exists but [CF6]2- does not.
```

> **TRAP:** Do not write "the C-Cl bond is stronger than the Si-Cl bond".
> That is false — Si-Cl is actually the stronger bond. The answer is
> **carbon has no vacant d orbital and cannot expand its octet.**

## 12.5 Hydrides (short but examinable)

```
      All group 14 elements form covalent hydrides MH4 (tetrahedral, sp3).

           CH4  methane      SiH4  silane      GeH4  germane
           SnH4 stannane     PbH4  plumbane (extremely unstable)

      STABILITY :   CH4  >  SiH4  >  GeH4  >  SnH4  >  PbH4
      REASON    :   the M-H bond gets longer and weaker as the atom grows.
                    (C-H 414 , Si-H 318 , Ge-H 285 , Sn-H 253 kJ/mol)

      REDUCING POWER of the hydride INCREASES down the group
      (the weaker the M-H bond, the more easily it gives up hydrogen).

      Carbon forms an ENORMOUS number of hydrides (all of organic
      chemistry). Silicon forms only a handful (up to about Si6H14),
      and lead forms essentially none. This is CATENATION again.
```

## 13.1 Preparation

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   IN THE LABORATORY - dehydration of formic acid                     |
  |                                                                      |
  |        HCOOH   --(conc. H2SO4 , 373 K)-->   CO  +  H2O               |
  |                                                                      |
  |        (conc. H2SO4 acts as a DEHYDRATING AGENT, removing water      |
  |         from formic acid. Oxalic acid may also be used, but it       |
  |         gives a mixture of CO and CO2.)                              |
  |                                                                      |
  |             H2C2O4 --(conc.H2SO4)--> CO + CO2 + H2O                  |
  |             (the CO2 is removed by passing through KOH solution)     |
  |                                                                      |
  |   COMMERCIALLY                                                       |
  |                                                                      |
  |     (a)  Incomplete combustion of carbon:                            |
  |               2 C  +  O2 (limited)  -->  2 CO                        |
  |                                                                      |
  |     (b)  WATER GAS - steam over red hot coke at ~1273 K:             |
  |               C  +  H2O  -->  CO  +  H2      (water gas / syn gas)   |
  |                                                                      |
  |     (c)  PRODUCER GAS - air over red hot coke:                       |
  |               2 C  +  O2  +  4 N2  -->  2 CO  +  4 N2                |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 13.2 Structure

```
      CO is written with a TRIPLE bond:      : C === O :

      One sigma bond + one pi bond are normal covalent bonds;
      the THIRD bond is a COORDINATE (dative) bond from oxygen to carbon.
      Both atoms then have a complete octet.

      C-O bond length in CO = 112.8 pm  (very short = very strong)
      CO has the HIGHEST bond dissociation enthalpy of any diatomic
      molecule except N2.
```

## 13.3 Properties

| PROPERTY | DETAIL |
|---|---|
| Physical | Colourless, odourless, tasteless gas |
| Solubility | Almost **insoluble** in water |
| Nature | **NEUTRAL** oxide (does not turn litmus) |
| Combustible | Burns with a **blue flame**: `2 CO + O2 --> 2 CO2` |
| Reducing agent | **Powerful reducer** — this is the key chemical property |
| Toxicity | **Highly poisonous** |
| Ligand | Forms metal carbonyls with transition metals |

```
  CO AS A REDUCING AGENT  (this is why it matters in metallurgy)

      Fe2O3   +  3 CO   --(blast furnace)-->   2 Fe   +  3 CO2
      ZnO     +  CO     --(heat)-->            Zn     +  CO2
      CuO     +  CO     --(heat)-->            Cu     +  CO2

  CO AS A LIGAND - metal carbonyls

      Ni  +  4 CO   --(330-350 K)-->   [Ni(CO)4]   nickel tetracarbonyl
                                        (used in the MOND PROCESS to
                                         purify nickel)
      Fe  +  5 CO   -->   [Fe(CO)5]    iron pentacarbonyl

  ESTIMATION OF CO  (a nice 2-mark fact)

      5 CO  +  I2O5   -->   I2  +  5 CO2
      (the iodine liberated is titrated, so CO can be measured)
```

## 13.4 *** WHY IS CARBON MONOXIDE POISONOUS? ***

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   1.  The blood carries oxygen using HAEMOGLOBIN. Oxygen binds to    |
  |       the iron of haemoglobin, forming OXYHAEMOGLOBIN.               |
  |                                                                      |
  |            Hb  +  O2   -->   HbO2      (OXYHAEMOGLOBIN)              |
  |                                                                      |
  |   2.  Carbon monoxide binds to the SAME iron site, forming           |
  |       CARBOXYHAEMOGLOBIN.                                            |
  |                                                                      |
  |            Hb  +  CO   -->   HbCO      (CARBOXYHAEMOGLOBIN)          |
  |                                                                      |
  |   3.  CARBOXYHAEMOGLOBIN IS ABOUT 300 TIMES MORE STABLE THAN         |
  |       OXYHAEMOGLOBIN.  So CO wins the competition and the binding    |
  |       is effectively IRREVERSIBLE.                                   |
  |                                                                      |
  |   4.  The haemoglobin is now blocked and can no longer carry oxygen  |
  |       to the tissues. The oxygen-carrying capacity of the blood      |
  |       collapses.                                                     |
  |                                                                      |
  |   5.  Result: headache, dizziness, unconsciousness, and death by     |
  |       ASPHYXIATION (suffocation) even though the person is           |
  |       breathing normally. CO is odourless, so there is no warning.   |
  |                                                                      |
  |   This is why a charcoal sigri, a car engine or a gas geyser must    |
  |   NEVER be used in a closed room.                                    |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 13.5 Uses of CO

```
  1.  As a REDUCING AGENT in the extraction of metals (blast furnace).
  2.  As a FUEL - as water gas and producer gas.
  3.  In the MOND PROCESS for purifying nickel, via Ni(CO)4.
  4.  In the manufacture of METHANOL:  CO + 2 H2 --(ZnO/Cr2O3)--> CH3OH
  5.  In the synthesis of many organic chemicals (the "oxo" process).
```

> **TRAP:** CO is a **neutral** oxide, not acidic. It does not turn moist
> blue litmus red. Only CO2 does that. And CO is **insoluble** in water —
> do not write that it dissolves to give an acid.

## 14.1 Preparation

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   IN THE LABORATORY                                                  |
  |                                                                      |
  |     CaCO3  +  2 HCl (dil.)  -->  CaCl2  +  H2O  +  CO2               |
  |                                                                      |
  |     (marble chips + dilute hydrochloric acid, in a Kipp's apparatus) |
  |                                                                      |
  |   BY COMPLETE COMBUSTION                                             |
  |                                                                      |
  |     C  +  O2  -->  CO2                                               |
  |     CH4 + 2 O2 --> CO2 + 2 H2O    (any hydrocarbon burnt in excess   |
  |                                    oxygen gives CO2)                 |
  |                                                                      |
  |   COMMERCIALLY - by heating limestone                                |
  |                                                                      |
  |     CaCO3   --(1000-1200 K)-->   CaO  +  CO2                         |
  |                                                                      |
  |   BY FERMENTATION (a by-product of the brewing industry)             |
  |                                                                      |
  |     C6H12O6  --(zymase)-->  2 C2H5OH  +  2 CO2                       |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 14.2 Structure of CO2 — a favourite 2-marker

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |     *  CO2 is a LINEAR molecule.                                     |
  |     *  Carbon is  sp HYBRIDISED  (2 sigma bonds, 2 pi bonds).        |
  |     *  Bond angle O-C-O = 180 degrees                                |
  |     *  It is NON-POLAR overall, because the two equal C=O dipoles    |
  |        point in exactly opposite directions and cancel.              |
  |     *  Observed C-O bond length = 115 pm. This is SHORTER than the   |
  |        expected C=O double bond length, which shows RESONANCE.       |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
              THE STRUCTURE AND ITS RESONANCE

                     O === C === O           (the main structure)
                             |
                          180 degrees, linear, sp hybridised


              RESONANCE STRUCTURES

           O === C === O   <-->   (-)O - C === O(+)   <-->  (+)O === C - O(-)

           The real molecule is a RESONANCE HYBRID of these three.
           Because of resonance the C-O bond has partial triple-bond
           character, so it is SHORTER (115 pm) and STRONGER than a
           pure C=O double bond.
```

## 14.3 Properties

| PROPERTY | DETAIL |
|---|---|
| Physical | Colourless, odourless gas; heavier than air |
| In the atmosphere | About **0.03 % by volume** |
| Solubility | Slightly soluble; the solution is weakly acidic |
| Nature | **ACIDIC oxide** |
| Combustion | Does not burn and does not support burning |
| Solid form | **DRY ICE** — solid CO2, which **sublimes** at 195 K |
| Lime water test | Turns lime water **milky** |

```
  THE KEY REACTIONS

  1.  WITH WATER  -  forms carbonic acid, a WEAK DIBASIC acid

          CO2  +  H2O   <-->   H2CO3
          H2CO3  <-->  H+ + HCO3-   <-->  2 H+ + CO3 2-

  2.  THE LIME WATER TEST  (learn both halves)

          CO2  +  Ca(OH)2   -->   CaCO3 (white, MILKY)  +  H2O
          CaCO3  +  H2O  +  CO2 (excess)  -->  Ca(HCO3)2 (soluble, CLEAR)

          So lime water first turns MILKY and then the milkiness
          DISAPPEARS when excess CO2 is passed. That double behaviour is
          the complete test.

  3.  WITH ALKALI

          CO2  +  2 NaOH   -->   Na2CO3  +  H2O
          CO2 (excess) + NaOH  -->  NaHCO3

  4.  PHOTOSYNTHESIS - how green plants remove it

          6 CO2  +  12 H2O  --(chlorophyll, sunlight)-->
                                  C6H12O6  +  6 H2O  +  6 O2

  5.  WITH MAGNESIUM  -  CO2 does NOT put out a burning Mg ribbon

          2 Mg  +  CO2   -->   2 MgO  +  C
          (this is why a CO2 extinguisher must not be used on burning Mg)
```

## 14.4 *** THE GREENHOUSE EFFECT AND GLOBAL WARMING ***

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   HOW A GREENHOUSE WORKS (the analogy)                               |
  |                                                                      |
  |   A glass greenhouse lets the sun's short-wavelength light IN but    |
  |   does not let the long-wavelength heat radiated by the plants and   |
  |   soil OUT. So the inside gets hotter than the outside.              |
  |                                                                      |
  |   THE ATMOSPHERE DOES THE SAME THING                                 |
  |                                                                      |
  |                       SUN                                            |
  |                        |                                             |
  |                short-wave radiation passes straight through          |
  |                        |                                             |
  |                        v                                             |
  |     ~~~~~~~~~~~~~~ CO2 layer ~~~~~~~~~~~~~~~~~~~~                    |
  |          ^             |            ^                                |
  |          |             v            |                                |
  |    heat REFLECTED  EARTH SURFACE  heat radiated back                 |
  |    BACK DOWN       warms up and   as long-wave INFRA-RED             |
  |    -> earth gets   radiates heat  -> ABSORBED BY CO2                 |
  |       hotter                                                         |
  |                                                                      |
  |   MECHANISM IN WORDS                                                 |
  |     1.  Short-wave solar radiation passes freely through CO2 and     |
  |         reaches the earth's surface.                                 |
  |     2.  The warm earth re-radiates the energy as LONG-WAVELENGTH     |
  |         INFRARED radiation.                                          |
  |     3.  CO2 molecules ABSORB this infrared radiation strongly and    |
  |         re-emit part of it back towards the earth.                   |
  |     4.  Heat is therefore TRAPPED near the surface and the average   |
  |         temperature of the earth rises. This trapping is the         |
  |         GREENHOUSE EFFECT, and the rise in temperature is called     |
  |         GLOBAL WARMING.                                              |
  |                                                                      |
  |   OTHER GREENHOUSE GASES: methane (CH4), water vapour, nitrous       |
  |   oxide (N2O), CFCs, ozone.                                          |
  |                                                                      |
  |   WHY CO2 IS RISING                                                  |
  |     *  burning of FOSSIL FUELS (coal, petrol, diesel, natural gas)   |
  |     *  DEFORESTATION - fewer trees to absorb CO2 by photosynthesis   |
  |     *  cement manufacture and other industry                         |
  |                                                                      |
  |   CONSEQUENCES                                                       |
  |     *  melting of polar ice caps and glaciers                        |
  |     *  rise in sea level, flooding of coastal cities                 |
  |     *  changed rainfall patterns, droughts, crop failure             |
  |     *  more extreme weather                                          |
  |                                                                      |
  |   NOTE: a NORMAL greenhouse effect is NECESSARY - without it the     |
  |   earth would be about 33 degrees colder and lifeless. The problem   |
  |   is the ENHANCED greenhouse effect caused by human activity.        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 14.5 Uses of CO2

```
  1.  As a FIRE EXTINGUISHER. It is heavier than air and does not
      support combustion, so it blankets the fire and cuts off oxygen.
      (Not for burning magnesium or electrical-plus-metal fires.)
  2.  DRY ICE (solid CO2) as a REFRIGERANT for ice cream, frozen food
      and transporting medicines. It sublimes, so it leaves no liquid.
  3.  In AERATED SOFT DRINKS and soda water.
  4.  In the manufacture of UREA:
          2 NH3  +  CO2  --(heat, pressure)-->  NH2CONH2  +  H2O
  5.  In the SOLVAY process for making sodium carbonate.
  6.  In fire-fighting foams and in welding as a shielding gas.
  7.  It is essential for PHOTOSYNTHESIS - the source of all food.
```

> **TRAP:** "Dry ice" is solid **CO2**, not ice made from water and not

# TOPIC 15 — SILICON DIOXIDE (SILICA), SiO2

## 15.1 Occurrence and structure

```
  SiO2 occurs naturally as QUARTZ, CRISTOBALITE and TRIDYMITE, and as
  sand, flint and agate. It makes up about 95 % of the rocks of the crust.
```

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE STRUCTURE OF SILICA                                            |
  |                                                                      |
  |   *  Each silicon atom is  sp3 HYBRIDISED  and is bonded             |
  |      COVALENTLY to FOUR oxygen atoms arranged TETRAHEDRALLY.         |
  |                                                                      |
  |   *  EACH OXYGEN ATOM IS SHARED BETWEEN TWO SILICON TETRAHEDRA       |
  |      (it acts as a bridge, Si - O - Si).                             |
  |                                                                      |
  |   *  So each silicon really "owns" only 4 x 1/2 = 2 oxygens.         |
  |      That is why the formula comes out as SiO2.                      |
  |                                                                      |
  |   *  The tetrahedra link up in all directions -> a GIANT COVALENT    |
  |      THREE-DIMENSIONAL NETWORK. The whole crystal is one molecule.   |
  |                                                                      |
  |   *  Si-O bond length about 161 pm ; the Si-O bond is very strong.   |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
                    A SLICE THROUGH THE SILICA NETWORK

                O           O           O
                |           |           |
           O -- Si -- O -- Si -- O -- Si -- O
                |           |           |
                O           O           O
                |           |           |
           O -- Si -- O -- Si -- O -- Si -- O
                |           |           |
                O           O           O

           Every Si is at the centre of a tetrahedron of 4 O.
           Every O is a BRIDGE joining 2 Si atoms.
           This continues in THREE dimensions, endlessly.
```

## 15.2 *** WHY IS CO2 A GAS BUT SiO2 A HARD SOLID? ***

Another guaranteed question. Both are `MO2` oxides of the same group.

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   CO2                                                                |
  |   *  Carbon is SMALL (77 pm). Its 2p orbital can overlap SIDEWAYS    |
  |      effectively with the 2p orbital of oxygen.                      |
  |   *  So carbon forms strong  p(pi)-p(pi) DOUBLE BONDS with oxygen.   |
  |   *  Carbon's valency is completely satisfied inside a single small  |
  |      molecule:   O = C = O                                           |
  |   *  These discrete molecules are held to each other only by very    |
  |      WEAK VAN DER WAALS FORCES.                                      |
  |   *  Therefore CO2 is a GAS at room temperature, with a very low     |
  |      sublimation point (195 K).                                      |
  |                                                                      |
  |   SiO2                                                               |
  |   *  Silicon is LARGE (118 pm) and its 3p orbitals are diffuse. The  |
  |      sideways overlap with oxygen's small 2p orbital is very POOR.   |
  |   *  So silicon CANNOT form p(pi)-p(pi) double bonds with oxygen.    |
  |   *  Instead silicon satisfies its valency by forming FOUR SINGLE    |
  |      SIGMA BONDS to four oxygens, and each oxygen bridges to another |
  |      silicon.                                                        |
  |   *  This produces a GIANT THREE-DIMENSIONAL COVALENT NETWORK.       |
  |   *  Melting it means breaking millions of strong Si-O bonds.        |
  |   *  Therefore SiO2 is a HARD, HIGH-MELTING SOLID (m.p. ~1996 K).    |
  |                                                                      |
  |   ONE-LINE ANSWER:                                                   |
  |   Carbon forms p(pi)-p(pi) multiple bonds and gives discrete O=C=O   |
  |   molecules ; silicon cannot, so it forms a giant 3-D network of     |
  |   single Si-O bonds.                                                 |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
       CO2                              SiO2

    O = C = O    O = C = O                O       O
                                          |       |
       weak van der Waals            O -- Si -- O -- Si -- O
                                          |       |
    O = C = O    O = C = O                O       O

    small separate MOLECULES         one ENDLESS NETWORK
    -> GAS                           -> HARD HIGH-MELTING SOLID
```

## 15.3 Properties of silica

```
  *  Very HARD, high melting (about 1996 K), insoluble in water.
  *  Chemically very UNREACTIVE - it resists all acids EXCEPT HF.
  *  It is an ACIDIC oxide - it reacts with hot alkali and with
     basic oxides at high temperature.

         SiO2  +  4 HF     -->   SiF4   +  2 H2O
              (this is why HF is stored in wax or plastic bottles,
               NEVER in glass - it eats the glass)

         SiO2  +  2 NaOH   --(fused)-->   Na2SiO3  +  H2O

         SiO2  +  CaO      --(high temp)-->  CaSiO3
              (this is the slag-forming reaction in the blast furnace)

         SiO2  +  2 C      --(electric furnace)-->  Si  +  2 CO
              (manufacture of silicon)

         SiO2  +  3 C      --(2000 K)-->  SiC  +  2 CO
              (SiC = CARBORUNDUM, an extremely hard abrasive)
```

## 15.4 Uses of silica

```
  1.  QUARTZ is PIEZOELECTRIC - it is used in quartz watches, clocks,
      radio oscillators and ultrasound generators.
  2.  SILICA GEL is a powerful DRYING AGENT (desiccant) and an
      adsorbent in chromatography. (Those little sachets in shoe boxes.)
  3.  In making GLASS, CEMENT, ceramics, porcelain and refractory bricks.
  4.  KIESELGUHR (a form of silica) is used in filtration and as the
      absorbent in dynamite.
  5.  Fused quartz / silica glass is used for optical fibres, laboratory
      apparatus and UV lamps, because it stands sudden temperature
      changes and passes ultraviolet light.
  6.  Pure silicon obtained from silica is used to make semiconductor
      chips and solar cells.
```

# TOPIC 16 — SILICONES

## 16.1 What they are

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   SILICONES are ORGANOSILICON POLYMERS containing a backbone of      |
  |   alternating SILICON and OXYGEN atoms, with organic (alkyl or       |
  |   aryl) groups attached to each silicon.                             |
  |                                                                      |
  |   The repeating unit is  ( R2 Si O )  - which is the same empirical  |
  |   formula as a KETONE (R2CO), and that is why they were named        |
  |   "silicones".                                                       |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## 16.2 Preparation — the two steps

```
  STEP 1 : MAKE THE ALKYL CHLOROSILANES (Grignard route)

      RMgCl  +  SiCl4   -->   RSiCl3   +  MgCl2
      RMgCl  +  RSiCl3  -->   R2SiCl2  +  MgCl2
      RMgCl  +  R2SiCl2 -->   R3SiCl   +  MgCl2
      RMgCl  +  R3SiCl  -->   R4Si     +  MgCl2

      (Industrially the DIRECT PROCESS is used instead:
           2 CH3Cl  +  Si  --(Cu, 570 K)-->  (CH3)2SiCl2 )

  STEP 2 : HYDROLYSE AND LET IT POLYMERISE (condense)

      R2SiCl2  +  2 H2O   -->   R2Si(OH)2  +  2 HCl
      The R2Si(OH)2 units then CONDENSE, losing water, and join up into
      a long chain.
```

```
  THE OVERALL EQUATION TO WRITE IN THE EXAM

      n R2SiCl2  +  n H2O   -->   [ -O-SiR2- ]n   +  2n HCl
                                     LINEAR SILICONE
```

## 16.3 Structure — and how the chain length is controlled

```
              LINEAR SILICONE  (from R2SiCl2)

              R     R     R     R
              |     |     |     |
        ... - Si -O-Si -O-Si -O-Si - O - ...
              |     |     |     |
              R     R     R     R

              (R is usually CH3 - methyl)


              CHAIN TERMINATION  (add R3SiCl)

              R     R     R     R           R
              |     |     |     |           |
         R -  Si -O-Si -O-Si -O-Si - O -Si- R      <-- capped at both ends
              |     |     |     |           |
              R     R     R     R           R

         R3SiCl gives only ONE Si-OH on hydrolysis, so it can join at
         only one end. It BLOCKS the chain and fixes its length.
         MORE R3SiCl -> SHORTER chains -> thinner silicone OIL.
         LESS R3SiCl -> LONGER chains  -> thicker GREASE or RUBBER.


              CROSS-LINKED / SHEET SILICONE  (from RSiCl3)

              R           R
              |           |
         -O - Si - O -    Si - O-
              |           |
              O           O
              |           |
         -O - Si - O -    Si - O-
              |           |
              R           R

         RSiCl3 gives THREE Si-OH groups, so it can branch in three
         directions -> a rigid cross-linked RESIN.


   SUMMARY OF WHAT EACH STARTING MATERIAL GIVES
   +-----------+---------------------+----------------------------------+
   | R3SiCl    | one -OH after       | CHAIN STOPPER (end cap)          |
   |           | hydrolysis          |                                  |
   | R2SiCl2   | two -OH             | LINEAR chain polymer             |
   | RSiCl3    | three -OH           | CROSS-LINKED / sheet resin       |
   | SiCl4     | four -OH            | fully 3-D network                |
   +-----------+---------------------+----------------------------------+
```

## 16.4 Properties of silicones

```
  1.  Chemically VERY INERT - resistant to acids, alkalis, oxidation
      and most chemicals.
  2.  THERMALLY STABLE - they stand very high temperatures without
      decomposing (the Si-O bond is extremely strong, about 452 kJ/mol).
  3.  WATER-REPELLENT (hydrophobic) - the outward-facing methyl groups
      hate water.
  4.  Excellent ELECTRICAL INSULATORS.
  5.  Their viscosity hardly changes with temperature - they stay
      usable as lubricants from very cold to very hot.
  6.  NON-TOXIC and biologically compatible.
```

## 16.5 Uses of silicones

```
  1.  As high-temperature LUBRICANTS and greases (in aircraft, engines).
  2.  As ELECTRICAL INSULATORS for motors and transformers.
  3.  For WATERPROOFING fabrics, paper, leather and building materials.
  4.  Mixed into PAINTS and ENAMELS to make them resist heat and damp.
  5.  As SEALANTS in bathrooms and windows, and as adhesives.
  6.  In SURGICAL and COSMETIC IMPLANTS, contact lenses and artificial
      heart valves (because they are non-toxic and inert).
  7.  As silicone RUBBER, which stays flexible over a huge temperature
      range; and as anti-foaming agents and mould-release agents.
```

  1.  DEFINITION. Silicones are organosilicon polymers with a backbone of

# TOPIC 17 — SILICATES

## 17.1 The basic structural unit

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   THE BASIC STRUCTURAL UNIT OF ALL SILICATES IS THE                  |
  |                                                                      |
  |            [ SiO4 ] 4-   TETRAHEDRON                                 |
  |                                                                      |
  |   *  One silicon atom at the centre.                                 |
  |   *  Four oxygen atoms at the corners of a regular tetrahedron.      |
  |   *  Si is sp3 hybridised ; the O-Si-O angle is 109.5 degrees.       |
  |   *  Each oxygen carries one unit of negative charge, so the whole   |
  |      unit has a charge of  4- .                                      |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
                 THE  SiO4 4-  TETRAHEDRON

                          O(-)
                           |
                           |
                           Si
                         / | \
                       /   |   \
                     /     |     \
                 O(-)    O(-)    O(-)

            All four Si-O bonds equal. Charge = 4- overall.
```

## 17.2 How silicates are built — by SHARING CORNERS

```
  A silicate is formed when SiO4 4- tetrahedra SHARE THEIR CORNER OXYGEN
  ATOMS with each other. How MANY corners are shared decides the shape.
```

| SHARED CORNERS | TYPE | ANION | EXAMPLE MINERAL |
|---|---|---|---|
| 0 (none) | **Ortho**silicate (discrete) | `SiO4 4-` | Zircon `ZrSiO4`, olivine, willemite |
| 1 | **Pyro**silicate | `Si2O7 6-` | Thortveitite `Sc2Si2O7` |
| 2 | **Cyclic (ring)** silicate | `(SiO3)n 2n-` | Beryl `Be3Al2Si6O18` |
| 2 | **Chain** silicate (pyroxene) | `(SiO3)n 2n-` | Spodumene `LiAl(SiO3)2` |
| 2 and 3 alternating | **Double chain** (amphibole) | `(Si4O11)n 6n-` | **Asbestos** |
| 3 | **Sheet / layer** silicate | `(Si2O5)n 2n-` | **Talc, mica, clay, kaolin** |
| 4 (all) | **Three-dimensional** silicate | `SiO2` (neutral) | **Quartz, feldspar, zeolites** |

```
              PICTURES OF THE MAIN TYPES

  ORTHOSILICATE (no sharing)          PYROSILICATE (one corner shared)

        O                                   O           O
        |                                   |           |
    O - Si - O                          O - Si -- O -- Si - O
        |                                   |           |
        O                                   O           O
    [SiO4]4- , separate                 [Si2O7]6-


  CHAIN SILICATE (two corners shared)

        O     O     O     O
        |     |     |     |
    - Si -O- Si -O- Si -O- Si -            an endless single chain
        |     |     |     |                (SiO3)n 2n-
        O     O     O     O


  SHEET SILICATE (three corners shared)

        O     O     O
        |     |     |
    - Si -O- Si -O- Si -
        |     |     |
        O     O     O          the sheets stack loosely -> that is why
        |     |     |          TALC and MICA flake and feel slippery
    - Si -O- Si -O- Si -       (Si2O5)n 2n-
        |     |     |
        O     O     O


  THREE-DIMENSIONAL (all four corners shared)

        Every oxygen bridges two silicons -> the charge disappears ->
        the formula becomes neutral SiO2 -> QUARTZ.
```

```
  A USEFUL MEMORY LINE

      MORE corners shared  ->  LESS negative charge  ->  bigger structure

           0 shared  ->  4-  per Si   ->  separate ions
           1 shared  ->  3-  per Si   ->  pairs
           2 shared  ->  2-  per Si   ->  chains and rings
           3 shared  ->  1-  per Si   ->  sheets
           4 shared  ->  0            ->  3-D network = SiO2
```

## 17.3 Charge balance

```
  The negative charge on a silicate anion is balanced by METAL CATIONS
  such as Na+, K+, Mg2+, Ca2+, Al3+ and Fe2+ sitting in the gaps.

  Example: ZrSiO4 = Zr4+ balancing one SiO4 4- unit.
```

> **TRAP:** The basic unit is `SiO4` **4-**, tetrahedral — not `SiO3` and not
> planar. Asbestos is a **double chain** silicate. Mica and talc are **sheet**
> silicates (that is why they peel and feel soapy). Learn those three
> examples; they are the ones asked.

# TOPIC 18 — ZEOLITES

## 18.1 What they are

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   ZEOLITES are THREE-DIMENSIONAL ALUMINOSILICATES formed when SOME   |
  |   of the silicon atoms of a 3-D silicate framework are REPLACED BY   |
  |   ALUMINIUM atoms.                                                   |
  |                                                                      |
  |   *  Each Si4+ replaced by Al3+ leaves the framework with ONE UNIT   |
  |      OF NEGATIVE CHARGE (an [AlO4]5- unit in place of SiO4 4-).      |
  |                                                                      |
  |   *  This charge is balanced by CATIONS such as Na+, K+ or Ca2+      |
  |      sitting LOOSELY inside the framework - they are not part of it. |
  |                                                                      |
  |   *  The framework is HONEYCOMBED with CAVITIES and CHANNELS of a    |
  |      definite, uniform size, which water and small molecules can     |
  |      enter and leave.                                                |
  |                                                                      |
  |   *  General formula:  Mx/n [(AlO2)x (SiO2)y] . z H2O                |
  |                                                                      |
  |   *  The name means "boiling stone" (Greek zeo = boil, lithos =      |
  |      stone), because the trapped water froths out on heating.        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
              THE ZEOLITE FRAMEWORK (a cartoon)

           O       O       O       O
           |       |       |       |
      -O- Si -O-  Al -O-  Si -O-  Al -O-
           |       |(-)    |       |(-)
           O       O       O       O
             \    /   \    /   \  /
              CAVITY   CHANNEL   CAVITY
              (Na+)     (H2O)     (Ca2+)
             /    \   /    \   /  \
           O       O       O       O
           |       |(-)    |       |(-)
      -O- Si -O-  Al -O-  Si -O-  Al -O-
           |       |       |       |
           O       O       O       O

      Rigid framework  +  loosely held cations  +  open pores
      = catalyst + ion exchanger + molecular sieve
```

## 18.2 The three uses — and why each works

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   USE 1 :  AS CATALYSTS (shape-selective catalysis)                  |
  |                                                                      |
  |   The pores are of a FIXED size, so only molecules of the right      |
  |   size and shape can get in and react. This is called SHAPE          |
  |   SELECTIVE CATALYSIS.                                               |
  |     *  ZSM-5 converts ALCOHOLS DIRECTLY INTO GASOLINE (petrol) by    |
  |        dehydrating them to a mixture of hydrocarbons.                |
  |     *  Zeolites are used for the CRACKING of heavy hydrocarbons and  |
  |        for ISOMERISATION in the petrochemical industry.              |
  |                                                                      |
  |   USE 2 :  AS ION EXCHANGERS - SOFTENING HARD WATER                  |
  |                                                                      |
  |   The Na+ ions inside the cavities are held loosely and can swap     |
  |   with the Ca2+ and Mg2+ ions that make water hard.                  |
  |                                                                      |
  |        Na2Z  +  Ca2+   -->   CaZ  +  2 Na+        (Z = zeolite)      |
  |        Na2Z  +  Mg2+   -->   MgZ  +  2 Na+                           |
  |                                                                      |
  |   The exhausted zeolite is REGENERATED by washing with brine:        |
  |        CaZ  +  2 NaCl  -->  Na2Z  +  CaCl2                           |
  |                                                                      |
  |   The hydrated sodium aluminosilicate used this way is called        |
  |   PERMUTIT.  Zeolites are also added to DETERGENTS as builders,      |
  |   in place of phosphates.                                            |
  |                                                                      |
  |   USE 3 :  AS MOLECULAR SIEVES / DRYING AGENTS                       |
  |                                                                      |
  |   Because the pores are all exactly the same size, a zeolite lets    |
  |   SMALL molecules in and keeps LARGE ones out. It therefore          |
  |   SEPARATES mixtures by molecular size and is used to DRY gases      |
  |   and solvents (water molecules are small and get trapped).          |
  |                                                                      |
  +----------------------------------------------------------------------+
```

> **TRAP:** A zeolite is an **aluminosilicate**, not a pure silicate. The
> negative charge comes from replacing Si(IV) by Al(III). And "shape
> selective catalysis" is the phrase the examiner wants — use it.

# THE TEN SENTENCES THAT EARN THE MOST MARKS

```
  1.  General configuration of group 14 = ns2 np2 ; C non-metal,
      Si and Ge metalloids, Sn and Pb metals.

  2.  Down the group: size UP, IE DOWN, EN DOWN, m.p. DOWN,
      metallic character UP, catenation DOWN.

  3.  Inert pair effect = reluctance of the ns2 pair to bond, caused by
      poor shielding by d and f electrons -> +2 more stable down the
      group -> PbO2 oxidises, SnCl2 reduces.

  4.  Carbon is anomalous because it is small, highly electronegative,
      has a high IE and HAS NO d ORBITALS.

  5.  Catenation order C >> Si > Ge ~ Sn > Pb, because the M-M bond
      enthalpy falls (C-C 348, Si-Si 297 kJ/mol).

  6.  Diamond: sp3, 3-D network, hardest, insulator.
      Graphite: sp2, layers 340 pm apart, soft lubricant, conductor.
      Fullerene C60: sp2, 20 hexagons + 12 pentagons, only PURE allotrope.

  7.  CCl4 is not hydrolysed because carbon has no vacant d orbital;
      SiCl4 is hydrolysed because silicon has vacant 3d orbitals.

  8.  CO is poisonous because carboxyhaemoglobin is about 300 times more
      stable than oxyhaemoglobin, so the blood cannot carry oxygen.

  9.  CO2 is a linear gas because carbon forms p(pi)-p(pi) double bonds;
      SiO2 is a giant solid because silicon cannot.

 10.  Zeolites are aluminosilicates used as shape-selective catalysts
      (ZSM-5, alcohol to gasoline), ion exchangers (water softening)
      and molecular sieves.
```
