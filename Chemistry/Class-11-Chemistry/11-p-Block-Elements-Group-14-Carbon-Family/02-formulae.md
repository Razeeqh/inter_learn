# 3. TRENDS — the direction AND the reason

| PROPERTY | DIRECTION DOWN THE GROUP | REASON |
|---|---|---|
| Atomic / covalent radius | **INCREASES** | A new shell is added each period |
| Ionic radius | INCREASES | Same reason |
| Ionisation enthalpy | **DECREASES** (Pb > Sn is the exception) | Bigger atom, outer electron farther away and better shielded |
| Electronegativity | DECREASES sharply C to Si, then almost constant | Carbon is very small so it pulls electrons hardest |
| Melting / boiling point | **DECREASES** (Pb > Sn is the exception) | Giant covalent network (C, Si, Ge) gives way to weaker metallic bonding (Sn, Pb); bonds also lengthen |
| Density | INCREASES | Atomic mass rises faster than atomic volume |
| Metallic character | **INCREASES** | IE falls, so electrons are lost more easily |
| Catenation | **DECREASES** | M-M bond enthalpy falls as atoms grow |
| Stability of +4 state | DECREASES | Inert pair effect |
| Stability of +2 state | **INCREASES** | Inert pair effect |
| Stability of hydride MH4 | DECREASES | M-H bond gets longer and weaker |
| Reducing power of MH4 | INCREASES | Weaker M-H bond gives up H more easily |
| Acidic character of oxide MO2 | DECREASES (acidic -> amphoteric) | Metallic character rises |
| Oxidising power of M(IV) | INCREASES | +4 becomes unstable at the bottom |
| Reducing power of M(II) | DECREASES | +2 becomes stable at the bottom |

```
  COMPARISON WITH GROUP 13 (worth a mark in a general question)

      Group 14 atoms are SMALLER than group 13 atoms of the same period.
      Group 14 IEs are HIGHER than group 13 IEs.
      REASON: higher nuclear charge across the period.
```

# 4. OXIDATION STATES AND THE INERT PAIR EFFECT

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   INERT PAIR EFFECT                                                  |
  |                                                                      |
  |   DEFINITION : the reluctance of the ns2 electron pair to take part  |
  |                in bond formation, which increases down a p-block     |
  |                group, making the LOWER oxidation state more stable.  |
  |                                                                      |
  |   CAUSE      : filled d (3d10, 4d10, 5d10) and f (4f14) subshells    |
  |                shield the nuclear charge POORLY, so the ns2 pair is  |
  |                held very tightly and is not available for bonding.   |
  |                Promoting an ns electron to np costs too much energy. |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| ELEMENT | STABLE STATE | UNSTABLE STATE | BEHAVIOUR |
|---|---|---|---|
| C | +4 | +2 (CO only) | CO is a strong **reducing agent** |
| Si | +4 | +2 | Si(II) is very rare |
| Ge | +4 | +2 | Ge(II) is a **reducing agent** |
| Sn | +4 | +2 | Sn(II), e.g. `SnCl2`, is a good **reducing agent** |
| Pb | **+2** | +4 | Pb(IV), e.g. `PbO2`, is a strong **oxidising agent** |

```
  STABILITY ORDERS TO MEMORISE

      DIHALIDES     :   GeX2  <  SnX2  <  PbX2      (stability INCREASES)
      TETRAHALIDES  :   CX4 > SiX4 > GeX4 > SnX4 > PbX4  (DECREASES)
      HYDRIDES MH4  :   CH4 > SiH4 > GeH4 > SnH4 > PbH4  (DECREASES)
      +2 STATE      :   C  <  Si  <  Ge  <  Sn  <  Pb    (INCREASES)
      +4 STATE      :   C  >  Si  >  Ge  >  Sn  >  Pb    (DECREASES)
```

**Reactions that prove the oxidising / reducing behaviour:**

```
  Sn(II) AS A REDUCING AGENT
      SnCl2  +  2 HgCl2   -->   SnCl4  +  Hg2Cl2 (white ppt)
      SnCl2  +  Hg2Cl2    -->   SnCl4  +  2 Hg   (grey)
      2 SnCl2 + O2 + 4 HCl -->  2 SnCl4 + 2 H2O

  Pb(IV) AS AN OXIDISING AGENT
      PbO2   +  4 HCl     -->   PbCl2  +  Cl2  +  2 H2O
      2 PbO2  --(heat)-->  2 PbO  +  O2
      PbCl4  --(gentle heat)-->  PbCl2  +  Cl2

  WHY PbI4 DOES NOT EXIST
      Pb4+ is strongly OXIDISING , I- is strongly REDUCING.
      They destroy each other:   Pb4+  +  2 I-  -->  Pb2+  +  I2
      (PbF4 and PbCl4 exist because F- and Cl- are hard to oxidise.)
```

# 5. ANOMALOUS BEHAVIOUR OF CARBON

| THE FOUR REASONS | THE VALUE |
|---|---|
| 1. Very small atomic size | covalent radius **77 pm** |
| 2. High electronegativity | **2.5** — the highest in the group |
| 3. High ionisation enthalpy | **1086 kJ/mol** |
| 4. **Absence of d orbitals** in the valence shell | n = 2 has only 2s and 2p |

| CONSEQUENCE | EXAMPLE |
|---|---|
| Maximum covalency of C is **4**; the others can reach **6** | `[SiF6]2-` exists, `[CF6]2-` does not |
| C forms strong **p(pi)-p(pi) multiple bonds** | C=C, C=C=C, C=O, C=N; Si does not |
| CO2 is a discrete gas; SiO2 is a giant solid | see section 12 |
| C has the maximum tendency for **catenation** | all of organic chemistry |
| `CCl4` is not hydrolysed; `SiCl4` is | see section 9 |
| C shows **allotropy** | diamond, graphite, fullerene |
| Carbides differ | `CaC2` -> `C2H2` but `Be2C`, `Al4C3` -> `CH4` |

# 6. CATENATION

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   DEFINITION : the self-linking of like atoms by covalent bonds to   |
  |                form long chains, branched chains and rings.          |
  |                                                                      |
  |   ORDER     :   C  >>  Si  >  Ge  ~  Sn  >  Pb  (Pb: essentially 0)  |
  |                                                                      |
  |   REASON    :   catenation depends on the M-M BOND ENTHALPY.         |
  |                 C-C 348 > Si-Si 297 > Ge-Ge 260 > Sn-Sn 240 kJ/mol   |
  |                 As the atom gets bigger the orbitals overlap poorly  |
  |                 over the longer distance, so the M-M bond is longer  |
  |                 and weaker and the chain breaks.                     |
  |                                                                      |
  +----------------------------------------------------------------------+
```

```
  DIAMOND - the reasons in one line each

     HARD           : rigid 3-D network of strong C-C sigma bonds
     HIGH m.p.      : melting means breaking millions of covalent bonds
     NON-CONDUCTOR  : all 4 electrons locked in sigma bonds, none free
     SPARKLES       : refractive index 2.42, total internal reflection


  GRAPHITE - the reasons in one line each

     SOFT / LUBRICANT : layers 340 pm apart, held only by WEAK VAN DER
                        WAALS forces, so they SLIDE over each other
     CONDUCTOR        : the 4th electron of each C sits in an unhybridised
                        p orbital -> DELOCALISED pi cloud -> mobile
     HIGH m.p.        : the covalent bonds inside a layer are very strong
     LOW DENSITY      : the wide 340 pm gaps make the structure open


  FULLERENE C60 - the numbers

     20 HEXAGONS  +  12 PENTAGONS  =  32 faces , 60 carbon atoms
     Each pentagon is fused ONLY to hexagons.
     PREPARATION: heat graphite in an ELECTRIC ARC in He or Ar ->
                  sooty material containing C60 and some C70.
     Doped K3C60 is a SUPERCONDUCTOR at low temperature.
```

  ONE-LINE CONVERSIONS

      diamond  --(1773 K , no air)-->  graphite
      graphite --(very high T and P)-->  diamond   (artificial diamonds)

## 8.1 Acid-base character of the oxides

| OXIDE | TYPE | CHARACTER | EVIDENCE |
|---|---|---|---|
| CO | MO | **NEUTRAL** | no reaction with acids or bases |
| CO2 | MO2 | **ACIDIC** | `CO2 + H2O -> H2CO3` |
| SiO2 | MO2 | **ACIDIC** | `SiO2 + 2NaOH -> Na2SiO3 + H2O` |
| GeO2 | MO2 | weakly acidic / amphoteric | dissolves in alkali |
| SnO2 | MO2 | **AMPHOTERIC** | reacts with acid and base |
| PbO2 | MO2 | **AMPHOTERIC** | reacts with acid and base |
| GeO, SnO, PbO | MO | **AMPHOTERIC** | `PbO + 2HNO3 -> Pb(NO3)2`; `PbO + 2NaOH -> Na2PbO2` |

```
  TWO RULES

      1.  DOWN THE GROUP the dioxides go   ACIDIC -> AMPHOTERIC ,
          because metallic character increases.

      2.  FOR THE SAME ELEMENT , MO2 is MORE ACIDIC than MO ,
          because the higher oxidation state pulls electrons harder.
```

# 9. THE TETRAHALIDES AND THE CCl4 / SiCl4 QUESTION

| FACT ABOUT MX4 | DETAIL |
|---|---|
| Shape and hybridisation | **Tetrahedral, sp3** |
| Bonding | Covalent (except most PbX4 / SnF4 which have ionic character) |
| Physical state | Mostly colourless liquids or low-melting solids |
| Stability | `CX4 > SiX4 > GeX4 > SnX4 > PbX4` |
| Non-existent | **`PbBr4` and `PbI4` do not exist** |
| Hydrolysis | All are hydrolysed **except `CX4`** |

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   *** THE MOST-ASKED 4-MARK QUESTION IN THE CHAPTER ***              |
  |                                                                      |
  |       CCl4   +  H2O    -->   NO REACTION                             |
  |       SiCl4  +  4 H2O  -->   Si(OH)4  +  4 HCl                       |
  |                                                                      |
  |   REASON                                                             |
  |                                                                      |
  |   Hydrolysis begins when the LONE PAIR of the oxygen of water        |
  |   attacks the central atom. The central atom must have a VACANT      |
  |   ORBITAL to accept it, i.e. it must be able to EXPAND ITS OCTET.    |
  |                                                                      |
  |   CARBON  (period 2) has NO d ORBITALS in its valence shell.         |
  |           All four orbitals are used in CCl4. It cannot accept the   |
  |           lone pair and cannot expand its covalency beyond 4.        |
  |           It is also small and completely screened by 4 large Cl.    |
  |           -> NOT HYDROLYSED.                                         |
  |                                                                      |
  |   SILICON (period 3) HAS VACANT 3d ORBITALS. Water's lone pair       |
  |           enters a vacant 3d orbital, silicon expands its octet,     |
  |           and the Si-Cl bonds break.                                 |
  |           -> READILY HYDROLYSED (fumes of HCl in moist air).         |
  |                                                                      |
  |   THE SAME REASON EXPLAINS:                                          |
  |       [SiF6]2- exists but [CF6]2- does not.                          |
  |       SnCl4, GeCl4, TiCl4 all fume in moist air; CCl4 does not.      |
  |                                                                      |
  +----------------------------------------------------------------------+
```

# 11. CARBON MONOXIDE, CO

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   PREPARATION                                                        |
  |                                                                      |
  |   LAB (dehydration of formic acid by conc. H2SO4):                   |
  |        HCOOH   --(conc. H2SO4 , 373 K)-->   CO  +  H2O               |
  |                                                                      |
  |   From oxalic acid (gives CO + CO2; remove CO2 with KOH):            |
  |        H2C2O4  --(conc. H2SO4)-->  CO  +  CO2  +  H2O                |
  |                                                                      |
  |   COMMERCIAL:                                                        |
  |        2 C  +  O2 (limited)  -->  2 CO      incomplete combustion    |
  |        C  +  H2O  --(1273 K)-->  CO + H2    WATER GAS                |
  |        2 C + O2 + 4 N2 --(air)-->  2 CO + 4 N2   PRODUCER GAS        |
  |                                                                      |
  |   STRUCTURE :   : C === O :                                          |
  |        1 sigma + 1 pi normal + 1 COORDINATE bond (O -> C)            |
  |        Bond length 112.8 pm ; extremely strong bond                  |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| PROPERTY OF CO | DETAIL |
|---|---|
| Colour / smell | Colourless, odourless, tasteless |
| Solubility in water | Almost **insoluble** |
| Acid-base nature | **NEUTRAL** oxide |
| Combustion | Burns with a **blue flame**: `2 CO + O2 -> 2 CO2` |
| Chief chemical property | **Powerful REDUCING AGENT** |
| Toxicity | **Highly poisonous** (see box below) |
| As a ligand | Forms **metal carbonyls** with transition metals |

```
  CO AS A REDUCING AGENT (metallurgy)

      Fe2O3  +  3 CO  --(blast furnace)-->  2 Fe  +  3 CO2
      ZnO    +    CO  --(heat)-->             Zn  +    CO2
      CuO    +    CO  --(heat)-->             Cu  +    CO2

  CO AS A LIGAND

      Ni  +  4 CO  --(330-350 K)-->  [Ni(CO)4]   (MOND PROCESS for Ni)
      Fe  +  5 CO  -->  [Fe(CO)5]

  ESTIMATION OF CO

      5 CO  +  I2O5  -->  I2  +  5 CO2     (titrate the iodine)

  MANUFACTURE OF METHANOL

      CO  +  2 H2  --(ZnO / Cr2O3 , 573-673 K, 300 atm)-->  CH3OH
```

```
  +----------------------------------------------------------------------+
  |   WHY IS CO POISONOUS?  (learn these five lines)                     |
  |                                                                      |
  |     1.  Hb  +  O2   -->   HbO2      OXYHAEMOGLOBIN (normal)          |
  |     2.  Hb  +  CO   -->   HbCO      CARBOXYHAEMOGLOBIN               |
  |     3.  HbCO is about 300 TIMES MORE STABLE than HbO2.               |
  |     4.  So CO blocks the haemoglobin and the blood can no longer     |
  |         carry oxygen to the tissues.                                 |
  |     5.  Result: headache, unconsciousness and DEATH BY ASPHYXIATION. |
  |         CO is odourless, so there is no warning.                     |
  +----------------------------------------------------------------------+
```

**USES OF CO:** reducing agent in metallurgy; fuel (water gas, producer gas);
Mond process for nickel; manufacture of methanol; organic synthesis.

# 12. CARBON DIOXIDE, CO2

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   PREPARATION                                                        |
  |                                                                      |
  |   LAB:      CaCO3  +  2 HCl (dil.)  -->  CaCl2  +  H2O  +  CO2       |
  |   BURNING:  C  +  O2  -->  CO2                                       |
  |             CH4 + 2 O2 -->  CO2 + 2 H2O                              |
  |   INDUSTRY: CaCO3  --(1000-1200 K)-->  CaO  +  CO2                   |
  |   FERMENT.: C6H12O6  --(zymase)-->  2 C2H5OH  +  2 CO2               |
  |                                                                      |
  |   STRUCTURE:      O === C === O                                      |
  |       LINEAR , sp HYBRIDISED , bond angle 180 degrees ,              |
  |       NON-POLAR (the two dipoles cancel) ,                           |
  |       C-O bond length 115 pm - SHORTER than a normal C=O because     |
  |       of RESONANCE:                                                  |
  |                                                                      |
  |       O=C=O  <-->  (-)O-C(+)=O  <-->  O=C(+)-O(-)                    |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| PROPERTY OF CO2 | DETAIL |
|---|---|
| In the atmosphere | **0.03 % by volume** |
| Colour / smell | Colourless, odourless; heavier than air |
| Acid-base nature | **ACIDIC oxide** |
| In water | Slightly soluble; gives weak, dibasic `H2CO3` |
| Combustion | Neither burns nor supports burning |
| Solid form | **DRY ICE** — **sublimes** at 195 K, never melts |
| Test | Turns lime water **milky**; milkiness clears in excess CO2 |

```
  KEY REACTIONS OF CO2

      CO2  +  H2O   <-->   H2CO3           (weak DIBASIC acid)

      CO2  +  Ca(OH)2  -->  CaCO3 (MILKY) + H2O
      CaCO3 + H2O + CO2 (excess) -->  Ca(HCO3)2 (clear again)

      CO2  +  2 NaOH   -->   Na2CO3  +  H2O
      CO2 (excess) + NaOH  -->  NaHCO3

      2 Mg  +  CO2   -->   2 MgO  +  C
          (so a CO2 extinguisher must NOT be used on burning magnesium)

      6 CO2 + 12 H2O --(chlorophyll, sunlight)--> C6H12O6 + 6 H2O + 6 O2
          (PHOTOSYNTHESIS)

      2 NH3  +  CO2  --(heat, pressure)-->  NH2CONH2 (UREA) + H2O
```

```
  +----------------------------------------------------------------------+
  |   THE GREENHOUSE EFFECT - the four steps                             |
  |                                                                      |
  |     1.  SHORT-WAVE solar radiation passes freely through the CO2 in  |
  |         the atmosphere and reaches the earth's surface.              |
  |     2.  The warmed earth re-radiates that energy as LONG-WAVELENGTH  |
  |         INFRARED radiation.                                          |
  |     3.  CO2 molecules ABSORB this infrared radiation and re-emit     |
  |         part of it back towards the earth.                           |
  |     4.  Heat is TRAPPED near the surface -> the average temperature  |
  |         rises -> GLOBAL WARMING.                                     |
  |                                                                      |
  |   OTHER GREENHOUSE GASES : CH4 , H2O vapour , N2O , CFCs , O3        |
  |   CAUSES OF RISING CO2   : burning FOSSIL FUELS , DEFORESTATION ,    |
  |                            cement and other industry                 |
  |   EFFECTS                : melting ice caps , rising sea level ,     |
  |                            floods , droughts , crop failure          |
  |   NOTE                   : a NORMAL greenhouse effect keeps the      |
  |                            earth about 33 degrees warmer and is      |
  |                            NECESSARY. The problem is the ENHANCED    |
  |                            effect caused by human activity.          |
  +----------------------------------------------------------------------+
```

**USES OF CO2:** fire extinguisher (heavier than air, does not support

# 13. SILICON DIOXIDE (SILICA), SiO2

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   STRUCTURE                                                          |
  |     *  Each Si is sp3 hybridised and covalently bonded to FOUR       |
  |        oxygens arranged TETRAHEDRALLY.                               |
  |     *  EACH OXYGEN IS SHARED BETWEEN TWO Si TETRAHEDRA.              |
  |     *  So each Si owns 4 x 1/2 = 2 oxygens  ->  formula SiO2.        |
  |     *  It is a GIANT COVALENT 3-D NETWORK - one huge molecule.       |
  |     *  Si-O bond about 161 pm, very strong (452 kJ/mol).             |
  |     *  Crystalline forms: QUARTZ , CRISTOBALITE , TRIDYMITE.         |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| PROPERTY | DETAIL |
|---|---|
| Melting point | ~1996 K — very high |
| Hardness | Very hard |
| Solubility | Insoluble in water |
| Reactivity | Very unreactive; attacked only by **HF** and by hot alkali |
| Nature | **ACIDIC oxide** |

```
  REACTIONS OF SILICA

      SiO2  +  4 HF   -->   SiF4  +  2 H2O
          (so HF is stored in wax or plastic, NEVER in glass)

      SiO2  +  2 NaOH  --(fused)-->   Na2SiO3  +  H2O

      SiO2  +  CaO   --(high temperature)-->   CaSiO3   (blast furnace slag)

      SiO2  +  2 C   --(electric furnace)-->   Si  +  2 CO   (making Si)

      SiO2  +  3 C   --(2000 K)-->   SiC  +  2 CO
          (SiC = CARBORUNDUM, extremely hard abrasive)
```

```
  +----------------------------------------------------------------------+
  |   *** WHY IS CO2 A GAS BUT SiO2 A HARD SOLID? ***                    |
  |                                                                      |
  |   CO2 :  Carbon is SMALL (77 pm), so its 2p orbital overlaps         |
  |          sideways well with oxygen's 2p. Carbon therefore forms      |
  |          p(pi)-p(pi) DOUBLE BONDS and its valency is satisfied       |
  |          inside one small molecule, O = C = O. These discrete        |
  |          molecules are held to each other only by WEAK VAN DER       |
  |          WAALS forces  ->  CO2 is a GAS.                             |
  |                                                                      |
  |   SiO2:  Silicon is LARGE (118 pm) with diffuse 3p orbitals, so      |
  |          sideways overlap with oxygen's small 2p is POOR. Silicon    |
  |          CANNOT form p(pi)-p(pi) bonds. Instead it forms FOUR        |
  |          SINGLE sigma bonds to four oxygens, each oxygen bridging    |
  |          to another silicon  ->  a GIANT 3-D COVALENT NETWORK  ->    |
  |          SiO2 is a HARD, HIGH-MELTING SOLID.                         |
  +----------------------------------------------------------------------+
```

**USES OF SILICA:** quartz is **piezoelectric** (watches, oscillators,
ultrasound); **silica gel** as a drying agent and adsorbent; making glass,
cement, ceramics and refractory bricks; kieselguhr in filtration and
dynamite; fused quartz for optical fibres and UV apparatus.

# 14. SILICONES

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   DEFINITION : organosilicon POLYMERS with a backbone of alternating |
  |                Si and O atoms, carrying alkyl / aryl groups on Si.   |
  |                Repeating unit  ( R2 Si O ).                          |
  |                                                                      |
  |   PREPARATION - STEP 1 (Grignard route to the chlorosilanes)         |
  |        RMgCl  +  SiCl4    -->   RSiCl3   +  MgCl2                    |
  |        RMgCl  +  RSiCl3   -->   R2SiCl2  +  MgCl2                    |
  |        RMgCl  +  R2SiCl2  -->   R3SiCl   +  MgCl2                    |
  |        RMgCl  +  R3SiCl   -->   R4Si     +  MgCl2                    |
  |        (industrial DIRECT PROCESS:                                   |
  |             2 CH3Cl + Si --(Cu, 570 K)--> (CH3)2SiCl2 )              |
  |                                                                      |
  |   PREPARATION - STEP 2 (hydrolysis then condensation)                |
  |        R2SiCl2  +  2 H2O  -->  R2Si(OH)2  +  2 HCl                   |
  |                                                                      |
  |   OVERALL EQUATION TO WRITE IN THE EXAM                              |
  |        n R2SiCl2  +  n H2O  -->  [ -O-SiR2- ]n  +  2n HCl            |
  |                                                                      |
  |   STRUCTURE                                                          |
  |              R     R     R     R                                     |
  |              |     |     |     |                                     |
  |        ... - Si -O-Si -O-Si -O-Si - O - ...                          |
  |              |     |     |     |                                     |
  |              R     R     R     R                                     |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| STARTING MATERIAL | -OH GROUPS AFTER HYDROLYSIS | PRODUCT |
|---|---|---|
| `R3SiCl` | 1 | **Chain terminator** — fixes the chain length |
| `R2SiCl2` | 2 | **Linear** silicone polymer |
| `RSiCl3` | 3 | **Cross-linked** sheet / resin |
| `SiCl4` | 4 | Fully three-dimensional network |

| PROPERTY OF SILICONES | REASON / NOTE |
|---|---|
| Chemically inert | Resistant to acids, alkalis and oxidation |
| Thermally very stable | The Si-O bond is very strong (452 kJ/mol) |
| **Water-repellent (hydrophobic)** | Outward-facing methyl groups repel water |
| Excellent electrical insulators | No mobile charges |
| Viscosity almost constant with temperature | Useful as lubricants over a huge range |
| Non-toxic, biocompatible | Safe for medical implants |

**USES OF SILICONES:** high-temperature lubricants and greases; electrical
insulation; waterproofing fabrics, paper and buildings; heat-resistant paints
and enamels; sealants and adhesives; surgical and cosmetic implants, contact
lenses; silicone rubber; anti-foaming agents.

# 15. SILICATES

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   BASIC STRUCTURAL UNIT  =   [ SiO4 ] 4-   TETRAHEDRON               |
  |        Si at the centre, 4 O at the corners, sp3, 109.5 degrees.     |
  |        Each O carries one negative charge -> overall charge 4-.      |
  |                                                                      |
  |   Silicates are built by SHARING CORNER OXYGEN ATOMS between         |
  |   tetrahedra. How many corners are shared decides the structure.     |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| CORNERS SHARED | TYPE | ANION | EXAMPLE |
|---|---|---|---|
| 0 | **Ortho**silicate (discrete) | `SiO4 4-` | Zircon `ZrSiO4`, olivine, willemite |
| 1 | **Pyro**silicate | `Si2O7 6-` | Thortveitite `Sc2Si2O7` |
| 2 | **Cyclic / ring** silicate | `(SiO3)n 2n-` | Beryl `Be3Al2Si6O18` |
| 2 | **Chain** silicate (pyroxene) | `(SiO3)n 2n-` | Spodumene `LiAl(SiO3)2` |
| 2 and 3 alternately | **Double chain** (amphibole) | `(Si4O11)n 6n-` | **Asbestos** |
| 3 | **Sheet / layer** silicate | `(Si2O5)n 2n-` | **Talc, mica, clay, kaolin** |
| 4 | **Three-dimensional** | `SiO2` neutral | **Quartz, feldspar, zeolites** |

```
  THE PATTERN

      MORE corners shared -> LESS negative charge -> bigger structure

          0 shared -> 4- per Si -> separate ions
          1 shared -> 3- per Si -> pairs
          2 shared -> 2- per Si -> chains and rings
          3 shared -> 1- per Si -> sheets  (talc, mica: they FLAKE)
          4 shared ->  0        -> 3-D network = SiO2 (quartz)

      The negative charge is balanced by cations: Na+, K+, Mg2+, Ca2+,
      Al3+, Fe2+ sitting in the gaps.
```

# 16. ZEOLITES

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   DEFINITION : three-dimensional ALUMINOSILICATES made when SOME Si  |
  |                atoms of a 3-D silicate framework are replaced by Al. |
  |                                                                      |
  |   *  Si4+ replaced by Al3+  ->  each [AlO4] unit leaves ONE UNIT OF  |
  |      NEGATIVE CHARGE on the framework.                               |
  |   *  Balanced by loosely held cations Na+, K+, Ca2+ inside the pores.|
  |   *  The framework is honeycombed with CAVITIES and CHANNELS of      |
  |      UNIFORM SIZE.                                                   |
  |   *  General formula:  Mx/n [(AlO2)x (SiO2)y] . z H2O                |
  |   *  The name means "boiling stone" - trapped water froths out on    |
  |      heating.                                                        |
  |                                                                      |
  +----------------------------------------------------------------------+
```

| USE | WHY IT WORKS | EXAMPLE |
|---|---|---|
| **Catalysts** | The pores are of fixed size, so only molecules of the right shape can enter — **shape selective catalysis** | **ZSM-5** converts alcohols to gasoline; cracking and isomerisation of hydrocarbons |
| **Ion exchangers** | The Na+ inside the cavity is loosely held and swaps with Ca2+ / Mg2+ | **Softening hard water** (permutit); zeolite builders in detergents |
| **Molecular sieves** | Uniform pore size lets small molecules in and keeps large ones out | Drying gases and solvents; separating mixtures by molecule size |

```
  ION EXCHANGE EQUATIONS  (Z = the zeolite framework)

      Na2Z  +  Ca2+   -->   CaZ  +  2 Na+
      Na2Z  +  Mg2+   -->   MgZ  +  2 Na+

  REGENERATION with brine

      CaZ   +  2 NaCl  -->  Na2Z  +  CaCl2
```

# 19. THE ONE-LINE REASON BANK (steal these sentences)

| IF THE QUESTION ASKS ... | WRITE THIS |
|---|---|
| Why is diamond hard? | Rigid **three-dimensional** network of strong C-C sigma bonds; every C is sp3 |
| Why doesn't diamond conduct? | All four electrons are locked in sigma bonds; **no free electrons** |
| Why is graphite soft? | Layers 340 pm apart held only by **weak van der Waals forces**, so they slide |
| Why does graphite conduct? | The fourth electron of each C is in an unhybridised p orbital, giving a **delocalised pi cloud** |
| Why is C60 the pure allotrope? | It is a closed cage with **no dangling bonds** at any edge |
| Why does catenation fall down the group? | The **M-M bond enthalpy falls** as the atom gets bigger and overlap worsens |
| Why is carbon anomalous? | Small size, high EN, high IE and **no d orbitals** |
| Why is CCl4 not hydrolysed? | Carbon has **no vacant d orbital** and cannot expand its octet |
| Why is CO2 a gas but SiO2 a solid? | C forms **p(pi)-p(pi) double bonds**; Si cannot, so it makes a 3-D network |
| Why does the +2 state get stable down the group? | **Inert pair effect** — poor shielding by d and f electrons |
| Why is PbO2 an oxidiser? | Pb(IV) is unstable and drops to the stable Pb(II) |
| Why is SnCl2 a reducer? | Sn(II) is unstable and rises to the stable Sn(IV) |
| Why doesn't PbI4 exist? | Pb4+ oxidises I- to I2 immediately |
| Why is CO poisonous? | **HbCO is ~300 times more stable than HbO2**, so the blood cannot carry O2 |
| Why is Pb's IE higher than Sn's? | **Poor shielding** by the 4f14 and 5d10 electrons |
| Why is HF not stored in glass? | `SiO2 + 4HF -> SiF4 + 2H2O` — it eats the glass |
| Why do silicones repel water? | The outward-facing alkyl (methyl) groups are hydrophobic |
| Why are zeolites good catalysts? | Uniform pore size gives **shape selective catalysis** |
