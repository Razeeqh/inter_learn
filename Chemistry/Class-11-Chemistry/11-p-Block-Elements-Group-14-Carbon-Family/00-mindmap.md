## THE 60-SECOND VERSION

Group 14 is the **fourth column of the p-block**. Five elements:

```
  C  ->  Si  ->  Ge  ->  Sn  ->  Pb

  NON-METAL   METALLOID  METALLOID   METAL   METAL
      C          Si         Ge         Sn      Pb

  All of them have the SAME outer configuration:   ns2 np2
       C   [He] 2s2 2p2
       Si  [Ne] 3s2 3p2
       Ge  [Ar] 3d10 4s2 4p2
       Sn  [Kr] 4d10 5s2 5p2
       Pb  [Xe] 4f14 5d10 6s2 6p2
```

Almost every fact in this chapter comes from **two root causes**:

```
  ROOT CAUSE 1 :  THE ATOM GETS BIGGER GOING DOWN

        bigger atom  ->  outer electrons held loosely
                     ->  IONISATION ENTHALPY falls
                     ->  METALLIC CHARACTER rises
                     ->  bonds get weaker  ->  m.p. and catenation fall


  ROOT CAUSE 2 :  CARBON IS TINY AND HAS NO d ORBITALS

        no d orbitals  ->  covalency can NEVER exceed 4
                       ->  CCl4 cannot be hydrolysed
                       ->  no CF6 2- , no CCl6 2-
        tiny + high EN ->  strong p(pi)-p(pi) double bonds
                       ->  CO2 is O=C=O , a small GAS molecule
                       ->  strong C-C bond  ->  BEST CATENATION
```

**And the one extra idea that runs down the whole group:**

```
      INERT PAIR EFFECT  ->  the ns2 pair refuses to bond
                         ->  the +2 state becomes MORE stable going down
                         ->  Pb4+ is a strong OXIDISER, Sn2+ is a REDUCER
```

**If you understand only those three boxes, you can reason out most of the paper.**

## THE OXIDATION-STATE LADDER (one box, several marks)

```
     STATE        C        Si        Ge        Sn        Pb
     -----------------------------------------------------------------
     +4        stable   stable    stable    stable    UNSTABLE
     +2        rare     rare      fair      fair      MOST STABLE

                <----------- +4 stability FALLS -----------
                ----------- +2 stability RISES ----------->


  THEREFORE:
       PbO2 , PbCl4 , Pb(IV)  are STRONG OXIDISING AGENTS
                               (they want to drop to Pb2+)

       SnCl2 , Sn(II) , Ge(II) are GOOD REDUCING AGENTS
                               (they want to rise to Sn4+)

       CO is a strong REDUCING agent (C wants to reach +4 as CO2)

  CAUSE:  INERT PAIR EFFECT - the ns2 pair is pulled in so tightly by a
          badly shielded nucleus that it will not take part in bonding.
```

## THE KEY BOX — the two ideas that unlock most questions

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   KEY IDEA 1 :  CARBON HAS NO d ORBITALS                             |
  |                                                                      |
  |      Maximum covalency of C = 4 , always.                            |
  |      Si, Ge, Sn, Pb HAVE vacant d orbitals -> covalency can be 6.    |
  |                                                                      |
  |      This ONE sentence answers:                                      |
  |         *  Why is CCl4 not hydrolysed but SiCl4 is?                  |
  |         *  Why does [SiF6]2- exist but [CF6]2- does not?             |
  |         *  Why is CO2 a gas and SiO2 a giant solid?                  |
  |         *  Why is carbon's behaviour anomalous?                      |
  |                                                                      |
  +----------------------------------------------------------------------+

  +----------------------------------------------------------------------+
  |                                                                      |
  |   KEY IDEA 2 :  INERT PAIR EFFECT                                    |
  |                                                                      |
  |      Going down the group the intervening d and f electrons shield   |
  |      badly. The nucleus therefore grips the ns2 pair very tightly.   |
  |      That pair becomes "inert" and stops taking part in bonding.     |
  |                                                                      |
  |      Result:  +2 state becomes MORE stable down the group            |
  |               +4 state becomes LESS stable down the group            |
  |                                                                      |
  |      This ONE idea answers:                                          |
  |         *  Why is PbO2 a strong oxidising agent?                     |
  |         *  Why is SnCl2 a reducing agent?                            |
  |         *  Why is PbCl2 more stable than PbCl4?                      |
  |         *  Why does PbI4 not exist at all?                           |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## THE SIX EQUATIONS TO WRITE ON YOUR PALM

```
  1.   HCOOH  --(conc. H2SO4 , 373 K)-->  CO  +  H2O          (lab CO)

  2.   C  +  H2O  --(red hot coke, 473-1273 K)-->  CO  +  H2   (WATER GAS)

  3.   CaCO3  +  2 HCl  -->  CaCl2  +  H2O  +  CO2             (lab CO2)

  4.   SiCl4  +  4 H2O  -->  Si(OH)4  +  4 HCl                 (hydrolysis)
       CCl4   +  H2O    -->  NO REACTION

  5.   SiO2  +  2 NaOH  -->  Na2SiO3  +  H2O                   (silica is acidic)
       SiO2  +  4 HF    -->  SiF4  +  2 H2O

  6.   n R2SiCl2  +  n H2O  -->  [-O-SiR2-]n  +  2n HCl        (SILICONE)
```
