# Trigonometric Ratios upto Transformations — Every Question Pattern

A "pattern" is a question SHAPE. The numbers and the angles change every year.
The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — DEGREE / RADIAN / GRADE CONVERSION                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Convert 150 degrees into radians", "express 7pi/12 in degrees",
            "express 60 grades in degrees".
  METHOD    1. Write the master relation:  D/90 = G/100 = 2R/pi
            2. For degree -> radian, multiply by pi/180.
               For radian -> degree, multiply by 180/pi.
            3. Cancel the common factor and leave pi in the answer.
  TRAP      Writing the answer as a decimal when the examiner wants pi.
            "5pi/6" is the answer; "2.618" is not.
```

```
  PATTERN 2 — ARC LENGTH AND AREA OF A SECTOR                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   Any mention of a circle plus "arc", "sector", "pendulum swings",
            "railway curve", "minute hand sweeps".
  METHOD    1. CONVERT the angle to radians first. Always.
            2. s = r theta
            3. Area = (1/2) r^2 theta = (1/2) r s
            4. Perimeter of a sector = 2r + s
  TRAP      Substituting the angle in DEGREES. This is the single most common
            error in the chapter. The formula is only true in radians.
```

```
  PATTERN 3 — FIND THE VALUE OF sin / cos / tan OF A BIG ANGLE     2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find sin 750", "cos 1290", "tan 855", "sin(-1230)".
  METHOD    1. Add or subtract multiples of 360 until the angle is in 0-360.
            2. Write it as (multiple of 90) +- (standard angle).
            3. ODD multiple of 90 -> CHANGE the ratio. EVEN -> KEEP it.
            4. Decide the sign from the quadrant using ASTC.
            5. Read the value from the standard-angle table.
  TRAP      Forgetting step 3. sin(90 + A) is cos A, not sin A.
```

```
  PATTERN 4 — SIMPLIFY AN ALLIED-ANGLE EXPRESSION                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   A long expression full of (90 + A), (180 - A), (270 + A), (-A).
            The answer is almost always 0, 1, -1 or 2.
  METHOD    1. Convert EVERY term to a plain ratio of A first, in a column.
            2. Only then multiply and add.
            3. Look for sin^2 A + cos^2 A appearing.
  TRAP      Doing the arithmetic before the conversion. Convert first, always.
```

```
  PATTERN 5 — GIVEN ONE RATIO AND A QUADRANT, FIND THE OTHERS      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "If cos A = -3/5 and A is in the third quadrant, find sin A."
            Also: "sin theta = 4/5 and theta is not in the first quadrant."
  METHOD    1. Use sin^2 + cos^2 = 1 to get the size of the missing ratio.
            2. Take the square root - you get TWO answers.
            3. Use ASTC on the given quadrant to pick the right sign.
            4. Build any other ratio from the two you now have.
  TRAP      Skipping step 3. Half the marks are for the sign.
```

```
  PATTERN 6 — PROVE A SMALL PYTHAGOREAN IDENTITY               2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Prove that cos^4 A - sin^4 A = cos 2A",
            "prove (1 - cos^2 A) cosec^2 A = 1",
            "prove cot A + tan A = 2 cosec 2A".
  METHOD    1. Start from the MESSIER side.
            2. Convert everything into sin and cos.
            3. Take a common denominator.
            4. Use sin^2 + cos^2 = 1 to collapse the numerator.
            5. Convert back to whatever the right-hand side wants.
  TRAP      Working on BOTH sides at once and meeting in the middle.
            Examiners want one side transformed into the other.
```

```
  PATTERN 7 — "IF sec A + tan A = k" TYPE                          2 marks
  ------------------------------------------------------------------------
  TRIGGER   A sum or difference of sec and tan (or cosec and cot) set equal
            to a number.
  METHOD    1. Write  (secA + tanA)(secA - tanA) = 1.
            2. So the OTHER combination is 1/k straight away.
            3. Add the two equations -> 2 sec A. Subtract -> 2 tan A.
            4. Read off whatever was asked.
  TRAP      Squaring the given equation. It works but takes four times longer
            and usually loses a sign.
```

```
  PATTERN 8 — PERIOD OF A TRIGONOMETRIC FUNCTION                   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the period of ...".
  METHOD    sin(ax+b), cos(ax+b), sec, cosec  ->  2 pi / |a|
            tan(ax+b), cot(ax+b)              ->    pi / |a|
            A MODULUS or a SQUARE on sin/cos  ->  halve it (period pi)
            A SUM of two functions            ->  LCM of the two periods
  TRAP      Answering 2pi for sin^2 x. The correct answer is pi.
```

```
  PATTERN 9 — MAXIMUM AND MINIMUM OF a cos th + b sin th       2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the maximum and minimum values of ...", "find the range of
            ...", anything of the form (number) sin + (number) cos.
  METHOD    1. Collect into exactly the form  a cos th + b sin th + c.
               (Expand any cos(th + alpha) or sin(pi/6 - th) FIRST.)
            2. r = sqrt(a^2 + b^2)
            3. MAX = c + r ,  MIN = c - r
            4. State the range as [c - r , c + r].
  TRAP      Putting c inside the square root. c stays outside.
            Second trap: forgetting to expand a shifted term before collecting.
```

```
  PATTERN 10 — WRITE a sin x + b cos x AS ONE SINE OR COSINE       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Express sqrt3 sin x + cos x in the form R sin(x + alpha)."
  METHOD    1. R = sqrt(a^2 + b^2)
            2. Factor R out.
            3. Recognise the bracket as sin x cos alpha + cos x sin alpha.
            4. Read alpha from tan alpha = (coefficient of cos)/(coeff of sin).
  TRAP      Mixing up which coefficient gives cos alpha and which gives
            sin alpha. Check by expanding your answer back.
```

```
  PATTERN 11 — COMPOUND ANGLE VALUE (15, 75, 105 ...)              2 marks
  ------------------------------------------------------------------------
  TRIGGER   An angle that is a SUM or DIFFERENCE of two standard angles.
  METHOD    1. Split it: 75 = 45 + 30 , 15 = 45 - 30 , 105 = 60 + 45.
            2. Apply sin(A+-B) or cos(A+-B).
            3. Rationalise the denominator.
  TRAP      cos(A + B) has a MINUS in the middle. sin(A + B) has a PLUS.
            "sin keeps, cos flips."
```

```
  PATTERN 12 — GIVEN sinA AND cosB, FIND sin(A+B)              2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Two ratios of two different angles given, with the quadrants
            stated, and a compound angle asked for.
  METHOD    1. FIRST find the missing partner of each (using sin^2+cos^2=1).
            2. Fix each sign from its stated quadrant.
            3. Only then substitute into the compound formula.
  TRAP      Substituting before finding the missing ratios - you end up with
            an expression, not a number, and score zero.
```

```
  PATTERN 13 — tanA + tanB + k tanA tanB TYPE                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   Two angles that add to 45 or 60, and an expression containing
            their tangents plus their product.
  METHOD    1. Note A + B = 45 (or 60).
            2. Write tan(A+B) = (tanA + tanB)/(1 - tanA tanB) = 1 (or sqrt3).
            3. Cross-multiply and rearrange to match the expression asked.
  TRAP      Not spotting that the two angles add to something standard.
            ALWAYS add the two angles first - that is the whole question.
```

```
  PATTERN 14 — sin(A+B) sin(A-B) TYPE                          2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   A DIFFERENCE OF TWO SQUARES of sines or cosines, e.g.
            "find sin^2 52.5 - sin^2 22.5".
  METHOD    sin^2 A - sin^2 B = sin(A + B) sin(A - B)
            cos^2 A - cos^2 B = sin(A + B) sin(B - A)
            cos^2 A - sin^2 B = cos(A + B) cos(A - B)
  TRAP      Getting the order of (A - B) and (B - A) wrong in the cosine
            version - it flips the sign of your answer.
```

```
  PATTERN 15 — DOUBLE ANGLE, GIVEN ONE RATIO                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "If cos x = 3/5 find cos 2x", "if tan x = 3/4 find sin 2x".
  METHOD    Choose the form that matches what you were GIVEN:
                given cos only  ->  cos2x = 2cos^2 x - 1
                given sin only  ->  cos2x = 1 - 2 sin^2 x
                given tan only  ->  sin2x = 2t/(1+t^2) , cos2x = (1-t^2)/(1+t^2)
  TRAP      Converting tan back to sin and cos separately. Slow, and it forces
            you to worry about signs you do not need.
```

```
  PATTERN 16 — HALF-ANGLE VALUES FROM A GIVEN cos A                4 marks
  ------------------------------------------------------------------------
  TRIGGER   "If cos A = -3/5 and pi/2 < A < pi, find sin(A/2), cos(A/2),
            tan(A/2)."
  METHOD    1. HALVE the given interval to locate A/2 - this fixes all signs.
            2. 1 - cos A = 2 sin^2(A/2)  ->  sin(A/2) = sqrt((1-cosA)/2)
               1 + cos A = 2 cos^2(A/2)  ->  cos(A/2) = sqrt((1+cosA)/2)
            3. Divide to get tan(A/2).
            4. CHECK with cos A = (1 - t^2)/(1 + t^2).
  TRAP      Using the quadrant of A instead of the quadrant of A/2.
            If A is in quadrant II, A/2 is in quadrant I - all signs positive.
```

```
  PATTERN 17 — PROVE sin3A / cos3A / tan3A                         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Prove sin 3A = 3 sinA - 4 sin^3 A" or a question that needs it.
  METHOD    1. Write 3A = 2A + A.
            2. Expand with the compound formula.
            3. Substitute sin2A = 2 sinA cosA and the RIGHT form of cos2A
               (the one that leaves you with only sines, or only cosines).
            4. Replace cos^2 A by 1 - sin^2 A (or the reverse) and collect.
  TRAP      Choosing the wrong form of cos 2A and ending with a mixture of
            sines and cosines that will not simplify.
```

```
  PATTERN 18 — THE t = tan(A/2) SUBSTITUTION                   2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Express sin A and cos A in terms of tan(A/2)", or a question
            giving you tan(A/2) and asking for sin A.
  METHOD    sinA = 2t/(1+t^2) , cosA = (1-t^2)/(1+t^2) , tanA = 2t/(1-t^2)
            Substitute t, simplify the fractions, cancel.
  TRAP      Losing the 1 + t^2 denominator halfway through the algebra.
            Write it once, keep it visible.
```

```
  PATTERN 19 — CHAIN PRODUCT OF COSINES (ANGLES DOUBLE)            4 marks
  ------------------------------------------------------------------------
  TRIGGER   cos 20 . cos 40 . cos 80  - each angle is DOUBLE the last.
  METHOD    1. Multiply AND divide by 2 sin(smallest angle).
            2. Use 2 sinX cosX = sin2X repeatedly, once per cosine.
            3. Finish with sin(180 - x) = sin x to cancel.
            OR use the formula:  sin(2^n A) / (2^n sin A)
  TRAP      Forgetting to divide by the same 2 sin A that you multiplied by.
```

```
  PATTERN 20 — PRODUCT OF THE FORM A, 60-A, 60+A                   4 marks
  ------------------------------------------------------------------------
  TRIGGER   Three angles where the outer two are 60 either side of the first,
            e.g. sin 10 . sin 50 . sin 70 , or sin20 sin40 sin80.
  METHOD    sinA sin(60-A) sin(60+A) = (1/4) sin 3A
            cosA cos(60-A) cos(60+A) = (1/4) cos 3A
            tanA tan(60-A) tan(60+A) = tan 3A
  TRAP      Not rewriting the angles first. 40 = 60 - 20 and 80 = 60 + 20 -
            you must SEE that before the formula applies.
```

```
  PATTERN 21 — SUM-TO-PRODUCT FRACTION                             4 marks
  ------------------------------------------------------------------------
  TRIGGER   A fraction with a sum (or difference) of sines on top and a sum
            of cosines underneath, e.g. (sin70 + sin10)/(cos70 + cos10),
            or (sinA + sin3A + sin5A + sin7A)/(cosA + ... + cos7A).
  METHOD    1. Convert the top to a product; convert the bottom to a product.
            2. With four terms, pair the OUTER two and the INNER two - their
               half-sums are equal, so a common factor appears.
            3. Cancel the common factors.
            4. What survives is a single tan or cot.
  TRAP      Pairing terms 1-2 and 3-4 instead of 1-4 and 2-3. The wrong
            pairing gives no common factor and the question dies.
```

```
  PATTERN 22 — SUM OF COSINES EQUALS A NUMBER                      4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Prove cos12 + cos84 + cos132 + cos156 = -1/2", or
            "cos^2 A + cos^2(A+120) + cos^2(A-120) = 3/2".
  METHOD    1. For SQUARES: use cos^2 X = (1 + cos2X)/2 first.
            2. Pair the two terms whose angles average to a standard angle
               (60, 90, 120 ...).
            3. Sum -> product on each pair.
            4. The standard cosines (cos60 = 1/2, cos120 = -1/2) do the rest.
  TRAP      Choosing the pairing blindly. Test the averages before you commit:
            (12+132)/2 = 72 and (84+156)/2 = 120 both work; other pairings do not.
```

```
  PATTERN 23 — PRODUCT TO SUM                                      4 marks
  ------------------------------------------------------------------------
  TRIGGER   A PRODUCT of two sines or cosines that you need to break apart,
            typically inside a longer expression.
  METHOD    2 sinA cosB = sin(A+B) + sin(A-B)
            2 cosA sinB = sin(A+B) - sin(A-B)
            2 cosA cosB = cos(A+B) + cos(A-B)
            2 sinA sinB = cos(A-B) - cos(A+B)
            Multiply by 2, apply, then divide back by 2.
  TRAP      The last one is the odd one out: (A-B) comes FIRST.
            Writing cos(A+B) - cos(A-B) reverses the sign of the answer.
```

```
  PATTERN 24 — CONDITIONAL IDENTITY, A + B + C = 180               7 marks
  ------------------------------------------------------------------------
  TRIGGER   "If A + B + C = 180 (or: if A, B, C are the angles of a triangle),
            prove that ...". THIS IS THE LONG ANSWER. Expect it every year.
  METHOD    1. LINE 1 (worth a mark on its own):
                 A + B = 180 - C
                 so sin(A+B) = sinC and cos(A+B) = -cosC
                 and (A+B)/2 = 90 - C/2, so cos((A+B)/2) = sin(C/2)
            2. Take the FIRST TWO terms and convert the sum to a product.
            3. Replace (A+B) or (A+B)/2 using line 1.
            4. Convert the THIRD term with a double- or half-angle formula so
               it carries the SAME factor (sinC or cos(C/2)).
            5. Take the common factor out.
            6. Convert the bracket back to a product.
            7. Write "Hence proved."
  TRAP      Three of them:
              - dropping the leading -1 in the cos2A identity
              - dropping the leading +1 in the cosA identity
              - stopping halfway and not converting the final bracket
```

```
  PATTERN 25 — CONDITIONAL IDENTITY, TANGENT VERSION               7 marks
  ------------------------------------------------------------------------
  TRIGGER   "If A + B + C = 180 prove tanA + tanB + tanC = tanA tanB tanC",
            or the cot / half-angle-tan versions.
  METHOD    1. Write A + B = 180 - C.
            2. Take tan (or cot) of BOTH SIDES.
            3. Expand tan(A + B) with the compound formula.
            4. Cross-multiply and collect. Done in five lines.
  TRAP      Trying to use sum-to-product. Tangent questions do NOT use
            transformations - they use "take tan of both sides".
```

```
  PATTERN 26 — CONDITIONAL IDENTITY, THE 2S VERSION                7 marks
  ------------------------------------------------------------------------
  TRIGGER   "If A + B + C = 2S, prove cos(S-A) + cos(S-B) + cos(S-C) + cosS
            = 4 cos(A/2)cos(B/2)cos(C/2)".
  METHOD    1. Write down the two consequences first:
                 2S - A - B = C      and      2S - C = A + B
            2. Pair terms 1 and 2, then pair terms 3 and 4.
            3. Sum -> product on each pair; both give a factor cos(C/2).
            4. Take cos(C/2) out and convert the bracket.
  TRAP      Pairing (1 with 3) and (2 with 4). Only the 1-2 / 3-4 pairing
            produces the common factor.
```

```
  PATTERN 27 — DERIVE sin 18 / cos 36                          4 or 7 marks
  ------------------------------------------------------------------------
  TRIGGER   "Prove that sin 18 = (sqrt5 - 1)/4", or a question needing the
            values of 18, 36, 54, 72 degrees.
  METHOD    1. Let A = 18, so 5A = 90, so 2A = 90 - 3A.
            2. Take sine of both sides: sin2A = cos3A.
            3. Expand both; divide through by cos A.
            4. You get a QUADRATIC in sin A: 4sin^2A + 2sinA - 1 = 0.
            5. Solve; keep the POSITIVE root because 18 deg is acute.
            6. Get cos36 from cos36 = 1 - 2 sin^2 18.
  TRAP      Keeping the negative root. Always state "18 degrees lies in the
            first quadrant, so sin 18 > 0" - that sentence carries a mark.
```

```
  PATTERN 28 — "IF a sinA + b cosA = c, FIND b sinA - a cosA"      4 marks
  ------------------------------------------------------------------------
  TRIGGER   Two linear combinations of sinA and cosA, one given, one asked.
            Example: "if 3 sinA + 5 cosA = 5, show 5 sinA - 3 cosA = +-3".
  METHOD    1. Call them X (given) and Y (asked).
            2. Compute X^2 + Y^2 - the cross terms cancel and you are left
               with a^2 + b^2.
            3. Substitute the given value of X and solve for Y.
            4. Keep BOTH signs in the answer.
  TRAP      Dropping the +- . The question usually says "+- 3" for a reason.
```

```
  PATTERN 29 — ELIMINATE theta                                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   Two equations both containing theta; "eliminate theta"; or the
            answer options contain no theta at all.
  METHOD    1. Make each equation give ONE trig ratio alone.
            2. Pick the identity that links those two ratios:
                 sin & cos    ->  sin^2 + cos^2 = 1
                 sec & tan    ->  sec^2 - tan^2 = 1
                 cosec & cot  ->  cosec^2 - cot^2 = 1
            3. If the two expressions are "mixed" (like a cos + b sin and
               a sin - b cos), SQUARE AND ADD instead.
  TRAP      Trying to solve for theta. You are never asked to find theta -
            you are asked to make it disappear.
```

```
  PATTERN 30 — SUM OF A LONG SERIES OF SINES OR COSINES        4 or 7 marks
  ------------------------------------------------------------------------
  TRIGGER   "sin A + sin 3A + sin 5A + ... ", or "cos1 + cos2 + ... + cos179".
  METHOD    1. Look for terms that CANCEL: cos X + cos(180 - X) = 0.
            2. Otherwise pair the outer terms inward; each pair gives the same
               factor and you can take it out.
            3. Odd number of terms? The middle one is usually a standard
               angle (45, 60, 90) - handle it separately.
  TRAP      Trying to add them one by one. There is always a pairing.
```

## THE FIVE DECISIONS THAT SOLVE EVERY QUESTION IN THIS CHAPTER

```
  1.  Is the angle bigger than 360, or negative?
         ->  reduce it first, then allied-angle rule, then ASTC.

  2.  Is there a SUM of trigonometric terms?
         ->  convert to a PRODUCT.

  3.  Is there a PRODUCT of trigonometric terms?
         ->  convert to a SUM, unless the angles double or sit at
             A, 60-A, 60+A (then use the standard product results).

  4.  Is there a sin and a cos with number coefficients?
         ->  it is a max/min question:  +- sqrt(a^2 + b^2).

  5.  Does the question say A + B + C = 180?
         ->  write  sin(A+B) = sinC  and  cos((A+B)/2) = sin(C/2)
             on the very first line, then follow Pattern 24.
```
