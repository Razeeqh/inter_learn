## Topic: Signs, quadrants, allied angles

### Q A6
Find the value of sin 330 degrees.

**ANSWER:**
```
  330 = 360 - 30

  360 is an EVEN multiple of 90, so sin stays sin.
  330 lies in QUADRANT IV, where sin is NEGATIVE.

  sin 330 = - sin 30 = - 1/2
```

### Q A7
Find the value of tan 855 degrees.

**ANSWER:**
```
  855 - 720 = 135          (720 = 2 x 360, two full turns)

  tan 855 = tan 135 = tan(180 - 45)

  180 is EVEN, so tan stays tan.  135 lies in QUADRANT II, tan is NEGATIVE.

  tan 855 = - tan 45 = -1
```

### Q A8
Find the value of cos 1290 degrees.

**ANSWER:**
```
  1290 - 1080 = 210        (1080 = 3 x 360)

  cos 1290 = cos 210 = cos(180 + 30)

  180 EVEN -> cos stays cos.  Quadrant III -> cos is NEGATIVE.

  cos 1290  =  - cos 30  =  - sqrt3 / 2
```

### Q A9
Simplify  sin(90 + A) cos(180 - A) + cos(90 - A) sin(180 + A).

**ANSWER:**
```
  sin(90 + A)  =  cos A          cos(180 - A) = -cos A
  cos(90 - A)  =  sin A          sin(180 + A) = -sin A

  = (cosA)(-cosA) + (sinA)(-sinA)
  = -(cos^2 A + sin^2 A)
  = -1
```

### Q A10
If sin theta = 4/5 and theta is **not** in the first quadrant, find cos theta.

**ANSWER:**
```
  sin theta is POSITIVE. By ASTC that means quadrant I or quadrant II.
  We are told it is not quadrant I, so theta lies in QUADRANT II.

  cos^2 theta = 1 - 16/25 = 9/25   ->   cos theta = +- 3/5

  In quadrant II cos is NEGATIVE.

  ANSWER:  cos theta = - 3/5
```

### Q A11
Find the value of  sin^2 (pi/10) + sin^2 (4pi/10) + sin^2 (6pi/10) + sin^2 (9pi/10).

**ANSWER:**
```
  The angles in degrees are  18 , 72 , 108 , 162.

### Q A12
Prove that  cos^4 A - sin^4 A  =  cos 2A.

**ANSWER:**
```
  cos^4 A - sin^4 A = (cos^2 A - sin^2 A)(cos^2 A + sin^2 A)
                    = (cos^2 A - sin^2 A)(1)
                    = cos 2A
```

### Q A13
If sec A + tan A = 5, find tan A.

**ANSWER:**
```
  sec^2 A - tan^2 A = 1
  (secA + tanA)(secA - tanA) = 1
  5 (secA - tanA) = 1   ->   secA - tanA = 1/5

  Subtract:  2 tanA = 5 - 1/5 = 24/5   ->   tan A = 12/5
```

### Q A20
If tan 20 = lambda, show that

```

        8 sin20           8 sin20           8 sin20       8

  Therefore the whole product = (1/8) x (1/2) = 1/16          PROVED

### Q B9
If  3 sin A + 5 cos A = 5, show that  5 sin A - 3 cos A = +- 3.

**ANSWER:**
```
  Let  X = 3 sinA + 5 cosA  and  Y = 5 sinA - 3 cosA.

  X^2 = 9 sin^2 A + 30 sinA cosA + 25 cos^2 A
  Y^2 = 25 sin^2 A - 30 sinA cosA + 9 cos^2 A
  -------------------------------------------
  X^2 + Y^2 = 34 sin^2 A + 34 cos^2 A = 34

  Given X = 5 , so  25 + Y^2 = 34   ->   Y^2 = 9   ->   Y = +- 3   PROVED
```

> **This "square and add" trick is the standard method** for every question of
> the shape "if a sinA + b cosA = c, find b sinA - a cosA".

## Q C1 — the single most-asked long answer in this chapter

**If A + B + C = 180 degrees, prove that
sin 2A + sin 2B + sin 2C = 4 sin A sin B sin C.**

**ANSWER (full model answer, mark split shown):**
```
  Given  A + B + C = 180                                        [ 1 mark ]
  so     A + B = 180 - C ,  hence  sin(A + B) = sin C
                            and    cos C = - cos(A + B)

  LHS = sin2A + sin2B + sin2C

  STEP 1  Take the first two terms and apply                    [ 2 marks ]
          sinC + sinD = 2 sin((C+D)/2) cos((C-D)/2) :

          sin2A + sin2B = 2 sin( (2A + 2B)/2 ) cos( (2A - 2B)/2 )
                        = 2 sin(A + B) cos(A - B)
                        = 2 sin C cos(A - B)

  STEP 2  Rewrite the third term:                               [ 1 mark  ]

          sin2C = 2 sinC cosC = 2 sinC [ - cos(A + B) ]
                = - 2 sinC cos(A + B)

  STEP 3  Add them and take out 2 sin C :                       [ 1 mark  ]

          LHS = 2 sinC cos(A - B) - 2 sinC cos(A + B)
              = 2 sinC [ cos(A - B) - cos(A + B) ]

  STEP 4  Expand the bracket:                                   [ 1 mark  ]

          cos(A - B) = cosA cosB + sinA sinB
          cos(A + B) = cosA cosB - sinA sinB
          ----------------------------------
          difference = 2 sinA sinB

  STEP 5  LHS = 2 sinC x 2 sinA sinB                            [ 1 mark  ]
              = 4 sinA sinB sinC
              = RHS

  Hence proved.

  NUMERICAL CHECK (A = B = C = 60):
     LHS = 3 sin120 = 3(0.8660) = 2.598
     RHS = 4 (0.8660)^3 = 4(0.6495) = 2.598                 correct
```

## Q C2

**If A + B + C = 180 degrees, prove that
cos A + cos B + cos C = 1 + 4 sin(A/2) sin(B/2) sin(C/2).**

**ANSWER:**
```
  Given A + B + C = 180 , so  (A + B)/2 = 90 - C/2 ,
  which gives  cos( (A+B)/2 ) = sin(C/2)   and   sin(C/2) = cos((A+B)/2).

  LHS = cosA + cosB + cosC

  STEP 1  cosA + cosB = 2 cos( (A+B)/2 ) cos( (A-B)/2 )
                      = 2 sin(C/2) cos( (A-B)/2 )

  STEP 2  cos C = 1 - 2 sin^2 (C/2)

  STEP 3  LHS = 2 sin(C/2) cos((A-B)/2) + 1 - 2 sin^2(C/2)

              = 1 + 2 sin(C/2) [ cos((A-B)/2) - sin(C/2) ]

  STEP 4  Replace the inner sin(C/2) by cos((A+B)/2) :

              = 1 + 2 sin(C/2) [ cos((A-B)/2) - cos((A+B)/2) ]

  STEP 5  cos((A-B)/2) - cos((A+B)/2)

              = -2 sin( [ (A-B)/2 + (A+B)/2 ] / 2 )
                    sin( [ (A-B)/2 - (A+B)/2 ] / 2 )

              = -2 sin(A/2) sin(-B/2)
              =  2 sin(A/2) sin(B/2)

  STEP 6  LHS = 1 + 2 sin(C/2) x 2 sin(A/2) sin(B/2)
              = 1 + 4 sin(A/2) sin(B/2) sin(C/2)  =  RHS

  Hence proved.

  NUMERICAL CHECK (A = B = C = 60):
     LHS = 3(0.5) = 1.5
     RHS = 1 + 4 (0.5)^3 = 1 + 0.5 = 1.5                    correct
```

## Q C3

**If A + B + C = 180 degrees, prove that
cos 2A + cos 2B + cos 2C = -1 - 4 cos A cos B cos C.**

**ANSWER:**
```
  Given A + B = 180 - C , so cos(A + B) = - cos C.

  STEP 1  cos2A + cos2B = 2 cos( (2A+2B)/2 ) cos( (2A-2B)/2 )
                        = 2 cos(A + B) cos(A - B)
                        = - 2 cosC cos(A - B)

  STEP 2  cos 2C = 2 cos^2 C - 1

  STEP 3  LHS = -2 cosC cos(A - B) + 2 cos^2 C - 1

              = -1 - 2 cosC [ cos(A - B) - cosC ]

  STEP 4  Replace cos C inside the bracket by  - cos(A + B) :

              = -1 - 2 cosC [ cos(A - B) + cos(A + B) ]

  STEP 5  cos(A - B) + cos(A + B) = 2 cosA cosB

  STEP 6  LHS = -1 - 2 cosC x 2 cosA cosB
              = -1 - 4 cosA cosB cosC  =  RHS

  Hence proved.

  NUMERICAL CHECK (A = B = C = 60):
     LHS = 3 cos120 = -1.5
     RHS = -1 - 4(0.5)^3 = -1 - 0.5 = -1.5                  correct
```

> **The "-1" is the whole examination trap here.** If you write
> `-4 cosA cosB cosC` alone you lose 2 marks.

## Q C4

**If A + B + C = 180 degrees, prove that
sin A + sin B + sin C = 4 cos(A/2) cos(B/2) cos(C/2).**

**ANSWER:**
```
  Given (A + B)/2 = 90 - C/2 , so  sin((A+B)/2) = cos(C/2)
                              and  cos((A+B)/2) = sin(C/2).

  STEP 1  sinA + sinB = 2 sin( (A+B)/2 ) cos( (A-B)/2 )
                      = 2 cos(C/2) cos( (A-B)/2 )

  STEP 2  sin C = 2 sin(C/2) cos(C/2)

  STEP 3  LHS = 2 cos(C/2) cos((A-B)/2) + 2 sin(C/2) cos(C/2)
              = 2 cos(C/2) [ cos((A-B)/2) + sin(C/2) ]

  STEP 4  Replace sin(C/2) by cos((A+B)/2) :

              = 2 cos(C/2) [ cos((A-B)/2) + cos((A+B)/2) ]

  STEP 5  cos((A-B)/2) + cos((A+B)/2) = 2 cos(A/2) cos(B/2)

  STEP 6  LHS = 2 cos(C/2) x 2 cos(A/2) cos(B/2)
              = 4 cos(A/2) cos(B/2) cos(C/2)  =  RHS

  Hence proved.

  NUMERICAL CHECK (A = B = C = 60):
     LHS = 3(0.8660) = 2.598
     RHS = 4 (cos30)^3 = 4(0.6495) = 2.598                  correct
```

## Q C5

**If A + B + C = 180 degrees, prove that
sin^2 A + sin^2 B - sin^2 C = 2 sin A sin B cos C.**

**ANSWER:**
```
  STEP 1  Use  sin^2 X - sin^2 Y = sin(X + Y) sin(X - Y) on the
          FIRST and THIRD terms:

          sin^2 A - sin^2 C = sin(A + C) sin(A - C)

  STEP 2  A + C = 180 - B , so  sin(A + C) = sin B :

          sin^2 A - sin^2 C = sinB sin(A - C)

  STEP 3  LHS = sin^2 B + sinB sin(A - C)
              = sinB [ sinB + sin(A - C) ]

  STEP 4  Replace the inner sin B by sin(A + C) :

              = sinB [ sin(A + C) + sin(A - C) ]

  STEP 5  Use  2 sinA cosC = sin(A + C) + sin(A - C) :

              = sinB x 2 sinA cosC
              = 2 sinA sinB cosC  =  RHS

  Hence proved.

  NUMERICAL CHECK (A = B = C = 60):
     LHS = 0.75 + 0.75 - 0.75 = 0.75
     RHS = 2(0.8660)(0.8660)(0.5) = 0.75                    correct
```

## Q C6 — the "2S" version (asked when the examiner wants a fresh look)

**If A + B + C = 2S, prove that
cos(S - A) + cos(S - B) + cos(S - C) + cos S
= 4 cos(A/2) cos(B/2) cos(C/2).**

**ANSWER:**
```
  Given A + B + C = 2S , so :
        2S - A - B = C     and     2S - C = A + B

  STEP 1  Pair the first two:

          cos(S-A) + cos(S-B)
             = 2 cos( [ (S-A) + (S-B) ] / 2 ) cos( [ (S-A) - (S-B) ] / 2 )
             = 2 cos( (2S - A - B)/2 ) cos( (B - A)/2 )
             = 2 cos( C/2 ) cos( (A - B)/2 )

          (cos is an even function, so cos((B-A)/2) = cos((A-B)/2).)

  STEP 2  Pair the last two:

          cos(S-C) + cos S
             = 2 cos( (2S - C)/2 ) cos( C/2 )
             = 2 cos( (A + B)/2 ) cos( C/2 )

  STEP 3  Add:

          LHS = 2 cos(C/2) [ cos((A-B)/2) + cos((A+B)/2) ]

  STEP 4  cos((A-B)/2) + cos((A+B)/2) = 2 cos(A/2) cos(B/2)

  STEP 5  LHS = 2 cos(C/2) x 2 cos(A/2) cos(B/2)
              = 4 cos(A/2) cos(B/2) cos(C/2)  =  RHS

  Hence proved.

  NUMERICAL CHECK (A = B = C = 60, so S = 90):
     LHS = 3 cos30 + cos90 = 3(0.8660) + 0 = 2.598
     RHS = 4 (cos30)^3 = 2.598                              correct
```

## Q C7 — the value-derivation long answer

**Prove that sin 18 = (sqrt5 - 1)/4 and hence find cos 36.
Also show that cos 36 . cos 72 = 1/4.**

**ANSWER:**
```
  PART 1 — sin 18                                            [ 4 marks ]

  Let  A = 18 degrees.  Then  5A = 90 , so  2A = 90 - 3A.

  Take sine of both sides:

        sin 2A = sin(90 - 3A) = cos 3A

        2 sinA cosA  =  4 cos^3 A  -  3 cosA

  cos 18 is not zero, so divide both sides by cos A :

        2 sinA  =  4 cos^2 A - 3
                =  4(1 - sin^2 A) - 3
                =  1 - 4 sin^2 A

  Rearrange:

        4 sin^2 A + 2 sinA - 1 = 0

  Solve as a quadratic in sin A :

                    -2 +- sqrt(4 + 16)       -1 +- sqrt5
        sin A  =  ----------------------  =  -------------
                            8                      4

  18 degrees is in the first quadrant, so sin 18 is POSITIVE:

                    sqrt5 - 1
        sin 18  =  ------------                             PROVED
                        4

  PART 2 — cos 36                                            [ 2 marks ]

        cos 36 = 1 - 2 sin^2 18
               = 1 - 2 (sqrt5 - 1)^2 / 16
               = 1 - (6 - 2 sqrt5)/8
               = (8 - 6 + 2 sqrt5)/8
               = (2 + 2 sqrt5)/8

                    sqrt5 + 1
        cos 36  =  ------------
                        4

  PART 3 — the product                                       [ 1 mark  ]

        cos 72 = sin 18 = (sqrt5 - 1)/4

        cos36 . cos72 = (sqrt5+1)(sqrt5-1)/16 = 4/16 = 1/4   PROVED

  NUMERICAL CHECK:
     sin18 = (2.2360 - 1)/4 = 0.3090      correct
     cos36 = (2.2360 + 1)/4 = 0.8090      correct
     0.8090 x 0.3090 = 0.25               correct
```
