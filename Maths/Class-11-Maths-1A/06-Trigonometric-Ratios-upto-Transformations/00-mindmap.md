## THE 60-SECOND VERSION

Trigonometry is one idea repeated: **a ratio of two sides of a right triangle**,
stretched so it works for any angle at all.

Everything in this chapter is one of five jobs:

| Job | What you actually do | Where it is asked |
|-----|----------------------|-------------------|
| Convert / evaluate | degrees to radians, find sin 750 deg | Section A, 2 marks |
| Simplify an allied-angle mess | use the 90 / 180 / 270 rules | Section A, 2 marks |
| Prove a plain identity | expand with compound / multiple angle | Section B, 4 marks |
| Find max and min | +- sqrt(a^2 + b^2) | Section A or B |
| **Prove a conditional identity (A+B+C = 180)** | **transformations** | **Section C, 7 marks** |

## THE KEY BOX — the formulas that unlock most of the paper

```
  +----------------------------------------------------------------+
  |                                                                |
  |   sin^2 A + cos^2 A = 1        <-- rewrites anything           |
  |                                                                |
  |   cos(A - B) = cosA cosB + sinA sinB   <-- the mother formula  |
  |                                                                |
  |            C + D             C - D                             |
  |   sinC + sinD = 2 sin ------- cos -------                      |
  |                          2           2                         |
  |                                                                |
  |            C + D             C - D                             |
  |   cosC + cosD = 2 cos ------- cos -------                      |
  |                          2           2                         |
  |                                                                |
  |   If A + B + C = 180 deg  then  A + B = 180 - C                |
  |         so   sin(A + B) = sin C    and    cos(A + B) = -cos C  |
  |                                                                |
  |         and  (A+B)/2 = 90 - C/2                                |
  |         so   sin((A+B)/2) = cos(C/2)                           |
  |              cos((A+B)/2) = sin(C/2)                           |
  |                                                                |
  |   THAT last block IS the 7-mark question. Nothing else.        |
  +----------------------------------------------------------------+
```

## IF YOU ONLY HAVE 3 DAYS

```
  DAY 1  (4 hours)
     - Write the ASTC diagram and the standard-angle table 10 times
       from memory until you can do it in 60 seconds.
     - Learn the 3 Pythagorean identities.
     - Learn the allied-angle rule: ODD multiple of 90 CHANGES the ratio,
       EVEN multiple KEEPS it; the sign comes from the quadrant.
     - Do 15 questions of the type "find the value of sin 780 deg".
     THAT ALONE SECURES 4 MARKS IN SECTION A.

  DAY 2  (5 hours)
     - Memorise sin(A+-B), cos(A+-B), tan(A+-B).
     - Memorise sin2A, cos2A (all four forms), tan2A, sin3A, cos3A.
     - Memorise the 4 sum-to-product and the 4 product-to-sum formulas.
     - Learn max = +sqrt(a^2+b^2), min = -sqrt(a^2+b^2).
     - Do 10 Section B proofs from file 03.
     THAT SECURES ANOTHER 4-6 MARKS.

  DAY 3  (5 hours)
     - Only the A + B + C = 180 conditional identities.
     - Learn the 6 standard ones by heart (they are listed in file 02).
     - Write out the FULL proof of
           sin2A + sin2B + sin2C = 4 sinA sinB sinC
       five times until your hand knows it.
     - Then do cos2A + cos2B + cos2C and sinA + sinB + sinC.
     - Learn sin18 and cos36 values.
     THAT SECURES THE 7-MARK LONG ANSWER.

  TOTAL AFTER 3 DAYS:  about 15 marks, from one chapter.
```

## THE ONE SENTENCE TO REMEMBER

> **Sum of angles on the left? Break it into a product.**
> **Product on the left? Break it into a sum.**
> Every single 4-mark and 7-mark question in this chapter is that one decision.
