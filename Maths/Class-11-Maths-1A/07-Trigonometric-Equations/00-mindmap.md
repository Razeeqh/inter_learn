## THE 60-SECOND VERSION

```
  An IDENTITY  is a statement that is true for EVERY angle.
       sin^2 A + cos^2 A = 1          true for A = 5, A = 173, A = anything

  An EQUATION  is a statement that is true only for SPECIAL angles.
       sin A = 1/2                    true for A = 30 deg,  false for A = 40 deg

  Your job in this chapter: find EVERY angle that makes the equation true.

  Because sin and cos repeat every 360 degrees (2 pi) and tan repeats every
  180 degrees (pi), if ONE angle works then infinitely many work.
  So the answer is never a single number. It is a FORMULA containing n,
  where n = 0, +-1, +-2, +-3, ...  That formula is the GENERAL SOLUTION.

  Three steps, every single time:

     STEP 1   Squeeze the whole equation down to    sin th = k
              or  cos th = k  or  tan th = k  or a PRODUCT = 0.

     STEP 2   Write k as sin alpha / cos alpha / tan alpha
              for a KNOWN standard angle alpha.

     STEP 3   Fire the matching general-solution formula.
```

  |                                                                    |

  |                                                                    |

        cos  ->  2 n pi  +-  alpha        "cos has the PLUS-MINUS and the 2"
        tan  ->  n pi  +  alpha           "tan is the SIMPLEST"
        any SQUARE  ->  n pi +- alpha     "squares forget which one it was"
```

## WHAT THE (-1)^n ACTUALLY DOES

```
  sin theta = sin alpha    =>    theta = n pi + (-1)^n alpha

  Unfold it. (-1)^n is +1 when n is EVEN and -1 when n is ODD:

  +-----+---------------------------+-------------------------+
  |  n  |  n pi + (-1)^n alpha      |  simplifies to          |
  +-----+---------------------------+-------------------------+
  | -2  |  -2 pi + alpha            |  -2 pi + alpha          |
  | -1  |  - pi - alpha             |  - pi - alpha           |
  |  0  |  0 + alpha                |  alpha                  |
  |  1  |  pi - alpha               |  pi - alpha             |
  |  2  |  2 pi + alpha             |  2 pi + alpha           |
  |  3  |  3 pi - alpha             |  3 pi - alpha           |
  +-----+---------------------------+-------------------------+

  EVEN n gives   2m pi + alpha        (the angle itself, plus full turns)
  ODD  n gives   (2m+1) pi - alpha    (the SUPPLEMENT, plus full turns)

  Which is exactly right, because sin(pi - alpha) = sin alpha.
  The (-1)^n is just a compact way of writing "alpha AND its supplement".
```

```
              y
              |
              |         sin theta = 1/2 means:
        1  ---|---                "which angles have HEIGHT 1/2 ?"
              |
    ----------+---------- y = 1/2
        P     |     Q            P is at  theta = pi - alpha  = 150 deg
         \    |    /             Q is at  theta = alpha       =  30 deg
          \   |   /
   --------\--+--/----------- x  BOTH have the same height.
            \ | /                So BOTH are solutions.
             \|/                 Then add 2 pi as many times as you like.
              O

## THE SIX SOLVING METHODS AT A GLANCE

| What the equation looks like | Method | Example |
|---|---|---|
| Mixed sin and cos, ONE angle | Use sin^2 + cos^2 = 1 to reduce to one ratio | 2 cos^2 th + sqrt3 sin th + 1 = 0 |
| Every term has a common factor | FACTORISE, set each factor = 0 | sin 2th + sin th = 0 |
| Only one ratio, but squared | Treat as a QUADRATIC, factorise or use the formula | 2 sin^2 th - 3 sin th + 1 = 0 |
| A SUM of three sines or cosines | Transformations: sum -> product | sin th + sin 2th + sin 3th = 0 |
| a cos th + b sin th = c | Divide by sqrt(a^2 + b^2), then cos(th - al) = ... | sqrt3 cos th + sin th = 1 |
| A square root, or sec/tan on both sides | SQUARE, solve, then **CHECK EVERY ROOT** | tan th + sec th = sqrt3 |

## THE TRAP LIST — read this the morning of the exam

```
  1. Forgetting "where n is an integer". It costs half a mark EVERY time.

  2. Writing theta = 30 degrees when the rest of your answer is in radians.
     PICK ONE unit and stay in it. Radians are safer.

  3. Cancelling a common factor. NEVER cancel cos theta from both sides -
     you throw away every solution with cos theta = 0.  FACTORISE instead.

  4. Using  2 n pi +- alpha  for a SINE equation. That is the COS formula.

  5. Forgetting that sin theta and cos theta can never go outside [-1, 1].
     If your working ends at sin theta = 3, the answer is "NO SOLUTION",
     and that IS the full mark.

  6. Solving a cos th + b sin th = c without checking c^2 <= a^2 + b^2.

  7. Squaring and then not checking. Squaring MANUFACTURES fake roots.

  8. Keeping a root that makes tan / sec / cot / cosec undefined.
     cos th = 0 kills tan and sec.  sin th = 0 kills cot and cosec.
```

## IF YOU ONLY HAVE 2 DAYS

```
  DAY 1  (4 hours)

    Hour 1   Write the seven general solutions from memory, ten times,
             until you can do it in 90 seconds with the conditions.
             Learn the three principal ranges.

    Hour 2   Do 15 one-line questions:
                sin th = 1/2 , cos th = -1/2 , tan th = sqrt3 ,
                sin 2th = 1/sqrt2 , cos 3th = 0 , tan^2 th = 3 , sec th = 2
             THIS ALONE SECURES THE SECTION A QUESTION.

    Hour 3   Quadratic type. Do 6 of them:
                2 sin^2 th - 3 sin th + 1 = 0
                2 cos^2 th + sqrt3 sin th + 1 = 0
                4 cos^2 th + sqrt3 = 2(sqrt3 + 1) cos th
             Remember to THROW OUT any root outside [-1, 1].

    Hour 4   Factorise type and sum -> product type:
                sin th + sin 2th + sin 3th = 0
                cos th + cos 2th + cos 3th = 0
                sin 3th = 4 sin th sin 2th sin 4th

  DAY 2  (4 hours)

    Hour 1   a cos th + b sin th = c.  Do FIVE of them, out loud, every step:
                sqrt3 cos th + sin th = 1
                cos th + sqrt3 sin th = sqrt2
                sqrt2 (sin th + cos th) = sqrt3
             Say the existence condition c^2 <= a^2 + b^2 every time.

    Hour 2   Solutions in a given interval. Take each general solution above
             and list every root in [0, 2 pi] by putting n = 0, 1, 2, -1.

    Hour 3   Squaring and extraneous roots + simultaneous equations.

    Hour 4   Sit with file 03 and write out SIX Section B answers with a pen,
             timed, 8 minutes each. Do not read them - WRITE them.

  That is 8 hours and it buys you a near-certain 4 marks, often 6.
```

## THE FOUR DECISIONS THAT SOLVE EVERY QUESTION IN THIS CHAPTER

```
  1.  Is it already  sin th = k  /  cos th = k  /  tan th = k ?
         ->  write k as a standard ratio and fire the formula. Done.

  2.  Are there several DIFFERENT angles (th, 2th, 3th) added together?
         ->  transformations, turn the sum into a PRODUCT, then each
             factor = 0.

  3.  Is there one angle but a MIXTURE of sin and cos (or a square)?
         ->  use sin^2 + cos^2 = 1 to reduce to ONE ratio, then treat it
             as a quadratic.

  4.  Are there NUMBER coefficients in front of cos th and sin th?
         ->  it is the  a cos th + b sin th = c  question.
             Divide by sqrt(a^2 + b^2). Check c^2 <= a^2 + b^2 first.
```
