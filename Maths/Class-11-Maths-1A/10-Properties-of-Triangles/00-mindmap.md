## THE 60-SECOND VERSION

A triangle has 6 measurements: three sides `a, b, c` and three angles `A, B, C`.
This whole chapter answers one question:

> **Given some of the six, how do I find the rest — and everything else about the triangle?**

There are exactly **four bridges** between sides and angles:

```
  +-------------------------------------------------------------------+
  |  SINE RULE        a/sinA = b/sinB = c/sinC = 2R                   |
  |                                                                   |
  |  COSINE RULE      cos A = (b^2 + c^2 - a^2) / (2bc)               |
  |                                                                   |
  |  PROJECTION       a = b cos C + c cos B                           |
  |                                                                   |
  |  TANGENT RULE     tan((A-B)/2) = ((a-b)/(a+b)) cot(C/2)           |
  +-------------------------------------------------------------------+
```

Everything else — half-angles, area, r, R, r1, r2, r3 — is built out of these four.

And the single most useful move in the whole chapter is:

```
  +-------------------------------------------------------------+
  |   a = 2R sin A       b = 2R sin B       c = 2R sin C         |
  |                                                             |
  |   Use this to turn ANY side into an angle, or ANY angle      |
  |   into a side. It converts a "sides" problem into a          |
  |   "trigonometry" problem, which you already know how to do.  |
  +-------------------------------------------------------------+
```

## THE KEY BOX — the two lines that unlock most 7-mark questions

```
  +===================================================================+
  |                                                                   |
  |   KEY 1     r  = delta / s                                        |
  |             r1 = delta / (s - a)                                  |
  |             r2 = delta / (s - b)                                  |
  |             r3 = delta / (s - c)                                  |
  |             R  = abc / (4 delta)                                  |
  |                                                                   |
  |   Almost EVERY 7-mark identity is proved by writing every         |
  |   letter in terms of delta and s, then doing simple fraction       |
  |   algebra. You are not doing geometry. You are adding fractions.  |
  |                                                                   |
  +===================================================================+

  +===================================================================+
  |                                                                   |
  |   KEY 2     delta^2 = s(s-a)(s-b)(s-c)          [Heron]           |
  |                                                                   |
  |             and       2s = a + b + c                              |
  |             so        2s - a - b = c                              |
  |                       2s - b - c = a                              |
  |                       2s - c - a = b                              |
  |                                                                   |
  |   Those three little substitutions finish 80% of the proofs.      |
  |                                                                   |
  +===================================================================+
```

## THE ONE WORKED NUMBER SET TO MEMORISE

Use the **13, 14, 15 triangle** to test any formula you are unsure about.
Every value comes out clean:

```
  a = 13    b = 14    c = 15

  s     = (13 + 14 + 15)/2 = 21
  s - a = 8        s - b = 7        s - c = 6

  delta = sqrt(21 x 8 x 7 x 6) = sqrt(7056) = 84

  r  = delta/s     = 84/21 = 4
  r1 = delta/(s-a) = 84/8  = 10.5
  r2 = delta/(s-b) = 84/7  = 12
  r3 = delta/(s-c) = 84/6  = 14
  R  = abc/(4 delta) = (13 x 14 x 15)/336 = 2730/336 = 8.125

  CHECK:  r1 + r2 + r3 - r = 10.5 + 12 + 14 - 4 = 32.5
          4R              = 4 x 8.125          = 32.5     MATCHES
```

If a formula you half-remember fails on 13-14-15, you have remembered it wrong.

## IF YOU ONLY HAVE 2 DAYS

**Day 1, morning — the notation and the four rules (2 hours)**
Draw the labelled triangle 10 times. Write the sine rule, cosine rule, projection rule
and tangent rule from memory until you can do it with the book shut.
Then do 6 easy numerical questions: "find angle A given a, b, c".

**Day 1, evening — area and the radii (2 hours)**
Learn the five area formulas and the five radius formulas. Use the 13-14-15 triangle
to compute s, delta, r, R, r1, r2, r3 by hand. Do it three times on three different
triangles: (3,4,5), (5,12,13), (13,14,15). All give whole-number answers.

**Day 2, morning — the identities (3 hours). THIS IS THE 7 MARKS.**
Write out, with full proof, these four:

```
  1.  r1 + r2 + r3 - r = 4R
  2.  1/r = 1/r1 + 1/r2 + 1/r3
  3.  r . r1 . r2 . r3 = delta^2
  4.  r1 r2 + r2 r3 + r3 r1 = s^2
```

Each is proved the SAME way: replace every r by delta/(something), add the fractions,
use 2s = a + b + c. Once you can do one, you can do all four.

**Day 2, evening — half-angles + one solved triangle (2 hours)**
Learn sin(A/2), cos(A/2), tan(A/2). Then solve one triangle completely from three
given sides, and one from two sides and the included angle.
