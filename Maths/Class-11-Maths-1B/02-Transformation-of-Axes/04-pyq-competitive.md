  +------------------+----------------------+---------------------------+

```

  TG EAPCET  (Maths, 80 questions)  ->  1 , sometimes 0

# PATTERN 1 — Translation applied to a point (pure subtraction)

### Q1
When the origin is shifted to (3, -4), the new coordinates of the point (2, 5) are

(a) (5, 1) &nbsp;&nbsp; (b) (-1, 9) &nbsp;&nbsp; (c) (-1, 1) &nbsp;&nbsp; (d) (5, 9)

**ANSWER: (b)**
```
  X = x - h = 2 - 3    = -1
  Y = y - k = 5 - (-4) =  9
```

> **SHORTCUT:** the answer is always `(old) - (new origin)`. If you see a plus in an
> option, it is a distractor built from the mistake `X = x + h`.

---

### Q2
When the origin is shifted to (-2, 5), the point (1, -3) becomes

(a) (-1, 2) &nbsp;&nbsp; (b) (3, -8) &nbsp;&nbsp; (c) (-3, 8) &nbsp;&nbsp; (d) (3, 8)

**ANSWER: (b)**
```
  X = 1 - (-2) =  3
  Y = -3 - 5   = -8
```

---

### Q3
When the origin is shifted to (a, b), the new coordinates of the OLD origin are

(a) (a, b) &nbsp;&nbsp; (b) (-a, -b) &nbsp;&nbsp; (c) (0, 0) &nbsp;&nbsp; (d) (b, a)

**ANSWER: (b)**
```
  X = 0 - a = -a          Y = 0 - b = -b
```

> **SHORTCUT:** this is the mirror-image fact. If you walk forwards to the new origin,
> the old one is now behind you by the same amount.

---

### Q4
The origin is shifted to (2, 3). If the new coordinates of a point P are (4, -3), then
P is

(a) (2, -6) &nbsp;&nbsp; (b) (6, 0) &nbsp;&nbsp; (c) (-2, 6) &nbsp;&nbsp; (d) (6, -6)

**ANSWER: (b)**
```
  Going BACKWARDS, so ADD:

  x = X + h = 4 + 2  = 6
  y = Y + k = -3 + 3 = 0
```

> **SHORTCUT:** "find the original point" = ADD. "find the new point" = SUBTRACT.
> Half the wrong options in this pattern are the other direction's answer.

---

### Q5
If the origin is shifted to (h, k) and the point (2, 3) is unchanged, then (h, k) is

(a) (2, 3) &nbsp;&nbsp; (b) (0, 0) &nbsp;&nbsp; (c) (-2, -3) &nbsp;&nbsp; (d) (1, 1)

**ANSWER: (b)**
```
  Unchanged means   x - h = x   and   y - k = y ,  so  h = 0 and k = 0.
```
Only the "do nothing" shift leaves a point alone.

The point to which the origin should be shifted so that (3, 0) becomes (2, -3) is

(a) (1, 3) &nbsp;&nbsp; (b) (5, -3) &nbsp;&nbsp; (c) (1, -3) &nbsp;&nbsp; (d) (-1, 3)

**ANSWER: (a)**
```
  h = x - X = 3 - 2      = 1

```

# PATTERN 3 — Transformed equation after a translation

### Q9
When the origin is shifted to (-1, 2), the equation `x^2 + y^2 + 2x - 4y + 1 = 0`
becomes

(a) X^2 + Y^2 = 4 &nbsp;&nbsp; (b) X^2 + Y^2 = 2 &nbsp;&nbsp;
(c) X^2 + Y^2 = 1 &nbsp;&nbsp; (d) X^2 + Y^2 = 9

**ANSWER: (a)**

> **SHORTCUT — do not expand anything.** The equation is a circle. Its centre is
> `(-g, -f) = (-1, 2)`, which is exactly where the origin is going. So the new
> equation must be `X^2 + Y^2 = r^2` with
> `r^2 = g^2 + f^2 - c = 1 + 4 - 1 = 4`. Answer in five seconds.

---

### Q10
When the origin is shifted to (1, -2), the line `2x + 3y + 4 = 0` becomes

(a) 2X + 3Y = 0 &nbsp;&nbsp; (b) 2X + 3Y + 8 = 0 &nbsp;&nbsp;
(c) 2X + 3Y + 4 = 0 &nbsp;&nbsp; (d) 2X + 3Y - 4 = 0

**ANSWER: (a)**
```
  2(X + 1) + 3(Y - 2) + 4  =  2X + 3Y + 2 - 6 + 4  =  2X + 3Y
```

> **SHORTCUT:** for a line, the coefficients NEVER change under a translation — only
> the constant does, and the new constant is just the old expression evaluated at the
> new origin: `2(1) + 3(-2) + 4 = 0`. So the new constant is 0. One line of work.

---

### Q11
When the origin is shifted to (1, 1), the equation `xy = 0` becomes

(a) XY = 0 &nbsp;&nbsp; (b) XY + X + Y + 1 = 0 &nbsp;&nbsp;
(c) XY - X - Y + 1 = 0 &nbsp;&nbsp; (d) XY = 1

**ANSWER: (b)**
```
  (X + 1)(Y + 1) = XY + X + Y + 1
```

---

### Q12
Under a translation of axes, which of the following is NOT changed?

(a) the constant term &nbsp;&nbsp; (b) the coefficient of x &nbsp;&nbsp;
(c) the coefficient of x^2 &nbsp;&nbsp; (d) the coefficient of y

**ANSWER: (c)**

> **SHORTCUT:** under a TRANSLATION, `a`, `h` and `b` are frozen; `g`, `f` and `c`
> move. Under a ROTATION it is the other way about — `c` is frozen and `a`, `h`, `b`
> move (though `a + b` and `ab - h^2` survive).

# PATTERN 4 — Removing the first degree terms (= finding the centre)

This is the pattern that actually earns you a mark in EAPCET. Learn the two-line
version.

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |    NO xy TERM :          alpha = -g/a          beta = -f/b           |
  |                                                                      |
  |    WITH xy TERM:  solve   a.alpha + h.beta + g = 0                   |
  |                           h.alpha + b.beta + f = 0                   |
  |                                                                      |
  |                   or      alpha = (hf - bg)/(ab - h^2)               |
  |                           beta  = (gh - af)/(ab - h^2)               |
  |                                                                      |
  +----------------------------------------------------------------------+
```

### Q13
The point to which the origin must be shifted to remove the first degree terms from
`x^2 + y^2 - 4x + 6y - 12 = 0` is

(a) (2, 3) &nbsp;&nbsp; (b) (2, -3) &nbsp;&nbsp; (c) (-2, 3) &nbsp;&nbsp; (d) (4, -6)

**ANSWER: (b)**
```
  2g = -4 -> g = -2 ,   2f = 6 -> f = 3

  alpha = -g/a =  2          beta = -f/b = -3
```

> **SHORTCUT for a circle:** the answer is just the centre, `(-g, -f)`. Halve the
> coefficients of `x` and `y` and flip the signs. `(-(-2), -(3)) = (2, -3)`.

---

### Q14
The origin must be shifted to which point so that `4x^2 + 9y^2 - 8x + 36y + 4 = 0` has
no first degree terms?

(a) (1, 2) &nbsp;&nbsp; (b) (1, -2) &nbsp;&nbsp; (c) (-1, 2) &nbsp;&nbsp; (d) (2, -4)

**ANSWER: (b)**
```
  a = 4 , b = 9 , g = -4 , f = 18

  alpha = -g/a = 4/4  =  1
  beta  = -f/b = -18/9 = -2
```

> **TRAP built into option (d):** if you forget to divide by `a` and `b` you get
> `(4, -18)`; if you forget to halve you get `(2, -4)`. Both mistakes are in the
> options. Halve, then divide.

---

### Q15
The point to which the origin must be shifted to remove the first degree terms from
`2x^2 + 4xy + 5y^2 - 4x - 22y + 7 = 0` is

(a) (2, -3) &nbsp;&nbsp; (b) (-2, 3) &nbsp;&nbsp; (c) (3, -2) &nbsp;&nbsp; (d) (-3, 2)

**ANSWER: (b)**
```
  a = 2 , h = 2 , b = 5 , g = -2 , f = -11
  ab - h^2 = 10 - 4 = 6

  alpha = ( (2)(-11) - (5)(-2) ) / 6 = (-22 + 10)/6 = -2
  beta  = ( (-2)(2) - (2)(-11) ) / 6 = (-4 + 22)/6  =  3
```

---

### Q16
The centre of the conic `14x^2 - 4xy + 11y^2 - 44x - 58y + 71 = 0` is

(a) (2, 3) &nbsp;&nbsp; (b) (3, 2) &nbsp;&nbsp; (c) (-2, -3) &nbsp;&nbsp; (d) (1, 2)

**ANSWER: (a)**
```
  a = 14 , h = -2 , b = 11 , g = -22 , f = -29
  ab - h^2 = 154 - 4 = 150

  alpha = ( (-2)(-29) - (11)(-22) ) / 150 = ( 58 + 242 )/150 = 300/150 = 2
  beta  = ( (-22)(-2) - (14)(-29) ) / 150 = ( 44 + 406 )/150 = 450/150 = 3
```

> **SHORTCUT:** "centre of the conic" and "point to which the origin is shifted to
> remove the first degree terms" are **the same question**. Same formula, different
> wording. Recognise it instantly.

---

### Q17
The transformed equation of `2x^2 + 4xy + 5y^2 - 4x - 22y + 7 = 0` after the first
degree terms are removed is

(a) 2X^2 + 4XY + 5Y^2 = 22 &nbsp;&nbsp; (b) 2X^2 + 4XY + 5Y^2 = 7 &nbsp;&nbsp;
(c) 2X^2 + 4XY + 5Y^2 = 11 &nbsp;&nbsp; (d) 2X^2 + 5Y^2 = 22

**ANSWER: (a)**
```
  alpha = -2 , beta = 3  (from Q15)

  c' = g.alpha + f.beta + c = (-2)(-2) + (-11)(3) + 7 = 4 - 33 + 7 = -22
```

> **SHORTCUT:** `c'` is just the whole original expression evaluated at the centre —
> and by the two conditions it collapses to `g.alpha + f.beta + c`. Three
> multiplications, done.

---

### Q18
The origin is shifted to remove the first degree terms of `x^2 + 2y^2 - 4x + 8y - 1 = 0`.
The transformed equation is

(a) X^2 + 2Y^2 = 13 &nbsp;&nbsp; (b) X^2 + 2Y^2 = 1 &nbsp;&nbsp;
(c) X^2 + 2Y^2 = 5 &nbsp;&nbsp; (d) X^2 + 2Y^2 = 9

**ANSWER: (a)**
```
  a = 1 , b = 2 , g = -2 , f = 4

  alpha = -g/a = 2          beta = -f/b = -2

  c' = g.alpha + f.beta + c = (-2)(2) + (4)(-2) + (-1) = -4 - 8 - 1 = -13
```

---

### Q19
For `ax^2 + 2hxy + by^2 + 2gx + 2fy + c = 0`, no point exists to which the origin can
be shifted to remove both first degree terms when

(a) `a = b` &nbsp;&nbsp; (b) `h = 0` &nbsp;&nbsp;
(c) `ab - h^2 = 0` &nbsp;&nbsp; (d) `g = f = 0`

**ANSWER: (c)**

The two simultaneous equations have a unique solution only when the determinant
`ab - h^2` is non-zero. If it is zero the conic has no centre — it is a parabola or a
pair of parallel lines.

### Q20
The origin is shifted to the centre of `3x^2 + 2y^2 + 12x - 4y + 5 = 0`. The centre is

(a) (2, -1) &nbsp;&nbsp; (b) (-2, 1) &nbsp;&nbsp; (c) (-4, 2) &nbsp;&nbsp; (d) (6, -2)

**ANSWER: (b)**
```
  a = 3 , b = 2 , g = 6 , f = -2

  alpha = -6/3 = -2          beta = 2/2 = 1
```

# PATTERN 5 — Rotation applied to a point

### Q21
When the axes are rotated through 45 degrees, the new coordinates of (1, 1) are

(a) (0, sqrt(2)) &nbsp;&nbsp; (b) (sqrt(2), 0) &nbsp;&nbsp;
(c) (1, 1) &nbsp;&nbsp; (d) (sqrt(2), sqrt(2))

**ANSWER: (b)**
```
  X =  x cos t + y sin t = 1/sqrt(2) + 1/sqrt(2) = sqrt(2)
  Y = -x sin t + y cos t = -1/sqrt(2) + 1/sqrt(2) = 0
```

> **SHORTCUT — no algebra needed.** `(1, 1)` lies on the line `y = x`, and after a
> 45-degree rotation the new X-axis IS the line `y = x`. So the point lands on the new
> X-axis, which forces `Y = 0`. Its distance from the origin is `sqrt(2)`, so it is
> `(sqrt(2), 0)`. Two seconds.

---

### Q22
When the axes are rotated through 90 degrees, the point (-2, 4) becomes

(a) (4, 2) &nbsp;&nbsp; (b) (-4, -2) &nbsp;&nbsp; (c) (4, -2) &nbsp;&nbsp; (d) (2, 4)

**ANSWER: (a)**
```
  cos 90 = 0 , sin 90 = 1

  X =  (-2)(0) + (4)(1) = 4
  Y = -(-2)(1) + (4)(0) = 2
```

> **SHORTCUT for 90 degrees:** `X = y` and `Y = -x`. So `(-2, 4) -> (4, 2)`.

---

### Q23
The axes are rotated through an angle theta with `tan(theta) = 4/3`. The new
coordinates of (3, 4) are

(a) (5, 0) &nbsp;&nbsp; (b) (0, 5) &nbsp;&nbsp; (c) (4, 3) &nbsp;&nbsp; (d) (3, 4)

**ANSWER: (a)**
```
  tan t = 4/3   ->   cos t = 3/5 ,  sin t = 4/5

  X =  3(3/5) + 4(4/5) = 9/5 + 16/5 = 5
  Y = -3(4/5) + 4(3/5) = -12/5 + 12/5 = 0
```

> **SHORTCUT:** the point `(3, 4)` has `tan = 4/3` from the origin — exactly the angle
> we rotated through. So it lands on the new X-axis, and its X-coordinate is its
> distance `sqrt(9 + 16) = 5`. Answer `(5, 0)` without any substitution at all.

### Q24
When the axes are rotated through 30 degrees, the new coordinates of (4, 3) are

(a) ((4 sqrt(3)+3)/2, (3 sqrt(3)-4)/2) &nbsp;&nbsp;
(b) ((4 sqrt(3)-3)/2, (3 sqrt(3)+4)/2)
(c) ((3 sqrt(3)+4)/2, (4 sqrt(3)-3)/2) &nbsp;&nbsp;
(d) ((4 sqrt(3)+3)/2, (4-3 sqrt(3))/2)

**ANSWER: (a)**
```
  X =  4(sqrt(3)/2) + 3(1/2)       = ( 4 sqrt(3) + 3 ) / 2
  Y = -4(1/2)       + 3(sqrt(3)/2) = ( 3 sqrt(3) - 4 ) / 2
```

> **SHORTCUT to eliminate options fast:** `X^2 + Y^2` must equal `16 + 9 = 25`.
> Only option (a) satisfies that. Also, `X` should come out positive and large
> (the point is near the direction we rotated towards), and `Y` small.

---

### Q25
Under a rotation of the axes through any angle, the quantity `x^2 + y^2` for a point

(a) doubles &nbsp;&nbsp; (b) is unchanged &nbsp;&nbsp;
(c) becomes `x^2 - y^2` &nbsp;&nbsp; (d) depends on theta

**ANSWER: (b)**

Rotation does not move the origin and does not stretch anything, so the distance of a
point from the origin cannot change. `X^2 + Y^2 = x^2 + y^2` always.

# PATTERN 6 — Transformed equation after a rotation

### Q26
When the axes are rotated through 45 degrees, `xy = c^2` becomes

(a) X^2 - Y^2 = 2c^2 &nbsp;&nbsp; (b) X^2 + Y^2 = 2c^2 &nbsp;&nbsp;
(c) X^2 - Y^2 = c^2 &nbsp;&nbsp; (d) XY = c^2

**ANSWER: (a)**
```
  At 45 degrees ,   xy = ( X^2 - Y^2 ) / 2

  So   ( X^2 - Y^2 ) / 2 = c^2   ->   X^2 - Y^2 = 2c^2
```

> **SHORTCUT — memorise the 45-degree pair:**
> `x^2 + y^2 = X^2 + Y^2` and `xy = (X^2 - Y^2)/2`.
> With those two lines every 45-degree rotation is a ten-second question.

---

### Q27
When the axes are rotated through 45 degrees, `x^2 - y^2 = a^2` becomes

(a) 2XY = a^2 &nbsp;&nbsp; (b) 2XY = -a^2 &nbsp;&nbsp;
(c) XY = a^2 &nbsp;&nbsp; (d) X^2 - Y^2 = a^2

**ANSWER: (b)**
```
              (X-Y)^2     (X+Y)^2       -4XY
  x^2 - y^2 = -------  -  -------  =  --------  =  -2XY
                 2           2            2

  So   -2XY = a^2   ->   2XY = -a^2
```

Check with `(a, 0)`: new coordinates `(a/sqrt(2), -a/sqrt(2))`, so
`2XY = 2(-a^2/2) = -a^2`. Correct.

---

### Q28
When the axes are rotated through 45 degrees, `3x^2 + 10xy + 3y^2 = 9` becomes

(a) 8X^2 - 2Y^2 = 9 &nbsp;&nbsp; (b) 2X^2 - 8Y^2 = 9 &nbsp;&nbsp;
(c) 8X^2 + 2Y^2 = 9 &nbsp;&nbsp; (d) 3X^2 + 3Y^2 = 9

**ANSWER: (a)**
```
  a = b = 3 , h = 5 , theta = 45 :      a' = a + h = 8 ,   b' = a - h = -2
```

> **SHORTCUT (the biggest time-saver in this chapter):** when `a = b` and the rotation
> is 45 degrees, `a' = a + h` and `b' = a - h`. No trigonometry at all.

---

### Q29
When the axes are rotated through 45 degrees, `17x^2 - 16xy + 17y^2 = 225` becomes

(a) 9X^2 + 25Y^2 = 225 &nbsp;&nbsp; (b) 25X^2 + 9Y^2 = 225 &nbsp;&nbsp;
(c) 9X^2 - 25Y^2 = 225 &nbsp;&nbsp; (d) 16X^2 + 18Y^2 = 225

**ANSWER: (a)**
```
  a = b = 17 , 2h = -16 so h = -8 , theta = 45 :

     a' = a + h = 17 - 8 =  9
     b' = a - h = 17 + 8 = 25
```

---

### Q30
When the axes are rotated through `pi/6`, `x^2 + 2 sqrt(3) xy - y^2 = 2a^2` becomes

(a) X^2 - Y^2 = a^2 &nbsp;&nbsp; (b) X^2 + Y^2 = a^2 &nbsp;&nbsp;
(c) X^2 - Y^2 = 2a^2 &nbsp;&nbsp; (d) XY = a^2

**ANSWER: (a)**
```
  A = 1 , h = sqrt(3) , B = -1 , t = 30

  A' = 1(3/4) + 2 sqrt(3)(1/2)(sqrt(3)/2) + (-1)(1/4) = 3/4 + 3/2 - 1/4 =  2
  B' = 1(1/4) - 3/2 + (-1)(3/4)                       = 1/4 - 3/2 - 3/4 = -2

  2X^2 - 2Y^2 = 2a^2      ->      X^2 - Y^2 = a^2
```

> **SHORTCUT using the invariants:** `A + B = 0` and `AB - h^2 = -1 - 3 = -4`. So
> `a'` and `b'` are the roots of `t^2 - 0.t - 4 = 0`, i.e. `t = 2` and `t = -2`.
> That gives `2X^2 - 2Y^2 = 2a^2` immediately.

---

### Q31
When the axes are rotated through any angle theta, `x^2 + y^2 = a^2` becomes

(a) X^2 + Y^2 = a^2 &nbsp;&nbsp; (b) X^2 - Y^2 = a^2 &nbsp;&nbsp;
(c) depends on theta &nbsp;&nbsp; (d) XY = a^2

**ANSWER: (a)**

A circle centred at the origin looks the same from every angle. The rotation leaves it
completely untouched.

---

### Q32
When the axes are rotated through an angle `alpha`, the line
`x cos(alpha) + y sin(alpha) = p` becomes

(a) X = p &nbsp;&nbsp; (b) Y = p &nbsp;&nbsp; (c) X + Y = p &nbsp;&nbsp; (d) X = -p

**ANSWER: (a)**
```
  x cos a + y sin a
     = (X cos a - Y sin a) cos a + (X sin a + Y cos a) sin a
     = X (cos^2 a + sin^2 a) + Y (0)
     = X
```

> **SHORTCUT:** `x cos a + y sin a = p` is the normal form of a line whose
> perpendicular from the origin points at angle `alpha`. Rotate the axes by `alpha`
> and that perpendicular becomes the new X-axis, so the line is `X = p`.

# PATTERN 7 — The angle that removes the xy term

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |                          coefficient of xy                           |
  |     tan( 2 theta )  =  ---------------------                         |
  |                              a  -  b                                 |
  |                                                                      |
  |     a = b   ->   theta = 45 degrees , every time                     |
  |                                                                      |
  |     REMEMBER TO HALVE. It is tan(2 theta), not tan(theta).           |
  |                                                                      |
  +----------------------------------------------------------------------+
```

### Q33
The angle through which the axes must be rotated to remove the xy term from
`3x^2 + 10xy + 3y^2 = 9` is

(a) 30 deg &nbsp;&nbsp; (b) 45 deg &nbsp;&nbsp; (c) 60 deg &nbsp;&nbsp; (d) 90 deg

**ANSWER: (b)** — `a = b = 3`, so `theta = 45` degrees straight away.

---

### Q34
The angle of rotation that removes the xy term from `x^2 + 2 sqrt(3) xy - y^2 = 2a^2` is

(a) 15 deg &nbsp;&nbsp; (b) 30 deg &nbsp;&nbsp; (c) 45 deg &nbsp;&nbsp; (d) 60 deg

**ANSWER: (b)**
```
                  2 sqrt(3)
  tan(2 theta) = ----------- = sqrt(3)   ->   2 theta = 60   ->   theta = 30
                   1 - (-1)
```

> **TRAP in option (d):** 60 degrees is `2 theta`, not `theta`. Halve it.

---

### Q35
The angle of rotation that removes the xy term from `6x^2 + 5xy - 6y^2 = 0` is

(a) (1/2) tan^-1(5/12) &nbsp;&nbsp; (b) tan^-1(5/12) &nbsp;&nbsp;
(c) (1/2) tan^-1(12/5) &nbsp;&nbsp; (d) 45 degrees

**ANSWER: (a)**
```
                      5          5
  tan(2 theta) = ---------- = ------      ->    theta = (1/2) tan^-1 (5/12)
                  6 - (-6)      12
```

---

### Q36
The angle of rotation that removes the xy term from `2x^2 + sqrt(3) xy + 3y^2 = 0` is

(a) 30 deg &nbsp;&nbsp; (b) 45 deg &nbsp;&nbsp; (c) 60 deg &nbsp;&nbsp; (d) 75 deg

**ANSWER: (c)**
```
                   sqrt(3)
  tan(2 theta) = ----------- = -sqrt(3)
                    2 - 3

  2 theta = 120 degrees        ->        theta = 60 degrees
```

> **SHORTCUT:** a NEGATIVE `tan(2 theta)` means `2 theta` is in the second quadrant,
> so `2 theta = 180 - (the acute angle)`. Here `180 - 60 = 120`, giving `theta = 60`.
> Never report a negative angle for this question.

---

### Q37
The angle of rotation that removes the xy term from
`4x^2 + 2 sqrt(3) xy + 2y^2 = 1` is

(a) 15 deg &nbsp;&nbsp; (b) 30 deg &nbsp;&nbsp; (c) 45 deg &nbsp;&nbsp; (d) 60 deg

**ANSWER: (b)**
```
                  2 sqrt(3)
  tan(2 theta) = ----------- = sqrt(3)   ->   2 theta = 60   ->   theta = 30
                    4 - 2
```

# PATTERN 8 — The invariants

### Q39
If the axes are rotated and `5x^2 + 4xy + 2y^2` becomes `a'X^2 + 2h'XY + b'Y^2`, then
`a' + b'` equals

(a) 5 &nbsp;&nbsp; (b) 7 &nbsp;&nbsp; (c) 2 &nbsp;&nbsp; (d) depends on theta

**ANSWER: (b)** — `a + b` is invariant, and `5 + 2 = 7`.

### Q40
For the same expression `5x^2 + 4xy + 2y^2`, the value of `a'b' - h'^2` after any
rotation is

(a) 10 &nbsp;&nbsp; (b) 6 &nbsp;&nbsp; (c) 14 &nbsp;&nbsp; (d) 4

**ANSWER: (b)**
```
  ab - h^2 = (5)(2) - (2)^2 = 10 - 4 = 6           and it is invariant.
```

### Q41
If the xy term of `3x^2 + 10xy + 3y^2` is removed by a rotation, the new coefficients
of `X^2` and `Y^2` are

(a) 8 and -2 &nbsp;&nbsp; (b) 6 and 0 &nbsp;&nbsp;
(c) 5 and 1 &nbsp;&nbsp; (d) 4 and 2

**ANSWER: (a)**

> **THE KILLER SHORTCUT.** With `h' = 0`, the two invariants say
> `a' + b' = a + b` and `a'b' = ab - h^2`. So `a'` and `b'` are the roots of
> ```
>    t^2  -  (a + b) t  +  ( ab - h^2 )  =  0
> ```
> Here: `t^2 - 6t - 16 = 0`, giving `t = 8` and `t = -2`. **No trigonometry.**

### Q43
Two points are 13 units apart. The origin is shifted to (5, -2) and then the axes are
rotated through 37 degrees. The distance between the two points is now

(a) 13 &nbsp;&nbsp; (b) 13 cos 37 &nbsp;&nbsp; (c) 26 &nbsp;&nbsp; (d) cannot be found

# PATTERN 9 — Naming the conic without transforming anything

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |     ab - h^2  >  0    ->    ELLIPSE  type   (circle if a=b and h=0)  |
  |     ab - h^2  =  0    ->    PARABOLA type                            |
  |     ab - h^2  <  0    ->    HYPERBOLA type                           |
  |                                                                      |
  |     This works because ab - h^2 is a rotation invariant, so it       |
  |     tells you the shape without doing the transformation.            |
  |                                                                      |
  +----------------------------------------------------------------------+
```

### Q45
The curve `2x^2 + 4xy + 5y^2 - 4x - 22y + 7 = 0` is

(a) a circle &nbsp;&nbsp; (b) an ellipse &nbsp;&nbsp;
(c) a parabola &nbsp;&nbsp; (d) a hyperbola

**ANSWER: (b)**
```
  ab - h^2 = (2)(5) - (2)^2 = 6 > 0        ->  ellipse type
  (a is not equal to b, so it is not a circle)
```

---

### Q46
The curve `3x^2 + 10xy + 3y^2 - 2x - 14y - 13 = 0` is

(a) a circle &nbsp;&nbsp; (b) an ellipse &nbsp;&nbsp;
(c) a parabola &nbsp;&nbsp; (d) a hyperbola

**ANSWER: (d)**
```
  ab - h^2 = 9 - 25 = -16 < 0              ->  hyperbola
```
(In fact the full reduction gives `X^2 - Y^2/4 = 1` about the centre `(2, -1)`.)

### Q47
The curve `x^2 - 4xy + 4y^2 + 6x - 8y + 5 = 0` is

(a) a circle &nbsp;&nbsp; (b) an ellipse &nbsp;&nbsp;
(c) a parabola &nbsp;&nbsp; (d) a hyperbola

**ANSWER: (c)**
```
  a = 1 , 2h = -4 so h = -2 , b = 4

  ab - h^2 = 4 - 4 = 0                     ->  parabola type
```

> **SHORTCUT:** `x^2 - 4xy + 4y^2` is a perfect square, `(x - 2y)^2`. A perfect square
> in the second degree part always means `ab - h^2 = 0`, hence a parabola (or a pair
> of parallel lines). Spot the square and you are done.

### Q48
The number of independent invariants of `ax^2 + 2hxy + by^2` under a rotation of the
axes is

(a) 0 &nbsp;&nbsp; (b) 1 &nbsp;&nbsp; (c) 2 &nbsp;&nbsp; (d) 3

**ANSWER: (c)** — `a + b` and `ab - h^2`.

  +----------------------------------+-------------------------------------+

  |   the new coordinates"           |  Do not expand anything.            |
  +----------------------------------+-------------------------------------+
  |  "find the ORIGINAL point"       |  ADD. x = X+h , y = Y+k.            |
  +----------------------------------+-------------------------------------+
  |  "find the point to which the    |  h = x - X , k = y - Y.             |
  |   origin must be shifted so      |  Old minus new.                     |
  |   that (x,y) becomes (X,Y)"      |                                     |
  +----------------------------------+-------------------------------------+
  |  "remove the first degree terms" |  If NO xy: alpha = -g/a ,           |
  |   or "find the CENTRE of the     |            beta  = -f/b.            |
  |   conic"                         |  If xy: alpha = (hf-bg)/(ab-h^2) ,  |
  |   (they are the SAME question)   |         beta  = (gh-af)/(ab-h^2).   |
  |                                  |  HALVE the x, y, xy coefficients    |
  |                                  |  first.                             |
  +----------------------------------+-------------------------------------+
  |  a circle, "shift the origin"    |  The answer is the centre (-g, -f). |
  |                                  |  New equation X^2+Y^2 = g^2+f^2-c.  |

  |  "the new constant term"         |  c' = g.alpha + f.beta + c.         |

  |  coefficient of x^2 EQUALS       |  theta = 45 degrees. Stop. Do not   |
  |  coefficient of y^2              |  divide by zero.                    |

  |  a = b and theta = 45            |  a' = a + h , b' = a - h.           |

  +----------------------------------+-------------------------------------+
  |  "the new coefficients after     |  Roots of                           |

  +----------------------------------+-------------------------------------+
  |  a 45 degree rotation of any     |  Use x^2+y^2 = X^2+Y^2 and          |
  |  equation                        |  xy = (X^2-Y^2)/2. Ten seconds.     |
  +----------------------------------+-------------------------------------+

  +----------------------------------+-------------------------------------+

  |  "name the conic"                |  ab-h^2 > 0 ellipse , = 0 parabola ,|
  |                                  |  < 0 hyperbola. Do not transform.   |
  +----------------------------------+-------------------------------------+
  |  new coordinates after a         |  Check X^2+Y^2 = x^2+y^2 to knock   |
  |  rotation, four ugly options     |  out three of the four options.     |

  |  EAPCET and you are stuck        |  There is NO negative marking.      |
  |                                  |  Guess. Never leave a blank.        |
  +----------------------------------+-------------------------------------+
```

## The five numbers to have in your head before you walk in

```
  1.  X = x - h ,  Y = y - k                      (translation, a point)
  2.  alpha = -g/a ,  beta = -f/b                 (no xy term)
  3.  alpha = (hf-bg)/(ab-h^2) , beta = (gh-af)/(ab-h^2)
  4.  tan(2 theta) = 2h/(a-b) ,  and a=b gives 45 degrees
  5.  a+b and ab-h^2 are invariant
```

Five lines. That is genuinely all this chapter can ask you in a competitive exam.
