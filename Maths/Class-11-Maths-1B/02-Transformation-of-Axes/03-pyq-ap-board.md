## Topic: Translation applied to a point

### Q A1  (very frequently asked)
When the origin is shifted to the point (3, -4) by the translation of axes, find the
new coordinates of the point (2, 5).

**ANSWER:**
```
  Formula:  X = x - h ,  Y = y - k        with  h = 3 , k = -4

  X = 2 - 3       = -1
  Y = 5 - (-4)    = 5 + 4  =  9
```
**New coordinates: ( -1 , 9 )**

Check by going back: `x = X + h = -1 + 3 = 2` and `y = Y + k = 9 - 4 = 5`. Correct.

---

### Q A2
When the origin is shifted to (-1, 2), find the new coordinates of the point (4, -3).

**ANSWER:**
```
  h = -1 ,  k = 2

  X = 4 - (-1)    = 5
  Y = -3 - 2      = -5
```
**New coordinates: ( 5 , -5 )**

---

### Q A3  (very frequently asked)
Find the point to which the origin is to be shifted so that the point (3, 0) may
change to (2, -3).

**ANSWER:**
```
  We need  X = 2  and  Y = -3  for the point  x = 3 , y = 0.

  X = x - h    ->    2 = 3 - h     ->    h = 1
  Y = y - k    ->   -3 = 0 - k     ->    k = 3
```
**The origin must be shifted to ( 1 , 3 ).**

Check: `X = 3 - 1 = 2` and `Y = 0 - 3 = -3`. Correct.

---

### Q A4
Find the point to which the origin should be shifted so that the point (-1, 4) becomes
(3, -2).

**ANSWER:**
```
  h = x - X = -1 - 3   = -4
  k = y - Y =  4 - (-2) = 6
```
**The origin must be shifted to ( -4 , 6 ).**

Check: `X = -1 - (-4) = 3` and `Y = 4 - 6 = -2`. Correct.

---

### Q A5
The origin is shifted to (2, 3). The new coordinates of a point P are (4, -3). Find
the original coordinates of P.

**ANSWER:**
```
  Going backwards, so use the PLUS version:

  x = X + h = 4 + 2   = 6
  y = Y + k = -3 + 3  = 0
```
**P was ( 6 , 0 ).**

> **TRAP:** "Find the ORIGINAL coordinates" means ADD. "Find the NEW coordinates"
> means SUBTRACT. Read which one is being asked before you write anything.

---

### Q A6
When the origin is shifted to (-2, 3), what are the new coordinates of the old origin?

**ANSWER:**
```
  The old origin is the point (0, 0) in the old system.

  X = 0 - (-2)  = 2
  Y = 0 - 3     = -3
```
**( 2 , -3 )**

This makes sense: if you walk 2 left and 3 up to reach the new origin, then from there
the old origin is 2 right and 3 down.

## Topic: Translation applied to a curve

### Q A7  (very frequently asked)
When the origin is shifted to the point (-1, 2) by the translation of axes, find the
transformed equation of `x^2 + y^2 + 2x - 4y + 1 = 0`.

**ANSWER:**
```
  x = X - 1 ,   y = Y + 2

  (X - 1)^2 + (Y + 2)^2 + 2(X - 1) - 4(Y + 2) + 1 = 0

  Expand each piece:
      X^2 - 2X + 1
    + Y^2 + 4Y + 4
    + 2X - 2
    - 4Y - 8
    + 1

  X terms  : -2X + 2X          = 0
  Y terms  :  4Y - 4Y          = 0
  constants:  1 + 4 - 2 - 8 + 1 = -4
```
**Transformed equation: `X^2 + Y^2 - 4 = 0`, i.e. `X^2 + Y^2 = 4`**

Check with the point `(-1, 0)`, which is on the old curve
(`1 + 0 - 2 - 0 + 1 = 0`). Its new coordinates are `(0, -2)`, and `0 + 4 = 4`. Correct.

---

### Q A8
Find the transformed equation of the straight line `3x - 4y + 7 = 0` when the origin is
shifted to (1, -2).

**ANSWER:**
```
  x = X + 1 ,   y = Y - 2

  3(X + 1) - 4(Y - 2) + 7  =  3X + 3 - 4Y + 8 + 7  =  3X - 4Y + 18
```
**`3X - 4Y + 18 = 0`**

Notice the coefficients 3 and -4 are unchanged, so the slope is unchanged. That is
always true for a translation.

---

### Q A9
When the origin is shifted to (2, 3), find the transformed equation of
`2x + 3y - 5 = 0`.

**ANSWER:**
```
  x = X + 2 ,   y = Y + 3

  2(X + 2) + 3(Y + 3) - 5  =  2X + 4 + 3Y + 9 - 5  =  2X + 3Y + 8
```
**`2X + 3Y + 8 = 0`**

Check: `(1, 1)` is on the old line. New coordinates `(-1, -2)`:
`2(-1) + 3(-2) + 8 = -2 - 6 + 8 = 0`. Correct.

---

### Q A10
When the origin is shifted to (1, 2), the transformed equation of a curve is
`X^2 + Y^2 - 4 = 0`. Find the original equation.

**ANSWER:**
```
  Going backwards, so use   X = x - 1 ,  Y = y - 2

  (x - 1)^2 + (y - 2)^2 - 4  =  x^2 - 2x + 1 + y^2 - 4y + 4 - 4
                             =  x^2 + y^2 - 2x - 4y + 1
```
**`x^2 + y^2 - 2x - 4y + 1 = 0`**

Check: `(3, 2)` gives `9 + 4 - 6 - 8 + 1 = 0`. Yes. Its new coordinates are `(2, 0)`
and `4 + 0 - 4 = 0`. Correct.

## Topic: Removing the first degree terms (the most asked topic)

### Q A11  (the single most repeated question of the chapter)
Find the point to which the origin is to be shifted so that the equation
`x^2 + y^2 - 4x + 6y - 12 = 0` has no first degree terms.

**ANSWER:**
```
  No xy term, so complete the square:

     (x^2 - 4x) + (y^2 + 6y) - 12 = 0

     (x - 2)^2 - 4  +  (y + 3)^2 - 9  - 12 = 0

     (x - 2)^2 + (y + 3)^2 = 25
```
**The origin must be shifted to ( 2 , -3 ). The new equation is `X^2 + Y^2 = 25`.**

Faster route: `alpha = -g/a` and `beta = -f/b` with `2g = -4` so `g = -2`, and
`2f = 6` so `f = 3`. Then `alpha = 2` and `beta = -3`. Same answer.

---

### Q A12
Find the point to which the origin is to be shifted to remove the first degree terms
from `x^2 + y^2 - 5x + 2y - 5 = 0`.

**ANSWER:**
```
  a = 1 , b = 1 ,  2g = -5 so g = -5/2 ,  2f = 2 so f = 1

  alpha = -g/a = 5/2
  beta  = -f/b = -1
```
**( 5/2 , -1 )**

The new equation, if wanted:
```
  c' = g.alpha + f.beta + c = (-5/2)(5/2) + (1)(-1) + (-5) = -25/4 - 6 = -49/4

  ->   X^2 + Y^2 = 49/4
```

---

### Q A13
Find the point to which the origin is to be shifted so that
`4x^2 + 9y^2 - 8x + 36y + 4 = 0` has no first degree terms.

**ANSWER:**
```
  a = 4 , b = 9 ,  2g = -8 so g = -4 ,  2f = 36 so f = 18

  alpha = -g/a = 4/4  =  1
  beta  = -f/b = -18/9 = -2
```
**( 1 , -2 )**

Check by completing the square: `4(x-1)^2 + 9(y+2)^2 = 36`. Correct.

---

### Q A14
Find the point to which the origin is to be shifted to remove the first degree terms
from `3x^2 + 2y^2 + 12x - 4y + 5 = 0`.

**ANSWER:**
```
  a = 3 , b = 2 ,  2g = 12 so g = 6 ,  2f = -4 so f = -2

  alpha = -g/a = -6/3 = -2
  beta  = -f/b =  2/2 =  1
```
**( -2 , 1 )**

New equation: `c' = (6)(-2) + (-2)(1) + 5 = -12 - 2 + 5 = -9`, so `3X^2 + 2Y^2 = 9`.

### Q A15  (with an xy term — a favourite)
Find the point to which the origin is to be shifted so as to remove the first degree
terms from `2x^2 + 4xy + 5y^2 - 4x - 22y + 7 = 0`.

**ANSWER:**
```
  a = 2 ,  2h = 4  -> h = 2 ,  b = 5 ,
  2g = -4 -> g = -2 ,  2f = -22 -> f = -11 ,  c = 7

  ab - h^2 = 10 - 4 = 6

           h f - b g     (2)(-11) - (5)(-2)     -22 + 10     -12
  alpha = ----------- = -------------------- = ---------- = ----- = -2
           ab - h^2              6                 6           6

           g h - a f     (-2)(2) - (2)(-11)      -4 + 22       18
  beta  = ----------- = -------------------- = ---------- = ----- =  3
           ab - h^2              6                 6           6
```
**( -2 , 3 )**

### Q A16
Find the point to which the origin is to be shifted to remove the first degree terms
from `x^2 - 2xy + 3y^2 - 4x + 8y + 5 = 0`.

**ANSWER:**
```
  a = 1 , 2h = -2 -> h = -1 , b = 3 , 2g = -4 -> g = -2 , 2f = 8 -> f = 4

  ab - h^2 = 3 - 1 = 2

           (-1)(4) - (3)(-2)      -4 + 6      2
  alpha = ------------------- = ---------- = --- = 1
                    2                2        2

           (-2)(-1) - (1)(4)       2 - 4     -2
  beta  = ------------------- = ---------- = ---- = -1
                    2                2        2
```
**( 1 , -1 )**

## Topic: Rotation applied to a point

### Q A17  (very frequently asked)
Find the new coordinates of the point (1, 1) when the axes are rotated through an angle
of 45 degrees.

**ANSWER:**
```
  cos 45 = sin 45 = 1/sqrt(2)

  X =  x cos t + y sin t = 1/sqrt(2) + 1/sqrt(2) = 2/sqrt(2) = sqrt(2)
  Y = -x sin t + y cos t = -1/sqrt(2) + 1/sqrt(2) = 0
```
**( sqrt(2) , 0 )**

Sensible: `(1, 1)` lies on the line `y = x`, which is exactly the direction of the new
X-axis, so its new Y-coordinate must be zero.

---

### Q A18
Find the new coordinates of (4, 3) when the axes are rotated through 30 degrees.

**ANSWER:**
```
  cos 30 = sqrt(3)/2 ,  sin 30 = 1/2

  X =  4(sqrt(3)/2) + 3(1/2)        = 2 sqrt(3) + 3/2  = ( 4 sqrt(3) + 3 ) / 2
  Y = -4(1/2)       + 3(sqrt(3)/2)  = -2 + 3 sqrt(3)/2 = ( 3 sqrt(3) - 4 ) / 2
```
**( (4 sqrt(3) + 3)/2 , (3 sqrt(3) - 4)/2 )**

Check: `X^2 + Y^2` must equal `16 + 9 = 25`.
```
  X^2 = (57 + 24 sqrt(3))/4        Y^2 = (43 - 24 sqrt(3))/4

  X^2 + Y^2 = 100/4 = 25                              CORRECT.
```

---

### Q A19
Find the new coordinates of (-2, 4) when the axes are rotated through 90 degrees.

**ANSWER:**
```
  cos 90 = 0 ,  sin 90 = 1

  X =  (-2)(0) + (4)(1) =  4
  Y = -(-2)(1) + (4)(0) =  2
```
**( 4 , 2 )**

Check: `4 + 16 = 20` and `16 + 4 = 20`. Same distance from the origin. Correct.

## Topic: Rotation applied to a curve, and the angle

### Q A20  (very frequently asked)
Find the angle of rotation of the axes needed to remove the xy term from
`3x^2 + 10xy + 3y^2 = 9`.

**ANSWER:**
```
  a = 3 ,  b = 3 ,  so  a = b.

  Then a - b = 0, tan(2 theta) is infinite, so 2 theta = 90 degrees.
```
**theta = 45 degrees ( pi/4 )**

---

### Q A21
Find the angle through which the axes are to be rotated to remove the xy term from
`x^2 + 2 sqrt(3) xy - y^2 = 2a^2`.

**ANSWER:**
```
  Coefficient of x^2 is 1 , of y^2 is -1 , of xy is 2 sqrt(3).

                   2 sqrt(3)     2 sqrt(3)
  tan(2 theta) = ------------ = ----------- = sqrt(3)
                   1 - (-1)          2

  2 theta = 60 degrees      ->      theta = 30 degrees
```
**theta = 30 degrees ( pi/6 )**

---

### Q A22
Find the angle of rotation that removes the xy term from `6x^2 + 5xy - 6y^2 = 0`.

**ANSWER:**
```
  a = 6 ,  b = -6 ,  coefficient of xy = 5

                      5          5
  tan(2 theta) = ---------- = ------
                  6 - (-6)      12
```
**theta = (1/2) tan^-1 ( 5/12 )**

> Leave it in this form. Do not reach for a calculator — the inverse-tan form IS the
> answer the marking scheme wants.

### Q A23
Find the angle of rotation that removes the xy term from
`x^2 + 4xy + y^2 - 2x + 2y - 6 = 0`.

**ANSWER:**
```
  Only a, h and b matter. Ignore the first degree terms completely.

  a = 1 ,  b = 1 ,  so a = b   ->   theta = 45 degrees
```
**theta = 45 degrees ( pi/4 )**

### Q A24
When the axes are rotated through 45 degrees, find the transformed equation of
`xy = c^2`.

**ANSWER:**
```
        X - Y                X + Y
  x = ---------      y = ---------
      sqrt(2)             sqrt(2)

         (X - Y)(X + Y)      X^2 - Y^2
  xy  = ---------------- = -------------
               2                 2

  So    (X^2 - Y^2)/2 = c^2
```
**`X^2 - Y^2 = 2c^2`**

Check with `(c, c)`, which is on `xy = c^2`. Its new coordinates are
`X = 2c/sqrt(2) = c sqrt(2)` and `Y = 0`. Then `X^2 - Y^2 = 2c^2`. Correct.

---

### Q A25
When the axes are rotated through 45 degrees, find the transformed equation of
`x^2 - y^2 = a^2`.

**ANSWER:**
```
             (X - Y)^2       (X + Y)^2
  x^2 - y^2 = --------- - ------------
                  2             2

              ( X^2 - 2XY + Y^2 ) - ( X^2 + 2XY + Y^2 )      -4XY
            = ---------------------------------------- =  -------- = -2XY
                                2                             2

  So   -2XY = a^2
```
**`2XY = -a^2`, i.e. `XY = -a^2 / 2`**

Check with `(a, 0)`, which is on `x^2 - y^2 = a^2`. New coordinates
`X = a/sqrt(2)`, `Y = -a/sqrt(2)`, so `XY = -a^2/2`. Correct.

### Q A26  (theory)
If the axes are rotated through any angle, what happens to `a + b` and to `ab - h^2`
for the equation `ax^2 + 2hxy + by^2 + ... = 0`? Illustrate with `5x^2 + 4xy + 2y^2`.

**ANSWER:**
```
  Both are INVARIANT - they do not change.

       a' + b'        =   a + b       =   5 + 2   =   7
       a'b' - h'^2    =   ab - h^2    =   10 - 4  =   6
```
**`a + b = 7` and `ab - h^2 = 6` no matter what angle is used.**

### Q B1  (the most likely 4-mark question)
Find the point to which the origin is to be shifted so as to remove the first degree
terms from `2x^2 + 4xy + 5y^2 - 4x - 22y + 7 = 0`, and find the transformed equation.

**ANSWER:**

**Step 1 — read off the coefficients.**
```
  a  = 2                            (coefficient of x^2)
  2h = 4    -> h = 2                (coefficient of xy , halved)
  b  = 5                            (coefficient of y^2)
  2g = -4   -> g = -2               (coefficient of x  , halved)
  2f = -22  -> f = -11              (coefficient of y  , halved)
  c  = 7
```

**Step 2 — write the two conditions.**
```
  a.alpha + h.beta + g = 0    ->   2.alpha + 2.beta - 2  = 0
  h.alpha + b.beta + f = 0    ->   2.alpha + 5.beta - 11 = 0
```

**Step 3 — solve them.** Subtracting the first from the second:
```
  3.beta - 9 = 0     ->     beta = 3

  then 2.alpha + 2(3) - 2 = 0   ->   2.alpha = -4   ->   alpha = -2
```
(Or use the ready formula, `ab - h^2 = 6`, giving `alpha = -12/6 = -2` and
`beta = 18/6 = 3`.)

**Step 4 — the new constant.**
```
  c' = g.alpha + f.beta + c = (-2)(-2) + (-11)(3) + 7 = 4 - 33 + 7 = -22
```

**The origin must be shifted to ( -2 , 3 ), and the transformed equation is
`2X^2 + 4XY + 5Y^2 - 22 = 0`.**

**VERIFICATION** — substitute `x = X - 2`, `y = Y + 3` into the original:
```
   2(X - 2)^2       =  2X^2  -  8X          +  8
   4(X - 2)(Y + 3)  =  4XY   + 12X  -  8Y   - 24
   5(Y + 3)^2       =  5Y^2         + 30Y   + 45
  -4(X - 2)         =        -  4X          +  8
 -22(Y + 3)         =               - 22Y   - 66
   +7               =                       +  7

  X terms  : -8 + 12 - 4        =  0                GOOD
  Y terms  : -8 + 30 - 22       =  0                GOOD
  constants:  8 - 24 + 45 + 8 - 66 + 7  =  -22      MATCHES c'
```

### Q B2
Find the point to which the origin is to be shifted so as to remove the first degree
terms from `x^2 - 2xy + 3y^2 - 4x + 8y + 5 = 0`, and find the transformed equation.

**ANSWER:**
```
  a = 1 ,  2h = -2 -> h = -1 ,  b = 3 ,
  2g = -4 -> g = -2 ,  2f = 8 -> f = 4 ,  c = 5

  ab - h^2 = (1)(3) - (-1)^2 = 2

           h f - b g      (-1)(4) - (3)(-2)      -4 + 6
  alpha = ----------- = -------------------- = --------- = 1
           ab - h^2               2                2

           g h - a f      (-2)(-1) - (1)(4)       2 - 4
  beta  = ----------- = -------------------- = --------- = -1
           ab - h^2               2                2

  c' = g.alpha + f.beta + c = (-2)(1) + (4)(-1) + 5 = -1
```
**Shift to ( 1 , -1 ). Transformed equation: `X^2 - 2XY + 3Y^2 - 1 = 0`.**

**VERIFICATION** with `x = X + 1`, `y = Y - 1`:
```
   (X + 1)^2        =   X^2 + 2X            +  1
  -2(X + 1)(Y - 1)  =  -2XY + 2X  -  2Y     +  2
   3(Y - 1)^2       =   3Y^2      -  6Y     +  3
  -4(X + 1)         =        - 4X           -  4
   8(Y - 1)         =              +  8Y    -  8
   +5               =                       +  5

  X : 2 + 2 - 4 = 0        Y : -2 - 6 + 8 = 0       const : -1     ALL GOOD
```

### Q B3
Find the point to which the origin is to be shifted so that
`4x^2 + 9y^2 - 8x + 36y + 4 = 0` loses its first degree terms. Find the new equation
and name the curve.

**ANSWER:**
```
  a = 4 , b = 9 , h = 0 , 2g = -8 -> g = -4 , 2f = 36 -> f = 18 , c = 4

  alpha = -g/a = 4/4  =  1
  beta  = -f/b = -18/9 = -2

  c' = g.alpha + f.beta + c = (-4)(1) + (18)(-2) + 4 = -4 - 36 + 4 = -36
```
**Shift to ( 1 , -2 ). New equation `4X^2 + 9Y^2 = 36`, i.e.**

```
       X^2       Y^2
      -----  +  -----  =  1
        9         4
```

**It is an ELLIPSE with centre `(1, -2)`, semi-major axis 3 along the new X-axis and
semi-minor axis 2 along the new Y-axis.**

**VERIFICATION:** with `x = X + 1`, `y = Y - 2`:
```
  4(X+1)^2 = 4X^2 +  8X +  4
  9(Y-2)^2 = 9Y^2 - 36Y + 36
  -8(X+1)  =       - 8X -  8
  36(Y-2)  =       + 36Y - 72
  +4       =              + 4

  X : 8 - 8 = 0     Y : -36 + 36 = 0     const : 4 + 36 - 8 - 72 + 4 = -36    GOOD
```

### Q B4
When the origin is shifted to the point (2, 3), the transformed equation of a curve is
`X^2 + 3XY - 2Y^2 + 17X - 7Y - 11 = 0`. Find the original equation of the curve.

**ANSWER:**
```
  Going backwards:   X = x - 2 ,   Y = y - 3

    X^2   = (x - 2)^2        =  x^2 - 4x + 4
    3XY   = 3(x - 2)(y - 3)  =  3xy - 9x - 6y + 18
   -2Y^2  = -2(y - 3)^2      = -2y^2 + 12y - 18
   17X    = 17(x - 2)        =  17x - 34
   -7Y    = -7(y - 3)        =  -7y + 21
   -11                       =  -11

  x^2 : 1        xy : 3        y^2 : -2
  x   : -4 - 9 + 17           =  4
  y   : -6 + 12 - 7           = -1
  c   : 4 + 18 - 18 - 34 + 21 - 11  = -20
```
**`x^2 + 3xy - 2y^2 + 4x - y - 20 = 0`**

**VERIFICATION.** Take any point, say `x = 5`, `y = 4`, so `X = 3`, `Y = 1`.
Both expressions must give the same number:
```
  old:  25 + 60 - 32 + 20 - 4 - 20            =  49
  new:   9 +  9 -  2 + 51 - 7 - 11            =  49        MATCH.
```

### Q B5  (very likely if a rotation question appears)
When the axes are rotated through an angle of 45 degrees, find the transformed
equation of `3x^2 + 10xy + 3y^2 = 9`.

**ANSWER:**
```
  cos 45 = sin 45 = 1/sqrt(2) , so

        X - Y                X + Y
  x = ---------  ,     y = ---------
      sqrt(2)              sqrt(2)

               3
  3x^2  =    ----- ( X^2 - 2XY + Y^2 )
               2

               3
  3y^2  =    ----- ( X^2 + 2XY + Y^2 )
               2

  Adding these two, the XY parts cancel:      3X^2 + 3Y^2

              10
  10xy  =   ------ ( X^2 - Y^2 )   =   5X^2 - 5Y^2
              2

  Total :   3X^2 + 3Y^2 + 5X^2 - 5Y^2   =   8X^2 - 2Y^2
```
**`8X^2 - 2Y^2 = 9`**

**CHECK with the invariants:** `a + b = 3 + 3 = 6` and `a' + b' = 8 - 2 = 6`. Match.
`ab - h^2 = 9 - 25 = -16` and `a'b' - h'^2 = -16 - 0 = -16`. Match. Correct.

### Q B6
When the axes are rotated through 45 degrees, find the transformed equation of
`17x^2 - 16xy + 17y^2 = 225`.

Use the two shortcuts at 45 degrees: `x^2 + y^2 = X^2 + Y^2` and `xy = (X^2 - Y^2)/2`.
```
  17x^2 + 17y^2   =  17( x^2 + y^2 )  =  17X^2 + 17Y^2

                       ( X^2 - Y^2 )
  -16xy           = -16 -------------  =  -8X^2 + 8Y^2

### Q B7  (the classic)
When the axes are rotated through an angle `pi/6`, find the transformed equation of
`x^2 + 2 sqrt(3) xy - y^2 = 2a^2`.

**ANSWER:**
```
  cos 30 = sqrt(3)/2 ,  sin 30 = 1/2

  A = 1 ,  2h = 2 sqrt(3) so h = sqrt(3) ,  B = -1

  A' = A cos^2 t + 2h sin t cos t + B sin^2 t

     = (1)(3/4)  +  2 sqrt(3)(1/2)(sqrt(3)/2)  +  (-1)(1/4)

     = 3/4 + 3/2 - 1/4   =   (3 + 6 - 1)/4   =   8/4   =   2

  B' = A sin^2 t - 2h sin t cos t + B cos^2 t

     = (1)(1/4)  -  3/2  +  (-1)(3/4)   =   (1 - 6 - 3)/4   =   -2

  2h' = 2h cos(2t) - (A - B) sin(2t)
      = 2 sqrt(3) cos 60 - (1 + 1) sin 60
      = 2 sqrt(3)(1/2)   - 2(sqrt(3)/2)
      = sqrt(3) - sqrt(3)   =   0
```
So `2X^2 - 2Y^2 = 2a^2`.

**Transformed equation: `X^2 - Y^2 = a^2` — a rectangular hyperbola.**

**VERIFY.** The new point `(a, 0)` has old coordinates
`x = a sqrt(3)/2`, `y = a/2`:
```
  x^2 + 2 sqrt(3) xy - y^2

    = 3a^2/4  +  2 sqrt(3) . (a sqrt(3)/2)(a/2)  -  a^2/4

    = 3a^2/4  +  6a^2/4  -  a^2/4     =     8a^2/4    =    2a^2
```
Equals the right-hand side. Correct.

### Q B8
When the axes are rotated through an angle `alpha`, find the transformed equation of
`x cos(alpha) + y sin(alpha) = p`.

**ANSWER:**
```
  x = X cos a - Y sin a          y = X sin a + Y cos a

  x cos a + y sin a
     = ( X cos a - Y sin a ) cos a  +  ( X sin a + Y cos a ) sin a
     = X cos^2 a - Y sin a cos a  +  X sin^2 a + Y sin a cos a
     = X ( cos^2 a + sin^2 a )  +  Y ( - sin a cos a + sin a cos a )
     = X (1) + Y (0)
     = X
```
**`X = p`**

**Why it makes sense:** `x cos a + y sin a = p` is a line whose perpendicular from the
origin makes angle `alpha` with the x-axis. Turn the axes through `alpha` and that
perpendicular becomes the new X-axis, so the line is simply `X = p`.

### Q B10  (derivation — the theory 4-marker)
Show that the axes must be rotated through an angle `(1/2) tan^-1 ( 2h / (a - b) )` to
remove the xy term from `ax^2 + 2hxy + by^2 = 0`, and that the angle is 45 degrees
when `a = b`.

**ANSWER:**
```
  Rotate through theta. Substitute

     x = X cos t - Y sin t          y = X sin t + Y cos t

  and pick out the coefficient of XY:

     from  a x^2   :   a . 2(cos t)(-sin t)         = -2a sin t cos t
     from  2h xy   :   2h ( cos^2 t - sin^2 t )     =  2h cos(2t)
     from  b y^2   :   b . 2(sin t)(cos t)          =  2b sin t cos t

  Coefficient of XY  =  2h cos(2t)  -  ( a - b ) . 2 sin t cos t

                     =  2h cos(2t)  -  ( a - b ) sin(2t)

  For this to be zero:

       2h cos(2t)  =  ( a - b ) sin(2t)

        sin(2t)          2h
       ---------   =   -------
        cos(2t)         a - b

                          2h                     1          (  2h  )
       tan( 2 theta ) = -------     so  theta = --- tan^-1  ( ------ )
                         a - b                   2          (  a-b )
```

**Special case `a = b`:**
```
  a - b = 0, so tan(2 theta) is undefined (infinite).

  tan(2 theta) is infinite when  2 theta = 90 degrees.

  Therefore  theta = 45 degrees = pi/4.
```

### Q B11  (proof)
Show that `a + b` is invariant under a rotation of the axes.

**ANSWER:**
```
  After a rotation through theta,

     a'  =  a cos^2 t  +  2h sin t cos t  +  b sin^2 t
     b'  =  a sin^2 t  -  2h sin t cos t  +  b cos^2 t

  Add them:

     a' + b'  =  a ( cos^2 t + sin^2 t )  +  b ( sin^2 t + cos^2 t )
                 +  ( 2h sin t cos t  -  2h sin t cos t )

              =  a (1)  +  b (1)  +  0

              =  a  +  b
```
**Hence `a + b` is unchanged by any rotation.**

### Q B12  (proof)
Show that the distance between two points is unchanged when the axes are rotated
through an angle theta.

**ANSWER:**
```
  Let the two points be A(x1, y1) and B(x2, y2). After the rotation,

     X1 =  x1 cos t + y1 sin t          Y1 = -x1 sin t + y1 cos t
     X2 =  x2 cos t + y2 sin t          Y2 = -x2 sin t + y2 cos t

  Write  u = x1 - x2  and  v = y1 - y2. Subtracting,

     X1 - X2 =  u cos t + v sin t
     Y1 - Y2 = -u sin t + v cos t

  Therefore

  (X1-X2)^2 + (Y1-Y2)^2

    = ( u cos t + v sin t )^2  +  ( -u sin t + v cos t )^2

    = u^2 cos^2 t + 2uv sin t cos t + v^2 sin^2 t
      + u^2 sin^2 t - 2uv sin t cos t + v^2 cos^2 t

    = u^2 ( cos^2 t + sin^2 t )  +  v^2 ( sin^2 t + cos^2 t )
                                            [ the cross terms cancel ]

    = u^2 + v^2

    = ( x1 - x2 )^2 + ( y1 - y2 )^2
```
**So the new AB equals the old AB. The distance is invariant.**

### Q B13  (proof)
Show that the area of a triangle is unchanged by a translation of the axes.

**ANSWER:**
```
  Let the vertices be A(x1,y1) , B(x2,y2) , C(x3,y3), and shift the origin
  to (h, k). The new vertices are

     ( x1 - h , y1 - k ) ,  ( x2 - h , y2 - k ) ,  ( x3 - h , y3 - k )

  The area formula uses only DIFFERENCES of the y-coordinates:

     y2' - y3' = ( y2 - k ) - ( y3 - k ) = y2 - y3       ( the k's cancel )
     y3' - y1' = y3 - y1
     y1' - y2' = y1 - y2

  So the new area is

    1
   --- abs( (x1-h)(y2-y3) + (x2-h)(y3-y1) + (x3-h)(y1-y2) )
    2

  The terms containing h add up to

     -h [ (y2-y3) + (y3-y1) + (y1-y2) ]  =  -h [ 0 ]  =  0

  Everything containing h disappears, leaving

    1
   --- abs( x1(y2-y3) + x2(y3-y1) + x3(y1-y2) )   =   the ORIGINAL area
    2
```
**Hence the area is unchanged.**

### Q C1 (revision-grade) — One curve, the full translation treatment

Consider the curve `x^2 + y^2 - 4x + 6y - 12 = 0`.

(a) Find the point to which the origin must be shifted so that the equation has no
first degree terms. **[2]**
(b) Find the transformed equation. **[2]**
(c) Name the curve and state its centre and radius in the ORIGINAL system. **[1]**

```
Comparing with `X^2 + Y^2 = 25` where `X = x - 2` and `Y = y + 3`:

**The origin must be shifted to `(2, -3)`.**

*(Formula route: `a = b = 1`, `2g = -4` so `g = -2`, `2f = 6` so `f = 3`; then
`alpha = -g/a = 2` and `beta = -f/b = -3`. Same.)*

**(b)** `c' = g.alpha + f.beta + c = (-2)(2) + (3)(-3) + (-12) = -4 - 9 - 12 = -25`.

**(c)** It is a **CIRCLE with centre `(2, -3)` and radius `5`** in the original system.
(In the new system it is the circle `X^2 + Y^2 = 25`, centred at the new origin.)

**(d)** Is `(7, -3)` on the old curve?
```
  49 + 9 - 28 - 18 - 12 = 0            YES.

  Its new coordinates:  X = 7 - 2 = 5 ,  Y = -3 - (-3) = 0

  New equation:  5^2 + 0^2 = 25                        CORRECT.
```

**(e)** First check `(-3, -3)` is also on the curve: `9 + 9 + 12 - 18 - 12 = 0`. Yes.
```
  OLD distance:  ( -3 - 7 )^2 + ( -3 - (-3) )^2  =  100 + 0    ->  10

  NEW coordinates:   (7, -3)  ->  ( 5 , 0 )
                     (-3,-3)  ->  ( -5 , 0 )

  NEW distance:  ( -5 - 5 )^2 + ( 0 - 0 )^2  =  100 + 0        ->  10

**Both are 10.** Of course they are — the two points are the ends of a diameter of a

### Q C3 (revision-grade) — The complete reduction of a general conic

Reduce `3x^2 + 10xy + 3y^2 - 2x - 14y - 13 = 0` to its simplest form using a

**ANSWER:**

**STAGE 1 — read off the coefficients. [1]**
```
  a  = 3
  2h = 10   ->  h  =  5
  b  = 3
  2g = -2   ->  g  = -1
  2f = -14  ->  f  = -7

  ab - h^2  =  9 - 25  =  -16          ( not zero, so a centre exists )

  alpha  = ----------- = -------------------- = --------- = ----- =  2
            ab - h^2             -16               -16       -16

            g h - a f      (-1)(5) - (3)(-7)      -5 + 21      16
  beta   = ----------- = -------------------- = ---------- = ----- = -1
            ab - h^2             -16               -16        -16

```
**Shift the origin to `(2, -1)`. The equation becomes `3X^2 + 10XY + 3Y^2 - 8 = 0`.**

**VERIFY STAGE 2** by substituting `x = X + 2`, `y = Y - 1`:
```
   3(X + 2)^2       =  3X^2 + 12X          + 12
  10(X + 2)(Y - 1)  = 10XY  - 10X  + 20Y   - 20
   3(Y - 1)^2       =  3Y^2        -  6Y   +  3

 -14(Y - 1)         =              - 14Y   + 14

  X terms  :  12 - 10 - 2        =  0                          GOOD
  Y terms  :  20 -  6 - 14       =  0                          GOOD
  constants:  12 - 20 + 3 - 4 + 14 - 13   =  -8                MATCHES c'
```

**STAGE 3 — the rotation that kills the xy term. [2]**
```
  In  3X^2 + 10XY + 3Y^2 = 8  we have  a = 3 , b = 3 , so a = b.

       ->    theta = 45 degrees

  Shortcut for a = b at 45 degrees:

       a'  =  a + h  =  3 + 5  =   8
       b'  =  a - h  =  3 - 5  =  -2
```
So the equation becomes
```
      8 X'^2  -  2 Y'^2  =  8
```

**STAGE 4 — tidy up and name the curve. [1]**
```
  Divide throughout by 8:

                    Y'^2
      X'^2   -   --------   =   1

```

**STAGE 5 — VERIFY the rotation with the invariants. [1]**

                         a'b'      = (8)(-2)  = -16               MATCH

**Summary of the whole reduction:**

           |  shift origin to (2, -1)

```

### Q C4 (revision-grade) — All the theory in one answer

(a) Derive the translation formulas `x = X + h`, `y = Y + k`. **[1]**
(b) Derive the rotation formulas `x = X cos t - Y sin t`, `y = X sin t + Y cos t`. **[2]**
(c) Derive the condition `tan(2 theta) = 2h/(a - b)` for removing the xy term, and
    deal with the case `a = b`. **[2]**
(d) Prove that `a + b` is invariant under rotation. **[1]**
(e) Prove that the distance between two points is invariant under translation. **[1]**

**ANSWER:**

**(a) Translation.**
```
  The new origin O' is at (h, k) in the old system, and the new axes are
  parallel to the old ones.

  To travel horizontally from O to a point P you first cover h (from O to
  the foot of O'), then a further X. So the total horizontal displacement is

        x  =  h  +  X          i.e.   x = X + h

  Vertically, in the same way,

        y  =  k  +  Y          i.e.   y = Y + k

  Rearranging gives  X = x - h  and  Y = y - k.
```

**(b) Rotation.**
```
  Let OP = r and let OP make an angle phi with the OLD x-axis. Then

        x = r cos(phi)          y = r sin(phi)

  The origin has not moved, so OP is still r in the new system. But the
  new X-axis has been turned forward by theta, so the angle of OP measured
  from the NEW X-axis is  ( phi - theta ). Therefore

        X = r cos( phi - theta )          Y = r sin( phi - theta )

  Expand:

        X = r cos phi cos t + r sin phi sin t  =   x cos t + y sin t
        Y = r sin phi cos t - r cos phi sin t  =  -x sin t + y cos t

  To invert, multiply the first by cos t, the second by -sin t and add:

        X cos t - Y sin t = x( cos^2 t + sin^2 t ) = x

  Multiply the first by sin t, the second by cos t and add:

        X sin t + Y cos t = y( sin^2 t + cos^2 t ) = y

  Hence   x = X cos t - Y sin t  and  y = X sin t + Y cos t.
```

**(c) The xy-removing angle.**
```
  Substitute x = X cos t - Y sin t and y = X sin t + Y cos t into
  a x^2 + 2h xy + b y^2 and collect the coefficient of XY:

     from a x^2  :  -2a sin t cos t
     from 2h xy  :   2h ( cos^2 t - sin^2 t )  =  2h cos(2t)
     from b y^2  :   2b sin t cos t

  Coefficient of XY  =  2h cos(2t) - ( a - b )( 2 sin t cos t )

                     =  2h cos(2t) - ( a - b ) sin(2t)

  Set it to zero:

     2h cos(2t) = ( a - b ) sin(2t)

                        2h
     tan( 2 theta ) = -------
                       a - b

  IF a = b : the denominator is zero, so tan(2 theta) is infinite,
             which happens when 2 theta = 90 degrees,
             so theta = 45 degrees.
```

**(d) `a + b` is invariant.**
```
  a' = a cos^2 t + 2h sin t cos t + b sin^2 t
  b' = a sin^2 t - 2h sin t cos t + b cos^2 t
       --------------------------------------- add
  a' + b' = a( cos^2 t + sin^2 t ) + b( sin^2 t + cos^2 t ) + 0
          = a + b
```

**(e) Distance is invariant under translation.**
```
  A(x1, y1) -> ( x1 - h , y1 - k )        B(x2, y2) -> ( x2 - h , y2 - k )

  X1 - X2 = ( x1 - h ) - ( x2 - h ) = x1 - x2        ( h cancels )
  Y1 - Y2 = ( y1 - k ) - ( y2 - k ) = y1 - y2        ( k cancels )

  So    ( X1 - X2 )^2 + ( Y1 - Y2 )^2  =  ( x1 - x2 )^2 + ( y1 - y2 )^2

  The new AB equals the old AB.
```
