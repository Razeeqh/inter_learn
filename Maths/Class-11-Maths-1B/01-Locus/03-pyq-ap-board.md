## Topic: The toolbox — distance, midpoint, section, area

### Q A1
Find the distance between the points (2, 3) and (-1, 7).

**ANSWER:**
```
  AB^2 = (-1 - 2)^2 + (7 - 3)^2
       = (-3)^2 + (4)^2
       = 9 + 16
       = 25

  AB   = 5
```
**5 units**

---

### Q A2
Find the value of x if the distance between (x, 2) and (3, 4) is 2 sqrt(2).

**ANSWER:**
```
  (x - 3)^2 + (2 - 4)^2 = (2 sqrt(2))^2 = 8

  (x - 3)^2 + 4 = 8

  (x - 3)^2 = 4

  x - 3 = 2   or   x - 3 = -2

  x = 5       or   x = 1
```
**x = 5 or x = 1**

> Two answers, because a point can be on either side. Give both.

### Q A6
Show that the points (1, 2), (3, 6) and (5, 10) are collinear.

**ANSWER:**
```
  Collinear means the area of the triangle is zero.

  x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)

    = 1(6 - 10) + 3(10 - 2) + 5(2 - 6)
    = 1(-4) + 3(8) + 5(-4)
    = -4 + 24 - 20
    = 0
```
**The area is 0, so the three points are collinear.**

## Topic: Definitions and theory

### Q A7
Define the locus of a point.

**ANSWER:**
```
  The LOCUS of a point is the PATH traced out by that point when it moves
  according to a given geometrical condition.

  The equation of the locus is the equation in x and y satisfied by
  the coordinates of every point on that path.
```

---

### Q A8
State the two conditions a curve must satisfy to be called the locus of a point
obeying a condition K.

**ANSWER:**
```
  (i)   Every point that LIES ON the curve satisfies the condition K.

  (ii)  Every point that SATISFIES the condition K lies on the curve.

  Both must hold. If only (i) holds the curve is too small (some points
  are missing). If only (ii) holds the curve is too big (it contains
  points that do not obey the condition).
```

## Topic: Simple loci

### Q A9
Find the equation of the locus of a point whose distance from the origin is 5.

**ANSWER:**
```
  Let P(x, y).      OP = 5      ->      OP^2 = 25

  x^2 + y^2 = 25
```
**x^2 + y^2 = 25 — a circle, centre the origin, radius 5.**

---

### Q A10
Find the equation of the locus of a point P whose distance from A(2, 3) is 4.

**ANSWER:**
```
  Let P(x, y).      PA^2 = 16

  (x - 2)^2 + (y - 3)^2 = 16

  x^2 - 4x + 4 + y^2 - 6y + 9 = 16

  x^2 + y^2 - 4x - 6y - 3 = 0

  CHECK P(6, 3):  36 + 9 - 24 - 18 - 3 = 0.   And its distance from
                  (2,3) is 4.   Correct.
```
**x^2 + y^2 - 4x - 6y - 3 = 0 — a circle, centre (2, 3), radius 4.**

---

### Q A11
Find the locus of a point which is equidistant from A(2, 0) and B(-2, 0).

**ANSWER:**
```
  Let P(x, y).      PA^2 = PB^2

  (x - 2)^2 + y^2  =  (x + 2)^2 + y^2

  x^2 - 4x + 4  =  x^2 + 4x + 4

  -4x = 4x    ->    8x = 0    ->    x = 0
```
**x = 0 — the y-axis (the perpendicular bisector of AB).**

---

### Q A12
Find the locus of a point which is equidistant from A(1, 2) and B(5, 2).

**ANSWER:**
```
  Let P(x, y).      PA^2 = PB^2

  (x - 1)^2 + (y - 2)^2  =  (x - 5)^2 + (y - 2)^2

  x^2 - 2x + 1  =  x^2 - 10x + 25          (the (y-2)^2 cancels)

  8x = 24     ->     x = 3
```
**x = 3 — a vertical line through the midpoint (3, 2) of AB.**

---

### Q A13
Find the locus of a point P which is equidistant from A(1, 2) and B(1, -2).

**ANSWER:**
```
  Let P(x, y).      PA^2 = PB^2

  (x - 1)^2 + (y - 2)^2  =  (x - 1)^2 + (y + 2)^2

  y^2 - 4y + 4  =  y^2 + 4y + 4

  -8y = 0     ->     y = 0
```
**y = 0 — the x-axis.**

---

### Q A14
Find the locus of a point whose distance from the x-axis is 3.

**ANSWER:**
```
  Let P(x, y). The distance of P from the x-axis is abs(y).

  abs(y) = 3     ->     y = 3   or   y = -3     ->     y^2 = 9
```
**y = 3 and y = -3 (i.e. y^2 = 9) — a pair of horizontal lines.**

> Both lines. Writing only y = 3 loses half the locus.

---

### Q A15
Find the locus of a point which is equidistant from the coordinate axes.

**ANSWER:**
```
  Distance from the y-axis = abs(x) ,   distance from the x-axis = abs(y)

  abs(x) = abs(y)     ->     x^2 = y^2     ->     x^2 - y^2 = 0
```
**x^2 - y^2 = 0, that is y = x and y = -x — a pair of lines through the origin.**

---

### Q A16
Find the locus of a point whose distance from the y-axis is twice its distance
from the x-axis.

**ANSWER:**
```
  abs(x) = 2 abs(y)

  Square:     x^2 = 4y^2      ->      x^2 - 4y^2 = 0
```
**x^2 - 4y^2 = 0, i.e. x = 2y and x = -2y.**

---

### Q A17
Find the equation of the locus of a point P such that the segment joining
A(1, 0) and B(-1, 0) subtends a right angle at P.

**ANSWER:**
```
  Use  (x - x1)(x - x2) + (y - y1)(y - y2) = 0

  (x - 1)(x + 1) + (y - 0)(y - 0) = 0

  x^2 - 1 + y^2 = 0

  x^2 + y^2 = 1
```
**x^2 + y^2 = 1 — the circle on AB as diameter.**

### Q A18
Find the equation of the locus of a point P such that the segment joining
A(2, 3) and B(-1, 5) subtends a right angle at P.

**ANSWER:**
```
  (x - 2)(x + 1) + (y - 3)(y - 5) = 0

  x^2 - x - 2 + y^2 - 8y + 15 = 0

  x^2 + y^2 - x - 8y + 13 = 0

  CHECK:  centre = (1/2, 4) = midpoint of AB.        Correct.
          radius^2 = 1/4 + 16 - 13 = 13/4
          AB^2/4 = (9 + 4)/4 = 13/4.                 Correct.
```
**x^2 + y^2 - x - 8y + 13 = 0**

## Topic: Parameters and naming the curve

### Q A19
Find the locus of the point P(t + 1, 2t - 3) as t varies.

**ANSWER:**
```
  x = t + 1        ->      t = x - 1
  y = 2t - 3

  Substitute:   y = 2(x - 1) - 3 = 2x - 5

  2x - y - 5 = 0

  CHECK  t = 0  ->  P(1, -3):   2 - (-3) - 5 = 0.    Correct.
```
**2x - y - 5 = 0 — a straight line.**

---

### Q A20
Find the locus of the point P(3 cos t, 3 sin t).

**ANSWER:**
```
  x = 3 cos t     ->     cos t = x/3
  y = 3 sin t     ->     sin t = y/3

  Square and add:      x^2/9 + y^2/9 = cos^2 t + sin^2 t = 1

  x^2 + y^2 = 9
```
**x^2 + y^2 = 9 — a circle, centre the origin, radius 3.**

---

### Q A21
Find the locus of the point P(2t, t^2).

**ANSWER:**
```
  x = 2t     ->     t = x/2

  y = t^2 = (x/2)^2 = x^2/4

  x^2 = 4y

  CHECK  t = 1  ->  P(2, 1):   4 = 4(1).    Correct.
```
**x^2 = 4y — a parabola.**

---

### Q A22
What curve does `x^2 + y^2 - 6x + 8y = 0` represent? Give its centre and radius.

**ANSWER:**
```
  Compare with  x^2 + y^2 + 2gx + 2fy + c = 0 :

     2g = -6  ->  g = -3
     2f =  8  ->  f =  4
     c  =  0

  centre = (-g, -f) = (3, -4)

  radius = sqrt(g^2 + f^2 - c) = sqrt(9 + 16 - 0) = sqrt(25) = 5
```
**A circle with centre (3, -4) and radius 5.**

---

### Q A23
What curve does `4x^2 + 9y^2 = 36` represent?

**ANSWER:**
```
  Divide by 36:

     x^2      y^2
    -----  + -----  =  1
      9        4

  Both squares present, SAME sign, DIFFERENT coefficients.
```
**An ellipse.**

---

### Q A24
What curve does `9x^2 - 4y^2 = 36` represent?

**ANSWER:**
```
  Divide by 36:

     x^2      y^2
    -----  - -----  =  1
      4        9

  Both squares present, OPPOSITE signs.
```
**A hyperbola.**

### Q B1  (the single most-repeated locus question)
Find the equation of the locus of a point P which is equidistant from the points
A(-2, 3) and B(4, -5).

**ANSWER:**
```
  Let P(x, y) be any point on the locus.

  Given condition:      PA = PB
  Therefore             PA^2 = PB^2

  (x + 2)^2 + (y - 3)^2  =  (x - 4)^2 + (y + 5)^2

  LHS = x^2 + 4x + 4 + y^2 - 6y + 9  =  x^2 + y^2 + 4x - 6y + 13
  RHS = x^2 - 8x + 16 + y^2 + 10y + 25 = x^2 + y^2 - 8x + 10y + 41

  Cancel x^2 and y^2:

      4x - 6y + 13  =  -8x + 10y + 41

      4x - 6y + 13 + 8x - 10y - 41 = 0

      12x - 16y - 28 = 0

  Divide by 4:        3x - 4y - 7 = 0
```
**Locus: 3x - 4y - 7 = 0, a straight line (the perpendicular bisector of AB).**

```
  CHECK 1 - the midpoint of AB must lie on it.
     midpoint = ( (-2+4)/2 , (3-5)/2 ) = (1, -1)
     3(1) - 4(-1) - 7 = 3 + 4 - 7 = 0.       Correct.

  CHECK 2 - it must be perpendicular to AB.
     slope of AB = (-5 - 3)/(4 + 2) = -8/6 = -4/3
     slope of locus = -a/b = -3/(-4) = 3/4
     product = (-4/3)(3/4) = -1.             Correct.

  CHECK 3 - test a real point.
     Put y = 2:  3x - 8 - 7 = 0  ->  x = 5.  So P(5, 2).
     PA^2 = (5+2)^2 + (2-3)^2 = 49 + 1 = 50
     PB^2 = (5-4)^2 + (2+5)^2 = 1 + 49 = 50.  Equal.  Correct.
```

### Q B2
Find the equation of the locus of a point P such that PA^2 + PB^2 = 26, where
A(1, 2) and B(3, -4).

**ANSWER:**
```
  Let P(x, y).

  PA^2 = (x - 1)^2 + (y - 2)^2 = x^2 - 2x + 1 + y^2 - 4y + 4
  PB^2 = (x - 3)^2 + (y + 4)^2 = x^2 - 6x + 9 + y^2 + 8y + 16

  Add them:

     2x^2 + 2y^2 - 8x + 4y + 30  =  26

     2x^2 + 2y^2 - 8x + 4y + 4 = 0

  Divide by 2:

     x^2 + y^2 - 4x + 2y + 2 = 0
```
**Locus: x^2 + y^2 - 4x + 2y + 2 = 0, a circle with centre (2, -1) and
radius sqrt(3).**

```
  CHECK:  radius^2 = g^2 + f^2 - c = 4 + 1 - 2 = 3.

  Take the point P(2 + sqrt(3), -1) on this circle.
     PA^2 = (1 + sqrt(3))^2 + (-3)^2 = 1 + 2sqrt(3) + 3 + 9 = 13 + 2sqrt(3)
     PB^2 = (sqrt(3) - 1)^2 + (3)^2  = 3 - 2sqrt(3) + 1 + 9 = 13 - 2sqrt(3)
     Sum  = 26.        Correct.
```

> Note the pattern: **PA^2 + PB^2 = constant always gives a CIRCLE**
> (the x^2 and y^2 survive with the same coefficient).

### Q B3
Find the equation of the locus of a point P such that PA^2 - PB^2 = 12, where
A(1, 2) and B(-1, 3).

**ANSWER:**
```
  Let P(x, y).

  PA^2 = (x - 1)^2 + (y - 2)^2 = x^2 - 2x + 1 + y^2 - 4y + 4
  PB^2 = (x + 1)^2 + (y - 3)^2 = x^2 + 2x + 1 + y^2 - 6y + 9

  Subtract, term by term:

     x^2 - x^2        =  0
     (-2x) - (+2x)    = -4x
     1 - 1            =  0
     y^2 - y^2        =  0
     (-4y) - (-6y)    = +2y
     4 - 9            = -5

  So   PA^2 - PB^2 = -4x + 2y - 5

  Set equal to 12:

     -4x + 2y - 5 = 12

     -4x + 2y - 17 = 0        ->        4x - 2y + 17 = 0
```
**Locus: 4x - 2y + 17 = 0, a straight line.**

```
  CHECK:  put y = 0  ->  4x = -17  ->  x = -17/4 , so P(-17/4, 0).
     PA^2 = (-17/4 - 1)^2 + (0 - 2)^2 = (441/16) + 4 = 505/16
     PB^2 = (-17/4 + 1)^2 + (0 - 3)^2 = (169/16) + 9 = 313/16
     PA^2 - PB^2 = 192/16 = 12.        Correct.
```

> Note the pattern: **PA^2 - PB^2 = constant always gives a STRAIGHT LINE**
> (the x^2 and y^2 cancel), and that line is perpendicular to AB.

### Q B4  (Apollonius circle)
Find the equation of the locus of a point P which moves so that its distance from
the origin O is three times its distance from A(4, 0).

**ANSWER:**
```
  Let P(x, y).

  Given:       OP = 3 PA
  Square:      OP^2 = 9 PA^2          (remember to square the 3 as well)

  x^2 + y^2  =  9 [ (x - 4)^2 + y^2 ]

  x^2 + y^2  =  9 ( x^2 - 8x + 16 + y^2 )

  x^2 + y^2  =  9x^2 - 72x + 144 + 9y^2

  0 = 8x^2 + 8y^2 - 72x + 144

  Divide by 8:

     x^2 + y^2 - 9x + 18 = 0
```
**Locus: x^2 + y^2 - 9x + 18 = 0, a circle with centre (9/2, 0) and radius 3/2.**

```
  CHECK 1 - P(3, 0):   9 - 27 + 18 = 0.  On the locus.
            OP = 3 ,  PA = abs(3 - 4) = 1 ,  OP = 3 PA.   Correct.

  CHECK 2 - P(6, 0):   36 - 54 + 18 = 0.  On the locus.
            OP = 6 ,  PA = abs(6 - 4) = 2 ,  OP = 3 PA.   Correct.
```

### Q B5  (Apollonius circle with a proper ratio)
Find the locus of a point P such that PA : PB = 2 : 3, where A(-2, 3) and
B(6, -5).

**ANSWER:**
```
  Let P(x, y).

    PA     2
   ---- = ---     ->     3 PA = 2 PB     ->     9 PA^2 = 4 PB^2
    PB     3

  PA^2 = (x + 2)^2 + (y - 3)^2 = x^2 + y^2 + 4x - 6y + 13
  PB^2 = (x - 6)^2 + (y + 5)^2 = x^2 + y^2 - 12x + 10y + 61

  9( x^2 + y^2 + 4x - 6y + 13 )  =  4( x^2 + y^2 - 12x + 10y + 61 )

  9x^2 + 9y^2 + 36x - 54y + 117  =  4x^2 + 4y^2 - 48x + 40y + 244

  5x^2 + 5y^2 + 84x - 94y - 127 = 0
```
**Locus: 5x^2 + 5y^2 + 84x - 94y - 127 = 0, a circle.**

```
  CHECK - the point dividing AB internally in 2 : 3 must satisfy it,
  because for that point PA : PB is exactly 2 : 3.

        2(6) + 3(-2)     6            2(-5) + 3(3)     -1
   x = ------------- =  ---  ,   y = ------------- =  ----
            5            5                5             5

   P = (6/5, -1/5).  Substitute:

     5(36/25) + 5(1/25) + 84(6/5) - 94(-1/5) - 127
   = 36/5 + 1/5 + 504/5 + 94/5 - 635/5
   = (36 + 1 + 504 + 94 - 635)/5
   = 0.                    Correct.
```

### Q B6  (right angle)
Find the equation of the locus of a point P such that the segment joining
A(2, 1) and B(-3, 4) subtends a right angle at P.

**ANSWER:**
```
  Let P(x, y).

  Condition:  angle APB = 90 degrees, so (slope PA)(slope PB) = -1.

    y - 1       y - 4
   -------  x  -------  =  -1
    x - 2       x + 3

  (y - 1)(y - 4)  =  -(x - 2)(x + 3)

  y^2 - 5y + 4  =  -( x^2 + x - 6 )  =  -x^2 - x + 6

  x^2 + y^2 + x - 5y + 4 - 6 = 0

  x^2 + y^2 + x - 5y - 2 = 0
```
**Locus: x^2 + y^2 + x - 5y - 2 = 0, the circle on AB as diameter.**

```
  Same answer, faster, using the direct formula:
     (x - 2)(x + 3) + (y - 1)(y - 4) = 0
     x^2 + x - 6 + y^2 - 5y + 4 = 0
     x^2 + y^2 + x - 5y - 2 = 0.      Same.

  CHECK 1 - centre = (-1/2, 5/2) = midpoint of A(2,1) and B(-3,4).  Correct.
  CHECK 2 - radius^2 = 1/4 + 25/4 + 2 = 34/4 ;  AB^2/4 = (25+9)/4 = 34/4. Correct.
  CHECK 3 - put y = 0:  x^2 + x - 2 = 0  ->  x = 1 or x = -2.
            Take P(1, 0).   PA direction = (2-1, 1-0) = (1, 1)
                            PB direction = (-3-1, 4-0) = (-4, 4)
            Dot product = -4 + 4 = 0.   Perpendicular.   Correct.
```

### Q B7  (constant area)
Find the equation of the locus of a point P such that the area of the triangle
formed by P, A(1, 1) and B(4, 5) is 5 square units.

**ANSWER:**
```
  Let P(x, y).  Take (x1,y1) = P , (x2,y2) = A(1,1) , (x3,y3) = B(4,5).

     1
    --- abs( x(1 - 5) + 1(5 - y) + 4(y - 1) )  =  5
     2

     Inside:  -4x + 5 - y + 4y - 4  =  -4x + 3y + 1

     1
    --- abs( -4x + 3y + 1 )  =  5

     2
    abs( -4x + 3y + 1 ) = 10

    abs( 4x - 3y - 1 ) = 10           (since abs(-t) = abs(t))

  TWO cases:

     4x - 3y - 1 = 10     ->     4x - 3y - 11 = 0
     4x - 3y - 1 = -10    ->     4x - 3y + 9  = 0
```
**Locus: the pair of parallel lines 4x - 3y - 11 = 0 and 4x - 3y + 9 = 0.**

```
  CHECK - one point from each line.

  From 4x - 3y - 11 = 0 with y = 0:  x = 11/4 , P(11/4, 0)
      area = (1/2) abs( (11/4)(1-5) + 1(5-0) + 4(0-1) )
           = (1/2) abs( -11 + 5 - 4 ) = (1/2)(10) = 5.      Correct.

  From 4x - 3y + 9 = 0 with y = 0:  x = -9/4 , P(-9/4, 0)
      area = (1/2) abs( (-9/4)(1-5) + 1(5-0) + 4(0-1) )
           = (1/2) abs( 9 + 5 - 4 ) = (1/2)(10) = 5.        Correct.
```

> **The two-case step is the whole question.** Writing only one line halves
> your marks.

### Q B8  (ellipse)
Find the equation of the locus of a point the sum of whose distances from
A(2, 0) and B(-2, 0) is 6.

**ANSWER:**
```
  Let P(x, y).      PA + PB = 6

  sqrt( (x-2)^2 + y^2 )  +  sqrt( (x+2)^2 + y^2 )  =  6

  Isolate one root:

  sqrt( (x+2)^2 + y^2 )  =  6 - sqrt( (x-2)^2 + y^2 )

  Square:

  (x+2)^2 + y^2  =  36 - 12 sqrt( (x-2)^2 + y^2 ) + (x-2)^2 + y^2

  x^2 + 4x + 4  =  36 - 12 sqrt(...) + x^2 - 4x + 4

  8x - 36 = -12 sqrt(...)

  12 sqrt(...) = 36 - 8x

  Divide by 4:      3 sqrt( (x-2)^2 + y^2 )  =  9 - 2x

  Square again:

  9 [ x^2 - 4x + 4 + y^2 ]  =  81 - 36x + 4x^2

  9x^2 - 36x + 36 + 9y^2  =  81 - 36x + 4x^2

  5x^2 + 9y^2 = 45
```
**Locus: 5x^2 + 9y^2 = 45, i.e. x^2/9 + y^2/5 = 1 — an ELLIPSE.**

```
  CHECK 1 - P(3, 0):   PA = 1 , PB = 5 , sum = 6.      Correct.
                       5(9) + 0 = 45.   On the curve.  Correct.

  CHECK 2 - P(0, sqrt(5)):  PA = sqrt(4 + 5) = 3 , PB = 3 , sum = 6.  Correct.
                       0 + 9(5) = 45.   On the curve.  Correct.
```

### Q B9  (hyperbola)
Find the equation of the locus of a point the difference of whose distances from
A(-3, 0) and B(3, 0) is 4.

**ANSWER:**
```
  Let P(x, y).      PA - PB = 4

  sqrt( (x+3)^2 + y^2 )  =  4 + sqrt( (x-3)^2 + y^2 )

  Square:

  x^2 + 6x + 9 + y^2  =  16 + 8 sqrt(...) + x^2 - 6x + 9 + y^2

  12x - 16 = 8 sqrt(...)

  Divide by 4:      3x - 4 = 2 sqrt( (x-3)^2 + y^2 )

  Square again:

  9x^2 - 24x + 16  =  4 [ x^2 - 6x + 9 + y^2 ]

  9x^2 - 24x + 16  =  4x^2 - 24x + 36 + 4y^2

  5x^2 - 4y^2 = 20
```
**Locus: 5x^2 - 4y^2 = 20, i.e. x^2/4 - y^2/5 = 1 — a HYPERBOLA.**

```
  CHECK - P(2, 0):   PA = 5 , PB = 1 , difference = 4.     Correct.
                     5(4) - 0 = 20.   On the curve.        Correct.
```

### Q B10  (parabola from focus and directrix)
Find the equation of the locus of a point P whose distance from the point
S(3, 0) is equal to its distance from the line x + 3 = 0.

**ANSWER:**
```
  Let P(x, y).

  PS = distance from P to the line x + 3 = 0 = abs(x + 3)

  Square both sides:

  (x - 3)^2 + y^2  =  (x + 3)^2

  x^2 - 6x + 9 + y^2  =  x^2 + 6x + 9

  y^2 = 12x
```
**Locus: y^2 = 12x — a parabola with vertex at the origin, opening rightwards.**

```
  CHECK - P(3, 6):   y^2 = 36 , 12x = 36.  On the curve.
     Distance to S(3,0) = 6.
     Distance to x = -3 is abs(3 + 3) = 6.       Equal.   Correct.
```

### Q B11  (point equidistant from a point and a line)
Find the locus of a point P which is equidistant from the point A(2, 3) and the
line y = 1.

**ANSWER:**
```
  Let P(x, y).

  PA = distance from P to the line y = 1 = abs(y - 1)

  Square:

  (x - 2)^2 + (y - 3)^2  =  (y - 1)^2

  x^2 - 4x + 4 + y^2 - 6y + 9  =  y^2 - 2y + 1

  x^2 - 4x + 4 - 6y + 9 + 2y - 1 = 0

  x^2 - 4x - 4y + 12 = 0
```
**Locus: x^2 - 4x - 4y + 12 = 0 — a parabola opening upwards.**

```
  CHECK - the vertex should be halfway between A(2,3) and the line y = 1,
          that is at (2, 2).
          4 - 8 - 8 + 12 = 0.   On the curve.
          Distance from (2,2) to A(2,3) = 1 ; distance to y = 1 is 1.  Correct.
```

### Q B12  (midpoint of a sliding rod)
A straight rod of length 12 units slides with its ends on the coordinate axes.
Find the locus of its midpoint.

**ANSWER:**
```
  Let the ends be A(a, 0) on the x-axis and B(0, b) on the y-axis.
  Let P(x, y) be the midpoint of AB.

  From the midpoint formula:

        a + 0                          0 + b
   x = -------  ->  a = 2x        y = -------  ->  b = 2y
          2                              2

  The rod has fixed length 12:

     AB^2 = 144      ->      a^2 + b^2 = 144

  Substitute:

     (2x)^2 + (2y)^2 = 144

     4x^2 + 4y^2 = 144

     x^2 + y^2 = 36
```
**Locus: x^2 + y^2 = 36 — a circle of centre O and radius 6 (half the rod).**

```
  CHECK - rod from A(12,0) to B(0,0):  midpoint (6,0);  36 + 0 = 36.  Correct.
        - rod from A(0,0) to B(0,12):  midpoint (0,6);  0 + 36 = 36.  Correct.
        - rod from A(7.2,0) to B(0,9.6): length^2 = 51.84 + 92.16 = 144. Good.
                                   midpoint (3.6, 4.8);
                                   12.96 + 23.04 = 36.               Correct.
```

### Q B13  (midpoint with a point moving on a circle)
A(-2, 3) is a fixed point and Q moves on the circle x^2 + y^2 = 25.
Find the locus of the midpoint P of AQ.

**ANSWER:**
```
  Let P(x, y) be the midpoint and let Q = (h, k) with  h^2 + k^2 = 25.

  Midpoint formula:

        -2 + h                            3 + k
   x = --------  ->  h = 2x + 2      y = -------  ->  k = 2y - 3
          2                                 2

  Substitute into h^2 + k^2 = 25 :

     (2x + 2)^2 + (2y - 3)^2 = 25

     4x^2 + 8x + 4 + 4y^2 - 12y + 9 = 25

     4x^2 + 4y^2 + 8x - 12y - 12 = 0

  Divide by 4:

     x^2 + y^2 + 2x - 3y - 3 = 0
```
**Locus: x^2 + y^2 + 2x - 3y - 3 = 0 — a circle of radius 5/2 (half the
original), centre (-1, 3/2).**

```
  CHECK - take Q(5, 0), which is on x^2 + y^2 = 25.
          Midpoint of A(-2,3) and Q(5,0) is (3/2, 3/2).
          9/4 + 9/4 + 3 - 9/2 - 3 = 18/4 - 18/4 = 0.       Correct.
```

### Q B14  (point dividing a segment in a ratio)
A(3, -1) is a fixed point and Q moves on the line 2x + 3y = 5. Find the locus of
the point P which divides AQ internally in the ratio 1 : 2.

**ANSWER:**
```
  Let P(x, y) and Q = (h, k) with  2h + 3k = 5.

  P divides A(3,-1) to Q(h,k) in the ratio m : n = 1 : 2 :

        1(h) + 2(3)      h + 6
   x = ------------  =  -------      ->      h = 3x - 6
          1 + 2             3

        1(k) + 2(-1)     k - 2
   y = -------------  = -------      ->      k = 3y + 2
           1 + 2           3

  Substitute into 2h + 3k = 5 :

     2(3x - 6) + 3(3y + 2) = 5

     6x - 12 + 9y + 6 = 5

     6x + 9y - 11 = 0
```
**Locus: 6x + 9y - 11 = 0 — a straight line (parallel to the given line).**

```
  CHECK - take Q(1, 1), which lies on 2x + 3y = 5.
     P = ( (1 + 6)/3 , (1 - 2)/3 ) = (7/3, -1/3)
     6(7/3) + 9(-1/3) - 11 = 14 - 3 - 11 = 0.        Correct.
```

### Q B15  (eliminating a parameter)
Find the locus of the point of intersection of the lines
`x cos(theta) + y sin(theta) = 4` and `x sin(theta) - y cos(theta) = 3`,
where theta is a parameter.

**ANSWER:**
```
  Let P(x, y) be the point of intersection, so BOTH equations hold at P.

  Square both and add:

  (x cos t + y sin t)^2 + (x sin t - y cos t)^2  =  4^2 + 3^2

  First  = x^2 cos^2 t + 2xy sin t cos t + y^2 sin^2 t
  Second = x^2 sin^2 t - 2xy sin t cos t + y^2 cos^2 t

  Adding, the middle terms cancel:

       x^2 ( cos^2 t + sin^2 t ) + y^2 ( sin^2 t + cos^2 t )
     = x^2 + y^2

  So    x^2 + y^2 = 16 + 9 = 25
```
**Locus: x^2 + y^2 = 25 — a circle, centre the origin, radius 5.**

```
  CHECK with theta = 0:  the lines become  x = 4  and  -y = 3 , so P(4, -3).
     16 + 9 = 25.        Correct.
```

### Q C1 (revision-grade)  —  Three loci from the same pair of points

Given the fixed points **A(1, 2)** and **B(5, -2)**, find the equation of the
locus of a point P such that

(a) P is equidistant from A and B **(2 marks)**
(b) PA = 2 PB **(3 marks)**
(c) AB subtends a right angle at P **(2 marks)**

**ANSWER:**

**(a) Equidistant.**
```
  PA^2 = PB^2

  (x - 1)^2 + (y - 2)^2  =  (x - 5)^2 + (y + 2)^2

  x^2 - 2x + 1 + y^2 - 4y + 4  =  x^2 - 10x + 25 + y^2 + 4y + 4

  -2x - 4y + 5  =  -10x + 4y + 29

  8x - 8y - 24 = 0

  x - y - 3 = 0
```
**(a) x - y - 3 = 0, a straight line.**
```
  CHECK: midpoint of AB = (3, 0);  3 - 0 - 3 = 0.               Correct.
         slope AB = (-2-2)/(5-1) = -1 ; slope of locus = 1 ;
         product = -1 (perpendicular).                          Correct.
```

**(b) PA = 2 PB.**
```
  PA^2 = 4 PB^2                      (square the 2 as well)

  x^2 - 2x + 1 + y^2 - 4y + 4  =  4 ( x^2 - 10x + 25 + y^2 + 4y + 4 )

  x^2 + y^2 - 2x - 4y + 5  =  4x^2 + 4y^2 - 40x + 16y + 116

  0 = 3x^2 + 3y^2 - 38x + 20y + 111
```
**(b) 3x^2 + 3y^2 - 38x + 20y + 111 = 0, an Apollonius circle.**
```
  CHECK: the point dividing AB internally in 2 : 1 must satisfy it.

         ( (2(5) + 1(1))/3 , (2(-2) + 1(2))/3 )  =  ( 11/3 , -2/3 )

         3(121/9) + 3(4/9) - 38(11/3) + 20(-2/3) + 111
       = 121/3 + 4/3 - 418/3 - 40/3 + 333/3
       = (121 + 4 - 418 - 40 + 333)/3
       = 0.                                                     Correct.
```

**(c) Right angle at P.**
```
  (x - 1)(x - 5) + (y - 2)(y + 2) = 0

  x^2 - 6x + 5 + y^2 - 4 = 0

  x^2 + y^2 - 6x + 1 = 0
```
**(c) x^2 + y^2 - 6x + 1 = 0, the circle on AB as diameter.**
```
  CHECK: centre = (3, 0) = midpoint of AB.                      Correct.
         radius^2 = 9 - 1 = 8 ;  AB^2/4 = (16 + 16)/4 = 8.      Correct.
         Put x = 1:  1 + y^2 - 6 + 1 = 0  ->  y^2 = 4  ->  y = 2 or -2.
         Take P(1, -2):  PA direction = (0, 4) , PB direction = (4, 0)
         Dot product = 0.  Perpendicular.                       Correct.
```

### Q C2 (revision-grade)  —  A sliding rod, two different tracked points

A rod AB of length 15 units slides with A on the x-axis and B on the y-axis.
Find the locus of

(a) the midpoint of AB **(3 marks)**
(b) the point P on AB such that AP : PB = 2 : 1 **(4 marks)**

**ANSWER:**

**Setup (common to both parts).**
```
  Let A(a, 0) and B(0, b).  Since AB = 15,

     a^2 + b^2 = 225        ...(*)
```

**(a) The midpoint.**
```
  Let P(x, y) be the midpoint.

     x = a/2  ->  a = 2x           y = b/2  ->  b = 2y

  Put into (*):    4x^2 + 4y^2 = 225

                   x^2 + y^2 = 225/4
```
**(a) x^2 + y^2 = 225/4 — a circle of radius 15/2, half the rod length.**
```
  CHECK: rod from A(15,0) to B(0,0) gives midpoint (7.5, 0);
         56.25 + 0 = 56.25 = 225/4.                              Correct.
         rod from A(9,0) to B(0,12): 81 + 144 = 225, good rod.
         midpoint (4.5, 6): 20.25 + 36 = 56.25.                  Correct.
```

**(b) The point dividing AB in 2 : 1.**
```
  Let P(x, y) divide A(a, 0) to B(0, b) in the ratio m : n = 2 : 1.

        2(0) + 1(a)      a
   x = ------------ =  -----     ->     a = 3x
          2 + 1          3

        2(b) + 1(0)     2b                            3y
   y = ------------ =  ----      ->      b  =  ------
          2 + 1          3                            2

  Put into (*) , that is  a^2 + b^2 = 225 :

                 9 y^2
     9 x^2  +   -------   =  225
                   4

  Divide by 9:

              y^2
     x^2  +  -----  =  25
               4

  That is:      x^2       y^2
               -----  +  -----  =  1
                 25       100
```
**(b) x^2/25 + y^2/100 = 1 — an ELLIPSE (not a circle this time).**
```
  CHECK: a = 15 , b = 0  ->  P = (5, 0):    25/25 + 0 = 1.        Correct.
         a = 0 , b = 15  ->  P = (0, 10):   0 + 100/100 = 1.      Correct.
         a = 9 , b = 12  ->  P = (3, 8):    9/25 + 64/100
                                          = 0.36 + 0.64 = 1.      Correct.
```

> Notice: the **midpoint** gives a circle, but **any other dividing point** gives
> an ellipse. That is a favourite twist.

### Q C3 (revision-grade)  —  Four parameter eliminations

Find the locus of each of the following points as the parameter varies, and name
the curve in each case.

(a) P( 2t , t^2 - 1 ) **(2 marks)**
(b) P( 5 cos t , 5 sin t ) **(1 mark)**
(c) P( 3 sec t , 4 tan t ) **(2 marks)**
(d) the point of intersection of `x cos t + y sin t = a` and
    `x sin t - y cos t = b` **(2 marks)**

**ANSWER:**

**(a)**
```
  x = 2t          ->    t = x/2
  y = t^2 - 1     ->    y = (x/2)^2 - 1 = x^2/4 - 1

  Multiply by 4:      4y = x^2 - 4

                      x^2 - 4y - 4 = 0
```
**A PARABOLA.**
```
  CHECK  t = 1  ->  P(2, 0):   4 - 0 - 4 = 0.        Correct.
         t = 0  ->  P(0, -1):  0 + 4 - 4 = 0.        Correct.
         t = 3  ->  P(6, 8):   36 - 32 - 4 = 0.      Correct.
```

**(b)**
```
  cos t = x/5 ,  sin t = y/5

  Square and add:    x^2/25 + y^2/25 = 1     ->     x^2 + y^2 = 25
```
**A CIRCLE, centre the origin, radius 5.**

**(c)**
```
  sec t = x/3 ,  tan t = y/4

  Square and SUBTRACT, using sec^2 t - tan^2 t = 1 :

     x^2      y^2
    -----  - -----  =  1              i.e.   16x^2 - 9y^2 = 144
      9       16
```
**A HYPERBOLA.**
```
  CHECK  t = 0  ->  sec t = 1, tan t = 0, so P(3, 0):
         16(9) - 0 = 144.                             Correct.
```

**(d)**
```
  Square both equations and add. The 2xy sin t cos t terms cancel:

     x^2 (cos^2 t + sin^2 t) + y^2 (sin^2 t + cos^2 t)  =  a^2 + b^2

     x^2 + y^2 = a^2 + b^2
```
**A CIRCLE, centre the origin, radius sqrt(a^2 + b^2).**

### Q C4 (revision-grade)  —  The whole conic zoo from one pair of points

Take the fixed points **A(-4, 0)** and **B(4, 0)**. Find the locus of P in each
case and name the curve.

(a) PA = PB
(b) PA + PB = 10
(c) abs(PA - PB) = 6
(d) angle APB = 90 degrees
(e) PA = 3 PB
(f) area of triangle PAB = 12
(g) PA = distance of P from the line x = 4

**ANSWER:**

**(a) PA = PB.**
```
  (x + 4)^2 + y^2 = (x - 4)^2 + y^2
  8x = -8x   ->   x = 0
```
**x = 0, the y-axis (a straight line).**

**(b) PA + PB = 10.**
```
  Half the constant: a = 5.  Half the distance between A and B: c = 4.
  For an ellipse,  b^2 = a^2 - c^2 = 25 - 16 = 9.

     x^2      y^2
    -----  + -----  =  1        i.e.   9x^2 + 25y^2 = 225
     25        9
```
**An ELLIPSE.**
```
  CHECK  P(5, 0):  PA = 9 , PB = 1 , sum = 10.  9(25) + 0 = 225.   Correct.
         P(0, 3):  PA = 5 , PB = 5 , sum = 10.  0 + 25(9) = 225.   Correct.
```

**(c) abs(PA - PB) = 6.**
```
  a = 3 ,  c = 4.   For a hyperbola,  b^2 = c^2 - a^2 = 16 - 9 = 7.

     x^2      y^2
    -----  - -----  =  1        i.e.   7x^2 - 9y^2 = 63
      9        7
```
**A HYPERBOLA.**
```
  CHECK  P(3, 0):  PA = 7 , PB = 1 , difference = 6.
                   7(9) - 0 = 63.                                  Correct.
```

**(d) angle APB = 90.**
```
  (x + 4)(x - 4) + (y - 0)(y - 0) = 0

  x^2 - 16 + y^2 = 0     ->     x^2 + y^2 = 16
```
**A CIRCLE of radius 4 with AB as diameter.**

**(e) PA = 3 PB.**
```
  PA^2 = 9 PB^2

  (x + 4)^2 + y^2  =  9 [ (x - 4)^2 + y^2 ]

  x^2 + 8x + 16 + y^2  =  9x^2 - 72x + 144 + 9y^2

  0 = 8x^2 + 8y^2 - 80x + 128

  x^2 + y^2 - 10x + 16 = 0
```
**An APOLLONIUS CIRCLE, centre (5, 0), radius 3.**
```
  CHECK  P(2, 0):  4 - 20 + 16 = 0.  On the locus.
                   PA = 6 , PB = 2 , PA = 3 PB.                    Correct.
         P(8, 0):  64 - 80 + 16 = 0.  On the locus.
                   PA = 12 , PB = 4 , PA = 3 PB.                   Correct.
```

**(f) area of triangle PAB = 12.**
```
     1
    --- abs( x(0 - 0) + (-4)(0 - y) + 4(y - 0) )  =  12
     2
     1
    --- abs( 4y + 4y ) = 12       ->      4 abs(y) = 12
     2
                                  ->      abs(y) = 3
```
**y = 3 and y = -3 — a pair of parallel straight lines.**
```
  Sensible: base AB = 8, so (1/2)(8)(height) = 12 gives height = 3.  Correct.
```

**(g) PA = distance from the line x = 4.**
```
  (x + 4)^2 + y^2  =  (x - 4)^2

  x^2 + 8x + 16 + y^2  =  x^2 - 8x + 16

  y^2 = -16x
```
**A PARABOLA opening to the LEFT (vertex at the origin).**
```
  CHECK  P(-1, 4):  y^2 = 16 , -16x = 16.  On the curve.
         PA = distance from (-1,4) to (-4,0) = sqrt(9 + 16) = 5
         distance from (-1,4) to the line x = 4 is abs(-1 - 4) = 5.
         Equal.                                                    Correct.
```
