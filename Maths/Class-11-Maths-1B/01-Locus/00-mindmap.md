# Locus — Mind Map

**Maths 1B · Chapter 1 · The easiest 4 marks in the whole paper**

This is the opening chapter of Maths IB and it is the friendliest one you will meet.
There is **one method**, it never changes, and once you have learned it you can answer
every question in the chapter — even ones you have never seen before.

In the board exam this chapter is normally worth a straight **4 marks (Section B)**,
sometimes with a 2-mark question added. It is not a 7-mark chapter. But those 4 marks
are almost free, and the ideas here (distance formula, section formula, area of a
triangle) are the ideas you will use again in The Straight Line, The Circle, the
Parabola, the Ellipse and the Hyperbola. **Do not skip it.**

## THE WHOLE CHAPTER ON ONE PAGE

```
LOCUS
|
+-- 1. WHAT A LOCUS IS
|     |
|     +-- the PATH traced by a moving point
|     +-- the point obeys one fixed geometrical rule
|     +-- everyday pictures: clock hand tip , goat tied to a peg
|     +-- the answer is always an EQUATION in x and y
|
+-- 2. THE TWO CONDITIONS (the definition, both halves)
|     |
|     +-- (i)  every point ON the path obeys the rule
|     +-- (ii) every point that obeys the rule LIES ON the path
|     +-- if only (i) holds you have too big a curve
|     +-- if only (ii) holds you have missed part of the curve
|
+-- 3. THE FIXED 5-STEP RECIPE          <-- learn this, it is the chapter
|     |
|     +-- STEP 1  let P(x, y) be ANY point on the locus
|     +-- STEP 2  write the geometrical condition in WORDS
|     +-- STEP 3  translate the words into an EQUATION
|     +-- STEP 4  simplify to a relation between x and y
|     +-- STEP 5  state the locus and NAME the curve
|
+-- 4. THE FIVE TRANSLATION TOOLS
|     |
|     +-- distance formula ......... sqrt((x2-x1)^2 + (y2-y1)^2)
|     +-- section formula .......... ((m x2 + n x1)/(m+n) , (m y2 + n y1)/(m+n))
|     +-- midpoint ................. ((x1+x2)/2 , (y1+y2)/2)
|     +-- slope .................... (y2 - y1)/(x2 - x1)
|     +-- perpendicular ........... m1 x m2 = -1
|     +-- area of a triangle ....... 1/2 abs( x1(y2-y3) + x2(y3-y1) + x3(y1-y2) )
|
+-- 5. THE TEN STANDARD LOCI  (every board question is one of these)
|     |
|     +-- (a) equidistant from 2 fixed points ....... PERPENDICULAR BISECTOR
|     +-- (b) fixed distance from a fixed point ..... CIRCLE
|     +-- (c) distances in a fixed RATIO k:1 ........ APOLLONIUS CIRCLE
|     |          (k = 1 gives back the perpendicular bisector)
|     +-- (d) SUM of distances constant ............. ELLIPSE
|     +-- (e) DIFFERENCE of distances constant ...... HYPERBOLA
|     +-- (f) AB subtends a RIGHT ANGLE at P ........ CIRCLE on AB as diameter
|     +-- (g) area of triangle PAB constant ......... TWO PARALLEL LINES
|     +-- (h) distance from a point = distance
|     |          from a line ........................ PARABOLA
|     +-- (i) MIDPOINT of a moving segment .......... depends - usually circle
|     +-- (j) point DIVIDING a segment in a ratio ... shrunk copy of the curve
|
+-- 6. PARAMETER PROBLEMS
|     |
|     +-- the moving point is given as (f(t), g(t))
|     +-- you must ELIMINATE t between the two equations
|     +-- tricks: make t the subject / square and add / use an identity
|     +-- sin^2 + cos^2 = 1  and  sec^2 - tan^2 = 1  do most of the work
|
+-- 7. NAMING THE CURVE FROM THE EQUATION
      |
      +-- ax + by + c = 0 .............................. STRAIGHT LINE
      +-- x^2 + y^2 + 2gx + 2fy + c = 0 ................ CIRCLE
      +-- only ONE square term (y^2 = 4ax type) ........ PARABOLA
      +-- x^2/a^2 + y^2/b^2 = 1 ........................ ELLIPSE
      +-- x^2/a^2 - y^2/b^2 = 1 ........................ HYPERBOLA
      +-- xy = c^2 ..................................... RECTANGULAR HYPERBOLA
```

## THE 60-SECOND VERSION

A **locus** is the path drawn by a point that is moving under a rule.

Think of a goat tied by a 5 metre rope to a peg. The goat can wander, but it can
never get further than 5 metres from the peg. If it keeps the rope tight and walks
around, the path it wears into the grass is a **circle of radius 5**.
That circle is the locus.

The exam does not want you to describe the path in English. It wants the **equation**.
So you do exactly this, every single time:

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |   Let P(x, y) be any point on the locus.                             |
  |   Write the given condition.                                         |
  |   Turn it into an equation using distance / section / slope / area.  |
  |   Clean it up.                                                       |
  |   Say what curve it is.                                              |
  |                                                                      |
  +----------------------------------------------------------------------+
```

That is the entire chapter. Nothing else is examined.

## THE KEY BOX — THE TOOLS THAT TRANSLATE WORDS INTO EQUATIONS

```
  +==========================================================================+
  |                                                                          |
  |   1.  DISTANCE BETWEEN TWO POINTS                                        |
  |                                                                          |
  |          AB  =  sqrt( (x2 - x1)^2  +  (y2 - y1)^2 )                      |
  |                                                                          |
  |       AND THE VERSION YOU ACTUALLY USE (no square roots):                |
  |                                                                          |
  |          AB^2 =  (x2 - x1)^2  +  (y2 - y1)^2                             |
  |                                                                          |
  |       TRIGGER WORDS: "distance", "equidistant", "at a distance of",      |
  |                      "is twice as far from", "sum of the distances"      |
  |                                                                          |
  +--------------------------------------------------------------------------+
  |                                                                          |
  |   2.  SECTION FORMULA   (P divides AB in the ratio m : n)                |
  |                                                                          |
  |               m x2 + n x1        m y2 + n y1                             |
  |          P = ( ------------- ,  ------------- )                          |
  |                  m + n              m + n                                |
  |                                                                          |
  |       MIDPOINT is the case m : n = 1 : 1                                 |
  |                                                                          |
  |               x1 + x2      y1 + y2                                       |
  |          M = ( -------- ,  -------- )                                    |
  |                   2           2                                          |
  |                                                                          |
  |       TRIGGER WORDS: "midpoint", "divides in the ratio", "trisects"      |
  |                                                                          |
  +--------------------------------------------------------------------------+
  |                                                                          |
  |   3.  SLOPE  and the PERPENDICULAR CONDITION                             |
  |                                                                          |
  |                y2 - y1                                                   |
  |          m =  ---------                    m1 x m2  =  -1                |
  |                x2 - x1                                                   |
  |                                                                          |
  |       TRIGGER WORDS: "right angle", "subtends 90 degrees",               |
  |                      "perpendicular", "angle PAB = 90"                   |
  |                                                                          |
  +--------------------------------------------------------------------------+
  |                                                                          |
  |   4.  AREA OF A TRIANGLE FROM THREE VERTICES                             |
  |                                                                          |
  |          1                                                               |
  |     A = --- abs( x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2) )               |
  |          2                                                               |
  |                                                                          |
  |       TRIGGER WORDS: "area of triangle PAB", "collinear" (area = 0)      |
  |                                                                          |
  +==========================================================================+
```

If you can write these four boxes from memory, you can start any locus question
in the book. Everything else is algebra you already know.

## IF YOU ONLY HAVE 2 DAYS

**Day 1 morning — the toolbox (2 hours).**
Write out the four boxes above on one sheet of paper, from memory, five times.
Do not read about locus yet. If the distance formula is not automatic, nothing
else in this chapter will work. Then do 10 pure practice sums:
"find the distance between (2,3) and (-1,7)", "find the midpoint of ...".

**Day 1 evening — the recipe and the two easiest loci (2 hours).**
Learn the 5 steps. Then do these two types only, five questions each:

```
  TYPE 1   equidistant from A and B          ->  PA^2 = PB^2
  TYPE 2   distance from A is constant r     ->  PA^2 = r^2
```

Both are one line of setup and two lines of algebra. Between them they are the
most-asked shapes in the chapter.

**Day 2 morning — the three money-makers (2.5 hours).**
These three are what the actual 4-mark question usually is:

```
  RATIO      PA : PB = m : n     ->   n^2 PA^2 = m^2 PB^2    (Apollonius circle)
  RIGHT ANGLE  angle APB = 90    ->   (slope PA)(slope PB) = -1
                                      or  (x-x1)(x-x2) + (y-y1)(y-y2) = 0
  AREA       area of PAB = k     ->   1/2 abs(...) = k , then drop the abs
                                      with a PLUS-OR-MINUS
```

Write out one complete solution of each in full exam layout.

**Day 2 evening — parameters and naming (1.5 hours).**
Learn the two elimination tricks:

```
  x = a cos t , y = b sin t     ->   square, divide, ADD    (cos^2 + sin^2 = 1)
  x = a sec t , y = b tan t     ->   square, divide, SUBTRACT (sec^2 - tan^2 = 1)
  x = at^2 , y = 2at            ->   get t from y, put it in x
```

Then learn the naming table in section 7 of the mind map. Saying
"the locus is a circle with centre (2,-3) and radius 5" instead of just leaving
the equation is worth a mark on its own in Section B.

**That plan secures the 4-mark Section B question, and it takes one day.**
