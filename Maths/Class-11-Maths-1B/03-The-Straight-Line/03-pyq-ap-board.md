## Topic: Slope and inclination

### Q A1
Find the slope of the straight line whose inclination is 135 degrees.

**ANSWER:**
```
  m = tan(135)
    = tan(180 - 45)
    = - tan(45)              (tangent is negative in the second quadrant)
    = - 1
```
**m = -1**

---

### Q A2
Find the slope of the straight line passing through (3, -2) and (-1, 4).

**ANSWER:**
```
        y2 - y1        4 - (-2)         6
  m =  ---------  =  ------------  =  ------  =  -3/2
        x2 - x1         -1 - 3          -4
```
**m = -3/2**

### Q A3
Find the angle which the straight line `x + sqrt(3) y - 4 = 0` makes with the
positive direction of the x-axis.

**ANSWER:**
```
              -a         -1            1
  slope m =  ----  =  ---------  =  - ------
               b       sqrt(3)        sqrt(3)

  tan(theta) = -1/sqrt(3)      and theta must lie in [0, 180)

  tan(150) = tan(180 - 30) = -tan(30) = -1/sqrt(3)
```
**theta = 150 degrees**

### Q A4
Find y if the line joining (3, y) and (2, 7) is parallel to the line joining
(-1, 4) and (0, 6).

**ANSWER:**
```
                          6 - 4        2
  Slope of the second =  --------  =  ---  =  2
                          0 + 1        1

                          7 - y        7 - y
  Slope of the first  =  --------  =  --------  =  y - 7
                          2 - 3         -1

  Parallel  ->  slopes equal:      y - 7 = 2      ->      y = 9
```

## Topic: Writing the equation of a line

### Q A5
Find the equation of the straight line passing through (2, 3) and making an
angle of 135 degrees with the positive x-axis.

**ANSWER:**
```
  m = tan(135) = -1

  y - y1 = m (x - x1)
  y - 3  = -1 (x - 2)
  y - 3  = -x + 2
  x + y - 5 = 0

  CHECK:  2 + 3 - 5 = 0     Correct.
```
**x + y - 5 = 0**

### Q A6
Find the equation of the straight line whose inclination is 45 degrees and
whose y-intercept is 3.

**ANSWER:**
```
  m = tan(45) = 1 ,   c = 3

  y = mx + c   ->   y = x + 3   ->   x - y + 3 = 0
```
**x - y + 3 = 0**

### Q A7
Find the equation of the straight line passing through (-4, 5) and cutting off
equal non-zero intercepts on the coordinate axes.

**ANSWER:**
```
  Equal intercepts means  a = b , so   x/a + y/a = 1   ->   x + y = a

  Through (-4, 5):    -4 + 5 = a    ->    a = 1
```
**x + y - 1 = 0**

### Q A8
Find the equation of the straight line passing through (-2, 4) making non-zero
intercepts whose sum is zero.

**ANSWER:**
```
  Sum zero means  b = -a , so   x/a + y/(-a) = 1   ->   x - y = a

  Through (-2, 4):    -2 - 4 = a    ->    a = -6

  x - y = -6
```
**x - y + 6 = 0**

### Q A9
Find the equation of the straight line parallel to `3x - 4y + 7 = 0` and

## Topic: Intercepts, transformation, area

### Q A11
Find the slope and the intercepts of `3x + 4y - 12 = 0`.

**ANSWER:**
```
                 -a        -3
  slope  m  =   ----  =   ----                      m = -3/4
                  b         4

  x-intercept:  put y = 0  ->  3x = 12  ->  x = 4
  y-intercept:  put x = 0  ->  4y = 12  ->  y = 3
```
**m = -3/4, x-intercept = 4, y-intercept = 3**

### Q A12
Transform `4x - 3y + 12 = 0` into intercept form.

**ANSWER:**
```
  4x - 3y = -12

  Divide every term by -12:

      4x        -3y
    ------  +  ------  =  1
    (-12)      (-12)

      x        y
    ------ +  ---  =  1
     (-3)      4
```
**x/(-3) + y/4 = 1, so a = -3 and b = 4**

### Q A13
Find the sum of the squares of the intercepts made by `4x - 7y + 28 = 0`
on the coordinate axes.

**ANSWER:**
```
  x-intercept:  y = 0  ->  4x + 28 = 0  ->  x = -7
  y-intercept:  x = 0  ->  -7y + 28 = 0 ->  y = 4

  Sum of squares  =  (-7)^2 + 4^2  =  49 + 16  =  65
```
**65**

### Q B1 — the classic "transform into all three forms"
Transform `3x + 4y + 12 = 0` into (a) slope-intercept form,
(b) intercept form, (c) normal form.

**ANSWER:**
```
  (a) SLOPE-INTERCEPT FORM

      4y = -3x - 12

              -3
       y  =  ---- x  -  3            so   m = -3/4 ,  c = -3
               4


  (b) INTERCEPT FORM

      3x + 4y = -12

      Divide every term by -12:

         3x         4y
       ------  +  ------  =  1
       (-12)      (-12)

          x          y
       ------  +  ------  =  1        so   a = -4 ,  b = -3
        (-4)       (-3)


  (c) NORMAL FORM

      sqrt(a^2 + b^2) = sqrt(9 + 16) = 5

      Move the constant:   3x + 4y = -12
      The right side is negative, so multiply the whole line by -1:

                          -3x - 4y = 12

      Divide by 5:

           -3          -4          12
          ---- x  +  ---- y   =  ------
            5           5           5

      So   cos(alpha) = -3/5 ,  sin(alpha) = -4/5 ,  p = 12/5.
      Both are negative, so alpha lies in the THIRD quadrant.
```

### Q B2
Transform `x + y + 1 = 0` into normal form.

**ANSWER:**
```
  sqrt(1^2 + 1^2) = sqrt(2)

  Move the constant:  x + y = -1
  RHS is negative, so multiply by -1:   -x - y = 1

  Divide by sqrt(2):

        -1              -1                 1
      -------- x   +  -------- y   =   --------
      sqrt(2)         sqrt(2)          sqrt(2)

  So   cos(alpha) = -1/sqrt(2) ,  sin(alpha) = -1/sqrt(2) ,  p = 1/sqrt(2).

  Both negative  ->  alpha is in the third quadrant  ->  alpha = 225 degrees.
```
**x cos(225) + y sin(225) = 1/sqrt(2)**

### Q B3
Find the point on the line `3x + y + 4 = 0` which is equidistant from (-5, 6)
and (3, 2).

**ANSWER:**
```
  KEY IDEA: equidistant from two points  ->  it lies on the PERPENDICULAR
            BISECTOR of the segment joining them.

  STEP 1  Midpoint of (-5, 6) and (3, 2):

              ( -5 + 3      6 + 2 )
             ( --------- ,  ------- )   =   ( -1 , 4 )
              (    2           2    )

  STEP 2  Slope of the segment:

               2 - 6        -4
              --------  =  ----  =  -1/2      ->  perpendicular slope = 2
               3 + 5         8

  STEP 3  Perpendicular bisector through (-1, 4):

              y - 4 = 2 (x + 1)   ->   y = 2x + 6            ... (i)

  STEP 4  Given line:   y = -3x - 4                          ... (ii)

  STEP 5  Solve:   2x + 6 = -3x - 4   ->   5x = -10   ->   x = -2
                   y = 2(-2) + 6 = 2

  CHECK   on the line:  3(-2) + 2 + 4 = 0                    Correct.
          to (-5,6):  sqrt(9 + 16) = 5      to (3,2):  sqrt(25 + 0) = 5
```
**The point is (-2, 2).**

```
            22 - 15 + k = 0

```

### Q B8
A straight line through Q(sqrt(3), 2) makes an angle of 30 degrees with the
positive x-axis. If it meets the line `sqrt(3) x - 4y + 8 = 0` at P, find PQ.

**ANSWER:**
```
  Use the SYMMETRIC (parametric) form.

  STEP 1   x = sqrt(3) + r cos(30) = sqrt(3) + r sqrt(3)/2
           y = 2       + r sin(30) = 2 + r/2

  STEP 2   Substitute into  sqrt(3) x - 4y + 8 = 0 :

           sqrt(3)[ sqrt(3) + r sqrt(3)/2 ]  -  4[ 2 + r/2 ]  +  8  =  0

  STEP 3   Expand.

              3  +  3r/2  -  8  -  2r  +  8  =  0
              3  +  3r/2  -  2r  =  0
              3  -  r/2  =  0
              r  =  6

  STEP 4   In the symmetric form, r IS the distance from Q.
```
**PQ = 6**

### Q B9
A straight line with slope 1 passes through Q(-3, 5) and meets the line
`x + y - 6 = 0` at P. Find the distance PQ.

**ANSWER:**
```
  Slope 1  ->  theta = 45 degrees  ->  cos(45) = sin(45) = 1/sqrt(2)

  STEP 1   x = -3 + r/sqrt(2)  ,   y = 5 + r/sqrt(2)

  STEP 2   Substitute into  x + y - 6 = 0 :

              -3 + r/sqrt(2)  +  5 + r/sqrt(2)  -  6  =  0
              -4  +  2r/sqrt(2)  =  0
              2r  =  4 sqrt(2)
              r   =  2 sqrt(2)
```
**PQ = 2 sqrt(2)**

### Q B10
Find the foot of the perpendicular from (-1, 3) to the line `5x - y - 18 = 0`.

**ANSWER:**
```
  a = 5 , b = -1 , c = -18 ,  (x1, y1) = (-1, 3)

  STEP 1   a x1 + b y1 + c  =  5(-1) + (-1)(3) + (-18)  =  -5 - 3 - 18  = -26

  STEP 2   a^2 + b^2  =  25 + 1  =  26

  STEP 3   Use the FOOT formula (the multiplier is -1):

              x - x1        y - y1         -( -26 )        26
             ---------  =  ---------  =  ------------  =  ----- =  1
                 a             b              26            26

  STEP 4   x = -1 + 5(1)   =  4
           y =  3 + (-1)(1) =  2

  CHECK    5(4) - 2 - 18  =  20 - 20  =  0     The foot lies on the line.
```
**The foot of the perpendicular is (4, 2).**

### Q B13
Find the equations of the straight lines passing through (1, 2) and making an
angle of 60 degrees with the line `sqrt(3) x + y + 2 = 0`.

**ANSWER:**
```
  Slope of the given line:  m2 = -sqrt(3) / 1 = -sqrt(3)

  Let the required slope be m.

                    m - (-sqrt(3))
      abs      ---------------------------   =   tan(60)  =  sqrt(3)
                1 + m(-sqrt(3))

  CASE 1  (take the + sign)

      m + sqrt(3)  =  sqrt(3) ( 1 - sqrt(3) m )
      m + sqrt(3)  =  sqrt(3) - 3m
      4m = 0        ->      m = 0

      Line through (1, 2) with slope 0:        y - 2 = 0

  CASE 2  (take the - sign)

      m + sqrt(3)  =  - sqrt(3) ( 1 - sqrt(3) m )
      m + sqrt(3)  =  - sqrt(3) + 3m
      2 sqrt(3)    =  2m        ->      m = sqrt(3)

      Line through (1, 2) with slope sqrt(3):

          y - 2 = sqrt(3) ( x - 1 )
          sqrt(3) x  -  y  +  2  -  sqrt(3)  =  0
```
**y - 2 = 0 and sqrt(3) x - y + 2 - sqrt(3) = 0**

### Q B15

### Q B16
If p is the length of the perpendicular from the origin to the line
`x/a + y/b = 1`, prove that `1/p^2 = 1/a^2 + 1/b^2`.

**ANSWER:**
```
  STEP 1   Clear fractions. Multiply  x/a + y/b = 1  by ab :

               b x  +  a y  =  a b        ->        b x + a y - a b = 0

  STEP 2   Perpendicular distance from the origin (0, 0):

                    abs( - a b )              abs( a b )
             p  =  ----------------   =   ------------------
                   sqrt( b^2 + a^2 )       sqrt( a^2 + b^2 )

  STEP 3   Square it:

                       a^2 b^2
             p^2  =  ------------
                      a^2 + b^2

  STEP 4   Turn it upside down and split:

               1        a^2 + b^2         a^2          b^2
             ----  =  ------------  =  ---------  +  ---------
              p^2       a^2 b^2         a^2 b^2       a^2 b^2

               1          1         1
             ----  =    ----  +   ----                          PROVED
              p^2        b^2       a^2
```

## Q C1 — ORTHOCENTRE from three vertices

Find the orthocentre of the triangle whose vertices are A(-2, -1), B(6, -1)
and C(2, 5).

**ANSWER:**
```
                       C(2, 5)
                        *
                       / \
                      /   \
                     /     \
                    /       \
           A(-2,-1)*---------* B(6,-1)


  The ORTHOCENTRE is the point where the ALTITUDES meet.
  An altitude goes through a VERTEX and is PERPENDICULAR to the opposite side.
  Two altitudes are enough.


  STEP 1 — SPOT THE EASY ONE.

     A(-2,-1) and B(6,-1) both have y = -1, so AB is a HORIZONTAL line.
     Therefore the altitude from C is VERTICAL and passes through C(2, 5):

                   x = 2                                ... (i)


  STEP 2 — ALTITUDE FROM A, perpendicular to BC.

                      5 - (-1)          6
     slope of BC  =  ----------  =  --------  =  -3/2
                      2 - 6            -4

                                    -1          -1
     slope of the altitude  =  ------------ = -------- = 2/3
                               slope of BC     (-3/2)


  STEP 3 — WRITE THAT ALTITUDE through A(-2, -1) with slope 2/3.

              y - (-1)  =  (2/3) ( x - (-2) )
              y + 1     =  (2/3) ( x + 2 )
              3y + 3    =  2x + 4
              2x - 3y + 1 = 0                            ... (ii)


  STEP 4 — SOLVE (i) AND (ii) TOGETHER.

              Put x = 2 into (ii):
              2(2) - 3y + 1 = 0
              4 - 3y + 1 = 0
              5 = 3y
              y = 5/3


  STEP 5 — VERIFY with the THIRD altitude (from B, perpendicular to CA).

                      5 - (-1)         6
     slope of CA  =  ----------  =  -------  =  3/2
                      2 - (-2)         4

     altitude slope = -2/3 , through B(6, -1):

              y + 1 = (-2/3)( x - 6 )
              3y + 3 = -2x + 12
              2x + 3y - 9 = 0

     Test (2, 5/3):   2(2) + 3(5/3) - 9  =  4 + 5 - 9  =  0     TRUE
```
**ORTHOCENTRE = (2, 5/3)**

## Q C2 — CIRCUMCENTRE from three vertices

Find the circumcentre of the triangle whose vertices are A(-2, -1), B(6, -1)
and C(2, 5).

**ANSWER:**
```
  The CIRCUMCENTRE is where the PERPENDICULAR BISECTORS of the sides meet.
  A perpendicular bisector goes through the MIDPOINT of a side and is
  PERPENDICULAR to it. Two of them are enough.


  STEP 1 — PERPENDICULAR BISECTOR OF AB.

                             ( -2 + 6      -1 + (-1) )
     midpoint of AB  =      ( --------- ,  ---------- )   =   ( 2 , -1 )
                             (    2             2     )

     AB is horizontal, so its perpendicular bisector is VERTICAL:

                   x = 2                                ... (i)


  STEP 2 — PERPENDICULAR BISECTOR OF BC.

                             ( 6 + 2      -1 + 5 )
     midpoint of BC  =      ( -------- ,  -------- )   =   ( 4 , 2 )
                             (    2           2   )

                      5 - (-1)
     slope of BC  =  ----------  =  -3/2      ->   perpendicular slope = 2/3

     Through (4, 2) with slope 2/3:

              y - 2  =  (2/3)( x - 4 )
              3y - 6 =  2x - 8
              2x - 3y - 2 = 0                            ... (ii)


  STEP 3 — SOLVE (i) AND (ii).

              Put x = 2 into (ii):
              4 - 3y - 2 = 0
              2 = 3y
              y = 2/3


  STEP 4 — VERIFY. The circumcentre must be the SAME distance from all
           three vertices.

     to A(-2,-1):  sqrt( (2 + 2)^2 + (2/3 + 1)^2 )
                 = sqrt( 16 + (5/3)^2 ) = sqrt( 16 + 25/9 )
                 = sqrt( 169/9 ) = 13/3

     to B(6,-1) :  sqrt( (2 - 6)^2 + (2/3 + 1)^2 ) = sqrt( 16 + 25/9 ) = 13/3

     to C(2, 5) :  sqrt( 0 + (5 - 2/3)^2 ) = sqrt( (13/3)^2 ) = 13/3

     All equal. The circumradius is 13/3.
```
**CIRCUMCENTRE = (2, 2/3)**

```
  BONUS 30-SECOND CHECK linking C1 and C2 (the Euler line):

     centroid G = ( (-2 + 6 + 2)/3 , (-1 - 1 + 5)/3 ) = ( 2 , 1 )

     Orthocentre (2, 5/3) , Centroid (2, 1) , Circumcentre (2, 2/3)
     -> all have x = 2, so they are COLLINEAR.

     OG = 5/3 - 1 = 2/3        GS = 1 - 2/3 = 1/3
     OG : GS = 2 : 1           Both answers confirmed.
```

## Q C3 — ORTHOCENTRE of the triangle formed by three LINES

Find the orthocentre of the triangle formed by the lines `x + 2y = 0`,
`4x + 3y - 5 = 0` and `3x + y = 0`.

**ANSWER:**
```
  Call them  L1: x + 2y = 0 ,  L2: 4x + 3y - 5 = 0 ,  L3: 3x + y = 0.

  STEP 1 — FIND THE VERTICES (each vertex is where two lines meet).

     A = L1 and L3 :    x + 2y = 0   and   3x + y = 0
                        From L3:  y = -3x
                        x + 2(-3x) = 0  ->  -5x = 0  ->  x = 0 , y = 0
                        A = (0, 0)

     B = L1 and L2 :    x = -2y
                        4(-2y) + 3y - 5 = 0  ->  -5y = 5  ->  y = -1
                        x = 2
                        B = (2, -1)

     C = L2 and L3 :    y = -3x
                        4x + 3(-3x) - 5 = 0  ->  -5x = 5  ->  x = -1
                        y = 3
                        C = (-1, 3)


  STEP 2 — ALTITUDE FROM A(0,0), perpendicular to side BC, which is L2.

     slope of L2 = -4/3     ->     altitude slope = 3/4

           y - 0 = (3/4)( x - 0 )
           4y = 3x
           3x - 4y = 0                                   ... (i)


  STEP 3 — ALTITUDE FROM B(2,-1), perpendicular to side CA, which is L3.

     slope of L3 = -3       ->     altitude slope = 1/3

           y + 1 = (1/3)( x - 2 )
           3y + 3 = x - 2
           x - 3y - 5 = 0                                ... (ii)


  STEP 4 — SOLVE (i) AND (ii).

     From (i):  3x = 4y   ->   x = 4y/3

     Substitute into (ii):

           4y/3  -  3y  -  5  =  0
           ( 4y - 9y ) / 3  =  5
           -5y / 3 = 5
           -5y = 15
           y = -3       ->      x = 4(-3)/3 = -4


  STEP 5 — VERIFY with the third altitude (from C(-1,3), perpendicular to L1).

     slope of L1 = -1/2     ->     altitude slope = 2

           y - 3 = 2( x + 1 )   ->   y = 2x + 5

     Test (-4, -3):   2(-4) + 5  =  -3      TRUE
```
**ORTHOCENTRE = (-4, -3)**

## Q C4 — CIRCUMCENTRE (a second full worked model)

Find the circumcentre of the triangle whose vertices are A(1, 3), B(0, -2)
and C(-3, 1).

**ANSWER:**
```
  STEP 1 — PERPENDICULAR BISECTOR OF AB.

                             ( 1 + 0     3 + (-2) )
     midpoint of AB  =      ( -------- , ---------- )  =  ( 1/2 , 1/2 )
                             (    2           2    )

                      -2 - 3        -5
     slope of AB  =  --------  =  ------  =  5
                       0 - 1        -1

     perpendicular slope = -1/5

           y - 1/2  =  (-1/5)( x - 1/2 )

     Multiply everything by 10:

           10y - 5  =  -2( x - 1/2 )  =  -2x + 1
           2x + 10y - 6 = 0
           x + 5y - 3 = 0                                ... (i)


  STEP 2 — PERPENDICULAR BISECTOR OF BC.

                             ( 0 + (-3)     -2 + 1 )
     midpoint of BC  =      ( ----------- , -------- )  =  ( -3/2 , -1/2 )
                             (     2            2   )

                      1 - (-2)         3
     slope of BC  =  -----------  =  ------  =  -1
                      -3 - 0          -3

     perpendicular slope = 1

           y + 1/2  =  1 ( x + 3/2 )
           y = x + 1
           x - y + 1 = 0                                 ... (ii)


  STEP 3 — SOLVE (i) AND (ii).

     From (ii):  x = y - 1

     Substitute into (i):
           ( y - 1 ) + 5y - 3 = 0
           6y = 4
           y = 2/3        ->      x = 2/3 - 1 = -1/3


  STEP 4 — VERIFY (distances to all three vertices must be equal).

     to A(1, 3)  :  sqrt( (1 + 1/3)^2 + (3 - 2/3)^2 )
                 =  sqrt( (4/3)^2 + (7/3)^2 ) = sqrt( 16/9 + 49/9 )
                 =  sqrt(65)/3

     to B(0, -2) :  sqrt( (1/3)^2 + (-2 - 2/3)^2 )
                 =  sqrt( 1/9 + 64/9 ) = sqrt(65)/3

     to C(-3, 1) :  sqrt( (-3 + 1/3)^2 + (1 - 2/3)^2 )
                 =  sqrt( 64/9 + 1/9 ) = sqrt(65)/3

     All three equal.
```
**CIRCUMCENTRE = (-1/3, 2/3), circumradius = sqrt(65)/3**

## Q C5 — ANGLE BISECTORS: which contains the origin, which is acute

Find the equations of the bisectors of the angles between the lines
`4x + 3y - 7 = 0` and `24x + 7y - 31 = 0`. State which bisector contains the
origin and which one bisects the acute angle.

**ANSWER:**
```
  STEP 1 — WRITE THE BISECTOR EQUATION.

     sqrt(4^2 + 3^2)  = sqrt(25)  = 5
     sqrt(24^2 + 7^2) = sqrt(576 + 49) = sqrt(625) = 25

           4x + 3y - 7             24x + 7y - 31
          -------------   =   +/- ----------------
                5                        25

     Multiply both sides by 25:

           5 ( 4x + 3y - 7 )  =  +/- ( 24x + 7y - 31 )


  STEP 2 — THE  " + "  CASE.

           20x + 15y - 35  =  24x + 7y - 31
                       0   =  4x - 8y + 4
                       0   =  x - 2y + 1

                            x - 2y + 1 = 0                ... BISECTOR 1


  STEP 3 — THE  " - "  CASE.

           20x + 15y - 35  =  -24x - 7y + 31
           44x + 22y - 66  =  0
            2x +  y -  3   =  0

                            2x + y - 3 = 0                ... BISECTOR 2


  STEP 4 — WHICH BISECTOR CONTAINS THE ORIGIN?

     RULE: first make BOTH constant terms POSITIVE, then the " + " bisector
           is the one containing the origin.

     Multiply both given lines by -1:

            -4x -  3y +  7 = 0        (c1 =  7 , positive)
           -24x -  7y + 31 = 0        (c2 = 31 , positive)

     The " + " bisector of these:

           5( -4x - 3y + 7 )  =  -24x - 7y + 31
           -20x - 15y + 35    =  -24x - 7y + 31
             4x -  8y +  4    =  0
              x -  2y +  1    =  0

     So the bisector containing the origin is   x - 2y + 1 = 0.


  STEP 5 — ACUTE OR OBTUSE?

     Using the positive-constant versions,

           a1 a2  +  b1 b2  =  (-4)(-24)  +  (-3)(-7)  =  96 + 21  =  117

     117 is POSITIVE, so the origin bisector is the OBTUSE angle bisector.
     Therefore the other one is the acute angle bisector.


  STEP 6 — CHECK. The two bisectors must be perpendicular.

     slope of  x - 2y + 1 = 0   is   1/2
     slope of  2x + y - 3 = 0   is   -2

     product = (1/2)(-2) = -1        Perpendicular. Correct.
```
**Bisectors: x - 2y + 1 = 0 and 2x + y - 3 = 0**
**Contains the origin (and bisects the OBTUSE angle): x - 2y + 1 = 0**
**Bisects the ACUTE angle: 2x + y - 3 = 0**

## Q C6 — A PERPENDICULAR-LENGTH IDENTITY

If p and q are the lengths of the perpendiculars from the origin to the
straight lines `x sec(A) + y cosec(A) = a` and `x cos(A) - y sin(A) = a cos(2A)`,
prove that `4 p^2 + q^2 = a^2`.

**ANSWER:**
```
  STEP 1 — FIND p.

     Line 1:   x sec(A) + y cosec(A) - a = 0

                       abs( -a )                          abs( a )
        p  =  ------------------------------  =  ------------------------------
              sqrt( sec^2(A) + cosec^2(A) )      sqrt( sec^2(A) + cosec^2(A) )


  STEP 2 — SIMPLIFY  sec^2(A) + cosec^2(A).

            1            1          sin^2(A)  +  cos^2(A)
        --------  +  --------  =  -------------------------
        cos^2(A)     sin^2(A)        sin^2(A) cos^2(A)

                                            1
                                =  ---------------------
                                    sin^2(A) cos^2(A)

        Now use  sin(2A) = 2 sin(A) cos(A) , so  sin(A)cos(A) = sin(2A)/2
        and therefore  sin^2(A) cos^2(A) = sin^2(2A) / 4.

                                           4
                                =  ----------------
                                     sin^2(2A)


  STEP 3 — SUBSTITUTE BACK.

                abs( a )              abs( a ) . abs( sin(2A) )
        p  =  -------------   =   ---------------------------------
               2 / abs(sin 2A)                   2

        Square it:

               a^2 sin^2(2A)
        p^2 = ----------------        ->      4 p^2  =  a^2 sin^2(2A)
                     4


  STEP 4 — FIND q.

     Line 2:   x cos(A) - y sin(A) - a cos(2A) = 0

                 abs( - a cos(2A) )          abs( a cos(2A) )
        q  =  --------------------------  = ------------------- = abs(a cos 2A)
              sqrt( cos^2(A) + sin^2(A) )        sqrt( 1 )

        so    q^2  =  a^2 cos^2(2A)


  STEP 5 — ADD THEM.

        4 p^2  +  q^2  =  a^2 sin^2(2A)  +  a^2 cos^2(2A)

                       =  a^2 [ sin^2(2A) + cos^2(2A) ]

                       =  a^2 ( 1 )

                       =  a^2                                   PROVED
```
