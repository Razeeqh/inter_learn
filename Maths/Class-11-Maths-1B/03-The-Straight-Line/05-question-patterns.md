# The Straight Line — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The numbers change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — FIND THE SLOPE                                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the slope of ..." , or an inclination angle is given,
            or two points are given.
  METHOD    Whatever you are given, one of these three applies:
               angle given        ->   m = tan(theta)
               two points given   ->   m = (y2 - y1)/(x2 - x1)
               ax + by + c = 0    ->   m = -a/b
  TRAP      A VERTICAL line has NO slope (undefined). A HORIZONTAL line has
            slope ZERO. Students swap these every year.
```

```
  PATTERN 2 — FIND AN UNKNOWN COORDINATE FROM A SLOPE CONDITION   2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find y if the line joining (3, y) and (2, 7) is parallel to ..."
            or "... is perpendicular to ..."
  METHOD    1. Compute the slope of the reference line.
            2. Write the slope of the unknown line with the letter in it.
            3. Set them EQUAL (parallel) or set the PRODUCT = -1
               (perpendicular).
            4. Solve the one small equation.
  TRAP      Sign errors in (y2 - y1)/(x2 - x1) when a coordinate is negative.
```

```
  PATTERN 3 — LINE THROUGH ONE POINT WITH A GIVEN SLOPE OR ANGLE  2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the equation of the line through (2,3) with slope -1"
            or "... making an angle of 135 degrees with the x-axis".
  METHOD    1. If an angle is given, convert:  m = tan(theta).
            2. Use  y - y1 = m ( x - x1 ).
            3. Expand and write it as  ax + by + c = 0.
            4. Substitute the point back to check.
  TRAP      Signs inside the bracket when x1 or y1 is negative:
            x - (-3) becomes x + 3.
```

```
  PATTERN 4 — LINE THROUGH TWO GIVEN POINTS                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   Two points and nothing else.
  METHOD    1. Find m = (y2 - y1)/(x2 - x1).
            2. Use point-slope form with EITHER point.
            3. Check with the OTHER point - it must satisfy the equation.
  TRAP      If both points have the same x, the line is x = that value.
            If both have the same y, the line is y = that value.
            Do NOT try the slope formula in those cases.
```

```
  PATTERN 5 — INTERCEPT-FORM WORD PROBLEMS                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   The words "intercept", "cuts the axes", "equal intercepts",
            "sum of the intercepts is zero".
  METHOD    Start from  x/a + y/b = 1  and apply the condition:

               equal intercepts               ->   b = a   ->  x + y = a
               equal magnitude, opposite sign ->   b = -a  ->  x - y = a
               sum of intercepts is zero      ->   b = -a  ->  x - y = a
               intercepts in ratio p : q      ->   a = pk , b = qk

            Then substitute the given point to find the single unknown.
  TRAP      "Equal intercepts" and "sum zero" look similar but give
            OPPOSITE signs. Read the wording twice.
```

```
  PATTERN 6 — NORMAL FORM FROM p AND alpha                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "distance from the origin is p and the normal makes angle alpha"
  METHOD    Write   x cos(alpha) + y sin(alpha) = p ,
            substitute the trig values, then clear fractions.
  TRAP      p must be POSITIVE. If a negative appears, multiply the whole
            equation by -1 and re-read cos and sin.
```

```
  PATTERN 7 — READ OFF SLOPE AND INTERCEPTS OF ax + by + c = 0    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the slope / the intercepts of 3x + 4y - 12 = 0."
  METHOD    slope = -a/b .
            For the intercepts, do not use a formula - just substitute:
               put y = 0  ->  gives the x-intercept
               put x = 0  ->  gives the y-intercept
  TRAP      Forgetting the minus sign in -a/b.
```

```
  PATTERN 8 — TRANSFORM ax + by + c = 0 INTO THE STANDARD FORMS   4 marks
  ------------------------------------------------------------------------
  TRIGGER   The word "transform" or "reduce", plus a list (a), (b), (c).
  METHOD    (a) SLOPE-INTERCEPT : make y the subject.
            (b) INTERCEPT       : move c right, divide every term by (-c).
            (c) NORMAL          : divide by sqrt(a^2 + b^2), then force the
                                  right-hand side to be POSITIVE.
            Finally STATE m, c, a, b, p and the quadrant of alpha.
  TRAP      Skipping the "make the RHS positive" step in the normal form.
            That alone costs 1 to 2 marks every time.
```

```
  PATTERN 9 — LINE PARALLEL / PERPENDICULAR TO A GIVEN LINE       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "parallel to ... and passing through ..." (or "perpendicular").
  METHOD    parallel      ->   ax + by + k = 0
            perpendicular ->   bx - ay + k = 0
            Substitute the given point to find k.
  TRAP      For the perpendicular, SWAP a and b and flip exactly ONE sign.
            Flipping both signs gives back a parallel line.
```

```
  PATTERN 10 — FIND k FOR PARALLEL / PERPENDICULAR / COINCIDENT   2 marks
  ------------------------------------------------------------------------
  TRIGGER   One of the two line equations contains a letter.
  METHOD    parallel      ->   a1 b2 - a2 b1 = 0     (or m1 = m2)
            perpendicular ->   a1 a2 + b1 b2 = 0
            coincident    ->   a1/a2 = b1/b2 = c1/c2
  TRAP      Using m1 m2 = -1 when one line might be vertical.
            The a1a2 + b1b2 = 0 version never breaks.
```

```
  PATTERN 11 — ANGLE BETWEEN TWO LINES                            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the angle between ..."
  METHOD    1. Find m1 and m2.
            2. tan(theta) = abs( (m1 - m2) / (1 + m1 m2) ).
            3. Convert to an angle using the standard tan values.
  TRAP      Dropping the abs( ). The answer wanted is the ACUTE angle.
            If 1 + m1 m2 = 0, do not divide - just write 90 degrees.
```

```
  PATTERN 12 — FIND k GIVEN THE ANGLE BETWEEN TWO LINES           4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find k if the angle between ... is 45 degrees."
  METHOD    1. Write m1 and m2 (one contains k).
            2. Put them into the tan formula and set it equal to tan(45).
            3. Remove the abs( ) by writing  " = +  "  and  " = -  ".
            4. Solve BOTH cases.
  TRAP      Giving only ONE value of k. There are almost always TWO.
```

```
  PATTERN 13 — LINES THROUGH A POINT AT A GIVEN ANGLE TO A LINE   4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the equationS (plural) of the straight lines through
            (1,2) making 60 degrees with the line ..."
  METHOD    1. m2 = slope of the given line. Let the required slope be m.
            2. abs( (m - m2)/(1 + m m2) ) = tan(given angle).
            3. Split into the + case and the - case  ->  TWO values of m.
            4. Write TWO lines using  y - y1 = m ( x - x1 ).
  TRAP      Writing only one line. The word "lines" is plural for a reason -
            half the marks sit in the second line.
```

```
  PATTERN 14 — POINT OF INTERSECTION OF TWO LINES                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the point of intersection of ..."
  METHOD    Solve the two equations together by elimination.
            Then substitute back into BOTH to check.
  TRAP      If  a1 b2 - a2 b1 = 0  the lines are parallel and there is no
            intersection at all. Say so.
```

```
  PATTERN 15 — CONCURRENCY OF THREE LINES                         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Show that the three lines are concurrent" or
            "Find k if the three lines are concurrent."
  METHOD    1. Solve the TWO equations that do NOT contain the unknown.
            2. That gives the common point P.
            3. Substitute P into the third line.
                  "show" version  ->  it must give 0 = 0
                  "find k" version ->  solve the resulting equation for k
            (Alternative: set the 3x3 determinant of coefficients to 0.)
  TRAP      Solving a pair that CONTAINS the unknown. Always pick the clean
            pair first.
```

```
  PATTERN 16 — PERPENDICULAR DISTANCE FROM A POINT TO A LINE      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the distance from (x1,y1) to the line ..." , or
            "the length of the perpendicular from the origin to ..."
  METHOD    1. Rewrite the line as  ax + by + c = 0  (zero on the right).
            2. d = abs( a x1 + b y1 + c ) / sqrt( a^2 + b^2 ).
            3. From the ORIGIN this shortens to abs(c)/sqrt(a^2 + b^2).
  TRAP      Using the line as "3x + 4y = 10" and taking c = 10.
            It must first become 3x + 4y - 10 = 0, so c = -10.
```

```
  PATTERN 17 — DISTANCE BETWEEN TWO PARALLEL LINES                2 marks
  ------------------------------------------------------------------------
  TRIGGER   Two equations with proportional x and y coefficients.
  METHOD    1. SCALE one equation so that a and b are IDENTICAL in both.
            2. d = abs( c1 - c2 ) / sqrt( a^2 + b^2 ).
  TRAP      Forgetting to scale. This is the single most common lost mark
            in the whole chapter. Do step 1 in writing, every time.
```

```
  PATTERN 18 — FOOT OF THE PERPENDICULAR                          4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the foot of the perpendicular from P to the line L."
  METHOD    1. Compute  N = a x1 + b y1 + c  and  D = a^2 + b^2.
            2. t = -N / D                         (multiplier -1 for FOOT)
            3. x = x1 + a t ,   y = y1 + b t.
            4. Check: the answer must SATISFY the line equation.
  ALTERNATIVE (if you forget the formula)
            Write the perpendicular through P with slope b/a, then solve
            it together with the given line.
```

```
  PATTERN 19 — IMAGE (REFLECTION) OF A POINT IN A LINE            4 marks
  ------------------------------------------------------------------------
  TRIGGER   The word "image", "reflection" or "mirror".
  METHOD    Exactly the same as Pattern 18 but with the multiplier -2:
            1. N = a x1 + b y1 + c ,  D = a^2 + b^2.
            2. t = -2 N / D.
            3. x = x1 + a t ,   y = y1 + b t.
            4. CHECK: the MIDPOINT of P and the image must lie on the line.
  SHORTCUT  mirror y = x    ->  swap the coordinates
            mirror x-axis   ->  flip the sign of y
            mirror y-axis   ->  flip the sign of x
  TRAP      Using -1 instead of -2. That gives the foot, not the image.
```

```
  PATTERN 20 — FAMILY OF LINES  L1 + k L2 = 0                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "the line passing through the INTERSECTION of two given lines
            and also ..."
  METHOD    1. Write  ( L1 )  +  k ( L2 )  =  0.
            2. Apply the extra condition to find k:
                  passes through P        ->  substitute P
                  parallel to L3          ->  equate slopes
                  perpendicular to L3     ->  product of slopes = -1
                  passes through origin   ->  constant term = 0
                  parallel to the x-axis  ->  coefficient of x = 0
            3. Put k back and simplify.
  TRAP      Actually solving for the intersection point first. You do not
            need it, and it wastes half your time.
```

```
  PATTERN 21 — RATIO IN WHICH A LINE DIVIDES A SEGMENT            4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the ratio in which the line ... divides the join of ..."
  METHOD    1. L(A) = put A into the left side of the line equation.
            2. L(B) = put B in the same way.
            3. ratio = - L(A) : L(B).
            4. POSITIVE means INTERNAL, NEGATIVE means EXTERNAL. Say which.
  SHORTCUT  For the x-axis, ratio = -y1 : y2 .
            For the y-axis, ratio = -x1 : x2 .
  TRAP      Forgetting the minus sign in front of L(A), which flips
            internal and external.
```

```
  PATTERN 22 — WHICH SIDE OF A LINE TWO POINTS LIE ON             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Show that the points ... lie on the same / opposite sides."
  METHOD    Compute L(P) and L(Q) and compare only the SIGNS.
               same sign      ->  same side
               opposite signs ->  opposite sides
               either is 0    ->  that point is ON the line
  TRAP      Comparing the SIZES instead of the signs. Only the sign matters.
```

```
  PATTERN 23 — AREA OF THE TRIANGLE FORMED WITH THE AXES      2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "area of the triangle formed by the line with the coordinate axes"
  METHOD    1. Find the intercepts a and b (put y = 0, then x = 0).
            2. Area = (1/2) abs( a b ).
            Direct version:  Area = c^2 / ( 2 abs(a b) )  for ax + by + c = 0.
  REVERSE   "The area is 6, find k" -> set the formula = 6 and solve.
            Expect TWO answers (k and -k).
  TRAP      Losing the absolute value and reporting a negative area.
```

```
  PATTERN 24 — DISTANCE MEASURED ALONG A LINE (SYMMETRIC FORM)    4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A line through Q makes an angle theta with the x-axis and meets
            the line L at P. Find PQ."  Or "distance measured ALONG ...".
  METHOD    1. x = x1 + r cos(theta) ,  y = y1 + r sin(theta).
            2. Substitute into the equation of L.
            3. Solve for r. That r IS the required distance.
  TRAP      Using the perpendicular-distance formula. "Along a line" and
            "perpendicular distance" are completely different questions.
```

```
  PATTERN 25 — POINT ON A LINE EQUIDISTANT FROM TWO POINTS        4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the point on the line ... equidistant from A and B."
  METHOD    1. Equidistant  ->  it lies on the PERPENDICULAR BISECTOR of AB.
            2. Midpoint of AB , slope of AB , then perpendicular slope.
            3. Write that perpendicular bisector.
            4. Solve it together with the given line.
            5. CHECK both distances come out equal.
  ALTERNATIVE  Take a general point on the line, set PA^2 = PB^2 and solve.
```

```
  PATTERN 26 — BISECTORS OF THE ANGLES BETWEEN TWO LINES      *** 7 marks ***
  ------------------------------------------------------------------------
  TRIGGER   "Find the bisectors of the angles between ... " , often with
            "which one contains the origin" or "which bisects the acute angle".
  METHOD    STEP 0  Rewrite both equations so that BOTH constants are
                    POSITIVE. Do this before anything else.
            STEP 1  ( a1x + b1y + c1 ) / sqrt(a1^2+b1^2)
                       = +/-  ( a2x + b2y + c2 ) / sqrt(a2^2+b2^2)
            STEP 2  Work out the " + " case and the " - " case separately.
            STEP 3  The " + " one CONTAINS THE ORIGIN.
            STEP 4  Compute  a1 a2 + b1 b2 :
                       negative  ->  the origin bisector is the ACUTE one
                       positive  ->  the origin bisector is the OBTUSE one
            STEP 5  CHECK: the two bisectors must be perpendicular.
  TRAP      Skipping STEP 0. Then "origin" and "acute" both come out wrong,
            and the whole 7 marks go with them.
```

```
  PATTERN 27 — ORTHOCENTRE OF A TRIANGLE                     *** 7 marks ***
  ------------------------------------------------------------------------
  TRIGGER   "Find the orthocentre of the triangle with vertices ... " or
            "... formed by the lines ..."
  METHOD    0. If the triangle is given by LINES, first find the three
               vertices by solving the lines in pairs.
            1. Look for a horizontal or vertical side - it gives a free
               altitude (vertical or horizontal respectively).
            2. Altitude from A: slope = -1 / (slope of BC), through A.
            3. Altitude from B: slope = -1 / (slope of CA), through B.
            4. Solve the two altitude equations together.
            5. Verify with the third altitude.
  SHORTCUT  RIGHT-ANGLED triangle -> the orthocentre IS the right-angle
            vertex. Check for a right angle before doing any work.
  TIME      About 8 minutes.
  TRAP      Using the slope of the SIDE instead of its perpendicular.
```

```
  PATTERN 28 — CIRCUMCENTRE OF A TRIANGLE                    *** 7 marks ***
  ------------------------------------------------------------------------
  TRIGGER   "Find the circumcentre" , or "the centre of the circle passing
            through the three points".
  METHOD    1. Take side AB: find its MIDPOINT and its slope.
            2. Perpendicular bisector of AB: through that midpoint with
               slope  -1/(slope of AB).
            3. Repeat for side BC.
            4. Solve the two equations together.
            5. CHECK: the distance to all three vertices must be equal.
               (That common distance is the circumradius.)
  SHORTCUT  RIGHT-ANGLED triangle -> circumcentre = MIDPOINT of the
            hypotenuse.
  ALTERNATIVE  Let the centre be (x, y), set SA^2 = SB^2 and SB^2 = SC^2,
               and solve the two resulting linear equations.
  TRAP      Using the vertex instead of the midpoint. The perpendicular
            bisector passes through the MIDPOINT of the side.
```

```
  PATTERN 29 — PERPENDICULAR-LENGTH IDENTITY PROOF           *** 7 marks ***
  ------------------------------------------------------------------------
  TRIGGER   "If p and q are the lengths of the perpendiculars from the
            origin to ... prove that 4p^2 + q^2 = a^2" (and similar).
  METHOD    1. Write each line as  ax + by + c = 0.
            2. p = abs(c) / sqrt(a^2 + b^2) for each line.
            3. SQUARE both, because the identity is always in p^2 and q^2.
            4. Simplify the trig using sec^2 + cosec^2 = 1/(sin^2 cos^2),
               sin(2A) = 2 sin(A) cos(A), and sin^2 + cos^2 = 1.
            5. Add and collect.
  TRAP      Trying to keep the square roots. Square everything at step 3 and
            the whole problem becomes routine algebra.
```

# GUARANTEED-MARKS PLAN FOR THIS CHAPTER

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  LEVEL 1 - THE 4 MARKS YOU CANNOT AFFORD TO MISS  (Section A)      |
  |                                                                    |
  |     Learn ONLY patterns  1, 3, 5, 9, 10, 11, 16, 17.               |
  |                                                                    |
  |     Every one of them is a single substitution. None takes more    |
  |     than 3 minutes. Section A must be answered in FULL, so these   |
  |     are the most reliable marks in the entire paper.               |
  |                                                                    |
  |     Practice target: 20 tiny questions, 2 lines of working each.   |
  |                                                                    |
  +--------------------------------------------------------------------+
  |                                                                    |
  |  LEVEL 2 - THE 4-MARK QUESTION  (Section B, answer any 5 of 7)     |
  |                                                                    |
  |     Learn patterns  8, 15, 18, 19, 21, 24.                         |
  |                                                                    |
  |     Pattern 8 (transform into three forms) and patterns 18/19      |
  |     (foot and image) are the two that appear most often, and       |
  |     18 and 19 share ONE formula. Learning that single formula      |
  |     covers two different 4-mark questions.                         |
  |                                                                    |
  +--------------------------------------------------------------------+
  |                                                                    |
  |  LEVEL 3 - THE 7-MARK QUESTION  (Section C, answer any 5 of 7)     |
  |                                                                    |
  |     Learn patterns  27 and 28 FIRST (orthocentre, circumcentre).   |
  |     They are mechanical - no cleverness required, just slopes,     |
  |     midpoints and solving two equations.                           |
  |                                                                    |
  |     Then add pattern 26 (angle bisectors). It is only 6 lines of   |
  |     working plus ONE decision rule.                                |
  |                                                                    |
  |     Pattern 29 (the p and q proof) is worth learning last - it is  |
  |     the same proof every time, so it is pure memory.               |
  |                                                                    |
  +--------------------------------------------------------------------+
```

**The order to actually study in, if today is the day before the exam:**

```
  1 hour   Patterns 1, 3, 5, 9, 16, 17            ->  4 to 6 marks, Section A
  1 hour   Pattern 8, then patterns 18 and 19     ->  4 marks, Section B
  1 hour   Pattern 27, then pattern 28            ->  7 marks, Section C
  15 min   Pattern 26 decision rule only          ->  backup 7-mark question
```

**Three habits that quietly protect about 5 marks:**

```
  1.  Always rewrite the line as  ax + by + c = 0  before any formula.
  2.  Always substitute your final answer back into ONE original equation.
  3.  Always take abs( ) for a distance, and always state whether a ratio
      is internal or external.
```
