# The Straight Line — Mind Map

**Maths 1B · Chapter 3 · One of the HIGHEST-SCORING chapters in Maths IB**

Almost every year this single chapter gives you:
1 long answer (7 marks) + 1 short answer (4 marks) + 1 or 2 very short answers (2 marks).

That is roughly **13 to 15 marks out of 75**, and it needs no theory-heavy proofs —
just substitution into formulas you can write on one page.

## THE WHOLE CHAPTER ON ONE PAGE

```
THE STRAIGHT LINE
|
+-- 1. SLOPE  (call it m)
|     |
|     +-- from the angle of inclination ....... m = tan(theta)
|     +-- from two points ..................... m = (y2 - y1)/(x2 - x1)
|     +-- from ax + by + c = 0 ................ m = -a/b
|     +-- parallel lines ...................... m1 = m2
|     +-- perpendicular lines ................. m1 x m2 = -1
|
+-- 2. THE FIVE FORMS OF THE EQUATION
|     |
|     +-- slope-intercept .... y = mx + c
|     +-- point-slope ........ y - y1 = m(x - x1)
|     +-- two-point .......... (y - y1)/(x - x1) = (y2 - y1)/(x2 - x1)
|     +-- intercept .......... x/a + y/b = 1
|     +-- normal ............. x cos(alpha) + y sin(alpha) = p
|     |
|     +-- (bonus 6th) symmetric / parametric form
|           (x - x1)/cos(theta) = (y - y1)/sin(theta) = r
|
+-- 3. GENERAL EQUATION   ax + by + c = 0
|     |
|     +-- slope = -a/b
|     +-- x-intercept = -c/a ,  y-intercept = -c/b
|     +-- reduce to slope-intercept ... make y the subject
|     +-- reduce to intercept ......... shift c over, divide by -c
|     +-- reduce to normal ............ divide by sqrt(a^2 + b^2)
|     +-- parallel line ............... ax + by + k = 0
|     +-- perpendicular line .......... bx - ay + k = 0
|
+-- 4. TWO LINES TOGETHER
|     |
|     +-- angle between them .... tan(theta) = abs((m1 - m2)/(1 + m1 m2))
|     +-- parallel .............. m1 = m2      or   a1/a2 = b1/b2
|     +-- perpendicular ......... m1 m2 = -1   or   a1 a2 + b1 b2 = 0
|     +-- point of intersection . solve the two equations together
|     +-- three lines concurrent  the 3x3 determinant = 0
|     +-- family of lines ....... L1 + k L2 = 0
|
+-- 5. DISTANCES
|     |
|     +-- point to line ......... abs(a x1 + b y1 + c) / sqrt(a^2 + b^2)
|     +-- origin to line ........ abs(c) / sqrt(a^2 + b^2)
|     +-- two parallel lines .... abs(c1 - c2) / sqrt(a^2 + b^2)
|
+-- 6. A POINT AND A LINE
|     |
|     +-- foot of the perpendicular
|     +-- image (reflection) of a point
|     +-- which SIDE of the line a point lies on
|     +-- the RATIO in which a line cuts a segment
|
+-- 7. TRIANGLES  (the 7-mark favourites)
      |
      +-- area of the triangle a line makes with the axes
      +-- orthocentre  (altitudes meet)
      +-- circumcentre (perpendicular bisectors meet)
      +-- angle bisectors: internal / external, origin one, acute one
```

## THE 60-SECOND VERSION

A straight line on paper is just a rule connecting x and y.
Every equation in this chapter is `ax + by + c = 0` wearing a different costume.

There are only **four** things an exam can ask you:

| The job | What you actually do | Where it is asked |
|---------|----------------------|-------------------|
| Write down a line | given a point + slope, or 2 points, or intercepts | Section A, 2 marks |
| Compare two lines | angle, parallel, perpendicular, where they meet | Section A or B |
| Measure a distance | point to line, line to line, foot, image | Section B, 4 marks |
| Build a triangle | orthocentre, circumcentre, bisectors, area | **Section C, 7 marks** |

If you can do those four, the chapter is finished.

## THE KEY BOX — THE FIVE FORMS. LEARN THESE FIRST.

```
  +==========================================================================+
  |                                                                          |
  |   1.  SLOPE - INTERCEPT FORM                                             |
  |                                                                          |
  |            y  =  m x  +  c          m = slope , c = y-intercept          |
  |                                                                          |
  |       USE WHEN: you are told the slope and where it cuts the y-axis.     |
  |                                                                          |
  +--------------------------------------------------------------------------+
  |                                                                          |
  |   2.  POINT - SLOPE FORM                                                 |
  |                                                                          |
  |            y - y1  =  m ( x - x1 )                                       |
  |                                                                          |
  |       USE WHEN: you know ONE point (x1, y1) and the slope m.             |
  |       This is the one you will use most often in the whole chapter.      |
  |                                                                          |
  +--------------------------------------------------------------------------+
  |                                                                          |
  |   3.  TWO - POINT FORM                                                   |
  |                                                                          |
  |            y - y1        y2 - y1                                         |
  |           ---------  =  ----------                                       |
  |            x - x1        x2 - x1                                         |
  |                                                                          |
  |       USE WHEN: two points are given. (Or: find m first, then use 2.)    |
  |                                                                          |
  +--------------------------------------------------------------------------+
  |                                                                          |
  |   4.  INTERCEPT FORM                                                     |
  |                                                                          |
  |            x       y                                                     |
  |           ---  +  ---  =  1        a = x-intercept , b = y-intercept     |
  |            a       b                                                     |
  |                                                                          |
  |       USE WHEN: the words "intercept", "cuts the axes", "area with       |
  |       the axes" appear anywhere in the question.                         |
  |                                                                          |
  +--------------------------------------------------------------------------+
  |                                                                          |
  |   5.  NORMAL FORM                                                        |
  |                                                                          |
  |            x cos(alpha)  +  y sin(alpha)  =  p                           |
  |                                                                          |
  |            p     = perpendicular distance from the ORIGIN (p > 0)        |
  |            alpha = angle that this perpendicular makes with +ve x-axis   |
  |                                                                          |
  |       USE WHEN: the question says "normal form", or gives you            |
  |       a distance from the origin plus an angle.                          |
  |                                                                          |
  +==========================================================================+
```

Picture of the normal form — this is what p and alpha mean:

```
        y
        ^
        |          the line
        |         /
        |        /
        |       /
        |      /
        |     N          N = foot of the perpendicular from O
        |    /|          ON = p  (the shortest distance O to the line)
        |   / |
        |  /  |
        | /   |
        |/    |
      O +--- alpha ------------------> x
        the angle alpha is measured from the +ve x-axis to the line ON
```

## IF YOU ONLY HAVE 2 DAYS

**Day 1 morning — the free 2-mark marks.**
Slope from two points. Slope from inclination. Point-slope form.
Slope of `ax + by + c = 0` is `-a/b`. Its intercepts are `-c/a` and `-c/b`.
Then do 10 tiny questions of the type "find the equation of the line through
(2,3) with slope -1". Nothing else. These questions appear EVERY year.

**Day 1 evening — distance and transformation.**
Learn only two formulas, but learn them perfectly:

```
                abs(a x1 + b y1 + c)                        abs(c1 - c2)
  point-line = ----------------------      parallel pair = --------------
                  sqrt(a^2 + b^2)                          sqrt(a^2+b^2)
```

Then practise reducing `3x + 4y + 12 = 0` into slope-intercept, intercept and
normal forms. That exact style of question is a standing 4-mark question.

**Day 2 morning — foot, image, concurrency.**
Memorise the single line that does BOTH foot and image:

```
   x - x1     y - y1         (a x1 + b y1 + c)
  --------  = --------  =  k ------------------- ,   k = -1 for the FOOT
     a           b               a^2 + b^2           k = -2 for the IMAGE
```

One formula, two questions, 8 marks.

**Day 2 evening — the 7-mark question.**
Do ONE orthocentre problem and ONE circumcentre problem, fully written out.
They are mechanical:

```
  ORTHOCENTRE   = intersection of two ALTITUDES
                  (through a vertex, perpendicular to the opposite side)

  CIRCUMCENTRE  = intersection of two PERPENDICULAR BISECTORS
                  (through the midpoint of a side, perpendicular to it)
```

Do the SAME triangle for both. If your orthocentre, centroid and circumcentre
come out on one straight line with `OG : GS = 2 : 1`, you know both answers are
right — that check takes 30 seconds and protects 14 marks.

That plan alone is worth about 13 of the 75 marks in Maths IB.
