# PATTERN 1 — Slope and inclination (free marks)

### Q1
The slope of the straight line joining (3, -2) and (-1, 4) is

(a) 3/2 &nbsp;&nbsp; (b) -3/2 &nbsp;&nbsp; (c) 2/3 &nbsp;&nbsp; (d) -2/3

**ANSWER: (b)**
```
        4 - (-2)         6
  m =  ------------  =  ------  =  -3/2
         -1 - 3          -4
```

---

### Q2
The angle of inclination of the line `sqrt(3) x + y - 1 = 0` is

(a) 30 &nbsp;&nbsp; (b) 60 &nbsp;&nbsp; (c) 120 &nbsp;&nbsp; (d) 150 (degrees)

**ANSWER: (c)**
```
  m = -a/b = -sqrt(3)/1 = -sqrt(3)

  tan(theta) = -sqrt(3)  with  0 <= theta < 180

  tan(120) = tan(180 - 60) = -tan(60) = -sqrt(3)     ->    theta = 120
```

> **SHORTCUT:** a NEGATIVE slope always means the inclination is between
> 90 and 180 degrees. That kills two options instantly.

### Q3
If the line joining (2, 3) and (4, k) is parallel to `3x - y = 5`, then k =

(a) 6 &nbsp;&nbsp; (b) 9 &nbsp;&nbsp; (c) 3 &nbsp;&nbsp; (d) -9

**ANSWER: (b)**
```
  Slope of 3x - y = 5  is  3.

     k - 3
    -------  =  3      ->      k - 3 = 6      ->      k = 9
     4 - 2
```

### Q4
A straight line makes equal angles with both coordinate axes. Its slope is

(a) 0 only &nbsp;&nbsp; (b) 1 only &nbsp;&nbsp; (c) 1 or -1 &nbsp;&nbsp; (d) undefined

**ANSWER: (c)**
```
  Equal angles means the inclination is 45 or 135 degrees.
  tan(45) = 1 ,   tan(135) = -1
```

(c) 3x - y + 5 = 0 &nbsp;&nbsp; (d) x - 3y - 5 = 0

**ANSWER: (a)**
```
  y + 2 = 3 ( x - 1 )

The acute angle between `3x + y = 1` and `x + 2y = 3` is

(a) 30 &nbsp;&nbsp; (b) 45 &nbsp;&nbsp; (c) 60 &nbsp;&nbsp; (d) 90 (degrees)

**ANSWER: (b)**
```
  m1 = -3 ,   m2 = -1/2

                   -3 - (-1/2)              -5/2
  tan(theta) = abs -------------- = abs  ----------  =  1     ->  45 degrees
                   1 + (-3)(-1/2)            5/2
```

### Q14
If `3x + k y = 5` is perpendicular to `2x + 3y = 1`, then k =

(a) 2 &nbsp;&nbsp; (b) -2 &nbsp;&nbsp; (c) 3 &nbsp;&nbsp; (d) -3

**ANSWER: (b)**
```
  Perpendicular condition:   a1 a2 + b1 b2 = 0

     3(2) + k(3) = 0
     6 + 3k = 0
     k = -2
```

> **SHORTCUT:** always use `a1 a2 + b1 b2 = 0` instead of `m1 m2 = -1`.
> It never breaks down when a line is vertical, and it needs no fractions.

> than solving.

### Q18
If the lines `a x + 2y + 1 = 0`, `b x + 3y + 1 = 0`, `c x + 4y + 1 = 0`
are concurrent, then a, b, c are in

(a) AP &nbsp;&nbsp; (b) GP &nbsp;&nbsp; (c) HP &nbsp;&nbsp; (d) no relation

**ANSWER: (a)**
```
   | a   2   1 |
   | b   3   1 |  =  0
   | c   4   1 |

   a(3 - 4)  -  2(b - c)  +  1(4b - 3c)  =  0
   -a - 2b + 2c + 4b - 3c  =  0
   -a + 2b - c  =  0
   2b  =  a + c            ->      a , b , c are in ARITHMETIC PROGRESSION
```

### Q19
If `2x + y = 3`, `3x - y = 2` and `k x + 2y = 5` are concurrent, then k =

(a) 1 &nbsp;&nbsp; (b) 2 &nbsp;&nbsp; (c) 3 &nbsp;&nbsp; (d) 4

**ANSWER: (c)**
```
  Solve the two WITHOUT k:

     2x + y = 3
     3x - y = 2
     ----------- ADD
     5x     = 5    ->   x = 1 ,  y = 1

  Put (1, 1) into the third:   k(1) + 2(1) = 5   ->   k = 3
```

### Q24
The distance of (2, 3) from the line `2x - 3y + 9 = 0` measured ALONG the line
`x - y + 1 = 0` is

(a) 4 &nbsp;&nbsp; (b) 4 sqrt(2) &nbsp;&nbsp; (c) 2 sqrt(2) &nbsp;&nbsp; (d) 8

**ANSWER: (b)**
```
  Note (2, 3) lies on x - y + 1 = 0 , since 2 - 3 + 1 = 0.
  That line has slope 1, so its inclination is 45 degrees.

  Use the SYMMETRIC form:
      x = 2 + r/sqrt(2)  ,   y = 3 + r/sqrt(2)

  Substitute into 2x - 3y + 9 = 0 :

      4 + 2r/sqrt(2)  -  9  -  3r/sqrt(2)  +  9  =  0
      4  -  r/sqrt(2)  =  0
      r  =  4 sqrt(2)
```

> **SHORTCUT:** "distance measured ALONG a given line" is ALWAYS the symmetric
> form. It is never the perpendicular-distance formula. Two different things.

# PATTERN 7 — Foot of the perpendicular and image

### Q25
The foot of the perpendicular from the origin to `3x + 4y - 5 = 0` is

(a) (3/5, 4/5) &nbsp;&nbsp; (b) (4/5, 3/5) &nbsp;&nbsp;
(c) (1, 1/2) &nbsp;&nbsp; (d) (5/3, 0)

**ANSWER: (a)**
```
  a = 3 , b = 4 , c = -5 ,  (x1, y1) = (0, 0)

      a x1 + b y1 + c  =  -5           a^2 + b^2  =  25

              -(-5)        1
      t  =  ---------  =  ---
               25           5

      x = 0 + 3(1/5) = 3/5      y = 0 + 4(1/5) = 4/5

  CHECK:  3(3/5) + 4(4/5) - 5 = 9/5 + 16/5 - 5 = 5 - 5 = 0     On the line.
```

The image of (2, 1) in the line `y = x` is

# PATTERN 8 — Family of lines

### Q29
The line through the intersection of `x + 2y = 5` and `3x + y = 5` and through
the ORIGIN is

(a) 2x - y = 0 &nbsp;&nbsp; (b) x - 2y = 0 &nbsp;&nbsp;
(c) x + y = 0 &nbsp;&nbsp; (d) 2x + y = 0

**ANSWER: (a)**
```
  Family:  (x + 2y - 5) + k (3x + y - 5) = 0

  Through the origin -> the constant term must vanish:

      -5 - 5k = 0     ->     k = -1

      (x + 2y - 5) - (3x + y - 5)  =  -2x + y  =  0     ->    2x - y = 0
```

> **SHORTCUT:** "passes through the origin" always means "constant term = 0".
> "Parallel to the x-axis" means "coefficient of x = 0".
> "Parallel to the y-axis" means "coefficient of y = 0".

# PATTERN 9 — Ratio of division and side of a line

### Q31
The line `3x + 4y = 9` divides the join of (1, 3) and (2, 7) in the ratio

(a) 6 : 25 internally &nbsp;&nbsp; (b) 6 : 25 externally &nbsp;&nbsp;
(c) 25 : 6 internally &nbsp;&nbsp; (d) 1 : 2 externally

**ANSWER: (b)**
```
  L(A) at (1, 3)  :  3 + 12 - 9  =  6
  L(B) at (2, 7)  :  6 + 28 - 9  =  25

              - L(A)         -6

### Q34
The length of the portion of `3x + 4y = 12` intercepted between the axes is

(a) 5 &nbsp;&nbsp; (b) 7 &nbsp;&nbsp; (c) 12 &nbsp;&nbsp; (d) 25

**ANSWER: (a)**
```

### Q36

# PATTERN 11 — Angle bisectors

### Q37
The bisector of the angle between `x + y - 3 = 0` and `7x - y + 5 = 0` that
CONTAINS THE ORIGIN is

(a) x - 3y + 10 = 0 &nbsp;&nbsp; (b) 6x + 2y - 5 = 0 &nbsp;&nbsp;
(c) 3x - y + 4 = 0 &nbsp;&nbsp; (d) x + 3y - 5 = 0

**ANSWER: (b)**
```
  STEP 0  Make both constants POSITIVE:

            -x - y + 3 = 0        (c1 = 3)
            7x - y + 5 = 0        (c2 = 5)

  STEP 1  Take the " + " sign.

          sqrt(1 + 1) = sqrt(2)          sqrt(49 + 1) = sqrt(50) = 5 sqrt(2)

            -x - y + 3            7x - y + 5
           ------------   =    ----------------
              sqrt(2)             5 sqrt(2)

            5( -x - y + 3 )  =  7x - y + 5
            -5x - 5y + 15    =  7x - y + 5
            -12x - 4y + 10   =  0
              6x + 2y -  5   =  0
```

---

### Q38
For the same two lines, the bisector of the ACUTE angle is

(a) x - 3y + 10 = 0 &nbsp;&nbsp; (b) 6x + 2y - 5 = 0 &nbsp;&nbsp;
(c) both &nbsp;&nbsp; (d) neither

**ANSWER: (b)**
```
  With both constants positive ( -x - y + 3 = 0 and 7x - y + 5 = 0 ):

     a1 a2 + b1 b2  =  (-1)(7) + (-1)(-1)  =  -7 + 1  =  -6

  NEGATIVE  ->  the origin bisector IS the acute angle bisector,
  and that is 6x + 2y - 5 = 0.
```

> **SHORTCUT — the whole bisector decision in one line:**
> make both constants positive, then
> `a1 a2 + b1 b2 < 0` means the origin bisector is ACUTE,
> `a1 a2 + b1 b2 > 0` means the origin bisector is OBTUSE.

If p is the length of the perpendicular from the origin to `x/a + y/b = 1`,

     p^2       a^2 b^2         b^2       a^2
```

### Q42
If the point (a, a) lies between the lines `x + y = 2` and `4(x + y) = 5`,
which is true?

(a) a lies between 1 and 5/8 &nbsp;&nbsp; (b) a lies between 5/8 and 1
&nbsp;&nbsp; (c) a > 1 &nbsp;&nbsp; (d) a < 5/8

**ANSWER: (b)**
```
  The point (a, a) has  x + y = 2a.

  "Between" the two parallel lines  x + y = 5/4  and  x + y = 2  means

          5/4  <  2a  <  2

          5/8  <   a  <  1
```

# THE 20-SECOND SANITY CHECK

Before you shade the bubble, ask ONE of these:

```
  Found a LINE ?      Substitute the given point. It must give 0.
  Found a POINT ?     Substitute it into the given line. It must give 0.
  Found a DISTANCE ?  Is it positive? Distances never come out negative.
  Found an ANGLE ?    Is it between 0 and 90? The formula gives the ACUTE angle.
  Found an IMAGE ?    Is the midpoint of the two points on the mirror line?
```

Every one of these takes under 20 seconds and catches almost every sign error
this chapter can produce.
