## THE 60-SECOND VERSION

A quadratic expression is just `ax^2 + bx + c` with `a` not equal to 0.

Its graph is always a **parabola** — a U shape or an upside-down U shape.

**Everything in this chapter is one of these four jobs:**

| Job | What you actually do | Where it is asked |
|-----|----------------------|-------------------|
| Find or describe the roots | discriminant, quadratic formula | Section A, 2 marks |
| Play with the roots | sum, product, form new equations | Section A / B |
| Ask about the SIGN | where is f(x) positive / negative? | Section B, 4 marks |
| Ask about the VALUE | max, min, range, range of a fraction | **Section C, 7 marks** |

The single picture that runs the whole chapter:

```
        a > 0   (U shape)                a < 0   (upside-down U)
             \         /                        _______
              \       /                        /       \
               \     /                        /         \
                \___/                        /           \

         has a MINIMUM                        has a MAXIMUM
         opens UPWARD                         opens DOWNWARD
```

## THE THREE DISCRIMINANT PICTURES (a > 0 shown)

```
      D > 0                     D = 0                     D < 0
   two real roots           one repeated root         no real roots

     \           /            \         /              \         /
      \         /              \       /                \       /
  -----\-------/-----      -----\-----/-----             \     /
   alpha\     /beta              \   /                    \___/
         \___/                    \_/                 ------------------
                              (just touches)          (never touches)
  ---------------------    ---------------------    ---------------------
   f(x) is NEGATIVE         f(x) >= 0 always         f(x) > 0 for ALL x
   only between the         (only 0 at x = -b/2a)
   roots

  For a < 0, flip every picture upside down and swap the words
  POSITIVE and NEGATIVE.
```

**The one sentence that answers half the sign questions:**

> `ax^2 + bx + c` has **the SAME sign as `a`** for every real x,
> **EXCEPT when x lies strictly between the roots** — there it has the opposite sign.

## IF YOU ONLY HAVE 2 DAYS

**Day 1 morning** — `D = b^2 - 4ac` and the four nature-of-roots cases.
Then sum `= -b/a`, product `= c/a`, and forming `x^2 - Sx + P = 0`.
Do 10 tiny questions. These are pure 2-mark marks and they are free.

**Day 1 evening** — The three parabola pictures and the sentence
"same sign as a except between the roots". Then solve 5 inequations
on a number line. That covers a full Section B question.

**Day 2 morning** — Maximum / minimum. Only two things to remember:
`x = -b/(2a)` and the value is `-D/(4a)`. Then the RANGE of a quadratic.
Do 5 problems.

**Day 2 evening** — The **range of a rational expression**. Learn the
5-step recipe (put `y =`, cross-multiply, collect as a quadratic in x,
set `D >= 0`, solve the inequality in y). Do the SAME 3 questions twice.
This one recipe is worth 7 marks on its own.

That plan alone is worth about 11 of the 75 marks in Maths IIA.
