## Topic: Nature of the roots

### Q A1
Find the nature of the roots of `4x^2 - 20x + 25 = 0`.

**ANSWER:**
```
  a = 4 , b = -20 , c = 25

  D = b^2 - 4ac = (-20)^2 - 4(4)(25) = 400 - 400 = 0

  D = 0  ->  the roots are REAL and EQUAL.

                 -b       20        5
  Both roots =  ------ = ------ = -----
                  2a        8        2
```

### Q A2
Find the nature of the roots of `3x^2 + 7x + 2 = 0`.

**ANSWER:**
```
  D = 7^2 - 4(3)(2) = 49 - 24 = 25 = 5^2

  D > 0 AND D is a perfect square, and 3, 7, 2 are rational.

  ->  the roots are RATIONAL and DISTINCT.

              -7 +- 5           -2      1              -12
      x  =  -----------  ->  x = --- = - ---   or  x = ------ = -2
                 6                6      3               6
```

### Q A3
Find the nature of the roots of `2x^2 - 8x + 3 = 0`.

**ANSWER:**
```
  D = (-8)^2 - 4(2)(3) = 64 - 24 = 40

  D > 0 but 40 is NOT a perfect square.

  ->  the roots are REAL, DISTINCT and IRRATIONAL
      (a conjugate surd pair).
```

## Topic: Forming a quadratic equation

### Q A11
Form the quadratic equation whose roots are `2 + sqrt(3)` and `2 - sqrt(3)`.

**ANSWER:**
```
  S = (2 + sqrt3) + (2 - sqrt3) = 4
  P = (2 + sqrt3)(2 - sqrt3)    = 4 - 3 = 1

  x^2 - Sx + P = 0    ->    x^2 - 4x + 1 = 0
```

### Q A16
If alpha, beta are the roots of `x^2 + px + q = 0`, form the equation whose
roots are `alpha^2` and `beta^2`.

**ANSWER:**
```
  S = -p ,  P = q

  New sum     = alpha^2 + beta^2 = S^2 - 2P = p^2 - 2q
  New product = alpha^2 . beta^2 = P^2      = q^2

  x^2 - (p^2 - 2q) x + q^2 = 0
```

### Q B3
Prove that `ax^2 + bx + c` has a minimum value `(4ac - b^2)/(4a)` at
`x = -b/(2a)` when `a > 0`.

**ANSWER:**
```
  Take a out of the first two terms and complete the square:

                                  b        c
  a x^2 + bx + c  =  a [ x^2  +  --- x  + --- ]
                                  a        a

                             b        b^2       b^2     c
                =  a [ x^2 + --- x + ------  - ------ + --- ]
                             a       4a^2      4a^2     a

                            b   2        b^2       c
                =  a [ ( x + ---- )  -  ------ + --- ]
                            2a          4a^2      a

                          b   2       b^2     c
                =  a ( x + ---- )  -  ---- + a . ---
                          2a          4a         a

                          b   2      4ac - b^2
                =  a ( x + ---- )  + -----------
                          2a             4a

  Now  ( x + b/(2a) )^2  is a square, so it is never negative.
  Since a > 0, the term  a ( x + b/(2a) )^2  is never negative either,

                  b
           x + ------- = 0      i.e.      x = -b/(2a)
                 2a

                  4ac - b^2         -D
```

### Q B6
If `x^2 + bx + c = 0` and `x^2 + cx + b = 0` (with b not equal to c) have a
common root, show that `b + c + 1 = 0`.

**ANSWER:**
```
  Let alpha be the common root. Then

      alpha^2 + b.alpha + c = 0        ... (1)
      alpha^2 + c.alpha + b = 0        ... (2)

  Subtract (2) from (1):

      (b - c) alpha  +  (c - b)  =  0
      (b - c) alpha  -  (b - c)  =  0
      (b - c)( alpha - 1 )       =  0

  Given b is not equal to c, so  b - c  is not 0.
  Therefore   alpha = 1.

  Put alpha = 1 in (1):

      1 + b + c = 0

      i.e.   b + c + 1 = 0                                    (proved)
```

### Q B8
Show that `x^2 + ax + b = 0` and `x^2 + cx + d = 0` have a common root if and
only if `(b - d)^2 = (a - c)(bc - ad)`.

**ANSWER:**
```
  Let alpha be the common root.

      alpha^2 + a.alpha + b = 0        ... (1)
      alpha^2 + c.alpha + d = 0        ... (2)

  SUBTRACT (2) from (1):

      (a - c) alpha + (b - d) = 0
                                 -(b - d)        b - d
                        alpha =  ---------- =  ---------      ... (3)
                                   a - c          c - a

  MULTIPLY (1) by d and (2) by b, then subtract, to kill the constant:

      d.alpha^2 + a d.alpha + bd = 0
      b.alpha^2 + b c.alpha + bd = 0
      -------------------------------
      (d - b) alpha^2 + (ad - bc) alpha = 0

      alpha [ (d - b) alpha + (ad - bc) ] = 0

  For a non-zero common root,

                      ad - bc         bc - ad
             alpha = ---------- =  ------------            ... (4)
                       b - d          b - d

  Equate (3) and (4):

           b - d        bc - ad
         ---------  =  ----------
           c - a         b - d

         (b - d)^2  =  (c - a)(bc - ad)

  and since (c - a)(bc - ad) = (a - c)(ad - bc), the standard form is

         (b - d)^2  =  (a - c)(bc - ad)                     (proved)

  CHECK with a real pair:  x^2 - 5x + 6 = 0 and x^2 - x - 6 = 0
                           (a = -5, b = 6, c = -1, d = -6), common root 3.

         (b - d)^2      = (6 + 6)^2 = 144
         (a - c)(bc-ad) = (-5 + 1)( (6)(-1) - (-5)(-6) )
                        = (-4)( -6 - 30 ) = (-4)(-36) = 144    YES
```

### Q B10
Prove that the roots of `(x - a)(x - b) = h^2` are always real.

**ANSWER:**
```
  Expand:

      x^2 - (a + b)x + ab - h^2 = 0

  Discriminant:

      D = (a + b)^2 - 4(ab - h^2)
        = a^2 + 2ab + b^2 - 4ab + 4h^2
        = a^2 - 2ab + b^2 + 4h^2
        = (a - b)^2 + 4 h^2

  Both (a - b)^2 and 4h^2 are squares, so neither can be negative.

      D  >=  0   for all real a, b, h.

  Therefore the roots are always REAL.
  (They are equal only when a = b AND h = 0.)          (proved)
```

### Q B12
If x is real, find the range of `(x^2 + x + 1) / (x^2 - x + 1)`.

**ANSWER:**
```
  STEP 1   Denominator  x^2 - x + 1 :
           D = (-1)^2 - 4(1)(1) = 1 - 4 = -3 < 0 and a = 1 > 0,
           so the denominator is positive for every real x - never zero.

  STEP 2   Let  y = (x^2 + x + 1)/(x^2 - x + 1) ,  cross-multiply:

           y(x^2 - x + 1) = x^2 + x + 1

  STEP 3   Collect as a quadratic in x:

           (y - 1) x^2  -  (y + 1) x  +  (y - 1)  =  0

  STEP 4   x is real  ->  B^2 - 4AC >= 0 :

           (y + 1)^2  -  4(y - 1)(y - 1)  >=  0
           (y + 1)^2  -  [ 2(y - 1) ]^2   >=  0

           Difference of squares, A = y + 1 , B = 2y - 2 :

           ( y + 1 - 2y + 2 )( y + 1 + 2y - 2 )  >=  0
                ( 3 - y )( 3y - 1 )              >=  0

           Multiply by -1 and flip:
                ( y - 3 )( 3y - 1 )              <=  0

  STEP 5   Roots  y = 1/3  and  y = 3 :

                   +             -             +
           <------------ 1/3 ---------- 3 ------------>

           RANGE  =  [ 1/3 , 3 ]
```

```
      (3)        (0==========================================>

      Common part:   0 < a <= 1

  ANSWER:   0 < a <= 1

  CHECK a = 1 :  x^2 - 2x + 1 = (x - 1)^2  ->  roots 1, 1 both positive  YES
  CHECK a = 2 :  x^2 - x + 2 , D = 1 - 8 = -7 < 0 , not real -> correctly
                 excluded.
```

### Q B15
Find k so that `2x^2 + 3xy - 2y^2 + 5x + 5y + k` is resolvable into two linear
factors.

**ANSWER:**
```
  Compare with   a x^2 + 2h xy + b y^2 + 2g x + 2f y + c :

      a = 2 ,  2h = 3  -> h = 3/2 ,  b = -2
      2g = 5  -> g = 5/2 ,  2f = 5  -> f = 5/2 ,  c = k

  Condition:      a b c + 2 f g h - a f^2 - b g^2 - c h^2 = 0

      a b c   =  2 (-2) k              =  -4k
      2 f g h =  2 (5/2)(5/2)(3/2)     =  75/4
      a f^2   =  2 (5/2)^2  = 2(25/4)  =  50/4
      b g^2   = -2 (5/2)^2  = -2(25/4) = -50/4
      c h^2   =  k (3/2)^2             =  9k/4

      -4k + 75/4 - 50/4 - ( -50/4 ) - 9k/4  =  0
      -4k + 75/4 - 50/4 + 50/4 - 9k/4       =  0
      -4k - 9k/4 + 75/4                     =  0

  Multiply throughout by 4:

      -16k - 9k + 75 = 0
             -25k    = -75
                 k   = 3

  CHECK:   2x^2 + 3xy - 2y^2 = (2x - y)(x + 2y)
           (2x - y + 3)(x + 2y + 1)
           = 2x^2 + 4xy + 2x - xy - 2y^2 - y + 3x + 6y + 3
           = 2x^2 + 3xy - 2y^2 + 5x + 5y + 3          YES,  k = 3
```

### Q C1
If x is real, find the range of
```
              x^2 + 14x + 9
       y  =  ----------------
              x^2 + 2x + 3
```

**ANSWER:**
```
  STEP 1   The denominator never vanishes.

           For  x^2 + 2x + 3 :   D = 2^2 - 4(1)(3) = 4 - 12 = -8  <  0
           and the coefficient of x^2 is 1 > 0.
           So  x^2 + 2x + 3 > 0  for every real x.  The fraction is
           defined for all real x.

  STEP 2   Cross-multiply.

           y ( x^2 + 2x + 3 )  =  x^2 + 14x + 9

           y x^2 + 2y x + 3y   =  x^2 + 14x + 9

  STEP 3   Bring everything to one side and group as a quadratic IN x.

           ( y - 1 ) x^2  +  ( 2y - 14 ) x  +  ( 3y - 9 )  =  0

                A = y - 1 ,   B = 2y - 14 ,   C = 3y - 9

  STEP 4   Since x is REAL, the discriminant of this quadratic in x
           must be greater than or equal to zero.

           B^2 - 4AC  >=  0

           ( 2y - 14 )^2  -  4 ( y - 1 )( 3y - 9 )  >=  0

           4 ( y - 7 )^2  -  4 ( y - 1 ) . 3 ( y - 3 )  >=  0

           Divide by 4:

           ( y - 7 )^2  -  3 ( y - 1 )( y - 3 )  >=  0

           ( y^2 - 14y + 49 )  -  3 ( y^2 - 4y + 3 )  >=  0

             y^2 - 14y + 49  -  3y^2 + 12y - 9  >=  0

                       -2 y^2  -  2y  +  40     >=  0

           Divide by -2 and FLIP the inequality:

                        y^2  +  y  -  20        <=  0

  STEP 5   Factorise and use the number line.

                    ( y + 5 )( y - 4 )  <=  0

                   +             -             +
           <------------- -5 ---------- 4 ------------>

           The expression is <= 0 between the roots, endpoints included.

           +----------------------------------------+
           |   RANGE  =  [ -5 , 4 ]                  |
           |   that is,   -5  <=  y  <=  4           |
           +----------------------------------------+

  NOTE on y = 1.  When y = 1 the coefficient A becomes 0 and the equation
  is no longer quadratic; it becomes  -12x - 6 = 0 , giving x = -1/2 ,
  which is real. So y = 1 IS attained, and 1 lies inside [-5, 4]. Consistent.
```

### Q C2
If x is real, find the maximum and minimum values of
```
                x + 2
       y  =  --------------
              2x^2 + 3x + 6
```

**ANSWER:**
```
  STEP 1   Denominator  2x^2 + 3x + 6 :
           D = 3^2 - 4(2)(6) = 9 - 48 = -39  <  0 , and 2 > 0.
           So the denominator is positive for all real x - never zero.

  STEP 2   y ( 2x^2 + 3x + 6 )  =  x + 2

  STEP 3   2y x^2 + 3y x + 6y - x - 2 = 0

  STEP 4   x real   ->   B^2 - 4AC >= 0

           ( 3y - 1 )^2  -  4 ( 2y )( 6y - 2 )  >=  0

           9y^2 - 6y + 1  -  48y^2 + 16y        >=  0

                     -39 y^2  +  10y  +  1      >=  0

                      39 y^2  -  10y  -  1      <=  0

  STEP 5   Solve  39y^2 - 10y - 1 = 0  by the formula:

                  10 +- sqrt( 100 + 4(39) )       10 +- sqrt(256)

                            2(39)                       78

                  10 +- 16
              =  ----------
                     78

                  26      1                    -6         1
           y  =  ---- = -----     and    y = ------ =  - -----
                  78      3                    78         13

                    +               -               +
           <------------ -1/13 ----------- 1/3 ------------>

           +---------------------------------------------+
           |   RANGE  =  [ -1/13 , 1/3 ]                  |
           |                                              |
           |   MAXIMUM value  =  1/3                      |
           |   MINIMUM value  =  -1/13                    |
           +---------------------------------------------+

  NOTE on y = 0.  Then A = 0 and the equation becomes  -x - 2 = 0 , so
```

### Q C3
If x is real, prove that
```
              x^2 - 3x + 4
       y  =  ---------------
              x^2 + 3x + 4
```
lies between `1/7` and `7`.

**ANSWER:**
```
  STEP 1   Denominator  x^2 + 3x + 4 :
           D = 9 - 16 = -7  <  0 , and 1 > 0 , so it is positive for all
           real x and never zero.

  STEP 2   y ( x^2 + 3x + 4 )  =  x^2 - 3x + 4

  STEP 3   ( y - 1 ) x^2  +  ( 3y + 3 ) x  +  ( 4y - 4 )  =  0

                A = y - 1 ,   B = 3(y + 1) ,   C = 4(y - 1)

  STEP 4   x real   ->   B^2 - 4AC >= 0

           9 ( y + 1 )^2  -  4 ( y - 1 ) . 4 ( y - 1 )  >=  0

           9 ( y + 1 )^2  -  16 ( y - 1 )^2  >=  0

           [ 3(y + 1) ]^2  -  [ 4(y - 1) ]^2  >=  0

           Difference of two squares:

           ( 3y + 3 - 4y + 4 )( 3y + 3 + 4y - 4 )  >=  0

                ( 7 - y )( 7y - 1 )  >=  0

           Multiply by -1 and FLIP:

                ( y - 7 )( 7y - 1 )  <=  0

  STEP 5   Roots  y = 1/7  and  y = 7 :

                   +             -             +
           <------------ 1/7 ---------- 7 ------------>

           +--------------------------------------------+
           |     1/7  <=  y  <=  7                       |
           +--------------------------------------------+

           So the expression never goes outside [ 1/7 , 7 ].    (proved)

  NOTE on y = 1.  Then A = 0 and the equation becomes 6x = 0 , so x = 0 ,
  which is real, and indeed at x = 0 the fraction is 4/4 = 1. Consistent.
```

### Q C4
If x is real, show that
```
              x^2 + 34x - 71
       y  =  -----------------
               x^2 + 2x - 7
```
does not lie between `5` and `9`.

**ANSWER:**
```
  STEP 1   Note first that  x^2 + 2x - 7 = 0  when x = -1 +- 2 sqrt(2).
           Those two values of x are excluded from the domain; for every
           other real x the fraction is defined.

  STEP 2   y ( x^2 + 2x - 7 )  =  x^2 + 34x - 71

  STEP 3   y x^2 + 2y x - 7y - x^2 - 34x + 71  =  0

           ( y - 1 ) x^2  +  ( 2y - 34 ) x  +  ( 71 - 7y )  =  0

                A = y - 1 ,   B = 2( y - 17 ) ,   C = 71 - 7y

  STEP 4   x real   ->   B^2 - 4AC >= 0

           4 ( y - 17 )^2  -  4 ( y - 1 )( 71 - 7y )  >=  0

           Divide by 4:

           ( y - 17 )^2  -  ( y - 1 )( 71 - 7y )  >=  0

           ( y^2 - 34y + 289 )  -  ( 71y - 7y^2 - 71 + 7y )  >=  0

           ( y^2 - 34y + 289 )  -  ( -7y^2 + 78y - 71 )      >=  0

             y^2 - 34y + 289 + 7y^2 - 78y + 71               >=  0

                     8 y^2  -  112 y  +  360                 >=  0

           Divide by 8:

                       y^2  -  14 y  +  45                   >=  0

  STEP 5   Factorise:      ( y - 5 )( y - 9 )  >=  0

                   +             -             +
           <------------- 5 ----------- 9 ------------>

           The expression is >= 0 OUTSIDE the roots.

           +----------------------------------------------+
           |    y <= 5    or    y >= 9                     |
           |                                               |
           |    So y NEVER lies strictly between 5 and 9.  |
           +----------------------------------------------+
                                                            (proved)
```

### Q C5
Prove that `ax^2 + bx + c` has the same sign as `a` for every real x if and
only if `b^2 - 4ac < 0`. Hence find the values of m for which
`m x^2 + (m - 1) x + (m - 1)` is negative for every real x.

**ANSWER:**
```
  PART 1 - the proof.

  From completing the square (see Q B3):

                                b   2      4ac - b^2
      a x^2 + bx + c  =  a ( x + ---- )  + -----------
                               2a             4a

  Multiply both sides by 4a:

      4a ( ax^2 + bx + c )  =  ( 2ax + b )^2  +  ( 4ac - b^2 )

                            =  ( 2ax + b )^2  -  D            where D = b^2-4ac

  Now  ( 2ax + b )^2  is never negative.

  CASE D < 0 :   then  -D > 0 , so the right side is
                 (something >= 0) + (something > 0)  =  STRICTLY POSITIVE.
                 So  4a . f(x) > 0  for every x, which means f(x) has the
                 same sign as a for every real x.

  CASE D = 0 :   the right side is (2ax + b)^2 , which is 0 when x = -b/2a.
                 So f(x) = 0 there - it does NOT keep the sign of a.

  CASE D > 0 :   the right side  (2ax+b)^2 - D  is negative for values of x
                 that make (2ax+b)^2 < D , so 4a.f(x) changes sign.
                 So f(x) does NOT keep the sign of a.

  Hence f(x) keeps the sign of a for ALL real x exactly when D < 0.  (proved)


  PART 2 - the application.

  We need  m x^2 + (m - 1)x + (m - 1)  <  0  for every real x.

  That needs TWO things:

     (i)   m < 0                     (the sign of a must be negative)
     (ii)  D < 0

  Compute D:

     D = (m - 1)^2 - 4 m (m - 1)
       = (m - 1) [ (m - 1) - 4m ]
       = (m - 1)( -3m - 1 )
       = -(m - 1)(3m + 1)

  Require D < 0:

       -(m - 1)(3m + 1)  <  0
        (m - 1)(3m + 1)  >  0

  Roots  m = 1  and  m = -1/3 :

                   +             -             +
           <------------ -1/3 ---------- 1 ------------>

       ->   m < -1/3    or    m > 1

  Now combine with condition (i) m < 0 :

       (i)    <=============0)
       (ii)   <====-1/3)              (1=========>

       Common part:   m  <  -1/3

  +--------------------------------------------+
  |   ANSWER:   m  <  -1/3                      |
  +--------------------------------------------+

  CHECK m = -1 :   -x^2 - 2x - 2 ,  a = -1 < 0 ,
                   D = 4 - 4(-1)(-2) = 4 - 8 = -4 < 0     negative always  YES

  CHECK m = -1/5 : -0.2x^2 - 1.2x - 1.2 ,
                   D = 1.44 - 4(-0.2)(-1.2) = 1.44 - 0.96 = 0.48 > 0
                   -> it changes sign, so correctly excluded.
```
