## THE FAMILY OF NUMBERS (where complex numbers fit)

```
                       COMPLEX NUMBERS   C          z = x + iy
                                |
        +-----------------------+-----------------------+
        |                                               |
   REAL NUMBERS  R                            PURELY IMAGINARY
   (when y = 0)                                  (when x = 0)
        |                                        3i , -7i , i sqrt2
   +----+----+
   |         |
 RATIONAL  IRRATIONAL
   |
 INTEGERS
   |
 WHOLE
   |
 NATURAL
```

Read it downwards: every real number is also a complex number
(5 is really 5 + 0i). **The reverse is NOT true.**

> Zero is the only number that is BOTH purely real and purely imaginary.

## THE 60-SECOND VERSION

Some equations have no answer among ordinary numbers. `x^2 + 1 = 0` needs a
number whose square is -1. Nobody could find one, so mathematicians **invented**
one and called it **i**.

```
                        i x i  =  i^2  =  -1
```

That single line is the whole chapter. Everything else follows from it.

A complex number is just **two real numbers glued together**: `z = x + iy`.
Treat it like the algebra expression `x + 5y` — collect terms, multiply out
brackets — and every time you see `i^2`, replace it by `-1`.

Everything in this chapter is one of five jobs:

| Job | What you actually do | Where it is asked |
|-----|----------------------|-------------------|
| Simplify | powers of i, add, multiply | Section A, 2 marks |
| Express in a + ib form | multiply top and bottom by the conjugate | Section A, 2 marks |
| Measure | find modulus and principal amplitude | Section A / B |
| Prove | show an identity using z x z bar = \|z\|^2 | Section B, 4 marks |
| Find a locus | turn a z-statement into an x-y equation | **Section B / C** |

## THE KEY BOX — the two formulas that unlock most problems

```
  +--------------------------------------------------------------+
  |                                                              |
  |     (1)     i^2  =  -1                                       |
  |                                                              |
  |     (2)     z  x  z bar  =  x^2 + y^2  =  |z|^2              |
  |                                                              |
  |             (x + iy)(x - iy)  =  x^2 + y^2                   |
  |                                                              |
  |             ...and this is ALWAYS A REAL NUMBER.             |
  |             That is why multiplying by the conjugate         |
  |             clears i out of the denominator.                 |
  |                                                              |
  +--------------------------------------------------------------+
```

Formula (2) is the reason the conjugate exists. Every "express in a + ib form",
every "find the multiplicative inverse", every modulus proof is that one line.

## IF YOU ONLY HAVE 2 DAYS

**Day 1 morning (2 hours)** — Powers of i, `i^2 = -1`, addition, multiplication,
equality of complex numbers. Then do 10 "express in a + ib form" divisions.
This alone secures 4 marks in Section A.

**Day 1 evening (2 hours)** — Conjugate + modulus. Memorise the six modulus
properties. Learn the multiplicative inverse formula. Do 5 problems.

**Day 2 morning (2 hours)** — Modulus and PRINCIPAL amplitude, with the
quadrant rule. Practise these four and you have seen every version:

```
      1 + i sqrt3          ->  r = 2 ,        theta =  pi/3
     -1 + i                ->  r = sqrt2 ,    theta =  3pi/4
     -1 - i sqrt3          ->  r = 2 ,        theta = -2pi/3
      1 - i                ->  r = sqrt2 ,    theta = -pi/4
```

**Day 2 evening (2 hours)** — Square root of a complex number (one formula),
then locus problems. Learn just these three shapes:

```
     |z - z1| = r          ->  CIRCLE, centre z1, radius r
     |z - z1| = |z - z2|   ->  PERPENDICULAR BISECTOR (a straight line)
     amp(...) = pi/2       ->  CIRCLE (set the REAL part to zero)
```

That is about 10 of the 75 marks in Maths IIA, from a chapter you can finish
in eight hours.
