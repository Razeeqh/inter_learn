## Topic: Centre and radius from the general equation

### Q A1
Find the centre and radius of the circle x^2 + y^2 - 4x + 6y - 12 = 0.

**ANSWER:**
```
  2g = -4  ->  g = -2          2f = 6  ->  f = 3          c = -12

  CENTRE = (-g, -f) = ( 2 , -3 )

  RADIUS = sqrt(g^2 + f^2 - c) = sqrt(4 + 9 + 12) = sqrt(25) = 5
```
**Centre (2, -3), radius 5**

### Q B8
Find the pair of tangents drawn from the origin to x^2 + y^2 + 4x + 3 = 0.

**ANSWER:** Use S * S1 = T^2.
```
  g = 2 , f = 0 , c = 3 ,  (x1, y1) = (0, 0)

  S1 = 0 + 0 + 0 + 0 + 3 = 3        (positive, so the origin is outside)

  T  = x(0) + y(0) + 2(x + 0) + 0(y + 0) + 3  =  2x + 3

  S * S1 = T^2 :

     3 ( x^2 + y^2 + 4x + 3 )   =   (2x + 3)^2

     3x^2 + 3y^2 + 12x + 9      =   4x^2 + 12x + 9

     3y^2 - x^2 = 0

     x^2 - 3y^2 = 0    ->    ( x - sqrt(3) y )( x + sqrt(3) y ) = 0

  CHECK: centre (-2,0), r = sqrt(4 - 3) = 1. A line y = mx from the origin
         touches when | -2m | / sqrt(1 + m^2) = 1,  so 4m^2 = 1 + m^2,
         m^2 = 1/3.   CORRECT
```
**x^2 - 3y^2 = 0, i.e. the two lines x = sqrt(3) y and x = -sqrt(3) y**

### Q C4
Find the equation of the pair of tangents drawn from (0, 0) to
x^2 + y^2 + 10x + 10y + 40 = 0.

**ANSWER:**
```
  STEP 1   Identify:  g = 5 , f = 5 , c = 40
           Centre = (-5, -5) ,  r = sqrt(25 + 25 - 40) = sqrt(10)

  STEP 2   S1 at (0, 0):

           S1 = 0 + 0 + 10(0) + 10(0) + 40 = 40      (positive -> outside)

  STEP 3   T with (x1, y1) = (0, 0):

           T = x(0) + y(0) + 5(x + 0) + 5(y + 0) + 40  =  5x + 5y + 40

  STEP 4   Pair of tangents:   S * S1 = T^2

           40 ( x^2 + y^2 + 10x + 10y + 40 )  =  ( 5x + 5y + 40 )^2

  LEFT  =  40x^2 + 40y^2 + 400x + 400y + 1600

  RIGHT =  25x^2 + 25y^2 + 1600 + 50xy + 400x + 400y

  STEP 5   LEFT - RIGHT = 0 :

           15x^2 + 15y^2 - 50xy = 0

           Divide by 5:

           3x^2  +  3y^2  -  10xy  =  0

  STEP 6   Factorise to see the two separate lines:

           3x^2 - 10xy + 3y^2 = ( 3x - y )( x - 3y ) = 0

           so the tangents are   3x - y = 0   and   x - 3y = 0

  STEP 7   CHECK.  A line y = mx through the origin touches when

              | -5m + 5 |
             -------------  =  sqrt(10)
             sqrt(m^2 + 1)

              25(1 - m)^2 = 10(m^2 + 1)
              25m^2 - 50m + 25 = 10m^2 + 10
              15m^2 - 50m + 15 = 0
               3m^2 - 10m + 3  = 0
                     m = 3  or  m = 1/3

           which are exactly the lines y = 3x and y = x/3.    CORRECT
```
**3x^2 + 3y^2 - 10xy = 0, i.e. the lines 3x - y = 0 and x - 3y = 0**

### Q C5
Show that the circles x^2 + y^2 - 6x - 2y + 1 = 0 and
x^2 + y^2 + 2x - 8y + 13 = 0 touch each other. Find the point of contact and
the equation of the common tangent at that point.

**ANSWER:**
```
  STEP 1   Centres and radii.

     CIRCLE 1:  g1 = -3 , f1 = -1 , c1 = 1
                C1 = (3, 1) ,  r1 = sqrt(9 + 1 - 1) = sqrt(9) = 3

     CIRCLE 2:  g2 = 1 , f2 = -4 , c2 = 13
                C2 = (-1, 4) ,  r2 = sqrt(1 + 16 - 13) = sqrt(4) = 2

  STEP 2   Distance between the centres.

     d = sqrt( (3 + 1)^2 + (1 - 4)^2 ) = sqrt(16 + 9) = sqrt(25) = 5

  STEP 3   Compare.

     r1 + r2 = 3 + 2 = 5 = d

     ->  THE CIRCLES TOUCH EXTERNALLY.

  STEP 4   Point of contact.
     It divides C1C2 INTERNALLY in the ratio r1 : r2 = 3 : 2.

            ( 3(-1) + 2(3)     3(4) + 2(1) )
      P  =  ( -------------- , ------------- )
            (     3 + 2            3 + 2    )

            (  -3 + 6     12 + 2  )       (  3    14  )
         =  ( --------- , -------- )   =  ( --- , ---- )
            (     5           5    )      (  5     5  )

  STEP 5   Common tangent = the radical axis S - S' = 0.

     ( -6x - 2y + 1 )  -  ( 2x - 8y + 13 )  =  0

           -8x + 6y - 12 = 0

     Divide by -2:      4x - 3y + 6 = 0

  STEP 6   CHECKS.

     Point of contact on the tangent:
         4(3/5) - 3(14/5) + 6 = 12/5 - 42/5 + 6 = -6 + 6 = 0   CORRECT

     Distance from C1(3,1) to 4x - 3y + 6 = 0
         = |12 - 3 + 6| / 5 = 15/5 = 3 = r1                    CORRECT

     Distance from C2(-1,4) to 4x - 3y + 6 = 0
         = |-4 - 12 + 6| / 5 = 10/5 = 2 = r2                   CORRECT
```
**They touch externally at ( 3/5 , 14/5 ); common tangent 4x - 3y + 6 = 0**

### Q C6
Find the equation of the circle which passes through the origin and (2, 0) and
cuts the circle x^2 + y^2 - 4x + 2y - 7 = 0 orthogonally.

**ANSWER:**
```
  STEP 1   Let the required circle be  x^2 + y^2 + 2gx + 2fy + c = 0

  STEP 2   It passes through the ORIGIN (0, 0):

              0 + 0 + 0 + 0 + c = 0      ->     c = 0

  STEP 3   It passes through (2, 0):

              4 + 0 + 4g + 0 + 0 = 0     ->     4g = -4     ->    g = -1

  STEP 4   Orthogonality with the given circle
           ( g2 = -2 , f2 = 1 , c2 = -7 ):

              2 g g2  +  2 f f2   =   c + c2

              2(-1)(-2)  +  2 f (1)  =  0 + (-7)

                    4    +   2f      =  -7

                            2f       =  -11

                             f       =  -11/2

  STEP 5   The circle:

              x^2 + y^2 - 2x - 11y = 0

  STEP 6   CHECKS.

     Origin  : 0 = 0                                        CORRECT
     (2, 0)  : 4 + 0 - 4 - 0 = 0                            CORRECT
     Orthogonality: 2(-1)(-2) + 2(-11/2)(1) = 4 - 11 = -7
                    c1 + c2 = 0 + (-7) = -7   EQUAL         CORRECT
```
**x^2 + y^2 - 2x - 11y = 0**
