## THE 60-SECOND VERSION

A circle is the set of all points that are a **fixed distance** (the radius) from
one **fixed point** (the centre). That single sentence generates the entire chapter.

Everything you will ever be asked is one of five jobs:

| Job | What you actually do | Where it is asked |
|-----|----------------------|-------------------|
| Find centre and radius | read off -g, -f and sqrt(g^2+f^2-c) | Section A, 2 marks |
| Find the equation of a circle | plug the given data into a form | Section A / B |
| Where is a POINT? | compute S1 and look at its sign | Section A, 2 marks |
| Where is a LINE? | compare perpendicular distance d with r | Section B, 4 marks |
| Tangent / chord / polar / two circles | one formula each | **Section C, 7 marks** |

## THE ONE BOX YOU MUST NEVER FORGET

```
  +------------------------------------------------------------------+
  |                                                                  |
  |     GENERAL EQUATION OF A CIRCLE                                  |
  |                                                                  |
  |            x^2  +  y^2  +  2gx  +  2fy  +  c  =  0               |
  |                                                                  |
  |     (coefficient of x^2 = coefficient of y^2, and NO xy term)    |
  |                                                                  |
  |     CENTRE   =  ( -g , -f )        <-- HALF the x-coefficient    |
  |                                        and HALF the y-coefficient|
  |                                        with the SIGN FLIPPED     |
  |                                                                  |
  |     RADIUS   =  sqrt( g^2 + f^2 - c )                            |
  |                                                                  |
  +------------------------------------------------------------------+

  READ IT LIKE THIS:

     x^2 + y^2 - 4x + 6y - 12 = 0
                 ----   ----   ---
                 2g=-4  2f=6   c=-12
                 g =-2  f =3

     Centre = (-g, -f) = ( 2 , -3 )
     Radius = sqrt(4 + 9 + 12) = sqrt(25) = 5
```

**And the three cases:**

```
  +--------------------------+-------------------------------------+
  |  g^2 + f^2 - c  >  0     |  REAL circle (a proper circle)       |
  +--------------------------+-------------------------------------+
  |  g^2 + f^2 - c  =  0     |  POINT circle (radius 0, just the    |
  |                          |  single point (-g, -f))              |
  +--------------------------+-------------------------------------+
  |  g^2 + f^2 - c  <  0     |  IMAGINARY circle (nothing is drawn) |
  +--------------------------+-------------------------------------+
```

## THE ONE EXPRESSION THAT RUNS THE WHOLE CHAPTER

```
  Let    S   =  x^2 + y^2 + 2gx + 2fy + c            (the circle itself)

         S1  =  x1^2 + y1^2 + 2gx1 + 2fy1 + c        (put the POINT in)

         T   =  x*x1 + y*y1 + g(x + x1) + f(y + y1) + c
                \_______/     \_________/  \_________/
                 mix x with    average      average
                 x1, y with y1  the x's     the y's

  +--------------------------------+------------------------------+
  |  S1 < 0                        |  point is INSIDE             |
  |  S1 = 0                        |  point is ON the circle      |
  |  S1 > 0                        |  point is OUTSIDE            |
  |  sqrt(S1)                      |  LENGTH of the tangent       |
  |  S1                            |  POWER of the point          |
  |  T = 0 with (x1,y1) ON circle  |  the TANGENT at that point   |
  |  T = 0 with (x1,y1) OUTSIDE    |  the CHORD OF CONTACT        |
  |  T = 0 for ANY point           |  the POLAR of that point     |
  |  T = S1                        |  chord with MIDPOINT (x1,y1) |
  |  S S1 = T^2                    |  PAIR OF TANGENTS            |
  +--------------------------------+------------------------------+
```

**That single table is worth more marks than any other page in this folder.**

## IF YOU ONLY HAVE 2 DAYS

**Day 1 morning** — The general equation. Centre = (-g, -f), radius = sqrt(g^2+f^2-c).
Do 15 of them, including ones where you must first divide by 2 or 3.
Then the diameter form and "touches the x-axis / y-axis". These are pure 2-mark marks.

**Day 1 evening** — S1. Position of a point, length of the tangent, power of a point.
Then line vs circle using the perpendicular distance d. Do 8 problems.

**Day 2 morning** — The T family: tangent at a point, chord of contact, polar,
chord with a given midpoint. They are ONE formula. Write T out ten times by hand.
Then the circle through three points — that is your 7-mark question.

**Day 2 evening** — Two circles: number of common tangents, radical axis S - S' = 0,
and orthogonality 2g1g2 + 2f1f2 = c1 + c2. Do 5 problems.

That alone is worth about 13 of the 75 marks in Maths IIB, and it is the most
mechanical, least-thinking set of marks in the entire paper.
