# PATTERN 1 — Centre, radius, type of circle (free marks)

### Q1
The centre of the circle 2x^2 + 2y^2 - 6x + 4y - 3 = 0 is

(a) (3/2, -1) &nbsp;&nbsp; (b) (-3/2, 1) &nbsp;&nbsp; (c) (3, -2) &nbsp;&nbsp; (d) (-3, 2)

**ANSWER: (a)**
```
  Divide by 2 first:   x^2 + y^2 - 3x + 2y - 3/2 = 0

  2g = -3  ->  g = -3/2         2f = 2  ->  f = 1

  Centre = (-g, -f) = ( 3/2 , -1 )
```

> **SHORTCUT:** Centre = ( -half the x-coefficient , -half the y-coefficient ).
> Never complete the square in an MCQ — it wastes 40 seconds.

---

### Q2
The radius of x^2 + y^2 - 4x + 6y - 12 = 0 is

(a) 3 &nbsp;&nbsp; (b) 4 &nbsp;&nbsp; (c) 5 &nbsp;&nbsp; (d) 25

**ANSWER: (c)**
```
  g = -2 , f = 3 , c = -12

  r = sqrt(4 + 9 + 12) = sqrt(25) = 5
```

### Q3
The equation x^2 + y^2 - 2x + 4y + 5 = 0 represents

(a) a real circle &nbsp; (b) a point circle &nbsp; (c) an imaginary circle &nbsp; (d) not a circle

**ANSWER: (b)**
```
  g = -1 , f = 2 , c = 5

  g^2 + f^2 - c = 1 + 4 - 5 = 0    ->   radius 0

  It is only the point (1, -2).
```

### Q4
If the radius of x^2 + y^2 + 4x + 6y + k = 0 is 4, then k =

(a) 3 &nbsp;&nbsp; (b) -3 &nbsp;&nbsp; (c) 13 &nbsp;&nbsp; (d) 29

**ANSWER: (b)**
```
  g = 2 , f = 3

  g^2 + f^2 - c = r^2

     4 + 9 - k = 16

           k = -3
```

### Q5
The circle x^2 + y^2 - 4x - 6y + k = 0 touches the x-axis if k =

(a) 4 &nbsp;&nbsp; (b) 6 &nbsp;&nbsp; (c) 9 &nbsp;&nbsp; (d) 13

**ANSWER: (a)**
```
  Touching the x-axis  <=>  g^2 = c

  g = -2  ->  g^2 = 4  =  k

  CHECK: centre (2,3), r = sqrt(4 + 9 - 4) = 3 = distance to the x-axis.
```

> **SHORTCUT:** touches x-axis -> g^2 = c ; touches y-axis -> f^2 = c ;
> touches BOTH -> g^2 = f^2 = c ; passes through the origin -> c = 0.
> Four one-line answers, no working needed.

**ANSWER: (c)** — put (0, 0) in: the whole left side becomes c, so c = 0.

# PATTERN 2 — Writing down the equation of a circle

### Q7
The equation of the circle with centre (2, -3) and radius 4 is

(a) x^2 + y^2 - 4x + 6y - 3 = 0
(b) x^2 + y^2 + 4x - 6y - 3 = 0
(c) x^2 + y^2 - 4x + 6y + 3 = 0
(d) x^2 + y^2 - 4x - 6y - 3 = 0

**ANSWER: (a)**
```
  (x - 2)^2 + (y + 3)^2 = 16

  x^2 - 4x + 4 + y^2 + 6y + 9 = 16

  x^2 + y^2 - 4x + 6y - 3 = 0

  CHECK: g = -2, f = 3, c = -3, r = sqrt(4 + 9 + 3) = 4   CORRECT
```

### Q8
The circle whose diameter has ends (2, -3) and (-3, 5) is

(a) x^2 + y^2 + x - 2y - 21 = 0
(b) x^2 + y^2 - x + 2y - 21 = 0
(c) x^2 + y^2 + x + 2y + 21 = 0
(d) x^2 + y^2 - x - 2y + 21 = 0

**ANSWER: (a)**
```
  (x - 2)(x + 3) + (y + 3)(y - 5) = 0

  (x^2 + x - 6) + (y^2 - 2y - 15) = 0

  x^2 + y^2 + x - 2y - 21 = 0
```

> **SHORTCUT:** For the diameter form just write the x's together and the
> y's together. There is nothing else to remember.

### Q9
The circle of radius 5 lying in the first quadrant and touching both axes is

(a) x^2 + y^2 - 10x - 10y + 25 = 0
(b) x^2 + y^2 - 10x - 10y + 50 = 0
(c) x^2 + y^2 + 10x + 10y + 25 = 0
(d) x^2 + y^2 - 5x - 5y + 25 = 0

**ANSWER: (a)**
```
  Touching both axes in quadrant I  ->  centre (5, 5) , r = 5

  (x - 5)^2 + (y - 5)^2 = 25

  x^2 + y^2 - 10x - 10y + 25 = 0

  CHECK the rule g^2 = f^2 = c :  25 = 25 = 25   CORRECT
```

### Q10
A circle passes through the origin and makes intercepts a and b on the x-axis
and y-axis. Its equation is

(a) x^2 + y^2 - ax - by = 0
(b) x^2 + y^2 + ax + by = 0
(c) x^2 + y^2 - ax - by + ab = 0
(d) x^2 + y^2 = a^2 + b^2

**ANSWER: (a)**
```
  It passes through (0,0) , (a,0) , (0,b).

  Through the origin  ->  c = 0 , so  x^2 + y^2 + 2gx + 2fy = 0

  Through (a,0) :  a^2 + 2ga = 0  ->  2g = -a
  Through (0,b) :  b^2 + 2fb = 0  ->  2f = -b

  x^2 + y^2 - ax - by = 0
```

### Q11
The circle concentric with x^2 + y^2 - 4x + 6y - 12 = 0 and passing through
(2, 3) is

(a) x^2 + y^2 - 4x + 6y - 23 = 0
(b) x^2 + y^2 - 4x + 6y + 23 = 0
(c) x^2 + y^2 - 4x + 6y - 12 = 0
(d) x^2 + y^2 - 4x + 6y - 36 = 0

**ANSWER: (a)**
```
  "Concentric" = same centre = (2, -3).  Only c changes.

  New radius = distance from (2,-3) to (2,3) = 6

  4 + 9 - c = 36     ->     c = -23
```

> **SHORTCUT:** Concentric circles differ ONLY in the constant c. Keep the
> x and y terms exactly as they are and just solve for c.

# PATTERN 3 — Position of a point, tangent length, power

### Q12
The length of the tangent from (0, 0) to x^2 + y^2 - 2x + 4y + 1 = 0 is

(a) 1 &nbsp;&nbsp; (b) 2 &nbsp;&nbsp; (c) sqrt(5) &nbsp;&nbsp; (d) 3

**ANSWER: (a)**
```
  S1 = 0 + 0 - 0 + 0 + 1 = 1

  Length = sqrt(1) = 1

  CHECK: centre (1,-2), r = sqrt(1 + 4 - 1) = 2, d = sqrt(5)
         sqrt(5 - 4) = 1     CORRECT
```

> **SHORTCUT:** Length of the tangent = sqrt(S1). Just substitute the point.
> Never compute the distance to the centre — that is three times the work.

# PATTERN 4 — Line versus circle

### Q16
The line 3x + 4y = 5 with respect to the circle x^2 + y^2 = 1 is a

(a) secant &nbsp;&nbsp; (b) tangent &nbsp;&nbsp; (c) line that misses it &nbsp;&nbsp; (d) diameter

**ANSWER: (b)**
```
  Centre (0,0) , r = 1

  d = | -5 | / sqrt(9 + 16) = 5/5 = 1 = r    ->    TANGENT
```

### Q17
The length of the chord cut off by x + y = 4 on the circle x^2 + y^2 = 16 is

(a) 4 &nbsp;&nbsp; (b) 4 sqrt(2) &nbsp;&nbsp; (c) 8 &nbsp;&nbsp; (d) 2 sqrt(2)

**ANSWER: (b)**
```
  r = 4

  d = | -4 | / sqrt(2) = 4/sqrt(2) = 2 sqrt(2)   ->   d^2 = 8

  Length = 2 sqrt(16 - 8) = 2 sqrt(8) = 2 x 2 sqrt(2) = 4 sqrt(2)
```

### Q18
The line y = x + c touches x^2 + y^2 = 8 when c =

(a) +/- 2 &nbsp;&nbsp; (b) +/- 4 &nbsp;&nbsp; (c) +/- 8 &nbsp;&nbsp; (d) +/- 16

**ANSWER: (b)**
```
  Condition:  c^2 = a^2 ( 1 + m^2 )

  a^2 = 8 , m = 1

  c^2 = 8 (1 + 1) = 16   ->   c = +/- 4
```

> **SHORTCUT:** For y = mx + c and x^2 + y^2 = a^2, the touching condition
> c^2 = a^2(1 + m^2) is the single most-used one-liner in this chapter's MCQs.

### Q19
The tangents to x^2 + y^2 = 25 which are parallel to 3x - 4y = 0 are

(a) 3x - 4y = +/- 5 &nbsp;&nbsp; (b) 3x - 4y = +/- 15
(c) 3x - 4y = +/- 25 &nbsp;&nbsp; (d) 3x - 4y = +/- 10

**ANSWER: (c)**
```
  Take the tangent as  3x - 4y + k = 0.

  d = |k| / sqrt(9 + 16) = |k| / 5 = r = 5    ->    |k| = 25

  3x - 4y + 25 = 0   and   3x - 4y - 25 = 0
```

### Q20
The line lx + my + n = 0 touches x^2 + y^2 = a^2 if

(a) n^2 = a^2(l^2 + m^2) &nbsp;&nbsp; (b) n = a(l + m)
(c) a^2 = n^2(l^2 + m^2) &nbsp;&nbsp; (d) l^2 + m^2 = a^2

The tangent to x^2 + y^2 = 100 at the point (6, 8) is

**ANSWER: (a)**

The chord of contact of (1, 2) with respect to x^2 + y^2 = 4 is

(a) x + 2y = 4 &nbsp;&nbsp; (b) x + 2y = 2 &nbsp;&nbsp; (c) 2x + y = 4 &nbsp;&nbsp; (d) x + y = 4

**ANSWER: (a)**
```
  S1 = 1 + 4 - 4 = 1 > 0, so the point is outside.  Good.

  Chord of contact  T = 0 :    x(1) + y(2) = 4    ->    x + 2y = 4
```

### Q23
The pole of 2x + 3y = 6 with respect to x^2 + y^2 = 4 is

(a) (4/3, 2) &nbsp;&nbsp; (b) (2, 4/3) &nbsp;&nbsp; (c) (3/2, 1) &nbsp;&nbsp; (d) (-4/3, -2)

**ANSWER: (a)**
```
  Polar of (x1,y1) is   x*x1 + y*y1 = 4.   Compare with 2x + 3y = 6 :

       x1       y1       4        2
      ----  =  ----  =  ---  =  ---
        2        3       6        3

       x1 = 4/3 ,   y1 = 2
```

> **SHORTCUT:** For x^2 + y^2 = a^2, the pole of lx + my + n = 0 is
> ( -a^2 l / n , -a^2 m / n ). Here l=2, m=3, n=-6, a^2=4:
> ( -4(2)/(-6) , -4(3)/(-6) ) = ( 4/3 , 2 ). Same answer in 5 seconds.

### Q24
The polar of (1, 1) with respect to x^2 + y^2 - 4x - 6y + 9 = 0 is

(a) x + 2y - 4 = 0 &nbsp;&nbsp; (b) x - 2y + 4 = 0 &nbsp;&nbsp; (c) 2x + y - 4 = 0 &nbsp;&nbsp; (d) x + 2y + 4 = 0

**ANSWER: (a)**
```
  g = -2 , f = -3 , c = 9 ,  x1 = 1 , y1 = 1

  T = x + y - 2(x + 1) - 3(y + 1) + 9
    = x + y - 2x - 2 - 3y - 3 + 9
    = -x - 2y + 4

  Polar:  -x - 2y + 4 = 0   ->   x + 2y - 4 = 0
```

### Q25
The locus of the point of intersection of two perpendicular tangents to
x^2 + y^2 = 9 is

(a) x^2 + y^2 = 3 &nbsp;&nbsp; (b) x^2 + y^2 = 9 &nbsp;&nbsp; (c) x^2 + y^2 = 18 &nbsp;&nbsp; (d) x^2 + y^2 = 81

**ANSWER: (c)**
```
  The locus is the DIRECTOR CIRCLE:   x^2 + y^2 = 2 a^2

  Here a^2 = 9 , so   x^2 + y^2 = 18
```

> **SHORTCUT:** "Perpendicular tangents" always means the director circle
> x^2 + y^2 = 2a^2 — radius sqrt(2) times bigger, same centre.

The points (1, 3) and (2, k) are conjugate with respect to x^2 + y^2 = 14 if k =

# PATTERN 6 — Chord with a given midpoint

### Q27
The chord of x^2 + y^2 = 25 whose midpoint is (2, 3) is

(a) 2x + 3y = 13 &nbsp;&nbsp; (b) 2x + 3y = 25 &nbsp;&nbsp; (c) 3x + 2y = 13 &nbsp;&nbsp; (d) 2x - 3y = 13

**ANSWER: (a)**
```
  T = S1 :

      2x + 3y - 25  =  4 + 9 - 25  =  -12

      2x + 3y = 13

  CHECK: does (2,3) satisfy it?  4 + 9 = 13   YES
```

### Q28
The midpoint of the chord 2x + y = 5 of the circle x^2 + y^2 = 25 is

(a) (1, 3) &nbsp;&nbsp; (b) (2, 1) &nbsp;&nbsp; (c) (5/2, 0) &nbsp;&nbsp; (d) (0, 5)

**ANSWER: (b)**
```
  The midpoint is the FOOT OF THE PERPENDICULAR from the centre (0,0).

  Perpendicular from the origin to 2x + y = 5 has direction (2, 1),
  so the foot is (2t, t) for some t :

       2(2t) + t = 5   ->   5t = 5   ->   t = 1

  Midpoint = ( 2 , 1 )

  CHECK with T = S1 :  2x + y - 25 = 4 + 1 - 25 = -20  ->  2x + y = 5  CORRECT
```

> **SHORTCUT:** To find the midpoint of a GIVEN chord, drop a perpendicular
> from the centre. To find the chord from a GIVEN midpoint, use T = S1.
> They are the two directions of the same idea.

# PATTERN 7 — Two circles

### Q29
The number of common tangents to x^2 + y^2 = 1 and
x^2 + y^2 - 2x - 6y + 6 = 0 is

(a) 1 &nbsp;&nbsp; (b) 2 &nbsp;&nbsp; (c) 3 &nbsp;&nbsp; (d) 4

**ANSWER: (d)**
```
  CIRCLE 1: centre (0,0) , r1 = 1
  CIRCLE 2: centre (1,3) , r2 = sqrt(1 + 9 - 6) = 2

  d = sqrt(1 + 9) = sqrt(10) = 3.16...

  r1 + r2 = 3        and    3.16 > 3

  d > r1 + r2   ->   the circles are apart   ->   4 common tangents
```

### Q30
The circles x^2 + y^2 = 4 and x^2 + y^2 - 6x + 8 = 0

(a) cut at two points &nbsp; (b) touch externally &nbsp; (c) touch internally &nbsp; (d) do not meet

**ANSWER: (b)**
```
  CIRCLE 1: centre (0,0) , r1 = 2
  CIRCLE 2: centre (3,0) , r2 = sqrt(9 - 8) = 1

  d = 3     and     r1 + r2 = 2 + 1 = 3

  d = r1 + r2   ->   TOUCH EXTERNALLY  (3 common tangents)
```

### Q31
The radical axis (common chord) of x^2 + y^2 = 16 and x^2 + y^2 - 8x = 0 is

(a) x = 2 &nbsp;&nbsp; (b) x = 4 &nbsp;&nbsp; (c) y = 2 &nbsp;&nbsp; (d) x = 8

**ANSWER: (a)**
```
  S - S' = 0 :

     ( x^2 + y^2 - 16 )  -  ( x^2 + y^2 - 8x )  =  0

              -16 + 8x = 0    ->    x = 2
```

### Q32
The length of the common chord in Q31 is

(a) 2 sqrt(3) &nbsp;&nbsp; (b) 4 sqrt(3) &nbsp;&nbsp; (c) 8 &nbsp;&nbsp; (d) 4

**ANSWER: (b)**
```
  Use circle 1: centre (0,0), r = 4.

  Length = 2 sqrt(16 - 4) = 2 sqrt(12) = 2 x 2 sqrt(3) = 4 sqrt(3)
```

### Q33
The circles x^2 + y^2 = 9 and x^2 + y^2 - 10x + 9 = 0 intersect at an angle of

(a) 30 degrees &nbsp;&nbsp; (b) 45 degrees &nbsp;&nbsp; (c) 60 degrees &nbsp;&nbsp; (d) 90 degrees

**ANSWER: (d)**
```
  CIRCLE 1: centre (0,0) , r1 = 3 ,   g1 = 0 , f1 = 0 , c1 = -9
  CIRCLE 2: centre (5,0) , r2 = sqrt(25 - 9) = 4 ,  g2 = -5, f2 = 0, c2 = 9

  ORTHOGONALITY TEST:
       2 g1 g2 + 2 f1 f2 = 0        c1 + c2 = -9 + 9 = 0     EQUAL

  Or geometrically:  d = 5 ,  d^2 = 25 = 9 + 16 = r1^2 + r2^2

  ->  the circles cut at 90 degrees (ORTHOGONAL).
```

### Q34
The circles x^2 + y^2 + 2ax + c = 0 and x^2 + y^2 + 2by + c = 0 cut
orthogonally if

(a) c = 0 &nbsp;&nbsp; (b) a = b &nbsp;&nbsp; (c) a^2 + b^2 = c &nbsp;&nbsp; (d) ab = c

**ANSWER: (a)**
```
  g1 = a , f1 = 0 , c1 = c
  g2 = 0 , f2 = b , c2 = c

  2 g1 g2 + 2 f1 f2  =  2(a)(0) + 2(0)(b)  =  0

  c1 + c2 = 2c

  Orthogonal  ->   0 = 2c   ->   c = 0
```

# PATTERN 8 — Parametric form and small mixed questions

### Q35
The point on x^2 + y^2 = 16 whose parameter is theta = 45 degrees is

(a) (2 sqrt(2), 2 sqrt(2)) &nbsp;&nbsp; (b) (4, 4) &nbsp;&nbsp; (c) (2, 2) &nbsp;&nbsp; (d) (8, 8)

**ANSWER: (a)**
```
  x = 4 cos 45 = 4 / sqrt(2) = 2 sqrt(2)
  y = 4 sin 45 = 4 / sqrt(2) = 2 sqrt(2)

  CHECK: 8 + 8 = 16    CORRECT
```

### Q36
If (2, k) lies on x^2 + y^2 - 4x - 6y + 9 = 0, then k =

(a) 1 or 5 &nbsp;&nbsp; (b) 2 or 4 &nbsp;&nbsp; (c) 3 only &nbsp;&nbsp; (d) 0 or 6

**ANSWER: (a)**
```
  4 + k^2 - 8 - 6k + 9 = 0

       k^2 - 6k + 5 = 0

       (k - 1)(k - 5) = 0

       k = 1  or  k = 5
```

### Q37
The length of the intercept made by x^2 + y^2 - 8x - 6y + 9 = 0 on the x-axis is

(a) 3 &nbsp;&nbsp; (b) 5 &nbsp;&nbsp; (c) 2 sqrt(7) &nbsp;&nbsp; (d) 8

**ANSWER: (c)**
```
  x-intercept  =  2 sqrt( g^2 - c )

  g = -4 , c = 9

  = 2 sqrt(16 - 9) = 2 sqrt(7)
```

### Q38
The equation of the normal to x^2 + y^2 = 25 at the point (3, 4) is

(a) 4x - 3y = 0 &nbsp;&nbsp; (b) 3x + 4y = 25 &nbsp;&nbsp; (c) 3x - 4y = 0 &nbsp;&nbsp; (d) 4x + 3y = 0

**ANSWER: (a)**
```
  The normal passes through the CENTRE (0,0) and the point (3,4).

  Its equation is  y1 * x - x1 * y = 0  ->  4x - 3y = 0

  CHECK: (0,0) gives 0, and (3,4) gives 12 - 12 = 0     CORRECT
```

> **SHORTCUT:** Any normal to a circle passes through the centre.
> In an MCQ, just test which option is satisfied by the centre. Usually
> that alone kills three of the four options.

```
  +-----------------------------------+------------------------------------+
  |  IF YOU SEE THIS ...              |  DO THIS IMMEDIATELY               |
  +-----------------------------------+------------------------------------+
  |  a number in front of x^2         |  DIVIDE the whole equation by it   |
  |                                   |  before touching anything else     |
  +-----------------------------------+------------------------------------+
  |  "centre" asked                   |  (-half x-coeff , -half y-coeff)   |
  +-----------------------------------+------------------------------------+
  |  "radius" asked                   |  sqrt(g^2 + f^2 - c) - keep the    |
  |                                   |  sign of c                         |
  +-----------------------------------+------------------------------------+
  |  "length of the tangent"          |  sqrt(S1) - just substitute        |
  +-----------------------------------+------------------------------------+
  |  "inside / outside / on"          |  sign of S1: minus = inside        |
  +-----------------------------------+------------------------------------+
  |  "touches the x-axis"             |  g^2 = c    (y-axis: f^2 = c)      |
  +-----------------------------------+------------------------------------+
  |  "passes through the origin"      |  c = 0                             |
  +-----------------------------------+------------------------------------+
  |  "ends of a diameter"             |  (x-x1)(x-x2) + (y-y1)(y-y2) = 0   |
  +-----------------------------------+------------------------------------+
  |  "concentric"                     |  keep g and f, change only c       |
  +-----------------------------------+------------------------------------+
  |  y = mx + c and "touches"         |  c^2 = a^2 (1 + m^2)               |
  +-----------------------------------+------------------------------------+
  |  a line and "length of the chord" |  2 sqrt(r^2 - d^2)                 |
  +-----------------------------------+------------------------------------+
  |  "midpoint of the chord" given    |  T = S1                            |
  +-----------------------------------+------------------------------------+
  |  "midpoint" ASKED for a line      |  foot of perpendicular from centre |
  +-----------------------------------+------------------------------------+
  |  "chord of contact" or "polar"    |  T = 0  (same formula, both times) |
  +-----------------------------------+------------------------------------+
  |  "perpendicular tangents"         |  director circle x^2 + y^2 = 2a^2  |
  +-----------------------------------+------------------------------------+
  |  "normal" in the options          |  the centre must satisfy it -      |
  |                                   |  test the centre, not the point    |
  +-----------------------------------+------------------------------------+
  |  "orthogonally"                   |  2g1g2 + 2f1f2 = c1 + c2           |

  |  "common chord" / "radical axis"  |  subtract:  S - S' = 0             |

  |  Stuck, and it's EAPCET           |  GUESS - there is no negative      |

```

# THE OPTION-TESTING TRICK

Many circle MCQs give you four candidate EQUATIONS. Do not derive anything —
**test** instead:

```
  STEP 1   Read off the centre of each option in 2 seconds
           ( -half x-coeff , -half y-coeff ).
  STEP 2   If the question gives a point on the circle, substitute it.
           Only one option will give 0.
  STEP 3   If the question gives a radius, check g^2 + f^2 - c.
```

One substitution usually eliminates three options. This turns a 3-minute
derivation into a 20-second check — and it is impossible to make a sign error,
because you never rearrange anything.
