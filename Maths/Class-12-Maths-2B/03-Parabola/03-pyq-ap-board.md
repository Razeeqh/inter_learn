## Topic: Reading a standard form

### Q A1
Find the vertex and focus of the parabola `y^2 = 16x`.

**ANSWER:**
```
  y is squared, sign is +   ->  form y^2 = 4ax, opens RIGHT
  4a = 16   ->   a = 4

  VERTEX = ( 0 , 0 )        FOCUS = ( a , 0 ) = ( 4 , 0 )
```
**Vertex (0, 0), Focus (4, 0)**

---

### Q A2
Find the coordinates of the focus and the equation of the directrix of `x^2 = -4y`.

**ANSWER:**
```
  x is squared, sign is -   ->  form x^2 = -4ay, opens DOWN
  4a = 4   ->   a = 1

  FOCUS = ( 0 , -a ) = ( 0 , -1 )
  DIRECTRIX :  y = a   =>   y = 1
```
**Focus (0, -1), Directrix y = 1**

### Q A3
Find the length of the latus rectum of `3y^2 = 8x`.

**ANSWER:**
```
  DIVIDE BY 3 FIRST:      y^2 = ( 8 / 3 ) x

  4a = 8/3   ->   a = 2/3

  LATUS RECTUM = 4a = 8/3
```
**8/3**

  VERTEX = ( 1 , 0 )      AXIS :  y = 0      LATUS RECTUM = 8
  (opens LEFT, focus at ( 1 - 2 , 0 ) = ( -1 , 0 ) )
```
**Vertex (1, 0), axis y = 0, latus rectum 8**

### Q A5
Find the ends of the latus rectum of `y^2 = 24x` and its length.

**ANSWER:**
```

**Ends (6, 12) and (6, -12); length 24**

## Topic: Classifying a conic

### Q A24
Show that `9x^2 - 12xy + 4y^2 + 68x - 54y + 153 = 0` represents a parabola.

**ANSWER:**
```
  Compare with a x^2 + 2h xy + b y^2 + 2g x + 2f y + c = 0 :

     a = 9 ,  h = -6 ,  b = 4 ,  g = 34 ,  f = -27 ,  c = 153

  (i)  h^2 - a b  =  36 - 36  =  0

  (ii) Delta = abc + 2fgh - af^2 - bg^2 - ch^2
             = 5508 + 11016 - 6561 - 4624 - 5508
             = -169   !=  0

  h^2 = ab  AND  Delta != 0    ->    it is a PARABOLA.
```
**It is a parabola** *(in fact the one with focus (-2, 3) and directrix 2x + 3y - 4 = 0)*

Find the vertex, focus, directrix, axis and latus rectum of

### Q B9
Find the pair of tangents drawn from `(-1, 2)` to `y^2 = 4x`, and show that they
are perpendicular.

**ANSWER:**
```
  a = 1.
  S  = y^2 - 4x
  S1 = 4 - 4(-1) = 8            ( > 0 , so two real tangents exist )
  T  = y(2) - 2( x - 1 ) = 2y - 2x + 2 = 2( y - x + 1 )

  S S1 = T^2 :
        8 ( y^2 - 4x ) = 4 ( y - x + 1 )^2
        2 ( y^2 - 4x ) = y^2 + x^2 + 1 - 2xy + 2y - 2x

        x^2 - 2xy - y^2 + 6x + 2y + 1 = 0

  PERPENDICULAR?  For a pair of lines a x^2 + 2h xy + b y^2 + ... = 0 the
  lines are perpendicular when a + b = 0.
        a + b = 1 + ( -1 ) = 0   ✓  PERPENDICULAR
```
*Reason: (-1, 2) lies on the directrix x = -1, and perpendicular tangents to a
parabola always meet on the directrix.*

### Q B11
Prove that the tangents at the ends of a focal chord of `y^2 = 4ax` intersect at
right angles on the directrix.

**ANSWER:**
```
  Tangent at t :   t y = x + a t^2

  Solving the tangents at t1 and t2:
       ( t1 - t2 ) y = a ( t1^2 - t2^2 )   ->   y = a ( t1 + t2 )
       x = t1 y - a t1^2 = a t1 t2

  So they meet at   P = ( a t1 t2 , a ( t1 + t2 ) ).

  For a FOCAL chord,  t1 t2 = -1 :

       x-coordinate of P  =  a ( -1 )  =  -a       ->   P LIES ON x = -a,
                                                        THE DIRECTRIX.

  Slopes of the two tangents are 1/t1 and 1/t2 , so

       product = 1 / ( t1 t2 ) = 1 / ( -1 ) = -1   ->   PERPENDICULAR.
```

### Q B12
Show that the normal at the point `t1` on `y^2 = 4ax` meets the curve again at
the point `t2 = -t1 - 2/t1`. Hence find where the normal at `(1, 2)` on `y^2 = 4x`
meets the curve again.

**ANSWER:**
```
  Normal at t1 :        y + t1 x = 2 a t1 + a t1^3        SLOPE = - t1
  Chord t1 t2  :   ( t1 + t2 ) y = 2 x + 2 a t1 t2        SLOPE = 2/( t1 + t2 )

  Same line  =>  same slope:
                     2 / ( t1 + t2 )  =  - t1
                     2  =  - t1 ( t1 + t2 )
                     t1 + t2  =  - 2 / t1

                     t2  =  - t1  -  2 / t1

  APPLICATION:  y^2 = 4x  ->  a = 1.  Point (1, 2)  ->  t1 = y1/(2a) = 1.
                     t2 = -1 - 2 = -3
                     Point = ( a t2^2 , 2 a t2 ) = ( 9 , -6 )
```
*Check: the normal at (1,2) is x + y - 3 = 0. At (9, -6): 9 - 6 - 3 = 0 ✓
and (-6)^2 = 36 = 4(9) ✓*

### Q B13
Find the length of the focal chord of `y^2 = 4ax` that makes an angle of
60 degrees with the axis. What is the shortest possible focal chord?

**ANSWER:**
```
  LENGTH = 4a cosec^2 ( theta )

         = 4a / sin^2 60 = 4a / ( 3/4 ) = 16a / 3

  SHORTEST: cosec^2(theta) is smallest when theta = 90 degrees, giving 1.
            So the shortest focal chord is 4a  =  the LATUS RECTUM.
```
*Cross-check with the t-form: the chord slope is 2/(t - 1/t) = tan(theta),
so t - 1/t = 2cot(theta) and (t + 1/t)^2 = 4cot^2 + 4 = 4cosec^2. At 60 degrees
this is 16/3, giving length a(16/3) = 16a/3 ✓*

### Q B14
Find the locus of the midpoints of the focal chords of `y^2 = 4ax`.

**ANSWER:**
```
  Let the midpoint be ( x1 , y1 ). Its chord is  T = S1 :

        y y1 - 2a ( x + x1 )  =  y1^2 - 4 a x1

  It is a FOCAL chord, so it passes through S( a , 0 ). Put x = a , y = 0 :

        0 - 2a ( a + x1 )  =  y1^2 - 4 a x1
        -2a^2 - 2a x1      =  y1^2 - 4 a x1
        y1^2               =  2 a x1  -  2 a^2

  LOCUS :     y^2  =  2 a ( x - a )
```
*Check: this is itself a parabola with vertex (a, 0) = the focus, and
4a' = 2a, so its latus rectum is half that of the original. Sensible.*

### Q B15
Show that the foot of the perpendicular from the focus to any tangent of
`y^2 = 4ax` lies on the tangent at the vertex.

**ANSWER:**
```
  Tangent at t :        t y = x + a t^2     ->   x - t y + a t^2 = 0
  Its slope is 1/t , so the perpendicular from S( a, 0 ) has slope  -t :

        y = - t ( x - a )

  SUBSTITUTE into the tangent:

        x - t [ - t ( x - a ) ] + a t^2 = 0
        x + t^2 ( x - a ) + a t^2 = 0
        x + t^2 x - a t^2 + a t^2 = 0
        x ( 1 + t^2 ) = 0
        x = 0

  So the foot lies on the line x = 0, which is the TANGENT AT THE VERTEX.
```

### Q C1
**Derive the equation of a parabola in the standard form `y^2 = 4ax`.**

**ANSWER (full model answer):**

```
  MARK SPLIT:  set-up and figure 2  |  distance expressions 2  |
               algebra 2  |  conclusion + properties 1
```

**Step 1 — Definition.** A parabola is the locus of a point `P` which moves so
that its distance from a fixed point `S` (the focus) equals its perpendicular
distance from a fixed line (the directrix). That is, the eccentricity `e = 1`.

**Step 2 — Choice of axes.** Drop a perpendicular from `S` to the directrix,
meeting it at `Z`. Let `A` be the midpoint of `SZ`. Since `AS = AZ`, the point
`A` satisfies the definition, so `A` lies on the parabola — it is the **vertex**.

Take `A` as the origin, the line `ZAS` as the x-axis, and the perpendicular to it
at `A` as the y-axis. Let `AS = a > 0`.

```
              y
              ^                 directrix  x + a = 0
              |          |
              |  M ------|--------------------------- P(x, y)
              |          |
      --------+----Z-----A---------S----------------> x
              |  (-a,0) (0,0)    (a,0)
              |          |
                     <-a-><-a->
```

Then `S = (a, 0)`, `Z = (-a, 0)`, and the directrix is `x + a = 0`.

**Step 3 — Write both distances.** Let `P(x, y)` be any point on the parabola and
`M` the foot of the perpendicular from `P` to the directrix.

```
   SP = sqrt( ( x - a )^2 + ( y - 0 )^2 )

              | x + a |
   PM  =  --------------  =  | x + a |
            sqrt( 1^2 )
```

**Step 4 — Apply the definition and simplify.**

```
   SP = PM        ->        SP^2 = PM^2

   ( x - a )^2 + y^2  =  ( x + a )^2

   x^2 - 2ax + a^2 + y^2  =  x^2 + 2ax + a^2

                     y^2  =  4 a x
```

**Step 5 — Conclusion and properties.**

```
  +--------------------------------------------------------------------------+
  |                          y^2  =  4 a x                                   |
  +--------------------------------------------------------------------------+

  (i)   y^2 >= 0 and a > 0, so x >= 0 : the curve lies entirely to the right
        of the y-axis, i.e. it OPENS RIGHT.
  (ii)  Replacing y by -y leaves the equation unchanged, so the curve is
        SYMMETRIC about the x-axis; the x-axis is its AXIS.
  (iii) It meets the axis only at (0,0), the VERTEX.
  (iv)  Putting x = a gives y = ± 2a, so the LATUS RECTUM has ends
        (a, 2a), (a, -2a) and LENGTH 4a.
```

### Q C2
**Find the vertex, focus, the equations of the directrix and the axis, the length
of the latus rectum and the ends of the latus rectum of the parabola
`y^2 - x + 4y + 5 = 0`.**

**ANSWER:**

```
  MARK SPLIT:  completing the square 2  |  vertex + focus 2  |
               directrix + axis 2  |  latus rectum & ends 1
```

**Step 1 — Complete the square in y.**

```
        y^2 + 4y            =  x - 5
        y^2 + 4y + 4        =  x - 5 + 4
        ( y + 2 )^2         =  x - 1
                            =  1 ( x - 1 )
```

**Step 2 — Identify the form.**

```
   Compare with ( y - k )^2 = 4a ( x - h ) :

        h = 1 ,   k = -2 ,   4a = 1   ->   a = 1/4 ,   OPENS RIGHT
```

**Step 3 — Read off every element.**

| Element | Formula | Value |
|---|---|---|
| Vertex | (h, k) | **(1, -2)** |
| Focus | (h + a, k) | **(5/4, -2)** |
| Directrix | x = h - a | **x = 3/4** |
| Axis | y = k | **y = -2** |
| Latus rectum | 4a | **1** |

**Step 4 — Ends of the latus rectum.** The latus rectum is the line `x = 5/4`.

```
        ( y + 2 )^2 = 5/4 - 1 = 1/4      ->     y + 2 = ± 1/2

        y = -3/2   or   y = -5/2

   ENDS  =  ( 5/4 , -3/2 )  and  ( 5/4 , -5/2 )
   ( their separation is 1 = 4a  ✓ )
```

**Step 5 — Sketch.**

```
              y
              ^        directrix x = 3/4
              |            |
              |            |        *
              |            |     *
              |            |  *
     ---------+------------|-V(1,-2)---.S(5/4,-2)------------- y = -2 (axis)
              |            |  *
              |            |     *
              |            |        *
              |            |
              +-------------------------------------> x
```

*Check by the definition: the vertex (1,-2) is 1/4 from the focus and 1/4 from
the directrix ✓. Also put y = 0 in the original: -x + 5 = 0 gives x = 5, so
(5, 0) is on the curve; its distance to the focus is
sqrt((5 - 5/4)^2 + 4) = sqrt(225/16 + 64/16) = sqrt(289/16) = 17/4,
and its distance to x = 3/4 is 5 - 3/4 = 17/4 ✓*

### Q C3
**Prove that the line `y = mx + c` touches the parabola `y^2 = 4ax` if and only if
`c = a/m`, and find the point of contact. Hence find the tangent to `y^2 = 16x`
which makes an angle of 45 degrees with the axis.**

**ANSWER:**

```
  MARK SPLIT:  substitution 1  |  discriminant work 3  |
               point of contact 2  |  application 1
```

**Step 1 — Substitute.**

```
   Put  y = m x + c  into  y^2 = 4 a x :

        ( m x + c )^2 = 4 a x

        m^2 x^2 + 2 m c x + c^2 = 4 a x

        m^2 x^2 + ( 2 m c - 4 a ) x + c^2 = 0        ... (*)
```

**Step 2 — Tangency means equal roots.** A tangent meets the curve in two
coincident points, so the discriminant of (*) must be zero.

```
        ( 2 m c - 4 a )^2  -  4 m^2 c^2  =  0

        4 m^2 c^2 - 16 a m c + 16 a^2 - 4 m^2 c^2 = 0

                  - 16 a m c + 16 a^2 = 0

                          a m c = a^2

                            m c = a          ->      c  =  a / m
```

**Step 3 — Point of contact.** With `c = a/m`, equation (*) becomes

```
        m^2 x^2 - 2 a x + a^2 / m^2 = 0

        ( m x - a/m )^2 = 0        ->     x = a / m^2

        y = m ( a/m^2 ) + a/m = a/m + a/m = 2a / m

  +--------------------------------------------------------------------------+
  |      TANGENT   y = m x + a/m       CONTACT   ( a / m^2 ,  2a / m )       |
  +--------------------------------------------------------------------------+
```
*Verification that the contact point is on the curve:
`(2a/m)^2 = 4a^2/m^2 = 4a (a/m^2)` ✓*

**Step 4 — Application.** For `y^2 = 16x`, `4a = 16`, so `a = 4`. A 45-degree
angle with the axis means `m = tan 45 = 1`.

```
        y = (1) x + 4/1  =  x + 4          ->     x - y + 4 = 0

        Contact = ( a/m^2 , 2a/m ) = ( 4 , 8 )
```
*Check: `8^2 = 64 = 16(4)` ✓ and `4 - 8 + 4 = 0` ✓*

### Q C4
**Show that the common tangents to the circle `x^2 + y^2 = 2a^2` and the parabola
`y^2 = 8ax` are `y = ± ( x + 2a )`.**

**ANSWER:**

```
  MARK SPLIT:  tangent to the parabola 2  |  distance condition 2  |
               solving for m 2  |  writing both tangents 1
```

**Step 1 — A general tangent to the parabola.** For `y^2 = 8ax` we have
`4A = 8a`, so `A = 2a`. Every tangent of slope `m` is

```
        y = m x + A/m  =  m x + 2a/m
   i.e.  m x - y + 2a/m = 0
```

**Step 2 — It must also touch the circle.** The circle has centre `(0,0)` and
radius `sqrt(2) a`. For tangency the perpendicular distance from the centre to
the line equals the radius:

```
        | 2a / m |
      ---------------  =  sqrt(2) * a
       sqrt( m^2 + 1 )
```

**Step 3 — Square and solve.**

```
        4 a^2 / m^2  =  2 a^2 ( m^2 + 1 )

        4 / m^2      =  2 m^2 + 2

        4            =  2 m^4 + 2 m^2

        m^4 + m^2 - 2 = 0

        ( m^2 + 2 )( m^2 - 1 ) = 0

   m^2 = -2 is impossible for a real slope, so   m^2 = 1  ->  m = ± 1.
```

**Step 4 — Write the tangents.**

```
   m =  1 :   y =  x + 2a/1  =  x + 2a
   m = -1 :   y = -x + 2a/(-1) = -x - 2a  =  -( x + 2a )

  +--------------------------------------------------------------------------+
  |                    y  =  ±  ( x  +  2 a )                                |
  +--------------------------------------------------------------------------+
```

*Check for m = 1: distance from origin to `x - y + 2a = 0` is
`|2a| / sqrt(2) = sqrt(2) a` = radius ✓; and the contact point on the parabola is
`(A/m^2, 2A/m) = (2a, 4a)`, which satisfies `y^2 = 16a^2 = 8a(2a)` ✓*

### Q C5
**Prove that the normal chord drawn at the point of the parabola `y^2 = 4ax`
whose ordinate equals its abscissa subtends a right angle at the focus.**

**ANSWER:**

```
  MARK SPLIT:  finding the point 2  |  finding the second point 2  |
               slopes / dot product 2  |  conclusion 1
```

**Step 1 — Find the point where the ordinate equals the abscissa.**

```
   Let the point be P( a t^2 , 2 a t ). Ordinate = abscissa:

        2 a t  =  a t^2      ->     a t ( t - 2 ) = 0    ->    t = 0 or t = 2

   t = 0 gives the vertex (0,0), which is the trivial case, so

        t1 = 2      ->      P = ( 4a , 4a )
```

**Step 2 — Where does the normal at P meet the curve again?**

```
        t2  =  - t1 - 2 / t1  =  - 2 - 1  =  -3

        Q = ( a t2^2 , 2 a t2 ) = ( 9a , -6a )
```

**Step 3 — Vectors from the focus `S(a, 0)`.**

```
        S P  =  ( 4a - a , 4a - 0 )   =  ( 3a ,  4a )
        S Q  =  ( 9a - a , -6a - 0 )  =  ( 8a , -6a )
```

**Step 4 — Show the angle is 90 degrees.**

```
   DOT PRODUCT:   ( 3a )( 8a ) + ( 4a )( -6a )  =  24 a^2 - 24 a^2  =  0

   (or by slopes:  slope SP = 4a/3a = 4/3 ,  slope SQ = -6a/8a = -3/4 ,
                   product = -1 )

   Hence  angle P S Q = 90 degrees.        THE NORMAL CHORD SUBTENDS A
                                            RIGHT ANGLE AT THE FOCUS.  QED
```

*Extra check: SP = sqrt(9a^2 + 16a^2) = 5a, and by the focal-distance formula
SP = x1 + a = 4a + a = 5a ✓. SQ = sqrt(64a^2 + 36a^2) = 10a, and
x2 + a = 9a + a = 10a ✓.*

### Q C6
**From an external point `P` two tangents are drawn to the parabola `y^2 = 4ax`,
making angles `theta1` and `theta2` with its axis. If
`tan(theta1) + tan(theta2)` is a constant `b`, show that `P` lies on the line
`y = b x`.**

**ANSWER:**

```
  MARK SPLIT:  general tangent through P 2  |  forming the quadratic 2  |
               sum of roots 2  |  conclusion 1
```

**Step 1 — Let `P = (x1, y1)`.** Every tangent to `y^2 = 4ax` of slope `m` is

```
        y = m x + a / m
```

**Step 2 — It passes through P.**

```
        y1 = m x1 + a / m

   MULTIPLY BY m :        m y1 = m^2 x1 + a

  +--------------------------------------------------------------------------+
  |          x1 m^2  -  y1 m  +  a  =  0                                     |
  +--------------------------------------------------------------------------+
```

This is a **quadratic in m**, so there are two tangent slopes `m1` and `m2` —
exactly the two tangents from `P`. Their slopes are `tan(theta1)` and
`tan(theta2)`, because the axis is the x-axis.

**Step 3 — Sum of the roots.**

```
                                 -( - y1 )        y1
        m1 + m2  =  tan th1 + tan th2  =  -----------  =  ----
                                              x1           x1
```

**Step 4 — Apply the given condition.**

```
        y1 / x1  =  b        ->       y1  =  b x1

   So the point P( x1 , y1 ) satisfies   y = b x .

   Hence P lies on the straight line  y = b x.       QED
```

*(Companion results from the same quadratic, often asked as riders:
`m1 m2 = a / x1`, so if the tangents are perpendicular then `m1 m2 = -1` gives
`x1 = -a` — the point lies on the **directrix**. And if
`tan th1 · tan th2 = c` is constant, `P` lies on the line `x = a/c`.)*

### Q C7
**Show that the area of the triangle formed by the tangents at three points of the
parabola `y^2 = 4ax` is half the area of the triangle formed by the three points
themselves.**

**ANSWER:**

```
  MARK SPLIT:  inscribed triangle area 3  |  tangent triangle vertices 2  |
               tangent triangle area 1  |  ratio 1
```

**Step 1 — The three points.** Take `P(t1)`, `P(t2)`, `P(t3)` where
`P(t) = (a t^2, 2 a t)`.

```
   Area of the INSCRIBED triangle

     = (1/2) | x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2) |

     = (1/2) | a t1^2 (2a t2 - 2a t3) + a t2^2 (2a t3 - 2a t1)
                                       + a t3^2 (2a t1 - 2a t2) |

     = a^2 | t1^2 (t2 - t3) + t2^2 (t3 - t1) + t3^2 (t1 - t2) |

     = a^2 | ( t1 - t2 )( t2 - t3 )( t3 - t1 ) |            ... (I)
```

**Step 2 — Vertices of the tangent triangle.** The tangents at `ti` and `tj` meet at
`( a ti tj , a ( ti + tj ) )`. So the three vertices are

```
        A = ( a t1 t2 , a ( t1 + t2 ) )
        B = ( a t2 t3 , a ( t2 + t3 ) )
        C = ( a t3 t1 , a ( t3 + t1 ) )
```

**Step 3 — Its area.**

```
   Area = (1/2) | a t1t2 [ a(t2+t3) - a(t3+t1) ]
                + a t2t3 [ a(t3+t1) - a(t1+t2) ]
                + a t3t1 [ a(t1+t2) - a(t2+t3) ] |

        = (a^2/2) | t1t2 ( t2 - t1 ) + t2t3 ( t3 - t2 ) + t3t1 ( t1 - t3 ) |

        = (a^2/2) | ( t1 - t2 )( t2 - t3 )( t3 - t1 ) |         ... (II)
```

**Step 4 — Compare.**

```
        (II)          ( a^2 / 2 ) | ... |          1
       ------   =   ---------------------   =   -----
        (I)            a^2 | ... |               2

  +--------------------------------------------------------------------------+
  |   AREA OF THE TANGENT TRIANGLE  =  HALF the AREA OF THE INSCRIBED        |
  |   TRIANGLE.                                                              |
  +--------------------------------------------------------------------------+
```

*Numerical check with `a = 1`, `t1 = 0, t2 = 1, t3 = 2`:
points `(0,0), (1,2), (4,4)`; inscribed area `= (1/2)|0(2-4) + 1(4-0) + 4(0-2)|
= (1/2)|4 - 8| = 2`. Formula (I): `|(0-1)(1-2)(2-0)| = 2` ✓.
Tangent-triangle vertices `(0,1), (2,3), (0,2)`; area
`= (1/2)|0(3-2) + 2(2-1) + 0(1-3)| = 1`. Formula (II): `(1/2)(2) = 1` ✓.
Ratio 1 : 2 ✓*
