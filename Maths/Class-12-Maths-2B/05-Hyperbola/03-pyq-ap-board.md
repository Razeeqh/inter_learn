## Topic: reading a standard form

### Q A1
Find the eccentricity of the hyperbola `9x^2 - 16y^2 = 144`.

**ANSWER:**
```
  Divide by 144:      x^2/16  -  y^2/9  =  1

  The PLUS sign is on x^2 , so  a^2 = 16 -> a = 4 ,  b^2 = 9 -> b = 3

  a e = sqrt( a^2 + b^2 ) = sqrt( 16 + 9 ) = sqrt 25 = 5

              a e       5
        e  =  -----  =  ---
               a        4
```
**e = 5/4** (greater than 1, as it must be)

---

### Q A2
Find the eccentricity of `16y^2 - 9x^2 = 144`.

**ANSWER:**
```
  Divide by 144:      y^2/9  -  x^2/16  =  1

  The PLUS sign is on y^2 , so the TRANSVERSE AXIS IS THE y-AXIS.
        a^2 = 9 -> a = 3      b^2 = 16 -> b = 4      ( b > a is fine! )

  a e = sqrt( 9 + 16 ) = 5      ->      e = 5/3
```
**e = 5/3**

> Do NOT choose `a^2` as the bigger number. That habit belongs to the ellipse.

### Q A3
Find the eccentricity of `x^2 - 4y^2 = 4`.

**ANSWER:**
```
  Divide by 4:        x^2/4  -  y^2/1  =  1

  a^2 = 4 -> a = 2 ,  b^2 = 1

  a e = sqrt( 4 + 1 ) = sqrt 5     ->     e = sqrt5 / 2  =  1.118
```
**e = sqrt(5)/2**

### Q A10
If the latus rectum of a hyperbola equals half its transverse axis, find `e`.

**ANSWER:**
```
        2 b^2 / a  =  (1/2)( 2 a )  =  a

              2 b^2 = a^2

        b^2 = a^2 ( e^2 - 1 )   ->   2 a^2 ( e^2 - 1 ) = a^2

              e^2 - 1 = 1/2    ->    e^2 = 3/2    ->    e = sqrt(3/2) = sqrt6 / 2
```
**e = sqrt(6)/2 ≈ 1.22** (greater than 1 — **TICK**)

### Q A11

```
       ----  +  ----  =  1

        1                 16        9
       ----  =  1  -     ----  =   ----
       e2^2               25        25

              e2^2 = 25/9      ->      e2 = 5/3
```
**e2 = 5/3**

### Q A12
If `e1` and `e2` are the eccentricities of a hyperbola and its conjugate, prove that
`1/e1^2 + 1/e2^2 = 1`.

**ANSWER:**
```
  For  x^2/a^2 - y^2/b^2 = 1 :   e1^2 = ( a^2 + b^2 ) / a^2
  For  y^2/b^2 - x^2/a^2 = 1 :   e2^2 = ( a^2 + b^2 ) / b^2

        1        1          a^2            b^2         a^2 + b^2
       ----  +  ----  =  ---------  +  ---------  =  -----------  =  1
       e1^2     e2^2      a^2+b^2       a^2+b^2       a^2 + b^2
```
**Proved.**

### Q A16
Find the equation of the hyperbola whose asymptotes are `3x ± 5y = 0` and which passes
through `(1, -1)`.

**ANSWER:**
```
  Asymptote pair :  ( 3x - 5y )( 3x + 5y ) = 0  ->  9x^2 - 25y^2 = 0

  A hyperbola with those asymptotes differs only by a CONSTANT :

        9 x^2 - 25 y^2 = k

  Through ( 1 , -1 ) :   9 ( 1 ) - 25 ( 1 ) = -16 = k
```
**9x² - 25y² = -16, i.e. 25y² - 9x² = 16**

### Q B4
Find the equation of the hyperbola whose foci are `(0, ±10)` and which passes through
`(2, 3)`.

**ANSWER:**
```

              y^2                  x^2
```

**y²/8.62 - x²/91.38 = 1 (approximately); exactly `A = (113 - sqrt 9169)/2`**

### Q B5
Prove that the difference of the focal distances of any point on the hyperbola
`x^2/a^2 - y^2/b^2 = 1` is constant.

**ANSWER:**
```
  Let P ( x1 , y1 ) be on the RIGHT branch, so x1 >= a .

  The foci and their directrices are
        S  ( ae , 0 )   with   x =  a/e
        S' ( -ae , 0 )  with   x = -a/e

  By the definition of a conic ( SP = e * PM ) :

        S P  = e ( x1 - a/e )  =  e x1  -  a
        S' P = e ( x1 + a/e )  =  e x1  +  a

  Subtract :

        S' P  -  S P  =  ( e x1 + a ) - ( e x1 - a )  =  2 a

  This does not depend on ( x1 , y1 ) , so the DIFFERENCE of the focal
  distances is constant and equals the length of the TRANSVERSE AXIS.
                                                                    QED
```

### Q B7
Find the equations of the asymptotes of `3x^2 - 5xy - 2y^2 + 5x + 11y - 8 = 0`.

**ANSWER:**
```
  Asymptote pair is  S + L = 0 , i.e. the same equation with constant -8 + L .

  a = 3 , h = -5/2 , b = -2 , g = 5/2 , f = 11/2 , c = -8 + L

  Delta = abc + 2fgh - af^2 - bg^2 - ch^2 = 0

        3(-2)(-8+L) + 2(11/2)(5/2)(-5/2) - 3(121/4) - (-2)(25/4) - (-8+L)(25/4) = 0

        ( 48 - 6L ) - 275/4 - 363/4 + 50/4 + 200/4 - 25L/4 = 0

  Multiply by 4 :

        192 - 24L - 275 - 363 + 50 + 200 - 25L = 0
                        -196 - 49 L = 0
                                 L  = -4

  Asymptote pair :   3x^2 - 5xy - 2y^2 + 5x + 11y - 12 = 0
```

### Q B14
Prove that the product of the perpendicular distances from the two foci to any tangent
of `x^2/a^2 - y^2/b^2 = 1` is `b^2`.

**ANSWER:**
```
  A tangent is  y = m x + c  with  c^2 = a^2 m^2 - b^2 , i.e. m x - y + c = 0 .

  Foci  S ( ae , 0 ) and S' ( -ae , 0 ) .

        p1 = | m ( ae ) + c |  / sqrt( m^2 + 1 )
        p2 = | m ( -ae ) + c | / sqrt( m^2 + 1 )

        p1 p2 = | c^2 - a^2 e^2 m^2 | / ( m^2 + 1 )

  Now a^2 e^2 = a^2 + b^2 and c^2 = a^2 m^2 - b^2 , so

        c^2 - a^2e^2 m^2 = a^2m^2 - b^2 - ( a^2 + b^2 ) m^2 = - b^2 ( 1 + m^2 )

        p1 p2 = b^2 ( 1 + m^2 ) / ( 1 + m^2 )  =  b^2                  QED
```

### Q C1  (the single most-asked long answer in the chapter)
Define a hyperbola. Derive the equation of a hyperbola in the standard form
`x^2/a^2 - y^2/b^2 = 1`.

**ANSWER — full model answer with the mark split:**

```
  DEFINITION                                                        [ 1 mark ]

  A HYPERBOLA is the locus of a point P which moves so that its distance
  from a fixed point S (the FOCUS) bears a constant ratio e (the
  ECCENTRICITY, with e > 1) to its perpendicular distance from a fixed
  line (the DIRECTRIX) not passing through S.

              S P  =  e * P M      with     e > 1


  SETTING UP                                                       [ 2 marks ]

  Drop a perpendicular from S to the directrix, meeting it at Z.
  On the line SZ there are exactly two points satisfying SP = e PM :
  the point A dividing SZ internally in the ratio e : 1 , and the point
  A' dividing it externally in the ratio e : 1 . These are the VERTICES.

  Let  A A' = 2a . Take the MIDPOINT C of A A' as the ORIGIN, the line
  A'A as the x-axis and the perpendicular through C as the y-axis.

        A = ( a , 0 )      A' = ( -a , 0 )      C = ( 0 , 0 )

  Let S = ( c , 0 ) and let the directrix be x = d .

        A  is on the curve :   c - a = e ( a - d )        ... (1)
        A' is on the curve :   c + a = e ( a + d )        ... (2)

        (1) + (2) :   2 c = 2 a e     ->     c = a e
        (2) - (1) :   2 a = 2 e d     ->     d = a / e

        So      S = ( a e , 0 )    and    directrix   x = a / e .


  THE DERIVATION                                                   [ 3 marks ]

  Let P ( x , y ) be any point of the locus. Then

        S P^2  =  e^2  P M^2

        ( x - a e )^2 + y^2  =  e^2 ( x - a/e )^2

        x^2 - 2 a e x + a^2 e^2 + y^2  =  e^2 x^2 - 2 a e x + a^2

        x^2 ( 1 - e^2 ) + y^2  =  a^2 ( 1 - e^2 )

  Divide by a^2 ( 1 - e^2 ) :

             x^2              y^2
            -----  +  -----------------  =  1
             a^2       a^2 ( 1 - e^2 )


  FINISHING                                                        [ 1 mark ]

  Since e > 1 , the quantity 1 - e^2 is NEGATIVE. Put

             b^2  =  a^2 ( e^2 - 1 )      ( a positive number )

  so that a^2 ( 1 - e^2 ) = - b^2 , and the equation becomes

                        x^2       y^2
                        ---   -   ---   =   1
                        a^2       b^2

  which is the required standard form, with  b^2 = a^2 ( e^2 - 1 ) .
                                                                    QED
```

> Draw the small labelled diagram (Z, A, C, A', S, directrix). It is usually
> worth a mark on its own and takes 30 seconds.

### Q C5
Derive the condition for the line `y = mx + c` to be a tangent to
`x^2/a^2 - y^2/b^2 = 1`, find the point of contact, and hence find the locus of the
point of intersection of two perpendicular tangents (the director circle).

**ANSWER:**

```
  PART 1 — THE CONDITION                                         [ 3 marks ]

  Substitute y = m x + c into b^2 x^2 - a^2 y^2 = a^2 b^2 :

        b^2 x^2 - a^2 ( m x + c )^2 = a^2 b^2

        ( b^2 - a^2 m^2 ) x^2 - 2 a^2 m c x - a^2 ( c^2 + b^2 ) = 0

  For a TANGENT the two roots must be equal, so the discriminant is zero:

        4 a^4 m^2 c^2 + 4 ( b^2 - a^2 m^2 ) a^2 ( c^2 + b^2 ) = 0

  Divide by 4 a^2 :

        a^2 m^2 c^2 + ( b^2 - a^2 m^2 )( c^2 + b^2 ) = 0

        a^2m^2c^2 + b^2c^2 + b^4 - a^2m^2c^2 - a^2m^2b^2 = 0

        b^2 ( c^2 + b^2 - a^2 m^2 ) = 0

                        c^2  =  a^2 m^2  -  b^2

  So the tangents of slope m are   y = m x ± sqrt( a^2 m^2 - b^2 ) ,
  and they exist only when  | m | >= b / a .


  PART 2 — POINT OF CONTACT                                       [ 1 mark ]

  The tangent at ( x1 , y1 ) is  x x1/a^2 - y y1/b^2 = 1 . Comparing with
  m x - y + c = 0 :

        ( x1/a^2 ) / m  =  ( -y1/b^2 ) / ( -1 )  =  ( -1 ) / c

        ->    x1 = - a^2 m / c    ,    y1 = - b^2 / c


  PART 3 — DIRECTOR CIRCLE                                       [ 3 marks ]

  Let the two perpendicular tangents meet at ( h , k ) . Then

        k = m h ± sqrt( a^2 m^2 - b^2 )
        ( k - m h )^2 = a^2 m^2 - b^2

        ( h^2 - a^2 ) m^2  -  2 h k m  +  ( k^2 + b^2 )  =  0

  The two roots of this quadratic are the slopes of the two tangents.
  Perpendicular means their product is -1 :

              k^2 + b^2
             -----------  =  -1      ->     k^2 + b^2 = a^2 - h^2
              h^2 - a^2

                        h^2 + k^2  =  a^2 - b^2

  LOCUS :               x^2 + y^2  =  a^2 - b^2

  This is the DIRECTOR CIRCLE. It is a real circle only when a > b
  ( equivalently e < sqrt 2 ). If a = b it shrinks to the centre, and if
  a < b no pair of perpendicular tangents exists at all.
```
