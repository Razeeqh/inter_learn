# SECTION 1 — THE FOUR FUNDAMENTAL FORCES

**This is the highest-value table in the chapter. Learn it first.**

```
  +----------------+------------+--------------+-------------+------------------+
  |  FORCE         |  RELATIVE  |    RANGE     |  MEDIATING  |  ACTS ON         |
  |                |  STRENGTH  |              |  PARTICLE   |                  |
  +----------------+------------+--------------+-------------+------------------+
  | Gravitational  |   10^-39   |   INFINITE   |  graviton   | every object      |
  |                |  WEAKEST   |              | (predicted, | with mass         |
  |                |            |              |  not found) |                   |
  +----------------+------------+--------------+-------------+------------------+
  | Weak nuclear   |   10^-13   |  ~10^-16 m   |  W and Z    | electrons,        |
  |                |            |  SHORTEST    |  bosons     | neutrinos,        |
  |                |            |    RANGE     |             | beta decay        |
  +----------------+------------+--------------+-------------+------------------+
  | Electromagnetic|   10^-2    |   INFINITE   |  photon     | charged particles  |
  +----------------+------------+--------------+-------------+------------------+
  | Strong nuclear |     1      |  ~10^-15 m   |  gluon      | protons and       |
  |                | STRONGEST  |  (1 fermi)   |  (pion in   | neutrons in the   |
  |                |            |              | older text) | nucleus           |
  +----------------+------------+--------------+-------------+------------------+
```

| Fact | When it is asked |
|---|---|
| Order of strength: **gravitational < weak < electromagnetic < strong** | "Arrange the four forces in increasing order of strength" |
| Weakest = **gravitational** | "Which is the weakest force in nature?" |
| Strongest = **strong nuclear** | "Which is the strongest force in nature?" |
| Infinite range: **gravitational and electromagnetic only** | "Which forces have infinite range?" |
| Shortest range: **weak nuclear (~10^-16 m)** | "Which force has the shortest range?" |
| Gravity is always **attractive**; EM can be attractive **or** repulsive | "How does gravity differ from the electric force?" |
| Strong force is **charge independent** — equal for p-p, p-n, n-n | "What is meant by charge independence?" |
| Friction, tension, normal reaction, elasticity, chemical bonds are all **electromagnetic** | "To which fundamental force does friction belong?" |
| Electric force is about **10^37 times** stronger than gravity | "Compare the strengths of gravity and the electric force" |

**Why gravity rules the universe despite being weakest:**
it has infinite range AND is always attractive, so it never cancels.
Electric forces are far stronger but + and − cancel in bulk matter.

# SECTION 3 — CONSERVATION LAWS

```
  +---------------------------+------------------------------+-------------------+
  |  CONSERVED QUANTITY       |  CONDITION                   |  STANDARD EXAMPLE |
  +---------------------------+------------------------------+-------------------+
  |  ENERGY                   |  isolated system             |  falling stone:   |
  |                           |                              |  PE -> KE         |
  +---------------------------+------------------------------+-------------------+
  |  LINEAR MOMENTUM          |  net EXTERNAL FORCE = 0      |  recoil of a gun; |
  |                           |                              |  rocket           |
  +---------------------------+------------------------------+-------------------+
  |  ANGULAR MOMENTUM         |  net EXTERNAL TORQUE = 0     |  spinning skater  |
  |   L = I omega             |                              |  pulling arms in  |
  +---------------------------+------------------------------+-------------------+
  |  ELECTRIC CHARGE          |  isolated system             |  rubbing glass    |
  |                           |                              |  with silk;       |
  |                           |                              |  beta decay       |
  +---------------------------+------------------------------+-------------------+
  |  MASS-ENERGY              |  always;  E = m c^2          |  nuclear fission  |
  |                           |  mass alone NOT conserved    |  (mass defect)    |
  |                           |  in nuclear reactions        |                   |
  +---------------------------+------------------------------+-------------------+
  |  PARITY (mirror symmetry) |  holds for gravitational,    |  VIOLATED in beta |
  |                           |  EM and strong forces;       |  decay of Co-60   |
  |                           |  VIOLATED by the WEAK force  |  (Wu, 1957)       |
  +---------------------------+------------------------------+-------------------+
```

## Symmetry -> conservation

```
  +-----------------------------------+----------------------------+
  |  SYMMETRY OF NATURE               |  CONSERVATION LAW          |
  +-----------------------------------+----------------------------+
  |  Homogeneity of SPACE             |  LINEAR MOMENTUM           |
  |  (laws same at every point)       |                            |
  +-----------------------------------+----------------------------+
  |  Isotropy of SPACE                |  ANGULAR MOMENTUM          |
  |  (laws same in every direction)   |                            |
  +-----------------------------------+----------------------------+
  |  Homogeneity of TIME              |  ENERGY                    |
  |  (laws same at all instants)      |                            |
  +-----------------------------------+----------------------------+
  |  Mirror reflection symmetry       |  PARITY                    |
  +-----------------------------------+----------------------------+
```

**One-line version:** *every symmetry of nature gives rise to a conservation law.*

| Fact | When it is asked |
|---|---|
| Momentum conservation follows from **Newton's third law** | "On what law is momentum conservation based?" |
| Angular momentum conservation explains **Kepler's second law** | "Why does a planet move faster near the Sun?" |
| Mass alone is **not** conserved in nuclear reactions | "Is mass always conserved?" |
| **Parity** is the conservation law that gets violated, and only by the **weak** force | "Which conservation law is not universal?" |

```
  +------------------------------+-------------------------------------------+
  |  TECHNOLOGY                  |  PRINCIPLE BEHIND IT                      |
  +------------------------------+-------------------------------------------+
  |  Steam engine                |  Laws of thermodynamics                   |
  |  Nuclear reactor             |  Controlled nuclear fission               |
  |  Nuclear bomb                |  Uncontrolled chain reaction; E = m c^2   |
  |  Radio and television        |  Generation, propagation and detection    |
  |                              |  of electromagnetic waves                 |

  |  Transistor                  |  Semiconductor p-n junctions              |
  |  Laser                       |  Stimulated emission of radiation         |
  |  Superconducting magnet /    |  Superconductivity                        |
  |  Maglev train                |                                           |
  |  Digital camera / photocell  |  Photoelectric effect                     |
  |  Solar cell                  |  Photoelectric effect in semiconductors   |
  |  Electric generator          |  Faraday's laws of electromagnetic        |
  |                              |  induction                                |
  |  Rocket propulsion           |  Newton's third law / conservation of     |
  |                              |  linear momentum                          |
  |  Aeroplane                   |  Bernoulli's principle                    |
  |  Hydroelectric power         |  Gravitational PE converted to electrical |
  |  Sonar                       |  Reflection of ultrasonic waves           |
  |  Optical fibre               |  Total internal reflection                |
  |  Electron microscope         |  Wave nature of the electron              |
```

**The two-way relationship, in one line each:**

```
  PHYSICS -> TECHNOLOGY   Faraday's induction gave us the generator.
  TECHNOLOGY -> PHYSICS   The steam engine existed FIRST; trying to
                          improve it created thermodynamics.
```

# SECTION 7 — VOCABULARY THAT EARNS MARKS

| Word | Meaning in one line |
|---|---|
| **Unification** | explaining many different phenomena with a single law |
| **Reductionism** | explaining a large system from the properties of its smaller parts |
| **Hypothesis** | an intelligent, testable guess offered to explain an observation |
| **Theory** | a hypothesis that has survived repeated experimental testing |
| **Model** | a simplified stand-in for a real system, e.g. the ideal gas |
| **Idealisation** | deliberately ignoring irrelevant features, e.g. a point mass |
| **Isolated system** | one that exchanges no matter, energy, force or charge with its surroundings |
| **Parity** | mirror symmetry — the mirror image of a valid process is also valid |
| **Charge independence** | the strong force is the same for p-p, p-n and n-n |
| **Domain of validity** | the range of conditions in which a law actually works |
