## THE 60-SECOND VERSION

An object moves along a straight line. This chapter answers four questions:

```
  1.  How far did it go and in which direction?  ->  distance & displacement
  2.  How fast?                                  ->  speed & velocity
  3.  Is it speeding up or slowing down?         ->  acceleration
  4.  Where will it be after time t ?            ->  the 3 equations of motion
```

Everything else — graphs, free fall, relative velocity, stopping distance — is
just those same three equations wearing a costume.

> **The single most important idea in the whole chapter:**
> On a **v-t graph**, the **SLOPE is acceleration** and the **AREA is displacement**.

## THE KEY BOX — LEARN THIS FIRST, EVERYTHING ELSE FOLLOWS

```
  +====================================================================+
  |                 THE THREE EQUATIONS OF MOTION                      |
  |            (valid ONLY when acceleration a is CONSTANT)            |
  |                                                                    |
  |          1)     v   =   u  +  a t                                  |
  |                                                                    |
  |          2)     s   =   u t  +  (1/2) a t^2                        |
  |                                                                    |
  |          3)     v^2 - u^2  =  2 a s                                |
  |                                                                    |
  |  BONUS   4)     s   =   ( (u + v) / 2 ) x t                        |
  |                                                                    |
  |  BONUS   5)     s(nth)  =  u  +  (a/2)(2n - 1)                     |
  |                                                                    |
  +--------------------------------------------------------------------+
  |  u = initial velocity     v = final velocity                       |
  |  a = acceleration         t = time        s = displacement         |
  |                                                                    |
  |  SIGN RULE:  fix ONE direction as positive and stick to it         |
  |              for the whole problem.                                |
  |                                                                    |
  |  UNDER GRAVITY:  replace  a  by  g = 9.8 m/s^2  (downwards)        |
  |                  replace  s  by  h                                 |
  +====================================================================+
```

## IF YOU ONLY HAVE 2 DAYS

```
  ------------------------------- DAY 1 -------------------------------
  MORNING    (2 hours)
     - Distance vs displacement  (write 2 examples)
     - Average speed vs average velocity  (do 3 numericals)
     - Memorise the 3 equations of motion and write them 10 times

  EVENING    (2 hours)
     - Motion under gravity: free fall and vertical throw
     - Learn:  H = u^2 / 2g  ,  t(up) = u/g  ,  T = 2u/g
     - Do 6 numericals

  ------------------------------- DAY 2 -------------------------------
  MORNING    (2 hours)
     - GRAPHS: draw all four x-t graphs and all four v-t graphs
     - Learn: slope of x-t = v , slope of v-t = a , AREA of v-t = s
     - Derive v = u + at and s = ut + (1/2)at^2 FROM THE v-t GRAPH

  EVENING    (2 hours)
     - Distance in the nth second: s(n) = u + (a/2)(2n - 1)
     - Relative velocity in 1-D: v(AB) = vA - vB
     - Stopping distance:  s = v^2 / (2a)  plus reaction distance
     - Re-read 05-question-patterns.md once
```

**Learn these five lines and you cannot score zero in this chapter:**

```
  1.  Displacement can be zero, distance never can.
  2.  v = u + at , s = ut + (1/2)at^2 , v^2 - u^2 = 2as
  3.  Slope of x-t = velocity.  Slope of v-t = acceleration.
  4.  AREA under v-t = displacement.
  5.  Thrown up:  H = u^2/2g , time up = time down = u/g , total T = 2u/g
```
