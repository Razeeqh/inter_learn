## THE 60-SECOND VERSION

A **fluid** is anything that flows — liquid or gas. It cannot resist a shearing force,
so it takes the shape of its container. Five ideas run the whole chapter:

```
  1.  A fluid at rest pushes on everything.        ->  P = P0 + h rho g
      That push depends only on DEPTH.

  2.  A push applied to an enclosed fluid is       ->  PASCAL'S LAW
      passed on undiminished to every point.           (hydraulic lift)

  3.  A body in a fluid is pushed UP by the        ->  ARCHIMEDES' PRINCIPLE
      weight of the fluid it displaces.                (floatation)

  4.  When a fluid speeds up, its pressure         ->  BERNOULLI'S PRINCIPLE
      DROPS.                                           (aeroplane, venturimeter)

  5.  Liquids stick to themselves.                 ->  SURFACE TENSION
      That makes drops round and makes water           (capillarity, excess
      climb up thin tubes.                              pressure)
```

Plus one villain: **VISCOSITY** — internal friction inside a fluid, which is why
honey pours slower than water and why a raindrop does not keep accelerating forever.

## THE KEY BOX — the formulas that unlock most of the chapter

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   PRESSURE AT DEPTH h      P  =  P0  +  h rho g                    |
  |                                                                    |
  |   PASCAL / HYDRAULIC LIFT       F1        F2                       |
  |                                ----  =  ----                       |
  |                                 A1        A2                       |
  |                                                                    |
  |   CONTINUITY               A1 v1  =  A2 v2                         |
  |                                                                    |
  |                                  1                                 |
  |   BERNOULLI                P  +  - rho v^2  +  rho g h  =  const   |
  |                                  2                                 |
  |                                                                    |
  |                                          2 T cos(theta)            |
  |   CAPILLARY RISE                 h  =  ------------------          |
  |                                            r rho g                 |
  |                                                                    |
  +--------------------------------------------------------------------+
```

If you learn only these five lines you can attempt something in almost every
question this chapter can ask.

## THE "WHICH FORMULA?" DECISION TREE

```
  Question mentions ...                    ->  Use ...
  ------------------------------------------------------------------
  depth, dam, submarine, tank              ->  P = P0 + h rho g
  two pistons, hydraulic, lift a car       ->  F1/A1 = F2/A2
  floating, sinking, apparent weight       ->  Archimedes: Fb = V rho g
  pipe of changing cross-section, speed    ->  A1 v1 = A2 v2
  pressure AND speed together              ->  Bernoulli
  hole in a tank, efflux                   ->  v = sqrt(2 g h)
  honey / glycerine / "slows down"         ->  viscosity, eta
  small ball falling in a liquid           ->  terminal velocity
  laminar or turbulent?                    ->  Reynolds number
  drop, bubble, film, "energy to make"     ->  surface tension
  thin tube, water rises                   ->  capillarity
```
