## THE 60-SECOND VERSION

```
  1.  EVERY two masses pull each other.        F = G m1 m2 / r^2

  2.  The Earth pulling YOU is what you call weight.
      Divide that force by your mass and you get  g = G M / R^2 = 9.8 m/s^2

  3.  g is NOT a constant. It gets smaller if you go UP, smaller if you go DOWN,
      smallest at the EQUATOR, biggest at the POLES.

  4.  Gravitational potential energy is NEGATIVE:   U = - G M m / r
      Negative means TRAPPED. To escape you must supply enough energy to
      bring U up to zero. That speed is the escape velocity, 11.2 km/s.

  5.  A satellite is an object that is falling forever and keeps missing the Earth.
      Its speed is  v = sqrt(GM/r),  and its total energy is NEGATIVE, so it is bound.
```

Everything in the chapter is one of those five sentences dressed up in numbers.

## THE KEY BOX — THESE TWO UNLOCK MOST QUESTIONS

```
  +--------------------------------------------------------------+
  |                                                              |
  |                       G M                                    |
  |               g  =  -------        so     G M  =  g R^2      |
  |                       R^2                                    |
  |                                                              |
  |   Whenever a question gives you G and M, or gives you g       |
  |   and R, SWAP using G M = g R^2. That one swap solves        |
  |   half the numericals in this chapter.                       |
  |                                                              |
  +--------------------------------------------------------------+

  +--------------------------------------------------------------+
  |                                                              |
  |     ESCAPE  v_e  =  sqrt( 2 G M / R )  =  sqrt( 2 g R )      |
  |                                                              |
  |     ORBITAL v_o  =  sqrt( G M / r )    =  sqrt( g R )        |
  |                                        (r = R, near surface) |
  |                                                              |
  |                  v_e  =  sqrt(2)  x  v_o                     |
  |                                                              |
  +--------------------------------------------------------------+
```
