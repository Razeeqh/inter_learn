## THE 60-SECOND VERSION

```
  1.  A body that repeats its motion in equal intervals of time
      is in PERIODIC motion. If it goes TO AND FRO about a fixed
      point, it is OSCILLATORY motion.

  2.  The simplest and most important oscillation is SIMPLE HARMONIC
      MOTION (SHM). Its one defining condition is:

           acceleration  =  -(constant) x displacement

      i.e.   a = -omega^2 y     The MINUS sign means "always pushed
                                back towards the middle".

  3.  Solving that gives     y = A sin(omega t + phi)

  4.  From y you get everything else by differentiating:
           v = A omega cos(omega t + phi)
           a = -A omega^2 sin(omega t + phi)

  5.  Energy keeps swapping between KE and PE, but the TOTAL stays
      fixed at   E = (1/2) m omega^2 A^2.

  6.  Two standard systems obey this exactly:
           simple pendulum   T = 2 pi sqrt(l / g)
           loaded spring     T = 2 pi sqrt(m / k)
```

**The whole chapter is one equation with a minus sign in it.** Everything
else is a consequence.

## THE KEY BOX — the two lines that unlock most of the chapter

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |     DEFINING CONDITION OF SHM                                      |
  |                                                                    |
  |             a  =  - omega^2  y                                     |
  |                                                                    |
  |     "acceleration is proportional to displacement and is           |
  |      always directed TOWARDS the mean position"                    |
  |                                                                    |
  +--------------------------------------------------------------------+
  |                                                                    |
  |     ITS SOLUTION                                                   |
  |                                                                    |
  |             y  =  A sin( omega t  +  phi )                         |
  |                                                                    |
  |             v  =  omega sqrt( A^2 - y^2 )                          |
  |                                                                    |
  |                     2 pi                                           |
  |             omega = ------  =  2 pi n                              |
  |                       T                                            |
  |                                                                    |
  +--------------------------------------------------------------------+
```

Every derivation in the chapter has the SAME shape:

```
  STEP A   Displace the body by y.
  STEP B   Find the restoring force F acting on it.
  STEP C   Show that   F = -(constant) x y
  STEP D   Divide by m:   a = -(constant/m) x y
  STEP E   Compare with  a = -omega^2 y     ->   omega^2 = constant/m
  STEP F   Use T = 2 pi / omega             ->   the time period.
```

Learn this six-step skeleton once and you can derive the pendulum, the vertical
spring, the horizontal spring, a floating cylinder and a liquid in a U-tube.

## IF YOU ONLY HAVE 2 DAYS

```
  DAY 1  (about 3 hours)
  ----------------------
   1 hr   Definition of SHM (a = -omega^2 y) + y = A sin(wt + phi)
          + the meaning of A, omega, T, n, phase, epoch.
          Learn the four "maximum value" results:
              v_max = A omega    at the mean position
              a_max = A omega^2  at the extreme position
   1 hr   Derive v and a. Draw the three time graphs.
          Learn the phase differences 90 deg and 180 deg.
   1 hr   ENERGY: derive KE, PE, total. Draw the energy graph.
          Memorise E = (1/2) m omega^2 A^2.

  DAY 2  (about 3 hours)
  ----------------------
   1.5 hr SIMPLE PENDULUM full derivation, word for word,
          written out THREE times by hand. This is your 8 marks.
          Add: seconds pendulum, lift up/down, free fall, Moon.
   1 hr   LOADED SPRING T = 2 pi sqrt(m/k), series, parallel, cutting.
   0.5 hr Damped oscillations + resonance definitions and examples
          (soldiers on a bridge, radio tuning, Tacoma Narrows).

  If you do ONLY Day 2, you still walk out with 8-10 marks.
  If you do ONLY the pendulum derivation, you still get 8.
```
