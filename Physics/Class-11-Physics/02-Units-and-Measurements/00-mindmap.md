## THE 60-SECOND VERSION

Physics measures things. This chapter answers three questions:

```
  1.  In what units do we measure?      ->  SI system, 7 base units
  2.  How wrong is my measurement?      ->  errors
  3.  Is my formula even possible?      ->  dimensions
```

Almost every mark in this chapter comes from a **memorised list**, not from
thinking. That is exactly why a weak student should study it first.

## THE ONE TABLE THAT EARNS THE MOST MARKS

```
  +-------------------------+--------------------+
  |  QUANTITY               |  DIMENSIONS        |
  +-------------------------+--------------------+
  |  Velocity               |  [ L T^-1 ]        |
  |  Acceleration           |  [ L T^-2 ]        |
  |  FORCE                  |  [ M L T^-2 ]      |   <-- learn this one first
  |  Work / Energy          |  [ M L^2 T^-2 ]    |
  |  Power                  |  [ M L^2 T^-3 ]    |
  |  Pressure / Stress      |  [ M L^-1 T^-2 ]   |
  |  Momentum / Impulse     |  [ M L T^-1 ]      |
  +-------------------------+--------------------+
```

**Learn FORCE first.** Almost everything else is built from it:

```
  Work     =  Force x Length          =  [M L T^-2] x [L]      = [M L^2 T^-2]
  Power    =  Work / Time             =  [M L^2 T^-2] / [T]    = [M L^2 T^-3]
  Pressure =  Force / Area            =  [M L T^-2] / [L^2]    = [M L^-1 T^-2]
  Momentum =  Force x Time            =  [M L T^-2] x [T]      = [M L T^-1]
```
