## Topic: Units and systems

### Q A1
What are the fundamental quantities in the SI system? Name their units.

**ANSWER:**
```
  Length                      ->  metre     (m)
  Mass                        ->  kilogram  (kg)
  Time                        ->  second    (s)
  Electric current            ->  ampere    (A)
  Thermodynamic temperature   ->  kelvin    (K)
  Amount of substance         ->  mole      (mol)
  Luminous intensity          ->  candela   (cd)
```

---

### Q A2
What are the supplementary units in SI? Give their units.

**ANSWER:**
```
  Plane angle  ->  radian     (rad)
  Solid angle  ->  steradian  (sr)

  Both are DIMENSIONLESS.
```

---

### Q A3
Distinguish between fundamental and derived units with one example each.

**ANSWER:**
```
  FUNDAMENTAL  -  independent, cannot be derived from other units.
                  Example: the metre.

  DERIVED      -  obtained by combining fundamental units.
                  Example: m / s for velocity.
```

**ANSWER:**

  PARSEC      -  the distance at which 1 AU subtends an angle of
                 1 second of arc.
                 = 3.08 x 10^16 m

  PARSEC IS LARGER.    1 parsec = 3.26 light years
```

## Topic: Errors and significant figures

### Q A14
Distinguish between accuracy and precision.

**ANSWER:**
```
  ACCURACY   -  how CLOSE a measurement is to the TRUE value.

  PRECISION  -  the resolution / repeatability of the measurement.

  A measurement can be precise but inaccurate: an instrument with a zero
  error gives consistent but wrong readings.
```

**ANSWER:** Errors that occur in the **same direction every time**, and can
therefore be corrected.

personal error.

## Topic: Applications

### Q A19
State the principle of homogeneity of dimensions.

**ANSWER:** In a dimensionally correct equation, the dimensions of every term
on both sides must be identical. Only quantities with the same dimensions can
be added or equated.

---

### Q A20
Can a dimensionally correct equation be physically wrong? Explain.

**ANSWER:** **Yes.** Dimensional analysis cannot detect a missing or extra
dimensionless constant.
Example: `s = ut + at^2` is dimensionally correct but physically wrong,
because the correct form has a factor of 1/2.

### Q A32
What are random errors? How can they be reduced?

**ANSWER:** Errors that are **irregular in both size and sign**, caused by
unpredictable fluctuations in the conditions of the experiment or in the
observer's judgement.
They are reduced by **taking a large number of readings and using the mean**,
because positive and negative deviations then tend to cancel.

### Q B1
What are the different types of errors in a measurement? Explain each briefly.

**ANSWER:**
```
  1. SYSTEMATIC ERRORS - occur in the same direction every time.
       (a) Instrumental      - zero error, worn-out scale
       (b) Imperfect method  - heat loss, buoyancy ignored
       (c) Personal          - parallax, careless habit
     These CAN be removed by calibration.

  2. RANDOM ERRORS - irregular in sign and size, due to unpredictable
     fluctuations. Reduced by taking many readings and averaging.

  3. LEAST COUNT ERROR - due to the finite resolution of the instrument.

  4. GROSS ERRORS - human blunders in recording or calculating.
```

Explain the rules for combination of errors in (i) sum/difference
(ii) product/quotient (iii) power.

**ANSWER:**
```
  (i)   Z = A + B   or   Z = A - B

              dZ  =  dA  +  dB              (ABSOLUTE errors add)


  (ii)  Z = A x B   or   Z = A / B

             dZ       dA       dB
            ---- =   ---- +   ----          (RELATIVE errors add)
              Z        A        B


                 A^p  B^q
  (iii) Z  =  --------------
                   C^r

             dZ         dA        dB        dC
            ---- =  p  ---- + q  ---- + r  ----
              Z          A         B         C

  The MAXIMUM possible error is always taken, so all terms are ADDED.
```

### Q B3
Write the rules for determining significant figures and for arithmetic
operations with them.

**ANSWER:** See Topic 6 in `01-concepts.md` for the seven counting rules, plus:
```
  Addition / Subtraction    ->  fewest DECIMAL PLACES
  Multiplication / Division ->  fewest SIGNIFICANT FIGURES
```

Written out in full, for the exam:

```
  COUNTING RULES

    1.  All non-zero digits are significant.               234    -> 3
    2.  Zeros between non-zero digits are significant.     2004   -> 4
    3.  Leading zeros are NOT significant.                 0.0025 -> 2
    4.  Trailing zeros are significant only if a decimal
        point is present.                                  2.500  -> 4
    5.  Trailing zeros with no decimal point are
        ambiguous; use scientific notation.                2500   -> ?
    6.  In  a x 10^b  only the digits of  a  count.        6.02x10^23 -> 3
    7.  Exact and counted numbers have infinite
        significant figures.                               10 students

  ARITHMETIC RULES

    ADDITION / SUBTRACTION  ->  the answer keeps the FEWEST DECIMAL PLACES
        436.32 + 227.2 + 0.301  =  663.821    ->    663.8

    MULTIPLICATION / DIVISION  ->  the answer keeps the FEWEST SIGNIFICANT
    FIGURES
        4.237 x 2.51  =  10.63487             ->    10.6

  ROUNDING RULES

    dropped digit  >  5        ->  round UP                1.68 -> 1.7
    dropped digit  <  5        ->  simply drop it          1.62 -> 1.6
    dropped digit  =  5 exactly ->  make the preceding digit EVEN
                                                           1.65 -> 1.6
                                                           1.75 -> 1.8

  NOTE:  changing the unit never changes the number of significant figures.
         2.308 cm = 23.08 mm = 0.02308 m , and all three have 4 s.f.
```

### Q B4
What is dimensional analysis? State its uses.

**ANSWER:**
```
  Dimensional analysis studies the dimensions of physical quantities in
  order to relate them.

  USE 1 - CONVERSION of units from one system to another, using

              n2 = n1 (M1/M2)^a (L1/L2)^b (T1/T2)^c

  USE 2 - CHECKING the correctness of an equation, using the principle of
          homogeneity.

  USE 3 - DERIVING a relation between physical quantities when the
          dependence is known.
```

---

### Q B5  ***ASKED VERY OFTEN***
State the limitations of dimensional analysis.

**ANSWER:**
```
  1.  The value of the dimensionless constant cannot be found.

  2.  It fails if a quantity depends on more than three other quantities.

  3.  It cannot be used for equations containing a SUM of terms.

  4.  It cannot handle trigonometric, exponential or logarithmic functions.

  5.  It cannot distinguish scalars from vectors.
      (Work and torque have identical dimensions.)

  6.  A dimensionally correct equation may still be physically incorrect.
```

### Q B8
Derive the expression for the time period of a simple pendulum using
dimensional analysis.

**ANSWER:**
```
  STEP 1   Assume  T  depends on  mass m , length l , gravity g :

                 T  =  k  x  m^a  x  l^b  x  g^c


  STEP 2   Substitute dimensions:

           [ M^0 L^0 T^1 ]  =  [M]^a  [L]^b  [ L T^-2 ]^c

                            =  [ M^a   L^(b+c)   T^(-2c) ]


  STEP 3   Compare powers:

           M :      a    =  0        ->   a = 0
           T :    -2c    =  1        ->   c = -1/2
           L :   b + c   =  0        ->   b = +1/2


  STEP 4   Therefore

                              +-------+
                              |   l   |
              T  =  k  x sqrt |  ---  |
                              |   g   |
                              +-------+


  STEP 5   Experiment gives k = 2 pi , so   T = 2 pi sqrt( l / g )

  NOTE:  the period does NOT depend on the mass of the bob.
```

### Q B11
In a simple pendulum experiment, l = 100.0 cm (least count 1 mm) and the time

```

### Q B12
Explain how the distance of a planet from the Earth is determined by the
parallax method.

**ANSWER:**
```
  1.  Observe the planet at the SAME MOMENT from two points A and B on the
      Earth, separated by a known distance b (called the BASIS).

  2.  Measure the parallax angle theta that AB subtends at the planet.

  3.  Since theta is very small,

                       b                             b
          theta  =  -------      therefore    D  =  -------
                       D                            theta

      with theta measured in RADIANS.

  4.  Once D is known, the diameter d of the planet follows from its
      angular diameter alpha:

          d  =  D  x  alpha
```

  STEP 1   Convert to radians:

           alpha  =  1920  x  4.85 x 10^-6   =   9.312 x 10^-3 rad

### Q C1  (revision-grade) — the complete "errors" answer

Explain the different types of errors in measurement. State the rules for the
combination of errors. A physical quantity is given by `P = a^3 b^2 / (c d)`.
If the percentage errors in a, b, c and d are 1 %, 3 %, 2 % and 4 %, find the
maximum percentage error in P.

**ANSWER — mark split: 3 + 3 + 2**
```
  PART 1  TYPES OF ERRORS                                          (3 marks)

    1. SYSTEMATIC - same direction every time, therefore correctable
         (a) instrumental      - zero error, worn scale
         (b) imperfect method  - heat loss, buoyancy ignored
         (c) personal          - parallax while reading, careless habit

    2. RANDOM - irregular in sign and size; reduced by taking many
       readings and averaging.

    3. LEAST COUNT ERROR - from the finite resolution of the instrument.

    4. GROSS ERROR - a human blunder in reading or recording.


  PART 2  COMBINATION OF ERRORS                                    (3 marks)

    Z = A + B  or  A - B      ->    dZ  =  dA + dB      (ABSOLUTE errors add)

                                          dZ       dA       dB
    Z = A x B  or  A / B      ->         ---- =   ---- +   ----
                                           Z        A        B

              A^p B^q                     dZ         dA        dB       dC
    Z  =  -------------       ->         ---- =  p  ---- + q  ---- + r ----
                C^r                        Z          A         B        C

    Every sign is a PLUS because the MAXIMUM possible error is taken.


  PART 3  THE NUMERICAL                                            (2 marks)

     dP         da         db        dc        dd
    ----  =  3 ----  +  2 ----  +   ----  +   ----
      P          a          b         c         d

          =  3 x 1 %  +  2 x 3 %  +  1 x 2 %  +  1 x 4 %

          =  3  +  6  +  2  +  4

          =  15 %
```

### Q C2  (revision-grade) — the complete "dimensions" answer

What is a dimensional formula? State the principle of homogeneity and describe
the three uses of dimensional analysis with one example each. State its
limitations.

**ANSWER — mark split: 1 + 1 + 3 + 3**
```
  PART 1  DIMENSIONAL FORMULA                                      (1 mark)

    The expression that shows which powers of the base quantities make up a
    physical quantity.   Example:  force = [ M L T^-2 ].


  PART 2  PRINCIPLE OF HOMOGENEITY                                 (1 mark)

    In a correct physical equation every term on both sides must have
    identical dimensions. You cannot add a length to a time.


  PART 3  THE THREE USES                                           (3 marks)

    USE 1  CONVERTING UNITS

              n2  =  n1 (M1/M2)^a (L1/L2)^b (T1/T2)^c

           Example: force is [M L T^-2], so
              1 N  =  1 x 10^3 x 10^2 x 1  =  10^5 dyne


    USE 2  CHECKING AN EQUATION

           Check  v^2 = u^2 + 2 a s :

              LHS = [ L^2 T^-2 ]
              u^2 = [ L^2 T^-2 ] ,  2 a s = [ L T^-2 ][ L ] = [ L^2 T^-2 ]

           All terms agree, so the equation is dimensionally correct.


    USE 3  DERIVING A RELATION

           T = k m^a l^b g^c

              [ M^0 L^0 T^1 ]  =  [ M^a  L^(b+c)  T^(-2c) ]

              M :    a     = 0   ->  a = 0
              T :  -2c     = 1   ->  c = -1/2
              L :  b + c   = 0   ->  b = +1/2

           T  =  k sqrt( l / g ) ,  and experiment gives k = 2 pi.


  PART 4  LIMITATIONS                                              (3 marks)

    1. Cannot give the dimensionless constant.
    2. Fails if the quantity depends on more than three others
       (M, L and T give only three equations).
    3. Cannot handle an equation that is a SUM of terms.
    4. Cannot handle trigonometric, exponential or logarithmic functions.
    5. Cannot distinguish a scalar from a vector (work and torque).
    6. A dimensionally correct equation may still be physically wrong
       (s = ut + at^2).
```

### Q C3  (revision-grade) — measuring distances, large and small

Describe how the distance of a planet and the size of a planet are measured.
Define astronomical unit, light year and parsec. A star shows an annual
parallax of 0.5 seconds of arc; find its distance in metres, parsecs and
light years.

**ANSWER — mark split: 3 + 2 + 3**
```
  PART 1  THE TWO METHODS                                          (3 marks)

    PARALLAX (distance):
      Observe the planet at the same instant from two points A and B a known
      distance b apart. Measure the parallax angle theta subtended by AB at
      the planet. Then

                            b
                 D   =   -------          theta in RADIANS
                          theta

    ANGULAR DIAMETER (size):
      Measure the angle alpha that the planet's disc subtends at the Earth.
      Once D is known,

                 d   =   D  x  alpha      alpha in RADIANS


  PART 2  THE THREE UNITS                                          (2 marks)

    ASTRONOMICAL UNIT - the mean Earth-Sun distance = 1.496 x 10^11 m

    LIGHT YEAR        - the distance light travels in vacuum in one year
                      = 9.46 x 10^15 m

    PARSEC            - the distance at which 1 AU subtends 1 second of arc
                      = 3.08 x 10^16 m  =  3.26 light years


  PART 3  THE NUMERICAL                                            (3 marks)

    theta  =  0.5"  =  0.5 x 4.85 x 10^-6  =  2.425 x 10^-6 rad

              1.496 x 10^11
    D    =  ----------------   =   6.17 x 10^16 m
             2.425 x 10^-6

    In parsec:        6.17 x 10^16 / 3.08 x 10^16   =   2.0 pc

    In light years:   2.0 x 3.26                    =   6.5 ly

    SHORT CUT:  distance in parsec = 1 / (parallax in arc-seconds) = 1/0.5 = 2
```

### Q C4  (revision-grade) — significant figures and the reporting of a result

State the rules for counting significant figures and for arithmetic with them.
Apply them to: (i) the number of significant figures in 0.007, 2.64 x 10^24,
0.2370 and 6.320; (ii) 436.32 + 227.2 + 0.301; (iii) 4.237 x 2.51;
(iv) the density of a body of mass 5.74 g and volume 1.2 cm^3.

**ANSWER — mark split: 3 + 2 + 3**
```
  PART 1  COUNTING RULES                                           (3 marks)

    1. All non-zero digits count.                     234    -> 3
    2. Zeros between non-zero digits count.           2004   -> 4
    3. Leading zeros do NOT count.                    0.0025 -> 2
    4. Trailing zeros count if a decimal point is present.  2.500 -> 4
    5. Trailing zeros with no decimal point are ambiguous - use
       scientific notation.
    6. In  a x 10^b  only the digits of  a  count.
    7. Exact and counted numbers have infinite significant figures.

    ARITHMETIC:
       Addition / Subtraction    ->  fewest DECIMAL PLACES
       Multiplication / Division ->  fewest SIGNIFICANT FIGURES


  PART 2  COUNTING PRACTICE                                        (2 marks)

       0.007          ->  1 s.f.
       2.64 x 10^24   ->  3 s.f.
       0.2370         ->  4 s.f.
       6.320          ->  4 s.f.


  PART 3  THE ARITHMETIC                                           (3 marks)

    (ii)   436.32 + 227.2 + 0.301  =  663.821
           227.2 has only ONE decimal place    ->    663.8

    (iii)  4.237 x 2.51  =  10.63487
           2.51 has only THREE significant figures    ->    10.6

    (iv)   rho  =  5.74 / 1.2  =  4.783...
           1.2 has only TWO significant figures    ->    4.8 g/cm^3
```
