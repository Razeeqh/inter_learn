## THE 60-SECOND VERSION

In Chapter 3 things moved along a straight line, so a plus or a minus sign was
enough to say "which way". In a **plane** an object can move in any direction, so
a number alone is useless. You need a **vector** — a number **plus** a direction.

```
  STEP 1   Learn how to ADD and RESOLVE vectors.
  STEP 2   Then EVERY 2-D motion problem becomes TWO separate 1-D problems:
              one along x  and  one along y,  solved with Chapter 3 formulas.
```

That single idea — **break it into x and y, solve each separately** — is the whole
chapter. Projectile motion is just this idea applied to a thrown ball:

```
  HORIZONTAL (x):   no force, no acceleration   ->  constant velocity
  VERTICAL   (y):   gravity pulls down          ->  a = -g,  like a ball thrown up

  The two motions do NOT affect each other. They only share the same CLOCK (time t).
```

## THE ONE PICTURE TO KEEP IN YOUR HEAD

```
                              PROJECTILE
                              ...........
                        .....             .....
                    ...        | H (max)       ...
                 ..            |                  ..
               ..              |                    ..
             ..                |                      ..
           ..                  |                        ..
         ..                    |                          ..
       ..                      |                            ..
     ./ theta                  |                              .
   -O---------------------------------------------------------O----->
    |<------------------- R (range) --------------------------->|

    HORIZONTAL:  velocity stays u cos theta FOREVER.  a_x = 0
    VERTICAL  :  behaves exactly like a ball thrown straight up
                 with speed u sin theta.  a_y = -g
    At the TOP :  vertical velocity = 0,  but the ball is STILL MOVING
                  horizontally at u cos theta.  Speed at top is NOT zero.
```
