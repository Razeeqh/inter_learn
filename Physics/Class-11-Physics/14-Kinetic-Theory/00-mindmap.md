## THE 60-SECOND VERSION

A gas looks smooth and continuous. It is not. It is a swarm of tiny hard balls
flying in every direction at about 500 metres per second, banging into the walls
billions of times a second.

```
  PRESSURE      =  the drumming of molecules on the wall
                   P = (1/3) rho c^2

  TEMPERATURE   =  how fast those molecules are going
                   (1/2) m c^2 = (3/2) k T

  HEAT CAPACITY =  how many different ways a molecule can store energy
                   each way stores (1/2) k T
```

That is the entire chapter. Everything else is algebra hanging off these three lines.

## THE KEY BOX — THE FORMULAS THAT UNLOCK MOST QUESTIONS

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |                    1   m N              1                          |
  |            P   =  --- ------- c^2  =   --- rho c^2                 |
  |                    3     V              3                          |
  |                                                                    |
  |            1                3                                      |
  |           --- m c^2   =    --- k T          (per MOLECULE)         |
  |            2                2                                      |
  |                                                                    |
  |                        ______        ______                        |
  |                       / 3 R T       / 3 k T                        |
  |            c_rms  =  /  ------- =  /  -------                      |
  |                    \/     M      \/      m                         |
  |                                                                    |
  |                        f                                  2        |
  |            Cv  =  ---- R      Cp = Cv + R      gamma = 1 + ---     |
  |                     2                                       f      |
  |                                                                    |
  +--------------------------------------------------------------------+

  f = number of degrees of freedom = 3 (mono), 5 (diatomic), 6 (polyatomic)
```

Three numbers you must never look up again:

```
  NA  =  6.022 x 10^23  per mole
  R   =  8.314  J mol^-1 K^-1
  k   =  1.38 x 10^-23  J K^-1        and    R  =  NA  x  k
```

## THE ONE THING EXAMINERS LOVE MOST

```
  +---------------------------------------------------------------+
  |                                                               |
  |   The average kinetic energy of a gas molecule depends        |
  |   ONLY on the absolute temperature.                           |
  |                                                               |
  |   NOT on the pressure.                                        |
  |   NOT on the volume.                                          |
  |   NOT on the nature of the gas.                               |
  |                                                               |
  |   So at the SAME temperature, a hydrogen molecule and a       |
  |   carbon-dioxide molecule have the SAME average KE --         |
  |   but hydrogen moves much FASTER, because it is lighter.      |
  |                                                               |
  +---------------------------------------------------------------+
```

Half the two-mark and MCQ questions in this chapter are just this box in disguise.

## IF YOU ONLY HAVE 2 DAYS

```
  DAY 1  (about 3 hours)
  ------------------------------------------------------------------
   1 hr   The 7 postulates + the FULL derivation of P = (1/3) rho c^2.
          Write the derivation out from memory three times.
   1 hr   (1/2) m c^2 = (3/2) k T , absolute zero, and the three
          molecular speeds with their ratio 1 : 1.128 : 1.224.
   1 hr   Work the numericals in 03-pyq-ap-board.md Section A.
          Almost all of them are "put numbers into c_rms".

  DAY 2  (about 3 hours)
  ------------------------------------------------------------------
   1 hr   Law of equipartition, degrees of freedom, and the
          Cv / Cp / gamma table. Memorise the table as NINE numbers.
   1 hr   Mean free path (formula + what it depends on) and
          Brownian motion. Deducing Boyle's and Charles' laws.
   1 hr   The MCQ patterns in 04-pyq-competitive.md.
```

If you have only **2 hours in total**, learn exactly these four things:

```
  1.  P = (1/3) rho c^2   and the derivation outline.
  2.  (1/2) m c^2 = (3/2) k T   ->  KE depends only on T.
  3.  c_rms = sqrt(3RT/M).
  4.  The nine-number table:   3/2 R , 5/2 R , 5/3
                               5/2 R , 7/2 R , 7/5
                                 3 R ,   4 R , 4/3
```

That is roughly 6 marks in the board exam and 2 marks in EAPCET, for one evening's work.
