## THE 60-SECOND VERSION

The whole chapter answers ONE question:

```
      "A body has some forces on it. What does it DO?"
```

And there is only ONE answer:

```
  +----------------------------------------------------------------+
  |                                                                |
  |     NET FORCE   =   MASS   x   ACCELERATION                    |
  |                                                                |
  |          F_net  =  m a                                         |
  |                                                                |
  |     If  F_net = 0    ->  the body stays at rest, or keeps      |
  |                          moving at CONSTANT velocity           |
  |                                                                |
  +----------------------------------------------------------------+
```

Everything else — friction, lifts, pulleys, banked roads — is just the SAME
equation applied to a different picture. So the picture (the free body diagram)
is the whole exam.

## HOW TO SOLVE ANY MECHANICS PROBLEM (the 5 steps)

**Follow these five steps in this order, every single time. No thinking needed.**

```
  +-------------------------------------------------------------------+
  |  STEP 1                                                           |
  |  DRAW THE FREE BODY DIAGRAM                                       |
  |  Take ONE body. Draw it as a box. Rub out everything else.        |
  |  Draw an arrow for EVERY force touching it:                       |
  |     - weight  mg     (always straight DOWN)                       |
  |     - normal  N      (always PERPENDICULAR to the surface)        |
  |     - tension T      (always ALONG the string, AWAY from body)    |
  |     - friction f     (always OPPOSITE to sliding)                 |
  |     - applied force F                                             |
  +-------------------------------------------------------------------+
                                   |
                                   v
  +-------------------------------------------------------------------+
  |  STEP 2                                                           |
  |  CHOOSE YOUR AXES                                                 |
  |  Put the x-axis ALONG the direction of the acceleration.          |
  |  On an incline, tilt the axes to lie along the slope.             |
  +-------------------------------------------------------------------+
                                   |
                                   v
  +-------------------------------------------------------------------+
  |  STEP 3                                                           |
  |  RESOLVE every slanted force into x and y components.             |
  |     along the slope  ->  mg sin(theta)                            |
  |     perpendicular    ->  mg cos(theta)                            |
  +-------------------------------------------------------------------+
                                   |
                                   v
  +-------------------------------------------------------------------+
  |  STEP 4                                                           |
  |  APPLY  F = m a  ALONG THE MOTION                                 |
  |  APPLY  F = 0    PERPENDICULAR TO THE MOTION                      |
  |  (Perpendicular to the motion there is no acceleration, so the    |
  |   forces there must balance. This is how you always get N.)       |
  +-------------------------------------------------------------------+
                                   |
                                   v
  +-------------------------------------------------------------------+
  |  STEP 5                                                           |
  |  SOLVE                                                            |
  |  One body  -> one equation.                                       |
  |  Two bodies -> two equations, two unknowns (usually a and T).     |
  |  ADD the equations to kill T and get a. Then put a back to get T. |
  +-------------------------------------------------------------------+
```

## IF YOU ONLY HAVE 2 DAYS

```
  ----------------------------- DAY 1 -------------------------------

  MORNING   (2 hours)
     - The three laws, word-perfect. Inertia and its 3 types.
     - Momentum p = mv, second law F = ma, impulse J = F t = change in p.
     - Practise: "why does a cricketer pull his hands back", the batsman,
       the jumping-on-sand question. These are free 2-mark answers.

  AFTERNOON (2 hours)
     - Conservation of momentum: the DERIVATION from the third law.
     - Gun recoil numerical. Rocket propulsion in 4 lines.
     - Lami's theorem statement + diagram.

  EVENING   (2 hours)
     - FREE BODY DIAGRAMS. Draw all five pictures above, 10 times each,
       until you can do them with the book shut.
     - The LIFT: memorise the four cases table.

  ----------------------------- DAY 2 -------------------------------

  MORNING   (2 hours)
     - Two connected blocks: derive a and T.
     - ATWOOD MACHINE: derive a = (m1 - m2)g/(m1 + m2) and
       T = 2 m1 m2 g /(m1 + m2). This is an 8-mark question.

  AFTERNOON (2 hours)
     - FRICTION: static vs limiting vs kinetic, laws of friction,
       angle of friction, angle of repose, mu = tan(theta).
     - Advantages, disadvantages, methods of reducing friction.
       (Straight 4 marks, pure memory.)

  EVENING   (2 hours)
     - Inclined plane, rough and smooth.
     - Circular motion: level road v_max = sqrt(mu g r),
       banked road tan(theta) = v^2 / (r g).
     - Re-read 05-question-patterns.md once and sleep.
```

## THE FOUR SENTENCES THAT ARE WORTH THE MOST MARKS

```
  1.  "Every body continues in its state of rest or of uniform motion in a
       straight line unless acted upon by an external force."

  2.  "The rate of change of momentum of a body is directly proportional to
       the applied force and takes place in the direction of the force."

  3.  "To every action there is an equal and opposite reaction, and they act
       on TWO DIFFERENT BODIES."

  4.  "When the net external force on a system is zero, its total linear
       momentum remains constant."
```
