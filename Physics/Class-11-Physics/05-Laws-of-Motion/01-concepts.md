# TOPIC 1 — Aristotle's fallacy (why the old idea was wrong)

Aristotle, 2300 years ago, said:

```
  "A body needs a force to KEEP MOVING.
   Stop pushing, and the body stops."
```

That is called **Aristotle's fallacy** (fallacy = a wrong belief).

It *looks* true. Push a book on a table, it slides and stops. Stop pedalling a
bicycle, it slows down. So a force seems needed just to keep going.

**Galileo showed the truth.** The body stops because of a HIDDEN force —
**friction** and **air resistance**. Remove them, and the body would never stop.

## Galileo's double inclined plane experiment

```
  Roll a ball down one slope and up another.

     \                                       /
      \                                     /
       \  ball                             /
        \  o                              /
         \  |                            /   the ball climbs to nearly
          \ v                           /    the SAME HEIGHT it started
           \                           /     from
            \_________________________/
                    (smooth)

  Now make the second slope gentler:

     \
      \
       \  o
        \  |
         \ v            ______________________________
          \____________/       still tries to reach the same height,
                               so it travels FURTHER

  Now make the second surface FLAT:

     \
      \  o
       \ |
        \v
         \_________________________________________________>  for ever

  With no friction, the ball never reaches its old height,
  so it NEVER STOPS.
```

```
  +----------------------------------------------------------------------+
  |  CONCLUSION                                                          |
  |                                                                      |
  |  A force is NOT needed to keep a body moving.                        |
  |  A force is needed only to CHANGE the motion.                        |
  |                                                                      |
  |  This directly leads to Newton's FIRST LAW.                          |
  +----------------------------------------------------------------------+
```

> **TRAP:** In the exam, "Aristotle's fallacy" means the *wrong statement*,
> not the correction. State the wrong belief first, then say why it is wrong.

# TOPIC 2 — Inertia and Newton's FIRST law

## Newton's first law (learn this sentence word-for-word)

```
  +----------------------------------------------------------------------+
  |  Every body continues in its state of REST or of UNIFORM MOTION in   |
  |  a STRAIGHT LINE, unless it is compelled by an EXTERNAL FORCE to     |
  |  change that state.                                                  |
  +----------------------------------------------------------------------+
```

The first law does two jobs:

```
  1.  It DEFINES force  ->  force is that which changes the state of motion.
  2.  It DEFINES inertia ->  the property that resists that change.
```

That is why the first law is also called the **law of inertia**.

## What is inertia?

**Inertia** is the natural laziness of matter: a body's inability to change its
own state of rest or uniform motion by itself.

```
  MEASURE OF INERTIA  =  MASS

  More mass  ->  more inertia  ->  harder to start, harder to stop.

  A loaded truck is far harder to push than an empty cycle.
```

## The three types of inertia

```
  +---------------------+------------------------------------------------+
  |  TYPE               |  EVERYDAY EXAMPLES  (learn 2 each)             |
  +---------------------+------------------------------------------------+
  |  1. INERTIA OF REST |  - Dust flies off when a carpet is beaten.     |
  |     A body at rest  |    The carpet moves, the dust stays at rest.   |
  |     wants to STAY   |  - A passenger falls BACKWARD when a bus       |
  |     at rest.        |    suddenly starts.                            |
  |                     |  - Coin on a card over a glass: flick the card,|
  |                     |    the coin drops straight into the glass.     |
  +---------------------+------------------------------------------------+
  |  2. INERTIA OF      |  - A passenger falls FORWARD when a moving bus |
  |     MOTION          |    suddenly brakes.                            |
  |     A moving body   |  - An athlete runs some distance before a long |
  |     wants to KEEP   |    jump, to gain inertia of motion.            |
  |     moving.         |  - A man jumping off a moving bus falls        |
  |                     |    forward if he does not run a few steps.     |
  +---------------------+------------------------------------------------+
  |  3. INERTIA OF      |  - A cyclist is thrown outward at a sharp turn |
  |     DIRECTION       |    because the body wants to go straight.      |
  |     A body wants to |  - Mud flies off a moving wheel along the      |
  |     keep the SAME   |    tangent.                                    |
  |     DIRECTION.      |  - Sparks fly off tangentially at a grinding   |
  |                     |    wheel.                                      |
  +---------------------+------------------------------------------------+
```

## The bus example, drawn

```
  BUS SUDDENLY STARTS                    BUS SUDDENLY STOPS

     bus accelerates -->                    bus was moving -->
   +-----------------+                   +-----------------+
   |     o           |                   |          o      |
   |    /|\  <- man  |                   |         /|\     |
   |     |  falls    |                   |          |  falls
   |    / \ BACKWARD |                   |         / \ FORWARD
   +--O-------O------+                   +--O-------O------+

  His FEET move with the bus,            His FEET stop with the bus,
  his BODY stays at rest.                his BODY keeps moving.
  -> INERTIA OF REST                     -> INERTIA OF MOTION
```

> **TRAP:** Students swap these two. Remember: **START = fall BACK**,
> **STOP = fall FORWARD**. The upper body always "keeps doing what it was doing".

### Worked example

**Q. Why does a coin placed on a card over a glass fall into the glass when the
card is flicked away?**

```
  +-----------------+
  |     (coin)      |            flick this way -->
  +-----------------+
  |=====CARD========|
        |     |
        | GLASS|
        |     |

  The FLICK acts only on the CARD, for a very short time.
  The card leaves quickly.
  The coin, because of INERTIA OF REST, does not move sideways.
  With nothing under it, gravity pulls it straight DOWN into the glass.
```

# TOPIC 3 — Linear momentum

**Momentum** measures "how much motion" a body has. It depends on BOTH mass and
velocity.

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |          p  =  m v                                                   |
  |                                                                      |
  |   VECTOR quantity, direction = direction of velocity                 |
  |   SI unit    :  kg m / s     (also  N s)                             |
  |   Dimensions :  [ M L T^-1 ]                                         |
  |                                                                      |
  +----------------------------------------------------------------------+
```

Why do we need it? Because a slow heavy thing can be as dangerous as a fast
light thing.

```
  A 10000 kg truck at 1 m/s      ->  p = 10000 kg m/s
  A 10 kg cannonball at 1000 m/s ->  p = 10000 kg m/s

  Both need the SAME total "stopping effort".
```

## Useful relation between momentum and kinetic energy

```
                                                +--------+
       p^2                                      |        |
  KE = -----          and         p  =  sqrt    | 2 m KE |
       2 m                                      |        |
                                                +--------+

  For the SAME kinetic energy, the HEAVIER body has MORE momentum.
  For the SAME momentum, the LIGHTER body has MORE kinetic energy.
```

### Worked example

**Q. A 2 kg ball moving at 5 m/s is struck and returns along the same line at
3 m/s. Find the change in momentum.**

```
  Take the ORIGINAL direction as POSITIVE.

  Initial momentum   p1  =  m u  =  2 x (+5)  =  +10 kg m/s

  Final momentum     p2  =  m v  =  2 x (-3)  =  -6 kg m/s
                                        ^
                                     NEGATIVE because it reversed

  Change  =  p2 - p1  =  (-6) - (+10)  =  -16 kg m/s

  MAGNITUDE = 16 kg m/s, directed OPPOSITE to the original motion.
```

> **TRAP:** When a body bounces back, the change in momentum is
> `mv + mu`, NOT `mv - mu`. The sign flip is where most marks are lost.

# TOPIC 4 — Newton's SECOND law

```
  +----------------------------------------------------------------------+
  |  The RATE OF CHANGE OF MOMENTUM of a body is directly proportional   |
  |  to the applied force, and takes place in the direction of the       |
  |  force.                                                              |
  +----------------------------------------------------------------------+
```

## From the statement to F = ma

```
                 dp
   F  is prop.  ----
                 dt

                dp        d(mv)              dv
   So    F = k ----  = k -------   =  k m  ------      (m constant)
                dt         dt                dt

              =  k m a

   In SI units the unit of force is DEFINED so that  k = 1.

                 +---------------+
                 |               |
                 |   F  =  m a   |
                 |               |
                 +---------------+
```

```
  1 NEWTON  =  the force that gives a mass of 1 kg an acceleration
               of 1 m/s^2.

  1 N  =  1 kg m / s^2          Dimensions  [ M L T^-2 ]
  1 N  =  10^5 dyne
```

## The three things the second law tells you

```
  1.  Force and acceleration are in the SAME direction.
  2.  If F = 0, then a = 0  ->  the FIRST law is contained inside the second.
  3.  Force is needed for ACCELERATION, not for velocity.
```

## Component form

```
  F_x  =  m a_x        F_y  =  m a_y        F_z  =  m a_z

  Each direction is handled SEPARATELY. This is why we resolve forces.
```

### Worked example

**Q. A force of 20 N acts on a 4 kg body at rest. Find (i) the acceleration
(ii) the velocity after 5 s (iii) the distance travelled in 5 s.**

```
  (i)          F        20
        a  =  ---  =  ------  =  5 m/s^2
               m         4

  (ii)  v  =  u + a t  =  0 + 5 x 5  =  25 m/s

  (iii) s  =  u t + (1/2) a t^2  =  0 + (1/2)(5)(25)  =  62.5 m
```

# TOPIC 5 — Impulse and the impulse-momentum theorem

Some forces act for a VERY SHORT TIME and are very LARGE: a bat hitting a ball,
a hammer hitting a nail, a car crash. We cannot easily measure such a force, but
we CAN measure what it did to the momentum.

```
  +----------------------------------------------------------------------+
  |  IMPULSE  J  =  Force  x  time  =  F t                               |
  |                                                                      |
  |  IMPULSE-MOMENTUM THEOREM:                                           |
  |                                                                      |
  |        J  =  F t  =  m v  -  m u  =  CHANGE IN MOMENTUM              |
  |                                                                      |
  |  VECTOR quantity                                                     |
  |  SI unit    :  N s   (same as kg m/s)                                |
  |  Dimensions :  [ M L T^-1 ]   (same as momentum)                     |
  +----------------------------------------------------------------------+
```

## Impulse as the AREA under the F-t graph

When the force is not constant, impulse is the area under the force-time curve.

```
   Force
     ^
     |             ____
     |           /      \
     |          /        \
     |         /          \
     |        /   AREA =   \
     |       /   IMPULSE    \
     |      /                \
     |     /                  \
     +----+--------------------+---------> time
          t1                   t2

           J  =  area under the F-t graph  =  change in momentum

  For a constant force this is just a rectangle:   J = F x (t2 - t1)
```

## The big idea: for a FIXED change of momentum, longer time = smaller force

```
                          change in momentum
        Average force  =  ---------------------
                                  time

        SAME top,  BIGGER bottom  ->  SMALLER force.
```

That one line explains all of these exam favourites:

```
  +--------------------------------------+------------------------------+
  |  SITUATION                           |  WHY                         |
  +--------------------------------------+------------------------------+
  |  A cricketer pulls his hands BACK    |  increases the catching time |
  |  while catching a ball.              |  -> smaller force on hands   |
  |                                      |                              |
  |  We jump onto SAND, not concrete.    |  sand increases stopping time|
  |                                      |  -> smaller force on legs    |
  |                                      |                              |
  |  A car has crumple zones and an      |  they lengthen the collision |
  |  airbag.                             |  time -> smaller force       |
  |                                      |                              |
  |  China cups are wrapped in straw.    |  straw lengthens the impact  |
  |                                      |  time -> cup does not break  |
  |                                      |                              |
  |  A high jumper lands on a foam bed.  |  same reason                 |
  |                                      |                              |
  |  A karate expert breaks a slab in a  |  he makes the time VERY      |
  |  very short strike.                  |  SHORT -> a HUGE force       |
  +--------------------------------------+------------------------------+
```

### Worked example

**Q. A 150 g cricket ball moving at 20 m/s is caught. The catch takes 0.1 s.
Find the average force on the hands. What if the catch takes 0.5 s?**

```
  m = 150 g = 0.15 kg ,  u = 20 m/s ,  v = 0

  Change in momentum  =  m(v - u)  =  0.15 (0 - 20)  =  -3 kg m/s
  Magnitude = 3 N s

  CASE 1:  t = 0.1 s

                 3
        F  =  ------  =  30 N
                0.1

  CASE 2:  t = 0.5 s

                 3
        F  =  ------  =  6 N
                0.5

  FIVE TIMES the time  ->  ONE-FIFTH the force.
  That is exactly why the cricketer pulls his hands back.
```

> **TRAP:** Convert grams to kilograms BEFORE you start. Writing 150 instead of
> 0.15 makes the answer 1000 times too big.

# TOPIC 6 — Newton's THIRD law

```
  +----------------------------------------------------------------------+
  |  To every ACTION there is always an EQUAL and OPPOSITE REACTION.     |
  |                                                                      |
  |  If A exerts a force on B, then B exerts an equal and opposite       |
  |  force on A.                                                         |
  |                                                                      |
  |        F(A on B)   =   -  F(B on A)                                  |
  +----------------------------------------------------------------------+
```

## Four facts about action-reaction pairs (each is worth a mark)

```
  1.  They are EQUAL in magnitude and OPPOSITE in direction.

  2.  They act on TWO DIFFERENT BODIES.
      *** THEREFORE THEY NEVER CANCEL EACH OTHER. ***

  3.  They act SIMULTANEOUSLY. There is no "first" force.

  4.  They are always of the SAME NATURE
      (both gravitational, or both contact forces).
```

## Why they never cancel — the picture

```
      HORSE                          CART
        |                              |
        v                              v

    +---------+                  +-----------+
    |  HORSE  |  --- F -------->  |   CART   |     force ON the cart
    |         |  <------- F ---   |          |     force ON the horse
    +---------+                  +-----------+

  These two arrows are on DIFFERENT boxes.
  To find what the CART does, you look ONLY inside the CART's box.
  Inside the cart's box there is only ONE of the two arrows.
  So it does NOT cancel, and the cart accelerates.
```

> **TRAP:** "If action and reaction are equal and opposite, how does anything
> ever move?" ANSWER: because they act on **different bodies**. Forces only
> cancel when they act on the **same** body.

## Examples to quote in the exam

```
  +------------------------------------+---------------------------------+
  |  ACTION                            |  REACTION                       |
  +------------------------------------+---------------------------------+
  |  A book presses DOWN on a table    |  the table pushes UP on the book|
  |  A swimmer pushes water BACKWARD   |  water pushes the swimmer FORWARD|
  |  We push the ground BACKWARD when  |  the ground pushes us FORWARD   |
  |  walking                           |                                 |
  |  A gun pushes the bullet FORWARD   |  the bullet pushes the gun BACK |
  |  Hot gases pushed DOWN by a rocket |  gases push the rocket UP       |
  |  Earth attracts an apple           |  the apple attracts the Earth   |
  +------------------------------------+---------------------------------+
```

> **TRAP:** The weight `mg` of a book and the normal reaction `N` from the table
> are **NOT** an action-reaction pair — they act on the **same body** (the book).
> The true reaction to `mg` is the pull of the book on the **Earth**.

# TOPIC 7 — Conservation of linear momentum

```
  +----------------------------------------------------------------------+
  |  If the NET EXTERNAL FORCE on a system is ZERO, the TOTAL LINEAR     |
  |  MOMENTUM of the system remains CONSTANT.                            |
  |                                                                      |
  |            m1 u1  +  m2 u2   =   m1 v1  +  m2 v2                     |
  |                                                                      |
  |            (before)              (after)                             |
  +----------------------------------------------------------------------+
```

## Derivation from the THIRD law (a very common 4-mark question)

```
  Two bodies A and B collide. During the collision they push each other.

        BEFORE                    DURING                   AFTER

   +----+      +----+       +----+  +----+           +----+     +----+
   | m1 |->u1  | m2 |->u2   | m1 |->| m2 |           | m1 |->v1 | m2 |->v2
   +----+      +----+       +----+  +----+           +----+     +----+
                             F12 -> <- F21


  STEP 1   By the THIRD law, during the collision

               F_12  =  -  F_21


  STEP 2   By the SECOND law, force = rate of change of momentum

              m1 v1 - m1 u1           m2 v2 - m2 u2
   F_21  =  -----------------   ,   ------------------  =  F_12
                    t                       t

           (F_21 acts on body 1 , F_12 acts on body 2)


  STEP 3   Substitute into  F_12 = - F_21 :

              m2 v2 - m2 u2             m1 v1 - m1 u1
             ---------------   =   -  -----------------
                    t                         t


  STEP 4   Cancel t and rearrange:

              m2 v2 - m2 u2  =  - m1 v1 + m1 u1


                 +-------------------------------------+
                 |                                     |
                 |   m1 u1 + m2 u2  =  m1 v1 + m2 v2   |
                 |                                     |
                 +-------------------------------------+

           TOTAL MOMENTUM BEFORE  =  TOTAL MOMENTUM AFTER
```

## Application 1 — Recoil of a gun

```
        BEFORE FIRING                       AFTER FIRING

   +-------------------+              +-------------------+
   |      GUN  M       |              |     GUN  M        |
   |   +------------+  |              |  <-- V            |   -->  v
   |   |  bullet m  |  |              |                     (o) bullet m
   +-------------------+              +-------------------+

        total p = 0                    M V  +  m v  =  0
```

```
  Initially both are at rest, so total momentum = 0.
  Nothing external pushes the system, so total momentum stays 0.

           M V  +  m v  =  0

                       m v
           V   =   -  -----
                        M

  The MINUS sign means the gun moves BACKWARD. That is the RECOIL.

  Because M is much bigger than m, V is much SMALLER than v.
  The gun crawls back; the bullet flies out.
```

```
  WHY A GUN IS HELD TIGHT AGAINST THE SHOULDER:
  the shoulder + body join the gun, so the recoiling mass M becomes huge,
  and the recoil velocity V becomes tiny.
```

## Application 2 — Rocket propulsion

```
             +---+
             |   |   <-- rocket of mass M moving UP with velocity V
             | R |
             |   |
             +---+
              | |
              vvv   burnt gases of mass m thrown DOWN with velocity v

  The rocket throws gas DOWNWARD (action).
  By the third law, the gas pushes the rocket UPWARD (reaction).

  Total momentum stays zero:      M V  =  m v

  This is the ONLY way to move in space, because there is nothing
  outside to push against.

  As fuel burns, M DECREASES, so the rocket's velocity keeps INCREASING.
```

## Application 3 — Explosion of a stationary bomb

```
                        BEFORE:  at rest, total p = 0

                              (BOMB)


                        AFTER:  fragments fly out

                         \      |      /
                          \     |     /
                           \    |    /
                            <-------->
                           /    |    \
                          /     |     \
                         /      |      \

  The VECTOR SUM of all the fragment momenta must still be ZERO.
  For two equal fragments, they fly in exactly opposite directions
  with equal speeds.
```

### Worked example

**Q. A gun of mass 3 kg fires a bullet of mass 30 g with a muzzle velocity of
100 m/s. Find the recoil velocity of the gun.**

```
  M = 3 kg      m = 30 g = 0.03 kg      v = 100 m/s

     M V  +  m v  =  0

              m v         0.03 x 100          3
     V  =  -  -----  =  -  -----------  =  - ---  =  - 1 m/s
                M              3              3

  The gun recoils at 1 m/s, opposite to the bullet.
```

# TOPIC 8 — Equilibrium of concurrent forces and Lami's theorem

## Equilibrium

```
  A body is in EQUILIBRIUM when the NET force on it is ZERO.

        F1  +  F2  +  F3  +  ...  =  0

  In components:      sum of F_x = 0       and       sum of F_y = 0

  STATIC equilibrium   ->  body stays at rest
  DYNAMIC equilibrium  ->  body moves with CONSTANT velocity
```

**Concurrent forces** = forces whose lines of action all pass through one point.

## Triangle law for three forces

```
  If three concurrent forces keep a body in equilibrium, they can be
  represented by the three sides of a triangle taken in ORDER.

                    F2
                 ------->
              /|         \
             / |          \
        F1  /  |           \  F3
           /   |            \
          v    |             v
```

## LAMI'S THEOREM

```
  +----------------------------------------------------------------------+
  |  If three CONCURRENT forces keep a body in equilibrium, each force   |
  |  is proportional to the SINE OF THE ANGLE BETWEEN THE OTHER TWO.     |
  +----------------------------------------------------------------------+
```

```
                          F1
                           ^
                            \
                     gamma   \      alpha
                              \
              <----------------O----------------->  F2
                              /  beta
                             /
                            /
                           v
                          F3

  alpha = angle between F2 and F3
  beta  = angle between F3 and F1
  gamma = angle between F1 and F2

         F1              F2              F3
     -----------  =  -----------  =  -----------
      sin(alpha)      sin(beta)      sin(gamma)

  NOTE: alpha + beta + gamma = 360 degrees
```

### Worked example — a hanging sign

**Q. A body of weight 20 N hangs from two strings which make angles of 30 deg
and 60 deg with the ceiling. Find the tensions.**

```
              CEILING
  ///////////////////////////////
      \                    /
   T1  \  30deg    60deg  /  T2
        \                /
         \              /
          \            /
           +----------+
           |   20 N   |
           +----------+
                |
                v  W = 20 N

  Angle between T1 and T2      =  180 - 30 - 60  =  90 deg
  Angle between T1 and W       =  180 - 30       =  150 deg  -> use 90+30=120
  Working with the standard result for perpendicular strings:

     T1  =  W cos(30)  =  20 x 0.866  =  17.3 N
     T2  =  W cos(60)  =  20 x 0.5    =  10   N

  CHECK:   sqrt( 17.3^2 + 10^2 )  =  sqrt( 299 + 100 )  =  20 N     CORRECT
```

# TOPIC 9 — Free body diagrams (the most important skill in Physics)

```
  +----------------------------------------------------------------------+
  |  A FREE BODY DIAGRAM (FBD) is a picture of ONE body alone,           |
  |  with EVERY force acting ON IT drawn as an arrow.                    |
  |                                                                      |
  |  Everything else in the problem is rubbed out.                       |
  +----------------------------------------------------------------------+
```

## The rules for drawing forces

```
  +--------------+------------------------------------------------------+
  |  FORCE       |  DIRECTION - NO EXCEPTIONS                           |
  +--------------+------------------------------------------------------+
  |  Weight  mg  |  Always straight DOWN, towards the Earth's centre.   |
  |  Normal  N   |  Always PERPENDICULAR to the surface, pushing the    |
  |              |  body AWAY from the surface. Never pulls.            |
  |  Tension T   |  Along the string, always PULLING the body TOWARDS   |
  |              |  the string. A string can never push.                |
  |  Friction f  |  Along the surface, OPPOSING relative sliding.       |
  |  Applied F   |  Wherever the question says.                         |
  +--------------+------------------------------------------------------+
```

## The systematic method (write these steps in the exam)

```
  1.  Choose ONE body.
  2.  Draw it as a simple box.
  3.  Draw ALL the forces on it (use the table above).
  4.  Choose x along the acceleration, y perpendicular to it.
  5.  Resolve every slanted force into x and y.
  6.  Along the motion:            sum of F  =  m a
      Perpendicular to the motion: sum of F  =  0
  7.  Repeat for the second body if there is one.
  8.  Solve the equations together.
```

> **TRAP:** Never draw a force "because the body is moving". Motion is not a
> force. There is no "forward force" on a coasting ball. Only draw a force if
> you can name what OBJECT is applying it.

# TOPIC 10 — System 1: a block on a horizontal table

## Case A — no applied force

```
              N
              ^
              |
        +-----------+
        |     m     |
        +-----------+
              |
              v  mg

  Vertical:   N  -  mg  =  0     ->     N  =  mg
  The block does not move.
```

## Case B — pushed horizontally on a SMOOTH table

```
              N
              ^
              |
        +-----------+
   F -->|     m     |  ---> a
        +-----------+
              |
              v  mg

  Horizontal:   F   =  m a       ->     a  =  F / m
  Vertical:     N   =  mg
```

## Case C — a force applied at an ANGLE theta above the horizontal

```
                        F sin(theta)
              N              ^      F
              ^               \     /
              |                \   /
              |                 \ /  theta
        +-----------------------+---------
        |          m            |  --> F cos(theta)
        +-----------------------+
              |
              v  mg

  Vertical:     N  +  F sin(theta)  -  mg  =  0

                N  =  mg  -  F sin(theta)      <-- N is REDUCED

  Horizontal:   F cos(theta)  -  f  =  m a
```

> **TRAP:** When the force is applied at an angle UPWARD, the normal reaction is
> `N = mg - F sin(theta)`, NOT `mg`. If the force is pushed DOWNWARD at an
> angle, `N = mg + F sin(theta)`. This changes friction, and changes the answer.

### Worked example

**Q. A 10 kg block on a smooth table is pulled by a 50 N force at 37 deg above
the horizontal. Find the normal reaction and the acceleration.
(sin 37 = 0.6, cos 37 = 0.8, g = 10 m/s^2)**

```
  N  =  mg  -  F sin(37)  =  (10)(10)  -  50(0.6)  =  100  -  30  =  70 N

       F cos(37)         50 (0.8)         40
  a =  ----------   =   ----------   =   ----   =   4 m/s^2
           m                10            10
```

# TOPIC 11 — System 2: two connected blocks pulled by a string

```
                        SMOOTH SURFACE

           T          T
    +-----+   ______   +-----+
    | m2  |==========  | m1  | <--- F
    +-----+            +-----+
   ////////////////////////////////

                <-------- a  (whole system moves together)
```

## Free body diagrams

```
   BLOCK m1  (the front one)          BLOCK m2  (the back one)

          N1                                 N2
          ^                                  ^
          |                                  |
     +---------+                        +---------+
  T<-|   m1    |<-- F                T ->|   m2    |
     +---------+                        +---------+
          |                                  |
          v m1 g                             v m2 g

  F  -  T  =  m1 a                     T  =  m2 a
```

## Solving

```
  STEP 1   Treat the WHOLE system as ONE body of mass (m1 + m2):

                       F
              a  =  ---------
                    m1 + m2


  STEP 2   Now look at the BACK block alone to find the tension:

                                 m2 F
              T  =  m2 a  =  -----------
                              m1 + m2


  +----------------------------------------------------------------+
  |                     F                          m2 F            |
  |         a  =  -----------          T  =   -------------        |
  |                m1 + m2                      m1 + m2            |
  +----------------------------------------------------------------+

  RULE OF THUMB:  the tension equals
      (the mass BEHIND the string)  x  (the acceleration)
```

> **TRAP:** The tension is NOT equal to F, and it is NOT F/2 unless the masses
> are equal. Always use the block on the FAR side of the string.

### Worked example

**Q. Blocks of 3 kg and 2 kg are joined by a light string on a smooth floor. A
force of 10 N pulls the 3 kg block. Find a and T.**

```
              10
   a  =  ---------  =  2 m/s^2
          3  +  2

   T  =  m2 a  =  2 x 2  =  4 N
              ^
      the block NOT being pulled directly
```

# TOPIC 12 — System 3: the pulley (Atwood machine)

Two masses hang over a frictionless, massless pulley. Assume `m1 > m2`.

```
                       _____
                      /     \
                     |   O   |   frictionless pulley
                      \_____/
                       |   |
                       |   |
                       |   |
                    +--+   +--+
                    |m1|   |m2|
                    +--+   +--+

              m1 goes DOWN , m2 goes UP , both with the same |a|
```

## Free body diagrams

```
      MASS m1 (heavier, goes DOWN)      MASS m2 (lighter, goes UP)

              T                                  T
              ^                                  ^
              |                                  |
          +-------+                          +-------+
          |  m1   |  |                       |  m2   |  ^
          +-------+  | a                     +-------+  | a
              |      v                           |
              v m1 g                             v m2 g

     m1 g  -  T  =  m1 a  .....(1)       T  -  m2 g  =  m2 a  .....(2)
```

## The derivation (this is the classic 8-mark question)

```
  ADD equations (1) and (2)  --  this kills T:

       m1 g  -  T  +  T  -  m2 g   =   m1 a  +  m2 a

       ( m1  -  m2 ) g   =   ( m1  +  m2 ) a


                    +---------------------------+
                    |                           |
                    |          ( m1 - m2 ) g    |
                    |    a  =  ---------------   |
                    |            m1 + m2        |
                    |                           |
                    +---------------------------+


  Now put a back into equation (2):     T  =  m2 ( g  +  a )

                             +-             -+
                             |   (m1 - m2) g |
       T  =  m2 g  +  m2  x  |  ------------ |
                             |    m1 + m2    |
                             +-             -+

            m2 g (m1 + m2)  +  m2 g (m1 - m2)
       =  --------------------------------------
                      m1  +  m2

            m1 m2 g  +  m2^2 g  +  m1 m2 g  -  m2^2 g
       =  ---------------------------------------------
                          m1  +  m2


                    +---------------------------+
                    |                           |
                    |            2 m1 m2 g      |
                    |     T  =  -------------   |
                    |             m1 + m2       |
                    |                           |
                    +---------------------------+
```

## The force on the pulley (a bonus 2-mark question)

```
                                   4 m1 m2 g
   Force on the pulley  =  2 T  =  -----------
                                    m1 + m2

   Note this is LESS than (m1 + m2) g, because the system is accelerating.
```

### Worked example

**Q. Masses of 5 kg and 3 kg hang over a smooth pulley. Find a and T.
(g = 10 m/s^2)**

```
         (5 - 3)(10)        20
   a  =  ------------  =  ------  =  2.5 m/s^2
            5 + 3            8


         2 (5)(3)(10)       300
   T  =  ------------  =  -------  =  37.5 N
             5 + 3           8

  CHECK:   T must lie BETWEEN m2 g = 30 N and m1 g = 50 N.
           37.5 N does.   CORRECT.
```

> **TRAP:** The tension is NOT `m1 g`, and NOT `(m1 + m2)g / 2`. And there is
> only ONE tension in a single string over a smooth, light pulley.

# TOPIC 13 — System 4: a body in a LIFT (apparent weight)

This is guaranteed in the exam. Memorise the four cases.

```
  APPARENT WEIGHT = the NORMAL REACTION from the floor = what a
                    weighing machine would show.
```

```
                 +---------------------+
                 |                     |
                 |        LIFT         |
                 |                     |
                 |         N ^         |
                 |           |         |
                 |      +---------+    |
                 |      |    m    |    |
                 |      +---------+    |
                 |           |         |
                 |           v  mg     |
                 |                     |
                 +---------------------+
                        ||     ||
```

## CASE 1 — lift at rest, or moving with CONSTANT velocity  (a = 0)

```
        N  -  mg  =  0

        N  =  mg           APPARENT WEIGHT = TRUE WEIGHT
```

## CASE 2 — lift accelerating UPWARD with acceleration a

```
                 N ^
                   |          a ^  (upward)
              +---------+
              |    m    |
              +---------+
                   |
                   v  mg

        N  -  mg  =  m a

        N  =  m ( g  +  a )        YOU FEEL HEAVIER
```

## CASE 3 — lift accelerating DOWNWARD with acceleration a

```
                 N ^
                   |
              +---------+
              |    m    |
              +---------+          a |  (downward)
                   |                 v
                   v  mg

        mg  -  N  =  m a

        N  =  m ( g  -  a )        YOU FEEL LIGHTER
```

## CASE 4 — the cable snaps: FREE FALL  (a = g)

```
        N  =  m ( g  -  g )  =  0

        APPARENT WEIGHT = ZERO.  This is WEIGHTLESSNESS.
        You float inside the lift. Your real weight has NOT changed.
```

## The master table — copy this into your answer sheet

```
  +----------------------------------+-------------------+--------------+
  |  MOTION OF THE LIFT              |  APPARENT WEIGHT  |  YOU FEEL    |
  +----------------------------------+-------------------+--------------+
  |  At rest                         |  N = m g          |  normal      |
  |  Constant velocity (up or down)  |  N = m g          |  normal      |
  |  Accelerating UPWARD    (a)      |  N = m (g + a)    |  HEAVIER     |
  |  Decelerating while going DOWN   |  N = m (g + a)    |  HEAVIER     |
  |  Accelerating DOWNWARD  (a)      |  N = m (g - a)    |  LIGHTER     |
  |  Decelerating while going UP     |  N = m (g - a)    |  LIGHTER     |
  |  FREE FALL   (a = g)             |  N = 0            |  WEIGHTLESS  |
  +----------------------------------+-------------------+--------------+
```

> **TRAP:** What matters is the direction of the **ACCELERATION**, not the
> direction of the **VELOCITY**. A lift moving DOWN but SLOWING DOWN has an
> UPWARD acceleration, so you feel HEAVIER.

### Worked example

**Q. A man of mass 60 kg stands in a lift. Find his apparent weight when the
lift (i) rises at 2 m/s^2 (ii) descends at 2 m/s^2 (iii) cable breaks.
(g = 10 m/s^2)**

```
  (i)    N  =  m (g + a)  =  60 (10 + 2)  =  60 x 12  =  720 N

  (ii)   N  =  m (g - a)  =  60 (10 - 2)  =  60 x 8   =  480 N

  (iii)  N  =  0 N       (free fall, weightlessness)

  True weight throughout  =  60 x 10  =  600 N
```

# TOPIC 14 — System 5: a block on an INCLINED plane

## The picture and the resolution

```
                                  N
                                  ^
                                  |
                            +-----+-----+
                           /|     m     |
                          / +-----------+
                         /       |    \
                        /        |     \  mg sin(theta)   (down the slope)
                       /         |      \
                      /          v       v
                     /       mg cos(theta)
                    /
                   /  theta                  mg acts straight DOWN
                  /_________________         and splits into TWO parts
```

```
  +----------------------------------------------------------------------+
  |  ALWAYS TILT YOUR AXES ALONG THE SLOPE.                              |
  |                                                                      |
  |  ALONG the slope (down)         :   mg sin(theta)                    |
  |  PERPENDICULAR to the slope     :   mg cos(theta)                    |
  |                                                                      |
  |  These two are at RIGHT ANGLES to each other.                        |
  +----------------------------------------------------------------------+
```

## Case A — SMOOTH incline (no friction)

```
  Perpendicular:   N  =  mg cos(theta)          (no motion this way)

  Along the slope: mg sin(theta)  =  m a


                 +--------------------------+
                 |                          |
                 |    a  =  g sin(theta)    |
                 |                          |
                 +--------------------------+

  NOTE: the acceleration does NOT depend on the mass.
        theta = 0  ->  a = 0        (flat ground, no motion)
        theta = 90 ->  a = g        (free fall)
```

Speed at the bottom of a smooth incline of length L:

```
  v^2  =  u^2  +  2 a L  =  0  +  2 (g sin theta) L

  v  =  sqrt( 2 g L sin(theta) )  =  sqrt( 2 g h )      where h = L sin(theta)
```

## Case B — ROUGH incline, block SLIDING DOWN

```
                                  N
                                  ^
                            +-----+-----+
                           /|     m     |
                          /_+-----------+
                         / ^      |
                        /  |      |         friction acts UP the slope
                       /   f      |         (it opposes sliding DOWN)
                      /           v
                     /       mg cos(theta)      and    mg sin(theta) down
                    /
                   /  theta
                  /_________________

  Perpendicular:   N  =  mg cos(theta)

  Friction:        f  =  mu N  =  mu mg cos(theta)

  Along the slope: mg sin(theta)  -  mu mg cos(theta)  =  m a


          +----------------------------------------------------+
          |  a  =  g ( sin(theta)  -  mu cos(theta) )          |
          +----------------------------------------------------+
```

## Case C — ROUGH incline, block pushed UP the slope

```
  Now friction acts DOWN the slope (it opposes the upward sliding):

  Retardation:

          +----------------------------------------------------+
          |  a  =  g ( sin(theta)  +  mu cos(theta) )          |
          +----------------------------------------------------+

  Going UP is HARDER: gravity AND friction both oppose you.
```

> **TRAP:** Friction always **flips direction** when the motion flips. The sign
> in front of `mu cos(theta)` is MINUS going down and PLUS going up. Get this
> wrong and you lose the whole numerical.

### Worked example

**Q. A 4 kg block slides down a 30 deg incline with mu = 0.2.
Find the acceleration. (g = 10 m/s^2, cos 30 = 0.866)**

```
  a  =  g ( sin 30  -  0.2 cos 30 )

     =  10 ( 0.5  -  0.2 x 0.866 )

     =  10 ( 0.5  -  0.173 )

     =  10 x 0.327

     =  3.27 m/s^2      down the slope
```

# TOPIC 15 — FRICTION

**Friction** is the force that opposes relative motion (or attempted motion)
between two surfaces in contact. It acts **along** the surfaces.

## Why friction exists

```
  No surface is truly smooth. Under a microscope:

     ___/\____/\_____/\___/\____    body
        \/    \/     \/   \/
        /\    /\     /\   /\
     ___\/____\/_____\/___\/____    ground

  The hills and valleys interlock. Sliding means breaking these tiny
  cold-welded joints, and that needs force.
```

## The three kinds of friction

```
  +---------------------+-------------------------------------------------+
  |  1. STATIC          |  Acts when the body is NOT YET moving.          |
  |     f_s             |  It is SELF-ADJUSTING: it exactly matches       |
  |                     |  whatever force you apply, up to a maximum.     |
  |                     |         f_s  <=  mu_s N                         |
  +---------------------+-------------------------------------------------+
  |  2. LIMITING        |  The MAXIMUM static friction, just before the   |
  |     f_L             |  body starts to move.                           |
  |                     |         f_L  =  mu_s N                          |
  +---------------------+-------------------------------------------------+
  |  3. KINETIC         |  Acts once the body IS sliding. It is CONSTANT  |
  |     (dynamic)  f_k  |  and does NOT depend on the speed.              |
  |                     |         f_k  =  mu_k N                          |
  |                     |  ALWAYS  f_k  <  f_L                            |
  +---------------------+-------------------------------------------------+
```

## Why static friction is SELF-ADJUSTING

```
  Push a heavy almirah gently. It does not move. Why?
  Because friction pushed back with EXACTLY the same force.

  Push harder. Still does not move. Friction grew to match you again.

  Push harder still. At some point it moves.
  You have beaten the LIMITING value.

  +----------------------------------------------------------------+
  |  Static friction is NOT a fixed number.                        |
  |  It equals the applied force, until it reaches its MAXIMUM.    |
  +----------------------------------------------------------------+
```

## The friction graph (draw this in the exam)

```
   Friction
   force f
      ^
      |                f_L
      |                 *
      |               / |
      |             /   |
      |           /     +-----------------------  f_k (constant)
      |         /       |
      |       /         |
      |     /  f_s = F  |     body is SLIDING
      |   /   (45 deg   |
      | /      line)    |
      +-----------------+-------------------------> applied force F
      0                 |
             STATIC     |     KINETIC
             REGION     |     REGION
                     the body
                     starts to move here

  Note the SUDDEN DROP from f_L to f_k. That is why a heavy box is hard to
  START pushing, but easier to KEEP pushing.
```

## The laws of friction (4-mark question)

```
  LAWS OF STATIC / LIMITING FRICTION

  1.  Friction always OPPOSES the relative motion (or attempted motion).
  2.  It acts TANGENTIALLY, along the surfaces in contact.
  3.  Limiting friction is DIRECTLY PROPORTIONAL to the normal reaction:
                  f_L  =  mu_s N
  4.  It is INDEPENDENT of the AREA of contact (as long as N is the same).
  5.  It DEPENDS on the NATURE and ROUGHNESS of the two surfaces.

  LAWS OF KINETIC FRICTION

  1.  f_k  =  mu_k N
  2.  It is INDEPENDENT of the SPEED of the body (over normal speeds).
  3.  It is INDEPENDENT of the area of contact.
  4.  It is always LESS than the limiting friction:   mu_k  <  mu_s
```

> **TRAP:** Friction does NOT depend on the area of contact. Students answer
> "a bigger area means more friction". It is wrong, and it is asked every year.

## Coefficient of friction

```
                 friction force            f
        mu  =  --------------------  =  -------
                normal reaction            N

  DIMENSIONLESS (a ratio of two forces).  Has NO UNIT.
  Depends only on the NATURE of the two surfaces.
  Usual values: 0 (ideal smooth)  to  about 1.
```

## Angle of friction (theta_f)

```
  The angle between the NORMAL REACTION and the RESULTANT of the normal
  reaction and the limiting friction.

              R (resultant)
                  \      N
                   \     ^
                    \    |
                     \   |
                      \  |
              theta_f  \ |
                        \|
        <---------------- +----------------
                     f_L        surface


                                 f_L        mu N
        tan( theta_f )   =     -------  =  ------   =   mu
                                  N           N

                 +-----------------------------+
                 |    mu  =  tan( theta_f )    |
                 +-----------------------------+
```

## Angle of repose (theta_r)

```
  The MINIMUM angle of an inclined plane at which a body placed on it
  JUST BEGINS TO SLIDE DOWN on its own.

                            N
                            ^
                      +-----+-----+
                     /|     m     |
                    /_+-----------+
                   / ^      |
                  /  f_L    |
                 /          v mg cos(theta_r)
                /     and mg sin(theta_r) down the slope
               /
              /  theta_r
             /_________________

  At the point of "just sliding":

       ALONG the slope:          mg sin(theta_r)  =  f_L  =  mu N
       PERPENDICULAR:            N  =  mg cos(theta_r)

  Substitute N:

       mg sin(theta_r)   =   mu  x  mg cos(theta_r)

           sin(theta_r)
          --------------   =   mu
           cos(theta_r)

                 +-----------------------------+
                 |    mu  =  tan( theta_r )    |
                 +-----------------------------+
```

## THE KEY RESULT

```
  +----------------------------------------------------------------------+
  |                                                                      |
  |     ANGLE OF FRICTION   =   ANGLE OF REPOSE                          |
  |                                                                      |
  |          theta_f   =   theta_r                                       |
  |                                                                      |
  |     because BOTH are equal to  arctan( mu ).                         |
  |                                                                      |
  +----------------------------------------------------------------------+
```

## Rolling friction

```
  When a body ROLLS instead of sliding, the opposition is called
  ROLLING FRICTION.

        SLIDING                          ROLLING
     +-----------+                          ___
     |   BOX     |                        /     \
     +-----------+                       |   O   |
   ///////////////                        \ ___ /
   large contact,                      //////////////
   many joints to break               a point touches at a time,
                                      the surface is not "torn"

  ROLLING FRICTION  <<  SLIDING FRICTION

  Reason: in rolling, the surfaces do not slide over each other. Contact is
  momentary and at almost a point, so far fewer joints must be broken.

  THIS IS WHY WE INVENTED THE WHEEL, and why ball bearings are used.
```

## Advantages of friction

```
  1.  We can WALK. (Without friction our feet would slip.)
  2.  Vehicles can move and can BRAKE.
  3.  Nails, screws and knots hold.
  4.  We can HOLD objects in our hands.
  5.  Belts can drive machinery.
  6.  Writing with a pen or chalk is possible.
```

## Disadvantages of friction

```
  1.  WEAR AND TEAR of machine parts, tyres and shoe soles.
  2.  Loss of ENERGY as HEAT  ->  reduced efficiency of machines.
  3.  Machines get hot and can seize.
  4.  Extra fuel is needed to overcome it.
```

## Methods of reducing friction

```
  1.  POLISHING the surfaces (removes the microscopic hills).
  2.  LUBRICATION with oil or grease (a fluid layer separates the surfaces).
  3.  Using BALL BEARINGS / ROLLER BEARINGS (turns sliding into rolling).
  4.  STREAMLINING the shape of cars, aeroplanes and ships (reduces the
      friction of air and water).
  5.  Using an AIR CUSHION (as in a hovercraft) or an air-jet layer.
  6.  Using ALLOYS with low friction for bearing surfaces.
```

> **TRAP:** Do NOT say "friction should be removed completely". Without friction
> you could not walk, drive or hold anything. It is a **necessary evil**.

### Worked example

**Q. A 10 kg block on a horizontal floor just begins to move when a horizontal
force of 25 N is applied. Find mu_s and the angle of repose.
(g = 10 m/s^2)**

```
  N  =  mg  =  10 x 10  =  100 N

  At "just begins to move",  f_L  =  25 N

          f_L        25
  mu_s = -----  =  -----  =  0.25
           N        100

  Angle of repose:  theta_r  =  arctan( 0.25 )  =  about 14 degrees
```

# TOPIC 16 — Motion on a rough inclined plane, the full treatment

## Summary of every case

```
  +--------------------------------+-------------------------------------+
  |  SITUATION                     |  RESULT                             |
  +--------------------------------+-------------------------------------+
  |  Smooth incline                |  a  =  g sin(theta)                 |
  |                                |  N  =  mg cos(theta)                |
  +--------------------------------+-------------------------------------+
  |  Rough, sliding DOWN           |  a = g(sin(theta) - mu cos(theta))  |
  |                                |  friction acts UP the slope         |
  +--------------------------------+-------------------------------------+
  |  Rough, moving UP              |  a = g(sin(theta) + mu cos(theta))  |
  |  (retardation)                 |  friction acts DOWN the slope       |
  +--------------------------------+-------------------------------------+
  |  Body on the VERGE of sliding  |  mu  =  tan(theta)                  |
  |  (angle of repose)             |                                     |
  +--------------------------------+-------------------------------------+
  |  theta LESS than the angle of  |  body stays at rest; friction is    |
  |  repose                        |  STATIC and equals mg sin(theta)    |
  +--------------------------------+-------------------------------------+
```

## Minimum force to push a body UP a rough incline at constant speed

```
  At constant speed, a = 0, so the applied force must beat BOTH
  gravity and friction:

        F  =  mg sin(theta)  +  mu mg cos(theta)

        F  =  mg ( sin(theta)  +  mu cos(theta) )
```

> **TRAP:** If `theta` is less than the angle of repose, the block does **not**
> move at all, and the friction is whatever is needed to hold it —
> `f = mg sin(theta)` — **NOT** `mu mg cos(theta)`. Only use `mu N` when the
> body is sliding or is on the verge of sliding.

### Worked example

**Q. A block is placed on a rough incline. It just starts to slide when the
angle is 30 deg. If the incline is raised to 45 deg, find the acceleration.
(g = 10 m/s^2)**

```
  STEP 1   At the angle of repose:   mu = tan(30) = 0.577

  STEP 2   At 45 deg:

     a  =  g ( sin 45  -  mu cos 45 )

        =  10 ( 0.707  -  0.577 x 0.707 )

        =  10 x 0.707 ( 1  -  0.577 )

        =  7.07 x 0.423

        =  2.99  which is about  3 m/s^2
```

# TOPIC 17 — Circular motion and centripetal force

## Why a force is needed to go round a circle

```
  Even at CONSTANT SPEED, going in a circle means the DIRECTION of the
  velocity keeps changing.

  Changing velocity = acceleration = a force is needed.

                     v
                     ^
                     |
              . . . .+. . . .
           .         |         .
         .           |           .
        .        <---O            .    the acceleration always points
        .        a   |            .    towards the CENTRE
         .           |           .
           .         |         .
              . . . .|. . . .
```

```
  +----------------------------------------------------------------------+
  |  CENTRIPETAL FORCE:  the force that acts towards the CENTRE and      |
  |  keeps a body moving in a circle.                                    |
  |                                                                      |
  |                    m v^2                                             |
  |            F   =  -------   =   m  r  omega^2                        |
  |                      r                                               |
  |                                                                      |
  |  It CHANGES the DIRECTION of the velocity, never its magnitude.      |
  |  It does NO WORK (it is always perpendicular to the motion).         |
  +----------------------------------------------------------------------+
```

**"Centripetal force" is a JOB, not a new kind of force.** Something real always
does that job:

```
  +-------------------------------+-----------------------------------+
  |  SITUATION                    |  WHAT PROVIDES THE CENTRIPETAL    |
  |                               |  FORCE                            |
  +-------------------------------+-----------------------------------+
  |  Stone whirled on a string    |  the TENSION in the string        |
  |  Car turning on a level road  |  FRICTION between tyres and road  |
  |  Car on a banked road         |  component of the NORMAL REACTION |
  |  Earth going round the Sun    |  GRAVITATIONAL attraction         |
  |  Electron round a nucleus     |  ELECTROSTATIC attraction         |
  +-------------------------------+-----------------------------------+
```

> **TRAP:** "Centrifugal force" (outward) is NOT a real force. It is a
> *pseudo force* felt only by an observer sitting inside the rotating frame.
> In the exam, always work with the **centripetal** (inward) force.

## Case A — a car on a LEVEL road

```
                              N
                              ^
                              |
                     +------------------+
                     |       CAR        |
                     +--O----------O----+
                        |          |
             f <--------+----------+    friction acts towards the CENTRE
                        |
                        v  mg

  Vertical:      N  =  mg

  The ONLY horizontal force is FRICTION, and it must supply the
  centripetal force:

                   m v^2
             f  =  -------      but      f  <=  mu N  =  mu mg
                      r

                   m v^2
                  -------   <=   mu m g
                      r

                     v^2   <=   mu g r


            +--------------------------------------+
            |                                      |
            |    v_max  =  sqrt( mu  g  r )        |
            |                                      |
            +--------------------------------------+

  NOTE: the maximum safe speed does NOT depend on the mass of the car.
        On a wet road mu falls, so v_max falls. That is why you skid.
```

## Case B — a car on a BANKED road (no friction)

The road is tilted inward by an angle `theta`. Now a component of the NORMAL
REACTION does the job, and friction is not needed at all.

```
                                     N
                                      \
                        N cos(theta)   \
                              ^         \
                              |          \
                              |           \
                        +-----+------------\
                        |       CAR         \
                        +--O-----------O-----\
                       /       |              \
                      /        v  mg           \
                     /                          \
                    /  theta                     \
                   /_______________________________\
                      (the road surface is tilted)

              N sin(theta)  points HORIZONTALLY, towards the centre
```

```
  VERTICAL (no vertical acceleration):

        N cos(theta)   =   mg                        .....(1)


  HORIZONTAL (this supplies the centripetal force):

                          m v^2
        N sin(theta)  =  --------                    .....(2)
                            r


  DIVIDE (2) by (1):

         N sin(theta)        m v^2  /  r
        --------------  =  ----------------
         N cos(theta)            m g


            +-------------------------------------+
            |                                     |
            |                     v^2             |
            |    tan(theta)  =  --------          |
            |                     r g             |
            |                                     |
            +-------------------------------------+


  OPTIMUM (safe) SPEED on a frictionless banked road:

        v  =  sqrt( r g tan(theta) )
```

```
  NOTES worth a mark each:
    - The banking angle does NOT depend on the mass of the vehicle.
    - At exactly this speed, NO friction is needed at all.
    - This is why race tracks and railway curves are banked.
    - For railways, the outer rail is raised. The raising is called
      SUPERELEVATION or CANT.
```

## Case C — a banked road WITH friction (the maximum speed)

```
  Friction now also helps, acting DOWN the slope when the car tends
  to slide OUTWARD.

           +----------------------------------------------------+
           |                                                    |
           |                   +-                        -+     |
           |                   |  mu  +  tan(theta)       |     |
           |  v_max = sqrt  rg | ----------------------   |     |
           |                   |  1  -  mu tan(theta)     |     |
           |                   +-                        -+     |
           +----------------------------------------------------+

  And the MINIMUM speed below which the car slides INWARD:

                            +-                        -+
                            |  tan(theta)  -  mu       |
           v_min = sqrt  rg | ----------------------   |
                            |  1  +  mu tan(theta)     |
                            +-                        -+

  CHECK:  put theta = 0  ->  v_max = sqrt( mu g r )   = the level road.
          put mu = 0     ->  v_max = sqrt( rg tan th) = the ideal banking.
```

## Case D — bending of a cyclist

A cyclist must LEAN INWARD while turning. The lean provides the centripetal
force.

```
                              R (reaction from the ground)
                                \
                     R cos(th)   \
                          ^       \  o   <- cyclist leaning in
                          |        \/|\
                          |        /\ \
                          |          /\
              <-----------+---------(  )
              R sin(th)   |
                          v  mg
              //////////////////////////  road
                        theta = angle of lean from the vertical


  VERTICAL:        R cos(theta)  =  mg

                                     m v^2
  HORIZONTAL:      R sin(theta)  =  --------
                                       r


  Dividing:
                        +-----------------------------+
                        |                    v^2      |
                        |   tan(theta)  =  --------   |
                        |                    r g      |
                        +-----------------------------+

  Exactly the SAME formula as the banked road.

  The FASTER he goes, or the SHARPER the turn, the MORE he must lean.
  Also, for safety we need  tan(theta) <= mu, so  v <= sqrt(mu g r).
```

### Worked example

**Q. A curve of radius 50 m is banked at 15 deg. Find the optimum speed.
(g = 10 m/s^2, tan 15 = 0.268)**

```
  v  =  sqrt( r g tan(theta) )

     =  sqrt( 50 x 10 x 0.268 )

     =  sqrt( 134 )

     =  11.6 m/s      (about 42 km/h)
```

### Worked example

**Q. What is the maximum speed at which a car can take a turn of radius 100 m
on a level road with mu = 0.4? (g = 10 m/s^2)**

```
  v_max  =  sqrt( mu g r )

         =  sqrt( 0.4 x 10 x 100 )

         =  sqrt( 400 )

         =  20 m/s      (72 km/h)
```
