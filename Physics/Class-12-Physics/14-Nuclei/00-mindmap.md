## THE 60-SECOND VERSION

```
  1.  A nucleus = protons + neutrons, packed into a ball of radius
      R = 1.2 x A^(1/3) fermi.  Because volume grows exactly like A,
      the DENSITY of every nucleus is the SAME: 2.3 x 10^17 kg/m^3.

  2.  Weigh the nucleus. It weighs LESS than its parts.
      The missing mass (MASS DEFECT) turned into the glue
      (BINDING ENERGY) by  E = m c^2.   1 u = 931.5 MeV.

  3.  Binding energy per nucleon is about 8.8 MeV at A = 56 (iron),
      and smaller at both ends. So:
          light nuclei joining   -> climb the curve -> FUSION gives energy
          heavy nuclei splitting -> climb the curve -> FISSION gives energy

  4.  Unstable nuclei throw out alpha, beta or gamma, and the number left
      falls exponentially:   N = N0 e^(-lambda t)
```

If you understand only these four lines you can still write half the chapter.

## THE KEY BOX — the formulas that unlock most of the paper

```
  +------------------------------------------------------------------+
  |                                                                  |
  |   SIZE          R  =  R0 A^(1/3)          R0 = 1.2 fermi         |
  |                                                                  |
  |   ENERGY        E  =  m c^2               1 u = 931.5 MeV        |
  |                                                                  |
  |   MASS DEFECT   dm =  [ Z mp + (A - Z) mn ]  -  M                |
  |                                                                  |
  |   BINDING       BE =  dm x 931.5   MeV                           |
  |   ENERGY                                                         |
  |                                                                  |
  |   DECAY LAW     N  =  N0 e^(-lambda t)                           |
  |                                                                  |
  |   HALF LIFE     T  =  0.693 / lambda                             |
  |                                                                  |
  |   MEAN LIFE     tau = 1 / lambda  =  T / 0.693  =  1.44 T        |
  |                                                                  |
  |   ACTIVITY      R  =  lambda N                                   |
  |                                                                  |
  +------------------------------------------------------------------+

  If you write ONLY these nine lines on your palm you can attempt
  every numerical in this chapter.
```
