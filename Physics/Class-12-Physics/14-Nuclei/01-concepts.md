# TOPIC 1 — WHAT IS INSIDE A NUCLEUS

## 1.1 The picture

An atom is almost entirely empty space. All of its **mass** sits in a tiny lump at
the centre called the **nucleus**, and the electrons fly around it far away.

```
       ATOM  (radius about 10^-10 m)
       ..............................................
      .                                              .
     .        e-                              e-      .
    .                                                  .
    .                      (o)  <-- NUCLEUS             .
    .                   radius about 10^-15 m           .
     .                                                 .
      .       e-                             e-       .
       ..............................................

   The nucleus is 10^-15 m, the atom is 10^-10 m.
   Ratio = 10^-5.  The nucleus is 100000 times smaller than the atom.

   REAL-LIFE SCALE:  if the atom were a cricket STADIUM,
                     the nucleus would be a single GRAIN OF RICE
                     at the centre spot.
```

## 1.2 The two residents

The nucleus contains only two kinds of particle, together called **nucleons**.

| Particle | Symbol | Charge | Mass (u) | Mass (kg) |
|---|---|---|---|---|
| Proton | p or 1H^1 | +1.6 x 10^-19 C | 1.007276 | 1.6726 x 10^-27 |
| Neutron | n or 0n^1 | zero | 1.008665 | 1.6749 x 10^-27 |
| (Electron, outside) | e- | -1.6 x 10^-19 C | 0.000549 | 9.1 x 10^-31 |

```
  A neutron is very slightly HEAVIER than a proton.
  An electron is about 1836 times LIGHTER than a proton.
  So:   mass of atom  =  mass of nucleus  (near enough always)
```

The neutron was discovered by **James Chadwick** in 1932. Before that nobody could
explain why a helium atom weighs 4 units but carries only 2 units of charge.

## 1.3 The three numbers you must be able to read off a symbol

```
                  A
                   X
                  Z

   Z  =  ATOMIC NUMBER   =  number of PROTONS
                         =  number of electrons in a neutral atom
                         =  decides WHICH ELEMENT it is

   A  =  MASS NUMBER     =  number of protons + number of neutrons
                         =  total number of NUCLEONS
                         =  always a WHOLE NUMBER

   N  =  A - Z           =  number of NEUTRONS
```

Written in the AP textbook style, the symbol is **zX^A**, for example **92U^235**.

```
  EXAMPLES

  6C^12     Z = 6    A = 12   N = 12 - 6  = 6      carbon-12
  92U^235   Z = 92   A = 235  N = 235-92  = 143    uranium-235
  11Na^23   Z = 11   A = 23   N = 23 - 11 = 12     sodium-23
  1H^1      Z = 1    A = 1    N = 0        <-- the only nucleus with NO neutron
```

> **TRAP:** Z is written at the **bottom-left**, A at the **top-right**. Students who
> swap them lose the whole question. Memory hook: **A is on top because A is Above,
> and A is the bigger number.**

## 1.4 Isotopes, isobars, isotones — the classic 2-mark question

```
  +-----------+-------------------------+------------------------------------+
  |  NAME     |  WHAT IS THE SAME       |  EXAMPLES                          |
  +-----------+-------------------------+------------------------------------+
  |           |                         |                                    |
  | ISOTOPES  |  same Z (same element)  |  1H^1 , 1H^2 , 1H^3                |
  |           |  different A            |  6C^12 , 6C^13 , 6C^14             |
  |           |  different N            |  17Cl^35 , 17Cl^37                 |
  |           |                         |  8O^16 , 8O^17 , 8O^18             |
  |           |  SAME chemistry,        |                                    |
  |           |  different mass         |                                    |
  +-----------+-------------------------+------------------------------------+
  |           |                         |                                    |
  | ISOBARS   |  same A                 |  1H^3  and  2He^3                  |
  |           |  different Z            |  18Ar^40 and 20Ca^40               |
  |           |  different N            |  6C^14  and  7N^14                 |
  |           |                         |                                    |
  |           |  DIFFERENT elements,    |                                    |
  |           |  same mass number       |                                    |
  +-----------+-------------------------+------------------------------------+
  |           |                         |                                    |
  | ISOTONES  |  same N                 |  1H^3 (N=2)  and  2He^4 (N=2)      |
  |           |  different Z            |  6C^14 (N=8) and  8O^16 (N=8)      |
  |           |  different A            |  19K^39(N=20) and 20Ca^40(N=20)    |
  |           |                         |                                    |
  +-----------+-------------------------+------------------------------------+
  |           |                         |                                    |
  | ISOMERS   |  same Z AND same A,     |  Co^60 and Co^60m                  |
  |           |  different ENERGY state |  (m = metastable, excited)         |
  |           |                         |                                    |
  +-----------+-------------------------+------------------------------------+
```

**Memory trick that never fails:**

```
  isoTOPes   ->  P for PROTON is same     (Z same)
  isoBARs    ->  A for mAss is same       (A same)  ["bar" of the same weight]
  isoTONes   ->  N for NEUTRON is same    (N same)
```

## 1.5 Why atomic masses are not whole numbers

Chlorine's atomic mass is 35.5 u. There is no nucleus weighing 35.5 u. What exists is
75% of 17Cl^35 and 25% of 17Cl^37.

```
  Average  =  (75 x 35  +  25 x 37) / 100
           =  (2625  +  925) / 100
           =  3550 / 100
           =  35.5 u
```

**WORKED EXAMPLE 1.1**
Neon has two isotopes, 10Ne^20 (mass 19.99 u) and 10Ne^22 (mass 21.99 u), present in
the ratio 90.5 : 9.5. Find the average atomic mass.

```
  STEP 1   Average = (percentage1 x m1  +  percentage2 x m2) / 100

  STEP 2   =  (90.5 x 19.99  +  9.5 x 21.99) / 100

  STEP 3   90.5 x 19.99  =  1809.095
            9.5 x 21.99  =   208.905
                            ----------
                sum      =  2018.000

  STEP 4   Average  =  2018.000 / 100  =  20.18 u

  ANSWER:  20.18 u
```

# TOPIC 2 — THE SIZE OF THE NUCLEUS

## 2.1 How we know

**Rutherford's alpha-scattering experiment** fired alpha particles at a gold foil.
A few bounced almost straight back. From how close an alpha could get before being
turned around, the nucleus was shown to be smaller than about 10^-14 m.

Later, fast **electron scattering** measured nuclear radii accurately for many elements.
The result was beautifully simple.

## 2.2 The formula

```
  +------------------------------------------------------------+
  |                                                            |
  |             R  =  R0  x  A^(1/3)                           |
  |                                                            |
  |    R   =  radius of the nucleus                            |
  |    A   =  mass number  (number of nucleons)                |
  |    R0  =  1.2 x 10^-15 m  =  1.2 fermi  =  1.2 fm          |
  |                                                            |
  |    1 fermi (fm)  =  10^-15 metre                           |
  |                                                            |
  +------------------------------------------------------------+
```

## 2.3 What the formula is really saying

Cube both sides:

```
      R^3  =  R0^3  x  A

  Volume of the nucleus  V  =  (4/3) pi R^3
                            =  (4/3) pi R0^3 A

      So       V  is PROPORTIONAL to  A
```

```
   PLAIN ENGLISH:  every extra nucleon takes up the SAME amount of room.

   It is exactly like packing MARBLES in a bag.
   Twice the marbles  ->  twice the volume.
   The marbles do not squeeze into each other.

   This is called the SATURATION of nuclear forces (Topic 6).
```

## 2.4 THE BIG CONCLUSION — nuclear density is the same for all nuclei

This is a favourite 2-mark and a compulsory part of many 4-mark answers.

```
                 mass of nucleus        A x m
   density  =  -------------------  =  ---------------------
               volume of nucleus       (4/3) pi R0^3 A

   The A on top and the A at the bottom CANCEL.

   +---------------------------------------------------------+
   |                                                         |
   |                      m                                  |
   |     rho  =  --------------------      NO  A  IN  IT     |
   |              (4/3) pi R0^3                              |
   |                                                         |
   +---------------------------------------------------------+
```

Now put the numbers in. Take the average mass of one nucleon
m = 1.66 x 10^-27 kg and R0 = 1.2 x 10^-15 m.

```
  STEP 1   R0^3  =  (1.2 x 10^-15)^3
                 =  1.728 x 10^-45  m^3

  STEP 2   (4/3) pi R0^3  =  4.1888 x 1.728 x 10^-45
                          =  7.238 x 10^-45  m^3
           (this is the volume "owned" by ONE nucleon)

  STEP 3   rho  =  1.66 x 10^-27  /  7.238 x 10^-45

  STEP 4   rho  =  2.29 x 10^17  kg / m^3

           +--------------------------------------------+
           |   NUCLEAR DENSITY = 2.3 x 10^17 kg/m^3     |
           |   SAME for EVERY nucleus, light or heavy   |
           +--------------------------------------------+
```

```
  HOW BIG IS THAT?

     water          1 x 10^3    kg/m^3
     nucleus        2.3 x 10^17 kg/m^3

     ratio = 2.3 x 10^14

  A matchbox (about 1 cm^3 = 10^-6 m^3) filled with nuclear matter
  would weigh  2.3 x 10^17 x 10^-6 = 2.3 x 10^11 kg
  = about 230 million tonnes.  A NEUTRON STAR is made of exactly this stuff.
```

**WORKED EXAMPLE 2.1**
Find the radius of the aluminium nucleus 13Al^27.

```
  STEP 1   R = R0 A^(1/3),   R0 = 1.2 fm,  A = 27
  STEP 2   A^(1/3) = 27^(1/3) = 3     (because 3 x 3 x 3 = 27)
  STEP 3   R = 1.2 x 3 = 3.6 fm

  ANSWER:  R = 3.6 fermi = 3.6 x 10^-15 m
```

**WORKED EXAMPLE 2.2**
The radius of 8O^16 is 3.0 fm. Find the radius of 82Pb^205 (approximately).

```
  STEP 1   R1 / R2  =  (A1 / A2)^(1/3)

  STEP 2   R_Pb  =  R_O  x  (205 / 16)^(1/3)
                 =  3.0  x  (12.81)^(1/3)

  STEP 3   12.81^(1/3):   2^3 = 8,  2.3^3 = 12.17,  2.34^3 = 12.81
           So  (12.81)^(1/3)  =  2.34

  STEP 4   R_Pb  =  3.0 x 2.34  =  7.02 fm

  ANSWER:  about 7.0 fermi
```

**WORKED EXAMPLE 2.3**
Two nuclei have mass numbers in the ratio 1 : 8. What is the ratio of their radii?

```
  R1 / R2  =  (A1/A2)^(1/3)  =  (1/8)^(1/3)  =  1/2

  ANSWER:  1 : 2
```

> **TRAP:** The cube root, not the number itself. If A becomes 8 times bigger,
> R becomes only **2** times bigger, and the VOLUME becomes 8 times bigger.
> Handy cubes to memorise: 2^3=8, 3^3=27, 4^3=64, 5^3=125, 6^3=216, 7^3=343.

# TOPIC 3 — MASS AND ENERGY ARE THE SAME THING

## 3.1 The atomic mass unit (u or amu)

Kilograms are far too big for nuclei, so we define our own unit.

```
  +---------------------------------------------------------------+
  |                                                               |
  |   1 atomic mass unit (1 u)                                    |
  |         =  1/12 of the mass of ONE neutral carbon-12 atom     |
  |                                                               |
  |         =  1.660539 x 10^-27 kg     (use 1.66 x 10^-27 kg)    |
  |                                                               |
  +---------------------------------------------------------------+
```

Why carbon-12? Because it is common, easy to purify and its mass is defined
to be **exactly** 12.000000 u. Everything else is measured against it.

## 3.2 Einstein's mass-energy relation

```
  +---------------------------------------------------+
  |                                                   |
  |                 E  =  m c^2                       |
  |                                                   |
  |   E = energy in joule                             |
  |   m = mass in kilogram                            |
  |   c = 3 x 10^8 m/s (speed of light in vacuum)     |
  |                                                   |
  +---------------------------------------------------+
```

Mass is not "stuff" and energy is not "activity". They are two names for the same
thing, and c^2 is only the exchange rate — a huge one (9 x 10^16), which is why a
speck of mass buys an enormous amount of energy.

## 3.3 The conversion you will use 50 times: 1 u = 931.5 MeV

```
  STEP 1   Take m = 1 u = 1.66 x 10^-27 kg

  STEP 2   E = m c^2
             = 1.66 x 10^-27  x  (3 x 10^8)^2
             = 1.66 x 10^-27  x  9 x 10^16
             = 14.94 x 10^-11
             = 1.494 x 10^-10  joule

  STEP 3   Convert joule to electron volt.
           1 eV = 1.6 x 10^-19 J

           E  =  1.494 x 10^-10  /  1.6 x 10^-19
              =  0.934 x 10^9  eV
              =  9.34 x 10^8  eV
              =  934  MeV       (with rounded c; exact value 931.5 MeV)

  +----------------------------------------------------------+
  |                                                          |
  |     1 u  =  931.5  MeV / c^2      i.e.  1 u  "is worth"  |
  |                                          931.5 MeV       |
  |                                                          |
  |     So:   ENERGY in MeV  =  (mass defect in u) x 931.5   |
  |                                                          |
  +----------------------------------------------------------+
```

```
  USEFUL SIDE FACTS
     1 MeV                =  1.6 x 10^-13 J
     1 eV                 =  1.6 x 10^-19 J
     mass of electron     =  0.511 MeV/c^2
     mass of proton       =  938.3 MeV/c^2
     mass of neutron      =  939.6 MeV/c^2
```

**WORKED EXAMPLE 3.1**
Find the energy equivalent of 1 gram of matter.

```
  STEP 1   m = 1 g = 10^-3 kg
  STEP 2   E = m c^2 = 10^-3 x (3 x 10^8)^2
  STEP 3     = 10^-3 x 9 x 10^16
  STEP 4     = 9 x 10^13 J

  ANSWER:  9 x 10^13 joule.
  (Enough to run a 100 W bulb for about 28 000 years.)
```

> **TRAP:** In `E = mc^2` the mass MUST be in kilograms if you want joules.
> If the mass is in **u**, do NOT use c^2 — just multiply by **931.5** to get MeV.
> Mixing the two routes is the single commonest arithmetic disaster in this chapter.

# TOPIC 4 — MASS DEFECT

## 4.1 The astonishing fact

Take a helium nucleus apart into 2 protons and 2 neutrons and weigh the pieces.
**The pieces weigh more than the whole.**

```
   BEFORE (separate)                    AFTER (joined)
   ------------------                   ---------------
    p   p   n   n                          [ He-4 ]

    2 x 1.007825 = 2.015650 u             4.002603 u
    2 x 1.008665 = 2.017330 u
    -----------------------
    total        = 4.032980 u

           4.032980  -  4.002603   =   0.030377 u   HAS GONE MISSING
```

That missing mass did not vanish. It was **converted into the energy that was released
when the nucleons stuck together**, exactly as `E = mc^2` says.

```
   ANALOGY:  a ball rolling into a valley SPEEDS UP and gives out energy.
             To get it out of the valley again you must PUT that energy back.
             The nucleus is the ball; the valley is the nuclear force;
             the mass defect is the energy it gave out on the way down.
```

## 4.2 The formula

```
  +----------------------------------------------------------------+
  |                                                                |
  |   MASS DEFECT                                                  |
  |                                                                |
  |     dm  =  [ Z x mp  +  (A - Z) x mn ]  -  M                   |
  |                                                                |
  |     Z       = number of protons                                |
  |     A - Z   = number of neutrons                               |
  |     mp      = 1.007825 u   (mass of 1H^1 ATOM, includes 1 e-)  |
  |     mn      = 1.008665 u                                       |
  |     M       = actual measured mass of the ATOM                 |
  |                                                                |
  |   dm is ALWAYS POSITIVE for a stable nucleus.                  |
  |                                                                |
  +----------------------------------------------------------------+
```

> **TRAP:** Boards give atomic masses (which include the electrons). Then you must
> use the **hydrogen ATOM** mass 1.007825 u, not the bare proton 1.007276 u.
> The electrons then cancel automatically. If the question says "mass of proton",
> use 1.007276 u. Read the question and use what it gives you.

# TOPIC 5 — BINDING ENERGY

## 5.1 Two ways to define it — both are correct, learn both sentences

```
  DEFINITION 1 (energy released)
  The BINDING ENERGY of a nucleus is the energy released when free nucleons
  come together to form the nucleus.

  DEFINITION 2 (energy needed) -- easier to picture
  The BINDING ENERGY of a nucleus is the energy required to break the nucleus
  completely into its individual free nucleons.
```

```
  +--------------------------------------------------------+
  |                                                        |
  |    BE  =  dm  x  c^2      (dm in kg  -> answer in J)   |
  |                                                        |
  |    BE  =  dm  x  931.5    (dm in u   -> answer in MeV) |
  |                                                        |
  |                              BE                        |
  |    BINDING ENERGY  =  --------------  MeV per nucleon  |
  |    PER NUCLEON               A                         |
  |                                                        |
  +--------------------------------------------------------+
```

## 5.2 Binding energy per nucleon is what really matters

Uranium-235 has a total binding energy of about 1784 MeV, far bigger than helium's
28.3 MeV. Yet helium is much more tightly bound. Why?

```
  Total BE tells you how big the nucleus is, not how strong it is.

  BE / A tells you the STRENGTH OF THE GLUE PER PARTICLE.
  It is the fair comparison, exactly like comparing salary PER PERSON
  instead of the total wage bill of a company.

     He-4    :  28.3 / 4    =  7.07 MeV per nucleon   (tightly bound)
     U-235   :  1784 / 235  =  7.59 MeV per nucleon
     Fe-56   :  492 / 56    =  8.79 MeV per nucleon   (the champion)
```

**HIGHER BE/A  =  MORE STABLE.**

**WORKED EXAMPLE 5.1 — the deuteron (asked again and again)**
Find the binding energy of 1H^2, given mass of 1H^2 = 2.014102 u,
mp = 1.007825 u, mn = 1.008665 u.

```
  STEP 1   Z = 1,  A = 2,  so  A - Z = 1 neutron.

  STEP 2   Mass of the parts
              1 x 1.007825  =  1.007825
              1 x 1.008665  =  1.008665
                                --------
              total         =  2.016490 u

  STEP 3   dm  =  2.016490  -  2.014102  =  0.002388 u

  STEP 4   BE  =  0.002388 x 931.5  =  2.224 MeV

  STEP 5   BE per nucleon = 2.224 / 2 = 1.112 MeV

  ANSWER:  BE = 2.22 MeV,   BE/A = 1.11 MeV per nucleon
           (the LOWEST of all nuclei -- the deuteron is very loosely bound)
```

**WORKED EXAMPLE 5.2 — helium-4**
Mass of 2He^4 = 4.002603 u. Find BE and BE per nucleon.

```
  STEP 1   Z = 2, A = 4, neutrons = 2.

  STEP 2   2 x 1.007825  =  2.015650
           2 x 1.008665  =  2.017330
                            --------
                          =  4.032980 u

  STEP 3   dm = 4.032980 - 4.002603 = 0.030377 u

  STEP 4   BE = 0.030377 x 931.5 = 28.30 MeV

  STEP 5   BE/A = 28.30 / 4 = 7.07 MeV per nucleon

  ANSWER:  BE = 28.3 MeV,  BE/A = 7.07 MeV
           (unusually high for such a light nucleus -- this is why
            the alpha particle is so stable and gets emitted whole)
```

**WORKED EXAMPLE 5.3 — oxygen-16**
Mass of 8O^16 = 15.994915 u.

```
  STEP 1   8 protons, 8 neutrons.

  STEP 2   8 x 1.007825  =   8.062600
           8 x 1.008665  =   8.069320
                             ---------
                          =  16.131920 u

  STEP 3   dm = 16.131920 - 15.994915 = 0.137005 u

  STEP 4   BE = 0.137005 x 931.5 = 127.6 MeV

  STEP 5   BE/A = 127.6 / 16 = 7.98 MeV per nucleon

  ANSWER:  BE = 127.6 MeV,  BE/A = 7.98 MeV
```

**WORKED EXAMPLE 5.4 — lithium-7**
Mass of 3Li^7 = 7.016004 u.

```
  3 x 1.007825 = 3.023475
  4 x 1.008665 = 4.034660
                 ---------
                 7.058135 u

  dm  = 7.058135 - 7.016004 = 0.042131 u
  BE  = 0.042131 x 931.5 = 39.24 MeV
  BE/A = 39.24 / 7 = 5.61 MeV

  ANSWER:  BE = 39.2 MeV,  BE/A = 5.61 MeV
```

> **TRAP:** Do not round in the middle. The mass defect is a tiny difference of two
> big numbers. Keep all six decimal places until STEP 4, then round the MeV answer.
> Rounding 4.032980 to 4.03 turns a correct 28.3 MeV into a garbage answer.

# TOPIC 6 — THE BINDING ENERGY PER NUCLEON CURVE

## 6.1 The graph — draw it exactly like this

```
   BE/A
  (MeV)
    |
  9 |
    |                Fe-56  (8.8 MeV, A = 56)  <-- THE PEAK
    |                  *
  8 |          O-16  * * * * * *
    |            *              * * * * * *
    |         *                             * * * * *  U-235
  7 |    He-4                                          (7.6)
    |     *
    |
  6 |
    |
  5 |    Li-7
    |     *
  4 |
    |
  3 |
    |  H-3
  2 |   *
    |
  1 | H-2 *  (1.1)
    |*
  0 +--+----+----+----+----+----+----+----+----+----+----+---> A
    0  20   40   60   80  100  120  140  160  180  200  240

       |<-- steep rise -->|<-flat->|<---- slow fall ---->|
          A < 20            30-170        A > 170
```

## 6.2 Every feature, and what it means (this IS the 8-mark answer)

```
  FEATURE 1   Very light nuclei (A < 20) have LOW BE/A.
              H-2 has only 1.1 MeV. They are loosely bound.
              REASON: too few nucleons, most of them sit on the "surface"
              with few neighbours to attract them.

  FEATURE 2   The curve RISES STEEPLY up to about A = 20,
              with sharp spikes at He-4, C-12 and O-16
              (A = 4, 8, 12, 16 -- multiples of 4, "alpha-like" nuclei).

  FEATURE 3   BE/A is nearly CONSTANT at about 8.5 MeV
              in the broad range A = 30 to A = 170.
              REASON: SATURATION -- each nucleon is attracted only by its
              nearest neighbours, so adding more nucleons does not increase
              the glue per nucleon.

  FEATURE 4   MAXIMUM value 8.8 MeV per nucleon near A = 56 (IRON).
              IRON IS THE MOST STABLE NUCLEUS.
              This is why iron is so abundant, and why a star stops
              producing energy once its core turns to iron.

  FEATURE 5   For A > 170 the curve slowly FALLS,
              reaching 7.6 MeV at U-235.
              REASON: with 92 protons the electrostatic repulsion
              (which is LONG range and acts between ALL pairs)
              starts to beat the short-range nuclear attraction.
```

## 6.3 How the shape explains BOTH fission and fusion

This is the single most important idea in the chapter. Say it like this:

> **Any change that moves nuclei TOWARDS the peak of the curve releases energy.**

```
    LEFT SIDE (light nuclei, A small)          RIGHT SIDE (heavy nuclei)
    ---------------------------------          ------------------------
    BE/A is low, curve rises steeply.          BE/A is falling.

    JOIN two light nuclei                      SPLIT one heavy nucleus
    -> the product sits HIGHER on              -> the two products sit
       the curve                                  HIGHER on the curve
    -> total binding energy increases          -> total binding energy
    -> the surplus comes out as energy            increases
                                               -> surplus comes out

           = = = F U S I O N = = =                = = F I S S I O N = =
```

```
  A CONCRETE NUMBER FOR FISSION

    Before:  U-236 nucleus,  A = 236,  BE/A = 7.6 MeV
             total BE = 236 x 7.6 = 1794 MeV

    After:   two fragments with A about 118 each, BE/A = 8.5 MeV
             total BE = 236 x 8.5 = 2006 MeV

    Energy released = 2006 - 1794 = 212 MeV       (about 200 MeV)

  A CONCRETE NUMBER FOR FUSION

    Before:  4 protons,  BE/A = 0
    After:   He-4,  BE = 28.3 MeV
    Energy released = about 26.7 MeV for 4 nucleons
                    = 6.7 MeV PER NUCLEON

  Fission gives 200 MeV per EVENT but only 0.85 MeV per NUCLEON.
  Fusion gives less per event but MUCH MORE PER NUCLEON.
  That is why fusion is the better energy source per kilogram of fuel.
```

**WORKED EXAMPLE 6.1**
Using BE/A values, estimate the energy released when a nucleus of A = 240
(BE/A = 7.6 MeV) splits into two equal fragments of A = 120 (BE/A = 8.5 MeV).

```
  STEP 1   BE before = 240 x 7.6 = 1824 MeV
  STEP 2   BE after  = 2 x (120 x 8.5) = 2 x 1020 = 2040 MeV
  STEP 3   Energy released = BE after - BE before = 2040 - 1824 = 216 MeV

  ANSWER:  216 MeV
```

> **TRAP:** Energy released = (BE of products) − (BE of reactants). Students subtract
> the other way and get a negative answer. Remember: **products are more bound, so
> their BE is bigger.**

# TOPIC 7 — NUCLEAR FORCES

## 7.1 The problem that needs solving

```
  Inside a nucleus, 92 protons sit within 10^-14 m of each other.
  All are POSITIVE. Coulomb repulsion between two protons 2 fm apart is
  enormous (about 58 N -- the weight of a 6 kg mass, on ONE proton).

  Gravity between them is 10^-36 times weaker -- hopelessly too small.

  So there MUST be a third, much stronger, attractive force.
  ->  THE NUCLEAR FORCE  (the strong interaction)
```

## 7.2 The six properties — a guaranteed 4-mark question

```
  +----+------------------------+---------------------------------------+
  | 1  | STRONGEST FORCE        | About 100 times stronger than the     |
  |    | IN NATURE              | electrostatic force and 10^38 times   |
  |    |                        | stronger than gravity.                |
  +----+------------------------+---------------------------------------+
  | 2  | VERY SHORT RANGE       | Acts only up to about 2 to 3 fermi.   |
  |    |                        | Beyond about 10 fm it is ZERO.        |
  |    |                        | It does NOT obey the inverse square   |
  |    |                        | law.                                  |
  +----+------------------------+---------------------------------------+
  | 3  | CHARGE INDEPENDENT     | The force is the SAME between         |
  |    |                        | n-n , p-p and n-p pairs.              |
  |    |                        | It does not care about charge.        |
  +----+------------------------+---------------------------------------+
  | 4  | SATURATED              | Each nucleon attracts only its        |
  |    |                        | NEAREST NEIGHBOURS, not all the       |
  |    |                        | others. This is why BE/A is roughly   |
  |    |                        | constant and why volume goes as A.    |
  +----+------------------------+---------------------------------------+
  | 5  | SPIN DEPENDENT         | Stronger when the two nucleon spins   |
  |    | (non-central)          | are PARALLEL than when antiparallel.  |
  +----+------------------------+---------------------------------------+
  | 6  | ATTRACTIVE, BUT        | Attractive for r greater than 0.8 fm. |
  |    | REPULSIVE AT VERY      | Strongly REPULSIVE for r less than    |
  |    | SHORT DISTANCE         | 0.8 fm -- this "hard core" stops the  |
  |    |                        | nucleus collapsing to a point.        |
  +----+------------------------+---------------------------------------+

  (7)  It is exchange in nature -- carried by mesons (Yukawa, 1935).
```

# TOPIC 8 — RADIOACTIVITY

## 8.1 Discovery

```
  1896   HENRI BECQUEREL, in Paris, left uranium salt on a photographic plate
         wrapped in black paper, inside a drawer. The plate was fogged.
         Something was coming out of the uranium by itself.
         He had discovered RADIOACTIVITY (by accident).

  1898   MARIE CURIE and PIERRE CURIE isolated two far more active elements
         from pitchblende:  POLONIUM and RADIUM.
         Marie Curie coined the word "radioactivity".

  1899   RUTHERFORD separated the radiation into ALPHA and BETA using
         absorbers; VILLARD later found the third, GAMMA.
```

**Definition to write in the exam:**
> Radioactivity is the phenomenon of **spontaneous emission** of alpha, beta or gamma
> radiation from the **unstable nucleus** of an atom.

```
  IMPORTANT CHARACTER OF RADIOACTIVITY

   *  It is a NUCLEAR phenomenon, not a chemical one.
   *  It is SPONTANEOUS and RANDOM -- you cannot say WHICH nucleus decays next.
   *  It is UNAFFECTED by temperature, pressure, chemical state,
      electric or magnetic fields.  Heating uranium does NOT speed it up.
   *  Elements with Z > 82 (after lead) are all naturally radioactive.
```

## 8.2 Separating the three radiations

```
                                  +--------------+ SCREEN

        the page (x x x)          |    /         |   bends A LOT

     |  lead   |    ----------->  | *  gamma     |   neutral,

      radioactive                 |     * alpha  |   heavy, positive,
      source                      |              |   bends a LITTLE
                                  +--------------+   the OTHER way
```

```
     PENETRATING POWER and IONISING POWER are OPPOSITE.

     Alpha is fat and slow: it smashes into everything, loses its energy
     at once, so it ionises hugely and penetrates barely.
     Gamma is a massless photon: it slips through, ionising almost nothing,
     so it penetrates hugely.

     ANALOGY: alpha is a cannonball fired into a crowd (stops immediately,
     does enormous damage). Gamma is a bullet fired through fog.
```

## 8.4 The displacement laws (Soddy and Fajans)

### ALPHA DECAY

```
  +----------------------------------------------------------+
  |                                                          |
  |     zX^A   -->   (z-2)Y^(A-4)   +   2He^4   +   Q        |
  |                                                          |
  |     Z falls by 2 ,  A falls by 4                         |
  |     The product moves TWO places LEFT in the periodic     |
  |     table.                                               |
  +----------------------------------------------------------+

  EXAMPLES
     92U^238   -->   90Th^234   +   2He^4     + 4.27 MeV
     88Ra^226  -->   86Rn^222   +   2He^4     + 4.87 MeV
     84Po^210  -->   82Pb^206   +   2He^4     + 5.41 MeV

  CHECK EVERY TIME:   238 = 234 + 4  (mass numbers balance)
                       92 =  90 + 2  (charge numbers balance)

  WHY it happens: only heavy nuclei (A > 210) do this. They have too many
  protons; throwing out a very tightly bound He-4 lump is the cheapest way
  to lose 2 protons at once.
```

### BETA-MINUS DECAY (the usual one)

```
  Inside the nucleus:     0n^1  -->  1p^1  +  -1e^0  +  antineutrino

  +----------------------------------------------------------+
  |                                                          |
  |    zX^A   -->   (z+1)Y^A   +   -1e^0   +   antineutrino  |
  |                                                          |
  |    Z rises by 1 ,  A does NOT change                     |
  |    The product moves ONE place RIGHT.                    |
  +----------------------------------------------------------+

  EXAMPLES
     90Th^234  -->   91Pa^234   +   -1e^0  +  antineutrino
      6C^14    -->    7N^14     +   -1e^0  +  antineutrino
     15P^32    -->   16S^32     +   -1e^0  +  antineutrino

  WHY: the nucleus has TOO MANY NEUTRONS. One neutron converts to a proton.
  The electron is NOT taken from the orbit -- it is CREATED at the instant
  of decay inside the nucleus.
```

### BETA-PLUS DECAY (positron emission)

```
  Inside the nucleus:     1p^1  -->  0n^1  +  +1e^0  +  neutrino

  +----------------------------------------------------------+
  |                                                          |
  |    zX^A   -->   (z-1)Y^A   +   +1e^0   +   neutrino      |
  |                                                          |
  |    Z falls by 1 ,  A does NOT change                     |
  +----------------------------------------------------------+

  EXAMPLES
     11Na^22   -->   10Ne^22   +   +1e^0  +  neutrino
      6C^11    -->    5B^11    +   +1e^0  +  neutrino

  WHY: the nucleus has TOO MANY PROTONS.
```

**Why the neutrino had to be invented:** beta particles come out with a *continuous*
range of energies, not one fixed value. Energy and momentum seemed not to balance.
**Pauli** proposed a third, almost massless, chargeless particle that carries away the
rest — the **neutrino**. It shares the energy with the electron, which is exactly why
the beta spectrum is continuous.

### GAMMA DECAY

```
  +----------------------------------------------------------+
  |                                                          |
  |     zX^A (excited)   -->   zX^A (ground)   +   gamma     |
  |                                                          |
  |     NEITHER Z NOR A CHANGES.                             |
  |     It is not a new element -- only a cooling down.      |
  +----------------------------------------------------------+

  Gamma emission almost always FOLLOWS an alpha or beta decay, because the
  daughter is left in an EXCITED state and must drop to its ground state.

  THE STANDARD EXAMPLE  (cobalt-60, used in cancer therapy)

     27Co^60  -->  28Ni^60*  +  -1e^0  +  antineutrino        (beta first)
     28Ni^60* -->  28Ni^60   +  gamma (1.17 MeV)              (then gamma)
              -->              +  gamma (1.33 MeV)

  ENERGY LEVEL PICTURE

        Ni-60*  ------------------  2.50 MeV
                        |
                        |  gamma 1.17 MeV
                        v
        Ni-60*  ------------------  1.33 MeV
                        |
                        |  gamma 1.33 MeV
                        v
        Ni-60   ------------------  0  (ground state)

  Gamma-ray energies are in MeV; X-ray energies are in keV.
  Gamma comes from the NUCLEUS; X-rays come from the ELECTRON shells.
```

## 8.5 The Q value of a decay

```
  +---------------------------------------------------------------+
  |                                                               |
  |   Q  =  [ mass of parent  -  total mass of products ] x c^2   |
  |                                                               |
  |   With masses in u:     Q (MeV)  =  dm (u)  x  931.5          |
  |                                                               |
  |   Q > 0  ->  energy is RELEASED  ->  the decay CAN happen     |
  |              spontaneously                                    |
  |   Q < 0  ->  energy must be SUPPLIED -> it CANNOT happen      |
  |              on its own                                       |
  |                                                               |
  |   The Q value appears as the KINETIC ENERGY of the products.  |
  +---------------------------------------------------------------+
```

**WORKED EXAMPLE 8.1**
Find the Q value for 92U^238 --> 90Th^234 + 2He^4.
Given: m(U-238) = 238.05079 u, m(Th-234) = 234.04363 u, m(He-4) = 4.00260 u.

```
  STEP 1   Mass of products = 234.04363 + 4.00260 = 238.04623 u

  STEP 2   dm = 238.05079 - 238.04623 = 0.00456 u

  STEP 3   Q = 0.00456 x 931.5 = 4.25 MeV

  ANSWER:  Q = 4.25 MeV.  It is positive, so the decay is spontaneous.
```

**Where does the 4.25 MeV go?** By momentum conservation the light alpha particle
takes almost all of it (about 4.18 MeV) and the heavy thorium nucleus recoils with
the rest. Kinetic energy is shared in inverse proportion to mass.

# TOPIC 9 — THE LAW OF RADIOACTIVE DECAY

## 9.1 The one assumption

> The number of nuclei that decay per second is **proportional to the number of
> undecayed nuclei present at that moment**. Nothing else matters.

Think of popcorn in a hot pan: the more unpopped kernels there are, the more pops you
hear per second. As kernels run out, the popping slows down. Same law.

## 9.2 THE DERIVATION — write it exactly like this in the exam

```
  STEP 1   Let N be the number of undecayed nuclei at time t.
           Let dN be the (negative) change in a small time dt.

  STEP 2   By the law of radioactive decay

                  - dN / dt   is proportional to   N

                  - dN / dt   =   lambda N

           lambda = the DECAY CONSTANT (a positive constant for each isotope).
           The minus sign shows N is DECREASING.

  STEP 3   Separate the variables

                  dN / N   =   - lambda dt

  STEP 4   Integrate both sides

                  INT (dN / N)   =   - lambda INT dt

                  ln N   =   - lambda t   +   C

  STEP 5   Find C using the initial condition:  at t = 0 , N = N0

                  ln N0  =   0  +  C        so    C  =  ln N0

  STEP 6   Put C back

                  ln N   =   - lambda t  +  ln N0

                  ln N  -  ln N0   =   - lambda t

                  ln ( N / N0 )    =   - lambda t

  STEP 7   Take the exponential of both sides

           +---------------------------------------------+
           |                                             |
           |          N   =   N0  e^( - lambda t )       |
           |                                             |
           +---------------------------------------------+

           This is the LAW OF RADIOACTIVE DECAY.
```

## 9.3 The decay curve

```
   N
    |
  N0*
    |  *
    |    *
    |      *
 N0/2 - - - -*
    |    :     *
    |    :       *
 N0/4 - -:- - - - -*
    |    :    :      *
    |    :    :        *  *
 N0/8 - -:- -:- - -:- - - - -*  *
    |    :    :    :             *  *  *
    |    :    :    :                     *  *  *  *  *  *
  0 +----+----+----+----+----+----+----+----+----+----+---> t
    0    T    2T   3T   4T   5T

    * The curve NEVER touches the t-axis. N never becomes exactly zero.
    * It falls by the SAME FRACTION (one half) in every equal interval T.
    * The tangent at t = 0, extended, meets the axis at t = tau (mean life).
```

## 9.4 Decay constant — what it actually means

```
  From   N = N0 e^(-lambda t),  put  t = 1/lambda :

         N  =  N0 e^-1  =  N0 / e  =  N0 / 2.718  =  0.368 N0

  +------------------------------------------------------------------+
  |  DECAY CONSTANT lambda                                           |
  |                                                                  |
  |  = the reciprocal of the time in which the number of nuclei      |
  |    falls to 1/e (that is 36.8 %) of its initial value.           |
  |                                                                  |
  |  = the probability per unit time that a given nucleus decays.    |
  |                                                                  |
  |  UNIT:  per second (s^-1).  Also per minute, per hour, per year. |
  |                                                                  |
  |  A LARGE lambda  ->  fast decay  ->  short half life.            |
  +------------------------------------------------------------------+
```

## 9.5 HALF LIFE

```
  DEFINITION: the time in which HALF of the nuclei present decay,
              i.e. N falls from N0 to N0/2.

  DERIVING THE RELATION

  STEP 1   At  t = T (half life),  N = N0 / 2.

  STEP 2   N0/2  =  N0 e^(-lambda T)

  STEP 3   1/2   =  e^(-lambda T)

  STEP 4   Invert:      2  =  e^(+lambda T)

  STEP 5   Take ln:     ln 2  =  lambda T

  STEP 6   +--------------------------------------------+
           |                                            |
           |      T  =  ln 2 / lambda  =  0.693/lambda  |
           |                                            |
           |      lambda  =  0.693 / T                  |
           |                                            |
           +--------------------------------------------+
```

## 9.6 MEAN LIFE (average life)

```
  DEFINITION: the average of the lifetimes of ALL the nuclei of the sample.

  It works out to

           +-----------------------------------------------+
           |                                               |
           |    tau  =  1 / lambda                         |
           |                                               |
           |    and since lambda = 0.693 / T ,             |
           |                                               |
           |    tau  =  T / 0.693  =  1.44 T               |
           |                                               |
           |    or   T  =  0.693 tau                       |
           |                                               |
           +-----------------------------------------------+

  SO:      MEAN LIFE  is  ALWAYS  LONGER  than  HALF LIFE.
           tau  >  T   always.   (tau is 44 % bigger.)

  WHY?  A few nuclei survive for an extremely long time, and those long
        lifetimes drag the average up above the half-life value.
```

## 9.7 ACTIVITY and its units

```
  +----------------------------------------------------------------+
  |                                                                |
  |   ACTIVITY  R  =  - dN/dt  =  lambda N                         |
  |                                                                |
  |   = the number of disintegrations per second.                  |
  |                                                                |
  |   Activity also decays exponentially:                          |
  |                                                                |
  |            R  =  R0  e^( - lambda t )                          |
  |                                                                |
  +----------------------------------------------------------------+

  UNITS OF ACTIVITY

  +----------------+-----------------------------------------------+
  | BECQUEREL (Bq) | THE SI UNIT.  1 Bq = 1 disintegration per     |
  |                | second.  Named after Henri Becquerel.         |
  +----------------+-----------------------------------------------+
  | CURIE (Ci)     | The old, practical unit.                      |
  |                | 1 Ci = 3.7 x 10^10 Bq                         |
  |                | = the activity of 1 gram of RADIUM-226.       |
  |                | 1 mCi = 3.7 x 10^7 Bq                         |
  +----------------+-----------------------------------------------+
  | RUTHERFORD (Rd)| 1 Rd = 10^6 Bq                                |
  +----------------+-----------------------------------------------+
```

```
  +---------------------------------------------------------------+
  |                                                               |
  |    After n half lives:                                        |
  |                                                               |
  |         N            ( 1 )^n           where   n  =  t / T    |

  |         N0           ( 2 )                                    |
  |                                                               |
  |    Same for mass:  m = m0 (1/2)^n                             |
  |    Same for activity:  R = R0 (1/2)^n                         |
  |                                                               |
  +---------------------------------------------------------------+

  THE TABLE TO MEMORISE

  +-----------+--------------+-----------------+------------------+
  | n (half   | fraction     | percentage      | percentage       |

  +-----------+--------------+-----------------+------------------+

  |    3      |    1/8       |     12.5 %      |     87.5 %       |
```

**WORKED EXAMPLE 9.1**
The half life of a radioactive sample is 20 minutes. What fraction remains after
1 hour 20 minutes?

```
  STEP 1   Total time t = 1 h 20 min = 80 minutes.
  STEP 2   n = t / T = 80 / 20 = 4 half lives.
  STEP 3   Fraction = (1/2)^4 = 1/16.

  ANSWER:  1/16  (that is 6.25 %). The decayed fraction is 15/16.
```

**WORKED EXAMPLE 9.2**
The half life of radon is 3.8 days. Find (a) the decay constant, (b) the mean life.

```
  (a)  lambda = 0.693 / T
              = 0.693 / 3.8 days
              = 0.1824 per day

       In SI:  T = 3.8 x 24 x 3600 = 3.283 x 10^5 s
               lambda = 0.693 / 3.283 x 10^5 = 2.11 x 10^-6 s^-1

  (b)  tau = 1 / lambda = 1 / 0.1824 = 5.48 days
       CHECK:  tau = 1.44 x T = 1.44 x 3.8 = 5.47 days.  Agrees.

  ANSWER:  lambda = 2.11 x 10^-6 s^-1 ,   tau = 5.48 days
```

**WORKED EXAMPLE 9.3**
A radioactive sample contains 10^20 nuclei with half life 10 hours.
Find its initial activity in becquerel and in curie.

```
  STEP 1   T = 10 h = 10 x 3600 = 3.6 x 10^4 s

  STEP 2   lambda = 0.693 / 3.6 x 10^4 = 1.925 x 10^-5 s^-1

  STEP 3   R = lambda N = 1.925 x 10^-5 x 10^20
                        = 1.925 x 10^15 Bq

  STEP 4   In curie:  R = 1.925 x 10^15 / 3.7 x 10^10
                        = 5.2 x 10^4 Ci

  ANSWER:  1.93 x 10^15 Bq  =  5.2 x 10^4 curie
```

**WORKED EXAMPLE 9.4 — the classic radium calculation**
Show that the activity of 1 gram of radium-226 (half life 1600 years) is about 1 curie.

```
  STEP 1   Number of atoms in 1 g:
              N = (mass / atomic mass) x Avogadro number
                = (1 / 226) x 6.022 x 10^23
                = 2.665 x 10^21 atoms

  STEP 2   T = 1600 years = 1600 x 3.156 x 10^7 s = 5.05 x 10^10 s

  STEP 3   lambda = 0.693 / 5.05 x 10^10 = 1.372 x 10^-11 s^-1

  STEP 4   R = lambda N = 1.372 x 10^-11 x 2.665 x 10^21
                        = 3.66 x 10^10 disintegrations per second

  ANSWER:  3.66 x 10^10 Bq, which is 3.7 x 10^10 Bq = 1 CURIE.
           This is exactly how the curie was originally defined.
```

**WORKED EXAMPLE 9.5 — carbon dating**
A piece of old wood shows a C-14 activity that is one-eighth of that of fresh wood.
Half life of C-14 is 5730 years. How old is the wood?

```
  STEP 1   R / R0 = 1/8 = (1/2)^3 , so n = 3 half lives.
  STEP 2   t = n T = 3 x 5730 = 17190 years.

  ANSWER:  about 17 200 years old.
```

**WORKED EXAMPLE 9.6 — when the fraction is not a nice power of 2**
A sample decays to 20 % of its original amount in 100 seconds.
Find the decay constant and the half life.

```
  STEP 1   N/N0 = 0.20  and  N = N0 e^(-lambda t)

  STEP 2   0.20 = e^(-lambda x 100)

  STEP 3   Take ln of both sides:
              ln 0.20 = - 100 lambda
              -1.609  = - 100 lambda

  STEP 4   lambda = 1.609 / 100 = 0.01609 s^-1

  STEP 5   T = 0.693 / lambda = 0.693 / 0.01609 = 43.1 s

  ANSWER:  lambda = 1.61 x 10^-2 s^-1 ,  half life = 43.1 s

  CHECK:  100 s is about 2.3 half lives; (1/2)^2.3 = 0.203. Correct.
```

**WORKED EXAMPLE 9.7**
Two radioactive samples X and Y have half lives 2 h and 4 h. Initially both contain
the same number N0 of nuclei. Find the ratio of the numbers remaining after 8 hours.

```
  STEP 1   For X:  n = 8/2 = 4 half lives  ->  N_X = N0 (1/2)^4 = N0/16
  STEP 2   For Y:  n = 8/4 = 2 half lives  ->  N_Y = N0 (1/2)^2 = N0/4

  STEP 3   N_X : N_Y  =  (1/16) : (1/4)  =  1 : 4

  ANSWER:  1 : 4
```

**WORKED EXAMPLE 9.8**
The activity of a sample falls from 8000 counts/min to 1000 counts/min in 30 minutes.
Find the half life and the mean life.

```
  STEP 1   R/R0 = 1000/8000 = 1/8 = (1/2)^3 , so n = 3.
  STEP 2   n T = 30  ->  T = 10 minutes.
  STEP 3   lambda = 0.693/10 = 0.0693 per minute.
  STEP 4   tau = 1/lambda = 14.4 minutes  (= 1.44 x 10, checks out).

  ANSWER:  half life 10 min,  mean life 14.4 min
```

> **TRAP 1:** "Fraction that has DECAYED" is `1 - (1/2)^n`, not `(1/2)^n`.
> Read the question word by word.

> **TRAP 2:** lambda and T must use the SAME time unit. If T is in days and the
> question wants activity in Bq, convert T to seconds FIRST.

> **TRAP 3:** Radioactive decay is a NUCLEAR process. Cooling the sample, putting it
> under pressure or making a compound of it changes NOTHING.

# TOPIC 10 — NUCLEAR FISSION

## 10.1 What it is

> **Nuclear fission** is the process in which a heavy nucleus, on being bombarded by a
> slow (thermal) neutron, splits into two nearly equal lighter nuclei with the release
> of 2 or 3 neutrons and a large amount of energy.

Discovered in 1939 by **Otto Hahn** and **Fritz Strassmann**; explained by
**Lise Meitner** and **Otto Frisch**.

## 10.2 The equations

```
  THE MAIN ONE (learn this):

    92U^235  +  0n^1  -->  [ 92U^236 ]*  -->  56Ba^141 + 36Kr^92 + 3 0n^1 + Q

                              unstable,
                              lives 10^-14 s

  CHECK:   mass numbers   235 + 1 = 236 ;  141 + 92 + 3 = 236   OK
           atomic numbers  92 + 0 =  92 ;   56 + 36     =  92   OK

  ANOTHER COMMON SPLIT:

    92U^235  +  0n^1  -->  56Ba^144  +  36Kr^89  +  3 0n^1  +  Q

  CHECK:   235 + 1 = 236 ;  144 + 89 + 3 = 236    OK
            92 + 0 =  92 ;   56 + 36     =  92    OK

  Q  =  about 200 MeV per fission.
```

Fission is not a single fixed reaction — over 100 different fragment pairs are
possible. The fragments are usually **unequal**, peaking near A = 95 and A = 140.

## 10.3 Where the 200 MeV comes from

```
  ROUTE 1 -- from the BE/A curve
     U-236 :  BE/A = 7.6 MeV   ->  total BE = 236 x 7.6 = 1794 MeV
     fragments : BE/A = 8.5 MeV -> total BE = 236 x 8.5 = 2006 MeV
     Energy released = 2006 - 1794 = about 212 MeV

  ROUTE 2 -- from the mass defect
     The products weigh about 0.2154 u LESS than the reactants.
     Q = 0.2154 x 931.5 = about 200 MeV.

  HOW THE 200 MeV IS SHARED
     Kinetic energy of the two fragments  ....  165 MeV   (the bulk)
     Kinetic energy of the neutrons       ....    5 MeV
     Instantaneous gamma rays             ....    7 MeV
     Beta particles from fragment decay   ....    7 MeV
     Gamma from fragment decay            ....    6 MeV
     Neutrinos (escape, wasted)           ....   10 MeV
                                              ---------
                                                200 MeV
```

**WORKED EXAMPLE 10.1**
Find the energy released when 1 kg of U-235 undergoes complete fission
(200 MeV per fission).

```
  STEP 1   Number of atoms in 1 kg = 1000 g
              N = (1000 / 235) x 6.022 x 10^23
                = 4.2553 x 6.022 x 10^23
                = 2.562 x 10^24 atoms

  STEP 2   Total energy = 2.562 x 10^24 x 200 MeV
                        = 5.124 x 10^26 MeV

  STEP 3   Convert to joule.  1 MeV = 1.6 x 10^-13 J
              E = 5.124 x 10^26 x 1.6 x 10^-13
                = 8.2 x 10^13 J

  ANSWER:  8.2 x 10^13 joule from ONE kilogram.
           Burning 1 kg of coal gives about 3 x 10^7 J.
           Fission is nearly THREE MILLION times better per kilogram.
```

## 10.4 The chain reaction

```
  Each fission uses 1 neutron and PRODUCES about 2.5 neutrons on average.
  Those neutrons can cause further fissions. The result grows like this:

                                 n
                                 |
                              [ U-235 ]
                              /   |   \
                             n    n    n
                            /     |     \
                       [U-235] [U-235] [U-235]
                       /  |  \  / | \   / | \
                      n   n   n n n n  n  n  n
                     ...  ...  ...  (9 fissions)
                             |
                            27
                             |
                            81 ...

    Generation:   1  ->  3  ->  9  ->  27  ->  81  ->  ...
    Each generation takes about 10^-8 s.
    In under a microsecond the whole sample can go.
```

```
  NEUTRON REPRODUCTION FACTOR  k
  = (number of neutrons in one generation) / (number in the previous one)

  +--------+-------------------+--------------------------------------+
  | k < 1  | SUB-CRITICAL      | reaction dies out                    |
  | k = 1  | CRITICAL          | reaction is STEADY  -> NUCLEAR       |
  |        |                   | REACTOR (controlled)                 |
  | k > 1  | SUPER-CRITICAL    | reaction grows explosively ->        |
  |        |                   | ATOM BOMB (uncontrolled)             |
  +--------+-------------------+--------------------------------------+
```

```
  CONTROLLED   vs   UNCONTROLLED

  CONTROLLED (k = 1)              UNCONTROLLED (k > 1)
  ---------------------------     -----------------------------
  Extra neutrons are absorbed     All neutrons are allowed to
  by CONTROL RODS.                cause fission.
  Energy comes out slowly and     Energy comes out in microseconds.
  steadily.                       Result: an ATOMIC BOMB.
  Used in a NUCLEAR REACTOR       Hiroshima (U-235) and
  for electricity.                Nagasaki (Pu-239), 1945.
```

## 10.5 Critical mass

```
  DEFINITION: the MINIMUM mass of fissile material needed for a
              self-sustaining chain reaction (k = 1).

  WHY does mass matter?
     A neutron must hit another nucleus BEFORE it escapes from the surface.
     Small lump -> big surface-to-volume ratio -> neutrons leak out -> k < 1.
     Big lump   -> neutrons get absorbed inside -> k = 1 or more.

     A SPHERE is used because it has the least surface for a given volume.

  For pure U-235 the critical mass is roughly 10 kg (a sphere the size
  of a large orange).

  HOW A BOMB WORKS: two SUB-critical pieces are kept apart and slammed
  together by chemical explosive to instantly exceed the critical mass.
```

# TOPIC 11 — NUCLEAR FUSION

## 11.1 What it is

> **Nuclear fusion** is the process in which two very light nuclei combine to form a
> heavier nucleus, with the release of a large amount of energy.

```
  EXAMPLES

    1H^2  +  1H^2   -->   2He^3  +  0n^1  +  3.27 MeV
    1H^2  +  1H^2   -->   1H^3   +  1H^1  +  4.03 MeV
    1H^2  +  1H^3   -->   2He^4  +  0n^1  +  17.59 MeV   <-- easiest fusion

  OVERALL, in the Sun:

    4 (1H^1)  -->  2He^4  +  2 (+1e^0)  +  2 neutrinos  +  26.7 MeV
```

## 11.2 Why fusion needs a huge temperature — the Coulomb barrier

```
  Both nuclei are POSITIVE. To fuse they must touch, at about 2 fm.
  But as they approach, the repulsion grows fiercely.

   Potential
   energy
     |
     |         COULOMB BARRIER  (about 400 keV)
     |              ****
     |            **    **
     |          **        **
     |        **            **
     |     ***                ***
     |  ***                       *****
   0 +--------------------------------|------------> separation r
     |                                |
     |                          *****  <-- nuclear well
     |                          the two nuclei must get INSIDE here

  To climb this barrier the nuclei must be fired at each other very hard.
  The only way to do that to a whole gas is to make it very HOT, because
  average kinetic energy = (3/2) k T.

     Set  (3/2) k T  =  400 keV   ->   T  is about  3 x 10^9 K

  In practice, QUANTUM TUNNELLING lets it happen at a much lower
  temperature, about 10^7 K.  The core of the Sun is 1.5 x 10^7 K.

  Because the reaction is driven by HEAT, it is called a
  THERMONUCLEAR REACTION.
```

## 11.3 The proton-proton (p-p) cycle — the Sun's engine

```
  The Sun (core temperature 1.5 x 10^7 K) runs mainly on this:

  (1)   1H^1  +  1H^1   -->   1H^2  +  +1e^0  +  neutrino  + 0.42 MeV
                                          (very slow step -- takes
                                           billions of years per proton;
                                           this is why the Sun lasts so long)

  (2)   +1e^0  +  -1e^0  -->   gamma  +  gamma           + 1.02 MeV
                                          (positron meets an electron and
                                           they annihilate)

  (3)   1H^2  +  1H^1   -->   2He^3  +  gamma            + 5.49 MeV

  (4)   2He^3  +  2He^3  -->  2He^4  +  1H^1  +  1H^1    + 12.86 MeV
        (steps 1 to 3 must happen TWICE to make two He-3 nuclei
         before step 4 can run)

  NET RESULT:
        4 (1H^1)  +  2 (-1e^0)  -->  2He^4  +  2 neutrinos  +  6 gamma
                                              +  26.7 MeV
```

## 11.4 The carbon-nitrogen (CNO) cycle — for hotter, bigger stars

```
  Carbon acts purely as a CATALYST: it goes in at the start and comes
  back out at the end, unchanged.

   6C^12  +  1H^1   -->   7N^13   +  gamma
   7N^13            -->   6C^13   +  +1e^0  +  neutrino
   6C^13  +  1H^1   -->   7N^14   +  gamma
   7N^14  +  1H^1   -->   8O^15   +  gamma
   8O^15            -->   7N^15   +  +1e^0  +  neutrino
   7N^15  +  1H^1   -->   6C^12   +  2He^4       <-- carbon returns

  ADD THEM ALL UP.  The carbon cancels, and what is left is:

        4 (1H^1)  -->  2He^4  +  2 (+1e^0)  +  2 neutrinos  +  26.7 MeV

  EXACTLY the same net result as the p-p cycle.

  WHICH CYCLE WHERE?
     Stars cooler than about 1.7 x 10^7 K  ->  p-p cycle dominates
                                               (our Sun)
     Hotter, more massive stars            ->  CNO cycle dominates
```

**Why the Sun is not a bomb:** gravity holds the hot plasma together (this is called
*gravitational confinement*) and the reaction rate is limited by the extremely slow
first step of the p-p cycle. The Sun has been burning for 4.5 billion years and has
fuel for about 5 billion more.

**WORKED EXAMPLE 11.1**
In the reaction 1H^2 + 1H^2 --> 2He^3 + 0n^1, find the energy released.
Given m(1H^2) = 2.014102 u, m(2He^3) = 3.016029 u, m(0n^1) = 1.008665 u.

```
  STEP 1   Mass before = 2 x 2.014102 = 4.028204 u
  STEP 2   Mass after  = 3.016029 + 1.008665 = 4.024694 u
  STEP 3   dm = 4.028204 - 4.024694 = 0.003510 u
  STEP 4   Q  = 0.003510 x 931.5 = 3.27 MeV

  ANSWER:  3.27 MeV
```

## 11.5 FISSION versus FUSION — the comparison table

```
  +----------------------+---------------------------+---------------------------+
  |  POINT               |  FISSION                  |  FUSION                   |
  +----------------------+---------------------------+---------------------------+
  |  What happens        |  A heavy nucleus SPLITS   |  Two light nuclei JOIN    |
  |                      |  into two lighter ones    |  into one heavier one     |
  +----------------------+---------------------------+---------------------------+
  |  Nuclei involved     |  Heavy: U-235, Pu-239     |  Light: H-1, H-2, H-3, Li |
  +----------------------+---------------------------+---------------------------+
  |  Started by          |  A SLOW NEUTRON           |  Very HIGH TEMPERATURE    |
  |                      |  hitting the nucleus      |  (about 10^7 K)           |
  +----------------------+---------------------------+---------------------------+
  |  Energy per event    |  LARGE: about 200 MeV     |  Smaller: about 27 MeV    |
  +----------------------+---------------------------+---------------------------+
  |  Energy per NUCLEON  |  SMALL: about 0.85 MeV    |  LARGE: about 6.7 MeV     |
  |                      |                           |  (fusion wins per kg)     |
  +----------------------+---------------------------+---------------------------+
  |  Can it be           |  YES -- nuclear reactor   |  NOT YET on Earth.        |
  |  controlled?         |  (control rods)           |  No container can hold    |
  |                      |                           |  a 10^7 K plasma; magnetic|
  |                      |                           |  confinement (tokamak) is |
  |                      |                           |  still experimental.      |
  +----------------------+---------------------------+---------------------------+
  |  Products            |  Radioactive fragments;   |  Helium -- harmless,      |
  |                      |  dangerous waste that     |  NO long-lived radioactive|
  |                      |  lasts thousands of years |  waste                    |
  +----------------------+---------------------------+---------------------------+
  |  Fuel supply         |  Limited (uranium ore)    |  Almost unlimited         |
  |                      |                           |  (deuterium from seawater)|
  +----------------------+---------------------------+---------------------------+
  |  Chain reaction      |  Yes, possible            |  No chain reaction        |
  +----------------------+---------------------------+---------------------------+
  |  Where it occurs     |  Reactors, atom bomb      |  STARS and the SUN,       |
  |                      |                           |  hydrogen bomb            |
  +----------------------+---------------------------+---------------------------+
```

**The hydrogen bomb** uses a *fission* bomb as its trigger: the fission explosion
creates the millions of degrees needed to start the *fusion* of deuterium and tritium.
That is why it is also called a **thermonuclear bomb**, and it is far more destructive
than an atom bomb.

# TOPIC 12 — NUCLEAR HOLOCAUST AND RADIATION HAZARDS

## 12.1 Nuclear holocaust

```
  On 6 August 1945 a U-235 bomb destroyed HIROSHIMA;
  on 9 August 1945 a Pu-239 bomb destroyed NAGASAKI.
  Each released energy equal to about 20 000 tonnes of TNT.
  About 200 000 people died from blast, heat and radiation.

  The world today holds enough warheads to release energy equal to
  thousands of megatonnes of TNT. A large-scale nuclear war would cause:

    *  immediate blast and fire deaths on a huge scale
    *  a radioactive FALLOUT cloud spreading for thousands of km
    *  a "NUCLEAR WINTER" -- dust and soot blocking sunlight for years,
       killing crops and collapsing the food chain
    *  genetic damage carried into future generations

  This is called a NUCLEAR HOLOCAUST. It is the reason for
  international treaties limiting nuclear weapons.
```

## 12.2 Biological hazards of radiation

```
  HOW RADIATION HARMS YOU
     Radiation IONISES the atoms in living cells. That breaks chemical
     bonds, damages DNA, and either kills the cell or makes it grow
     abnormally.

  TWO KINDS OF EFFECT
  +---------------+----------------------------------------------------+
  | SOMATIC       | Damage to the person exposed:                      |
  |               | skin burns, hair loss, nausea, low white blood     |
  |               | cell count, sterility, cataract, LEUKAEMIA and     |
  |               | other CANCERS.                                     |
  +---------------+----------------------------------------------------+
  | GENETIC       | Damage to the reproductive cells, causing          |
  |               | MUTATIONS that appear in children and              |
  |               | grandchildren.                                     |
  +---------------+----------------------------------------------------+

  UNITS OF ABSORBED DOSE
     1 GRAY (Gy)     =  1 joule of energy absorbed per kg of tissue
     1 rad           =  0.01 Gy
     1 SIEVERT (Sv)  =  the dose in Gy multiplied by a quality factor
                        that allows for how damaging that radiation is
                        (alpha counts about 20 times worse than gamma)
     1 rem           =  0.01 Sv

     Safe occupational limit is roughly 20 mSv per year.
     A whole-body dose above about 4 Gy is usually fatal.

  SAFETY MEASURES
     *  Keep your DISTANCE (intensity falls as 1/r^2)
     *  Keep the TIME of exposure short
     *  Use SHIELDING: paper or clothing for alpha, aluminium for beta,
        thick LEAD or CONCRETE for gamma and neutrons
     *  Handle sources with remote tongs, wear film badges/dosimeters
     *  Never bring a source near the eyes or the body
```
