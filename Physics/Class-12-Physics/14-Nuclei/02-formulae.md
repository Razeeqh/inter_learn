# 1. COMPOSITION OF THE NUCLEUS

```
  +----------------------------------------------------------+
  |                                                          |
  |            A                                             |
  |             X          Z = atomic number  = no. of p     |
  |            Z           A = mass number    = no. of p + n |
  |                        N = A - Z          = no. of n     |
  |                                                          |
  |     written in text as   zX^A    e.g.  92U^235           |
  |                                                          |
  +----------------------------------------------------------+
```

| Formula | When to use |
|---|---|
| `N = A - Z` | Any "how many neutrons" question |
| `Z1 = Z2` , `A1 ≠ A2` | Test for **isotopes** |
| `A1 = A2` , `Z1 ≠ Z2` | Test for **isobars** |
| `N1 = N2` , `Z1 ≠ Z2` | Test for **isotones** |
| `Z1 = Z2` and `A1 = A2`, different energy | Test for **isomers** |

```
  Average atomic mass of an element from its isotopes

                p1 x m1  +  p2 x m2
      M_avg =  ----------------------      (p = percentage abundance)
                        100
```

# 2. SIZE, VOLUME AND DENSITY OF THE NUCLEUS

```
  +--------------------------------------------------------------+
  |                                                              |
  |        R  =  R0  A^(1/3)        R0 = 1.2 fermi               |
  |                                    = 1.2 x 10^-15 m          |
  |                                                              |
  |        1 fermi (fm)  =  10^-15 m                             |
  |                                                              |
  +--------------------------------------------------------------+


                                     4          4
   VOLUME OF A NUCLEUS      V  =   ----- pi R^3  =  ---- pi R0^3 A
                                     3          3

                            So    V   is proportional to   A


                         R1        ( A1 )^(1/3)
   RATIO OF RADII      ------  =   ( -- )
                         R2        ( A2 )


                        V1        A1
   RATIO OF VOLUMES   ------  =  ----
                        V2        A2


                                     mass          A m
   NUCLEAR DENSITY     rho  =  --------------  =  ----------------
                                  volume          (4/3) pi R0^3 A


           +-------------------------------------------------+
           |                m                                |
           |  rho  =  ----------------  =  2.3 x 10^17 kg/m3 |
           |          (4/3) pi R0^3                          |
           |                                                 |
           |  INDEPENDENT OF A  --  the same for ALL nuclei  |
           +-------------------------------------------------+
```

| Formula | When to use |
|---|---|
| `R = 1.2 A^(1/3)` fm | Find the radius of a named nucleus |
| `R1/R2 = (A1/A2)^(1/3)` | "Ratio of radii of two nuclei" |
| `V1/V2 = A1/A2` | "Ratio of volumes / how many times bigger" |
| `rho = 2.3 x 10^17 kg/m^3` | Any nuclear density question — quote the value AND say it is independent of A |

```
  CUBE ROOTS YOU SHOULD KNOW BY HEART
     8^(1/3)=2    27^(1/3)=3    64^(1/3)=4    125^(1/3)=5
   216^(1/3)=6   343^(1/3)=7   512^(1/3)=8  1000^(1/3)=10
```

# 3. MASS-ENERGY EQUIVALENCE

```
  +----------------------------------------------------------+
  |                                                          |
  |               E  =  m c^2       (m in kg, E in joule)    |
  |                                                          |
  |    1 atomic mass unit                                    |
  |         1 u = 1/12 of the mass of a C-12 atom            |
  |             = 1.66 x 10^-27 kg                           |
  |                                                          |
  |    +--------------------------------------------+        |
  |    |        1 u   =   931.5  MeV                |        |
  |    +--------------------------------------------+        |
  |                                                          |
  |    E (in MeV)  =  dm (in u)  x  931.5                    |
  |                                                          |
  +----------------------------------------------------------+
```

|---|---|
| 1 u | 1.66 x 10^-27 kg |
| 1 u | 931.5 MeV |
| 1 eV | 1.6 x 10^-19 J |
| 1 MeV | 1.6 x 10^-13 J |
| 1 fermi | 10^-15 m |
| 1 barn | 10^-28 m^2 |

| mass of neutron | 1.008665 u = 939.6 MeV/c^2 |

# 4. MASS DEFECT AND BINDING ENERGY

```
  +--------------------------------------------------------------+
  |                                                              |
  |  MASS DEFECT                                                 |
  |                                                              |
  |     dm  =  [ Z mp  +  (A - Z) mn ]  -  M                     |
  |                                                              |
  |     (use mp = 1.007825 u, the H ATOM mass, when M is an      |
  |      ATOMIC mass -- the electrons then cancel out)           |
  |                                                              |
  +--------------------------------------------------------------+
  |                                                              |
  |  BINDING ENERGY                                              |
  |                                                              |
  |     BE  =  dm  c^2            (dm in kg  -> joule)           |
  |     BE  =  dm  x  931.5  MeV  (dm in u   -> MeV)             |
  |                                                              |
  +--------------------------------------------------------------+
  |                                                              |
  |  BINDING ENERGY PER NUCLEON                                  |
  |                                                              |
  |                    BE           dm x 931.5                   |
  |     BE / A   =   ------   =   ---------------   MeV          |
  |                     A                A                       |
  |                                                              |
  |     HIGHER BE/A  =  MORE STABLE                              |
  |                                                              |
  +--------------------------------------------------------------+
  |                                                              |
  |  PACKING FRACTION                                            |
  |                                                              |
  |                    M  -  A                                   |
  |          f   =   -----------      (M = exact atomic mass)    |
  |                       A                                      |
  |                                                              |
  |     Negative packing fraction -> stable nucleus              |
  |                                                              |
  +--------------------------------------------------------------+
```

| Formula | When to use |
|---|---|
| `dm = [Z mp + (A-Z) mn] - M` | Always the FIRST line of any binding-energy numerical |
| `BE = dm x 931.5` | Masses given in u, answer wanted in MeV |
| `BE = dm x c^2` | Masses given in kg, answer wanted in joule |
| `BE/A` | "Which nucleus is more stable?" — compare BE/A, never total BE |
| `E = (BE of products) - (BE of reactants)` | Energy released in fission or fusion using a BE/A graph |

# 5. THE BE-PER-NUCLEON CURVE — the facts to quote

```
  +----------------------------------------------------------------+
  |  1.  Rises steeply for A < 20  (H-2 only 1.1 MeV)              |
  |  2.  Sharp peaks at A = 4, 8, 12, 16  (He-4, Be-8, C-12, O-16) |
  |  3.  Nearly CONSTANT at about 8.5 MeV for A = 30 to 170        |
  |      -- proof of SATURATION of nuclear forces                  |
  |  4.  MAXIMUM  8.8 MeV  at  A = 56  (IRON = most stable)        |
  |  5.  Falls slowly beyond A = 170, down to 7.6 MeV at U-235     |
  |      -- because Coulomb repulsion between 92 protons grows     |
  |  6.  LEFT side rising  -> joining releases energy -> FUSION    |
  |  7.  RIGHT side falling-> splitting releases energy-> FISSION  |
  +----------------------------------------------------------------+
```

# 6. NUCLEAR FORCES — the facts to quote

```
  +------------------------------------------------------------------+
  |  1.  STRONGEST force in nature (100 x electrostatic,             |
  |      10^38 x gravitational)                                      |
  |  2.  SHORT RANGE -- only up to 2 to 3 fm; zero beyond 10 fm;     |
  |      does NOT obey the inverse square law                        |
  |  3.  CHARGE INDEPENDENT -- same for p-p, n-n and p-n             |
  |  4.  SATURATED -- acts only on nearest neighbours                |
  |  5.  SPIN DEPENDENT -- stronger for parallel spins               |
  |  6.  ATTRACTIVE for r > 0.8 fm , strongly REPULSIVE for          |
  |      r < 0.8 fm (a hard core that stops collapse)                |
  |  7.  Exchange in nature -- mediated by MESONS (Yukawa)           |
  |                                                                  |
  |  Equilibrium separation r0 = 0.8 fm ; PE at the minimum          |
  |  is about -100 MeV                                               |
  +------------------------------------------------------------------+
```

# 7. RADIOACTIVE DECAY — THE DISPLACEMENT LAWS

```
  +----------------------------------------------------------------+
  |                                                                |
  |  ALPHA        zX^A   -->   (z-2)Y^(A-4)  +  2He^4              |
  |               Z decreases by 2 , A decreases by 4              |
  |               e.g.  92U^238 --> 90Th^234 + 2He^4               |
  |                                                                |
  +----------------------------------------------------------------+
  |                                                                |
  |  BETA MINUS   zX^A   -->   (z+1)Y^A  +  -1e^0  + antineutrino  |
  |               Z increases by 1 , A unchanged                   |
  |               inside:  0n^1 --> 1p^1 + -1e^0 + antineutrino    |
  |               e.g.  6C^14 --> 7N^14 + -1e^0                    |
  |                                                                |
  +----------------------------------------------------------------+
  |                                                                |
  |  BETA PLUS    zX^A   -->   (z-1)Y^A  +  +1e^0  +  neutrino     |
  |               Z decreases by 1 , A unchanged                   |
  |               inside:  1p^1 --> 0n^1 + +1e^0 + neutrino        |
  |               e.g.  11Na^22 --> 10Ne^22 + +1e^0                |
  |                                                                |
  +----------------------------------------------------------------+
  |                                                                |
  |  GAMMA        zX^A (excited)  -->  zX^A (ground)  +  gamma     |
  |               NEITHER Z NOR A CHANGES                          |
  |               e.g.  28Ni^60* --> 28Ni^60 + gamma (1.17, 1.33)  |
  |                                                                |
  +----------------------------------------------------------------+
```

## Counting decays in a whole chain

```
  If  zX^A  becomes  z'Y^A'  after emitting  a  alphas and  b  betas:

           A - A'                                     A - A'
     a  =  ------           b  =  2a - (Z - Z')  =  2 x ------ - (Z - Z')
              4                                            4

  EXAMPLE:  92U^238 --> 82Pb^206
            a = (238-206)/4 = 32/4 = 8 alphas
            b = 2(8) - (92-82) = 16 - 10 = 6 betas
```

## Q value

```
  +--------------------------------------------------------------+
  |                                                              |
  |  Q  =  [ mass of reactants  -  mass of products ] x 931.5    |
  |                                                    MeV       |
  |                                                              |
  |  Q > 0  ->  energy released  ->  reaction is spontaneous     |
  |  Q < 0  ->  energy absorbed  ->  reaction cannot happen      |
  |             on its own                                       |
  |                                                              |
  |  The Q value appears as the KINETIC ENERGY of the products.  |
  |                                                              |
  +--------------------------------------------------------------+
```

# 8. THE LAW OF RADIOACTIVE DECAY  *** the heart of the chapter ***

```
  +--------------------------------------------------------------+
  |                                                              |
  |  BASIC LAW           - dN / dt   =   lambda N                |
  |                                                              |
  |  SOLUTION            N   =   N0  e^( - lambda t )            |
  |                                                              |
  |  IN TERMS OF MASS    m   =   m0  e^( - lambda t )            |
  |                                                              |
  |  IN TERMS OF         R   =   R0  e^( - lambda t )            |
  |  ACTIVITY                                                    |
  |                                                              |
  |  LOG FORM            ln ( N0 / N )   =   lambda t            |
  |                                                              |
  |                          2.303          ( N0 )               |
  |                lambda = -------  log10  ( -- )               |
  |                            t            ( N  )               |
  |                                                              |
  +--------------------------------------------------------------+
```

## Half life, mean life, decay constant

```
  +--------------------------------------------------------------+
  |                                                              |
  |  HALF LIFE        T   =   0.693 / lambda                     |
  |                                                              |
  |                   lambda  =  0.693 / T                       |
  |                                                              |
  |  MEAN LIFE        tau  =  1 / lambda                         |
  |                                                              |
  |                   tau  =  T / 0.693  =  1.44 T               |
  |                                                              |
  |                   T    =  0.693 tau                          |
  |                                                              |
  |  ALWAYS   tau  >  T                                          |
  |                                                              |
  +--------------------------------------------------------------+
```

## After n half lives

```
  +--------------------------------------------------------------+
  |                                                              |
  |      N            ( 1 )^n                     t              |
  |    -----   =      ( - )          where  n = -----            |
  |      N0           ( 2 )                       T              |
  |                                                              |
  |    Fraction REMAINING  =  (1/2)^n                            |
  |    Fraction DECAYED    =  1 - (1/2)^n                        |
  |                                                              |
  |    Number of nuclei DECAYED  =  N0 - N  =  N0 [1 - e^(-lt)]  |
  |                                                              |
  +--------------------------------------------------------------+
```

## Activity

```
  +--------------------------------------------------------------+
  |                                                              |
  |    ACTIVITY   R  =  lambda N   =  0.693 N / T                |
  |                                                              |
  |    R1 / R2  =  N1 / N2      (same isotope)                   |
  |                                                              |
  |    1 becquerel (Bq)  =  1 disintegration per second   [SI]   |
  |    1 curie (Ci)      =  3.7 x 10^10 Bq                       |
  |    1 millicurie      =  3.7 x 10^7 Bq                        |
  |    1 rutherford (Rd) =  10^6 Bq                              |
  |                                                              |
  +--------------------------------------------------------------+

  NUMBER OF NUCLEI IN A GIVEN MASS  (needed for almost every
  activity numerical)

                mass in gram
       N  =  -------------------- x 6.022 x 10^23
              atomic mass number
```

| Formula | When to use |
|---|---|
| `N = N0 e^(-lambda t)` | Time is NOT a whole number of half lives |
| `N = N0 (1/2)^n` | Time IS a whole number of half lives — much faster |
| `lambda = 0.693/T` | Converting between half life and decay constant |
| `tau = 1.44 T` | Any mean-life question |
| `R = lambda N` | "Find the activity in Bq or Ci" |
| `N = (m/A) x 6.022x10^23` | Activity of a given MASS of a sample |
| `lambda = (2.303/t) log10(N0/N)` | Awkward fractions like 20 %, 30 %, 1/3 |

# 9. NUCLEAR FISSION

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  92U^235 + 0n^1 --> 56Ba^141 + 36Kr^92 + 3 0n^1 + 200 MeV          |
  |                                                                    |
  |  92U^235 + 0n^1 --> 56Ba^144 + 36Kr^89 + 3 0n^1 + 200 MeV          |
  |                                                                    |
  |  ENERGY PER FISSION  =  about 200 MeV  =  3.2 x 10^-11 J           |
  |                                                                    |
  +--------------------------------------------------------------------+

  NEUTRON REPRODUCTION FACTOR

        neutrons produced in one generation
   k = -------------------------------------
        neutrons produced in the previous one

        k < 1  sub-critical    -> dies out
        k = 1  CRITICAL        -> reactor (controlled)
        k > 1  super-critical  -> bomb (uncontrolled)

  ENERGY FROM A MASS m OF U-235

        m (in g)
   N = ----------- x 6.022 x 10^23     then    E = N x 200 MeV
          235

  1 kg of U-235 -> 2.56 x 10^24 fissions -> 8.2 x 10^13 J

  POWER OF A REACTOR

                        Energy released           P x t
        P  =  --------------------------      N = -----------------
                       time                       200 x 1.6x10^-13

        (N = number of fissions needed in time t for power P watts)
```

## Reactor parts and their functions

| Part | Material | Function |
|---|---|---|
| Fuel | Enriched U-235 (2-3 %), Pu-239, U-233 | Supplies fissile nuclei |
| Moderator | Heavy water D2O, graphite, light water | **Slows** fast neutrons to thermal speed |
| Control rods | Cadmium, boron | **Absorb** surplus neutrons to keep k = 1 |
| Coolant | Water, D2O, liquid sodium, CO2 | Carries heat to the heat exchanger |
| Shielding | Thick concrete, lead | Stops gamma rays and neutrons escaping |

# 10. NUCLEAR FUSION

```
  +------------------------------------------------------------------+
  |                                                                  |
  |  1H^2 + 1H^2  --> 2He^3 + 0n^1  +  3.27 MeV                      |
  |  1H^2 + 1H^2  --> 1H^3  + 1H^1  +  4.03 MeV                      |
  |  1H^2 + 1H^3  --> 2He^4 + 0n^1  + 17.59 MeV   (easiest)          |
  |                                                                  |
  |  NET SOLAR REACTION                                              |
  |     4 (1H^1)  -->  2He^4 + 2(+1e^0) + 2 neutrinos + 26.7 MeV     |
  |                                                                  |
  +------------------------------------------------------------------+

  CONDITION FOR FUSION
     Coulomb barrier about 400 keV
     Classical requirement  (3/2) k T = 400 keV  ->  T about 3 x 10^9 K
     Actual (with tunnelling)                    ->  T about 1 x 10^7 K
     Core of the Sun = 1.5 x 10^7 K
```

## THE P-P CYCLE (the Sun)

```
   1H^1 + 1H^1  --> 1H^2 + +1e^0 + neutrino  +  0.42 MeV   (slowest step)
   +1e^0 + -1e^0 --> gamma + gamma           +  1.02 MeV
   1H^2 + 1H^1  --> 2He^3 + gamma            +  5.49 MeV
   2He^3 + 2He^3 --> 2He^4 + 1H^1 + 1H^1     + 12.86 MeV
   ------------------------------------------------------
   NET:  4 (1H^1) + 2(-1e^0) --> 2He^4 + 2 neutrinos + 6 gamma + 26.7 MeV
```

## THE CARBON-NITROGEN (CNO) CYCLE (hotter stars)

```
   6C^12 + 1H^1 --> 7N^13 + gamma
   7N^13        --> 6C^13 + +1e^0 + neutrino
   6C^13 + 1H^1 --> 7N^14 + gamma
   7N^14 + 1H^1 --> 8O^15 + gamma
   8O^15        --> 7N^15 + +1e^0 + neutrino
   7N^15 + 1H^1 --> 6C^12 + 2He^4        <-- carbon returns (CATALYST)
   ------------------------------------------------------
   NET:  4 (1H^1) --> 2He^4 + 2(+1e^0) + 2 neutrinos + 26.7 MeV
```
