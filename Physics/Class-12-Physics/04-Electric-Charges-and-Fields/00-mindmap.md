## THE 60-SECOND VERSION

Everything in this chapter answers ONE question:

```
  "There is a charge sitting somewhere.
   What does it DO to the space around it?"
```

The chapter answers it three times, each time more cleverly:

```
  LEVEL 1   COULOMB'S LAW   ->  charge pushes charge.  Needs TWO charges.
  LEVEL 2   ELECTRIC FIELD  ->  ONE charge fills space with "influence".
                                Any charge put there feels a force.
  LEVEL 3   GAUSS'S LAW     ->  count the field lines leaving a closed
                                surface; that count tells you the charge
                                inside. Fastest way to get E for symmetric
                                bodies.
```

If you understand only that ladder, half the chapter is already yours.

  |                       1        q1 q2                             |

  |                     4 pi e0      r^2                             |

  |        e0 = 8.854 x 10^-12  C^2 N^-1 m^-2                        |
  |                                                                  |
  |   In a medium of dielectric constant K, divide F by K.           |
  |                                                                  |

  +==================================================================+
  |                                                                  |
  |   GAUSS'S LAW                                                    |
  |                                                                  |
  |   The total electric flux through any CLOSED surface equals      |
  |   1/e0 times the NET charge enclosed by that surface.            |

  |                                            e0                    |
  |                                                                  |

  |                                                                  |

## THE ONE TABLE THAT EARNS THE MOST MARKS

```
  +------------------------------+-------------------------+-------------+
  |  SITUATION                   |  FIELD E                |  FALLS AS   |
  +------------------------------+-------------------------+-------------+
  |  Point charge                |  k Q / r^2              |  1 / r^2    |
  |  Dipole, AXIAL point         |  2 k p / r^3            |  1 / r^3    |
  |  Dipole, EQUATORIAL point    |  k p / r^3              |  1 / r^3    |
  |  Long straight wire          |  lambda / (2 pi e0 r)   |  1 / r      |
  |  Infinite plane sheet        |  sigma / (2 e0)         |  CONSTANT   |
  |  Between two opposite sheets |  sigma / e0             |  CONSTANT   |
  |  Outside a spherical shell   |  k Q / r^2              |  1 / r^2    |
  |  Inside a spherical shell    |  ZERO                   |  --         |
  +------------------------------+-------------------------+-------------+
```

**Notice the pattern of the powers.** It is the single most examined idea:

```
  Point charge     ->  1 / r^2     (a "0-dimensional" body)
  Line of charge   ->  1 / r^1     (a "1-dimensional" body)
  Sheet of charge  ->  1 / r^0     (a "2-dimensional" body) = constant
  Dipole           ->  1 / r^3     (because + and - almost cancel)
```

Every time you go one dimension bigger, the power of r drops by one.
Say that sentence out loud twice and you will never mix these up again.

## THE ONE-LINE WARNINGS

```
  *  Charge is a SCALAR. Force and field are VECTORS.
  *  In Coulomb's law put only the MAGNITUDES of charges; decide the
     direction (attraction or repulsion) by looking at the signs.
  *  r is the distance in METRES. Convert cm to m FIRST.
  *  Field lines NEVER intersect and NEVER form closed loops.
  *  Inside a charged conducting shell E = 0. Everywhere inside. Always.
  *  Gauss's law uses only the charge INSIDE the surface.
```
