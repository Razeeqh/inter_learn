# Electric Charges and Fields — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The numbers change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — PROPERTIES OF ELECTRIC CHARGE                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What are the properties of electric charge?" /
            "What is quantisation of charge?"
  METHOD    Name all three, one line each:
            1. QUANTISATION  Q = n e , e = 1.6 x 10^-19 C
            2. ADDITIVITY    charge is a SCALAR, add with signs
            3. CONSERVATION  total charge of an isolated system is fixed
  TRAP      Writing only the names without the equation Q = ne.
            The formula carries half the mark.
```

```
  PATTERN 2 — NUMBER OF ELECTRONS FROM A GIVEN CHARGE             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "How many electrons are in excess / deficit?" /
            "Can a body have a charge of 1.6 x 10^-20 C?"
  METHOD    1. n = Q / e , with e = 1.6 x 10^-19 C.
            2. If n is a whole number, the charge is possible.
            3. If n is a fraction, the charge is IMPOSSIBLE.
  TRAP      "Excess electrons" means the body is NEGATIVE.
            "Deficit of electrons" means it is POSITIVE.
```

```
  PATTERN 3 — CHARGE SHARED BETWEEN IDENTICAL SPHERES             2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Two identical spheres carrying q1 and q2 are brought into
            contact and then separated."
  METHOD              q1 + q2
            q'  =   -----------      on EACH sphere
                         2
  TRAP      Add the charges WITH THEIR SIGNS. +8 and -2 gives +3, not +5.
            The spheres must be IDENTICAL for this to work.
```

```
  PATTERN 4 — CHARGING BY FRICTION / CONDUCTION / INDUCTION       2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain charging by induction" /
            "Distinguish conduction and induction."
  METHOD    Induction in 4 numbered steps WITH diagrams:
            1. Bring the charged rod near (charges separate).
            2. EARTH the far side while the rod is still there.
            3. Remove the EARTHING first.
            4. Remove the ROD last.
            State: the body gets the OPPOSITE charge; the rod loses
            nothing.
  TRAP      The ORDER in steps 3 and 4. Remove the earth FIRST.
            Reversing it means the body stays neutral, and the examiner
            is looking for exactly this.
```

```
  PATTERN 5 — STATE COULOMB'S LAW (SCALAR AND VECTOR FORM)        2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State Coulomb's law" / "Write it in vector form."
  METHOD    1. Statement in words (product of charges, inverse square of
               distance, along the line joining them).
            2. Scalar form  F = q1 q2 / (4 pi e0 r^2).
            3. Vector form with the unit vector r21.
            4. Explain every symbol, give k = 9 x 10^9 N m^2 C^-2 and
               e0 = 8.854 x 10^-12 C^2 N^-1 m^-2.
            5. Say WHY the vector form is better: the sign of q1 q2
               automatically gives attraction or repulsion.
  TRAP      Forgetting the phrase "point charges AT REST". Coulomb's law
            is only for STATIC point charges.
```

```
  PATTERN 6 — EFFECT OF A MEDIUM / DIELECTRIC CONSTANT            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "The charges are placed in water / oil / a medium of
            dielectric constant K."
  METHOD                F_vacuum                  F_vacuum         e
            F_medium = -----------      and  K = ----------  =  ------
                            K                     F_medium        e0
  TRAP      DIVIDE by K, never multiply. K is dimensionless.
            K = 1 for vacuum, 80 for water, INFINITY for a metal.
```

```
  PATTERN 7 — SIMPLE COULOMB'S LAW NUMERICAL                      2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the force between two charges q1 and q2 placed r apart."
  METHOD    1. Convert microC -> 10^-6 C , nC -> 10^-9 C.
            2. Convert cm -> m.
            3. F = 9 x 10^9 x q1 x q2 / r^2 (magnitudes only).
            4. State ATTRACTIVE or REPULSIVE from the signs.
            5. Write the unit: newton.
  TRAP      Squaring 30 instead of 0.30. This one mistake costs more
            marks in this chapter than any other.
```

```
  PATTERN 8 — "FACTOR CHANGE" QUESTION                            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "If the distance is halved and each charge is doubled,
            what happens to the force?"
  METHOD    Do NOT recompute anything. Track factors only:
                F is proportional to q1 q2 / r^2
                each charge doubled   ->  x 2 x 2 = 4
                distance halved       ->  x 4
                answer                ->  16 F
  TRAP      Halving r MULTIPLIES the force by 4, it does not halve it.
```

```
  PATTERN 9 — SUPERPOSITION: FORCE ON ONE CHARGE OF SEVERAL       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Three / four charges are at the corners of a triangle /
            square. Find the force on one of them."
  METHOD    1. DRAW the figure and mark every charge.
            2. Draw the force ARROW on the target charge from each
               other charge (away if like, towards if unlike).
            3. Find each magnitude from F = k q1 q2 / r^2.
            4. Add as VECTORS.
               Shortcuts:  two equal forces at 60 deg  -> sqrt(3) F
                           two equal forces at 90 deg  -> sqrt(2) F
                           two equal forces at 120 deg -> F
            5. State the direction of the resultant.
  TRAP      In a square the DIAGONAL distance is a sqrt(2), so that
            force is F/2, not F.
```

```
  PATTERN 10 — NULL POINT / NEUTRAL POINT                         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Where is the electric field (or net force) zero?"
  METHOD    1. Decide WHERE the point can be:
                LIKE charges   ->  BETWEEN them
                UNLIKE charges ->  OUTSIDE, beyond the SMALLER charge
            2. Set  k q1 / x^2  =  k q2 / (d - x)^2  (or d + x).
            3. Take the SQUARE ROOT of both sides (this avoids a
               quadratic).
            4. Solve the resulting linear equation for x.
  TRAP      Forgetting to square-root and then wrestling with a
            quadratic. Also: the null point is always NEARER the
            SMALLER charge.
```

```
  PATTERN 11 — DEFINE ELECTRIC FIELD INTENSITY                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define electric field intensity. Give its unit."
  METHOD    "The force experienced by a UNIT POSITIVE TEST CHARGE
             placed at that point."
                E = F / q0   (as q0 -> 0)
            Unit: N C^-1 or V m^-1.  Dimensions: [M L T^-3 A^-1].
            It is a VECTOR.
  TRAP      Omitting the word POSITIVE, or omitting the unit.
            Also be ready for "why must q0 be very small?" — because a
            large test charge would disturb the source charges.
```

```
  PATTERN 12 — DERIVE E DUE TO A POINT CHARGE                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive an expression for the electric field due to a
            point charge."
  METHOD    1. Place a test charge q0 at distance r.
            2. F = k Q q0 / r^2   (Coulomb's law).
            3. E = F / q0  =  k Q / r^2 .
            4. State the direction (outward for +Q, inward for -Q).
            5. Note that E is independent of q0.
  TRAP      Leaving q0 in the final answer.
```

```
  PATTERN 13 — FIELD AT A POINT DUE TO SEVERAL CHARGES            4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the resultant field at the midpoint / at a corner."
  METHOD    1. Find each E from  E = k Q / r^2 (magnitude only).
            2. DRAW each field arrow: away from +, towards -.
            3. Add as vectors.
  TRAP      Two charges of OPPOSITE sign at the ends of a line give
            fields that ADD at the midpoint. Two LIKE charges give
            fields that CANCEL. Draw the arrows before deciding.
```

```
  PATTERN 14 — PROPERTIES OF ELECTRIC FIELD LINES                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the properties of electric lines of force" /
            "Why do field lines never intersect?"
  METHOD    Six properties: start on +, end on -; tangent gives
            direction; never intersect; crowding shows strength;
            never form closed loops; perpendicular to a conductor
            and absent inside it.
            For "why do they not intersect?" give the REASON:
            two tangents would mean two directions of E at one point.
  TRAP      A one-word answer. Every property needs its reason if the
            question says "why".
```

```
  PATTERN 15 — DRAW THE FIELD LINE PATTERN                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Draw the lines of force for a positive charge / a negative
            charge / two like charges / a dipole."
  METHOD    Single +   ->  radial arrows OUTWARD
            Single -   ->  radial arrows INWARD
            Two like   ->  lines bend away, NEUTRAL POINT in the middle
            Dipole     ->  curved lines from + to -, densest between
  TRAP      Forgetting the ARROWHEADS. A line without an arrow scores
            nothing. Also mark the neutral point for two like charges.
```

```
  PATTERN 16 — DEFINE DIPOLE AND DIPOLE MOMENT                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define electric dipole moment. Give its unit."
  METHOD    Dipole: a pair of EQUAL and OPPOSITE charges separated by
                    a SMALL distance 2a.
                    p = q x 2a
            Direction: from  -q  TOWARDS  +q.
            Unit: C m.  Dimensions: [L T A]. It is a VECTOR.
  TRAP      Getting the direction backwards. It is MINUS to PLUS
            (the opposite of the field-line direction inside the dipole).
```

```
  PATTERN 17 — DERIVE THE AXIAL FIELD OF A DIPOLE                 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive E on the axial line / end-on position of a dipole."
  METHOD    1. Draw the dipole with -q at A, +q at B, centre O, point P
               at distance r from O. Mark r - a and r + a.
            2. E1 = kq/(r-a)^2 towards P ;  E2 = kq/(r+a)^2 away from P.
            3. SUBTRACT: E = E1 - E2 (they are anti-parallel).
            4. Common denominator; numerator simplifies to 4ar.
            5. Use q(4ar) = 2 p r.
            6. Exact:  E = 2 k p r / (r^2 - a^2)^2
            7. Short dipole (r >> a):  E = 2 k p / r^3, PARALLEL to p.
  TRAP      Adding instead of subtracting. Forgetting to state the
            direction. Forgetting the "short dipole" step, which is
            usually the last 2 marks.
```

```
  PATTERN 18 — DERIVE THE EQUATORIAL FIELD OF A DIPOLE            8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive E on the equatorial line / broadside-on position."
  METHOD    1. Draw the dipole and P on the perpendicular bisector.
               Both distances are sqrt(r^2 + a^2), so E1 = E2.
            2. RESOLVE both into components.
            3. Perpendicular components CANCEL; components along the
               axis ADD.
            4. E = 2 E cos(theta), with cos(theta) = a/sqrt(r^2+a^2).
            5. Exact:  E = k p / (r^2 + a^2)^(3/2)
            6. Short dipole:  E = k p / r^3, ANTI-PARALLEL to p.
  TRAP      Forgetting the resolution step — the whole derivation is
            about which components survive. Also forgetting that the
            direction here is OPPOSITE to p.
```

```
  PATTERN 19 — COMPARE AXIAL AND EQUATORIAL FIELDS                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Compare the axial and equatorial fields of a short dipole"
            or "What is the ratio E_axial : E_equatorial?"
  METHOD    E_axial = 2kp/r^3 (parallel to p)
            E_eq    =  kp/r^3 (anti-parallel to p)
            Ratio 2 : 1 . Both vary as 1/r^3.
  TRAP      Saying 1/r^2. A dipole field falls as 1/r^3.
```

```
  PATTERN 20 — TORQUE ON A DIPOLE IN A UNIFORM FIELD              4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the torque on a dipole in a uniform field."
  METHOD    1. Draw the dipole at angle theta to E.
            2. Forces +qE and -qE.  NET FORCE = ZERO.
            3. They form a COUPLE; perpendicular distance = 2a sin(theta).
            4. tau = qE x 2a sin(theta) = p E sin(theta).
            5. Vector form  tau = p x E.
            6. Cases: theta = 0 -> 0 (stable);
                      theta = 90 -> pE (maximum);
                      theta = 180 -> 0 (unstable).
  TRAP      Forgetting to say the NET FORCE IS ZERO. That statement
            alone usually carries one mark.
            In a NON-uniform field the net force is NOT zero.
```

```
  PATTERN 21 — POTENTIAL ENERGY / WORK ON A DIPOLE                4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the potential energy of a dipole" /
            "Find the work done in rotating it from t1 to t2."
  METHOD    1. dW = tau d(theta) = pE sin(theta) d(theta).
            2. Integrate:  W = pE [ cos(t1) - cos(t2) ].
            3. Taking U = 0 at 90 degrees:  U = - p E cos(theta).
            4. Standard results: W(0 to 180) = 2pE ;
                                 W(0 to 90)  = pE ;
                                 U(0) = -pE (stable), U(180) = +pE.
  TRAP      Dropping the MINUS sign in U = -pE cos(theta).
            Also, cos(180) = -1, so 1 - (-1) = 2, giving 2pE not zero.
```

```
  PATTERN 22 — DEFINE ELECTRIC FLUX / FLUX NUMERICAL              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define electric flux" / "Find the flux through a square
            held at an angle in a uniform field."
  METHOD    phi = E A cos(theta), theta measured from the NORMAL.
            Unit N m^2 C^-1. SCALAR.
            theta = 0  -> maximum ;  theta = 90 -> zero.
  TRAP      If the question gives the angle with the PLANE of the
            surface, the angle with the NORMAL is (90 - that angle).
            Read the wording twice.
```

```
  PATTERN 23 — STATE AND PROVE GAUSS'S LAW                        4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State Gauss's law and prove it for a point charge."
  METHOD    1. Statement: total flux through any CLOSED surface
               = q(enclosed) / e0 .
            2. Take a point charge at the centre of a SPHERE of radius r.
            3. Say WHY the sphere is chosen: E is constant in magnitude
               on it AND parallel to dA everywhere.
            4. phi = E x 4 pi r^2 .
            5. Substitute E = kq/r^2 ; the r^2 cancels; phi = q / e0.
            6. Note that the result is independent of r, and hence of
               the shape of the surface.
  TRAP      Not justifying step 3. The justification is worth a mark.
```

```
  PATTERN 24 — FLUX THROUGH A CUBE / CLOSED SURFACE               2 marks
  ------------------------------------------------------------------------
  TRIGGER   "A charge q is at the centre / corner of a cube. Find the
            flux through the cube or through one face."
  METHOD    Total flux always = q(enclosed) / e0.
            Charge at the CENTRE : total q/e0 , one face q/(6 e0).
            Charge at a CORNER   : q/(8 e0) through that cube.
            Charge OUTSIDE       : ZERO.
            Charges of both signs: use the ALGEBRAIC sum.
  TRAP      Using the side length of the cube. It is never needed.
            If it is given, it is a deliberate distractor.
```

```
  PATTERN 25 — GAUSS'S LAW: INFINITE CHARGED WIRE                 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Using Gauss's law derive E due to an infinitely long
            straight uniformly charged wire."
  METHOD    1. State Gauss's law.
            2. Symmetry: E is RADIAL and constant at distance r.
            3. Gaussian surface: a CYLINDER of radius r, length l,
               coaxial with the wire. DRAW IT.
            4. Flux: curved surface E x 2 pi r l ;
                     two flat caps ZERO (E lies in their plane).
            5. Charge enclosed = lambda x l.
            6. E x 2 pi r l = lambda l / e0
                    ->   E = lambda / (2 pi e0 r) = 2 k lambda / r
            7. Note E varies as 1/r and that l cancels.
  TRAP      Not explaining WHY the flat caps give zero flux. That
            sentence is worth a mark on its own. Also, if l survives
            in your answer, you have made an algebra slip.
```

```
  PATTERN 26 — GAUSS'S LAW: INFINITE PLANE SHEET                  8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive E due to a uniformly charged infinite plane sheet."
  METHOD    1. Symmetry: E is PERPENDICULAR to the sheet, equal on
               both sides.
            2. Gaussian surface: a CYLINDER / PILLBOX of face area A
               pushed symmetrically through the sheet. DRAW IT.
            3. Flux: two flat caps give E A each, total 2 E A ;
                     curved side gives ZERO.
            4. Charge enclosed = sigma A.
            5. 2 E A = sigma A / e0    ->   E = sigma / (2 e0)
            6. Conclusion: E is INDEPENDENT of distance -> uniform field.
  TRAP      sigma/(2 e0) is for a thin NON-CONDUCTING sheet.
            Just outside a CONDUCTOR it is sigma/e0. Read the question.
```

```
  PATTERN 27 — FIELD BETWEEN TWO PARALLEL CHARGED SHEETS          4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the field between two parallel sheets carrying
            +sigma and -sigma."
  METHOD    1. Each sheet alone gives sigma/(2 e0).
            2. Draw the direction of each field in the three regions.
            3. BETWEEN: they point the same way -> ADD -> sigma/e0.
               OUTSIDE: they oppose -> CANCEL -> 0.
            4. Mention that this is the parallel plate capacitor.
            5. For two sheets both +sigma the results SWAP:
               between 0, outside sigma/e0.
  TRAP      Mixing up which case gives which. Always draw the arrows
            in all three regions before writing anything.
```

```
  PATTERN 28 — GAUSS'S LAW: CHARGED SPHERICAL SHELL               8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find E due to a uniformly charged thin spherical shell at
            a point outside / on / inside it."
  METHOD    OUTSIDE (r > R): Gaussian sphere radius r, q_enc = Q,
                             E x 4 pi r^2 = Q/e0  ->  E = kQ/r^2 .
                             State: behaves like a point charge at
                             the centre.
            SURFACE (r = R): E = kQ/R^2 = sigma/e0 , the MAXIMUM.
            INSIDE  (r < R): Gaussian sphere inside encloses ZERO
                             charge  ->  E = 0.
                             Mention ELECTROSTATIC SHIELDING.
            Finish with the E-versus-r GRAPH.
  TRAP      Confusing a hollow SHELL with a SOLID sphere.
            Shell inside E = 0. Solid sphere inside E = kQr/R^3
            (grows linearly). Examiners test this deliberately.
```

```
  PATTERN 29 — CONTINUOUS CHARGE DENSITIES                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define linear, surface and volume charge density."
  METHOD    lambda = q/L   (C m^-1)
            sigma  = q/A   (C m^-2)
            rho    = q/V   (C m^-3)
            Also know q_enclosed = lambda x length / sigma x area /
            rho x volume, which is how they enter Gauss's law.
  TRAP      Giving the formula but not the unit, or vice versa.
```

```
  PATTERN 30 — COMPARE ELECTROSTATIC AND GRAVITATIONAL FORCES     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Compare Coulomb's law with Newton's law of gravitation."
  METHOD    SIMILARITIES: both inverse-square, both central, both
                          long-range, both obey Newton's third law,
                          both conservative.
            DIFFERENCES:  electric can attract OR repel, gravity only
                          attracts; electric depends on the medium,
                          gravity does not; electric can be shielded;
                          electric is about 10^39 times stronger for
                          an electron-proton pair.
  TRAP      Giving only differences. The question usually wants BOTH.
```

# GUARANTEED-MARKS PLAN FOR THIS CHAPTER

## The 8-mark decision

```
  In Section C you answer any 2 of 3. This chapter almost always
  supplies one of the three. Prepare THESE FOUR derivations and you can
  walk into the hall knowing you already have one full 8-mark answer:

     1.  Gauss's law applied to a WIRE and a SHEET   (Pattern 25, 26)
     2.  Spherical SHELL, all three cases + graph    (Pattern 28)
     3.  Dipole field on the AXIAL line              (Pattern 17)
     4.  Dipole field on the EQUATORIAL line         (Pattern 18)
```

## What each derivation is worth, step by step

```
  +--------------------------------------------------+-------+
  |  PART OF THE ANSWER                              | MARKS |
  +--------------------------------------------------+-------+
  |  Correct labelled DIAGRAM                        |  1-2  |
  |  Statement of the law being used                 |   1   |
  |  Symmetry argument / choice of Gaussian surface  |   1   |
  |  Flux through each part, with reasons            |   2   |
  |  Charge enclosed                                 |   1   |
  |  Final boxed result + direction + variation      |  1-2  |
  +--------------------------------------------------+-------+

  NOTE: you can score 4 or 5 of the 8 marks from the diagram, the
  statement and the setup ALONE, even if the algebra goes wrong.
  So NEVER leave a Section C question blank.
```

## The minimum plan

Learn only these six things and you score about **12 out of 60**:

```
  1.  Coulomb's law: statement, scalar form, vector form, effect of K.
  2.  E = F/q and E = kQ/r^2 with directions.
  3.  The six properties of field lines.
  4.  p = q x 2a , tau = pE sin(theta) , U = -pE cos(theta).
  5.  Gauss's law: statement + proof for a point charge.
  6.  ONE full application derivation, done perfectly (the WIRE is the
      shortest, so start there).
```
