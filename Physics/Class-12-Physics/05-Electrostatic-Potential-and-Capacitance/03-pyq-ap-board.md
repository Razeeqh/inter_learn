## Topic: Potential

### Q A1
Define electric potential at a point. Give its SI unit.

**ANSWER:**
```
  The electric potential at a point is the WORK DONE by an external agent
  in bringing a UNIT POSITIVE charge from INFINITY to that point, slowly
  and without acceleration.

               W
        V  =  ---            SI unit:  volt (V) = joule / coulomb
               q

  It is a SCALAR quantity.
```

---

### Q A2
Define potential difference between two points.

**ANSWER:**
```
  The potential difference between two points A and B is the work done in
  carrying a unit positive charge from B to A.

                            W ( B -> A )
        V(A) - V(B)   =   ----------------
                                 q

  Unit: volt.
```

---

### Q A3
What is the work done in moving a charge of 10 micro-coulomb between two
points on an equipotential surface?

**ANSWER:** **ZERO.**
```
  Every point on an equipotential surface has the SAME potential.

        W  =  q ( V - V )  =  q x 0  =  0
```

---

### Q A4
Define an equipotential surface. Give one example.

**ANSWER:**
```
  A surface on which the electric potential has the SAME value at
  every point.

  Example: any sphere drawn around an isolated point charge.
           Also: the surface of any charged conductor.
```

---

### Q A5
Can two equipotential surfaces intersect each other? Give the reason.

**ANSWER:** **No.**
```
  If they intersected, the point of intersection would have TWO different
  potentials at the same time, which is impossible.
```

---

### Q A6
What is the potential at a point on the equatorial line of an electric dipole?

**ANSWER:** **ZERO.**
```
  Such a point is equally distant from +q and -q, so the two contributions
  k(+q)/r and k(-q)/r cancel exactly.
```

### Q A7
Write the relation between electric field and electric potential.

**ANSWER:**
```
             - dV
      E  =  ------            ( dV / dr = potential gradient )
              dr

  The minus sign shows that E points in the direction of DECREASING V.
  Unit of E:  volt / metre = newton / coulomb.

### Q A8
The electric potential in a region is constant. What is the electric field
there?

**ANSWER:** **ZERO.**
```
  E = - dV/dr .  If V is constant, dV/dr = 0 , so E = 0.
```

### Q A9
Is it possible for the electric potential to be zero at a point where the
electric field is not zero? Give an example.

**ANSWER:** **Yes.**
```
  At the midpoint of an electric dipole:
     V = 0     (the two scalar terms cancel)
     E is NOT zero (the two field vectors point the same way and add).
```

### Q A10
Define electron volt.

**ANSWER:**
```
  The energy gained by an electron when it is accelerated through a
  potential difference of one volt.

        1 eV  =  1.6 x 10^-19  J
```

## Topic: Conductors and dielectrics

### Q A11
What is the electric field inside a charged conductor? Why?

**ANSWER:** **Zero.**
```
  The free electrons rearrange themselves until the field they produce
  exactly cancels any applied field. This is electrostatic equilibrium.
```

---

### Q A12
What is electrostatic shielding? Give one use.

**ANSWER:**
```
  Since the field inside a conductor is zero, the cavity inside a hollow
  conductor is completely protected from any external electric field.
  This is called electrostatic shielding.

  USE: a car or aeroplane body protects the passengers during lightning;
       sensitive instruments are kept inside metal cases.
```

---

### Q A13
Why is the electric field just outside a charged conductor perpendicular to
its surface?

**ANSWER:**
```
  If E had a component ALONG the surface, the free charges would move along
  the surface and the conductor would not be in equilibrium.
  Therefore E must be entirely perpendicular, with E = sigma / e0 .
```

### Q A14
Distinguish between polar and non-polar molecules with one example each.

**ANSWER:**
```
  POLAR      -  the centres of positive and negative charge do NOT
                coincide; a PERMANENT dipole moment exists.
                Example: H2O , HCl

  NON-POLAR  -  the centres coincide; the dipole moment is ZERO
                until a field is applied.
                Example: O2 , H2 , CO2
```

### Q A15
Define dielectric constant (kappa).

**ANSWER:**
```
  The ratio of the permittivity of the medium to the permittivity of
  free space.

                 e            E0 (field without the dielectric)
      kappa  =  ----   =   -------------------------------------
                 e0           E  (field inside the dielectric)

  It has NO UNITS and is always greater than 1.
```

### Q A16
What is dielectric strength? Give its value for air.

**ANSWER:**
```
  The maximum electric field a dielectric can withstand before it breaks
  down and starts conducting.

  Unit:  V m^-1.       For air, about  3 x 10^6  V m^-1.
```

## Topic: Capacitance

### Q A17
Define capacitance. Give its SI unit and dimensional formula.

**ANSWER:**
```
  The charge required to raise the potential of a conductor by one volt.

           Q
      C = ---          SI unit: FARAD (F) = coulomb / volt
           V

  Dimensional formula:  [ M^-1 L^-2 T^4 A^2 ]
```

---

### Q A18
Define one farad.

**ANSWER:**
```
  A conductor has a capacitance of one farad if a charge of one coulomb
  raises its potential by one volt.

  The farad is very large, so we use uF (10^-6 F) and pF (10^-12 F).
```

---

### Q A19
On what factors does the capacitance of a parallel plate capacitor depend?

**ANSWER:**
```
  1.  The AREA A of the plates      ( C increases with A )
  2.  The SEPARATION d              ( C decreases as d increases )
  3.  The MEDIUM between them       ( C becomes kappa times larger )

  It does NOT depend on the charge given or the voltage applied.
```

---

### Q A20
What happens to the capacitance of a parallel plate capacitor when a
dielectric slab is introduced between the plates?

**ANSWER:**
```
  The capacitance INCREASES, becoming kappa times its original value.
  The dielectric gets polarised and reduces the field between the plates,
  which reduces V, and since C = Q / V , C rises.
```

### Q A21
Three capacitors each of capacitance C are connected (a) in series
(b) in parallel. Find the equivalent capacitance in each case.

**ANSWER:**
```
  (a)  SERIES:      1/Ceq = 1/C + 1/C + 1/C = 3/C      ->   Ceq = C / 3

  (b)  PARALLEL:    Ceq = C + C + C                    ->   Ceq = 3 C
```

### Q B1
Derive an expression for the electric potential due to a point charge.

**ANSWER:**
```
                              <---- F = k Q q0 / x^2
   Q                     q0
   o------------------->  o  <------ dx
   |                      |
   |<-------- x --------->|
   |<---------- r --------------->| P

  Let a charge +Q be at the origin and a test charge +q0 be at a
  distance x from it. The force on q0 is

              1     Q q0
      F  =  ------ -------
            4pi e0   x^2

  The small work done by the external agent in moving q0 through dx
  towards Q is

      dW  =  - F dx

  Total work in bringing q0 from infinity to the point P at distance r:

               r                                     +-      -+ r
      W  =   Int  ( - k Q q0 / x^2 ) dx  = - k Q q0  | -1 / x |
              inf                                    +-      -+ inf

                        +-  1        1  -+          k Q q0
      W  =     k Q q0   | ---   -   ---- |    =   ----------
                        +-  r       inf  -+            r

  By definition  V = W / q0 :

      +--------------------------------------------------+
      |                  1        Q            Q         |
      |         V  =   -------  x ---   =  k  ---        |
      |                4 pi e0     r            r        |
      +--------------------------------------------------+

  V varies as 1/r , while E varies as 1/r^2 .
```

### Q B4
Prove that the electric field is always perpendicular to an equipotential
surface.

**ANSWER:**
```
  Suppose the field E had a component E(t) ALONG the surface.

  Moving a test charge q a small distance dl along the surface would then
  need work
                 dW  =  q E(t) dl        which is NOT zero.

  But all points on the surface have the SAME potential, so the work done
  between any two of them is
                 dW  =  q ( V - V )  =  0.

  These two statements contradict each other. Hence E(t) must be zero.

  Therefore the electric field has NO component along an equipotential
  surface, i.e. E is always PERPENDICULAR to it.
```

### Q B5
Derive the relation between electric field and potential gradient.

**ANSWER:**
```
  Consider two equipotential surfaces separated by a small distance dr,
  with potentials V and V + dV.

         V           V + dV
         |             |
         |<--- dr ---->|
         |             |
    <----+-------------+---- E
         |             |

  To move a unit positive charge from the first surface to the second
  against the field, the work done is

         dW  =  - E dr

  But by definition this work equals the change in potential:

         dW  =  dV

  Therefore
         dV  =  - E dr

       +--------------------------------------------------+
       |                       - dV                       |
       |              E   =   ------                      |
       |                        dr                        |
       +--------------------------------------------------+

  dV / dr is the POTENTIAL GRADIENT. The minus sign shows that E is
  directed from HIGH potential to LOW potential.
  Unit of E:  V m^-1 = N C^-1.
```

### Q B6
Derive an expression for the potential energy of a system of three point
charges.

**ANSWER:**
```
                q1
                 o
                / \
          r12  /   \  r31
              /     \
             o-------o
            q2  r23   q3

  Bring the charges in one at a time from infinity.

  STEP 1  Bring q1. There is no field yet, so  W1 = 0.

                        r12

             W3 = q3| -------- + -------| =    ---------- + ----------
                    +-   r31       r23 -+         r31          r23

  Total potential energy U = W1 + W2 + W3 :

    +------------------------------------------------------------+
    |             1     +-  q1 q2      q2 q3      q3 q1  -+      |
    |    U   =  ------- |  --------  + -------- + --------|      |
    |           4 pi e0 +-   r12         r23        r31  -+      |

  In general n charges give n(n-1)/2 terms.

### Q B7
Derive an expression for the potential energy of an electric dipole placed in
a uniform electric field. State when it is minimum and maximum.

**ANSWER:**
```
              E ---->    E ---->    E ---->

                            +q
                             o
                            /|          force qE
                       2a  / |
                          /  | theta
                         o---+---------->  E
                        -q

  In a uniform field the two forces qE are equal and opposite, so there is
  no net force, only a TORQUE

        tau  =  ( q E ) x ( 2a sin theta )  =  p E sin theta

  Work done in rotating the dipole through a small angle d(theta):

        dW  =  tau d(theta)  =  p E sin theta  d(theta)

  Total work in turning it from theta1 to theta2:

                 theta2
        W  =   Int      p E sin theta d(theta)
                theta1

           =   p E ( cos theta1  -  cos theta2 )

  Taking theta1 = 90 degrees as the reference (where U = 0):

        U  =  p E ( cos 90 - cos theta )

    +------------------------------------------------------------+
    |               U   =   -  p E cos theta                     |
    +------------------------------------------------------------+

    theta = 0    ->   U = - p E    MINIMUM   -> STABLE equilibrium
    theta = 90   ->   U =   0
    theta = 180  ->   U = + p E    MAXIMUM   -> UNSTABLE equilibrium

  Work needed to flip the dipole from 0 to 180 degrees  =  2 p E.
```

### Q B8
Derive an expression for the equivalent capacitance of three capacitors
connected in SERIES.

**ANSWER:**
```
       ---||-----------||-----------||---
          C1           C2           C3
      |<-V1->|     |<-V2->|     |<-V3->|
      |<------------- V ------------->|

  In series the SAME charge Q appears on every capacitor, because the
  inner plates are isolated and charge is conserved. The applied voltage
  is shared:

        V  =  V1 + V2 + V3

  For each capacitor  V1 = Q/C1 , V2 = Q/C2 , V3 = Q/C3 , and for the
  combination V = Q/C. Substituting:

         Q        Q       Q       Q
        ---  =   ----  + ----  + ----
         C        C1      C2      C3

  Cancelling Q throughout:

    +------------------------------------------------------------+
    |            1        1       1       1                      |
    |          -----  =  ----  + ----  + ----                    |
    |            C        C1      C2      C3                     |
    +------------------------------------------------------------+

  The equivalent capacitance is SMALLER than the smallest capacitor.
  For two capacitors:   C = C1 C2 / ( C1 + C2 ).
```

### Q B9
Derive an expression for the equivalent capacitance of three capacitors

### Q B10
Derive an expression for the energy stored in a capacitor. Hence obtain the
energy density of an electric field.

**ANSWER:**
```
  Let the capacitor already hold a charge q, so its potential is  V = q/C .
  The small work done in bringing a further charge dq onto it is

         dW  =  V dq  =  ( q / C ) dq

  Total work in charging it from 0 to Q:

                Q                    +-      -+ Q
              Int    q               |  q^2   |          Q^2
       W  =   ----  --- dq  = (1/C)  | ------ |      =  ------
               0     C               |   2    | 0        2 C
                                     +-      -+

  This work is stored as electrostatic energy:

    +------------------------------------------------------------+
    |            Q^2         1              1                    |
    |     U  =  ------  =   --- Q V   =    --- C V^2             |
    |            2 C         2              2                    |
    +------------------------------------------------------------+

  ENERGY DENSITY

  For a parallel plate capacitor  C = e0 A / d  and  V = E d .
  The field occupies the volume A d, so

              U        (1/2) ( e0 A / d ) ( E d )^2          1
       u  =  ------ =  -----------------------------  =     --- e0 E^2
              A d                 A d                        2

    +------------------------------------------------------------+
    |                  u   =   (1/2) e0 E^2      J m^-3          |
    +------------------------------------------------------------+
```

### Q B11
A 900 pF capacitor is charged by a 100 V battery. (a) How much electrostatic
energy is stored? (b) The capacitor is disconnected and then connected to
another uncharged 900 pF capacitor. How much energy is stored now, and how much

```
  (a)  U  =  (1/2) C V^2  =  (1/2)( 900 x 10^-12 )( 100 )^2

               C1 V1 + C2 V2      ( 900 )( 100 ) + 0
         V  =  ---------------  = --------------------  =  50 V

         U'  =  (1/2)( 1800 x 10^-12 )( 50 )^2

             =  (1/2)( 1800 x 10^-12 )( 2500 )  =  2.25 x 10^-6  J

       ENERGY LOST  =  4.5 x 10^-6  -  2.25 x 10^-6  =  2.25 x 10^-6 J

  Exactly HALF the energy is lost as heat in the connecting wires.
```

### Q B14
State and explain the properties of a conductor in electrostatic equilibrium.

**ANSWER:**
```
  1.  E INSIDE THE CONDUCTOR IS ZERO.
      The free electrons move until their field cancels any applied field.

  2.  ALL EXCESS CHARGE LIES ON THE OUTER SURFACE.
      By Gauss's law, if E = 0 inside, the charge enclosed by any internal
      surface must be zero, so the charge has to be on the outside.

  3.  E JUST OUTSIDE IS PERPENDICULAR TO THE SURFACE, E = sigma / e0 .
      A tangential component would push the surface charges sideways and
      equilibrium would be destroyed.

  4.  THE WHOLE CONDUCTOR IS AT ONE POTENTIAL.
      Since E = 0 inside, dV/dr = 0 inside, so V does not change.

  5.  CHARGE DENSITY IS GREATEST AT SHARP POINTS.
      This is used in lightning conductors and in the Van de Graaff
      generator.
```

### Q B15
Explain electrostatic shielding and give two of its applications.

**ANSWER:**
```
  Because the electric field inside a conductor is always zero, the space
  inside a hollow conductor is completely free from any external electric
  field, however strong that field may be. This protection of the interior
  is called ELECTROSTATIC SHIELDING, and the enclosure is called a
  FARADAY CAGE.

           external field  E0  ---->
               ____________________
              /                    \
     ---->   |    ____________      |   ---->
     ---->   |   |   E = 0    |     |   ---->
     ---->   |   |   SAFE     |     |   ---->
              \__|____________|_____/

  APPLICATIONS
    1.  A car or an aeroplane acts as a Faraday cage, so the passengers
        are safe during a lightning strike.
    2.  Sensitive electronic equipment is enclosed in metal cases;
        coaxial cables use a metal braid for the same reason.
```

### Q B16
Explain polarisation of a dielectric. Show that the field inside a dielectric
is reduced.

**ANSWER:**
```
  A dielectric has no free charges. When an external field E0 is applied:

    - NON-POLAR molecules get stretched, so an induced dipole moment
      appears along E0.
    - POLAR molecules already have a dipole moment; they simply TURN
      and line up along E0.

  In both cases the molecules line up:

           |                                       |
          -|  + - + - + - + - + - + - + - +        |+
          -|  + - + - + - + - + - + - + - +        |+
          -|  + - + - + - + - + - + - + - +        |+
           |                                       |
      bound NEGATIVE charge                 bound POSITIVE charge

  Inside the slab the + of one molecule sits next to the - of the next and
  they cancel, so no net charge appears in the bulk. Only the two FACES
  carry BOUND CHARGE. This is called POLARISATION.

  The bound charges set up their own field Ep OPPOSITE to E0, so the net
  field inside is

                                        E0
        E  =  E0  -  Ep      =      -----------
                                      kappa

  Since E is reduced, V = E d is reduced, and because C = Q / V the
  capacitance INCREASES kappa times.
```

### Q C1  *** THE MOST REPEATED LONG ANSWER IN THIS CHAPTER ***
Define capacitance. Derive an expression for the capacitance of a parallel
plate capacitor. Explain the effect of introducing a dielectric slab between
the plates.

**ANSWER:**

**Part 1 — Definition (1 mark)**
```
  The capacitance of a conductor is the charge required to raise its
  potential by one volt.

           Q
      C = ---            SI unit: farad (F) = C V^-1
           V

  Capacitance depends only on the SIZE, SHAPE and SURROUNDING MEDIUM of
  the conductors, not on the charge given or the voltage applied.
```

**Part 2 — Construction and diagram (1 mark)**
```
                          area A
     +Q   ============================================   plate 1
          |     |     |     |     |     |     |     |
          |     |     |     |     |     |     |     |    E = sigma / e0
          v     v     v     v     v     v     v     v
                                                          gap = d
     -Q   ============================================   plate 2

  Two large parallel conducting plates, each of area A, carrying charges
  +Q and -Q, separated by a small distance d, with vacuum between them.
```

**Part 3 — Derivation of C = e0 A / d (4 marks)**
```
  STEP 1   The surface charge density on each plate is

                      Q
            sigma = -----
                      A

  STEP 2   From Gauss's law, the field due to ONE infinite charged sheet is

                       sigma
            E1  =  -----------
                      2 e0

  STEP 3   BETWEEN the plates, the fields of the positive and the negative
           sheet point in the SAME direction and therefore ADD:

                     sigma       sigma        sigma           Q
            E   =  ---------- + ---------- = --------  =  ---------
                      2 e0        2 e0          e0          e0 A

           OUTSIDE the plates the two fields are opposite and cancel,
           so E = 0 outside. The field between the plates is UNIFORM.

  STEP 4   For a uniform field the potential difference between the plates
           is

                                         Q d
            V  =  E d          =>   V = --------
                                         e0 A

  STEP 5   By definition C = Q / V :

                       Q                Q
            C   =   -------   =  ----------------
                       V           Q d / ( e0 A )

           +--------------------------------------------------+
           |                                                  |
           |                      e0 A                        |
           |             C   =   -------                      |
           |                        d                         |
           |                                                  |
           +--------------------------------------------------+

  CONCLUSION:  C depends only on the GEOMETRY (A and d) of the capacitor
  and on the MEDIUM. It is independent of Q and V.
     - Larger plates  ->  larger C
     - Smaller gap    ->  larger C
```

**Part 4 — Effect of a dielectric slab (2 marks)**
```
  (a)  SLAB COMPLETELY FILLING THE GAP

       The dielectric gets polarised and reduces the field to E0 / kappa,
       so V falls to V0 / kappa and

                    kappa e0 A
             C  =  -------------   =   kappa  x  C0
                         d

       The capacitance is INCREASED kappa times.

  (b)  SLAB OF THICKNESS t PARTLY FILLING THE GAP

     +Q   ============================================
          |            air gap  d - t                |
          ############################################   slab, kappa
          |            air gap                       |
     -Q   ============================================

             V  =  E0 ( d - t )  +  ( E0 / kappa ) t

                            e0 A
             C  =  ---------------------------
                     ( d - t )  +  t / kappa

       CHECKS:   t = 0  ->  C = e0 A / d
                 t = d  ->  C = kappa e0 A / d
                 kappa = infinity (a metal slab)  ->  C = e0 A / (d - t)

  In every case a dielectric INCREASES the capacitance.
```

### Q C2
Derive an expression for the electric potential due to a point charge. Define
an equipotential surface, state its properties, and draw the equipotential
surfaces for a point charge, a uniform field and a dipole.

**ANSWER:**

**Part 1 — Potential due to a point charge (4 marks)**
```
   Q                     q0
   o------------------->  o  <------ dx
   |                      |
   |<-------- x --------->|
   |<---------- r ------------------>| P

  Force on the test charge q0 at a distance x from Q:

              1     Q q0
      F  =  ------ -------
            4pi e0   x^2

  Work done by the external agent in moving q0 a distance dx towards Q:

      dW  =  - F dx

  Total work in bringing q0 from infinity to P at a distance r:

              r                                    +-       -+ r
      W  =  Int  ( - k Q q0 / x^2 ) dx = - k Q q0  | - 1 / x |
             inf                                   +-       -+ inf

                       +-  1        1  -+          k Q q0
      W  =    k Q q0   | ---   -   ---- |   =    ----------
                       +-  r       inf  -+            r

      +--------------------------------------------------+
      |            W        1        Q            Q      |
      |     V  =  ----  = -------  x ---  =   k  ---     |
      |            q0     4 pi e0     r            r     |
      +--------------------------------------------------+

  Note that V goes as 1/r while E goes as 1/r^2.
  V is POSITIVE for a positive charge and NEGATIVE for a negative charge.
  V = 0 at infinity.
```

**Part 2 — Equipotential surfaces (2 marks)**
```
  DEFINITION: a surface every point of which is at the SAME potential.

  PROPERTIES
    1.  No work is done in moving a charge over the surface.
    2.  E is always PERPENDICULAR to the surface.
        (If it were not, there would be a component along the surface
         doing work, contradicting the constant potential.)
    3.  Two equipotential surfaces never intersect, otherwise the point of
        intersection would have two potentials at once.
    4.  Closely packed surfaces mean a strong field, since E = -dV/dr.
    5.  A conductor's surface and interior form one equipotential region.
```

### Q C3
What is a capacitor? Derive expressions for the equivalent capacitance of
capacitors connected in series and in parallel. Derive the expression for the
energy stored in a capacitor.

**ANSWER:**

**Part 1 — Capacitor (1 mark)**
```
  A capacitor is an arrangement of two conductors separated by an insulator,
  used to store electric charge and electrical energy.

      Q = C V         C = capacitance, unit FARAD.
```

**Part 2 — SERIES combination (2.5 marks)**
```
       ---||-----------||-----------||---
          C1           C2           C3
      |<-V1->|     |<-V2->|     |<-V3->|
      |<------------- V ------------->|

  The inner plates are isolated, so the SAME charge Q appears on all three.
  The applied voltage divides:

       V  =  V1 + V2 + V3

       Q         Q      Q      Q
      ---   =   ---- + ---- + ----
       C         C1     C2     C3

  Cancelling Q:

       +--------------------------------------------------+
       |          1        1       1       1              |
       |        -----  =  ----  + ----  + ----            |
       |          C        C1      C2      C3             |
       +--------------------------------------------------+

  The equivalent capacitance is LESS than the smallest capacitor.
  For two:   C = C1 C2 / ( C1 + C2 ).
```

**Part 3 — PARALLEL combination (2 marks)**
```
                +------||------+
                |      C1      |
         -------+------||------+-------
                |      C2      |
                +------||------+
                       C3
         |<---------- V ---------->|

  The SAME voltage V is across all three. The charges add:

       Q   =  Q1 + Q2 + Q3
      C V  =  C1 V + C2 V + C3 V

  Cancelling V:

       +--------------------------------------------------+
       |             C  =  C1 + C2 + C3                   |
       +--------------------------------------------------+

  The equivalent capacitance is GREATER than the largest capacitor.
```

**Part 4 — Energy stored (2.5 marks)**
```
  Let the capacitor already carry a charge q, so its potential is q/C.
  Work needed to add a further small charge dq:

       dW  =  V dq  =  ( q / C ) dq

  Total work in charging from 0 to Q:

               Q                    +-      -+ Q
             Int   q                |  q^2   |         Q^2
      W  =   ----  --- dq = (1/C)   | ------ |    =   ------
              0     C               |   2    | 0       2 C
                                    +-      -+

       +--------------------------------------------------+
       |          Q^2        1             1              |
       |   U  =  ------  =  --- Q V   =   --- C V^2       |
       |          2 C        2             2              |
       +--------------------------------------------------+

  The battery supplies Q V but only (1/2) Q V is stored; the other half
  is lost as heat in the wires.

  ENERGY DENSITY:   u  =  U / ( A d )  =  (1/2) e0 E^2      J m^-3
```

### Q C4
Derive an expression for the electric potential energy of a system of charges.
A dipole is placed in a uniform external field: derive its potential energy and
discuss the stable and unstable positions.

**ANSWER:**

**Part 1 — Two charges (2 marks)**
```
  Bring q1 from infinity: no field exists yet, so no work is done.
  Bring q2 to a distance r12 from q1. The potential there is k q1 / r12,
  so the work done is

       +--------------------------------------------------+
       |                     k q1 q2                      |
       |            U   =   ----------                    |
       |                       r12                        |
       +--------------------------------------------------+

  U is POSITIVE for like charges (energy had to be supplied) and
  NEGATIVE for unlike charges (the system is bound).
```

**Part 2 — Three charges (2 marks)**
```
                q1
                 o
                / \
          r12  /   \  r31
              /     \
             o-------o
            q2  r23   q3

  Adding the work for each charge as it is brought in:

       +------------------------------------------------------------+
       |            +-  q1 q2      q2 q3      q3 q1  -+             |
       |   U  =  k  |  --------  + -------- + --------|             |
       |            +-   r12         r23        r31  -+             |
       +------------------------------------------------------------+

  Exactly one term per PAIR:  n charges give n(n-1)/2 terms.
```

**Part 3 — Dipole in a uniform field (4 marks)**
```
              E ---->    E ---->    E ---->

                            +q
                             o
                            /|          force qE
                       2a  / |
                          /  | theta
                         o---+---------->  E
                        -q            force qE (opposite)

  The two forces qE are equal and opposite, so the net FORCE is zero,
  but they form a COUPLE with torque

       tau  =  ( q E ) ( 2a sin theta )  =  p E sin theta

  Work done in turning the dipole through d(theta):

       dW  =  p E sin theta  d(theta)

                theta2
       W  =  Int      p E sin theta d(theta)
               theta1

          =  p E ( cos theta1 - cos theta2 )

  Taking theta1 = 90 degrees as the zero of energy:

       +--------------------------------------------------+
       |             U   =   -  p E cos theta             |
       +--------------------------------------------------+

  DISCUSSION

  +-----------+---------------+-------------+------------------------+
  |  theta    |   TORQUE      |     U       |  EQUILIBRIUM           |
  +-----------+---------------+-------------+------------------------+
  |    0 deg  |      0        |   - p E     |  STABLE (minimum U)    |
  |   90 deg  |   p E  MAX    |     0       |  --                    |
  |  180 deg  |      0        |   + p E     |  UNSTABLE (maximum U)  |
  +-----------+---------------+-------------+------------------------+

  A dipole always tries to turn until p is ALONG E, where its energy
  is least. The work needed to flip it from 0 to 180 degrees is 2 p E.
```

### Q C5
Explain the behaviour of dielectrics in an electric field. Derive the
expression for the capacitance of a parallel plate capacitor with a dielectric
slab partly filling the gap, and discuss the effect of inserting the slab with
the battery connected and with the battery disconnected.

**ANSWER:**

**Part 1 — Dielectrics and polarisation (3 marks)**
```
  A dielectric is an insulator; it has no free charges, so no current can
  flow through it. Its molecules are of two kinds:

    NON-POLAR   -  centres of + and - charge COINCIDE; no permanent
                   dipole moment. Examples: H2, O2, CO2.
                   In a field they get STRETCHED and acquire an
                   induced dipole moment.

    POLAR       -  centres of + and - charge are SEPARATED even without
                   a field. Examples: H2O, HCl, NH3.
                   In a field they simply TURN and line up.

  In both cases the molecular dipoles line up with E0:

           |                                       |
          -|  + - + - + - + - + - + - + - +        |+
          -|  + - + - + - + - + - + - + - +        |+
          -|  + - + - + - + - + - + - + - +        |+
           |                                       |
       bound NEGATIVE                        bound POSITIVE

  In the bulk the charges cancel; only the two FACES carry BOUND CHARGE.
  This is POLARISATION. The bound charge produces a field Ep opposing E0,
  so

                                E0
        E  =  E0  -  Ep   =  ---------           kappa > 1 always
                              kappa

  kappa is the DIELECTRIC CONSTANT (relative permittivity). It has no
  units.
```

**Part 2 — Capacitance with a slab of thickness t (3 marks)**
```
     +Q   ============================================
          |                                          |
          |         air gap of total width d - t     |
          ############################################   slab of
          ############################################   thickness t
          |                                          |   constant kappa
     -Q   ============================================

  In the air gaps the field is    E0  =  sigma / e0  =  Q / ( e0 A )
  Inside the slab it is reduced   E   =  E0 / kappa

  Total potential difference across the capacitor:

        V  =  E0 ( d - t )  +  ( E0 / kappa ) t

               Q     +-                 t     -+
        V  =  ------ |  ( d - t )  +  ------   |
              e0 A   +-                kappa  -+

  Using C = Q / V :

       +--------------------------------------------------+
       |                        e0 A                      |
       |         C  =  -----------------------------      |
       |                 ( d - t )  +  t / kappa          |
       +--------------------------------------------------+

  CHECKS
     t = 0                  ->  C = e0 A / d
     t = d                  ->  C = kappa e0 A / d
     kappa = infinity       ->  C = e0 A / ( d - t )   (metal slab)

  The slab always INCREASES C, wherever it is placed in the gap.
```

**Part 3 — Battery connected or disconnected (2 marks)**
```
  +--------------+--------------------------+--------------------------+
  |  QUANTITY    |  BATTERY CONNECTED       |  BATTERY DISCONNECTED    |
  |              |  ( V is constant )       |  ( Q is constant )       |
  +--------------+--------------------------+--------------------------+
  |   C          |  increases kappa times   |  increases kappa times   |
  |   V          |  UNCHANGED               |  falls to  V / kappa     |
  |   Q          |  rises to  kappa Q       |  UNCHANGED               |
  |   E          |  UNCHANGED  (E = V/d)    |  falls to  E / kappa     |
  |   U          |  rises to  kappa U       |  falls to  U / kappa     |
  +--------------+--------------------------+--------------------------+

  BATTERY CONNECTED: V is fixed by the battery. Since C increases,
  Q = C V increases, and the extra charge is supplied by the battery.
  The stored energy U = (1/2) C V^2 therefore rises.

  BATTERY DISCONNECTED: the charge Q is trapped on the plates and cannot
  change. Since C increases, V = Q / C falls, and U = Q^2 / (2C) falls.
  The lost energy is the work done by the field in pulling the slab in.
```
