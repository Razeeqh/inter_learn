# Wave Optics — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The numbers change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — DEFINE A WAVEFRONT / NAME ITS TYPES                 2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is a wavefront?"  "Name the types of wavefront."
            "What is the shape of the wavefront from ...?"
  METHOD    1. "A wavefront is the LOCUS of all points of a medium
               vibrating in the SAME PHASE."
            2. Three types:
                  SPHERICAL    <- point source
                  CYLINDRICAL  <- line source / slit
                  PLANE        <- source at infinity (sun, laser, star)
            3. Add: "a ray is the NORMAL to the wavefront."
  TRAP      Writing "circular". In three dimensions it is SPHERICAL.
            Also: light from a point source at the FOCUS of a convex lens
            gives a PLANE wavefront, not a spherical one.
```

```
  PATTERN 2 — STATE HUYGENS' PRINCIPLE                            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "State Huygens' principle."
  METHOD    1. Every point on a wavefront acts as a source of SECONDARY
               WAVELETS travelling out with the speed of light in that
               medium.
            2. The FORWARD ENVELOPE (common tangent) of these wavelets
               after time t gives the NEW wavefront.
  TRAP      Writing only part (1). BOTH sentences are needed — one mark
            each. The words "secondary wavelets" and "forward envelope"
            are the mark-carrying words.
```

```
  PATTERN 3 — HUYGENS' CONSTRUCTION FOR A PLANE / SPHERICAL       4 marks
             WAVEFRONT
  ------------------------------------------------------------------------
  TRIGGER   "Using Huygens' principle, construct the new position of a
            plane (or spherical) wavefront."
  METHOD    1. State the principle first (it carries marks by itself).
            2. Draw AB, the wavefront now. Mark points 1, 2, 3, 4 on it.
            3. Draw a circle of radius r = v t about each point.
            4. Draw the common tangent A'B' on the FORWARD side.
            5. Label A'B' as the new wavefront, and label the gap as v t.
            6. Add the note that the BACKWARD envelope is ignored because
               the wavelet intensity is zero backwards.
  TRAP      Not labelling the radius as v t, and forgetting to say
            "common tangent". Those two labels are worth a mark.
```

```
  PATTERN 4 — PROVE THE LAWS OF REFLECTION BY HUYGENS          4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Using Huygens' principle prove the laws of reflection."
  METHOD    1. State Huygens' principle.
            2. Draw: incident wavefront AB hitting mirror XY; A arrives
               at P; B still has BQ to travel; wavelet from P of radius
               PC; tangent QC = reflected wavefront. Mark i and r.
            3. Say BOTH travel in the SAME medium, so PC = c t = BQ.
            4. Triangles PBQ and PCQ: two right angles, PC = BQ, PQ
               common  ->  CONGRUENT by RHS.
            5. Therefore angle BPQ = angle CQP , i.e.  i = r.  (LAW 1)
            6. All lines lie in one plane -> incident ray, reflected ray
               and normal are COPLANAR.  (LAW 2)
  TRAP      Skipping step 3. Without "same medium, so equal distances in
            equal times" the congruence is unjustified and you lose marks.
            Also: you must state BOTH laws at the end, not just i = r.
```

```
  PATTERN 5 — PROVE SNELL'S LAW BY HUYGENS                    4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Using Huygens' principle derive Snell's law / prove the laws
            of refraction."
  METHOD    1. State Huygens' principle.
            2. Draw two media with speeds v1 and v2, the incident
               wavefront AB, A reaching the surface at P, B travelling
               BQ = v1 t, and the wavelet from P of radius PC = v2 t in
               medium 2. Tangent QC = refracted wavefront.
            3. Triangle PBQ:  sin i = BQ / PQ
               Triangle PCQ:  sin r = PC / PQ
            4. Divide:  sin i / sin r = BQ / PC = v1 / v2 = mu21
            5. Box that as SNELL'S LAW, and add mu1 sin i = mu2 sin r.
            6. State the coplanarity (second) law.
  TRAP      Using the SAME speed in both media (that is the reflection
            proof, not this one). The whole point is v1 is NOT v2.
            Also remember to say v2 < v1 for a denser medium, which is
            why the ray bends TOWARDS the normal.
```

```
  PATTERN 6 — FREQUENCY / WAVELENGTH / SPEED ON REFRACTION        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Which of these change when light enters glass?"
            "Find the wavelength / speed of light in the medium."
            "Does the colour change inside water?"
  METHOD    1. FREQUENCY  -> UNCHANGED  (fixed by the source; the boundary
               cannot create or destroy crests)
            2. SPEED      -> v = c / mu
            3. WAVELENGTH -> lam' = lam / mu
            4. COLOUR     -> UNCHANGED (colour follows frequency)
  TRAP      Saying the frequency changes, or saying the colour changes.
            Both are wrong and both are deliberately offered as options.
```

```
  PATTERN 7 — DOPPLER EFFECT / RED SHIFT NUMERICAL                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "A line of wavelength X is observed at Y. Find the speed."
            "What does the red shift of galaxies tell us?"
  METHOD    1. Compute d(lam) = observed - actual.
            2. INCREASED wavelength -> RED shift -> RECEDING.
               DECREASED wavelength -> BLUE shift -> APPROACHING.
            3. v = c x d(lam) / lam.
            4. State the conclusion: the universe is EXPANDING.
  TRAP      Forgetting to say approaching or receding. The direction
            usually carries half the marks.
```

```
  PATTERN 8 — WHAT ARE COHERENT SOURCES / WHY TWO BULBS FAIL      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define coherent sources."  "Why can two independent bulbs
            not produce interference?"
  METHOD    1. Coherent = SAME frequency AND CONSTANT phase difference.
            2. Independent sources: atoms emit random bursts of about
               10^-8 s, so the phase difference changes about 10^8 times
               per second.
            3. The average of cos(phi) is zero, so I = I1 + I2 and the
               screen is uniformly lit — NO fringes.
            4. Real experiments SPLIT the light from ONE source
               (division of wavefront or of amplitude).
  TRAP      Giving only one of the two conditions. Both are needed.
```

```
  PATTERN 9 — CONDITIONS FOR SUSTAINED INTERFERENCE               4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State the conditions necessary to observe sustained
            interference."
  METHOD    Write SEVEN points:
            1. sources COHERENT
            2. derived from a SINGLE source
            3. MONOCHROMATIC light
            4. same direction of travel and same polarisation
            5. EQUAL (or nearly equal) amplitudes -> good contrast
            6. NARROW source slit
            7. d SMALL and D LARGE, so beta is visible
  TRAP      Writing only three points for a four-mark question. Aim for
            six or seven — one mark per pair of points.
```

```
  PATTERN 10 — PATH DIFFERENCE / PHASE DIFFERENCE CONVERSION      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "The path difference is X. Is the point bright or dark?"
            "Convert a phase difference of ... into a path difference."
  METHOD    1. phase difference = (2 pi / lam) x path difference
            2. path diff = n lam            -> BRIGHT (phase = 2n pi)
               path diff = (2n-1) lam / 2   -> DARK   (phase = (2n-1) pi)
            3. Say the answer in words: BRIGHT or DARK.
  TRAP      Mixing up the two. Memory hook: a WHOLE wavelength of path
            difference means the waves line up again -> BRIGHT.
```

```
  PATTERN 11 — YOUNG'S DOUBLE SLIT: FULL DERIVATION               8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Describe Young's double slit experiment and derive an
            expression for the fringe width."
  METHOD    1. DIAGRAM: source, single slit S, double slit S1 S2
               separated by d, screen at distance D, fringes drawn.
               State D >> d.
            2. Explain why S1 and S2 are coherent (cut from the SAME
               wavefront).
            3. PATH DIFFERENCE: write (S2P)^2 - (S1P)^2 = 2yd, use
               S1P + S2P = 2D, get path difference = y d / D.
            4. BRIGHT: y d / D = n lam   ->  y = n D lam / d
               DARK  : y d / D = (2n-1) lam/2 -> y = (2n-1) D lam / 2d
            5. beta = y(n+1) - y(n) = D lam / d.   BOX IT.
            6. Show the dark-fringe subtraction gives the same beta, so
               all fringes are of EQUAL WIDTH.
            7. Add: equal intensity, central fringe bright, angular
               fringe width = lam / d.
            8. Sketch the intensity graph I = 4 I0 cos^2(phi/2).
  TRAP      Jumping straight to beta = D lam / d without deriving the
            path difference. Four of the eight marks live in steps 3 and 4.
            Also: state the approximation D >> d explicitly.
```

```
  PATTERN 12 — FRINGE WIDTH NUMERICAL                             4 marks
  ------------------------------------------------------------------------
  TRIGGER   "d = ..., D = ..., lam = ... Find the fringe width."
            "Find the wavelength given the fringe width."
  METHOD    1. Convert EVERYTHING to metres:
                  1 A = 10^-10 m , 1 nm = 10^-9 m , 1 mm = 10^-3 m
            2. beta = D lam / d          (or lam = beta d / D)
            3. Convert the answer back to mm if the question used mm.
            4. Write the UNIT.
  TRAP      A missed power of ten. Write the conversions down as a
            separate line before substituting — every single time.
```

```
  PATTERN 13 — POSITION OF THE nth FRINGE / DISTANCE BETWEEN      4 marks
              FRINGES
  ------------------------------------------------------------------------
  TRIGGER   "Find the distance of the 5th bright fringe from the centre."
            "Find the distance between the 3rd and the 8th bright fringe."
  METHOD    1. beta = D lam / d first.
            2. nth BRIGHT:  y = n beta
               nth DARK  :  y = (2n - 1) beta / 2
            3. "Between the mth and the nth" = (n - m) beta.
  TRAP      Counting fringes instead of GAPS. 1st to 10th = NINE fringe
            widths, not ten. This single error is the most common one in
            the whole chapter.
```

```
  PATTERN 14 — EFFECT OF CHANGING lam, D, d                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What happens to the fringe width if ... is doubled/halved?"
            "Which colour gives the widest fringes?"
  METHOD    1. Write beta = D lam / d.
            2. D and lam are UPSTAIRS -> beta changes the same way.
               d is DOWNSTAIRS        -> beta changes the opposite way.
            3. Red (long lam) -> widest fringes. Violet -> narrowest.
            4. If d becomes very large, the fringes merge into uniform
               illumination.
  TRAP      Forgetting that changing BOTH D and d by the same factor
            leaves beta unchanged.
```

```
  PATTERN 15 — FRINGE WIDTH IN A LIQUID                       2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "The whole apparatus is immersed in water / a liquid of
            refractive index mu."
  METHOD    1. Inside the liquid lam' = lam / mu.
            2. Therefore beta' = beta / mu.
            3. Say in words: the fringes become NARROWER and the pattern
               is squeezed towards the centre.
  TRAP      Multiplying by mu instead of dividing. Sanity check: the
            answer must be SMALLER than the original.
```

```
  PATTERN 16 — FRINGE SHIFT BY A THIN SHEET                       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A mica/glass sheet of thickness t and index mu is placed
            over one slit."
  METHOD    1. Extra optical path = (mu - 1) t.
            2. Number of fringes shifted = (mu - 1) t / lam.
            3. Linear shift = D (mu - 1) t / d.
            4. State: the shift is TOWARDS the covered slit, and the
               fringe WIDTH does not change.
  TRAP      Using mu t instead of (mu - 1) t. The sheet REPLACES a
            thickness t of air, so only the EXTRA path counts.
```

```
  PATTERN 17 — TWO WAVELENGTHS COINCIDING                         4 marks
  ------------------------------------------------------------------------
  TRIGGER   "At what least distance do the bright fringes of lam1 and
            lam2 coincide?"
  METHOD    1. Coincidence requires n1 lam1 = n2 lam2.
            2. Form n1/n2 = lam2/lam1 and reduce to the SMALLEST whole
               numbers.
            3. Substitute into y = n1 D lam1 / d.
            4. CHECK with the other wavelength — you must get the same y.
  TRAP      Not reducing the ratio to lowest terms, which gives a
            distance that is a multiple of the least one.
```

```
  PATTERN 18 — INTENSITY RATIOS Imax : Imin                       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "The intensities of the two sources are in the ratio ..."
            "Imax / Imin = ... Find the amplitude ratio."
  METHOD    1. a = sqrt(I). Take square roots FIRST.
            2. Imax / Imin = (a1 + a2)^2 / (a1 - a2)^2.
            3. Going backwards: with k = sqrt(Imax/Imin),
                     a1 : a2 = (k + 1) : (k - 1).
            4. For slits of unequal WIDTH, I is proportional to the width.
  TRAP      Adding the intensities instead of the amplitudes. Amplitudes
            add, intensities do not.
```

```
  PATTERN 19 — INTENSITY AT A GENERAL POINT                    2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the intensity at a point where the path difference is
            lam / 4 (or lam / 3, etc.)."
  METHOD    1. phase difference phi = (2 pi / lam) x path difference.
            2. I = 4 I0 cos^2 (phi / 2)   for equal sources.
            3. Compare with Imax = 4 I0.
  TRAP      Forgetting the HALF inside the cosine. It is cos^2(phi/2),
            not cos^2(phi).
```

```
  PATTERN 20 — WHITE LIGHT FRINGES                                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is seen when white light is used in Young's
            experiment?"
  METHOD    1. Central fringe is WHITE (zero path difference for all
               colours).
            2. A few COLOURED fringes on each side: VIOLET nearest the
               centre, RED furthest (beta is proportional to lam).
            3. Further out the colours overlap -> general white
               illumination, no clear fringes.
  TRAP      Saying red is nearest the centre. Short wavelength = small
            beta = closest in. Violet wins.
```

```
  PATTERN 21 — VISIBILITY / EFFECT OF A WIDE SOURCE SLIT          4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What happens if the source slit is made wider?"
            "State the conditions for the fringes to be clearly seen."
  METHOD    1. A wide slit = many independent narrow sources.
            2. Each makes its own pattern, slightly SHIFTED.
            3. These patterns are incoherent, so their INTENSITIES add.
            4. The minima stop being zero -> CONTRAST falls -> fringes
               eventually disappear.
            5. The fringe WIDTH beta is UNCHANGED throughout.
  TRAP      Saying beta increases. It does not. Only the contrast changes.
```

```
  PATTERN 22 — SINGLE SLIT: DERIVE THE MINIMA               4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the condition for minima in single slit diffraction."
  METHOD    1. Draw the slit of width a, a plane wavefront arriving, and
               a direction theta. Path difference between the edges
               = a sin theta.
            2. Set a sin theta = lam and split the slit into TWO halves;
               every point pairs with one a/2 below it, path difference
               lam/2, so they cancel  ->  DARK.
            3. Generalise by splitting into 2n strips:
                     a sin theta = n lam ,   n = 1, 2, 3 ...
            4. State that n = 0 is EXCLUDED — it is the CENTRAL MAXIMUM.
            5. Secondary maxima: split into (2n+1) strips ->
                     a sin theta = (2n + 1) lam / 2.
  TRAP      Forgetting to exclude n = 0, and using d (slit separation)
            instead of a (slit width).
```

```
  PATTERN 23 — WIDTH OF THE CENTRAL MAXIMUM                       4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the width of the central maximum."
            "What happens to it if the slit is made narrower?"
  METHOD    1. First minimum at a sin theta = lam -> theta = lam / a.
            2. Half-width on the screen = D lam / a.
            3. FULL width = 2 D lam / a.
               ANGULAR width = 2 lam / a.
            4. a is downstairs: NARROWER slit -> WIDER central maximum.
            5. Note it is TWICE as wide as every other band.
  TRAP      Giving the half-width when the question asks for the full
            width. Read the word "width" carefully — and if the question
            says "angular", drop the D.
```

```
  PATTERN 24 — INTERFERENCE versus DIFFRACTION                    4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between interference and diffraction."
  METHOD    Draw a two-column table with at least FOUR of these rows:
            1. two separate sources    vs  parts of the SAME wavefront
            2. all fringes equal width vs  central band is widest
            3. all maxima equally bright vs intensity falls fast
            4. minima perfectly dark   vs  minima not perfectly dark
            5. many fringes            vs  few bands
            6. depends on d            vs  depends on a
            7. d sin th = n lam bright vs  a sin th = n lam DARK
  TRAP      Forgetting the SWAP in row 7. In interference n lam is
            BRIGHT; in diffraction n lam is DARK.
```

```
  PATTERN 25 — RESOLVING POWER / RAYLEIGH CRITERION           2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State the Rayleigh criterion." "Find the limit of resolution
            of a telescope." "How can resolving power be increased?"
  METHOD    1. Rayleigh: two sources are JUST RESOLVED when the CENTRAL
               MAXIMUM of one falls on the FIRST MINIMUM of the other.
            2. Telescope: d(theta) = 1.22 lam / D , RP = D / 1.22 lam.
            3. Microscope: d(min) = 1.22 lam / (2 mu sin beta).
            4. To improve: bigger D, shorter lam, oil immersion.
  TRAP      Confusing resolving power with magnification. A stronger
            eyepiece magnifies but does NOT resolve more detail.
```

```
  PATTERN 26 — POLARISATION PROVES LIGHT IS TRANSVERSE            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What does polarisation tell us about the nature of light?"
  METHOD    1. Longitudinal waves vibrate ONLY along the direction of
               travel, so there is nothing to restrict — they CANNOT be
               polarised.
            2. Transverse waves have infinitely many perpendicular
               vibration directions, so they CAN be restricted to one.
            3. Light CAN be polarised, therefore LIGHT IS TRANSVERSE.
  TRAP      Just writing "light is transverse" without the reasoning.
            The argument is the mark.
```

```
  PATTERN 27 — BREWSTER'S LAW                                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State Brewster's law." "Find the polarising angle for ..."
            "Show that the reflected and refracted rays are
            perpendicular."
  METHOD    1. tan ( i_p ) = mu.
            2. Numerical: i_p = tan^-1(mu), or mu = tan(i_p).
            3. Proof of perpendicularity:
                  Brewster  mu = sin i_p / cos i_p
                  Snell     mu = sin i_p / sin r
                  => sin r = cos i_p = sin(90 - i_p)  =>  r = 90 - i_p
                  => angle between reflected and refracted = 90 degrees.
            4. Add: at i_p the reflected light is COMPLETELY plane
               polarised, with vibrations PERPENDICULAR to the plane of
               incidence.
  TRAP      Writing sin(i_p) = mu. It is TAN. Standard values worth
            knowing: water 53 deg, glass 56 deg, sqrt(3) -> exactly 60 deg.
```

```
  PATTERN 28 — MALUS' LAW (statement, derivation, graph)      2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State Malus' law." "Find the intensity through two
            polaroids at theta." "Sketch I against theta."
  METHOD    1. I = I0 cos^2 (theta).
            2. Derivation: transmitted amplitude = A0 cos theta, and
               intensity is proportional to amplitude squared.
            3. If the incident light is UNPOLARISED, halve it FIRST:
                     I = (I0 / 2) cos^2 (theta).
            4. Graph: a cos^2 curve, I0 at 0 and 180 degrees, zero at
               90 degrees, I0/2 at 45 degrees; two maxima per full turn.
  TRAP      Forgetting to halve for unpolarised light — the single most
            common error in this topic. And do not halve TWICE.
```

```
  PATTERN 29 — MULTIPLE POLAROIDS                                 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Three polaroids ... the first and third are crossed ..."
  METHOD    1. First polaroid: HALVE the unpolarised intensity.
            2. Apply cos^2 for the angle between polaroid 1 and 2.
            3. Apply cos^2 again for the angle between polaroid 2 and 3
               (work that angle out — it is NOT given directly).
            4. Multiply everything together.
  TRAP      Using the angle each polaroid makes with the FIRST one at
            every step. Malus' law always uses the angle between the
            polaroid and the one IMMEDIATELY BEFORE it.
            Standard result: crossed polaroids with a third at 45 degrees
            in between give I0 / 8.
```

```
  PATTERN 30 — POLARISATION BY SCATTERING / BLUE SKY          2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Explain polarisation by scattering."  "Why is the sky blue?"
            "Why is the setting sun red?"
  METHOD    1. Scattering intensity is proportional to 1 / lam^4
               (Rayleigh).
            2. BLUE SKY: blue is scattered about 16 times more than red.
            3. RED SUNSET: the long path scatters the blue away, leaving
               red to reach the eye directly.
            4. POLARISATION: an oscillating charge radiates nothing along
               its own vibration direction, so light scattered at exactly
               90 degrees to the beam is COMPLETELY plane polarised.
            5. Clouds are WHITE because water droplets are much LARGER
               than the wavelength, so 1/lam^4 does not apply.
  TRAP      Answering "the sky is blue because it reflects the sea."
            That is not physics. Say SCATTERING and quote 1 / lam^4.
```

```
  PATTERN 31 — USES OF POLAROIDS                                  2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Mention the uses of polaroids."
  METHOD    List four or five:
            1. sunglasses (cut horizontally polarised road/water glare)
            2. camera filters (darken the sky, remove reflections)
            3. LCD screens
            4. 3-D cinema glasses
            5. car headlights and windscreens to reduce dazzle
            6. polarimeters, to measure sugar concentration
  TRAP      Vague answers like "in optics". Name the DEVICE each time.
```

```
  PATTERN 32 — ENERGY CONSERVATION IN INTERFERENCE                2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Does interference violate conservation of energy?"
  METHOD    1. NO.
            2. The energy missing from the dark fringes appears in the
               bright fringes (4 I0 instead of 2 I0).
            3. The AVERAGE intensity is 2 I0 = I1 + I2, exactly what
               it would be without interference.
            4. Interference only REDISTRIBUTES energy.
  TRAP      Answering just "no". The three-line reason is the mark.
```

     A wavefront is the locus of points vibrating in the same phase.
     A ray is the normal to the wavefront.
     Huygens: secondary wavelets, forward envelope.
     Coherent = same frequency + constant phase difference.
     Frequency never changes; v = c/mu; lam' = lam/mu.
     BRIGHT: path diff = n lam.  DARK: (2n-1) lam / 2.
     beta = D lam / d.    In a liquid, beta / mu.
     Single slit MINIMA:  a sin theta = n lam.
     Central maximum width = 2 D lam / a. Narrow slit -> wide pattern.
     tan i_p = mu ;  i_p + r = 90 ; reflected _|_ refracted.
     I = I0 cos^2 theta ; halve first if unpolarised.
     Scattering goes as 1 / lam^4 -> blue sky, red sunset.
     Interference redistributes energy; it does not destroy it.
