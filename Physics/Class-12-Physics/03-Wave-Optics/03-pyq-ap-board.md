## Topic: Wavefronts and Huygens' principle

### Q A1
What is a wavefront? Name its types.

**ANSWER:**
```
   A WAVEFRONT is the LOCUS of all the points of a medium that are
   vibrating in the SAME PHASE.

   THREE TYPES:
      1. SPHERICAL     -  from a POINT source
      2. CYLINDRICAL   -  from a LINE source (a narrow slit)
      3. PLANE         -  from a source at INFINITY (sunlight, a laser)
```

---

### Q A2
State Huygens' principle.

**ANSWER:**
```
   1.  Every point on a given wavefront acts as a fresh source of
       SECONDARY WAVELETS, which travel out in all directions with the
       speed of light in that medium.

   2.  The FORWARD ENVELOPE (the common tangent surface) of all these
       secondary wavelets after a time t gives the NEW POSITION of the
       wavefront.
```

---

### Q A3
What is the relation between a ray and a wavefront?

**ANSWER:** A **ray** is a line drawn **normal (perpendicular) to the
wavefront**, in the direction in which the wave travels.

```
      SPHERICAL wavefront  ->  rays DIVERGE radially from the source
      PLANE wavefront      ->  rays are PARALLEL straight lines
```

---

### Q A4
What is the shape of the wavefront of light coming from a distant star as it
reaches the Earth? Why?

**ANSWER:** **PLANE.** The star emits a spherical wavefront, but by the time it
reaches the Earth its radius is enormous, so the small portion intercepted by
the Earth has negligible curvature and is treated as plane — exactly as a small
patch of the Earth's surface looks flat.

---

### Q A5
What shape of wavefront emerges from a convex lens when a point source is
placed at its focus?

**ANSWER:** A **PLANE** wavefront. A point source at the focus gives a parallel
emergent beam, and parallel rays mean a plane wavefront.

## Topic: Reflection, refraction, Doppler

### Q A6
When light travels from air into glass, which of the following change:
frequency, wavelength, speed? Give the reason for the one that does not change.

**ANSWER:**
```
   FREQUENCY  ->  DOES NOT CHANGE
   SPEED      ->  DECREASES,   v    =  c / mu
   WAVELENGTH ->  DECREASES,   lam' =  lam / mu

   REASON: the frequency is fixed by the SOURCE. The boundary cannot
   create or destroy wave crests, so the number of crests arriving per
   second must equal the number leaving per second. Hence nu is the same
   in both media.
```

```
           lam        600

            mu        1.5

           c        3 x 10^8
   v    = ------ = ----------  =  2 x 10^8  m s^-1
           mu         1.5
```

### Q A8
What is the red shift? What does it tell us about the universe?

**ANSWER:** When a light source moves **away** from the observer, the observed
wavelength is **longer** than the emitted wavelength — the spectral lines shift
towards the **red** end. This is the **red shift**. The light from almost all
distant galaxies is red shifted, which shows that they are receding from us,
i.e. the **universe is expanding**.

**ANSWER:**

```
           d(lam)                1

             lam               5000

      =  2 x 10^-4  x  3 x 10^8   =   6 x 10^4  m s^-1  =  60 km/s
```

## Topic: Coherence and interference

### Q A10
What are coherent sources?

**ANSWER:** Two sources are **coherent** if they emit light waves of
**(i) the same frequency (same wavelength)** and **(ii) a constant, unchanging
phase difference**. In practice they must be obtained by splitting the light
from a **single source**.

---

### Q A11
Why do two independent bulbs of the same power never produce interference
fringes?

**ANSWER:** Light is emitted by crores of independent atoms in short bursts of
about 10^-8 s, each with a random phase. The phase difference between two
independent bulbs therefore changes randomly about 10^8 times per second, so
the sources are **incoherent**. The average of cos(phi) is zero, the
intensities simply add (I = I1 + I2) and the screen is uniformly lit.

---

### Q A12
State the conditions for constructive and destructive interference in terms of
path difference.

**ANSWER:**
```
   CONSTRUCTIVE (BRIGHT) :  path difference  =  n lam
                            n = 0, 1, 2, 3, ...

                                                (2n - 1) lam
   DESTRUCTIVE  (DARK)   :  path difference  =  -------------
                                                      2
                            n = 1, 2, 3, ...
```

---

### Q A13
Does interference of light violate the law of conservation of energy? Explain.

**ANSWER:** **No.** Interference only **redistributes** the energy. The energy
that disappears from the dark fringes reappears in the bright fringes (each
bright fringe carries 4 I0 instead of 2 I0). The **average** intensity over the
whole pattern is still I1 + I2, so the total energy is unchanged.

## Topic: Young's double slit

### Q A14
Define fringe width. Write its expression.

**ANSWER:** The **fringe width** is the distance between the centres of two
consecutive bright (or two consecutive dark) fringes.

```
              D lam
   beta  =  --------      D   = distance from the slits to the screen
                d         d   = separation of the two slits
                          lam = wavelength of the light used
```

---

### Q A15
Define the angular fringe width. On what does it depend?

**ANSWER:**
```
              beta        lam
   theta  =  ------  =  -------     (in radians)
                D          d

   It depends only on lam and d.  It does NOT depend on D — moving the
   screen changes the linear fringe width but not the angular one.
```

---

### Q A16
In Young's experiment, D = 1 m, d = 0.5 mm and lam = 5000 Å. Find the fringe
width.

**ANSWER:**
```
   d   = 0.5 mm   =  5 x 10^-4  m
   lam = 5000 A   =  5 x 10^-7  m

             D lam        1 x 5 x 10^-7
   beta  =  -------  =  -----------------  =  1 x 10^-3  m  =  1 mm
                d           5 x 10^-4
```

### Q A17
What happens to the fringe width if the whole Young's apparatus is immersed in
water of refractive index 4/3?

**ANSWER:** In the liquid the wavelength becomes `lam / mu`, so

```
              beta        beta          3
   beta'  =  ------  =  -------  =  ----- beta  =  0.75 beta
               mu         4/3          4

   The fringes become NARROWER (the pattern is squeezed by a factor mu).
```

---

### Q A18
What is seen on the screen in Young's experiment when white light is used?

**ANSWER:**
```
   *  The CENTRAL fringe is WHITE (zero path difference for every colour).
   *  A few COLOURED fringes on either side, with VIOLET nearest the
      centre and RED furthest (because beta = D lam / d).
   *  Beyond these the fringe systems of the different colours overlap
      and give general WHITE illumination with no clear fringes.
```

## Topic: Diffraction

### Q A19
What is diffraction of light? When is it noticeable?

**ANSWER:** **Diffraction** is the bending of light round the edges of an
obstacle or an aperture and its spreading into the geometrical shadow. It is
noticeable only when the size of the obstacle or slit is **comparable to the
wavelength** of the light.

---

### Q A20
Write the condition for the minima in single slit diffraction, and state why
n = 0 is excluded.

**ANSWER:**
```
   a sin theta  =  n lam         n = 1, 2, 3, ...

   n = 0 is EXCLUDED because theta = 0 gives ZERO path difference, so
   every point of the slit contributes IN PHASE. That is the CENTRAL
   MAXIMUM — the brightest point of the whole pattern, not a minimum.
```

---

### Q A21
How does the width of the central maximum in single slit diffraction change if
the slit is made narrower?

**ANSWER:**
```
                            2 D lam
   width of central max  =  ---------
                                a

   a is in the DENOMINATOR, so a NARROWER slit gives a WIDER central
   maximum — the light spreads out more.
```

## Topic: Polarisation

### Q A22
What does the polarisation of light prove about its nature?

**ANSWER:** It proves that light is a **TRANSVERSE** wave. A longitudinal wave
vibrates only along its direction of travel, so there is nothing to restrict
and it cannot be polarised. Only transverse waves can be polarised, and light
can be — therefore light is transverse.

---

### Q A23
State Brewster's law. Define the polarising angle.

**ANSWER:**
```
   The POLARISING ANGLE i(p) is the angle of incidence at which the
   REFLECTED light is COMPLETELY PLANE POLARISED.

   BREWSTER'S LAW:        tan ( i(p) )  =  mu

   At this angle the reflected and refracted rays are PERPENDICULAR,
   and   i(p) + r  =  90 degrees.
```

---

### Q A24
Find the polarising angle for water (mu = 1.33).

**ANSWER:**
```
   tan ( i(p) )  =  1.33

        i(p)  =  tan^-1 (1.33)  =  53.1 degrees   (about 53 degrees)
```

---

### Q A25
State Malus' law.

**ANSWER:**
```
   When plane polarised light of intensity I0 falls on an analyser whose
   pass axis makes an angle theta with the plane of polarisation, the
   transmitted intensity is

              I  =  I0 cos^2 ( theta )

   theta = 0  -> I = I0 (maximum);   theta = 90 -> I = 0 (darkness).
```

---

### Q A26
Why is the sky blue and the setting sun red?

**ANSWER:**
```
   Scattered intensity is proportional to 1 / lam^4 (Rayleigh scattering).

   BLUE SKY  : blue has the shortest visible wavelength, so it is
               scattered about 16 times more strongly than red by the
               air molecules; the scattered light filling the sky is blue.

   RED SUNSET: at sunset the light travels a long path through the
               atmosphere and almost all the blue is scattered away
               sideways, so mainly RED and ORANGE reach the eye directly.
```

### Q B1
State Huygens' principle and use it to construct the new position of a plane
wavefront after time t.

**ANSWER:**

```
   HUYGENS' PRINCIPLE
   ------------------
   1. Every point on a wavefront acts as a source of SECONDARY WAVELETS
      that spread out in all directions with the speed v of light in
      that medium.
   2. The FORWARD ENVELOPE of these wavelets after time t gives the NEW
      position of the wavefront.
```

```
   CONSTRUCTION FOR A PLANE WAVEFRONT

         A |                                | A'
           |  .-.    .-.    .-.    .-.      |
           |(   )  (   )  (   )  (   )      |
           | 1 *    2 *    3 *    4 *       |
           |(   )  (   )  (   )  (   )      |
           |  '-'    '-'    '-'    '-'      |
         B |                                | B'

           |<----------- v t -------------->|

   STEP 1  AB is the wavefront at t = 0. Mark points 1, 2, 3, 4 on it.
   STEP 2  With each point as centre, draw a sphere of radius r = v t.
           These are the secondary wavelets.
   STEP 3  Draw the common tangent A'B' on the FORWARD side.
   STEP 4  A'B' is the new wavefront — again PLANE, moved forward by v t.

   The backward envelope is ignored, because the intensity of a secondary
   wavelet is maximum in the forward direction and zero backwards.
```

### Q B2
Prove the laws of reflection using Huygens' principle.

**ANSWER:** *(This is also asked as an 8-mark question — see Section C. The
4-mark version is the same proof written compactly.)*

```
              A
               \  \  \                        /  /  /  C
                \  \  \                      /  /  /
                 \  \  \                    /  /  /
                  \  \  \  B               /  /  /
                   \  \  \|               /  /  /
                    \  \  \              /  /  /
                 i   \  \  \        r   /  /  /
       XXXXXXXXXXXXXXXX\XXXXXXXXXXXXXXX/XXXXXXXXXXXXXXXXX
                        P             Q       MIRROR
```

```
   1.  AB is the incident plane wavefront. The ray from A reaches the
       mirror at P.
   2.  Meanwhile B must still travel BQ to reach the mirror at Q.
                              t  =  BQ / c
   3.  P at once becomes a source of a secondary wavelet. In the SAME
       time t, in the SAME medium, this wavelet grows to radius
                              PC  =  c t  =  BQ
   4.  The tangent QC from Q to this wavelet is the reflected wavefront.
   5.  In triangles PBQ and PCQ:
              angle PBQ = angle PCQ = 90 deg
              BQ = PC                      (step 3)
              PQ = PQ                      (common)
       So the triangles are CONGRUENT (RHS).
   6.  Hence   angle BPQ = angle CQP,  i.e.   i  =  r      (LAW 1)
   7.  All the lines lie in the plane of the paper, so the incident ray,
       the reflected ray and the normal are COPLANAR.       (LAW 2)
```

### Q B3
Using Huygens' principle, derive Snell's law of refraction.

**ANSWER:**

```
      MEDIUM 1  (speed v1)
              A
               \  \  \
                \  \  \  B
                 \  \  \|
              i   \  \  \
       ============\=====\=========================  SURFACE
                   P \    Q
                      \     \        MEDIUM 2 (speed v2, v2 < v1)
                  r    \       \
                        \         \
                         C
```

```
   1.  AB is the incident wavefront; A reaches the surface at P.
   2.  B still has to travel BQ in medium 1:      BQ  =  v1 t
   3.  In the same time t, the wavelet from P spreads into medium 2 to
       a radius                                   PC  =  v2 t
   4.  QC, the tangent from Q, is the refracted wavefront.
   5.  In triangle PBQ:      sin i  =  BQ / PQ
       In triangle PCQ:      sin r  =  PC / PQ
   6.  Dividing:

              sin i        BQ        v1 t        v1
             -------  =  ------  =  ------  =  ------  =  a CONSTANT
              sin r        PC        v2 t        v2

       This constant is mu21, the refractive index of medium 2 with
       respect to medium 1.  ->  SNELL'S LAW.
   7.  Since mu = c/v, this is also   mu1 sin i  =  mu2 sin r.
   8.  All lines lie in one plane -> incident ray, refracted ray and
       normal are COPLANAR (second law).
```

### Q B4
State the conditions necessary for observing sustained interference of light.

**ANSWER:**

```
   ESSENTIAL CONDITIONS
   --------------------
   1.  The two sources must be COHERENT: the same frequency and a
       CONSTANT phase difference.
   2.  They must be derived from a SINGLE original source (by division
       of wavefront or division of amplitude).
   3.  The light should be MONOCHROMATIC (a single wavelength).
   4.  The two waves must travel in nearly the SAME direction and be in
       the same state of POLARISATION.

   CONDITIONS FOR GOOD CONTRAST
   ----------------------------
   5.  The AMPLITUDES should be equal or nearly equal, so that the dark
       fringes are completely dark.
   6.  The SOURCE SLIT must be NARROW; a wide source washes out the
       fringes.
   7.  The slit separation d must be SMALL and the screen distance D
       LARGE, so that beta = D lam / d is big enough to see.
```


### Q B8
Two coherent sources have intensities in the ratio 4 : 1. Find (a) the ratio of
their amplitudes, (b) the ratio Imax : Imin in the interference pattern.

**ANSWER:**
```
  (a)  Intensity is proportional to (amplitude)^2, so

           a1        sqrt(I1)       sqrt(4)        2
          ----  =  -----------  =  ---------  =  -----
           a2        sqrt(I2)       sqrt(1)        1

  (b)     Imax        (a1 + a2)^2       (2 + 1)^2        9
         ------  =  --------------  =  -----------  =  -----  =  9
          Imin        (a1 - a2)^2       (2 - 1)^2        1

       Imax : Imin  =  9 : 1
```

### Q B9
Distinguish between interference and diffraction of light. (Any four points.)

**ANSWER:**

| # | INTERFERENCE | DIFFRACTION |
|---|---|---|
| 1 | Superposition of waves from **two separate** coherent sources | Superposition of secondary wavelets from **different parts of the same** wavefront |
| 2 | All fringes have the **same width** (beta = D lam / d) | The **central band is the widest**; the others are narrower |
| 3 | All bright fringes are **equally bright** | Intensity **falls rapidly** away from the centre (100 %, 4.5 %, 1.6 %) |
| 4 | The dark fringes are **perfectly dark** | The minima are **not perfectly dark**; contrast is poor |
| 5 | Depends on the **separation d** of the two slits | Depends on the **width a** of the single slit |
| 6 | Maxima: `d sin th = n lam` | Minima: `a sin th = n lam` |

### Q B12
State and explain Brewster's law. Show that at the polarising angle the
reflected and refracted rays are perpendicular to each other.

**ANSWER:**
```
   BREWSTER'S LAW:  the tangent of the polarising angle equals the
   refractive index of the reflecting medium.

              tan ( i(p) )  =  mu

   PROOF THAT THE TWO RAYS ARE PERPENDICULAR
   -----------------------------------------
   From Brewster's law     mu  =  sin(i_p) / cos(i_p)          ... (1)
   From Snell's law        mu  =  sin(i_p) / sin(r)            ... (2)

   Comparing (1) and (2):

              sin ( r )  =  cos ( i_p )  =  sin ( 90 - i_p )

                      r  =  90  -  i_p

              i_p  +  r  =  90 degrees

   The angle of reflection is also i_p, so the angle between the
   reflected and the refracted ray

        =  180  -  ( i_p  +  r )   =  180  -  90  =  90 degrees.

   Hence at the polarising angle the reflected and refracted rays are
   MUTUALLY PERPENDICULAR.
```

### Q B13
Unpolarised light of intensity I0 falls on two polaroids whose pass axes are at
30 degrees to each other. Find the intensity of the emergent light. What
happens when the angle is made 90 degrees?

**ANSWER:**
```
   AFTER THE FIRST POLAROID (unpolarised light -> always halved):

              I1  =  I0 / 2

   AFTER THE SECOND (Malus' law):

              I2  =  I1 cos^2 (30)

                                    sqrt(3)  2
                  =  ( I0 / 2 ) x ( ------- )
                                       2

                  =  ( I0 / 2 ) x ( 3 / 4 )   =   3 I0 / 8

   AT 90 DEGREES (crossed polaroids):

              I2  =  ( I0 / 2 ) cos^2 (90)  =  0

   No light emerges at all — the polaroids are said to be CROSSED.
```

### Q B14
Explain how light is polarised by scattering. Why does a patch of blue sky
viewed at 90 degrees to the Sun appear polarised?

**ANSWER:**
```
   SUNLIGHT (unpolarised)
        |   |   |
        v   v   v
   ------------------->  ( o ) air molecule
                          |
                          |  scattered at 90 degrees
                          v
                     to the observer  ->  COMPLETELY PLANE POLARISED
```

```
   1.  Unpolarised sunlight sets the electrons of an air molecule
       vibrating in the two directions PERPENDICULAR to the beam.
   2.  A vibrating charge radiates NOTHING along its own direction of
       vibration.
   3.  An observer looking at 90 degrees to the incident beam therefore
       receives radiation from only ONE of the two vibration directions
       — the other one points straight at him and radiates nothing
       towards him.
   4.  Hence the light scattered at 90 degrees is COMPLETELY PLANE
       POLARISED; light scattered at other angles is only PARTIALLY
       polarised.
   5.  TEST: view a patch of blue sky 90 degrees from the Sun through a
       rotating polaroid — it brightens and darkens twice per turn.
```

### Q B16
What is resolving power? State the Rayleigh criterion and write the expression
for the limit of resolution of a telescope.

**ANSWER:**
```
   RESOLVING POWER is the ability of an optical instrument to show two
   very close objects as SEPARATE. It is the reciprocal of the LIMIT OF
   RESOLUTION (the smallest separation that can still be distinguished).

   RAYLEIGH CRITERION
   ------------------
   Two point sources are JUST RESOLVED when the CENTRAL MAXIMUM of the
   diffraction pattern of one falls exactly on the FIRST MINIMUM of the
   diffraction pattern of the other.

   FOR A TELESCOPE of objective diameter D:

                        1.22 lam                              D
       d(theta)  =  --------------  ,   resolving power = -----------
                            D                              1.22 lam

   So a LARGER objective and a SHORTER wavelength give a BETTER
   resolving power — that is why astronomical telescopes are built with
   very large objectives.
```

**1. The arrangement**

```
                                                          S C R E E N
     mono-                                              +-------------+
     chromatic       S1                                 |    dark     |
     source          ---.                               |  ####bright#|
       |                 \                              |    dark     |
      (*)---> [ S ] ------ >  d  <                       |  ####bright#|

              placed SYMMETRICALLY so they are always equidistant from S.
     Because they are cut out of the SAME wavefront, S1 and S2 are
     COHERENT (division of wavefront).
     D      = distance from the double slit to the screen (about 1 m).
     D >> d.
```

**2. Path difference at a point P**

```
              S1  .
                  |\
                  | \  r1                        P
                  |  \  - - - - - - - - - - - - -*
            d     |   \                       .  |
                  |    \                   .     |
       - - - - - -O- - -\- - - - - - - - .- - - -+ y
                  |      \            .          |
                  |       \        .             |
              S2  .________\____.________________C
                            r2
                  |<---------- D ---------------->|
```

```
   Let P be at a distance y from the centre C.

              (S2P)^2  =  D^2  +  ( y + d/2 )^2
              (S1P)^2  =  D^2  +  ( y - d/2 )^2

   Subtracting:

              (S2P)^2 - (S1P)^2  =  2 y d

              (S2P + S1P)(S2P - S1P)  =  2 y d

   Since D >> d and D >> y, both S1P and S2P are nearly D, so
   (S2P + S1P) = 2D. Hence

                                 2 y d          y d
              PATH DIFFERENCE = --------  =  ---------
                                  2 D            D

   (equivalently, path difference = d sin theta for small theta).
```

**3. Positions of bright and dark fringes**

```
   BRIGHT FRINGES (constructive):    path difference  =  n lam

              y d                             n D lam
             -----  =  n lam       ->   y  = ----------   n = 0,1,2,...
               D                                 d


   DARK FRINGES (destructive):  path difference = (2n - 1) lam / 2

              y d      (2n - 1) lam            (2n - 1) D lam
             ----- =  --------------  ->  y = ----------------  n=1,2,3..
               D             2                       2 d
```

**4. Fringe width**

```
   beta  =  y(n+1)  -  y(n)

              (n + 1) D lam        n D lam
         =   ---------------  -   ---------
                    d                 d

              +=====================================+
              |                D lam                 |
              |     beta   =  -------                 |
              |                  d                    |
              +=====================================+

   Doing the same subtraction with the dark-fringe formula gives the
   SAME answer, so the bright and the dark fringes are equally spaced.

   CONCLUSION:  the fringes are of EQUAL WIDTH and (for equal slit
   widths) of EQUAL INTENSITY, and they are equally spaced on either
   side of a central bright fringe.
```

**5. Discussion of the effects**

```
   *  lam INCREASED (e.g. blue -> red)  ->  beta INCREASES.
      Red light gives the widest fringes, violet the narrowest.

   *  D INCREASED (screen moved back)   ->  beta INCREASES
      (but the fringes get fainter).

   *  d INCREASED (slits moved apart)   ->  beta DECREASES.
      If d becomes large, beta becomes too small to see and the screen
      appears uniformly illuminated.

   *  APPARATUS IMMERSED IN A LIQUID of index mu:  lam becomes lam/mu,
      so beta becomes beta/mu — the fringes get NARROWER.

   *  WHITE LIGHT: the centre is WHITE, a few coloured fringes appear
      (violet inside, red outside) and further out the pattern washes
      out into general white illumination.

   *  ONE SLIT COVERED: the interference fringes disappear; a single
      slit diffraction pattern is seen instead.
```

**6. Intensity distribution**

```
   |  *       *   *       *   *       *   *       *   *       *

  0+*-----------*-----------*-----------*-----------*-----------> y
   -2beta      -beta         0        +beta       +2beta

              I  =  4 I0 cos^2 ( phi / 2 )

   All the maxima are equally high (equal intensity) and equally spaced

   that interference only REDISTRIBUTES energy — it does not create or
   destroy it.
```

### Q C2
State Huygens' principle. Using it, prove the laws of reflection of light at a
plane surface.

**ANSWER:**

```
  MARK SPLIT
  ----------
    Statement of Huygens' principle  .....................  2 marks
    Labelled diagram  ....................................  2 marks
    Congruent-triangle argument  .........................  3 marks
    Statement of both laws  ..............................  1 mark
```

**1. Huygens' principle**

```
   (a) Every point on a wavefront acts as a fresh source of SECONDARY
       WAVELETS which travel out in all directions with the speed of
       light in that medium.
   (b) The FORWARD ENVELOPE (common tangent) of these wavelets after a
       time t gives the NEW position of the wavefront.
```

**2. Diagram**

```
              A
               \  \  \                          /  /  /  C
                \  \  \                        /  /  /
                 \  \  \                      /  /  /
        incident  \  \  \                    /  /  /   reflected
        wavefront  \  \  \  B               /  /  /    wavefront
                    \  \  \|              /  /  /
                     \  \  \             /  /  /
                  i   \  \  \       r   /  /  /
       XXXXXXXXXXXXXXXXX\XXXXXXXXXXXXXX/XXXXXXXXXXXXXXXXXXXXX
                         P            Q                 MIRROR XY

       AB  =  incident plane wavefront
       CQ  =  reflected plane wavefront
       BQ  =  the distance B still has to travel
       PC  =  radius of the secondary wavelet from P
```

**3. Proof**

```
   STEP 1  AB is the incident plane wavefront. The end A reaches the
           mirror at P.

   STEP 2  At that instant B is still a distance BQ from the mirror.
           The time it needs is        t  =  BQ / c.

   STEP 3  By Huygens' principle P immediately becomes a source of a
           secondary wavelet. Since it spreads in the SAME medium
           (air), in the same time t it has radius

                       PC  =  c t  =  BQ                        ... (1)

   STEP 4  Draw the tangent QC from Q to this wavelet. CQ is the
           reflected wavefront.

   STEP 5  Compare the right-angled triangles PBQ and PCQ:

                 angle PBQ  =  angle PCQ  =  90 degrees
                 BQ         =  PC                  from (1)
                 PQ         =  PQ                  (common)

           By the RHS rule the triangles are CONGRUENT.

   STEP 6  Therefore the corresponding angles are equal:

                 angle BPQ  =  angle CQP        i.e.   i  =  r

   STEP 7  This is the FIRST LAW OF REFLECTION: the angle of incidence
           equals the angle of reflection.

   STEP 8  The incident wavefront, the reflected wavefront and the
           mirror all lie in the plane of the paper, so the incident
           ray, the reflected ray and the normal at the point of
           incidence are COPLANAR. That is the SECOND LAW OF REFLECTION.
```

### Q C3
State Huygens' principle and, using it, derive Snell's law of refraction. Hence

enters a denser medium.

```
  MARK SPLIT
  ----------
    Statement of Huygens' principle  .....................  2 marks
    Labelled diagram  ....................................  2 marks
    Derivation of sin i / sin r = v1/v2 = mu21  ..........  3 marks
    Behaviour of nu, lam and v  ..........................  1 mark
```

**1. Huygens' principle** — as stated in Q C2.

**2. Diagram**

```
      MEDIUM 1  (rarer,  index mu1, speed v1)

              A
               \  \  \
                \  \  \       incident plane wavefront AB
                 \  \  \
                  \  \  \  B
                   \  \  \|
                i   \  \  \

                        \     \

                          \         \

       PC  =  v2 t     (the wavelet from P grows this much in medium 2)

```

**3. Derivation**

```
   STEP 1  AB is the incident wavefront; A reaches the surface at P.

   STEP 2  B has still to travel BQ in medium 1:
                            BQ  =  v1 t                       ... (1)

   STEP 3  In the same time t the wavelet from P spreads into medium 2:
                            PC  =  v2 t                       ... (2)

   STEP 4  QC, drawn tangent from Q to that wavelet, is the refracted
           wavefront.

   STEP 5  In right-angled triangle PBQ (right angle at B):

                            BQ
               sin i  =  --------                             ... (3)
                            PQ

           In right-angled triangle PCQ (right angle at C):

                            PC
               sin r  =  --------                             ... (4)
                            PQ

   STEP 6  Dividing (3) by (4):

               sin i       BQ       v1 t        v1
              -------  =  ----  =  ------  =  ------
               sin r       PC       v2 t        v2

   STEP 7  v1 and v2 are constants for the two media, so

              +--------------------------------------------------+
              |     sin i        v1                               |
              |    -------  =  ------  =  mu21  =  a CONSTANT     |
              |     sin r        v2                               |
              +--------------------------------------------------+

           This is SNELL'S LAW — the first law of refraction.

   STEP 8  Since  mu1 = c/v1  and  mu2 = c/v2 ,

                v1        mu2                 
               ----  =  ------      so   mu1 sin i  =  mu2 sin r
                v2        mu1

   STEP 9  Everything is drawn in one plane, so the incident ray, the
           refracted ray and the normal are COPLANAR — the second law.
```

**4. Frequency, wavelength and speed in the denser medium**

```
   FREQUENCY   nu   ->  UNCHANGED.
        The frequency is fixed by the SOURCE. The boundary cannot create
        or destroy wave crests, so the number of crests arriving per
        second equals the number leaving per second.

   SPEED       v    ->  DECREASES,     v  =  c / mu

   WAVELENGTH  lam  ->  DECREASES,     lam' = lam / mu
        (because v = nu lam and nu is unchanged)

   COLOUR           ->  UNCHANGED (colour depends on frequency)

   NOTE: this derivation predicts that light travels SLOWER in a denser
   medium, which experiment confirms — and which proves Newton's
   corpuscular theory (that predicted the opposite) wrong.
```

### Q C5
What is polarisation of light? Explain polarisation by reflection and state
Brewster's law. State and explain Malus' law. Mention four uses of polaroids.

**ANSWER:**

```
  MARK SPLIT
  ----------
    Meaning of polarisation + transverse-wave conclusion  .  2 marks
    Polarisation by reflection + diagram + Brewster's law .  3 marks
    Malus' law + derivation + graph  .....................  2 marks
    Uses of polaroids  ...................................  1 mark
```

**1. Polarisation**

```
   In ordinary (UNPOLARISED) light the electric field vibrates in every
   direction perpendicular to the direction of travel, changing at
   random.

   POLARISATION is the process of restricting these vibrations to ONE
   single plane. Light in which the vibrations are confined to one plane
   is called PLANE (or LINEARLY) POLARISED light.

       UNPOLARISED     :   . | . | . | .    (dots and arrows)
       PLANE POLARISED :   | | | | |        (arrows only)

   Only TRANSVERSE waves can be polarised, because only they have more
   than one possible vibration direction to choose from. Since light CAN
   be polarised, LIGHT IS A TRANSVERSE WAVE.
```

**2. Polarisation by reflection and Brewster's law**

```
                    unpolarised          completely PLANE POLARISED
                    incident light       reflected ray  (dots)
                          \                       .
                           \      90 degrees    .
                        . | .\   <---------->  .
                          . | \ |  i(p)      .
       ======================\==.===========================
                              \     |                    GLASS mu
                        r      \    |
                                \   | 90 deg
                                 \  |
                          PARTIALLY POLARISED refracted ray
```

```
   *  When unpolarised light is reflected from a non-metallic surface
      (glass, water, a road) the reflected light is PARTIALLY polarised.

   *  At one particular angle of incidence, called the POLARISING ANGLE
      or BREWSTER ANGLE i(p), the reflected light becomes COMPLETELY
      PLANE POLARISED, with its vibrations PERPENDICULAR to the plane of
      incidence.

   BREWSTER'S LAW:            tan ( i(p) )  =  mu

   PROOF THAT REFLECTED AND REFRACTED RAYS ARE PERPENDICULAR
   ---------------------------------------------------------
       Brewster:  mu  =  sin(i_p) / cos(i_p)
       Snell   :  mu  =  sin(i_p) / sin(r)

       =>  sin r = cos i_p = sin(90 - i_p)   =>   r = 90 - i_p

       =>  i_p + r = 90 degrees

       angle between reflected and refracted rays
              =  180 - (i_p + r)  =  180 - 90  =  90 degrees.

   PHYSICAL REASON: the reflected light is radiated by the vibrating
   electrons in the glass, and a vibrating charge radiates nothing along
   its own vibration direction. At i_p the in-plane vibrations point
   straight along the reflected ray, so only the perpendicular component
   survives.
```

**3. Malus' law**

```
   POLARISER P1              ANALYSER P2

   unpolarised     plane polarised            final
   I0              I0 / 2                    intensity I
   ~~~~~~~>  |||  ==========>  |||  --------->

```

```
   analyser, the transmitted intensity is

              +----------------------------------+
              |      I   =   I0 cos^2 ( theta )   |
              +----------------------------------+

   where theta is the angle between the pass axes.

   DERIVATION: resolve the incident amplitude A0 along and across the
   analyser's pass axis.

                     A0
                     ^
                     |\
                     | \
             theta   |  \     A0 cos(theta)  -> TRANSMITTED
                     |   \   ------------->
        -------------+----\-------------->  pass axis
                          A0 sin(theta) -> ABSORBED

        transmitted amplitude  =  A0 cos(theta)
        I is proportional to A^2   =>   I  =  I0 cos^2(theta)

   NOTE: if the light falling on the FIRST polaroid is UNPOLARISED, the
   transmitted intensity is always exactly HALF, whatever the setting.
```

### Q C6
Explain the phenomenon of interference of light. State the conditions for
sustained interference. Obtain expressions for the resultant intensity and for
the ratio Imax : Imin, and show that energy is conserved.

**ANSWER:**

```
  MARK SPLIT
  ----------
    Meaning of interference + superposition  .............  2 marks
    Conditions for sustained interference  ...............  2 marks
    Expression for the resultant intensity  ..............  2 marks
    Imax/Imin ratio + conservation of energy  ............  2 marks
```

**1. Interference and superposition**

```
   PRINCIPLE OF SUPERPOSITION: when two or more waves pass through the
   same region, the resultant displacement at any point is the algebraic
   sum of the individual displacements:      y  =  y1 + y2.

   INTERFERENCE is the redistribution of light energy that results when
   two COHERENT light waves superpose.

      crest on crest (in phase)      ->  CONSTRUCTIVE  ->  BRIGHT
      crest on trough (out of phase) ->  DESTRUCTIVE   ->  DARK

   CONSTRUCTIVE:  path diff = n lam ,           phase diff = 2 n pi
   DESTRUCTIVE :  path diff = (2n-1) lam/2 ,    phase diff = (2n-1) pi
```

**2. Conditions for sustained interference**

```
   1.  The two sources must be COHERENT (same frequency, constant phase
       difference).
   2.  They must be obtained from a SINGLE original source.
   3.  The light should be MONOCHROMATIC.
   4.  The waves must travel in nearly the same direction and have the
       same state of polarisation.
   5.  The amplitudes should be equal or nearly equal (for good
       contrast, so the minima are truly dark).
   6.  The source slit must be NARROW.
   7.  d should be small and D large, so that beta = D lam / d is large
       enough to be seen.
```

**3. Resultant intensity**

```
   Let the two waves at a point be

        y1  =  a1 sin(omega t)
        y2  =  a2 sin(omega t + phi)

   By superposition the resultant amplitude R satisfies

        R^2  =  a1^2 + a2^2 + 2 a1 a2 cos(phi)

   Since intensity is proportional to the square of the amplitude,

        +-------------------------------------------------------+
        |    I  =  I1  +  I2  +  2 sqrt(I1 I2) cos( phi )       |
        +-------------------------------------------------------+

   For two EQUAL sources (I1 = I2 = I0) this becomes

        +-------------------------------------------------------+
        |    I  =  4 I0 cos^2 ( phi / 2 )                       |
        +-------------------------------------------------------+

        phi = 0, 2pi, 4pi ...     ->  I = 4 I0     (BRIGHT)
        phi = pi, 3pi, 5pi ...    ->  I = 0        (DARK)
```

**4. Imax : Imin, and conservation of energy**

```
        Imax  =  ( sqrt(I1) + sqrt(I2) )^2  =  ( a1 + a2 )^2
        Imin  =  ( sqrt(I1) - sqrt(I2) )^2  =  ( a1 - a2 )^2

        +-------------------------------------------------------+
        |     Imax        ( a1 + a2 )^2                          |
        |    ------  =  ----------------                         |
        |     Imin        ( a1 - a2 )^2                          |
        +-------------------------------------------------------+

   CONSERVATION OF ENERGY
   ----------------------
   The average value of cos^2(phi/2) over the whole pattern is 1/2, so
   the AVERAGE intensity is

        I(avg)  =  4 I0 x (1/2)  =  2 I0  =  I1 + I2

   which is exactly the intensity that would be present without any
   interference. The energy missing from the dark fringes reappears in
   the bright fringes. Interference therefore only REDISTRIBUTES
   energy — the total energy is CONSERVED.
```
