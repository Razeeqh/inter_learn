## THE 60-SECOND VERSION

Ray optics said: *light travels in straight lines*. That explains mirrors and
lenses — but it CANNOT explain why light spreads round a tiny slit, or why a
soap bubble is coloured. So we upgrade the model:

```
  LIGHT IS A WAVE.

  1.  Every point on a wavefront acts as a NEW source of tiny waves.
                                       ->  HUYGENS' PRINCIPLE
      (this alone proves reflection AND refraction)

  2.  When two waves meet, their displacements ADD.
                                       ->  SUPERPOSITION
      crest + crest  =  BRIGHT   (constructive)
      crest + trough =  DARK     (destructive)

  3.  Two coherent slits  ->  equally spaced bright and dark bands
                                       ->  INTERFERENCE  (Young)

  4.  One narrow slit     ->  a wide bright centre with faint side bands
                                       ->  DIFFRACTION

  5.  Light can be filtered so it vibrates in ONE plane only
                                       ->  POLARISATION
      (this proves light is a TRANSVERSE wave)
```

The single most valuable line in the whole chapter:

```
              D lam
   beta  =  ---------          fringe width in Young's experiment
                d
```

## THE KEY BOX — LEARN THIS BEFORE ANYTHING ELSE

```
  +======================================================================+
  |            THE FOUR FORMULAE THAT UNLOCK THIS WHOLE CHAPTER          |
  +======================================================================+
  |                                                                      |
  |  1.  YOUNG'S FRINGE WIDTH                                            |
  |                                                                      |
  |                D lam                                                 |
  |      beta  =  --------      D = slit-to-screen distance              |
  |                  d          d = separation of the two slits          |
  |                             lam = wavelength                         |
  |                                                                      |
  |      All fringes have the SAME width and the SAME intensity.         |
  |                                                                      |
  |  2.  INTERFERENCE CONDITIONS  (path difference = d sin theta)        |
  |                                                                      |
  |      BRIGHT :  path diff  =  n lam            n = 0, 1, 2, ...       |
  |      DARK   :  path diff  =  (2n - 1) lam / 2   n = 1, 2, 3, ...     |
  |                                                                      |
  |  3.  SINGLE SLIT DIFFRACTION                                         |
  |                                                                      |
  |      MINIMA :  a sin theta  =  n lam          n = 1, 2, 3, ...       |
  |                                                                      |
  |                                     2 D lam                          |
  |      WIDTH OF CENTRAL MAXIMUM  =  ----------                         |
  |                                        a                             |
  |                                                                      |
  |      NARROWER slit  ->  WIDER central maximum.  (a is downstairs)    |
  |                                                                      |
  |  4.  POLARISATION                                                    |
  |                                                                      |
  |      BREWSTER :  tan(i_p)  =  mu       and    i_p + r  =  90 deg     |
  |                                                                      |
  |      MALUS    :  I  =  I0 cos^2(theta)                               |
  |                                                                      |
  +======================================================================+
```

```
  +======================================================================+
  |          WHAT CHANGES WHEN LIGHT ENTERS A DENSER MEDIUM              |
  +======================================================================+
  |                                                                      |
  |     FREQUENCY  ( nu )      ->   DOES  NOT  CHANGE                    |
  |                                 (it is fixed by the SOURCE)          |
  |                                                                      |
  |     SPEED      ( v )       ->   v    =  c / mu        (decreases)    |
  |                                                                      |
  |     WAVELENGTH ( lam )     ->   lam' =  lam / mu      (decreases)    |
  |                                                                      |
  |     COLOUR                 ->   DOES NOT CHANGE (colour follows      |
  |                                 frequency, not wavelength)           |
  |                                                                      |
  |   ONE-LINE REASON: the number of wave crests arriving per second     |
  |   at the boundary must equal the number leaving it, otherwise        |
  |   waves would pile up at the surface. So nu is the same on both      |
  |   sides, and since v = nu lam, a smaller v forces a smaller lam.     |
  +======================================================================+
```

## THE ONE COMPARISON TABLE THE BOARD LOVES

```
  +----------------------+---------------------------+---------------------------+
  |  POINT               |  INTERFERENCE             |  DIFFRACTION              |
  +----------------------+---------------------------+---------------------------+
  |  Caused by           |  TWO separate coherent    |  Secondary wavelets from   |
  |                      |  wavefronts               |  the SAME wavefront        |
  |  Fringe width        |  ALL fringes equal width  |  Central band is widest;   |
  |                      |                           |  others get narrower       |
  |  Intensity           |  All bright bands equally |  Intensity FALLS rapidly   |
  |                      |  bright                   |  away from the centre      |
  |  Dark fringes        |  Perfectly dark           |  Not perfectly dark        |
  |  Number of fringes   |  Large                    |  Few                       |
  |  Condition (bright)  |  d sin th = n lam         |  a sin th = (2n+1) lam/2   |
  |  Condition (dark)    |  d sin th = (2n-1) lam/2  |  a sin th = n lam          |
  +----------------------+---------------------------+---------------------------+
```

> Notice the **swap**: in interference `n lam` means BRIGHT, in diffraction
> `n lam` means DARK. Examiners test exactly this swap.

## THE FIVE SENTENCES MOST LIKELY TO EARN YOU A MARK

```
  1.  "A wavefront is the locus of all points of a medium vibrating in
       the SAME PHASE."

  2.  "Every point on a wavefront acts as a source of secondary wavelets;
       the forward envelope of these wavelets at a later instant gives
       the new position of the wavefront."

  3.  "Two sources are coherent if they emit waves of the SAME frequency
       with a CONSTANT phase difference."

  4.  "Interference redistributes energy — it does not create or destroy
       it — so the total energy is conserved."

  5.  "Polarisation can occur only in transverse waves, therefore the fact
       that light can be polarised proves that light is a transverse wave."
```
