## THE 60-SECOND VERSION

```
  1.  Fire alpha particles at gold foil.
      Most go straight  ->  the atom is MOSTLY EMPTY SPACE.
      A few bounce back ->  all the positive charge and nearly all the mass
                            sit in a TINY NUCLEUS (10^-15 m) at the centre.

  2.  Electrons must orbit that nucleus. But classical physics says an
      orbiting electron RADIATES, loses energy, and spirals in within
      10^-8 s. Atoms would not exist. Rutherford's model FAILS.

  3.  Bohr fixes it by DECREE:
        - only orbits with  m v r = n h / 2 pi  are allowed
        - in those orbits the electron does NOT radiate
        - light is emitted only when it JUMPS DOWN:  h nu = E2 - E1

  4.  Two numbers fall out and they run the whole chapter:

            r_n = 0.529 n^2 / Z  angstrom          E_n = -13.6 Z^2 / n^2  eV

  5.  Because energies are DISCRETE, the jumps are discrete, so the light
      comes out as SHARP LINES, not a rainbow. That is the whole chapter.
```

## THE KEY BOX — these two lines unlock 80% of the questions

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |                          0.529 x n^2                               |
  |     RADIUS      r_n  =  --------------  angstrom   (1 A = 10^-10 m)|
  |                               Z                                    |
  |                                                                    |
  |                          -13.6 x Z^2                               |
  |     ENERGY      E_n  =  --------------  electron volt              |
  |                              n^2                                   |
  |                                                                    |
  |     JUMP        E2 - E1  =  h nu  =  h c / lambda                  |
  |                                                                    |
  |                    12400                                           |
  |     SHORTCUT   lambda (in A)  =  ----------------                  |
  |                                   E (in eV)                        |
  |                                                                    |
  +--------------------------------------------------------------------+

  For hydrogen put Z = 1.   For He+ put Z = 2.   For Li2+ put Z = 3.
```

Everything else in the chapter is a sentence to memorise.
