# Ray Optics and Optical Instruments — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The numbers change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — STATE THE LAWS OF REFLECTION                        2 marks
  ------------------------------------------------------------------------
  TRIGGER   "State the laws of reflection of light."
  METHOD    1. i = r
            2. incident ray, reflected ray and normal are COPLANAR
  NOTE      Pure recall. NEVER lose this mark.
```

```
  PATTERN 2 — NUMBER OF IMAGES BY TWO INCLINED MIRRORS            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Two plane mirrors are inclined at ... degrees. How many
            images are formed?"
  METHOD    1. Compute  N = 360 / a
            2. N EVEN                     ->  n = N - 1
               N ODD, object on bisector  ->  n = N - 1
               N ODD, object off bisector ->  n = N
               N a fraction               ->  n = integer part of N
  TRAP      Parallel mirrors (a = 0) give an INFINITE number of images.
            Say it in words, do not divide by zero.
```

```
  PATTERN 3 — ANGLE PROBLEMS ON A PLANE MIRROR                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "A ray strikes a mirror at X degrees to the SURFACE ..."
            "The mirror is rotated by theta ..."
  METHOD    1. Angle with the NORMAL  =  90 - (angle with the surface)
            2. Angle between incident and reflected ray  =  2 i
            3. Rotating the mirror by theta turns the reflected ray by
               2 theta.
  TRAP      Surface versus normal. This ONE confusion loses more marks
            than anything else in the reflection section.
```

```
  PATTERN 4 — DERIVE  f = R / 2                                   4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Show that the focal length of a spherical mirror is half
            its radius of curvature."
  METHOD    1. Draw a parallel ray hitting the mirror at M; CM is the
               normal.
            2. Alternate angles  ->  angle MCP = theta.
            3. Law of reflection ->  triangle MCF is ISOSCELES, FM = FC.
            4. Paraxial rays     ->  FM = FP.
            5. Therefore F is the midpoint of C and P, so f = R/2.
  TRAP      You MUST state that the rays are PARAXIAL. One mark is
            reserved for that condition.
```

```
  PATTERN 5 — DERIVE THE MIRROR FORMULA                           4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive  1/v + 1/u = 1/f  for a concave mirror."
  METHOD    1. Draw the diagram with object AB and image A'B'.
            2. Similar triangles A'B'P and ABP  ->  A'B'/AB = PA'/PA
            3. Similar triangles A'B'F and MPF  ->  A'B'/AB = FA'/FP
            4. Equate, then substitute PA = -u , PA' = -v , PF = -f.
            5. Simplify and divide by uvf.
  TRAP      Forgetting to apply the sign convention in step 4.
            Without it the derivation is worth zero.
```

```
  PATTERN 6 — MIRROR NUMERICAL                                    4 marks
  ------------------------------------------------------------------------
  TRIGGER   "An object is placed X cm in front of a concave/convex mirror
            of focal length Y. Find the image."
  METHOD    1. Write u with a MINUS sign.
            2. f is NEGATIVE for concave, POSITIVE for convex.
            3. Apply  1/v + 1/u = 1/f  and solve for v.
            4. Compute  m = -v / u   and   h' = m h.
            5. STATE IN WORDS: real/virtual, erect/inverted,
               magnified/diminished.
  TRAP      Step 5 carries a mark on its own. Do not stop at the number.
```

```
  PATTERN 7 — IMAGE POSITION TABLE FOR MIRRORS                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Draw ray diagrams for image formation by a concave mirror
            for different positions of the object."
  METHOD    Reproduce the six-row table (infinity / beyond C / at C /
            between C and F / at F / between F and P) with a ray diagram
            for at least two of the rows.
  TRAP      Missing the ARROWHEADS on the rays, and forgetting to label
            P, F and C. Both cost marks.
```

```
  PATTERN 8 — SNELL'S LAW / REFRACTIVE INDEX                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define refractive index." / "Find the speed of light in ..."
            / "Find the angle of refraction."
  METHOD    1. mu = c / v = sin i / sin r
            2. mu1 sin i = mu2 sin r  for a general boundary.
            3. Remember: frequency is UNCHANGED, speed and wavelength
               both divide by mu.
  TRAP      Writing that the frequency changes. It does not.
```

```
  PATTERN 9 — GLASS SLAB AND LATERAL SHIFT                     2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A ray passes through a rectangular glass slab ..."
  METHOD    1. State that the emergent ray is PARALLEL to the incident ray.
            2. Apply  d = t sin( i - r ) / cos r
  TRAP      Thinking the slab changes the DIRECTION of the ray. It only
            shifts it sideways.
```

```
  PATTERN 10 — APPARENT DEPTH AND NORMAL SHIFT                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A coin at the bottom of a tank ..." /
            "By how much does the print appear to be raised?"
  METHOD    1. mu = real depth / apparent depth
            2. apparent depth = real depth / mu
            3. normal shift  x = t ( 1 - 1/mu )
            4. For stacked layers, add  t / mu  for each layer.
  TRAP      The question asks for the SHIFT, not the apparent depth.
            Read it twice. The shift is the DIFFERENCE.
```

```
  PATTERN 11 — TOTAL INTERNAL REFLECTION: THEORY                  4 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is total internal reflection? State the conditions and
            derive sin C = 1/mu. Give applications."
  METHOD    1. Definition in one sentence.
            2. Diagram with i < C , i = C , i > C.
            3. Two CONDITIONS: denser to rarer, and i > C.
            4. Snell at C:  mu sin C = 1 x sin 90  ->  sin C = 1/mu
            5. Applications: mirage, diamond, optical fibre, totally
               reflecting prism.
  NOTE      *** ONE OF THE HIGHEST-FREQUENCY 4-MARK QUESTIONS ***
```

```
  PATTERN 12 — CRITICAL ANGLE NUMERICAL                           2 marks
  ------------------------------------------------------------------------
  TRIGGER   "The critical angle for a medium is ... Find mu / the speed
            of light in it."
  METHOD    1. sin C = 1 / mu   ->   mu = 1 / sin C
            2. Then  v = c / mu  if the speed is asked.
            3. For two media neither of which is air,
               sin C = mu(rarer) / mu(denser).
  TRAP      Using mu = sin C instead of 1/sin C. mu must come out
            GREATER than 1 — use that as your check.
```

```
  PATTERN 13 — REFRACTION AT A SINGLE SPHERICAL SURFACE           8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the relation for refraction at a single spherical
            refracting surface."
  METHOD    1. Draw O, P, C, I and the ray hitting the surface at N.
            2. Exterior angle in triangle ONC   ->  i = alpha + gamma
            3. Exterior angle in triangle INC   ->  r = gamma - beta
            4. Small angles: alpha = h/(-u), beta = h/v, gamma = h/R
            5. Snell for small angles: mu1 i = mu2 r
            6. Substitute, cancel h, rearrange:
                    mu2/v  -  mu1/u  =  ( mu2 - mu1 ) / R
  TRAP      Not stating the PARAXIAL assumption. Also, getting the
            direction of the formula backwards — it is
            "mu2 over v MINUS mu1 over u".
```

```
  PATTERN 14 — DERIVE THE LENS MAKER'S FORMULA                    8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the lens maker's formula. State the assumptions."
  METHOD    1. Treat the lens as TWO spherical surfaces.
            2. Surface 1:  mu2/v1 - mu1/u  = (mu2 - mu1)/R1
            3. Surface 2:  mu1/v  - mu2/v1 = (mu1 - mu2)/R2
               (the image I1 becomes the OBJECT for surface 2)
            4. ADD the two equations; the v1 terms cancel.
            5. Divide by mu1, put mu = mu2/mu1.
            6. Put u = infinity, v = f  ->  the lens maker's formula.
  TRAP      Forgetting to state the FOUR assumptions (thin lens, paraxial
            rays, point object on the axis, lens in air). One mark.
```

```
  PATTERN 15 — LENS MAKER NUMERICAL                               4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A biconvex / plano-convex lens has radii ... and mu = ...
            Find f." / "Find f when the lens is dipped in water."
  METHOD    1. Fix the signs of R1 and R2 from the shape table.
            2. Apply  1/f = ( mu - 1 )( 1/R1 - 1/R2 )
            3. In a liquid, replace ( mu - 1 ) by ( mu/mu(L) - 1 ).
  TRAP      Both radii POSITIVE for a biconvex lens. R2 must be NEGATIVE.
            Shortcuts: biconvex with equal R and mu = 1.5 gives f = R.
                       Plano-convex with mu = 1.5 gives f = 2R.
```

```
  PATTERN 16 — LENS NUMERICAL                                     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "An object is placed X cm from a convex/concave lens of
            focal length Y. Find the image."
  METHOD    1. u is NEGATIVE. f is + for convex, - for concave.
            2. Apply  1/v - 1/u = 1/f .
            3. m = v/u  and  h' = m h.
            4. State the nature in words.
  TRAP      Using the MIRROR formula (with a plus) by mistake.
            Mirror -> plus. Lens -> minus.
```

```
  PATTERN 17 — POWER AND COMBINATION OF LENSES                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define the power of a lens." / "Two lenses of focal length
            ... are placed in contact. Find F and P."
  METHOD    1. P = 1/f with f in METRES  (or P = 100 / f in cm)
            2. In contact:  1/F = 1/f1 + 1/f2 ,  P = P1 + P2
            3. Separated by d:  1/F = 1/f1 + 1/f2 - d/(f1 f2)
  TRAP      Leaving f in centimetres when computing P. Always convert.
            Also, the "in contact" formula does NOT apply if a
            separation is mentioned.
```

```
  PATTERN 18 — LENS RAY DIAGRAMS AND THE IMAGE TABLE           2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Draw ray diagrams for image formation by a convex lens for
            various positions of the object."
  METHOD    Use only two of the three standard rays:
              parallel ray  ->  through F
              ray through O ->  straight on
              ray through F ->  emerges parallel
            Then reproduce the six-row table.
  TRAP      A concave lens ALWAYS gives a virtual erect diminished image.
            Never draw a real image for it.
```

```
  PATTERN 19 — DERIVE  A + D = i + e                              4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the relation between the angle of the prism, the
            angle of deviation, the angle of incidence and the angle
            of emergence."
  METHOD    1. Quadrilateral A-N-O-N':   A + angle NON' = 180
            2. Triangle NON':            r1 + r2 + angle NON' = 180
            3. Therefore  A = r1 + r2
            4. D = ( i - r1 ) + ( e - r2 ) = ( i + e ) - A
  TRAP      Writing the deviation at one face only. There are TWO faces
            and the deviations ADD.
```

```
  PATTERN 20 — DERIVE THE PRISM FORMULA + THE i-D GRAPH           8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive  mu = sin((A + Dm)/2) / sin(A/2) . Draw the i-D graph
            and state the conditions for minimum deviation."
  METHOD    1. Get  A = r1 + r2  and  A + D = i + e  first.
            2. Draw the i-D graph (a U-shaped curve with a single minimum).
            3. At the minimum, i = e and r1 = r2 = A/2 , D = Dm.
            4. So  r = A/2  and  i = ( A + Dm ) / 2.
            5. Snell at the first face:  mu = sin i / sin r.
  TRAP      Using the prism formula when the question is NOT about
            minimum deviation. If the question just gives i and D,
            use A + D = i + e instead.
```

```
  PATTERN 21 — PRISM NUMERICAL                                 2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A = ... , Dm = ... Find mu." / "Find Dm given mu and A."
            / "A thin prism of angle ... produces a deviation of ..."
  METHOD    1. If the prism angle is 10 degrees or less, use D = (mu-1)A.
            2. Otherwise use the full prism formula.
            3. If i and e are both given, use A + D = i + e.
  TRAP      "Passes symmetrically" or "i = e" is code for MINIMUM
            DEVIATION. Recognise it instantly.
```

```
  PATTERN 22 — DISPERSION, ANGULAR DISPERSION, DISPERSIVE POWER  2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define dispersive power." / "mu(v) = ... , mu(r) = ...
            Find the angular dispersion / dispersive power."
  METHOD    1. Angular dispersion  theta = ( mu(v) - mu(r) ) A
            2. Mean deviation      D(y)  = ( mu(y) - 1 ) A
            3. Dispersive power    omega = ( mu(v) - mu(r) ) / ( mu(y) - 1 )
  TRAP      Dispersive power contains NO A. If your answer has the prism
            angle in it, you have used the wrong formula.
```

```
  PATTERN 23 — SCATTERING: BLUE SKY AND RED SUNSET             2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why is the sky blue?" / "Why does the setting Sun look red?"
            / "Why is the sky black for an astronaut?"
  METHOD    1. State Rayleigh's law:  I is proportional to 1/lambda^4
            2. Blue has a short lambda, so it scatters far more.
            3. At sunset the long path scatters all the blue away,
               leaving red.
            4. No atmosphere in space means no scattering, hence black.
  NOTE      Free 2 marks. Just three sentences.
```

```
  PATTERN 24 — SIMPLE MICROSCOPE                               2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the magnifying power of a magnifying glass ..."
  METHOD    Image at the near point   ->   m = 1 + D/f
            Image at infinity         ->   m = D/f
            with D = 25 cm
  TRAP      Mixing up the two cases. The near-point value is always
            exactly ONE more than the infinity value.
```

```
  PATTERN 25 — COMPOUND MICROSCOPE (DIAGRAM + DERIVATION)         8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Draw the ray diagram of a compound microscope and derive
            an expression for its magnifying power."
  METHOD    1. DRAW the labelled ray diagram (objective, eyepiece, A'B',
               final image A''B'', uo, vo, ue, L).
            2. Describe the construction (fo very small, fe small).
            3. Describe the working in 4 lines.
            4. M = m(objective) x m(eyepiece) = (vo/uo)(1 + D/fe)
               at the near point, and (vo/uo)(D/fe) at infinity.
            5. Tube length  L = vo + ue.
            6. To increase M: make fo and fe both SMALL.
  NOTE      *** THE MOST-REPEATED 8-MARK QUESTION IN THIS CHAPTER ***
  TRAP      Drawing the diagram without labels. Half the marks are for
            the labelled diagram alone.
```

```
  PATTERN 26 — ASTRONOMICAL TELESCOPE (DIAGRAM + DERIVATION)      8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Draw the ray diagram of an astronomical telescope in normal
            adjustment and derive its magnifying power."
  METHOD    1. DRAW the labelled diagram: parallel rays in, objective,
               common focus, eyepiece, final image at infinity.
            2. M = beta / alpha = ( h/fe ) / ( h/fo ) = fo / fe
            3. Tube length  L = fo + fe
            4. Near-point case: M = (fo/fe)(1 + fe/D) , L = fo + ue
            5. For high M: fo LARGE, fe SMALL. For a bright image:
               LARGE objective aperture.
  NOTE      Easier than the microscope. If you only have time for ONE
            8-mark instrument answer, learn THIS one.
```

```
  PATTERN 27 — MICROSCOPE / TELESCOPE NUMERICAL                4 or 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "fo = ... , fe = ... , tube length = ... Find the magnifying
            power."
  METHOD    TELESCOPE:  straight substitution into M = fo/fe , L = fo + fe
            MICROSCOPE: 1. Find ue from the eyepiece lens formula with
                           ve = -25 cm.
                        2. vo = L - |ue|
                        3. Find uo from the objective lens formula.
                        4. M = (vo/uo)(1 + D/fe)
  TRAP      Forgetting that ve = -25 cm (negative) for the eyepiece.
```

```
  PATTERN 28 — DEFECTS OF VISION                               2 or 4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A person cannot see beyond ... " (myopia)
            "A person's near point is ... " (hypermetropia)
  METHOD    MYOPIA:         u = infinity , v = -(far point)
                            f = -(far point) , P is NEGATIVE, CONCAVE lens
            HYPERMETROPIA:  u = -25 cm , v = -(near point)
                            f = D N / ( N - D ) , P POSITIVE, CONVEX lens
  TRAP      v is always NEGATIVE for a spectacle lens, because the image
            it forms is virtual and on the same side as the object.
```

# GUARANTEED-MARKS PLAN FOR THIS CHAPTER

```
  ==================== TIER 1  —  DO THIS FIRST ====================
  (about 2 hours, worth roughly 10 marks)

  1.  THE SIGN CONVENTION. Write it out five times.
  2.  1/v + 1/u = 1/f  (mirror)   and   1/v - 1/u = 1/f  (lens)
      plus  m = -v/u  and  m = v/u .   Do 8 numericals.
  3.  sin C = 1/mu , the two conditions for TIR, and the four
      applications.
  4.  ONE 8-mark instrument answer. Choose the ASTRONOMICAL TELESCOPE —
      the diagram is simpler and the derivation is three lines.

  ==================== TIER 2  —  DO THIS NEXT ====================
  (about 2 more hours, worth roughly 5 more marks)

  5.  The COMPOUND MICROSCOPE diagram and magnifying power.
  6.  The PRISM: A + D = i + e , minimum deviation conditions, the
      prism formula, and the i-D graph.
  7.  Apparent depth and normal shift.
  8.  Power of a lens, combination in contact.
  9.  Blue sky / red sunset (free 2 marks).
  10. Myopia and hypermetropia.

  ==================== TIER 3  —  IF TIME PERMITS ====================

  11. Derivation of f = R/2.
  12. Derivation of the mirror formula.
  13. Refraction at a single spherical surface.
  14. Lens maker's formula derivation.
  15. Dispersive power and angular dispersion.
```
