## THE 60-SECOND VERSION

Light travels in straight lines called **rays**. This chapter asks only three
questions, over and over:

```
  1.  What happens when light HITS a shiny surface?   ->  REFLECTION (mirrors)
  2.  What happens when light ENTERS a new medium?    ->  REFRACTION (lenses,
                                                          prisms, slabs)
  3.  How do we STACK lenses to see small or far
      things?                                         ->  OPTICAL INSTRUMENTS
```

And in the whole chapter there are really only **two master equations**:

```
  MIRRORS         1/v  +  1/u  =  1/f
  LENSES          1/v  -  1/u  =  1/f
```

Notice the ONLY difference is a **plus** for mirrors and a **minus** for lenses.
If you remember that one sentence you have half the numerical marks already.

## THE KEY BOX — LEARN THIS BEFORE ANYTHING ELSE

```
  +======================================================================+
  |                       THE TWO MASTER FORMULAE                        |
  +======================================================================+
  |                                                                      |
  |   MIRROR                          LENS                               |
  |                                                                      |
  |     1     1     1                   1     1     1                    |
  |    --- + --- = ---                 --- - --- = ---                   |
  |     v     u     f                   v     u     f                    |
  |                                                                      |
  |            R                                                         |
  |     f  =  ---                       P  =  1 / f    (f in METRES)     |
  |            2                                                         |
  |                                                                      |
  |            -v      h'                       v      h'                |
  |     m  =  ----  = ----              m  =  ----  = ----               |
  |             u      h                        u      h                 |
  |                                                                      |
  |   NOTE THE SIGNS:  mirror has  + between the two terms                |
  |                    lens   has  - between the two terms                |
  |                    mirror magnification has a MINUS in front          |
  |                    lens magnification has NO minus in front           |
  +======================================================================+
```

```
  +======================================================================+
  |            THE CARTESIAN SIGN CONVENTION  (use it EVERY time)        |
  +======================================================================+
  |                                                                      |
  |                        + height (up)                                 |
  |                             ^                                        |
  |                             |                                        |
  |                             |                                        |
  |     INCOMING LIGHT  ------> |                                        |
  |     ============>           |  P (pole / optical centre)             |
  |   ----------------------[---o---]--------------------------->        |
  |        distances are        |         distances are                  |
  |        NEGATIVE  (-)        |         POSITIVE  (+)                  |
  |        (against the light)  |         (along the light)              |
  |                             |                                        |
  |                             v                                        |
  |                        - height (down)                               |
  |                                                                      |
  |   RULE 1  All distances are measured FROM THE POLE P                 |
  |           (mirror) or from the OPTICAL CENTRE (lens).                |
  |   RULE 2  Light always travels LEFT to RIGHT in your diagram.        |
  |   RULE 3  Distance measured ALONG the incoming light  ->  +          |
  |           Distance measured AGAINST the incoming light ->  -         |
  |   RULE 4  Heights ABOVE the principal axis  ->  +                    |
  |           Heights BELOW the principal axis  ->  -                    |
  |                                                                      |
  |   CONSEQUENCE THAT SAVES YOU EVERY TIME:                             |
  |       The object is ALWAYS on the left, so  u  is ALWAYS NEGATIVE.   |
  |       CONCAVE mirror   f = -ve        CONVEX mirror   f = +ve        |
  |       CONVEX  lens     f = +ve        CONCAVE lens    f = -ve        |
  +======================================================================+
```

## THE ONE TABLE THAT EARNS THE MOST MARKS

Sign of f, and what each device does:

```
  +-------------------+--------+---------------------------------------+
  |  DEVICE           |  f     |  IMAGE IT USUALLY MAKES               |
  +-------------------+--------+---------------------------------------+
  |  Plane mirror     |  inf.  |  virtual, erect, same size, behind    |
  |  CONCAVE mirror   |  -ve   |  real & inverted (virtual only when   |
  |                   |        |  the object is inside the focus)      |
  |  CONVEX mirror    |  +ve   |  ALWAYS virtual, erect, diminished    |
  |  CONVEX lens      |  +ve   |  real & inverted (virtual only when   |
  |                   |        |  the object is inside the focus)      |
  |  CONCAVE lens     |  -ve   |  ALWAYS virtual, erect, diminished    |
  +-------------------+--------+---------------------------------------+

  MEMORY LINE:   "CONVEX MIRROR and CONCAVE LENS are the two liars —
                  they ALWAYS give a small, upright, virtual image."
```

## IF YOU ONLY HAVE 2 DAYS

```
  ==================== DAY 1  (about 4 hours) ====================

  HOUR 1   The sign convention. Write it out 5 times.
           Mirror formula + magnification. Do 5 numericals.

  HOUR 2   Snell's law, refractive index, mu = c/v.
           Apparent depth and normal shift. Do 3 numericals.
           Total internal reflection, mu = 1/sin C, and the 4 applications.

  HOUR 3   Lens formula, lens maker's formula, power, lenses in contact.
           Do 5 numericals.

  HOUR 4   The PRISM.  Derive  A + D = i + e.  Learn the prism formula.
           Draw the i-D graph. State the minimum deviation condition.

  ==================== DAY 2  (about 4 hours) ====================

  HOUR 5   COMPOUND MICROSCOPE - draw the ray diagram 5 times,
           write the magnifying power for both cases.

  HOUR 6   ASTRONOMICAL TELESCOPE - draw the ray diagram 5 times,
           magnifying power and tube length for both cases.

  HOUR 7   Dispersion, dispersive power, scattering (blue sky / red sunset).
           Human eye, myopia, hypermetropia and their correction.

  HOUR 8   Work straight through 03-pyq-ap-board.md.
           Then time yourself on 05-question-patterns.md.
```

**If you only have 2 HOURS instead of 2 days, learn just these four:**

```
  1.  The sign convention.
  2.  1/v + 1/u = 1/f  (mirror)  and  1/v - 1/u = 1/f  (lens).
  3.  mu = 1/sin C  and the four applications of total internal reflection.
  4.  ONE of the two instrument diagrams (pick the TELESCOPE - it is easier).
```

That alone is worth roughly **10 marks out of 60**.
