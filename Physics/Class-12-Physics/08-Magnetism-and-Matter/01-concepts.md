# TOPIC 1 — The bar magnet and magnetic poles

## What a magnet actually is

A magnet is a piece of material that attracts iron, and that always points north-south
when it is free to turn. The ends where the attraction is strongest are called the
**POLES**.

```
                MAGNETIC LENGTH  =  2l
        <---------------------------------------->

        +-------------------+-------------------+
        |         S         |         N         |
        +-------------------+-------------------+
        ^                   ^                   ^
      SOUTH               CENTRE              NORTH
      POLE                                    POLE

        <---------------------------------------->
                GEOMETRIC LENGTH  =  L

        RULE OF THUMB:      2l  =  (5/6) x L
                            The poles sit a little INSIDE the ends.
```

The end that points towards the earth's geographic north is called the **north-seeking
pole**, written simply as the **N pole**. The other end is the **S pole**.

```
  LIKE poles     ->  REPEL      (N-N or S-S)
  UNLIKE poles   ->  ATTRACT    (N-S)

  Repulsion is the SURE test of magnetism.
  (Attraction is not, because a magnet also attracts ordinary unmagnetised iron.)
```

> **TRAP:** "Which is the sure test of magnetism — attraction or repulsion?" is a
> favourite 2-mark question. The answer is **REPULSION**, and you must give the reason:
> a magnet attracts unmagnetised iron too, so attraction proves nothing.

## Pole strength

**Pole strength `m`** measures how strong one pole is.

```
  +------------------------------------------------------------+
  |                                                            |
  |     Force on a pole placed in a field B :   F  =  m B      |
  |                                                            |
  |     Unit of pole strength :   ampere metre   (A m)         |
  |                                                            |
  |     The two poles of ONE magnet always have EQUAL           |
  |     and OPPOSITE strengths  (+m at N, -m at S).            |
  |                                                            |
  +------------------------------------------------------------+
```

## Magnetic dipole moment

```
  +------------------------------------------------------------+
  |                                                            |
  |         M  =  m  x  2l                                     |
  |                                                            |
  |         M  =  magnetic dipole moment                       |
  |         m  =  pole strength      (A m)                     |
  |        2l  =  magnetic length    (m)                       |
  |                                                            |
  |         UNIT of M :   ampere metre-squared   (A m^2)       |
  |         also written as   joule / tesla   (J/T)            |
  |                                                            |
  |         M is a VECTOR pointing from S to N inside          |
  |         the magnet.                                        |
  |                                                            |
  +------------------------------------------------------------+
```

Think of `M` as the "how magnetic am I" number of the whole magnet. A long strong magnet
has a big `M`; a tiny weak one has a small `M`.

## ISOLATED MAGNETIC POLES DO NOT EXIST

This is the single most important idea in the whole chapter.

You can have a lone positive charge. You can have a lone negative charge. But nobody has
ever found a lone N pole or a lone S pole. They are called **magnetic monopoles**, and
they have never been observed.

**Why?** Because magnetism is not caused by "magnetic charge" at all — it is caused by
**circulating currents** (electrons orbiting and spinning inside atoms). A current loop
automatically has two faces, one behaving as N and one as S. You cannot have a loop with
only one face.

## What happens when a magnet is cut

```
   ORIGINAL MAGNET          moment M,  pole strength m,  length 2l

        +---------+---------+
        |    S    |    N    |
        +---------+---------+


   CUT PERPENDICULAR TO THE LENGTH (across the middle)

        +---------+         +---------+
        |  S   N  |         |  S   N  |
        +---------+         +---------+

        Each piece is a COMPLETE magnet with BOTH poles.

        pole strength  m   ->  UNCHANGED  ( = m )
        length         2l  ->  HALVED     ( = l )
        moment         M   ->  HALVED     ( = M/2 )


   CUT PARALLEL TO THE LENGTH (lengthwise, into two thin slabs)

        +-------------------+
        |    S    |    N    |
        +-------------------+
        |    S    |    N    |
        +-------------------+

        pole strength  m   ->  HALVED     (the face area is halved)
        length         2l  ->  UNCHANGED
        moment         M   ->  HALVED     ( = M/2 )
```

```
  In BOTH cases the MOMENT is halved.
  What changes is WHICH factor got halved.
```

> **TRAP:** Students write "the two pieces become one N magnet and one S magnet".
> That is completely wrong and loses the whole mark. **Every piece, however small, is a
> full magnet with an N and an S pole.** Keep cutting forever and you end at a single
> atom — which is still a tiny dipole, never a monopole.

## WORKED EXAMPLE 1.1

*A bar magnet of magnetic moment 3.2 A m^2 and magnetic length 8 cm is cut into two
equal halves perpendicular to its length. Find the pole strength and the magnetic
moment of each piece.*

```
  STEP 1  Find the original pole strength.

              M  =  m x 2l

              3.2  =  m x 0.08

              m  =  3.2 / 0.08  =  40 A m


  STEP 2  Cut perpendicular to the length:
              pole strength stays the same       m' = 40 A m
              length is halved                   2l' = 0.04 m


  STEP 3  New moment.

              M'  =  m' x 2l'  =  40 x 0.04  =  1.6 A m^2

  CHECK:      M' = M/2 = 3.2/2 = 1.6  ✓
```

**ANSWER:** pole strength = **40 A m** (unchanged), moment = **1.6 A m^2** (halved).

# TOPIC 2 — Magnetic field lines

A **magnetic field line** is an imaginary curve drawn so that the tangent at any point
gives the direction of the magnetic field at that point.

```
              MAGNETIC FIELD LINES OF A BAR MAGNET

                   ___________________
                  /                   \
                 /    _____________    \
                /    /             \    \
               |    |    _______    |    |
               |    |   /       \   |    |
               |    |  |  +---------------+  |
        <------|----|--|  |  S  ===>  N  |  |--|----|------>
               |    |  |  +---------------+  |
               |    |   \_______/   |    |
               |    |               |    |
                \    \_____________/    /
                 \                     /
                  \___________________/

     OUTSIDE the magnet :   lines run from  N  to  S
     INSIDE  the magnet :   lines run from  S  to  N
     ==> every line is a CLOSED LOOP
```

## The properties of magnetic field lines (learn all six)

```
  +---+------------------------------------------------------------------+
  | 1 | They are CONTINUOUS CLOSED CURVES. They have no beginning and    |
  |   | no end. (Outside: N -> S.  Inside: S -> N.)                      |
  +---+------------------------------------------------------------------+
  | 2 | The TANGENT at any point gives the DIRECTION of B there.          |
  +---+------------------------------------------------------------------+
  | 3 | The NUMBER OF LINES PER UNIT AREA (crowding) is proportional to  |
  |   | the STRENGTH of B. Lines are most crowded at the poles.           |
  +---+------------------------------------------------------------------+
  | 4 | Two field lines NEVER INTERSECT. If they did, there would be two |
  |   | different directions of B at one point, which is impossible.      |
  +---+------------------------------------------------------------------+
  | 5 | They behave like STRETCHED ELASTIC THREADS: they try to CONTRACT |
  |   | along their length (this explains attraction of unlike poles)     |
  |   | and they REPEL each other sideways (this explains repulsion of    |
  |   | like poles).                                                      |
  +---+------------------------------------------------------------------+
  | 6 | They can pass through ANY material, including iron and vacuum.    |
  |   | There is no magnetic insulator.                                   |
  +---+------------------------------------------------------------------+
```

## Magnetic field lines COMPARED with electric field lines

| Point | ELECTRIC field lines | MAGNETIC field lines |
|---|---|---|
| Start / end | Start on **+** charge, end on **-** charge | **No start, no end** — closed loops |
| Isolated source | Possible (a single charge) | **Impossible** (no monopole) |
| Inside the source | Do **not** exist inside a conductor | **Do** exist inside the magnet (S to N) |
| Can they cross? | No | No |
| Flux through a closed surface | `q(enclosed) / e0` — can be non-zero | **Always ZERO** |
| Work in a closed path | Zero (field is conservative) | Zero for a static field |
| Shielding | Possible — a metal box shields E | **Not possible** — no magnetic insulator |
| What they represent | Force per unit charge | Direction a free N pole would move |

> **TRAP:** "Magnetic field lines start at N and end at S" is HALF a statement and
> costs marks. You must add "outside the magnet", and then state that inside the magnet
> they run from S to N so that every line closes on itself.

## WORKED EXAMPLE 2.1

*Why can two magnetic field lines never intersect?*

```
  Suppose two lines DID cross at a point P.

              line 1
                 \       /  line 2
                  \     /
                   \   /
                    \ /
                     P
                    / \
                   /   \
                  /     \
                 /       \

  The tangent to line 1 at P gives one direction of B.
  The tangent to line 2 at P gives a DIFFERENT direction of B.

  So the magnetic field at P would point in TWO directions at once.
  A field has only ONE value at a point.  ==>  CONTRADICTION.

  Therefore field lines never intersect.
```

# TOPIC 3 — The bar magnet as an equivalent solenoid

This is the "big idea" question of the chapter and it is asked again and again for
4 marks.

## The claim

**Ampere's hypothesis:** all magnetism comes from circulating electric currents.
Therefore a bar magnet should be identical, from the outside, to a **current-carrying
solenoid** of the same size.

If you place a small compass around a solenoid carrying a steady current, and then
around a bar magnet, the compass behaves in exactly the same way. The field patterns
are indistinguishable.

```
        BAR MAGNET                        SOLENOID (current in)

    +-----------------+              ((((((((((((((((((
    |   S  =====>  N  |              (  (  (  (  (  (  ---> current
    +-----------------+              ((((((((((((((((((
            |                                 |
            v                                 v
      ___________                       ___________
     /           \                     /           \
    |  ---------> |                   |  ---------> |
     \___________/                     \___________/

          SAME EXTERNAL FIELD PATTERN
```

## The derivation (write this in the exam)

```
  SET-UP

    Solenoid of length  2l , radius  a ,
    n turns per unit length, carrying current  I .
    Total number of turns  N = n (2l) .

    Find B at a point P on the axis, at distance r from the centre,
    with  r >> l  and  r >> a .


           |<---------- 2l ---------->|
           +--------------------------+
           |))))))))))))))))))))))))))|- - - - - - - - - - -> P
           +--------------------------+          ^
           -l        O        x   dx  +l         |
                     |<--------- r ------------->|
```

```
  STEP 1  Take an ELEMENT of the solenoid of thickness dx at a distance x
          from the centre. It contains  n dx  turns.

  STEP 2  The field on the axis of a circular coil of  n dx  turns, radius a,
          at a distance (r - x) from it is

                        mu0 (n dx) I a^2
              dB  =  --------------------------
                     2 [ (r - x)^2 + a^2 ]^(3/2)

  STEP 3  Integrate over the whole solenoid, x from  -l  to  +l :

                     mu0 n I a^2      +l              dx
              B  =  --------------  INT      ------------------------
                          2          -l      [ (r-x)^2 + a^2 ]^(3/2)

  STEP 4  Since r is very large compared with x and a,

              [ (r - x)^2 + a^2 ]^(3/2)   is approximately   r^3

          so it comes out of the integral:

                     mu0 n I a^2     +l                 mu0 n I a^2
              B  =  --------------  INT  dx      =    --------------  x (2l)
                       2 r^3         -l                    2 r^3


                     mu0  n (2l) I a^2
              B  =  ---------------------
                          2 r^3

  STEP 5  Multiply and divide by  2 pi  to force the standard shape:

                     mu0      2 [ n (2l) I (pi a^2) ]
              B  =  ------ x --------------------------
                     4 pi              r^3
```

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |                        mu0      2 M                                |
  |               B  =   ------  x  -------                            |
  |                       4 pi       r^3                               |
  |                                                                    |
  |     with        M  =  n (2l) I (pi a^2)  =  N I A                  |
  |                                                                    |
  |     N = total turns,  I = current,  A = cross-section area         |
  |                                                                    |
  +--------------------------------------------------------------------+

  This is EXACTLY the axial field of a bar magnet of moment M.

  CONCLUSION:  A bar magnet is equivalent to a solenoid, and the
               magnetic moment of a current loop of N turns is

                          M  =  N I A
```

## Why this matters

```
  Because of this equivalence:

    - "pole strength" is only a convenient fiction; the real thing
      is the CURRENT LOOP.
    - A single pole is impossible, because a loop always has two faces.
    - Every atom, with its orbiting and spinning electrons, is a tiny
      current loop, i.e. a tiny magnet. That is the seed of the whole
      "Magnetic Materials" half of this chapter.
```

## WORKED EXAMPLE 3.1

*A solenoid of length 25 cm has 500 turns of wire and carries a current of 3 A. Its
cross-sectional area is 4 cm^2. Find its magnetic dipole moment. What is the axial
field at a point 50 cm from its centre?*

```
  STEP 1   M  =  N I A
              =  500 x 3 x (4 x 10^-4)
              =  500 x 3 x 0.0004
              =  0.6  A m^2

  STEP 2   Axial field at r = 0.5 m
           (r = 50 cm is much larger than the length 25 cm, so the
            far-point formula is fair)

                     mu0     2 M                      2 x 0.6
              B  =  ------ x ------  =  10^-7  x  ---------------
                     4 pi     r^3                    (0.5)^3

                                          1.2
                 =  10^-7  x   -------------  =  10^-7 x 9.6
                                  0.125

              B  =  9.6 x 10^-7  T
```

**ANSWER:** M = **0.6 A m^2**, B = **9.6 x 10^-7 T** directed along the axis.

# TOPIC 4 — Field of a bar magnet on the AXIAL line

The **axial line** (also called the *end-on* position, or the *tan-A* position) is the
straight line through both poles, extended outwards.

```
        <--------- 2l --------->
        +-----------------------+
        |    S             N    |- - - - - - - - - - - - ->  P
        +-----------------------+                           .
       -m                       +m                          .
        |<--------- r ----------|-------------------------->|
        |<--------- (r + l) ------------------------------->|
                                |<------- (r - l) --------->|
                                          O = centre
```

## Derivation

```
  STEP 1  Field at P due to the N pole (repels a hypothetical N test pole,
          so it points AWAY from N, i.e. towards the right):

                       mu0        m
              B(N)  = ------ x --------        directed  O -> P
                       4 pi    (r - l)^2

  STEP 2  Field at P due to the S pole (attracts, so it points towards S,
          i.e. towards the left):

                       mu0        m
              B(S)  = ------ x --------        directed  P -> O
                       4 pi    (r + l)^2

  STEP 3  They are opposite, so subtract:

                             mu0        +-      1              1      -+
              B(axial)  =   ------ m    | -----------  -  ----------- |
                             4 pi       +- (r - l)^2       (r + l)^2 -+

  STEP 4  Take the LCM:

                             mu0        (r+l)^2 - (r-l)^2
              B(axial)  =   ------ m x --------------------
                             4 pi         (r^2 - l^2)^2

                             mu0            4 r l
                        =   ------ m x ------------------
                             4 pi       (r^2 - l^2)^2

          Now use  M = m (2l) , so  m (4 r l) = 2 r [ m (2l) ] = 2 M r :

                             mu0        2 M r
              B(axial)  =   ------ x ----------------
                             4 pi     (r^2 - l^2)^2

  STEP 5  For a SHORT magnet (r >> l) drop l^2 :

                             mu0      2 M
              B(axial)  =   ------ x -------
                             4 pi     r^3
```

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |    EXACT :                    mu0        2 M r                     |
  |                   B  =      ------  x  ---------------             |
  |                              4 pi       (r^2 - l^2)^2              |
  |                                                                    |
  |    SHORT MAGNET (r >> l) :    mu0        2 M                       |
  |                   B  =      ------  x  --------                    |
  |                              4 pi        r^3                       |
  |                                                                    |
  |    DIRECTION :  PARALLEL to M  (same direction as the moment)      |
  |                                                                    |
  +--------------------------------------------------------------------+
```

# TOPIC 5 — Field of a bar magnet on the EQUATORIAL line

The **equatorial line** (also called the *broadside-on* position, or the *tan-B*
position) is the perpendicular bisector of the magnet.

```
                              P
                             /|\
                            / | \
                  B(S)     /  |  \     B(N)
                          /   |   \
                         /    |    \
              sqrt(r^2+l^2)   |  sqrt(r^2+l^2)
                       /      | r     \
                      /       |        \
                     /  theta |  theta  \
        +-----------+---------+----------+-----------+
        |     S     |         O          |     N     |
        +-----------+--------------------+-----------+
       -m           |<---- l ---->|<--- l --->|      +m
```

## Derivation

```
  STEP 1  Distance from EITHER pole to P:

              d  =  sqrt( r^2 + l^2 )        (the same for both)

  STEP 2  Magnitude of the field due to each pole:

                             mu0         m
              B(N) = B(S) = ------ x -----------
                             4 pi     (r^2 + l^2)

          B(N) points AWAY from N (along N -> P extended)
          B(S) points TOWARDS S  (along P -> S)

  STEP 3  RESOLVE both into components.

          The components PERPENDICULAR to the magnet (the "up" components)
          are equal and opposite  ->  they CANCEL.

          The components PARALLEL to the magnet (both pointing from
          N towards S) ADD:

              B(eq)  =  B(N) cos(theta)  +  B(S) cos(theta)
                     =  2 B(N) cos(theta)

  STEP 4  From the geometry:

                                    l
              cos(theta)  =  -----------------
                             sqrt(r^2 + l^2)

  STEP 5  Substitute:

                         mu0         m                    l
              B(eq) = 2 ------ x ----------- x -------------------
                         4 pi    (r^2 + l^2)   sqrt(r^2 + l^2)

                         mu0          m (2l)
                      = ------ x ---------------------
                         4 pi     (r^2 + l^2)^(3/2)

                         mu0            M
                      = ------ x ---------------------
                         4 pi     (r^2 + l^2)^(3/2)

  STEP 6  For a SHORT magnet (r >> l):

                         mu0        M
              B(eq)  =  ------ x -------
                         4 pi     r^3
```

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |    EXACT :                   mu0             M                     |
  |                  B  =      ------  x  --------------------         |
  |                             4 pi       (r^2 + l^2)^(3/2)           |
  |                                                                    |
  |    SHORT MAGNET (r >> l) :   mu0          M                        |
  |                  B  =      ------  x  --------                     |
  |                             4 pi        r^3                        |
  |                                                                    |
  |    DIRECTION :  ANTI-PARALLEL to M  (OPPOSITE to the moment)       |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## THE COMPARISON — axial versus equatorial

```
  +------------------+--------------------------+--------------------------+
  |                  |  AXIAL (end-on)          |  EQUATORIAL (broadside)  |
  +------------------+--------------------------+--------------------------+
  |  Position        |  On the axis, extended   |  On the perpendicular    |
  |                  |  beyond the poles        |  bisector                |
  +------------------+--------------------------+--------------------------+
  |                  |   mu0     2 M            |   mu0      M             |
  |  Short-magnet B  |  ------ x -----          |  ------ x -----          |
  |                  |   4 pi     r^3           |   4 pi     r^3           |
  +------------------+--------------------------+--------------------------+
  |  Direction       |  SAME as M (parallel)    |  OPPOSITE to M           |
  +------------------+--------------------------+--------------------------+
  |  Exact form      |   mu0     2 M r          |   mu0        M           |
  |                  |  ------ x ----------     |  ------ x -----------    |
  |                  |   4 pi   (r^2-l^2)^2     |   4 pi   (r^2+l^2)^1.5   |
  +------------------+--------------------------+--------------------------+

              ***  B(axial)  =  2  x  B(equatorial)  ***
                    at the SAME distance r from the SAME magnet
```

## THE ELECTROSTATICS <-> MAGNETISM ANALOGY TABLE

Learn this table and you get half of Chapter 4 (Electric Charges) for free.

| Feature | ELECTRIC DIPOLE | MAGNETIC DIPOLE |
|---|---|---|
| Source pair | `+q` and `-q` separated by `2a` | `+m` and `-m` separated by `2l` |
| Dipole moment | `p = q x 2a` (C m) | `M = m x 2l` (A m^2) |
| Constant in front | `1 / (4 pi e0)` = `9 x 10^9` | `mu0 / (4 pi)` = `10^-7` |
| Axial field | `E = (1/4 pi e0) x 2p / r^3` | `B = (mu0/4 pi) x 2M / r^3` |
| Equatorial field | `E = (1/4 pi e0) x p / r^3` | `B = (mu0/4 pi) x M / r^3` |
| Field at a general point | `(1/4 pi e0)(p/r^3) sqrt(1+3cos^2 th)` | `(mu0/4 pi)(M/r^3) sqrt(1+3cos^2 th)` |
| Torque | `tau = p x E`, `tau = pE sin th` | `tau = M x B`, `tau = MB sin th` |
| Potential energy | `U = - p . E = - pE cos th` | `U = - M . B = - MB cos th` |
| Work to rotate | `W = pE(cos th1 - cos th2)` | `W = MB(cos th1 - cos th2)` |
| Force in uniform field | Zero | Zero |
| Flux through closed surface | `q / e0` (Gauss) | **Zero** (Gauss in magnetism) |
| Can the source be split? | Yes — isolated charge exists | **No** — no monopole |

```
  THE ONE-LINE CONVERSION RULE

        1                  mu0
     --------   ---->    ------            p   ---->   M
      4 pi e0             4 pi

  Every electrostatic dipole formula becomes a magnetic one by these
  two substitutions. That is the whole trick.
```

## WORKED EXAMPLE 5.1

*A short bar magnet has a magnetic moment of 0.4 A m^2. Find the magnetic field on its
axis and on its equatorial line, both at a distance of 20 cm from the centre.*

```
  Given   M = 0.4 A m^2 ,  r = 0.20 m ,  mu0/(4pi) = 10^-7

  r^3  =  (0.20)^3  =  0.008  m^3


  AXIAL

                       2 x 0.4               0.8
       B  =  10^-7 x  ----------  = 10^-7 x -------  =  10^-7 x 100
                        0.008                0.008

       B(axial)  =  1.0 x 10^-5  T      directed ALONG M


  EQUATORIAL

                        0.4
       B  =  10^-7 x  -------  =  10^-7 x 50
                       0.008

       B(eq)  =  5.0 x 10^-6  T         directed OPPOSITE to M


  CHECK:   1.0 x 10^-5  =  2 x (5.0 x 10^-6)   ✓
```

> **TRAP:** In the equatorial answer students forget the direction. Always write
> "**opposite to the magnetic moment**". Direction usually carries half a mark.

# TOPIC 6 — Torque on a magnetic dipole in a uniform field

## Set-up

Place a bar magnet of moment `M` in a **uniform** magnetic field `B`, making an angle
`theta` with `B`.

```
                                 F = mB  (up-field)
                                 ^
                                 |
                   +-------------+
                   |          N  |
                   |        /    |             B  ------->
                   |      /      |             B  ------->
                   |    /  theta |             B  ------->
                   |  /          |             B  ------->
                   | ------------|--------->  (direction of B)
                   |  S          |
                   +-------------+
                   |
                   v
                 F = mB  (down-field)

       The two forces are EQUAL, OPPOSITE and NOT along the same line.
       ==>  net FORCE = 0  but net TORQUE is NOT zero.
       ==>  the magnet TURNS but does not MOVE.
```

## Derivation of the torque

```
  STEP 1  Force on the N pole  =  m B   , along  +B
          Force on the S pole  =  m B   , along  -B

          Net force  =  mB - mB  =  ZERO
          (This is why a magnet in a UNIFORM field does not translate.)

  STEP 2  These two form a COUPLE.

              torque  =  (one force)  x  (perpendicular distance
                                          between the two forces)

  STEP 3  From the diagram, the perpendicular distance between the two
          lines of action is  2l sin(theta) :

              tau  =  (m B) x (2l sin theta)
                   =  (m x 2l) B sin(theta)

  STEP 4  Since  M = m x 2l :
```

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |            tau  =  M B sin(theta)                                  |
  |                                                                    |
  |     In vector form :        ->      ->     ->                      |
  |                            tau  =   M   x   B                      |
  |                                                                    |
  |     tau is MAXIMUM  =  M B      when theta = 90 degrees            |
  |     tau is ZERO                 when theta = 0 or 180 degrees      |
  |                                                                    |
  |     DEFINITION OF M :   M = tau(max) / B                           |
  |     "the torque on the magnet when it is placed perpendicular      |
  |      to a unit magnetic field"                                     |
  |                                                                    |
  +--------------------------------------------------------------------+
```

> **TRAP:** "Uniform field" means **no net force, only a torque**. In a
> **NON-uniform** field there IS a net force as well — that is exactly why a
> paramagnetic sample gets sucked towards the strong region of a field.

## WORKED EXAMPLE 6.1

*A bar magnet of moment 0.5 A m^2 is placed in a uniform field of 0.20 T at 30 degrees
to the field. Find the torque acting on it. What is the maximum possible torque?*

```

       =  0.5 x 0.20 x sin(30)
       =  0.5 x 0.20 x 0.5
       =  0.05  N m

  Maximum torque (theta = 90):
  tau(max)  =  M B  =  0.5 x 0.20  =  0.10  N m
```

**ANSWER:** torque = **0.05 N m**, maximum torque = **0.10 N m**.

# TOPIC 7 — Potential energy of a dipole; stable and unstable equilibrium

## Work done in rotating the magnet

To turn the magnet against the torque you must do work.

```
  STEP 1  Small work to turn through a small angle d(theta):

              dW  =  tau d(theta)  =  M B sin(theta) d(theta)

  STEP 2  Total work from theta1 to theta2:

                       theta2
              W  =  INT        M B sin(theta) d(theta)
                       theta1

                 =  M B [ - cos(theta) ]  from theta1 to theta2

              W  =  M B ( cos theta1  -  cos theta2 )

  STEP 3  This work is stored as POTENTIAL ENERGY. Taking U = 0 at
          theta = 90 degrees (the standard convention, because there
          the magnet is perpendicular to the field):

              U  =  M B ( cos 90  -  cos theta )  =  - M B cos(theta)
```

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |            U  =  - M B cos(theta)                                  |
  |                                                                    |
  |     In vector form :         ->    ->                              |
  |                        U  =  - M .  B                              |
  |                                                                    |
  |     Work to rotate from theta1 to theta2 :                         |
  |                                                                    |
  |            W  =  M B ( cos theta1  -  cos theta2 )                 |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## The special angles — memorise this table

```
  +-----------+-------------------+---------------+-----------------------+
  |  theta    |  TORQUE           |  ENERGY U     |  STATE                |
  +-----------+-------------------+---------------+-----------------------+
  |   0 deg   |  0                |  - M B        |  STABLE EQUILIBRIUM   |
  |           |                   |  (MINIMUM)    |  M parallel to B      |
  +-----------+-------------------+---------------+-----------------------+
  |  90 deg   |  M B  (MAXIMUM)   |  0            |  perpendicular        |
  +-----------+-------------------+---------------+-----------------------+
  | 180 deg   |  0                |  + M B        |  UNSTABLE EQUILIBRIUM |
  |           |                   |  (MAXIMUM)    |  M antiparallel to B  |
  +-----------+-------------------+---------------+-----------------------+

  Work needed to flip the magnet completely (0 -> 180):

        W  =  M B ( cos 0 - cos 180 )  =  M B ( 1 - (-1) )  =  2 M B
```

```
  ENERGY versus ANGLE

     U
     |
 +MB |          ___
     |        /     \        <-- UNSTABLE (top of the hill)
     |      /         \
   0 |----/-------------\----------------------- theta
     |  /                 \
     |/                     \
 -MB |                        \___/  <-- STABLE (bottom of the valley)
     +---+--------+--------+--------+----->
         0       90       180      270
```

> **TRAP:** The minus sign in `U = -MB cos(theta)` is worth a mark on its own.
> Physically: nature pushes the magnet to the LOWEST energy, which is
> `theta = 0`, i.e. lined up with the field. That is why a compass points north.

## WORKED EXAMPLE 7.1

*A magnet of moment 0.5 A m^2 lies along a uniform field of 0.20 T. How much work is
needed to rotate it to (i) 60 degrees (ii) 90 degrees (iii) 180 degrees?*

```
  W  =  M B ( cos theta1 - cos theta2 )      with theta1 = 0

  M B  =  0.5 x 0.20  =  0.10  J

  (i)   theta2 = 60     W = 0.10 (1 - 0.5)      =  0.05  J
  (ii)  theta2 = 90     W = 0.10 (1 - 0)        =  0.10  J
  (iii) theta2 = 180    W = 0.10 (1 - (-1))     =  0.20  J    ( = 2MB )
```

**ANSWER:** (i) **0.05 J** (ii) **0.10 J** (iii) **0.20 J**.

# TOPIC 8 — Angular SHM of a magnetic dipole (the oscillation formula)

## What happens

A compass needle, when you push it away from north and release it, does not go straight
back. It **swings to and fro** about the north direction. This is angular simple harmonic
motion.

```
                    B  ------->

              \      |      /
               \     |     /
                \    |    /
                 \   |   /
                  \  |  /
                   \ | /
                    \|/
                     +          <-- pivot at the centre of mass

           The needle swings back and forth about the
           direction of B, exactly like a pendulum.
```

## Derivation

```
  STEP 1  Displace the magnet by a small angle theta.
          The restoring torque tries to bring it back, so it is NEGATIVE:

              tau  =  - M B sin(theta)

  STEP 2  For a rotating body,  tau = I x (angular acceleration) :

                  d2(theta)
              I ------------  =  - M B sin(theta)
                   dt^2

          Here  I  =  MOMENT OF INERTIA of the magnet about the
          vertical axis through its centre.

  STEP 3  For SMALL oscillations,  sin(theta) is approximately theta :

                  d2(theta)          M B
                ------------  =  - ------- theta
                   dt^2               I

  STEP 4  Compare with the SHM equation  d2x/dt2 = - omega^2 x :

                              M B
              omega^2  =  ---------
                              I

                              +-       -+
                              |   M B   |
              omega    =  sqrt| ------- |
                              |    I    |
                              +-       -+

  STEP 5  Time period  T = 2 pi / omega :
```

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |                              +-       -+                           |
  |                              |    I    |                           |
  |         T  =  2 pi   x  sqrt | ------- |                           |
  |                              |  M B    |                           |
  |                              +-       -+                           |
  |                                                                    |
  |         I  =  moment of inertia of the magnet (kg m^2)             |
  |         M  =  magnetic moment (A m^2)                              |
  |         B  =  magnetic field (T)                                   |
  |                                                                    |
  |     For a bar magnet of mass  W , length  L , breadth  b ,         |
  |     oscillating about its centre :                                 |
  |                                                                    |
  |                     W ( L^2 + b^2 )                                |
  |              I  =  ------------------                              |
  |                            12                                      |
  |                                                                    |
  +--------------------------------------------------------------------+
```

```
  READING THE FORMULA

      T  is SMALLER when  M  is bigger      (stronger magnet, faster swing)
      T  is SMALLER when  B  is bigger      (stronger field, faster swing)
      T  is BIGGER  when  I  is bigger      (heavier magnet, slower swing)

      T  does NOT depend on the AMPLITUDE  (for small angles).

      Rearranged, this is how B(H) of the earth is measured in a
      vibration magnetometer:

                     4 pi^2  I
          B     =  --------------
                      M  T^2
```

## WORKED EXAMPLE 8.1

*A bar magnet of magnetic moment 5 A m^2 and moment of inertia 7.5 x 10^-6 kg m^2 is
suspended in a uniform field of 2 x 10^-5 T. Find its period of small oscillations.*

```
  T  =  2 pi sqrt( I / (M B) )

  M B  =  5  x  (2 x 10^-5)  =  1 x 10^-4

   I / (M B)  =  (7.5 x 10^-6) / (1 x 10^-4)  =  7.5 x 10^-2  =  0.075

  sqrt(0.075)  =  0.2739

  T  =  2 x 3.1416 x 0.2739  =  1.72  s
```

**ANSWER:** T = **1.72 s** (about 1.7 seconds).

## WORKED EXAMPLE 8.2

*A magnet makes 20 oscillations per minute at a place. If the magnetic field is made
4 times stronger, how many oscillations per minute will it now make?*

```
  T  is proportional to  1 / sqrt(B)
  ==>  frequency  f  is proportional to  sqrt(B)

  B becomes 4B   ->   f becomes sqrt(4) = 2 times

  New rate  =  2 x 20  =  40 oscillations per minute
```

**ANSWER:** **40 oscillations per minute.**

# TOPIC 9 — Gauss's law in magnetism

## The statement

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |     The NET MAGNETIC FLUX through ANY CLOSED SURFACE               |
  |     is ALWAYS ZERO.                                                |
  |                                                                    |
  |                       ->    ->                                     |
  |          phi(B)  =  $ B  .  dS   =   0                             |
  |                                                                    |
  |     (the $ sign here means a closed-surface integral)              |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## Why it is true

Magnetic field lines are **closed loops**. Any line that enters a closed surface must
come out again somewhere, because it has nowhere to end.

```
          CLOSED SURFACE around one pole of a magnet

                    . - - - - - - - - .
                  .                     .
                 .    +-----------+      .
                 .    |  S     N  |------.------->  lines OUT
       lines  ---.----|           |      .
       IN     ---.----+-----------+      .
                 .                       .
                  .                     .
                    ' - - - - - - - - '

          NUMBER OF LINES GOING IN  =  NUMBER OF LINES COMING OUT
          ==>   net flux  =  0
```

Compare with electrostatics:

```
  ELECTRIC (Gauss's law)          MAGNETIC (Gauss's law in magnetism)
  ------------------------        --------------------------------------
                 q(enclosed)
   $ E . dS  =  -------------      $ B . dS   =   0
                    e0

   Non-zero if the surface        ALWAYS zero, no matter what is inside
   encloses net charge

   ==> ISOLATED CHARGES EXIST     ==> ISOLATED POLES DO NOT EXIST
```

## What it tells us

```
  1.  MAGNETIC MONOPOLES DO NOT EXIST.
      If a single N pole could exist, a surface drawn round it would
      have lines only coming OUT, giving non-zero flux. Experiment says
      the flux is always zero, so no monopole.

  2.  The simplest magnetic structure in nature is the DIPOLE,
      not the monopole.

  3.  Magnetic field lines form CONTINUOUS CLOSED LOOPS.

  4.  This is one of MAXWELL'S FOUR EQUATIONS of electromagnetism.
```

## WORKED EXAMPLE 9.1

*A closed surface encloses the north pole of a bar magnet only. What is the net magnetic
flux through it? What if it encloses the entire magnet?*

```
  Case 1 (N pole only)      :  net flux  =  ZERO
  Case 2 (the whole magnet) :  net flux  =  ZERO

  Gauss's law in magnetism does not care what is inside.
  The answer is ALWAYS ZERO because there are no magnetic monopoles.
```

# TOPIC 10 — The earth's magnetism

## The basic fact

A freely suspended magnet always sets itself along north-south. This means the
**earth itself behaves as a huge magnet**.

```
        GEOGRAPHIC                         The earth's magnetic axis is
        NORTH POLE   *                     tilted about 11.3 degrees
                   /                       from the geographic (rotation)
                  /   ~11.3 deg            axis.
                 /  /
                / /                        The magnetic dipole moment of
        - - - -+/- - - - -  equator        the earth is about
              /|                                8 x 10^22  A m^2
             / |
            /  |                           Field near the surface:
           /   |                                0.3 to 0.6 gauss
          *    |                                = 3 to 6 x 10^-5  T
      GEOGRAPHIC
      SOUTH POLE

  IMPORTANT:  the MAGNETIC SOUTH pole of the earth's equivalent bar
  magnet lies near the GEOGRAPHIC NORTH.  That is why the N pole of
  your compass is attracted towards the north.
```

## The cause of the earth's magnetism (the DYNAMO THEORY)

```
  +---+------------------------------------------------------------------+
  | 1 | The earth's outer core is MOLTEN IRON AND NICKEL, which is a     |
  |   | good electrical conductor.                                       |
  +---+------------------------------------------------------------------+
  | 2 | Convection currents plus the earth's rotation keep this liquid   |
  |   | metal CIRCULATING.                                               |
  +---+------------------------------------------------------------------+
  | 3 | Circulating conducting fluid = huge ELECTRIC CURRENT LOOPS.      |
  +---+------------------------------------------------------------------+
  | 4 | These current loops produce the earth's magnetic field. This is  |
  |   | called the SELF-EXCITING DYNAMO (or geodynamo) EFFECT.           |
  +---+------------------------------------------------------------------+

  Older / partial explanations you may also mention:
    - magnetised iron ore deposits in the crust (rejected: the interior
      is far hotter than the Curie temperature, so it cannot stay
      permanently magnetised)
    - charged particles trapped in the ionosphere and radiation belts
    - electric currents in the ionosphere driven by the solar wind
```

# TOPIC 11 — Magnetisation and magnetic intensity

Now we stop looking at one magnet and start looking at **matter inside a field**.

## Magnetisation (M)

When you put a material in a magnetic field, the tiny atomic dipoles inside it line up.
The material develops a net magnetic moment.

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |                     net magnetic moment                            |
  |     MAGNETISATION = ---------------------- =    M(net)             |
  |          M                 volume               ------             |
  |                                                    V               |
  |                                                                    |
  |     UNIT :   ampere / metre   (A / m)                              |
  |     It is a VECTOR.                                                |
  |     Dimensions :  [ L^-1 A ]                                       |
  |                                                                    |
  +--------------------------------------------------------------------+
```

```
   BEFORE the field is applied              AFTER the field is applied

     ->    <-    ^     v                       ->  ->  ->  ->
     v     ->    <-    ^                       ->  ->  ->  ->
     <-    ^     ->    v                       ->  ->  ->  ->
     ^     v     <-    ->                      ->  ->  ->  ->

   random, net moment = 0                   aligned, net moment large
                                            ==> the sample is MAGNETISED
```

## Magnetic intensity (H) — the "magnetising field"

Inside a magnetised material there are now **two** contributions to the total field `B`:

```
  1.  the field YOU applied from outside      B0 = mu0 H
  2.  the field produced by the material's own alignment   =  mu0 M
```

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |         B  =  mu0 ( H  +  M )                                      |
  |                                                                    |
  |    B  =  total magnetic field inside the material   (tesla)        |
  |    H  =  magnetic intensity / magnetising field     (A / m)        |
  |    M  =  magnetisation                              (A / m)        |
  |                                                                    |
  |    H  is caused ONLY by the free currents you supply:              |
  |            inside a long solenoid,   H  =  n I                     |
  |                                                                    |
  |    Note: H and M have the SAME unit (A/m). B does not.             |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## Susceptibility and permeability

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   MAGNETIC SUSCEPTIBILITY                                          |
  |                                    M                               |
  |                         chi  =  -------                            |
  |                                    H                               |
  |                                                                    |
  |   "how easily the material gets magnetised"                        |
  |   DIMENSIONLESS and UNITLESS.                                      |
  |                                                                    |
  +--------------------------------------------------------------------+

  +--------------------------------------------------------------------+
  |                                                                    |
  |   Starting from   B = mu0 (H + M)   and   M = chi H  :             |
  |                                                                    |
  |       B  =  mu0 ( H + chi H )  =  mu0 H ( 1 + chi )                |
  |                                                                    |
  |   Writing   B = mu H   where mu is the PERMEABILITY:               |
  |                                                                    |
  |       mu  =  mu0 ( 1 + chi )                                       |
  |                                                                    |
  |   RELATIVE PERMEABILITY                                            |
  |                          mu          B                             |
  |             mu(r)  =  -------  =  --------                         |
  |                          mu0        mu0 H                          |
  |                                                                    |
  |                                                                    |
  |          ****    mu(r)  =  1  +  chi    ****                       |
  |                                                                    |
  |   mu(r) is DIMENSIONLESS.   mu has units T m / A  (same as mu0).   |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## The four quantities side by side

| Symbol | Name | Unit | Meaning |
|---|---|---|---|
| `B` | Magnetic field / flux density | tesla (T) | The actual total field inside |
| `H` | Magnetic intensity | A/m | The field you applied from outside |
| `M` | Magnetisation | A/m | Moment developed per unit volume |
| `chi` | Susceptibility | none | `M/H` — willingness to be magnetised |
| `mu(r)` | Relative permeability | none | `1 + chi` — how much the material multiplies the field |

## WORKED EXAMPLE 11.1

*A solenoid has 1000 turns per metre and carries a current of 2 A. A rod of relative
permeability 400 is inserted in it. Find (i) H (ii) the susceptibility (iii) the
magnetisation M (iv) the magnetic field B inside.*

```
  (i)   H  =  n I  =  1000 x 2  =  2000  A/m


  (ii)  mu(r) = 1 + chi
        chi   =  mu(r) - 1  =  400 - 1  =  399


  (iii) M  =  chi H  =  399 x 2000  =  7.98 x 10^5  A/m


  (iv)  B  =  mu0 (H + M)
           =  4 pi x 10^-7  x  ( 2000 + 798000 )
           =  1.2566 x 10^-6  x  8.0 x 10^5
           =  1.005  T


  CHECK using  B = mu(r) mu0 H :
           =  400 x 1.2566 x 10^-6 x 2000
           =  1.005  T    ✓
```

**ANSWER:** H = **2000 A/m**, chi = **399**, M = **7.98 x 10^5 A/m**, B = **1.005 T**.

## WORKED EXAMPLE 11.2

*A bar magnet of magnetic moment 1.2 A m^2 has a volume of 10 cm^3. Find its
magnetisation.*

```
  Volume  =  10 cm^3  =  10 x 10^-6  m^3  =  1 x 10^-5  m^3

              M(moment)       1.2
  M     =   ------------  =  ---------  =  1.2 x 10^5  A/m
               Volume         10^-5
```

**ANSWER:** magnetisation = **1.2 x 10^5 A/m**.

# TOPIC 12 — Magnetic materials: dia, para and ferro

Every substance on earth falls into one of these three classes.

## The everyday picture

```
  DIAMAGNETIC   ->  "It hates magnets."  Weakly PUSHED OUT of a field.
                    Examples: water, copper, bismuth, gold.

  PARAMAGNETIC  ->  "It quite likes magnets." Weakly PULLED IN.
                    Examples: aluminium, oxygen, sodium.

  FERROMAGNETIC ->  "It LOVES magnets." Strongly PULLED IN, and can
                    stay magnetic afterwards.
                    Examples: iron, cobalt, nickel.
```

## The behaviour in a NON-UNIFORM field (the classic diagram)

```
   DIAMAGNETIC rod            PARAMAGNETIC rod         FERROMAGNETIC rod
   suspended between          suspended between        suspended between
   the poles                  the poles                the poles

    N |         | S            N |         | S          N |         | S
      |         |                |         |              |         |
      | =====   |                |    ||   |              |    ||   |
      | ROD     |                |    ||   |              |    ||   |
      |         |                |    ||   |              |    ||   |
    ---+-------+---            ---+-------+---          ---+-------+---

    sets PERPENDICULAR         sets PARALLEL to          sets PARALLEL,
    to the field               the field                 very STRONGLY

    moves from STRONG          moves from WEAK           moves from WEAK
    to WEAK field              to STRONG field           to STRONG field
    (repelled)                 (weakly attracted)        (strongly attracted)
```

## Field lines through each type

```
   DIAMAGNETIC                PARAMAGNETIC               FERROMAGNETIC

   ---\   /-------            ---\ | | /------           --\\ ||| //---
   ----\ /--------            ----\|||/-------           ---\\|||//----
   -----X---------            -----|||--------           ----|||||-----
   ----/ \--------            ----/|||\-------           ---//|||\\----
   ---/   \-------            ---/ | | \------           --//  |  \\---

   lines are PUSHED           a FEW extra lines          lines CROWD
   OUT of the material        crowd in                   strongly in
   (mu(r) slightly < 1)       (mu(r) slightly > 1)       (mu(r) >> 1)
```

## THE FULL COMPARISON TABLE — learn this, it is 4 marks

| Feature | DIAMAGNETIC | PARAMAGNETIC | FERROMAGNETIC |
|---|---|---|---|
| **Cause** | Atoms have **NO** permanent dipole moment (paired electrons; net moment zero). An applied field *induces* an opposing moment (Lenz's law at atomic scale) | Atoms **DO** have permanent dipole moments, but they point randomly; the field partly aligns them | Atoms have permanent moments AND they lock together in **DOMAINS** (large regions all pointing one way) |
| **In a non-uniform field** | Moves from **STRONG to WEAK** field (repelled) | Moves from **WEAK to STRONG** field (weakly attracted) | Moves from **WEAK to STRONG** field (strongly attracted) |
| **Rod in a field** | Sets **PERPENDICULAR** to the field | Sets **PARALLEL** to the field | Sets **PARALLEL**, very quickly |
| **Field lines** | Pushed **out** of the material | Slightly **crowded** inside | Very strongly **crowded** inside |
| **Magnetisation M** | Small, **opposite** to H | Small, **along** H | Very large, **along** H |
| **Susceptibility chi** | Small and **NEGATIVE**, about `-10^-5` | Small and **POSITIVE**, about `+10^-5` to `10^-3` | **Very large POSITIVE**, `10^3` to `10^5` |
| **Range of chi** | `-1 <= chi < 0` | `0 < chi < small positive` | `chi >> 1` |
| **Relative permeability mu(r)** | Slightly **less than 1** (`0 <= mu(r) < 1`) | Slightly **more than 1** (`1 < mu(r) < 1 + eps`) | **Very much greater than 1** (`mu(r) >> 1`, up to 10^5) |
| **Permeability mu** | `mu < mu0` | `mu > mu0` | `mu >> mu0` |
| **Effect of temperature** | **INDEPENDENT** of temperature | `chi = C / T` — **CURIE'S LAW**; chi falls as T rises | Ferromagnetic below the **CURIE TEMPERATURE Tc**; above Tc it becomes **PARAMAGNETIC** with `chi = C/(T - Tc)` |
| **Does it stay magnetised?** | No | No | **YES** — it can be made a permanent magnet |
| **Effect of a liquid in a watch-glass** | Depression at the centre | Rise at the centre | Strong rise |
| **Examples** | Bismuth, copper, lead, silicon, nitrogen, water, sodium chloride, gold, diamond, mercury | Aluminium, sodium, calcium, oxygen (gas), copper chloride, platinum, chromium | Iron, cobalt, nickel, gadolinium, magnetite (Fe3O4), alnico |

## CURIE'S LAW

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   For a PARAMAGNETIC substance :                                   |
  |                                                                    |
  |                     C                              C B             |
  |          chi  =  -------              or     M  =  -----           |
  |                     T                                T             |
  |                                                                    |
  |   C = CURIE CONSTANT ,  T = ABSOLUTE temperature (kelvin)          |
  |                                                                    |
  |   "Susceptibility is INVERSELY proportional to the                 |
  |    ABSOLUTE TEMPERATURE."                                          |
  |                                                                    |
  |   WHY:  heat = random jiggling, which knocks the dipoles out of    |
  |         alignment. Hotter -> less aligned -> weaker magnetisation. |
  |                                                                    |
  +--------------------------------------------------------------------+

    chi
     |
     |  \
     |    \
     |      \                chi = C / T
     |         \                a rectangular hyperbola
     |             \ _
     |                 \ _ _ _ _
     +----------------------------------> T
```

## THE CURIE TEMPERATURE (Tc)

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |   The CURIE TEMPERATURE is the temperature above which a           |
  |   FERROMAGNETIC substance loses its ferromagnetism and             |
  |   becomes PARAMAGNETIC.                                            |
  |                                                                    |
  |   Above Tc (the CURIE-WEISS law):                                  |
  |                                                                    |
  |                         C                                          |
  |            chi  =  -----------          for  T > Tc                |
  |                     T  -  Tc                                       |
  |                                                                    |
  |   Reason: thermal energy destroys the DOMAIN structure.            |
  |                                                                    |
  +--------------------------------------------------------------------+

  +-----------------+------------------+
  |  SUBSTANCE      |  CURIE TEMP Tc   |
  +-----------------+------------------+
  |  Cobalt         |   1394  K        |
  |  Iron           |   1043  K        |
  |  Nickel         |    631  K        |
  |  Gadolinium     |    317  K        |
  +-----------------+------------------+
```

## DOMAINS — why ferromagnets are special

```
  UNMAGNETISED IRON                  MAGNETISED IRON
  (domains point every way,          (domains grow / rotate until
   net moment = 0)                    almost all point one way)

  +-----+-----+-----+-----+          +-----+-----+-----+-----+
  | ->  |  v  | <-  |  ^  |          | ->  | ->  | ->  | ->  |
  +-----+-----+-----+-----+          +-----+-----+-----+-----+
  |  ^  | ->  |  v  | <-  |          | ->  | ->  | ->  | ->  |
  +-----+-----+-----+-----+          +-----+-----+-----+-----+
  | <-  |  ^  | ->  |  v  |          | ->  | ->  | ->  | ->  |
  +-----+-----+-----+-----+          +-----+-----+-----+-----+

  A DOMAIN is a microscopic region (about 1 mm across, containing
  roughly 10^11 atoms) in which ALL the atomic moments are already
  perfectly aligned by a quantum "exchange interaction".

  Magnetising iron does not turn individual atoms — it grows the
  favourably-oriented domains at the expense of the others.
```

> **TRAP:** A superconductor is a **PERFECT DIAMAGNET**: `chi = -1` exactly and
> `mu(r) = 0`, so `B = 0` inside it. The expulsion of the field is called the
> **MEISSNER EFFECT**. This is a favourite one-mark competitive question.

## WORKED EXAMPLE 12.1

*A paramagnetic substance has a susceptibility of 6 x 10^-4 at 300 K. What will its
susceptibility be at 600 K?*

```
  Curie's law:   chi  is proportional to  1/T

        chi1 T1  =  chi2 T2

        (6 x 10^-4)(300)  =  chi2 (600)

                 (6 x 10^-4)(300)
        chi2  =  -----------------  =  3 x 10^-4
                        600
```

**ANSWER:** **3 x 10^-4** (halved, because the temperature doubled).

## WORKED EXAMPLE 12.2

*A material has a relative permeability of 0.9998. Identify its type and find its
susceptibility.*

```
  chi  =  mu(r) - 1  =  0.9998 - 1  =  - 2 x 10^-4

  chi is NEGATIVE and small,  mu(r) is slightly LESS than 1

  ==>  the material is DIAMAGNETIC
```

**ANSWER:** **diamagnetic**, `chi = -2 x 10^-4`.

# TOPIC 13 — Hysteresis and the B-H loop

## What hysteresis means

Take a piece of iron. Slowly increase the magnetising field `H` and watch `B` grow.
Then reduce `H` back to zero. You find that **B does not come back to zero**. The iron
"remembers".

```
  HYSTERESIS  =  "lagging behind".
  B always LAGS BEHIND H.
```

## THE B-H LOOP (draw this exactly)

```
                              B
                              |
                         b    |
                          ----+---- a          a = SATURATION
                        /     |     \
                       /      |      \
                      /       |       \
                     /        |        \
        -------------+--------+---------+------------------> H
             -Hc    c|        O         |  +Hc
                     |        |        /
                     \        |       /
                      \       |      /
                       \      |     /
                        ------+-----
                         d    |   e
                              |
                          -Br |
                              |

    O -> a    virgin curve: as H increases, B rises and SATURATES at a
    a -> b    H reduced to zero, but B does NOT: Ob = RETENTIVITY (Br)
    b -> c    H reversed; at Oc, B finally = 0: Oc = COERCIVITY (Hc)
    c -> d    H made more negative: reverse saturation
    d -> e -> a   H brought back up: the curve returns by the lower path

    The path from a to b to c is NOT the same as the path from
    d to e to a.  That difference IS hysteresis.
```

## The two numbers you must be able to define

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |  RETENTIVITY  (also called REMANENCE or residual magnetism), Br    |
  |                                                                    |
  |     The MAGNETIC FLUX DENSITY B that REMAINS in the material       |
  |     when the magnetising field H is reduced to ZERO.               |
  |                                                                    |
  |     "How much magnetism the material keeps by itself."             |
  |     Unit: tesla.                                                   |
  |                                                                    |
  +--------------------------------------------------------------------+

  +--------------------------------------------------------------------+
  |                                                                    |
  |  COERCIVITY  (or coercive force), Hc                               |
  |                                                                    |
  |     The REVERSE magnetising field H that must be applied to        |
  |     reduce the residual magnetism B to ZERO.                       |
  |                                                                    |
  |     "How hard it is to demagnetise the material."                  |
  |     Unit: ampere / metre.                                          |
  |                                                                    |
  +--------------------------------------------------------------------+
```

## ENERGY LOSS — the area of the loop

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |     THE AREA ENCLOSED BY THE B-H LOOP                              |
  |         =  the ENERGY LOST as HEAT                                 |
  |            per UNIT VOLUME  per CYCLE of magnetisation             |
  |                                                                    |
  |     Energy lost per cycle  =  (area of loop) x (volume)            |
  |                                                                    |
  |     Total energy in time t at frequency f :                        |
  |                                                                    |
  |         W  =  (area) x (volume) x f x t        joules              |
  |                                                                    |
  |     Units of "area of the loop" :  J / m^3  per cycle              |
  |                                                                    |
  +--------------------------------------------------------------------+

  WHERE DOES THE ENERGY GO?
  Into repeatedly re-orienting the domains, which rubs and heats
  the material. This is HYSTERESIS LOSS.
```

## The shape of the loop decides the use

```
      SOFT IRON                             STEEL
   (thin, tall, narrow loop)          (fat, wide loop)

           B                                   B
           |                                   |
        ---+---                          ------+------
       /   |   \                       /       |       \
       |   |   |                      /        |        \
   ----+---+---+----> H          ----+---------+---------+----> H
       |   |   |                      \        |        /
       \   |   /                       \       |       /
        ---+---                          ------+------
           |                                   |

   small area  ->  small energy loss     large area -> large energy loss
   LOW coercivity                        HIGH coercivity
   HIGH retentivity, but easily lost     keeps its magnetism firmly
```

## SOFT IRON versus STEEL — the comparison table

| Property | SOFT IRON | STEEL |
|---|---|---|
| Shape of the B-H loop | **Narrow / thin**, tall | **Wide / fat** |
| Area of the loop | **Small** | **Large** |
| Hysteresis loss per cycle | **Small** | **Large** |
| Retentivity (remanence) | **High** | Lower than soft iron |
| Coercivity | **LOW** (easy to demagnetise) | **HIGH** (hard to demagnetise) |
| Permeability `mu` | **Very high** | Lower |
| Susceptibility | Very high | Lower |
| Magnetism when the current stops | Almost completely lost | Largely **retained** |
| **USED FOR** | **ELECTROMAGNETS, transformer cores, motor and generator cores, chokes, telephone diaphragms** | **PERMANENT MAGNETS**, magnetic compass needles, loudspeaker magnets |

```
  THE LOGIC, IN ONE BREATH

     A TRANSFORMER core is magnetised and demagnetised 50 times a
     second. Each cycle wastes energy equal to the loop area.
     So you want the SMALLEST possible area  ->  SOFT IRON.

     A PERMANENT MAGNET must hold on to its magnetism for years
     against stray fields and knocks.
     So you want the HIGHEST possible coercivity  ->  STEEL / alnico.
```

> **TRAP:** Many students write "steel has higher retentivity than soft iron".
> The safe, correct board answer is: **soft iron has high retentivity but LOW
> coercivity; steel has HIGH coercivity**. It is the **coercivity** that makes steel
> the permanent-magnet material. Say coercivity and you cannot go wrong.

## WORKED EXAMPLE 13.1

*The hysteresis loop of a material has an area of 250 J/m^3 per cycle. A core of volume
10^-4 m^3 made of this material is used in a transformer working at 50 Hz. Find the
energy lost as heat in one hour.*

```
  STEP 1  Energy per cycle
             =  area x volume
             =  250 x 10^-4
             =  0.025  J


  STEP 2  Cycles in one hour
             =  50 x 3600
             =  1.8 x 10^5  cycles


  STEP 3  Total energy
             =  0.025 x 1.8 x 10^5
             =  4500  J
             =  4.5  kJ
```

**ANSWER:** **4500 J = 4.5 kJ** lost as heat in one hour.

# TOPIC 14 — Permanent magnets and electromagnets

## What makes a good PERMANENT magnet

```
  REQUIREMENTS
     1.  HIGH RETENTIVITY      -> so it stays strongly magnetised
     2.  HIGH COERCIVITY       -> so stray fields cannot demagnetise it
     3.  HIGH SATURATION magnetisation
     4.  Mechanically hard, resistant to knocks and corrosion

  MATERIALS
     steel, cobalt-steel, ALNICO (aluminium + nickel + cobalt + iron),
     TICONAL, and modern rare-earth magnets like samarium-cobalt and
     neodymium-iron-boron (NdFeB).
```

## THREE WAYS TO MAKE A PERMANENT MAGNET

```
  METHOD 1 — SINGLE TOUCH
     Stroke the steel bar repeatedly from one end to the other, always
     in the SAME direction, with ONE pole of a strong magnet.
     Lift the magnet away at the end of each stroke.

        magnet
          |
          v
        [ N ]  ---->  ---->  ---->
        =========================         steel bar


  METHOD 2 — DOUBLE TOUCH
     Place the UNLIKE poles of two magnets at the middle of the bar and
     stroke outwards to the two ends simultaneously. Repeat many times.

           N       S
            \     /
        =========================         steel bar


  METHOD 3 — ELECTRICAL METHOD (best)
     Place the steel rod INSIDE a solenoid and pass a strong DC current.
     The rod is magnetised along the axis of the solenoid.
     Its polarity is given by the right-hand thumb / clock rule.

        ((((((((((((((((((
        (  =============  )   <-- steel rod inside
        ((((((((((((((((((
              I --->


  METHOD 4 — HAMMERING IN THE EARTH'S FIELD
     Hold a steel rod along the magnetic meridian, tilted at the angle
     of dip, and hammer it. The vibration lets the domains settle along
     the earth's field.
```

## ELECTROMAGNETS

```
  An ELECTROMAGNET is a SOFT IRON core wrapped with an insulated coil.
  It is a magnet ONLY while the current flows.

        ((((((((((((((((((
        (  =============  )   <-- SOFT IRON core
        ((((((((((((((((((
              I --->

  REQUIREMENTS
     1.  HIGH permeability          -> a very strong field for a small current
     2.  LOW coercivity / LOW retentivity
                                    -> switches OFF completely when the
                                       current stops
     3.  SMALL hysteresis loop area -> little heating

  MATERIAL:  SOFT IRON (or mu-metal, permalloy)

  USES
     electric bells, relays, telephone earpieces, loudspeakers,
     electric motors and generators, transformers, MRI machines,
     lifting scrap iron in junkyards, magnetic separators,
     maglev trains, particle accelerators.
```

## PERMANENT MAGNET versus ELECTROMAGNET

| Point | PERMANENT MAGNET | ELECTROMAGNET |
|---|---|---|
| Material | Steel / alnico | Soft iron |
| Needs a current? | No | **Yes**, works only while current flows |
| Strength | Fixed, moderate | **Adjustable** — change the current or turns |
| Can be switched off? | No | **Yes** |
| Polarity | Fixed | **Reversible** by reversing the current |
| Coercivity needed | High | Low |
| Retentivity after switch-off | High (that is the point) | Should be nearly zero |
| Uses | Compass, loudspeaker, moving-coil meters | Bells, relays, cranes, motors, MRI |
