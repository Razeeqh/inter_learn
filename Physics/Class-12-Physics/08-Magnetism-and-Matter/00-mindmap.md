## THE 60-SECOND VERSION

```
  1.  A bar magnet is really a tiny CURRENT LOOP (a solenoid).
      Its strength is the magnetic dipole moment  M = m x 2l = N I A.

  2.  Break a magnet and you get TWO smaller magnets.
      A single N pole or a single S pole has NEVER been found.
      That single fact IS Gauss's law in magnetism:  total flux = 0.

  3.  The field of a bar magnet copies the ELECTRIC DIPOLE exactly.
      Replace  p -> M  and  1/(4 pi e0) -> mu0/(4 pi)  and you are done.

  4.  In a uniform field a magnet feels NO net force but a TORQUE
      tau = M B sin(theta), stores energy U = -M B cos(theta),
      and if disturbed it oscillates with T = 2 pi sqrt( I / (M B) ).

  5.  The Earth itself is a giant magnet tilted about 11.3 degrees.
      Three numbers fix its field anywhere: DECLINATION, DIP, and B(H).

  6.  Matter responds in three ways: DIAMAGNETIC (weakly pushed out),
      PARAMAGNETIC (weakly pulled in), FERROMAGNETIC (strongly pulled in).

  7.  Ferromagnets remember their history -> the HYSTERESIS loop.
      Fat loop -> permanent magnet (steel).
      Thin loop -> electromagnet / transformer core (soft iron).
```

## THE KEY BOX — THE FORMULAS THAT UNLOCK MOST QUESTIONS

```
  +--------------------------------------------------------------------+
  |                                                                    |
  |                          mu0     2 M                               |
  |    AXIAL:        B  =  ------ x -------        (along the axis)    |
  |                         4 pi      r^3                              |
  |                                                                    |
  |                          mu0       M                               |
  |    EQUATORIAL:   B  =  ------ x -------        (perpendicular      |
  |                         4 pi      r^3           bisector)          |
  |                                                                    |
  |         ==>   B(axial)  =  2  x  B(equatorial)   at the same r     |
  |                                                                    |
  +--------------------------------------------------------------------+

  +--------------------------------------------------------------------+
  |                                                                    |
  |    TORQUE     tau  =  M B sin(theta)      (vector:  M x B)         |
  |                                                                    |
  |    ENERGY     U    =  - M B cos(theta)    (vector:  - M . B)       |
  |                                                                    |
  |    SHM        T    =  2 pi sqrt( I / (M B) )                       |
  |                                                                    |
  +--------------------------------------------------------------------+

  +--------------------------------------------------------------------+
  |                                                                    |
  |    B  =  mu0 ( H + M )        chi = M / H        mu(r) = 1 + chi   |
  |                                                                    |
  |    EARTH:   B(H) = B cos(dip)      B(V) = B sin(dip)               |
  |                                                                    |
  |             tan(dip) = B(V) / B(H)      B = sqrt( B(H)^2 + B(V)^2 )|
  |                                                                    |
  +--------------------------------------------------------------------+
```

**mu0 / (4 pi) = 10^-7 T m / A exactly. Memorise it as "ten to the minus seven".**
