# Moving Charges and Magnetism — Every Question Pattern That Can Be Asked

A "pattern" is a question SHAPE. The numbers change every year. The shape does not.

For each one, learn:
- **TRIGGER** — how to recognise it in one glance
- **METHOD** — the fixed steps
- **TRAP** — where marks get lost

---

```
  PATTERN 1 — OERSTED'S EXPERIMENT / MAGNETIC EFFECT OF CURRENT     2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the importance of Oersted's experiment?"
            "How do magnetic field lines differ from electric field lines?"
  METHOD    1. A magnetic needle near a current-carrying wire DEFLECTS.
            2. Reversing the current reverses the deflection.
            3. Conclusion: a current produces a magnetic field around it;
               electricity and magnetism are linked.
            4. For the second version: magnetic lines are CLOSED loops,
               electric lines are OPEN (start on +, end on -), because
               isolated magnetic poles do not exist.
  TRAP      Do not just say "the needle moves". Say WHAT it proves.
```

```
  PATTERN 2 — FORCE ON A MOVING CHARGE + SPECIAL CASES              2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Write the expression for the force on a moving charge."
            "When is the force maximum / minimum?"
  METHOD    F = q v B sin(theta) ,   F = q ( v x B )
            theta = angle between v AND B
            theta = 90  -> F = qvB  MAXIMUM
            theta = 0 or 180 -> F = 0
            v = 0 -> F = 0 ; q = 0 -> F = 0
  TRAP      theta is between v and B - not between v and the wire, not
            between the plane of anything and anything.
```

```
  PATTERN 3 — DIRECTION OF THE MAGNETIC FORCE                       2 marks
  ------------------------------------------------------------------------
  TRIGGER   "An electron moves east in a field pointing north. Find the
            direction of the force." / "State Fleming's left hand rule."
  METHOD    1. Work out  v x B  using the right hand rule
               (fingers along v, curl to B, thumb gives v x B).
            2. If the charge is NEGATIVE, REVERSE the answer.
            OR use Fleming's LEFT hand rule:
               First finger = Field, seCond = Current, thuMb = Motion.
  TRAP      Forgetting to reverse for an electron. That single slip is
            the most common error in this whole chapter.
```

```
  PATTERN 4 — "MAGNETIC FORCE DOES NO WORK"                         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why does a magnetic field not change the speed of a charge?"
            "What is the work done by a magnetic force?"
  METHOD    1. F = q(v x B) is ALWAYS perpendicular to v.
            2. W = F s cos 90 = 0.
            3. Hence the SPEED and the KINETIC ENERGY are unchanged;
               only the DIRECTION changes.
  TRAP      Saying "the field does not affect the particle". It does -
            it changes the direction. Say "it does not change the SPEED".
```

```
  PATTERN 5 — LORENTZ FORCE                                         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "What is the Lorentz force?" / "Write its expression."
  METHOD    F = q E + q ( v x B )  =  q [ E + ( v x B ) ]
            Name the two parts: the electric part and the magnetic part.
  TRAP      Writing only  q(v x B). The word LORENTZ means BOTH forces.
```

```
  PATTERN 6 — VELOCITY SELECTOR                                     2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Undeflected", "goes straight through", "crossed fields",
            "velocity selector", "entrance of a mass spectrometer".
  METHOD    1. Draw E vertical, B into the page, v horizontal.
            2. Electric force qE balances magnetic force qvB.
            3.      q E = q v B     ->     v = E / B
            4. State that it is independent of q and m.
  TRAP      The fields must be MUTUALLY PERPENDICULAR and both
            perpendicular to v. If they are parallel, the path is a helix.
```

```
  PATTERN 7 — CIRCULAR MOTION: DERIVE r, T AND f                    4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A charged particle enters a magnetic field perpendicularly.
            Derive expressions for the radius, time period and frequency."
  METHOD    1. Magnetic force = centripetal force :  qvB = mv^2 / r
            2.  r  =  m v / ( q B )
            3.  T  =  2 pi r / v  =  2 pi m / ( q B )
            4.  f  =  1 / T  =  q B / ( 2 pi m )
            5. STATE that T contains no v and no r, so it is INDEPENDENT
               of the speed. (This sentence carries a mark.)
  TRAP      Forgetting step 5. It is the whole point of the question.
```

```
  PATTERN 8 — NUMERICAL ON r, T OR f                                2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   Numbers given for q, m, v (or K, or V) and B.
  METHOD    Choose the right form of r :
                speed given         ->   r = m v / (q B)
                momentum given      ->   r = p / (q B)
                kinetic energy K    ->   r = sqrt(2 m K) / (q B)
                accelerating p.d. V ->   r = sqrt(2 m V / q) / B
            Then T = 2 pi m / (q B) , f = 1/T .
  TRAP      Convert cm to metres. Convert eV to joules (x 1.6 x 10^-19).
            Write the unit beside the answer.
```

```
  PATTERN 9 — RATIO / COMPARISON OF TWO PARTICLES                   2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A proton and an alpha particle ... find the ratio of ..."
  METHOD    Identify WHAT IS THE SAME, then use:
                same speed      ->  r prop. to  m / q
                same momentum   ->  r prop. to  1 / q
                same KE         ->  r prop. to  sqrt(m) / q
                same p.d. V     ->  r prop. to  sqrt( m / q )
                ALWAYS          ->  T prop. to  m / q
            Data:  proton (1,1)  deuteron (2,1)  alpha (4,2)
  TRAP      Reading "same energy" as "same speed". They give different
            answers. Underline the word before you start.
```

```
  PATTERN 10 — HELICAL PATH AND PITCH                               2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "enters at an angle theta to the field", "pitch of the helix"
  METHOD    1. v_par  = v cos(theta)  -> no force -> uniform drift
               v_perp = v sin(theta)  -> circular motion
            2. r     = m v sin(theta) / (q B)
            3. T     = 2 pi m / (q B)          (unchanged)
            4. pitch = v cos(theta) x T
  TRAP      SIN for the radius, COS for the pitch.
            Memory hook: "Pitch and Cos both sound like C."
```

```
  PATTERN 11 — CYCLOTRON: FULL DESCRIPTION                          8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Describe the construction and working of a cyclotron."
  METHOD    Write ALL SIX parts - each is worth marks:
            1. LABELLED DIAGRAM (dees, ion source, oscillator, magnet
               poles, exit) ................................. 2 marks
            2. PRINCIPLE (repeated acceleration in resonance,
               because T does not depend on speed) .......... 1 mark
            3. CONSTRUCTION (dees, evacuated chamber, magnet) . 1 mark
            4. WORKING (the 5 numbered steps) ................ 2 marks
            5. f = qB / (2 pi m) and KE_max = q^2B^2R^2 / 2m .. 1 mark
            6. LIMITATIONS (4 of them) ....................... 1 mark
  TRAP      Skipping the limitations. They are almost always explicitly
            asked and are the easiest mark in the question.
```

```
  PATTERN 12 — CYCLOTRON NUMERICAL                                  2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "oscillator frequency", "maximum energy of the protons",
            "what magnetic field is needed"
  METHOD    f = q B / (2 pi m)      ->    B = 2 pi m f / q
            KE_max = q^2 B^2 R^2 / (2 m)
            To convert J to MeV, divide by 1.6 x 10^-13.
            Number of revolutions n = KE_max / (2 q V).
  TRAP      Using the proton mass for a deuteron (2x) or an alpha (4x).
            Read which particle it is.
```

```
  PATTERN 13 — LIMITATIONS OF THE CYCLOTRON                         2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Why can't a cyclotron accelerate electrons / neutrons?"
  METHOD    ELECTRONS - too light, become relativistic almost at once,
                        mass increases, T increases, RESONANCE IS LOST.
            NEUTRONS  - neutral, q = 0, so neither qE nor qvB acts.
            Plus: relativistic limit at high speed, and the huge magnet
            needed for high energy.
  TRAP      Saying "electrons are too small". The reason is the
            RELATIVISTIC MASS INCREASE breaking the resonance.
```

```
  PATTERN 14 — FORCE ON A CURRENT-CARRYING CONDUCTOR                2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A wire of length L carrying I is placed at an angle to B."
  METHOD    F = B I L sin(theta) ,  F = I ( L x B )
            theta = angle between the WIRE and B.
            Max = BIL at 90 ; zero at 0 or 180.
            Derivation if asked: F = (nAL)(q vd B sin T) and I = nAq vd.
  TRAP      For a CURVED wire in a uniform field, use the STRAIGHT LINE
            joining the ends as L. For a CLOSED LOOP the net force is ZERO.
```

```
  PATTERN 15 — FORCE BETWEEN TWO PARALLEL CURRENTS + THE AMPERE     4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the force between two parallel currents and hence
            define the ampere."
  METHOD    1. B1 = mu0 I1 / (2 pi d)   at wire 2
            2. F = B1 I2 L
            3. F / L = mu0 I1 I2 / (2 pi d) = 2 x 10^-7 I1 I2 / d
            4. Same direction ATTRACT, opposite REPEL.
            5. Put I1 = I2 = 1 A, d = 1 m  ->  F/L = 2 x 10^-7 N/m
            6. State the full definition of the ampere.
  TRAP      The definition must contain ALL of: infinitely long, straight,
            parallel, negligible cross-section, 1 metre apart, IN VACUUM,
            2 x 10^-7 newton PER METRE.
```

```
  PATTERN 16 — STATE THE BIOT-SAVART LAW                            2 marks
  ------------------------------------------------------------------------
  TRIGGER   "State the Biot-Savart law." / "Write its vector form."
  METHOD    dB is proportional to I, to dl, to sin(theta), and to 1/r^2.

                mu0     I dl sin(theta)              mu0    I (dl x r_hat)
        dB  =  ------ x -----------------     dB =  ------ x -------------
                4 pi          r^2                    4 pi         r^2

            Direction: perpendicular to the plane of dl and r.
  TRAP      Forgetting to say what theta is (the angle between dl and r),
            and forgetting the DIRECTION statement.
```

```
  PATTERN 17 — FIELD DUE TO A STRAIGHT CONDUCTOR                    4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive B due to a straight wire of finite length."
            "Show that for an infinite wire B = mu0 I / (2 pi r)."
  METHOD    1. Take an element dl at angle phi from the perpendicular.
            2. Substitute l = a tan(phi), dl = a sec^2(phi) dphi,
               r = a sec(phi).
            3. dB = (mu0 I / 4 pi a) cos(phi) dphi
            4. Integrate:  B = (mu0 I / 4 pi a)(sin phi1 + sin phi2)
            5. Infinite wire: phi1 = phi2 = 90  ->  B = mu0 I / (2 pi r)
  TRAP      For a SEMI-infinite wire (point opposite one end) only ONE
            angle is 90 and the other is 0, giving mu0 I / (4 pi a).
```

```
  PATTERN 18 — FIELD ON THE AXIS OF A CIRCULAR LOOP                 8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Using the Biot-Savart law, derive B at a point on the axis
            of a circular current loop."
  METHOD    1. State Biot-Savart law + draw the labelled diagram.
            2. Every element is perpendicular to r, so sin(theta) = 1.
            3. dB = (mu0/4pi) I dl / (a^2 + x^2)
            4. Resolve into axial and perpendicular components.
            5. Say clearly: PERPENDICULAR COMPONENTS CANCEL in pairs.
            6. cos(alpha) = a / sqrt(a^2 + x^2)
            7. INT dl = 2 pi a
            8. B = mu0 N I a^2 / [ 2 (a^2 + x^2)^(3/2) ]
            9. Put x = 0  ->  B = mu0 N I / (2 a)
  TRAP      Step 5 carries a full mark on its own. Write the sentence
            about cancellation explicitly.
```

```
  PATTERN 19 — FIELD AT THE CENTRE OF A COIL OR AN ARC              2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find B at the centre of a coil / semicircle / arc."
  METHOD    Coil (N turns) :   B = mu0 N I / ( 2 a )
            Arc of angle theta (RADIANS) :
                               B = ( mu0 I / 2a ) x ( theta / 2 pi )
                                 = mu0 I theta / ( 4 pi a )
            semicircle -> mu0 I / 4a ,  quarter -> mu0 I / 8a
  TRAP      There is NO pi in the denominator for a full coil.
            Straight wire has 2 pi r ; a coil centre has just 2a.
```

```
  PATTERN 20 — "SAME WIRE BENT INTO n TURNS"                        2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "A wire of length L is bent into n turns of a circular coil.
            Find B at the centre."
  METHOD    1. L = n ( 2 pi a )   ->   a = L / (2 pi n)
            2. B = mu0 n I / (2a) = mu0 pi n^2 I / L
            3. So B is proportional to n^2.
  TRAP      Using the original radius. The radius SHRINKS when you make
            more turns from the same wire.
```

```
  PATTERN 21 — STATE AND APPLY AMPERE'S CIRCUITAL LAW               2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "State Ampere's circuital law." / "Using it find B ..."
  METHOD    INT B.dl = mu0 I_enclosed  round any CLOSED (Amperian) loop.
            Recipe:
              1. Choose a loop on which B is constant and parallel to dl.
              2. INT B.dl = B x (length of that loop).
              3. Count the enclosed current.
              4. Equate and solve.
  TRAP      Only the current THREADING the loop counts. Currents outside
            the loop contribute nothing to the integral.
```

```
  PATTERN 22 — SOLENOID FROM AMPERE'S LAW                           4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the magnetic field inside a long solenoid."
  METHOD    1. Draw the solenoid with a rectangular Amperian loop abcd,
               ab inside along the axis (length L), cd outside.
            2. ab gives BL ; bc and da give 0 (B perpendicular to dl) ;
               cd gives 0 (B = 0 outside).
            3. I_enclosed = n L I
            4. B L = mu0 n L I   ->   B = mu0 n I
            5. Mention: uniform inside, mu0 n I / 2 at each END,
               zero outside.
  TRAP      n is turns PER METRE. If the question gives 500 turns in
            50 cm, then n = 1000, not 500.
```

```
  PATTERN 23 — TOROID FROM AMPERE'S LAW                             4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the magnetic field inside a toroid."
  METHOD    1. Amperian loop = a circle of mean radius r through the core.
            2. INT B.dl = B ( 2 pi r )
            3. I_enclosed = N I     (N = TOTAL turns)
            4. B = mu0 N I / ( 2 pi r )
            5. State that B = 0 both in the hollow centre and outside.
  TRAP      Here N is the TOTAL number of turns, unlike the solenoid
            where n is per metre. Getting these two swapped is the
            single most common mistake in this pair of derivations.
```

```
  PATTERN 24 — CURRENT LOOP AS A MAGNETIC DIPOLE                    2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define the magnetic dipole moment of a current loop."
  METHOD    M = N I A ;  direction along the normal by the right hand
            rule ;  SI unit A m^2 ; dimensions [ L^2 A ].
            Add: far on the axis, B = (mu0/4pi)(2M / x^3), the field of
            a magnetic dipole - which is WHY a loop is called a dipole.
  TRAP      Forgetting N. For a circular loop A = pi a^2, not 2 pi a.
```

```
  PATTERN 25 — TORQUE ON A CURRENT LOOP (DERIVATION)                4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Derive the torque on a current-carrying coil in a uniform
            magnetic field."
  METHOD    1. Force on each of the two sides of length l : F = B I l.
            2. They are equal, opposite and not collinear -> a COUPLE.
            3. Perpendicular distance between them = b sin(theta).
            4. tau = (B I l)(b sin theta) = B I A sin(theta).
            5. For N turns : tau = N I A B sin(theta) = M B sin(theta),
               vector form tau = M x B.
            6. Add: the NET FORCE is zero in a uniform field.
  TRAP      theta is between the NORMAL and B. If the question gives the
            angle with the PLANE, use  90 - that angle.
```

```
  PATTERN 26 — POTENTIAL ENERGY / WORK ON A MAGNETIC DIPOLE         2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Find the work done in rotating the coil from ... to ..."
  METHOD    U = - M B cos(theta)  =  - ( M . B )
            W = M B ( cos theta1  -  cos theta2 )
            theta = 0   -> U = -MB, STABLE
            theta = 180 -> U = +MB, UNSTABLE
            0 to 180 -> W = 2 M B
  TRAP      The minus sign in U. And theta is measured from B, not from
            the plane of the coil.
```

```
  PATTERN 27 — MOVING COIL GALVANOMETER: FULL DESCRIPTION           8 marks
  ------------------------------------------------------------------------
  TRIGGER   "Describe the construction and working of a moving coil
            galvanometer."
  METHOD    1. LABELLED DIAGRAM (coil, suspension, concave poles,
               soft iron core, hair spring, mirror) ........ 2 marks
            2. PRINCIPLE (torque on a current-carrying coil,
               balanced by the twist of the suspension) .... 1 mark
            3. CONSTRUCTION ............................... 1 mark
            4. DERIVATION  N I A B = C phi , I = (C/NAB) phi  2 marks
            5. Radial field -> sin(theta) = 1 -> UNIFORM SCALE
               and the soft iron core ..................... 1 mark
            6. Current and voltage sensitivity ............ 1 mark
  TRAP      Not explaining WHY the field is made radial. That single
            sentence ("so that the scale is uniform") is worth a mark.
```

```
  PATTERN 28 — SENSITIVITY AND FIGURE OF MERIT                      2 marks
  ------------------------------------------------------------------------
  TRIGGER   "Define current sensitivity / voltage sensitivity /
            figure of merit."
  METHOD    current sensitivity = phi / I = N A B / C      (div per A)
            voltage sensitivity = phi / V = N A B / (C G)  (div per V)
                                = current sensitivity / G
            figure of merit  k  = I / phi = C / (N A B)    (A per div)
                                = 1 / current sensitivity
  TRAP      The statement "increasing the current sensitivity does not
            necessarily increase the voltage sensitivity" (because G
            also rises with N) is itself a repeated 2-mark question.
```

```
  PATTERN 29 — CONVERT A GALVANOMETER INTO AN AMMETER               2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is a galvanometer converted into an ammeter?"
            "Find the shunt required to read up to ... A."
  METHOD    1. Connect a LOW resistance SHUNT S in PARALLEL.
            2. Ig G = ( I - Ig ) S
            3.  S = Ig G / ( I - Ig )
               or, if the range is multiplied n times,  S = G / (n - 1)
            4. Resistance of the ammeter = G S / (G + S) - very small.
            5. Ideal ammeter has ZERO resistance.
  TRAP      Putting the shunt in series. Memory hook:
            "Ammeter = A = pArAllel".
```

```
  PATTERN 30 — CONVERT A GALVANOMETER INTO A VOLTMETER              2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "How is a galvanometer converted into a voltmeter?"
            "Find the resistance to be connected to read up to ... V."
  METHOD    1. Connect a HIGH resistance R in SERIES.
            2. V = Ig ( G + R )
            3.  R = V / Ig  -  G
               or, if the range is multiplied n times,  R = G ( n - 1 )
            4. Resistance of the voltmeter = G + R - very large.
            5. Ideal voltmeter has INFINITE resistance.
  TRAP      Forgetting to SUBTRACT G. V/Ig is the TOTAL resistance;
            R is only the extra piece you add.
```

```
  PATTERN 31 — COMPARE / DISTINGUISH QUESTIONS                      2-4 marks
  ------------------------------------------------------------------------
  TRIGGER   "Distinguish between ..."
  METHOD    Learn these four comparison tables:
            1. Biot-Savart law  vs  Ampere's circuital law
            2. Ammeter  vs  Voltmeter
            3. Electric force  vs  Magnetic force on a charge
            4. Magnetic field lines  vs  Electric field lines
  TRAP      Write them as a TABLE with matching rows, not as two
            separate paragraphs. Examiners award per matched pair.
```
